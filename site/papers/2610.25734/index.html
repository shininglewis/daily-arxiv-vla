Card 03 核心贡献

核心贡献

  • 提出 Think Densely, Act Sparsely 新驾驶范式：在生成稀疏动作前，先于潜空间构建稠密的视觉-语义-几何世界理解，为 VLA 框架的稠密信息损失问题提供原则性解决方案。
  • 设计 Latent Expert Cognitive Chain（潜在专家认知链）：注入少量任务特定潜在 token，按“表征→语义→几何”的课程式顺序渐进内化基础视觉模型知识，实现低成本、可解释的稠密世界建模。
  • 设计 Dense Perception Capability Heads（稠密感知能力头）：分别对应 DINOv3 特征对齐、SAM3 交通语义分割、DepthAnything3 度量深度估计，并利用冻结专家模型生成伪标签进行监督。
  • 提出 离散运动基元检索 + 连续偏移精修 的混合轨迹表示，将直接航点预测转为“检索+精修”，提升轨迹规划的鲁棒性与精度。
  • 在 5 个主流基准（开放/闭环规划与语言驱动感知预测）上取得一致且显著的性能提升，验证范式的普适有效性。
Card 04 方法描述

方法描述

  • 骨干网络采用 Qwen2.5-VL-7B，输入多视角驾驶图像与任务指令；nuScenes 系基准用 6 路环视，NAVSIM 用前左/前/前右 3 路前视，规划任务额外注入自车状态与导航指令。
  • 在每个视角的视觉 token 后插入三组任务特定潜在 token：\、\、\，每组 n=8 个，作为稠密知识的“载体”。
  • 从 VLM 的第 4、10、18、28 层按固定位置 ID 掩码抽取对应专家嵌入并跨层聚合（维度 4·D），以缓解极窄 token 预算下的层级信息损失。
  • 三个轻量稠密头通过 Pixel Shuffle 上采样 + 线性投影 将嵌入还原为 2D 特征图后做稠密预测。
  • 联合训练目标：L = λ₁·L_CE + λ₂·L_DINO + λ₃·L_SAM + λ₄·L_DEPTH，其中 DINO 用 MSE，SAM 用加权交叉熵（背景权重 0.2，前景 1.0），深度用掩码 SmoothL1（仅优化 0
  • 关键创新点：专家阶段并非独立多任务目标，而是相互依赖的潜空间认知链，高层监督反向精修低层表征，模拟人类层级化感知过程。
Card 05 数据集与资源

数据集与资源

  • 语言/感知预测基准：NuInstruct、DriveLM、OmniDrive
  • 轨迹规划基准：nuScenes-Plan（开环）、NAVSIM v1 / v2 navtest（闭环）
  • 专家模型：DINOv3（ViT，840M 参数，LVD-1689M 预训练）、SAM 3、DepthAnything3（DA3NESTED-GIANT-LARGE，1.4B 参数）
  • 主模型：Qwen2.5-VL-7B，每专家潜在 token 数 n=8；轨迹聚类为 2048 个运动基元
  • 训练配置：学习率 5×10⁻⁵，训练 5 个 epoch，损失权重 λ₁=1、λ₂=0.5、λ₃=0.5、λ₄=1.5
  • 计算资源：8 张 NVIDIA H200 GPU
Card 06 评估与结果

评估与结果

  • NAVSIM-v1（闭环）：PDMS 达 89.81，较解耦式方法 AdaThinkDrive 提升 +2.31，较几何增强方法 VGGDrive 提升 +1.05；NC 98.72、DAC 96.97、EP 83.68、TTC 96.39。
  • NAVSIM-v2 navtest：EPDMS 89.44，超过 VGGDrive +0.94，并在 NC(98.73)、DCC(99.49)、TLC(99.88)、TTC(98.43)、LK(97.34)、HC(98.34) 上领先或持平。
  • NuInstruct：MAP 38.25（基线 6.15，+32.10）、Accuracy 57.02（+9.31）、BLEU 82.38、MAE 3.57、综合 43.52，优于 InMLLM（20.13）与 VGGDrive（42.98）。
  • DriveLM：Accuracy 79.81（较基线 +15.46）、Average 61.41（+6.82），ChatGPT 65.69、Language 56.53、Match 47.73。
  • 消融实验（NAVSIM-v1）：基线 PDMS 86.04 → 加 MT/Offset 87.44 → 加 DINOv3 +0.58 → 加 SAM3 +0.24 → 加 DA3 +0.50 至 89.81；移除任一专家均导致性能下降，说明三者互补。
  • 可视化：仅用 8 个任务特定潜在 token 即可生成语义分割与深度估计的稠密世界建模结果，并保持风险目标感知与状态预测能力。
