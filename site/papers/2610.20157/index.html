Card 03 核心贡献

核心贡献

  • 提出 Atomic-WAM：一个 understand-then-execute 框架，通过状态相关的原子动作描述把高层任务推理与视频–动作联合生成连接起来。
  • 设计可扩展的原子动作标注流水线：融合末端位移（displacement）与夹爪（gripper）线索、多视角证据与视觉校验，为动作选择和执行提供时间对齐、富含接触信息的监督。
  • 提出 Execution-Grounded GRPO（EG-GRPO） 闭环推理器适配方法：在冻结 WAM 的条件下，利用物理执行结果作为奖励信号，同时优化“动作合理性”与“执行成功率”。
  • 在 RoboLab 的真实到仿真（real-to-sim）评测中取得领先结果：默认指令下 39.6% 任务成功率，模糊指令下 31.6%，分别比 Cosmos3-Nano-Policy 提升 2.8 和 11.0 个百分点。
Card 04 方法描述

方法描述

  • 理解–执行流水线：基于 Cosmos3-Nano 实现，由自回归 reasoner（VLM 推理器） 与基于扩散的 video–action generator（WAM） 组成；推理器输入任务指令 \(l\) 与视觉上下文 \(o_{t-h:t}\)，输出原子动作描述 \(\hat{d}_t\)，再与当前观测 \(o_t\)、机器人状态 \(s_t\) 一起条件化 WAM，生成未来视频潜变量 \(\hat{x}^v_t\) 与动作块 \(\hat{x}^a_t\)。
  • 原子动作数据构建：受 VITRA 中基于速度的手轨迹分割启发，用末端执行器速度变化与夹爪状态转换划分物理片段；再对左、右、腕部三视角分别标注（可见动作、操作物体、来源位置、目标位置），利用时序上下文合并相邻片段为原子动作段，并为抓取段补充可见抓取点与夹爪位置等接触细节。
  • 监督学习：推理器以 LoRA 微调，目标为描述 token 的负对数似然 \(\mathcal{L}_{\mathrm{reason}}\)；WAM 使用 joint flow matching 同时预测视频与动作，损失为 \(\mathcal{L}_{\mathrm{exec}}=w_v\mathcal{L}^{v}_{\mathrm{FM}}+w_a\mathcal{L}^{a}_{\mathrm{FM}}\)；两组件使用独立前向与优化器并行训练，WAM 侧条件由禁用 LoRA 的冻结基座推理器编码。
  • EG-GRPO 闭环适配：将推理器视为原子动作描述的高层策略 \(\pi_{\psi,\phi}\)，对同一状态采样 \(K\) 个候选动作，由冻结 WAM 独立执行得到 rollout \(\xi_{t,i}\)，计算任务奖励 \(r^{\mathrm{task}}_{t,i}\) 与执行奖励 \(r^{\mathrm{exec}}_{t,i}\)，层次化组合 \(r_{t,i}=r^{\mathrm{task}}_{t,i}(0.5+0.5r^{\mathrm{exec}}_{t,i})\)；组内归一化得到优势 \(\widehat{A}_{t,i}\)，用带 KL 正则的 GRPO 目标更新 LoRA，仅更新 \(\phi\)，基座推理器与执行器保持冻结。
  • 关键创新：用原子动作描述作为推理与执行之间的显式接口；用执行结果（而非仅语义合理性）直接优化高层推理器，实现对执行器能力对齐。
Card 05 数据集与资源

数据集与资源

  • DROID 数据集：使用 57k 条成功演示，转换得到 369k 个原子动作片段用于监督训练。
  • 标注模型：使用 Qwen 系列模型进行多阶段标注与校验，报告 96.8% 的 checker 通过率，并对 200 个通过样本人工复核得到 90.5% 一致性。
  • 基础模型：推理器与 WAM 均以 Cosmos3-Nano 初始化；推理器 LoRA 配置为 r=128、α=256。
  • 训练资源：32 张 NVIDIA A800 GPU。
  • 训练配置：WAM 训练 14,000 步、batch size 768、学习率 2×10⁻⁴、视频/动作权重 w_v=w_a=10、32 步动作块；推理器训练 3,000 步、学习率 5×10⁻⁵，三帧观测与单帧观测按 8:2 混合（历史跨度为 8 帧与 16 帧前）。
  • EG-GRPO 设置：在 4 个 RoboLab 任务（丢弃苹果、把 Rubik 方块放入箱中、把电子设备放入箱中、装罐）上采样，每状态 4 个候选描述（温度 1.0），执行 30 次更新、batch size 8、学习率 10⁻⁵。
Card 06 评估与结果

评估与结果

  • 评测环境：采用 RoboLab 真实到仿真（real-to-sim）基准，共 120 个分布外任务、每任务 10 个随机种子；涵盖 visual（视觉）、relational（关系）、procedural（程序性） 三类能力；同时评测默认指令与模糊指令两种设定，指标为任务成功率 SR 与子任务进度 Score。
  • 主结果：Atomic-WAM 在两种指令设定下均取得最佳综合表现——默认指令 39.6% SR / 53.7 Score，模糊指令 31.6% SR / 46.7 Score；从默认到模糊指令仅下降 8.0 个百分点，而 Cosmos3-Nano-Policy 下降 16.2 个百分点。
  • 能力分层结果：视觉任务提升最显著（默认 26.1%→34.0%，模糊 13.5%→26.3%）；关系任务在模糊指令下提升明显（32.4%→38.6%）；程序性任务提升较小，默认指令下 25.9% 略低于 Cosmos3-Nano-Policy 的 27.3%。
  • 消融实验（原子动作监督）：基线 30.0% → 加入原子动作描述 32.5% → 再加入可见抓取点与夹爪位置细节 36.7%。
  • 消融实验（推理器适配）：监督推理器 36.7%，去掉执行奖励的 GRPO 降至 34.2%，EG-GRPO 提升至 39.2%。
  • 推理器对比分析：在 64 个 RoboLab 任务子集上，训练后的推理器完成 23 个任务，基于 GPT-5.6-Sol 的 Codex agent 不回退时完成 33 个、允许回退时完成 50 个，说明单纯更强推理提升有限，执行反馈对动作选择至关重要。
  • 训练效率：为便于迭代实验，将全局 batch 从 8,192 降至 768、训练至 20,000 步（约 80 小时）；复现基线最佳为 30.0%（12,000 步），监督版 Atomic-WAM 在 13,000/14,000 步达到 36.7%，18,000 步时两者分别回落到 26.7% 与 30.0%。
  • 局限性：EG-GRPO 中执行奖励评估成本高（30 次更新对应 960 次 rollout），当前使用人工判断执行成功，未来计划开发高效自动执行评估器以支持更大规模训练。
