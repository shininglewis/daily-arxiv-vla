MIM-VLA: Learning Physical Interaction Representations from Gripper Motor Feedback

Card 02 论文概述

论文概述

  • 论文提出 MIM-VLA，一种基于夹爪电机反馈的视觉-语言-动作架构，用于学习物理交互表征
  • 核心问题：现有 VLA 策略主要依赖视觉观察和机器人状态，未显式表示接触后的物理响应，难以判断物体硬度、柔软度或易碎性
  • 研究目标：利用夹爪已有的电流、位置、速度等遥测信号，构建时序交互 token，提升接触丰富操作中的物理推理与抓取控制
Card 03 核心贡献

核心贡献

  • 提出仅用电机信号的 Motor Interaction Module (MIM)，从夹爪时序遥测中预训练出 128 维交互 token，无需校准力传感
  • 设计夹爪专用集成方式：交互 token 仅条件化 SmolVLA 的夹爪动作路径，保留预训练视觉-语言骨干、手臂路径和位置控制接口
  • 提出 Material Explain Module (MEM)，复用交互 token 进行候选对象比较、选择与解释
  • 在三个真实世界任务中验证：跨外观硬度比较、外观匹配的物理消歧、易碎物体轻柔抓取
  • 证明时序监督的电机交互表征优于瞬时原始电流条件化或普通 SmolVLA
Card 04 方法描述

方法描述

  • MIM-VLA 将物理交互表征与任务级视觉和动作生成分离
  • MIM 输入因果窗口的夹爪测量历史，包括位置、速度、电流及其一阶差分、电机状态位、有效性掩码和时间信息；排除指令位置、目标位置、电流限制和饱和指示
  • MIM 预训练：使用 GRU 编码时序，MLP 输出交互 token τ ∈ R^128；用二元接触标签和五阶段标签（idle、closing、squeeze、hold、opening）监督辅助头；视频仅用于生成标签，不输入编码器
  • MEM：按候选对象存储交互 token 历史，通过 Temporal Summary Module 生成摘要 token；默认 K=4；摘要与任务指令输入 selector VLM，输出候选选择、相对位置/电流预测和解释
  • SmolVLA 集成：保留 flow-matching 动作公式；可训练投影器将 τ 映射到动作专家上下文；专用夹爪专家接收 token 和基础手臂轨迹；非对称注意力掩码阻止交互 token 反向影响观测上下文
  • 训练策略：先冻结 MIM 训练 Temporal Summary Module，再冻结摘要模块训练 VLM 投影、结构化预测头和 LoRA；策略微调时更新动作专家、投影、交互 token embedding 和 MIM 编码器，冻结预训练接触/阶段头
Card 05 数据集与资源

数据集与资源

  • MIM 预训练数据：360 个交互 episode，包含 18 个物体，每个物体 20 个 episode，有人工审核的接触和阶段标签
  • 实验 1 和 2 训练数据：共 1,200 个训练 episode，用于 probe–compare–select 流程
  • 实验 3 策略数据：197 个策略 episode，加上 43 个无接触基线和 3 个高力诊断负例，共 243 个 episode、65,512 个因果样本，30 Hz，2 秒、200×12 的电机历史窗口
  • 硬件资源：RTX 5090 GPU，batch size 64；机器人平台为 6-DoF OMY F3M follower arm，配 Dynamixel 两指夹爪、overview RGB 相机和 wrist-mounted Intel RealSense D405
  • 通信与部署：ROS 2 和 Zenoh 传输 100 Hz 遥测；实验 3 的 gripper-policy checkpoint 取 10,000 updates；实验 1、2 每对物体 20 trials
Card 06 评估与结果

评估与结果

  • 评估环境：三个真实世界任务——跨外观硬度比较、外观匹配的物理消歧、易碎物体轻柔抓取
  • 基线：vanilla SmolVLA、SmolVLA + raw current、TA-VLA-inspired temporal-current baseline，以及 SmolVLA-flow gripper baseline
  • 实验 1 和 2 选择准确率：MIM-VLA 总体 75.0%（195/260），SmolVLA 48.8%（127/260），raw current 29.2%（76/260）
  • 跨外观 unseen 选择：MIM-VLA 58.3%（35/60），SmolVLA 35.0%，raw current 23.3%
  • 外观匹配任务选择：MIM-VLA 68.3%（41/60），SmolVLA 41.7%，raw current 21.7%
  • 实验 3 轻柔抓取：seen 可变形物体 SAM 2 mask-area reduction 从 SmolVLA-flow 31.4%、TA-VLA-inspired 24.0% 降至 14.2%；unseen 可变形物体从 28.0%、20.8% 降至 12.5%
  • 易碎物体无损伤抓取成功率：seen 易碎物体 50.0%（20/40），SmolVLA-flow 15.0%，TA-VLA-inspired 30.0%；unseen raw egg 30.0%（6/20），SmolVLA-flow 5%，TA-VLA-inspired 15%
  • 消融：MEM 摘要 token 容量 K=4 取得最佳选择准确率（99.5±0.7）、解释一致性（90.0±2.3）和交换一致性（93.8±2.9）；K=2 在 position/current F1 最高，但整体决策与解释性能 K=4 最优
  • 结论：将执行器遥测建模为时序监督的交互表征比瞬时原始输入更有效；局限包括单一夹爪平台、无校准力目标、分割误差敏感、unseen 易碎物体成功有限
