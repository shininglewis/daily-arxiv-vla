Card 03 核心贡献

核心贡献

  • 提出 GameWAM，据作者所述是首个面向原生闭环游戏玩法与 GUI 控制的 WAM，基于并行 Video/Action DiT、块因果注意力和联合流匹配（flow matching），联合生成未来观察与可执行动作。
  • 构建同步的 gameplay 与 GUI 轨迹数据，将标准化游戏数据与脚本化界面交互结合，支持联合世界-动作学习。
  • 提出统一的原生动作与块-周期（block–cycle）公式化方法：支持在共享键盘-鼠标动作空间中完成游戏与 GUI 控制，通过块-周期控制解耦长时程预测与短时程执行，并结合细粒度周期内上下文与分层跨周期历史记忆。
  • 发现 Low-Frequency Action Source Imprinting（LASI，低频动作源印记） 现象——采样动作源的低频成分在固定条件下系统性地引导粗粒度的生成相机运动，跨重规划步骤复用同一动作源时偏差会累积，构成生成式控制的病态失败模式。
Card 04 方法描述

方法描述

  • 采用块因果世界-动作建模：以 (C_{c,k}, ℓ, H_c, s_{c,k}) 作为条件上下文，涵盖周期内观察上下文、语言指令、跨周期视觉历史与本体状态，对 R 个块进行块因果自回归生成。
  • 视觉与动作分别由 Video DiT 和 Action DiT 建模，采用 Fast-WAM 风格的模态解耦掩码（两个模态共享干净前缀、噪声变量互不条件），视频 K/V 状态被 Action DiT 共享，联合视频与动作监督塑造动作生成上下文。
  • 逐动作路由（per-action routing）：通过学习到的路由器在每个动作时间步选择 gameplay 专用或 GUI 专用的动作流预测分支，分别使用各自的连续动作归一化统计，离散维度共享归一化，以适配异构控制分布。

  • 分层跨周期历史记忆：周期内 KV 缓存随周期刷新，周期边界将已执行视觉段经 VAE 和 Conv3D 压缩为 segment token，通过 FIFO 近期缓冲与基于注意力池化、可学习门控更新的长期记忆槽，实现有界内存下的持久多周期条件。

Card 06 评估与结果

评估与结果

  • MCU 基准：GameWAM 在 Mini 与全部任务集上都取得最高平均成功率（ASR Avg Mini 50.7、ASR Avg All 46.6），同时在所有任务类别中成功回合的平均原生动作步数最少（Embodied 138 步、GUI 155 步、Combat 203 步），显著优于 VPT、STEVE-1、ROCKET-1、JARVIS-VLA、OpenHA、Game-TARS 等基线。
  • ViZDoom 四场景：GameWAM 在四个地图上持续优于 Game-TARS，相对所比较的多模态智能体取得具有竞争力或领先的平均奖励（每张地图 50 个回合的均奖励）。
  • 消融分析：移除未来视频监督（action-only）或使用更粗时间采样导致最大性能下降；事件锚定片段采样贡献显著；统一 gameplay/GUI 动作分布劣于模式特定公式；预测-执行水平匹配（P=E）降低 ASR，验证了超越执行范围预测的必要性；跨周期历史对依赖跨重规划信息任务的 GUI 与战斗任务有价值。
  • LASI 诊断：通过受控频域干预，验证低频频段动作源成分在固定条件下系统性导向粗粒度相机运动，跨重规划复用时可累积为持续方向性相机偏差（如原地旋转）。
