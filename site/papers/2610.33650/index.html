Card 03 核心贡献

核心贡献

  • 提出一种仅依赖轨迹的蒸馏方法：将固定的教师特征库、自适应判别器奖励与大规模 VLA 的在线策略优化耦合在一起。
  • 设计基于判别器的密集奖励 + GRPO 在线更新框架，使奖励能随学生行为自适应变化，而教师数据保持冻结不变。
  • 提供系统的训练诊断与续训消融，区分「判别器分类质量」「采样 rollout 行为」「确定性策略评测」三者，揭示分类准确率高并不等于任务成功率提升。
  • 与非受限的白盒 OPD 进行量化对比，同时报告不对等的学生交互预算与优化批次数，明确性能与预算的权衡。
  • 指出仅用 8 维关节位置特征（qpos8）判别的是特征边缘分布而非完整时序轨迹，并讨论其对奖励表达能力的限制。
Card 04 方法描述

方法描述

  • 问题建模：学生策略只接收视觉-语言输入 $x_t$，动作以 action chunk 输出；教师一次性提供轨迹集 $\mathcal{D}_T$，不提供 logits、梯度、权重或隐状态。
  • 特征提取：用固定映射 $\phi:\mathcal{O}\to\mathbb{R}^{8}$ 抽取 8 维关节位置（qpos8），并用教师特征库统计量一次性归一化，教师与学生共享同一映射。
  • 判别器：一个 ReLU-MLP（隐层 [256,256]）区分教师特征与学生特征，使用带标签平滑（$\eta=0.1$）的 BCE 损失，并保留最近 4 个学生 batch 的回放以缓解过拟合。
  • 奖励构造：采用 AIRL 风格的 logit 奖励 $r_t=\log D_\psi(\phi(o_t))-\log(1-D_\psi(\phi(o_t)))$，每个 action chunk 取一个特征样本；不使用 AIRL 的完整奖励恢复结构。
  • 策略更新：将奖励按轨迹求和得到回报，组内相对归一化得到优势 $\hat{A}_i$，再用非对称裁剪的 PPO/GRPO 目标更新 actor；actor 与判别器并行更新，当前 rollout 的奖励在更新前固定。
  • 对照 OPD：白盒 OPD 使用 token 级教师 log-likelihood 减旧学生 log-likelihood 的 stop-gradient 信号，目标函数与 TAD 不同（无裁剪、无组归一化回报）。
Card 05 数据集与资源

数据集与资源

  • 基准环境：ManiSkill3（或 PutOnPlateInScene25Main-v3），Bridge 风格抓取-放置任务，WidowX 机械臂，场景组合随机化。
  • 学生模型：OpenVLA-OFT（7B），经 LoRA 微调的 SFT 初始化，基线 success-once 26.2% / success-at-end 20.3%。
  • 教师模型：同架构经 GRPO 强化学习训练，本地评测 93.8% / 77.3%（模型卡另报 94.1%，评测协议未对齐）。
  • 教师特征库规模：教师采集 5 个外层迭代，得 12,800 = 5×4×64×(80/8) 个 chunk 边界特征样本，之后永不扩充。
  • 训练单元：每外层迭代使用 64 个并行环境 × 4 轮 rollout = 256 条学生轨迹，地平线 80 环境步，action chunk 长度 8。
  • 系统框架：RLinf（Ray 调度 + FSDP actor + Hydra 配置）；GPU/TPU 型号与数量未在正文明确报告（仅提及一次主机显存不足失败）。
Card 06 评估与结果

评估与结果

  • 评测协议：固定测试套件上的贪心解码，每个 checkpoint 使用 n=256 条轨迹；success-once 指任意时刻成功，success-at-end 要求终止时仍成功；为点估计，未做多随机种子检验。
  • 主要结果：TAD 将 OpenVLA-OFT 从 26.2% → 76.6% success-once（+50.4pp）、20.3% → 58.6% success-at-end；白盒 OPD 为 81.6% / 59.4%，TAD 落后 5.0 / 0.8 个百分点。
  • 关键消融：仅 qpos8 + logit 奖励 + 权重衰减 + 回放的早期版本判别准确率约 0.78 但任务成功率仍接近 SFT（26.2%）；用状态-动作特征时判别准确率高达 0.998 却无提升（25.4%）；随机噪声奖励曾出现 42% 的采样 rollout 峰值，说明瞬时峰值不足以证明模仿有效。
  • 学习率诊断：actor lr 为 5e-5 的 v8 在第 150 步达到 68.8% 确定性成功率，明显优于 2e-6 与 1e-5 的配置。
  • 续训结果：从共享 step-150 checkpoint 出发的四 epoch 续训取得最佳 TAD 结果（76.6% / 58.6%），比 step-150 高 7.8 / 12.1pp，且未增加教师数据；但采样 rollout 区间（59.8%–70.0%）与基线（59.4%–69.5%）大幅重叠。
  • 预算对比：最佳 TAD 使用 300 次迭代（前 150 次 1 epoch、后 150 次 4 epoch），相对 OPD 的 60 次迭代，相当于 5× 学生轨迹量与 12.5× 完整 rollout 批次优化通过数；该比值不等于 GPU 时间或总算力。
  • 局限：仅覆盖单一操作任务与单一学生架构，未与同轨迹上的行为克隆对比，qpos8 忽略物体位姿与时序进度，结果缺少完整逐轨迹日志与冻结配置快照。
