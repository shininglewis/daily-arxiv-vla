Coordi-pi: Coordination-Aware Dual-Hand Action Representation for Bimanual Dexterous Manipulation

2026-10-14 · 原文 · 翻译 · 2610.19753

论文提出 Coordi-π，一种面向双臂灵巧操作（bimanual dexterous manipulation）的协调感知双手机动作表示框架，旨在解决现有双臂 VLA 策略将左右臂–手动作简单拼接、导致跨手交互隐式化的问题。 传统方法在每个控制时间步将右侧与左侧的臂–手动作拼接为单一动作向量，两侧仅通过特征维度区分，手部身份与跨手结构未被显式建模。 论文将左右两侧动作表示为独立的动作 token，并组织成交错序列（interleaved sequence），使双臂结构在 token 层面显式暴露，同时引入手部身份嵌入与分解式 RoPE 以保留手部身份与时间同步信息。

Card 03 核心贡献

核心贡献

  • 提出 Coordi-π，将右侧与左侧臂–手动作表示为独立 token 并排列成交错序列，显式暴露双臂结构，支持 token 级跨手交互。
  • 引入可学习的手部身份嵌入（hand-identity embedding），在共享动作表示中显式区分右手与左手动作 token。
  • 提出序列–控制时间步分解旋转位置编码（sequence–control-timestep factorized RoPE），将序列位置与控制时间步分离，使同一控制时间步的左右动作共享时间坐标但保留不同序列位置。
  • 在 DexJoCo 全部五个双臂灵巧操作任务上，于 rand-obj 与 rand-full 两种设置下均取得 SOTA 性能。
  • 在四个真实世界双臂灵巧操作任务上一致优于基线 π_0.5。
Card 04 方法描述

方法描述

  • 基于 π_0.5 VLA 架构，保留其 flow-matching 动作专家，仅修改内部动作表示以适应双臂灵巧控制。
  • 交错双动手表示：对 h = 0,…,H−1，令 z_2h = a^R_{t+h}、z_2h+1 = a^L_{t+h}，将 H 步双臂动作块表示为 2H 个侧别专属动作 token，解码时按控制时间步配对还原为联合双臂命令。
  • 手部身份嵌入：动作 token 输入表示 h_i = f_in(z_i) + e_h(i)，其中 e_R、e_L 为可学习嵌入，同一侧所有 token 共享，初始化为零。
  • 分解式 RoPE：为每个 token 定义序列位置 s_i = i 与控制时间步 τ_i = ⌊i/2⌋，将 query/key 分为 d_seq = d_ctrl = d_head/2 两个子空间，分别用序列坐标与控制时间步坐标独立施加 RoPE，从而区分 R_h→L_h（Δs=1, Δτ=0）与 L_h→R_{h+1}（Δs=1, Δτ=1）。
  • 交错仅改变内部动作表示，动作视野 H 保持不变；上下文 token 仍使用原始位置编码。
  • 训练时按交错顺序排列带噪动作块，加入手部身份嵌入并施加分解 RoPE；推理时反交错并按共享控制时间步重构双臂动作。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：DexJoCo 全部五个双臂灵巧操作任务（Hanoi、Photograph、Unlock iPad、Assembly、Microwave），覆盖互补手部角色、顺序交互、精确插入与长时程操作。

  • 真实世界任务：在真实双臂灵巧平台上评估 Photograph、Hanoi、Assembly、Microwave 四个任务。
  • 观测与动作空间：3 路 224×224 RGB 视图、语言指令、46 维本体状态；动作视野 H = 30，每侧 22 维臂–手动作，每个控制时间步 44 维双臂命令；Coordi-π 内部表示为 2H = 60 个侧别专属 token。
  • 训练资源：4 块 A100 GPU，训练 40k 迭代，batch size 为 32，固定训练种子 42。
Card 06 评估与结果

评估与结果

  • 仿真评估协议：每个方法–任务–设置组合使用 3 个评估种子（0、1、2），每个种子 50 个 episode，共 150 个评估 episode；报告三个种子的平均成功率与样本标准差。
  • 主要结果（rand-obj）：Coordi-π 平均成功率 51.3%，显著优于 π_0.5 的 31.9% 与 DP-T 的 33.5%，提升 19.4 个百分点；在全部五个任务上取得最佳或并列最佳。
  • 主要结果（rand-full）：Coordi-π 平均成功率 32.3%，优于 π_0.5 的 18.3%。
  • 最大提升出现在 Hanoi（15.3% → 48.7%）与 Unlock iPad（12.0% → 52.0%），两任务均需互补手部角色与有序跨手交互；Assembly 仍对所有方法具挑战性。
  • 消融实验（rand-obj 平均成功率）：仅交错表示 39.7%，+ 手部身份 42.4%，+ 分解 RoPE 44.3%，完整 Coordi-π 51.3%，表明三项设计具互补贡献。
  • 双臂协调分析：在 RCS、TCS、BCS 指标上 Coordi-π 整体优于 π_0.5、DP3 与仅交错表示。
  • 真实世界实验：Coordi-π 在四个真实双臂灵巧任务上一致优于 π_0.5。
