Card 03 核心贡献

核心贡献

  • 提出一个极简 affordance 头配方：stop-gradient 读取骨干 + 学习式 bridge 特征回注，将强 VLA 从 93.1% 提升到 96.2% 平均成功率，媲美专用三专家架构的 AffordanceVLA（95.8%），额外参数量不足 1%。
  • 通过 stop-gradient 消融证明梯度隔离是前提条件：当 affordance 梯度流入骨干时，策略反而低于无头基线（85.5% vs. 93.1%，Goal 子集崩至 62%），整个干预的正负号由此单一位翻转。
  • 在同一数据、预算与种子下完成 2×2 因子消融（拼接 vs. 残差 × 零初始化 vs. 随机初始化），发现初始化而非拓扑是主导杠杆：active 比 lazy 在两种拓扑上分别高 +2.0 与 +2.7 分，拓扑仅贡献至多 +0.5 分且仅在 active 下显现。
  • 提供两个机制探针：将 ground-truth affordance 作为输入反而有害（-5.6 分），说明信号必须被“预测内化”而非作为数据注入；推理时置零探针区分出两种机制——lazy bridge 仅起训练期正则作用，active bridge 则成为承重通路（长程成功率 82.6% → 91.4%）。
  • 建议将 2×2 协议与 置零探针作为 VLA 辅助头的标准报告实践。
Card 04 方法描述

方法描述

  • 基础策略为 StarVLA 平台上的 QwenPI（即 π0 设计）：Qwen3-VL-2B 骨干编码两路 RGB 视角与指令，逐层 flow-matching 动作专家（DiT） 去噪动作块，目标函数为条件流匹配损失 L_act。
  • Affordance 监督构造：利用 MuJoCo/robosuite 回放演示的特权仿真状态，向前扫描接触事件，取夹爪首次接触的 3D 位置投影到像素坐标 u*，生成固定尺度 σ 的各向同性高斯热图（前瞻式、阶段边界处离散跳变，无人工标注）。
  • Affordance 头：在均匀间隔的骨干层做 stop-gradient 采样，对不同层重排到不同合成分辨率（早层细、晚层粗），按 DPT/FPN 式自顶向下金字塔 + 横向连接多尺度融合，经 FiLM 用池化指令嵌入调制，输出逐视角接触热图，以 BCE（L_aff） 训练。
  • Stop-gradient 机制：sg[·] 使 L_aff 只更新头参数 φ，不更新骨干；骨干与专家仍由 L_act 端到端全量微调，无需冻结模块、LoRA 保护或分阶段课程。
  • Affordance bridge：回注的不是最终热图，而是中间融合阶段 F_k 的特征 r（其空间网格与骨干视觉 token 网格对齐），在每个条件层写入视觉 token，得到 v'_l = v_l + W_aff r（残差）或 v'_l = W_aff [v_l ‖ r]（拼接）。
  • 关键创新点：沿 W_aff 采用 Kaiming 随机初始化（active） 而非业界惯用的零初始化（lazy）——零初始化会陷入“lazy attractor”，动作损失在 W_aff=0 处边际价值近零、bridge 收敛到极小幅值而运行时惰性；随机初始化强制专家的表征围绕 affordance 通路构建。

Card 06 评估与结果

评估与结果

  • 评估环境与基准：LIBERO 四个套件，每任务 50 次试验（每套件 500 次），五组运行（无头基线 + 四种接线）仅相差头部的接线方式。
  • 主要指标：各套件与平均 成功率（%）。
  • 关键结果：

- Res-Active（本文方法） 平均 96.2%，优于无头基线 93.1%，增益集中于 Goal +5.6 与 Long +6.2，在接近饱和的 Object/Spatial 上持平。

- 逐套件（Res-Active）：Object 98.8、Spatial 98.4、Goal 96.2、Long 91.4；对照 Cat-Lazy 93.8、Res-Lazy 93.6、Cat-Active 95.8。

- Long 套件最清晰：82.6（Cat-Lazy）→ 85.2（Res-Lazy）→ 89.4（Cat-Active）→ 91.4（Res-Active）；lazy 下拼接的 re-mixing 相对基线损失 2.6 分，残差的身份通路正好补回。

- 与 AffordanceVLA（full, 95.8%） 对比：二者相当，但去掉其第二阶段课程后即掉到 86.2%，说明本文方案架构复杂度远低而性能不逊。

- 探针结果：真值 affordance 作输入仅 88.3%（相对其匹配基线 94.0% 净降 -5.6，Goal -5.5、Long -19）；置零探针对 Cat-Lazy 几乎无变化（Goal 94.8→95.6，Long 82.6→83.2，属噪声范围），而 active bridge 的同类消融在初步实验中使 Goal 崩落 28 分。

- 头部质量并非瓶颈：预测接触峰值落在真值数像素内且能区分重复物体，剩余 Long 失败多为第二阶段精度误差（如放置到已占用灶眼）。

  • 局限：仅限单一仿真基准、单一骨干规模、每格单种子；affordance 标签依赖特权仿真状态。
