Card 02 论文概述

论文概述

  • 论文提出 ActTune，一个面向视觉-语言-动作（VLA）模型的动作感知精度与 GPU 工作点自适应框架，目标是降低每次成功任务的 GPU 能耗。
  • 解决的核心问题：机器人反复调用 VLA 推理使 GPU 能耗成为持续成本，但单纯降低单次推理能耗不等同于降低单次成功任务能耗（数值误差会增加失败、推理变慢会延长执行）。
  • 研究约束：在保持任务成功率的前提下，将推理延迟增幅限制在 10% 以内。
Card 03 核心贡献

核心贡献

  • 经验性刻画：首次系统刻画量化敏感度如何随动作类别、Transformer 层以及权重/激活精度变化，并证明不同数值精度偏好不同的 GPU 工作点。
  • 动作感知精度与 GPU 工作点自适应：将动作条件化的逐层精度分配与工作负载相关的 GPU 频率-功耗上限联合选择相连接，通过轻量决策树与共享常驻量化权重库实现每次动作块仅一次策略调用的在线自适应。
  • 量化评估：在 LIBERO 上相较 QVLA 与 ActQuant 平均任务成功率最高提升 2.3%，静态模型存储最多减少 29.3%，相比原始 BF16 实现最高 2.02× 推理加速，单次成功任务能耗最多降低 76.8%。
Card 04 方法描述

方法描述

  • 动作感知精度选择：轻量二叉决策树以当前本体感受（proprioception）与前一段预测动作块为输入，学习分裂条件与叶节点精度配置，配置直接从与 BF16 参考策略的动作误差中学习。
  • 共享常驻量化权重库：基于 AWQ（激活引导通道缩放）与输出行裁剪构建敏感度引导的候选权重/激活对，多个叶节点可共享同一配置，切换时无需重建权重或为每个叶节点存储完整模型副本。
  • GPU 工作点选择（"DVFS"）：离线在重放训练工作负载上联合剖析请求频率与功耗上限，选取在延迟预算（≤10%）内估计能耗最低的查找表；在线时控制器预测下一工作负载并在调用之间异步应用选定工作点。
  • 整数内核执行：依据每层权重/激活精度选择 INT4×INT4 或 INT8×INT8 Tensor Core 内核（INT32 累加），支持不重建稠密权重的低比特线性层执行，并融合激活量化与 GEMM 尾声以降低内核启动与中间内存流量。
  • 关键创新点：将"精度决定工作负载、工作负载决定最优硬件工作点"这一耦合关系显式建模为两阶段自适应。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO 终身机器人学习基准，包含 Spatial、Object、Goal、Long 四个任务套件；每个套件 500 个 episode，每个模型-精度设置共 2,000 个 episode。
  • 评估模型：量化 OpenVLA-OFT 与 π₀.₅（视觉编码器与语言 Transformer 中的可量化线性层）。
  • 硬件资源：NVIDIA RTX A6000 GPU（Ampere 架构，计算能力 8.6）。
  • 精度配置：W4A16、W4A8、W4A4；每个模型-预算对共享一棵决策树，两个可切换矩阵各两种精度选项构成 4 种配置。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 闭环仿真基准（Spatial/Object/Goal/Long），硬件为单独运行的 RTX A6000，参考工作点固定为 1800 MHz / 300 W 功耗上限。
  • 主要指标：任务成功率、推理加速比、压缩后静态模型存储、单次成功 episode 的 GPU 板级能耗、平均推理延迟增幅。
  • 基线对比：通用量化方法 SmoothQuant、GPTQ、AWQ（W4A8/W4A4），VLA 专用方法 QVLA、ActQuant（W4A16）。
  • 关键结果：

- W4A4 下 ActTune 在 OpenVLA-OFT 达 95.5%、π₀.₅ 达 98.4%，分别超过最强基线 4.0 和 5.1 个百分点。

- W4A16 下平均成功率达 97.0%（OpenVLA-OFT）与 98.1%（π₀.₅），π₀.₅ 存储降至 3.42 GB（比基线低 44.8–45.7%）。

- 推理速度：π₀.₅ 的 W4A8/W4A4 相比 BF16 实现 2.02× 与 1.81× 加速。

- 能耗：开启 GPU 工作点自适应后，OpenVLA-OFT 与 π₀.₅ 的单次成功能耗分别降低 70.2%/68.0% 与 76.8%/56.9%。

- GPU 工作点自适应使平均推理延迟增加 7.79–8.63%，全部四种设置均满足 10% 预算。

- 消融表明 K=3（三叶节点）的决策树配置在闭环评估中表现最佳（97.0% 与 98.4%）。
