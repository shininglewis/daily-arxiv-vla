Card 03 核心贡献

核心贡献

  • 提出 SEES 自进化框架，可兼容不同 VLA 主干，自动识别原子瓶颈并通过仿真 RL 构造针对性训练任务来改进策略，不依赖额外专家演示。
  • 设计失败引导的家族级（family-level）进化机制：将相关瓶颈任务联合训练一个共享适配器，使改进在技能家族内共享，惠及未被直接 RL 训练的同类原子技能。
  • 提出基于终止头（termination head）的失败归因与瓶颈选择机制，将失败定位到首个阻塞的原子阶段，并按失败频次选出每轮瓶颈。
  • 使用 LLM 任务构建器自动生成成功谓词与恢复初始状态，构造稀疏奖励 RL 任务，且不依赖特权任务 oracle。
  • 在 RoboCasa365 与 LIBERO 上的多主干实验证明策略逐步提升，且增益可扩展到未见任务。
Card 04 方法描述

方法描述

  • 任务分解与路由：冻结的 VLM 规划器将长时序指令分解为有序原子任务序列，语言智能体将每个原子任务映射到预定义技能家族，同家族任务共享一个 VLA 适配器。
  • 失败归因：在预训练 VLA 上附加终止头预测原子任务完成；未在步数上限前发出终止信号或环境终止失败即判为失败，失败归因到首个阻塞阶段，下游被阻塞阶段不计数。
  • 瓶颈选择：按每轮统计的失败次数取最大值，为每个复合任务选出一个瓶颈：b_c = argmax_i F_{c,i}。
  • RL 任务构造：收集瓶颈任务开始前的状态并恢复为初始条件（均匀采样），由 LLM 根据任务指令、对象标识和仿真器查询接口生成布尔成功谓词 C_i(s)，以 r_{i,t}=S_{i,t}-S_{i,t-1} 计算稀疏奖励。
  • 家族级策略进化：对每个含瓶颈的家族构造训练池并按权重采样（新任务权重高、旧任务逐步降权），用 PPO 在线更新该家族共享适配器；适配器采用 LoRA 低秩分解 W_f = W_0 + (α/r) B_f A_f，仅训练动作头 LoRA 及家族专属价值头与终止头，主干保持冻结。
  • 检查点校验与复用：在瓶颈任务上比较更新前策略与各保存检查点，选择任务等权平均成功率增益最大的检查点（Δ_T > 0 才注册），否则保留当前家族策略。
  • 实现基于 RLinf 训练管线；对 flow-based 策略，似然指采样得到的随机去噪转移概率。
Card 05 数据集与资源

数据集与资源

  • RoboCasa365：主基准，含 65 个原子任务与 300 个复合任务；采用其 50 任务评测协议（Atomic 18 + Composite-Seen 16 + Composite-Unseen 16）。
  • LIBERO：四个套件 Object、Spatial、Goal、Long，每套件 10 个任务，每套件任务构成一个技能家族。
  • VLA 主干：GR00T N1.5（视觉语言编码器 + 扩散 Transformer 动作模型）与 RLDX-1（Multi-Stream Action Transformer）。
  • 初始化：RoboCasa365 上两个主干均从 Human300 监督微调检查点出发，每任务 100 条演示，覆盖 65 原子 + 235 复合任务；LIBERO 使用 RLinf 发布的各套件 GR00T N1.5 SFT 检查点。
  • 训练配置：LoRA 秩为 8；RoboCasa365 每轮每活跃家族 40 步 PPO；LIBERO 每套件约 80–96 个外层 PPO 步，每轮最多新增 3 个易失败任务为目标。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboCasa365 与 LIBERO 仿真基准，指标为成功率（%）；原子任务测单任务完成，复合任务测全任务完成。
  • RoboCasa365（三轮进化后）：

- GR00T N1.5：Atomic 47.2 → 55.7，Composite-Seen 10.2 → 13.1，Composite-Unseen 3.5 → 6.1。

- RLDX-1：Atomic 66.4 → 70.3，Composite-Seen 20.4 → 21.8，Composite-Unseen 6.0 → 7.1。

- 相对 execution-only 配置，Composite-Unseen 由 4.7 → 6.1（GR00T N1.5）、4.2 → 7.1（RLDX-1），显示对未见任务的迁移。

  • LIBERO（三轮进化后）：跨套件平均成功率由 53.10% → 65.40%；分套件整体成功率 Object 66.13 → 86.00、Spatial 41.33 → 50.53、Goal 43.73 → 59.47、Long 61.20 → 65.60。
  • 家族级 vs 原子级适配（5 个相关 pick-and-place 任务）：家族级 LoRA 在瓶颈任务 74.0、非目标 sibling 任务 80.0、整体 76.4，均优于原子级 LoRA 的 70.7 / 72.0 / 71.2，说明共享家族适配器带来跨任务正迁移。
  • 瓶颈选择消融（ScrubCuttingBoard，两轮进化）：瓶颈选择将留出场景全任务成功率由 18% 提升至 64%，显著优于随机选择（28%）与最高成功率阶段控制（34%）。
  • 其他验证：附录审计支持基于终止信号的失败归因，并评估了生成成功函数与官方谓词的一致性。
