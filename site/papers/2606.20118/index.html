Card 02 论文概述

论文概述

  • 提出 Pose6DAug，一个 failure-driven 的 3D 感知数据增强框架，利用策略自身已有的成功操作片段，通过物体替换生成针对失败模式的定向演示，无需额外数据采集。
  • 解决 VLA（视觉-语言-动作）策略在分布外、新物体实例上泛化能力差的问题，通过显式 3D 网格和基于机器人运动学的 6D 位姿轨迹实现物理合理且多视角一致的增强。
  • 在 RoboCasa 基准上验证有效性，相比 2D 视频编辑（VACE）和模拟轨迹适配（MimicGen）基线，显著提升新物体上的任务成功率。
Card 03 核心贡献

核心贡献

  • 提出 Pose6DAug 框架，首次将显式 3D 网格重建与机器人正向运动学驱动的 6D 位姿轨迹相结合，实现多视角一致的对象替换增强。
  • 设计三阶段流水线：目标网格重建与 6D 位姿提取、几何扰动增强、3D 网格位姿引导的视频合成，确保物理合理性和跨视角几何一致性。
  • 引入旋转、沿抓取轴平移、垂直缩放等 3D 空间几何扰动，在增加数据多样性的同时保持可抓取的物理合理性。
  • 在 RoboCasa365 仿真基准上全面超越 2D 视频编辑和模拟轨迹适配基线，相对成功率提升 16.5%。
Card 04 方法描述

方法描述

  • 使用 SAM3D 从单张观测图像重建目标物体的 3D 网格，并通过仿真器状态或外部 6D 姿态估计器获取物体位姿轨迹。
  • 对目标网格施加旋转、沿夹爪接近轴的平移、垂直缩放等 3D 几何扰动，使其在共享规范坐标系中继承源物体的位姿轨迹。
  • 使用视频修复模型（如 VOID）完成背景补全，随后按深度顺序合成渲染目标网格，并叠加原始机器人/夹爪区域，保证遮挡关系正确。
  • 所有相机视图渲染同一 3D 网格、同一世界坐标系位姿，从构造上保证多视角一致性，无需跨视角后验对齐。
Card 05 数据集与资源

数据集与资源

  • 使用 RoboCasa365（基于 MuJoCo 的仿真基准）中的 Counter-to-Cabinet 任务（从厨房台面抓取物体放入柜子）。
  • 使用 Objaverse 物体资产库中的多样化物体实例，识别 8 个基础策略成功率 ≤30% 的硬样本作为增强目标。
  • 基础模型为 GR00T-1.5（NVIDIA 的 VLA 基础模型）；生成 176 个增强片段（Pose6DAug 和 VACE），MimicGen 仅生成 33 个有效片段。
  • 训练资源为 1× NVIDIA A100 (80 GB) GPU，每轮微调约 8 GPU-小时，使用 AdamW 优化器、学习率 1×10⁻⁵。
Card 06 评估与结果

评估与结果

  • 在 RoboCasa 基准上评估，采用成功率（Success Rate）、翻转率（Turnover Ratio）和类别恢复（Class Recovery）三个指标。
  • 在失败片段上，Pose6DAug 达到 22.8% 成功率，超过 VACE（16.4%）和 MimicGen（15.8%）；翻转率 24.5%，优于 VACE（18.2%）和 MimicGen（17.2%）。
  • 仅用增强数据的硬样本评估中，Pose6DAug 达到 21.2% 成功率，显著超过 VACE（15.0%）和 MimicGen（5.7%），恢复 8 个硬物体中的 7 个（VACE 恢复 5 个，MimicGen 仅恢复 2 个）。
  • 完整评估中 Pose6DAug 达到 49.5% 总体成功率，高于基础策略的 47.2%，且不损害分布内性能；MimicGen 反而导致性能退化至 46.0%。
