Card 02 论文概述

论文概述

  • 论文提出 R²-WAM，一个面向 World Action Models (WAMs) 的两阶段 repair-and-reject 后训练框架。
  • 目标：让世界模型预测的未来更忠实于输入动作，并用预测后果选择低质量动作进行负微调，从而精炼策略。
  • 解决的问题：视觉上合理的世界模型预测可能不反映候选动作，导致用错误预测评估策略，把视频模型误差误判为策略失败。
Card 03 核心贡献

核心贡献

  • 提出 预测修复（Predictive Repair）：利用演示动作的观测未来与运动学对齐分数，识别并负微调动作不一致的视频预测。
  • 提出 动作拒绝（Action Rejection）：在修复后的视频专家冻结条件下，用 STEAM 比较采样动作与演示动作的想象任务进度，选择性负微调落后样本。
  • 将视频预测从表示学习扩展到基于后果的策略精炼，无需额外环境交互，也不改变推理流程。
  • 在 RoboTwin 2.0 50 任务和真实世界长时操作任务上验证有效性。
Card 04 方法描述

方法描述

  • 基于 Fast-WAM 的共享注意力世界动作模型架构，包含视频专家与动作专家（diffusion transformers）。
  • 先以 flow matching 联合训练视频与动作专家；预测修复阶段固定动作专家，优化视频专家。
  • 预测修复：对每个演示采样 K_v 个未来，通过地标跟踪计算绝对位置一致性和相对轨迹一致性，得到 action-following score。
  • 观测参考选择：比较生成未来与观测未来的分数差 ΔR，超过 margin 的样本获得负微调权重，采用 DiffusionNFT 隐式负参数化。
  • 动作拒绝：冻结修复后的视频专家，采样 K_a 个候选动作，用 STEAM 预测任务进度；进度差 ΔA 超过 margin 的动作接受 rejection-only 负微调。
Card 05 数据集与资源

数据集与资源

  • 模拟数据集：RoboTwin 2.0，50 个双臂操作任务；训练集含 2,500 条 clean 演示与 25,000 条 randomized 演示。
  • 真实世界平台：PIPER 双臂机器人，1 个前视相机 + 2 个腕部 RGB 相机；任务为 Fold Shirt 和 Clean Table。
  • 模型基础：Fast-WAM，视频专家和动作专家均为 diffusion transformers。
  • 训练设置：联合 flow matching 5 epochs；Fast-WAM 继续 2 epochs；R²-WAM 对每个专家进行 2 epochs 的后训练。

Card 06 评估与结果

评估与结果

  • 评估基准：RoboTwin 2.0 模拟环境（clean 与 randomized），以及真实世界 Fold Shirt、Clean Table 任务。
  • 主要指标：闭环任务成功率（%），动作负选择 precision 与 recall。
  • 模拟结果：R²-WAM 在 RoboTwin 2.0 达到 clean 93.8%、randomized 93.7%、平均 93.8%，比 action-conditioned Fast-WAM 平均提升约 3.3 个百分点。
  • 负选择结果：margin 0.08 时，预测修复将 precision 从 64.6% 提至 69.8%，recall 从 35.5% 提至 50.6%。
  • 真实世界结果：Fold Shirt 平均成功率 87.5%，而 Fast-WAM 为 0%；Clean Table 在联合变化条件下达到 70.0%，超过最强基线 π0.5 30 个百分点。
