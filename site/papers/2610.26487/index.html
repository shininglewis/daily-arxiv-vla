SPAR: Structural Pruning and Action Recovery for Vision-Language-Action Models

2026-10-19 · 原文 · 翻译 · 2610.26487

提出 SPAR（Structural Pruning and Action Recovery）框架，用于压缩视觉-语言-动作（VLA）模型，以适配机器人有限的车载算力。 核心问题是：机器人本体的算力有限，难以承载 VLA 模型的推理开销；仅靠监督微调（SFT），无法恢复激进压缩后损失的操作性能。 目标是在永久性结构压缩（得到更小的稠密模型）之后，通过强化学习（RL）交互把策略性能补回来，并研究 hidden 维与 FFN 中间维在容量分配上的不同作用。

Card 02 论文概述

论文概述

  • 提出 SPAR（Structural Pruning and Action Recovery）框架，用于压缩视觉-语言-动作（VLA）模型，以适配机器人有限的车载算力。
  • 核心问题是：机器人本体的算力有限，难以承载 VLA 模型的推理开销；仅靠监督微调（SFT），无法恢复激进压缩后损失的操作性能。
  • 目标是在永久性结构压缩（得到更小的稠密模型）之后，通过强化学习（RL）交互把策略性能补回来，并研究 hidden 维与 FFN 中间维在容量分配上的不同作用。
Card 03 核心贡献

核心贡献

  • 提出双维度结构化剪枝框架：同时学习 LLM 主干中 hidden 维与 FFN intermediate 维的通道 mask，两者使用独立的保留目标（ρ_hid / ρ_int）与正则化 mask 学习目标。
  • 给出维度敏感性的实证分析：仅剪 FFN 中间维时，任务成功率维持较高水平（如 100%/10% 保留目标下 LIBERO 平均 96.45%）；而在此基础上再剪 hidden 维会带来明显性能下降，这部分损失可由 RL 大幅弥补。
  • 系统评估恢复与效率：跨压缩档位报告任务成功率、LIBERO-Plus 鲁棒性以及实测的整策略推理加速。
  • 实证证明 LLM 主干中间维存在大量冗余：语言主干从 2.34B 降到 0.09B（约移除 96%），整模型从 3.37B 降到 1.12B（约移除 67%）。
  • 在后剪枝 RL 恢复后，将 4 个 LIBERO 套件的平均成功率从 84.55% 提升到 93.45%（+8.90 个百分点），并获得 1.98× 的整策略推理加速。
Card 04 方法描述

方法描述

  • 以 PAT（Pruning-aware Tuning）的 Hybrid Sparsification Module 为基础，其前向为 Z = diag(M)·D·W·X，在通道选择的同时适配预训练权重。
  • 双维度剪枝：hidden 维 mask 作用于注意力 Q/K/V 的输入侧与输出投影（W_O），并要求跨层共享 mask 以保持残差通道一致；FFN 中间维 mask 作用于 up/gate 的行与 down 的列（W' = D_i·W·D_h），剪枝后残差流宽度不变。
  • Soft-to-hard masking：mask logits 初始化为 +1.5 / −1.5，训练时 M(s)=σ(τ(s)·W_M)，逆温度 τ(s) 从 1 线性退火至 10（在 r_stop·s₀ 处达到），之后按 𝟙[W_M ≥ 0] 二值化。
  • 剪枝目标函数：L_total = L_SFT + L_count + L_entropy + L_disc，即目标通道数惩罚（软计数逼近 N_target）、熵正则（趋向二值）、离散度项（远离 0.5 阈值）。
  • 二值化后物理删除非活跃通道，得到更小的稠密矩阵，再对紧凑模型做 SFT。
  • 后剪枝 RL 恢复：使用 PPO 与 RLinf 并行仿真 rollout；采用稀疏二值奖励（成功为 1，否则为 0）、奖励与对数概率按 action-chunk 聚合；仅更新 action expert 与 value head，冻结剪枝后的 LLM 主干，以成对评估衡量 RL 增益。
  • 方法命名约定：*PAT only* 指剪枝+监督适配阶段，*PAT+RL* 指完整 SPAR。
Card 05 数据集与资源

数据集与资源

  • 评测基准：LIBERO（Spatial / Object / Goal / Long 四个套件）与 LIBERO-Plus（相机视角、机器人初始状态、语言、光照、背景、噪声、布局 7 类扰动）。

  • 压缩后规模：最小配置（ρ_hid/ρ_int = 10%/10%）为 0.09B LLM / 1.12B 全模型；含 0.74B、0.58B、0.41B、0.26B 等中间档位。
  • 部署与加速测量平台：Jetson AGX Orin + TensorRT；对比方法 EcoVLA 的加速比在 RTX 3090 + Triton 自定义 kernel 上测得（论文明确说明二者非同一平台对比）。

Card 06 评估与结果

评估与结果

  • 主结果（LIBERO）：未剪枝 π₀.₅ 基线平均 96.80%；10%/10% 极端压缩下 PAT only 为 84.55%，PAT+RL 提升至 93.45%（+8.90），与 NORA-1.5（95.00%）、EcoVLA（96.70%，但为非稠密/动态稀疏）等可比较。
  • 剪枝档位趋势：RL 增益随压缩加剧单调增大——90%/10% 为 +1.90、70%/10% 为 +3.75、50%/10% 为 +4.20、30%/10% 为 +4.75、10%/10% 为 +8.90，说明 RL 主要补偿结构性容量损失。
  • 维度敏感性（表 I）：固定 hidden 维只剪 FFN 中间维时，即使保留 10%（LLM 降至 0.82B、整模型 1.85B），仍保持 96.45% 平均成功率，说明 FFN 中间维冗余度最高。
  • 效率：随剪枝加深加速比从 1.05× 增至 1.98×；中间维单剪在 100%/10% 时已达 1.73×。
  • 鲁棒性（LIBERO-Plus）：未剪枝基线 Overall 为 83.98%；10%/10% 的 PAT only 降至 47.46%（相机 59.47、机器人 24.00、布局 34.43 下降最重），90%/10% 为 72.68%；论文报告 RL 恢复可改善鲁棒性（对应 PAT+RL 行在提供的原文中被截断）。
