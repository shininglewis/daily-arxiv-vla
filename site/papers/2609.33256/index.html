Card 02 论文概述

论文概述

  • 论文提出 ActionGround，一种神经符号（neuro-symbolic）、免训练（training-free）的运行时精炼层，可包裹任意已冻结的 VLA 策略，在不重训、不微调、不访问权重的前提下修正其输出动作。
  • 核心问题：现有 VLA 模型（如 OpenVLA、π₀、CogACT）仅从示教数据端到端拟合动作，没有显式建模操作的离散阶段结构（接近/抓取/搬运/放置），也不遵守刚体动力学约束，导致接触阶段误抓、放置阶段超调等失败。
  • 研究目标：在不改变策略权重与接口的条件下，通过运行时离散—连续耦合注入任务相位先验与解析动力学信息，提升任务成功率、轨迹稳定性与效率。
Card 03 核心贡献

核心贡献

  • 对单步与记忆增强（chunked）VLA 模型中的"物理缺口"（physics gap）进行实证分析，指出统一时间平滑（EMA）会以牺牲成功率为代价换取稳定性。
  • 提出 ActionGround：可插拔、免训练的神经符号运行时层，仅作用于冻结 VLA 的标准 7-DoF 动作向量，每控制步延迟 < 1 ms。
  • 在 4 种 VLA 范式（单步自回归、动作分块、力残差、流匹配通用）与 10 个 LIBERO-Spatial 任务上统一评估，无需逐任务或逐骨干调参。
  • 报告最高 +6% 绝对成功率、+19% 绝对稳定性提升，轨迹效率提升最高 15%，仅在 OpenVLA 上出现两个明确的任务级回退。
  • 在 Robosuite 跨仿真器噪声扫描中实现约 10× 的轨迹抖动鲁棒性改进，并在 Agilex Piper 真机上完成定性部署演示。
Card 04 方法描述

方法描述

  • 总体架构：ActionGround 是双分支（two-branch）修正器，位于 VLA 预测动作 a_VLA 与执行器之间，读取 MuJoCo 状态 s_t = (p_eef, q_grip, p_obj, c_t)。
  • 全局混合公式：a_t = (1-c)·a_VLA + c·a_phys，其中 c = 0.05；即 95% 采用 VLA 原始动作，仅由 5% 物理修正精炼；当 \|g\|> 1.5 时对夹爪命令强制覆盖，保证抓取指令不被压制。
  • Branch A：相位感知有限状态机注入器

- 通过几何谓词 DetectPhase(s_t) 将回合划分为 approach / grasp / transport / place 四个相位（阈值如 δ_grasp = 6 cm、z_lift = 1 cm）。

- Approach：过早抓取否决 g ← 0；Grasp：以 β=0.5 向抓取路点 p* 引导且不做平滑；Transport：垂直抬升偏置 Δz⁺ = +2 cm 加仅限该相的 EMA（α=0.92）；Place：按 min(1, d_xy/d_thresh) 做减速斜坡。

  • Branch B：常开惯性加权拉格朗日修正

- 计算欧拉-拉格朗日残差 r_EL = M(q)q̈ + C(q,q̇)q̇ + G(q) − τ，其中 τ 直接读取仿真器实际施加力矩，q̈ 由 VLA 预测的 delta 位姿纯运动学推导，二者独立来源，避免同方程自证。

- 惯性权重 w = Softmax(diag(M(q))⁻¹)，对低惯量关节（动力风险更高）施加更大修正；r_EL 仅作为一致性诊断量记录，不做门控。

- 融合式 a_phys = w ⊙ a_A + (1−w) ⊙ a_raw。

  • 创新点：离散相位符号与连续动力学信号双向运行时耦合（符号选修正律，连续惯性权重决定信任度），闭环经环境而非梯度回传，永不更新 π_θ 权重。
Card 05 数据集与资源

数据集与资源

  • 主要基准：LIBERO-Spatial，10 个空间推理抓放任务（T0–T9），7-DoF Franka Emika Panda 机械臂。
  • 评测设置：每任务 5 次试验，随机种子 7（每格 50 个 episode），MuJoCo 闭环仿真，控制频率 20 Hz。
  • 跨仿真器扩展：Robosuite Lift 任务，OSC_POSE 控制器，高斯 XY 噪声 σ ∈ {0, 0.05, 0.10, 0.15, 0.20, 0.30, 0.40}，每格 n=10。
  • 被包裹的骨干模型（共 4 个，全部冻结）：

- OpenVLA（7B 单步自回归，无记忆）

- OpenVLA-OFT（动作分块解码，接近上限参照）

- Force-VLA（力残差头，读取 6-DoF 接触力旋量）

- Generalist-VLA（流匹配集成头，π₀/GR00T-N1 风格）

- 后两者共享同一 OpenVLA-7B 骨干，仅动作头不同。

  • 硬件：单张 NVIDIA RTX 4090；真机为 Agilex Piper 6-DoF 机械臂。
  • 计算开销：Branch A 约 0.2 ms、Branch B 约 0.4 ms，合计约 0.6 ms/步，远低于 50 ms 控制周期，且被 VLA 前向（30–90 ms）主导。
Card 06 评估与结果

评估与结果

  • 评估指标：Success（二值任务完成率）、Stability（1 − 归一化累积末端抖动）、Precision（与抓取/放置路点的接近度）、Efficiency（1 − 归一化完成步数）。
  • 对比模式：Baseline（原样）、Temporal（统一 EMA α=0.85）、ActionGround (Branch A)（主表配置，统一施加于四个骨干）、ActionGround + EL blend（仅 OpenVLA 报告）。
  • 聚合提升（Table II，相对同排 Baseline）：

- OpenVLA：+16.7% 稳定性，+2% 成功率

- Force-VLA：+18.2% / +4%

- Generalist-VLA：+19.3% / +6%

- OpenVLA-OFT：+2.8% / +0%

  • Table III 聚合结果（Stab% / Succ%）：

- OpenVLA：20.1/36 → Temporal 36.2/28 → ActionGround 36.8/38

- OpenVLA-OFT：86.1/92 → 88.1/92 → 88.9/92

- Force-VLA：20.0/40 → 36.6/36 → 38.2/44

- Generalist-VLA：29.9/36 → 39.2/26 → 49.2/42

  • 关键结论：统一 EMA 在三个单步骨干上均以成功率换稳定性（如 OpenVLA 36%→28%），而 ActionGround 在所有四个骨干上同时提升稳定性与成功率；在分块的 OFT 上 EMA 冗余、ActionGround 零成功率代价换取稳定性。
  • 任务级回退：仅 OpenVLA 的 T3（100%→60%）与 T6（100%→60%）；Force-VLA 与 Generalist-VLA 无任何回退。
  • 结构性失败：T4（抽屉中的碗）与 T9（木柜上的碗） 在所有单步骨干上恒为 0%，因目标几何被遮挡导致相位判定失效；T5 卡在 60% 天花板，对应亚厘米级放置精度不足。
  • 跨仿真器鲁棒性（Robosuite Lift）：ActionGround 平均抖动从 0.064 增至 0.075（+17%），Baseline 从 0.064 增至 0.176（+175%），约 10× 鲁棒性优势；σ=0.40 时 Δ_jerk = −0.102（降幅 58%），奖励 ActionGround 11.06 vs Baseline 10.89。
  • 匹配种子仿真伴随实验（place-on-plate，n=20/模式）：Baseline 成功率 35% → 95%。
  • 真机实验：Agilex Piper 抓放海绵块的定性部署演示，ActionGround 成功放置而原骨干瞄准失败；逐次试验的定量成功率留作未来工作。
  • 局限性：依赖 URDF/XML 运动学与惯性参数精度；5% 修正上限对需训练时物理集成的任务过小；相位谓词缺少接触感知与记忆，遮挡场景下无法恢复。
