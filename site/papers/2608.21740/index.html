Card 02 论文概述

论文概述

  • 提出 CounterAlign，一个面向 Vision-Language-Action (VLA) 模型的离线强化学习（offline RL）框架
  • 核心思路：通过反事实重标注（counterfactual relabeling），将成功的专家演示转化为纠正性监督信号，无需额外环境交互、奖励标注或纠正性演示
  • 解决的问题：机器人数据采集昂贵、行为克隆（BC）仅提供正向监督导致 VLA 模型对物体位置偏移、指令改写等扰动鲁棒性不足
Card 03 核心贡献

核心贡献

  • 提出一个将专家演示转化为信息丰富的反事实监督信号的框架，用于离线 RL 训练，无需额外 rollout、标注或奖励标签
  • 引入基于 nnPU（non-negative Positive-Unlabeled） 学习的判别器目标，显式处理重标注指令–动作对的语义歧义，产生密集且基于指令的奖励
  • 将该奖励整合进 VLA 策略的离线 RL 训练中，在物体位置与任务扰动下提升鲁棒性和泛化能力
  • 在仿真和真实机器人实验中，在维持原始训练分布性能的同时，超越强基线方法
Card 04 方法描述

方法描述

  • 训练两个共享架构的判别器：对抗判别器（区分专家动作与策略生成动作）和重标注判别器（评估指令与动作的语义一致性）
  • 通过三种重标注策略构造监督样本：指令重标注、动作重标注、联合重标注
  • 使用相似度约束（如指令相似度、动作相似度、本体感觉相似度）筛选非平凡近负样本，避免过易或过难的伪负样本
  • 联合重标注样本视为未标记数据，采用 nnPU 学习 和熵正则化训练重标注判别器
  • 基于 IQL（Implicit Q-Learning） 进行离线 RL 策略优化，采用 flow-matching 模型 作为策略，并引入优势加权 flow-matching 目标（Advantage-Weighted Flow Matching Objective）
  • 交替优化判别器与策略，形成对抗式离线 RL 训练循环

数据集与资源

  • 使用仿真环境（Simulation）与真实机器人平台（Real World）进行实验
  • 策略为 flow-matching 生成模型，训练数据来自专家演示数据集（expert demonstrations）

Card 06 评估与结果

评估与结果

  • 评估环境：仿真（Simulation）与真实机器人（Real World）两组实验场景
  • 主要评估指标：任务成功率（success rate），在物体位置扰动与任务扰动条件下评测
  • 关键结果：CounterAlign 在仿真中显著提升鲁棒性与泛化性能，并成功迁移到真实机器人系统，优于强基线（baseline）方法
