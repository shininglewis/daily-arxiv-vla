Card 03 核心贡献

核心贡献

  • 揭示了连续去噪步之间 action-to-future attention 在空间分布上存在显著重叠（尽管未来表征持续更新），为跨步复用 token 选择提供依据。
  • 提出 Action-Guided Token Selection：利用时间对齐的动作查询为每帧打分，保留 frame-specific core tokens 与跨帧共享的 shared spatial anchor tokens，仅压缩未来帧 token，完整保留观测与动作 token。
  • 提出高效执行引擎 Pilot：通过轻量注意力打分（复用 log-sum-exp 归一化器）与跨步选择/打包元数据复用，降低选择与稀疏执行开销。
  • 在三个 WAM（FastWAM-Joint、Cosmos 3 Edge、Cosmos 3 Nano Policy）及多个基准与真实机器人任务上验证有效性。
  • 在 LIBERO 上实现 1.98× 加速，平均成功率仅下降 0.30 个百分点；在 RoboLab-120 上约 1.8× 加速。
Card 04 方法描述

方法描述

  • Action-to-Future Attention：将各注意力头上「动作 token 查询 → 未来帧 token 键」的注意力权重按头平均，得到 U_ℓ(i,f,j)，作为 token 相关性的低成本代理指标。
  • 帧对齐打分：假设动作 token 数 H 可被未来帧数 F 整除，将其划分为 F 组（每帧约 H/F 个查询），按组内加权聚合得到空间分数 S_ℓ(f,j)；中心查询权重更大，以缓解边界查询跨帧关注的影响。
  • 层质量筛选：以 Q_ℓ = R_ℓ(1−E_ℓ) 衡量各层注意力是否既帧对齐（R）又空间集中（低归一化熵 E），选取得分最高的若干层形成核心层集合 L_core，加权聚合得到 V(f,j)。
  • Core Tokens（公式 4–5）：先以 max_f V(f,j) 构建大小为 N_s−K_s 的公共候选池 𝒫，再由每帧自身分数 TopK 选出 K_c 个帧特定核心位置，使选择能跟随帧间漂移的热点。
  • Shared Anchors（公式 6）：在未被选为核心的候选位置中，按 μ_j/(1+CV_j) 选取 K_s 个「注意力强且跨帧一致」的锚点位置，与核心集互斥，保证每帧恰好 K_c+K_s 个 token、序列长度固定。
  • Pilot 低开销剖析：直接复用密集条件前向中的 query–key 乘积与原始 LSE 归一化器，避免物化完整注意力矩阵或额外前向。
  • 跨步复用与紧凑执行：默认仅在动作 chunk 的初始步执行完整计算，后续稀疏步复用选择与视觉速度预测缓存，并复用位置索引与打包元数据。
  • 被省略区域的采样更新（公式 7）：ṽ = M_v ⊙ v^(τ) + (1−M_v) ⊙ v^(τ_d)，保留位置用当前预测、其余位置用缓存预测，使所有未来 latent 仍参与采样，而动作预测每步重算。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（SR）、相对密集 eager 推理的平均加速比、FLOPs 占密集推理的百分比。
  • LIBERO（FastWAM-Joint）：1.98× 加速、FLOPs 降至 49.65%、平均成功率 98.45%（密集为 98.75%，仅降 0.30 个百分点）；ToCa、WorldCache、C³ache 最高仅约 1.62×；SpecPrune-VLA 成功率下降较大，长时任务尤甚。
  • RoboLab-120（Cosmos 3 Edge）：1.85× 加速，平均成功率 23.00%（密集 22.90%）；Cosmos 3 Nano Policy：1.81× 加速，成功率 35.50%（密集 36.75%），均为加速变体中最高。
  • 观察到 FLOPs 少不必然延迟低：Edge 上 Sparse-WAM 用 60.73% FLOPs 取得 1.85×，快于 50.35% FLOPs 的 SpecPrune-VLA 适配版（1.52×），归因于固定稀疏序列长度与复用支持编译执行。
  • 真实世界：2.08× 加速（延迟 501 ms → 242 ms），平均成功率 75.00%（密集 77.78%）。
  • 消融：核心 token + 稳定锚点组合达 35.5%，优于仅核心、仅锚点与随机选择（31.7%）；剪枝率从 28.89% 提升到 68.89% 时加速由 1.45× 升至 2.36×，成功率由 37.5% 降至 28.3%，体现效率–控制权衡。
  • 局限性：仅在 RTX 4090 上评测、仅覆盖三个 WAM、环境扰动下性能下降，未来拟引入自适应 token 选择机制。
