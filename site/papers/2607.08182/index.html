Card 02 论文概述

论文概述

  • 提出 LEEVLA，一种面向视觉-语言-动作（Vision-Language-Action, VLA）模型的新架构，致力于在潜空间环境演化中聚焦任务关键信息。
  • 针对现有 VLA 方法将所有视觉 token 统一对待、并依赖人工选择的上下文线索（如子目标图像、分割、深度）进行推理的问题，LEEVLA 直接在潜特征空间建模环境演化。
  • 核心思想：通过 drift-guided dynamic prioritization (DGDP) 告诉模型“在哪里关注”，通过 structured feature flow generation (SFFG) 建模“如何演化”，形成任务感知的“where–how”训练框架。
Card 03 核心贡献

核心贡献

  • 提出 漂移引导动态优先化（DGDP） 机制，由 动态位置优先化（DPP） 和 语义漂移引导（SDG） 组成，自动发现动态活跃且指令相关的区域。
  • 提出 结构化特征流生成（SFFG） 策略，包括 原型到外围（P2P）预测 和 互邻域对比（MC）损失，引导模型在潜空间学习结构化的状态演化。
  • 在 LIBERO 和 CALVIN 等基准上进行大量实验，验证了显式任务相关引导与结构化潜推理共同增强 VLA 的泛化能力和长时程推理能力。
Card 04 方法描述

方法描述

  • DGDP：DPP 通过相邻时间步 patch 特征的余弦相似度变化（θ = 1 − cos(v_t,i, v_{t+T,i})）定义动态性分数；SDG 通过 patch 与语言指令嵌入的最大内积计算指令相关分数 r，并得到语义漂移因子 ω；最终优先化权重 β = σ(ω·θ)。
  • SFFG-P2P：对多视图未来特征进行联合聚类，按成员到质心的欧氏距离从近到远排序，构造“原型到外围”的有序序列，并采用带全局因子 α 和优先化权重 β 的余弦嵌入损失作为 P2P 预测损失。
  • MC 损失：基于一阶（TopK）和二阶（邻居的 TopM）邻居集合，仅保留相互邻居作为正样本对，采用 InfoNCE 损失抑制聚类噪声和不对称亲和关系。
  • 总体训练目标为 L_total = λ1·L_action + λ2·L_P2P + λ3·L_MC，其中 L_action 为 L1 动作回归损失；DGDP 和 SFFG 仅在训练时使用，推理阶段无额外开销。
Card 05 数据集与资源

数据集与资源

  • LEEVLA-large：初始化为 OpenVLA-7B，在 Open X-Embodiment 大规模混合数据集上预训练，训练 50k–150k 优化步。
  • LEEVLA-mini：初始化为 miniVLA（基于 LIBERO-90 预训练），训练 20k–50k 步，参数量约 0.5B。
  • 视觉编码器采用 DinoV2 和 SigLIP 预训练骨干，语言骨干采用大语言模型（如 Llama-2-7B）。
  • 训练资源为 8×A100（80GB）GPU，使用 AdamW 优化器；large 学习率 5×10⁻⁴，mini 学习率 2×10⁻⁵。
  • 真实世界实验采用 Universal Robots UR5 六自由度机械臂，完成放置、按按钮、关抽屉三项任务。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO 套件（Spatial、Object、Goal、Long 四类任务）和 CALVIN 平台（ABC-D 任务）。
  • 对比基线：小规模模型（Octo、UniACT、Seer、DreamVLA、FLOWER 等）和大规模模型（OpenVLA、π0、OpenVLA-OFT、UniVLA、MemoryVLA 等）。
  • 消融实验（LIBERO-Goal）：基线 94.8%，+P2P 95.2%，+MC 95.6%，+DPP 96.3%，+SDG 96.6%，验证各组件互补有效。
  • 真实世界评估：LEEVLA-large 在 Place、Press、Drawer 三个任务上均优于 OpenVLA。
  • 可视化分析显示，LEEVLA 的视觉特征与语言指令的余弦相似度更高，说明模型更好地耦合了视觉观测与动作生成；聚类可视化进一步表明同语义 patch 被聚类到同一特征簇。
