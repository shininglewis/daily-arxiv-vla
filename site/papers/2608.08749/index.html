OnEvoMemory: Evolving Memory through Online Robot Rollouts for Pretrained Robot Policies

2026-08-09 · 原文 · 翻译 · 2608.08749

论文概述

Card 03 核心贡献

核心贡献

  • 提出层级记忆架构，包含短时原始缓冲区、精英经验库和转换库，分别捕获最近上下文、高价值经验和显著价值转换。
  • 开发可学习的价值引导记忆写入机制，无需固定时间窗口或手工规则，即可识别任务相关经验。
  • 提出在线记忆进化方法，利用成功和不成功的回放轨迹在冻结底层策略的前提下更新价值估计器和记忆模块。
  • 在长时程操作基准上验证了离线初始化和在线进化均能提升预训练 VLA 策略的性能。
Card 04 方法描述

方法描述

  • 基础策略为 token 级 VLA 模型（QwenOFT），利用策略输出的动作查询表示 Q_t=E_θ(o_t) 作为记忆单元。
  • 记忆结构：短期缓冲区（FIFO 队列，保存近期上下文）、精英经验库（保留高价值经验，如稳定抓取和完成中间阶段）、转换库（保留价值显著变化，如任务进展、接触丢失、失败和恢复事件）。
  • 记忆写入由动作条件化价值估计器 F_φ 引导，输出写入分数 V_t、检索键 k_t 和存储表示 v_t；高价值经验写入精英库，价值变化大的写入转换库。
  • 检索阶段采用 TopK 语义相似度与最近 K 条经验结合的联合策略，并通过门控交叉注意力注入当前查询。
  • 离线阶段按时间顺序重放专家演示，初始化记忆先验并训练读写模块；在线阶段用真实回放轨迹（成功和失败）更新价值估计器与记忆模块，预训练策略冻结。
Card 05 数据集与资源

数据集与资源

  • LiberoLong-10：10 个长时程操作任务，在线适应时每任务收集 20 条回放轨迹。
  • RMBench：使用 SwapBlocks 和 SwapT 两个长时程任务，每任务收集 10 条回放轨迹。
  • 基础策略为 QwenOFT VLA；原文未提供模型具体参数量及 GPU/TPU 训练资源信息。
Card 06 评估与结果

评估与结果

  • 评估基准：LiberoLong-10 平均成功率，以及 RMBench 两个长时程任务的成功率（%）。
  • 三组对比设置：基础 VLA 原策略、+离线记忆初始化、+一轮在线记忆进化。
  • LiberoLong-10 平均成功率：基础策略 86.2% → 离线 88.6% → 在线 90.2%。
  • RMBench SwapBlocks：基础策略 0% → 离线 10.0% → 在线 14.0%。
  • RMBench SwapT：基础策略 0% → 离线 8.0% → 在线 10.0%。
  • 定性分析表明，记忆在任务阶段转换时尤为有效，可避免策略丢失进度和重复已完成子任务动作；在线进化的增益主要来自失败回放提供的纠错监督，可修正高估经验和保留更具信息量的事件。
