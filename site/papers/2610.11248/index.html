Card 03 核心贡献

核心贡献

  • 提出 SimVLA 框架：首个完全由仿真数据训练、可零样本迁移到真实移动操作场景的 VLA 流水线，覆盖 35 个移动操作任务。
  • 构建 SimAction：约 200K 条轨迹（2,778 小时）的合成动作数据集，跨 100 个程序化生成的房屋、3 种机器人本体，通过原子技能 API 组合 + 运动规划生成，无需遥操作。
  • 提出 SimVQA：利用仿真器特权状态自动生成约 1M 条问答样本，为 VLM 骨干提供空间、几何与子任务级别的视觉-语言监督。
  • 构建 SimDeploy：通过策略在多样仿真环境（RoboCasa、MolmoSpaces、SceneSmith）中 rollout 收集 22K 条轨迹（460 小时），暴露策略自身诱导的状态分布。
  • 提出两阶段训练范式（预训练 + 后训练），并通过消融验证 SimVQA、Tokenized SimAction、SimDeploy 各自的价值；实验表明 SimVLA 在真实环境中优于用 50 条域内真机示范微调的 π0.5。
Card 04 方法描述

方法描述

  • 基础架构：基于预训练 VLM（PaliGemma 风格 VLM 骨干）+ flow-matching 动作专家，沿用 π0.5 的模型结构，以隔离数据与监督方式带来的增益。
  • 场景生成：使用 Scene Synthesizer 程序化生成五类厨房布局（island、L-shaped、peninsula、single-wall、U-shaped），随机化家具高度、柜体配置、材质与物体摆放；物体形状来自 Objaverse，仿真环境基于 Isaac Lab。
  • SimAction 生成：脚本化技能 API（抓取、放置、倾倒、煮沸、开合、上菜、导航、搜索）组合为长时程任务程序，产生子任务目标态；抓取位姿由 BODex 自动生成；用 cuRobo 计算无碰撞轨迹；含 search 技能以应对部分可观测与主动视觉。
  • 混合系统辨识（Hybrid System Identification）：同时约束关节空间与末端执行器任务空间的跟踪行为，以减小仿真与真机的动力学差异。
  • 域随机化：结合广泛的视觉与物理条件随机化，配合系统辨识缩小 sim-to-real 差距。
  • 训练策略：预训练阶段单次前向同时优化三个目标——连续动作 flow matching、tokenized 动作自回归预测（FAST 风格）与 SimVQA 答案预测，并对动作头到骨干的梯度做 stop-gradient 以保护预训练 VLM；后训练阶段在 SimAction + SimDeploy 混合数据上优化 flow-matching 目标，并允许梯度更新 VLM 骨干。
Card 05 数据集与资源

数据集与资源

  • SimAction：约 200K 条轨迹、2,778 小时机器人数据、35 个移动操作任务、100 个程序化厨房。
  • SimVQA：约 1M 条视觉问答监督样本（空间关系、几何属性、机器人状态、子任务进度）。
  • SimDeploy：22K 条策略 rollout 轨迹（460 小时），来自 RoboCasa、MolmoSpaces、SceneSmith 等仿真环境。
  • 本体与平台：仿真覆盖 Anubis、RB-Y1、ROBOTIS AI Worker 三种机器人；真机实验使用 Anubis（双臂 6-DoF、平行夹爪、三轮全向底盘）。

Card 06 评估与结果

评估与结果

  • 评估环境：仿真侧在程序化生成的 SimVLA 厨房与 MolmoSpaces 上零样本评测（RB-Y1，另含 Anubis 的 8 个长时程任务）；真机侧覆盖 mock kitchen（ID / OOD-pos / OOD-vis）、pantry、real home 三类环境。
  • 评测任务与指标：真机 5 个长时程任务（放杯子/碗/瓶子入水槽、放碗入抽屉、倒水），以任务进度（子目标完成百分比）为主指标，共 2,120 次 rollout；基线为在 50 / 200 条真机示范上微调的 π0.5。
  • 真机结果：SimVLA 达到 54.4% 平均任务进度，优于用 50 条域内真机示范微调的 π0.5；π0.5（200 条示范）在 mock kitchen-ID 为 67.8%，但在 pantry 与 real home 分别骤降至 21.3% 与 29%，而 SimVLA 在三类真实环境中保持稳定。
  • 仿真零样本结果：Pick 任务在 MolmoSpaces 上 71.0±2.9 vs MolmoB0T 36.3±2.8；在 SimVLA 厨房上 91.2±2.8 vs 9.7±1.7；PnP 在 MolmoSpaces 49.0±3.4 vs 1.0±0.7，SimVLA 厨房 79.5±3.1 vs 0.5±0.5；部分可观测设定下 MolmoB0T 全为 0%，SimVLA 达 51.8% 与 81.0%。
  • 消融结论：移除 SimVQA 或 Tokenized SimAction 会一致降低全部任务表现（无 SimVQA 常因抓取不准失败）；SimDeploy 对 sink / drawer 类任务提升显著，对 pouring 提升较小；SimVQA 评测中完整模型取得 0.06 m 中位 3D 位置误差与 0.61 跨视角 IoU（1,369 条留出样本）；完全去除预训练会显著劣化性能。
