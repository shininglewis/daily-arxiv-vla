Card 03 核心贡献

核心贡献

  • 将混合质量机器人数据上的 AC-BC 形式化为两个耦合问题：条件构建与条件表达，并提出两个诊断指标 ACF（AC-BC Condition Fidelity，条件保真度）与 CVFS（Conditional Vector-Field Separability，条件向量场可分性）。
  • 提出直接分类式成对条件估计器，在策略实际消费的标签空间中直接预测离散条件，避免对连续标量分数做事后阈值化所带来的转换误差。
  • 提出 AdaRMS 动作专家注入机制：将分类条件与流匹配时间嵌入融合，通过自适应归一化调制注入 DiT 动作专家，使条件对向量场计算产生直接且逐层重复的影响。
  • 在两个真实机器人本体（ARX X5、Franka）上，用受控的“标准 + 重试密集”混合数据验证方法，显示条件保真度、条件相关向量场分离度与闭环成功率同时提升。
  • 补充的多任务探针实验表明，CVFS 与动作专家注入所体现的“分类可控性”并不限于优势标签，也可迁移到任务类别注入。
Card 04 方法描述

方法描述

  • 条件中介分解：将 AC-BC 写成两阶段——条件构建 c_t = g_φ(D_mix) 与条件表达 v_t = v_θ(x_t, t, o_t, c_t)，其中 v_θ 是流匹配动作专家预测的向量场。
  • 直接分类成对估计器：在同轨迹随机采样帧对 (o_i, o_j) 上，用前向时间间隔 j - i > τ（τ = 30 帧）定义分类监督 c̃_{i,j} = g_τ(j - i)，以交叉熵 L_cls = -log p_φ(c̃_{i,j} \|o_i, o_j) 训练；推理时用固定局部对比窗口 N = 50 取 argmax 得到帧级条件。
  • 阈值前置：阈值只用于构造分类监督标签，而非在推理后离散化噪声标量预测，从而减少近边界误差。
  • 条件表达设计：将标量条件标签映射到流匹配时间嵌入维度并与处理后的时间嵌入相加，再由求和嵌入参数化每层动作专家的 AdaRMS 的 scale、shift、gate，使条件直接调制动作嵌入特征（幅度与残差更新强度）。
  • 注入机制渐进对比：prompt/prefix 条件 → 动作侧嵌入相加 → 逐层加性注入 → outcome token → AdaRMS，用于分离“绕过 VLM 通路”“逐层重复条件”“自适应特征调制”各自的收益。
  • CVFS 诊断：对固定探针（观测、噪声动作、流时间）只改变条件，计算条件间散度 B 与条件内散度 W，定义 CVFS = B / (B + W + ε)；值高表示向量场变化按条件一致聚类。

Card 06 评估与结果

评估与结果

  • 评估设置：每个策略变体在固定装置与固定初始状态、物体位姿下做 30 次闭环 rollout 进行配对比较；仅当任务目标在无人工干预下完成才计为成功。
  • 主要指标：估计器用 ACF-Precision / Recall / F1（正类）；策略用闭环成功率；注入机制用 CVFS（含流时间平均 CVFS̄）。
  • 条件估计结果（表 1）：直接二分类估计器在 ARX X5 上 Precision 97.7% / Recall 79.2% / F1 87.5%，在 Franka 上 90.7% / 89.1% / 89.9%，F1 与召回均优于 π*_0.6 式（82.5% / 88.5%）与 χ_0 式（82.3% / 83.3%）阈值基线；三分类变体接近但略弱。
  • 闭环成功率（表 2）：纯 SFT 为 46.7% / 6.7%，加入重试轨迹后一致性改善不明显（50.0% / 3.3%）；固定 prompt 注入时，直接二分类估计器达 70.0% / 40.0%，优于 π*_0.6（50.0% / 26.7%）与 χ_0（56.7% / 33.3%）。
  • 注入消融：固定同一估计器，ARX 成功率从 prompt 的 70.0% → embedding 相加 76.7% → 逐层加性 83.3% → outcome token 76.7% → AdaRMS 90.0%；Franka 从 40.0% 提升至 56.7%（outcome token 为 53.3%）。
  • 整体对比：ALIGN 达到 90.0%（ARX 堆碗）与 56.7%（Franka 挂钥匙），最强 AC-BC 基线为 56.7% 与 33.3%；CVFS 与成功率呈正相关，AdaRMS 在两者上均最高。
  • 多任务泛化探针：在 Franka 三任务设置下用 AdaRMS 注入任务类别，拧瓶盖 0.0% → 73.3%、堆碗 26.7% → 80.0%、挂钥匙 0.0% → 50.0%。
  • 局限性：方法仍是任务特定的，估计器不追求跨任务/本体语义泛化；二值条件无法区分正类内部更细的质量差异；CVFS 只是开环诊断，可分性不必然带来行为提升；注入机制对比并不穷尽。
