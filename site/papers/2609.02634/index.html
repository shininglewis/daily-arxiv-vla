Card 02 论文概述

论文概述

  • 该论文提出了一种用于视觉-语言-动作模型（VLA）的潜在空间分析方法，称为 LAVLA（Latent Cluster Analysis for Vision-Language-Action Models），旨在提升对 VLA 模型内部表征的理解。

  • 当前 VLA 模型的“黑箱”特性阻碍了其在机器人领域的高风险应用，而现有多数解释性研究忽视了动作解码器内部，该论文从中入手填补了这一研究空白。
Card 03 核心贡献

核心贡献

  • 提出了LAVLA框架，一种基于聚类的 VLA 嵌入分析方法，并首次对 NVIDIA GR00T N1.5 动作解码器的潜在空间进行系统分析。
  • 引入基于交叉注意力的嵌入加权模块（cross-attention-based embedding-weighting），用于放大动作解码器在扩散过程中关注的视觉-语言 token 的影响，该模块在无监督聚类基准上带来性能提升。
  • 提供概念提取管道，通过外部 VLM 为每个聚类生成人类可理解的语义概念，并用 CLIP 进行自动评估，实现潜在空间的可解释化。
  • 实验揭示了 VLA 分层中潜在表征的时空与运动学特征逐步解耦现象，即中间层表征更精细、靠近输出层趋于稳定的规律，进一步证明了交叉注意力在动作扩散过程中的关键作用。
Card 04 方法描述

方法描述

  • 嵌入收集：在GR00T N1.5模型的 VLM 骨干网络最后层（Eagle 12th 层）以及动作解码器的15个交叉注意力层，分别于4个扩散时间步中收集嵌入。
  • 聚类算法：使用凝聚层次聚类（agglomerative hierarchical clustering），基于欧氏距离和平均链接法，并针对不同层单独选择距离阈值。
  • 嵌入加权模块：通过对交叉注意力权重矩阵进行平均，得到各视觉-语言 token 的影响得分，再经 softmax 归一化后，与 VLM 嵌入做Hadamard乘积，实现特征增强。
  • 概念生成：对聚类中心最近的top-5个样本（包含指令文本和视频帧），先用 LLaVA 72B 对每个样本生成概括句，再汇总为单一概念标签，最后使用 CLIPSIM 评估概念与视频内容一致性。
  • 与相关的 SAE 方法相比，LAVLA 不依赖大量数据训练，更适合机器人快速迭代的研究需求。
Card 05 数据集与资源

数据集与资源

  • 数据集：使用Open-X-Embodiment中的GR1人形机器人桌面操作任务数据子集，共包含24个任务，每个任务采样1000条样本，总样本量为24,000个观察-动作对。
  • 每个任务视频包含5秒片段、10帧画面，样本间隔10帧采样。
  • 使用的模型：GR00T N1.5，参数量3B，采用Eagle VLM作为骨干，动作解码器为扩散Transformer（DiT）。
  • 训练与推理资源：嵌入收集在单个 NVIDIA A100 GPU上进行约4小时；概念生成使用2×NVIDIA A100 GPU约3小时。
Card 06 评估与结果

评估与结果

  • 评估基准：在层内采用Silhouette分数、Davies-Bouldin Index、Caliński-Harabasz Index等无监督聚类指标；跨层一致性则采用Jaccard Index和Overlap Coefficient；概念质量使用CLIPSIM（CLIP相似度）。
  • 嵌入加权模块显著改善聚类效果：Silhouette分数在无 PCA 情况下提升62.1%，在 PCA 情况下提升 24.0%，DB Index 均有约 8% 改进。
  • 在加入 PCA 和加权时，Silhouette分数平均达到 0.1642，DB指数最低为 1.3617（加权无PCA）与1.4682（加权+PCA）。
  • 更深层和更晚扩散时间步的潜在表示结构更有序、聚类数更少，说明模型会从噪声逐步解码为结构化动作表征。
  • 加权机制使潜在空间始终保持更一致的聚类，未加权时早期扩散时间步的噪声导致聚类被大量孤立点占据（平均1.5万+聚类数，加权后降至约3800个）。
  • 动作解码器聚类的轮廓与骨架运动特征间有明显区分，左右臂位移在 Wasserstein 距离上显示出约 20% 的簇间差异，表明模型在动作扩散过程中已编码特定的运动学与时间状态。
  • CLIPSIM 分数在基线（unweighted）与加权、PCA 变体上的差异不大（约 0.206-0.233），但 PCA 配置在多数层上一致地带来更高分数，概念生成在仅静态画面与文本下存在较高语义天花板。
  • 聚类稳定性随扩散推进提升，同一层不同时间步的聚类分配一致性明显，说明交叉注意力会持续关注某些特定特征token。
