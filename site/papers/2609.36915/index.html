Card 03 核心贡献

核心贡献

  • 提出首个（作者称）集成大规模并行仿真 + 自动示教生成 + 轨迹级分析的空中 VLA 基准，支持底层载荷感知飞行与操作控制。
  • 结合专家规则与强化学习策略自动生成示教，无需人工遥操作，覆盖多样物体、环境与随机初始位姿，包含基础技能与需导航—操作协同的长时程任务。
  • 提出自动事件标注与轨迹分类方案，可对任务进度、行为结果和空中安全约束（过度倾斜、高度越界、非目标接触、负载丢失、平台稳定性等）进行分析，超越单纯的总体成功率。
  • 在受控任务设置下系统评估多种模仿学习与 VLA 基线（ACT、Diffusion Policy、π0、π0.5），揭示其性能特征与失败模式。
  • 开源全部环境、训练、评估与数据生成代码，并公开数据集。
Card 04 方法描述

方法描述

  • 仿真基础：基于 ManiSkill3 构建，使用 ReplicaCAD 室内环境，任务设置改编自 ManiSkill-HAB 与 HAB (Habitat 2.0)，支持 GPU 并行物理与渲染。
  • 机器人系统：基于 X500 四旋翼，提供轻量 1-DoF 夹爪平台与 3-DoF 机械臂两种配置，配 UMI 式指尖；抓取与搬运通过真实物理接触实现，不使用刚性绑定或位姿瞬移。
  • 载荷感知控制：采用级联速度—姿态控制器跟踪世界系速度与偏航率指令；用 6 个虚拟关节表示自由飞行机体，通过 Q = JᵀW 将旋翼力/力矩映射到关节；物理与底层控制 240 Hz、策略 20 Hz；抓取后更新前馈质量并增大姿态增益，释放后恢复无载质量并清零垂向积分项。
  • 示教生成（Privileged Hybrid Expert）：融合冻结的学习组件、规则控制、几何规划与脚本化反馈，并访问物体位姿、碰撞几何等特权仿真信息；仅用于生成成功示教，不作为被评估策略，也不做 RL 更新。
  • 技能策略学习：BC 通过最小化预测动作与归一化专家动作的 MSE 学习完整连续动作；PPO 在 GPU 并行环境中以高斯 actor + 独立 critic、GAE 和裁剪更新进行优化，可从零训练或由 BC 初始化（可选 critic 预热与模仿正则），参考配置为 64 步 rollout、γ=0.97、裁剪系数 0.2。
  • 任务与技能定义：定义五类参数化技能 Pick、Place、Open、Close、Nav，并组合成 PickPlace = Pick → Nav → Place 的长时程序列。
Card 05 数据集与资源

数据集与资源

  • 四大任务设置：TidyHouse、PrepareGroceries（物体级 Pick/Place）、PackageDelivery（室外取件—导航—放置）、LongHorizonRearrangement（长时程导航+抓放+开关柜门/冰箱门）。
  • 数据集规模：超过 80K 条示教，涵盖基础技能与长时程任务；全部由自动流程生成，无人工遥操作。
  • 观测与动作空间：3 路机载 RGB-D 视图（drone front、drone hand、drone own，128×128）+ 19 维本体感知状态；语言条件策略额外接收自然语言指令；输出 5 维归一化连续动作 [u_x, u_y, u_z, u_ψ, u_g] ∈ [-1,1]^5（世界系平移速度、偏航率、夹爪开合）。
  • 训练资源：依赖 GPU 并行仿真 完成数据采集与批量 VLA 推理；论文正文与所提供原文片段中未给出具体 GPU/TPU 型号与数量等硬件细节。
Card 06 评估与结果

评估与结果

  • 评估围绕两个问题：不同数据生成策略（专家 / 模仿 / 强化学习）在成功率、学习效率、轨迹多样性与执行效率上的对比；以及代表性视觉运动与 VLA 策略从生成示教中的学习效果。
  • 基线方法：ACT（Transformer 条件 VAE 预测动作块）、Diffusion Policy (DP)（条件去噪生成动作序列）、π0 与 π0.5（基于流匹配的预训练 VLA）。
  • 下游基准（PrepareGroceries，16 组 Pick/Place–物体组合平均成功率）：π0.5 44.6% > π0 38.9% > DP 33.9% > ACT 29.5%，说明预训练 VLA 能有效迁移到空中操作，但距完全完成任务仍有明显差距。
  • 技能/物体级分析：Place 普遍易于 Pick，可靠的空中抓取（Pick）是主要瓶颈；不同物体因几何、可抓取性和操作难度差异导致成功率显著不同。
  • 数据生成策略对比：BC 样本效率远高于 PPO（Pick 上仅需 67–81k 示教转移即接近专家，PPO 需数百万次交互且留出评估仍低于专家），是低成本策略蒸馏路径。
  • PPO 的价值在于多样性：轨迹空间覆盖率（TidyHouse 205 vs 专家 53 / BC 77；PrepareGroceries 283 vs 46 / 71）与速度方向熵（3.0 bits vs 1.8/2.0；3.7 vs 1.7/1.7）显著更高，且成功轨迹执行更快（TidyHouse 15.8s → 3.8s；PrepareGroceries ~14.7s → 4.0s），主要来自更短的接近阶段（11.4s → 2.5s）。
  • 局限：评估仅限于仿真，sim-to-real 迁移尚未验证；未来工作将扩展到真实空中机械臂平台及更多平台、环境和长时程任务。
