Card 03 核心贡献

核心贡献

  • 提出 PRICE 方法，从跨轨迹的物理关系与终端结果中推断动作块信用，无需任务特定奖励设计或额外学习型评估器。
  • 建立理论联系：证明 oracle 端点势能变化（endpoint potential change）在期望上等价于终端成功目标的策略梯度（Theorem 1）。
  • 为基于池化证据的信用估计提供有限样本方向性界（finite-sample directional bound），论证置信门控（confidence gating）能保证信用符号的正确性。
  • 在 LIBERO、RoboTwin 2.0 仿真基准与真实机器人任务上验证，性能优于无评估器基线，并与有评估器 SOTA（SRPO）相当，同时学习更快。
  • 通过独立续接评估（independent continuation evaluation）与受控消融，验证历史证据与置信门控对策略改进的贡献。

Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Spatial、Object、Goal、Long 四个套件）、RoboTwin 2.0（六项双臂操作任务：Handover Block、Lift Pot、Move Can Pot、Pick Dual Bottles、Place Container Plate、Place Empty Cup）。
  • 真实机器人任务：HiFi-UMI 的 Remote Insertion 与 Produce Sorting。
  • 基础模型：OpenVLA-OFT（LIBERO 一次性 SFT 初始化；RoboTwin 用任务特定 SFT 检查点）、OpenPI-π0.5（真机，基于 400 条 HiFi-UMI 轨迹后训练）。
  • 训练资源：8 张 NVIDIA A800（80GB） GPU，学习率 5×10⁻⁶，优化 mini-batch 为 128。
  • 采样设置：每批 64 个初始条件、每条件 8 条 rollout（共 512 条轨迹），采样温度 1.6。
Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（%）、达到目标成功率所需训练步数/GPU 小时；信用质量指标包括方向准确率 DirAcc、RankCorr（Spearman 秩相关）、AlignedGap（对齐的 MC 进展差距）。
  • LIBERO 结果：PRICE 平均成功率 99.0%，超过所有无评估器方法，接近有评估器的 SRPO（99.2%）；LIBERO-Long 达 97.6%，比最强无评估器基线高 3.6 个百分点。
  • RoboTwin 2.0 结果：PRICE 平均成功率 90.0%，较 OpenVLA-OFT（SFT）初始化（31.9%）提升 58.1 个百分点，数值上高于 Feat2Go（88.8%）、RLinf-VLA（84.5%）和 SimpleVLA-RL（71.3%）。
  • 训练效率：相比 SimpleVLA-RL，达到 90% 成功率时 PRICE 在 Goal 任务减少 34.5% 步数、Spatial 任务减少 37.1% 步数，GPU 小时分别节省 38.3% 与 32.8%。
  • 机制验证：独立续接测试表明 PRICE 保留的信用与节点平均成功率变化方向一致；消融实验证实历史证据与置信门控对策略提升均有贡献。
  • 真机结果：PRICE-AWR 在离线流匹配适配中优于轨迹级 GRPO-AWR，验证方法在真实操作场景的泛化性。
