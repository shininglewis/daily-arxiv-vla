Card 03 核心贡献

核心贡献

  • 提出通过进化 harness 实现物理自改进：EmbodiedEvo 将物理交互转化为持久控制程序与决策指导，Code as World 与 Agent as Policy 使知识显式、可编辑、可复用，同时保持模型权重和机器人接口固定。
  • 设计耦合动作与条件的经验表示：Skills 存储可执行控制过程及使用条件，Lessons 记录适用性、失败模式和结果验证经验；Playground-to-Test 协议在每个任务的一个场景上获取知识并冻结，供独立智能体跨未见布局和不同模型重用。
  • 证明获取经验与应用经验是可区分能力：未完成任务也能产生有用知识，较弱执行器可受益于自身难以获取的经验。
  • 实验上，EmbodiedEvo 在 RoboDojo-Sim 上超过所有官方验证结果；Skills/Lessons 与原始交互历史相比，在任务性能相当的情况下将 Test 执行成本降低 53.0%。
Card 04 方法描述

方法描述

  • Code as World：将物理交互组织为两层代码。L1 是环境原语，包括 get_instruction()、get_observation()、step(action) 和 reset()；L2 是由 L1 组合出的可执行 Python 程序，可包含变量、函数、循环和条件分支。
  • Agent as Policy：编码智能体自主决定观察时机、执行哪个程序、如何根据反馈修订代码；工作区包含固定规范文件、可编辑 submission/solution.py、执行记录、scratch/、skills/ 和 lessons/。
  • Harness Evolution：在单个 Playground 场景中，智能体通过编辑—执行—反馈循环不断修订 Skills 和 Lessons；Skills 保存参数化控制过程，Lessons 保存前置条件、失败模式和恢复策略。
  • Playground-to-Test 协议：Playground 允许同场景 reset 以继续尝试；结束后冻结 harness，Test 使用全新智能体、工作区和模拟器，harness 只读且禁用 reset，不更新经验。
  • 关键创新：以代码使物理控制显式、可检查、可复用；用可读写的 Skills/Lessons 而非参数更新来保留经验；支持跨模型复用，无需额外 Playground 探索、参数更新或学习 adapter。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboDojo-Sim 仿真基准，与 VLA、WAM 和 Agent 类方法比较，参考 October 9, 2026 leaderboard snapshot。
  • 评估指标：Score（0–100，含部分进度）和 Success Rate (SR, %)。
  • 总体结果：EmbodiedEvo 使用 Astra/xhigh 在 full set 上达到 Average Score 44.48、SR 37.82%，超过所有官方验证结果；比 VPP2 高 5.22 Score / 5.56 SR，比 Simate-beta 高 10.53 / 9.86，比 PhysicalRSI 高 8.21 / 6.44。
  • 分类结果：Memory 达 71.90 Score / 69.67% SR，Open 达 55.52 / 53.00%；Precision 为 23.65 / 13.25%，Long-Horizon 为 37.20 / 23.50%，仍是瓶颈。
  • 配对消融：无 wiki 时，SR 从 8.50% 提升到 30.17%；有 wiki 时，SR 从 13.36% 提升到 35.08%；最大增益出现在记忆依赖任务，协调过程可成功复用。
  • 跨模型迁移：Astra 的经验使 Sol 和 Luna 的成功率分别提升 8.86 和 5.50 个百分点。
  • 成本：相比 raw interaction history，Skills/Lessons 在任务性能相当情况下将 Test 执行成本降低 53.0%。
