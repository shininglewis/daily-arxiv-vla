dVLA-RL: Reinforcement Learning over Denoising Trajectories for Discrete Diffusion Vision-Language-Action Models

2026-06-22 · 原文 · 翻译 · 2606.23623

论文提出 dVLA-RL，一个针对离散扩散视觉-语言-动作模型（dVLAs）的强化学习框架，解决 dVLA 策略最终动作边际概率不可解的问题。 核心思路是将 dVLA 的迭代去噪生成过程建模为马尔可夫决策过程（MDP），将优化目标从不可解的边际动作概率转向可解的采样去噪路径联合概率。 该框架实现了标准 PPO 策略梯度算法对 dVLA 策略的直接优化，并引入了统一的去噪步长调度策略，实现任务自适应的高效训练。

Card 02 论文概述

论文概述

  • 论文提出 dVLA-RL，一个针对离散扩散视觉-语言-动作模型（dVLAs）的强化学习框架，解决 dVLA 策略最终动作边际概率不可解的问题。
  • 核心思路是将 dVLA 的迭代去噪生成过程建模为马尔可夫决策过程（MDP），将优化目标从不可解的边际动作概率转向可解的采样去噪路径联合概率。
  • 该框架实现了标准 PPO 策略梯度算法对 dVLA 策略的直接优化，并引入了统一的去噪步长调度策略，实现任务自适应的高效训练。
Card 03 核心贡献

核心贡献

  • 提出轨迹级概率建模方法：将 RL 目标定义为采样去噪轨迹的联合概率（而非最终动作的边际概率），使标准策略梯度算法可天然应用于多步离散扩散策略。
  • 引入 dVLA-RL 统一去噪步长训练策略：通过轨迹级概率公式，根据任务复杂度和初始策略性能分配不同去噪步长，兼顾性能与计算效率。
  • 通过实验证明 RL 能显著超越 dVLA 的 SFT 初始化性能：在 LIBERO 上达到 99.7% 平均成功率，在 RoboTwin 2.0 上比 SFT 基线提升 30.6%。
  • 验证了轨迹级概率建模的必要性：对比实验显示，仅用最后一步概率作为代理会导致优化不稳定和性能退化。
  • 提出混合去噪步长（Hybrid）策略：在统一概率框架下为不同任务分配 1-step、2-step 或 4-step 去噪，在保持成功率的同时降低训练和推理开销。
Card 04 方法描述

方法描述

  • 将 dVLA 的 K 步去噪过程展开为马尔可夫链，轨迹联合概率分解为逐步转移概率的乘积形式。
  • 单步转移概率由两部分构成：Gumbel-TopK 调度器的 token 选择概率和网络对解掩码 token 的生成概率。
  • 梯度更新仅作用于从 [MASK] 状态到具体 token 的转换子集，将调度器视为非可微系统动态，避免高方差梯度。
  • 由于网络置信度 pθ 在调度和生成机制间共享，对 token 预测的优化隐式改进了调度过程。
  • 轨迹级公式统一了不同去噪步长：1-step 视为单转移的退化路径，多步对应更长的生成路径，支持混合步长调度。
Card 05 数据集与资源

数据集与资源

  • LIBERO：包含 Spatial、Object、Goal、Long 四个单臂操作套件，评估空间关系、目标中心操作、目标条件变化和长时程指令。
  • RoboTwin 2.0：更 challenging 的双臂操作基准，包含多样化物体、域随机化环境和双臂协调任务。
  • 骨干模型为 MM-ACT，统一离散扩散 VLA 模型，通过掩码去噪生成动作 token。
  • SFT 数据规模：LIBERO 每套件 500 条演示，RoboTwin 2.0 每任务 1000 条演示，采用多任务联合训练。
  • RL 训练基于 RLinf 平台的 PPO 实现，使用稀疏结果奖励（成功为 1，失败为 0）。
Card 06 评估与结果

评估与结果

  • LIBERO 评估：每个子任务 50 次试验，全套件共 2000 次试验；dVLA-RL 在所有四个套件上成功率均超 99%，平均 99.7%，超越 SimpleVLA-RL（99.1%）、MM-ACT（96.3%）及 π0.5、OpenVLA-OFT 等 VLA/WAM 基线。
  • RoboTwin 2.0 评估：每个任务 1000 个训练场景，64 次 rollout 评估；dVLA-RL 平均成功率从 SFT 基线的 61.4% 提升至 92.0%，其中 Handover Mic（+47.9）、Move Can Pot（+47.5）、Lift Pot（+43.1）提升最大。
  • 消融实验：轨迹级目标在 2-step 和 4-step 去噪下均优于仅用最后一步概率的代理目标，优化更稳定且成功率更高。
  • 效率分析：混合步长策略训练时间 607.89s，远低于固定 4-step 的 845.95s，推理延迟 387.24ms，FLOPs 37289.12 GFLOPs，在保持高成功率的同时显著降低成本。
