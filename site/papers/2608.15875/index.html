Card 03 核心贡献

核心贡献

  • 提出三系统架构，将理解规划、预测评估与连续动作生成深度耦合，并保留各系统专业化目标。
  • 构建 单阶段多形态 VLA 预训练框架，联合优化视觉-语言理解、层次化任务预测、离散动作表示和连续动作生成，消除多级训练流水线的碎片化问题。
  • 构建超大规模异构数据语料，清理后包含 37,256.98 小时实体轨迹数据（覆盖 16 种机器人形态）和 271,976,674 个 VLM 图像-文本/问答样本。
  • 提出 Soft Knowledge Insulation (Soft KI) 机制，在保护 VLM 通用视觉-语言能力的同时，允许骨干网络适应具身控制任务。
  • 设计 World-Model-Powered 后训练 管线，利用 System 3 预测的子目标图像和值函数信号条件化 System 1 策略，并通过经验驱动强化学习实现持续改进。
Card 04 方法描述

方法描述

  • 采用 Mixture-of-Transformers (MoT) 架构，将 PaliGemma2 (3B) VLM 骨干与专用的 Action Expert (0.5B) 结合，通过联合注意力耦合，但保持独立的前馈参数。
  • System 2 通过链式思维推理从当前观测和任务指令中分解出子任务指令；System 3 基于 GigaWorld-1 世界模型，预测未来视频帧（子目标图像）并估计任务进度值，提供双重条件接口。
  • 引入 Temporal-Spatial Blocks 短期视觉记忆机制，在保持高维上下文长度与单帧设置相当的前提下，融合历史帧信息。
  • 采用流匹配 (Flow Matching) 生成连续动作块，同时保留自回归离散动作通路作为训练桥梁；系统 1 支持多形态统一优化，通过掩码和投影模块处理异构自由度。
  • 经验强化阶段包括离线经验强化（利用失败与纠正轨迹训练进度判别器）和在线强化（人类纠正反馈 + 子任务成功标签构建密集奖励），形成持续学习生命周期。
Card 05 数据集与资源

数据集与资源

  • 真实机器人数据：20,535.65 小时，覆盖 16 种机器人（Maker H01、Maker M01、Agibot-G1/G2、AgileX、Franka、UR5、Galaxea R1 Lite 等），共计 1,810,101 个 episode。

  • VLM 数据：271,976,674 个样本，覆盖图像描述、视觉问答、空间关系、区域 Grounding、点预测、功能属性理解和机器人任务理解。
  • 模型规模：System 1/2 基于 PaliGemma2 (3B) + Action Expert (0.5B)；System 3 基于 GigaWorld-1 (5B) 世界价值模型。
Card 06 评估与结果

评估与结果

  • 评估平台涵盖 AgileX PiPER/PiPER-X 和自研 Maker H01 平台，覆盖零样本、多任务执行、语言指令跟随、分布外泛化和长程操作。
  • 与 GigaBrain-0 系列 和 π0.5 等基线对比，GigaBrain-0.7 在基础零样本能力、语言条件指令跟随和任务后训练成功率上均有显著提升。
  • 消融实验验证了 System 3 中未来状态预测和值函数评估信号的单独及联合贡献，以及数据规模、VLM 骨干容量和 VLA 耦合架构对性能的影响。
  • 在全真机平台上展示了基于人类干预数据和纠正反馈的经验驱动策略改进，并通过离线强化和在线强化进一步提升了复杂精细操作的成功率。
  • 大量实验表明，大规模异构预训练带来的涌现具身能力（emergent embodied capabilities）使模型在基础语言跟随和复杂操作任务上持续提升。
