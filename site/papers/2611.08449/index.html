Card 02 论文概述

论文概述

  • 提出 VFlash，一个面向 Physical AI（机器人、自动驾驶）的通用视觉规划解码框架，用并行的「Flash Primitive Decoding」（FPD）替代逐坐标的自回归（AR）解码。
  • 针对的问题：视觉规划（点、包围框、轨迹）的空间细节越多，需要的坐标 token 就越多；自回归 VLM 逐个 token 解码，在延迟受限、batch size = 1 的物理智能体场景下严重限制规划精度与更新频率。
  • 关键洞察：视觉基元（visual primitive）的类型、维度、长度一旦确定，其边界与坐标布局即已知，因此可整块并行预测；空间精度并不要求复现自回归模型的精确 token 序列。
Card 03 核心贡献

核心贡献

  • 提出 Flash Primitive Decoding（FPD）：将草稿块边界与完整视觉基元对齐，一次前向即可联合预测一个基元的全部坐标（可含几十到上百 token），支持包围框、变长 2D/3D 轨迹和稠密点运动。
  • 设计 boundary alignment + position alignment 两原则与固定宽度 token 布局（1,001 个坐标专用 token；文本型坐标用符号位 + 5 位数字格），使不同格式与长度共享同一布局模板。
  • 提出宽松接受准则：推理时只要求基元通过 schema 校验（包围框另加 LocateAnything 空间置信度守卫）即整块接受，不要求与目标模型 token 级一致；文本部分仍保留带验证的推测解码。
  • 训练直接使用标注坐标（而非目标模型的续写）作为监督，使草稿器在空间精度上可超过其自回归目标模型。
  • 在 2D/3D 机器人轨迹、包围框、稠密 3D 点运动预测及下游操作/驾驶任务上，同时取得更快速度与更高精度。
Card 04 方法描述

方法描述

  • 以 DFlash 的块扩散草稿架构为基础：冻结的目标 VLM 提供选定层特征 $H_\theta(x)$，作为 key/value 注入轻量草稿器各层。
  • 草稿器为五层非因果（bidirectional）浅层网络，给定起始 token $a_0$ 与 MASK 序列，单次前向并行输出 $B(s)-1$ 个位置的条件独立分布。
  • 工具调用（tool call）声明预测长度 $P$、基元类型决定坐标布局，推测预算 $\gamma = B(s)-1$ 由请求而非固定窗口决定。
  • 训练损失为整块加权交叉熵，基元位置使用均匀权重（不同于验证路径中偏重前段的衰减权重）；采用 packed attention 隔离样本与独立块。
  • 推理：先以 16 位置 DFlash 块解码直到接受 primitive-start token，随后一次性草稿整块；施加逐位置词表约束与跨位置规则（越界坐标成对处理），均只作用于已有 logits，不增加神经计算。
  • 定义直接接受吞吐 $\tau_{\text{dir}} = B(s)$（通过校验）或 $1+r$（失败则保留前 $r$ 个草稿槽并用约束 AR 重新生成），有效每 token 延迟 $L_{\text{dir}} = (t_{\text{par}} + t_{\text{target}})/B(s)$。
Card 05 数据集与资源

数据集与资源

  • 基础 VLM：定制具身 VLM，组合 Qwen3-4B + 原生分辨率 MoonViT 编码器 + MLP connector；稠密运动使用开源的 MolmoMotion-AR 作为目标模型。
  • 评估数据集：ShareRobot-Bench、VABench-V（2D 轨迹）；COCO、Dense200（包围框）；InternA1、AgiBot、MolmoBot（3D 机器人轨迹）；PointMotionBench（HOT3D、WorldTrack、DAVIS，稠密点运动）；MolmoSpaces、LIBERO（下游操作）；NAVSIM、Waymo（驾驶，8 个 / 20 个路点）。
  • 模型规模：目标 VLM 4B，草稿器 5 层；对比基线含 Qwen3-VL 4B/8B、MolmoAct 7B、Embodied-R1 3B、HAMSTER 13B、RoboBrain-2.0 7B、LoHo-Manip 4B 等。
  • 推理硬件：NVIDIA Jetson Thor、DGX Spark、H100。
Card 06 评估与结果

评估与结果

  • 评估方式：开环指标（2D：DFD/HD/RMSE；3D：ADE/FDE/SR@5/SR@10；点运动：ADE/FDE/PWT；包围框：F1@IoU、BPS）+ 下游闭环任务成功率 + 吞吐/延迟分析（App. E/F）。
  • 2D 轨迹：相对同源 AR 目标在六个误差上全面下降（HD 降约 7%，DFD/RMSE 降 3–6%）；VABench-V 上较最佳先前模型 LoHo-Manip 误差降低约 40%。
  • 包围框：使用 AR fallback 时平均 F1 与 AR 持平，解码快 2.6–2.8×；IoU 0.50 上更高，IoU 0.95 上更低；无 fallback 时 Dense200 平均 F1 掉约 20 点。
  • 3D 机器人轨迹：三个目标变体、三个数据集上四项指标全面提升；ADE 在 3D-only 下降低 18–49%，2D+3D 下降低 28–61%；AgiBot 上 SR@5 从 50%→73%、40%→74%；加腕部相机训练再降 ADE 3–12%。
  • 稠密点运动：DAVIS 的 ADE/FDE 分别降 27% 和 19%，HOT3D FDE 降 8%，单次 rollout 生成约 25× 加速；部分指标（WorldTrack FDE、PWT）略逊。
  • 下游应用：MolmoSpaces 上以 VFlash 规划为条件的 world action model 四套任务平均成功率 70.2%，基线为 62.6%；机器人操作流水线在 Jetson Thor 与 DGX Spark 上推理延迟降低约 80%。
