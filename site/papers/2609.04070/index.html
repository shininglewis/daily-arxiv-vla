Continuous Actions from Discrete Minds: Latent-Aligned Planning for End-to-End Autonomous Driving

2026-09-03 · 原文 · 翻译 · 2609.04070

本文提出 LaPla（Latent-aligned Planning），一个统一的视觉-语言-动作（VLA）框架，用于端到端自动驾驶。 核心问题是弥合视觉语言模型（VLM）的离散语义推理与自动驾驶所需的连续、受物理约束的动作执行之间的差距。 现有方法存在三种缺陷：动作标记化引入量化误差导致轨迹抖动；双系统耦合松散导致时空割裂；扩散式动作头训练不稳定且推理延迟高。LaPla 通过在运动学合理的连续潜空间中直接规划来解决这些问题。

Card 02 论文概述

论文概述

  • 本文提出 LaPla（Latent-aligned Planning），一个统一的视觉-语言-动作（VLA）框架，用于端到端自动驾驶。
  • 核心问题是弥合视觉语言模型（VLM）的离散语义推理与自动驾驶所需的连续、受物理约束的动作执行之间的差距。
  • 现有方法存在三种缺陷：动作标记化引入量化误差导致轨迹抖动；双系统耦合松散导致时空割裂；扩散式动作头训练不稳定且推理延迟高。LaPla 通过在运动学合理的连续潜空间中直接规划来解决这些问题。
Card 03 核心贡献

核心贡献

  • 提出 LaPla，将自动驾驶建模为潜空间对齐的序列任务，融合多模态上下文实现高精度轨迹生成，弥合语义与连续规划的不匹配。
  • 首创隐式潜对齐规划机制：利用冻结的残差 VQ-VAE 解码器作为运动学梯度预处理器，将原始欧氏误差映射为物理一致的梯度更新，引导 VLM 输出落在运动学可行的流形上，同时绕过离散码本瓶颈。
  • 提出非对称动作表示：历史动作使用离散量化提供结构化粗到细上下文，未来动作预测使用连续潜变量以避免量化误差，实现平滑且物理可行的轨迹。
  • 在 nuScenes 上实现竞争性的开环性能，并将长期（3s）L2 误差降低 15.52%（相比 SOTA VLA 方法）；在 NVIDIA AlpaSim 闭环模拟中将成功率提升 33.34 个百分点，同时显著降低推理延迟。
Card 04 方法描述

方法描述

  • 两阶段流程：(1) 在大规模轨迹数据上预训练一个残差 VQ-VAE，作为表征物理运动模式的冻结潜先验；(2) 引入 VLA 框架在冻结解码器驱动的连续潜空间中规划轨迹。
  • 轨迹 VQ-VAE 使用残差量化（L=4 层，码本大小 [64,64,128,128]），编码位移与航向特征，产生粗到细的动作原语；训练损失为重建损失 + 承诺损失，码本用 EMA 更新。
  • 统一 VLA 框架：采用 Emu3-8B 作为主干，输入序列为多视野图像视觉 token + 历史动作 latent token + 导航指令 token + 可学习动作查询 （可选 VQA 后缀）。通过 LoRA 微调，保持 VQ-VAE（编码器和解码器）冻结。
  • 并行轨迹生成：所有 T 个动作查询在单次前向中因果关注多模态上下文，通过 MLP 投影头映射到冻结解码器输入空间。加入 N 个可学习扰动向量以产生多样轨迹候选，用 Best-of-N 平滑 L1 损失监督。
  • 辅助 VQA 任务：以多轮问答作为辅助监督，增强语义理解与可解释性，随机从标注集抽取问答对提高泛化。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes（约 3 万帧，2 Hz 标注，用于开环评估；VQA 标注来自 OmniDrive 相关工作）； NVIDIA AlpaSim（高保真闭环模拟器，2 万帧微调 用于测试，60 个代表性场景，约 20 秒 @ 10 FPS）。
  • 模型主干：Emu3-8B（8B 参数 VLM，LoRA 微调）。
  • 训练资源：华为昇腾 910B3 NPU（64G VRAM）分布式平台；闭环 AlpaSim 运行于 4× RTX-4090 GPU（24G VRAM），通过 gRPC 与 NPU 端规划器通信。
  • BoN 推理设置：开环 N=20；闭环无扰动与 BoN，确定性执行。
Card 06 评估与结果

评估与结果

  • 开环评估（nuScenes，ST-P3 与 UniAD 指标）：LaPla 在 UniAD L2 平均上达到 0.60 m，优于 OpenDriveVLA-7B（0.66 m）、AutoVLA（0.70 m）；在 3s 长期误差上 LaPla 远低于 AutoVLA（0.98 m vs 1.16 m），在 ST-P3 3s L2 上也优于 EMMA（0.52 vs 0.54）。
  • 消融实验：MLP 直出轨迹（基线）严重退化；加入 VQ-VAE 解码器作为先验（M2）UniAD L2 从 1.81 m 降至 1.13 m；冻结解码器得到完整 LaPla（M3）进一步降至 0.60 m 且碰撞率仅为 0.52%；去除 VQA 会导致性能下降，验证了其有效性。
  • 动作量化验证：在运动学模型生成的螺旋轨迹上测试残差 VQ-VAE，重建精度随残差量化和历史信息引入而显著提高；比较 K-Disk、VQ、Res-VQ 等方法，Res-VQ 在编码效率与重建精度上整体更好。
  • 闭环评估（AlpaSim）：LaPla 成功率显著优于基线，相比 SOTA 提升 33.34 个百分点，且推理 FPS 大幅提升，轨迹平滑性显著提高。
  • 定性分析：LaPla 在雨天、夜间等感知退化条件下保持轨迹平滑；在绕行、超车、让行等战术动作中能准确捕获横向机动意图。
