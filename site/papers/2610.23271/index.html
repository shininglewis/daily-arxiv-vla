NestedVLA: Learning to Consolidate and Generate Skills for Vision-Language-Action Models

2026-10-16 · 原文 · 翻译 · 2610.23271

Card 03 核心贡献

核心贡献

  • 把技能整合重构为参数生成问题：用嵌入 VLA 的嵌套超网络（nested hypernetwork） 以任务标识为条件，直接生成动作专家（action expert）的稀疏参数增量，而非从固定参数集中选取或插值。
  • 提出 drop-and-rescale 压缩算子：对任务向量做模块级 top-K 稀疏化并全局重缩放，把十亿级稠密增量压缩为可学习的稀疏技能表示，在保真度—压缩率权衡上优于量化与低秩分解。
  • 设计完整的三阶段框架：技能获取 → 技能整合 → 推理时技能生成；训练后模型可直接部署，无需改动前向架构、无需专家路由、无需运行时混合计算。
  • 在 MetaWorld、ManiSkill、CALVIN 三个闭环操作基准上，比最强模型合并基线平均高出 41 个百分点，且在任务条件化方法中存储开销最低（1.5× 单模型）。
  • 给出存储核算与消融分析，指出性能瓶颈来自“从固定基值中做选择”这一范式本身，而非存储预算。
Card 04 方法描述

方法描述

  • 技能获取：对每个任务数据集独立微调共享基座 Θ₀ 得到 Θ_m，任务向量 τ_m = Θ_m − Θ₀；训练信号不限（监督微调、强化学习均可）。
  • drop-and-rescale 压缩：按模块计算 top-K 二值掩码 M_m，得到 z_m = α · τ_m ⊙ M_m；α 为全局重缩放因子，被离线预计算并外部存储，不交由超网络预测，以避免高杠杆标量污染回归目标。
  • 基于 patch 的参数 tokenization：把权重张量切分为 H_patch × W_patch 的二维 patch 网格，每个 patch 由四元组 (ptype, layer, patch_h, patch_w) 唯一寻址，使输出维度可控并保留结构化空间布局。
  • 超网络架构（五个可训练组件）：

- 逐任务 patch embedding：四类索引各经一张按任务索引的嵌入表，拼接为 patch 特征。

- 任务编码器：任务 id → 任务嵌入 → 轻量 2D 卷积 + 全局平均池化 → 单一任务特征 f_task。

- 拼接与广播：f_task 广播到所有 patch，与 patch 嵌入拼接，是任务信息与参数布局唯一的交汇点。

- 共享 FC 主干 + 逐任务 LoRA 路径：主干提供任务无关的特征传输，LoRA 让各任务轻度扰动表示。

- 多头输出：每个任务独占一个 FC 投影，显著缓解多任务干扰。

  • 训练目标：多任务掩码回归损失，只在 M_m = 1 的位置计算，并用任务平衡权重 w_m 补偿各基准可学习性的差异；基座 Θ₀ 全程冻结，仅优化 φ。
  • 推理时生成：查询一次超网络，施加预计算掩码与重缩放得到动作专家增量，检索压缩后的 VLM 残差，二者与冻结基座相加即实例化完整任务专用 VLA。
Card 05 数据集与资源

数据集与资源

  • 基座模型：π₀.₅，分解为 VLM 部分约 3.21B 参数与动作专家约 0.40B 参数（合计约 3.61B）。
  • 技能来源：用 FlowSDE 在三个基准上分别独立微调，得到 3 个任务向量。
  • 基准数据集：MetaWorld（32 任务，256 条轨迹）、ManiSkill（25 任务，320 条轨迹）、CALVIN ABC-D（96 次 rollout，每次 5 段子任务链）。
  • 超网络规模：覆盖 18 个 transformer block、9 类权重（162 个张量），切分为 256×256 patch（每任务 T = 6,480 个 patch）；共享 FC 隐藏宽度 h = 2048，逐任务 LoRA 秩 1024，多头输出为每任务 h→65,536 投影，共约 430M 可训练参数。
  • 压缩设置：模块级 top-K = 10%，全局重缩放 α = 1.1。
  • 训练配置：6,000 步，batch size 3，基础学习率 3×10⁻⁴，LoRA 乘子 3.0，600 步 warmup + 1,500 步 cosine 衰减，任务权重 (1.0, 0.4, 1.0) 对应 (MW, MA, CA)。
  • 计算资源：单张 A6000 GPU，约 10 小时。
Card 06 评估与结果

评估与结果

  • 评估环境：全部使用官方 RLinf 流水线，3 个随机种子取平均（典型标准差 ±2.7%）。
  • 主要指标：MetaWorld / ManiSkill 用 success_once（rollout 中任意时刻达成目标即成功）；CALVIN 用 success_at_end（完成五段任务链的比例）。
  • 主结果（Table 1）：

- NestedVLA 平均 66.7%，超越所有静态与动态合并基线 41–54 个百分点。

- ManiSkill 87.2%，距逐任务 FlowSDE 上限（88.1%）仅 0.9 pp。

- CALVIN 75.0%，说明单一共享 φ 足以支撑链式完成的精度要求。

- MetaWorld 37.9%，是剩余差距（平均 −13.8 pp）的主要来源。

  • 基线表现：静态合并全面失效（Averaging 14.8%、TIES 13.1%、WUDI 11.8%、TSV-Merging 13.4%，CALVIN 全为 0%）；动态合并最优为 Free-Merging 25.6%（2.16×），EMR-Merging 2.89× 存储仅得 23.0%，四者挤在 3 pp 带宽内，说明瓶颈在“选择”范式而非存储。
  • 存储分析：NestedVLA 总预算 1.5×——VLM 侧逐任务 top-10% 压缩残差约 0.35×，动作专家仅存每任务掩码约 0.01×、由超网络生成增量，超网络本身约 0.43B（≈0.12×）；容量集中在更难整合的动作侧。
  • 消融（Table 2）：多头输出贡献最大（移除后损失上升 0.2–0.5）；逐任务 patch embedding 增益有限（<0.1）；LoRA 路径可去掉，移除后在三个基准上均取得最低损失，且仅需默认参数的 97%。
