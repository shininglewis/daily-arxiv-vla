Card 03 核心贡献

核心贡献

  • 提出 P⁵ 技能模式（P⁵ Skill Schema），将任意具身技能统一分解为 perceive、propose、pre-manipulate、perform、post-manipulate 五个语义阶段，为责任比较提供可追踪的统一表示（灵感来自 REPL），并据此形式化为有限时域分层 MDP，在每个 P⁵ 阶段选择策略族 $c_i\in\{\mathrm{Mod},\mathrm{E2E}\}$
  • 提出 State-Locked Counterfactual Branching（SCB）：利用模拟器的保存/恢复机制与 oracle 结果判定，从同一物理状态出发执行每个可允许的策略族，从而暴露被选中分支经验所遗漏的同一状态反事实结果集合 $\mathcal{D}_{\mathrm{SCB}}$
  • 提出 Execution-Aware Learning（EAL）：将 MCTS 与 Q-learning 结合，把反事实结果蒸馏为族条件价值函数 $Q_\theta(x,c)$，包含失败与非偏好分支在内的所有树边转移均参与训练
  • 构建统一的 API 库：模块化族使用 InstructSAM、NeuGraspNet+、cuRoboV2 及确定性夹爪 API；端到端族筛选出 π0.5 与 FastWAM 作为 Perform_E2E 的局部执行器
  • 在 100 个任务、三个基准上取得 SOTA：总体成功率 77.0%，RoboSuite 90.0%、LIBERO-Pro 73.8%、RoboTwin 90.0%，并给出消融验证
Card 04 方法描述

方法描述

  • 问题形式化：语言条件操作建模为有限时域 MDP $\mathcal{M}=(\mathcal{X},\mathcal{C},\mathcal{P},r,\gamma)$；状态 $x_i=(\ell,o_i,h_i,z_i,g_i)$ 由语言指令、观测（RGB + 深度 + 本体感知）、可观测执行历史、当前 P⁵ 阶段与活跃技能模式组成；高层动作仅为策略族选择，低层由冻结编码智能体 $\pi_{\mathrm{code}}$ 生成完整可执行代码块 $a_i$
  • SCB（训练时算子）：以可恢复的 P⁵ 决策状态为节点、可允许策略族为边构建蒙特卡洛搜索树；节点快照 $\xi_i=(x_i,m_i,p_i,r)$ 含 oracle 掩码、真值物体位姿与终止奖励评估器；每个新节点至少对每个可允许族从同一状态评估一次，重复时重新采样代码并重放
  • 搜索四阶段：Selection（UCB 选择族边，式 1）、Expansion（SCB 同状态成对分支）、Rollout（用 API 库补全后缀，得到折扣回报 $G_i$）、Backpropagation（经验平均更新 $\widehat{Q}$，预算 $K=20$）
  • EAL 奖励设计：转移奖励 $\tilde r_i^c=w_{\mathrm{p}}r_{\mathrm{p},i}^c+w_{\mathrm{m}}r_{\mathrm{m},i}^c+w_{\mathrm{t}}d_i^c r$，其中感知分数来自与 oracle 掩码一致度，操作分数来自物体位姿误差（阈值 $\epsilon_p$），终端任务成功奖励 $r\in\{0,1\}$ 仅在终止时给出
  • Q 模型：状态与族构成以 结尾的多模态 token 序列，使用轻量 VLM 主干（如 Qwen3.5-0.8B）加 MLP 头输出标量 Q 值
  • 优化：采用 Smooth-L1 形式的 Bellman 损失（式 4、5），$Q_{\bar\theta}$ 为停止梯度的目标副本；不直接回归 rollout 回报或树估计
  • 测试时协调：用 softmax 诱导责任偏好 $\rho_\theta(c\mid x_i)$，选择 $c_i^*=\arg\max_c \rho_\theta$（等价于 $\arg\max_c Q_\theta$），编码智能体据此生成代码块，在每个 P⁵ 边界循环，无需状态恢复或特权模拟器状态
Card 05 数据集与资源

数据集与资源

  • 基准任务集：共 100 个桌面操作任务，来自 LIBERO-Pro、RoboSuite 与 RoboTwin 2.0 三个基准
  • 训练与评测划分：仅用 scene seed 0 采集特权 SCB 分支并训练 $Q_\theta$；协调器冻结后在 seeds 1–10 上评测，共 1,000 个测试回合，每个种子仅测试一次
  • 模块化族后端：InstructSAM（感知）、NeuGraspNet+（位姿提议，从 NeuGraspNet 扩展，仅在规划器可行的抓取中选 Top-1）、cuRoboV2（运动规划）、确定性夹爪
  • 端到端族后端：π0.5 与 FastWAM（离线筛选后选入 Perform_E2E），定位为抓取–抬升粒度的局部执行器
  • 模型规模：Q 值模型使用轻量 VLM 主干（如 Qwen3.5-0.8B）加 MLP 头；编码智能体、API 接口、后端绑定与低层后端参数在训练与评测全程冻结

Card 06 评估与结果

评估与结果

  • 评估环境：三个仿真基准 LIBERO-Pro（含指令重定向 T / 位置交换 S，分为 Spat、Obj、Goal、L10 等任务簇）、RoboSuite（完整任务池）、RoboTwin 2.0（双臂任务）；全局跨回合记忆对所有依赖记忆的基线均关闭以保证公平
  • 对比基线：端到端策略 π0、π0.5、FastWAM、FasterWAM；Code-as-Policy CaP、CaP-X、RATS、ASPIRE；带 harness 的 VLA Pigey、VLS、Harness-VLA
  • 主要指标：任务成功率（%），"Overall" 为可用列的均值
  • 关键结果：RoboAware 总体 77.0%，显著优于最佳基线 Harness-VLA（50.0%）与 ASPIRE（57.0%）；在 RoboSuite 与 RoboTwin 上均达 90.0%，成为 SOTA
  • 分项表现：LIBERO-Pro 上 Spat-T/S 68.0/68.0、Obj-T/S 92.0/86.0、Goal-T/S 66.0/84.0、L10-T/S 64.0/62.0，平均 73.8%；在 Goal-S、L10-T、L10-S 等困难列上取得最佳或并列最佳
  • 现象分析：端到端策略（VLA/WAM）在整任务分布偏移下零样本成功率低（如 π0 在多数列接近 0），RoboAware 通过生成可组合的模块化替代方案同时保留端到端局部能力来应对；Code-as-Policy 方法受接触精度与误差累积限制
