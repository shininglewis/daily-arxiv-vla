Card 02 论文概述

论文概述

  • 系统研究强化学习（RL）后训练如何从参数空间角度重塑视觉-语言-动作（VLA）模型，填补 LLM RL 已有参数级理解在 VLA 上的空白。
  • 发现 RL 在主流流匹配 VLA 模型上诱导出低秩参数更新，且高度集中在动作专家中被忽视的Timestep Modules（时间步模块）上。
  • 进一步刻画这些模块编码了什么信息（离散时间步特化、shift 向量编码任务结果与任务关系），并利用该结构指导更高效的微调与推理时策略引导。
Card 03 核心贡献

核心贡献

  • 首次揭示 RL 在 VLA 后训练中产生低秩、结构化的参数更新，且集中收敛于 Timestep Modules，该现象在 RL 训练的流式图像/视频 DiT 中并不出现，说明其是动作策略特有的。
  • 通过模块替换实验证明 Timestep Modules 仅占 14.83–27.58% 的参数，却承载了 RL 性能增益的绝大部分；将 LoRA 定向施加于该模块优于标准 LoRA 配置。
  • 揭示 RL 使 AdaRMS 特化到 rollout 中使用的离散去噪时间步（标准 BC 训练连续时间步），这种离散时间步训练正是低秩更新的根源。
  • 通过线性探测发现 shift 向量携带最多任务相关信息，其更新方向可预测任务成功（ROC-AUC 最高 99.6%），且 shift 更新几何与跨任务迁移模式相关（Spearman ρ 最高 0.794）。
  • 提出沿 shift 更新方向的自适应引导（steering），无需额外 RL 训练即可在五个基准上提升 RL 策略成功率 2.0–4.0%。
Card 04 方法描述

方法描述

  • 在流匹配 VLA 上使用 PPO 进行在线 RL 后训练，动作专家仅在 rollout 使用的离散去噪时间步上被更新，与 BC 在连续 τ∈[0,1] 上训练形成对比。
  • 定义 Timestep Modules 为 Time MLP 与 AdaRMS（自适应 RMS 归一化）参数，其输出为 scale、shift、gate 向量，仅以去噪时间步 τ 为条件，与图像、语言输入及任务进度无关。
  • 以 ΔW = W_trained − W_reference 刻画参数更新，用更新密度（绝对变化超过 10⁻⁵ 的比例）与有效更新秩（解释 95% 平方 Frobenius 范数所需的最少奇异方向数）做量化分析。
  • 对 AdaRMS 更新做 SVD，提取前三个输入奇异方向与条件向量 c_τ 的余弦相似度，分析时间步响应特化。
  • 通过模块替换实验（仅保留 Timestep Modules 更新 vs. 仅保留 MLP+Attn 更新）与低秩重构（仅用前 4 个奇异方向）验证 RL 增益来源。
  • 使用 ℓ₂ 正则化逻辑回归探针，将隐藏状态投影到 shift 更新方向 Δb 上预测回合成败；引导时仅当投影偏离成功回合均值时才做最小幅度干预。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、ManiSkill、MetaWorld、CALVIN 四个机器人操作基准，含模块替换、低秩重构、定向 LoRA、线性探测、跨任务迁移与激活引导等多组实验。
  • 主要指标：任务成功率（%）、参数更新密度、有效更新秩、探测 F1 / ROC-AUC、Spearman 相关。
  • 关键结果：

- RL 对 Timestep Modules 的更新密度达 70–95%，其他模块 <5%；有效秩仅 6–30，比 BC（250–650）低约一个数量级。

- 仅保留 Timestep Modules 的 RL 更新即可接近完整 RL 策略：MetaWorld 达 69.6%，在 LIBERO/ManiSkill/CALVIN 上仅分别落后 1.4%/1.6%/0.7%；而仅保留 MLP+Attn 在 ManiSkill 上最多下降 39.7%。

- ROB 探测：shift 更新方向预测任务成败的 ROC-AUC 达 98.6–99.6%，显著高于随机标签对照。

- 跨任务分析：shift 更新对齐度与迁移效应相关性平均 0.504（范围 0.224–0.794）。

- 引导效果：五个基准成功率提升 2.0–4.0%（如 LIBERO-Spatial 86.7%→90.0%，LIBERO-Goal 90.7%→94.7%），优于同范数随机方向。
