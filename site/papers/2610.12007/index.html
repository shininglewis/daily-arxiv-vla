Card 03 核心贡献

核心贡献

  • 识别分块 flow-based VLA 推理中的 coherence–freshness trade-off，并提出 input throughput 与 output throughput 作为闭环响应性的系统级度量。
  • 提出 REACT 滚动去噪机制：维护持久动作缓冲，使用交错 flow timesteps，在每个控制步用最新观测去噪完整 horizon，执行最干净前块，前移部分精炼的未来块，并在尾部追加新噪声。
  • 提出 Dual Decoupling：分离感知、VLM 编码、DiT 去噪和动作执行，在不改变模型权重的情况下实现高频观测更新和连续动作流，达到异步执行级别的吞吐。
  • 提出 matched staircase training：用与滚动推理一致的 per-position staircase flow times 监督 K 个确定性去噪阶段，提升训练收敛与开环预测精度。
  • 在仿真和真实任务上提升成功率、反应延迟与轨迹平滑度，并优于频繁重规划和异步+RTC 基线。
Card 04 方法描述

方法描述

  • 基于 π0.5 flow-based VLA；将动作 horizon H 分为 K 个长度为 S 的块，H=KS，并为每个动作位置分配阶梯式 flow time：τ_j=(⌊j/S⌋+1)/K。
  • 每个控制步给定最新观测，一次 DiT 前向预测全缓冲速度，执行一次 Euler 更新；随后执行前端块，其余块左移，尾部加入新鲜高斯噪声。
  • 每个块从噪声尾部移动到可执行前端的过程中经历 K 次滚动更新，因此被多个近期观测逐步精炼，减少独立重规划导致的多模态模式切换和块边界抖动。
  • Dual Decoupling 将感知/VLM 编码与 DiT 去噪/动作执行解耦，用 M 个 VLM worker 异步编码到 latest-ready cache，DiT 消费最新 embedding；吞吐受 Φ_in 和 Φ_out 约束。
  • 训练损失 L_REACT 监督完整 horizon 上的 per-position 去噪阶段，与部署时的滚动调度对齐，属于确定性多时间步训练。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 仿真、ARX X5 和 Franka R3 真实平台；还包括 Pour Rice 和 Reaction Game 动态任务。
  • 主要指标：Success Rate (%)；Trajectory Smoothness 用成功 episode 的平均关节轨迹 jerk 衡量；Reaction Game 用反应延迟 ms；Pour Rice 用成功率。
  • 仿真平均成功率：REACT w/o DD 达 49.71% Clean / 20.86% Random；full REACT 达 44.86% Clean / 19.86% Random，均优于 π0.5 H50E50、H50E10、H10E10 和 Async+RTC。
  • 真实总体平均成功率：REACT w/o DD 65.7%，full REACT 64.8%，高于 H50E50 58.7%、H50E10 35.9%、H10E10 21.0% 和 Async+RTC 17.7%。
  • 轨迹平滑：full REACT 将仿真 jerk 从 Async+RTC 2022.2 降至 1219.0，ARX X5 从 284.1 降至 90.1，Franka 从 31.6 降至 28.6。
  • 动态任务：Pour Rice 中 full REACT 成功率 63% 最高；Reaction Game 中 full REACT 延迟 734±94 ms 最低，接近人类 705±73 ms。
  • 训练效率：REACT 在 3k steps 达 52.7% 平均成功率，而 π0.5 基线为 25.0%；15k steps 匹配基线 30k steps 性能。
  • 统计显著性：两比例 z-test 给出 z=4.44、4.84、9.10，均 p<1e-5。
