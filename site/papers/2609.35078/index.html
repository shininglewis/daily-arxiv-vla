Card 03 核心贡献

核心贡献

  • 提出 RefineDrive，显式利用模型自身 rollout 中的失败案例，解决自动驾驶 VLA 的残余弱点。
  • 提出 Reliable Diagnosis 与 Minimum-Correction Target Retrieval：从模拟器状态生成可验证的结构化诊断，并从聚类人类轨迹库中检索满足硬安全约束且接近失败预测的修正轨迹，减少过校正。
  • 设计 Safety-Layered Reward，优先硬安全，保留连续安全反馈，并仅在硬安全满足后奖励驾驶进展。
  • 在 NAVSIM 基准上验证有效性：4B 基础模型从 87.7 PDMS 提升至 91.7 PDMS，且同一 checkpoint 在 NAVSIM v2 扩展指标下达到 89.4 EPDMS。
Card 04 方法描述

方法描述

  • 框架包含四个阶段：Failure Discovery、Structured Failure Correction、Correction SFT、Safety-Layered Reinforcement Learning。
  • Failure Discovery：对监督微调策略进行离线 rollout，使用 NAVSIM PDM Simulator 获取可复现的安全结果，聚焦 at-fault collisions 和 drivable-area violations。
  • Structured Failure Correction：包括可验证失败诊断和反事实最小修正。诊断从模拟器状态提取碰撞时间、对象类别、相对位置和 2D 框，以及可行驶区域左/右越界信息；最小修正从人类轨迹库中按 K-Means 聚类检索，优先同簇搜索，并用硬安全可行性 \(F(\tau)=\mathrm{NC}\wedge\mathrm{DAC}\wedge\mathrm{TTC}\) 过滤候选。
  • Correction SFT：训练时以驾驶上下文 \(q\) 和失败轨迹 \(\tau^{-}\) 为输入，自回归生成结构化诊断和修正轨迹 \(\tau^{*}\)；推理时仅根据 \(q\) 直接预测轨迹，不执行显式诊断或修复。
  • Safety-Layered GRPO：构造连续安全分数 \(S(\tau)\)，结合硬安全 \(F(\tau)\)、连续安全 \(S(\tau)\) 和驾驶进展 \(P(\tau)\)，最终奖励为 \(R(\tau)=\lambda_F F(\tau)+\lambda_S[1-\eta F(\tau)]S(\tau)+\lambda_P F(\tau)P(\tau)\)，设置 \((\lambda_F,\lambda_S,\lambda_P)=(2.0,1.0,0.25)\)，\(\eta=0.5\)。
Card 05 数据集与资源

数据集与资源

  • 使用 NAVSIM 基准，其基于 OpenScene/nuPlan；NAVTRAIN 用于监督训练、失败挖掘和强化学习，NAVTEST 仅用于评估。
  • 模型主干为 Qwen3.5-4B，首先在 NAVTRAIN 上进行轨迹 SFT，再执行 Correction SFT 和 Safety-Layered GRPO。
  • 推理时每个 checkpoint 直接预测未来 4 秒内 8 个 (x, y, heading) waypoints，间隔 0.5 秒，输入为前视图图像、自车状态和历史轨迹。

Card 06 评估与结果

评估与结果

  • 在 NAVSIM v1 上对比端到端和 VLA 规划方法，报告 PDMS、NC、DAC、TTC、EP、C 等指标；在 NAVSIM v2 扩展指标下评估同一 checkpoint。
  • 主要结果：RefineDrive 在 NAVSIM v1 上达到 91.7 PDMS、98.7 NC、98.2 DAC、95.9 TTC，相比 Base SFT 的 87.7 PDMS 显著提升。
  • 在 NAVSIM v2 扩展指标下，使用相同 checkpoint 且不额外训练，在原始 NAVTEST 场景达到 89.4 EPDMS。
  • 消融实验表明：最小修正目标优于 Human GT；结构化诊断监督带来额外收益；Safety-Layered Reward 相比直接 PDMS 优化在保持相同 EP 的同时提升 NC、DAC、TTC 和 PDMS。
  • 定性分析显示，RefineDrive 在相同 NAVTEST 场景中避免了基础策略出现的 off-road 和碰撞行为。
