Card 02 论文概述

论文概述

  • 论文提出 MOSAIC（Modular Obstacle and Spatial-Aware Framework），一个模块化、障碍物与空间感知的框架，可即插即用地增强预训练 VLA（Vision-Language-Action） 策略在杂乱场景中的操作能力。

  • 目标是在不破坏原有预训练 VLA 架构的前提下，显式注入语义、几何与障碍物感知线索，提升操作成功率与安全性。
Card 03 核心贡献

核心贡献

  • 提出 MOSAIC 模块化框架，增强 VLA 的以物体为中心的理解与空间推理能力，适用于杂乱环境下的操作任务。
  • 在 VLM 主干上引入辅助语义掩码预测任务，按角色区分为目标物体（target）、目的地区域（destination）、周围障碍物（obstacle）三类掩码。
  • 利用 VGGT-Ω 重建的深度估计与角色掩码结合，构建角色专属的几何 token 并直接注入 action expert。
  • 提出障碍物感知注意力监督：沿机器人连杆插值采样，建模全身与障碍物的接触邻近度，生成真值注意力热图并通过 KL 散度监督，再将注意力特征残差式注入后层。
  • 在 RoboPRO 基准与真实机器人上验证有效性：杂乱场景成功率提升 5.1%，视觉扰动下提升 9.7%，最具挑战场景最高提升 25.0%。
Card 04 方法描述

方法描述

  • 基线架构：在开源 VLA 模型 π0.5 上实现，共享视觉-语言主干编码观测与指令形成 prefix，较小的 action expert 以 flow matching 生成动作 chunk。
  • 语义掩码生成：为每个角色分配专用 token 组（K=4，共 12 个可学习 mask token），参与双向 prefix 注意力；专用 MaskHead 以均值池化后的角色 query 对主相机 patch 网格解码三张掩码；先用粗语义图预测，再用浅层 RGB 残差分支细化边界；损失为加权 BCE + soft Dice + 边界损失，仅在有效角色上平均。
  • 对象深度注入：冻结的 3D 场景重建解码器 Ω 生成深度图 D 与置信图 C，按角色掩码筛选有效像素；构建两类几何编码——全局统计 token（质心、包围框、深度均值/最小值/标准差）与 G×G（G=4）网格局部深度 token，共 17 个 token/角色，加角色嵌入后拼接到加噪动作序列；仅在 action expert 的最后 6 层注入。
  • 注意力引导：计算机器人点到各物体 OOBB 的最小距离，在时间窗 W=7 内取最小值，按阈值 d_thresh=15cm、软阈值 m=5cm、放大系数 g=3 生成邻近权重 β；生成逐物体接触盘掩码并按像素取 max 聚合，与高斯核（σ=15px）卷积得到空间热图，再转为 patch 级真值注意力分布；用 KL 散度监督前 3 层 action-expert 的注意力，并将 AttentionQueryHead 输出的残差通过 cross-attention 注入最后 3 层。
  • 训练策略：两阶段训练——阶段 1 冻结主干与 action expert，仅训练 grounding heads 与 rank-32 LoRA；阶段 2 合并 LoRA 后联合微调整个策略。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboPRO 基准，含 Office、Study、Kitchen-S、Kitchen-L 四个环境、80 个任务（单物体、铰接物体、多步三类），每任务 200 条专家演示（100 干净 + 100 杂乱，杂乱场景 6–15 个干扰物）；重放记录 320×240 RGB-D（台面 + 双腕相机）。
  • 真实数据集：自采集 1,000 条标注轨迹，UR5e 机械臂 + Robotiq 2F-85 夹爪，5 类任务（放杯入碗、碗上架、马克杯放杯垫、双立方体堆叠、三杯入三碗组合任务）；每任务 100 干净 + 4 个杂乱等级各 25 条；3 台 Intel RealSense 相机，640×480 @ ~20Hz，掩码由 SAM 2.1 视频分割生成并人工校正。
  • 模型规模：基于 π0.5 开源 VLA；输入 3 路 224×224 相机视图，预测 50 步动作 chunk；使用 rank-32 LoRA 适配器。
  • 训练资源：基线在 RoboPRO 上微调 30K 步、batch size 192；MOSAIC 两阶段训练使用全局 batch size 64，AdamW（β=(0.9, 0.95)，weight decay 1e-10，梯度裁剪 1.0），阶段 2 使用 EMA（衰减 0.99）；原文未明确给出 GPU/TPU 具体数量。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboPRO 仿真基准的干净/杂乱两种设置 + 视觉扰动设置（光照色调/阴影、高斯模糊 σ=0.5px、逐帧逐相机 ±0.5px 像素平移），以及真实机器人实验。
  • 评估指标：成功率 SR（Success Rate）、硬成功率 HSR（无意外碰撞完成）、碰撞率 CR（Collision Rate）。
  • 仿真主要结果（四环境平均）：完整 MOSAIC 在干净场景 SR 从 66.0% → 70.1%，HSR 61.0% → 64.8%；杂乱场景 SR 52.7% → 57.8%（+5.1%），HSR 39.7% → 41.3%。
  • 消融结果：仅掩码（含障碍物）在杂乱场景 SR +2.7%；去掉障碍物掩码使杂乱 SR 从 55.4% 降至 52.7%、HSR 从 39.2% 降至 38.7%；注意力模块再增 0.5%/1.5%；深度注入带来最大增益（干净 +4.1%、杂乱 +5.1% SR）。
  • 视觉扰动鲁棒性：12 个扰动任务上整体 SR 从 65.2% → 74.9%（+9.7%），HSR 从 63.4% → 72.7%（+9.3%），CR 基本不变；Office 环境提升最大，SR 从 51.7% → 76.7%（+25.0%），HSR 50.0% → 71.7%（+21.7%）。
  • 注意力可视化：与基线 π0.5 相比，MOSAIC 的注意力更集中于潜在碰撞区域，基线则常分散到无关区域。
  • 行为权衡观察：杂乱场景中 CR 由 39.7% 升至 44.8%，说明模型尝试并完成更多操作、暴露于更多潜在接触，执行安全性仍有提升空间。
