GaussianWAM: Distilling Geometry and Semantics from 3D Gaussian Fields into World-Action Models

2026-08-25 · 原文 · 翻译 · 2608.24714

提出 GaussianWAM，一个面向世界动作模型（World-Action Models, WAMs）的训练时表示增强框架，利用 3D 高斯场作为统一空间载体，将几何与视觉语义监督组织并蒸馏进 WAM 的当前观测表示。 现有 WAM 的视频潜变量主要针对视觉预测优化，缺乏显式的跨视角几何结构约束和空间定位的物体级语义约束；直接使用多个异构教师分别蒸馏缺乏共享空间载体，而显式 3D/4D 世界模型又会增加训练和推理成本。 GaussianWAM 在训练时构建高斯教师，渲染语义、深度和覆盖率目标并蒸馏到 WAM 表示中；推理时完全移除所有额外模块，保持原始 WAM 推理路径和计算开销不变。

Card 03 核心贡献

核心贡献

  • 提出 GaussianWAM 通用增强框架，使用 3D 高斯场作为统一空间载体，将互补的几何与视觉语义监督组织到动作相关的潜表示中。
  • 引入 高斯场蒸馏机制：将几何与视觉语义知识绑定到统一 3D 表示，再将渲染的语义、深度和覆盖信号蒸馏到当前观测的 WAM 表示。
  • 采用 训练-only 增强策略：高斯场、外部教师和辅助预测头在推理时全部移除，不改变原始 WAM 的推理流程与计算成本。
  • 在 FastWAM（双专家 MoT）和 Cosmos Policy（统一 DiT）两种代表性 WAM 架构上验证，在 LIBERO、LIBERO-Plus、RoboTwin 及真实世界机器人实验中均取得一致提升，证明方法的有效性和泛化性。
Card 04 方法描述

方法描述

  • 使用冻结的几何基础模型 VGGT-Omega 获取多视图深度、深度置信度、相机内参和外参；使用冻结的 CLIP ViT-B/16 提取密集视觉语义特征（降为 64 维）。
  • 通过几何有效点云初始化密集 3D 高斯场（每个高斯携带位置、旋转、尺度、不透明度和 64 维语义特征），并利用可微深度感知高斯渲染器进行多视图拟合，联合优化语义余弦距离、深度 L1 损失和覆盖率约束。
  • 拟合后渲染得到语义图、深度图、累积 alpha 覆盖图和有效性掩膜（几何有效 ∩ 渲染覆盖），离线缓存供训练重复使用。
  • 在 FastWAM 风格双专家 MoT 中，对视频专家最终层当前观测 token 施加蒸馏；在 Cosmos-Policy 风格统一 DiT 中，对共享骨干中当前观测视觉 token 施加蒸馏，蒸馏损失为掩膜余弦语义损失 + 掩膜深度 L1 + 掩膜 alpha L1。
  • 关键创新：用 3D 高斯场作为共享空间载体，将异构教师信号在统一 3D 坐标系中对齐，并通过渲染操作产生空间一致且受覆盖掩膜约束的稠密监督；推理阶段所有新增模块被移除。

  • 训练资源：

- FastWAM 及其 GaussianWAM 变体：8 张 NVIDIA A100 GPU，每卡 batch size 2，梯度累计 2 步（有效 batch 32），训练 70k 步，学习率 1e-4，权重衰减 1e-2。

- Cosmos Policy 及其变体：8 张 GPU，本地 batch 30，累计 8 步（有效 batch 1920），训练 5k 步。

- 高斯拟合每样本迭代 50 次（N_fit=50），语义蒸馏权重 λ_sem=0.01，深度 λ_depth=0.01，α λ_α=0.005。

Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO、LIBERO-Plus（零样本分布偏移）、RoboTwin 2.0 Clean-to-Random 基准，以及真实世界操作任务；主要指标为 任务成功率（%）。
  • 关键实验结果：

- LIBERO-Plus 整体成功率：FastWAM 从 52.05% 提升至 71.29%（+19.24）；Cosmos Policy 从 71.52% 提升至 77.30%（+5.78）。

- 在 FastWAM 上，相机偏移 +29.03，光照 +29.11，噪声 +39.46，机器人 +18.73，表明高斯监督显著增强了分布偏移下的空间鲁棒性。

- 直接 CLIP + VGGT 蒸馏建立 FastWAM 基线为 69.37%，高斯场统一进一步将其提升至 71.29%，验证了统一空间组织的收益。

- RoboTwin：FastWAM + GaussianWAM 保持 Clean 70.50% 并提升 Random 从 0.70% 到 1.60%；Cosmos Policy + GaussianWAM 将 Clean 从 34.40% 提升至 68.90%，Random 从 7.10% 提升至 14.40%。

- 真实世界操作：GaussianWAM 将 FastWAM 平均成功率从 30.00% 提升至 40.00%，在标准、布局、相机和视觉噪声四种设置下均有效。

- 消融研究：移除语义监督降至 68.06%，移除 α 降至 70.99%，移除深度监督降至 66.28%，说明三者互补；作用于最终层（层 30）优于中间层（67.86%@层10，68.44%@层20）。
