Card 03 核心贡献

核心贡献

  • 提出将离散轨迹作为轨迹-几何条件（TrajCond）：先预测离散轨迹，再以其几何-语义作为条件指导最终连续轨迹预测，而非直接把离散轨迹当作最终输出。
  • 设计 1D-Brohan 动作 token 化方案：在每一步局部坐标系下计算差分运动，并用三个独立的 Brohan 式码本分别离散化 \(x\)、\(y\)、yaw 的一维运动，每个 token 表示单自由度局部运动；相比 K-Means/K-Disks 共享码本，取得了更好的 TrajCond 效果与最低重构误差。
  • 提出两阶段对齐训练框架：阶段 1 用动作 token 序列预热（warm-up）新动作词表的语义；阶段 2 在给定已解码 TrajCond 与推理上下文的情况下回归最终连续轨迹，将“条件学习”与“最终轨迹预测”解耦。
  • 系统性分析了轨迹表示形式对驾驶 VLA 的影响，验证“离散轨迹作为直接输出较弱、但作为条件更强”的现象，并分析 TrajCond 是否吸收面向动作的规划语义。
  • 在 NAVSIM navtest、nuScenes、NeuroNCAP 三类开环/闭环基准上取得领先结果。
Card 04 方法描述

方法描述

  • 任务建模：给定观测图像 \(\mathbf{o}\) 与语言指令 \(\ell\)，传统 VLA 直接建模 \(\tau=f_{\text{VLA}}(\mathbf{o},\ell)\)；AutoVLA-D 改为两阶段 \(\mathbf{a}=f_{\text{VLA}}^{(1)}(\mathbf{o},\ell)\)、\(\tau=f_{\text{VLA}}^{(2)}(\mathbf{o},\ell,\mathbf{a})\)，其中阶段 2 由阶段 1 初始化。
  • 连续轨迹表示：沿用 Curious-VLA 的逐步归一化文本路点序列化，\(\tilde{\tau}_t=(\tau_t-\mu_t)/\sigma_t\)，其中 \((\mu_t,\sigma_t)\) 为训练集逐步统计量。
  • 差分动作构造：在 \(t-1\) 时刻局部坐标系下用平面旋转 \(\mathbf{R}(-\theta_{t-1})\) 计算差分 \((\Delta x_t,\Delta y_t,\Delta\theta_t)\)，而非使用静态坐标系。
  • 1D-Brohan 分词器：对每个动作维度取训练集 1%/99% 分位区间均匀划分为 \(Q_i\) 个 bin，形成 \(\mathbf{x}\)、\(\mathbf{y}\)、\(\boldsymbol{\theta}\) 三个码本，总词表 \(Q=\sum_i Q_i\)；默认 \(Q=768\)，每维 \(Q_i=256\)。
  • 轨迹离散化：以“最小角点距离”\(d_{\mathrm{corner}}\) 逐步迭代选择候选 tuple；为避免 \(Q_i^3\) 穷举，先对每维取绝对残差最小的 4 个 token，枚举 \(4\times4\times4\) 组合后择优。
  • 训练目标：阶段 1 使用动作 token 自回归损失；阶段 2 联合优化动作 token 损失与最终路点 token 损失，训练时对动作 token 采用 teacher forcing，推理时完全自回归（先 TrajCond 再连续轨迹）。
  • 推理与强化微调：在 NAVSIM 上引入 CoT 推理监督（由 Qwen3-VL-235B 标注关键对象/条件、专家轨迹解释、速度与指令元行为标签），并增加第三阶段用 GRPO 做 RFT，输出顺序为 \(\mathbf{a}\rightarrow\mathbf{r}\rightarrow\mathbf{w}\)；nuScenes 与 NeuroNCAP 仅使用阶段 1/2 的 SFT。

Card 06 评估与结果

评估与结果

  • 评估环境：NAVSIM navtest（闭环，遵循 ReCogDrive 设置）、nuScenes（开环，遵循 Impromptu VLA 设置）、NeuroNCAP（闭环，遵循 ImagiDrive 设置）。
  • 主要指标：NAVSIM 采用 PDMS 与更严格的 EPDMS（含 NC、DAC、DDC、TLC、EP、TTC、LK、C、EC 等子项）；nuScenes 采用 ST-P3 与 UniAD 指标下的 L2 误差与碰撞率；NeuroNCAP 采用 NeuroNCAP Score 与碰撞率（平均/静态/正面/侧面）。
  • NAVSIM navtest PDMS：AutoVLA-D（Qwen3-VL-4B）取得 92.0 PDMS，NC 98.8、DAC 97.7、EP 89.8、TTC 97.7、C 99.8，优于 ImagiDrive-S（87.4）、ReCogDrive（89.6/90.7）、DriveVLA-W0（90.2）、AutoVLA（89.1）、AdaThinkDrive（90.3）、Curious-VLA（90.3/89.7）、FLARE（91.4）。
  • NAVSIM navtest EPDMS：取得 86.8 EPDMS，其中 EP 91.2、TTC 98.2、LK 96.9、NC 98.8，超过 Curious-VLA（85.3）与 FLARE（86.3）。
  • nuScenes 开环：ST-P3 指标下 L2 = 0.30、碰撞率 0.09；UniAD 指标下 L2 = 0.60、碰撞率 0.29，优于 AutoVLA（0.48/0.13、0.86/0.35）与 Impromptu VLA（0.33/0.13、0.67/0.38）。
  • 消融验证：“Ours w/o TC”（去掉 TrajCond）在 nuScenes 上 L2/Col 为 0.30/0.11 与 0.60/0.34，加入 TrajCond 后碰撞率降至 0.09/0.29，验证 TrajCond 的增益。
  • 分析与结论：轨迹表示分析显示离散轨迹作为直接输出弱于连续轨迹，但作为 TrajCond 可稳定提升最终连续轨迹预测；语义分析进一步表明 TrajCond 在提供几何引导之外，还能吸收面向动作的指令规划语义。
