Card 03 核心贡献

核心贡献

  • 提出 Gnomon4D：通过 GeoDelta 显式建模视频对齐的 4D 几何运动，使动作专家在去噪过程中可直接读取“本体—物体”交互动力学。
  • 提出 InSAttn（Interaction-Salient Attention）：利用任务条件下的本体—物体相对运动，将空间读数聚焦到交互区域。
  • 提出 TransAgg（Transition-Anchored Aggregation）：在相对运动发生突变的帧（如抓取、释放）上聚合证据，实现时间维度的聚焦。
  • 将 GeoDelta 设计为本体无关（embodiment-agnostic）的“准动作（quasi-action）”，使人类手部视频与机器人视频共享同一监督空间，从而支持无动作标签预训练。
  • 在三个仿真基准与真实机器人上取得领先结果，并验证了跨域（ID/OOD）泛化优势。
Card 04 方法描述

方法描述

  • 架构：基于 Mixture-of-Transformers（MoT），包含 Video / GeoDelta / Action 三个专家，各专家权重独立，每层通过 joint attention 交换信息；三者均通过 cross-attention 读取语言指令与本体状态。
  • GeoDelta 表示：对前景（本体与被操作物体）每个像素记录同一物理点在相邻采样帧间的图像平面位移与深度变化 (Δu, Δv, Δd)；在同一相机下测量使其对相机运动不变，深度分量补充了 2D 光流缺失的视线方向运动。
  • 编码方式：将三分量软阈值去噪后按固定尺度 ω 归一化，用有符号 μ-law 压扩（μ=31） 映射到 8-bit 三通道，从而复用冻结的视频 VAE。
  • 去噪时钟与因果掩码：共享采样进度 u，σ_V(u)=1−u，σ_G(u)=σ_A(u)=max(1−2u,0)，即 GeoDelta 与动作以两倍速度收敛；因果掩码使未来 Video/GeoDelta token 只能看到自身时间步之前的动作，干净 token 不看噪声 token。
  • 关系引导读数：用轻量头从 GeoDelta 特征预测 token 运动 δ 与角色概率（本体/物体），构造相对运动场 c（本体与物体同动时趋 0，相对运动时趋 1）；抓取/释放表现为 \|Δc\|的峰值。
  • 读数与注入：InSAttn 用 MLP φ(c; ℓ, s₀) 加前景先验生成显著度 s 并加权注意力；TransAgg 以 rₙ=Σᵢ sₙ,ᵢ\|Δcₙ,ᵢ\|为帧打分做时间聚合；每模态 K=32 个可学习 query，共 2K 个交互 token 以残差 cross-attention 注入 Action 专家，并配合辅助动作预测头与指令/本体随机掩码。
Card 05 数据集与资源

数据集与资源

  • EgoManip-5000H：5,000+ 小时无动作标签的第一视角操作视频，用于 Video 与 GeoDelta 专家的预训练。
  • Robot-30H：30+ 小时真实机器人数据（源自 IG-10K），用于加入 Action 专家后的中训练。
  • 仿真基准：RoboTwin 2.0（50 个双臂任务，Clean / Rand. 设定，SAPIEN 回放生成精确 GeoDelta）、VLABench（MuJoCo 重新生成）、RoboDojo（仅 RGB、相机参数与机器人状态；本体 GeoDelta 由正运动学精确求得，物体 GeoDelta 用 DA3 深度 + SAM 3.1 掩码 + RAFT 光流估计）。
  • 真实机器人：5 个任务，GeoDelta 由 RGB-D 相机深度 + SAM 3.1 掩码 + RAFT 光流构建。
  • 模型规模：Video 专家初始化自 Wan2.2-TI2V-5B（30 层，宽度 3072）；GeoDelta 与 Action 专家宽度 1024，由宽度插值得到以共享注意力空间。
  • 训练资源：FSDP hybrid sharding + bfloat16 精度（原文未给出具体 GPU 数量）。
  • 推理设置：预测 H=32 步动作块，视频/GeoDelta 以 Δ=4 步长采样得 N=8 帧；共 20 个求解步，第 10 步后 GeoDelta 与动作变为干净并触发重规划。
Card 06 评估与结果

评估与结果

  • 评估环境：三个仿真基准（RoboTwin 2.0、VLABench、RoboDojo）+ 真实机器人 5 任务的分布内（ID）与分布外（OOD）测试；消融覆盖未来表示、交互读数与预训练课程。
  • 主要指标：任务成功率（Success Rate, %），RoboDojo 额外报告维度 SR（Gen./Prec./Long/Mem./Open）与 Score。
  • RoboTwin 2.0-Full：Gnomon4D 取得 Clean 94.56、Rand. 94.10、Avg 94.33，优于 STARRY（93.56）、Qwen-RobotManip（93.85）、LingBot-VA 2.0（93.60）、OpenWAM-Alpha（93.60）、FlowWAM（92.54）、X-WAM（90.22）等。
  • VLABench：Avg 62.5（ID 84.0、CS 61.7、Ins 59.1、Tex 68.8），高于 Xiaomi-Robotics-1（59.1）与 OpenWAM-Alpha（58.9），在 CS/Ins/Tex 子项均领先。
  • RoboDojo：在 Gen./Prec./Long/Mem./Open 各维度 SR 与总体 SR、Score 上均列第一。
  • 真实机器人：相比最强基线（Fast-WAM、X-WAM、FlowWAM）在 ID 设定提升 7.0 个百分点、OOD 设定提升 16.0 个百分点。
  • 消融结论：验证显式 4D 几何运动表示、关系引导的时空读数（InSAttn + TransAgg）以及“无动作预训练→机器人中训练→目标任务后训练”课程各自的必要性。
