FOCA: Future-Oriented Conditioning for Data-Efficient Vision-Language-Action Adaptation

2026-06-18 · 原文 · 翻译 · 2606.20867

论文提出 FOCA（Future-Oriented Conditioning），一种面向数据高效的视觉-语言-动作（VLA）模型适应性微调框架，解决 VLA 模型在少样本模仿学习（few-shot imitation learning）场景下的性能严重退化问题。 核心思想是通过显式预测任务相关的未来交互嵌入与隐式对齐未来目标观测，在潜在空间中实现长时程推理，避免像素级未来帧预测的高昂成本。 FOCA 天然支持无需动作标签的合成视频辅助训练，可无缝利用视频世界模型（如 DreamGen）生成的合成轨迹，提升数据利用效率。

Card 03 核心贡献

核心贡献

  • 系统性少样本压力测试：对 SOTA VLA 模型（π₀、GR00T-N1.5、EO-1、SmolVLA）在仅 10–30 条示范下的适应性能进行系统评估，揭示了现有模型在少样本条件下的严重性能退化。
  • 未来导向条件化框架：提出 FOCA，在 VLM 中引入显式未来预测 token 和隐式未来对齐 token，二者通过结构化注意力隔离掩码实现功能解耦，作为轻量级插件适配扩散式 VLA 策略。
  • 动作无关的合成视频利用：隐式对齐目标可仅使用合成视频（无需动作标签）进行 co-training，实现了动作无关的辅助监督信号。
  • 理论分析：将隐式未来对齐解释为目标条件折扣占用（goal-conditioned discounted occupancy），建立与对比式目标条件强化学习和 successor representation 的联系。
  • 跨仿真与真实机器人的持续性能提升：在 9 个仿真基准、1 个人形机器人及 3 个真实机器人场景（ALOHA、UR5）上验证了方法的有效性。
Card 04 方法描述

方法描述

  • 显式未来潜变量预测：利用现成的 grounding 模型定位语言指定的物体和机器人夹爪，构造目标中心交互区域（最小包围框）；通过轻量级预测头将显式 token 映射到未来区域的 patch 嵌入，并用 L2 损失匹配冻结视觉编码器提取的目标区域特征。
  • 隐式未来对齐：使用 InfoNCE 风格对比损失，将当前观测的隐式 token 嵌入与同 episode 未来目标帧嵌入对齐，负样本来自其他任务的 minibatch episode；未来偏移量按截断几何分布采样，对应折扣可达性解释。
  • 结构化 token 隔离：在 VLM 注意力层中阻止显式预测 token 与隐式对齐 token 之间的直接信息交换，但允许二者与共享的视觉/文本 token 交互，确保两种目标学习互补功能。
  • 三目标共同训练：总损失为流匹配损失（flow-matching loss）+ 显式预测损失 + 隐式对齐损失；对于合成视频数据仅优化后两项，推理时不执行未来预测。

Card 06 评估与结果

评估与结果

  • 数据效率：在 LIBERO 上仅用 20 条示范即达到 95.7% 成功率；在 RoboCasa 上提升 7–12%；真实机器人上带来高达 26 个百分点的绝对提升
  • 10% 数据规模对比：FOCA 在 LIBERO 平均成功率 85.3%，显著优于 π₀（77.6%）、GR00T-N1.5（78.2%）、EO-1（82.2%）、SmolVLA（77.3%）
  • PEFT 方法对比：FOCA 在 10% 演示下（85.3%）优于 ControlVLA（78.4%）、LoRA r=64（78.2%）、DoRA r=64（78.6%），在 100% 数据下也保持最优（96.6%）
  • 全数据规模：FOCA 在 LIBERO 100% 数据下平均成功率 96.6%，高于 π₀（94.6%）和 GR00T-N1.5（94.6%）等基线
