Card 03 核心贡献

核心贡献

  • 提出 VLA-Stem，一种基于强化学习的轻量级运行时安全机制；它直接把 VLA 任务意图与面向物理约束的安全适配整合起来，且无需微调基座 VLA 策略。
  • 设计轨迹级引导目标：把 VLA 输出的动作块（action chunk）作为运动参考，允许局部运动与执行时序灵活调整，同时保持任务空间意图不变。
  • 引入教师–学生蒸馏 + 课程学习框架，使学生策略能够从安全干预造成的执行偏差中恢复，并在部署时摆脱对任务特权信息的依赖。
  • 在仿真与真实世界中开展了大量实验，验证了免碰撞任务成功率显著提升，并且 Stem 策略可直接从仿真迁移到现实，无需真实世界训练或微调。
Card 04 方法描述

方法描述

  • VLA 条件化执行：冻结的 VLA 每隔 h 个控制步输出一个动作块，并将其转换为相对末端执行器位姿序列 τ_c^rel，作为该区间内的任务导向运动参考。
  • Stem 策略输入：机器人本体感知状态（关节位置、末端位姿）、局部障碍信息（障碍中心与包围盒尺寸），以及当前激活的 VLA 参考轨迹。
  • 轨迹级引导：把当前末端位置投影到参考轨迹的相邻路点线段上，并插值计算旋转偏差，得到综合偏差 d_i = d_i^pos + α·d_i^rot；用非递减段索引 m_t 和前瞻窗口 K 构成前向走廊，避免匹配已走过的段。
  • 稠密跟随奖励：r_t^follow = exp(-k_pose · d_t*)，在早期课程阶段额外加入与匹配段前进量成正比的进度奖励。
  • 教师–学生蒸馏：教师额外接收特权任务信息（例如目标物体位置），但不改变奖励函数；学生用 L = L_RL(PPO) + λ·D_KL(π_stu‖π_tea) 优化，λ = 0.1。
  • 强化学习与课程：总奖励由任务项、碰撞惩罚项（碰撞或违反约束时为 -1）和引导项加权组成；训练分为三阶段课程：无障碍跟随 → 静态空间约束 → 动态移动障碍（含等待行为）。
Card 05 数据集与资源

数据集与资源

  • 仿真平台为 ManiSkill，包含三个任务：PickCube、StackCube，以及自建的 Object Stowing（在空间约束下把日用品放入目标容器）。
  • 基座 VLA 模型为 π₀ 与 π₀.₅，每个基座 VLA 用 100 条示教微调 30,000 步，检查点被所有对比安全机制共享。
  • 每个任务构造三种场景：Normal（无障碍）、Static（静态障碍，含目标附近放置与路径横向偏移两种策略）、Dynamic（沿任务运动采样交叉区域的可移动障碍）。
  • Stem 策略：教师与学生均使用 MLP actor–critic 网络（轻量级）。
  • 训练配置：PPO，轨迹跟随阶段 256 个并行环境、学习率 2×10⁻⁴、8 个更新 epoch、minibatch 3,200；静态与动态阶段分别为 192 环境、1.5×10⁻⁴、12 epoch、minibatch 19,200；rollout 长度 100，折扣因子 γ = 0.8，Adam 优化器。
  • 训练预算（GPU 并行仿真）：各阶段约 38.0M / 23.7M / 20.6M 仿真环境转移（含教师与学生优化）。
Card 06 评估与结果

评估与结果

  • 评估指标：SUCC（无约束违规或碰撞的回合完成比例）与 COLL（发生违规或碰撞的回合比例）；每个任务–场景组合评估 3,200 回合。
  • 对比基线：基座 VLA（π₀、π₀.₅）、VLA-finetune（基于 RRT 避障轨迹微调，最佳配置为 1,500 条示教）、VLSA-EE 与 VLSA-ARM（CBF 安全层基线）。
  • 在六个受约束仿真设置中，VLA-Stem 的平均免碰撞任务成功率为 52.8%，而最强安全基线为 23.7%。
  • 无障碍场景未损害基座性能：PickCube 0.7325、Object Stowing 0.7061、StackCube 0.7521（对应 π₀.₅ 为 0.7166 / 0.6138 / 0.7450）。
  • 在静态与动态约束下，基座 π₀.₅ 在 PickCube 上的 SUCC 降至 0.0325 / 0.0131、COLL 高达 0.8781 / 0.9328，而 VLA-Stem 显著更优；在 StackCube 上，静态与动态的 SUCC 分别为 0.5141 / 0.5419，COLL 为 0.3353 / 0.0784。
  • 消融实验：移除 VLA 参考与引导奖励后，三个场景的 SUCC 均为 0；将轨迹级引导替换为逐步动作对齐后，Object Stowing 的正常场景 SUCC 从 0.7061 降至 0.2888。
  • 参考轨迹干预实验：在 StackCube 上对参考轨迹施加左、右、上三个方向 15–20 cm 的平滑扰动，90 次 rollout 中有 88 次（97.8%）更贴近被修改的参考（归一化距离 0.230，对比原参考 0.894），扰动场景下任务成功率为 60.0%–70.0%。
  • 真实世界实验显示，在静态与动态障碍下碰撞一致减少，Stem 策略无需真实数据训练即可完成仿真到现实的直接迁移。
