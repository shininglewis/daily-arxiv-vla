Card 03 核心贡献

核心贡献

  • C1（频率）：提出按控制维度可学习的平稳小波变换（SWT）动作空间分词，把每个动作维度的轨迹分解为保持长度的多分辨率频带 token，显式提供多尺度频率结构。
  • C2（几何）：提出时间 token 到时间–频率 token 的几何交叉注意力，以可学习权重融合点积（相似性）与楔积模长（对近正交敏感）两种打分。
  • 理论支撑：给出 命题 1（对齐–正交分解与次序分离），证明点积与楔积是单位圆上的两个正交坐标，且存在点积分数无法实现的键排序，楔积通道可直接实现且计算为 O(d_h)。
  • 工程可用性：通过零初始化残差（仅零初始化 W_O，保留 value 路径）使模块在初始化时完全复现基座行为，可安全地"drop-in"到预训练的 π0.5 上联合微调，新增参数仅约 4.23M（约 0.10%）。
  • 实证贡献：在 LIBERO / LIBERO-Plus / RoboTwin 2.0 / AgiBot A2 真机 四个设置上验证，增益在 OOD 条件下显著更大。
Card 04 方法描述

方法描述

  • 整体流程：在 VLA transformer 输出 H 与动作头之间插入 TFGCA，H → H̃，训练与推理的每个去噪步一致；模块与 chunk 的监督方式（flow matching / diffusion / 回归）正交。
  • 4.1 动作空间投影：用 ActionProj 将隐 token 投影到逐维度控制空间 Z^act ∈ R^{T×D}；并加入辅助对齐损失 L_align = \|\|Z^act − sg(a)\|\|²（stop-gradient），总损失为 L = L_FM + λ·L_align。
  • 4.2 逐维度可学习 SWT：每维独立滤波器对，初始化为 Daubechies-2（db2）；分解前做逐维去均值（DC removal）但不做方差归一化（保留接触/静止段的幅度对比信号）；可选有限差分预处理；J 级分解得到 J 个细节带 + 1 个近似带，每带用线性映射把 D 维动作向量联合编码为宽度 d 的 token，堆叠成 F ∈ R^{T(J+1)×d}。
  • 4.3 Dot-Plus-Wedge 交叉注意力：查询为时间 token H，键/值为频率 token F；分别计算 S^dot = s·(qᵀk) 与 S^wed = s·√(\|\|q\|\|²\|\|k\|\|² − (qᵀk)²)；两路各自 softmax 后用可学习标量 β = σ(ℓ)（初始化为 0.5）融合：A = (1−β)softmax(S^dot) + β softmax(S^wed)；输出残差写回 H̃ = H + W_O(A·V)。
  • 4.4 初始化与集成：仅零初始化 W_O，使初始 H̃ = H；保持 value 路径非零以保证初始梯度非零（零初始化 V 会锁死在恒等映射）。
  • 关键创新点：长度保持的 SWT 使频带与原始时间步对齐、可直接作注意力键；楔积以 Cauchy–Schwarz 闭式实现，避免 O(d_h²) 的二次特征提升；用双 softmax 再混合而非预设分数求和，使两通道各自为合法分布。

Card 06 评估与结果

评估与结果

  • 评估环境：四个设置分别覆盖近饱和的分布内性能（LIBERO）、OOD 泛化（LIBERO-Plus、RoboTwin randomized）、真机验证（AgiBot A2）；所有对比均在同源复现的 π0.5 基座、相同数据与训练预算下自测。
  • 主要指标：任务成功率（SR%）；LIBERO-Plus 报告七类扰动各自成功率与 Total；RoboTwin 报告每任务的 clean / randomized 成功率及 6 任务均值（每任务 100 次评估）；AgiBot A2 每任务 20 次、共 60 次试验。
  • LIBERO：TFGCA 四套件均值 98.2%，对比同源基座 96.7%（+1.5），最难 Long 套件从 94.6 提升到 97.0；消融 w/o SWT 97.7、w/o geometry 97.8、w/o alignment 97.1。
  • LIBERO-Plus：Total 从 66.7 提升到 73.0（+6.3），七类扰动中六类优于基座，增益集中在 Noise、Robot、Camera；消融中 w/o geometry 掉幅最大（69.7，−3.3），与分布内"alignment 最重要"的结论相反，支持几何通道在 OOD 下贡献更精确。
  • RoboTwin 2.0：六任务均值 clean 61.3 → 65.0（+3.7），randomized 14.2 → 42.7（+28.5）；randomized 均值比附录 D 中次优方法高约 24 个点；click_bell 与 stack_bowls_three 上基座 randomized 近乎崩溃（≈6%），TFGCA 保持 86% 与 59%。
  • AgiBot A2 真机：三个任务整体成功率提升 +11.67 个百分点。
  • 结论与局限：作者强调增益主要体现在 OOD/扰动条件，模块在初始化时严格等价于基座但不保证微调后一定优于基座；TFGCA 与大规模多任务预训练并不冲突；因果归因（Q/K 路由分析、OOD 消融）、更大规模验证与更强基线对比留作未来工作。
