Card 03 核心贡献

核心贡献

  • 提出 VLA-Gauge 统一评估框架，在同一可执行任务表示下整合能力导向的 ID/OOD 零样本泛化评估、扰动鲁棒性评估，以及诊断驱动的模型优化与再评估闭环。
  • 设计能力可归因的六类任务套件和层次化组合扰动空间，支持从 ID 到 OOD、从单因素到组合扰动的细粒度诊断。
  • 在统一协议下系统评估 12 个 VLA 模型，揭示其能力瓶颈、组合扰动鲁棒性不足，并验证诊断驱动微调能显著提升目标模型性能。
  • 开源 VLA-Gauge 评估套件、训练演示、微调 VLA 模型及自动化生成与评估工具。
Card 04 方法描述

方法描述

  • 使用统一可执行任务表示 T = (ℓ, O, C, E)，分别表示语言指令、场景布局、成功标准和执行条件配置。
  • 提出 V-BDDL（Variant-augmented Behavior Domain Definition Language），通过 :variant 块统一建模基础任务、单因素扰动和组合扰动任务。
  • 构建六类能力套件：视觉感知、语义接地、常识与世界知识、空间推理、动作推理、组合能力，并配对 ID 与 OOD 任务。
  • 构建层次化扰动空间：3 个扰动类别（视觉信息、空间结构、控制执行）、11 个扰动因子、33 个扰动属性、268 个验证参数值，支持静态与动态扰动。
  • 评估协议包括：单因素敏感性分析、组合扰动筛选、组合扰动评估；使用 R-Score 衡量扰动下性能保持程度。
  • 诊断驱动优化流程：根据能力缺口和扰动敏感结果选择困难场景，进行定向数据增强与模型微调，并在 held-out 场景上再评估。
Card 05 数据集与资源

数据集与资源

  • 基准包含 270 个干净基础场景，并组织为六类能力套件。
  • 共生成 6,300 个任务实例，使用 3,089 个候选物体。
  • 训练分布参考 LIBERO 训练分布，用于定义 ID 与 OOD 评估。

Card 06 评估与结果

评估与结果

  • 统一评估协议：模型参数在评估中冻结，每个场景执行 50 次闭环 rollout。
  • 主要指标包括 Zero-Shot Score、ID Score、OOD Score、ALL Score、Success Rate 和 R-Score。
  • 零样本泛化结果：所有模型在 VLA-Gauge 上的平均 Zero-Shot Score 仅为 22.3%，其中 ID 为 32.9%，OOD 仅为 7.2%。
  • SimpleVLA-RL 即便在 LIBERO 上报告 99.1% 成功率，在 VLA-Gauge 上零样本得分仅 8.0%，排名倒数第二。
  • 能力瓶颈：空间推理 最弱，平均分 13.0%；组合能力 在 OOD 上最差，平均仅 2.8%，12 个模型中有 9 个为零分。
  • 组合扰动鲁棒性：三种代表性组合扰动配置下平均 R-Score 为 9.3；36 个模型-配置对中有 34 个不高于 17.7；随扰动类别从 1 类增至 3 类，平均 R-Score 从 16.5 降至 2.9。
  • 诊断驱动微调：对 π0.5 进行定向微调后，在 held-out 场景上零样本泛化提升 72.4 分，选定扰动组合下的鲁棒性提升 31.8 分，超过 Libero-Plus 单因素微调带来的 10.9 分提升，且使用了更少的成功训练轨迹。
