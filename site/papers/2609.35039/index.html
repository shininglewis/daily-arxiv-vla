Card 04 方法描述

方法描述

  • 问题设定：机器人为四足平台搭载 6-DoF 机械臂，在棚架处从有限动作集合中选择（稳定并接近、倾身触及、重定位底盘、后退观察、重构腕部相机、暂停等待、跳过目标、剪切）；剪切不可逆，其余动作以有限恢复代价可逆
  • 视觉编码器：共享编码器从 RGB-D 观测提取特征，采用与 Jetson 级硬件兼容的轻量骨干，同时输出全局特征向量与空间 token
  • 符号分类头：接在全局特征上，输出三分类分布 {接近有益 / 接近有害 / 符号模糊}；仿真中用遮挡物几何得到精确标签，真实数据中用多视角三角化重建果柄位置并按伴生论文判据估计符号，模糊带内使用软标签
  • 符号门控动作生成：双流动作解码器分别生成四足与机械臂动作；门控信号 \(g=p_{\text{helps}}-p_{\text{hurts}}\in[-1,1]\)，以 \(\pi(a\mid s)=\text{softmax}(f_{\text{action}}(s)+g\cdot w_{\text{gate}})\) 调制动作 logits（softmax 前施加偏置）；\(g\) 接近 0 时偏置消失，由动作特征主导
  • 联合损失：\(\mathcal{L}=\mathcal{L}_{\text{action}}+\lambda_{\text{sign}}\mathcal{L}_{\text{sign}}+\lambda_{\text{gate}}\mathcal{L}_{\text{gate}}\)，其中 \(\mathcal{L}_{\text{sign}}\) 为符号分类交叉熵，\(\mathcal{L}_{\text{gate}}\) 促使门控信号与符号预测一致
  • 边界聚焦采样：对每个果串计算临界距离 \(d^{*}=r_{B}L/(r_{B}+r_{L}-\Delta_{L})\)，当相机—果串距离落在 \(d^{*}\) 的 \((1\pm\epsilon)\) 倍范围内时增加额外 rollout，\(\epsilon\) 控制采样带宽度
  • 边缘部署拆分：低频分支（1–2 Hz）运行视觉编码器、符号分类头与意图选择；高频分支（10–30 Hz）用缓存视觉特征运行双流动作解码器；两者共享编码器输出，低频分支更新符号预测与门控信号
