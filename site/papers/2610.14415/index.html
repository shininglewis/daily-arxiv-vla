论文概述

Card 03 核心贡献

核心贡献

  • 提出 Q-DEG，将 VLA 环境红队测试形式化为对可解释环境参数的质量多样性（QD）搜索问题。
  • 设计基于 自模仿（self-imitation） 的微调流程，利用 QD 搜索中缓存的自成功轨迹提升 VLA 鲁棒性。
  • 在 LIBERO 中对三个代表性 VLA 模型进行评估，证明 Q-DEG 在环境多样性、鲁棒性提升和 sim-to-real 迁移上均优于基线。
  • 使用 策略嵌入（policy embeddings） 作为多样性度量，无需动作对数概率，兼容自回归与流匹配（flow-matching）两类 VLA。
Card 04 方法描述

方法描述

  • 环境生成：扰动物体位置（xy）、相机位姿（xyz+轴角）、光源位置、桌面背景 RGB、镜面反射 RGB，构成 25 维连续搜索空间。
  • MIQP 修复：使用混合整数二次规划在最小化编辑距离的同时保持任务语义（如“碗挨着盘子”的空间关系）。
  • 反馈指标：以可行性感知失败率（若全部失败则置 0）作为质量度量；以 VLA 动作层前的激活经均值池化作为策略嵌入衡量多样性。
  • QD 优化：采用 CMA-ES 结合 CMA-MAE，通过阈值学习率 α 提供稠密反馈；停滞时从存档中采样高失败环境作为“垫脚石”重启。
  • PCA 降维：将高维策略嵌入投影到前 M=2 个主成分张成的低维子空间，离散为 100×100 网格存档。
  • 自模仿微调：仅对满足 0 < 失败率 < 1 的环境保留最短成功轨迹，加入 10% 原始数据缓解遗忘，使用标准行为克隆微调。
Card 05 数据集与资源

数据集与资源

  • LIBERO-Spatial：包含 10 个语言条件抓取-放置任务，作为主要基准。
  • 评估模型：π0-FAST（自回归）、OpenVLA-OFT（自回归）、π0.5（流匹配），以及真实世界中的 pi05_base 检查点。
  • 真实世界平台：Kinova JACO Gen2 机械臂。
  • DINOv2（dinov2_vitb14）用于计算环境图像语义多样性。
  • 微调使用 rank-16 LoRA、batch size 32、训练 10,000 步；红队预算模拟为 3,200 次 rollout，真实世界为 832 次。
  • 每个环境执行 k=4 次 rollout，CMA-ES 批大小 B=8，阈值学习率 α=0.1。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-Spatial 默认任务与各方法生成的对抗性环境（含随机化、CMA-ES 基线），并进行真实世界迁移测试。
  • 主要指标：可行对抗环境数量、平均成对 DINOv2 嵌入距离、默认与对抗环境上的成功率。
  • 红队测试结果：Q-DEG 在环境多样性上持续优于基线；在强模型 π0.5 上甚至比失败最大化基线 CMA-ES 找到更多可行对抗环境。
  • 鲁棒性结果：在三个 VLA 模型上，Q-DEG 微调后对抗环境成功率提升最高达 43.78%（如 π0.5 平均成功率 80.88%，优于 base 的 67.20%）。
  • Sim-to-real 结果：Q-DEG 微调的 VLA 在真实任务中抓取位置更集中于目标碗，而基线方法常聚集在错误固定位置，说明 Q-DEG 缓解了过拟合并改善迁移。
  • 附录补充：均匀采样（uniform）基线生成的环境多为 OOD 导致几乎无可行对抗样本，鲁棒性提升有限。
