Card 02 论文概述

论文概述

  • 提出 GALA（Geometry-Aware Latent Action modeling），一种在多具身数据上预训练 视觉-语言-动作（VLA） 模型的几何感知隐动作建模框架。
  • 针对的问题：不同末端执行器（人手、灵巧手、平行夹爪）动作空间异构，难以共享监督；而现有基于图像的 隐动作模型（LAM） 主要捕捉场景级位移，只能刻画末端执行器"移到哪里"，难以刻画"如何操作"，尤其缺失手指级细粒度几何变化。
  • 研究目标：在无需统一动作空间与点/关节对应关系的前提下，学习跨具身可共享的细粒度动作表征，并将视觉隐动作与几何隐动作联合作为 VLA 预训练监督信号。
Card 03 核心贡献

核心贡献

  • 提出 GALA 框架，在图像隐动作之外引入 3D 末端执行器几何运动，为跨具身 VLA 预训练提供"场景级 + 关节级"互补监督。
  • 提出 UEMR（Unified End-effector Motion Representation），在保留细粒度运动信息的同时提升隐动作的跨具身泛化性，无需点、关节或运动学对应。
  • 设计三项 UEMR 关键机制：统一双臂运动隐变量、成对一致的几何增强、双向时序转换学习。
  • 在细粒度运动探针、跨具身隐动作检索、RoboCasa 仿真与真实机器人任务上系统验证有效性，取得 68.3% RoboCasa-GR1 成功率与 75.5% 真实世界平均成功率。
  • 支持从无动作标签的自我中心人类视频与多机器人数据中联合学习，保留各具身原生可执行动作空间。
Card 04 方法描述

方法描述

  • 两阶段框架：几何感知隐动作学习（Stage 1）+ 几何感知 VLA 协同训练（Stage 2）。
  • 点云生成：人手用 WiLoR 估计左右 MANO 网格并采样；机器人具身由 URDF/MJCF 模型结合前向运动学采样，统一为腕部/根部为中心的局部坐标系点云，N = 1024 点。
  • 视觉与几何动作编码：冻结的 DINOv2 与 SigLIP 编码 RGB，冻结的 Point Transformer V3 (PTv3) 编码手部点云，经共享时空 Transformer 与语言条件融合。
  • 离散化：几何 token 经共享 EMA-VQ 码本量化，编码器、码本、解码器在人手、灵巧手与夹爪间共享；解码器以初始手部几何为条件，用 Chamfer Distance (CD) 监督目标点云重建。
  • UEMR 三项设计：双臂共享同一组隐 token（单臂数据左右分支复用同一点云）；对起止点云对施加相同的随机 3D 相似变换 A(P)=aRP+t 以消除数据集坐标偏差；前向（start→goal）与后向（goal→start）双向训练共享编码器/码本/解码器。
  • VLA 协同训练：基于 GR00T 架构，向 VLM 输入加入两组可学习 bridge token，自回归预测视觉与几何隐动作码（交叉熵损失）；动作专家由共享 DiT 加各具身专属动作头组成，采用 flow matching 目标，保留原生动作维度与控制语义。

Card 06 评估与结果

评估与结果

  • 评估分为三个问题：细粒度运动建模能力（探针）、跨具身语义共享性（检索）、下游 VLA 与具身规模化收益（仿真与真机）。
  • 细粒度运动探针（冻结隐动作编码器 + 轻量 MLP，预测平移 Δp、旋转 ΔR、手指关节 Δq）：GALA 在 Pos. 5.359 / Rot. 7.898 / Finger 7.585 三项误差上均最优，优于 METIS、Native Kinematics、OPFA 与 GALA w/o PC。
  • 跨具身隐动作检索（grasp/hold/release 三类，跨具身检索，宏平均 R@1/P@5/mAP）：人类-机器人赛道 R@1 45.67、P@5 44.57、mAP 49.49；纯机器人赛道 R@1 46.91、P@5 41.74、mAP 46.95，均优于全部基线。
  • RoboCasa-GR1 受控实验（仅 GR-1 数据，24 个任务）：GALA 成功率 55.7%，高于 Native Kinematics（51.8%）、OPFA（53.5%）与 GALA w/o UEMR（54.4%）。
  • 多具身联合预训练（Fourier hand + XHand + 人手 + Robotiq）：GALA 达 68.3% 成功率，超过 UniT（66.8%）、JoyAI-RA（63.2%）与 UniVLA（53.6%），相比仅 GR-1 训练提升 +12.6%。
  • 真实世界实验（12-DoF XHand，四个任务 Pick / Push / Press / Flip，每任务 50 次试验）：GALA 平均成功率 75.5%，比 HARP-VLA 高 4.0 个百分点、比 π0.5 高 7.5 个百分点；去除 UEMR 后平均下降 7.0 个百分点。
