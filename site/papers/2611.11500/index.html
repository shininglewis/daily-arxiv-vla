Card 03 核心贡献

核心贡献

  • 提出 ForeAct，将预训练视频世界模型复用为单次前向的表征骨干，直接处理当前观测的干净潜变量（$t_{\text{diff}}=0$），无需合成未来帧或迭代视频去噪即可提取动作特征。
  • 设计紧凑的可学习几何 token 接口：几何 token 与视觉 token 通过双向自注意力交互，并接受下一帧相对深度监督，从而把骨干中已有的空间知识塑造成“未来感知”的动作表征。
  • 几何读出模块仅在训练时使用，部署时移除，因此推理阶段既不需要深度输入，也不需要外部几何编码器，参数开销极小。
  • 在 LIBERO、SimplerEnv-Bridge 及 6 个真实世界任务上验证有效性，且不需要额外大规模机器人动作预训练。
  • 通过受控消融实验验证了“干净世界表征”“专用几何 token 接口”“双向注意力”和“下一帧深度监督”各自的必要性。
Card 04 方法描述

方法描述

  • 问题形式化：输入当前 RGB 观测 $\mathbf{I}_t$ 与语言指令 $c$，预测长度为 $H$ 的动作块 $\hat{\mathbf{a}}_{t:t+H-1}$，训练时联合预测下一帧归一化相对深度 $\hat{\mathbf{d}}_{t+1}$；该形式为无本体状态（state-free），便于跨形态部署。
  • 共享潜在世界表征：冻结视频 VAE 将观测编码为干净潜变量 $\mathbf{z}_t$，冻结文本编码器（T5）编码指令；patch embedding 后的视觉 token 与可学习几何 token $\mathbf{Q}^0$ 拼接，在 $t_{\text{diff}}=0$ 处经预训练世界骨干单次前向，输出视觉 token $\mathbf{V}_t$ 与几何 token $\mathbf{Q}_t$。
  • 动作专家：视觉 token 送入基于条件流匹配的 Action DiT 回归传输速度，生成动作块；动作专家为 16 层 DiT-B，隐藏维度 1024。
  • 未来几何学习：几何 token 投影并拼接为全局几何编码 $\mathbf{g}_t$，与 2D 坐标编码 $\gamma(u,v)$ 经坐标条件映射器 $\phi_{\text{geo}}$ 生成空间几何特征；再以零初始化的 $1\times1$ 残差路径注入当前帧 VAE 潜变量特征，解码出下一帧深度潜变量。
  • 监督方式：深度目标由 MoGe-3 离线生成，经冻结 VAE 编码到潜空间；损失在潜空间、解码像素空间、空间梯度空间三处监督，总损失为 $\mathcal{L}=\mathcal{L}_{\text{act}}+\lambda_{\text{geo}}(\lambda_{\text{lat}}\mathcal{L}_{\text{lat}}+\lambda_{\text{pix}}\mathcal{L}_{\text{pix}}+\lambda_{\text{grad}}\mathcal{L}_{\text{grad}})$，其中 $\lambda_{\text{geo}}=0.01$、$\lambda_{\text{lat}}=1$、$\lambda_{\text{pix}}=0.1$、$\lambda_{\text{grad}}=0.05$。
  • 关键设计：深度监督对共享 Cosmos 骨干的梯度被缩放为 0.01；几何 token 在部署时保留在共享骨干内，仅移除几何解码器；使用无掩码双向自注意力使深度监督能回流塑造动作特征。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（含 Spatial、Object、Goal、Long 四个套件，每套件 500 条演示、10 个任务）与 SimplerEnv-Bridge（WidowX 机器人，BridgeData V2 演示）。
  • 真实世界：Franka Emika Panda 机械臂 + 固定 Intel RealSense D435i RGB 相机，6 个桌面操作任务（Green-on-Yellow、Stack Bowls、Sandbag-to-Scale、Banana-to-Basket、Press-Bells-in-Order、Cup-in-Drawer），每任务 15 次试验。
  • 模型基础：初始化自 Cosmos-Predict2-2B Video2World，模型规模约 2.1B 参数；冻结 T5 文本编码器与视频 VAE；插入 8 个可学习全局几何 token。
  • 训练资源：LIBERO 训练 100K 步，4 块 GPU，全局 batch size 48；SimplerEnv-Bridge 训练 50K 步，8 块 GPU，全局 batch size 96；骨干学习率 $1\times10^{-5}$，动作专家与几何读出 $1\times10^{-4}$；动作视野 LIBERO 为 8、SimplerEnv 为 16。
  • 延迟评测：单张 NVIDIA H20 GPU，batch size 1。
Card 06 评估与结果

评估与结果

  • 评测设置：LIBERO 与 SimplerEnv-Bridge 各重复 3 次取平均成功率（固定种子分别为 42 和 7）；真实世界每方法 90 次 rollout；延迟覆盖从观测编码到动作块生成的全过程。
  • LIBERO：平均成功率 96.6%（Spatial 98.4%、Object 98.8%、Goal 97.2%、Long 91.8%），取得最佳 Spatial 分数，优于无额外机器人预训练的 WorldVLA（+14.8%）与 FlowVLA（+8.5%），并超过几何感知的 DepthVLA（+1.7%）。
  • SimplerEnv-Bridge：平均成功率 63.5% 排名第一，超过 GR00T N1.5 1.6 个百分点；Spoon on Towel 87.5%、Eggplant in Basket 100.0%（并列最佳），Stack Blocks 仅 12.5%，反映多物体顺序对齐的难度。
  • 真实世界：90 次试验中成功 67 次（74.4%），优于 FastWAM（58 次，64.4%）与 $\pi_0$（52 次，57.8%），在 6 个任务中的 5 个取得最佳结果。
  • 效率：约 168 ms 延迟、2.1B 参数下达到 96.6% 成功率；同等成功率下延迟约为 Cosmos Policy 的 1/3，且比 Fast-WAM 更快、模型更小。
  • 消融：扩散 WAM 93.2% → 仅动作（干净表征）94.3% → 加几何 token 无监督 94.7% → 完整 ForeAct 96.6%；直接对视觉特征做深度监督仅 93.4%，单向视觉→几何注意力 94.9%；几何 token 数 1/8/32/64 分别为 94.3%/96.6%/95.2%/94.7%；下一帧监督 96.6% 优于当前帧 95.2%，监督视野延至 $t+4$、$t+8$ 降至 95.5%、94.9%。
