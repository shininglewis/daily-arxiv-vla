Card 02 论文概述

论文概述

  • 论文提出 SLA（Spatial-Language-Action Model），通过持续预训练（continual pre-training）把隐式空间对齐扩展为基础模型能力，并在下游后训练中继续保持这一能力。

Card 03 核心贡献

核心贡献

  • 提出 SLA 机器人基础模型，在不改变原始 VLA 架构与动作生成头的前提下，迫使 VLA 的中间视觉嵌入与外部 3D 感知基础模型的空间表征对齐。
  • 将空间对齐从后训练扩展到大规模持续预训练，在精心整理并统一的公开机器人数据语料上构建具有空间感知能力的基础模型。
  • 设计自适应层选择（Adaptive Layer Selection）机制，用与特征相关的门控聚合 VLA 多层视觉嵌入，以适应异构数据中不同层对不同域的适用性差异。
  • 引入概率状态丢弃（State Dropout），缓解对示范轨迹的过拟合，促使策略更多依赖视觉线索。
  • 在多个仿真与真实基准上取得 SOTA，并验证双臂协调、空间与动态泛化、少样本跨本体迁移、指令跟随等真实部署能力。
Card 04 方法描述

方法描述

  • 主干：从预训练的 π0.5 策略初始化，联合优化动作预测损失与空间对齐损失，总目标为 L = L_action + α·L_align。
  • 外部空间监督：采用冻结的 OmniVGGT（基于 VGGT，含 GeoAdapter 相机/深度分支与随机多模态融合）从多视角 RGB 及可用的相机内外参、深度图中提取像素级 3D 表征，经位置嵌入与双线性重采样对齐到 VLA 视觉 token 分辨率。
  • 对齐损失：先经 LayerNorm + 两层 MLP 投影，再用余弦相似度最大化 VLA 视觉 token 与 3D 空间目标的一致性。
  • 自适应层选择：受 Gated Attention 启发，为每层每个视觉 token 学习特征相关门控（sigmoid），跨层加权求和得到统一空间表征，实现多层同时监督。
  • 状态丢弃：训练时对每个样本独立随机丢弃整段状态 token，防止策略把状态当作轨迹捷径。
  • 推理零开销：3D 教师模型、对齐投影器与层选择门控仅在训练时使用，部署时完全丢弃，无需深度图或相机标定输入。
Card 05 数据集与资源

数据集与资源

  • 预训练语料：6 个公开数据集，合计约 171.4 万条 episode、14,330 小时、1,504 个任务，包括 InternData-A1（630K）、AgiBotWorld-Beta（168K）、RoboCasa365-Pretrain（630K）、RoboCOIN（183K）、DROID（95K）、MolmoAct（7.9K）。
  • 数据统一处理：统一用末端执行器（EEF）位姿表示状态与动作，坐标系原点与轴向统一；旋转用旋转向量表示并通过 SO(3) 复合计算相对旋转，避免欧拉角的角度回绕离群值；并进行任务内 episode 降采样与过滤（仅保留两指夹爪、无移动底盘、去除空闲帧）。
  • 下游基准：LIBERO-Plus、RoboTwin 2.0、RoboCasa-Panda、RoboDojo-Real，以及 8 个私有真实部署条件（双臂 Piper 与单臂 Franka 平台，RealSense D435 相机）。
  • 训练资源：持续预训练 36k 步，有效全局批大小 4,608，学习率 5×10⁻⁵ 余弦衰减至 1×10⁻⁵，约 110 小时 / 48 张 NVIDIA H100 GPU。
Card 06 评估与结果

评估与结果

  • LIBERO-Plus：加权平均成功率 87.4%，较 π0.5 提升 3.0 个百分点、较 Spatial Forcing 提升 2.3 个百分点；七个扰动维度全面提升（噪声 89.0%→95.4%，背景 94.1%→98.0%，光照 98.8% 为最优）。
  • RoboTwin 2.0：Clean2Clean 86.0%、Clean2Random 72.3%、平均 79.2%，Clean2Random 与平均分别超 π0.5 26.3 和 20.9 个百分点，平均超 Spatial Forcing 10.5 个百分点。
  • RoboCasa-Panda：每任务仅用 50 条示范即达 68.4% 平均成功率，为对比方法最优，超过 Cosmos Policy（1.3 点）与 Spatial Forcing（0.8 点），优于使用 300–3,000 条示范的多种策略。
  • RoboDojo-Real：单一策略跨三种本体平均 33.9%，显著高于 π0.5 的 12.8%。
  • 真实部署：8 个部署条件下均为最优，平均 83.8%，较 π0.5 提升 24.0 个百分点。
  • 消融分析：数据规模趋势实验显示，在预训练与后训练两阶段都施加空间对齐，在所有测试数据比例下均优于仅单阶段对齐；并验证了自适应层选择、状态丢弃、旋转表示与相机标定的作用。
