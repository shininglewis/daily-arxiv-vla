Card 02 论文概述

论文概述

  • 针对视觉-语言-动作（VLA）策略的失败监测器（failure monitor）通常在离线训练后冻结部署，但部署后光照、物体、相机、磨损以及策略版本/任务都会漂移，导致监测器的失败排序能力（ranking）退化到接近随机水平
  • 论文提出 Streaming Failure Forecasting（SFF）：在部署期间持续学习，仅利用每个 episode 天然提供的唯一监督信号——是否成功——来更新监测器
  • 核心问题：阈值重校准无法修复排序能力（排序与阈值无关），那么在不知道何时、如何发生漂移的前提下，能否只用一个二值结果标签维持监测器可用性
Card 03 核心贡献

核心贡献

  • 提出 SFF 框架：冻结离线监测器网络，仅对最后的线性读出层（readout）做闭式重拟合，每 episode 更新一次，状态恒定 1.0 MB、不存储历史 episode
  • 设计仅成功时更新的自适应阈值规则（基于 adaptive conformal inference），为任意有界分数提供长期误报率（FAR）界，即使读出层仍在学习
  • 在 5 个仿真测试套件中，SFF 在 4/5 上排序优于冻结监测器（含预先指定的主测试 LIBERO-10，p=0.026），并在全部套件上优于「检测到漂移即重置」的基线
  • 将锁定超参迁移到 ArmnetBench 真实 SO-101 机械臂上 4 个 VLA 的 434 条录制轨迹，在每个 VLA 上都优于冻结监测器（合并 AUROC 提升 +0.121），并（探索性）优于在真实切换点做完全重置
  • 论证「只适应读出层」优于整网络在线学习（SFF-TD 隐藏层权重仅移动 0.2–2.8%），且成本极低：2.18 ms/次策略调用（占调用间隔 0.44%）
Card 04 方法描述

方法描述

  • 固定特征：用两层隐藏网络在标称 warm-up episodes 上离线训练失败预测，输入为 VLA 内部激活投影到 128 维 + 任务进度 t_c/T，得到 z_c ∈ ℝ¹³⁰，之后权重冻结
  • 在线读出层：s_c = θ^T z_c；每 episode 后用指数遗忘的递归最小二乘闭式求解 θ_e = (A_e + (a+δ)I)⁻¹(b_e + a θ̄)，只需一次 130×130 求解
  • 关键设计：1/n_k 让每个 episode 等权重（失败 episode 更长）；锚定项 a 是以离线头 θ̄ 为中心的高斯先验（L2-SP），使初始排序等同离线监测器；折扣 ρ≤1 让旧条件淡出；附加坐标 t_c/T 让读出层学到离线头缺失的时间权重
  • 成功-only 阈值：τ ← τ + η(1[M_e>τ] − α)，仅在成功 episode 后更新，初始为 warm-up 成功峰值的 conformal 分位数，α=0.1，η=0.05
  • 强调排序（ranking）与校准（calibration）是两个目标，需两套机制
Card 05 数据集与资源

数据集与资源

  • 仿真：LIBERO（Spatial、Goal、10）、LIBERO-Plus，策略为 SmolVLA（另含作者自行微调的 SmolVLA）
  • 真机：ArmnetBench v0.1（LeRobot，单臂 SO-101）录制的真实轨迹，涵盖 4 个 VLA：SmolVLA、π₀.₅、π₀、MolmoAct 2，共 434 条 run、40 次切换
  • 流式设置：200 个标称 warm-up episode（140 训练网络、60 设初阈值），之后 60-episode 的漂移块；每套件 3 种条件顺序 × 5 次抽样 × 3 个网络种子
  • 部署硬件：Jetson Orin Nano 单 CPU 核；状态仅 1.0 MB（对比全量重训增长到 5.5 MB、单次重拟合最长 13.8 s）
Card 06 评估与结果

评估与结果

  • 评估指标：within-task AUROC（同任务内失败 episode 峰值分数高于成功 episode 的概率，0.5 为随机）、FAR（成功 episode 上的误报率，目标 α=0.1）、提前报警比例、单次调用延迟
  • 仿真结果：LIBERO-10（主测试）+0.030 [−0.0004, +0.063]、p=0.026；LIBERO-Goal +0.050；LIBERO-Plus +0.021；Spatial 新种子 +0.033；自训练策略 −0.008（无显著差异）；对 detect-and-reset 全部领先 +0.024～+0.082（Holm p ≤ 0.022）
  • 真机结果：SmolVLA +0.163、π₀.₅ +0.064、π₀ +0.106、MolmoAct 2 +0.150，四者合并 +0.121 [+0.077, +0.162]；收益随结果累积（切换后 1–10 run 持平，21–30 run 领先）；优于「真实切换点全重置」与「每 20 run 重训」
  • 校准与效率：各套件 FAR 0.082–0.089（SAFE 固定带为 0.082–0.232），但复合漂移下降至 0.19–0.37；LIBERO-10 上 48% 的失败在最短成功前报警（冻结监测器 39%），早期误报 7.3% vs 9.0%
  • 局限性：仿真仅一个策略家族、3/5 测试套件复用 Spatial 任务、增益较小（0.02–0.05）；真机仅回放而非在线实跑；无漂移时学习略有代价（首任务排序低于冻结监测器）；真机仅 5 条校准 run，未报告真实 FAR
