Card 02 论文概述

论文概述

  • 研究长时程人形机器人导航：机器人需依据一段长指令推断出多个有序目的地，并在连续行走中保持稳定、自然的全身运动。
  • 指出两个核心难题：一是任务分解本身不足以保证执行过程中的进度一致性（目标切换必须反映真实执行进度）；二是路径约束（航点、轨迹、速度指令）无法直接保证全身执行时的无碰撞与自然性。
  • 提出 LHNav：一个异步多速率三层系统（Brain / Cerebellum / Brainstem），配合物理落地的数据引擎，将单目标导航策略扩展为长时程多目标导航。
Card 03 核心贡献

核心贡献

  • 提出异步多速率系统，整合任务推理、运动 token 预测与全身执行，并用进度感知与到达反馈的状态转移把单目标策略扩展到长时程人形导航。
  • 设计可扩展的物理落地数据引擎：借助特权编码器（P-SONIC）与冻结 SONIC 解码器提升对全局运动参考的跟踪精度，在 Gaussian–Mesh 场景中生成与真实执行对齐的导航示教数据。
  • 提出几何监督的联合预测：VLA 共享 DiT 同时预测运动 token 与辅助航点，并用基于 SDF 的软惩罚约束航点可通行性。
  • 实验验证在未见仿真场景中更高成功率、更平滑运动、更少碰撞与跌倒、更快长时程完成，并在 Unitree G1 上实现真机单目标导航与零样本长时程导航。
Card 04 方法描述

方法描述

  • Brain（脑）：带工具的语言规划智能体（可用 GPT-6 或 Qwen3.8-27B），维护“已完成 / 进行中 / 待完成”显式计划；Tool 1 为任务管理（可删除不再需要的待访问目标），Tool 2 为到达验证（独立 Qwen VLM，最高 1 Hz 判断是否抵达）。
  • Cerebellum（小脑）：基于 GR00T N1.7 微调框架的人形 VLA，保留视觉–语言骨干与 flow-matching 动作头，约 8 Hz、4 步去噪预测运动 token（ℝ^{40×64}）与辅助航点（ℝ^{40×5}，含平面位置、朝向 sin/cos、到达指示）。
  • Brainstem（脑干）：冻结的 SONIC 解码器结合本体感知，以 50 Hz 将运动 token 解码为关节目标，交由 PD 控制；新返回的 chunk 跳过已执行前缀、无混合地替换未执行尾部。
  • 几何监督：从 BgMesh + FgMesh 当前配置预计算 xy 平面 SDF（可通行区内为正），对去噪后航点做双线性查询，取最小净空 c_min 并以 softplus 形式惩罚，总损失为联合 flow-matching 损失加 λ_sdf 加权 SDF 项。
  • 数据引擎：首先在 InteriorGS 高斯背景上人工标注 BgMesh，并叠加可移动前景网格 FgMesh；随后标注目标包围盒与朝向，采样起点后用 2D A* 规划并在净空、平滑性、长度上精修路径；再用 ARDY 以 50 Hz 合成全身参考动作，由 P-SONIC 在 MuJoCo 中跟踪；最后回放记录的机器人状态，渲染第一人称观测（高斯与网格按深度合成）。
  • P-SONIC：在原 SONIC 编码器输入中拼接 10 个未来参考骨盆位置的机体系位移与 10 个近期机体系线速度，在 IsaacLab 中用 PPO 训练 40K 迭代、262K 并行环境，冻结 FSQ 量化器与解码器，消除长路径上的全局漂移。
Card 05 数据集与资源

数据集与资源

  • 场景数据：从 InteriorGS 选取 100 个训练场景与 20 个留出测试场景（工具链共覆盖 120 个场景）。
  • 示教规模：数据引擎生成 185,401 条单目标训练示教；单目标评测在留出场景上进行 522 个回合；184,990 条共享路线上做跟踪对比。
  • 长时程设置：使用训练集中的 20 个场景，14,410 条单目标示教训练策略，45 个需至少 3 个有序目标访问的评测任务。
  • 训练资源：所有导航策略训练 100K steps、全局 batch size 64，使用 8 张 NVIDIA H20 GPU。
  • 真机平台：Unitree G1 人形机器人 + 头部 3D 打印支架固定的前向 Orbbec Gemini335L 相机（第一人称 RGB）。
  • 基线：OmniNav、DualVLN（均从其公开 checkpoint 微调）；全身控制统一使用 SONIC。
Card 06 评估与结果

评估与结果

  • 评估环境：Isaac/仿真留出场景 + 真机家居环境；指标包括 SR₀.₅ / SR₁.₅（0.5/1.5 m 内成功且未跌倒）、NE（终点平面误差）、CR（根轨迹落在可通行区外的比例）、Jp（29 关节位置三阶差分 jerk）、Falls、长时程 Task SR₁.₅ / Progress / OSR / Time。
  • 单目标仿真（522 回合 / 20 留出场景）：LHNav 取得 SR₀.₅ 52.3%、SR₁.₅ 75.7%、NE 1.7 m、CR 8.6%、Jp 75.6、跌倒 0 次；对比 OmniNav（36.0 / 69.0 / 1.8 / 19.5 / 109.1 / 7）与 DualVLN（18.6 / 48.7 / 2.9 / 25.8 / 128.3 / 91）。
  • 长时程仿真（45 任务）：完整系统 Task SR₁.₅ 75.56%、Progress 82.2%、OSR 91.1%、NE 1.7 m、平均耗时 82.1 s（同步变体 73.3% 但耗时 97.8 s）；去掉任务管理后成功率降至 0%，去掉到达验证后降至 55.6%；Codex 版本从 55.6%（Native）→ 64.4%（+Harness）→ 71.1%（+Harness+tools）。
  • 真机（Unitree G1，每条件 5 次）：5 个家居单目标 100% 成功；3 个重排布局目标 93.3%–100%；三目的地“阅读笔记”零样本长时程任务 4/5（80%）；联合真机遥操作操作数据后还可完成“导航到桌边 + 推玩具狗”。
  • 消融：P-SONIC 将终点水平误差均值从 48.65 cm 降至 1.76 cm（降低 96.4%）；航点-only 26.4% → 运动 token 47.9% → 联合预测 52.3%；几何监督使 SR₀.₅ 提升 4.98 个百分点、CR 从 14.4% 降至 8.6%；Cerebellum 更新率约 8 Hz 时 CR 最低且无跌倒，较慢更新则 jerk 更低。
