Be My Eye: Learning to See Beyond a Robot's Own Perspective

2026-11-09 · 原文 · 翻译 · 2611.12295

论文聚焦多机器人协作中的部分可观测性问题：单台机器人受视角、传感器布局和遮挡限制，其观测往往不足以完成协作任务。 提出任务导向的主动上下文共享（active context sharing）框架，将机器人观测压缩为紧凑的上下文表示并与伙伴机器人交换，而非直接传输原始图像或通用视觉特征。 核心目标是让共享的信息按任务目标与执行进度选择性编码，在有限通信预算下直接服务于协作决策与动作生成。

Card 03 核心贡献

核心贡献

  • 提出面向多机器人协作的两阶段主动上下文共享框架：将本地观测编码为任务条件化的紧凑潜表示，接入伙伴的 VLA 策略，并通过下游动作监督联合优化。
  • 设计进度感知、任务条件化的观测压缩模块：基于可学习 query 支持多相机联合/分相机编码，并用任务导向未来预测 + 软任务进度对应学习约束表示空间。
  • 提出联合上下文优化机制：通过灵活的条件接口把压缩上下文注入预训练 VLA 策略，支持可变 token 预算与双向共享，接收端动作监督可回传优化发送端编码器。
  • 在真实双机器人操作任务上系统评估，与无共享、通用视觉特征共享等基线对比，并完成通信预算分析与组件消融。
Card 04 方法描述

方法描述

  • Stage 1：与协作模式无关的上下文压缩。冻结视觉/语言编码器提取特征，用 K 个可学习 query 聚合多相机特征与任务指令，输出 K×d_z 的上下文 token；支持联合编码与按相机分配 query（K=ΣK_c）。
  • 任务导向未来预测：用冻结视觉编码器对 t+Δ 帧特征作自监督目标，借助预训练视觉-语言模型的 patch–指令相似度生成有界权重，加权回归未来视觉特征，使表示保留任务相关状态转移信息。
  • 软任务进度对应学习：对同一观测做两次增强视为正对，以「任务身份 + 执行进度相似核」构造软亲和矩阵并行归一化，混合单位阵得到软目标，做双向 soft-label 对比学习，促进跨视角一致性、任务间可分性与任务内时序连续性。
  • Stage 2：联合上下文优化与协作策略学习：投影模块 P_ρ 将上下文 token 映射到预训练 VLA 策略（π0.5）的隐空间，作为多模态前缀与本地观测、指令、本体状态共同条件化动作生成；损失为接收端动作损失 + η 倍发送端 Stage 1 辅助损失。
  • 对称双向共享：两个方向共享编码器、投影与策略参数，无预定义 leader/follower 角色，可同时编码、交换与使用上下文；推理时省略预测解码器与对比投影头。

Card 06 评估与结果

评估与结果

  • 评估环境：两台 Astribot S1 真实机器人，两个受控协作任务——遮挡目标选择（每设置 18 次试验）、交替 leader–follower 标记抓取（48 次试验，覆盖 6 种颜色顺序 × 双向初始 leader）。
  • 主要指标：目标选择准确率；双向颜色匹配准确率、正确触发率、两阶段序列成功率；归一化过程分数（Process Score）；通信字节数/token 预算。
  • 遮挡目标选择：Ours-Joint 88.9%，显著优于 Generic SigLIP 72.2%（160 token）与 No Sharing 38.9%，token 预算降低约 80%。
  • 交替 leader–follower 检索：Ours-Joint 与 Generic SigLIP 均在四项指标上达 100%，而 No Sharing 序列成功率为 0%（触发率仅 25%）。
  • Stage 1 目标消融：完整 100%，去掉预测 96.7%，去掉对比学习降至 68.9%，说明进度对比学习更关键。
  • 冻结 vs 联合优化：Ours-Frozen 83.3% → Ours-Joint 100%（+16.7 个百分点）。
  • token 预算：K=4 → 90.5%（18 KiB）、K=16 → 97.6%（72 KiB）、K=32 → 100%（144 KiB），对比 SigLIP 160 token、720 KiB。
  • 定性分析：冰箱补货、盒子组装、叠毯打包三类真实任务验证泛化性；VLA 第 7 层注意力图显示两机器人关注互补区域并随任务阶段变化。
