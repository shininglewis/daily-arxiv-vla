Relational Geometry Forcing for World Action Models

2026-10-21 · 原文 · 翻译 · 2610.29282

论文关注 World Action Models（WAMs），这类模型联合学习视觉动态预测与可执行动作生成，但视频与动作目标中并未显式约束对精细操作至关重要的 3D 几何。 现有做法一是增加深度或 4D 预测分支，二是用预训练 3D 基础模型对 WAM 中间特征做 pointwise（逐点）表征对齐；作者发现逐点对齐对视频特征有益，却会损害动作学习。 论文提出 Relational Geometry Forcing（RGF），通过对齐“成对特征关系”而非逐点特征来迁移几何先验，在无显式几何重建、无额外推理模块的前提下提升操作性能。

Card 02 论文概述

论文概述

  • 论文关注 World Action Models（WAMs），这类模型联合学习视觉动态预测与可执行动作生成，但视频与动作目标中并未显式约束对精细操作至关重要的 3D 几何。
  • 现有做法一是增加深度或 4D 预测分支，二是用预训练 3D 基础模型对 WAM 中间特征做 pointwise（逐点）表征对齐；作者发现逐点对齐对视频特征有益，却会损害动作学习。
  • 论文提出 Relational Geometry Forcing（RGF），通过对齐“成对特征关系”而非逐点特征来迁移几何先验，在无显式几何重建、无额外推理模块的前提下提升操作性能。
Card 03 核心贡献

核心贡献

  • 揭示并解释了逐点对齐中的表征失配问题：稠密几何目标与紧凑动作特征所编码的内容角色不同，将逐点对齐扩展到动作专家会使成功率低于未对齐基线。
  • 提出 RGF，通过 intra-frame（帧内）、cross-view（跨视角）、action-temporal（动作-时序） 三类关系目标，将场景几何、多视角对应关系与几何场景演化迁移到 WAM 表示中。
  • RGF 仅在训练阶段使用，推理时完全移除教师模型与投影头，不改变原推理路径，也不需要深度/4D 预测分支。
  • 在 LIBERO、RoboTwin 2.0 与真实 Franka 机器人上验证有效性，并在三种 WAM 范式（Uncond / Joint / IDM）上取得一致增益。
  • 真实场景中展现出对未见物体、背景干扰物与高度变化的泛化能力。
Card 04 方法描述

方法描述

  • 几何教师：使用冻结的 VGGT（Visual Geometry Grounded Transformer），对每个时刻的同步多视角图像联合编码，得到逐视角 patch 特征；动作监督则对每视角特征做空间池化并拼接成场景向量。
  • 关系算子：对 token 集合做行级 L2 归一化后计算余弦相似度矩阵，定义自关系 R(X)=X̄X̄ᵀ 与跨关系 R(X,Y)=X̄Ȳᵀ；关系矩阵形状与特征维度无关，从而绕开维度/嵌入空间不一致的问题。
  • 损失函数：在有效项集合 Ω（排除对角线、padding token）上使用 Huber（smooth L1） 逐元素损失；相比 KL 散度，Huber 保留关系幅值。
  • 三类关系目标：

- 帧内目标：对齐每个视角内部的 patch 关系（几何重采样后对齐分辨率）。

- 跨视角目标：对所有视角对 v 匹配跨视角相似度矩阵，传递多视角对应关系。

- 动作-时序目标：将动作 token 的时序相似度结构与多视角场景演化的时序相似度结构对齐，而非直接回归场景向量。

  • 投影头：使用可训练的 g_vid 与 g_act 将监督特征与隐藏状态解耦。
  • 总体目标：L = L_FM^v + L_FM^a + λ_RGF (w_i L_intra + w_c L_cross + w_t L_temporal)。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Spatial / Object / Goal / Long 四个 suite，共 40 个任务、每任务 500 条演示，每 suite 500 次 rollout，共 2000 次）；RoboTwin 2.0（50 个双臂操作任务，clean 50 条演示、随机化 500 条演示，每设置 100 次 rollout）。
  • 真实机器人：Franka Research 3 机械臂 + 3 台 ZED 2i 相机，每任务 50 条演示、每设置 20 次 rollout。
  • 模型规模：基于 Wan2.2-TI2V-5B 视频专家 + 1B Action DiT 动作专家；几何教师为冻结的 VGGT-1B（对比实验另用 DINOv2）。
  • 训练配置：动作 horizon H=32、每训练块 9 帧视频、推理 10 步去噪、CFG scale 1.0；默认在 WAM 第 15 层施加三类关系目标，等权重，λ_RGF=0.5。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 与 RoboTwin 2.0 仿真基准 + 真实 Franka 机器人；指标为任务成功率（%）；对比 VLA（OpenVLA-OFT、π0.5、Spatial Forcing）与 WAM（LingBot-VA、Motus、Fast-WAM、X-WAM、GeoSem-WAM、WAM4D、MECo-WAM）。
  • LIBERO：RGF-WAM 平均成功率 98.65%，为所有对比方法最高；相对 Fast-WAM 在 Spatial / Goal / Long 分别提升 +1.2 / +1.6 / +1.4，Object 两者均为 100%。
  • RoboTwin 2.0：平均 92.71%（最高），clean 从 91.88% 提升到 92.92%，randomized 从 91.78% 提升到 92.50%，且无需具身策略预训练；超过 MECo-WAM 0.09 个百分点。
  • 几何迁移分析：逐点对齐用于视频仅带来小幅增益（VGGT +0.30），扩展到动作后降至 -0.05；关系对齐在 Uncond / Joint / IDM 上分别提升 +1.05 / +0.60 / +0.55；关系式 DINOv2（98.35%）甚至优于逐点 VGGT（97.90%），说明对齐方式比特征来源更关键。
  • 消融：单一关系目标收益有限，跨视角监督最关键；三者联合达 +1.05，优于最佳双目标组合（+0.40），体现非加性互补；Huber（98.65%）优于 KL（98.05%）。
  • 真实世界：平均成功率 65.71%，比 Fast-WAM（57.14%）高 8.6 个百分点；在两阶段多物体任务上提升最大（+10、+15），在未见颜色 / 干扰物 / 高度变化下分别提升 +5 / +5 / +20。
  • 定性结果：RGF 的帧内相似度图更平滑且贴近真值 3D 距离图，跨视角最高相似 patch 落在真值对应附近，动作-时序相似度矩阵能复现非匀速运动下的非均匀带状结构。
