Card 03 核心贡献

核心贡献

  • 提出 VLA² 智能体框架，集成任务规划、未知概念到已知信息的转换（通过网络与记忆检索）、VLA 执行以及任务完成度验证模块。
  • 对 OpenVLA 进行微调，使其能够接受带透明彩色掩码的图像输入和分步骤的子任务提示，从而提升物体操纵泛化性。
  • 基于 LIBERO 仿真环境设计了三个难度级别的物体泛化任务（颜色变化、目标物体替换、全新概念物体），用于系统评估 OOD 泛化性能。
  • 在 Hard 级基准上，相比独立 OpenVLA 基线提升 44.2% 成功率，在所有自定义环境中平均提升 20.2%，且不损失域内任务性能。
Card 04 方法描述

方法描述

  • 框架分三部分：初步信息处理（Planner 与视觉预处理）、认知与记忆（Vision 与 Language 模块）、判断与执行（Verifier 与执行器）。
  • Planner 使用 GLM-4.1V-9B-Thinking 将复杂指令分解为结构化子任务，并设计三层后处理保证输出可靠性。
  • 视觉预处理采用微调后的 MMGroundingDINO 生成目标边界框；认知阶段通过 Bulk-Bing-Image-downloader 检索网络图像，结合 GLM 生成描述关键词，实现“即时学习”将未知物体锚定到已知属性（颜色、形状、功能等）。
  • 对检测到的目标使用 SAM2.1-L 生成像素级掩码，并通过 Cutie (VOS) 生成时间连续、颜色编码的掩码视频流，减少对表面纹理的依赖。
  • 语言模块对任务文本中的未知名词进行词汇替换，将其映射到训练分布内的已知词表（KnownList），并利用记忆机制复用替换结果。
  • 验证器使用 Qwen2.5-VL-3B-Instruct 微调后判断子任务是否完成；执行模块使用微调后的 OpenVLA，训练数据采用带彩色掩码的 RGB 视频和“现在执行当前子任务、整体任务为所有子任务联合”的提示形式。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 仿真环境（Spatial、Goal、Object、Long 四个套件）作为域内基准。
  • 构建自定义 OOD 环境：Easy（黑碗改为橙色系）、Medium（换成白碗、蓝瓶、白柜）、Hard（引入茅台瓶、青花瓷碗、黄油等全新概念）。
  • 训练资源：全部在 NVIDIA A100-80GB GPU 上进行；OpenVLA 使用 8 卡，MMGroundingDINO 使用 2 卡，Qwen2.5-VL 使用 4 卡。
  • 关键模型：OpenVLA（执行主干）、MMGroundingDINO（检测）、SAM2.1-L（分割）、GLM-4.1V-9B-Thinking（规划与理解）、Qwen2.5-VL-3B-Instruct（验证器）。
  • 对比基线：OpenVLA-OFT、π₀、π₀-FAST、Agentic Robot。

评估与结果

  • 评估环境：原始 LIBERO 四个套件 + 自定义 Easy/Medium/Hard 三档 OOD 环境；每任务执行 50 次，报告成功率（SR）。
