Card 02 论文概述

论文概述

  • 论文提出 CondenseVLA，一种面向多帧视觉-语言-动作（VLA）策略的可学习历史压缩机制，用于把机器人操作中的短期视觉历史注入动作解码过程。
  • 核心问题：机器人操作依赖短暂接触、临时遮挡、中间物体状态等单帧无法判定的线索；但单纯扩大历史窗口计算昂贵（增加 4 帧可让前向速度下降约 35%），且邻近帧高度冗余、固定间隔采样会漏掉关键事件，收益有限甚至为负。
  • 目标：在固定、可控的解码端 token 预算下，自适应地压缩并筛选任务相关的近期视觉证据，而非“无脑加长历史”。
Card 03 核心贡献

核心贡献

  • 方法层面：提出解码端可学习历史压缩模块 LHC（Learnable History Condensation），将缓存的近期 VLM 帧特征蒸馏为固定数量的 slot token 作为动作条件。
  • 正则化设计：引入简单辅助正则（注意力图多样性约束 + slot 嵌入去相关），鼓励 slot 关注互补的历史片段、减少冗余。
  • 实证结果：在 Simpler-WidowX、LIBERO、RMBench 与真实机器人平台上一致优于 CronusVLA 基线（如 Simpler-WidowX 从 58.7% 提升至 69.8%）。
  • 机理性发现：长历史中存在大量冗余，学习式任务相关压缩比朴素扩展历史窗口或刚性采样更可靠。
  • 提供项目主页与开源代码（github.com/FeiyangHong/CondenseVLA）。
Card 04 方法描述

方法描述

  • 整体流程：每步 VLM 只编码当前观测得到 \(f_t\)；FIFO 缓存最近 \(M\) 个历史特征 \(F_t\)；LHC 将其压缩为 \(K\) 个 slot（\(K \ll M\)）；扩散解码器以定长序列 \(Z_t=[\tilde F_t; f_t]\) 为条件。
  • LHC 结构：\(K\) 个可学习 slot query 通过多头交叉注意力对 \(M\) 个历史特征做 key/value 聚合；每个 slot 由基查询、slot 嵌入和一个固定相对标量（经 MLP 注入）构成，仅用于打破置换对称性，不强加硬性时间分配。
  • 时间位置编码：历史位置嵌入只进入 value 路径，并带初始化为 0 的可学习缩放。
  • 训练目标：\(L = L_{\text{diff}} + \lambda_{\text{div}} L_{\text{div}} + \lambda_{\text{slot}} L_{\text{slot}}\)；\(L_{\text{div}}\) 用 \(\mathrm{MSE}(\bar A \bar A^\top, I)\) 惩罚 slot 注意力重叠，\(L_{\text{slot}}\) 对中间 slot 对（\(2 \le i < j \le K-1\)）做余弦相似度平方去相关。
  • 微调范围：冻结视觉编码器与语言模型，仅训练多模态投影器、LHC 和扩散动作解码器；历史特征使用 stop-gradient。
  • 计算成本：LHC 注意力混合为 \(\mathcal{O}(KMD)\)，解码器条件 token 数为 \(K+6\)，与 \(M\) 无关。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：SimplerEnv / Simpler-WidowX（Spoon on Towel、Carrot on Plate、Stack Cube、Eggplant in Basket 四项）、LIBERO（Spatial / Object / Goal / Long 四个套件）、RMBench（9 个记忆依赖任务，含 \(M(1)\) 与 \(M(n)\) 类别，每任务 50 条演示、100 次评测）。
  • 真实平台：Galaxea R1 Lite 机器人 + 顶部中心第三人称 RGB 相机，5 个任务，每任务 50 条训练演示、每方法 50 次评测。
  • 基线模型：以 CronusVLA（基于 OpenVLA + DiT 风格扩散解码器）为主干与同协议基线，另对比 OpenVLA、OpenVLA-OFT、π₀、TraceVLA、SpatialVLA、MemoryVLA、GR00T-N1.5、HAMLET、ContextVLA、HPT 类方法等。
  • 模型规模：冻结的视觉/语言主干约 7.47B 参数；动作解码器 134.7M；LHC 约 100.8M（约占主干 1.35%，约为解码器的 74.8%）。
  • 超参设置：Simpler/RMBench/真机用 \(M=20, K=6\)；LIBERO 用 \(M=10, K=3\)。
  • 计算资源：延迟/速度测试使用 A100-SXM4-80GB、batch size 1、10 步 DDIM；完整训练硬件细节置于附录（原文未展开）。
Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（%）、多阶段任务的中间阶段成功率与最终成功率、策略前向延迟/推理速度（Hz）。
  • Simpler-WidowX：平均成功率 69.8% vs. CronusVLA 58.7%（+11.1 pp）；分任务增益 +13.9/+15.3/+11.1/+4.2 pp。
  • LIBERO：平均 97.2% vs. CronusVLA 96.3%；Long 套件 94.6% vs. 94.0%（接近饱和，不能单独证明记忆能力）。
  • RMBench：总体 21.6% vs. 稠密历史 CronusVLA 14.3%（+7.2 pp）；\(M(1)\) 提升 +10.6 pp，\(M(n)\) 仅 +3.0 pp，暴露有限窗口的局限（Press Button 三方法全失败）。
  • 真实机器人（Galaxea R1 Lite）：平均最终成功率 52.8% vs. CronusVLA 45.2%（+7.6 pp）；三个多阶段任务平均由 37.3% 升至 46.7%（+9.3 pp）。
  • 消融：去掉稠密历史、MHA 压缩、注意力多样性、slot 去相关逐项验证；\(K/M\) 网格显示 \(M=20,K=6\)（70.8%）与 \(M=30,K=10\)（64.6%）的交互效应；与静态索引（55.2%）、静态权重（54.2%）、等间隔采样（59.4%）相比，学习式压缩最优。
  • 效率：固定 \(K=6\) 时，\(M=10\) 延迟略高 0.25%，而 \(M=20\)、\(M=30\) 时分别降低 3.8%、7.4%；但 LHC 自身开销随 \(M\) 增长，不构成普适端到端加速。
  • 局限：FIFO 无法检索窗口外事件；\(M\)、\(K\) 无独立验证集调参；仅单一 VLA 主干与单一实机平台；新增 LHC 容量使增益无法完全归因于时间选择。
