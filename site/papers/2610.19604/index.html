ForceBench: Benchmarking Force Integration for Robotic Manipulation

2026-10-14 · 原文 · 翻译 · 2610.19604

ForceBench 是一个用于评估六轴腕力集成（six-axis wrist-force integration）在机器人操作中表现的模拟基准。 论文旨在解决现有力感知系统因任务、演示和控制设置差异而难以可靠比较力集成设计的问题。 通过统一的协议，比较一个无力基线和六种力集成设计，并分析其在不同操作需求下的收益与局限。

Card 03 核心贡献

核心贡献

  • 提出 ForceBench 统一力集成基准，包含八个任务、参数化物理条件、1,600 个同步多模态演示，以及任务级和类别级评估结果。
  • 在共享 π0.5 骨干上系统比较观察条件、辅助预测监督和时间力表示，刻画其在物理属性推断、阻力依赖交互和接触丰富装配中的优缺点。
  • 在五个真实世界任务、800 次试验中评估八个系统，支持模拟中的主要定性趋势，并揭示总体成功率所掩盖的任务相关权衡。
  • 发现 Prompt Fusion 在模拟中达到最高平均成功率 35.31%，相比无力基线 23.25% 提升 12.06 个百分点。
  • 真实世界中 Prompt Fusion 和 Dual-Path Fusion 平均成功率达 63.00%，基线为 40.00%，但仅 Prompt Fusion 在全部任务上均有提升。
Card 04 方法描述

方法描述

  • 基于 Isaac Lab / Isaac Sim 构建，使用 Franka 机械臂和平行夹爪，在桌面和家庭环境中执行任务。
  • 力集成设计包括：π0.5 (No Force) 基线、Token Fusion、Prompt Fusion、Cross-Attention、Token Fusion + Pred、Temporal Prompt 和 Dual-Path Fusion。
  • Prompt Fusion 将力附加到机器人状态，归一化并离散化为数值 token 放入 prompt；Token Fusion 用 MLP 将力映射为连续 token 放在动作 token 前。
  • Token Fusion + Pred 在训练中增加未来力预测监督；Temporal Prompt 读取过去 16 个力样本并附加均值/标准差；Dual-Path Fusion 同时使用 prompt 路径和掩码统计连续 token 路径。
  • 所有方法共享 π0.5 骨干，动作块预测与统一控制器执行，模拟物理 60 Hz、控制 15 Hz。
Card 05 数据集与资源

数据集与资源

  • 数据集为 ForceBench，包含 1,600 个同步专家演示（每个任务 200 个），涵盖八个任务。
  • 使用共享 π0.5 骨干，同时对比 π0、ForceVLA 和 ForceFlow 作为外部参考。
  • 训练配置：七个 π0.5 配置训练 10,000 步，batch size 为 32；π0 训练 10,000 步；ForceVLA 和 ForceFlow 训练 100,000 步。
  • 真实世界实验使用 Franka Research 3 机械臂，配备六轴力/力矩传感器，每个任务 200 个演示，训练 10,000 步，batch size 为 64。
  • 模拟环境基于 Isaac Lab / Isaac Sim，真实世界使用外部相机、腕部相机、KWR75B 力/力矩传感器和 Robotiq 夹爪。
Card 06 评估与结果

评估与结果

  • 模拟评估在八个任务上进行，每个任务-方法对 200 episodes，共 16,000 episodes；真实世界评估在五个任务上进行，每个任务-方法对 20 trials，共 800 trials。
  • 主要评估指标为任务成功率（%），并报告物理属性推断、阻力依赖交互和接触丰富装配的类别级平均成功率。
  • Prompt Fusion 模拟平均成功率 35.31%，无力基线 23.25%；Dual-Path Fusion 紧随其后为 35.13%。
  • Dual-Path Fusion 在物理属性推断上领先（85.75%），Prompt Fusion 在阻力依赖交互上领先（20.80%）。
  • 未来力监督将 Token Fusion 从 23.56% 提升至 26.25%，但增益集中在 Weight Sort，CoM Sort 下降。
  • 真实世界中 Prompt Fusion 和 Dual-Path Fusion 平均成功率 63.00%，基线 40.00%；时间设计在 Weight Sort 上超过 Prompt Fusion，但在 Block Insert 上低于基线。
  • 失败结构分析表明，力集成主要改善由隐藏物理条件决定的选择；预测和时间增益在决策与执行之间呈现不同权衡。
