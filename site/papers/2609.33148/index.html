Card 03 核心贡献

核心贡献

  • 提出 DroneWAM，采用 JEPA-based 架构直接在表示空间预测未来状态，避免显式未来图像生成的高计算成本。
  • 设计预训练 Resampler，将密集编码器特征从 512 tokens 压缩到 128 tokens，降低多步想象中重复传播的计算量。
  • 提出 Adaptive Rollout 机制，通过偏好训练（DPO-style）的 Gate 根据当前场景自适应决定预测深度，而非固定 rollout 长度。
  • 构建 DroneNav-6D 数据集，包含 3,837 条轨迹片段、1,592,170 帧 RGB 观测和 63.03 小时飞行记录，支持完整 6-DoF 空中运动监督。
  • 在 DroneNav-6D 和 LIBERO 上验证了方法在轨迹精度与推理效率上的优势，并展示自适应 rollout 的跨域泛化能力。
Card 04 方法描述

方法描述

  • 采用 JEPA-based 预测学习，在潜在表示空间进行未来状态预测，核心关注导航相关的场景结构与运动线索。
  • 使用冻结的 ViT-L 视觉编码器提取特征，再通过预训练 TokenAE Resampler 将 512 tokens 压缩为 128 tokens。
  • Predictor 自回归预测未来潜在状态，Planner 基于预测潜在前缀生成 8 步 ego-frame 6-DoF 动作计划。
  • 训练分为三阶段：Resampler 预训练、Predictor 与 Planner 训练、Gate 偏好训练。
  • Gate 使用仅含推理时信息的输入，通过 DPO-style 偏好优化学习预测深度选择，并在校准集上确定停止阈值。
  • 推理时采用 Adaptive Inference：Predictor、Planner 和 Gate 迭代执行，当 Gate 分数超过阈值时停止，并返回得分最高的动作计划。
  • 世界预测损失采用时间折扣的潜在 L1 损失，规划损失结合 rATE 与 rRPE。

数据集与资源

  • DroneNav-6D：基于 Unreal Engine 4.27 与 AirSim 构建，覆盖 SnappyRoads、雪山、CITYBIM 沿海城市、RuralAustralia、NYC 密集城市街道 五个仿真世界。

Card 06 评估与结果

评估与结果

  • 评估包括 开环轨迹预测 与 闭环视觉导航，指标包括 ATE、Rel.ATE、RPE、Rel.RPE、任务进度（Prog.）、MSE、推理延迟 及平均 rollout 深度。
  • 开环结果：DroneWAM 达到 ATE 1.1062、Rel.ATE 0.0578、RPE 0.3470、Rel.RPE 0.0180、推理延迟 483.29 ms。
  • 相比 FastWAM，DroneWAM 将 ATE 从 1.8366 降至 1.1062（降低 39.8%），推理延迟从 712.33 ms 降至 483.29 ms（降低 32.2%）。
  • 闭环结果：DroneWAM 任务进度达到 0.774，优于 FastWAM 的 0.510，同时保持更低轨迹误差和延迟，但所有方法仍未完成全部任务。
  • 消融实验：加入 Resampler 将推理时间从 656.12 ms 降至 582.65 ms，几乎不损失轨迹精度。
  • 自适应 rollout 将平均预测深度从 8.0 降至 4.578，延迟降至 483.29 ms，并优于随机停止和固定深度策略。
  • Resampler token 消融：从 512 压缩到 128 tokens 可获得 18.3% 延迟下降，精度几乎不变；进一步压缩到 16 tokens 则精度明显下降。
  • 泛化到 LIBERO：自适应 rollout 将延迟从 890.8 ms 降至 411.9 ms（降低 53.8%），并略微提升动作预测精度和抓取准确率。
  • 偏好训练的 Gate 在未见环境上表现与已见环境接近，最大 Rel.ATE 差距仅 0.0034，显示较好的环境泛化性。
