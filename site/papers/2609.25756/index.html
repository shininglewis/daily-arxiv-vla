论文概述

Card 03 核心贡献

核心贡献

  • 提出面向精密医疗任务的分层架构，将高层判断与底层执行解耦，在受限技能空间中实现安全闭环控制（"感知–推理–门控–执行–更新"循环）。
  • 设计技能导向的多智能体数据生成机制，构建约 30,000 条低冗余、强泛化的结构化样本数据集，为闭环决策学习提供数据基础。
  • 引入中间门控模块（动作空间有效性校验 + 基于状态的逻辑门控），在物理任务状态层面拦截不安全或过早的操作，失败时触发 E_STOP、硬件自检与人工接管。
  • 将思维链（CoT）推理整合进决策三元组 think / answer / function，兼顾可解释推理轨迹与函数预测精度。
  • 在真实柔性电极植入平台上完成 100 次闭环试验，取得 95.0% 任务成功率，分别超越 OpenVLA（8%） 和 π₀（15%） 87.0 与 80.0 个百分点。
Card 04 方法描述

方法描述

  • 任务建模：将任务形式化为 (I_t, u_t, s_t) → y_t → ⟨function⟩_t → (s_{t+1}, I_{t+1}) 的闭环过程，而非传统 (I_t, u_t) → a_t 的连续动作回归；预测函数须满足 ⟨function⟩_t ∈ F(s_t)。
  • 高层决策模块：微调 LVLM（大视觉语言模型），将双目图像、用户指令与机器人状态组合为状态感知提示，输出结构化决策三元组（think、answer、function）。
  • 中层门控模块：依次执行*动作空间有效性校验*与*状态逻辑门控*，预条件包括针–电极孔几何对准状态、视觉系统就绪度（曝光与对焦在操作范围内）及工作空间初始化状态。
  • 底层动作模块：按决策调用受限技能接口，单步执行后更新状态与观测并反馈回上层。
  • 数据生成流水线：Human Agent 生成多样化任务提示，Robot Agent 生成结构化响应，Verification Agent 执行硬约束、软约束与语义连贯性三级校验；使用 Qwen2.5-VL-3B-Instruct 隐层表征与余弦相似度阈值去冗余。
  • 安全设计：门控拒绝时立即 E_STOP 并移交人工，而非自主重规划，符合高风险医疗场景的保守原则。
Card 05 数据集与资源

数据集与资源

  • 真实数据：约 3,000 条真实样本（同步双目图像、函数标签、轨迹，采样率 5 Hz），经受控图像扰动扩展至约 30,000 条样本。
  • 微调骨干模型：InternVL2-2B（2B）、Qwen2.5-VL-3B（3B）、Llama-3.2-11B-Vision-Instruct（11B）。
  • 对比基线：OpenVLA-7B（自回归动作 token 化）与 π₀-3.3B（流匹配连续控制），另含零样本 Qwen2.5-VL-3B 与 Qwen3-VL-30B-A3B。
  • 部署配置：选用 Qwen2.5-VL-3B，在单块 GPU 上运行；论文未明确给出 GPU 型号、数量及训练总时长。
  • 实验平台：真实柔性电极植入平台，钨针尖约 10 μm，需穿过 30×50 μm 电极孔，含双目相机、LED 光源与机械臂。
  • 动作空间：7 个离散函数，分为图像调节（ADJUST_EXPOSURE、ADJUST_FOCUS）、状态管理（REINITIALIZE_RANGE、RESTART_CAMERA）、安全控制（E_STOP）与动作执行（ALIGN_NEEDLE、INSERT）。
Card 06 评估与结果

评估与结果

  • 评估协议：分为离线函数预测（动作平衡测试集，1,000 样本）与真机闭环执行（统一 100 次试验协议，随机初始化针位，基线先跑后复原起始状态），指标为 Exact Match (EM)、Macro-F1 与闭环植入成功率。
  • 离线结果：完整 Qwen2.5-VL-3B 变体达 95.00% EM / 0.9604 Macro-F1；Llama-3.2-11B 达 95.70% / 0.9570（最佳）；InternVL2-2B 达 94.00% / 0.9400；零样本 Qwen2.5-VL-3B 仅 29.60%、Qwen3-VL-30B-A3B 为 65.40%。
  • CoT 消融：无 CoT 时 EM 为 85.30%，加入 CoT 提升至 95.00%；ADJUST_FOCUS（65.84%→96.71%）与 ALIGN_NEEDLE（48.67%→72.57%）增益最大，而 INSERT 从 93.33% 降至 81.67%（误差多为误判为 ALIGN_NEEDLE，体现保守倾向）；ADJUST_EXPOSURE、REINITIALIZE_RANGE、RESTART_CAMERA、E_STOP 接近或达到 100%。
  • 闭环结果：最大决策轮数限 3 时成功率 73.00%，限 6 时提升至 95.00%，显著优于 OpenVLA（8.00%） 与 π₀（15.00%）；验证了额外对齐轮次的收益高于过早插入的风险。
  • 推理延迟：单次决策循环约 10 秒（LVLM 推理约 8 s、状态更新与门控校验约 2 s），运行决策频率约 0.1 Hz，与 5 Hz 离线采样率不同。
  • 门控分析：500 余次测试推理中门控仅拒绝 2 次（均为输出超出七函数动作空间），均触发 E_STOP 与人工接管；因安全考虑未做完整门控消融实验。
  • 局限性：仅在单一精密医疗任务上验证，训练数据由自建流水线生成可能存在构造性偏好；门控规则依赖任务特定状态，尚未纳入解剖边界、组织交互模型等更丰富医学约束。
