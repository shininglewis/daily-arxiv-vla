Card 02 论文概述

论文概述

  • 提出 Xiaomi Auto World Model 2.0，一个面向 Physical AI 的统一流式因果世界模型，同时覆盖通用视频生成、自动驾驶与具身机器人三大场景
  • 核心目标是建模并生成真实世界中的因果物理演化，并在统一框架内融合异构条件输入（文本、首帧、布局、动作、相机位姿）实现视角一致的生成
  • 解决的关键问题是：真实物理交互呈长尾分布、现有模型对多视角/多控制格式支持不足、以及长时多视角推演的算力与显存开销过大
Card 03 核心贡献

核心贡献

  • 提出 View-Temporal Attention (VTA)，将自注意力沿时间与视角维度分解为交替的奇偶层，复杂度由 O(N²T²) 降至 O(TN(N+T))，且不引入额外注意力模块
  • 在 VTA 时间层引入 Gated Linear Attention (GLA)（4:1 门控 softmax 锚点调度），使流式推理的时序 KV 缓存减少 97% 以上，单步开销与生成长度解耦
  • 提出 WorldRec 2.0，单次前向从多视角多时刻观测重建静态/动态 3D 高斯，并以渲染结果作为显式 3D 场景记忆注入生成器，提升长时程几何与外观一致性
  • 设计 物理交互数据管线，结合仿真引擎（CARLA/UE5/Blender）、视频生成器与公开素材构造碰撞等长尾反事实数据
  • 构建 Pre-train / Mid-train / Post-train 三阶段训练 与蒸馏加速方案（Consistency Distillation + Streaming DMD），支撑闭环仿真、闭环训练与 World Action Model (WAM) 应用
Card 04 方法描述

方法描述

  • 主干采用 Wan2.2-5B 的架构、权重与 VAE 编码器，基于 DiT 做因果流式自回归建模
  • World Control Injection：将世界控制 w_i 用同一 VAE 编码后与目标 latent 通道拼接，轻量且不改变基础模型结构，无控制时零填充
  • Multi-view RoPE：把同一时刻的多视角沿宽度轴拼接并分配不重叠坐标，使各视角相对位置与单视角一致
  • Fused PRoPE：用投影矩阵 P_i = K_f·E 对 Q/K/V 做投影旋转编码，将相机位姿注入注意力计算本身而非额外条件分支
  • WorldRec 2.0：点对齐查询 + 场景结构化寄存器（compress / communicate / broadcast 三段式交互）+ 4D RoPE，解码为静态与动态 3D 高斯并栅格化渲染
  • 后训练加速：一致性蒸馏将多步教师蒸馏为少步学生；Streaming DMD 采用长视频分段自回滚 + Random Gradient Sampling 降低显存
Card 05 数据集与资源

数据集与资源

  • 训练语料共 12.6M 视频片段，分三类：通用数据、物理世界数据（驾驶/机器人）、物理因果数据
  • 通用数据：Pandas 70M、SpatialVID-HQ、Sekai、RealCam-Vid、TartanAir
  • 驾驶数据：PhysicalAI-Autonomous-Vehicles（3.6M）、nuPlan、nuScenes、自采 MiData（11 路 30Hz 相机 + LiDAR）
  • 机器人数据：AgiBot World Beta、DROID、EgoDex、Galaxea Open-World、InternData-A1、Open X-Embodiment、RoboCOIN、RoboMIND、RoboTwin 2.0
  • 物理因果数据：CARLA（CARLA Ego / CARLA Adv）、UE5、Blender 仿真数据，以及扩散视频生成器合成的长尾驾驶数据
  • 基座模型规模约 5B 参数（Wan2.2-5B）；三阶段分辨率 480p → 480p/540p，视角数 1V → 1–7V
