Card 03 核心贡献

核心贡献

  • 配对式评测框架：在同一观测协议下，对 GPT-6-Astra 智能体的两种配置与 8 个后训练策略在全部 510 个 EBench 测试回合上做配对比较，覆盖所有任务组与泛化维度。
  • 刻画直接控制的能力边界：仅用 单条标注演示 且 无参数更新，定位智能体在 8 个后训练策略中的领先/落后位置，并将失败回合追溯到具体失效机理。
  • 分析 Harness with Policy 与设计启示：量化调用后训练策略带来的增益与代价，识别出策略调用次优、固定指令无法传子目标、恢复控制时抓握失维护三类残余瓶颈，为未来 agent harness 设计提供方向。
  • 揭示互补性：智能体擅长视觉定位、回合内纠错与跨泛化维度稳定性，后训练策略擅长长程与高精度接触，二者互补但无法共同突破高精度接触上限。
Card 04 方法描述

方法描述

  • 将智能体形式化为 (F, H)：MLLM 核心 F 与 agent harness H = (p_H, O_H, T_H)（提示词、观测接口、工具集），由 harness 执行决策闭环，形成无需机器人后训练的闭环策略 π_A。
  • 观测协议：仅提供 3 路 RGB 视图（overlook 俯视 + 左右腕部相机）与本体状态（双 EEF 位姿、夹爪开度、底盘位姿、已用仿真步数），无深度、无标定、无真值位姿、无奖励与子目标指示。
  • 动作空间：动作集分为物理推进类 A^act 与信息查询类 A^info；直接控制时 A^act = A_EEF（EEF/底盘/夹爪路点），harness 模式额外加入 A_pol（策略调用）。
  • 单样本上下文学习（single-shot ICL）：由另一 GPT-6-Astra 实例检查一条训练轨迹，选取 10–18 个关键帧，并配以机器人状态与动作，生成详细任务描述，要求智能体按当前视觉自适应而非回放坐标。
  • Harness 机制：每次策略调用可指定 1–300 个物理步 的步限并给出“陈述理由”，策略在固定任务指令下自主执行，智能体保留任务规划、进度监控与错误恢复。
  • 评测采用 高推理强度（high reasoning effort） 的 GPT-6-Astra，每个回合独立会话，不跨回合保留状态。
Card 05 数据集与资源

数据集与资源

  • EBench：基于 GenManip 与 Isaac Sim 的诊断性仿真基准，机器人平台为 ARX Lift 2 双臂移动机器人。
  • 规模：26 个任务、9 类场景（家庭/零售/工业）、510 个测试回合、468 个不同场景；24 个任务各 20 回合，Sandwich 与 Microwave 各 15 回合。
  • 任务划分：19 移动 / 7 桌面；14 低 / 8 中 / 4 高精度；11 短程 / 15 长程。
  • 泛化维度：Background（未见背景）、Object（未见物体实例）、Instruction（改写指令）、Mix（三者联合扰动）。
  • 训练数据：后训练策略使用 EBench 公开训练集 6,600 条演示（26 任务）；智能体每任务仅用 1 条 训练演示标注。
  • 回合限制：每个物理步为 30 Hz，任务相关步限为 1,500–5,000 步，且不向智能体披露。
  • 模型与算力：核心模型为 GPT-6-Astra；论文未在给定正文中报告具体训练 GPU/TPU 资源（智能体侧为纯推理，无参数更新）。
Card 06 评估与结果

评估与结果

  • 评估基准与协议：全部 510 个 EBench 测试回合，配对比较；官方指标为 任务成功率（SR） 与 阶段完成分（score），先在任务内按回合平均，再在 26 个任务上等权平均。
  • 对比基线（8 个后训练策略）：OpenWAM-α（WAM, 55.3% / 0.701）、InternW0-Δ（WAM, 49.2% / 0.660）、Qwen-RobotManip（VLA, 45.6% / 0.608）、π0.5（VLA, 41.4% / 0.544）、InternVLA-A1.5（34.2% / 0.468）、π0（33.7% / 0.475）、GigaBrain-0.7（33.3% / 0.460）、Fast-WAM（25.6% / 0.371）。
  • 直接控制：总体 46.7% SR / 0.654 score，在 9 个对象中排名第三，超过 6 个后训练策略；短程任务 73.2% SR 排名第一；移动任务 56.6% SR 排名第二；长程仅 27.3%、桌面 20.0%、高精度 11.3%。
  • 泛化稳定性：四个泛化维度 SR 区间 44.2%–50.8%，波动 6.6 个百分点，为所有对比对象中最小；在 Mix 维度以 46.2% SR / 0.643 排名第一（OpenWAM-α 从 61.5% 降至 44.6%，Qwen-RobotManip 从 55.4% 降至 33.8%）。
  • Harness with Policy：调用 π0.5 提升至 53.0% / 0.692，调用 InternW0-Δ 提升至 56.0% / 0.744，总体成功率超过表中所有后训练策略，且 每次成功的 token 成本降低一半以上；但受策略调用次优、固定指令无子目标、恢复控制时抓握破坏影响，仍低于两组件各自的任务级上界。
  • 失败机理：273 个失败回合中 229 个 因步限终止；仅 85 个回合得分为 0；43 个提前结束，其中 21 个 误报成功（Dishwasher 占 7 个，门未关）；共检测到 811 次抓握丢失（分布于 333 个回合），其中 469 次 发生在“未做抓取测试”的调用中；31 个回合出现 24 步内腕部旋转 ≥90°，169 个回合关节速度超 0.08 rad/步。
  • 成本分析：失败回合平均 5.45M tokens / 55.9 次调用，约为成功回合（1.84M / 27.4 次）的 3 倍与 2 倍；长程任务每次成功约 20.6M tokens，约为短程（2.23M）的 9 倍；调用次数与 token 消耗相关系数 r = 0.88。
