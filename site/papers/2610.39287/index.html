论文概述

Card 03 核心贡献

核心贡献

  • 提出统一机载 VLA 架构：0.8B Qwen3.5-VL 主干 + 0.2B 紧凑动作专家，同一检查点支持 VQA、视觉定位、空间推理与语言条件导航。
  • 提出 Motion-Adaptive Memory（MAM），将飞行历史压缩为有界的事件级 token（动作片段 + 视觉锚点图像），在保留更长历史的同时大幅降低输入长度与推理耗时。
  • 提出 Motion-Structured Prior（MSP），用数据驱动的运动原型构造流匹配的源分布，使动作专家在单步去噪下即可生成高质量 12 航点动作块。
  • 构建 OpenFlyV2-130K 数据集：约 70,000 条导航轨迹 + 60,000 条视觉-语言指令-回答对，覆盖 13 个环境（4 个 AirSim、2 个 Unreal Engine 城市、7 个 3DGS 真实场景重建），总面积 254.81 km²。
  • 完成全机载真实飞行验证：在 DJI M30T + NVIDIA Jetson Orin NX 上以 10 Hz 生成动作块，零样本真实世界导航成功率达 48%。
Card 04 方法描述

方法描述

  • 共享主干：视觉-语言前缀由 MAM token、当前图像 token、语言 token 和一个专用 motion token 组成，输出文本回答或为动作生成提供条件。
  • MAM：按动作变化幅度与最大段长切分运动事件，事件内容经时序卷积编码 + 动作查询跨注意力聚合锚点图像特征，并叠加事件年龄嵌入；已完成事件的内容可跨预测周期缓存。
  • MSP：离线将非静止动作块按路径长度归一化后做 K-means（K=4） 聚类得到运动原型；推理时预测头输出类别、长度与累积偏航系数，调整原型得到条件化高斯源分布。
  • 动作生成：动作专家以条件流匹配（conditional flow matching） 从源样本输运到最终动作块，公式为 x_τ = τz + (1−τ)A*，用欧拉积分从 τ=1 到 τ=0；单步积分仍一次输出全部 12 个航点。
  • 训练流程：两阶段监督训练（先联合 VLN+VQA 两个 epoch，再启用 MAM/MSP 训练三个 epoch），随后对导航策略做分组相对优化（GRPO 类）强化后训练，仅更新动作专家。
  • 机载部署：异步动作块执行 + 训练时动作前缀条件化，在新块生成期间继续执行旧块，飞行控制器负责稳定与航点跟踪。
Card 05 数据集与资源

数据集与资源

  • OpenFlyV2-130K：72,352 条语言条件导航轨迹 + 60,006 条 VQA 问答对（颜色识别、物体描述、距离估计、空间关系推理、视觉定位）。
  • 数据来源：AirSim 环境、Unreal Engine 城市场景，以及团队用 3D Gaussian Splatting 重建的 5 个校园与 2 个灾后废墟场景；9 个环境用于训练，4 个（AirSim 16、UE Big City、GS NWPU 01、GS Ruins 02）完全留出。
  • 标注由 GPT-5 自动生成，经 200 名标注员人工核验，仅约 60% 样本通过筛选。
  • 模型规模：总计约 1B 参数（0.8B 视觉-语言主干 + 0.2B 动作专家），动作块视界 H=12 航点，每步含 3 个机体坐标系增量 + 1 个停止信号。
  • 机载硬件：NVIDIA Jetson Orin NX（搭载于 DJI M30T）；论文未披露具体训练 GPU/TPU 规模。
Card 06 评估与结果

评估与结果

  • 视觉-语言评测：颜色识别、物体描述、距离估计、空间关系各 300 例 + 1,000 例视觉定位；描述质量由 GPT-6.1-sol 十分制打分。
  • 仿真导航：800 条已见 + 300 条未见 episode，指标为 SR / OSR / SPL / NE，成功需在目标 25 m 内显式停止。
  • 感知结果：整体与 GPT-5.5 相当，优于 Qwen3.5-9B 与 Gemini 3 Flash；视觉定位 Acc@0.5 达 67.1%（GPT-5.5 为 61.6%），距离估计 MAE 47.32 m（GPT-5.5 为 52.62 m），相对误差 0.27 vs 0.34，描述得分 6.38 vs 6.36。
  • 仿真导航结果：已见/未见环境 SR 分别为 62.88% / 52.67%，比最强基线 DualVLN（38.88% / 36.67%）高 24.00 / 16.00 个百分点；NE 分别为 33.72 m / 38.81 m（DualVLN 为 65.75 m / 57.98 m），OSR 与 SPL 同样最优。
  • 消融实验（1 步去噪）：Base SR 49.82% → 加 MAM 53.45% → 加 MAM+MSP 57.09%，NE 从 49.18 m 降至 33.55 m；2 步去噪时仅 MAM 最强（SR 59.45%）。
  • 效率提升：输入 token 由 446 降至 ≤218（减少 ≥51.1%），Orin NX 上动作专家去噪时间由 80 ms 降至 20 ms（4× 加速）。
  • 真实飞行：4 个场景（含 2 个未见过地点）共 100 次试验（50 条单地标 + 50 条双地标指令），零样本总成功率 48%，全程机载推理、无人工接管。
