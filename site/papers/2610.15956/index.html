Card 02 论文概述

论文概述

  • 论文研究无光（lights-out）工业环境下的具身导航问题，提出用空间音频（spatial audio）定位目标方向、用深度（depth）感知局部几何，替代传统依赖 RGB 的视觉-语言-动作（VLA）模型。
  • 核心动机是：关灯工厂不再需要持续可见照明，维持照明用于机器人感知会造成不必要的能耗，而降低照明会严重削弱基于 RGB 的导航系统。
  • 论文要解决的问题是：在没有可见光、且存在复杂工业噪声干扰的条件下，智能体能否仅凭空间音频与深度实现可靠、可泛化的闭环导航。
Card 03 核心贡献

核心贡献

  • 提出 DarkNav-Bench：一个基于 Unity、包含 24 个工业场景的无 RGB 导航基准，设置 Clean、Prop、DN、LN 四个递进式声学难度等级（几何传播、弥散噪声、局部噪声累积叠加）。
  • 提出 ADAPT：一个音频-深度动作规划框架，通过轻量级空间音频适配器（SAA）与多模态动作监督微调，使 LMM 具备方向性声学推理与音频-深度联合决策能力。
  • 提出 TARS（Transition-Aware Reward Shaping）：在"位置–朝向"动作图上定义姿态感知的最短动作数势函数，区分有益旋转与无效旋转，弥补测地线进度奖励对原地转向不敏感的缺陷。
  • 构建骨干共享、梯度解耦的 Actor–Critic 结构，以 PPO 优化闭环策略，并引入有界动作历史（最近 8 步动作）作为无额外参数的时序上下文。
Card 04 方法描述

方法描述

  • 三阶段训练流程：空间音频适配 → 多模态监督微调（SFT）→ 基于 PPO 的闭环强化学习优化。
  • 空间音频适配（SAA）：在音频编码器上引入来自 SPUR 的 SAA 模块，并附加轻量级方向回归头，以角度回归损失（DoA 方位角）将声学表示锚定到声源方向。
  • 多模态 SFT：以专家轨迹（oracle 规划器）的"观测–动作"对进行教师强制负对数似然训练，将下一动作预测为短文本回答，仅动作答案 token 计入损失。
  • TARS 奖励塑形：基于势函数 Φ(s) = −N(s)（N(s) 为到达目标区域所需的最少可执行动作数），定义转移奖励 r_TARS = γ_Φ Φ(s_{t+1}) − Φ(s_t)（γ_Φ = 1），并与每步松弛惩罚及 SPL 加权成功奖励组合。
  • 关键创新：TARS 在智能体原地转向时也能给出方向敏感反馈，使奖励与离散动作空间及长时程导航进度对齐；动作图与特权状态仅用于训练期奖励构造，从不暴露给策略。
Card 05 数据集与资源

数据集与资源

  • DarkNav-Bench：由 IndustryNav 扩展而来，包含 24 个工业场景，其中 10 个为 seen 场景、14 个为 unseen 场景。
  • 数据规模：12,000 条训练 episode、seen 场景 3,000 条测试 episode、unseen 场景 4,200 条测试 episode。
  • 声学资源：背景噪声使用 MIMII 的真实机器录音；使用改进的 Steam Audio 管线进行空间化，观测为四通道一阶 Ambisonics（FOA）+ 自我中心深度图。
  • 模型基座：Qwen2.5-Omni-7B；训练硬件为 NVIDIA H200 GPU。
Card 06 评估与结果

评估与结果

  • 评估设置：在 seen 与 unseen 场景上，跨 Clean / Prop / DN / LN 四种声学条件进行闭环评估。
  • 评估指标：成功率 SR、路径长度加权成功率 SPL、动作数加权成功率 SNA、最终目标距离 FDG。
  • 对比基线：训练型方法 MAGNet、SAVi、SoundSpaces；零样本多模态模型 Qwen 2.5-Omni、Qwen 3-Omni（含 oracle 与非 oracle 设定）。
  • 关键结果（unseen 场景）：ADAPT 在 Clean 下达到 90.6% SR / 86.0 SPL，在 Prop 下 81.6% SR，在 DN 下 62.0% SR，在最难的 LN 下仍保持 60.0% SR。
  • 关键结果（seen 场景）：Clean 97.7% SR / 93.48 SPL，Prop 91.33% SR，DN 69.70% SR，LN 67.40% SR，全面优于所有训练型与非 oracle 零样本基线。
  • 消融结论：SAA 在 SFT 阶段稳定提升性能；TARS 优于测地线距离奖励塑形，且在无动作历史时增益最大；SAA 与 TARS 结合效果最佳，动作历史进一步提供轻量时序上下文提升鲁棒性。
  • 定性结论：ADAPT 能保持稳定的目标导向进展，而基线方法易停滞或偏离路线；即便带 oracle 信息的零样本 LMM 也难将准确目标信息转化为有效的避障闭环行为。
