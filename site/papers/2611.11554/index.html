Kimodo-Policy: Learning Kinematic Action Models for Humanoid Loco-Manipulation

Card 03 核心贡献

核心贡献

  • 提出 KAMs 范式：把全身运动当作直接预训练目标，将时序与跨肢体的协调先验迁移到下游控制，为人体动作策略学习提供互补基础。
  • 构建 Kimodo-Policy：以冻结的 Kimodo 文本到运动主干 + 轻量 ControlNet 视觉条件化为核心，形成紧凑策略（678M 参数，仅 92M 可训练）。
  • 设计 root–body–hand 三阶段架构 与 HandNet 手部扩散头，并引入 Dual-Path Fusion 视觉注入机制，协调移动与操作。
  • 提出 运动历史条件化 + 重复动作块预测（receding-horizon） 机制，将运动生成改造为闭环控制，支持持续重规划与执行纠偏。
  • 在 HumanoidArena 多任务上取得对比方法中最高总体成功率 72.14%，在 SIMPLE 保持竞争力，并在 8 项真实机器人任务上达到 60% 平均成功率；消融验证了预训练运动主干的贡献。
Card 04 方法描述

方法描述

  • 主干：采用冻结的 Kimodo-G1 分层 root–body 去噪生成器，继承其在大规模动捕数据上学到的全身运动表征（root 平移/朝向 + 关节位置、速度、朝向、足部接触）。
  • 视觉条件化：对冻结的 root/body 去噪器挂接可训练 ControlNet 分支，将 DINOv3 自视角视觉特征以零初始化残差方式注入指定层，保证初始时行为等同预训练模型。
  • Dual-Path Fusion：一路以未来运动隐状态为 query 对图像 token 做交叉注意力；另一路用 token 轴 MLP 将空间视觉 token 映射到未来时间维度；两路求和后经零初始化投影形成残差提示，仅作用于未来运动 token。
  • 三阶段生成：z_r = G_r(c) → z_b = G_b(c, sg(z_r)) → Û = G_h(s^h, sg(V), sg(z_b))，阶段间使用 stop-gradient 解耦梯度、保留前向依赖。
  • HandNet：独立扩散头预测左右手开合控制，支持二值开/闭与连续闭合量两种参数化，避免把手部标签塞入 root–body 运动空间。
  • 闭环改造：把每次策略查询建模为 Kimodo 运动表征下的“约束运动补全”——已测运动历史占据窗口前缀并在每步去噪中被恢复，未来片段自由生成；执行块前缀后重新规划。
  • 训练目标：掩码去噪监督 L = λ_r L_r + λ_b L_b + λ_h (L_h + λ_Δ L_Δ)，权重 (4, 1, 1, 0.2)；L_Δ 为手部控制相邻帧变化的 ℓ1 转移损失。推理使用 DDIM 迭代去噪，输出结果反变换后交给底层全身跟踪器。
Card 05 数据集与资源

数据集与资源

  • 预训练语料：419 小时机器人交互数据，来自 HIW-500、UniFoLM-WBT（当时可用的 14 个 G1 任务子集）与 Humanoid Everyday（10.3K 轨迹、超 300 万帧、260 项任务）。
  • 微调与评测数据：HumanoidArena 的 SONIC 数据（7 任务 × 100 条示范 = 700 条）；SIMPLE 的 8 个任务；真实世界 8 任务，每任务 25–30 条遥操作示范（LeRobot v2.1 兼容格式扩展）。
  • 模型规模：总计 678M 参数，可训练 92M（ControlNet 分支 + HandNet）；Kimodo 主干与 DINOv3 编码器均冻结。
  • 训练资源：预训练 16× NVIDIA H200，约 60 小时，bfloat16 混合精度，全局 batch 1024，1000k 步；下游微调在 4 张 GPU 上完成。
  • 推理部署：单张 NVIDIA RTX 4090，10 步扩散去噪，30 Hz 下预测 50 帧（≈1.67 s），每次更新执行 15 帧（0.5 s），历史窗口最长 100 帧。
  • 硬件平台：人形机器人配备 Intel RealSense D435i 与 Dex3-1 灵巧手；PICO 4 Ultra 头显 + 手柄 + 全身追踪器用于遥操作采集；底层 SONIC 跟踪器以 50 Hz 运行。
Card 06 评估与结果

评估与结果

  • 评测环境：HumanoidArena（7 个语言条件任务，含 3 个 HOI 与 4 个 HSI）、SIMPLE（8 个接触丰富任务）、以及真实人形机器人 8 项任务。
  • 主要指标：成功率 SR、平均跌倒率 AFR；仿真评测关闭 RTC，真机部署启用实时分块（RTC）。
  • 单任务结果：Kimodo-Policy 总体 SR 69.76%，超最强基线 DP 9.76 个百分点；AFR 4.29% 为表内最低；HSI 均值 84.58%（DP 65.83%），含 SitSofa 100%、VisNavi 75%；HOI 均值 50.00% 略低于 DP 的 52.22%。
  • 多任务结果：Kimodo-Policy* 总体 SR 72.14%，高于 GR00T N1.7（69.70%）与 GigaWorld-Policy（68.39%）；AFR 约 4.3% 为报告该指标方法中最低；HSI 均值约 84.2%，HOI 约 56.1%（低于 GR00T N1.7 的 62.22%）。
  • 预训练增益：多任务联合训练下，交互预训练把总体 SR 从 67.63% 提升到 72.14%（+4.51 点）；但单任务设定下反而从 69.76% 降至 67.14%，说明其收益依赖下游设定。
  • 真实机器人：8 项任务平均成功率 60%，优于所评估的真机基线。
  • 分析与消融：预训练运动主干的贡献得到消融支持；不同运动先验（不同预训练运动模型）会显著影响下游控制性能；并考察了机器人交互数据规模与可训练策略容量的扩展性。
