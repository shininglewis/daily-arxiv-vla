Democratizing Robot-Use Agents: A Unified Harness with Open Models

2026-11-01 · 原文 · 翻译 · 2611.01560

论文提出 uni-robot-agent，一个统一、模块化、支持后续训练的“机器人使用智能体”（Robot-Use Agent, RUA）执行框架（harness），目标是让开放权重（open-weight）模型也能完成有竞争力的机器人操作任务。 现有 RUA 研究严重依赖 GPT-6 Astra、Opus 5.5 等闭源前沿模型，无法访问权重，因此难以开展进一步训练；同时 API 成本高、推理慢，模型层面的优化受限。 论文要解决的核心问题是：如何在不使用特权信息（真值深度、CAD 模型、隐藏标注、任务验证器反馈）的前提下，用开源模型达到甚至超越闭源前沿模型的机器人操作水平，并系统分析其能力来源。

Card 03 核心贡献

核心贡献

  • 提出 uni-robot-agent 统一框架，通过共享工具接口与统一反馈格式，连接不同智能体运行时、仿真环境、真实机器人与本体，避免 N×M 的工具-环境重复实现，并支持跨环境的联合训练数据收集。
  • 首次证明开放权重模型可在 RoboDojo 上超越闭源前沿模型：Qwen3.8-Flash-Next 取得 25.00% SR / 31.39 Score，超过 GPT-6 Astra–RoboProbe 的 22.48% SR / 28.97 Score，且无特权信息、无蒸馏。
  • 在 19 个真实世界桌面操作任务 上验证可行性：Qwen3.8-Flash-Next 达 49.50 分，超过 Dream-1（35.50），与微调后的 π_0.5（47.75）相当。
  • 通过跨代际、跨家族、跨规模的模型对比与轨迹分析，归纳出有效机器人使用依赖的 四项通用能力：通用视觉理解、空间定位、几何代码编写、具身推理。
  • 系统分析了深度信息、技能库、成本与执行效率的影响，论证框架性能并不依赖特权输入或任务特定技能。
Card 04 方法描述

方法描述

  • 五层模块化架构：智能体层（模型交互与上下文管理）→ 编排层（调度与分发）→ 工具层（共享机器人操作）→ 服务层（运行时资源管理）→ 后端层（具体仿真器、机器人、模型实现）。
  • 统一交互接口：运动、感知、技能、回合控制共享同一套工具，参数、单位与反馈格式统一；环境适配器将共享工具（如 move）翻译为原生指令，新增环境只需适配器与配置。
  • 两级并发与两阶段流水线：background 调用立即返回任务句柄，使模型推理与工具执行重叠；共享独占资源的调用按提交顺序串行，非冲突调用并行；flush_queue 可在观测变化时取消未开始的调用。
  • 无特权输入设计：仅使用 RGB 图像、相机标定、机器人本体感知与描述、任务指令，禁用仿真真值深度、CAD 资产、隐藏场景标注、任务验证器反馈与外部网络。
  • 六项关键工程决策：图像-标定-机器人状态绑定为不可变快照；记录请求 ID 与执行状态以防通信失败后重复动作；move 同时接受目标位姿与夹爪开合以协同控制；带进度检测的受监控运动执行（自动停止/停滞返回）；返回位姿误差、停止原因等可诊断数值反馈与结果图像；滑动窗口批量淘汰旧图像并使用 codex CLI 压缩提示管理上下文。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboDojo 的 42 个任务，覆盖泛化、精度、长程执行、记忆、开放词汇指令五个维度；每任务 3 个种子 × 2 种布局 = 252 个回合。
  • 真实世界基准：自建 19 个任务，五个等权维度（空间理解、物体泛化、指令遵循、组合泛化、未见任务），使用 双臂平台 与 Intel RealSense D405 相机。
  • 评测模型：Qwen3.8-Flash-Next（125B）、Qwen3.8-27B、Qwen3.5-122B、Qwen3.5–3.7 Flash/Plus、DeepSeek-V4.1-Flash、GLM-5.3 Flash、GPT-5.6 Sol、GPT-6.1 Sol、GPT-6 Astra；基线含 π_0.5、Dream-1、Hy-Embodied-0.5-VLA、OpenWAM-α、Xiaomi-Robotics-1，以及 GAP (Hybrid)、RoboProbe、RPent 等框架。
  • 训练资源：论文原文未披露 GPU/TPU 具体配置；模型规模方面，Flash-Next 为 125B，另有 27B 与 >150B 级别模型参与对比。
Card 06 评估与结果

评估与结果

  • 评估方式：RoboDojo 官方协议报告成功率（SR）与 0–100 的部分成功得分（Score），按五维度先任务内平均再维度间平均；真实世界按五项能力各 20 分、总分 100 计分。
  • 仿真主结果：Qwen3.8-Flash-Next + uni-robot-agent 达 25.00% SR / 31.39 Score，超越 GPT-6 Astra–RoboProbe（22.48/28.97）与全部 VLA/WAM 基线；DeepSeek-V4.1-Flash 达 21.39% SR / 27.11 Score；同一模型换用 GAP 等框架性能下降约 8.89% SR 与 10.38 Score，说明框架设计贡献显著。
  • 真实世界主结果：Qwen3.8-Flash-Next 49.50 分（超 Dream-1 的 35.50，接近 π_0.5 的 47.75）；GPT-6 Astra + uni-robot-agent 达 75.50 分，大幅领先所有基线，说明框架同样惠及闭源模型。
  • 能力分析：GPT-5.6 Sol 已有 19.17% SR / 24.04 Score，Qwen3.8-27B 成功而更大更早的 Qwen 模型为 0% SR，说明模型规模不如训练分布关键；四类失败模式（视觉理解、空间定位、几何代码、具身推理）的错误率与 RoboDojo 得分强相关。
  • 消融结果：无深度但保留相机参数时，Astra 55.83→55.04、Qwen 35.89→31.39（保留 98.6% 与 87.5%）；仅 RGB 无相机参数时降至 31.29 与 9.13；关闭技能库后仍保留 96.6% 得分（30.31 分 / 24.58% SR），说明性能不依赖特权信息或任务特定技能。
