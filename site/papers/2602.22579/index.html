Metamorphic Testing of Vision-Language Action-Enabled Robots

Card 02 论文概述

论文概述

  • 论文研究 VLA（Vision-Language-Action）模型 控制的机器人系统面临的测试 oracle 问题——符号化 oracle 依赖于任务特定的模板，且无法评估轨迹质量、安全性等执行层面属性。

Card 03 核心贡献

核心贡献

  • 提出两个通用的蜕变关系模式（TC 和 TV），并在此基础上定义了五个具体的蜕变关系：MR1（同义词替换）、MR2（添加非干扰物体）、MR3（光照亮度变化）、MR4（否定/任务反转）、MR5（目标物体重新定位）。
  • 在 5 个 VLA 模型、2 个机器人平台、4 个操作任务 上进行了大规模实证研究，共构建 1,864 个源测试用例 和 9,320 个源—后续测试用例对，累计超过 11,000 次模拟执行。
  • 提出了面向 VLA 机器人的 故障分类法（taxonomy），将故障分为 操作（Manipulation）、运动（Motion） 和 规划与推理（Planning and Reasoning） 三大类别。
  • 证明了 MT 与符号化 oracle 具有互补性：符号化 oracle 捕捉"任务是否完成"（what），MT 捕捉"任务如何完成"（how），两者结合可获得更全面的故障覆盖。
  • 提供了完整的 复现包（replication package），包含代码、配置文件和项目网页。
Card 04 方法描述

方法描述

  • 核心思想基于机器人 轨迹（trajectory） 的蜕变测试：对输入（指令或环境）施加变换后，比较源轨迹与后续轨迹之间的 Fréchet 距离，若距离超出预设阈值 δ 则判定为 MR 违规。
  • MR1/2/3 属于轨迹一致性模式（TC）：输入变化不应显著影响轨迹（距离 ≲ δ）；MR4/5 属于轨迹变化性模式（TV）：输入变化应导致可预测的轨迹变化（距离 ≳ δ 或处于 α‖Δp‖ 与 β‖Δp‖ 之间）。
  • 采用 百分位数法 设置三档严格度阈值：严格（0.1m，约第 20 百分位）、中等（0.2m，中位数）、宽松（0.3m，约第 80 百分位）。
  • 源测试用例仅选择符号化 oracle 判定成功的用例，以避免偏向性评估，并用于分析两种方法的互补性。
  • 故障分类法通过 Cochran 抽样 获取 192 个统计代表性故障样本，由两位领域专家标注，并辅以三种 LLM（ChatGPT、Gemini、Grok）进行交叉验证。

数据集与资源

Card 06 评估与结果

评估与结果

  • 回答三个研究问题：RQ1（MT 的有效性）、RQ2（不同 MR 间检测能力对比）、RQ3（故障类型表征）。
  • 严格阈值下共检测到 7,822 个故障：640 个仅由符号化 oracle 发现，3,527 个仅由 MR 发现，3,655 个两者共同发现；中等阈值下共 6,286 个故障，宽松阈值下共 5,177 个故障，中等阈值提供了最佳平衡。
  • MR2（添加非干扰物体） 在大多数模型和任务中表现出最高的违规率（低阈值下 20 个组合中有 14 个最高），是最有效的 MR；MR4（否定/任务反转） 次之，尤其在语义理解场景中表现突出。
  • 符号化 oracle 主要发现 规划与推理类 故障（如未完成任务、错误动作序列），而 MT 能额外发现 运动类 和 操作类 故障（如轨迹次优、控制不稳定、碰撞等执行质量问题）。
  • 结论：MT 与符号化 oracle 互补，单独使用任一方法都会产生不完整的 VLA 行为视图，两者结合可显著提升故障覆盖率和系统可靠性评估的全面性。
