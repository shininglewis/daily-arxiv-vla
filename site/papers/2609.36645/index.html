Card 02 论文概述

论文概述

  • 研究未来预测（future prediction）作为辅助监督时，其"接入位置"如何决定 VLA（vision-language-action） 策略视觉表征的学习内容。
  • 核心问题：预测精度高并不代表策略学到了更好的可迁移控制表征；论文质疑"添加未来预测目标即可提升策略"这一前提。
  • 通过匹配目标构造、预测时域与训练条件的受控对比，揭示不同预测接口（prediction interface）会产生显著不同的预测结果与视觉表征，并影响分布偏移下的鲁棒性。
Card 03 核心贡献

核心贡献

  • 将预测输出（forecast output）与策略表征（policy representation）分离，证明相同的未来预测目标可产生差异巨大的视觉表征。
  • 证明预测监督进入策略的位置决定了动作相关的空间与时间信息是否保留在视觉表征中。
  • 通过扣分路由干预（credit-routing intervention）定位差异来源：直接的、同位置耦合（direct same-position coupling） 是关键，纯注意力介导路由无法恢复动作迁移能力。
  • 证明该表征层面的差异在仿真与真实机器人分布偏移下仍然对 VLA 鲁棒性具有实际影响。
  • 提出将未来预测视为表征学习的设计问题，其价值取决于监督是否到达策略用以行动的视觉通路。
Card 04 方法描述

方法描述

  • 形式化补丁级未来预测目标：以 EMA 目标编码器提供目标 $Y_t$、$Y_{t+h}$，用残差目标 $r_i = \mathrm{sg}(y_{t+h,i} - y_{t,i})$ 监督 token 级预测头 $H_\psi$。
  • 定义两类预测接口：vision-token 接口（$z_i=\tilde{v}_i$，直接读取对应 patch）与 special-token 接口（$z_i=\tilde{s}_i$，需经注意力混合间接到达 patch）。
  • 引入预测信用路由（forecast credit route） 概念，并用"同区域梯度占比（same-region gradient share）"量化空间对齐程度。
  • 干预手段包括：在 special token 上加对齐视觉路径 $z_i^{(\gamma)}=\tilde{s}_i+p_i+\gamma\tilde{v}_i$；使用 RoPE 锚定索引建立稳定的一对一 special-token 到 patch 对应；仅改变反向路由（保留/打乱/阻断）而保持前向计算不变的诊断实验。
  • 冻结编码器 + ridge 探针评估当前状态、未来位移、未来动作与物体中心几何的可线性解码性，并报告协方差有效秩（effective rank）。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（四个 suite）与 LIBERO-PRO（五类扰动族：语言、位置、物体、任务、环境）。
  • 真实机器人数据：398 条训练演示，覆盖三个任务；配对盲评共 28 个 block、420 次试验。
  • 基座模型：在匹配 LIBERO 演示上微调预训练的 π0.5 checkpoint；另做 SmolVLA 复现实验。
  • 变体配置：原生 M=16 special-token 接口、M=N=256 special-token 对照（含锚定索引变体）、vision-token 接口，以及 shuffled-future vision-token 对照。
  • 训练资源：VLA 策略训练使用 NVIDIA RTX PRO 6000 GPU；受控模型与辅助训练使用 NVIDIA RTX 3090 GPU。
Card 06 评估与结果

评估与结果

  • 受控预测分析（RQ1）：vision-token 预测能捕捉场景特定变化，关闭整图差距的 45.0%、运动像素差距的 56.4%；special-token 预测近似"复制当前观测"。
  • 表征探针（RQ1）：vision-token 特征在空间尾部集合上仍支持线性解码，未来动作读出达 R²=0.612；special-token 视觉流与 special-token 流均无法可靠恢复该信息，且有效秩更低。
  • 路由干预（RQ2）：加入对齐路径可将 special-token 表征从低秩近复制解中救出；仅修正注意力反向路由能改善预测与秩，但无法恢复动作迁移。
  • 仿真鲁棒性（RQ3，3 个种子均值±标准差）：Vision-token 取得最佳标准成功率 94.7±1.9、位置偏移 60.9±1.0、LIBERO-PRO 均值 66.3±0.6、保留率 0.696，优于 action-only 基线（92.3 / 48.8 / 59.5 / 0.635）。
  • 对照结论：M=N=256 仅匹配 token 数与粒度收益有限；锚定索引变体显著改善位置偏移（54.5±2.4）与整体扰动（63.5±1.1），但仍低于 vision-token；打乱未来的 vision-token 对照失去增益（位置偏移 42.8±6.3，保留率 0.635）。
  • 真实机器人：所有预测变体在相机模糊下均优于基线，vision-token 预测取得最高池化 OOD 成功率与最大未见锅具布局提升；位移读出与位置偏移成功率相关（r=0.82）。
