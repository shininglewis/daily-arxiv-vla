Card 03 核心贡献

核心贡献

  • 提出面向 WAM 的解耦原则：识别视频隐变量中语义与物理的纠缠是现有 WAM 的根本局限，阻碍动作生成同时区分高层任务规划与细粒度物理状态迁移。
  • 提出 PrismWAM 架构：基于 Mixture-of-Transformers（MoT），由 RGB 语义规划器引导基于深度的物理 rollout，并设计稠密深度监督 + 稀疏 RGB 目标监督的学习流程，推理时无需显式预测 RGB 目标帧。
  • 提出链式注意力（Chain Attention）结构化掩码，定向控制 RGB、深度、动作三路 token 的信息流，保证动作只通过演化中的深度特征获得物理信息。
  • 验证强性能与数据效率：无任何具身动作预训练、无额外数据增强，在仿真与真实世界均取得强操作性能，甚至超越 OpenWAM-α 等大规模具身动作预训练模型。
  • 提出范式转变：把世界动作模型从建模“世界看起来如何”转向建模“世界如何响应动作”，为以占据、光流、触觉、本体感知等为基础的以动作为中心的世界模型铺路。
Card 04 方法描述

方法描述

  • 问题建模：将策略写成对未来世界状态轨迹的边缘化积分 π(a\|x0,c)=∫p(a\|x1:F,x0,c)·p(x1:F\|x0,c)dx，再进一步分解为语义规划、物理 rollout、可执行动作三层。
  • 双流非对称时序监督：RGB 流用稀疏监督预测单张目标未来帧（学习任务语义）；深度流用稠密监督预测深度序列 d1:F（提供引导动作的中间空间状态）。
  • 主干与模块：基于预训练视频骨干 WAN，RGB 与深度共享视觉 block、各自保留模态相关的输入/条件/输出投影；动作塔独立参数化；冻结的 RGB/深度 VAE 与 T5 文本编码器；交叉注意力注入语言指令与本体感知上下文。
  • 链式注意力：未来 token 可读观测 token，反之不可；深度 token 仅额外读取观测 RGB token；动作 token 读取动作自身与观测/未来深度 token，完全不接触 RGB；各分支使用独立噪声等级嵌入。
  • 训练策略：深度 VAE 由 Wan VAE 初始化并在 2300 小时深度数据上预训练；策略训练分两阶段——先在深度空间适配 WAN 骨干，再联合优化 RGB 流、深度流、动作塔与条件投影。
  • 优化目标：联合 flow matching 损失 L = L_R + L_D + L_A，各模态独立采样噪声与噪声等级，仅在预测目标上加高斯扰动。
  • 推理：RGB 流只编码一次历史观测并缓存特征，不生成未来 RGB 帧；未来深度隐变量与动作块从高斯噪声联合去噪，可解码深度序列用于可视化但非必需，执行动作前缀后重规划。

Card 06 评估与结果

评估与结果

  • 评估设置：覆盖分布内操作（LIBERO）与分布外迁移（RoboTwin C2R、LIBERO-Plus、LIBERO-Pro、RoboDojo），并做真实世界验证；对比 starVLA、FastWAM（无动作预训练）、π0.5、OpenWAM-α（有动作预训练）、X-WAM、Spatial-Forcing、4D-WAM（引入空间信息）等。
  • 主要指标：任务成功率（%）、RoboDojo 的 Score（/100）与成功率（SR, %），LIBERO-Plus/LIBERO-Pro 按扰动维度（相机、机器人、语言、光照、背景、噪声、布局、物体、位置、语义、任务、环境）分组统计。
  • RoboTwin-C2R：随机场景成功率 53.16%，较 starVLA（3.16%）提升 50.00 pp，较 FastWAM（1.90%）提升 51.26 pp；clean/random 平均 70.57%，超过预训练 OpenWAM-α 的 69.05%；放大版 PrismWAM\* 达 83.67%。
  • LIBERO：总体成功率 99.35%，优于 4D-WAM 的 98.60%；LIBERO-Plus 总体 79.44%（OpenWAM-α 68.79%、FastWAM 52.56%），布局扰动下 81.70% 对 77.38%；LIBERO-Pro 物体属性变化下 88.65%，优于 OpenWAM-α 84.45% 与 FastWAM 73.00%。
  • RoboDojo：PrismWAM\* 总分 36.23（成功率 29.30），较 G0.5（20.23）高 16.00 分、较 Xiaomi-Robotics-1（20.07）高 16.16 分；Precision 任务上 PrismWAM 19.50% 对 OpenWAM-α 9.25%，PrismWAM\* 达 31.08%。
  • 鲁棒性（RQ2）：在 Metric Jitter、Edge Missing、Patch Hole 三类递进深度损坏下，最强损坏等级平均性能仅下降 2.45 pp。
  • 消融（RQ3）：去掉 RGB 流或深度流均降低干净场景与迁移表现（平均从 70.75% 降至 59.60%/42.70%）；允许观测 RGB 直连动作提升干净成功率但削弱迁移（64.70%）；将未来 RGB 暴露给深度流同样降低迁移（68.50%）；去掉未来 RGB 监督降至 66.50%，去掉深度单独训练阶段降至 57.00%，验证各设计互补且需协同工作。
