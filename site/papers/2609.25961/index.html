Card 03 核心贡献

核心贡献

  • 固定动作接口：提出信息保持的无参数编解码器，把连续动作表示为视觉空间 token，无需任何可训练的动作头或动作专用输出投影。
  • 视觉与动作联合预测：用共享的 DiT 与联合 flow-matching 目标同时去噪未来图像 token 与动作 token，并设计显式的条件前缀与注意力结构。
  • 匹配的双专家对照实验：在相同数据与优化设置下，与附加 0.64B 参数动作专家的双专家控制模型对比，证明去除专用动作通路仍能有效控制。
  • 多基准实证评估：覆盖 5 个评测设定，涵盖操作任务与扰动鲁棒性，在 RoboTwin 2.0、LIBERO、LIBERO-Plus、RoboDojo 上给出结果。
Card 04 方法描述

方法描述

  • Action-as-Patch（AP）编解码器：给定复制因子 \(r=\lfloor D/A\rfloor\)，把每个动作分量重复 \(r\) 次并零填充至维度 \(D\)；解码时对每组副本取均值，等价于编码器的 Moore–Penrose 伪逆，因此是精确左逆、无需重建损失。
  • 联合去噪：动作 chunk 与未来帧 token 共享同一噪声水平 \(\sigma\)（噪声实现相互独立），由单个 transformer 预测两组 token 的速度 \(v_\theta^x\)、\(v_\theta^u\)。
  • 训练目标：以 \(\lambda_x=0.5\)、\(\lambda_u=1.0\) 加权两组 MSE，采用 shift 后的噪声调度 \(s=5\) 与峰值在 \(\sigma=1/2\) 的权重 \(w(\sigma)\)；动作项仅在有效步上平均。
  • 注意力与位置编码：条件前缀（语言 + 本体状态 + 当前观测）只注意前缀；未来帧与动作 token 互相注意并注意前缀，用四轴位置坐标以值 10/0/20 区分 token 组。
  • 推理：从纯高斯噪声初始化联合潜变量，用 Euler 法沿 \(K=10\) 步调度积分，固定解码器还原动作 chunk 后回退时域执行，无需把未来帧潜变量解码为 RGB。
  • 骨干与文本编码器：基于 FLUX.2 [klein] 4B Base 与 ImageWAM 代码库；文本编码器在 RoboTwin/LIBERO 上用 Qwen3-4B，在 RoboDojo 上用带 LoRA 的 Qwen3-VL-4B-Instruct。
Card 05 数据集与资源

数据集与资源

  • 数据集/基准：RoboTwin 2.0（50 个双臂任务）、LIBERO（4 个套件各 10 任务）、LIBERO-Plus、RoboDojo（42 个仿真任务、5 个能力维度）。
  • 训练数据协议：全量数据协议（每任务 50 clean + 500 randomized 演示，7 个低成功率任务额外加 2100 条增强演示）；clean-to-random（C2R）协议仅用每任务 50 条 clean 演示。
  • 模型规模：骨干为 FLUX.2 [klein] 4B Base；对照的双专家控制在同一骨架上增加 0.64B 可训练参数的动作专家；RoboDojo 上文本编码器 LoRA 增加 132.1M 可训练参数。
  • 输入配置：RoboTwin 三视角合成为 288×256 图像，动作/本体状态 14 维；LIBERO 两视角合成 224×448，动作 7 维；RoboDojo 保留三个独立 256×256 视角。
  • 训练细节：全局 batch size 为 256（LIBERO 为 128，匹配对照为 64），动作在 RoboTwin/RoboDojo 用 z-score、LIBERO 用 min–max 归一化；评估统一用 \(K=10\) 求解步。
Card 06 评估与结果

评估与结果

  • 评估协议：RoboTwin 2.0 全量数据与 C2R 评测每任务每场景 100 回合（共 10,000 回合）；匹配对照为每检查点 1,000 回合；指标为成功率（SR），RoboDojo 额外报告 Score。
  • RoboTwin 2.0 全量数据：平均成功率 96.12%（clean 96.04%，randomized 96.20%），优于最强基线 MotuBrain 的 95.94%，clean 与 randomized 场景差距仅 0.16 个百分点。
  • Clean-to-Random 泛化：平均 79.14%（randomized 66.72%，clean 91.56%），平均值为所列方法最高；randomized 场景略低于 GigaBrain-0.7（67.90%）与 OLA-Sem（67.56%），但比 WAM SoTA 4D-WAM 的 41.80% 高出约 25 个百分点。
  • 匹配双专家对照：41,940 次更新后 PatchWAM 平均 88.0% vs 对照 78.4%，提升 9.6 个百分点，且可训练参数更少；PatchWAM 学习更快（20k 更新达 60.7%，对照需 30k 才达 60.4%）。
  • 其他基准：LIBERO-Plus 上达到 91.8% 成功率（使用增强训练）；LIBERO 与 RoboDojo 结果进一步刻画了模型的能力与局限。
  • 代价与局限：因图像与动作潜变量在每个去噪步都被更新，参数减少并不意味着推理延迟降低；作者也指出匹配对照同时改变了 token 交互与参数化方式，收益不能归因于单一因素。
