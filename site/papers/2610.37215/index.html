Card 03 核心贡献

核心贡献

  • 提出 R2A 框架：将成功示范离线组织为时空运动基元图，用纯运动学几何（位姿、状态、帧间变化）建模，完全绕开脆弱的视觉特征。
  • 设计查询依赖的图神经网络（query-dependent GNN）检索器：以机器人当前运动轨迹为查询，在图中动态定位执行进度，并召回结构兼容的未来运动基元。
  • 引入基于扩散的初始状态矫正模块：在回合开始时把 OOD 初始关节配置投影回训练流形，避免视觉-本体感知对齐在开始时就已经失效。
  • 提出动作协调（Action Harmonization）模块：用学习到的逐维度门控矩阵将检索到的几何先验与冻结 VLA 的预测残差式融合，仅修正空间位姿、不改动夹爪离散指令。
  • 在三种 SOTA VLA（GR00T N1.7、π0.5、StableVLA）上验证，仿真基准绝对成功率最高提升 +12%，真实世界部署最高提升 +40%，且无需微调基座策略。
Card 04 方法描述

方法描述

  • 运动基元图构建：节点编码片段运动学 norm(q_v, δq_v, γ_v) 与相对时间位置的正弦位置编码 PE(s̄_v)，并附带任务标签 y_v 与进度分数 p_v∈[0,1]；边分为时序边（同一示范内 t → t+Δ，Δ∈{2,4,6,8}）与空间边（跨任务连接末端执行器几何距离低于阈值的节点），形成跨任务的拓扑捷径。
  • 扩散式初始状态矫正：用条件扩散模型 M_φ 学习有效初始构型分布，以任务指令 ℓ 为条件训练噪声预测网络（MSE 噪声预测损失），推理时从高斯噪声反向采样得到 q₀^rect，再生成刚体矫正轨迹从 q₀^OOD 过渡到该状态。
  • 查询依赖 GNN 检索：查询 Q_t = Encoder([A_t^{π,pose} ‖ x_{t-H:t} ‖ A_{t-H:t}^{exec}]) 融合 VLA 预测与近期状态历史；消息传递与节点更新均以 Q_t 动态调制（而非静态聚合），输出全图相关性分布 w_v。
  • 边缘化与重排序：对 w_v 求期望得到任务分布 ŷ_t 与进度估计 p̂_t，构造上下文感知查询 Q̃_t；用余弦相似度加任务/进度偏置项打分，取 Top-K 节点并以温度 τ 的 softmax 权重加权融合示范动作为 A_t^ref。
  • 训练目标：GNN 采用排序式对比学习——对时序近邻与几何近邻为正样本集 P_u、其余为负样本集 N_u，损失为 BCE 与 ranking loss 的加权组合 L = αL_BCE + (1-α)L_RANK（缓解目标稀疏导致的梯度消失）。
  • 动作协调：门控 S_t = σ(MLP([Q_t ‖ A_t^{π,pose} ‖ A_t^ref])) ∈ [0,1]^{C×6}，执行动作 A_t^{exec,pose} = A_t^{π,pose} + S_t ⊙ (A_t^ref − A_t^{π,pose})，夹爪指令保持原样；训练时向查询注入噪声 Q̃_t = Q_t + ε 以模拟感知扰动，用 MSE 对齐真值示范动作。
  • 训练流程：顺序训练——先基座 VLA，再 GNN，最后协调 MLP（此时 VLA 与 GNN 均冻结）。
