PRISM: Primitive Routing via In-context Skill Mixing for Retentive VLA Adaptation

2026-11-06 · 原文 · 翻译 · 2611.08917

论文研究 Vision-Language-Action（VLA）模型在机器人操作中的技能保留（skill retention）与长程组合（long-horizon composition）问题。 标准做法通常将新任务吸收到共享参数中，导致已学技能难以定位、后续训练干扰旧技能，并在组合任务中无法按阶段调用已掌握的子技能。 作者发现逐技能 LoRA 更新并非无序分布，而是占据可区分、可复现的低维子空间；组合任务 LoRA 约 56% 的 Frobenius 能量落在该子空间中，而随机旋转控制接近 0%。 基于此提出 PRISM，将可复用技能表示为参数级“原语”，通过技能原语库、逐 chunk 路由器和确定性动作标签 oracle 实现技能保留与组合。

Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action（VLA）模型在机器人操作中的技能保留（skill retention）与长程组合（long-horizon composition）问题。
  • 标准做法通常将新任务吸收到共享参数中，导致已学技能难以定位、后续训练干扰旧技能，并在组合任务中无法按阶段调用已掌握的子技能。
  • 作者发现逐技能 LoRA 更新并非无序分布，而是占据可区分、可复现的低维子空间；组合任务 LoRA 约 56% 的 Frobenius 能量落在该子空间中，而随机旋转控制接近 0%。
  • 基于此提出 PRISM，将可复用技能表示为参数级“原语”，通过技能原语库、逐 chunk 路由器和确定性动作标签 oracle 实现技能保留与组合。
Card 03 核心贡献

核心贡献

  • 结构性发现：逐技能低秩更新形成近似 N 维、语义聚类的子空间，且可跨独立训练 checkpoint 复现；组合任务更新显著对齐该子空间。
  • 框架贡献：提出 PRISM，包含技能原语库、技能特定残差适配器、VLM prefix 条件路由器，以及确定性动作派生标签器。
  • 训练机制：组合训练阶段冻结每个技能原语，仅更新视觉编码器、语言 LoRA、技能残差、路由器、动作投影和时间 MLP，从结构上避免“原语坍缩”。
  • 实验贡献：在 RoboCasa365 上同时提升原子技能成功率和长程组合任务成功率，并在 AgileX PIPER 真实机器人上验证。
Card 04 方法描述

方法描述

  • 使用 π0.5 作为 VLA 主干，包含视觉编码器、语言模型和小型动作专家；动作专家输出 H=10 的动作 chunk，每次执行 5 步后重新规划。
  • 技能原语库：每个原子技能学习一个秩为 32 的动作专家 LoRA 原语 P_i = B_i A_i，各原语参数块互不共享，并在第一阶段后冻结。
  • 技能残差：组合训练时为每个技能增加秩为 10 的残差 R_i = D_i C_i，初始化为零，从而初始不改变原语分支输出。
  • 路由器：在每个动作 chunk 边界读取 VLM prefix 表示 h_t，经 LayerNorm 和两层 MLP 后 softmax，输出对原语–残差分支的混合权重 α(t)。
  • 标签 oracle：使用任务身份和演示动作中的夹爪开合事件生成逐帧技能标签，为路由器提供逐 chunk 交叉熵监督。
  • 激活空间组合：注意力投影中混合 P_i x + R_i x；FFN 中先计算每个技能分支的完整 FFN 输出再混合，避免不同 LoRA 因子相乘产生跨技能项。
  • 两阶段训练：第一阶段用原子演示和 one-hot 路由学习原语；第二阶段冻结原语，在组合演示与原子 replay 上训练残差、路由器和共享适配模块，损失为流匹配损失加 0.05 × 路由交叉熵。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboCasa365。
  • 原子数据：3,016 条人类演示，覆盖 28 个任务；包括 Pick & Place 18 任务/1,939 条、Turn Lever 3 任务/322 条、Close 7 任务/755 条。
  • 组合数据：415 条演示，覆盖 LoadDishwasher、SnackSorting、ThawInSink、WashLettuce 四个组合任务。
  • 第二阶段加入每个原子任务 20 条 replay，共 560 条，总计 975 个 episode、454,758 帧。
  • 真实机器人：AgileX PIPER 6-DoF 机械臂，每个任务采集 20 条遥操作演示，每个任务评估 20 次。

Card 06 评估与结果

评估与结果

  • 仿真基准为 RoboCasa365；原子成功率为 28 个原子任务的宏平均，每任务 20 次试验；组合成功率为 4 个组合任务的宏平均，每任务 100 次试验。
  • PRISM 达到 56.43% 原子成功率与 20.00% 组合成功率。
  • 标准 π0.5-LoRA 两阶段微调为 17.86% 原子成功率与 17.50% 组合成功率；PRISM 分别提升 38.57 和 2.50 个百分点。
  • 相比带 replay 的 LoRA 基线（49.82% 原子、10.25% 组合），PRISM 分别提升 6.61 和 9.75 个百分点。
  • 标准两阶段 LoRA 使原子成功率从 48.04% 降至 17.86%；PRISM 则从第一阶段 50.71% 提升至组合训练后的 56.43%，同时原语参数保持冻结。
  • 消融结果：运动学 oracle 20.00%，优于 MLP oracle 13.75% 和 Qwen2.5-VL oracle 11.25%；VLM prefix 路由 20.00%，优于仅视觉 10.25% 和仅状态 7.50%；激活空间软组合 20.00%，优于硬 one-hot 10.50%、参数空间软混合 15.50% 和动作空间软混合 13.50%。
  • 真实机器人实验在 AgileX PIPER 上验证了组合任务 rollout；但提供的 HTML 原文在真实机器人结果表处被截断，具体数值未能完整获取。
