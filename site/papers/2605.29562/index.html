Card 03 核心贡献

核心贡献

  • 提出 VLA-Pro 框架：将任务经验存储为任务特定的 LoRA 适配器 与其对应的结构化程序性状态序列，构建可检索、可复用的记忆库
  • 设计 Action-Aware Procedural Matching 检索机制：根据当前动作类型动态调整各程序性字段（动作、物体几何属性、末端朝向、交互点）的相似度权重，实现更精准的记忆匹配
  • 提出 top-k 记忆融合与动态参数注入 机制：按语义相似度加权融合检索到的多个 LoRA 适配器，并在动作块执行后卸载融合适配器，保持策略稳定性
  • 在 RoboTwin、RLBench 和真实机器人 上跨多种骨干模型（X-VLA、RDT、π₀.₅）验证有效性，在未见任务上最高提升 207%，真实世界任务平均提升约 59 个百分点
Card 04 方法描述

方法描述

  • 程序性记忆存储（Procedural Memory Storage）：先在已见任务上联合微调获得共享基础 LoRA（Δθ_base），再为每个任务微调任务特定 LoRA，并以结构化程序性状态 z = {a, o, e, p} 描述执行阶段（动作类型、物体几何属性、末端朝向、目标交互点）
  • 跨任务记忆检索（Cross-Task Memory Retrieval）：使用强视觉语言模型（Gemini-3-Flash）作为程序性状态提取器，结合观测、完整指令和交互历史生成查询状态；随后通过基于文本嵌入的 动作感知加权余弦相似度 匹配记忆库，选出 top-k 最相关的源任务记忆
  • 记忆融合与适配（Memory Merging and Adaptation）：将检索到的任务 LoRA 按 Softmax 归一化相似度进行参数级加权求和，得到融合适配器 Δθ_fused，并临时加载到预训练 VLA 骨架上生成动作块，执行完卸载恢复原模型
Card 05 数据集与资源

数据集与资源

  • RoboTwin：训练集含 2 个官方任务 + 6 个新设计任务，测试集含 9 个新设计的未见任务，每个任务 50 条轨迹
  • RLBench：遵循 X-ICM 协议，18 个已见任务各 100 条专家演示，8 个源任务构建记忆库，评估全部零样本任务
  • 真实世界：UR7e 机械臂 + Robotiq 2F-85 夹爪 + RealSense D405 相机，6 个训练任务与 6 个对应未见测试任务，每任务 50 条人工示教

Card 06 评估与结果

评估与结果

  • RoboTwin 评估：每个任务 30 次试验，VLA-Pro 将 X-VLA 平均成功率从 17.0% 提升至 30.0%（↑76%），RDT 从 11.1% 提升至 34.1%（↑207%），π₀.₅ 从 40.4% 提升至 59.3%（↑47%）
  • RLBench 评估：每个任务 25 次试验，VLA-Pro（基于 π₀.₅）平均成功率 20.9%，超过 RDT（10.2%）、AtomicVLA（14.7%）和 π₀.₅ 基线（13.8%），在 close_fridge（40.0% vs 24.0%）等任务上显著领先
  • 真实世界评估：每个任务 20 次试验，以 π₀.₅ 为骨干，平均成功率从 5.8% 提升至 65.0%；在 place_bell_behind 任务上从 0.0% 提升至 100.0%，展示了有效克服高频执行偏差的能力
  • 消融分析：VLM-backbone 与 action-expert 组件的 LoRA 适配对已见任务互补；对未见任务，语义泛化需求高时 VLM-backbone 适配更关键，与训练模式高度相似的场景需同时适配两类参数以获得最佳精度
  • 检索有效性：验证 top-k 设置（RoboTwin 使用 k=1，RLBench 使用 k=2），记忆与当前任务越相似性能越好，扩展记忆库规模可进一步提升泛化能力
