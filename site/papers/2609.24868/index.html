Card 02 论文概述

论文概述

  • 论文提出 DualWAM，一种双系统世界动作模型（World Action Model, WAM），用于机器人操作中的异步全局规划与局部细化。
  • 核心目标是解决现有 WAM 因未来视觉预测计算昂贵而依赖长动作块，导致闭环响应性不足的问题。
  • 通过将世界-动作生成解耦为低频全局规划（System 2）和高频局部细化（System 1），在保留广视野世界-动作生成的同时实现高频闭环动作更新。
Card 03 核心贡献

核心贡献

  • 提出 双系统 WAM，将全局规划与局部细化分配到共享去噪轨迹的互补阶段。
  • 在更新频率、去噪状态和视觉观察空间三个维度对两个系统进行角色专门化，结合连贯的全局生成与高频闭环校正。
  • 设计 异步闭环执行 机制，使每个全局计划可复用多次局部更新，同时 System 1 反复融入最新腕部交互反馈。
  • 在 Franka 和 Galbot 上进行零样本真实机器人评估，验证双系统分解、局部世界-动作建模、异步执行和角色匹配辅助数据的有效性。
  • 展示该解耦设计支持 边-云部署，相比基线显著降低通信开销，并实现 16.6× 关键路径加速。
Card 04 方法描述

方法描述

  • System 2（全局规划）：周期性对更广的世界-动作块执行高噪声双向去噪，从纯噪声推进到中间阈值 τ，建立全局轨迹结构。
  • System 1（局部细化）：仅使用腕部观察的紧凑 WAM，从 System 2 的中间去噪状态中提取时间对齐的短窗口，结合最新腕部观测和机器人状态完成低噪声细化。
  • 两个系统沿 共享整流流去噪轨迹 异步运行：System 2 在后台更新部分去噪的全局轨迹，System 1 在每个局部控制更新中实时细化对齐窗口。
  • 关键技术包括：共享轨迹去噪与边缘时间步采样（4→1 步采样，2.27× 端到端加速）、三 GPU CFG 并行、异步模型执行、CUDA Graph 编译、混合精度量化（W8A8）等。
  • 训练时对 System 1 进行时间偏移增强，模拟 System 2 预测轨迹与实际执行状态之间的错位，提升异步执行鲁棒性。
Card 05 数据集与资源

数据集与资源

  • 使用自采集的 Galbot 机器人语料库，包含 43,058 个标注操作子任务，覆盖 74 个技能标签。
  • 辅助数据：约 1,800 小时 的第一人称（egocentric）人类交互视频用于训练 System 2；约 1,200 小时 的腕部中心 UMI 演示用于训练 System 1。
  • 评估任务：20 个未见真实机器人任务，其中 10 个在 Galbot G1 上，10 个在 Franka FR3 上（遵循 DROID 设置）。
  • 模型初始化：Galbot 实验中 System 2 从 Cosmos3-Nano 初始化，System 1 从 Cosmos3-Edge 初始化；Franka 实验中 System 2 从 Cosmos3-Nano-Policy 初始化。
  • 训练资源：10k 迭代，全局 batch size 1,024，使用 8 个节点，每节点 8 张 NVIDIA H200 GPU。
  • 推理优化实验使用 3 张 NVIDIA GeForce RTX 4090 GPU。
Card 06 评估与结果

评估与结果

  • 评估环境为 零样本真实机器人操作，指标包括任务进度、成功率（SR）、关键路径延迟和成功回合的平均任务完成时间。
  • DualWAM 在 Franka 上达到 54% 成功率，在 Galbot 上达到 45%，分别比最强基线 Cosmos3-Nano-Policy 高 5 和 4 个百分点，平均提升 4.5 个百分点。
  • 关键路径延迟仅 63 ms，相比 Cosmos3-Nano-Policy 的 1043 ms 实现 16.6× 加速；同时成功回合的物理完成时间也缩短（Franka 从 24.88 s 降至 21.76 s，Galbot 从 53.11 s 降至 48.67 s）。
  • 消融实验表明：双系统分解和局部世界-动作建模均至关重要；移除任一都会导致性能大幅下降。例如，System 2 only 成功率为 49%，System 1 only 仅 9%，Action-only DiT S1 为 7%，Fast-WAM S1 为 14%。
  • 异步执行相比同步执行将成功率从 39% 提升至 45%，关键路径延迟从 850 ms 降至 63 ms（13.5× 加速）。
  • 角色匹配辅助数据有效：联合使用 egocentric 和 UMI 数据将成功率从 45% 提升至 59%（提升 14 个百分点）。
  • 边-云部署下，DualWAM 相比 AHA-WAM 将下行负载和平均下行带宽降低 104.6×，10 GbE 传输边界降低 18.0×。
