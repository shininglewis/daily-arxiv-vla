Card 03 核心贡献

核心贡献

  • 提出 Discrete Forcing：先预测离散动作 token 建立粗粒度动作结构，再以其作为“scratchpad”初始化并引导连续动作的精细去噪。
  • 设计 部分共享的双分支 Action DiT：前若干层 Transformer 共享参数以学习通用动作特征，后续层与输出头分别专用于离散预测和连续精化，参数量与单分支 DiT 相当。
  • 实现高效推理：仅需 2 NFE（一次离散前向 + 一次连续前向）即可生成高质量动作，比 10 步连续基线动作生成快约 5×、端到端快 2×。
  • 通过多基准与真实机器人实验验证方法的有效性、可扩展性与泛化性，并展示模型容量增大时性能持续提升。
  • 提供对生成机制的深入分析，验证离散阶段能在早期形成全局动作结构（方向与轨迹几何）。
Card 04 方法描述

方法描述

  • 基础框架：基于条件流匹配（flow matching），连续分支学习从源分布到目标动作块的向量场，损失为 L_FM = E[\|\|f_θ(A^τ, o) - (ε - A)\|\|²]。
  • 离散表示：归一化动作块的每个标量被独立量化到 255 个动作 bin，加上特殊 [MASK] token 构成词表大小 K=256，通过可学习嵌入表映射为离散动作 token。
  • 连续表示：归一化动作块经 MLP 动作编码器投影为连续动作 token，两种表示共享相同隐藏维度。
  • 训练目标：

- 离散分支按 forcing level ρ 掩码部分 token，仅在掩码位置优化交叉熵 L_disc。

- 连续分支以离散引导源 S_t = (1-α)ε + αQ⁻¹(Z_t)（α=0.3）为起点，在源与目标间插值，优化流匹配损失 L_FM。

- 引入 单步重建目标 L_1step，使连续分支能一步从源状态直接恢复目标动作；总损失 L_cont = L_FM + λ_1step·L_1step（λ_1step=0.5，λ_disc=0.1）。

  • 架构细节：交错的自注意力与交叉注意力层，交叉注意力逐层注入 VLM 的视觉-语言特征；两个专用分支之间不进行交叉注意力通信，以保持分支专精。
  • 推理流程：从全 [MASK] 离散序列出发 → 离散分支一次前向 argmax 得到粗动作先验 → 反量化构造离散引导连续源 → 连续分支一次去噪得到最终动作块。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、RoboTwin 2.0、RoboCasa-GR1 三个仿真基准 + ARX LIFT2 真机实验；真机每任务 20 次独立试验，用 Task Progress 而非二值成功率衡量。
  • 主要指标：任务成功率（%）与真机任务进度；推理延迟包括动作延迟与端到端延迟的 P50/P95；NFE。
  • LIBERO 结果：平均成功率 97.6%，在相同 1.5B 参数与 2 NFE 预算下比 StarVLA 高 2.5 个百分点，且超过表中所有迭代生成方法（NFE>2）。
  • RoboTwin 2.0：平均成功率 59.32%（StarVLA 为 49.80%），且无需机器人特定预训练，展现强泛化与少样本能力。
  • RoboCasa-GR1：平均成功率 56.8%，比 StarVLA 高 12.9%，在比较方法中最优。
  • 推理效率：动作延迟 P50 24.91 ms（对比 StarVLA NFE=10 的 145.46 ms），端到端 P50 78.95 ms（对比 200.43 ms），动作生成加速约 5×、端到端超 2×，同时成功率更高。
  • 缩放行为：性能随模型规模单调提升且未饱和；1.0B 变体达到 47.96% 成功率，接近 5.5B 基线的 48.60%，且快 2.97×、参数少 81.8%。
  • 机制分析：DF@1 的全局方向相似度达 0.989，归一化轨迹形状误差 0.0399，优于 1–10 NFE 范围内的 StarVLA，说明离散预测能在早期捕获全局动作结构。
  • 消融实验：Discrete→Continuous 最优；Discrete→Discrete 降 1.6%，Continuous→Continuous 降 3.4%；去除离散引导源降 2.6%，去除单步损失降 1.8%，加入分支通信降 4.8%；使用预测离散源训练与真值源几乎一致（95.3% vs 95.2%）。
  • 真机结果：四个任务上均优于 OpenVLA-OFT 与 π₀ 基线，平均 Task Progress 74.9%，提升 16.4%，在动态跟踪与抓取任务上增益尤为明显。
