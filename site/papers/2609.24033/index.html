Card 03 核心贡献

核心贡献

  • 提出 Imagine-RL 框架，将动作条件化的视觉–力矩想象集成进轻量级潜在噪声 VLA 后训练流程。
  • 提出 VTLWM（Visual–Torque Latent World Model），一种视觉–力矩潜在世界模型，无需像素重建即可预测动作条件下的未来视觉与力/力矩特征，用于价值估计。
  • 设计残差置信度引导的交叉注意力 critic，利用上一预测窗口的残差生成 token 级置信先验，抑制不可靠的未来 token，同时保留观测历史与当前证据。
  • 在真实机器人上验证了世界模型预测质量、critic 判别能力和任务成功率三方面的收益。
Card 04 方法描述

方法描述

  • Latent-Noise VLA-RL：冻结的流匹配 VLA π₀ 通过潜在噪声输入解码动作块，仅学习轻量噪声 actor π_θ；动作 critic Q_a 评估解码后的动作块，噪声 critic Q_w 由其蒸馏得到，采用 SAC 式更新（多 Q 集成取均值）。
  • VTLWM：扩展 LeWorldModel，共享编码器融合多视角图像得到 z_t，与归一化力矩 τ̂_t、动作嵌入 e_t^a 拼接；历史长度 H=15，单步预测器自回归展开 H_f=10 个未来位置；损失为视觉 MSE + 力矩 SmoothL1 + SIGReg 正则项。
  • 置信度评估：以“历史实际特征 − 上一窗口预测特征”的残差计算相对误差 ρ，通过 α = max(α_min, e^{−βρ}) 得到生成可靠性置信度（α_min=0.05，β=1）。
  • 交叉注意力 critic：以当前 (o_t, a_t) 生成查询，对历史 token 与动作条件未来 token 做多头注意力；把 log α 作为注意力偏置，将内容相关性与预测可靠性结合；上下文与可靠性统计量拼接后送入 MLP critic 输出 Q 值。
  • 关键点：VLA 与 VTLWM 全程冻结，不做骨干微调，也不进行像素级规划。
Card 05 数据集与资源

数据集与资源

  • 真实机器人平台：PIPER 机械臂 + Intel RealSense D435i 相机（左右腕部 + 俯视三视角，RGB 缩放至 128×128）。
  • 四个接触丰富的双臂协作任务：Socket Plug-in、Press-button、USB Plug-in、Peg-in-hole（每任务含按压、抓取、再按压、推动等多阶段）。
  • 训练数据：每个任务基础的 π₀ 用 100 条轨迹预训练；RL 使用 50 条轨迹预热缓冲，之后每收集 10 条轨迹更新一次（共 10×5 次更新）。
  • 关键超参：动作块长度 H_a=30（执行前 H_q=10 步），世界模型历史 H=15、预测视野 H_f=10，视觉/力矩 token 维度 192/14，注意力宽度 256、4 头，Q 集成 10 个，batch size 64，折扣 0.999，学习率 5e-5 / 1e-4 / 3e-4。
  • 算力：2 张 NVIDIA RTX 3090 托管 VLA 服务端，1 张 RTX 3090 本地训练 RL 组件。
Card 06 评估与结果

评估与结果

  • 评估环境：真实机器人，四个任务各 50 次试验；对比基线为 π₀、TA-VLA、DSRL 与 Imagine-RL（相同预训练骨干与交互量）。
  • 主要指标：任务成功率、世界模型预测（视觉余弦相似度、力矩 MAE/MSE/RMSE）、critic 判别边际 ΔQ、共享候选动作选择。
  • 成功率：相比 DSRL 平均提升 23.6%，相比 VLA 基线（π₀、TA-VLA）提升 60%，且仅使用 100 条 RL 轨迹。
  • 世界模型：视觉潜在预测平均余弦相似度 0.913（各任务 0.955/0.915/0.881/0.901）；力矩预测平均 MAE 0.0441、MSE 0.0054、RMSE 0.073，MAE 仅约为最大力矩值（±4.3799）的 1.00%。
  • Critic 判别：四个任务上 ΔQ 分别为 0.996→1.367、0.474→0.512、0.876→1.279、1.552→1.754（DSRL→Imagine-RL），相对提升 37.2%、8.0%、46.0%、13.0%，说明 Imagine-RL 的 critic 更能区分成功与失败动作。
  • 额外交互实验：在 Press-button 任务上继续训练至 100 条在线轨迹（预热 50 条 + 10×10 次更新）时，成功率再增 +46%，表明方法可在少量 RL 试验内快速提升。
