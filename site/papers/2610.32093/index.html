Card 02 论文概述

论文概述

  • 论文研究如何用强化学习（RL） 作为“数据生成器”，而不是部署用的控制器，为下游视觉-运动模仿学习（behavior cloning）批量产出演示数据。
  • 核心问题：只用任务奖励训练出的 RL 策略会收敛到单一狭窄的解，即使增加 rollout 数量也不会扩大状态覆盖；而演示数据的覆盖度直接决定行为克隆的鲁棒性。
  • 论文提出 DiscoDemo，其思路是：如果让生成器自身发现多种成功的解题模式，这些模式的并集就能为下游 BC 提供更广的成功状态覆盖。
Card 03 核心贡献

核心贡献

  • 提出 DiscoDemo 框架：训练一个以特权状态（privileged state）为输入的潜变量条件（latent-conditioned）RL 生成器，使其同时具备任务能力与解多样性。
  • 设计并行反向课程（parallel reverse curriculum）：以少量人类演示的状态作为重置点，从轨迹末端逐步向前推进边界，从而在稀疏奖励下高效地引导策略学会解题。
  • 提出成功门控的多样性目标（success-gated diversity objective）：借鉴 METRA 的度量感知表示，对成功轨迹给予多样性奖励；实验证明若去掉成功门控，多样性奖励会压倒稀疏任务奖励，导致学不会任务。
  • 引入安全塑形（safety shaping）与安全过滤两阶段机制：惩罚非法接触与插入卡死力，并在导出前剔除物理上不可取的轨迹。
  • 在仿真与真实机器人上均取得最优的下游成功率，并证明其收益与 DAgger、DART 式的纠正数据采集互补。
Card 04 方法描述

方法描述

  • 问题设定：假设可访问带特权状态和状态重置的仿真器；下游策略只能观测 $o=h(s)$（视觉 + 本体感知）。每个任务给定少量人类演示 $\mathcal{D}_{\text{human}}$，既作为离线 RL 经验，也作为课程重置候选状态。
  • 生成器训练：用 FlashSAC 在大规模并行仿真中训练，每条演示分配一组并行环境和独立课程边界 $c_i$；当某组的成功率超过阈值 $p$ 时，边界后移 $\Delta_c$，半数演示推进到 $c_i=0$ 后全体切换到原始初始分布 $\rho_0$。
  • 多样性奖励：将策略扩展为 $\pi_{\text{Gen}}(a_t\|s_t,z)$，潜变量 $z\sim\mathcal{N}(0,I)$ 每个回合采样一次并固定；联合学习状态表示 $\phi_\psi(s)$，奖励为 $r_{\text{div}}=\langle\phi_\psi(s_{t+1})-\phi_\psi(s_t), z\rangle$。
  • 成功门控：最终奖励 $\tilde r_t = r_{\text{task}} + \alpha\, y(\tau)\, r_{\text{div}}$，其中 $y(\tau)\in\{0,1\}$ 表示轨迹是否完成任务，即只在成功轨迹之间鼓励多样性。
  • 安全项：$r_{\text{safe}}=\lambda_c C_{\text{contact}}+\lambda_j C_{\text{jam}}$，从总奖励中扣除，软性引导生成器远离非法接触与过大插入力。
  • 数据导出：冻结生成器，从 $\rho_0$ 采样初始状态并逐回合采样不同 $z$ 做 rollout，保留满足 $y(\tau)=1$ 且通过 $\mathcal{F}_{\text{task}}$ 安全检查的轨迹，渲染观测并与关节位置目标配对，形成静态数据集 $\mathcal{D}$。
  • 下游模仿学习：用标准行为克隆在 $\mathcal{D}$ 上最小化 $\ell_{\text{IL}}$，不使用特权状态与潜变量，训练期间不再与环境或生成器交互。
Card 05 数据集与资源

数据集与资源

  • 仿真环境：Isaac Sim，使用 Franka Research 3 机械臂复现四个真实桌面操作任务。
  • 任务：PnP-Banana（香蕉入碗）、StackCube（红方块叠蓝方块）、FMB-Round 与 FMB-SqCircle（Functional Manipulation Benchmark 的两种销钉插入），均随机化初始物体位姿；回合时长为 30 s（前两者）和 20 s（插入任务）。
  • 数据规模：人类演示 H20（20 条）；所有生成式方法统一提供 3,000 条成功演示，采集自左肩相机与腕部相机。
  • 下游模型：在 DROID 数据集上预训练的 π0.5 流匹配视觉-语言-动作（VLA）模型，采用关节空间动作控制，各数据源使用完全相同的微调配方。
  • 训练资源：生成器训练与 rollout 在大规模并行仿真中进行，实验中 GPU 成本按单卡单进程归一化统计；PLD、ExpertGen 因反复调用视觉行为先验而显著更慢。原文可见部分未给出具体 GPU 型号与参数量。
Card 06 评估与结果

评估与结果

  • 评估设置：仿真中每个策略用 3 个微调种子 × 每种子 50 回合评估；真机取第一个种子、每任务 20 次试验，零样本部署。指标为成功率（SR）与成功回合的平均完成时间（Time）。
  • 对比基线：H20、运动规划 MP（CaP-X 风格）、MimicGen、PGDG、PLD、ExpertGen、P-RFCL（DiscoDemo@α=0，即无多样性的并行 RFCL），以及纠正式数据采集 DAgger、DART。
  • 主要结果：任务平均下游成功率在仿真中由最强基线的 40% 提升到 62%，在真机上由 39% 提升到 78%；最大单任务增益为仿真 FMB-Round 的 23 个百分点、真机 PnP-Banana 的 45 个百分点，且完成时间接近最高效的 RL 基线。
  • 数据分析：用 PGDG 的轨迹表示 + RBF 核 + Vendi score 量化多样性/覆盖度，DiscoDemo 平均多样性最高、覆盖最广；数据集级覆盖度比固定场景多样性更与下游成功率相关。
  • 生成质量与成本：在追求多解的同时仍保持高生成成功率、短回合长度与较低端到端 GPU 小时成本，说明多样性并非来自无约束探索或额外失败模式。
  • 多样性强度消融：随 $\alpha$ 增大解模式更分化，但下游成功率在中等 $\alpha$ 处达到峰值（主实验统一取 $\alpha=0.3$，各任务最优值在 0.1–1 之间），说明目标不是最大多样性而是“仍能成功的广覆盖”。
  • 安全消融：单独塑形无法消除所有不良成功轨迹；过滤带来更大降幅，两者结合在两个任务上取得最低非法接触（PnP-Banana 21.3→6.8 N·s，FMB-SqCircle 73.0→1.2 N·s），并使成功轨迹的过滤通过率从 31%/24% 提升到 50%/46%。
  • 生成器训练效率：P-RFCL 与 DiscoDemo 因使用轻量特权状态策略并依赖海量并行仿真，训练完成速度快于依赖视觉先验的 PLD 与 ExpertGen；多样性目标带来一定额外开销，但相对差距很小。
  • 互补性：DAgger 与 DART 能显著提升 P-RFCL，对 DiscoDemo 也带来进一步提升，且 DiscoDemo 在同等纠正下仍更强，说明扩展成功行为覆盖与纠正式采集针对的是不同覆盖维度。
