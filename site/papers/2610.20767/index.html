Card 03 核心贡献

核心贡献

  • 系统比较 BSFs 与 SAEs，BSFs 更好地捕捉感知、语言、本体感觉、任务状态和情节进展等计算几何。
  • 通过多层次的精细转向（语义、视觉、几何）因果验证特征，实现目标对象重定向等行为的精确控制。
  • 基于特征的数据归因，针对失败恢复行为，仅遮蔽约 1.4% 的微调 token 即可显著抑制该行为。
  • 提供迄今最大规模的未池化 VLA token 激活语料（约 5200万），并强化 SAE 基线以公平评估多维特征。
Card 04 方法描述

方法描述

  • 使用块稀疏特征器（BSF），将每个特征表示为低维子空间（块），通过组稀疏性选择激活块。
  • 采用 Vanilla BSF 和 Fisher 加权 BSF，后者利用 Fisher 矩阵加权重建误差以更好地保持动作似然。
  • 与 SAE（b=1 的特例）在相同数据管道和预算下对比，仅块维度不同。
  • 通过激活修补和自动搜索特征集，评估开环和闭环转向效果，并用于数据归因。
Card 05 数据集与资源

数据集与资源

  • 训练激活语料：约 52M 个未池化 token 激活，来自 45,344 个 episode。
  • 评估模型：MolmoAct2、π0.5、MolmoBot 等 VLA 模型。
  • 行为塑造使用 DROID 数据集进行微调。
  • 模型参数量和训练资源（如 GPU 数量）未在文中明确说明。
Card 06 评估与结果

评估与结果

  • 评估环境：开环转向（52 个场景-指令对）和闭环真实机器人任务。
  • 主要指标：激活重建 R²、动作似然变化、任务变量可解码性、每特征因果效应、转向恢复率、任务成功率。
  • 关键结果：BSF 在重建和行为保持上优于 SAE；几何转向单个 BSF 块达 99.7% 恢复；闭环语义重定向中 BSF 选对目标 100%，任务完成 93.3%（SAE 为 75.0%）；遮蔽 1.38% token 使失败恢复重新打开时间从 1.89s 增至 14.25s。
