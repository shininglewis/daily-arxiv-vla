Card 02 论文概述

论文概述

  • 论文提出 Bridge3D，一个分层式 3D 增强框架，让预训练的 2D VLA（Vision–Language–Action）模型能够在 3D 空间中"看见"并"行动"。
  • 指出当前 VLA 模型主要基于 2D 观测训练，存在 3D 感知到动作的鸿沟：感知端缺乏空间几何信息，动作端缺乏显式几何引导。
  • 目标是同时引入隐式空间先验与显式几何引导，弥合高层空间理解与底层机器人精细控制之间的差距。
Card 03 核心贡献

核心贡献

  • 提出 Bridge3D 分层 3D 增强框架，修复预训练 2D VLA 模型中被截断的空间通路，统一隐式空间先验与显式 3D 几何引导。
  • 提出两种协同策略：Implicit Fusion（IF） 用轻量残差适配器将 3D 基础模型先验融合进 2D 视觉 token；Explicit Conditioning（EC） 将原始场景几何保留在 3D 语义场中，直接引导细粒度动作生成。
  • 引入逐层线性探测（layer-wise linear probing），自适应地仅在关键层（#7–11）注入显式几何条件，在不损害模型内在去噪能力的前提下提升空间智能与学习效率。
  • 在 RoboTwin 2.0 仿真基准与真实世界任务上取得 SOTA，并显著提升数据效率（少用约 6.1 倍训练样本即可达到可比性能）。
Card 04 方法描述

方法描述

  • Implicit Fusion（IF）：采用双流 token 编码，语义流用预训练 VLM 编码器提取高层语义 token，几何流用冻结的 VGGT 3D 几何基础模型提取几何 token；通过两层 MLP 残差适配器将几何特征映射到 VLM 潜在空间，做逐 token 残差融合（z_fuse = z_VLM + Γ(z_3D)）。
  • Explicit Conditioning（EC）：构建 3D 语义点场 F = {(p_i, f_i)}；用 Grounded-SAM 生成实例掩码（只保留机器人与被操作物体），DINOv3 提取稠密特征图，并遵循 D³Fields 将 2D 特征提升到 3D，最终点表示降采样为操作点 1,536 个、背景点 256 个。
  • 3D 条件化动作生成：双臂动作隐状态经 FiLM（由末端执行器嵌入调制）拆分为左右两流；对注意力 Q/K 施加 3D RoPE（末端执行器坐标与场景点云坐标），再通过空间交叉注意力让动作隐状态查询 3D 场点，将动作生成锚定在度量 3D 工作空间中。
  • 逐层线性探测：冻结 VLA 骨干，在 RDT 的每个扩散块隐状态上训练线性岭回归预测机器人末端 3D 坐标；发现误差在 #7 到 #11 层急剧上升，据此仅在第 #7–11 块插入空间交叉注意力模块。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin 2.0（大规模双臂操作仿真基准，含 50+ 协作任务），实验选取 10 个代表性任务；每任务使用 50 条干净场景演示，评估 100 次。
  • 真实世界：6 个桌面精细操作任务（Insert Flower、Hang Mug、Put Object Cabinet、Sweep Trash、Place Cup Rack、Clear Trash），每任务采集 100 条演示。
  • 骨干模型：RDT（RDT-1B，扩散基础模型）与 GR00T-N1.5；对照基线包括 π0、Spatial Forcing、PointVLA、3D Diffusion Policy 等。
  • 机器人平台：KEENON XMAN-R1 双臂人形机器人（1 个 Intel RealSense D435 头部相机 + 2 个 D405 腕部相机）；空间泛化实验使用 AgileX PiPER 机械臂（2 个 D435）。
  • 训练资源：4 张 NVIDIA RTX 4090 GPU（AdamW，学习率 1e-4）；真实世界推理在单张 RTX 4090 工作站上执行。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 仿真（clean / randomized 两种场景）+ 真实机器人实验；主要指标为任务成功率（Success Rate, SR）。
  • 仿真主结果：RDT-Bridge3D 与 GR00T-N1.5-Bridge3D 相对各自骨干分别提升 26.1% 与 34.6%；clean 场景下 RDT-Bridge3D 平均成功率 84.8%，超过 3D Diffusion Policy（82.8%）、Spatial Forcing（77.1%）和 PointVLA（76.0%），最高领先 8.8 个百分点；randomized 场景相对提升 28.7% 与 54.7%，显著优于 Spatial Forcing 的 9.5%；整体较 π0 高出 14.0 个百分点。
  • 数据效率：在 *Grab Roller* 任务上约 6.1 倍更少训练样本即达到 74% 成功率，50 条演示下达 98%。
  • 消融实验：基线（w/o IF & EC）平均 78.8%；仅 IF 为 90.4%，仅 EC 为 92.0%，二者结合达 95.6%（相对提升 21.3%），说明 IF 与 EC 互补；EC 插入位置在第 #7–11 层时最佳（79.4%）；移除逐点语义特征会使功能性操作任务下降 8.0%，而引入 PointNet++ 编码器反而损害性能，说明保留原始场景几何更有利。
  • 真实世界主结果：RDT-Bridge3D 平均成功率 49.0%，较 RDT 骨干（34.3%）相对提升 42.9%，超过 Spatial Forcing（37.3%）达 11.7 个百分点；在 *Insert Flower* 等厘米级精度任务上成功率接近翻倍。
  • 空间泛化：在 Click Bell 任务上引入训练时未见的 1cm / 3cm / 5cm 桌面高度偏移，Bridge3D 性能下降远小于 2D VLA 基线 RDT，表现出更强的 3D 空间鲁棒性。
