论文概述

Card 03 核心贡献

核心贡献

  • 量化并定位瓶颈：设计“特权物体直接移动”诊断实验，把模型决策能力与机械臂执行能力分离，证明瓶颈主要是物理执行，而非任务推理。
  • 任务无关的框架设计：Auriga 不含任何任务特定代码、提示或启发式规则，也不访问仿真器特权状态；同一套代码与提示覆盖全部任务和随机化布局。
  • 显式任务信念与证据记录：模型维护紧凑可修正的 task belief B_t（含 plan、attention、ledger 三类前提状态）与上下文外的 evidence record E_t，在长程任务中避免丢失目标或把“已下达指令”误当作“已验证结果”。
  • 单一准入网关 + 预览–执行–验证闭环：所有物理动作（直接工具调用或模型生成的 Python 程序）都必须经过 admission gateway 𝒜，在执行前可视化轨迹预览，在执行中按模型自设容差检查，越界即停机并返回含实测偏差的回执，支持原地恢复。
  • 跨任务工具演化方法论：把 13 次开发迭代（#0–#12）定位为 RSI 的 L3–L5 层级（跨任务经验与工具演化），而非 L0–L2 的任务内试错调参；评估时框架完全冻结。
Card 04 方法描述

方法描述

  • 三层职责分离：Cortex（单一持久模型会话，负责全部任务决策）、能力层（通用测量/动作/计算/回忆工具）、准入网关 𝒜（唯一通向机器人的通道）。
  • 闭环形式化：决策 $u_t \sim \pi_\theta(\cdot \mid g, B_t, E_t)$；深思型调用不改变世界状态，物理型调用经 $\mathcal{A}$ 返回 $(s_{t+1}, r_t, o_{t+1})$。
  • 预览机制：仿真暂停时，网关将多阶段双臂序列规划为轨迹预览，给出路径、步代价与碰撞/间隙告警，模型在执行前即可看到完整路线。
  • 验证机制：每阶段设目标 $\hat{x}_k$ 与模型自选容差 $\tau_k=(\delta_p,\delta_\theta)$，执行中测量 $x_k$，当 $\epsilon_k = x_k-\hat{x}_k$ 超出 $\tau_k$、夹爪开合异常或触发检查点时立即停机。
  • 三层时间尺度闭环：stage loop（动作内拦截误差传播）、action loop（动作之间诊断成因并改路线/接触/目标/容差）、belief loop（回合级别修正任务级前提）。
  • 感知与动作接口：相机标定 + VGGT-Omega 深度 + SAM 3.1 分割，提供多视角三角化、射线–平面求交、点云估计与手中滑移测量；动作目标设在指尖接触区而非手腕，双臂共享时间线，按阶段设容差。
  • 信息边界：仅使用公开任务文本、标定 RGB 图、机器人实测状态、公开机器人模型与相机标定；不接触仿真深度、隐藏位姿、接触状态或评测器内部。
Card 05 数据集与资源

数据集与资源

  • RoboDojo：42 个任务、5 个能力维度（Generalization、Precision、Long-Horizon、Memory、Open），主实验共 6,300 个回合（3 个随机种子）；另有 210 回合诊断集（每任务 5 回合）。
  • RoboCasa365：Target50 移动操作子集，50 个未见厨房任务，共 250 个回合。
  • 基础模型：GPT-6 Astra（高推理强度；RoboProbe 基线为中等推理强度）。
  • 感知组件：VGGT-Omega（深度）、SAM 3.1（分割）。
  • 论文未报告模型参数量、训练数据规模或 GPU/TPU 训练资源（框架本身不训练模型，模型参数在评估期固定）。
Card 06 评估与结果

评估与结果

  • 评估协议：零样本单回合协议，即无目标任务探索或开发、无示教、每案例仅执行一次且不重置；框架在评估期完全冻结，错误恢复从当前物理状态原地继续。
  • 主要指标：成功率 SR (%) 与综合 Score (0–100)，以及 5 个能力维度分项与泛化分 G。
  • RoboDojo 主结果：Auriga + GPT-6 Astra 取得 64.0 Score / 57.7% SR，在排行榜上（含学习型策略与智能体方法）排名第一，超过同模型参考框架（29.0 Score / 22.5% SR）一倍以上，并领先智能体分组全部 12 列。
  • 鸿沟闭合度：在 210 回合诊断集上，Auriga 达 59.2% SR / 64.6 Score，闭合 68.3% 的规划–执行鸿沟（Score 口径 70.6%）。
  • 场景随机化：12 个 Generalization 任务上，学习型策略在随机布局下 SR 最多下降 33.9%，而 Auriga 在标准场景 52.3% SR、随机场景 45.6% SR 均排名第一，泛化分 G = 46.3。
  • RoboCasa365：73.2% 总体 SR（Atomic-Seen 92.2%、Composite-Seen 67.5%、Composite-Unseen 57.5%），在复合任务上比 VLA 辅助的 RPent（59.2%） 与 PyRUA-Lean（56.4%） 分别高出 19.4% 与 23.1%。
  • 开发轨迹：RoboDojo Score 从 #0 的 21.5（50 案例诊断集 4.0% SR）提升到 #4 的 45.5（36.2% SR）、#9 的 53.4、#11 的 58.8，最终 #12 达 64.0（57.7% SR），五个维度均有增益（Long-Horizon +29.5、Memory +30.8）。
