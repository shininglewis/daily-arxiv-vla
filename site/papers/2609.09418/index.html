Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration

2026-09-08 · 原文 · 翻译 · 2609.09418

论文提出 Valerant，一种免训练框架，将预训练动作条件世界模型（action-conditioned world model）转化为世界动作模型（WAM），用于自动探索并构建可导航 3D 游戏地图。 目标是从单张输入图像出发，通过耦合预测性视觉 rollout、基于 SLAM 的空间重建和探索驱动的动作选择，逐步生成持久化 3D 点云游戏地图。 解决的问题是：现有游戏导向方法多停留在 2D 视觉观测空间，不实例化持久 3D 几何；而 3D 游戏需要显式、可导航且支持碰撞与交互的空间结构，动作条件视频 rollout 本身无法提供该空间表示。

Card 02 论文概述

论文概述

  • 论文提出 Valerant，一种免训练框架，将预训练动作条件世界模型（action-conditioned world model）转化为世界动作模型（WAM），用于自动探索并构建可导航 3D 游戏地图。
  • 目标是从单张输入图像出发，通过耦合预测性视觉 rollout、基于 SLAM 的空间重建和探索驱动的动作选择，逐步生成持久化 3D 点云游戏地图。
  • 解决的问题是：现有游戏导向方法多停留在 2D 视觉观测空间，不实例化持久 3D 几何；而 3D 游戏需要显式、可导航且支持碰撞与交互的空间结构，动作条件视频 rollout 本身无法提供该空间表示。
Card 03 核心贡献

核心贡献

  • 提出 Valerant：一个统一的免训练框架，将预训练动作条件 WM 转为 WAM，并将其探索过程与基于 SLAM 的重建结合，实现自动游戏地图生成。
  • 设计反事实探索流程：在相同动作前上下文下生成多个候选动作的 what-if rollout，并用探索策略选择映射效用最高的动作，将选定观测转化为持久 3D 环境。
  • 建立从单一视觉概念扩展为可导航 3D 几何的新游戏地图创作方向，减少开发者对高成本人工地图构建流程的依赖。
  • 引入鲁棒探索模块：稳健地板估计、互补碰撞检测、死袋回溯（Dead-Pocket Rewind），以应对几何漂移、视觉幻觉和局部探索陷阱。
Card 04 方法描述

方法描述

  • 输入单张图像 o0，系统维护视觉上下文、当前相机位姿和全局地图；预训练视频世界模型保持冻结，SLAM 与探索策略仅在推理时使用。
  • 每个探索步骤从相同动作前上下文出发，评估 5 个候选动作序列：uw（直行）、jw（左转后前进）、lw（右转后前进）、jq（原地左转）、lq（原地右转）。
  • 对每个候选动作，由动作条件视频 WM 生成未来 rollout；视觉 SLAM 处理 rollout，估计相机轨迹并重建候选 3D 几何。
  • 探索策略根据 覆盖度 和 前向进度 计算映射效用，并排除碰撞候选，选择得分最高的分支；随后恢复到动作前状态，只提交被选动作并更新视觉上下文和全局地图。
  • 鲁棒探索：用局部自适应地板平面和归一化地板相对高度缓解单目 SLAM 尺度/高度漂移；用点云碰撞与深度碰撞检测互补识别穿墙；用 WM-SLAM 同步检查点和失败区域记忆实现死袋回溯。
  • 关键实现使用 Matrix-Game 3.0 作为动作条件视频 WM，使用 MASt3R-SLAM 进行视觉定位与 3D 重建，可选使用 video2world 后处理全局细化点云。
Card 05 数据集与资源

数据集与资源

  • 数据集：所有输入图像均为从 VALORANT 直接截取的截图，每张截图作为初始帧和单视图条件；所有方法使用同一组初始帧。

  • 模型与工具：Matrix-Game 3.0（动作条件视频世界模型）、MASt3R-SLAM、可选 video2world 后处理；整体为免训练框架。
  • 训练资源：实验在单张 NVIDIA H100 GPU 上进行；论文未明确报告模型参数量。
Card 06 评估与结果

评估与结果

  • 任务为开放式生成任务，单张输入图可对应多种合理 3D 环境，没有唯一真值地图，因此采用感知指标而非参考指标。
  • 评估指标：AS（正文称 Authenticity Score，表注标为 aesthetic score）使用 VLM 作为评估器；UP（User Preference）通过成对人工比较统计偏好比例。
  • 主要结果：Valerant 在 AS 上达到 80.00%，UP 达到 83.33%；基线 HY-World 2.0 的 AS 为 20.00%，UP 为 16.67%。
  • 定性结果：在四个场景中，从首帧开始自动探索与重建，智能体可平滑穿过走廊、转弯和开阔区域并避免碰撞，最终生成覆盖范围较大的持久 3D 点云地图。
  • 消融实验：RF 缓解地板估计漂移，COL 阻止生成轨迹穿墙，DP 帮助智能体逃离局部死袋并改走替代路线，三者处理互补失败模式。
