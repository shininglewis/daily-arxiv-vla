Card 02 论文概述

论文概述

  • 论文提出 RAF-VLA（Representation Alignment with the Future），一种基于 VLA 的端到端自动驾驶框架，通过在表示层面直接利用未来场景监督来塑造规划相关的内部表示。
  • 现有 World-Modeling VLA 依赖显式未来生成（如图像、深度、占用预测）作为密集监督，导致额外的训练负担和推理延迟；RAF-VLA 旨在消除这一依赖，同时保留未来监督的益处。
  • 核心目标：让驾驶策略无需生成未来场景，仅通过对齐隐藏状态与未来帧表示，即可学习到对规划有用的内部表示。
Card 03 核心贡献

核心贡献

  • 提出 RAF-VLA，在表示层面利用未来场景监督，使驾驶策略直接学习规划相关的内部表示，而非通过生成任务间接学习。
  • 设计 Future-Aligned Supervised Fine-Tuning (SFT)，通过一个简单的正则化项将策略的隐藏状态与未来帧表示对齐，避免未来生成带来的训练负担和推理延迟。
  • 在 NAVSIM 基准上验证，RAF-VLA 以显著更少的训练样本量达到与 SOTA VLA 规划器相当的规划性能，训练开销仅增加 3.8%，推理延迟仅增加 1 ms。
  • 结合 GRPO-based RFT 进一步优化策略，证实 Future-Aligned SFT 带来的增益在强化微调后仍然保持。
Card 04 方法描述

方法描述

  • 采用 Mixture-of-Transformers (MoT) 架构，包含 Vision-Language Expert（基于 Qwen2.5-VL-7B-Instruct）和轻量 Action Expert（嵌入维度 1024），二者通过逐层联合注意力交互。
  • 在 Vision-Language Expert 中引入可学习的 World Queries 作为表示槽，每个对齐的未来时间步（如 1s 和 4s）分配 K=4 个查询，采用块状因果注意力。
  • 使用冻结的预训练 世界编码器（来自 Cosmos world model）从未来帧提取目标表示，通过可训练的两层 MLP 投影器将对齐的隐藏状态映射到目标特征空间，最小化均方误差。
  • 训练目标：**L_SFT = L_act + λ_align * L_align**，其中 λ_align=1；对齐损失仅用于训练，推理时移除世界编码器和投影器，仅保留学习到的 world queries。
  • 第二阶段使用 GRPO 进行强化微调，以 PDMS 作为规划奖励，优化策略生成更优轨迹。
Card 05 数据集与资源

数据集与资源

  • 使用 NAVSIM v1 和 NAVSIM v2 基准，基于 OpenScene 的真实驾驶场景；训练集为 navtrain，测试集为 navtest。
  • Vision-Language Expert 采用 Qwen2.5-VL-7B-Instruct，Action Expert 为轻量 Transformer（嵌入维度 1024），世界编码器来自 Cosmos world model。
  • 训练资源：4×H200 GPUs；SFT 约 11 小时，RFT 约 7 小时。
  • 训练配置：SFT 使用 AdamW，全局 batch size 144，学习率 1e-5，余弦衰减，训练 4 个 epoch；RFT 全局 batch size 288，学习率 2e-6，组大小 G=8，KL 系数 β=0.04。
Card 06 评估与结果

评估与结果

  • 评估环境：NAVSIM v1 和 NAVSIM v2 闭环基准。
  • 主要指标：NAVSIM v1 使用 PDMS（由 NC、DAC、EP、TTC、C 构成）；NAVSIM v2 使用 EPDMS（额外包含 DDC、TLC、LK、HC、EC）。
  • 关键结果：

- NAVSIM v1 上，仅用单前视相机，RAF-VLA 达到 PDMS 90.0；采用 best-of-N 策略后 PDMS 提升至 94.2，其中 DAC 99.6、EP 89.8 为最佳。

- NAVSIM v2 上，Future-Aligned SFT 模型达到 EPDMS 86.2，与最佳 SFT 结果持平。

- 消融实验：Future-Aligned SFT 相比无对齐 SFT，PDMS 从 87.92 提升至 89.13（+1.21）；经 RFT 后，从 88.85 提升至 90.03（+1.18）。

- 训练开销：仅增加 3.8%（从 10.56h 增至 10.96h，42.2→43.8 H200 GPU-hours）。

- 推理延迟：仅增加 1 ms（0.152s → 0.153s），可忽略不计。
