Card 03 核心贡献

核心贡献

  • 构建覆盖三个维度的基准：CARLA-F（导航跟随，关闭交通、全绿灯）、B2D-C / NavSim-C（导航-场景冲突）、B2D-Adv（对抗指令）。
  • 提出 SafeDriveVLA，首个显式预测三级导航合规模式（strict / cautious / fallback）的驾驶 VLA，将冲突推理与动作生成解耦。
  • 提出 导航条件化世界模型 dreaming：与以往在世界模型中 rollout 专家动作或规划动作不同，本方法想象"严格遵循导航信号"的未来潜状态，从而判断跟随是否安全。
  • 在 Bench2Drive 上达到 88.16 DS / 68.64% SR，语言跟随闭环成功率提升 49.3%，B2D-C 碰撞数从 60 降至 38。
Card 04 方法描述

方法描述

  • 驾驶模式归因：对每个专家帧重标注离散模式（*strict* 立即执行、*cautious* 谨慎跟随、*fallback* 覆盖指令），在动作 token 之前输出模式 token（//），使冲突推理获得直接监督。
  • 潜在世界模型：基于 V-JEPA 2 AC 范式预训练，使用冻结的 V-JEPA 2 ViT-L 目标编码器 + Transformer 动作条件预测器，在 2.5s 时间窗、2 Hz 下以教师强制与自回归损失训练。
  • 关键改进：采用两帧连续图像编码潜表示（每潜变量携带 0.25s 运动信息），以弥补单帧无法恢复周边交通速度的缺陷。
  • 导航条件化 Dreaming：为每个 meta-command 预计算 action anchor（2.5s 训练轨迹均值），冻结世界模型在该 anchor 下向前 rollout 5 步，产生"dreamed latents"并投影为 world tokens。
  • VLA backbone：基于 InternVL3-1B，采用 LoRA 微调；使用 N=2048 运动基元码本离散化轨迹，T=10 个 token（4 Hz，2.5s 时域）， 分隔符起始；轻量 MLP 头回归 20 个自车坐标系路径点驱动横向 PID 控制器，离散 token 积分得到纵向目标速度。

Card 06 评估与结果

评估与结果

  • 评估环境：Bench2Drive 闭环 CARLA 基准，以及自建 CARLA-F、B2D-C、B2D-Adv；NavSim-C 用于诊断现有 VLA（评估性诊断，未评估 SafeDriveVLA 自身）。
  • 主要指标：DS（Driving Score）、SR（Success Rate）、NCR（Navigation Compliance Rate）、SE（Speed Error）、PDMS / NC / DAC / TTC / EP（NavSim）、碰撞 / 违规 / 脱轨次数。
  • Bench2Drive：SafeDriveVLA 达 88.16 DS / 68.64% SR（waypoint 导航），较同数据训练的 SimLingo 平均提升 +2.15 DS / +1.89% SR。
  • CARLA-F：语言指令下平均 NCR 达 83.0%，车道变换 NCR 从 0% 提升至 63.6%（左）/ 72.4%（右）；command 模式下 78.8% vs. SimLingo 73.6%。
  • B2D-C：85.9 DS / 67.3% SR，碰撞 38（较 SimLingo-Safe 下降 36.7%）、交通违规 9（下降 85.2%）、脱轨 4（下降 63.6%）。
  • B2D-Adv：对抗指令下 DS 从 94.7 降至 83.9（降幅 10.8），而 SimLingo 从 95.7 降至 76.0（降幅 19.7），退化幅度约减半。
  • 世界模型探针验证：预测潜状态在 5,095 个无危险起始片段上的 Hazard AUC 在各时间窗均高于首帧潜状态，恢复 oracle 增量的 49–78%；且 rollout 在真实动作下比零动作 / 镜像动作更接近 oracle，证明其确实响应动作输入。
