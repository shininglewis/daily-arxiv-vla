Card 03 核心贡献

核心贡献

  • 将跨范式机器人策略比较形式化为多轴、证据约束的评估问题，并设置官方 checkpoint 和协议忠实运行的比较门控。
  • 提供有界的六模型评估，覆盖已发布 VLA 与 WAM 设计、三个互补 LIBERO 系列任务轨道、重复运行级评估、归一化结果记录和显式证据状态。
  • 联合报告clean 能力、非语言鲁棒性、指令敏感性、延迟、显存、运行时模式、设置负担和复现状态，且不将其压缩为单一分数。
  • 通过实证表明接近饱和的 clean 成功会掩盖更大的诊断差异，并给出 checkpoint 级能力–鲁棒性–成本画像，而不将其因果归因于架构。
Card 04 方法描述

方法描述

  • 建立统一指令条件执行视图：将每个评估 episode 映射到共享流程，包括指令与观察接地、策略推理、动作转换和环境状态转移判断。
  • 采用四轴评估协议：Capability（LIBERO clean）、Robustness（LIBERO-Plus 非语言扰动）、Language sensitivity（LIBERO-Para 语义保持改写）和 Deployability & Reproducibility（延迟、显存、运行时模式、设置负担、checkpoint 来源）。
  • 引入证据策略与比较门控：记录仓库、checkpoint、命令、归一化输出和协议偏差；证据状态分为 PF（协议忠实）、NR（近复现）和 PV（待验证），仅 PF 行支持严格比较。
  • 每个模型–基准配置聚合三个运行级种子 {1,7,42} 的完整运行，固定 checkpoint 和推理配置；报告运行级均值和总体标准差。
  • 关键创新在于将 clean 能力、鲁棒性、语言敏感性和部署成本分离评估，并显式保留证据状态，避免隐藏评估路径差异。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 系列基准：LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long（clean 能力）。
  • 使用 LIBERO-Plus 评估非语言鲁棒性，扰动维度包括 camera viewpoint、robot appearance/embodiment、illumination、background、visual noise 和 object layout。
  • 使用 LIBERO-Para 评估指令改写敏感度，保持任务语义不变。
  • 评估六个公开可执行模型：π0.5 / OpenPI、UnifoLM-VLA-0、Xiaomi-Robotics-0、GR00T-N1.7、FastWAM、Cosmos Policy；DreamZero 因无公开可执行 checkpoint 被排除。
  • 参数规模：OpenPI 3.6B、UnifoLM-VLA-0 8.9B、Xiaomi-Robotics-0 4.7B、GR00T-N1.7 3.4B、FastWAM 12.4B、Cosmos Policy 2.0B。
  • 评估资源：报告 peak VRAM、per-call latency、runtime mode、diffusion steps、setup burden 和 single-GPU feasibility；例如 GR00T-N1.7 峰值显存 7,810 MiB、延迟 19.13 ms/call，FastWAM 峰值显存 26,902 MiB、延迟 45.33 ms/call。
  • 代码和评估记录发布于 https://github.com/xiaoqi-7/IndustrialVLA-Bench。
Card 06 评估与结果

评估与结果

  • 评估环境：基于 LIBERO 家族的仿真操作任务，使用 released checkpoints 和官方评估实现；每个配置聚合三个运行级种子 {1,7,42}。
  • 主要指标：clean episode success rate（SR）、LIBERO-Plus 扰动成功率与 clean-to-perturbation drop、LIBERO-Para 成功率与 clean-to-paraphrase drop、retention ratio、latency、peak VRAM、参数数量和证据状态。
  • 全部六个系统 clean LIBERO 平均分仅相差 1.58 点（96.52%–98.10%），而鲁棒性和改写摘要分别相差 14.62 点和 31.08 点。
  • 限制到三个 PF 系统后，clean、鲁棒性和改写范围分别为 1.36、14.62 和 23.10 点，诊断分离不依赖较弱证据层。
  • OpenPI 获得最高鲁棒性平均 85.31%，clean-to-robustness drop 最小 11.21 点；但在 LIBERO-Para 上为 71.33%，并非语言敏感性最佳。
  • FastWAM 在 LIBERO-Para 降至 51.16%，下降 45.39 点，是观察到的最大单轴退化，显示语言接地瓶颈。
  • 相机和机器人扰动是主要失败模式：跨模型平均成功率分别为 58.26% 和 60.35%；光照扰动影响较小，平均 95.42%。
  • 语言鲁棒性与视觉鲁棒性不相等：clean 与 robust 的 Spearman 秩相关为 -0.37，clean 与 paraphrase 为 0.77，robust 与 paraphrase 为 0.09。
  • 证据状态：OpenPI、GR00T-N1.7、FastWAM 为 PF；UnifoLM-VLA-0 为 NR；Xiaomi-Robotics-0 和 Cosmos Policy 为 PV，后两者保留作诊断覆盖但不支持严格排名。
