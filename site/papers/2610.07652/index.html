Card 02 论文概述

论文概述

  • 论文提出 SMART，一个面向关节物体（articulated object）操作的可扩展系统，利用大规模合成演示数据（Synthetic Manipulation data for ARTiculated object manipulation）进行预训练。
  • 核心目标是解决关节物体操作中真实世界示范数据难以大规模采集的问题：接触精度要求高、需持续保持接触并满足关节运动约束，导致遥操作成本高、效率低。

Card 03 核心贡献

核心贡献

  • 提出 SMART-Sim，一个具备关节感知设计（articulation-aware design）的可扩展仿真平台，覆盖资产标注、运动生成、技能设计与域随机化，支持高效任务与运动生成。
  • 提出 agentic 任务生成方法与分布式数据合成系统，构建 SMART-Data：包含 超 100 万条轨迹、44 种原子任务类型、5 种机器人配置与 2,507 个关节物体。
  • 在仿真基准上验证了预训练效果：SMART-VLA 在 LIBERO 和 RoboCasa365 上达到或超过代表性 VLA 模型（含在真实数据上预训练的模型）。
  • 实现零样本 sim-to-real 迁移，并展示性能随数据规模的正向扩展趋势，证明合成数据可用于接触密集型关节物体操作。
Card 04 方法描述

方法描述

  • 仿真平台基于 Isaac Lab 构建，支持 7 种机器人本体（Franka Panda、RM75、ARX AC-1、R1Pro、Flexiv Rizon 4S、Marvin M6s、Unitree H1-2），组装出 5 种机器人配置。
  • 资产标注：采用 HumanoidGen 的动作坐标系定义；刚体用 AnyGrasp 生成抓取标注；关节物体由 VLM 筛选可操作部件，并用 DINO-X 定位与光线追踪恢复三维表面点。
  • 运动生成：无碰撞空间使用 cuRobo 进行 GPU 加速批量轨迹优化；接触交互中引入关节约束感知的运动求解器（使用关节类型、位置与运动范围等特权信息作为显式约束）。
  • 技能体系：将关节类型与操作语义归纳为 23 种可复用操作技能（推、拉、滑动、按压、开门、旋转、翻转、旋钮/螺丝驱动、抓放、对齐等）。
  • 域随机化：提出关节感知的随机化，涵盖空间层（物体位姿、机器人初始状态、相机外参、分组随机化）、物理层（各运动部件独立的摩擦力与密度、关节刚度与阻尼）、视觉层（部件级材质纹理、光照与环境贴图）。
  • Agentic 任务生成：设计统一任务规范格式（环境配置、任务定义、仿真设置），由 LLM 将自然语言任务描述解析为可执行的技能程序与仿真配置。
  • 数据采集：分布式系统（调度器 + 轨迹收集 / 视觉渲染 / 数据集转换三类工作负载），仅保留成功轨迹并提前重置低质量轨迹，输出 LeRobot 格式数据。
  • 模型架构：采用 PRTS 的 VLA 架构，包含 Qwen3-VL 4B 视觉语言主干与基于 DiT 的动作专家，通过 flow matching 生成连续动作；第一阶段用 FAST 分词器以交叉熵目标在 SMART-Data 上预训练，第二阶段在目标基准上用流匹配微调。
Card 05 数据集与资源

数据集与资源

  • SMART-Data 数据集：超 100 万条 episode（1,004,584 条轨迹），约 5 亿帧、超 4,600 小时操作数据。
  • 覆盖 5 种机器人配置、23 种操作技能、44 种原子任务类型、1,122 个场景。
  • 任务层级分布：69.4% 原子任务、20.9% 组合任务、9.7% 长程任务；包含 10k 个任务 YAML 配置。
  • 资产规模：2,507 个关节物体（88 个功能类别）、9,116 个刚体对象（1,071 个类别）、1,452 个场景（SDGScenes、InteriorGS、GN0）+ 超 10,000 张 4K 合成室内图像。
  • 训练/生成资源：96 个 worker；单台服务器配 8 张 RTX 4090 GPU 每天可生成约 144 小时数据。
  • 数据集公开发布于 Hugging Face（TeleEmbodied/SMART-Data）。
Card 06 评估与结果

评估与结果

  • 评估基准：仿真使用 LIBERO（Spatial / Object / Goal / Long 四类任务）与 RoboCasa365（Atomic Seen / Composite Seen / Composite Unseen）；另在真实机器人上开展零样本 sim-to-real 实验。
  • 对比模型：GR00T N1 / N1.5 / N1.6、π0、π0.5、Qwen3-VL-π、InternVLA-M1，以及 SMART-VLA(Real)（真实数据预训练）、SMART-VLA(w/o S1)（无第一阶段预训练）等变体。
  • LIBERO 结果（bs=32, 30K steps）：SMART-VLA 平均成功率 96.8%，优于 w/o S1（94.7%）、π0（94.2%）与 Qwen3-VL-π（94.7%），接近 π0.5（96.9%，但后者 batch size 为 256）。
  • RoboCasa365 结果：SMART-VLA 平均 28.8%，显著优于 w/o S1（20.0%）、GR00T N1.5（23.9%）、GR00T N1.6（21.9%）、π0.5（16.9%）与 π0（14.8%）等基线。
  • 结论：仅用合成数据预训练的 SMART-VLA 在两个差异较大的基准上均具竞争力，并在真实环境中实现零样本策略迁移，且表现出数据规模扩展带来的性能提升趋势。
