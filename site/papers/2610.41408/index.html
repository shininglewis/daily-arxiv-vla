Card 02 论文概述

论文概述

  • 论文提出 SACQ，一种面向 Vision-Language-Action（VLA） 模型超低位宽的权重向量码本量化框架，在整个量化流程中不进行完整的模型重训练（post-training）。
  • 针对的问题是：从大型语言模型（LLM）继承来的 PTQ/向量量化方法在 VLA 超低比特下性能严重下降，且未显式考虑各投影在下游计算中的结构角色，也未考虑精度分配对最终策略动作的影响。
  • 目标是在极低比特（1–2 bpw）下保持接近 BF16 的任务成功率，同时显著降低机器人平台上的模型内存占用并提升推理速度。
Card 03 核心贡献

核心贡献

  • 提出结构感知码本拟合（Structure-Aware Codebook Fitting）：为 q/k/v/o、gate/up/down、动作头等不同投影角色推导专属二次型度量，同时反映输入统计量与下游敏感度。
  • 提出动作感知混合比特分配（Action-Aware Mixed-Bit Allocation）：以“每节省一比特所带来的最终动作误差增量”为准则，而非层局部重构误差，并使用实测方式测量层降级造成的动作误差。
  • 提出两阶段量化后精修（Two-Stage Post-Quantization Refinement）：先用二阶误差补偿重分配码字索引，再固定索引、针对解码动作校准码本与行组缩放。
  • 在 GR00T N1.7 上以 1.5 bpw 达到 93.85% LIBERO 平均成功率（BF16 为 94.10%），模型内存从 5.677 GB 降至 1.175 GB（4.83×）。
  • 结合 8-bit 激活量化与低精度注意力（W1.5A8）仍保持 93.55% 成功率，推理速度达 BF16 的 1.51×。
Card 04 方法描述

方法描述

  • 采用块缩放向量码本表示：块大小 g = 64、向量维度 d = 4、每层单一码本，行组缩放初始化为组内最大绝对值；码率由 b(M) = log2(M)/d 决定。
  • 结构感知度量构造：以投影输出被下游如何使用来定义失真 Σ α(v)(v−c)ᵀG(v)(v−c)。q/k 投影用注意力 logits 扰动推导，得到 G(v) = B_{r(v),r(v)} · A_{I(v),I(v)}（A 为输入 Gram，B 为 key/query 的 Gram）。
  • 可分离局部目标：仅保留 B 的对角线与 A 的 4×4 输入块，将全局二次目标近似为块对角形式，使各权重向量可独立拟合；跨向量误差交由后续二阶精修处理。
  • v/o 投影：v 侧输入 Gram 被注意力概率加权（A = E[Σ_s ω_s x_s x_sᵀ]，ω_s = Σ_{h,t} P²_{h,t,s}），输出侧为 W_Oᵀ W_O 的对角；o 投影取 A = E[CᵀC]、B = I。
  • FFN 投影：down 用 A = E[zzᵀ]、B = I；gate/up 通过 SwiGLU 与 W_d 的一阶展开得到对角度量（含 SiLU′(g_r)u_r 与 SiLU(g_r) 项）。
  • 动作头：DiT 动作头按同原则处理 cross-attention 的 q / kv 分离输入统计、GELU 前馈敏感度、AdaLN 调制输出侧加权。
  • 混合比特分配：候选状态链为 GPTQ(4bit) → GPTQ(3bit) → VC(2.75bit) → … → VC(1bit)（1-bit 点另外允许 VC(0.75bit)），仅允许相邻状态迁移；按实测动作相对误差增量与实测算得比特成本的比值 Δ_ℓ / (cost_ℓ(ρ_ℓ) − cost_ℓ(ρ′_ℓ)) 贪心选择，并在语言主干与动作头之间做组件均衡。
  • 精修：索引重分配使用量化策略上收集的输入二阶矩 H_ℓ 的阻尼 Cholesky 因子进行 GPTQ 式补偿；动作级校准在固定索引下最小化 ‖a_Q(x;C,s,a*) − a_BF16(x)‖²_F，只更新码本与缩放，保持存储码率不变。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四套件成功率（%）、SimplER VM/VA 成功率、模型常驻内存（GB）、相对 BF16 的推理加速比；比特以语言/动作（L/A）候选层的参数加权平均 bpw 报告，并计入码本与缩放的元数据开销。
  • LIBERO 主结果（GR00T N1.7）：

- BF16：94.10% 平均，5.677 GB。

- SACQ @ 1.50 bpw：93.85% 平均（Spatial 93.2 / Object 97.0 / Goal 96.2 / Long 89.0），内存 1.175 GB。

- 同比特下基线显著落后：AQLM 1.50 bpw 为 87.50%，ActQuant 1.50 bpw 仅 30.05%，GPTQ-Ternary 1.58 bpw 为 31.95%。

- 更低比特仍可用：SACQ 1.25 bpw 为 92.70%，1.00 bpw 为 83.05%；2.00 bpw 达 94.25%（略高于 BF16 参考）。

  • 效率：W1.5 内存降低 4.83×；W1.5A8（INT8 激活 + 低精度注意力）保持 93.55% 成功率并获得 1.51× 加速。
  • SimplER（2 bpw）：Visual Matching 63.76%（BF16 58.90%）、Variant Aggregation 52.27%（BF16 53.45%），在 VM 上超过全精度参考，VA 上基本持平。
  • 消融与分析：验证结构感知度量、动作感知分配、索引重分配与动作级校准各自的增益，并在有限精修条件下考察结构感知拟合的贡献。
