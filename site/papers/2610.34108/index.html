RoboDuo: Attempt, Check and Atomic Recovery through Code for Vision-Language-Action Models

2026-10-25 · 原文 · 翻译 · 2610.34108

论文针对 Vision-Language-Action（VLA） 模型的开环执行缺陷：模型每步只根据观测和指令输出动作，从不检查上一步是否真正完成，因此长程任务中一次未被察觉的失败会导致整个 episode 失败。 提出 RoboDuo，一个以代码为接口的闭环双系统框架：由编码智能体（coding agent）写程序，先让全任务 VLA 尝试整段任务，再用完成检查器判断是否成功；失败则由原子 VLA 完成剩余步骤。 目标是在不更新任何 VLA 权重的前提下，把已有全任务 VLA 包装成可自检、可重试、可切换执行器的系统，从而提升长程任务成功率与鲁棒性。

Card 02 论文概述

论文概述

  • 论文针对 Vision-Language-Action（VLA） 模型的开环执行缺陷：模型每步只根据观测和指令输出动作，从不检查上一步是否真正完成，因此长程任务中一次未被察觉的失败会导致整个 episode 失败。

Card 03 核心贡献

核心贡献

  • 提出 RoboDuo：一个闭环双系统，用代码（而非 token 或 latent 向量）作为高层决策与低层执行之间的接口，可表达"失败—重试—切换执行器"这类控制流。
  • 设计两层程序结构：Layer 1 调用 vla_execute_fulltask 做一次完整尝试，is_task_complete 判定成败；失败则 Layer 2 逐条执行原子指令 vla_execute_atomic，每步最多重试 3 次，且控制权不再交回全任务 VLA。
  • 从同一批 LIBERO 演示中构建 LIBERO-Atomic、LIBERO-Code、LIBERO-Judge 三个数据集，分别用于训练原子 VLA、编码智能体与完成检查器。
  • 在 X-VLA 与 π0.5 两种冻结主干上实例化，验证该方法与具体 VLA 骨干解耦、可即插即用。
  • 在 LIBERO、LIBERO-PRO 与真实机器人上验证，收益主要集中在"单步失败引发级联失败"的长程任务上。
Card 04 方法描述

方法描述

  • 问题形式化：演示记为 D = (ℓ, o₀:ᵀ, a₀:ᵀ₋₁)，VLA 按 ãₜ ∼ π(aₜ \|oₜ, ℓ) 逐步预测；原式中 ℓ 不变且无完成判定，RoboDuo 在不改动该式与参数的前提下补上测试环节。
  • 代码即接口：编码智能体 𝒞 在 episode 开始读取 (ℓ, o₀)，输出程序 P 与原子计划 {(ℓₖ, gₖ)}；完成检查 J(o, g) ∈ {0,1} 只在尝试结束后调用一次。
  • 执行选择：t < T_full 时用 π_full(aₜ \|oₜ, ℓ)；若 J(o_{T_full}, ℓ)=0，则 t ≥ T_full 起改用 π_atom(aₜ \|oₜ, ℓ_{kₜ})，两者均在各自控制频率下运行。
  • 原子动作切分：用工业级 VLM Doubao Seed 2.1 Pro 对每条 LIBERO 演示标注有序原子动词及时间窗，规则后处理清洗标签并把窗口末端改到效果完成时刻（抓取止于手指停止闭合，放置/旋转止于手指张开超过夹持宽度 20 mm）。
  • 五类原语：move_to_and_grasp、place_and_release、move_to_and_pull、rotate_and_release、move_to_and_press。
  • 训练：原子 VLA 在与骨干同架构的模型上以切分片段训练后冻结；编码智能体以最大化目标程序似然 ℒ_𝒞 = −𝔼_D[log p_𝒞(P_D \|ℓ, o₀)] 微调（目标程序总是"先全任务尝试、再原子兜底"）；完成检查 J 用 (oₜ, gₖ, y_{t,k}) 问答对训练的视觉语言分类器。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四个套件（闭环任务成功率 %）、LIBERO-PRO 八个 S/T 子列、以及真机三布局；同等权重下对比"单独主干"与"主干 + RoboDuo"。
  • 主要指标：闭环任务成功率（%）；LIBERO-PRO 取八列算术平均。
  • LIBERO 长程提升：X-VLA 87.4 → 91.6，π0.5 93.6 → 96.2；平均成功率 X-VLA 95.25 → 96.40、π0.5 97.25 → 98.40。
  • 失败消除比例：在 Long 上消除 X-VLA 约 33% 的失败、π0.5 约 41% 的失败。
  • 五套件训练（基线已较强，增益收窄）：X-VLA 97.65 → 97.95，π0.5 98.30 → 98.45；RoboDuo + π0.5 的 98.40 甚至略高于五套件基线 98.30，且未更新任何权重。
  • LIBERO-PRO 鲁棒性：π0.5 八列均值 32.05 → 39.33，最大增益出现在 Object-T（25.2 → 55.8）；五套件设置下均值 43.58 → 45.68。
  • 编码智能体消融：LIBERO-Code 微调后 Mean-8 达 39.33（无智能体基线 32.05）；对比 GPT-6-Astra 作为智能体（41.50）与 GPT + TAMP（43.00）仍具竞争力，且不依赖大规模闭源模型。
  • 真机结果：在冻结全任务 VLA 的条件下，成功率由 36.7% 提升至 53.3%。
