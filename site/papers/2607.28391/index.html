论文概述

Card 03 核心贡献

核心贡献

  • 提出 TacWAM 框架，将近期触觉历史与未来触觉预测引入视觉 WAM 训练，使模型能从当前触觉观测之外的触觉变化中学习
  • 设计了 Spatially Aligned Fusion (SAF) Tactile Encoder，将触觉外观、稠密力场和网格变形流映射到共享潜在表示，并通过双侧力/力矩重建保留全局接触信息
  • 提出 Anchor-Guided Tri-Modal (AGT) Attention，规定视觉、触觉、动作三模态 token 间的信息可见性，确保动作分支不能读取未来视觉或触觉预测目标
  • 在 四个真实接触丰富操作任务 上评估，TacWAM 平均成功率 75.0%，超过最强基线 VT-WAM（37.5%）达 37.5 个百分点；分级消融验证了触觉历史和受限信息流的重要性
Card 04 方法描述

方法描述

  • 模型基于 Mixture-of-Transformers 骨干网络，包含视觉、触觉、动作三个流；模态特定专家处理各流，通过掩码混合自注意力通信
  • SAF 触觉编码器：每个触觉观测包含三个空间对齐信号——矫正触觉图像、稠密力场、网格变形流；单帧编码器使观测态和预测态共享同一潜在空间，解码器重建稠密力场、变形流和双侧合力/力矩（3D 力 + 3D 力矩）
  • 触觉历史编码器：通过自适应归一化（adaptive normalization）调制触觉专家，总结当前动作块之前的触觉变化趋势，帮助消歧当前接触相位（如稳定接触、压力增长、滑移恢复）
  • AGT 注意力掩码：动作 token 只能读当前视觉锚点 V₀、当前触觉锚点 T₀ 和动作 token 本身；未来触觉 token 不读动作 token；未来视觉与触觉 token 之间也无双向交互
  • 训练策略：两阶段训练——先预训练 SAF 编码器/解码器（冻结），再联合训练 WAM 生成器；使用流匹配（flow-matching）目标，损失包含视频、动作、触觉潜在、触觉解码语义一致性和接触事件辅助损失

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估任务：薯片抓取（Chip）、樱桃抓取（Cherry）、白板擦拭（Wiping）、双笔旋转（Twirling），每个任务 20 次真实试验
  • 基线方法：π₀.₅（视觉-语言-动作模型）、Fast-WAM（纯视觉 WAM）、RDP（反应式扩散策略）、VT-WAM（视觉-触觉 WAM）
  • 主要结果：TacWAM 在四个任务上均优于所有基线——Chip 90.0%、Cherry 70.0%、Wiping 75.0%、Twirling 65.0%，平均 75.0%；最强基线 VT-WAM 平均仅 37.5%
  • 消融实验：移除触觉历史后平均成功率降至 55.0%（−27.5）；进一步允许动作读取完整未来触觉序列（Attn-AT）降至 37.5%；再放开视觉-触觉未来双向交互（Attn-VT）几乎崩溃，仅 7.5%
  • 触觉预测诊断：在白板擦拭和双笔旋转任务中，TacWAM 解码出的合力大小随时间趋势更接近真实值，而无历史模型存在明显的时间滞后
