Card 02 论文概述

论文概述

  • 论文聚焦长时程机器人操作（long-horizon manipulation）中的任务状态混叠（task-state aliasing）问题：多模态输入相同但所需动作不同，导致反应式 VLA 策略反复失败。
  • 核心假设是：预训练 VLA 已具备丰富的控制原语，瓶颈不在策略能力，而在于输入歧义，因此只需将执行上下文注入 VLA 的原生输入空间即可。
  • 提出 TaskAnchor：一个轻量适配器，通过"任务状态坐标 + 历史条件视觉残差"双路径调制，在不改变 VLA 主干架构与动作生成机制的前提下解锁其长时程能力。
Card 03 核心贡献

核心贡献

  • 揭示反应式 VLA 的长时程失败源于两类混淆歧义的耦合，并将任务状态解耦为任务状态坐标（子任务阶段）与细粒度历史证据（阶段内动作选择），把难以处理的时序建模问题转化为两个定向的条件化任务。
  • 完全在 VLA 原生输入空间内解决任务状态混叠：任务状态坐标以增强语言指令注入，历史证据以视觉残差注入，无需修改底层 VLA 架构或动作生成机制。
  • 证明仅需27M 额外参数和约 2ms 推理延迟开销，即可在 RMBench 上取得约 6× 平均成功率提升、在 RoboMemArena 上超过 2× 的 π0.5 性能，并实现可靠的真实机器人多阶段执行。
  • 提出 CA-TTT（Context-Adaptive Test-Time Training）机制，将 TTT 重新解释为瞬态的历史条件适配器，每步重建快权重并在读出后丢弃，避免持久化参数更新与序列长度的二次增长。
Card 04 方法描述

方法描述

  • 任务状态策略建模：将策略分解为 p(A\|X̃_t, ℓ_t⁺) · p(C_t\|X_t, M_t)，其中 TaskAnchor 负责历史推断，VLA 负责原生动作生成。
  • 任务状态坐标：定义连续坐标 p_t* = m_t/M（m_t 为语义里程碑索引），由轻量坐标头 C_ψc(·) 从任务状态查询 q_p,t 预测，用 MSE 损失 L_coord 监督，并以归一化小数形式经固定模板前置到语言指令。
  • CA-TTT 与历史记忆：维护压缩历史特征记忆库 M_t = [Φ(X_1);...;Φ(X_{t-1})]，Φ 用双线性插值做空间下采样，旋转位置编码表达时序；每层用自监督重建损失 L_TTT 从离线初始化 ω^(m) 做单步快权重更新，查询流通过 Q̄ = Q + g(Q; ω̂) 实现"隐式交叉注意力"。
  • 视觉残差注入：视觉查询 token 经偏移头产生残差 X̃_t = X_t + H_ψo(Q_O,t)，通过原生视觉接口注入历史条件。
  • 训练/推理协议：外层目标 L = L_act + λ_coord · L_coord，训练时用真值坐标做 teacher forcing 并将坐标头梯度阻断；推理时冻结所有慢权重，快权重用完即弃，记忆库在回合边界重置。
Card 05 数据集与资源

数据集与资源

  • RMBench：双机械臂长时程基准，评估早期证据检索（物体身份、位置、姿态）；评估 5 个 M(1) 任务，采用 "demo clean" 设置。
  • RoboMemArena：26 个长时程任务，平均 1,076 步，151 个标注子任务中 104 个需要历史信息；分 Transfer、Occlusion、Counting、Sequence 四类。
  • 真实机器人平台：DexForce 平台，包含多阶段真实任务（如 Lift Red Block Three Times、Chip-Bag Checkout、Human-Cued Matching）。
  • 基座模型：π0.5（主实现，TaskAnchor-π0.5）与 X-VLA（TaskAnchor-XVLA）。
  • 训练资源规模：RMBench 上每个变体训练 250 episodes，每任务 50 条演示（基线）/ TaskAnchor 联合多任务训练；RoboMemArena 每任务 100 条演示；附加参数约 27M；推理额外延迟约 2ms/动作块。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真基准 RMBench（指标 SR，范围 [0,1]，每任务 100 个固定种子、共 500 次闭环 rollout，无失败过滤或种子重选）与 RoboMemArena（指标 TSR 任务成功率、CSR 累积成功率），外加真实机器人实验。
  • RMBench 结果：联合多任务训练下 TaskAnchor-π0.5* 平均 SR 0.70、TaskAnchor-XVLA* 0.66，分别超对应预训练主干 +0.55 和 +0.54；在 *Rearrange*、*Put Back*、*Swap Blocks* 上均达 1.00；任务特定训练进一步提升至 0.79（π0.5）与 0.70（XVLA）。
  • RoboMemArena 结果：TaskAnchor-π0.5 取得最高平均 TSR 50.0% 与 CSR 74.2%，比 π0.5 提升 28.5 与 35.5 个百分点，比最强基线 PrediMem 高 11.5 与 19.0 个百分点；Occlusion 类提升最大（TSR 47.3%、CSR 75.9%，超 PrediMem 20.0 与 37.5 个百分点）。
  • 失败模式分析：剩余失败集中在 *Obs. & Pick*（目标消歧）与 *Swap T*（姿态/朝向恢复），说明精细目标与朝向推理仍具挑战，而历史相关状态恢复与动作选择已显著改善。
  • 效率表现：约 2ms 的额外推理延迟，接近零开销地换取大幅成功率提升（对应论文 Q1–Q4 四个研究问题）。
