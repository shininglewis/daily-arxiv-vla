Card 02 论文概述

论文概述

  • 提出 FASA（Feedback-Aware Sampling Adaptation），一个免训练、即插即用的运行时框架，用于加速基于扩散的 VLA（Vision-Language-Action）模型推理。
  • 核心问题：扩散式 VLA 模型每个控制步需数百次去噪迭代，带来沉重的计算与访存开销，难以在边缘平台实时部署；已有加速方法要么需要昂贵的重新训练（蒸馏、流匹配），要么采用静态调度的剪枝/缓存而忽略机器人交互的动态负载变化。
  • 核心思路：将实时多模态反馈（视觉特征变化、夹爪力、本体感知状态）作为去噪流水线的控制信号，动态分配采样步预算。
Card 03 核心贡献

核心贡献

  • 提出 FASA 框架，首个将环境与本体感知反馈作为扩散去噪循环控制信号的免训练运行时方案，无需修改模型权重或控制栈。
  • 设计 Interaction-Driven Sampling Range Adaptation：融合视觉特征变化与夹爪力反馈，动态缩放采样步的上下界范围。
  • 设计 Proprioception-Aware Sampling Step Adaptation：由关节位置/速度计算 MotionIndex 运动活跃度指标，经 sigmoid 门控在自适应范围内精确定位优化采样步。
  • 在 3D Diffuser Actor、Diffusion Policy、RDT、Evo-1 四种策略与三个基准上验证通用性，实现最高 1.45× 加速且成功率持平或提升。
  • 提出无力的变体（force-free FASA），在无夹爪力传感器的 LIBERO 环境下依然有效，扩展了适用场景。
Card 04 方法描述

方法描述

  • 标准扩散策略在每个执行步固定执行 K 步去噪；FASA 用反馈条件调度替换该固定预算。
  • 范围自适应：以负余弦相似度量化力变化与视觉变化 δ_force、δ_vision，融合为调制因子 α_t = ½δ_vision + ½δ_force + β（β = 1.5 作线性整流器防止生成崩溃），再按 s_min^t = s_min^{t-1}·α_t、s_max^t = s_max^{t-1}·α_t 更新范围（初值 s_max^0 = 2s_min^0），实现时用指数移动平均平滑并裁剪。
  • 步长自适应：定义 MotionIndex_t = ‖q̇_t‖ + ‖q_t − q_{t−1}‖（归一化关节速度与位移之和，量纲一致），通过 sigmoid 门控映射为 s_opt^t = s_min^t + (s_max^t − s_min^t)·σ(MotionIndex_t)。
  • 创新点：α_t < 1 时压缩稳定阶段预算，α_t > 1 时为动态交互分配更大算力；视觉特征复用策略原有视觉编码器提取，保证表示对齐；每步额外开销仅为一次视觉编码器调用、两次余弦相似度与 MotionIndex 范数计算。
Card 05 数据集与资源

数据集与资源

  • RLBench：18 个语言条件桌面任务，多视角视觉与本体感知，用于评测 3D Diffuser Actor (3D-DA)
  • ManiSkill3：GPU 并行接触丰富操作仿真器，选用 *PickCube*、*PushCube*、*StackCube* 三个任务，用于评测 Diffusion Policy (DP) 与 RDT
  • LIBERO：四个套件共 40 个语言条件任务，用于评测 Evo-1（使用无力变体）
  • 训练资源：NVIDIA RTX 4070 Laptop GPU（8 GB VRAM）用于 3D-DA 与 Evo-1；NVIDIA RTX 3090 GPU（24 GB VRAM）用于 DP 与 RDT
  • 模型均为现有预训练策略，FASA 不引入额外训练参数
Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（Avg. %，↑）与动作生成加速比（Speedup = 基线耗时 / FASA 耗时，↑），LIBERO 上另报告动作生成延迟（Lat.，ms，↓）
  • RLBench：平均成功率从 75.96% 提升至 77.48%，加速 1.40×；*close jar* 30.67%→42.67%，*stack blocks* 54.00%→66.67%
  • ManiSkill3：DP 从 70.28% 提升至 76.39%，加速 1.45×；RDT 从 86.11% 提升至 87.50%，加速 1.23×（RDT 仅 10 步采样，加速空间随基线预算增大而增大）
  • LIBERO：无力变体成功率从 93.0% 提升至 93.5%，平均去噪预算从 32 步降至 19.79 步，加速 1.23×；Long 套件达 1.35× 且成功率 +4 点，Spatial 套件成功率 -4 点（说明细粒度空间控制需更保守调度）
  • 消融实验（3D-DA 基线 77.22% / 33.59s）：仅范围自适应 1.64× 但精度略降（76.33%）；仅步长自适应 1.18×（77.06%）；两者耦合的 FASA 取得最高成功率 77.50% 与 1.42× 加速，证明两级自适应均不可或缺
  • 可视化显示采样步在状态稳定时递减、在状态突变时回升，证实闭环动态调控有效
