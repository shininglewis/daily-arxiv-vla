Card 03 核心贡献

核心贡献

  • 提出 GE-Act 2.0 完整架构，包含控制导向自编码器（CoAE）、单步视觉规划器（SVP）与逆向动力学模型（IDM），支持在互补数据上分别预训练后通过端到端共同训练连接。
  • 识别并形式化了 "有效性差距"（validity gap）——即预测的未来状态与记录动作来自不同结果模式时的监督不匹配问题，并据此提出 KASO（Knowledge-Aligned Selective Optimization） 共同训练策略。
  • 系统证明了从 300 小时扩展到 30,000 小时操作数据时，零样本 OOD 操作能力的显著提升（G1-OP 从 17.1% 提升到 44.1%），且跨 100 个真实机器人任务与两个本体（embodiment）实现广泛增益。
  • 在同一零样本 OOD 协议下，验证了模型对对象、颜色、形状、位置等指令的细粒度指称理解能力（≥90% 试验成功率）。
  • 在模拟基准（RoboTwin、GenieSim-Instruction、LIBERO）上提供了水平参考点，进一步验证模型的 OOD 泛化能力。
Card 04 方法描述

方法描述

  • CoAE（控制导向自编码器）：帧级 2D 自编码器，采用 64× 空间降采样（256×384 分辨率 → 每帧 4×6×512 = 24 token），通过像素重建、感知损失、对抗损失以及多教师对齐（SigLIP 2 / V-JEPA 2.1 / DINOv3 等冻结视觉编码器）训练。
  • SVP（单步视觉规划器）：基于条件化 MeanFlow 的扩散 transformer（DiT），结合多视角时空处理与跨视角注意力，一次前向传播即可从噪声完全去噪得到未来视觉潜变量序列，使视觉规划与 IDM 可分别预训练。
  • 多尺度视觉预测：同时预测稠密近端帧（控制相关）与稀疏远端帧（任务意图相关），在保持 token 效率的同时覆盖近期动态与远期场景演化。
  • IDM（逆向动力学模型）：通过交叉注意力将当前与预测的视觉潜变量及本体感觉信息映射为稠密动作块与稀疏远视界动作序列。
  • KASO 共同训练：保留 SVP 视频目标与 IDM 记录视频目标，采样多个生成候选，仅选择被主动 IDM 判定与记录动作行为兼容的候选进行端到端共同训练。
Card 05 数据集与资源

数据集与资源

  • 训练数据：异构操作视频与机器人交互数据，涵盖动作标注轨迹、无指令操作、失败尝试与部署回滚，规模从 300 小时扩展到 30,000 小时。

  • 基础视觉编码器：DC-AE（128 通道初始化，扩展至 512 通道）；冻结视觉教师包括 SigLIP 2、V-JEPA 2.1、DINOv3；冻结 VLM 采用 Qwen3.5。

Card 06 评估与结果

评估与结果

  • 零样本 OOD 评估协议：不对目标任务或本体进行任何 SFT/微调，直接评估预训练 checkpoint，保持协议在扩展检查点间固定。
  • 数据规模扩展效果：共同训练数据从 300 小时增至 30,000 小时，G1-OP 成功率从 17.1% 提升至 44.1%；G2-90D 从 13.4% 提升至 31.1%，增长覆盖 19/20 和 18/20 的技能组。
  • 跨本体迁移：G2-90D 仅占共同训练数据的不足 2%，但仍获得 17.7 个百分点的提升，表明广泛数据语料中存在有效的跨本体迁移。
  • 技能覆盖率相关性与成功率的关联：技能特定数据覆盖率与零样本 OOD 成功率高度相关（Pearson r=0.80；Spearman ρ=0.85）。
  • 指令理解：对象、颜色、形状和位置指称在超过 90% 的试验中被正确理解；定性压力测试表明模型能遵循明确指令，即便指令与已承诺行为或常规场景关联冲突。
  • CoAE 表示质量：CoAE 在动作恢复探测中 MAE 为 0.01673（仅比 DINOv3/V-JEPA 2.1 高 13–31%，但 token 数仅为 1/16），指令匹配错误率 2.05% 低于全部视觉教师与 DC-AE 基线。
