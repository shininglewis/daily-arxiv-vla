Card 02 论文概述

论文概述

  • 论文指出现有 视觉-语言-动作模型（VLA） 存在结构性错配：场景语义大约以 1 Hz 变化，但反应式控制需要 20–50 Hz；现有方法却在每个控制步都用数十亿参数的 VLM 重新编码整幅观测。
  • 提出 Leap-VLA，将单一 VLA 拆分为低频 语义锚（slow loop） 与高频 流匹配动作专家（fast loop）；前者缓存上下文并跨控制步复用，后者接收新鲜的低延迟视觉流。
  • 目标是在异步部署栈的真实时钟下，让策略对语义缓存“变旧”（staleness）几乎无感；同时研究指令与场景不匹配时 VLA 的失效模式。
Card 03 核心贡献

核心贡献

  • 提出非对称频率的 VLA 架构；它在复用语义缓存的同时，保留共享注意力 VLA 骨干的逐层语义耦合。
  • 提出 staleness-aware 缓存复用：以实测缓存年龄 τ 作为条件，并按物理时钟采样陈旧度分布进行训练；再加入与部署同构的像素腐蚀课程（curriculum）。在 LIBERO-Spatial 上，该方法把 2 s 刷新时从 61.4% 提升到 95.5%。
  • 提出快循环统一注入接口：视觉流（运动感知图像 token）通过单一可插拔 token-block 接口进入专家，采用序列拼接；其他流通过门控交叉注意力注入，并使用零初始化门控和交错调度。此外还提出机器人视频预训练配方（掩码重建 + 光流 + 深度）。
  • 提出 soft-nudge：这是一种仅前向的 chunk 边界修正，把 real-time chunking 的引导项重构为无需 autograd 的形式；它在零额外延迟下实现每控制步重规划（97.1%），并与基于梯度的 RTC 行为等价。
  • 提出指令–场景一致性研究：利用零成本的“负样本回合”（跨套件指令重指派）构造数据，揭示 achievability-prior 失效（策略在指令不匹配时仍继续操作场景）；并提出 CoT verdict gate，在不损害可行任务成功率的前提下，只在指令不匹配时冻结执行。
Card 04 方法描述

方法描述

  • Slow system（语义锚）：以 Qwen2.5-VL-2B 为骨干，在刷新时刻编码指令与相机观测，生成缓存上下文 C；缓存按周期、触发事件或回合重置刷新，且刷新异步执行，控制环不阻塞。
  • 关键设计：机器人状态不放入 prompt；因为把状态写成文本嵌入缓存前缀，机器人一移动缓存就会失效。状态改由快循环以专用 token 输入，因此前缀在缓存复用下保持语义有效。
  • CoT 监督：骨干在 prompt 后追加短链式推理区，用交叉熵（LM loss）监督；由于注意力是因果的且位置编码相对，专家消费的 prompt 区特征逐位不变，推理只塑造锚的表示，不进入动作通路。
  • Fast system（反应式专家）：遵循 π0 式注意力耦合；条件向量 c = MLP([t, enc(τ)])（t 为流时间，τ 为实测缓存年龄）经 AdaRMS 调制每层，年龄用 g(τ)=log(1+τ) 的正弦编码；本体感知作为专用输入 token，控制频率 f 也输入动作头。
  • 模态注入：(a) 序列拼接（当前视觉流，每相机 196 token，224²/patch-16）；(b) 门控交叉注意力（Flamingo 式零初始化输出投影，按层步长调度），每个重规划周期只编码一次，特征在各 Euler 步复用。
  • 快流编码器预训练：约 23M 参数，卷积 stem + 3 层宽 Transformer + RoPE；输入双帧对 (o_{t-δ}, o_t) 在 stem 早期融合为 6 通道；三个 MAE 式目标共享编码器——掩码重建（~49% 行列条带掩码、双帧）、稠密光流（WAFT 教师监督）、逐像素深度（Depth Anything V2 教师监督）。
  • 陈旧度训练：Δ ~ U[0, Δ_max]，Δ_max = T_ref + ε_jit，从同一回合历史取锚帧并按实际有效年龄编码；再按年龄对 VLM 输入图像做连续渐变的矩形灰块腐蚀（部署同构），低于 t₀ 时输入逐位不变以保护 τ=0 工作点。
  • 训练与推理：标准流匹配目标 L = E‖u_t − v_θ(x_t,·)‖²；冻结快流编码器（及冻结 VLM 时）可预计算特征；推理时每环境独立缓存，每周期编码一次快流并复用，可选时序投票融合重叠 chunk。
Card 05 数据集与资源

数据集与资源

  • 快流预训练数据：62 个机器人数据集，约 319k 回合、约 73M 帧；含 9 个自建多相机套件（约 63.5k 回合、约 45M 帧）与 53 个公开 OXE 源（约 256k 回合、约 28M 帧），以 fps 归一化帧步长固定物理帧间隔 δ。

Card 06 评估与结果

评估与结果

  • 评测环境：所有 LIBERO 数字均在异步部署栈上测得——50 ms 客户端时钟、每 0.5 s 重规划（消费 chunk 20 个动作中的 10 个）、语义条件按 0.2/0.5/1/2 s 周期刷新、基于观测时间戳的 stale-clock 门控；每格 500 回合（部分表为每任务 50 回合）。
  • 主要指标：任务成功率（%）；辅以 chunk 边界位移比（boundary/intra）、峰值边界位移、动作 RMS 与路径长度；以及吞吐（p50/p99 延迟、慢环占空比）分析。
  • 四套件（匹配频率）：96.3% 平均（Goal 97.2 / Spatial 97.5 / Object 98.0 / Long 92.4），高于 π0（94.4），落后 π0.5（96.9）、GR00T-N1.7（97.0）约 0.7–2.6 点。
  • 慢环降频：1 s 刷新平均 95.2%、2 s 刷新 94.5%（匹配锚 96.3%）；每套件从匹配到 2 s 仅降 1.6–2.0 点。
  • 训练阶梯（LIBERO-Spatial）：频率匹配微调在 2 s 下崩到 61.4%；仅加入异步 Δt 暴露 → 91.8%；再加实测年龄条件 → 92.9%；再加陈旧帧掩码课程 → 95.5%（1 s 下 95.9%，距匹配锚 97.5% 仅 1.6 点）；1 s→2 s 参考掉 21.5 点，而异步族平均仅掉 0.9 点。
  • soft-nudge：chunk 边界/块内位移比从 1.907 降到 1.035（95% CI 含 1.0，即边界步与块内步统计上不可区分），峰值边界位移 0.281→0.181，优于 RTC 梯度引导（1.194/0.207）；每步重规划（0.05 s）下成功率 97.1%，高于默认 0.5 s 的 95.5%，且零额外延迟。
  • 失效与门控：指令–场景不匹配时策略仍持续操作场景（achievability-prior 失效）；CoT verdict gate 在零成本负样本上训练，可在不匹配指令上精确冻结执行，且不损害可行任务成功率。
