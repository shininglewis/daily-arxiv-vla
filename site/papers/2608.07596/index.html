论文概述

Card 03 核心贡献

核心贡献

  • 重新定义 VLM-to-action 条件化为深度感知信息路由问题，提出"每个 Parallel Fusion Block（PFB）应访问以匹配层为中心的局部邻域而非单一层或全部层"的局部性先验
  • 提出 LIRA 机制：将 LIRA Query tokens 加入 VLM 并提取逐层特征，每个 PFB 聚合来自深度对齐局部窗口的 LIRA Query 特征，同时保留任务 token 特征的层对齐分支
  • 零额外参数量：LIRA 相比基线 VLA-Adapter 不引入任何新增可训练参数，路由特征沿 token 维度拼接，直接由现有交叉注意力消费
  • 显著性能提升：在 0.5B 参数配置下，零样本迁移至 LIBERO-Plus 将整体成功率从 59.1% 提升至 78.0%（+18.9 个百分点），并超出 OpenVLA-OFT 8.4 个百分点
  • 支持局部性先验的消融证据：通过路由拓扑、窗口宽度和查询预算三组消融实验验证了中心化三层窗口设计的有效性
Card 04 方法描述

方法描述

  • 深度对齐接口：VLM 含 L 层 Transformer，从第 ℓ 层提取任务 token 特征 T_t^(ℓ) 和 LIRA Query 特征 R_t^(ℓ)；动作解码器含 L 个 PFB，由 Action Query tokens 初始化
  • 局部跨层路由：对 PFB i 选择以匹配层 i 为中心、半径 r 的邻域 𝒲_r(i) = {ℓ \|\|ℓ-i\|≤ r}，将邻域内各层 LIRA Query 特征沿 token 维度升序拼接，形成路由表征 R̃_t^(i)；默认 r=1（三层窗口），边界层裁剪为两层
  • 条件化融合：每个 PFB 接收任务 token 特征（深度对齐语义锚点）、路由后的 LIRA Query 特征（局部邻域补充信息）以及本体感觉嵌入 E_t^p，通过 Bridge Attention 中的自注意力和交叉注意力进行融合
  • 训练目标：采用监督连续动作回归，L1 损失 L_act 平均预测动作块与真实动作在 H 时间步上的差异；与 VLA-Adapter 使用相同的训练配置以便隔离路由机制的影响
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（四任务套件）、LIBERO-Plus（10,030 个扰动任务，7 个扰动类别：相机、机器人、语言、光照、背景、噪声、布局）、CALVIN ABC→D（顺序任务完成）
  • 模型骨干：Prismatic 风格 VLM + Qwen2.5-0.5B 语言骨干，总参数量 0.5B
  • 训练配置：LoRA rank 64，学习率 1×10⁻⁴，批次大小 16，4 张 NVIDIA H100 GPU
  • LIRA 超参数：M=64 个 LIRA Query tokens，默认三层路由窗口（r=1）
  • 系统级对比：相比 OpenVLA-OFT，骨干大小 1/14×，训练内存 12.8GB vs 62GB（0.21×），吞吐量 186.3Hz vs 71.4Hz（2.61×）
  • 真实平台：7-DoF Franka Research 3 手臂 + Franka Hand 夹爪，两台 Orbbec Gemini 336L 相机，SpaceMouse 遥操作采集
Card 06 评估与结果

评估与结果

  • LIBERO 标准操作任务：LIRA 平均成功率 98.9%，超越 VLA-Adapter（97.3%）和 VLA-Adapter-Pro（98.5%）；LIBERO-Long 从 95.0% 提升至 97.6%（+2.6 个百分点，最大增益）
  • CALVIN ABC→D 顺序任务：五任务连续完成率从 76.5% 提升至 80.5%，平均完成序列长度从 4.42 提升至 4.52，为对比方法中最高
  • LIBERO-Plus 零样本迁移：整体成功率从 59.1% 提升至 78.0%（+18.9 点），超出 OpenVLA-OFT 8.4 点；7 个扰动类别中 6 个取得最高成功率，Light 类别提升最大（70.6%→96.9%）
  • LIBERO-Plus 微调后：整体成功率 82.9%，超过 VLA-Adapter（81.0%）和 OpenVLA-OFT（79.5%）
  • 消融实验：三层窗口在 LIBERO-Long（97.6%）和 CALVIN-5（80.5%）上均最优；全局聚合最差（93.7%/76.9%），验证局部性先验；64 个 LIRA Query tokens 时 LIRA 达 97.6%，而末层仅用 256 tokens 最高仅 92.8%
  • 真实机器人评估：4 个任务各 10 次试验，LIRA 全部取得最高成功率，Move 10/10、Pick-and-Place 9/10、Collection Step 2 为 8/10、Transfer Step 2 为 7/10，超越 OpenVLA-OFT 和 VLA-Adapter
