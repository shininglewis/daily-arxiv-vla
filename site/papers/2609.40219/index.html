论文概述

Card 03 核心贡献

核心贡献

  • 提出新型可学习动作经验词典（AED），将历史动作经验编码为视觉条件化的动作嵌入，使模型能利用操作任务间的潜在关系指导动作预测。
  • 将动作相关视觉信息融入 AED 中的动作嵌入，得到视觉条件化动作嵌入，同时融合任务相关视觉语义与动作经验，兼顾任务上下文与动作意图。
  • 引入运动感知转换损失（Motion-Aware Transition Loss, MT Loss），在随机时间区间上监督视觉特征变化预测，促使 AED 中的动作嵌入捕捉动作相关运动并减少对无关背景线索的依赖。
  • 给出时间组合误差界（Theorem 1），从理论上证明随机区间采样的 MT 损失是无偏估计，且其收敛意味着未来区间上均方组合误差收敛。
Card 04 方法描述

方法描述

  • 基于 FastWAM 框架，采用流匹配（Flow Matching） 联合训练视频专家与动作专家，视频与动作潜变量共享去噪过程。
  • AED 构建：定义可学习词典 $\mathcal{D}\in\mathbb{R}^{N\times d_a}$，将历史动作轨迹按视觉观测间隔聚合（手臂维度累积、夹爪维度保留末端状态），再用预训练动作分词器 $\Phi$ 检索任务相关动作嵌入。
  • 视觉条件化：用可学习查询将历史视觉 patch token 压缩为固定数量潜变量，再通过单层 Transformer 编码器的交叉注意力以动作嵌入为 query、视觉特征为 key/value，生成视觉条件化动作嵌入。
  • 前缀注入：将视觉条件化动作嵌入拼接（前置）到噪声动作 token 上，送入动作专家预测未来动作块，使模型可利用任务间关系。
  • MT 损失：随机采样未来时间步与时间窗口，用三层交叉注意力预测器从起始视觉特征与 AED 条件化隐藏状态预测视觉特征变化，强化动作相关运动、抑制背景干扰。
  • 训练目标：$\mathcal{L}=\mathcal{L}_{\mathrm{FM}}+\lambda_m\mathcal{L}_{\mathrm{MT}}$，其中 $\lambda_m=0.01$。
  • 推理：视频与动作潜变量由高斯噪声初始化，经 $K$ 步欧拉 ODE 去噪得到长度 $H$ 的动作块；部署时无需解码视频像素帧，也无需运行 MT 预测器。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO、RoboTwin 2.0、LIBERO-Plus。
  • 真实世界平台：Spirit AI MOZ1 与 ROKAE AR5 两种机器人平台。
  • 模型规模：视频专家 5B（由 Wan2.2 初始化，保留视频 DiT、文本编码器与视频 VAE），动作专家 1B（隐藏维度 $d_a=1024$）。
  • 训练资源：8 张 NVIDIA A100 GPU 在 LIBERO 上训练 10 个 epoch；32 张 NVIDIA H100 GPU 在 RoboTwin 2.0 上训练 5 个 epoch；优化器为 AdamW。
  • 视觉编码器：可选用 LingBot-Vision 或 DINOv3 提取视觉潜特征。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO（每套件 10 个任务、每任务 50 次 rollout）、RoboTwin 2.0（Clean 与 Random 环境共 50 个任务、每任务 100 次试验）、LIBERO-Plus（10,030 次试验）；主要指标为成功率（%）。
  • OOD 鲁棒性：在杂乱背景、低光照、未见物体三类分布外条件下，模型在 MOZ1 与 AR5 平台上均取得高于 LingBot-VA、Fast-WAM 等基线的成功率。
  • 消融实验（LIBERO-10）：完整模型 97.4，去除 MT 损失为 96.8，去除视觉条件化为 95.6，去除 AED 为 94.8，验证三个组件的有效性。
  • 推理效率：LIBERO 上 1/4/10/15 步推理延迟分别为 167.3ms / 284.6ms / 521.2ms / 708.5ms，内存占用恒为 24.1 GB。
  • 延迟对比：在 LIBERO Goal 与 MOZ1 平台上的延迟（m s）分别为 Ours 518.7 / 520.3、Fast-WAM 497.1 / 513.8、π0.5 220.0 / 494.9、Motus 2131.6 / 2163.7，表明方法在保持精度的同时具备与主流方法相当的实时性。
