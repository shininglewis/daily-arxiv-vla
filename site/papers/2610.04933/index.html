Card 02 论文概述

论文概述

  • 论文提出 DiVeR，一种决策关键性加权的验证器学习框架，用于 Vision-Language-Action (VLA) 模型的测试时缩放（Test-Time Scaling）。
  • 核心问题：现有分类式验证器从轨迹级结果学习时平等对待所有访问状态，但实际只有稀疏的决策关键状态对动作选择有显著影响，均匀权重会稀释监督信号。
  • 研究目标：无需步级标注或额外环境交互，将验证器学习聚焦于候选动作分歧大、选择后果重要的状态，从而提升 Best-of-N 动作选择的效果。
Card 03 核心贡献

核心贡献

  • 识别出均匀验证器训练的局限：常规状态主导轨迹且提供有限的候选辨别信号，而稀疏的决策关键状态对动作选择更为关键。
  • 提出 DiVeR：使用动作专家表示方差作为决策关键性的实用代理，并据此对验证器学习进行加权，强调候选动作分歧更大的状态。
  • 在模拟和真实机器人任务上验证：在 LIBERO、RoboCasa 和 Franka Research 3 上，通过更有效的验证器引导 Best-of-N 选择，一致提升任务成功率，且验证器推理开销可忽略。
  • 与 VLM 基验证器相比，DiVeR 成功率更高（+4.6%）且验证延迟降低超过 700 倍。
Card 04 方法描述

方法描述

  • 将预训练 VLA 策略视为冻结的随机动作生成器，在每个决策步采样 N 个候选动作块，由轻量级验证器打分并选择最高分候选执行。
  • 验证器基于成功与失败轨迹的状态-动作访问密度比进行训练，使用二元交叉熵；种群最优判别器的 logit 估计成功/失败访问密度比（success-visitation ratio）。
  • 决策关键性估计：在每个状态采样 K 个候选动作，提取 VLA 动作专家的内部表示，计算每坐标方差的均值 u_t 作为关键性分数。
  • 决策加权：在每个轨迹内标准化 u_t，通过 w_t = exp(β ũ_t) 转换为决策权重，然后使用加权 BCE 损失训练验证器。
  • 创新点：无需步级监督或额外环境交互；仅使用动作专家表示作为验证器输入；将学习重点放在稀疏的决策关键状态。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-Long、RoboCasa 模拟环境，以及 Franka Research 3 真实机器人。
  • 主要评估指标：任务成功率（%）。
  • 关键实验结果：

- LIBERO-Long：π0 在 N=32 时，DiVeR 比 N=1 基线提升 +5.8%，比最佳基线提升 +2.8%；π0.5 上同样提升。

- RoboCasa：DiVeR 平均比 N=1 基线提升 +5.9%（π0）和 +11.6%（π0.5）；Ours 平均成功率达 38.1%（π0）和 54.7%（π0.5）。

- 真实机器人：DiVeR 平均成功率 71.9%，比均匀训练验证器（65.6%）提升 +6.3 个百分点，比 N=1 基线（58.3%）提升 +13.6 个百分点。

- 与 VLM 基验证器对比：DiVeR 成功率 54.7% vs RoboMeter 50.1%（+4.6%），延迟 0.001s vs 0.743s（快 700 倍以上）。

- 消融：随机选择仅带来微小提升；均匀训练的动作表示验证器显著优于基线；决策关键性加权进一步带来 +3.2（π0）和 +4.1（π0.5）个百分点的提升；仅用动作专家表示作为验证器输入效果最佳。
