Card 03 核心贡献

核心贡献

  • 开展真机消融研究，逐项隔离数据增强、图像编码器预训练、动作表示、点云参考系、裁剪与归一化、预测时域、优化器、去噪采样器和策略家族，并报告每次对比中所有发生变化的训练设置。
  • 提出并验证技能分解 + 经典运动衔接的长程任务流程（经典点对点运动 + 学习的 grasp/insert 技能）。
  • 进行无泄漏的离线指标检验：在各自训练集的验证集上计算 67 个离线指标，检验它们与真机成功率的相关性。
  • 给出表示选择优于超参调优的实证结论，并提供成本、内存与鲁棒性对比。
Card 04 方法描述

方法描述

  • 任务分解为四个阶段：(1) 经典运动到起始位姿（由 FoundationPose 识别夹具位置）；(2) 学习策略抓取并拔出接头；(3) 经典运动搬运至插入夹具；(4) 学习策略完成插入。
  • 策略家族：Diffusion Policy (DP)、ACT、DP3（PointNet 点云）、iDP3（多级点编码器 + 自视角点云）、Flow Matching、π0.5 VLA（PaliGemma 2B + 300M action expert，LoRA 微调）、EquiBot 等变扩散策略。
  • 观测与动作：腕部 RealSense D455 RGB-D，RGB 分辨率 848×480，点云 2048 点；动作为 10 维（末端平移 3 + 欧拉角 3 + 4 个手部关节），可选 6D 旋转（扩为 13 维）；可选第二视角静态相机。
  • 关键消融创新点：ROI 三维裁剪、机器人基座坐标系点云、PointNet 逐层 LayerNorm、绝对动作预测 + 6D 旋转表示。
  • 评分协议：按到达的最深阶段记为 Fail / Grasp / Pick / Insert，报告 95% Clopper–Pearson 区间，配对比较用 Fisher 精确检验；离线指标用 Pearson 相关 + Benjamini–Hochberg 多重检验校正 + 留一策略符号稳定性。

数据集与资源

  • 演示数据：通过 HTC Vive 追踪器 + Manus 手套遥操作采集，ROS 2 录制并以 30 Hz 同步，策略以 10 Hz 运行（已验证 10 Hz 复现 30 Hz 结果）。

  • 训练资源：4× NVIDIA H100；抓取技能 batch 32/GPU，插入技能 batch 160；DP/DP3/iDP3 训练 1000–3000 epochs，ACT 150 epochs，π0.5 每技能 30k steps、batch 32。

Card 06 评估与结果

评估与结果

  • 基准环境：真机双夹具（中心 / 左侧 y=+0.05 m）各 5 次试验，多次复测后按检查点汇总；鲁棒性条件包括光照变化、背景变化、新场地、阳光直射、紧公差插槽。
  • 主要指标：Pick 率 = (I+P)/n、Insert\|pick = I/(I+P)、Insert = I/n，附 95% 置信区间。
  • 表示选择主导性能：ROI 裁剪使 iDP3 抓取率 0 → 100%；逐层 LayerNorm 使 DP3 插入 0 → 70%；基座坐标系点云使 PointNet 抓取 20 → 100%；绝对动作 + 6D 旋转使双视角 π0.5 插入 30 → 100%（欧拉角下仅 89 → 100%）。
  • 最优配置：iDP3 + ROI 裁剪 在两种夹具上均 100% 抓取与插入，仅 69M 参数、1.0 GB 推理内存；双视角 DP 与 π0.5 插入亦达 100%；单块端到端（grasp-and-insert）策略插入率最多仅 10%，而分解式流水线在每次试验中都成功插入。
  • 次阶因素影响小：无任何视觉增强超过未增强基线（40%）；ImageNet 初始化仅利于抓取不耐插入；iDP3 抓取技能的 15 种扰动（优化器、宽度、深度、DPM-Solver++、v-prediction）均未明显优于默认设置。
  • 鲁棒性：iDP3 流水线在光照、背景、场地、阳光下保持 80–100% 插入率；仅紧公差插槽降至 0–40%；RGB DP 在新场地与光照变化下明显退化。
  • 离线指标结论：67 个指标中仅 5 个（平均速度、路径长度、路径长度比、jerk、谱功率等预测轨迹平滑度/直接性指标）可靠相关，且仅在 iDP3 单一家族内成立（r = −0.70 至 −0.80）；验证损失与插入率无关（r = +0.08，p = 0.72），且验证损失在各家族前 250 epochs 即达最小后回升；无任何指标能追踪抓取率。结论：离线指标只能用于同家族内筛选，不能替代真机评测。
