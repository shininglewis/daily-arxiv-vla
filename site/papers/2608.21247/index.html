Card 02 论文概述

论文概述

  • 论文提出 Action-JND 概念，将经典 JND（最小可觉差）理论从人类感知和静态机器感知扩展到具身感知，为视觉-语言-动作（VLA）模型中的 token 压缩提供动作条件化的容忍边界。
  • 现有 VLA 加速方法（如 token 剪枝、KV-cache 重用）主要依赖视觉相似性、注意力分数、显著性等间接代理信号，未直接回答“token 被压缩后是否会导致下游机器人动作不可接受地偏离”这一核心问题。
  • 论文通过建模语言条件下的机器人动作响应来定义 token 变化的可接受性，并在此基础上实现更可靠的 KV-cache 重用和 token 剪枝。
Card 03 核心贡献

核心贡献

  • 将经典 JND 理论延伸至具身感知，形式化定义 Action-JND：在封闭环路控制中，最大可容忍的视觉 token 变化，使得 VLA 策略预测的动作偏差保持在允许范围内。
  • 在深度视觉特征空间中实例化 Action-JND，设计轻量级 token 级 JND 估计器，学习 token 级扰动幅度，并将其转换为动作容忍度得分。
  • 将 Action-JND 得分作为即插即用排序信号，集成到两种代表性 VLA 压缩范式中：KV-cache 重用（stale-KV reuse）和 token 剪枝（token pruning）。
  • 在 LIBERO 机器人操作基准上，基于 OpenVLA 和 OpenVLA-OFT 的实验表明，Action-JND 在多种压缩比下一致提升压缩可靠性，在激进压缩比下提升尤为显著。
Card 04 方法描述

方法描述

  • 给定视觉 token 特征 \(F_t\) 和语言指令 \(\ell\)，冻结 VLA 策略 \(\pi_\theta\) 生成动作；训练一个轻量级估计器 \(G_\phi\) 预测 token 级扰动 \(\hat{\Delta}_t\)，使扰动幅度尽量大但保持动作差异在容忍范围内。
  • 动作差异 \(D_{\mathrm{act}}\) 按策略输出类型实例化：对 OpenVLA 这类离散动作 token 策略使用 KL 散度；对 OpenVLA-OFT 这类连续动作回归策略使用加权 \(\ell_1\) 回归距离（包含平移、旋转、夹爪控制分量）。
  • 估计器架构：先将投影视觉 token 重塑为 \(16\times 16\) 空间特征图，经 \(3\times 3\) 空间卷积、多个空间残差块、通道混合残差块及 \(1\times 1\) 输出投影，输出经 tanh/clipping 限制，形成 token 级 JND 图；双视图设置下主视图与腕部视图分别使用独立参数的估计器。
  • 推理阶段不注入扰动，仅利用预测扰动幅度计算每 token 的动作容忍度得分（绝对或相对形式），对候选 token 按得分降序排序，从而优先压缩动作容忍度高的 token、保留动作敏感 token。

Card 06 评估与结果

评估与结果

  • 评估配置：在 LIBERO 基准上分别测试 KV-cache 重用 和 token 剪枝 两种压缩范式，覆盖多种压缩比（含激进压缩比）。
  • 主要评估指标：压缩条件下的机器人任务成功率（体现动作保持能力）。
  • 关键实验结果：Action-JND 相对于现有 VLA 压缩方法（如 VLA-Cache、VLA-Pruner 等基于视觉稳定性/注意力/重要性的方法）一致提升压缩可靠性；在激进压缩比下，优势尤其显著，表明动作条件化 JND 准则能更好地识别真正可压缩的 token，减少因压缩导致的动作偏差。
