Ego4WAM: What Matters When Scaling Egocentric Human Data for Robot Learning?

2026-09-30 · 原文 · 翻译 · 2609.40341

Card 03 核心贡献

核心贡献

  • 在受控 WAM 框架下，固定模型 backbone，系统解耦大规模 human data scaling 中常被耦合的数据属性与使用策略。
  • 表征 human-robot alignment、数据时长、任务多样性 和 可用监督 对下游机器人学习的不同影响，揭示仅用总时长或总任务数衡量数据规模并不充分。
  • 通过真实机器人和 RoboDojo 的闭环策略性能评估 egocentric data 效用，提供“收集什么数据、保留什么监督、如何使用 human data”的实践指导。
  • 提出 Egocentric Data Pyramid 和分阶段训练协议，验证 video-only pre-training 无需动作标签即可提供强 dynamics prior，并改善后续 world-action learning。
Card 04 方法描述

方法描述

  • Egocentric Data Pyramid：按最可靠监督级别组织数据，从少量 robot-aligned human demonstrations，到多任务 video-action data，再到大规模 video-only data。
  • World-Action Model 框架：视频分支负责 world modeling，动作分支负责 action prediction；语言指令作为条件信号，本体感觉仅输入动作分支；两分支通过共享注意力交互。
  • 共享注意力包括 base 和 joint 两种形式：base 中未来动作 token 只 attend 当前视觉上下文；joint 中动作 token 还可 attend 预测的未来视觉表示。
  • Unified Action Space：双臂动作为 32D，每臂 16D = 6D joint + 1D gripper + 9D EEF；human data 仅监督共享的 EEF 和 gripper 维度，缺失维度通过 validity mask 和 analytic forward-noise 路径处理。
  • 训练协议：pre-training 在 egocentric video 上优化 world-modeling 目标；mid-training 在 action-annotated data 上联合优化 world 和 action；post-training 使用机器人演示及可选 robot-aligned human data 适应下游操作任务。
  • EgoAlign 数据处理：使用 VGGT-Omega 估计相机轨迹，GroundingDINO 定位手部区域，HaMeR 估计 3D 手部姿态，并结合质量过滤获得可靠 human action trajectories。
Card 05 数据集与资源

数据集与资源

  • 内部数据集 EgoAlign：robot-aligned human demonstrations，采集任务和环境与真实机器人实验匹配。
  • 相关/公开 egocentric 数据包括 Ego4D、Egocentric-10K、RekaDaily-10K、EgoDex、EgoLive、EgoSuite、EgoVerse 等，构建时参考 OpenAoE pipeline。

Card 06 评估与结果

评估与结果

  • 评估环境包括真实机器人闭环操作任务和 RoboDojo 官方协议；主要指标为 progress score 和 success rate，重点关注 Generalization、Precision、Long-Horizon 等类别。
  • 真实机器人任务包括 Place into the Basket、Fold Cloth，以及扩展任务 Fold Towel、Tighten a Bottle Cap、Stack Plates and Bowls、Heat Food with a Microwave。
  • 在 Place into the Basket 上，robot-only 策略 ID 成功率 60%，object-OOD 10%，scene-OOD 0%；加入对应 human demonstrations 后，object-OOD 提升至 60%，scene-OOD 提升至 20%。
  • 在 Fold Cloth 上，机器人数据从 300 降到 100 会显著降性能；加入 human data 可恢复到 80% ID、60% object-OOD、80% scene-OOD；但机器人数据仅 20 条时，human data 不能完全替代 robot supervision。
  • multi-task mid-training 后，仅用 20 条目标机器人演示即可达到 80% ID、80% object-OOD、60% scene-OOD，说明广泛多任务 human 经验可进一步降低目标机器人数据需求。
  • 数据时长与任务多样性是不同 scaling 轴：固定 500 个任务时，时长从 1K→4K 小时提升 Generalization 5.0→7.8、Long-Horizon 12.0→16.2；任务数从 500→6K 提升 Generalization 5.0→7.0、Long-Horizon 12.0→16.2，但 Precision 随长尾任务下降。
  • Video-only pre-training 无需动作标签即可将 RoboDojo 平均分从 6.39 / 3.15% 提升到 14.13 / 9.45%；随后 video-action mid-training 提升到 15.04 / 10.78%；若无 video pre-training，mid-training 仅 10.28 / 6.42%。
  • 从同一 video-pretrained 模型出发，joint 共享注意力相对 base 将 RoboDojo 平均分从 14.13 提升到 20.29，成功率从 9.45% 提升到 14.35%；Ego4WAM 在 Precision 和 Long-Horizon 等类别表现突出，例如 Long-Horizon score 44.16、SR 29.75%，Precision score 31.16、SR 22.25%。
  • 总体结论：human data 可减少但不能完全替代 robot data；数据时长和任务多样性分别影响不同能力；egocentric video 为 world-action learning 提供强 dynamics prior；其价值取决于数据分布、可靠监督以及在训练 pipeline 中的使用方式。
