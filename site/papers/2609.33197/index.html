Card 02 论文概述

论文概述

  • 提出 TAO-DA，一个面向双臂协调操作的视觉–语言–动作（VLA）框架，目标是在共享任务级多模态推理的同时，实现按臂分离的动作生成。
  • 指出现有 VLA 模型缺乏显式机制解耦双臂状态与意图，导致非活跃臂对活跃臂的跨臂干扰，降低任务成功率。
  • 通过双臂意图路由与双臂专家结构，缓解单臂执行、双臂顺序执行及非对称角色演示场景下的干扰问题。
Card 03 核心贡献

核心贡献

  • 将非活跃臂干扰形式化为动作生成问题，并系统比较三种 DAE 变体：统一式（Single-Tower）、掩码解耦式（Dual-Mask）、独立臂级处理（Dual-Tower）。
  • 提出 DAIR（Dual-Arm Intent Routing），结合规则解析与学习式多模态分类，预测左臂、右臂或双臂执行意图。
  • 设计轻量任务进度预测模块，通过 GRU 与交叉注意力从本体感受与视觉观测估计帧级任务完成度，支持路由保持机制与多机器人协同调度。
  • 在真实机器人上开展受控非活跃臂扰动实验、模糊指令下的路由消融，以及跨臂技能复用与组合的探索性研究。
Card 04 方法描述

方法描述

  • 使用 SigLIP 编码多视角图像（1 个自视角 + 2 个左右末端执行器视角），由冻结的 Eagle-2.5-VL 主干融合视觉与语言 token。
  • DAIR 两阶段推理：第一阶段规则解析器识别“左臂/右臂/双臂”等显式表达；第二阶段用可学习 query 池化多模态特征，经 MLP 输出三类 logits，映射为二值活跃臂向量 r=[r_L, r_R]。
  • 路由训练使用交叉熵损失 L_route；推理时引入基于预测进度的保持机制（阈值 τ_hold）稳定路由决策。
  • DAE 三种变体：Single-Tower 将双臂状态与动作 token 拼接进同一 DiT；Dual-Mask 通过臂模式注意力掩码限制 token 交互；Dual-Tower 使用两套参数独立的 DiT 分支实现强解耦。
  • 采用 flow matching 目标进行动作生成；Dual-Tower 使用活跃臂监督 L_act = r_L·L_FM^L + r_R·L_FM^R。
  • 加入臂条件视角掩码：非活跃臂的末端视角 token 在进入 VLM 前被屏蔽，自视角始终保留。
  • 任务进度模块用 GRU 编码 DiT 时序特征，经交叉注意力与 VLM 表示融合，回归头预测归一化轨迹时间。
Card 05 数据集与资源

数据集与资源

  • 在 AGIBOT G1 人形机器人上采集，配备两条 7-DoF 机械臂与 3 个 RGB-D 相机，运行频率 30 Hz。
  • 共 9,080 条真实遥操作轨迹，总时长 31.9 小时。
  • 单臂任务：Steamer Delivery（1,200 条 / 3.0 h）、Bottle Grasping（880 条 / 3.2 h）、Fruit Grasping（4,000 条 / 14.4 h）、Tea Pouring（1,600 条 / 6.0 h）。
  • 双臂任务：Collaborative Tea（500 条 / 2.0 h）、Desktop Organization（900 条 / 3.3 h）。
  • 路由评估按轨迹级别随机留出 10% 作为测试集。
  • 训练资源（GPU/TPU 具体型号与数量）在提供的 HTML 原文中未明确给出。
Card 06 评估与结果

评估与结果

  • 单臂任务：TAO-DA 平均成功率 88.4%，优于 GR00T N1.5（82.0%）与 π0.5（80.5%），在 4 项任务上取得最佳或并列最佳。
  • 双臂任务：Collaborative Tea 达 100%，Desktop Organization 达 95%，后者超过 GR00T N1.5（80%）与 π0.5（85%）。
  • 非活跃臂扰动鲁棒性（离线 MSE 比值）：Single-Tower 为 1.94 / 1.60（右/左臂活跃），Dual-Mask 降至 1.46 / 1.13，Dual-Tower 为 0.99 / 1.00。
  • 真实机器人持续扰动：Dual-Tower 保持 100% / 95% 成功率，而 Single-Tower 仅 25% / 20%，Dual-Mask 为 65% / 65%。
  • 路由精度：左臂 85.37%、右臂 83.31%、双臂 96.13%；混淆矩阵显示无常左右误判，误差主要集中于单臂与双臂的区分。
  • 路由消融：移除任务进度模块使右臂精度从 83.31% 降至 68.48%、双臂从 96.13% 降至 89.22%；固定指令下右臂为 78.66%。
  • 跨臂技能复用：仅用双臂演示训练时，Dual-Tower 在左/右/双臂模式达 100% / 90% / 95%，Single-Tower 为 80% / 50% / 50%。
  • 部署案例：自主餐厅场景整合 3 类机器人、协调 6 台机器人、20+ 服务任务，在 101 次全流程试验中取得 92.08% 端到端成功率。
  • 局限性：架构比较非参数量对齐；DAIR 主要用路由精度评估；扰动实验仅覆盖本体感受扰动；任务进度以归一化轨迹时间监督而非语义完成度。
