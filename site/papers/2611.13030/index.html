Card 03 核心贡献

核心贡献

  • 提出从演示轨迹学习视觉选择：为共享的视觉选择器设计动作监督与动作条件下的未来视觉转移预测两个互补目标，前者保留复现策略与专家动作所需信息，后者用同一表征监督后续视觉变化。
  • 提出 Decision Influence Estimator（DIE）：一个轻量模块，结合图像 patch 局部特征、跨视角视觉上下文、语言指令与归一化本体感知（proprioception）为每个视觉 token 打分，并按相机视角固定预算做一次性硬选择。
  • 设计预算约束的可微门控机制：用 Laplace 累积分布函数将分数转为门控权重，按视角隐式求解阈值以满足固定预算，并以黑参考图像特征做残差填充，从而支持对选择器的端到端训练。
  • 保持模块化即插即用：训练时的未来预测头在部署阶段被移除，部署仅需选择器 + 冻结策略，保留原生动作生成过程与策略参数，可跨不同 VLA 架构使用。
  • 在仿真与真实世界均验证有效性：LIBERO 1.57×、RoboCasa365 1.46×、真实任务 1.47× 加速，且成功率接近未剪枝基线。
Card 04 方法描述

方法描述

  • 固定预算的视觉选择：冻结视觉编码器 $E_\omega$ 与投影器 $P_\omega$ 产生 token 特征，选择器 $S_\theta$ 仅用当前输入（视觉特征、指令 $\ell$、本体感知 $p_t$）打分，总预算 $K$ 按视角拆分为 $k_c$（$\sum_c k_c = K$）。
  • 动作监督：门控表征经冻结策略 $F_\omega$ 得到动作，同时对齐全输入稠密预测（stop-gradient 目标，保持原策略行为）与演示动作块，损失为两者 L1 误差的平均；随机动作生成时两分支共享采样噪声。
  • 视觉转移监督：固定摘要算子 $R$（2×2 空间网格平均 → 固定高斯投影到 64 维 → 非仿射层归一化）压缩特征；两层预测器 $H_\phi$ 以门控当前摘要与演示动作预测 $h$ 步后观测的摘要，目标端 stop-gradient；该项训练后即弃用。
  • 任务条件打分（DIE）：token 特征经 LayerNorm + 线性投影并加相机/位置嵌入；视角级 Mean/Max 池化 + 仿射映射得视觉条件，指令用冻结词嵌入表加投影与编码器平均得语言条件，本体感知经 MLP 得状态条件；三者相加广播后由两层 MLP（SiLU）打分，输入端全部 detach。
  • 可微门控实现：$g = F_{\text{Lap}}((s-b)/\alpha)$，每视角单独求阈值 $b$ 满足预算，梯度通过预算约束的隐式微分获得，训练中退火温度 $\alpha$。
  • 部署：每视角一次性 TopK 硬选择（同分按原索引确定），恢复相机与 patch 顺序后物理打包为紧凑序列，交由冻结策略原生动作生成；稠密教师分支、黑参考门控、未来预测器全部移除。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率、策略推理延迟（含视觉编码、token 选择与打包、语言主干计算、动作预测）、相对未剪枝基线的推理加速比。
  • LIBERO + OpenVLA-OFT（512 tokens，剪枝 50%/75%/87.5%）：75% 剪枝下延迟降至 68.75 ms（1.57×），平均成功率 95.75%，仅比未剪枝基线 97.00% 低 1.25 个百分点；50% 剪枝为 81.39 ms（1.33×）/ 96.58%；87.5% 剪枝延迟收益饱和（66.21 ms，1.63×）但成功率降至 93.92%，说明过度剪枝会丢失精细空间线索。
  • RoboCasa365：π0.5 平均 1.37× 加速（延迟 51.50 ms），XR-1 平均 1.52× 加速（延迟 142.93 ms）；XR-1 上较最强剪枝基线在 seen/unseen 复合任务分别高 3.00 与 1.64 个百分点，seen atomic 任务与未剪枝策略差距在半百分点内。
  • 真实世界：平均推理延迟从 137.25 ms 降至 93.25 ms（1.47×），平均成功率 61% 略高于未剪枝 π0.5 的 60%，单任务加速 1.44×–1.51×。
  • 消融实验：加入未来视觉监督后，在 256/128/64 token 预算下成功率分别提升 1.41 / 1.17 / 1.17 个百分点；未来目标时间对应关系被随机打乱后，2000 次更新时教师动作 L1 误差高出 37.8%，证明正确的时间对齐至关重要。
