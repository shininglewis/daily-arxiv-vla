论文概述

Card 03 核心贡献

核心贡献

  • 提出 Latent Transition Memory（LTM）：用紧凑的潜在转移编码历史，把记忆聚焦于"交互引起的变化"，避免稠密 RGB 历史带来的上下文开销，也无需记忆专用语义标注或外部推理模型。
  • 开发 LTM-π：将转移记忆通过轻量适配器注入 π0.5 的推理上下文，配合因果注意力、持续 KV 缓存与异步转移编码实现高效在线控制，H100 上策略推理时间为 66.71 ms。
  • 系统刻画转移记忆的信息量、数据扩展性与上下文预算权衡：消融实验区分转移内容与纯时间线索；RoboMME 数据扩展 10 倍使成功率从 57.67% 提升到 87.50%；过程监督的 Cup Swap 解码最终状态恢复率达 97.93%；200 token 预算下仍保持 84.00% 成功率。
  • 在真实机器人 Galbot G1 的重复抓放计数任务中，成功率从 11.25% 提升至 82.50%。
  • 公开数据集、训练代码与推理代码：https://github.com/buaa-colalab/LTM-pi。
Card 04 方法描述

方法描述

  • 潜在转移编码：使用冻结的潜在动作模型（LAM）编码器 E_φ 将相邻观测对 (o_{i-1}, o_i) 编码为 32 维转移向量 z_i，解码器 D_ψ 在 o_{i-1} 条件下重建 o_i，迫使潜码捕捉时序变化而非冗余外观。
  • 紧凑性与局部性：每个转移为低维向量；每个编码只依赖相邻两帧，支持增量构建记忆而无需重编码早期帧。
  • 记忆适配器：对归一化转移（使用数据集级均值/方差 + stopgrad）用两层 MLP（512→2048）投影到 PaliGemma-3B 主干（π0.5）的 2048 维隐空间，生成记忆 token。
  • 上下文拼接：序列形如 [语言指令; 记忆 token; 当前视觉 token]；语言–记忆前缀内部使用因果注意力，当前视觉 token 可关注该前缀，使 KV 表示可复用。
  • 延迟记忆准入：采用固定滞后 k（τ_t = max(0, t−k)），每个转移在观测对可得后异步编码并存入潜在缓冲区，拥有 k 步计算余量，使 LAM 计算与动作执行重叠。
  • KV 缓存效率：每 chunk 主干自注意力成本由 O((n+b)²) 降为 O(nb+b²)，对固定 b 呈对缓存长度的线性关系。
  • 视频演示视觉锚点：对视频条件任务，额外加入演示序列与执行序列的首帧视觉锚点及不同可学习类型嵌入，缓解演示与执行环境初始布局差异。
  • 可选 token 压缩：在线合并最相似的相邻投影 token，以固定预算约束执行记忆增长（合并需刷新相关缓存）。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboMME（16 个依赖历史的操作任务，4 个 suite：Counting、Permanence、Reference、Imitation）与 LIBERO-Mem（10 个任务，4 个对象中心记忆维度：Object Motion (OM)、Object Sequence (OS)、Object Relations (OR)、Object Occlusion (OO)）。
  • 扩展数据设置：RoboMME-10x，每个任务族从 100 条扩展到 1,000 条 episode。
  • 冻结潜在动作编码器：DreamDojo 与 CD-LAM。
  • 基座策略：π0.5（PaliGemma-3B 主干）。
  • 训练资源：8 张 H100 GPU，batch size 128；RoboMME 原始数据训练 40K 步，LIBERO-Mem 30K 步，RoboMME-10x 120K 步；学习率从 2.5×10⁻⁵ 衰减到 2.5×10⁻⁶，1K 预热步。
  • 关键超参：默认滞后 k=5（数据扩展与 token 压缩实验用 k=10）；动作 chunk 长度 RoboMME 50 步、LIBERO-Mem 10 步，分别执行前 10 步与 5 步后重规划；RoboMME 不使用本体感知输入。
  • 评测协议：LIBERO-Mem 每任务 20 个布局，RoboMME 每任务 50 次 rollout；基础数据 RoboMME 结果使用 3 个随机种子 报告平均成功率。
Card 06 评估与结果

评估与结果

  • RoboMME（原始数据）：使用 DreamDojo 转移的 LTM-π 达到 58.54% 平均成功率，而无记忆 π0.5 基线仅 17.93%。
  • LIBERO-Mem：LTM-π 达到 80.5%，对比纳入比较的最强基线 42.5%。
  • 记忆内容消融：将依赖观测的潜在转移替换为固定随机表示，RoboMME 成功率从 57.67% 降至 44.50%，验证转移特异性内容（而非仅时间进度线索）的贡献。
  • 推理延迟：使用 5 步滞后相对零滞后，潜在编码器阻塞估计从 114.25 ms 降至 9.47 ms，成功率仅从 57.88% 微降到 57.67%。
  • 数据扩展：RoboMME 数据扩展 10 倍后成功率从 57.67% 升至 87.50%，四个 track 全部提升，最弱的 Reference track 提升 47.50 个百分点；仅延长原数据训练到 120K 步无明显增益。
  • 对比强基线：在数据预算与监督假设不同的条件下，LTM-π 整体超过使用 9× 数据的 PonderPounce 结果 11.96 个百分点。
  • 时序组合诊断：VideoUnmaskSwap 与 ButtonUnmaskSwap 分别达到 74% 与 62%，而其非 swap 对应任务为 100%，表明局部转移组合为持久对象状态仍是挑战。
  • Cup Swap 诊断：过程监督下从潜在转移恢复最终状态达 97.93%，而仅最终状态监督仅 2.40%。
  • Token 压缩：RoboMME-10x 上 200-token 预算保持 84.00% 成功率（无压缩为 87.50%），并在 profiled 训练查询上将平均转移 token 数减少至少 38.26%。
  • 真实机器人：在 Galbot G1 上，LTM-π 将平均成功率从无记忆 π0.5 的 11.25% 提升到 82.50%。
  • 主要对比方法：RoboMME 上包括 DP-Unet、OpenVLA-OFT、π0.5（含 past actions 与 symbolic/perceptual/recurrent 记忆变体）、MemoryVLA、SAM2Act+、MemER、WeaveLA、PonderPounce (9B)、SimpleMemVLA、T²Mem；LIBERO-Mem 上包括 π0.5、SlotVLA、Naive E-SlotSSM、MemoryVLA、GMP、MemoryVAM、2AM 等。
