Card 03 核心贡献

核心贡献

  • 提出域不变场景表征（DISR），将人类与机器人观测抽象为共享的语义、空间与关系结构，使社会规范等人类导航先验能从大规模第一人称视频蒸馏并跨本体迁移。
  • 提出 DR-VLA，一种 Mixture-of-Transformers 隐世界动作模型，其理解、世界与动作三个专家解耦不同数据源的监督，可方便扩展到多种导航场景。
  • 构建 EgoLynx 数据集，将 10k 小时第一人称网络视频与 2,000 段遥操作四足机器人片段按统一格式（指令、描述、DISR 目标）配对，支持无动作预训练与数据高效适配。
  • 提出 QNS（Quadruped Navigation Score），一种伪闭环四足导航指标，综合评估安全性、指令遵循、舒适性和行进进度。
  • 实验上，DR-VLA 在真实四足导航中 QNS 超越最优方法约 5%，并在 NAVSIM 上取得 92.1 PDMS，验证表征的跨本体通用性。
Card 04 方法描述

方法描述

  • DISR 构造：仅从 RGB 视频生成，使用冻结的 SAM 3 提取语义掩码、Depth Anything 3 估计相对深度；因编码器只接收 (S_i, D_i) 而不接触 RGB，纹理、光照、成像风格等外观因素被构造性地排除。
  • 关系编码：DISR 编码器 E_φ 与轻量解码器 D_φ 组成自编码器，对连续 M=10 帧做通道拼接后在全部帧 token 上施加因果时空自注意力，学习跨帧实体对应、相对深度排序与共现关系；解码重构语义与深度并加正则项 R(z_i)。
  • 三专家架构：理解专家 f_u 基于预训练 Qwen3-VL-2B，以链式思维描述作辅助监督接地指令；世界专家 f_w 在可学习世界 token 上预测未来 DISR 潜变量；动作专家 f_a 通过条件流匹配（flow matching）生成机器人轨迹。
  • 结构化信息流：采用块级注意力掩码，世界与动作 token 不关注描述文本，使训练与推理输入一致；动作 token 对前缀与世界 token 不可见，故 h^u、h^w 推理时只计算一次并在积分步间复用。
  • 两阶段训练：Stage 1 在 EgoLynx-Web 上以 L_1 = L_cap + λ_w L_world 训练理解与世界专家（刻意不估计伪轨迹）；Stage 2 在 EgoLynx-Robot 上以 L_2 = L_1 + λ_a L_act 微调全部参数，并初始化动作专家与四路鱼眼视角嵌入。
  • 创新点：用结构化场景表征替代保留录制本体的通用视觉嵌入作为未来预测目标，并依据监督来源划分专家；推理时无需教师模型与 DISR 编码器。
Card 05 数据集与资源

数据集与资源

  • EgoLynx-Web：从 YouTube 收集约 10,000 小时第一人称网络视频（含步行、骑行等），覆盖城乡、不同时段与天气，规模约为 Sekai 的 2 倍、Ego4D 的 3 倍。
  • EgoLynx-Robot：2,000 段训练片段（约 17 小时）遥操作轮腿机器人真实配送数据，另设不重叠的保留测试集。
  • NAVSIM v1：用于驾驶泛化实验，按标准协议在 navtrain 训练、navtest 评估（仅用相机输入）。
  • 模型规模：理解专家由 Qwen3-VL-2B 初始化；驾驶模型共享同一架构，仅 V、N_a、δ 不同。
  • 训练资源：Stage 1 训练 20k 步，Stage 2 训练 5k 步，均在 32 块 NVIDIA H800 GPU 上完成。
Card 06 评估与结果

评估与结果

  • 评估环境：真实世界四足导航（EgoLynx-Robot 保留测试集）与 NAVSIM 自动驾驶基准。
  • 主要指标：开环平均/最终位移误差（ADE/FDE）、平均/最终朝向误差（AHE/FHE）；伪闭环指标无碰撞（NC）、可行区域合规（WAC）、碰撞时间（TTC）、间隙（CL）、自身进度（EP）、指令遵循（IC）及综合 QNS；驾驶侧为 PDMS。
  • 关键结果：相对该指标最强竞争结果，DR-VLA QNS 提升约 5%、FHE 降低 14.6%；在 NAVSIM v1 上（无网络预训练）取得 92.1 PDMS，移除世界专家后降至 89.5。
  • 消融结论：网络视频预训练提升保留机器人数据上的泛化性能；作为未来预测目标，DISR 优于 5 种通用视觉表征，且无需 Box/Line 标注或点云即可接近任务专用 3D 感知（OCC+BEV）的仅目标性能；将感知作为在线策略输入可进一步提升 QNS 但增加计算成本。
