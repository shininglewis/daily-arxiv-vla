Card 02 论文概述

论文概述

  • 论文研究具身视觉跟踪（Embodied Visual Tracking, EVT）：机器人需在遮挡、相似外观干扰物和模糊指令下，持续跟随语言指定的目标人物。
  • 核心发现：仅对紧凑 VLA 跟踪器的规划头做 PPO 后训练，能提升成功率与跟随率，但会把部分原本“目标丢失”的失败转化为“物理碰撞”，即持续性提升与安全代价同时增加。

Card 03 核心贡献

核心贡献

  • 构建 0.6B 冻结主干 VLA 跟踪栈（Qwen3-0.6B + 规划头），并实证分析仅规划头 PPO 后训练的安全代价：DT 场景碰撞率从 11.01% 升至 13.78%，SR/FR 全面提升。
  • 提出 TRACE 选择性目标状态风险门控：从 84 个目标状态线索预测碰撞风险，仅在超过校准阈值时缩放下一路点的平移分量；DT 上 CR 降低 3.96 个百分点、SR 提升 2.03、FR 提升 2.14，每步约 50 μs，仅 <2% 的执行动作被改变。
  • 设计匹配衰减对照实验（恒定衰减、随机触发、37 步滞后风险），证明增益来自干预时机与目标状态的时间对齐，而非衰减幅度或干预稀疏性本身。
  • 提出并评测比协议：用同臂零对照（identical-arm null pairs）量化评测器漂移，TRACE 的 ΔCR 为 −3.77 点，而同臂零对照仅 −0.29 点，说明效应超出评测波动。
  • 指出现有 EVT-Bench 评测器存在跨回合状态泄漏，修正后指标变动数个百分点，并在统一修正评测器上重测全部结果。
Card 04 方法描述

方法描述

  • 三阶段架构：监督跟踪器（视觉编码器 + Qwen3-0.6B 语言主干 + 识别适配器 + 规划头，输出 8×3 路点序列），经 SFT 训练后冻结编码器、主干与适配器。
  • 规划头 PPO：仅更新确定性路点头 μθ、探索项与价值头；奖励为跟随、碰撞、距离缩短、过远惩罚的加权和，权重 (1.0, 5.0, 0.5, 0.3)；PPO + GAE，两轮各 200 条 on-policy 回合。
  • 风险头：小型前馈网络 f_φ（约 28k 参数），输入 84 维目标状态向量（候选框几何与置信度、top-2 身份间隔、学习到的距离-方位探针、记忆年龄与状态标志、上一命令与预测路点、可见人数、步索引等），输出碰撞风险 r_t ∈ [0,1]，并附丢失目标/失败的辅助输出。
  • 门控执行（式 2）：当 r_t ≥ τ 时执行 (min(v_x,0)+s_f·max(v_x,0), s_l·v_y, s_ω·ω)，即保留偏航、横向衰减、仅在前向指令时衰减前向速度（后退减速无益于降低碰撞）；否则原样执行 PPO 动作，因此门控不会引入规划器未提出的运动。
  • 离线训练 + 在线校准：风险头在早期策略的 DT 轨迹上离线拟合，标签取碰撞终止前固定窗口内的步；DT 工作点为 (τ, s_f, s_l, s_ω) = (0.868, 0.25, 0.60, 1.00)；AT 单独拟合风险头并校准阈值。

Card 06 评估与结果

评估与结果

  • 指标：成功率 SR、跟随率 FR、碰撞率 CR（百分比），遵循 EVT-Bench 官方协议；采用修正后的无泄漏评测器，所有对比在同样 1,380 个回合、同样 5 次训练运行上配对完成。
  • 统计方法：回合级 bootstrap 置信区间（10⁴ 次重采样）+ 碰撞符号翻转置换检验（2×10⁴ 次），并以同一评测器、同一批回合的并发评测与同臂零对照作为基线噪声参照。
  • 主要数值（SR/FR/CR，%）：

- SFT 基座：STT 78.26/75.70/4.13；DT 41.38/54.46/11.01；AT 59.13/69.82/7.39

- + 规划头 PPO：STT 86.45/80.88/4.09；DT 43.99/55.44/13.78；AT 63.67/72.48/8.74

- + TRACE：STT 87.51/81.80/3.91；DT 46.02/57.58/9.83；AT 64.41/72.57/8.14

  • DT 配对增量：ΔSR +2.03 [+0.90, +3.17]、ΔFR +2.14 [+1.22, +3.05]、ΔCR −3.96 [−4.78, −3.14]，p < 10⁻⁴；在 281 个未参与风险头拟合的留出回合上 ΔCR 仍为 −4.13。
  • 并发评测：ΔSR +2.71、ΔFR +2.36、ΔCR −3.77，而同臂零对照仅 −0.29（区间含零）；STT 结果来自逐轮模型选择而非门控（门控在 STT 上触发率 0%）。
  • 对照实验：三种匹配衰减对照在 DT 上均停留在 PPO 参考水平（CR 13.67–14.00）；强均匀衰减虽把 CR 降到 6.01，但 SR 崩至 6.54、FR 仅 24.25；基于邻近度的规则仅改变 CR −0.68（区间含零）。
  • 局限：AT 校准门控的配对增益在并发评测下未复现（ΔCR −0.06，p=0.90）；风险分数经学习而非形式化认证，高分步若被风险头漏检则按原动作执行。
