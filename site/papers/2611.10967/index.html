BAT-WAM: Bridging Action and Touch in World-Action Models for Dexterous Hands

2026-11-07 · 原文 · 翻译 · 2611.10967

论文提出 BAT-WAM，这是一个面向世界动作模型（WAM）的多模态表征框架，用于在 RGB 视觉条件下打通灵巧手关节状态（Joint/State）与全手触觉（Touch）两类模态。 论文要解决的问题是：在灵巧手操作场景中，关节状态与触觉观测可能部分缺失或完全缺失，而 RGB 图像虽然能提供场景与手–物几何信息，但不足以可靠恢复这些缺失模态。 论文观察到手部状态与触觉信息之间存在强相关性这一此前被忽视的跨模态关系，并据此设计可双向学习、可互相补全的表示接口，服务于动作生成主干网络。

Card 03 核心贡献

核心贡献

  • 揭示了一个此前被忽视的跨模态关系：灵巧手关节状态与触觉观测之间存在强相关性。
  • 提出 BAT-WAM 跨模态表征框架，将离散的触觉/状态表征与连续的 RGB 上下文通过多模态桥接机制融合。
  • 为 Touch 与 Joint 分别设计独立的 codebook 与物理解码器，在保留各自物理语义与数据结构的同时，让它们在同一连续潜在空间中相互作用。
  • 支持两类任务：静态掩码补全（full-mask / local-mask）与条件式未来触觉预测，且在同一接口下完成。
  • 在 HT-Bench 离线基准、7 项真实机器人任务及零样本泛化评测上均超越基线。
Card 04 方法描述

方法描述

  • 模态专用 Tokenizer：Touch 为稠密空间压力场，按空间网格为每只手编码为 196 个 token；Joint 为低维向量，编码为 8 个 token；两者各自经过编码器、投影层、VQ 码本与物理解码器完成量化与重建。
  • RGB 连续通路：使用冻结的 SigLIP 编码器提取图像 patch 特征，再由可学习 query 生成上下文 token；RGB 不参与码本量化，也没有重建目标。
  • 跨模态桥接（Cross-Modal Bridging）：将掩码 Touch、Joint、RGB 与任务/掩码提示拼接后送入统一 Transformer 桥接模块，各模态特征映射到公共 256 维空间，并加入模态与视角身份嵌入；通过注意力可见性矩阵 V_T 严格限制模型访问被隐藏的信息。
  • 训练目标：包含单模态重建损失、跨模态掩码预测损失、桥接表征与完整目标特征对齐的潜在对齐损失，以及码本匹配损失与承诺损失。
  • 多模态时序预测：以历史 Touch、历史 Joint 与含目标时刻的 RGB 为条件，预测目标时刻触觉 p(T_t \|T_{t0:t-1}, J_{t0:t-1}, I_{t0:t})；目标时刻 Touch 仅用于监督。
  • 桥接模块输出的表征被拼成额外输入 token，用于条件化 π0.5 WAM 主干进行动作生成。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评测指标：RMSE（越低越好）与 cIoU（连续值交并比，越高越好）；F 类指标在全有效触觉像素上计算，H 类指标仅在局部掩码遮挡的有效像素上计算；真实实验使用任务成功率。
  • 全掩码触觉补全：BAT-WAM（Action+Image）达到 F-RMSE 0.0145、F-cIoU 0.8933，对比 HandTouch 的 0.0221 / 0.8316，RMSE 降低 34.73%。
  • 局部掩码补全：BAT-WAM（Action+Image）达到 H-RMSE 0.0137、H-cIoU 0.8984，对比 HandTouch 的 0.0224 / 0.8211，隐藏区域 RMSE 降低约 38.8%；mean-fill / zero-fill 明显更差。
  • 未来触觉预测：BAT-WAM 取得 RMSE 0.0157、cIoU 0.8901，相对 HandTouch 的 0.0211 / 0.8486 降低 RMSE 25.59%；摘要另称相对 OpenWAM + HangTouch 均值 RMSE 降低 85.56%。
  • 真实机器人实验：平均成功率 79.3%，高于 OpenWAM-α（66.4%） 与 OpenWAM-α + HandTouch（69.3%）；除 Close Drawer 外每项任务均最优，Wipe Whiteboard 上优势最大（45% vs 15% / 25%）。
  • 零样本泛化：在颜色、尺寸、形状、布局、位姿五类未见变化下平均成功率 54.5%，高于 38.5% / 42.0%；未见布局下达 80.0%，但未见尺寸（37.5%）与形状（27.5%，对比见过的 72.5%）仍是主要瓶颈。
  • 消融与条件分析：输入可用性（Image / Action）越多性能越好，Action+Image 组合最优，验证关节状态与视觉上下文可互补缺失的触觉信息。
