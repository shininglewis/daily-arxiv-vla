论文概述

  • 论文区分了 What-level 指令（指定任务本身，如“把胡萝卜放到盘子上”）与 How-level 指令（指定如何执行任务，如“握住胡萝卜的绿色端”），并系统诊断 VLA 模型对 How-level 指令的遵循能力。

Card 03 核心贡献

核心贡献

  • 提出 离线纠正（Offline Correction） 与 在线干预（Online Intervention） 两种诊断设置，揭示当前 VLA（包括为增强指令遵循设计的模型）无法可靠遵循 How-level 指令。
  • 提出 训练数据结构假设：将每个 episode 与单一指令配对限制了 How-level 指令遵循；通过引入 enriched instructions（段级丰富指令）显著提升动作层面的响应性（从约 53% 提升至约 84%），但未持续提升任务成功率。
  • 提出 SIMPLER-IN，一个基于 SIMPLER 的 Instruction-Necessity 基准，任务成功必须依赖 How-level 指令，揭示现有模型在严格条件和 OOD How-level 指令上仍然失败。
  • 进行 注意力层面分析，发现失败并非由关注度不足所致，支持训练数据结构是共同潜在原因的判断。
Card 04 方法描述

方法描述

  • 离线纠正：收集失败 episode，在同一初始状态下重跑三种条件——retry（仅换随机种子）、correction（追加准确纠正）、inverted correction（追加反转纠正），通过 McNemar 检验比较是否真正使用了指令内容。
  • 在线干预：采用双系统设计，Qwen3-VL-8B 作为 System 2 监控执行并生成纠正（corrector 模式）或子步骤指令（unified 模式），VLA 作为 System 1 执行，评估部署场景下的 How-level 指令遵循。
  • Enriched Instructions：基于 BridgeData V2 的 Embodied Chain-of-Thought (ECoT) 标注，按子任务变化切分 episode，用 GPT-5.4-mini 为每个 segment 生成一段祈使句作为 How-level 指令，覆盖 43,771 个 episode、共 272,662 条丰富指令。
  • 动作层面分析：对比模型在 correction 与 inverted correction 下轨迹的偏移方向，若轨迹朝指令指定方向偏移更远则视为遵循指令（随机水平为 50%）。
Card 05 数据集与资源

数据集与资源

  • 训练数据：BridgeData V2 及公开的 ECoT 标注，构建 272,662 条 enriched instructions（覆盖 43,771 个 episodes）。
  • 评估环境：SIMPLER 的 WidowX 机器人短时程抓取放置任务；新提出的 SIMPLER-IN 基准（Path、Grasp、Place 三类任务）。
  • 评估模型：π₀、InternVLA-M1、QwenGR00T、InstructVLA、LangForce 五个 VLA 模型家族。
  • 辅助系统：Qwen3-VL-8B（System 2）、Gemini 3.1 Pro（生成纠正）、GPT-5.4-mini（生成富集指令）。
  • 训练方式：采用各模型原始训练协议 + LoRA 微调，使用有限训练预算。
Card 06 评估与结果

评估与结果

  • 离线纠正：所有模型的 retry 恢复成功率均高于 correction；correction 与 inverted correction 无显著差异（部分模型 inverted 更高），未出现预期排序 correction > retry > inverted。
  • 在线干预：corrector 模式对除 π₀ 外所有模型均降低任务成功率；unified 模式对每个模型都大幅降低成功率（如 π₀ 下降 12.8%、InternVLA-M1 下降 14.2%、InstructVLA 下降 17.4%）。
  • 丰富指令效果：enriched 模型在动作层面遵循指令的比例达约 84%，而原始 checkpoint 与 control 约 53%（接近 50% 随机水平），证明训练指令结构确实限制了 How-level 响应。
  • SIMPLER-IN 结果：所有模型在 Path 任务上遵循率为 0%（均越过透明障碍）；Grasp 与 Place 中 enriched 模型仍接近随机水平（约 50%），表明其响应仅局限于训练分布内的 How-level 内容，无法泛化至 OOD 指令。
  • 结论：How-level 指令遵循仍是当前 VLA 的开放挑战，需要覆盖更广泛 How-level 内容的训练数据。
