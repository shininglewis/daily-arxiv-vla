Card 02 论文概述

论文概述

  • 核心问题：运行时屏蔽（如 AEGIS 基于 CBF 的运行时保护）仅能纠正单步动作，而底层策略保持不变，导致 策略–屏蔽不匹配（policy–shield mismatch） 反复发生，甚至阻碍任务完成（称为 shield collapse）。

Card 03 核心贡献

核心贡献

  • 识别 持久性策略–屏蔽不匹配 是仅动作级运行时保护的关键局限，并提出 observe-only 接口，在策略自身的 rollout 分布上收集反事实教师建议，而不改变执行过程。
  • 提出 四阶段自我进化框架，包含 outcome-aware 记录、累积失败库（failure bank） 和 guarded LoRA 更新，将运行时反馈转化为持久策略改进。
  • 在 VLA-Arena 基准上跨两个难度级别和两个 VLA 骨干进行广泛实验，证明 FailBank 相较于基座策略将任务成功率提升 8.5 和 6.9 个百分点，并将策略诱导累积成本降低 35.6% 和 23.8%。
  • 与 AEGIS 运行时屏蔽相比，FailBank 在两个骨干上分别提升任务成功率 25.4 和 9.5 个百分点，同时保持可比的策略诱导累积成本。
  • 通过消融实验验证了 observe-only 收集 和 quiet anchors 等关键组件对策略更新的重要性，并展示了跨状态、任务、难度级别和骨干的泛化能力。
Card 04 方法描述

方法描述

  • Stage 1: Observe and Label：策略执行名义动作，固定 CBF 教师以 observe-only 方式生成反事实提案（仅修改平移通道），记录触发指示和特权场景几何；环境始终执行名义动作，保证回合结果可归因于当前策略。
  • Stage 2: Admit and Weight：根据 rollout 结果和修正时机筛选有效记录，分配第一动作目标；教师修正保留时使用提案作为目标，成功未修正动作作为 quiet anchors 保留名义动作；每条记录按触发来源加权，CBF 触发记录根据安全性、任务进展、恢复等评分映射到离散权重，quiet anchors 使用预定义权重。
  • Stage 3: Accumulate：将新准入记录与之前轮次的证据合并，维护累积训练库；训练集与验证集在准入前划分，保留固定 held-out 批次用于后续 guard 评估。
  • Stage 4: Update：每轮从同一基座检查点拟合新的 LoRA adapter，优化加权 flow-matching 损失；候选策略仅在满足 held-out 损失比率 和 第一动作漂移 约束时被接受，否则丢弃 adapter 并保留原收集策略；接受后的策略用于下一轮收集，部署时无需教师或特权几何。
  • 关键技术：Control Barrier Function (CBF) 教师、observe-only 收集、outcome-aware 准入与加权、累积失败库、guarded LoRA 更新。

数据集与资源

  • 使用 VLA-Arena 基准，评估其 static-obstacle safety suite，每个难度级别包含五个任务（Level 0/1/2）。

Card 06 评估与结果

评估与结果

  • 评估环境：VLA-Arena 静态障碍安全套件，两个难度级别（Level 1 和 Level 2），两个 VLA 骨干（π0.5 和 π0）。
  • 主要评估指标：成功率 (SR)、累积成本 (CC)、策略诱导累积成本 (CC_policy) 和 基座相对分数 (BRS)。
  • 关键结果：

- 相比基座策略，FailBank 在 π0.5 上将平均 SR 从 66.0% 提升至 74.5%（+8.5 个百分点），在 π0 上从 47.5% 提升至 54.4%（+6.9 个百分点）。

- 平均 CC_policy 在 π0.5 上从 47.76 降至 30.76（-35.6%），在 π0 上从 10.62 降至 8.09（-23.8%）。

- 相比 AEGIS，FailBank 在 π0.5 上将平均 SR 从 49.1% 提升至 74.5%（+25.4 个百分点），在 π0 上从 44.9% 提升至 54.4%（+9.5 个百分点）。

- 在联合成功–成本操作点上，FailBank 在 8 个任务–骨干对中实现双目标改进，而 AEGIS 仅 3 个；BRS 在两个骨干上均高于 AEGIS。

  • 泛化：在 Level 1 mango 的 held-out 初始状态上，π0.5 的 SR 从 71.1% 提升至 93.3%；四个未见 Level 1 任务平均 SR 从 82.5% 提升至 88.7%；Level 2 平均 SR 从 50.5% 提升至 59.4%（无 Level 2 更新数据）。在 π0 上同样观察到跨状态、任务和难度的迁移。
  • 消融：shield-in-loop 收集 会将 88.9% 的失败记录变为屏蔽诱导失败，而 observe-only 更好保留策略原始失败分布；去掉 quiet anchors 后，修正记录能提升 SR 至 89%，但加入 quiet anchors 后进一步将 CC_policy 从 20.88 降至 16.52。
