RAVEL: Asynchronous Rolling Inference for Flow-Based Vision-Language-Action Models

RAVEL 是一个用于 flow-based VLA 模型 的异步滚动推理框架，旨在解决 VLM 编码和多步动作去噪带来的高推理延迟问题。 论文针对机器人在动态环境中响应慢、动作块间不连续以及新观测难以快速影响控制等瓶颈，提出同时降低 VLM 编码和动作专家计算延迟的方案。 目标是在保持预训练 VLA 操纵能力的同时，大幅降低响应延迟，实现高频、响应式的闭环控制。

Card 03 核心贡献

核心贡献

  • 提出 RAVEL 异步推理框架，将昂贵的 VLM 编码与动作生成解耦，使动作专家能连续生成动作，并引入轻量级 Fast Observation Pathway (FOP) 保持对当前观测的及时感知。
  • 结合 滚动动作缓冲区 与 时间偏移条件，使近期动作只需单步去噪即可执行，并补偿推理延迟对动作预测的影响。
  • 在仿真和真实世界任务中证明 RAVEL 在保持预训练 VLA 操纵能力的同时，显著降低响应延迟，提高动态仿真成功率，并实现更快、更平滑的真实世界操作。
Card 04 方法描述

方法描述

  • 偏移感知的滚动流去噪 (Offset-Aware Rolling Flow Denoising)：维护一个长度为 K 的未来动作滚动缓冲区，每个控制步只执行一次动作专家前向，将缓冲区中所有动作推进一个去噪步，并释放第一个动作；新动作从高斯噪声初始化加入缓冲区。缓冲区中动作的流时间步按位置分配，越晚执行的动作噪声越大。
  • 异步上下文更新与快速观察路径 (Asynchronous Context Updates and FOP)：VLM 上下文编码与滚动动作生成并行异步运行，动作专家使用最新可用的 VLM 上下文及对应的时间偏移。FOP 使用轻量图像编码器和当前本体状态投影，通过门控交叉注意力适配器将当前观测注入动作专家层，使即将执行的动作能响应最新观测而无需等待 VLM 编码完成。
  • 流对齐训练 (Streaming-Aligned Training)：在训练时采样观测时间步 t_o 和时间偏移 p，构造与推理时相同的滚动缓冲区噪声分布，并让动作专家以 VLM 上下文和时间偏移 δ_p = p/K 为条件预测各槽位的流速度，损失为流匹配目标。
  • 时间偏移条件：将归一化时间偏移 δ_p 作为额外条件信号，通过 MLP 嵌入（π0.5）或与噪声动作、本体感觉和流时间步嵌入拼接（X-VLA）的方式注入动作专家，使其能根据延迟预测动作执行时刻的目标。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（单臂桌面操作）、RoboTwin 2.0（双臂操作）、Dynamic Object Manipulation (DOM) 基准（动态物体操作，基于 DynamicVLA）。
  • 真实世界任务：乒乓球返回、网球抓取，使用 xArm7 机器人。
  • 基础模型：π0.5、X-VLA、DynamicVLA（均为预训练的 flow-based VLA 模型）。
  • 训练/推理资源：仿真实验使用 RTX 4090；真实世界推理使用 RTX 5090；DOM 实验使用两块 RTX 4090（仿真与策略推理分卡运行）。
  • 缓冲区长度：K = 10；每个槽位包含 h 个连续低级动作，总视界 H = K·h。
Card 06 评估与结果

评估与结果

  • 同步仿真 (LIBERO / RoboTwin 2.0)：RAVEL 保持与基线相当或略优的任务成功率；首动作延迟显著降低，X-VLA 从 142.58 ms 降至 54.97 ms（2.59× 加速），π0.5 从 272.86 ms 降至 93.45 ms（2.92× 加速）。
  • 异步仿真 (DOM)：RAVEL 总体成功率达 44.06%，加入 FOP 后提升至 46.94%，优于 CI & LAAS（35.50%）、VLASH（18.78%）、FASTER（23.78%）等基线；平均完成时间 6.04 s，比 DynamicVLA 减少 23.0%；在闭环反应 (62.5%) 和运动感知 (43.0%) 等维度表现突出。
  • 真实世界评估：乒乓球返回任务中，RAVEL 成功率达 90%，远高于 FASTER 和 VLASH 的 25%；观测年龄中位数 121.76 ms，95 分位数 132.20 ms，均为最低。网球抓取任务中，成功率与最佳基线持平（45%），但 E_HF（7.01）和 TCP jerk RMS（1800）最低，表明运动更平滑、稳定。
  • 消融研究：训练时需同时进行偏移视界训练和时间偏移条件，才能将 LIBERO 成功率从 78.00% 提升至 97.85%；忽略 VLM 计算延迟会使 DOM 成功率从 44.89% 降至 16.67%；时间偏移偏置在 δ0 = 0.3 时达到最优成功率 90%。
