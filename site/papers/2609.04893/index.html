论文概述

  • 核心发现聚焦对齐粒度：将每个动作 token 与其所属操作阶段的推理文本对齐（Dense LSS）显著优于对齐到单一情节级池化嵌入（Pooled LSS），在保留任务上具有更优的迁移能力
Card 03 核心贡献

核心贡献

  • 提出 LSS：一种在人类演示预训练阶段施加的辅助损失，通过小型投影头将 VLA 动作 token 表征对齐到物理推理文本的 T5 嵌入空间
  • 实现训练专用设计：投影头与推理编码器仅在训练时存在，推理阶段部署的是完全未修改的基础策略，零额外参数、零额外延迟
  • 揭示对齐粒度结论：per-token、phase-local 的 Dense LSS 在分布内任务与保留任务上都超越 episode-level 的 Pooled LSS，后者会过拟合于对齐训练任务
  • 通过受控微调阶梯排除人类演示数据与任务匹配等混淆因素，明确将增益归因于 LSS 机制
  • 提供表征探针证据：Dense LSS 在骨干网络中诱导约 2 倍于 Pooled LSS 的每阶段可分离性（silhouette 分数）
Card 04 方法描述

方法描述

  • 以 H-RDT 为骨干：DINO+SigLIP 视觉编码器 + 冻结 T5-XXL 命令编码器 + 2B 参数扩散 Transformer，输出 K=16 个 2176 维动作 token，受 flow-matching 动作损失监督
  • 训练流程扩展为三阶段：① 人类数据预训练 → ② LSS 人类数据预训练 → ③ 机器人微调；Stage 2 处理 48 维人类动作表征，Stage 3 微调到 14 维机器人动作
  • 推理文本由 VLM（Gemini-3-flash）离线生成，描述操作的因果结构（对象状态触发与物理响应），由冻结 T5-XXL 编码并缓存
  • Pooled LSS：动作 token 均值池化后对齐到整段推理文本的池化嵌入，损失为余弦距离，总损失 L_total = L_flow + λ·L_LSS（λ=0.1）
  • Dense LSS：推理文本被分割为有序阶段（approach、grip、rotate、withdraw），每个动作 token 依据帧范围映射到对应阶段，逐 token 对齐到该阶段的 T5 嵌入，跨阶段边界约 5% 的 token 被掩码
  • 投影头 LSAHead 为两层 MLP（2176→2176，GELU，2176→4096），将动作 token 映射到 T5 嵌入空间后计算余弦对齐损失
  • 创新点在于推理以对齐目标而非条件输入的形式注入，通过小幅 λ 对骨干表征施加结构性塑形而不覆盖动作预测主目标
Card 05 数据集与资源

数据集与资源

  • 自建人类演示数据集：远程操作采集 500 条 adjust_bottle 轨迹，采用 2×2 平衡设计（左手/右手 × 可乐/雪碧瓶），每种组合 125 条
  • 数据采集设备：Apple Vision Pro 记录操作者 48 维手部与腕部动作，ZED 立体相机采集前方 RGB 视频，采用 EgoDex 数据格式并基于 human-policy 框架构建
  • 推理标注由 Gemini-3-flash 离线生成，返回阶段分割标签及时间比例区间
  • 微调评估数据遵循 RoboTwin 2.0 协议，每个 Stage-3 任务使用固定 50 个 HDF5 轨迹片段的 22,000 步预算
  • 模型规模为 2B 参数的扩散 Transformer 骨干，动作 token 维度 2176，T5 嵌入维度 4096，动作块 K=16，LSS 权重 λ=0.1

Card 06 评估与结果

评估与结果

  • 评估基准：RoboTwin 2.0 模拟环境，aloha-agilex 14 自由度配置，demo_randomized 设置，成功率报告基于 100 次 rollout
  • 消融阶梯（adjust_bottle 分布内任务）：H-RDT 基线 70%，+AVP 无推理 79%，推理作为语言输入 71%，推理经 token 预测损失 74%，Pooled LSS 85%，Dense LSS 90% 取得最优
  • 对照实验表明对齐到平凡指令文本仅达 58%，证明推理内容本身而非辅助损失的存在性是增益来源；冻结 Stage-2 骨干进行微调结果为 0
  • 迁移实验（R1=H-RDT 基线，R2=+人类数据，R3=+Pooled LSS，R4=+Dense LSS）：adjust_bottle 上为 70/79/85/90，shake_bottle 上为 34/45/39/54，move_can_pot 上为 9.1/20/19/26
  • Pooled LSS 虽提升分布内任务，但在 shake_bottle 上从 R2 的 45% 回退至 39%，在 move_can_pot 上基本持平（19% vs 20%），验证其无法迁移的过拟合特性
  • 表征机制探针：在相同 λ=0.1 预算下，Dense LSS 的 silhouette 分数约为 Pooled LSS 的 2 倍（对比 AVP-only 基线为 0.047 vs 0.021；对比 H-RDT 基线为 0.037 vs 0.016），且绝对数值小是设计使然
  • 推理成本对比显示：与推理时生成 token 或预测未来状态的测试期推理方法（据文献报告慢 4.8×–83×）不同，LSS 部署模型与基础 H-RDT 策略在延迟与参数量上完全相同
