Card 03 核心贡献

核心贡献

  • 策略学习的预测目标空间（Policy-learned predictive target space）：预测目标空间与策略联合学习，而非由预训练编码器或分阶段表征规定，使预测学习与动作监督共同组织用于控制的表征。
  • 非对称预测–控制接口（Asymmetric prediction–control interface）：Future Expert 仅作用于紧凑预测表征，而 Action Expert 额外访问当前帧特征，使预测目标空间聚焦任务相关演化，而无需保留全部执行级空间细节。
  • 紧凑 token 接口：缩小预测目标空间，每个样本训练 token 更少（真实机器人设置 244 tokens vs. Fast-WAM 的 392），显著提升训练吞吐（自注意力为长度平方复杂度）。
  • 经验与表征层面的证据：在仿真与真实机器人上兼顾强控制性能与高效训练，消融与表征诊断将鲁棒性归因于所学 World 表征，并证明当前帧特征的互补作用。
Card 04 方法描述

方法描述

  • World Encoder：冻结的 V-JEPA 家族编码器 *f* 加上可训练的 online compactor *C_φ*，在任务指令嵌入 *e_s* 的 cross-attention 下压缩出 *K* 个宽度为 *d* 的紧凑 token，即 World 表征 *z_t*（LIBERO 28 tokens，RoboTwin/真实机器人 36 tokens）。
  • EMA 目标：由同一 compactor 的 EMA 副本 *C_{φ'}* 在 stop-gradient 下生成未来目标 *z̃_{t+τ}*（τ=1,…,H_f，且 H_f = H_a），遵循 BYOL/JEPA 实践避免表征坍缩。
  • Temporal Joint-Embedding Prediction：Future Expert 以条件流匹配（conditional flow matching）从 *z_t* 预测紧凑未来目标，条件为任务意图 *e_s*，训练速度场匹配 *ε − z̃*。
  • Action Expert：可学习空间编码器 *g_ψ* 与可微 grid sampler *S_ξ* 产生当前帧 token *v_t*，与 *z_t*、机器人状态 *q_t*、*e_s* 一同以同样的流匹配公式解码动作块。
  • 结构化注意力掩码：Future queries 仅关注 *z_t* 与其他未来 token；action queries 关注 *z_t*、*v_t*、*q_t*，但从不关注预测的未来 token——因此预测仅通过训练中塑造的表征影响控制；由于 compactor 共享，动作损失直接约束该空间本身。
  • 推理：测试时仅输入当前观测、机器人状态与指令；Future Expert 流作为上下文编码器运行一次填充 KV 缓存，Action Expert 经 10 步 flow 解码动作，不实例化任何未来 token。
Card 05 数据集与资源

数据集与资源

  • LIBERO：全部 40 个任务（Spatial、Object、Goal、Long 四个套件），每任务 50 次 rollout，每任务 50 条演示，动作空间为 delta EEF。
  • LIBERO-Plus：10,030 个扰动任务上的任务加权成功率。
  • RoboTwin：全部 50 个官方任务，Clean2Clean 与 Clean2Rand 两种设置，每任务 100 次 rollout、50 条演示，动作为绝对关节位置（qpos）。
  • 真实机器人：三个任务——*Fold the Towel*（长时程可变形物体）、*Put Banana*（对抗性放置的抓放）、*Stack Three Bowls*（多阶段刚性物体操作）；双臂 6-DoF + 三路 RGB 相机，无深度输入，14 维绝对关节位置；每任务 300 条遥操作演示（30 Hz，约 4.3 小时），每任务 50 个种子初始配置。
  • 模型与训练资源：2B 参数模型，在 8× RTX 5090 GPU 上训练 9.67 小时，比 Fast-WAM 快约 6×，且不使用具身预训练。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、LIBERO-Plus、RoboTwin 仿真基准，以及三任务真实机器人平台；统一使用相同消融配置（w/o Joint-Embedding Prediction、w/o Current-Frame Visual Features、w/o World Input & Future Expert 等）进行闭环重规划评估。
  • 主要指标：任务成功率（%）；LIBERO-Plus 报告任务加权成功率；RoboTwin 报告 Clean / Random / 平均值。
  • LIBERO 与 LIBERO-Plus：LIBERO 平均 97.25%（Long 95.2、Goal 95.6、Object 99.4、Spatial 98.8）；LIBERO-Plus 总分 80.85%，超过多个具身预训练 VLA，仅次于 Cosmos-Policy（82.2%）与 π0.5（85.7%），且在 Camera（78.67）与 Noise（76.52）等六类中取得更高合并成功率。
  • RoboTwin：在无具身预训练方法中平均成功率最高，达 41.91%（超过 EventVLA 40.65% 与 Fast-WAM 39.85%）；clean 集 70.84% 与 π0.5 的 70.70% 相当，但随机化下为 12.98%，明显低于 π0.5 的 46.00%。
  • 真实机器人：三个任务平均 96.3%，与 π0.5 相当。
  • 消融与表征分析：移除联合嵌入预测或当前帧视觉特征均导致性能下降（如同时移除两者时 LIBERO 仅 85.00、LIBERO-Plus 58.81）；表征诊断显示联合嵌入预测能更好地区分任务驱动变化与扰动，并将精确执行所需细节保留在 *v_t* 中，两条通路在空间聚焦与时间稳定性上具有互补性。
