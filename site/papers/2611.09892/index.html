Card 03 核心贡献

核心贡献

  • 提出 AMP1 参考 harness：提供视觉观测、代码执行与机械臂运动的直接控制接口；同一套实现跨单臂、双臂、移动平台不变，仅更换机器人描述与相机配置
  • 在 RoboLab-120 上取得零样本 85.6%（Gemini 4 Argon）/ 82.8%（Opus 5.5）成功率，显著超过最强 VLA（49.2%）、WAM（42.9%）与先前最强智能体基线（57.1%）
  • 在 CaP-Gym 的 LIBERO-PRO（95.2%）、robosuite（100.0%）、BEHAVIOR-1K（96.0%）三个子集上零样本领先，且在所有基准上复用同一 harness
  • 真实机器人上 108 次试验成功 104 次（96.3%），相比 VLA 与 WAM 基线将失败率分别降低约 20× 与 15×
  • 记录了 harness 与提示词中均未指定的涌现行为（寻找隐藏物体、工具使用、以推代抓、相机自标定、机械互锁抓取等），并给出在 1,200 个 RoboLab 回合上的技能统计
Card 04 方法描述

方法描述

  • 核心架构：通用前沿模型 + harness。Harness 分为感知（sensing）、理解（perception）、运动（motion）三部分，并内嵌 Python 解释器，模型通过生成/执行代码来感知与控机
  • Basic harness：模型输出带时间戳的末端位姿轨迹与夹爪指令；只拒绝不可达或过快动作，碰撞检查交由模型自身负责；不提供抓取、放置、推动等原语
  • Assistive harness：额外提供自动规划并执行 pick-and-place 的辅助例程，用于对照实验
  • 记忆增强版 AMP1+：维护一个持久记忆 ℳ（无格式约束，通常为 Markdown 笔记 + Python 代码库），每回合开始读取；模型权重固定，通过反思成功/失败回合迭代更新记忆，实现无梯度的少样本与持续学习
  • 平台抽象：RoboLab、CaP-Gym（LIBERO-PRO / robosuite / BEHAVIOR-1K）、RoboDojo 与真机均通过同一 harness 接入，仅替换机器人描述与相机配置
  • 关键创新：把通用模型保持在控制闭环内（区别于离线程序合成），并让其直接下达细粒度运动指令（区别于技能编排），从而把几何推理、接触推理与错误恢复都交给模型在回合内完成
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboLab-120（120 个自然语言任务，含 default / vague / specific 三种指令条件，共 3,600 回合）、CaP-Gym 的 LIBERO-PRO（3,000 回合）、robosuite（700 回合，含 5 个单臂 + 2 个双臂任务）、BEHAVIOR-1K（50 回合移动操作）
  • 学习实验基准：RoboDojo（42 个双臂操作任务，多布局，仅 RGB、无深度与相机标定）
  • 真实世界：自建 12 个短/长程任务；Franka Research 3 7-DoF 机械臂 + Robotiq 2F-85 夹爪 + 三路相机（左右肩视 + 腕部，类 DROID）
  • 被调用模型（13 个）：Gemini 4 Argon；Claude Opus 5.5 / Opus 5 / Opus 4.5 / Sonnet 5.5 / Sonnet 5 / Haiku 5.5；开源权重 Qwen3.6-35B-A3B、Qwen3.8-27B、Qwen3.8-Flash-Next、GLM-5.3 Flash、DeepSeek V4.1 Flash、Kimi K3
  • AMP1 自身无训练参数：不进行预训练、微调或梯度更新，仅调用现成通用模型；推理计算开销一节（Compute）在提供的原文片段中被截断，具体 GPU/TPU 规模未给出
Card 06 评估与结果

评估与结果

  • 评估协议：全部为零样本（单次尝试、无演示、无训练、无练习回合）；学习实验在未见布局上评测，仅使用基准的二元奖励信号
  • 主要指标：任务成功率、相对基线的失败率下降倍数、每回合模型调用次数（效率）、平均成功耗时（分为执行与推理时间）
  • RoboLab-120：AMP1 达 85.6%（Gemini 4 Argon，95% CI 83.5–87.5）与 82.8%（Opus 5.5）；对指令措辞鲁棒，vague / specific 条件下仅波动约 3 个百分点（基线 FLUX 从 42.9% 跌至 28.4%，π₀.₅ 从 28.0% 跌至 15.2%）；在无基准缺陷的 95 个任务上成功率达 96.2%
  • CaP-Gym：LIBERO-PRO 95.2%（CaP-Agent0 18.2%、微调 π₀.₅ 34.9%）；robosuite 100.0%（700/700，HarnessPAI 96.3%、人类专家程序 82.6%）；BEHAVIOR-1K 96.0%（48/50）
  • 真实世界：96.3%（104/108），FLUX 3 Action 45.4%、π₀.₅ 27.8%；开启控制器错误恢复功能后失败率进一步下降（关闭时为 87.0%，94/108）
  • 从经验学习：RoboDojo 少样本练习将成功率从 26.4% 提升至 84.1%（超越榜单最高的 Q0-Preview 68.9%）；单轮持续学习提升至 57.6%，且对未见过任务有正向迁移、对已学任务无遗忘；带记忆的智能体模型调用次数减少约 35%
  • 消融分析：模型选择影响最大（Qwen3.6-35B-A3B 12.8% → Gemini 4 Argon 85.6%；Claude 家族内 Opus 5.5 82.8%、Haiku 5.5 51.6%、Opus 4.5 35.2%）；增加推理对所有模型均有益（Sonnet 5.5 +17.2 分、Opus 5.5 +14.6 分）；辅助抓放例程利好弱模型却损害强模型；Opus 5.5 在全感知/无深度/无深度且无标定下为 82.8% / 81.1% / 75.8%，但每回合模型调用从 34.8 增至 46.3、53.5；以文本替代图像使成功率从 82.8% 骤降至 36.8%，与先前工作建议相反
