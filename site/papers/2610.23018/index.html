Card 03 核心贡献

核心贡献

  • VLA-Fabric 交互架构：把完整的臂级局部 VLA 作为多臂协作的执行单元；通过大规模受控架构搜索，确立有效的交互入口、聚合算子与适配策略。
  • 交互功能的分解：识别出三种互补的协同角色——共享语义上下文（RAW Common）、同伴潜在上下文（Private K/V）、动作意图（对最终 readout 做 Linear 融合）。
  • 跨架构迁移：在基于 Eagle2 VLM 的 SingleVLA 与 π0.5 两种结构差异明显的 VLA 上重新实例化同一交互范式，证明它不依赖特定张量布局或骨干网络实现。
  • 可组合的多臂扩展性：从双臂扩展到 3 臂与 4 臂团队，并在仿真与真实机器人任务上验证，其中真实任务相对独立训练的局部策略提升 16 到 40 个百分点。
  • 提出从“单个具身模型能力提升”走向“网络化具身智能”的组织路径：协同机制与基座模型能力可以各自独立推进。
Card 04 方法描述

方法描述

  • 局部 VLA 智能体：对 N 个智能体，第 i 个智能体在规划轮次 t 输出 H 步动作块 a_i = π_θi(o_i, q_i, ℓ, r_i; M_i)；M_i 为本轮接收到的同伴信息，独立训练的策略始终令 M_i = ∅。
  • 设计空间三要素：交互入口（Independent / Private K/V / Common / 动作侧交互）、交互算子（单向传递、AVG 对称平均、RAW 算子级同步；Linear 或 Transformer 动作融合）、适配策略（Single-stage 一步启用，Common-first 先用 Common 初始化，再引入其余交互）。
  • 共享语义上下文：用对称算子 Agg_sem 聚合各智能体的 Common 表征，形成团队级上下文（式 A.1）。
  • 同伴潜在上下文：本地 query 对拼接后的本地与同伴 K/V 做注意力，由接收方自行筛选相关信息（式 A.2）。
  • 动作意图：按固定角色顺序拼接动作侧状态 z_j，再经接收方专属融合算子 φ_i^act 生成 z̃_i（式 A.3），最终经本地 flow-matching 动作头输出。
  • 跨架构映射：SingleVLA 在 Eagle2 VLM 内的 Common/Private K/V 之后、融合最终 readout 再送入本地动作采样器；π0.5 则用 Common 多模态前缀融合形成共享上下文、以 Private Prefix K/V 供本地 Action Expert 查询，并把动作交互移入 Action Expert 的门控残差同伴注意力中。
  • 训练目标：冻结视觉编码器，微调语言骨干、动作头和已启用的交互模块；使用各臂原生动作损失的均值 L_act（式 A.4）。

Card 06 评估与结果

评估与结果

  • 评估设置：配对条件成功率；全文覆盖双臂四项任务、三臂与四臂仿真四项任务，以及真实机器人四任务；包含固定权重、推理时逐项移除三种交互的消融。
  • 主要指标：任务成功率（%），模型选择与最终评测使用互不相交的条件集。
  • 双臂能力对比：π0.5-Fabric（Full） 在 Box/Shoes/Mic/Scan 上达 80.5 / 94.5 / 97.5 / 33.0，优于 RDT-1B（69.4/66.0/90.0/4.0）、π0（78.8/82.4/98.0/18.0）、TwinVLA（78.0/84.8/84.0/11.0）与 SingleVLA-Fabric（80.0/70.0/84.0/5.5）。
  • 消融结论：推理时移除全部交互后，π0.5-Fabric 在 Box/Shoes/Mic/Scan 上降到 12.5 / 85.0 / 1.0 / 1.0；在 π0.5 的 Box 任务上，动作侧交互影响最大，而 Mic 与 Scan 更依赖同伴潜在上下文，说明三种交互功能互补，没有单一功能在所有任务上占优。
  • 架构搜索结论：仅用 Private K/V 就优于 Independent；Common-first 在全部 7 组匹配设计上均带来提升；AVG 与 RAW、Linear 与 Transformer 之间没有稳定赢家，最终选用 RAW Common + Private K/V + Linear 动作交互 作为标准实现。
  • 更大团队仿真：Stack3 90.5→91.0、Frame3 67.5→79.5、Frame4 9.5→89.5、Arch4 0.0→5.0；说明交互收益取决于局部动作之间的物理耦合强度，并不取决于臂的多少。
  • 真实机器人：Basket3 72.0→88.0、Relay3 16.0→56.0、Relay4 40.0→72.0、Frame4 36.0→60.0，四项任务均显著优于独立训练策略，提升幅度为 16 到 40 个百分点。
  • 局限性：实验仅覆盖角色固定、最多 4 臂的同质团队；交互结构目前是静态的；长时程高精度装配（如 Arch Building）仍受限于局部 VLA 的规划与精度控制能力。
