Detect and Suppress: A Mechanistic Defense against Adversarial Patches in VLA Models

2026-10-02 · 原文 · 翻译 · 2610.03498

论文研究 Vision-Language-Action (VLA) 模型在面对对抗性补丁（adversarial patch）攻击时的内部机制，并提出一种基于机制可解释性的防御方法。 核心目标是找出与对抗补丁存在高度相关的内部特征，并在推理阶段仅当检测到攻击时抑制该特征，从而提升鲁棒性而不微调 VLA 策略。 要解决的问题是：现有 VLA 防御要么依赖输入预处理（如图像变换），要么依赖对抗微调（计算成本高），且尚不清楚哪些内部机制导致攻击成功以及如何精准干预。

Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action (VLA) 模型在面对对抗性补丁（adversarial patch）攻击时的内部机制，并提出一种基于机制可解释性的防御方法。
  • 核心目标是找出与对抗补丁存在高度相关的内部特征，并在推理阶段仅当检测到攻击时抑制该特征，从而提升鲁棒性而不微调 VLA 策略。
  • 要解决的问题是：现有 VLA 防御要么依赖输入预处理（如图像变换），要么依赖对抗微调（计算成本高），且尚不清楚哪些内部机制导致攻击成功以及如何精准干预。
Card 03 核心贡献

核心贡献

  • 使用 稀疏自编码器（SAE） 对 VLA 内部表征进行机制分析，识别出激活值与对抗补丁存在强相关的 SAE 特征。
  • 提出 条件特征干预（Conditional Feature Intervention） 框架：先用线性探针（linear probe）检测攻击，再仅在被检测到攻击时抑制所选特征贡献。
  • 在 LIBERO-10 基准上针对 UADA 攻击进行闭环机器人控制评估，证明条件干预可提升任务成功率，而无条件持续抑制会显著损害策略性能。
  • 系统分析干预强度 λ 的影响，揭示鲁棒性与良性任务性能之间的权衡关系。
  • 验证方法在 gripper patch 等其他补丁类型上的有效性，并分析检测器的补丁特异性与特征选择的影响。
Card 04 方法描述

方法描述

  • 训练 TopK SAE 分解 VLA 内部残差流表征：对前缀 token 表征做均值池化后输入 SAE，得到稀疏特征激活。
  • 通过在多条 rollout 中开关对抗补丁，计算各候选层-特征对与补丁存在指示变量的 Pearson 相关系数，选择相关性最高且最稳定的 层-特征对 (ℓ⋆, j⋆) 作为干预目标。
  • 训练 逻辑回归线性探针，从检测层 k（k ≤ ℓ⋆）的均值池化表征估计攻击概率，并设定阈值 τ，使良性条件下误报率不超过 2%。
  • 干预公式为 h̃ = h − g_t · λ · z_{t,j⋆} · d_{j⋆}，其中 g_t 为检测门控，λ 为干预强度；λ∈(0,1) 表示衰减，λ=1 表示完全移除，λ>1 表示反向引导。
  • 关键创新点：不修改输入图像、不微调模型参数，仅在推理时基于内部状态条件性地抑制对抗补丁相关特征。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO-10 基准，10 个任务，每个任务 50 个初始状态共 500 次 rollout 用于主评估。
  • 模型：π0.5（仅使用 agent 相机）与 SmolVLA（同时使用 agent 与 wrist 相机），两者权重在防御实验中保持冻结。
  • π0.5 微调：在 LIBERO 训练集上按官方 LoRA 流程微调 30,000 步，替换 wrist 相机图像为黑图。
  • SAE 训练：每个候选层训练独立 TopK SAE，π0.5 使用 K=12、SmolVLA 使用 K=6，各训练 6,677 步，扩张比为 1×。
  • 训练硬件：4 张 NVIDIA RTX 6000 Ada GPU（每张 48 GB）。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-10 闭环机器人控制；主攻击为 UADA（针对 DoF 1 的通用补丁），补丁间歇性出现 n=3 或 n=10 次；额外评估 gripper patch 与持续攻击。
  • 主要指标：任务成功率 SR；检测指标包括 Recall、FPR、Precision。
  • 检测性能：探针在 n=3 时 Recall 达 81.76%、FPR 0.39%、Precision 92.71%；n=10 时 Recall 84.91%、FPR 0.71%、Precision 96.45%。
  • 攻击条件下 SR：π0.5 从基线 46.8% → 49.2%（n=3）、26.0% → 32.4%（n=10）；SmolVLA 从 18.6% → 19.6%（n=3）、6.2% → 7.6%（n=10）。
  • 良性条件下：条件干预在 π0.5 上保持性能（54.6% vs 54.4%），SmolVLA 略降至 36.6%；而持续干预（w/o Det.）大幅下降至 35.2% 与 19.0%。
  • 干预强度：攻击下 SR 在 λ≈0.2–0.3 时最高，λ 增大后下降；良性条件下 SR 随 λ 增大急剧下降。
  • 补充实验：gripper patch 攻击下 π0.5 从 30.4% → 46.4%（n=3）、4.4% → 33.6%（n=10）；持续攻击下性能反而下降；随机特征干预效果弱于相关性最高的选定特征。
