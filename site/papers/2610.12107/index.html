Card 02 论文概述

论文概述

  • 论文针对广义指代分割（GRES）任务，要求同时兼顾高层语义（识别可变数量的指代目标）与细粒度视觉证据（精确边界刻画）。
  • 指出现有级联式视觉-语言架构依赖静态特征接口和单次掩码预测，缺乏自适应感知与几何纠错能力。
  • 提出 ContourVLA，将 GRES 重构为闭环感知-动作视觉运动过程，以可编辑轮廓作为策略状态，由几何动作块驱动其更新。
Card 03 核心贡献

核心贡献

  • 提出 ContourVLA，首次将 GRES 重塑为主动感知-动作轮廓策略，几何状态在感知与轮廓动作之间起桥梁作用。
  • 提出 EASS（Evolution-Aware Semantic Scheduling），用状态条件调度器替代静态读取：空间轴做自适应双向边界采样，语义轴做进化感知的多层级多模态特征路由。
  • 提出 DECT-GRPO（Dustbin-Augmented Entropic Credit Transport GRPO），通过增加 dustbin 的熵正则最优传输建立软预测-目标对应，为 grounding token 与轮廓动作分配实例级信用，显式处理误检与漏检。
  • 在 gRefCOCO 上 gIoU 相比最强基线分别提升 8.7 / 2.8 / 2.7 点（val / testA / testB），并在全部 8 个 RefCOCO 系列 split 上取得最高 mIoU。
Card 04 方法描述

方法描述

  • 闭环感知-动作范式：以图像-表达式对 $(I,x)$ 为输入，VLIM 自回归生成结构化 grounding 序列（含推理 token 与 box 记录或 no-target 响应），box 解码后初始化为内切椭圆轮廓 $C_i^0$。
  • VLIM（V-L Interaction Module）：感知专家，负责指代目标 grounding，并缓存视觉特征网格 $F$ 与多层级多模态表示 $\{H^\ell\}$。
  • GAD（Geometric Action Decoder）：动作专家，将轮廓点 token、实例上下文与路由语义结合，并行预测各顶点的二维位移动作块。
  • EASS 空间轴（Spatial Visual Sampling）：沿顶点法向在 box 归一化坐标下做内外双向采样，感受野随目标尺度自适应。
  • EASS 语义轴（Multimodal Semantic Routing）：以实例几何、进化进度、轮廓运动、解码深度构造 query，与层级 key 匹配并 Softmax 选择层级，配合直通估计器（straight-through estimator）保持离散路由可微。
  • 动作块执行：$O_i^k=(\Phi(F,C_i^k,b_i),V_i,\mathcal{U}_i^k)$，$A_i^k=\pi_\phi(C_i^k,O_i^k)$，$C_i^{k+1}=\mathcal{T}(C_i^k,A_i^k)$，迭代更新轮廓状态并闭合感知-动作环路。
  • DECT-GRPO：把 mask IoU 覆盖矩阵扩展为带 dustbin 的 $\overline{Q}_g$，用熵正则最优传输求解软分配 $P_g^\star$；据此定义 transport-aware 精确率/召回率与调和均值奖励 $R_g$，并通过分支内归一化的信用图对共享 rollout 优势做有界、保均值的实例级调制。
  • 两阶段训练：先监督初始化（grounding + 参考轮廓轨迹监督及辅助几何/路由正则），再进行 DECT-GRPO 联合后训练，保留离散 grounding 与连续动作各自的似然。

Card 06 评估与结果

评估与结果

  • 评估环境：GRES 采用 gIoU 与 cIoU 指标，传统 RES 采用 mIoU 与 cIoU；另通过 no-target 准确率与实例级 F1 等分析拒识与实例分割能力。
  • gRefCOCO 结果：ContourVLA 在 val / testA / testB 上 gIoU 分别达 83.5 / 80.3 / 74.4，较最强基线提升 8.7 / 2.8 / 2.7 点；val 与 testA 的 cIoU 最高，testB cIoU 为 71.8，仅比 HiMTok 低 0.1 点。
  • 传统 RES 结果：同一联合训练 checkpoint 在全部 8 个 split 上取得最高 mIoU；RefCOCO 提升 1.3–1.8 点，RefCOCO+ 提升 2.8–3.2 点，RefCOCOg val/test 分别提升 0.7 / 0.3 点。
  • 消融分析：论文通过消融研究考察各组件贡献（如状态条件语义路由、grounding 与轮廓-动作联合优化），并对无目标表达式与实例级指标进行进一步分析。
