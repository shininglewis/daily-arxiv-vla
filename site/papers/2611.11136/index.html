Card 02 论文概述

论文概述

  • 论文提出一个名为 Script2Play 的全自动训练框架，把“生成游戏”与“游玩游戏”连接起来，使视觉-语言-动作（VLA）模型无需人类演示即可学会遵循游戏指令。
  • 核心动机是 VLA 跨游戏训练的监督瓶颈：人类演示采集成本高、公开视频缺少任务边界与完成信号、强化学习需要逐游戏奖励设计、手工搭建训练套件工程量大。
  • 关键洞见是游戏创建与专家演示生成都可以表述为编码智能体（coding agent）任务——因为游戏引擎将场景、机制与任务逻辑都表示为代码。
Card 03 核心贡献

核心贡献

  • 设计了自动的、以技能为条件的游戏生成框架：由工具调用的编码智能体从自然语言规格直接构建可执行游戏环境、多样化的指令跟随任务以及基于状态的验证器。
  • 提出纯合成、数据高效的编程专家监督流水线：利用模拟器的特权状态合成经过验证、与人类一致的键鼠演示，用于后训练像素到动作的 VLA 模型，全程无人类游戏数据。
  • 仅用 150.3 小时脚本教师数据，Script2Play 在公开游戏基准上超越用数千小时人类游玩数据训练的策略。
  • 验证了跨引擎泛化能力：同一检查点在未参与训练的 UE5（OmniGameArena） 与 Doom（ViZDoom） 上取得领先表现。
Card 04 方法描述

方法描述

  • 学生与教师：学生策略 Script2Play 仅观测指令、当前帧与历史帧-动作对（基准设置下 h=0，即只看指令与当前帧）；教师 π* 是编码智能体为每个游戏编写的程序，读取角色位姿、速度、目标坐标、敌人与弹道状态、碰撞几何，通过寻路、运动预测瞄准、有限状态机等决策，但只通过标准键鼠接口、与学生相同控制速率执行，不瞬移物体、不绕过物理。
  • 行为克隆目标：从预训练 VLM 出发，最大化教师动作的似然；对“按键集合相对上一窗口发生变化”的动作窗口提高 token 损失权重（Roblox ×5、Minecraft ×3）；每批次混入 15% 通用 VQA/OCR/文本样本以保留通用能力。
  • 动作表示：每 200 ms 输出一个动作块，以纯文本自回归生成 ΔX ΔY ; K1 ; K2 ; K3 ; K4——鼠标位移在 200 ms 窗口内分配，K1–K4 指定四个连续 50 ms 区间的按键与鼠标键，未列出的键视为释放（参考 Lumine）。
  • 数据生成：规格含五个字段（玩法技能、相机、动态范围、控制、任务契约）；编码智能体实现场景、交互机制、任务验证器与教师，并写场景生成器与离线镜像（游戏规则的独立实现，用于快速校验）；支持共享场景的反事实配对任务（要求不同目标），以检验验证器能否区分被指定目标与干扰物。
  • 五道审计门：G1 静态（代码可编译、配对任务同场景）、G2 可解（离线镜像中教师成功率 ≥95%，含加延迟情形）、G3 非平凡（空转/只按前进/随机按键策略很少成功，教师追错目标也失败）、G4 引擎一致性（引擎内成功率与镜像相差 ≤5 个百分点）、G5 视觉（帧非空白且随回合变化）。失败游戏最多修复三轮，否则丢弃。
Card 05 数据集与资源

数据集与资源

  • 训练数据：共 150.3 小时合成游玩数据 —— Minecraft 26.9 小时（31,494 条验证通过的回合，48 个与评测世界不相交的自定义世界种子，采集于 MineStudio）+ Roblox 123.4 小时（41 个生成游戏，六大类：战斗射击 56.4h、穿越跑酷 21.5h、物体交互 20.8h、闪避生存 19.7h、GUI 操作 3.7h、球类 1.3h）。
  • 模型规模：Qwen3.5-4B 作为骨干（4B 参数），冻结视觉编码器与投影层。
  • 训练资源：8 张 H200 GPU，bfloat16，全局批大小 384 个窗口，学习率 2×10⁻⁵，5% 预热后余弦衰减至峰值 10%。
  • 评测基准：OpenHA（Minecraft，训练引擎内）、OmniGameArena（UE5，5 个单人游戏，零样本）、ViZDoom（4 地图协议，35 Hz，每图 50 回合平均回报）。
Card 06 评估与结果

评估与结果

  • OpenHA 指令跟随（成功率 %）：Script2Play 平均 69.6（Embodied 63.9 / GUI 66.4 / Combat 78.6），超越此前最强训练策略 Game-TARS MoE-mini（64.5） 5.1 个百分点；对比 VPT 3.5、STEVE-1 5.0、ROCKET-1 15.6、JARVIS-VLA 24.5、OpenHA 31.5、UI-TARS-1.5 36.6、HiSTEVE 37.4、Game-TARS Dense 7B 42.5、GameWAM 46.6。
  • OmniGameArena 零样本迁移：平均 0.640，为所有对比智能体最高（Obstacle Run3D 0.374、Last Stand 0.436、Monster Shoot 0.972、Scene Escape 0.420、Cue Chase 1.000），超过最佳商业 VLM（Gemini 3.1 Pro Preview 0.473、GPT-5.5 0.463）和最佳训练策略（GameScaling-9B-S3 0.361）；训练中未使用任何 UE5 数据。
  • ViZDoom：在四地图协议下报告平均回合回报，用于检验战斗技能的跨引擎迁移，并配有动作序列分析说明控制如何迁移。
  • 监督来源对照实验：固定 Qwen2.5-VL-7B 骨干、仅用 Minecraft 子集，比较编程监督与人类游玩、RL 训练流水线，显示优势在同等架构下依然存在。
  • 总体结论：人类游玩演示与在线强化学习并非达到该性能水平的前提；围绕通用技能生成游戏即可提供足以训练出有能力且可迁移的游戏策略的监督信号。
