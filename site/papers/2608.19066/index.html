GS-VLA: Plug-and-Play Viewpoint Canonicalization for Frozen VLA Policies via Gaussian Splatting

2026-08-19 · 原文 · 翻译 · 2608.19066

论文提出一种轻量级、即插即用的框架 GS-VLA，通过 3D 高斯泼溅（3D Gaussian Splatting）实现视点规范化，提升冻结的视觉-语言-动作（VLA）策略对视点偏移的鲁棒性，而无需重新训练策略。 这是首个直接利用 3D 高斯新视角合成进行 VLA 策略观测空间适配的工作；核心思想是将视点偏移重新建模为局部新视角合成问题，在 Locality 假设下（相机扰动相对于工作空间保持在小范围内）将其简化为与场景和策略无关的去遮挡任务。 论文要解决的关键问题是：相机部署位姿与训练位姿不一致时 VLA 策略性能急剧下降（LIBERO 基准上成功率可从约 90% 跌落至最差约 10%），而大规模微调或生成式数据增强计算成本高昂且存在灾难性遗忘风险。

Card 02 论文概述

论文概述

  • 论文提出一种轻量级、即插即用的框架 GS-VLA，通过 3D 高斯泼溅（3D Gaussian Splatting）实现视点规范化，提升冻结的视觉-语言-动作（VLA）策略对视点偏移的鲁棒性，而无需重新训练策略。

Card 03 核心贡献

核心贡献

  • 新视角建模：将冻结 VLA 策略的视点适配问题从策略参数空间转移到观测空间，通过 Locality 前提将其形式化为局部去遮挡处理问题。
  • 首个基于高斯泼溅的规范化模块：提出 4M 参数 U-Net 适配器，预测 14 维高斯属性，可在单张 RTX A5000 上 5 小时收敛，无需策略重训练。
  • 三轴泛化能力：单个检查点即可跨多种策略架构（跨策略）、未见任务套件（跨任务套件）和大幅相机扰动（跨扰动尺度）迁移，全部使用在 libero_spatial 上以 εt=100cm 训练一次的模型。
  • 恢复机制的经验分析：提供实验证据表明大部分目标视图由确定性几何映射处理，学习只需针对狭小的空间局部残差区域。
Card 04 方法描述

方法描述

  • 规范化器采用像素对齐的 3D 高斯架构：每源像素通过深度反投影锚定一个高斯原语，U-Net 调整深度有界中心偏移、各向异性尺度、方向四元数、不透明度和颜色残差，再经 gsplat 可微 α-混合在规范位姿处光栅化。
  • 使用 FiLM 调制将位姿对嵌入（MLP 输出 128 维）注入对称 U-Net，所有头零初始化以保证从纯几何变换开始训练。
  • 高斯中心残差被限制在局部深度的 10% 以内（cΔμ=0.1 tanh），防止残差偏离几何基准，保证训练稳定性。
  • 训练目标为标准 3DGS 的 0.8:0.2 的 L1/SSIM 重建损失；仅在一个任务套件上训练以便其余套件作为未见测试域验证零样本泛化。
  • 位姿扰动通过平移容忍度 εt 和旋转容忍度 εR ≈ εt/dmin 统一控制，并定义归一化位姿距离 ρ 衡量总位姿变化。
Card 05 数据集与资源

数据集与资源

  • LIBERO 基准的四个任务套件：libero_spatial、libero_object、libero_goal、libero_10（涵盖空间推理、物体交互和长时程任务）。
  • 规范器规模：4M 参数 U-Net；相比微调 π0.5 小约 840×，相比 AnyCamVLA 小约 42×。
  • 冻结策略：π0.5（3.4B，lerobot/pi05_libero_finetuned）、OpenVLA-OFT（7B）、RynnVLA-002、XVLA。
  • 训练资源：单张 RTX A5000 GPU，约 5 小时。
  • 相机随机化：在规范位姿周围对相机位置和注视点注入高斯噪声，默认 εt≈100cm，并排除落在桌面以下的相机。
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO 四个套件，指标为多回合任务成功率（SR）；基线包括 No canon（无规范化）和 Fwd-warp（纯深度前向扭曲）。
  • 跨策略泛化（εt=100cm，500 回合）：XVLA 从 1.4% 提升至 81.0%（+79.6 pp）；OpenVLA-OFT 从 19.8% 提升至 81.6%（+61.8 pp）；RynnVLA-002 从 25.8% 提升至 78.6%（+52.8 pp）。
  • 跨任务套件泛化（π0.5，1000 回合）：libero_10 从 9.3% 提升至 72.1%（+62.8 pp）；spatial 从 42.6% 提升至 86.8%（+44.2 pp）；object 从 64.0% 提升至 90.2%（+26.2 pp）；goal 从 66.3% 提升至 92.2%（+25.9 pp）。
  • 扰动尺度鲁棒性：在 εt=5cm 至 200cm 扫描中，No canon 基线下降 49.5 pp，GS-VLA 仅下降 9.5 pp；εt=50cm 时 +13.7 pp，εt=100cm 时 +44.2 pp，εt=200cm 时 +42.8 pp。
  • 联合平移-旋转实验：Δ 保持在 [+21, +42] pp 范围；更大平移扩大收益，更大偏航角稍缩小收益（归因于训练时大角度采样不足，可通过数据侧解决）。
