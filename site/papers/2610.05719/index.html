When to Switch: Reliable Action-Chunk Extension for Vision-Language-Action Models

2026-10-05 · 原文 · 翻译 · 2610.05719

论文研究 Vision-Language-Action (VLA) 模型在长动作块（action chunk）执行下的可靠性问题，目标是减少策略调用带来的 stop-and-go 执行与空闲时间。 核心发现：长动作块中的动作误差集中出现在 子技能切换（transition） 处，且误差尖峰随块长度 H 增大而加剧，说明 transition timing（何时切换子技能） 是关键挑战。 提出 RACE（Reliable Action-Chunk Extension）框架，通过学习并条件化过渡时机，实现更长动作块的可靠执行。

Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action (VLA) 模型在长动作块（action chunk）执行下的可靠性问题，目标是减少策略调用带来的 stop-and-go 执行与空闲时间。
  • 核心发现：长动作块中的动作误差集中出现在 子技能切换（transition） 处，且误差尖峰随块长度 H 增大而加剧，说明 transition timing（何时切换子技能） 是关键挑战。
  • 提出 RACE（Reliable Action-Chunk Extension）框架，通过学习并条件化过渡时机，实现更长动作块的可靠执行。
Card 03 核心贡献

核心贡献

  • 识别出 操作子技能之间的过渡点 是扩展动作块时动作误差的集中位置，凸显块内 transition timing 的重要性。
  • 提出 RACE 框架：通过辅助的一步去噪（one-step denoising）预测过渡时机，使动作专家具备 transition-aware 能力，并以 token-wise modulation 与逐步可学习门控进行条件化生成。
  • 实验表明 RACE 在相同块长度下优于微调；在 2× 更长块上超越近期 SOTA 与高效 VLA 方法，在 4× 更长块上仍具竞争力。
  • 在真实机器人上使用 4× 更长动作块，将 stop-and-go 造成的空闲时间减少约 5×，且成功率高于同等块长度的微调方法。
  • 开发了代码与真实机器人演示（GitHub: RACE-VLA）。
Card 04 方法描述

方法描述

  • 基于 flow-matching VLA（如 π0.5）构建，包含冻结的 VLM 与 action expert，VLM 特征被缓存复用。
  • 过渡时机预测（Sec. 3.2）：通过辅助一步去噪传递获取动作专家隐藏状态 F_t，结合缓存的 VLM 特征 z_t，经 cross-attention + self-attention + 线性投影 + sigmoid 输出过渡时机先验 p̂_t ∈ [0,1]^H。
  • 过渡条件化动作生成（Sec. 3.3）：通过外积构造 token-wise transition features U_t^k，映射为自适应 RMSNorm 层的 scale/shift/gate 偏移，注入到动作专家的注意力与前馈模块；使用逐步可学习门控 α^k 控制注入强度。
  • 训练目标：L = L_full + λ_aux·L_aux + λ_timing·L_timing，其中 L_timing 为 BCE 损失；训练时使用 teacher forcing + jittering 的条件目标 p̃_t，推理时使用预测的 p̂_t。
  • 过渡标签获取：使用 PELT 变点检测从演示动作中无监督发现子技能边界，并转换为峰值衰减的 软标签（soft labels）。
  • 仅训练动作专家与新增模块，VLM 保持冻结；推理仅增加一次辅助传递与预测头。

Card 06 评估与结果

评估与结果

  • 评估环境：VLABench、RoboCasa-H50、LIBERO 仿真基准，以及真实机器人部署。
  • 主要指标：成功率（SR）、Progress Score（PS）、相对 π0.5 基线的每回合推理 加速比（Spd）、真实机器人 空闲时间。
  • VLABench（Table 1）：在 H_exec=5 时 RACE 平均 SR 30.5，优于 π0.5 基线的 24.6；在 H_exec=10 时 RACE 平均 SR 34.4，优于同长度微调的 32.2；在 H_exec=20 时 RACE 平均 SR 33.0，优于微调的 28.1。
  • 与 ACoT-VLA、AutoHorizon、PACE、Latent Bridge、GridS 等 SOTA 与高效方法相比，RACE 在更长动作块下取得更高成功率。
