Card 02 论文概述

论文概述

  • 论文提出 P³-WAM，一个用于第一视角（egocentric）灵巧操作的统一「世界动作模型」（World Action Model），将 3D 感知、动作条件预测与目标导向规划整合进同一框架。

Card 03 核心贡献

核心贡献

  • 提出统一的 P³-WAM 模型，在一个模型中同时支持 3D 交互重建（Perceive）、动作条件世界预测（Predict）与目标引导的世界–动作联合规划（Plan），并承诺开源代码与模型权重。
  • 提出统一训练框架：通过 Mixture-of-Transformers (MoT) 架构与 随机化模态可见性（randomized modality visibility），把预训练视频先验与结构化 3D 动作连接起来，实现三个模式间的互补学习。
  • 设计紧凑的动作表示：以 MANO 手部参数（全局/局部旋转、形状、根位置、手部存在性）加相机位姿构成动作序列，每帧仅 3 个 token（相机 + 左右手），并由冻结的动作自编码器编码。
  • 实验表明统一训练在三个任务上均优于单模式训练，并在四个数据集上超过专用基线；同时展示了把生成的人手动作迁移到真实灵巧机器人的演示。
Card 04 方法描述

方法描述

  • 基座模型为预训练的 Wan2.2-Fun-A14B-Control 视频扩散 Transformer，保留其潜空间视频表示、文本与首帧条件、骨架控制通路以及高/低噪声双扩散专家。
  • 动作条件的两条通路：渲染的手部骨架视频经 Wan2.1 VAE 编码后与噪声 RGB 潜变量拼接；相机以首帧坐标系表达并构造逐像素 Plücker 射线图，经轻量卷积适配器注入 DiT patch 特征。
  • MoT 架构：RGB 专家与动作专家共享基础投影权重，动作专家额外加入模态特定的 LoRA 低秩更新与归一化，两路通过联合注意力实现双向视觉–动作信息交换。
  • 统一任务形式化：三种模式由喂给同一模型的信息决定——给完整视频隐藏动作是 Perceive，给动作隐藏未来视频是 Predict，同时隐藏动作与视频则是 Plan；训练时逐片段、逐时间位置采样可见性模式，缺失动作用以可学习 query 嵌入表示。
  • 优化目标：视频用 flow matching 损失（仅作用于未观测潜变量），动作侧总损失为 L = L_video + L_param + L_spatial + L_temporal + L_presence + L_camera。
  • 推理：Perceive 单次前向预测完整动作序列；Predict/Plan 迭代去噪未观测 RGB 潜变量，Plan 在最终去噪步保留生成视频与动作轨迹；长任务使用图像生成器产生中间视觉子目标以分窗规划。

Card 06 评估与结果

评估与结果

  • 统一训练增益（Table 1/2）：Perceive 的相机空间、根相对（RR）、Procrustes 对齐（PA）误差分别下降 23.46%、14.23%、5.69%；Predict 的 PSNR 从 17.356 提升至 18.138 dB，FVD 从 1105.95 降至 1009.84。
  • Perceive 评测（Table 3）：与 HaMeR、Dyn-HaMR 对比，按 presence-aware MPJPE-*p* 报告。宏平均相机空间误差 63.05 mm（HaMeR 145.34、Dyn-HaMR 231.54），RR 误差 22.54 mm（46.61 / 45.25），PA 误差 11.79 mm（16.75 / 32.94），手部可见性 F1 达 99.16%，在全部四个数据集上均为最优。
  • Predict 评测（Table 4）：与 Wan2.2-Fun-Control、DreamDojo、Hand2World、EgoSim 对比，分别报告全帧与手部区域的 PSNR/SSIM/LPIPS/CLIP-I/FVD/IoU，本模型在各数据集上取得最优或前三的成绩（如 EgoDex 上 PSNR 24.511、FVD 401.26、CLIP-I 0.9448）。
  • Plan 评测（VLM 打分，1–5 分）：统一训练相比 Plan-only 全面提升——动作过程 2.89（vs 1.88）、指令遵循 3.22（vs 2.27）、物理交互 3.32（vs 2.52）、时序/身份一致性 3.57（vs 2.15）、目标过渡 3.29（vs 1.98）。
  • 机器人部署：论文展示了将生成的人手动作迁移到真实灵巧机器人上的演示，说明规划结果可用于真实操作。
