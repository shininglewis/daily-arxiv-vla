研究单位

  • 密歇根大学安娜堡分校机器人系（Robotics Department, University of Michigan, Ann Arbor, MI, USA）
  • 作者：Haoyang Wu、Abhinav Kumar、Dmitry Berenson
Card 02 论文概述

论文概述

  • 论文研究部分可观测条件下视觉-语言-动作（VLA）策略在拓扑复杂操作任务中的失败问题：相似视觉观察可能需要定性不同的动作，而拓扑签名可区分这些情况。
  • 提出拓扑引导的视觉提示框架，利用仿真规划增强名义演示数据，并在部署时通过 VLM 生成图像空间提示来指导 VLA。
  • 目标是在不依赖部署时完整环境几何信息的情况下，使 VLA 能够推理并纠正拓扑签名不匹配。
Card 03 核心贡献

核心贡献

  • 提出一种微调预训练 VLM 以执行拓扑签名推理的方法。
  • 提出一种视觉提示框架，将 VLM 生成的拓扑信息作为视觉引导增强 VLA 输入。
  • 设计基于模拟器特权几何信息的 h^v-aware 演示生成流程，包括签名纠正和任务延续轨迹。
  • 在三个模拟双臂任务和真实世界盒子拾取任务上验证，显著优于仅用名义演示微调的 VLA 和 PEEK 基线。
Card 04 方法描述

方法描述

  • 使用虚拟 h-signature（virtual h-signature）表示机器人-物体闭环与障碍物闭环的高斯链接积分，量化拓扑关系。
  • 在近似模拟器中利用特权几何信息，通过RRT规划生成 h^v-correction 和 task-continuation 轨迹，扩充 VLA 训练集。
  • 将末端执行器轨迹渲染为图像空间路径/箭头作为视觉提示，叠加在 VLA 的视觉观察上，而不修改 VLA 架构。
  • 微调 VLM 从实时相机观察预测 h^v 签名和末端执行器路点，在闭环中反复更新提示来指导 VLA 动作块。
  • 关键创新：分离拓扑推理与动作预测，避免联合微调导致 VLM 预训练推理能力退化；保留场景上下文（障碍物几何）以支持签名推理。
Card 05 数据集与资源

数据集与资源

  • 模拟任务：Rope Pulling、Cable Threading、Box Pickup；真实世界任务：Box Pickup。
  • VLA 骨干：π0 和 π0.5；VLM：Qwen3-VL-8B-Instruct。
  • VLA 微调：20,000 步，全局 batch size 32，学习率 5×10⁻⁵，1,000 预热步，动作 horizon 10，图像 224×224，bfloat16，LoRA rank 16（2B 视觉语言骨干）和 32（300M 动作专家）。
  • VLM 微调：1 epoch，LoRA rank 8，α=16，全局 batch size 32，4,096 token 上下文，最大 262,144 图像像素，FP16；学习率 5×10⁻⁵（Box Pickup）或 1×10⁻⁴（Cable Threading）。
  • 训练资源：4 块 NVIDIA A40 GPU。
  • 真实世界数据：15 条短真实轨迹 + 3 条 h^v-correction 轨迹，总帧数为模拟数据的 3%；VLM 使用 1,000 个随机真实世界配置的人工标注 h^v，约占其训练数据的 5%。
Card 06 评估与结果

评估与结果

  • 评估环境：三个模拟双臂任务（Rope Pulling、Cable Threading、Box Pickup）和真实世界 Box Pickup；基线包括 Base Policy（仅用名义演示微调）和 PEEK（VLM 提示基线）。
  • 评估指标：任务成功率、h^v-correction 成功率、VLM 虚拟 h^v 签名预测准确率。
  • 模拟结果：Cable Threading 上 Ours 比 Base 高 22–30%，比 PEEK 高 57–58%；Box Pickup 上 Ours 比 Base 高 37–53%，比 PEEK 高 16–27%；Rope Pulling 上与 Base 相当，比 PEEK 高 12–14%。
  • 模拟任务成功率（π0/π0.5）：Rope Pulling Ours 66/64，Base 70/52，PEEK 54/50；Cable Threading Ours 71/77，Base 49/47，PEEK 13/20；Box Pickup Ours 84/82，Base 31/45，PEEK 57/66。
  • VLM 签名预测准确率：Cable Threading 74%（π0）/76%（π0.5），Box Pickup 92%/92%。
  • 真实世界结果：Ours 达到 60% 任务成功率和 83% h^v-correction 成功率，超过最强基线 40 和 53 个百分点；Base π0 为 20%/30%，PEEK 为 3%/20%。
