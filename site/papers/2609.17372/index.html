Card 03 核心贡献

核心贡献

  • 提出四层数据金字塔（data pyramid）：L1 野外自我中心视频、L2 人类视频–动作数据、L3 任务/外观对齐的 bridge 数据、L4 机器人遥操作，另设仅用于仿真训练的失败/恢复集 F
  • 设计非对称 Mixture-of-Transformers（MoT）架构：共享视频主干同时服务于策略与仿真，动作 Transformer 从视频骨干的多层视觉特征读出动作，动作损失梯度可回传进入视频主干
  • 提出由粗到细（coarse-to-fine）联合训练范式：Stage I 纯视频预训练，Stage II 分 II-a/II-b/II-c 三阶段逐步加重目标机器人数据并保留人类 replay
  • 提出 Stage III-sim：chunk-wise self-gradient forcing（SGF），使仿真器适应自生成上下文，提升自回归长时程预测稳定性并降低推理步数
  • 提出 Stage III-policy：基于 DAgger 的恢复数据合成与策略微调，在专家轨迹周围合成“偏离–恢复”轨迹并做一致性过滤，实现世界模型驱动的策略自我改进
Card 04 方法描述

方法描述

  • 动作模式：由视觉历史、当前状态、语言指令条件下联合预测未来视频与可执行动作块，动作时为 N_a = 16，具身特定输入/输出投影 + 共享动作 Transformer
  • 仿真模式：由视觉历史、预设的 2D 骨架序列 κ 与 相机位姿 c_cam 条件下预测未来视频，动作 Transformer 不激活，不使用语言指令
  • Chunk-wise 预测：冻结视频 VAE 编码出初始锚 latent z₀ 与 M 个 chunk，每个 chunk 含 4 个 latent 帧（对应 16 个视频帧），采用 chunk 内双向、跨 chunk 因果的注意力
  • 骨架条件注入：对比 AdaLN、cross-attention、channel concat、token addition 四种方式，最终默认采用 token addition（骨架 patch embedding 零初始化以保护预训练表示）
  • 训练目标：视频与动作均采用 flow-matching 损失（L_v、L_a），仿真更新仅优化 L_v，视频–动作更新优化 L_v + L_a 且权重相等
  • 语言条件：多层级 caption（原始任务指令、稠密描述、原子动作指令、LLM 生成的任务改写），训练中按阶段调整采样比例，从稠密描述逐步过渡到部署风格的任务指令
  • 跨具身动作 schema：统一表示末端执行器位姿、手部关节运动与躯干/相机位姿，保留手部 articulation，源特定归一化
  • SGF 细节：8 步 ODE 采样器自回归 rollout，使用 stop-gradient 截断生成前缀梯度，保留 ℓ2 回归损失而非 DMD 分布匹配，以确保对给定控制的样本级对应
  • 恢复数据合成：选择 pivot 帧与位移最大的手臂，沿采样单位方向 v_d 以步长 μ 施加偏差、偏差视野 k ∈ {8, 16}，采用三角波函数在第 2k 帧回到 pivot；仅用世界模型渲染中间 2k 帧，前后分别拼接真实视频前缀与专家尾部
  • 一致性过滤：以 DINOv3 特征相似度、深度加权 PSNR 与 SSIM 构成三项质量指标，要求恢复端点相对偏差端点更接近专家（Δq > 0）且超过阈值 τq，并按分位数综合打分、任务均衡采样
  • 实时部署：流式 VAE 编码（每 4 帧视频产生 1 个 latent）、重叠视野拼接（overlapping-horizon stitching）、以约 10 Hz 发布控制指令，并通过衰减校正平滑衔接处
Card 05 数据集与资源

数据集与资源

  • 训练语料：约 5,000 小时具身视频，组织为 L1–L4 四层数据金字塔 + 失败/恢复集 F
  • 评测数据集：19 个子集，均独立于训练数据，分为 in-distribution (ID) 与 out-of-distribution (OOD)，涵盖场景外观、物体位姿、干扰物、指令、空间布局、任务组成与动作原语的变化

Card 06 评估与结果

评估与结果

  • 评测维度分为两类：仿真视频预测质量与真实机器人策略性能，指标包括 PSNR、SSIM、OFS（光流相似度）、DINO 特征相似度，以及推理延迟与显存
  • 骨架条件注入消融：token addition 在 ID 与 OOD 两分片上均取得最高 PSNR、SSIM 与 DINO，OOD OFS 亦最高；相比 AdaLN 在 ID 上提升 0.95 dB、OOD 上提升 1.11 dB，且不增加推理开销
  • 长时程自回归评测：Baseline + SGF 在 97 帧（100 ID / 52 OOD）与 193 帧（22 ID / 11 OOD）设置下评估；SGF 模型每 chunk 仅需 8 步 ODE 采样，而基线需 50 步，在提升预测保真度的同时显著降低推理成本
  • 真实机器人评测：在 IRON-R01-1.11 上以任务进度分数与成功率衡量，每个任务每个方法 20 次试验并匹配初始条件
  • 主要结论：异构训练（人类视频 + 机器人数据）提升了策略鲁棒性，并实现人类可观察技能向机器人示教中未出现任务的迁移；人类监督在机器人适配阶段的持续存在有助于抗过拟合与抗遗忘
  • 策略自我改进：合成恢复数据在 Stage III-policy 微调中占训练混合的 8%，其余来自 Phase II-c 数据配方，真实机器人任务完成率获得进一步提升，证明学到的仿真器可用于改进模型自身策略
