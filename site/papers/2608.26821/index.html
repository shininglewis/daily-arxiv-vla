TemporalFlow-VLA: Learning Physically Grounded Execution History for Long-Horizon Robot Manipulation

Card 02 论文概述

论文概述

  • 提出 TemporalFlow-VLA，一种通过物理锚定的时间监督学习紧凑执行历史的视觉-语言-动作（VLA）模型，用于解决长时程机器人操作问题。

Card 03 核心贡献

核心贡献

  • 提出 运动学锚定的机器人表面时间流（kinematics-grounded robot-surface temporal flow）：将记录的机器人运动投影到策略 RGB 图像平面，提供显式、可解释的监督信号，无需物体标注或额外的部署时传感器。
  • 设计两个 分块对齐的时间查询 \(Q_8\) 和 \(Q_{15}\)：其物理内容由区间特定的流重建定义，历史图像块不能直接到达动作专家，必须通过查询在联合掩码注意力中传递。
  • 引入 异步历史特征缓存（asynchronous historical-feature caching）：在动作执行期间后台编码历史观测，显著降低时间条件化的推理开销，使服务器端采样延迟保持在单帧级别。
  • 在 仿真基准（LIBERO、RoboTwin 2.0） 和 真实机器人 上进行了广泛的评估，验证了方法的有效性和实用性。
Card 04 方法描述

方法描述

  • 在预训练 VLA（基于 \(\pi_{0.5}\)）中引入并行时间通路：时间模块接收 \(t-15\)、\(t-8\) 和 \(t\) 时刻的头部相机观测。
  • 构建流程：使用机器人专用渲染器获取可见像素的 3D 表面交点，通过正向运动学将源时刻点传输到目标时刻，经相机投影后生成像素级流场，再聚合为 \(16\times16\times2\) 的补丁级流目标。
  • 两个可学习时间查询 \(Q_8\)（短程）和 \(Q_{15}\)（长程）通过 有向查询特定掩码 组织为层次结构：\(Q_8\) 只读语言、\(t-8\) 帧、当前帧和自身；\(Q_{15}\) 额外可读 \(t-15\) 帧和 \(Q_8\)。
  • 使用 FiLM 条件解码器：查询对源帧空间状态进行调制，经点级 MLP 预测流，损失采用带掩码的 Huber 损失；总损失为动作流匹配损失加时间流重建损失。
  • 部署时无需运动估计或几何处理：几何渲染管线仅用于训练，推理路径仅保留时间查询和动作生成。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO（Spatial/Object/Goal/Long 四个套件）和 RoboTwin 2.0（12 个任务，含 Clean 和 Randomized 条件）仿真基准。
  • 模型基于 \(\pi_{0.5}\) 架构，时间查询维度为 2048，流目标为 \(16\times16\times2\)。
  • 训练资源：8 块 NVIDIA H100 GPU，per-GPU batch size 为 32；LIBERO 训练 30k 步，RoboTwin 训练 60k 步。
Card 06 评估与结果

评估与结果

  • LIBERO 上平均成功率 97.63% ± 0.26%，其中 LIBERO Long 达 96.60% ± 0.87%，显著优于基线 \(\pi_{0.5}\)（92.4%）和 HAMLET（92.2%）。
  • RoboTwin 2.0 上 12 个任务平均 85.5%（Clean）/ 84.2%（Randomized），优于 \(\pi_{0}\)（63.5%/55.3%）、\(\pi_{0.5}\)（79.0%/72.3%）和 X-VLA（66.7%/67.3%）。
  • 在长时程、多阶段任务（H2/H3 组）上优势最明显；例如 Hanging Mug 任务 39%/33%（Clean/Rand.），显著超过其他方法。
  • 历史干预诊断显示：打乱历史帧顺序使离线动作损失几乎不变，而删除历史使损失增加约 4.6%，验证了显式时间监督对历史顺序敏感性的价值。
  • 异步特征缓存使推理延迟从三个视觉编码减少到单个当前帧编码，时间条件化不增加额外历史编码开销。
