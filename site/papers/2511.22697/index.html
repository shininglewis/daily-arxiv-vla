Card 02 论文概述

论文概述

  • 提出 Robotic Steering，一种基于机械可解释性（mechanistic interpretability）的VLA模型微调方法，利用少量演示（few-shot demonstrations）识别并选择性微调与任务相关的注意力头。

Card 03 核心贡献

核心贡献

  • 首次将机械可解释性用于VLA微调，通过语义归因（semantic attribution）识别任务相关的注意力头，实现可控的稀疏微调。
  • 提出基于 k-NN回归 的注意力头选择方法，无需额外模型推理即可高效选出关键头，头选择时间仅 0.2 分钟（对比CMA 58分钟、REINFORCE 93分钟）。
  • 在 π₀ 和 π₀.₅ 两个VLA模型上，用20个演示即可匹配或超越全头LoRA的成功率，同时减少 21% 微调时间、使用 96% 更少 的可训练参数。
  • 展示优越的任务泛化能力和环境鲁棒性（光照变化、物体形态变化、干扰物存在），并验证了多任务学习下非重叠头选择与联合头选择的优势。
  • 提供可部署的标准模型检查点，无需推理时额外干预，使机械微调可直接用于真实机器人系统。
Card 04 方法描述

方法描述

  • 方法分为三步：（1） 使用 k-NN 回归评估每个注意力头对动作预测的贡献，选出 top-m 个任务相关头；（2） 冻结视觉编码器、动作专家和LLM骨干，仅对选中头的 query 和 MLP 参数施加 LoRA 适配器进行微调；（3） 推理时使用微调后的标准检查点，无需额外开销。
  • 创新点在于利用头部激活的余弦相似度检索相似动作时间步，以回归误差作为头重要性评分，从而实现无需梯度的快速头部筛选。
  • 微调目标与基础VLA训练目标一致（如π₀/π₀.₅的 flow matching loss），确保方法兼容不同VLA架构。
Card 05 数据集与资源

数据集与资源

  • 使用 DROID 机器人数据集设定，任务在真实 Franka Emika Panda 7-DoF 机械臂 + Robotiq 夹爪 上执行。
  • 共5个主要任务：place marker in mug、press red button hard、pick up red cube、place green cube in red bowl、push red cup to red bowl，每任务 20 个遥操作演示。
  • 模型为 PaliGemma 3B LLM 骨干（18层 × 8头），使用 JAX 实现，训练使用 2× NVIDIA RTX A6000 GPU。
  • LoRA 秩 r=8，微调 5000 步，激活提取自 LLM 骨干的注意力头，选取 20 个 任务相关头。
Card 06 评估与结果

评估与结果

  • 在真实机器人上对每种方法进行 40 次试验 评估，对比零样本（π₀-DROID、π₀.₅-DROID）和微调方法（全头LoRA、Robotic Steering）。
  • 主要指标为 任务成功率（%） 和 计算开销（训练时间、参数量）。
  • 关键结果：Robotic Steering 在π₀上达到80%/75%/90%/85%/17.5%（五任务），优于全头LoRA的75%/45%/75%/60%/10%；在π₀.₅上也全面领先或持平，且训练时间更短（185-189 min vs 214-239 min），可训练参数减少约96%。
  • 鲁棒性实验显示，在光照、物体形态、干扰物变化下，Robotic Steering 比LoRA 的退化幅度更小（如光照变化下性能下降25% vs 37.5%）。
  • 多任务实验中，非重叠头选择在 Place Marker 和 Place Cube 上分别达到45%和65%，显著优于联合训练的LoRA（37.5%/37.5%）；对未见任务（Pick Mug）的泛化也优于LoRA。
  • 消融实验表明：k-NN回归头选择优于CMA和REINFORCE（速度更快且性能相当）；同时微调queries+MLP比仅微调queries效果更好（80% vs 10%成功率）。
