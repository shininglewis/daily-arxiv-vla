Card 02 论文概述

论文概述

  • 提出 ICI-VLA 框架，通过时空对齐的微演示（spatiotemporally aligned micro-demonstrations）赋予 VLA 模型少样本测试时上下文适应能力，无需在推理时更新任何参数。
  • 采用零结构修改的纯 VLM 文本生成范式（基于 VLA-0），将连续动作表示为数值文本，克服了现有 VLA 在附加动作头、离散 token 或定制架构上的工程开销与语义扰动问题。
  • 解决机器人 ICL 中两大核心挑战：长轨迹与短动作块的时间错位（temporal aliasing）和语义相似但运动不兼容的语义-动态失配（semantic-dynamic mismatch），防止上下文退化为误导性动作前缀。
Card 03 核心贡献

核心贡献

  • 将 VLA 适应建模为固定策略下的少量演示测试时条件生成，明确区分离线训练与测试时推理，替代每个任务单独微调。
  • 构建子任务级微演示库（约 139,659 个示例），将长轨迹分解为固定时域的动作块，并利用 DTW 挖掘运动学正样本，训练 RD-Encoder 实现语义与相位感知的检索。
  • 提出 Target Action Masking 目标函数，在训练时随机掩蔽上下文中的部分目标动作 token，减少策略对精确数值延续的依赖，增强对当前观测的利用。
  • 在 LIBERO、RoboTwin 2.0 与物理双机械臂 Aloha 系统上验证方法，达到最高成功率，并通过消融研究证实各模块贡献。
Card 04 方法描述

方法描述

  • 演示库构建：使用 Qwen3-VL 将全局指令分解为有序子任务，将长轨迹切分为带细粒度标签的微演示，每条包含全局/子任务指令、多视角观测、本体感觉和 k 步动作块。
  • 时空检索对齐：基于 Qwen3-VL-Embedding-2B 训练 RD-Encoder。采用迭代语义硬过滤（保留语义匹配的候选）与 DTW 距离排序，选取相位一致的正样本与相位错位的难负样本，以 InfoNCE 对比损失进行多轮优化。
  • 策略微调：以 Qwen3-VL-4B 为策略主干，全程全参数微调；检索器权重冻结。训练输入为系统指令+检索到的演示+当前查询，配以目标动作掩码（Target Action Masking）的上下文破坏损失。
  • 推理流程：策略与检索器均固定，仅通过检索当前观测相关的三组微演示作为上下文，自回归输出动作块。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（模拟）、RoboTwin 2.0（高保真双机械臂模拟）、Aloha 双机械臂物理系统（约 1,000 条遥操作轨迹）
  • 模型规模：策略 Qwen3-VL-4B；检索器 Qwen3-VL-Embedding-2B
  • 训练资源：Ubuntu 22.04，8× NVIDIA A100 GPU（80GB）
  • 训练配置：检索器 InfoNCE 温度 0.07，全局 batch size 128；策略 AdamW、峰值学习率 2×10⁻⁵；动作块大小 k=25，检索示例数 3，挖掘循环 5 轮
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO（Spatial / Object / Goal / Long 四个套件）、RoboTwin 2.0（Easy / Hard）、物理环境四项任务（单臂抓取、双臂抓取、抽屉放置、物体分拣）
  • 主要指标：成功率（Success Rate, SR）；每个模拟任务 10 次 rollout，物理任务每项 250 次（共 1,000 试次）
  • LIBERO 平均成功率 97.7%，较最高基线提升 1.3 个百分点（LIERO-Long 达到 96.8%，比基线高 3.6）
  • RoboTwin 2.0 平均成功率 60.4%，超过最强基线平均（41.1%）19.3 个百分点，Easy 和 Hard 分别领先 17.2 和 21.8 个百分点
  • 物理任务平均成功率 83.2%（95% CI 80.8–85.4），明显高于 π₀（66.4%）与 VLA-0（63.0%）
  • 消融：移除目标动作掩码使 LIBERO 平均从 97.7% 降至 71.5%，RoboTwin 2.0 从 60.4% 降至 10.7%；移除 DTW 或语义过滤亦显著下降
  • 检索器评估：完整 RD-Encoder 的 Recall@1 从基线 27.8% 提升至 70.8%（+43.0），Recall@5 从 52.4% 提升至 90.1%（+37.7）
