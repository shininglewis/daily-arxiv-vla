Card 02 论文概述

论文概述

  • 论文提出 SP-HLM，一个面向人形机器人“移动-操作”（loco-manipulation）的稀疏位姿驱动框架，用于连接高层任务策略与全身控制。
  • 核心思想：把任务关键的空间意图（显式的五点身体位姿）与全身协调性（隐式学习到的运动先验）用互补形式分别表示，而不再用单一动作表示同时承担两者。
  • 解决的问题：现有接口（关节空间、任务空间稀疏目标、motion token）要么让高层策略负担全身协调建模，要么使任务关键空间约束被隐式化而不明确。
Card 03 核心贡献

核心贡献

  • 提出稀疏位姿驱动的运动接口：用骨盆、双腕、双踝五个任务关键身体位姿（3D 位置 + 6D 旋转）表达空间意图，并配合学习到的运动先验表达全身协调。
  • 提出 SP-GMT：一个同时以稀疏目标与预训练运动隐表示为条件的全身运动跟踪器，实现显式-隐式融合的全身控制。
  • 提出 SP-MGM：通过两阶段蒸馏（离线监督微调 + rollout-aware 蒸馏）得到的实时稀疏条件运动生成器，兼顾稀疏约束贴合度与时序平滑性。
  • 提出 SP-VLA：基于 GR00T N1.7 初始化、采用异步 action-chunk 推理的视觉-语言-动作模型，仅预测稀疏位姿与手指关节目标。
  • 在 8 个仿真任务与 4 个真实机器人任务上验证：整体成功率 52.75%，优于 token 空间（33.75%）与关节空间（31.50%）基线。
Card 04 方法描述

方法描述

  • 整体管线：SP-VLA 预测五点目标与手指关节 → SP-MGM 生成全身运动轨迹 → 预训练运动 VAE 编码器映射为紧凑隐变量 → SP-GMT 结合当前骨盆系下的稀疏目标输出关节位置指令，手指目标直接送入手部 PD 控制器。
  • Yaw 不变隐运动先验：在约 190 小时运动数据上预训练运动 VAE，每帧表示为关节位置/速度 + 6D 骨盆朝向 + 骨盆线/角速度（2J+12 维），去掉全局水平位移与朝向，用 skip-connected Transformer 编码 10 帧窗口。
  • SP-GMT 优化：以目标条件强化学习形式用 PPO 训练，采用非对称 actor-critic（critic 训练时可见特权全身状态）；奖励含稀疏位姿项、全身位姿项、速度项与正则项；训练中使用失败感知 + 均匀运动采样，并随机化电机动力学、接触、外力、动作延迟等。
  • SP-MGM 两阶段蒸馏：压缩预训练扩散式运动生成器（减少网络深度与去噪步数）；Stage I 用冻结教师预测与配对真值联合监督；Stage II 在学生自身 rollout 访问到的状态上采样，由教师给出修正目标，并加入有限差分时序正则抑制高频抖动。
  • SP-VLA 细节：冻结视觉-语言主干，仅微调 flow-matching 动作头；训练时使用 RTC 处理推理延迟，保留干净前缀、只对后缀加噪，以保证 chunk 间时序连续性；推理时异步生成下一 chunk。

Card 06 评估与结果

评估与结果

  • 评测基准：运动跟踪对比 SONIC、Humanoid-GPT；运动生成对比 Kimodo；loco-manipulation 对比 GR00T + Token Space、GR00T + Joint Space、SP-HLM（直接隐变量预测）。
  • 主要指标：Progress、Local/Global MPJPE、Joint error、EE global/local error；生成质量用 EE Error Mean/P95、EE Jerk P95、Body Jerk P95、Generation Rate；任务用成功率。
  • 运动跟踪（Filtered CLOT-500）：SP-GMT Progress 99.83%、Global MPJPE 0.0676 m（最优）、EE global error 0.0733 m（最优）、Joint error 0.0889 rad。
  • 运动跟踪（BONES-SEED Diverse-500）：SP-GMT Progress 92.24%、Global MPJPE 0.0797 m（最优）、EE global error 0.0798 m（最优）、EE local error 0.0553 m。
  • 消融：去掉稀疏参考（w/o Sparse Reference）或去掉隐式参考（w/o Implicit Reference）后全局 MPJPE 与末端误差显著恶化（如 CLOT-500 上 Global MPJPE 升至 0.4436 / 0.1303），验证显式-隐式互补的必要性。
  • 运动生成：SP-MGM 相比生成基线提升稀疏位姿贴合度，并达到 1.45× 更高生成速率（表 III 中含 EE 误差与 jerk 的均值/P95 对比）。
  • Loco-manipulation：SP-HLM 在 8 个仿真任务上整体成功率 52.75%，显著高于 Token Space（33.75%）、Joint Space（31.50%）与直接隐变量预测（23.25%）；并在 4 个真实世界任务上验证可行性。
