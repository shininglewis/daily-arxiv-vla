Card 02 论文概述

论文概述

  • 论文提出了 Adaptive-WAM，一种基于质量引导的提前退出规划方法，利用视频扩散模型中间层特征进行自动驾驶决策，避免完整视频生成。
  • 核心问题：现有世界动作模型（WAM）在部署时需执行完整视频扩散模型，但自动驾驶仅需低维轨迹，因此探究“模型需要执行多少层才能做出可靠决策”。
  • 通过系统分析视频去噪时间步和 DiT 深度，发现规划性能对视频噪声水平不敏感，中间层已能解码出强轨迹，从而驱动自适应退出策略。
Card 03 核心贡献

核心贡献

  • 首次系统诊断视频扩散模型中视频噪声水平和 DiT 深度对驾驶规划的影响，揭示了规划对视频噪声的鲁棒性以及深度依赖的质量-计算权衡。
  • 提出 Adaptive-WAM，一种多出口世界动作模型架构，通过轻量级轨迹质量评分器动态选择 DiT 深度，无需完成视频生成即可输出规划。
  • 在 NAVSIM v1/v2 和 nuScenes 上验证，单轨迹自适应规划器达到 90.8 PDMS（v1），89.9 EPDMS（v2），在比较的世界模型方法中取得最优；零样本迁移时 nuScenes 平均 L2 误差 0.88m，碰撞率 0.08%。
  • 自适应路由在保持 90.79 PDMS 的同时，端到端规划延迟约 170 ms，比最强固定单出口模型（190 ms）低约 10%，比全深度固定模型（320 ms）低约 47%。
Card 04 方法描述

方法描述

  • 骨干网络：基于 Wan2.2-TI2V-5B 视频扩散模型，使用固定视频噪声索引（17/40）进行条件视频特征提取，避免迭代去噪和 VAE 解码。
  • 多出口轨迹解码：在 DiT 的 6 个中间块（5, 9, 15, 18, 22, 30）附加独立的 ReCogDrive 风格轨迹扩散头，每个出口仅解码一条轨迹。
  • 质量引导自适应推理：使用微调的 DINOv2-Small 评分器预测轨迹的 NAVSIM 子分数，并计算综合质量分数；若当前最佳轨迹质量超过阈值，则终止并返回该轨迹，否则继续执行更深层。
  • 训练策略：包含视频域适应（LoRA 微调骨干）、轨迹质量评分器训练（分离梯度）和仅规划器的强化学习（DiffGRPO）细化轨迹头。
  • 关键创新：① 将视频扩散模型作为可调节深度的规划特征提取器；② 用轻量级评分器实现按需终止，而非固定路径；③ 评分器预测多维组件，处理高饱和、常平分的规划奖励。
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSIM v1 和 v2 (navtest 协议)，nuScenes（零样本评估）。
  • 模型规模：Wan2.2-TI2V-5B 作为视觉骨干，6 个出口各带一个轻量轨迹扩散头，评分器基于 DINOv2-Small。
  • 训练资源：单张 A100 80GB GPU，端到端规划延迟测量批大小为 1。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 (PDMS)、NAVSIM v2 (EPDMS)、nuScenes (L2 位移、碰撞率)。
  • 主要指标：PDMS/EPDMS（越高越好），平均 L2 误差和碰撞率（越低越好），延迟（毫秒）。
  • 关键结果：

- 自适应单轨迹规划器在 NAVSIM v1 达 90.8 PDMS，固定出口 64 提案变体达 92.6 PDMS，超越之前世界模型方法。

- NAVSIM v2 上 89.9 EPDMS，为比较的前视视频世界模型规划器中最佳。

- 零样本 nuScenes 上平均 L2 误差 0.88 m，碰撞率 0.08%。

- 自适应路由（阈值 90）取得 90.79 PDMS 且平均延迟 170 ms，优于固定 B15 出口（90.62 PDMS，190 ms）和全深度出口（85.82 PDMS，320 ms）。

- 消融显示：联合 Wan LoRA 适配比冻结或缓存特征提升显著，ViT 替代 Wan 特征导致 PDMS 大幅下降，而 DINOv2-Small 评分器在性价比上优于其他骨干。
