Card 02 论文概述

论文概述

  • 论文聚焦 GUI 智能体的世界模型，让智能体在真实执行前预测候选动作的后果，从而提升长尾、不可逆与长程任务中的鲁棒性。
  • 指出现有像素空间世界模型存在两大问题：(L1) 像素重建计算开销巨大、(L2) 需重建大量与动作选择无关的外观细节，并易产生 identity shortcut（恒等捷径），即预测的未来屏幕仍接近当前屏幕。
  • 核心目标：将世界建模的预测目标从全屏重建转为潜空间中的动作诱导未来信息，使预测监督直接塑造用于动作选择的表示。
Card 03 核心贡献

核心贡献

  • 重新审视 GUI 世界建模：将预测目标由全屏重建转向潜空间中的 action-induced future information，直接服务于动作选择。
  • 提出 Latent GUI World-Action Model：以 LoRA 适配的 LMM 共享表示同时支撑动作选择与动作条件未来预测。
  • 设计 action-aware contrastive objective，将预测未来同时与当前状态及竞争未来状态对比，显式缓解恒等捷径问题。
  • 在离线与在线设置上均超过像素空间世界模型与基础智能体，同时将世界模型推理延迟最高降低 98.9%。
Card 04 方法描述

方法描述

  • 共享潜空间表示：给定当前截图、任务目标、交互历史与冻结 GUI 智能体提出的 K 个候选动作，用 LoRA 适配的 LMM 编码为动作特定隐表示。
  • 动作头（Action Head）：轻量线性头将各候选表示映射为标量分数，经 softmax 得到候选分布，用交叉熵对照真实 one-hot 动作监督。
  • 转移头（Transition Head）：从同一共享表示预测下一状态的视觉嵌入，目标由 target encoder 编码真实下一截图得到，仅在潜空间监督、不重建屏幕。
  • 动作感知对比学习：以预测未来潜表示为锚，正样本为真实下一状态潜表示，负样本包含当前状态潜表示与 FIFO memory bank 中的其他转移潜表示。
  • 联合优化：总损失为 ℒ = ℒ_Action + λ·ℒ_Transition；推理时丢弃转移头，仅用共享骨干与动作头单次前向完成候选打分，并可选地用置信度门控决定是否调用重打分。
Card 05 数据集与资源

数据集与资源

  • 离线数据集：AndroidControl（大规模 Android 交互轨迹）、AITZ（带详细动作标注的移动交互轨迹）。
  • 分布外数据集：GUI-Odyssey（跨应用、长程 GUI 导航基准）。
  • 在线基准：AndroidWorld（交互式 Android 环境，按任务完成度评估）。
  • 模型骨干：GPT-5.6、Gemini 3.6 Flash、GUI-Owl-7B、Qwen3-VL-8B、Qwen3-VL-32B；本方法在 Qwen3-VL-8B-Instruct 上以 LoRA 微调（r=16、α=32、dropout 0.05）。
  • 训练资源：AdamW，学习率 4×10⁻⁵，有效 batch size 为 8，训练 3 个 epoch，在单张 NVIDIA A6000 GPU 上训练约 8 小时；λ=1.0，温度 τ=0.07。
  • 对比基线：Code2World（可渲染代码预测）与 Diffusion2Image（扩散模型生成未来截图）。
Card 06 评估与结果

评估与结果

  • 离线指标：Type（动作类型准确率）、Grounding（点击坐标落在 14% 屏宽半径内）、SR（类型与参数均正确）；效率指标为 Tokens/Task 与 Run Time。
  • 在线指标：AndroidWorld 的 Easy/Medium/Hard/Overall 任务成功率，以及 Tokens/Task、Mean Steps、Run Time。
  • 离线结果：Type 在 AndroidControl 上提升 +0.9~+4.3 点、AITZ 上提升 +0.3~+4.9 点；SR 在 8 个骨干–数据集设置中的 7 个上提升，最高 +4.8 点；而像素空间世界模型在所有离线设置中 SR 反而下降最多 8.6 点。
  • 在线结果：在全部 5 个骨干上取得最高 Overall SR，较基座智能体提升 +4.5~+12.5 点，Hard 任务提升 +5.6~+11.1 点。
  • 效率结果：相比像素空间世界模型，推理延迟最高降低 98.9%；Code2World 约需 2.1–4.1× 运行时间，Diffusion2Image 约需 4.5–18.2× 更长执行时间。
  • 消融实验（AndroidWorld）：基座 27.68 → 仅加动作头 36.36 → 加转移头（点式余弦回归）38.18 → 加动作感知对比目标 40.18，总计提升 +12.50 点。
  • 分布外泛化：在 GUI-Odyssey 上取得最高 SR（GUI-Owl-7B 为 34.73，Qwen3-VL-8B 为 52.13），而两种像素空间世界模型均低于基座。
  • 定性分析：t-SNE 显示去除当前状态簇均值后，本方法形成最清晰的动作特定未来表示结构，优于 Base、Code2World 与 Diffusion 表示。
