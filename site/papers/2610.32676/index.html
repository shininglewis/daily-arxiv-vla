Retiming Robot Demonstrations with a Learned Speed Prior

2026-10-23 · 原文 · 翻译 · 2610.32676

机器人演示数据的速度节奏通常由遥操作者决定，而不是由任务本身决定；这导致同一动作在不同演示中速度差异巨大，模仿学习得到的策略会把操作者特定的“节奏”连同任务行为一起继承下来。 论文提出从大规模演示数据中学习一个速度先验（speed prior）：给定任务指令、运动路径及其沿途腕部相机图像，预测沿路径执行速度的分布；再从该分布取一个分位数，定义统一的“时钟”，用来对演示重新定时（retiming）。 目标是在不复制具体轨迹的前提下，把更快演示者（如手持夹爪采集者）的节奏迁移到遥操作演示上，并配套一个遵守机器人动力学约束的实时执行控制器。

Card 03 核心贡献

核心贡献

  • 提出跨任务共享的速度先验：一次训练即覆盖语料库中所有任务，避免现有方法“每个新任务都要重新拟合、标注或指定一对预定义速率”的成本。
  • 用域标签（src/tgt）+ 图像丢弃 + 类分类器无引导的方式，从源域路径读出目标域的节奏，实现对源演示的重新定时而不改变其路径。
  • 提出tempo channels（节奏通道）作为额外动作维度，让策略在部署时可按需加速，而不必重新训练。
  • 设计一个实时最优控制层：把预测节奏作为上界，在机器人速度、加速度和力矩约束下执行动作块，并在块边界实现位置、速度、加速度均连续的平滑拼接。
  • 在120 个 RoboLab 仿真任务和真实机器人上同时验证：训练更快、加加速度（jerk）更低、成功率更高。
Card 04 方法描述

方法描述

  • 路径与时钟表示：把每条演示按弧长重采样，弧长增量融合平移、旋转（ρ_r = 0.3 m/rad）和夹爪开合（ρ_g = 0.15 m），记为 t(s)；重定时即用 t̂(s) = ∫ ds′/v̂(s′) 替换原时间映射，保留路径本身。
  • 速度先验架构：从零训练的 Transformer，输入为指令 token、17 组（图像 + 节点）token 和 16 个 query token，图像与指令使用冻结编码器；每个窗口 17 个节点、间距 2 cm、跨度约 32 cm。
  • 分类式输出：对每个执行器预测 B = 256 个对数速度区间（1–5000 mm/s）上的类别分布，目标用 two-hot 编码，交叉熵训练；区间时长取两执行器中较慢者 T_j = max(L^a/v^a, L^g/v^g)。
  • 受分类器无引导启发的重定时：训练时以 0.5 概率丢弃图像，重定时时按 f̃^a = f^a(src, I) + λ[f^a(tgt, ∅) − f^a(src, ∅)] 组合 logits，再对覆盖同一区间的窗口分布取平均并解码分位数 q。
  • 策略微调：以中位时钟（q = 0.5）作为 base clock 微调 π0.5 DROID 策略，并额外回归 tempo channels τ_h^(q) = log(δ/δ_h^(q))（δ = 1/15 s）。
  • 执行求解器三步：Draft（最小 jerk 路径按目标节奏定时）→ Splice（在约束下选取最早的准点进入点）→ Smooth（带约束的最小 jerk QP 平滑）；并通过预留切换时刻 t_b 提前规划，保证机器人在 chunk 切换时不停顿、不跳变。
Card 05 数据集与资源

数据集与资源

  • DROID：大规模遥操作机器人演示数据集，作为源域演示（source）。
  • FastUMI-100K：手持夹爪（人手而非机械臂）演示数据集，作为目标节奏来源（target）。
  • RoboLab：120 个仿真任务用于评测；真实实验另采集 YUBI 夹爪手持演示。
  • 基座策略：π0.5（π0.5 DROID 权重）视觉-语言-动作策略。
  • 真实机器人：Franka Research 3，配 1 kHz 力矩底层控制器。
  • 速度先验为从零训练的 Transformer，论文正文未给出具体参数量与 GPU 配置（详见附录 B、C 的训练细节）。
Card 06 评估与结果

评估与结果

  • 仿真基准：RoboLab 120 个任务，对比“原时序 + 均匀加速到同等速度”的策略，以及“仅用最快演示训练”的策略。
  • 主要指标：成功率、执行时间、吞吐量、平滑度（jerk）、以及带 regret 的吞吐量。
  • 在 RoboLab 上，用学习时钟微调的策略成功率更高；在 2.4× 加速下，jerk 比均匀加速基线低 52%。
  • 仅用最快 DROID episode 训练（其节奏为全体的 1.5×）仅比全量数据策略快 1.07×，说明“选快数据”不能替代“学节奏”。
  • 真实机器人叠杯子：3.50 s 完成，默认策略为 6.02 s（1.72× 加速）；30 次试验成功 29 次；仅用最快四分之一数据训练的策略仅成功 9/30。
  • 与 SAIL 报告的 14.71 s、0.40 成功率相比，本方法叠三个杯子的金字塔快 4.2×、成功率高一倍以上。
  • 控制器消融：把关节 PD 换成所提控制器后，即使是按原始时序训练的策略，叠毛巾成功率也从 13% 提升到 97%。
  • 附录分析还显示：速度先验能刻画单次 episode 内的节奏变化、可迁移到手持节奏，且重定时后的演示更平滑；并支持零样本迁移评测。
