Card 03 核心贡献

核心贡献

  • 提出 VLALagBench，首个同时变化任务类型、目标速度、推理延迟、执行模式和 VLA 策略五因素的 VLA 延迟敏感性基准。
  • 给出四项关键发现：延迟对移动目标成功率影响显著且任务相关；敏感性源于观测陈旧与机器人停顿两类因素；异步执行可恢复部分成功率但增加推理请求频率；不同策略延迟敏感性不同，最优策略随任务与速度变化。
  • 提出一个经验成功率预测模型，仅需少量标定数据即可预测不同延迟、执行模式和执行视界下的任务成功率，RMS 误差仅 5.7%–7.8%。
  • 将该模型用于系统特定的算法配置选择：在四种代表性部署系统（Jetson AGX Thor、RTX 4090 + WiFi 7、H100 + 5G、H100 + 慢速云）上均选出与实测最优一致的执行模式与视界。
Card 04 方法描述

方法描述

  • 基准构建：在 MuJoCo 上的 LIBERO 环境中构建主基准，设计四类任务——release（投入移动篮筐）、set-down（放到移动盘子上）、grasping（抓取移动柜子上的碗）、articulated manipulation（拉开移动柜子的抽屉）。
  • 运动控制：目标沿闭合近椭圆轨迹以恒定速度运动（0.001–0.2 m/s），通过运动学更新位置但保留真实接触物理（如用摩擦带动碗、保留抽屉阻尼滑动关节）。
  • 三种执行模式：

- 同步执行：每执行 H 步后停机等待推理，空闲时间 I = L。

- 惰性异步执行：在剩余 L 步时发起推理，无停机，平均观测陈旧度与同步相同。

- 连续异步执行：推理一完成即发起下一次，H = L，短延迟下陈旧度可低于零延迟同步执行。

  • 延迟注入机制：将延迟换算为仿真控制步数（20 Hz 下 100 ms 对应 L = 2 步），并相应延长任务 deadline 以保证动作预算。
  • 经验模型：假设延迟等价于「提高目标速度」，用 S_X(v) ≈ S_0(λ_X·v) 建模，其中 λ_X = 1 + a·(相对陈旧度变化) + b·(空闲步比例)，系数 a、b 按「策略–任务」对分别拟合，量化其对陈旧观测与停顿的敏感度。

Card 06 评估与结果

评估与结果

  • 评估设置：控制频率 20 Hz，执行视界 H = 5，推理延迟从 0 到 250 ms（每 50 ms 一档）；指标为任务成功率与预测模型的 RMS 误差。
  • 主要结果（π0.5，同步执行）：目标速度 0.1 m/s 时，仅 100 ms 延迟就使 set-down 成功率从 71.5% 降至 40.5%（近乎腰斩），而 grasping 仅从 86.5% 降至 74.0%（保留 86%）。
  • 敏感度归因：set-down 容差仅 3 cm 而 release 篮口达 12.2 cm，故高精度任务受观测陈旧影响大；release 与 articulated 更受停顿影响（200 ms 延迟使 π0.5 接近速度下降 34%）；set-down 对两者都敏感。
  • 异步收益：50 ms 时连续异步将 set-down 在 0.125 m/s 下的成功率从 51.5% 提升至 70.0%；200 ms 时 release 由同步切换至惰性异步，π0.5 从 48.5% 升至 81.5%，MolmoAct2 从 57.0% 升至 92.0%，GR00T N1.7 仅从 30.0% 升至 32.0%。
  • 策略差异：近静态目标下成功率差异明显（set-down：π0.5 93.5%、MolmoAct2 74.0%、GR00T N1.7 56.0%）；GR00T N1.7 对初始目标位置高度敏感，是拟合中的异常点。
  • 模型与配置选择：四任务三模式整体 RMS 误差 5.7%，减少标定数据后中位误差 7.7%；四系统均选出实测最优配置，系统 B/C/D 预测误差 2.5%–4.6%。
