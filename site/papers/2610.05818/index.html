研究单位

Card 02 论文概述

论文概述

  • 研究 视觉-语言-动作模型（VLA） 在收到"行为本身无害、但动机有害"的指令时是否会被安全监控拦截，方法上保持任务动作固定，仅改变有害意图表述的显式程度。
  • 核心问题：VLA 无法拒绝指令（只输出动作），因此安全性依赖外部监控器（文本守卫与激活探针），但这些监控器能否识别"隐含有害"的机器人指令尚不清楚。
  • 结论：机器人无论在何种意图层级都会完成任务；文本守卫几乎只能识别直白的有害请求，而 机器人训练会削弱模型内部的有害意图信号。
Card 03 核心贡献

核心贡献

  • 提出面向 VLA 的受控意图测试：动作、物体与场景保持固定，仅改变所述目的及其显式程度，且守卫与探针在完全相同指令上运行。
  • 揭示"守卫漏掉的，机器人会执行"：如同监控聊天模型的情形，守卫主要捕捉直白危害，而机器人会执行那些被漏检的有害请求。
  • 发现 机器人训练侵蚀有害信号：在两个模型家族中，机器人训练前可从模型中近乎完美读出有害意图，训练后信号显著减弱，且对隐含危害削弱最严重（将 VLA 中视觉-语言知识丢失的现象扩展到安全相关内容）。
  • 量化了实际泄漏规模：隐含危害场景下最高 95% 的有害运行以"任务完成且未触发告警"告终，即使按机器人指令重新校准阈值后仍高达 90%。
Card 04 方法描述

方法描述

  • 指令构造：选取 5 个 LIBERO-Goal 厨房任务（如打开炉灶、把奶油奶酪放进碗里），由 LLM 为每项任务撰写有害"理由"故事，分为三档显式程度：L1 间接暗示、L2 直接陈述事实、L3 直白宣告，并配一条长度相近的无害对照；任务字符串逐字保留。
  • 质量把关：两个 LLM 评审（Claude Opus 5 / Claude Sonnet 5）检查意图保持、层级间显式度差异（1–10 量表上至少差 2 分）、动作必要性等，最终保留 51 条理由（显式度均值 1.0/3.5/6.6/9.6）；另由两名人工标注者盲评 200 条指令验证。
  • 机器人执行：使用 π0.5 与 OpenVLA-OFT 的公开 LIBERO 检查点；每任务 7 条理由 × 各层级 × 5 个初始布局，共 700 次运行；OFT 在 4 个任务上共 560 + 20 次；成功判据为 300 步内完成 LIBERO 内置检查。
  • 文本守卫：Llama Guard 3、WildGuard、Qwen3Guard 各自按"在 10,000 条良性 WildChat 提示上误报 1%"设定阈值，并在各层级间保持固定；附录另测 gpt-oss-safeguard-120B 与按机器人指令重校准的阈值。
  • 激活探针：对指令 token 的残差流激活做均值池化，用逻辑回归在 L3 vs 对照上训练，采用留一任务交叉验证；探测两个模型家族：Llama-2-7B → Prismatic-7B → OpenVLA-OFT 与 Gemma 2B → PaliGemma-3B → π0.5；排除前四分之一层以避开仅编码词元的浅层信号。
  • 关键指标"泄漏（leak）"：VLA 完成任务且守卫未对该指令报警。
Card 05 数据集与资源

数据集与资源

  • 任务数据集：LIBERO-Goal（5 个厨房任务）、LIBERO-Para（用于 OFT 的流水线合理性检查，20 条改述）。
  • 守卫校准数据：WildChat 的 10,000 条良性提示；附录使用 ASIMOV 的 71 条良性机器人指令进行重校准。
  • 模型：π0.5、OpenVLA-OFT（VLA）；Llama-2-7B、Prismatic-7B、Gemma 2B、PaliGemma-3B (pt-224)（基座 LM/VLM）；Llama Guard 3、WildGuard、Qwen3Guard、gpt-oss-safeguard-120B（守卫）。
  • 计算资源：全部 rollout 在 NVIDIA A10 GPU 上运行，随机种子 0，初始状态 0–4；π0.5 使用 GPU (EGL) 渲染。
Card 06 评估与结果

评估与结果

  • 评估环境：模拟厨房中的 LIBERO-Goal 任务，从公开 LIBERO 检查点复现原任务性能（OFT 489/500 = 97.8%，发表值 97.9%；π0.5 在五个任务上 49/50）。
  • 主要指标：任务成功率、守卫/探针的标记率（flag rate）、泄漏率（leak rate）、探针 AUROC、人类标注的有害意图识别率。
  • 机器人无视意图：π0.5 对照成功率 97.1%，L1/L2/L3 分别为 95.4%/96.6%/95.4%；明确说出危害也不改变行为。
  • OFT 的"安全"是假象：裸任务 19/20 成功，但含理由的 560 次运行 0 次成功（有害与无害皆然），因为它无法处理多出来的句子；在 LIBERO-Para 改述上仍有 69% 成功率，附加 5–20 个填充词也正常，仅在加入完整理由句时失败。
  • 守卫只抓直白危害：对照与原任务零报警；L3 标记率 92%–98%，但 L1/L2 几乎为零（0–2%，仅 Llama Guard 3 为 6% 与 33%）；L1/L2 泄漏率 66%–97%，L3 为 3%–11%；而人工标注者在 82% 的 L1 指令中识别出有害意图。按机器人指令重校准后 L2 大幅改善，但 L1 仍有 58%–90% 泄漏。
  • 机器人训练削弱内部危害信号：基座模型探针 AUROC 近乎完美（Llama-2 与 Prismatic 均为 1.00，Gemma 0.99/1.00/1.00，PaliGemma 0.99/1.00/1.00），训练后显著下降——Prismatic→OFT 降 0.27/0.20/0.14，PaliGemma→π0.5 降 0.20/0.17/0.03（95% 置信区间不含零），隐含危害下降最多；π0.5 探针作为监控器仅标记 12%–16% 的有害指令，约四分之三的有害运行泄漏。
  • 局限：仅一个模拟厨房、5 个任务、51 条理由、2 个 VLA；词袋基线（AUROC 0.97–1.00）几乎追平基座模型探针，说明部分信号可能是词汇性的；探针阈值基于少量负样本，噪声较大。
