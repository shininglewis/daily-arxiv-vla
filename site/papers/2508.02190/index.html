Card 02 论文概述

论文概述

  • 提出 FedVLA，首个面向机器人操作（Robotic Manipulation）的联邦视觉-语言-动作（Vision-Language-Action, VLA）学习框架，解决 VLA 模型集中式训练中用户数据隐私泄露的风险
  • 框架通过本地客户端训练模型、仅上传模型更新而非原始数据，在保护数据隐私的同时实现分布式协同优化，性能媲美集中式训练
  • 集成三个关键组件：Instruction-Oriented Scene-Parsing (IOSP) 任务导向场景解析、Dual Gating Mixture-of-Experts (DGMoE) 双门控专家混合、Expert-Driven Aggregation (EDA) 专家驱动的聚合策略
Card 03 核心贡献

核心贡献

  • 提出 FedVLA，第一个面向 VLA 训练的隐私保护联邦学习框架，用户数据无需离开本地设备，通过模拟与真实世界实验验证性能可与集中式训练媲美
  • 设计 Dual Gating Mixture-of-Experts (DGMoE) 机制，引入自感知专家（self-aware experts），实现 token 与专家之间的双向选择，动态决定专家激活数量，显著提升计算效率
  • 提出 Expert-Driven Aggregation (EDA) 聚合策略，基于客户端间专家选择相似度动态分配聚合权重，使语义对齐的知识得到更有效的整合，增强异构任务间的泛化能力
  • 提出 Instruction-Oriented Scene-Parsing (IOSP) 模块，利用 CLIP 视觉-语言对齐和 YOLOv8 目标检测，将场景解析为目标物体、周围物体和背景物体，增强任务相关特征提取
Card 04 方法描述

方法描述

  • IOSP 模块：从指令中提取目标物体（TOs），用 YOLOv8 检测前景物体（FOs）和背景物体（BOs），通过预训练 CLIP 模型的余弦相似度将场景物体分为三类，每组图像 token 经 MoE 模块增强后与其余 token 拼接，提升多物体场景下的上下文理解
  • DGMoE 机制：每层包含 K 个自感知专家和双重门控——token 侧门控 G_t（含软路由器和门控残差模块，融合前一层选择先验）和专家侧门控 G_e（基于可学习阈值 W_e 与缩放因子 λ=0.5，自主接受或拒绝 token 分配），最终输出为选中专家输出的加权和
  • EDA 聚合策略：客户端记录每层专家选择计数矩阵 V，服务器计算客户端间专家选择向量的余弦相似度，据此为每个客户端逐层分配归一化聚合权重，仅聚合 Trunk 模块（Stem 和 Head 保持个性化），广播更新后的全局 Trunk 给客户端
Card 05 数据集与资源

数据集与资源

  • 模拟环境：使用 MuJoCo 引擎和 Meta-World 基准，包含 Door Lock、Close Drawer、Sweep Into、Open Window 四个任务，Sawyer 机器人，三台 128×128 RGB 相机，每任务约 30–80 条轨迹
  • 真实环境：UR3 六自由度机械臂 + one-DoF 平行夹爪 + RealSense D435i RGB-D 相机（1280×720@30Hz），四个真实任务：Clean Up、Trash Collection、Open Drawer、Sorting Pills，每任务约 50 条专家演示轨迹
  • 模型主干：预训练 HPT（Homogeneous Pretrained Transformer）VLA 模型
  • 训练配置：1000 轮客户端-服务器通信轮次，每轮客户端本地训练 5 个 epoch，batch size 256，Adam 优化器；模拟环境学习率 5×10⁻⁶，真实环境 2×10⁻⁵
  • 硬件资源：2 块 GeForce GTX 4090Ti GPU、48 核 Intel Xeon CPU、128GB 内存
Card 06 评估与结果

评估与结果

  • 评估设置：每个任务 15 次试验，重复 5 次，以成功/失败（1/0）记录任务成功率；对比方法为集中式训练（作为性能上界）和 FedAvg（联邦平均基线）
  • 模拟实验结果：FedVLA 平均成功率 63.3%，接近集中式训练 65.0%，显著优于 FedAvg 的 51.7%；在 Close Drawer 任务上 FedVLA 达到 80.0%，超过集中式训练的 73.3%
  • 真实世界实验：FedVLA 平均成功率 63.3%，与集中式训练的 63.4% 基本持平，比 FedAvg 的 53.3% 高出 10%；在 Trash Collection 和 Sorting Pills 任务上与集中式训练成功率持平（46.7% 和 73.3%）
  • 消融实验：分别移除 IOSP、DGMoE、EDA 后平均成功率降至 41.1%、31.7%、26.7%（完整模型 63.3%），验证三个组件的必要性；移除 EDA 性能下降最严重，说明专家感知聚合对联邦 VLA 学习至关重要
  • 效率分析：DGMoE 每 token 平均激活专家数为 1.219–1.229，远低于传统 top-k MoE 的固定 k 值（k>1），显著降低前向计算量，适合资源受限的边缘设备部署
