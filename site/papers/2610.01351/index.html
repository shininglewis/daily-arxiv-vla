Card 02 论文概述

论文概述

  • 针对 Vision-Language-Action (VLA) 模型，提出一个与基准无关的行为鲁棒性评估框架，刻画扰动下"成功轨迹"的执行行为变化
  • 指出当前 VLA 鲁棒性评估几乎完全依赖 任务成功率（TSR） 这一二元指标，掩盖了成功轨迹的行为退化
  • 目标回答三个研究问题：扰动下成功轨迹的典型行为如何变化（RQ1）、这些变化是否反映在 TSR 中（RQ2）、扰动是否改变行为一致性（RQ3）
Card 03 核心贡献

核心贡献

  • 提出一个基准无关的行为评估方法论，在 TSR 之外补充轨迹级行为指标（时长、夹爪总移动量、笛卡尔 jerk、关节 jerk、笛卡尔路径长度、关节路径长度），并在 LIBERO / LIBERO-Plus 上实现
  • 将扰动效应分解为典型行为变化（任务级均值变化的中位数）和行为一致性变化（基于 MAD 的离散度度量）
  • 实证证明：对当前 SOTA VLA 模型，任务成功鲁棒性 ≠ 成功执行行为鲁棒性——即使在 TSR 保持时，成功轨迹也可能发生显著变化
  • 发现不同模型在相同扰动条件下可有相近 TSR 但行为差异巨大，说明仅用 TSR 比较模型会掩盖关键差异
  • 公开实现代码（https://github.com/esgi-research-group/vla-reliability），可扩展至其他基准（如 MetaWorld）
Card 04 方法描述

方法描述

  • 以无扰动 LIBERO 任务为 baseline，以 LIBERO-Plus 扰动任务为 condition，仅分析成功轨迹
  • 采用 RoboEval 中已有指标（Cartesian jerk、joint jerk、Cartesian/joint path length）并新增 total gripper movement
  • 时长使用仿真器控制时间（10 Hz）而非墙钟时间，避免 GPU 争抢/推理延迟的干扰
  • 计算任务级均值百分比变化 Δ，取所有任务的中位数汇总每类扰动效果
  • 使用 Mann-Whitney U 检验（双侧）+ Benjamini-Hochberg FDR 校正（α=0.05）判断显著性
  • 使用 中位数绝对偏差（MAD） 的百分比变化量化行为一致性变化
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 与 LIBERO-Plus 基准，覆盖四个任务套件：LIBERO-Spatial、LIBERO-Long、LIBERO-Goal、LIBERO-Object
  • 扰动维度为 LIBERO-Plus 的七类：对象布局、相机视角、机器人初始状态、语言指令、光照条件、背景纹理、传感器噪声（外加"无扰动"共 8 种条件）
  • 评估三个 SOTA VLA 模型：π₀.₅、VLANeXt、OpenVLA-OFT（后者仅评估 Spatial 套件，因 TSR 降至 67.9%）
  • 使用开源 vla-eval 评估框架（Choi 等）实现可复现的并行评估
  • baseline 每个任务 50 次 rollout；每个扰动变体 2 次 rollout（对象扰动仅 1 个初始状态）
  • 未在原文中披露模型参数量与具体 GPU/TPU 训练资源（HTML 被截断）
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO / LIBERO-Plus 仿真基准，跨 4 个任务套件、7 种扰动、3 个模型
  • 主要指标：TSR + 6 项轨迹行为指标（Duration、Cartesian/Joint Path、Cartesian/Joint Jerk、Gripper Movement）及 P95 Cartesian jerk
  • 关键发现一：π₀.₅ 在 LIBERO-Spatial 的 Camera 扰动下 TSR 从 98.8% 降至 69.7%，成功轨迹行为变化剧烈——P95 Cartesian jerk +48.7%、gripper movement +37.8%、duration +22.5%
  • 关键发现二：VLANeXt 与 π₀.₅ 在部分扰动下 TSR 接近（如 Spatial-Camera：68.0% vs 69.7%），但行为指标变化模式明显不同（VLANeXt 时长仅 +4.2%，π₀.₅ 为 +22.5%）
  • 关键发现三：OpenVLA-OFT 在 Camera 与 Robot 扰动下行为退化最严重（如 Robot 扰动 P95 jerk +54.7%、gripper movement +79.5%）
  • 结论性主张：评估 VLA 鲁棒性时，TSR 应辅以刻画成功执行行为性质与变异性的行为指标
