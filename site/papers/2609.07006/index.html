Card 03 核心贡献

核心贡献

  • 提出 GIFT 轻量级微调框架，通过 零初始化卷积（ZeroConv） 将目标图像特征注入 VLA 观测，不破坏预训练操作策略的稳定性。
  • 提出面向机器人场景的精细化图像编辑方法 Image Editing for Robotic Goal，采用上下文编辑提示（in-context edit prompt）确保与指令对齐，并引入 观测结构注入（Observation-structure Injection） 保持与观测场景一致。
  • 在 OpenVLA、CogACT、SpatialVLA 等多个 VLA 基线（涵盖 Prismatic VLM 与 PaLI-Gemma2 两种骨干）上验证了模型无关的泛化能力。
  • 仅以单个 epoch 微调，在 SIMPLER 两个设置上分别提升 6.0% 与 13.4%，在 LIBERO 上提升 4.7%；真实机器人任务上也获得一致性提升。
Card 04 方法描述

方法描述

  • 两阶段框架：先在推理前用图像编辑模型基于初始观测与语言指令生成目标图像，再将目标图像条件输入微调后的 VLA 策略预测动作。
  • 通过共享图像编码器提取目标与观测特征，计算语义差（Semantic Contrast）$F_{\Delta}=F_g-F_t$，突出任务相关变化。
  • 基于 ControlNet 风格的零初始化卷积层 $\mathrm{ZeroConv}(\mathrm{Proj_g}(F_{\Delta}))+\mathrm{Proj_o}(F_t)$，训练初期抑制干扰、训练中渐进注入目标信号；推理时目标图像在整个任务执行过程中重复使用。
  • 微调时冻结绝大部分预训练参数，仅更新三个轻量组件：目标图像投影器（由观测投影器初始化）、零初始化卷积层与动作预测头。
  • 图像编辑模块基于 FLUX.1-Fill-dev，通过 LoRA 微调 T2I DiT；先对观测做潜在反转（latent inversion），再与随机噪声拼接输入 DiT 去噪，并以加权融合方式注入观测结构特征 $\hat{z}=\alpha z^g+(1-\alpha)z^o$。
Card 05 数据集与资源

数据集与资源

  • 评估基准：SIMPLER（Google Robot 与 WidowX 双平台，含 Visual Matching 与 Variant Aggregation 设置）、LIBERO（Franka Emika Panda，Spatial/Object/Goal/Long 四个任务套件）。
  • 微调数据集按机器人平台严格对齐：WidowX 用 BridgeDataset V2，Google Robot 用 Fractal 数据集，LIBERO 用 LIBERO 数据集；图像编辑模型用三者的混合子集训练（90% Bridge + 90% Fractal + 30% LIBERO）。
  • 真实世界实验：Synria Alicia-D 六自由度机械臂 + Intel RealSense D405 相机，每个任务收集 30 条 LeRobot 格式演示，基线为 π0.5。
  • 训练资源：4 张 NVIDIA L20 GPU，PyTorch FSDP；单 epoch 训练时间约 CogACT 24/43.2 小时（Bridge/Fractal）、OpenVLA LIBERO 9.6 小时；图像编辑模型训练 3 epoch，LoRA rank=32，有效 batch size 144。
Card 06 评估与结果

评估与结果

  • SIMPLER（Google Robot）中 CogACT+GIFT 在 Visual Matching 达 80.5% 平均成功率（较 CogACT +6.0%），在 Variant Aggregation 达 74.7%（+13.4%）；WidowX 上 CogACT 四任务均提升，平均 51.3%→67.7%，其中 Task3 从 16.4% 涨至 43.1%。
  • LIBERO 中 OpenVLA+GIFT 平均成功率 81.2%（+4.7%），Spatial 89.5%、Goal 88.6%、最具挑战的 Long 任务 56.0%，均优于其他方法。
  • 真实机器人部署：π0.5+GIFT 在域内任务成功率由 56.7%/36.7% 提升至 71.7%/43.3%；OOD（暗光）场景增益更显著，由 33.3%/23.3% 提升至 51.7%/36.7%。
  • 目标图像质量对比（Table 4，固定注入模块、只换目标来源）：降级目标性能最差，SuSIE 缺乏空间一致性（Stack 为 0%），Turbo 编辑器牺牲保真度（约 1.1s），本方法（约 4.2s 一次性生成）在全部 9 个任务上优于所有生成基线且接近 GT 目标上界。
  • 消融实验表明：语义对比机制将性能从 57.5% 提升至 67.7%；ZeroConv 优于 FiLM，交叉注意力会严重破坏预训练策略（接近零成功率）；观测结构注入可提升场景布局与结构一致性。
  • 论文同时指出 GIFT 增强而非创造能力——例如 OpenVLA 注入目标后 PutInDrawer 仍为 0%，说明其只能放大大模型已具备的操作能力，无法凭空补足缺失技能。
