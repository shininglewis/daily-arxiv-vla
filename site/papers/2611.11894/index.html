论文概述

Card 03 核心贡献

核心贡献

  • 提出 closed-form instruction distillation（闭式指令蒸馏）：先找到一个能成功的改写指令，再把该改写带来的逐层内部效应以闭式权重编辑写入 VLM 的 MLP 权重。
  • 在 128 个 held-out seeds 上将成功率从 27/128 提升到 106/128，修复 81 个、破坏 2 个，说明该编辑可泛化到编辑时未使用的种子。
  • 证明编辑效果来自特定方向而非更新幅度：同等大小的随机方向更新无效；仅存储 0.16% 参数的小变体仍保留大部分效果。
  • 发现编辑位置很关键：写入 VLM 最有效并可迁移到两个其他任务；写入 action expert 或 action head 效果更差或无效。
  • 发布 weightsmith distill 工具，并报告七名盲测 Claude Opus 编辑器的受控研究，以及配对闭环评估的噪声下限。
Card 04 方法描述

方法描述

  • 在固定图像、机器人状态和 flow-matching 噪声的条件下，重放失败决策并尝试不同指令改写；找到能消除失败的 known-good instruction。
  • 对 VLM 每层构造 72 个 keys：40 个提示/状态位置 + 32 个图像单元（每相机 16 个）；keys 为原始指令下 MLP 下投影输入在 6 个失败决策上的均值。
  • values 为显式改写指令与原始指令下每层残差增量之差；使用多键闭式最小范数更新：ΔW = Kᵀ(KKᵀ + λI)⁻¹V，其中 λ = 10⁻³·tr(KKᵀ)/72。
  • 更新应用于 VLM 的 0–16 层，每层秩最多 72；不使用梯度、优化器、微调或黑盒搜索，指令文本保持不变。
  • 先在离线决策上检查是否消除过早释放，再在 practice seeds 上闭环验证，最后冻结编辑并在 held-out seeds 上评分。
Card 05 数据集与资源

数据集与资源

  • 基础模型：OpenPI π0.5 DROID joint-position checkpoint，约 3.35B 参数；由 18 层 PaliGemma VLM 与 18 层 Gemma action expert 组成，输出 15 步动作块。
  • 训练数据：模型在 DROID 数据上训练，但未在本文任务上训练，因此所有机器人结果为零样本。
  • 评估基准：RoboLab 的 16 个任务，运行于 Isaac Sim，每次评估使用 16 个并行环境。
  • 编辑规模：完整 VLM 编辑改动约 450M 个存储值，约为策略存储值的 13.4%；小变体低秩因子仅 5.3M 参数（0.16%），秩不超过 32，仅使用第 8–16 层图像单元。
  • 训练资源：原文未明确报告 GPU/TPU 训练资源；编辑与评估在 NumPy sandbox、模拟器闭环 rollout 中完成。
Card 06 评估与结果

评估与结果

  • 评估采用配对 seeds：编辑策略与未编辑策略从相同模拟器起点运行，报告 fixed/broke 对数、bootstrap 置信区间、精确 McNemar 检验和 Wilson 区间。
  • 主任务 held-out 结果：成功率从 27/128（21.1%） 升至 106/128（82.8%），81 fixed / 2 broken，提升 +61.7 个百分点，p = 7.2 × 10⁻²²。
  • 随机方向对照：同等层、秩和奇异值的随机更新仅 9/64，与未编辑策略的 13/64 无显著差异（p = 0.45）；蒸馏编辑为 50/64，显式改写为 57/64。
  • 小编辑变体：在 held-out seeds 上 102/128 vs 19/128，86 fixed / 3 broken；但与完整编辑头对头比较为 41/64 vs 55/64，未完全保留效果。
  • 迁移结果：拾取眼镜从 22/64 升至 44/64；方块放碗左侧从 8/64 升至 36/64；方块放碗右侧仍为 0/32；其余 13 个任务未检测到显著损害。
  • 编辑位置：VLM 编辑在 64 个 held-out seeds 上为 55/64 vs 5/64；action expert 为 20/64；action head 最小范数编辑为 0/64；VLM + action expert 为 43/64，反而低于单独 VLM 编辑。
  • 工具复现：weightsmith distill 在新 held-out seeds 上从 8/64 提升到 36/64，33 fixed / 5 broken，但当时仅在一个任务上运行。
  • 盲测编辑器：七名 Claude Opus 编辑器中仅 cube-then-banana 任务通过 held-out 评分，成功率 11/64 → 27/64，22 fixed / 6 broken，p = 0.004。
  • 其他失败层级：针对感知、缺失抓取能力、接触物理和夹爪阈值的编辑均未带来稳定收益。
  • 噪声下限：权重不变的重跑会翻转约三分之一的配对结果；16 个 episode 的筛选只能作为过滤，不能作为证据。
