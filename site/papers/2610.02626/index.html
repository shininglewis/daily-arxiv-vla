Card 02 论文概述

论文概述

  • 论文提出 IG-VLA，一个 VLA（视觉-语言-动作）推理框架，核心思想是"Imagine the Future, Internalize the Gist"（想象未来、内化要点），让机器人在执行前先想象未来的场景演化。
  • 解决两个关键问题：现有 VLA 推理只基于当前观测状态推理，不显式预测环境未来演化；以及在每个推理步骤都进行完整时空推理 rollout 会带来巨大计算开销。
  • 目标是同时提升长时程操作任务的鲁棒性/成功率，并大幅降低推理延迟，实现高效的 VLA 部署。
Card 03 核心贡献

核心贡献

  • 提出 Latent Spatiotemporal Reasoning（潜在时空推理），使 VLA 模型在视觉表示空间中学习想象任务相关的未来场景演化，引导动作预测，无需昂贵的像素级视频生成。
  • 提出 Scene Gist Memory（场景要点记忆），将推理得到的"场景–行为"关联内化为紧凑的 Scene Gist Token，推理时可绕过显式未来想象与完整推理 rollout，同时保留推理收益。
  • 借鉴人类认知的"未来情景预演"与"程序化记忆自动性"机制，为方法提供行为心理学与神经科学层面的动机解释。
  • 在 LIBERO、LIBERO-Plus、VLABench 三大基准上验证有效性与高效性，并在双臂 UR3 真实机器人上完成真机部署评估。
Card 04 方法描述

方法描述

  • 基于 PaliGemma 架构：SigLIP So400m/14 作为视觉编码器，Gemma-2B 作为多模态前缀模型，Gemma-300M 作为动作专家（action expert）。
  • 潜在时空推理模块 $\mathcal{R}_{\phi}$ 预测 K=10 个未来 SigLIP 潜在状态，预测的是视觉转移量（$\hat{z}_{t+k}=z_t+z^F_{t+k}$）而非完整未来表示，以聚焦任务相关变化。
  • 训练损失包括：潜在回归损失 $\mathcal{L}_{\mathrm{reg}}$（MSE）与方向一致性损失 $\mathcal{L}_{\mathrm{dir}}$（余弦距离）；辅助像素重建头仅在训练时使用。
  • Gist 压缩器 $\mathcal{C}_{\eta}$ 通过 MLP 瓶颈将推理增强表示 $h_t^R$ 压缩为 Scene Gist 向量 $\bar{g}_t$，以动作匹配方式训练；Gist 编码器 $\mathcal{G}_{\psi}$ 仅用当前上下文预测 $g_t$。
  • Gist 训练使用表示对齐损失 $\mathcal{L}_{\mathrm{align}}$ 与动作一致性损失 $\mathcal{L}_{\mathrm{act}}$，总目标 $\mathcal{L}_{\mathrm{gist}}=\mathcal{L}_{\mathrm{act}}+\lambda_{\mathrm{gist}}\mathcal{L}_{\mathrm{align}}$，推理时绕过潜在推理 rollout、隐式动作推理器与 gist 压缩器。
Card 05 数据集与资源

数据集与资源

  • 训练/评估数据集：LIBERO（Spatial / Object / Goal / Long 四个套件）、LIBERO-Plus（相机、机器人、语言、光照、背景、噪声、布局等扰动）、VLABench（分布内、跨类别、常识、语义指令、未见纹理五个公开赛道）。
  • 训练资源：8 张 NVIDIA H100 GPU 训练推理模块；4 张 NVIDIA A6000 GPU 训练 gist 记忆模块；单张 NVIDIA A6000 GPU 做端到端推理延迟评估。
  • 训练配置：LIBERO 训练 100K steps，batch size 16，峰值学习率 $5\times10^{-6}$（余弦衰减至 $1\times10^{-7}$）；VLABench 训练 61K steps，batch size 128。
Card 06 评估与结果

评估与结果

  • LIBERO：IG-VLA（推理策略）与 IG-VLA$^{\triangle}$（Gist 策略）均取得最高平均成功率 98.9%，超过最强基线 ACoT-VLA（98.5%）；Gist 策略在 Object 与 Long 套件分别达 100.0% 和 97.8%。
  • LIBERO-Plus：监督微调后平均成功率 88.5%，超过 ACoT-VLA 0.5 个百分点；语言变化套件从 79.7% 提升至 85.6%。
  • VLABench：平均 Intention Score 最高达 66.68，比 ACoT-VLA 提升 3.18；语义指令变化下 IS/PS 从 56.8/39.6 提升至 65.2/48.49（平均 PS 略低于 ACoT-VLA，46.11 vs 47.40）。
  • 推理效率：Gist 策略每动作块仅需 169.5 ms，相比 FastWAM-IDM（1081 ms）、FastWAM 1-step（302 ms）、ImageWAM（263 ms）分别实现 6.38×、1.78×、1.55× 加速；显式时空推理耗时 256.9 ms，而 Scene Gist 预测器仅增加 0.13 ms 开销。
  • 消融实验：关键帧数 K=10 最优（98.90%），K=15 因误差累积降至 97.80%；方向损失权重 $\lambda_{\mathrm{dir}}=0.1$ 最优（LIBERO-Spatial 99.4%），过大权重（0.5/0.8）导致严重退化；Gist 策略采用 两层 MLP 最优（98.9%，训练 3.45 GPU 小时）。
