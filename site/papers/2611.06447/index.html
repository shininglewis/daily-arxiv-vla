Card 02 论文概述

论文概述

  • 论文聚焦 视觉-语言-动作模型（VLA） 的视觉感知缺陷：动作预测目标本身缺乏细粒度、任务相关的感知监督，模型容易依赖任务无关的视觉捷径，注意力偏离目标物体与关键交互区域。
  • 作者指出，失败案例往往不是动作生成错误，而是 VLM 主干在微调过程中“注意力漂移”，逐渐丢失了预训练阶段具备的任务相关区域判别能力。
  • 核心目标是：从操作过程本身自动提取任务相关的视觉引导信号，无需人工标注，并在微调中显式约束 VLA 的注意力与表征，从而提升操作成功率与泛化性。
Card 03 核心贡献

核心贡献

  • 提出 A³-VLA（Automatic Perception-Guided Attention Alignment）框架，从示教轨迹的交互时刻自动推导任务相关的视觉引导，完全免除人工区域标注。
  • 设计两个互补的辅助训练目标：注意力权重分配损失（引导语言/状态 token 对目标物体/机器人区域的注意力质量）与对比学习损失（对齐目标区域表征与语言指令，推开无关区域）。
  • 框架 模型无关（model-agnostic），可无缝接入多种 VLA 主干，且推理阶段不引入额外计算开销。
  • 在仿真（VLABench、RoboTwin 2.0）与真实机器人场景中一致超越基线，相对各主干平均提升 6.5%–25.2% 成功率。
Card 04 方法描述

方法描述

  • 启发式区域提议：利用“目标物体在交互前视觉稳定、交互后发生显著变化”的假设，计算交互前/后窗口内 patch 的帧间差异，低前差异 + 高后差异的 patch 视为目标物体候选区 C_tar；全程高变化的 patch 视为机器人候选区 C_rob（阈值 τ=10）。
  • SAM2 时序精炼：将含噪的候选区域跨帧传播，得到轨迹级时序一致的伪区域，仅需粗粒度交互种子而非逐帧精确标注。
  • 注意力分配引导：取 VLM 最后一层、对全部注意力头求平均，构造 L_l2i（语言 token → 图像 token，约束目标区域注意力质量不低于 η₁）与 L_s2i（状态 token → 图像 token，约束机器人区域不低于 η₂），采用软下界约束而非硬标签。
  • 对比学习引导：以语言指令均值池化表征为锚点，正样本为目标区域 patch 表征、负样本为非目标区域表征，用余弦相似度构造 InfoNCE 式损失 L_cl，仅在交互前帧施加。
  • 联合训练：总损失 L = L_FM + λ₁(L_l2i + L_s2i) + λ₂L_cl（λ₁=0.1，λ₂=0.01，η₁=η₂=0.25），动作生成采用 flow-matching 目标 L_FM。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：VLABench（Chemistry Tube、Fruit、Poker、Toy、Mahjong 五个任务套件，各 500 条示教，每套件测试 50 episode）；RoboTwin 2.0（Beat Block Hammer、Click Bell、Move Playingcard Away、Place Burger & Fries，各 100 条示教，测试 100 episode）。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率 SR（Success Rate）与任务进度分 TP（Task Progress：完成 1 / 半途失败 0.5 / 不符指令 0）。
  • VLABench：A³-VLA(π₀) 平均 0.64 vs π₀ 0.47（+16.4%）；A³-VLA(OpenVLA-OFT) 0.40 vs 0.16（+24.0%）；A³-VLA(π₀.₅) 0.67 vs 0.41（+25.2%），Poker 任务达 1.00。
  • RoboTwin 2.0：A³-VLA(π₀) 0.52 vs 0.42；A³-VLA(π₀.₅) 0.65 vs 0.58；A³-VLA(OpenVLA-OFT) 0.27 vs 0.20。
  • 真实世界：A³-VLA(π₀) 平均 SR 0.76 / TP 0.87，优于 π₀（0.55/0.67）与 π₀.₅（0.62/0.73），为所有方法最优。
  • 消融实验（VLABench，π₀ 主干）：去 L_l2i 降至 0.52、去 L_s2i 降至 0.60、去 L_cl 降至 0.61，均低于完整模型 0.64，验证两个目标互补必要。
  • 扰动鲁棒性：纹理扰动下 A³-VLA(π₀.₅) 保持 0.42（π₀.₅ 仅 0.18），高斯噪声下 0.57（π₀.₅ 仅 0.33）。
