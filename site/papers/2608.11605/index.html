论文概述

Card 03 核心贡献

核心贡献

  • 识别并形式化了直接策略 WAM 中的关键接口问题：未来视频生成移除后，预测动力学如何传递到 Action DiT。
  • 提出 ForeWAM，结合 Future-KV（单次 Video DiT prefill 产生逐层 K/V 状态供动作去噪复用）与潜在动作监督的动力学寄存器。
  • 无需具身机器人数据预训练，即达到竞争性能，并使用更少的参数（2B vs Fast-WAM 的 6B）。
  • 在 LIBERO-Plus 上比报告中的 Fast-WAM 成功率最高提升 10.1 个百分点，动作生成延迟降低 67.0%（Flash 变体）。
  • 通过组件对比实验验证了 Future-KV 与潜在动作监督联合设计的互补优势。
Card 04 方法描述

方法描述

  • 模型由视频扩散 Transformer（Video DiT）、专用 Action DiT、隐藏未来槽 K/V 缓存和动力学寄存器组成。
  • Future-KV：训练时学习未来潜变量流匹配目标；推理时保留当前干净潜变量，未来槽填噪声，执行一次视频 prefill（σ=1.0）获得每层 K/V 缓存，并在整个动作去噪过程中复用。
  • 动力学寄存器：由冻结的 LaWM 潜在动作教师提供监督，鼓励寄存器编码交互引起的状态转移（物体运动、接触变化、任务进度）。
  • 采用结构化注意力掩码，将当前帧 token、动力学寄存器、未来槽 token、动作 token 分组路由，允许未来槽整合当前帧与寄存器信息，动作 token 读取完整视频序列与寄存器。
  • 训练目标为视频与动作的 flow matching 损失加潜在动作蒸馏损失，总损失 L = L_video + L_action + λ_LA L_LA。
  • 额外使用 OneDP 蒸馏得到加速变体 ForeWAM-Flash（2 步去噪）。
Card 05 数据集与资源

数据集与资源

  • 评估数据集：LIBERO（Spatial、Object、Goal、Long 四个套件）和 LIBERO-Plus（7 个扰动维度：相机视角、机器人初始状态、语言指令、光照、背景纹理、传感器噪声、物体布局）。
  • 模型规模：视频分支基于 Wan2.1-T2V-1.3B 初始化，视频 DiT 与动作专家各 30 个 Transformer 块，视频分支隐藏维度 1536，动作专家 1024，总参数约 2B。
  • 训练资源：未使用具身机器人数据预训练；推理延迟在单张 NVIDIA A800 80GB GPU 上测量。
Card 06 评估与结果

评估与结果

  • 标准 LIBERO：ForeWAM 平均成功率 96.7%（Spatial 97.0 / Object 99.6 / Goal 97.2 / Long 92.8），ForeWAM-Flash 达 96.9%，与 Fast-WAM（97.6%）仅差 0.7-0.9 个百分点。
  • LIBERO-Plus 鲁棒性：ForeWAM 总体成功率 61.6%，比 Fast-WAM（51.5%）高 10.1 个百分点；在相机视角扰动上提升最显著（+46.1 点），传感器噪声 +21.1 点；ForeWAM-Flash 达 58.2%。
  • 推理效率：ForeWAM 将 10 步动作生成延迟从 Fast-WAM 的 667ms 降至 568ms（降低 14.8%），ForeWAM-Flash 进一步降至 220ms（降低 67.0%）。
  • 消融研究：完整 ForeWAM（61.6%）优于仅用 Future-KV（58.5%）和仅用潜在动作监督（58.0%），基础策略为 53.6%，验证两组件互补性。
  • 与基线对比：ForeWAM 在 LIBERO 上优于 OpenVLA（76.5%）、WorldVLA（81.8%）、UniVLA（95.2%），并使用显著更少参数。
