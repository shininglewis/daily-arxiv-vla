Card 02 论文概述

论文概述

  • 论文提出 Physics-Guided Visual Prompting（PG-VP），一种即插即用的多模态感知模块，使 VLA 模型能够规避 RGB 相机无法感知的不可见风险（如辐射、温度异常）。
  • 核心思路是复用冻结 VLA 模型已有的"规避可见障碍物"能力，通过叠加移动的虚拟障碍物引导导航轨迹自然绕行。
  • 解决的关键问题是：传统扩展 VLA 输入模态需新增编码器、采集配对数据并重新训练，代价高昂且可能破坏原有导航性能。
Card 03 核心贡献

核心贡献

  • 提出 PG-VP，以零样本方式向 VLA 导航框架注入非几何多模态物理上下文，不修改模型权重；无风险时不渲染任何内容，完全保留原生导航性能。
  • 每个模态仅需一个风险评估模型，构建成本远低于新增编码器、采集数据与重训练。
  • 无论模态类型如何，PG-VP 渲染相同的虚拟障碍物，使视觉提示模式在不同传感模态间保持与训练分布的一致对齐。
  • 提出动态视觉提示机制：虚拟墙体跨连续帧平滑生长与消退，实现连续的轨迹引导而非单帧静态遮挡。
  • 在仿真基准与真实机器人（热源与辐射源）上验证有效性，且全程无需重新训练。
Card 04 方法描述

方法描述

  • 集成机器人多模态感知系统：融合 RGB（前视 120° 广角相机 + 左右各偏航 ±90° 的 69° 网络摄像头）、辐射（RadEye SPRD-ER 伽马探测器）与热成像（两个 FLIR Lepton 3.5 模块，侧向偏航 15°，组合 HFOV 约 87°）。
  • 物理引导风险评估（RA）：温度模型基于四个区域（LS/LF/RF/RS）的最大温度与阈值 ΔT_th，需维持 0.5 秒确认；辐射模型采用两阶段 PIML（风险模型 + 方向模型），输入机器人位置与 CPS 序列，使用 MLP 与包含逆平方律重建的物理辅助损失，方向模型采用 12 模型软投票集成。
  • 动态视觉提示：基于贝塞尔曲线渲染动态弯曲虚拟墙，通过生长/消退帧数与引导强度 S_guide 控制墙体长度，纹理为高斯噪声混凝土质感并带方向性明暗以营造深度感。
  • 关键创新在于将异构物理风险映射为同一种视觉模式（虚拟障碍物），从而被冻结的 VLA 策略直接理解并规避。
Card 05 数据集与资源

数据集与资源

  • 仿真评估数据集：R2R-CE 与 RxR-CE 的 val-unseen 划分。
  • 底层导航策略：OmniNav（快速-慢速架构中的快速系统，基于流匹配的航点生成）。
  • 辐射训练数据：基于 OpenMC 计算的 10m×10m 伽马辐射场（25 个障碍物环境，100×100 网格，0.1m 分辨率）生成；风险模型训练窗口 1,051,106 个，方向模型 911,106 个。
  • 硬件平台：Unitree Go2 EDU 四足机器人，板载 Jetson Orin Nano，辐射/热传感器经外部 Windows SBC 通过 Redis 实时传输。
Card 06 评估与结果

评估与结果

  • 仿真评估环境：R2R-CE 与 RxR-CE val-unseen，指标为正确引导比例（CGR）、x 方向位移 \|x_d\|、成功率（SR）与 SPL。
  • 关键仿真结果：PG-VP 在 84.9%（R2R-CE）与 83.2%（RxR-CE）的场景中将策略引导至预期的低风险动作，代价为 SR 分别下降 6.8 与 7.9 个百分点；S_guide=0.60 为导航成功率与引导效果的较优平衡点。
  • 真实机器人验证：在四个场景（两热源、两辐射源）下，PG-VP 均成功完成任务并有效绕行危险源。
  • 安全指标提升：热源场景的最差 10% 平均轨迹安全性提升 63.45%，辐射场景提升 32.59%；极值指标分别提升 69.64% 与 29.30%。
  • 局限观察：Scenario D 中辐射源被箱子遮挡，导致 RA 模型触发过晚，残余峰值仅降低幅度与斜率而未被消除。
