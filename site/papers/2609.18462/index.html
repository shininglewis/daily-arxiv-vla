CSWAM: Better Causal Semantic Representations for Out-of-Distribution Generalization in World Action Models

2026-09-16 · 原文 · 翻译 · 2609.18462

论文提出 CSWAM（Causal Semantic World Action Model），旨在提升 FastWAM 风格世界动作模型在视觉分布偏移下的泛化能力。 现有 FastWAM 依赖重建导向的 VAE 表示且缺乏观察历史，导致外观变化时策略失效。 CSWAM 通过引入 V-JEPA 2.1 因果语义专家和稀疏历史观测，在保持动作专用推理效率的同时显著提升 OOD 泛化。

Card 02 论文概述

论文概述

  • 论文提出 CSWAM（Causal Semantic World Action Model），旨在提升 FastWAM 风格世界动作模型在视觉分布偏移下的泛化能力。
  • 现有 FastWAM 依赖重建导向的 VAE 表示且缺乏观察历史，导致外观变化时策略失效。
  • CSWAM 通过引入 V-JEPA 2.1 因果语义专家和稀疏历史观测，在保持动作专用推理效率的同时显著提升 OOD 泛化。
Card 03 核心贡献

核心贡献

  • 研究了时间预测表示与观察历史对高效动作专用 WAM 中 OOD 泛化的作用，并设计了仿真与真实机器人的受控视觉偏移评估。
  • 提出 CSWAM，基于 V-JEPA 2.1 的因果语义专家从观察历史预测未来语义特征，并与视频和动作流共享历史衍生上下文，同时保留动作专用推理。
  • 在仿真和真实机器人实验中，CSWAM 同时提升了标准操作性能与 OOD 泛化能力，大幅超越 FastWAM。
Card 04 方法描述

方法描述

  • 在 FastWAM 视频-动作架构中增加一路因果语义专家，使用冻结的 V-JEPA 2.1 编码器从当前及过去观测的稀疏历史中提取语义特征。
  • 语义专家学习预测未来 V-JEPA 特征，通过流匹配目标建模任务相关状态的时序演化。
  • 采用混合 Transformer（MoT）架构，视频、语义、动作三路专家通过结构化因果注意力掩码交换信息；掩码允许动作流访问语义历史，但阻止其访问未来目标。
  • 训练时联合优化视频预测、语义预测和动作去噪损失；推理时丢弃未来目标流，仅对动作流迭代去噪，当前视频状态和语义历史只计算一次，保持高效动作专用推理。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 2.0，包含 50 个双臂操作任务；RoboTwin2.0-Full 使用 2,500 个清洁演示和 25,000 个随机化演示，RoboTwin2.0-Clean2Random 仅用 2,500 个清洁演示训练。
  • 真实机器人：双臂 ARX Robotics 平台，任务为 Sort（12 小时演示）和 Fold（4 小时演示）。
  • 预训练资源：5,000 小时具身机器人语料库（Embodied PT）。
  • 模型规模：视频专家初始化自 Wan2.2-TI2V-5B（约 5B 参数），ActionDiT 使用维度适配的同骨干；V-JEPA 2.1 ViT-B 冻结；因果语义 Transformer 从 ActionDiT 参数热启动。
  • 论文未明确说明训练所使用的 GPU/TPU 型号与数量。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 仿真和真实双臂机器人；基准包括 FastWAM、多种 VLA 和 WAM 方法；指标为成功率（%）和平均完成时间（秒）。
  • RoboTwin2.0-Full：CSWAM 取得 Clean 94.7%、Randomized 94.3%、平均 94.5%，优于最强 VLA 和 WAM 基线。
  • Clean-to-Randomized OOD 转移：无 Embodied PT 时，CSWAM 将 Randomized 成功率从 FastWAM 的 1.82% 提升至 9.36%；使用 Embodied PT 后，从 10.16% 提升至 45.18%，提升 35.02 个百分点。
  • 真实机器人 OOD：Sort 平均成功率 90.0% vs FastWAM 33.3%，Fold 平均 50.0% vs 21.7%；总体平均从 27.5% 提升至 70.0%，提升 42.5 个百分点。
  • 消融实验：移除历史观测在 Clean/Randomized 上分别下降 1.7/1.8 点；移除视频专家分别下降 6.1/8.1 点；V-JEPA 2.1 优于 DINOv3；8 帧历史优于 0 或 4 帧。
