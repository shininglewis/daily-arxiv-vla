AutodidactWAM: Cross-Modal Self-Distillation from Generated Video to Robot Actions

2026-10-06 · 原文 · 翻译 · 2610.08119

Card 03 核心贡献

核心贡献

  • 识别并量化 视频–动作泛化不对称：在真实机器人闭环中，native action 仅约 17% / 10% / 7% 达到 pre-grasp / grasp / pick-and-place。
  • 提出 AutodidactWAM：从模型自身生成视频恢复动作目标 \hat{a}，与 native action a⁻ 构成偏好对，并得到 preferred target a⁺；仅微调动作相关层。
  • 设计可扩展 合成数据引擎：通过少量静态锚帧、种子、LLM 提示改写和物体摆放多样化，生成无需人工标注的自蒸馏对。
  • 比较 SFT 重标注 与 rectified-flow 版 Diffusion-DPO，并提出 DPO+SFT+DTW 混合目标；实验表明组合目标而非单独对比目标驱动真实增益。
  • 在真实 Unitree G1 上验证跨物体迁移：仅用 Oreo 生成蒸馏对，可在未见过的 pink antistress toy 上提升 pre-grasp 10%→80%、full task 10%→30%。
Card 04 方法描述

方法描述

  • 三阶段流水线：从 anchor frame 和语言指令生成视频与 native action；冻结感知栈读取生成视频恢复动作轨迹；仅微调动作分支以偏好恢复轨迹。
  • 基础模型为 Cosmos 3 Nano：约 15.8B 参数，Qwen3-VL-8B backbone；视频 token 与动作 token 在单个 rectified flow 采样轨迹中联合去噪。
  • 动作表示为 57-D 动作块，T≈32，经固定 IK 映射到机器人 26 个关节命令。
  • 动作恢复使用 RoboHaMeR：YOLO 手部检测（Grounding-DINO 备用）+ HaMeR 适配版（ViT-H/16 编码器，替换 MANO 头）+ 差分臂 IK；感知栈仅用约 30k 合成渲染训练，无需遥操作。
  • 蒸馏目标包括：SFT 直接回归 a⁺；Flow-DPO 将 Diffusion-DPO 适配到 rectified flow，使用 flow-matching residual 和 Bradley–Terry 偏好目标；DTW 项 通过 FK 对齐 wrist 轨迹，λ=0.015。
  • 训练时对生成视频进行 teacher-forcing：视频作为 clean conditioning，损失只在 action tokens 上计算，梯度仅更新 action encoder/decoder 与 LoRA 适配器。
  • 实现细节：在已适配 G1 的 checkpoint 上继续训练，新增 rank-64 LoRA（α=128），仅训练 16.9M 参数；lr 5e-5，梯度累积 4，bfloat16，activation checkpointing；SFT 500 iterations，Flow-DPO 20 轮 × 25 步，β=2.0，EMA reference decay 0.999。

Card 06 评估与结果

评估与结果

  • 评估环境：真实 Unitree G1 + BrainCo 五指手，单桌面 pick-and-place 任务（Oreo 包装盒移动到托盘），仅用右臂/右手。
  • 评估协议：每个 (object, condition) 进行 N=20 次真实机器人试验；按 pre-grasp / grasp / pick-and-place 三累积阶段评分。
  • 对比条件：Pre-DPO（native a⁻ 基线）、Extracted \hat{a}（Video→Extractor→IK gate）、SFT、DPO（plain Flow-DPO）、DPO+SFT+DTW。
  • 主要结果：native a⁻ 平均约 17% / 10% / 7%；提取动作 \hat{a} 平均约 75% / 47% / 42%，验证生成视频中动作更可执行。
  • SFT 改善 targeting（Oreo pre-grasp 0.7；pink 0.5），但 grasp 与 pick-and-place 明显下降。
  • Plain Flow-DPO 在所有对象上成功率为 0%，尽管验证偏好准确率为 1.000。
  • DPO+SFT+DTW 为最强训练配置：Oreo pre-grasp 0.9、full task 0.2；held-out pink antistress pre-grasp 0.8、full task 0.3；blue ball 增益较小。
  • 跨物体迁移：仅 Oreo 蒸馏对使 held-out pink toy 的 pre-grasp 从 10% 提升到 80%，full pick-and-place 从 10% 提升到 30%。
  • 结论：组合目标（偏好 + 监督 + Cartesian/DTW 锚定）驱动真实增益，但训练策略仍未完全弥合与 \hat{a} gate 之间的差距。
