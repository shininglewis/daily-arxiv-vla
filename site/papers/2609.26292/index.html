Card 03 核心贡献

核心贡献

  • 提出 RoboTwin-Phys 基准：在 RoboTwin-2.0 上引入 13 个连续采样的物理属性，并为物理敏感任务设置任务特定校准范围。
  • 发布 物理标注训练集：包含超过 5,000 条专家演示，每条样本附带 13 维物理参数真值，支持物理属性估计、条件感知建模和物理条件策略训练。
  • 提出面向 WAMs 与 VLAs 的 物理鲁棒性评估协议，并通过对比实验揭示物理条件变化带来的显著性能下降。
  • 设计 任务感知物理有效性 与 可行性检查：9 个敏感任务使用专用物理域，采样条件需经专家规划器验证可执行。
  • 提供可复用的数据格式与评测设置，支持单独或联合研究物理变化与原有视觉/布局随机化。
Card 04 方法描述

方法描述

  • 在 RoboTwin-2.0 的 50 任务平台上增加物理变化维度，而非引入新任务；13 个物理属性覆盖场景几何、传感配置、质量、材料属性、质量分布和关节特性。
  • 物理属性在 episode 初始化时独立采样，并在整个 rollout 中保持固定；由 episode seed 决定采样过程，保证可复现。
  • 采用 任务感知物理有效性：多数任务使用全局物理范围，9 个物理敏感任务自动路由到专用配置，避免数值有效但物理不合理的组合。
  • 使用专家规划器预先验证采样条件下任务可执行，排除专家无法完成的情形，确保评测失败反映模型鲁棒性而非环境无解。
  • 评估设置包括 Clean、Official Random 和 Physical Random：前者禁用随机化，中者启用原始视觉/布局随机化但固定物理参数，后者额外采样 13 个物理属性。
  • 数据格式保持与官方 RoboTwin 兼容，包含 data/ HDF5 轨迹、video/ MP4 视频和 phys_meta/ JSON 物理元数据。
Card 05 数据集与资源

数据集与资源

  • 发布 RoboTwin-Phys Training Set v1，包含超过 5,000 条专家演示，覆盖物理条件分布。
  • 数据集基于 RoboTwin-2.0 的 50 个双臂操作任务；评估中每个任务使用 100 个 rollout episodes。
  • 每个 episode 标注 13 维物理参数真值，包括质量缩放、质心偏移、几何缩放、桌面倾斜/高度、外力、相机距离与角度、摩擦、恢复系数、物体关节阻尼、机械臂/夹爪关节阻尼等。
  • 全局物理范围示例：质量缩放 [0.125,4]×，质心偏移 [-1.5,1.5] cm，几何缩放 [0.85,1.05]×，摩擦 [0.01,1.25]，恢复系数 [0,0.5]，物体关节阻尼 [0,25]，机械臂/夹爪关节阻尼 [0.5,3]×。

Card 06 评估与结果

评估与结果

  • 评估模型包括 Fast-WAM、Motus、FACT、π₀.₅ 和 Galaxea-VLA (G0.5)，涵盖 WAMs 与 VLAs。
  • 评估环境为 RoboTwin-2.0 / RoboTwin-Phys，设置包括 Clean、Official Random 和 Physical Random。
  • 主要指标为任务成功率（%）；Physical Random 下平均成功率显著下降：

- Fast-WAM：Clean 91.88，Official Random 91.78，Physical Random 44.24

- Motus：Clean 88.66，Official Random 87.02，Physical Random 39.60

- FACT：Clean 88.40，Official Random 86.60，Physical Random 39.14

- π₀.₅：Clean 82.74，Official Random 76.76，Physical Random 31.60

- Galaxea-VLA：Clean 93.70，Official Random 92.80，Physical Random 37.82

  • Clean 到 Official Random 的下降相对较小，例如 Fast-WAM 下降 0.10 分，Motus 下降 1.64 分，FACT 下降 1.80 分，π₀.₅ 下降 5.98 分，Galaxea-VLA 下降 0.90 分。
  • 所有五个模型在 Physical Random 下均出现大幅性能下降，说明物理条件多样性是独立于视觉/布局随机化的鲁棒性维度。
  • 任务级分析显示结构化失败模式：较难任务包括 beat_block_hammer、move_stapler_pad、pick_diverse_bottles、put_bottles_dustbin、place_can_basket 等；较鲁棒任务包括 grab_roller、shake_bottle、shake_bottle_horizontally、place_container_plate 等。
  • 结果表明物理条件变化系统性地考验接触动力学、物体稳定性、质量分布和关节运动相关操作行为，而非产生随机失败。
