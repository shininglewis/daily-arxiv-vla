FailPatch: Failure Residual Patching for Vision-Language-Action Models

Card 02 论文概述

论文概述

  • 提出 FailPatch，一种失败驱动的残差修补框架，用于适配预训练 Vision-Language-Action (VLA) 策略。
  • 核心思路：解耦动作监督与执行可靠性监督——成功演示提供“如何行动”的动作监督，部署轨迹提供“何时不可靠”的可靠性监督。
  • 解决的问题：仅用成功演示微调的 VLA 策略无法覆盖执行偏离后的状态，而部署失败虽暴露这些状态却缺乏纠正动作标注。
Card 03 核心贡献

核心贡献

  • 提出 FailPatch 框架，无需纠正动作标注，也无需部署时的额外失败检测或重规划模块。
  • 发现 action hidden representations 对可靠与失败关联状态具有线性可分性，且直接条件动作生成，是理想的干预接口。
  • 设计 Null-gated Residual Expert Bank (REB)，插入冻结 VLA 的 action hidden space，通过 Preserve–Redirect–Trust 目标学习局部残差修补。
  • 仅 0.52% 可训练参数（17.3M），约 3 小时训练，在仿真和真实世界任务上大幅提升成功率。
  • 在四个 RoboTwin 长时任务上 clean 评估提升 11.0 百分点，clean-to-random 泛化提升 9.5 百分点，三个真实任务提升 16.7 百分点。
Card 04 方法描述

方法描述

  • 问题形式化：给定冻结 VLA 策略 π_φ、成功演示集 D_demo 和仅含最终结果标签的部署 rollout 集 B_deploy，学习轻量残差参数 θ。
  • 使用离线 VLM（GPT-5.5）标注失败起始点，并过滤可靠成功 rollout，将 action hidden 表示划分为可靠集 H⁺ 和失败关联集 H⁻。
  • 在冻结 VLA 的 action hidden space 插入 Null-gated REB：Null 专家保持原表示 c₀ = h，K=8 个残差专家产生 Δh_k，路由器 Top-1 稀疏选择。
  • Preserve：在可靠状态抑制干预，偏好 Null 专家并惩罚残差能量。
  • Redirect：在失败关联状态，用局部成功原型（最近邻中值）定义效用，路由到能拉近成功原型的残差专家，并约束最小进步。
  • Trust：限制失败状态下所选补丁的幅度，防止过大隐藏偏移。
  • 总目标：L_total = L_demo + λ_P L_P + λ_R L_R + λ_T L_T；训练前 5k 步为 Null-disabled 预热，总 30k 步。
Card 05 数据集与资源

数据集与资源

  • 仿真任务：RoboTwin 四个长时任务——Blocks Ranking、Stack Bowls、Put Object Cabinet、Place Bread Basket。
  • 基础策略：π_0.5 VLA，在 50 个操作任务上预训练，每任务 50 个干净演示（50-Task Base）。
  • 每个仿真任务：50 个演示用于适应，固定部署缓冲区含 50 成功 + 50 失败 rollout。
  • 真实世界任务：Blocks Ranking、Stack Bowls、Fold Dishcloth；双臂平台 + Intel RealSense D435i 相机；每任务 100 成功演示，部署缓冲区 50 成功 + 50 失败。
  • 可训练参数：17.3M（占 VLA 的 0.52%），残差专家数 K=8。
  • 训练资源：4 张 NVIDIA H20 GPU，约 3 小时训练；PPO 基线约 20 小时。
Card 06 评估与结果

评估与结果

  • 仿真评估：四个 RoboTwin 任务，每任务 100 个环境种子，指标为成功率（%）。
  • Clean 评估：FailPatch 平均 60.50%，比 50-Task Base 的 49.50% 提升 11.0 百分点，四个任务均最佳。
  • Clean-to-random 泛化：FailPatch 平均 37.50%，比基线 28.00% 提升 9.5 百分点。
  • 真实世界：FailPatch 平均 57.8%，比 Three-Task Base 的 41.1% 提升 16.7 百分点，三个任务均最佳。
  • 效率：比 LoRA SFT / Full SFT 快 2.6–3.6 倍；比 PPO 少 40.1 倍可训练参数，快 6 倍。
  • 消融：Redirect 单独增益最大（56.50%），Preserve+Redirect 达 59.00%，完整方案 60.50%；单专家 55.75%，无 Null 专家 56.50%。
  • 机制分析：action hidden 线性可分性 balanced accuracy 0.74、ROC-AUC 0.83；路由在失败起始附近触发；补丁显著拉近成功原型距离；不同专家学习到多样化干预方向。
