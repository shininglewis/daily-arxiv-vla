Card 02 论文概述

论文概述

  • 论文提出 LIBERO-MAX，一个用于评估机器人策略在任务执行中途环境发生变化时能否继续完成任务的配准（paired）基准。

Card 03 核心贡献

核心贡献

  • 配对式执行中鲁棒性基准：构建 8,000 个 rollout 配对（来自 LIBERO-Plus 5,600 + LIBERO-PRO 2,400），每对共享任务、初始状态、指令、策略随机种子以及事件前完全相同的已执行动作前缀（executed prefix），仅 Dynamic 侧施加一次中途事件。
  • 系统性的在线变化破坏研究：在 14 个预训练策略（VLA、混合预测、WAM）上验证，所有策略成功率下降 11.0–25.7 个百分点，且 20.8%–56.1% 的 Base 成功回合在事件后失败。
  • 面向响应的诊断工具：提出触发/响应覆盖率、stale-action exposure（陈旧动作暴露）、配对结果转移（(1,1)/(0,1)/(1,0)/(0,0)）以及查询节奏（query cadence）扫描，揭示几何与观测变化是共同弱点，且 VLA 与 WAM 排名交错。
  • 可复现的轻量版本：LIBERO-MAX Lite 仅 800 配对（1,600 rollouts/策略，为 Max 的十分之一），与完整基准的差异在 2.4 个百分点以内。
  • 候选恢复实验：验证针对传感器噪声的图像修复/去噪模块可部分挽回损失，证明该基准可用于衡量针对性干预的效果。
Card 04 方法描述

方法描述

  • 配对评估协议：每个 case 指定任务、指令、初始状态、策略种子与事件；Base 保持原始配置，Dynamic 先重放 Base 的动作至触发时刻 t_i，再注入事件并继续。
  • 指标定义：成功率变化 \(\widehat{\Delta}=\frac{1}{N}\sum(Y_i^1-Y_i^0)\)，以百分点报告；另报告 conditional regression（Base 成功中被事件摧毁的比例）；使用 95% bootstrap 区间、McNemar 精确检验与 Holm 校正。
  • 八类事件：target relocation、receptacle relocation、camera shift、illumination switch、sensor-noise onset、visual-theme switch、distractor burst、obstacle insertion；每类 1,000 配对，Plus/PRO 按 700/300 划分，含两个固定参数变体。
  • 触发机制：统一的确定性 pre_grasp_proximity 触发器，在末端执行器首次进入目标实体邻域时触发；事件为持续性事件，评估器不主动逆转变更。
  • 关键创新点：固定已执行前缀消除了随机采样导致的发散混淆；区分"到达触发点"与"获得事件后观测"；提出 stale-action exposure 度量 chunked 策略在事件后仍执行旧排队动作的数量。
  • 控制实验设计：相机控制实验对比 Base / Reset / Mid-task 三条件；查询节奏扫描改变每 \(Q\) 步查询一次的频率（动作块长 \(H\) 固定或设为 \(Q\)）。
  • 传感器恢复模块：在查询前用质量门控（quality gate）检测图像并施加 inpainting 与 denoising，不重训练策略，不接收事件标志或干净参考图。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 仿真环境，采用各策略官方发布的推理服务协议，因此模型规模、训练与动作接口差异均包含在比较之中。
  • 主要指标：Base 成功率、Dynamic 成功率、配对变化 Δ（pp）、条件退化率、四类配对结果占比、触发覆盖率与响应覆盖率（87.7%–96.6%）。
  • 总体结论：所有 14 个策略在事件后均显著退化，Δ 全为负且统计显著；最优者 MolmoAct2 80.3%→66.9%（-13.4） 与 π0.5 79.7%→65.7%（-13.9），最差为 DiT4DiT -25.7、X-VLA -24.9、OpenVLA-OFT -21.1。
  • 条件退化：SmolVLA 总分下降最小（-11.0），但其 Base 仅 26.1%，事件摧毁了 56.1% 的 Base 成功；MolmoAct2 净降 13.4 点对应损失 20.8% 的已解决回合。
  • 事件族别：几何类损失 21.2–52.4 点、观测类损失 13.3–49.7 点，显著高于外观/杂波与路径类；跨策略事件排序平均 Spearman 相关 0.80；target relocation 对 14 个策略中的 11 个损害最大；X-VLA 对 camera shift 最敏感，Fast-WAM 与 DiT4DiT 对 sensor noise 最敏感（Fast-WAM 从 43.4% 骤降至 0.3%）。
  • VLA 与 WAM 排名交错：Dynamic 成功率前三名（MolmoAct2 66.9%、π0.5 65.7%、DM0.5 62.1%）为 VLA，随后为 Cosmos-Policy 与 HiMem-WAM 两个 WAM，未呈现一致的架构家族优劣。
  • 相机控制关键发现：X-VLA Base 68.2% → Reset 1.3% → Mid-task 12.4%；π0.5 79.5% → 51.3% → 55.3%；HiMem-WAM 72.5% → 68.8% → 72.6%。Mid-task 普遍优于 Reset，说明"已有执行历史"有正贡献；但 84 个 model–case 实例在 Base 与 Reset 均成功却在 Mid-task 失败，且其中 13 例事件后未执行任何旧动作，说明陈旧动作无法解释全部失败。
  • 查询节奏无法弥合差距：在全部 18 个设置中 Dynamic 始终比 Base 低 11.1–23.0 点；X-VLA 的 Dynamic 成功率随 Q 从 2 增至 16 时由 10.8% 升至 39.2%，但 Base–Dynamic 差距反而扩大；各策略最优 Q 不同（GR00T N1.7 在 Q=12、Fast-WAM 在 Q=8）。
  • 任务与来源差异：类别宏平均损失 10.7–23.4 点，且每个策略在四个 LIBERO 任务套件上均受损；最难的套件因策略而异（MolmoAct2 在 LIBERO-10 损失 16.0 点，Light-WAM 在 LIBERO-Spatial 损失 25.3 点）。
  • 恢复实验：质量门控修复使 X-VLA 的 Dynamic 从 40.7% 提升至 47.7%（+7.0，95% CI [3.0, 11.3]），Base/Dynamic 差距从 26.0 缩窄至 19.3 点；但门控相对"始终开启"修复的优势未被数据证实。
