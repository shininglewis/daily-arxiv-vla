Card 02 论文概述

论文概述

  • 论文研究开放世界货物配送操作（open-world delivery manipulation）中的操作阶段，目标是让移动机械臂在杂乱场景中解析自由形式语言指令、定位目标物体并完成可靠抓取放置。
  • 核心问题是训练—部署失配：策略在固定环境、有限物体与指令词表中训练，却要在包含新物体、未见指代表达和变化场景配置的开放环境中部署，属于新的语言—物体映射泛化问题。
  • 论文提出把预训练流匹配 VLA（flow-matching VLA）作为低层控制器（System 1），把高层 grounding 输出的空间提示（spatial cue）当作显式目标指定信号来"驾驶"策略，而非修改策略输入图像。
Card 03 核心贡献

核心贡献

  • 分析了开放世界配送带来的策略学习挑战，提出一种将显式语言—物体 grounding 与学习式低层动作生成结合的双系统框架。
  • 设计了一个轻量的提示条件适配器（cue-conditioned adapter），对冻结的流匹配 VLA 输出的动作块施加对角仿射变换进行转向（steering），避免对整个策略做全量微调。
  • 提出两种对比学习目标：空间对比损失 $\mathcal{L}_{sp}$（空间移位负样本）与残差对比损失 $\mathcal{L}_{res}$（真实热图编码减去零热图编码），抑制场景捷径依赖，强化提示位置与动作变换的对应关系。
  • 在桌面（tabletop）与移动底盘（mobile-base）两类平台上验证，在域内与域外物体设置上均优于所有基线，平均任务成功率相对最优基线分别提升 86% 和 44%，推理开销可忽略（适配器仅增加约 0.02% 参数）。
Card 04 方法描述

方法描述

  • System 2（冻结的 grounding 模块）：用 grounding 模型预测目标包围框，再用分割模型转为像素级掩码，计算物体质心并构造高斯热图 $\mathbf{h}_t$ 作为空间提示；所有组件零样本推理，每个任务 rollout 开始时调用一次。
  • System 1（冻结的流匹配 VLA）：在流积分过程中，适配器在每个积分步预测两个调制项 $\boldsymbol{\gamma}^{\tau}_{t}$、$\boldsymbol{\beta}^{\tau}_{t}$，按 $\tilde{\mathbf{v}}^{\tau}_{t} = \mathbf{v}^{\tau}_{t}\odot(\mathbf{1}+\boldsymbol{\gamma}^{\tau}_{t}) + \boldsymbol{\beta}^{\tau}_{t}$ 修正速度场，从而在生成路径层面（而非直接编辑动作块）实现转向。
  • 关键创新：把 grounding 输出从"输入级视觉提示"转变为动作生成级转向信号；调制在每个积分步重新预测，冻结策略在转向后的状态上重新评估并继续塑造轨迹，保留预训练流先验。
  • 训练目标：$\mathcal{L} = \mathcal{L}_{\text{flow}} + \lambda_{\text{sp}}\mathcal{L}_{\text{sp}} + \lambda_{\text{res}}\mathcal{L}_{\text{res}} + \lambda_{\text{reg}}\mathcal{L}_{\text{reg}}$，其中 $\mathcal{L}_{\text{reg}}=\\|\boldsymbol{\gamma}^{\tau}_{t}\\|_2^2+\\|\boldsymbol{\beta}^{\tau}_{t}\\|_2^2$ 限制修正幅度，避免破坏预训练动作分布。
  • 适配器作为动作专家的轻量 sidecar 实现；实验中LoRA 在低数据量下过拟合，未产生稳健的提示转向行为。
Card 05 数据集与资源

数据集与资源

  • 训练数据：自采集 80 条演示轨迹，使用两个训练物体（黑色袋子、塑料袋子），无标签贴纸；在此基础上微调 π0.5 作为基座策略。
  • 模型：π0.5（流匹配 VLA，作为 System 1 / 冻结策略）；Qwen3-VL-2B 与 SAM2.1 作为 System 2 grounding 模块。
  • 仿真基准：LIBERO-PRO 的 Object-suite 任务泛化设置，共 200 个评估 episode。
  • 硬件：RTX 5080 单卡即可同时运行全流程，VLA 以 15 Hz 连续运行；机器人平台为 DEEP Robotics Lynx M20 Pro 轮式四足 + AgileX PiPER 机械臂（6-DoF），配备 ZED 2 第三人称相机与 RealSense D435i 腕部相机，机载 Jetson AGX Orin 负责通信，往返延迟约 80 ms。
Card 06 评估与结果

评估与结果

  • 评估设置：三种设置——(I) 已见物体 + 改写指令；(II) 未见物体 + 域内语言；(III) 未见物体 + 新语言（最难）；每任务 6 条 prompt × 2 种空间配置，成功率取二值任务完成指标。
  • 基线：Base（单 VLA 固定 prompt 微调）、Base-L（多 prompt 微调）、MOKA（几何低层控制器的双系统方法）、VP-VLA（视觉提示作为输入的双系统方法）。
  • 主结果（Table 2，成功率 %）：

- 桌面：Ours 平均 72.2%，对比 Base 38.9%、VP-VLA 36.1%、Base-L 25.0%、MOKA 18.0%；Setting III 达 66.7%（最强基线仅 29.2%）。

- 移动底盘：Ours 平均 63.9%，对比 VP-VLA 44.4%、Base 30.5%、MOKA 8.3%、Base-L 5.5%；Setting III 达 41.7%，基线仅 8.3%。

- Base 在 Setting III 桌面为 0.0%，体现纯 VLA 先验在强分布偏移下失效。

  • 消融（Setting III）：Base 8.3% → 仅加适配器 16.7% → 加 $\mathcal{L}_{sp}$ 得 33.3%（+16.6 点，单项增益最大）→ 再加 $\mathcal{L}_{res}$ 达 41.7%。
  • 提示格式研究：高斯热图与二值掩码表现相近；轴对齐包围框更差（粗边界可能指向不可操作区域）。
  • 正则强度：$\lambda_{\mathrm{reg}}\in\{0,0.01,0.03,0.1\}$ 对应成功率 11.5%、15.5%、12.5%、10.5%，$\lambda_{\mathrm{reg}}=0.01$ 最优。
  • 真实世界仿真对比：LIBERO-PRO 上 Ours 15.5%，对比 Base 10.5%、Base-L 9.5%、VP-VLA 10.5%。
  • 动态环境反应性：即使只在 rollout 开始时 grounding 一次，适配器仍能继承 VLA 的反应性应对目标物体被扰动的情况，无需重新查询高层规划器；局限在于仍对分布外的可操作区域与物体位置敏感，约束了移动底盘的停机位置与朝向。
