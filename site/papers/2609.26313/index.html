Card 02 论文概述

论文概述

  • 论文提出 SafeLoop，一个非侵入式外部安全封装器，为冻结的视觉-语言-动作（VLA）模型添加危险预测与基于回滚的恢复能力，无需修改基座策略参数。

Card 03 核心贡献

核心贡献

  • 提出一种非侵入式双频率（dual-rate）安全封装器，可包裹任意冻结的 VLA 策略而不改变其权重。
  • 设计四输出风险预测器，从机载视觉与本体感受输入同步预测身体级与物体级危险的发生概率与剩余时间（TTH）。
  • 提出学习型三动作决策器（noop / record / rollback）配合安全路点记忆回滚，使随机采样的基座策略能够从历史安全配置重新采样替代轨迹。
  • 在三种 VLA 骨干网络（Pi-0、OpenVLA-OFT、Pi-0.5）的仿真与真实机器人上验证有效性，且决策器无需真实世界 RL 训练即可迁移。
  • 实验显示危险案例减少约 70%，同时保持任务成功率与基座策略控制频率。
Card 04 方法描述

方法描述

  • 危险形式化：将危险分为身体级（碰撞、卡死、失控运动）与物体级（掉落、翻倒、非目标扰动），定义首次危险时间 $t_*^{(\mathrm{type})}$、短视界危险指示 $p_t$ 与归一化 TTH $\Delta_t$。
  • 风险预测器 $g_\phi$：以机载多视角 RGB 图像、本体感受历史（$H=3$ 帧）、指令与基座提议动作作为输入，输出四维风险向量 $\mathbf{r}_t=[\hat p^b,\hat\Delta^b,\hat p^o,\hat\Delta^o]^\top$；训练损失为 BCE + L1 组合（$\mathcal{L}_{\mathrm{risk}}$）。
  • 非对称 Actor-Critic MDP：Actor 仅使用可部署信号（49 维：关节/夹爪状态 + 风险值 + 辅助概率 + 记录/回滚可用性等）；Critic 训练时额外接入 7 个仿真特权信号（56 维），避免现实差距。
  • PPO + 规则教师热启动：先用启发式 $\pi_{\mathrm{rule}}$ 做行为克隆（阈值触发 rollback / record / noop），再以 PPO 优化，BC 系数 $\lambda_{\mathrm{BC}}$ 在训练前 80% 内线性退火到零。
  • 奖励塑形：$r_k=r_k^{\mathrm{task}}+\lambda_{\mathrm{hz}}r_k^{\mathrm{hazard}}+\lambda_{\mathrm{int}}r_k^{\mathrm{intervene}}$，惩罚危险与不必要的干预。
  • 双速率执行循环（Algorithm 1）：基座策略每步提议动作，风险预测器异步评估，低频决策器（20 步，约 1 Hz）仲裁；rollback 通过碰撞检测的关节空间路径规划返回最低风险成熟路点。
  • 实现细节：在冻结的 Qwen2.5-VL-3B 骨干上训练轻量风险头；决策器为宽度 128 的 MLP；仿真中同步调用预测器，硬件上异步运行。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO 四个标准套件（Object、Goal、10、Spatial）以及 Libero_90；风险预测器在所有套件标注轨迹上训练，决策器仅在 Libero_10 上训练。
  • 评估任务：从上述套件采样 24 个任务，每任务 16 个随机种子（每方法 384 次 rollout）。
  • 真实机器人：两台 6-DoF PIPER 机械臂 + 第三视角 RealSense L515 相机；3 个物理任务，每任务 25 次 rollout。
  • 骨干模型：Pi-0、OpenVLA-OFT、Pi-0.5 三种 VLA 控制器作为被包裹基座策略；风险预测头基于 Qwen2.5-VL-3B 冻结骨干。
  • 模型规模：风险头为紧凑轻量模型；决策器为 128 宽度 MLP（未给出显式参数量）。
  • 资助：江苏科技重大专项（BG2025035）与中央高校基本科研业务费（KG2025XX）。
Card 06 评估与结果

评估与结果

  • 评估指标：成功率（Success）、Haz-Body（含至少一次身体级危险的 rollout 比例）、Haz-Obj（物体级危险比例）、Events/1k（每 1000 步安全到危险的状态转移次数）。
  • 基线方法：端到端 RL（无显式风险预测器）、SAFE + stop、SAFE + backtrack。
  • 跨骨干安全性：危险率降低 56–75%；OpenVLA-OFT 身体危险从 22.9% → 5.7%，成功率 67.7% → 68.2%；Pi-0.5 身体危险 8.3% → 3.6%；Events/1k 从 1.03 → 0.21（约降 80%）。
  • 对比基线（Table I）：SafeLoop 取得最高成功率 59.6，最低 Haz-O 6.8 与最低 Events/1k 0.22；SAFE+backtrack 取得最低 Haz-B 4.4，但成功率仅 58.0。
  • 消融（Table II，π0 基座）：移除视觉（No Image）成功率降至 42.7%，单帧上下文（Context H=1）降至 43.7%；Resample 成功率高达 60.4% 但 Haz-Body 升至 16.6%、Events/1k 升至 0.53；规则教师 Teacher 危险更低但成功率降至 58.3%；完整 SafeLoop 达到最优安全—成功权衡（59.6 / 5.2 / 6.8 / 0.22）。
  • 真实机器人迁移：仅微调预测器、决策器从仿真原样迁移，平均危险降低约 78%，成功率与基线持平，无需真实世界 RL。
  • 结论数值：仿真中危险事件率整体降低约 82%（如 Pi-0 上 1.21 → 0.22 Events/1k）；局限在于无法保证产生不同轨迹，也无法撤销不可逆的物体状态变化。
