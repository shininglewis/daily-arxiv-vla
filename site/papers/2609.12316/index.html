DATAFARM: Distribution-Aligned Task and Motion Planning for Fine-Tuning Vision-Language-Action Models

Card 03 核心贡献

核心贡献

  • 揭示并形式化了 TAMP 生成演示与 VLA 预训练数据之间的行为分布不匹配问题，证明任务有效的轨迹未必是有效的微调数据。
  • 提出 DATAFARM 框架，通过学习参考分布（配置密度、轨迹潜在密度）并将其作为 TAMP 的优化目标，实现分布对齐的轨迹生成。
  • 设计了三个对齐组件：端点选择（joint-space alignment）、路径优化（style alignment）、重定时（timing alignment），并通过消融实验验证每个组件的必要性。
  • 在三个桌面操作任务上，DATAFARM 微调的 VLA 达到 56.7% 平均成功率，显著优于原始 TAMP（8.3%），并接近人类遥操作（61.7%）。
  • 在可变形物体操作（TAMP 无法执行的 OOD 任务）上，微调后的模型保留 85% 成功率，证明分布对齐在教授新任务的同时能较好地保留预训练能力。
Card 04 方法描述

方法描述

  • 参考分布学习：从 VLA 预训练数据集（DROID）中拟合两类参考模型——机器人关节配置的高斯混合密度 p_conf(q)，以及轨迹潜在空间的高斯密度 p_latent(z)。
  • 轨迹编码器：训练可微编码器 E_φ，将轨迹段映射到潜在向量 z，输入为关节位置及其速度、加速度、加加速度（jerk），采用辅助运动描述子预测目标与变分正则化训练。
  • 分布对齐规划：将学习到的成本函数集成到 TiPToP 规划流程中——用 c_conf(q) 对 IK 候选解排序进行端点选择；将 c_traj(ξ)（马氏距离）加入路径优化目标；用同一成本指导时间参数化（retiming）。
  • 约束保持：规划器原有碰撞、运动学、可行性约束全程保留，学习到的对齐成本仅作为附加优化项。
  • 数据收集与微调：执行对齐后的规划轨迹，收集演示数据 D，用于微调预训练 π0.5-DROID 模型。
Card 05 数据集与资源

数据集与资源

  • 预训练数据集：DROID（大规模真实世界机器人操作数据集，由人类遥操作收集），用于拟合参考分布并训练 π0.5-DROID 检查点。
  • 机器人平台：Franka Emika Panda 7-DOF 机械臂 + Robotiq 2F-85 夹爪，2 个外部 ZED 2 立体相机 + 1 个腕部 ZED Mini 立体相机。
  • 人类演示设备：Meta Quest 2 控制器。
  • 演示预算：每个目标任务使用 20 个成功演示 进行微调，评估时每个检查点运行 20 次试验。
  • 任务设置：3 个目标桌面任务（Geometric Constraints、Multi-Step Reasoning、Semantic Reasoning），每个需 3 次物体移动；1 个 OOD 任务（Deformable Object Manipulation，布折叠）。
  • 训练资源：Google TPU Research Cloud (TRC) 提供的 Cloud TPU，以及 NVIDIA Academic Grant 支持。
Card 06 评估与结果

评估与结果

  • 评估环境：在真实 DROID 机器人平台上评估，每个检查点在全新初始场景下运行 20 次试验；任务进度为终止时完成子目标的归一化比例。
  • 主要指标：成功率（Success rate） 与 任务进度（Task progress），并额外评估 OOD 任务上的能力保留率。
  • 核心结果：

- π0.5-DROID 基线成功率为 1.7%，原始 TAMP 微调后仅 8.3%，DATAFARM 达到 56.7%，人类遥操作 oracle 为 61.7%。

- 各任务成功率：Geometric Constraints 65%、Multi-Step Reasoning 35%、Semantic Reasoning 70%，全面优于原始 TAMP（5%/5%/15%）。

- 消融实验：移除 joint-space alignment 降至 23.3%，移除 style alignment 降至 15.0%，移除 timing alignment 降至 0%，证明每个组件均关键。

- DROID 分布对齐度：轨迹潜在空间中 96% 的 DATAFARM 样本落在 DROID 轮廓内（原始 TAMP 为 0%；无 style 为 89%，无 timing 为 19%）；关节空间中对齐度从 66% 提升至 74%。

- 能力保留：在未提供任何布折叠演示的情况下，微调后模型在 Deformable Object Manipulation 上保留 85% 平均成功率（预训练为 90%）。

- 演示预算：20 个演示达 65% 成功率，40 个达 75%，60 个保持 75%，80 个提升至 85%。

  • 结论：分布对齐可将 TAMP 转化为 VLA 微调的有效数据源，在无需人工控制的情况下接近人类遥操作水平，同时基本保持模型原有能力。
