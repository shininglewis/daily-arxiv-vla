React When You Need To: Event-Triggered Asynchronous Inference for VLA Policies

2026-09-18 · 原文 · 翻译 · 2609.22587

论文提出 event-triggered dynamic inference 策略，用于 Vision-Language-Action (VLA) 策略的异步执行。 现有 VLA 模型预测 action chunk，执行期间遇到环境变化无法及时反应；已有异步推理依赖固定 inference gap，在反应性和执行可靠性之间存在权衡。 目标是根据自上次策略推理以来的场景变化动态调整推理时机，在无显著事件时保持最大可行 gap，在事件发生时提前触发新推理。

Card 02 论文概述

论文概述

  • 论文提出 event-triggered dynamic inference 策略，用于 Vision-Language-Action (VLA) 策略的异步执行。
  • 现有 VLA 模型预测 action chunk，执行期间遇到环境变化无法及时反应；已有异步推理依赖固定 inference gap，在反应性和执行可靠性之间存在权衡。
  • 目标是根据自上次策略推理以来的场景变化动态调整推理时机，在无显著事件时保持最大可行 gap，在事件发生时提前触发新推理。
Card 03 核心贡献

核心贡献

  • 提出事件触发的动态推理调度，在无显著事件时保持最大可行 inference gap，检测到事件时立即触发早期推理。
  • 设计轻量级 event estimator，复用 VLA 视觉编码器 量化场景变化，与 VLA 推理交错运行，最高 15 Hz。
  • 自动从人类演示中构建事件监督，无需人工标注事件发生与相关性。
  • 在真实世界静态和动态任务中验证，平均全任务成功率达 95%，超过最强基线 55 个百分点。
Card 04 方法描述

方法描述

  • 使用 π0.5 VLA 策略作为骨干，并通过 LoRA 在静态演示上微调，获得名义任务行为参考。
  • 从人类演示自动构建事件监督：离线运行微调 VLA，将预测 action chunk 与演示动作的 MSE 作为 event score，保存 anchor/current 视觉特征对。
  • Event estimator：冻结的 VLA 视觉编码器 + 轻量 Transformer event decoder，输入 anchor 与当前视觉特征，预测事件分数。
  • 触发机制：以静态演示 event-score 的 P90 为阈值，连续两次超过阈值即触发新推理。
  • 调度与融合：策略推理和事件估计交替；无事件时执行 H-d 个动作后触发下一次推理；事件触发时用指数衰减权重融合新旧 chunk 的重叠动作。
Card 05 数据集与资源

数据集与资源

  • 数据集：每个任务收集 40 条静态演示和 160 条动态演示，覆盖 Task 1（静态/动态障碍物抓放） 和 Task 2（移动目标放置）。
  • 模型：π0.5 VLA 骨干，LoRA 微调；轻量 Transformer event decoder；论文未明确给出总参数量。
  • 训练配置：VLA 微调 30,000 steps，batch size 32，action-chunk horizon H=50，blending weight decay β=1.2。
  • 运行频率：演示采样率与执行频率 30 Hz，event estimator 15 Hz，inference delay d=5，RTC 延迟 d_RTC=8。
  • 硬件：Franka Emika Panda 机器人，3× Intel RealSense D435i 相机；控制 NUC Intel i7-10700；VLA 与 event estimator 使用 NVIDIA RTX 3090；微调使用 6× NVIDIA A40 GPU。
Card 06 评估与结果

评估与结果

  • 评估环境：真实世界操作实验，包含 Task 1 静态障碍、Task 1 动态障碍、Task 2 移动目标 三个设置；每个方法每设置 20 个 full-task trials。
  • 对比方法：Synchronous、DynamicVLA、RTC，以及固定 gap 消融 g∈{0,5,25,45}；所有方法共享 π0.5 骨干。
  • 指标：阶段成功率与全任务成功率，公式为 SR_c = N_success/N_trials × 100%。
  • Task 1 静态：本文方法 full-task 100%；DynamicVLA、RTC、g=0 因抓取阶段失败 full-task 为 0%，g=5 为 30%。
  • Task 1 动态：本文方法 full-task 100%；Synchronous 0%，DynamicVLA 0%，RTC 15%，固定 gap 消融最高 15%。
  • Task 2 移动目标：本文方法 85%，比 RTC 高 45 个百分点，比最佳固定 gap 消融高 25 个百分点。
  • 总体：三个设置分别 100%、100%、85%，平均 95%，超过最强基线 55 个百分点。
