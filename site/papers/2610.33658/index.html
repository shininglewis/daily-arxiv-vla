Card 02 论文概述

论文概述

  • 论文面向 Vision–Language–Action（VLA） 模型在边缘设备部署时因稠密连续值计算导致能耗过高的问题，提出把脉冲（event-driven）计算引入预训练 VLA 策略。

Card 03 核心贡献

核心贡献

  • 统一的 PoT-LIF 公式与重建保证：定义带符号、幅度为 2 的幂的脉冲发放规则与残差保留机制，给出无泄漏（λ=1）动态下精确算术的重建性质与几何误差界（需配合指数截断）。
  • PoT-LIF 与 π0.5 的集成且保持闭环性能：将 PoT-LIF 插入 π0.5 的视觉投影、视觉–语言投影与动作投影共 26 个投影位点，所有配置相对稠密基线成功率偏差不超过 0.80 个百分点。
  • 算子级能耗模型：形式化定义了 MAC 与 SAC（scaling–accumulation） 的能耗核算，在匹配 FP32 累加、T=1、发放率 60.01% 时，建模算术能耗约为稠密参考的 1/7.67，即降低 86.95%。
  • 提出 Heartbeat 输入调度，把事件时间维限制在单个投影内部，避免重复权重搬运与网络级多轮执行。
Card 04 方法描述

方法描述

  • PoT-LIF 事件编码：脉冲形如 \(s_t=\mathrm{sgn}(u_t)2^{e_t}\)，指数取 \(\lfloor\log_2\|u_t\|\rfloor\) 并裁剪到 \([-16,16]\)（33 个正电平、66 个带符号电平），阈值取 \(\theta=2^{h}\)。
  • 膜电位与残差保留：\(u_t=I_t+\lambda r_{t-1}\)，发放后 \(r_t=u_t-s_t\)，未表示部分留待后续事件逐步精化。
  • SAC 算术：以指数加法与符号合并替代一般尾数乘法，\(\mathrm{SAC}(a,w,s_t)=a+\mathrm{sgn}(u_t)\mathrm{Scale}_2(w,e_t)\)，仅在事件非零时计算。
  • Heartbeat 调度：每次投影调用时 \(r_0=0\)、输入只注入一次，最多执行 T 个内部抽取步，事件贡献在下一非线性前累加，调用结束重置局部状态；配置取 λ=1（无泄漏）。
  • 重建分析：证明 \(x=q_T(x)+r_K\)；误差界 \(\|x-q_T(x)\|\le 2^{-T}\|x\|\)、残差为零时精确重建、阈值提前终止时误差 \(<\theta\)；T=2 时最坏相对误差约 25%，均值约 9.9%。
  • 训练方式：前向使用真实带符号 2 的幂事件，反向使用 直通估计器（STE）/代理梯度 训练不连续发放规则。
  • 集成位置：SigLIP 视觉编码器、PaliGemma VLM、流匹配动作专家中的 patch embedding、Q/K/V、attention 输出、门控 FFN、专家投影与专家接口。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四个套件的闭环机器人操作，条件间共享初始状态与配对推理噪声。
  • 主要指标：各套件与总体成功率（%），以及与连续激活对照的整体百分点差 Δ。
  • 主要结果（总体成功率）：

- 连续激活对照 96.70%；匹配预算连续对照 96.25%

- Standard mode T=1：96.90%（+0.20）；T=2：96.35%（−0.35）

- Heartbeat T=2：97.25%（+0.55）；T=4：96.90%（+0.20）

- 分项：Long-Horizon 上 Heartbeat T=2 达 94.2%，优于对照的 92.4%；Object 上事件式配置为 97.4–98.4%，略低于对照 98.6%。

  • 事件统计：稠密参考 N=2.271×10¹² MAC（26 个位点、8 个固定观测）；加权事件比 μ₂=1.900、μ₄=3.480；T=2 发放 1.240×10⁹ 事件（4.314×10¹² 事件–权重对），T=4 为 2.270×10⁹（7.902×10¹²）。
  • 能耗结果（45 nm 参考模型，FP32 MAC 4.6 pJ、SAC 约 1.0 pJ/事件–权重对，仅计算术，排除数据搬运）：稠密约 10.45 J；T=1 约 1.36 J（降低 86.95%），T=2 约 4.31 J（58.7%），T=4 约 7.90 J（24.4%）。
  • 敏感性：SAC 成本升至 1.1/1.2 pJ 时，节能率降为 85.65%/84.35%。
