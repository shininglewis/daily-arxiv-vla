Card 02 论文概述

论文概述

  • 论文提出 DexForesight 框架，让灵巧操作策略在训练阶段从“动作条件空间世界模型”中获得隐式空间预见（spatial foresight）能力，包括关节手指运动与场景变化。
  • 核心问题：灵巧手操作需要预见被遮挡手指与物体的相对运动，但已有 World-Action Models（WAMs）依赖推理时显式预测未来（生成未来图像/3D 状态），带来额外计算；而依赖在线深度重建又会引入部署负担与时序一致性难题。
  • 研究目标：让策略在训练时吸收预测性表征、部署时仅用 RGB、语言指令与机器人状态生成动作，不做世界模型推理、不做深度重建、不做未来解码。
Card 03 核心贡献

核心贡献

  • 提出 DexForesight：将灵巧策略的 latent query 与冻结的动作条件空间世界模型的预测性 query 对齐，并用对齐特征条件化动作生成，实现隐式空间预见。
  • 构建动作条件空间世界模型，使用约 370 小时、60 个任务、5 大类别的演示数据，结合离线场景深度与运动学手部几何，联合预测 3D 手部点位移与视觉特征变化，可监督相机看不到的遮挡手指。
  • 在 11 个 DexJoCo 仿真任务与 3 个真实机器人任务（Close Box、Insert Battery、Screw On Lid）上验证，分别达到 60.5% 与 58.3% 成功率，超越最强基线 9.6 与 8.3 个百分点。
  • 通过线性探针证明：世界模型移除后，预测性手部运动信息仍保留在策略表征中，且表征迁移优于直接加预测头。
Card 04 方法描述

方法描述

  • 两阶段解耦设计：先训练动作条件空间世界模型，再冻结它，用其 query 特征监督策略 query（query alignment），避免部署时运行世界模型。
  • 手部几何编码：在 URDF 连杆上采样固定点，用正向运动学变换到机器人基座坐标系，保持跨帧对应关系；用 Point-BERT 编码当前点云与短时手部运动历史。
  • 深度融合：真实数据用 StereoAnyVideo 离线估计深度，仿真用 MuJoCo 直接渲染；OmniVGGT 将 RGB-D 编码为几何 token，通过跨层 cross-attention（层 2/6/10/14/18/22/26）注入骨干，并用 Attention Residuals 式跨层路由（层 4/8/12/16/20/24/28）聚合。
  • 动作条件世界查询：N 个可学习 world query 读取骨干第 12/20/28 层隐状态，经动作适配器注入演示动作（K=4 个偏移、覆盖 16 帧未来窗口），再条件化两个预测专家。
  • 双预测目标：Hand Flow Expert 预测持久手部锚点的 3D 位移；Visual Dynamics Expert 预测冻结 DINOv3 视觉特征残差；损失含 noise 预测 + Smooth L1 + 上下文重建项，并采用 future-horizon dropout。
  • 策略侧对齐：策略 query 读取 VLM 隐层，经投影映射到世界 query 特征空间，采用 token 对齐损失与关系（相似度矩阵）对齐损失，并与动作损失联合优化；对齐后的 query 经投影拼接到动作专家上下文。
  • 部署：仅保留策略与 query reader/投影，世界模型、深度编码器、手部几何编码器与两个预测专家全部移除。
Card 05 数据集与资源

数据集与资源

  • 真实机器人数据：约 370 小时演示，覆盖 60 个任务、5 类（空间布置、装配与接触、旋转与关节、可变形物体、工具使用）；其中 100 小时子集使用 StereoAnyVideo 离线估计深度。
  • 仿真数据：DexJoCo 的 11 个任务（单臂 + 双臂），深度由 MuJoCo rollout 直接渲染。
  • 硬件平台：真实为 Sharpa North 机器人 + 22-DoF Sharpa Wave 手；仿真为 Franka Panda + 16-DoF Allegro 手。
  • 基础模型：仿真基于 GR00T N1.7，真实机器人基于 QwenVLA；世界模型骨干由 RynnBrain 初始化；视觉特征用冻结 DINOv3。
  • 训练分三阶段：warmup → dynamics pretraining → depth injection；GPU/TPU 具体型号与数量原文未给出。
Card 06 评估与结果

评估与结果

  • 仿真（11 个 DexJoCo 任务，每任务 100 次试验）：DexForesight 60.5% 总体成功率（单臂 76.3%、双臂 41.6%），优于 Fast-WAM 50.9%、Cosmos3 49.5%、GR00T N1.7 49.4%、π0.5 35.1%。
  • 真实机器人（3 任务 × 20 次试验）：DexForesight 58.3%，优于 WLA 50.0%、GR00T N1.7 48.3%、Cosmos3 30.0%、Fast-WAM 10.0%；分任务为 Screw 50.0%、Close 45.0%、Insert 80.0%。
  • 推理开销：QwenVLA 227.4 ms vs. DexForesight 230.4 ms（仅增加 3.0 ms，1.3%）；而 Cosmos3 生成 16 帧未来视频需 930 ms。
  • 表征探针（线性 ridge probe 预测未来 3D 手部位移）：0.54 s 时误差从 13.59 mm 降至 10.01 mm（−26.3%），且随时域延长优势扩大。
  • 消融关键结论：手流预测头直连仅 53.1%（低于 DexForesight 7.4 点）；去掉离线深度仿真降 10.8 点、真机降 15.0 点；以 context depth tokens 替代跨层融合仅 42.0%；打乱动作条件降至 41.5%（低于骨干）。
