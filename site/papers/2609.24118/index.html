Card 03 核心贡献

核心贡献

  • 提出 经验引导的纠正数据合成（Experience-Guided Corrective Data Synthesis）：采集失败 rollout，建模阶段条件化的失败后偏差分布，据此合成具有代表性的失败状态并收集针对性纠正演示（减少文档）
  • 提出 原子纠正执行框架（Atomic Corrective Execution）：将长时程任务分解为原子阶段，用物理落地的 3D 几何监控器触发阶段内调整（intra-execution adjustment）或阶段后重操作（post-execution re-operation）
  • 提出 失败状态恢复基准 FSR-Bench，包含 36 个恢复场景、5 个任务，分为 Easy（21 个局部失败） 与 Hard（15 个结构性失败） 两种难度，直接从中途失败状态评估恢复成功率（RSR）
  • 在多个 VLA 骨干、仿真基准与真实双臂任务上验证，仿真平均任务成功率提升 14.5 分，真实世界提升 15.9 分，FSR-Bench 恢复成功率提升 7.5 分
  • 开源代码、模型与数据：https://github.com/xiaojunlan/care
Card 04 方法描述

方法描述

  • 失败建模：执行名义原子计划（无纠正监督），从 100 次仿真与真实 rollout 中记录失败；对每个原子阶段 $k_i$ 定义偏差 $d_i=(\Delta\tau_i, \Delta R_i)$，其中旋转以偏航角 $R_z(\Delta r_i)$ 表示
  • 分布拟合：对每个任务与原子阶段的标量分量 $(\Delta x,\Delta y,\Delta z,\Delta r)$ 分别拟合 Gaussian、Beta、Gamma、Weibull、Log-Normal、Uniform 候选分布，用 AIC 与 KS 检验 选择最佳拟合
  • 纠正数据合成：从阶段条件分布 $p(d\mid k)$ 采样偏差并扰动阶段相关相对位姿，再在物理动力学下向前 rollout 生成新的失败状态（非简单回放）
  • VLM 规划器：使用 GPT-4.1（temperature 0）在任务初始化时一次性将高层指令 $l$ 与全局视图 $I^g_0$ 分解为 K 个原子阶段，每阶段输出 $\Pi_k=(u_k,\gamma_k,\psi_k,\mathcal{U}_k)$，其中 $\mathcal{U}_k$ 含调整与重操作指令；规划固定、可避免恢复时反复调用 VLM
  • 3D 几何监控器：非学习的点云谓词检查器，在阶段关键事件（夹爪闭合、物体释放）或预测转换前触发；用 SAM 3 提取夹爪/物体/目标掩码，用 Depth Anything 3 提供深度，融合成点云并计算紧凑几何状态 $q_t$，输出 $\tilde u_t=f_{\mathrm{mon}}(\Pi_{k_t},q_t)$
  • VLA 执行器：同一策略执行名义、调整与重操作三类指令 $a_t\sim\pi(a_t\mid o_t,\tilde u_t)$，无需切换到独立的恢复策略；重复"监控–执行–验证"循环可实现多步恢复
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin 2.0（7 个 hard 双臂任务，使用 demo_randomized 设置）、RoboFactory（2/3/4 臂协作任务）、自建 FSR-Bench（5 个恢复任务）
  • 真实平台：LeRobot SO-101 双臂机器人，12 自由度（每臂 6 DoF），1 个全局 RGB 相机 + 每臂 1 个腕部 RGB 相机，30 Hz
  • VLA 骨干：π₀、π₀-FAST，FSR-Bench 上额外实例化 RDT-1B
  • 对比基线：ACT、RDT-1B、DP（Diffusion Policy）、DP3，真实世界对比 FailSafe
  • 训练数据：标准仿真任务每方法 150 条名义专家演示 + 每类错误 50 条额外轨迹；失败分布由 100 次预备 rollout 估计
  • 训练配置：40,000 梯度步、batch size 32、动作视野 50，使用 2× NVIDIA A800 SXM4 80GB GPU；FSR-Bench 变体为 20,000 步
  • 真实世界：每任务 50 条名义演示 + 每类错误 20 条轨迹，每任务 100 次预备执行估计失败分布
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0（Hard）、RoboFactory、FSR-Bench 仿真，以及 SO-101 真实双臂机器人四任务；每任务 100 次试验
  • 主要指标：任务成功率（Task Success Rate）与恢复成功率 RSR（100 次随机试次中达成场景恢复目标的比例）
  • RoboTwin 2.0：π₀ 从 39.6% → 60.7%（+21.1），π₀-FAST 从 17.4% → 33.1%（+15.7）
  • RoboFactory 多臂协作：π₀-FAST 提升 +9.3 分，π₀ 提升 +12.0 分，四臂任务从 82% → 88%
  • FSR-Bench（禁用经验引导合成、使用等量均匀采样纠正数据以隔离执行机制）：π₀ Easy 38.8% → 57.2%、Hard 15.8% → 21.2%；π₀-FAST Easy 24.4% → 32.6%、Hard 4.6% → 10.8%；RDT-1B Easy 21.8% → 25.2%、Hard 2.6% → 6.0%
  • 真实世界 SO-101：π₀ 从 30.8% → 50.0%，π₀-FAST 从 18.8% → 31.3%，分别比专用恢复方法 FailSafe 高出 13.7 与 7.3 分
  • 消融表明：仅靠匹配的纠正监督数据不足，必须结合原子纠正执行机制；执行模块与数据模块均有增益，且执行机制不依赖特定模型
