Card 03 核心贡献

核心贡献

  • 识别关键缺陷：首次明确提出当前反应式 VLA 模型在 wrist-only 设置下的两大根本问题——空间部分可观测性和时间任务进度遗忘，并给出形式化分析
  • 提出双记忆架构：设计了 4D 持久世界状态记忆（Persistent World State Memory） 与 Ego 工作状态记忆（Ego-Working State Memory） 协同工作的新框架，前者解决视觉盲区，后者维持任务进度认知
  • 构建端到端流水线：设计了一套超越传统"观测→动作"反应式范式的高效端到端训练和推理流程，实现从瞬时局部观测中主动进行空间推理
  • 实现 SOTA 性能：在 LIBERO、RLBench 和真实世界基准上仅用腕部相机即达到最先进水平，显著超越多视角基线（LIBERO-Long 提升 9.4%，真实世界长时序任务提升 17.5%）
  • 展示强鲁棒性：在极端遮挡和扩展时序压力测试中表现出色，验证了持久空间-时间建模对 VLA 从反应式控制向长时序操作扩展的必要性
Card 04 方法描述

方法描述

  • Persistent World State Memory：利用 Depth Anything v3 进行流式深度估计，通过空间反投影模块将 2D 腕部视觉 token 提升至 3D 潜空间；采用双空间-时间位置编码（MLP 参数化的空间坐标编码 + 时间戳编码）增强时空感知；基于 voxel-hashing 策略（类似 TSDF 融合）进行局部空间融合，配合时序滑动窗口和"永久首帧锚定"机制维护全局世界状态
  • Ego-Working State Memory：设计意图感知查询（intent-aware query）机制，通过可学习查询在 VLM 中进行交叉注意力聚合目标信息；维护时序意图记忆库，通过冗余感知的潜在整合（redundancy-aware consolidation）动态更新记忆，防止长时序任务中的意图漂移
  • World-Ego-Guided Action Generation：采用 去耦逐步条件化（decoupled step-wise conditioning） 的扩散 Transformer（DiT）；每个去噪步内依次执行 ego 工作注意力（捕获任务进度）和世界状态注意力（引入全局观测），最后通过动作解码器生成 7-DoF 末端执行器动作
  • 关键技术创新：空间反投影将 2D latent 与 3D 位置关联、基于深度估计置信度的加权融合、首帧永久锚定策略保持全局上下文
Card 05 数据集与资源

数据集与资源

  • LIBERO 仿真基准：五个套件（Spatial, Object, Goal, Long, 90），Franka 机器人，每任务 50 条演示
  • RLBench 仿真基准：6 个代表性多阶段任务，100 条演示/任务，单眼 128×128 RGB 输入
  • 真实世界平台：Franka 机器人，6 个通用操作任务 + 4 个长时序任务，仅腕部相机、无第三视角
  • 模型规模：7B 参数 LLM + ~300M 参数的 DiT 动作专家
  • 训练资源：8 块 NVIDIA A100 GPU，PyTorch FSDP，全局 batch 256，峰值学习率 2×10⁻⁵
  • 推理配置：DDIM 采样 10 步去噪，CFG 尺度 1.5
Card 06 评估与结果

评估与结果

  • LIBERO 基准：仅腕部相机下平均成功率 97.6%，超越带第三视角的 π₀（+3.4%）；LIBERO-Long 达到 94.6%，比 MemoryVLA 高 7.0%，比 π₀ 高 9.4%
  • RLBench 基准：仅腕部相机下平均成功率 70.8%，超越最强基线 MemoryVLA 7.5%（第三视角）和 15.8%（腕部视角）；在 Sweep to Dustpan 任务上达到 70%（其他方法均 ≤55%）
  • 真实世界通用任务：平均成功率 78.7%（仅腕部），超过 π₀（66.7%）12.0%，超过 MemoryVLA 第三视角版本 8.0%
  • 真实世界长时序任务：平均成功率 69.5%，相比 π₀ 提升 17.5%，相比 MemoryVLA 提升 9.0%
  • 消融实验：去除 World State Memory 后 LIBERO 降至 93.5%（真实长时序降至 54.0%），去除 Ego-Working Memory 后降至 95.0%（真实长时序 56.5%），而去除世界状态更新机制也导致显著性能下降——验证了双记忆架构和动态更新机制的共同必要性
