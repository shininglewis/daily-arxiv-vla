When and What to Prune? Stage-Aware Visual Token Pruning for Efficient VLA

研究单位

  • 作者：Tianjun Shi、Haotian Xiong、Ziyu Gong、Qi Lu、Li Li（通讯作者）
Card 02 论文概述

论文概述

  • 论文提出 SAPrune，一种面向视觉-语言-动作（VLA）模型高效推理的免训练（training-free）视觉 token 剪枝框架，目标是降低机器人策略推理延迟。
  • 针对现有剪枝方法普遍采用固定剪枝调度（在预设层剪一次或等间隔层剪枝）的问题：VLA 早期层的视觉证据尚未与语言指令结合，过早剪枝会误删后续才变得重要的 token。
  • 论文重新定义剪枝为两个问题：何时（When）剪枝才可靠，以及剪什么（What）动作相关证据应被保留。
Card 03 核心贡献

核心贡献

  • 通过分析动作到视觉注意力（action-to-visual attention）在层间的动态变化，发现注意力质量从浅层到中层快速集中、之后趋于平稳，据此提出基于 rollout 级注意力动态的剪枝层选择策略。
  • 提出层内双路径剪枝规则（Layer-Local Dual-Path Pruning）：注意力核心路径保护强注意力 token，功能多样性路径保留互补的上下文 token，避免保留集坍缩到单一高注意力区域。
  • 提出可靠性自适应预算分配机制：利用 preservation 分数与注意力集中度分数动态决定两条路径的 token 配额。
  • 在 LIBERO、SIMPLER 及真实机器人任务上验证，仅保留 32 个视觉 token，剪掉 87.5% 的视觉 token，实现最高 1.718× 推理加速，同时保持竞争力任务成功率。
  • 方法无需训练、不依赖奖励或任务成功标签，仅用少量校准集记录注意力统计。
Card 04 方法描述

方法描述

  • 剪枝层选择：用校准集计算各层 top-κ 动作到视觉注意力质量 S_l(t) 及其 rollout 平均 μ_l，经三点滑动平均后计算层间变化 d_l，通过分位数阈值 τ_s（平台检测）和 τ_r（再分配事件检测）划分浅/中/深三个相对深度区域，每区选一层。
  • 对中层和深层，先定位累积注意力偏移最大的再分配区间，仅在其之后搜索候选层；在每个有效搜索区内选择最早的平台起点，否则选局部平均偏移最小的层。
  • 候选池与预算：构造扩展的动作引导候选池 C_l（γ·K_l）和探针集 A_l^probe（ρ·K_l）。
  • 可靠性信号：用探针 token 归一化特征做 thin QR 分解构造正交基 U_l，计算保存分数 P_l = 1 - R_l；用归一化熵计算集中度分数 A_l。
  • 预算分配：η_l = √(P_l·A_l)，λ_l = (1-η_l)λ_min + η_lλ_max，据此划分 K_l^attn 与 K_l^cov。
  • 注意力核心路径：保留候选池中注意力排名最高的 K_l^attn 个 token。
  • 功能多样性路径：以动作查询 q_a 和按注意力选出的文本查询 Q_x 构成查询族，为每个候选 token 定义查询条件功能签名 r_i，通过贪心最大化“与残差证据内积 − β·与已选集合最大余弦相似度”来选择互补 token。
  • 关键创新：以查询响应的函数性差异（而非特征空间距离）衡量冗余，保证与当前动作-语言指令相关；若去重后不足则按注意力排名回填至 \|S_l\|= K_l。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（Spatial / Object / Goal / Long 四类任务）、SIMPLER、LIBERO-Plus（鲁棒性测试）。
  • 真实世界任务：真实机器人操作任务（含端到端延迟测量）。
  • 被测 VLA 模型：OpenVLA、OpenVLA-OFT、π₀、π₀.₅。
  • 校准集规模：默认使用 LIBERO；SIMPLER 用 30 条 rollout，真实世界用 40 条，混合仿真-真实用 270 条。校准仅记录注意力统计，不使用奖励或任务结果。
  • 对比基线：FastV、DivPrune、SP-VLA、VLA-ADP、EfficientVLA(T-only)。
  • 默认超参数：κ=0.125，q_s=0.4，q_r=0.8，m=2，l_min=1，γ=1.75，ρ=0.8，λ_min=0.1，λ_max=0.9，K_x=6，β=0.3。
Card 06 评估与结果

评估与结果

  • 评估指标：LIBERO 各任务组成功率（%，↑）、推理延迟（ms，↓）、加速比（↑）、FLOPs 比率（%，↓）。
  • OpenVLA + SAPrune（32 token）：Spatial 84.9、Object 85.1、Goal 75.3、Long 50.8，平均 74.0；延迟 110.96 ms，加速 1.608×，FLOPs 比率 39.5%。
  • OpenVLA-OFT + SAPrune（32 token）：Spatial 95.2、Object 98.1、Goal 95.9、Long 88.9，平均 94.5；延迟 60.30 ms，加速 1.718×，FLOPs 比率 37.8%，优于所有剪枝基线（如 EfficientVLA 平均 90.0、SP-VLA 92.5）。
  • 相比基线在更激进的剪枝率下（32 token vs 基线 58–128 token）仍取得更高的平均成功率与更大的加速比。
  • 附录补充实验包括：统一 32-token 预算下的受控对比、路由开销分析、注意力后端影响、真实机器人端到端延迟、校准迁移性、LIBERO-Plus 鲁棒性及不同最终剪枝比例下的性能。
