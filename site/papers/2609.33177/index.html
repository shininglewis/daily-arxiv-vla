Card 02 论文概述

论文概述

  • 提出 DeltaWAM，一种以变化为中心（change-centric）的 World-Action Model，用 delta token 替代整帧或全场景未来预测。
  • 解决现有 WAM 在像素空间或全 latent 状态预测中的时空冗余、计算开销大、任务无关信息浪费等问题。
  • 核心思想：连续帧共享大量静态上下文，动作策略真正需要预测的是低维、结构化的动态变化，如物体位移和末端执行器运动。
Card 03 核心贡献

核心贡献

  • 识别现有 WAM 的时空冗余，将视觉前瞻分解为静态视觉锚点和动态转移 token，把世界建模从场景重建转向变化预测。
  • 提出轻量高效的 DeltaWAM：总计 0.725B 参数，推理峰值显存 3.86GB，单动作块延迟 142.1ms。
  • 设计任务条件 DeltaWorld：通过 Gated AdaLN 注入语言指令，使预测的未来与任务意图对齐，避免无条件 rollout 误导策略。
  • 实验证明压缩 delta token 比完整未来 DINO 状态更具动作引导性，在 LIBERO 达 92.8% 成功率，在 LIBERO-Pro 任务扰动下平均 17.85%。
  • 在 AgileX PiPER 六自由度机械臂上完成真实世界拾放任务部署，验证方法可行性。
Card 04 方法描述

方法描述

  • 基于 DeltaWorld 的 delta tokenization：用冻结 DINOv3 提取 patch 级特征，将相邻帧 DINO 特征差压缩为单个 1D delta token。
  • DeltaWorld Predictor 根据观测历史 delta token 和任务嵌入，自回归预测未来 delta token 序列，每个未来帧对应一个 token。
  • 使用冻结 T5 编码语言指令，并通过 Gated AdaLN 的 scale、shift、residual gate 调制每个 DeltaWorld block，实现任务条件世界建模。
  • Action DiT 采用 flow-matching，条件于当前观测的密集 DINO patch 特征（空间锚点）和预测的未来 delta token 序列（动态子目标），生成动作块。
  • 两阶段训练：Stage 1 用 Best-of-Many (BoM) 训练任务条件 DeltaWorld；Stage 2 冻结 DeltaWorld，用 oracle 选择或随机采样的未来分支训练 Action DiT。
Card 05 数据集与资源

数据集与资源

  • 预训练视频数据：Kinetics-700
  • 模拟基准：LIBERO（Spatial、Object、Goal、LIBERO-10/Long）与 LIBERO-Pro 任务扰动；附录还评估 LIBERO-Plus
  • 真实机器人数据：AgileX PiPER 六自由度机械臂，150 episodes 拾放数据，30 Hz，前视与腕部 RGB 观测及 14 维机器人状态
  • 模型规模：总计 0.725B 参数，其中 120.3M 可训练参数
  • 训练资源：2 张 H100 GPU，总计 256 GPU hours
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 模拟基准和 PiPER 真实机械臂；每个任务评估 50 次，使用 3 个随机种子
  • 主要评估指标：任务成功率、动作块查询延迟、推理峰值显存、每动作 TFLOPs
  • LIBERO 平均成功率 92.8%：Spatial 92.6%，Object 97.0%，Goal 95.8%，Long 85.8%
  • 推理效率：142.1 ms 每动作块，峰值显存 3.86 GB，约 0.584 TFLOPs/action
  • LIBERO-Pro 任务扰动平均成功率 17.85%，显著高于多数接近 0% 的基线
  • 消融实验：仅使用当前 DINO 条件降至 73.9%；解码未来 DINO 条件降至 79.0%；预测 delta token 更有效
  • 相比最强预训练 VLA/WAM 基线成功率仍偏低，但以轻量、低延迟和程序性鲁棒性为主要优势。
