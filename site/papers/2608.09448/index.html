Card 03 核心贡献

核心贡献

  • 系统诊断了 QwenPi 上的潜在提示词 TTT，发现异构操作任务需要上下文相关的修正，并提出了 上下文路由的潜在提示词混合（MoLP），在紧凑适配空间中平衡跨任务共享与专用。
  • 提出了 世界预测接口（WPI），通过预测未来视觉表示作为部署时无标签代理目标，满足目标可观测性和策略相关性两个要求。
  • 设计了 注意力门控与验证驱动的测试时训练（AGV-TTT），将策略内部注意力转变转化为隔离的影子提议，并通过匹配的未来观察对候选进行验证，再原子提交或回滚。
  • 在 SimplerEnv WidowX 基准上，VANE 相比对应 TTT 基线平均成功率提升 3.2 个百分点；在 Google Robot 上验证了部署时收益具有任务和具身依赖性。
Card 04 方法描述

方法描述

  • MoLP：维护一个包含 8 个潜在提示词的共享提示词库，基于最终 VLM 表示通过 softmax 路由和 Top-2 稀疏组合生成上下文相关的有效提示词，无需外部任务标识符。
  • WPI：使用冻结的 V-JEPA 2 编码器提取当前和延迟未来的视觉表示，以当前视觉表示、路由提示词和噪声动作 token 构建 Latent-Action DiT 查询，预测未来视觉表示并计算均方误差损失。
  • AGV-TTT：利用动作到 VLM 和动作到预测潜变量的交叉注意力分布的时间变化检测交互事件；在事件触发时仅在影子副本上更新提示词库，随后在多个未来时间步上对比新旧提示词的预测损失，满足聚焦损失改进、全局损失不退化且多数未来对支持时才原子提交。
  • 训练阶段联合优化动作损失、WPI 损失和路由负载均衡损失；部署阶段仅优化潜在提示词库，其余模块冻结。
Card 05 数据集与资源

数据集与资源

  • 训练数据：BridgeData V2 和 RT-1 数据集，以等概率采样共同训练。
  • 评估基准：SimplerEnv 下的 WidowX（Stack、Carrot、Spoon、Eggplant 四任务）和 Google Robot（Pick Coke Can、Move Near、Open/Close Drawer 等，含 VM 和 VA 两种设置）。
  • 模型：QwenPi 为 Qwen 基座 flow-matching VLA 模型（基于 StarVLA-α 框架）；QwenWPI 为保留 QwenPi 动作策略骨干、仅替换代理分支为 WPI 的变体。
  • 训练资源：论文未明确列出 GPU/TPU 型号与数量，但所有实验基于 QwenPi 主干和冻结视觉编码器，仅优化提示词库，计算开销轻量。
Card 06 评估与结果

评估与结果

  • WidowX 对比：QwenWPI + MoLP + AGV-TTT 达到 71.2% 平均成功率；对应 TTT baseline QwenWPI + FP-LP + TTT 为 68.0%，提升 3.2 个百分点；同时超过 TTT-VLA 的 67.4%。
  • Google Robot 对比：QwenPi + MoLP + AGV-TTT 在三个共同任务族上的 Overall 为 76.7%，超过 QwenPi + SG-LP + TTT 的 71.7% 及 TTT-VLA 的 66.3%；但 QwenWPI + MoLP + AGV-TTT 为 72.4%，略低于 QwenWPI + FP-LP + TTT 的 73.6%，表明收益具任务/具身依赖性。
  • 诊断分析：单一共享提示词在所有任务上联合优化会降低整体成功率（64.1% → 63.3%），而任务特定提示词可提升至 66.1%；注意力可视化显示接触、抓取闭合等交互转换伴随显著的跨层注意力再分布。
  • 分布偏移分析：WidowX 的视觉表示分布比 Google Robot 更远离 RT-1/Bridge 训练参考（PCA-95 空间 MMD 0.330 vs 0.262），但该排序仅作为分布背景，不直接预测 TTT 收益。
