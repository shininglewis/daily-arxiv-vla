Card 03 核心贡献

核心贡献

  • 提出指令配对示教扩展策略：在同一初始场景下为不同指令生成示教，使策略必须在相同视觉上下文中做出不同决策，并配合分层采样平衡训练数据分布。
  • 提出物理一致的视觉扩展：使用仿真器对已保存轨迹重新渲染，改变相机位姿与光照，同时严格保留原有本体感知与动作目标。
  • 提出任务感知的闭环执行管线：结合逆变换运动学（IK）实现动作块到关节指令的转换，并按任务设定夹爪映射与滚动时域重规划。
  • 在 MetaFine 五项任务上取得官方 Overall 85.55% 的成绩，显著超过公开的 π₀ 基线（43.01%）。
  • 提供固定策略下的执行配置消融（执行视界 H、去噪步数 D、夹爪闭合阈值 θ_g），揭示执行设计对性能的显著影响。
Card 04 方法描述

方法描述

  • 指令配对扩展：对每个初始场景状态，用官方专家规划器为同一场景内的多条指令生成轨迹，仅在全部指令变体成功时保留该场景族。
  • 视觉重渲染：基于 ManiSkill3 / SAPIEN 仿真器恢复每个仿真状态并重新渲染 base 与 hand 相机图像，提供相机 L1–L3（平移 0.03/0.06/0.12 m、旋转 2/6/12°）与光照 L1–L3（半宽 0.10/0.25/0.40）扰动；T5 额外使用相机与光照的组合扰动（采样概率 0.45/0.30/0.20/0.05）。
  • 分层采样：按“增强类别 → 指令 → 基轨迹 → 渲染变体 → 时间窗起点”逐层均匀采样，避免渲染副本较多的轨迹被过度加权。
  • 监督式 VLA 适配：基于 Xiaomi-Robotics-1，输入指令、双路 RGB 与关节/夹爪状态，预测 K=30 步末端执行器动作块，采用 flow matching 生成动作，保留原架构与训练实现（含掩码、加权与辅助损失）。
  • 执行设计：将局部末端偏移转为世界坐标目标，经 IK 得到 7 个关节增量；夹爪目标裁剪至 [-0.01, 0.04] m，按任务阈值 θ_g 二值化为完全闭合，T3 保留连续目标；每次只执行前 H ≤ K 步后重新观测（滚动时域控制）。
Card 05 数据集与资源

数据集与资源

  • 使用 MetaFine 基准与 MetaFine_CoRL26 示教数据集，覆盖 5 个任务：部件级抓取（T1）、方向运动（T2）、开关拨动（T3）、物体分拣（T4）、字母插入（T5）。
  • 任务记录规模：T1 6,400、T2 3,300、T3 2,080、T4 2,940、T5 7,840（含渲染变体）；T5 最终池含 2,800 条不同成功轨迹，其中 2,000 条来自 500 个四指令场景的新运动。
  • 模型基于 Xiaomi-Robotics-1 预训练检查点，未改变其架构；各任务独立微调。
  • 训练配置：12,000 次 BF16 更新、batch size 4、余弦学习率 3×10⁻⁶ → 5×10⁻⁷、300 步 warmup。

Card 06 评估与结果

评估与结果

  • 评测遵循 MetaFine 官方协议，包含三个维度：Perception (P)、Understanding (U)、Controlled Behavior (B)；任务分为 P/U/B 均值，Overall 为五任务均值。
  • 官方榜单成绩 Overall 85.55%，相比 π₀ 的 43.01% 提升 +42.54 个百分点；分项均值为 P 85.14%、U 85.75%、B 85.75%。
  • 单任务得分：T1 64.65%、T2 99.49%、T3 99.65%、T4 99.38%、T5 64.55%，表明部件级抓取与字母插入仍是难点。
  • T1 执行视界消融：H=10 最优（P 93.75 / U 78.33 / SR 90.19），优于 H=25（SR 80.93）与 H=5（SR 81.30），说明并非越短越好。
  • T3 去噪步数消融：D=3 与部署的 D=5 持平（SR 均为 98.06），D=10 下降（P −0.83、U −2.50）。
  • 夹爪映射研究：完全闭合显著优于连续目标（P 27.92% → 57.92%，U 35.00% → 55.00%）。
  • 指令敏感性检验：在 8 个经专家筛选的 T5 场景中，正确指令成功率 21/32（65.63%），而循环置换字母后为 0/32，说明模型确实依赖指令而非场景捷径。
