Card 02 论文概述

论文概述

  • 论文首次系统研究交通元素感知（traffic element awareness）对端到端自动驾驶规划性能的影响，涵盖交通灯、道路标志等规则性信号。

Card 03 核心贡献

核心贡献

  • 首个系统性研究：量化了交通元素（TE）在端到端自动驾驶中的价值，证明其在多个基准和模型族上带来一致增益。
  • 3D交通元素数据集构建：提出从2D检测、单目深度估计与LiDAR融合中提取3D交通元素中心点的流程，为nuScenes、NAVSIM等无标注数据集自动生成伪标签。
  • 即插即用的辅助监督机制：在现有规划器上增加轻量级辅助3D TE检测损失（L1位置损失 + focal分类损失），仅需极小架构改动即可集成。
  • 语言引导的拓扑条件化：将预测的LCLC/LCTE拓扑矩阵过滤为自车相关子图，转换为结构化语言文本，经冻结BERT编码后注入规划解码器，优于GNN图编码方案。
  • 跨范式、跨基准的广泛验证：在VAD（感知-规划）、Orion（VLA）、LTF（回归）、DiffusionDrive（扩散）、DrivoR（轨迹评分）、DriveTransformer（统一Transformer）等六类方法上验证，并覆盖四个公开基准。
Card 04 方法描述

方法描述

  • 3D数据集构建：2D交通元素检测（YOLO） + 单目深度估计（UniDepthv2） + LiDAR点云几何约束，投影融合得到3D中心点坐标。
  • 辅助3D交通元素监督：在原有辅助任务基础上增加TE位置回归（L1）与类别分类（focal loss），损失权重与辅助任务一致，强制BEV特征分配专用容量给稀疏但关键的规则信号。
  • 语言引导拓扑条件化：预测全局拓扑矩阵 → 自车过滤 → 格式化为语言描述（例如"green traffic_light... no_right_turn road_sign... connects '1' 'straight' centerline"） → 冻结BERT编码 → 与BEV查询拼接输入规划解码器。
  • 创新点：显式3D表示优于2D线索；独立预测头+最大池化避免稀疏目标被密集背景梯度淹没；拓扑语言编码比GNN更高效紧凑。
Card 05 数据集与资源

数据集与资源

  • 数据集：nuScenes、NAVSIM-v1（navtest）、NAVSIM-v2（navhard）、Bench2Drive（CARLA闭环）
  • 模型规模：BERT-base（约1.1亿参数）作为拓扑语言编码器；各规划器骨干保持原配置（如VAD、Orion等）
  • 训练资源：nuScenes和Bench2Drive使用8×A100（batch size 1）；NAVSIM使用4×RTX 3090（batch size 32）
  • 运行时开销：引入TE与拓扑后FPS仅下降0.3，远低于VLM型场景理解方法（>10倍吞吐优势）
Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（开放轨迹误差L2、碰撞率CR）、NAVSIM-v1（PDMS）、NAVSIM-v2（EPDMS分段）、Bench2Drive（闭环Driving Score等）
  • nuScenes结果：VAD+TE将平均L2从0.72降至0.63（↓0.09），CR从0.22%降至0.17%；加入拓扑进一步将L2降至0.60；Orion+TE+Topo达到L2 0.26、CR 0.23%，优于原Orion（0.34/0.37）
  • NAVSIM结果：三个范式（回归/扩散/评分）在NAVSIM-v1和NAVSIM-v2上均取得一致提升，且在NAVSIM-v2上结合大规模模拟协同训练数据刷新技术水平
  • 闭环Bench2Drive：TE+Topo提升Driving Score、Success Rate等闭环指标
  • 消融发现：3D TE表示优于2D；选择性TE深度优于全局深度图；交通标志（不只是信号灯）同样关键；独立头+focal loss+最大池化对稀疏TE必要；语言拓扑编码优于GNN（提升L2且更快）
