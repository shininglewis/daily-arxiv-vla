Card 02 论文概述

论文概述

  • 提出 GeoBridge-VLA，一种面向视觉-语言-动作（VLA）模型的两阶段几何感知残差适配方法，让预训练 VLA 的冻结视觉编码器学习几何特征并用于动作预测。
  • 核心问题：VLA 的预训练表示偏重语义对齐，缺乏深度、相对位置、物体尺寸等精细几何信息，而机器人操作需要精确空间推理。
  • 目标：在不引入第二个图像编码器、不增加视觉 token 数量、且部署时不需要深度观测的前提下，把深度监督学到的几何信息注入原生视觉通路。
Card 03 核心贡献

核心贡献

  • 将预训练 VLA 中的几何集成形式化为 geometry retrofit（几何改装） 问题，提出共享层级（shared-hierarchy）路径，直接从冻结的中间层 VLA 特征学习深度监督的几何读出，无需增加独立图像编码器。
  • 提出两阶段策略：Stage I 用深度监督适配特征桥（feature bridge）与几何解码器；Stage II 冻结它们，通过门控残差接口把几何表示迁移到原生视觉 token 空间进行动作学习。
  • 将几何获取与几何到动作的迁移解耦，门控残差在初始化时为零（α₀≈0.002），保证 Stage II 从原生视觉表示出发优化。
  • 在 LIBERO 四个套件与真实 ROBOTIS OMY 机器人上进行无深度部署评测，并额外分析共享编码器深度预测与同检查点残差干预实验。
Card 04 方法描述

方法描述

  • Stage I（深度模型适配）：在冻结的 VLA 视觉编码器上，用逐层线性投影 Bℓ 对选定中间特征 Fℓ 做空间重采样与变换，得到 Hℓ，再送入基于 K4（四个固定采样位置的内容自适应聚合） 的几何解码器 D_geo，输出深度预测 d̂ 与几何特征图 g。
  • K4 聚合：解码器沿用 SPACE-CLIP 框架，在固定偏移 δ_k 处双线性采样并用 softmax 权重加权（w(q)=softmax(W_w u(q))），经门控残差加到解码器特征上，保留局部空间结构。
  • Stage I 损失：尺度不变对数深度损失 SILog + SSIM 结构相似度 + 多尺度辅助深度监督，权重系数固定。
  • Stage II（几何引导动作学习）：冻结桥与解码器，将 g 池化到原生 patch 网格，经 1×1 卷积 R_ω 投影为残差 Δz = α·R_ω(Pool(g))，α=σ(η) 为标量门；输出 z̃ = z + Δz，token 数不变。
  • Stage II 损失：骨干的流匹配（flow matching）损失 + 残差正则项 L_res = sqrt(mean(Δz²)+ε)，抑制对原生视觉表示的过度改动。
  • 训练时视觉编码器、视觉投影器、VLM、桥与几何解码器均冻结，仅训练残差接口、动作侧投影与原生动作专家。
Card 05 数据集与资源

数据集与资源

  • LIBERO：四个操作套件（Spatial / Object / Goal / Long）。
  • LIBERO 动作学习数据：HuggingFaceVLA LIBERO 集合，含 1,693 条演示、273,465 个动作帧。
  • LIBERO 深度监督：LIBERO 衍生的 RGB-D 采集数据，使用仿真器真值深度（无教师模型、无参考编码器）。

  • OMY 深度监督：使用冻结的 Depth Anything 3（DA3） 教师生成伪深度，仅在 Stage I 训练中使用，部署时移除。

  • 训练配置：Stage I 20,000 步、batch size 4；Stage II 50,000 步、batch size 32；SmolVLA 基线使用与 Stage II 相同的步数与批大小。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 仿真（40 个任务，每套件 10 任务 × 50 回合，共 2,000 回合）与真实 ROBOTIS OMY 机器人（每任务 50 次配对试验）。
  • 评估指标：任务成功率（SR）、百分比点变化 Δ；深度指标 AbsRel、RMSE(m)、δ₁。
  • LIBERO 结果：GeoBridge-VLA 总体 70.9% vs SmolVLA 60.0%（+10.9 pp）；各套件 Spatial +4.6、Object +20.8（65.6%→86.4%）、Goal +3.8、Long +14.4（32.8%→47.2%）。
  • 真实性机器人结果：总体 74.0%（148/200） vs SmolVLA 54.0%（108/200），提升 +20.0 pp；逐任务增益 +16.0 ~ +24.0 pp，堆叠任务提升最大（36.0%→60.0%），关抽屉达 86.0%。
  • 共享编码器深度预测（LIBERO 前视验证集）：AbsRel 0.030、RMSE 0.1316 m、δ₁ 0.975，优于 DA3-Mono-Large（AbsRel 0.036、RMSE 0.1549、δ₁ 0.988）。
  • 残差干预（同检查点）：启用残差 70.90% vs 关闭（Δz=0）69.85%，差 +1.05 pp；Spatial +3.20、Long +2.80，但 Object −1.20、Goal −0.60，套件间效果不一致。
  • 附录消融：SPACE-CLIPv2 相比 V1 在匹配 CLIP ViT-B/16 与 9,984 张测试图上，AbsRel 由 0.05239 降至 0.04321，RMSE 由 0.06134 降至 0.04993，δ₁ 由 0.95497 升至 0.96678。
  • 局限性：仅验证 SmolVLA 单一骨干与 ROBOTIS OMY 单一平台；真实场景依赖教师伪深度，未测试其他几何监督来源；缺少单独训练的「无几何」对照来严格隔离几何通路在训练期的贡献。
