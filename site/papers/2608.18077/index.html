Hydra-0: Action Flow for Generalist World Modeling and Control

2026-08-18 · 原文 · 翻译 · 2608.18077

本文提出 Hydra-0，一种以"动作流（Action Flow）"为条件输入的通用世界模型（generalist world model），将机器人动作表示为图像平面上的像素运动轨迹，从而在不同 embodiment（机械臂、双手臂、人手等）、任务、环境和视频生成骨干网络上实现统一的动作后果预测与控制。 核心思路是：用动作流替代传统的关节空间指令或末端执行器指令作为视频模型的视觉条件——动作流在观测平面中表达"可见机器人表面点的运动轨迹"，既保留了运动学约束，又天然跨 embodiment 可迁移。 该接口支持两种模式：前向模式（给定候选命令预测真实世界后果，用于策略评估）和逆向模式（给定期望物体流推断兼容的机器人运动，用于机器人控制），形成一个连接异构训练数据、开环策略评估和机器人控制的共享接口。

Card 03 核心贡献

核心贡献

  • 将机器人动作条件化形式化为运动学grounded的图像平面动作流：训练时可直接从交互视频中恢复，部署时通过 Isaac Lab 的控制器+物理仿真滚动，结合机器人几何与相机标定（Equation 1）从可执行命令推导得到。
  • 证明动作流可作为跨 embodiment 与视频生成骨干网络的通用接口，在 Cosmos 2.5 和 Wan2.2（A14B 与 TI2V-5B）三个骨干上均实现一致提升，最佳配置相比动作条件化的 Cosmos 2.5 基线降低 90.40% 机器人运动误差 和 60.16% 物体运动误差。
  • 实现动作流条件下的开环策略评估：在 RoboLab 基准的 5 个策略上，重放成功率与参考成功率的 Pearson 相关系数 r=0.96。
  • 反转同一接口，提出世界动作模型（world action model）：仅凭人类演示迁移的期望物体流即可推断兼容的机器人运动，并通过训练好的动作头直接输出可执行动作，无需任务特定的专家机器人演示。
  • 提出四种训练时流采样策略（Embodiment / Object / All / None），使模型在不同应用场景下灵活利用机器人本体运动或物体运动线索。
Card 04 方法描述

方法描述

  • 动作流表示为 N 个跟踪点在预测时域 H 内的图像平面轨迹集合 F = {τₙ}，每个轨迹包含位置序列 (u, v) 与可见性掩码 m。
  • 几何感知构建：部署时用 Isaac Lab 执行候选命令序列，获得机器人关节状态与连杆变换（Equation 1），将机器人表面采样点投影到相机平面生成动作流；仅视频构建：训练时用 AllTracker 稠密跟踪 + SAM 3 语义分割恢复动作流，无需机器人描述文件或相机标定。
  • 动作流条件化视频预测：借鉴 ATI 和 Wan-Move 的方法，将初始帧潜变量特征沿轨迹做双线性采样与高斯加权时间传播（Equation 3, 4），生成运动条件 C_motion 与视频噪声潜变量拼接后送入 DiT 修补嵌入。
  • 高效因果滚动：采用 LongLive-2.0 的自回归转换（分块生成+KV cache）与 DMD2 蒸馏实现少步采样（4步），同时保持动作流轨迹在绝对时间偏移下不被重新锚定。
  • 世界动作模型：在对象流条件下，从去噪后的 DiT token 特征中通过动作头（mean-pool + attention-pool → LayerNorm → 两层 GELU MLP）解码出可执行动作与状态，使用流损失 + 动作/状态 Huber 损失 + 速度平滑损失的联合训练目标（Equation 7）。
  • 训练策略：冻结预训练视频骨干权重（仅微调 DiT patch embedding），在 q/k/v/o 注意力投影与两层前馈投影上训练 rank-64 LoRA 模块。

数据集与资源

  • 构建多 embodiment 训练语料库，来自 7 个数据源，共 178,187 个 episode，1,565,634 个 81 帧窗口，约 2,201.7 小时：

- XVLA-Soft-Fold 与 H1-Fold-Clothes（布折叠，25.0 + 0.1 小时）

  • 模型骨干：Cosmos 2.5（2B）、Wan2.2 I2V-A14B、Wan2.2 TI2V-5B；世界动作模型使用 rank-32 LoRA 适配器与轻量动作头（隐藏层宽 1024）。
Card 06 评估与结果

评估与结果

  • 评估基准：在 XVLA-Soft-Fold、Deform360、DROID 三个数据集的 5 个保留测试集上各用 100 个验证片段；指标包括 PSNR、SSIM、物体 EPE、夹爪 EPE、FID、FVD 和 VLM 评分（1–5 分制）。
  • 主要结果（与 Cosmos 2.5 动作条件化基线相比）：

- 机器人运动误差降低 90.40%，物体运动误差降低 60.16%；最佳配置为 Ours (Wan2.2 A14B 4-step)，在 XVLA-Soft-Fold 上 PSNR 19.23、SSIM 0.781、物体 EPE 3.47、夹爪 EPE 3.20、FID 19.3、FVD 238.5、VLM 4.67，全面超越 ATI、Wan-Move 零样本基线与 Cosmos 2.5 微调基线。

- 在 Deform360 上 PSNR 20.63、SSIM 0.804、FVD 166.5；在 DROID 上 PSNR 与 FVD 同样显著优于基线。

  • 数据效率：多 embodiment 中期训练显著提升单任务微调的数据效率（数据集仅用于评估，不参与训练）。
  • 推理速度：4 步蒸馏采样配合因果 KV cache 实现实时或近实时推理。
  • 开环策略评估：在 5 个 RoboLab 策略上，重放成功率与参考成功率的 Pearson 相关系数 r=0.96，并完成真实世界概念验证。
  • 逆向控制：在真实机器人上，将人类演示中迁移的物体流输入世界动作模型，成功转换为可执行机器人动作，无需任务专属专家演示。
