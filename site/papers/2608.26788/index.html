Decoupling Planning and Control for Instructable Agents

Card 02 论文概述

论文概述

  • 提出 Instruct-to-Act 框架，将具身智能体的决策解耦为高层 规划（planning） 与低层 控制（control） 两部分。
  • 核心思想：预训练 VLM 作为规划器生成稀疏语言指令，世界模型控制器高频执行低层动作，两者异步协同工作。
  • 解决现有方法中 VLM 难以生成实时低层动作流、纯 RL 控制器缺少开放任务引导的问题，实现无需微调 VLM 即可适配多种环境。
Card 03 核心贡献

核心贡献

  • 提出语言条件化的 RSSM 世界模型控制器，利用冻结的对比语言编码器将指令嵌入策略、价值与停止预测头。
  • 提出 事后指令标注（post-hoc instruction supervision）：用 VLM 为回放轨迹段自动生成指令，结合行为克隆目标训练控制器，无需专家示范。
  • 设计 异步在线推理 机制，规划器在后台持续推理，控制器同时执行动作，大幅提升吞吐量并支持自然的多智能体扩展。
  • 实现 多智能体语言协调：共享控制器参数，规划器通过聊天室用自然语言通信，无需 CTDE 式集中训练或角色标注。
  • 验证 即插即用的规划器替换：同一控制器可搭配 Gemma、LLaVA、Qwen-VL、GPT-4o 等多种 VLM，无需重新训练。
Card 04 方法描述

方法描述

  • 控制器基于 DreamerV3 风格的 RSSM，使用 CLIP-base 与 DINOv2-base 视觉特征，MiniLM-L6 语言嵌入。
  • 训练目标联合世界模型损失、Dreamer 风格的 actor/critic 损失、行为克隆损失（BC）及指令完成二分类损失（stop）。
  • 回放缓冲区中 50% 的随机片段由 GPT-4o 用帧与动作序列标注为高级指令，其余片段保持无指令以保留自主行动能力。
  • 推理时规划器与控制器并行运行：规划器持续维护记忆库和局部计划，控制器在指令完成时请求下一条指令，支持在线（异步）与离线（同步）两种模式。
Card 05 数据集与资源

数据集与资源

  • 评估环境共 7 个：Atari (ALE)、MineRL ObtainDiamond、Crafter、DeepMind Lab (explore_goal_locations)、Overcooked-AI、Pico Park（多人合作）、MindCraft（Minecraft 多人协作）。
  • 控制器主力变体为 800M 参数，另有 50M、200M 小规模变体用于缩放实验。
  • 每个环境训练单个控制器，成本约 23 GPU-hours（4 块 RTX A6000），约 550 万环境步，标注额外开销约 17% GPU-hours。
Card 06 评估与结果

评估与结果

  • 对比基线包括复现的 DreamerV3、QMIX、MAPPO、领域自适应的 RT-2，以及文本规划方法 Voyager、DEPS、LS-Imagine、JARVIS-1。
  • 主要指标为各环境官方指标（如 Atari 分数、Minecraft Diamond 成功率、Overcooked 得分等）以及吞吐量（环境步/秒）。
  • 使用 GPT-4o 等 VLM 规划器 + 控制器，在 6/7 个任务上达到与强基线竞争的水平；相比直接 VLM 生成动作（w/o controller）显著提升。
  • 无指令时控制器性能与 DreamerV3 相当；引入语言指令后平均指令跟随准确率达 92.8%，并保持低延迟控制。
  • 在线异步规划比离线同步规划在吞吐量上提升一个数量级；多智能体分散式通信优于集中式，且扩展至 8 个智能体仍保持高效。
