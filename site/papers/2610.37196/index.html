Card 03 核心贡献

核心贡献

  • 提出去噪反事实协议：基于按位可复现的分支、重复延续、留出 oracle（held-out oracle）与公共随机数，测量选择器真正能实现的可选余量。
  • 揭示标准单延续 oracle 的增益主要来自延续随机性：候选效应仅 0.0006，而候选×延续交互为 0.028，即 98% 的候选差异在换种子后被重抽。
  • 发现结构化动作扰动（沿机器人六个轴偏移策略块）能创造真实可选余量，67–95% 在留出评估中存活，而原生样本至多 22%。
  • 证明想象未来中已携带排序信号：线性探针在想象未来与真实未来上表现无显著差异，而 Cosmos Policy 的价值头（AUROC 0.90）几乎未能利用该信号。
  • 构建失败门控选择器（失败门 + 学习排序器），在闭环中显著提升任务成功率，并发布 HeadroomBench 基准与分支数据集。
Card 04 方法描述

方法描述

  • 按位可复现分支：快照并恢复完整 MuJoCo 状态、全局随机数状态及 RoboCasa 夹具状态（如炉火），分支复现与种子重放的字节级一致。
  • 三类估计量：单延续 oracle O¹、样本内 oracle O^in（上界）、留出 oracle O^L（下界），并报告留出份额 R^L = Ō^L/Ō¹。
  • 方差分解：用两水平模型 Y_cj = μ + a_c + b_j + e_cj 分离候选效应 τ²、种子计划效应与不可利用的候选×延续交互。
  • 高效采样：每个候选先跑一次延续，仅对结果不同的决策点及哈希抽样的四分之一决策点追加延续，并用逆采样概率加权 + 按状态聚类的 bootstrap 置信区间。
  • 结构化提议：a'_{k,0:3} = clip(a_{k,0:3} + κe_d, -1, 1)，κ ∈ {0.1, 0.25, 0.5} 对应约 2/5/10 cm 末端执行器位移，方向与夹爪不变。
  • 表征探针：对冻结模型最终 Transformer 块未来帧位置的 token 做加权对偶岭回归线性探针，留一状态训练、决策点内中心化并对全局方向残差化，统计量为决策点内 Spearman 相关 ρ，零分布由决策点内置换重拟合得到。
  • 选择器设计：失败门（对 WAM 想象自身动作块时的表征做逻辑回归读出，用反事实分支的任务结果训练）判断是否偏离；排序器（想象通道上的岭读出）决定偏移方向，仅在门触发时调用。
Card 05 数据集与资源

数据集与资源

  • 基准：RoboCasa（3 个任务：TurnOnStove、TurnOnMicrowave、PnPCounterToSink）与 LIBERO-Plus（LIBERO-10 的扰动版本，选用 Objects Layout 与 Robot Initial States 两类扰动）。
  • 模型：四个 WAM——Cosmos Policy（2B 参数，RoboCasa 公开检查点平均成功率 67.1%）、Flex-π、Fast-WAM、Streaming-WAM。
  • 数据规模：12 个分支数据集（RoboCasa 4 个、LIBERO-Plus 8 个），累计超过 100,000 条分支 rollout；另含 400 个新状态（1,176 决策点）、480 个闭环回合、858 个未使用初始状态回合。
  • 训练细节：Cosmos Policy 的价值头在 1,200 条策略 rollout 上微调，使用 15K 步模型；选择器在 320 个 LIBERO-Plus 状态上按预声明网格做按状态交叉验证选参。
  • 计算开销：选择器每回合额外增加 17.5 次想象通道（相对 12 次策略查询）；原文未明确列出 GPU/TPU 型号与总量。
Card 06 评估与结果

评估与结果

  • 预注册评估：主文全部验证性检验均预注册，共 24 项测试（附录 A 按注册顺序列出），数据、统计量与判据均在数据收集前登记。
  • 主要指标：单延续 oracle Ō¹、留出 oracle ŌL、留出份额 R^L、相对策略块的增益、决策点内 Spearman ρ、AUROC、闭环任务成功率。
  • 复现与证伪：复现 Yuan et al. 的 +12.3 分 oracle 增益，但 Ō¹ = 0.102 [0.036, 0.190] 而 ŌL = 0.009 [-0.001, 0.023]，R^L = 0.086；K 增大时 Ō¹ 持续上升而 ŌL 持平，是“在噪声上选择”的典型特征。
  • 余量区间：17 次延续下，原生样本的可选份额对 Cosmos Policy 为 24%–52%，对 Flex-π 与 Fast-WAM 为三分之一到三分之二；单延续 oracle 至少高估 1.27–1.5 倍。
  • 结构化提议增益：留出 oracle 相对策略块提升 +0.112（Cosmos Policy）、+0.088（Fast-WAM）、+0.045（Flex-π）等，且增益集中在策略块失败的决策点（+0.21–0.44）。
  • 想象信号：想象未来探针 ρ = +0.31 / +0.37（TurnOnStove）、+0.54（TurnOnMicrowave）、0.26/0.20（LIBERO-Plus）；与真实未来差异在预注册 ±0.15 等效界内；价值头决策点内 \|ρ\|≤ 0.05。
  • 闭环结果：训练任务保留回合成功率 76.9% → 81.6%（+4.7 [1.9, 7.6]）；机器人初始状态扰动下 65.1% → 75.8%（+10.7）；未见任务 62.6% → 69.8%（+7.2 [4.7, 9.8]），全部任务训练时可达 76.0%（+13.4）。
