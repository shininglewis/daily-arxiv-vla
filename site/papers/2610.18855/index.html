Card 02 论文概述

论文概述

  • 论文提出 ILA（Interaction Latents as Actions），将运动轨迹、接触演化与力施加的联合演化编码为可解码的"交互潜变量"，作为策略的动作单元。

Card 03 核心贡献

核心贡献

  • 提出交互潜变量作为策略动作：以可解码表示联合刻画运动、接触与力的演化，并作为 VLA、WAM 及从头训练流匹配策略 的通用生成目标。
  • 实现交互空间中的评估与离线改进：用专家演示定义触觉条件下的专家一致性奖励，将成功回合的奖励加权学习与失败交互的观察兼容专家纠正相结合。
  • 在三类策略架构上进行真实世界评估：四个接触丰富任务上一致取得增益，并配合运动-接触表示分析与专家引导的离线改进。
  • 消融证明：将接触演化编码进动作目标优于仅使用触觉条件输入，且同一潜空间可复用于专家引导的离线改进。
Card 04 方法描述

方法描述

  • 交互表示学习：使用视觉条件化的联合"动作-触觉"重建学习潜变量，冻结 DINOv2 提取多帧 patch 特征，融合当前帧语义与相邻帧差分运动线索形成 S&D（Semantics-and-Dynamics） tokens。
  • 多模态编码：动作与触觉序列分别编码为时间对齐 token，通过联合自注意力耦合、交叉注意力引入视觉条件，再时间压缩为潜变量 $z_t^{enc} \in \mathbb{R}^{K\times d_z}$。
  • 时间条件隐式解码器：将运动与接触表示为连续时间函数，查询时间内插相邻 token 并融合时间编码，共享解码特征预测动作、触觉形变场与聚合形变。
  • 训练监督：在原始观测时刻外增加 2H 个分层随机采样查询时刻，损失包含动作 $L_1$、触觉形变 $L_1$、方向与幅值聚合监督项（$\mathcal{L}_{dir}$、$\mathcal{L}_{map}$）。
  • 策略学习：冻结编码器与解码器，离线编码演示片段作为流匹配目标，支持 VLA（π0.5 前缀追加 S&D 与触觉/本体历史 token）、WAM（共享交叉注意力条件，动作分支目标替换为交互潜变量）以及从头训练的 DiT 流匹配策略。
  • 离线改进：以流匹配残差定义专家一致性能量 $\mathcal{E}_\omega$ 与奖励 $r_t = -\mathcal{E}_\omega$；成功回合按奖励加权；失败回合检索观察兼容的专家参考，构造兼容性自适应纠正目标 $z_{ij}^* = (1-\alpha_{ij})\hat{z}_i^{ref} + \alpha_{ij}z_j^e$。
Card 05 数据集与资源

数据集与资源

  • 真实世界任务（4 个）：黄瓜削皮（cucumber peeling）、煎蛋翻面（egg flipping）、芹菜切割（celery cutting）、盘子擦拭（plate wiping）。
  • 数据规模：每个任务采集 150 条专家演示 用于策略训练；另收集策略 rollout 语料用于离线改进。
  • 硬件平台：双臂 ARX X5 平台 + 平行夹爪 + 指尖 Xense 触觉传感器；Intel RealSense D405 腕部相机 + 外部工作空间相机；图像、触觉形变场与本体感知以 30 Hz 同步。
  • 模型组件：VLA 骨干为 π0.5；视觉编码器为冻结的 DINOv2；WAM 基线包括 FastWAM-tac、DreamTac。

Card 06 评估与结果

评估与结果

  • 评估设置：每个任务 20 次试验，芹菜切割按每次切割计分，其余按试验计分；成功率为 SR，另报告执行力代理误差 $F_{ext}$ L1，开环预测报告 $F_{pred}$ L1 与 Tac. L1。
  • 对比方法：$P$-tac（直接生成运动序列）、$P$-tac\*（联合生成动作与触觉，类 KineDex/ForceMimic）、$P$-ILA（生成交互潜变量）；离线改进基线为 IQL 与 RECAP。
  • 主要结论：相对触觉条件直接动作基线，ILA 在 FM / VLA / WAM 上平均成功率分别提升 26.0 / 36.5 / 21.0 个百分点（总体 21.0–36.5 pp），12 次对比中 11 次降低 $F_{ext}$ L1。
  • 代表数值：FM-ILA 在四个任务的 SR 为 75% / 95% / 50% / 100%；VLA-ILA 为 50% / 85% / 37% / 95%；WAM-ILA 为 70% / 80% / 45% / 100%。
  • 离线改进效果：FM-ILA + 本文方法在削皮任务上 SR 从 75% 提升至 85%，力代理误差从 2.04 降至 0.51（降低约 75%）；优于 IQL（40%）与 RECAP（50%）。
  • 消融结果：去掉触觉表示使 VLA 在削皮/切割上分别下降 30 / 27 个百分点；去掉 S&D token 下降 10 / 5 个百分点；去掉隐式解码器使 FM 下降 10 / 6 个百分点，验证各设计模块有效性。
  • 奖励与纠正消融：以握力强度或 HapticVLA 风格奖励替代专家一致性奖励，SR 降至 70%；无失败纠正为 80%；加入参考引导纠正后达到 85% 且 $F_{ext}$ L1 从 2.89 降至 0.51。
