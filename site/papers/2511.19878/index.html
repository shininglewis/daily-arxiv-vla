MAPS: Preserving Vision-Language Representations via Module-Wise Proximity Scheduling for Better Vision-Language-Action Generalization

2025-11-25 · 原文 · 翻译 · 2511.19878

论文提出 MAPS (Module-Wise Proximity Scheduling)，这是首个专门面向 Vision-Language-Action (VLA) 模型的鲁棒微调（Robust Fine-Tuning）框架，旨在解决 VLA 模型在动作微调过程中灾难性遗忘预训练视觉-语言表征、导致泛化能力下降的问题。 核心挑战在于平衡动作适应与预训练泛化保持之间的权衡：过度微调导致模型偏离预训练初始化、鲁棒性下降，而微调不足则限制动作空间的对齐能力。 通过系统性分析，论文揭示了 VLA 不同组件（DINOv2 > SigLIP > Early language > Late language）在冻结/微调中的重要性层级，并据此设计模块级邻近约束调度，在保持视觉先验的同时允许语言层灵活适应动作空间。

Card 02 论文概述

论文概述

  • 论文提出 MAPS (Module-Wise Proximity Scheduling)，这是首个专门面向 Vision-Language-Action (VLA) 模型的鲁棒微调（Robust Fine-Tuning）框架，旨在解决 VLA 模型在动作微调过程中灾难性遗忘预训练视觉-语言表征、导致泛化能力下降的问题。
  • 核心挑战在于平衡动作适应与预训练泛化保持之间的权衡：过度微调导致模型偏离预训练初始化、鲁棒性下降，而微调不足则限制动作空间的对齐能力。
  • 通过系统性分析，论文揭示了 VLA 不同组件（DINOv2 > SigLIP > Early language > Late language）在冻结/微调中的重要性层级，并据此设计模块级邻近约束调度，在保持视觉先验的同时允许语言层灵活适应动作空间。
Card 03 核心贡献

核心贡献

  • 提出 MAPS 框架，首次将鲁棒微调范式系统性地引入 VLA 领域，通过模块级邻近调度在稳定性和灵活性之间取得平衡。
  • 通过系统性的冻结实验分析，揭示并量化了 VLA 各组件的经验重要性顺序：视觉编码器（尤其 DINOv2）应紧贴预训练先验，而面向动作的语言层可更自由地适应。
  • 用线性调度替代传统鲁棒微调中的全局统一约束，为不同模块分配不同的邻近强度，避免了冻结的刚性偏差和统一正则化的僵化。
  • MAPS 不引入任何额外参数、数据或辅助网络，即插即用，可无缝集成到现有 VLA 架构中。
  • 在多个 VLA 骨干（MiniVLA-VQ、MiniVLA-OFT、OpenVLA-OFT、VLA-Adapter）和多个基准（SimplerEnv、CALVIN、LIBERO、Franka Emika Panda 真机）上验证了 MAPS 的一致提升，OOD 性能最高提升 +30%。
Card 04 方法描述

方法描述

  • 基础机制：MAPS 建立在 SPD（Selective Projection Decay）之上，利用投影梯度方法将参数更新限制在预训练权重附近，并根据梯度-位移相关性决定是否投影。
  • 核心创新：将 SPD 的全局超参数 λ 替换为模块级、架构感知的线性调度：λ_k = λ_max × (1 − (k−1)/(\|L\|−1))，从早期视觉层（强约束）线性衰减到深层语言层（弱约束），新初始化的模块（动作头等）设为 λ=0 全微调。
  • 模块分解：将 VLA 分解为 DINOv2 → SigLIP → Bridge → Language 的模块栈，按层级分配不同的投影强度，视觉层保持强锚定、语言层灵活适应。
  • 优化过程：在每一步中，先计算无约束更新，当 c_t < 0 时执行层特定的投影 θ_t ← θ̃_t − λ_k · r_t · (θ̃_t − θ₀)，其中 r_t 为 SPD 偏差比率。
  • 轻量集成：无需修改架构、无需额外训练阶段，直接编码经验性模块重要性层级，实现"何时保持、何时适应"的自适应学习。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：SimplerEnv（BridgeData V2 Visual Matching）、CALVIN（ABC→D 协议）、LIBERO（LIBERO-90 训练，评估 Spatial/Object/Goal/Long OOD 子集）、真实世界 Franka Emika Panda 机器人平台。

  • 基线模型：RT-1-X、Octo、π₀、OpenVLA、miniVLA 系列、SpatialVLA 等。
  • 训练资源：从预训练 VLM 权重初始化，直接从头微调各 VLA 骨干，未提及具体 GPU 数量（从 OpenVLA-OFT 7B 规模推断需多卡高性能 GPU）。
Card 06 评估与结果

评估与结果

  • SimplerEnv：在 MiniVLA-OFT 上，MAPS 保持 ID 性能（30.0 vs 13.5 显著提升 ID Avg），OOD 平均提升 +26.9%（35.8 vs 8.9）；OpenVLA-OFT OOD 提升 +8.4%；MiniVLA-VQ OOD 提升 +1.5%，且超越更大规模预训练的 RT-1-X、Octo、π₀ 基线。
  • CALVIN：MiniVLA-OFT 平均序列长度 +0.7，各任务 horizon 成功率提升 7-15%（2/3/4/5 步序列各约 +15%）；OpenVLA-OFT 成功率提升 2%，平均长度 +0.1，显示 MAPS 与强基线互补。
  • LIBERO：MiniVLA-VQ ID 提升 +3.0%，OOD 平均提升 +4.75%（Goal +8%、Long +10%）；MiniVLA-OFT OOD 平均 +2.25%（Spatial +6%、Object +6%）；VLA-Adapter ID +5.0%、OOD +2.25%；OpenVLA-OFT OOD +5.5%。
  • 消融研究：线性调度优于常量 λ（均匀 SPD）和余弦替代方案，证实模块级、结构化邻近控制的重要性；冻结实验显示冻结视觉编码器（尤其 DINOv2）显著优于冻结语言层，但冻结本身存在任务依赖的归纳偏差。
