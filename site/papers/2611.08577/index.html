Card 03 核心贡献

核心贡献

  • 构建大规模数据基础：1.47 亿视觉-语言样本 + 15,060 小时、覆盖 12 种本体的精选机器人轨迹（含自建 RoboDesk 数据集）。
  • 提出三阶段渐进训练配方：离散动作 token 预训练 → 连续流匹配跨本体中期训练 → 真实世界策略优化（SFT、HG-DAgger、RECAP、CFG-DAgger）。
  • 提出 Rollback 数据采集机制：回退到历史锚点，将“被替换的策略片段”与“人类纠正片段”配对，为 CFG-DAgger 提供直接正/负标签，无需价值学习和优势标注。
  • 设计统一末端执行器（EEF）动作接口支持单臂与双臂异构本体学习，并提出异步动作块合并机制在变长推理延迟下保持平滑执行。
  • 提出事件驱动具身智能体：Monitor 把视觉观测转为任务事件，Memory Manager 维护持久事件记忆，Planner 仅在任务进度或可行性变化时触发重规划，实现跨任务检索与条件性任务恢复。
Card 04 方法描述

方法描述

  • 骨干网络：以 Qwen3.5-4B 初始化共享视觉-语言主干，全程可训练；预训练阶段用 FAST（DCT + BPE）将动作块离散化为 token，与文本共享自回归头。
  • 连续动作头：中期训练起改用 MMDiT 动作头，采用 flow matching 与 JiT 干净样本参数化，通过联合自注意力交换观测流与动作流信息，AdaLN 注入流时间步。
  • 动作表示：定义统一右手系本体/夹爪坐标系与肩心（SC）参考系，每臂动作为 10 维（绝对位置 3 + 6D 旋转 + 夹爪开合 1），双臂拼接为 20 维，并用二值掩码计算 masked loss 适配不同本体。
  • 数据策展流程：S1 静态边界裁剪、S2 运动学一致性检查（URDF 重投影比对）、S3 视频缺陷过滤，A1 跨本体动作规范化、A2 多粒度任务标注对齐（global_task / curr_subtask / scene / skill）。
  • 语言混合策略（langmix）：以等概率采样子任务标签或回合级目标，让同一动作同时对齐细粒度与任务级指令。
  • 执行系统：EVA-Client 后台策略线程按 $f_\pi$ 预测动作块，控制环按 $f_c$ 消费；丢弃过期前缀并与旧缓冲做线性混合（temporal chunk-wise smoothing）。
Card 05 数据集与资源

数据集与资源

  • 视觉-语言语料：约 1.47 亿样本，78% 通用数据（VQA、空间理解、视觉定位、计数）+ 22% 具身数据（场景描述、任务规划、可供性定位）。
  • 机器人语料（15,060 小时，12 本体）：RoboDesk 3,235 h（21.5%）、授权真实数据 7,530 h（50.0%）、开源仿真数据 4,295 h（28.5%）。
  • 开源真实数据来源：AgiBotWorld-Beta（2,174 h）、Galaxea Open-World（333 h）、RoboCOIN（311 h）、LET（172 h）、DROID（164 h）、RoboMIND（81 h）；仿真：InternData-A1（3,967 h）、Genie Sim 3.0（213 h）、RoboTwin 2.0（115 h）。
  • 预训练实际混合：VLA 动作池 1,444.5M 帧 / 约 13.6k 小时，VLM 协同训练池 150.7M 有效样本（来自 64 个子数据集）；损失权重 $\lambda_{vla}=1.0$、$\lambda_{vlm}=0.1$。
  • 训练资源：预训练 500,000 步 / 256 张 GPU（AdamW + 余弦退火）；中期训练 128 张 GPU，骨干低学习率、新动作头高学习率。
Card 06 评估与结果

评估与结果

  • 仿真基准：RoboTwin 2.0（50 任务，clean 与 randomized 两个划分，每任务 100 回合，共 5,000 回合/划分）与 RoboDojo VLA 赛道。
  • 真实机器人：三个桌面任务上与 π0.5 在同等 HG-DAgger 后训练条件下对比；另在网线插入任务上比较 HG-DAgger / RECAP / CFG-DAgger。
  • 主要指标：成功率（success rate）与进度分数（progress score）；CALVIN 上使用平均完成序列长度（Avg. Len.）。
  • 关键结果：

- RoboTwin 2.0 平均成功率 93.6%，显著优于 π0（62.2）、π0.5（79.8）、X-VLA（72.8）、ABot-M0（86.1）等基线。

- RoboDojo VLA 赛道按平均成功率排名第五。

- 在同等 HG-DAgger 后训练下，MR0 在三个真实任务上的平均成功率与进度分数均优于 π0.5。

- 网线插入任务：使用 Rollback 数据的 CFG-DAgger 达 70% 成功率 / 0.90 进度分，优于 HG-DAgger 与 RECAP，且无需价值学习与优势标注。

- CALVIN ABC→D 消融指导数据构建：2D 目标-可供性定位（4.102）、场景描述（4.082）效果最好，最终选择 2D 目标-可供性定位、场景描述与 2D 定位三类自建数据。

- 定性部署展示了跨任务事件检索，以及在条件暂时不满足时挂起、条件恢复后继续执行的能力。
