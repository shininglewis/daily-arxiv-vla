Card 02 论文概述

论文概述

  • 针对扩散式视频生成模型（VGMs）在长视频中相机自运动（ego-motion）漂移的问题，研究 VGM 内部如何表征、使用并保留精确的相机自运动信息。
  • 提出 CausalAlign：先用线性探针与因果干预定位自运动信息“先升后降”的失效位置，再在这些位置做 delta-token 表征对齐。
  • 目标是在不牺牲视觉质量、不引入推理期额外几何计算的前提下，提升相机轨迹的几何一致性与时间平滑性，并进一步惠及具身操作模型（WAMs）。
Card 03 核心贡献

核心贡献

  • 发现并提出 “geometric state forgetting”（几何状态遗忘） 现象：自运动信息在去噪中期被表征和使用，但在后期时间步与末尾若干 Transformer 层中衰减消失。
  • 提出 CausalAlign 因果对齐框架：通过线性探针“可解码性”与因果干预“因果效应”联合诊断，自动选择需对齐的层与去噪时间步。
  • 技术创新：将 delta token（相邻帧特征差分）思想用于自运动建模，并借助 3D 基础模型 LingBot-Map 构建教师 delta-token 空间，过滤静态场景冗余。
  • 将诊断信号从 rise-and-fall 改为 rise-and-maintain，证明对齐不只是提升可解码性，而是真正保留了生成过程中的因果影响力。
  • 在机器人移动操作基准 RoboCasa365 上验证下游价值，Fast-WAM 平均成功率提升 10.7 个百分点。
Card 04 方法描述

方法描述

  • 因果诊断：冻结 Wan2.2，对每层 ℓ 与噪声级 s 用线性探针从跨帧转移特征预测相对相机位姿，得到可解码性分数 D；再做 Mask / Shuffle / Replace / Inject 四种干预并结合随机对照计算因果效应 C。
  • 目标选择：对 D 与 C 做归一化融合得 J，按正向下降率最大处选出层 14（主）、10、12、20（辅） 与时间步 s ∈ {398, 799}，并以时间下降率作为损失权重 ω。
  • Stage 1：冻结 3D 基础模型 LingBot-Map（Φ_T）提取几何状态，训练编码器 E_Δ 生成 128 维 delta token（64 维自运动 + 40 维几何 + 24 维视觉分区），辅以状态重建、时间预测与相机位姿解码任务。
  • Stage 2：训练层特定的投影器 Q_ℓ，把 VGM 的跨帧隐状态转移映射进教师 delta-token 空间，训练后冻结。
  • Stage 3：仅在选中层与时间步更新 LoRA 适配器，损失为 L_pose + λ_Δ·L_Δ，梯度经冻结的投影器与相机解码器回传。
  • 推理：与原 Wan2.2 流程完全一致，教师模型与所有辅助模块均不再需要，无额外几何缓存或输入。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估维度：视觉质量（VBench-I2V 的 Quality / I2V Score / Smoothness，以及 FVD、CLIP、SSIM、LPIPS）、自运动一致性（平移与角速度接近度、重投影误差、深度-光流一致性、对极误差、轨迹平滑度、jerk）、几何状态保留度（探针可解码性与因果效应曲线）。
  • 对比基线：Wan2.2 基座；外部 3D 缓存类 GEN3C / Voyager；偏好对齐类 VideoGPA / Epipolar-DPO；直接特征对齐类 JOG3R / Geometry Forcing / FantasyWorld。
  • 自运动一致性：七项指标全部优于 Wan2.2，七项中六项最优；重投影误差 8.4 → 6.5 px（−22.6%），平滑度 0.71 → 0.88（+23.9%），jerk 0.182 → 0.151，平移接近度 0.68 → 0.79，旋转接近度 0.70 → 0.89，对极误差 2.9 → 2.1 px；仅深度-流一致性以 5.5 vs 5.4 px 略逊于 FantasyWorld，且无需相机轨迹输入。
  • 视觉质量：VBench Quality 0.805 → 0.806，I2V Score 持平 0.958，Smoothness 0.983 → 0.985，FVD 182.4 → 182.7，CLIP 0.311 → 0.314，SSIM 0.742 → 0.744，LPIPS 持平 0.183，几乎无损。
  • 下游 WAM：RoboCasa365 Target100 平均成功率 43.5% → 54.2%，Atomic Seen 59.1% → 78.1%（+19.0 点，703/900），Composite Seen 36.4% → 40.8%，Composite Unseen 33.2% → 40.6%。
  • 消融实验：结构化分区 delta token 在六项指标上均优于等宽 PCA 投影的无分区编码器；128 维 delta token 全面优于 LingBot-Map 原始 8192D 拼接特征与 4096D 差分特征（旋转误差 3.243° → 2.530°）。
