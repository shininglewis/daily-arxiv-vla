Card 02 论文概述

论文概述

  • 论文提出 HABILIS Brain 0 / GC-VLA，一种以几何变化（Geometry-Change）为监督信号的视觉-语言-动作（VLA）策略，目标是让策略不只理解当前几何，还能刻画动作执行过程中场景应发生的变化。
  • 核心问题：静态当前深度监督只能提供场景几何，无法直接描述动作时间跨度内的几何转变（如夹爪接近物体、抽屉沿约束滑动、接触建立、物体姿态变化）。
  • 研究目标：构建一个具身无关（embodiment-agnostic）的视觉接口，可先在机器人视频与人类第一视角视频上预训练，再进行机器人特定动作对齐，避免依赖动作标注。
Card 03 核心贡献

核心贡献

  • 提出 GC-VLM：从当前观测预测多视角未来–当前几何变化 token（ΔE = E_{t+H} − E_t），而非重建未来观测或完整未来隐状态，从而突出操作跨度内发生变化的区域与特征。
  • 设计四阶段训练管线：Stage 1 几何预训练 → Stage 2 动作专家分离式对齐 → Stage 3 耦合式 VLA 适配 → Stage 4 GCRF 残差后训练。
  • 提出 GCRF（Geometry-Conditioned Residual Flow）：冻结 GC-VLA，利用二值干预路由器和单一有界残差速度策略，在流速度空间中学习选择性修正，而非直接修改最终动作块。
  • 提出泄漏防护（Leakage Prevention）：未来帧仅作为离线训练标签，部署时不使用未来帧、不使用离线目标编码器，推理仅依赖当前语言指令、RGB 观测与机器人状态。
  • 在 LIBERO 上取得 95.20% 成功率，加 GCRF 后提升至 99.55%。
Card 04 方法描述

方法描述

  • 几何变化目标：离线用 Depth Anything 3（DA3-BASE） 生成伪深度，经 DINOv2 提取特征，计算当前帧与未来帧（H_GC = round(0.5f)，即 0.5 秒预测跨度）的特征差 ΔE ∈ R^{10×10×d}。
  • Token 化：每个视角量化为 10×10=100 个空间 token，三视角（head、wrist-L、wrist-R）拼接为 300 个几何 token 的固定布局；缺失相机保留槽位并由有效性掩码排除。
  • 架构：基于 Molmo2-ER 36 层主干，追加 12 个 transformer 块（复制前 12 个预训练块初始化）构成几何变化扩展；GeometryReader 用可学习 query 池化 GC 隐状态，并通过零初始化输出投影的交叉注意力残差注入选定的 ActionExpert 块，保证初始化为恒等映射。
  • 动作表示：统一为 14 维双臂末端执行器 delta（每臂 3 维平移 + 3 维旋转 + 1 维夹爪指令），缺失维度掩码处理。
  • 梯度路由课程：Stage 1 仅几何 token 交叉熵损失、无 ActionExpert；Stage 2 加入动作流匹配损失但在 VLM 接口处阻断动作流梯度；Stage 3 移除 detach 边界，动作梯度更新可训练 VLM 组件与 ActionExpert。
  • GCRF 细节：上下文 c_t = [v̄_base; g_GC; h_flow] ∈ R^96（各 32 维），有界修正 d_t = ε·tanh(z_t)，在 10 步积分中保持恒定；路由器由闭环结果监督训练，推理只用观测特征。

Card 06 评估与结果

评估与结果

  • 评估环境与协议：LIBERO 基准，4 个 suite（LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long），每 suite 10 个任务，每任务 50 个固定初始状态，共 2,000 次 rollout；使用固定初始化、seed 1000、batch size 5。
  • 主要指标：episode 成功率与各 suite 平均成功率；表示探针报告动作块 MSE、R² 与操作阶段分类准确率。
  • 关键结果：

- GC-VLA（Stage 1–3）：1,904/2,000 = 95.20% 成功率。

- GC-VLA + GCRF：1,991/2,000 = 99.55%（相对基线 +87 次成功、+4.35 个百分点）。

- 直接训练消融：当前深度 VQ 监督 82.1% → 几何变化变体（200 个 head+wrist 深度 delta token）86.1%（+80 次成功，+4.0 pp），证明增益来自目标设计本身而非分阶段课程。

- 表示探针：冻结 GC 表示在操作阶段解码上从 86.9% 提升至 90.6%（+3.7 pp），动作块 R² 从 0.512 提升至 0.532（+0.020，95% CI [+0.004, +0.037]）。

- 目标编码器证据：DA3–DINO 特征差的 AUROC/AP 为 0.937/0.762，显著优于仿射对齐直接深度（0.730/0.408）与 VQ 深度（0.712/0.421）；静态区域假阳性率 0.027（对比 0.092 与 0.093）。

- 对比基线：与 ABot-M0.5（99.4）、Being-H0.5（98.9）、PhysBrain 1.0（98.8）、Xiaomi-Robotics-0、RLinf-GRPO 等方法在 LIBERO 四套件上进行比较（论文指出因数据、接口与评测实现差异，该表不作为受控泛化对比）。
