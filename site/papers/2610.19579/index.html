Card 03 核心贡献

核心贡献

  • 形式化黑盒访问下的部署时策略改进问题，并提出 liveness filtering：外部 wrapper 短暂干预，将固定名义策略恢复到其成功 basin。
  • 提出实时实例化：单一策略条件 liveness value 同时用于监控执行和引导纠正规划，并在紧凑 latent world model 中搜索动作，使用数据 informed action proposal 提高搜索效率。
  • 在 LIBERO-Goal 十任务套件上将 π0.5 从 72.6% 提升至 81.5%，优于 offline-RL 和 safety-filtering 基线。
  • 在 Franka Panda 机械臂上使 diffusion policy 从 40% 提升至 60%，并保持实时控制（规划周期 108 ms，循环 >10 Hz）。
  • 方法仅需稀疏 episode-level 成功/失败标签和黑盒策略查询，无需访问策略参数或内部表示。
Card 04 方法描述

方法描述

  • 采用 monitoring-and-intervention 框架：名义策略默认执行，monitor 检测到进展丧失时触发 fallback planner 进行短时纠正，随后交还控制。
  • Monitor 使用策略条件 liveness value function V_{π_b}，通过带 min 算子的 Bellman 更新从 on-policy rollouts 学习，并集成 ensemble、时间平滑和随时间衰减的阈值来减少误报。
  • Planner 学习一个 29.6M 参数的四层 ViT world model φ，在紧凑状态表示上自回归预测下一状态；使用 CEM 优化动作序列，目标是最小化沿想象轨迹的累积 liveness value。
  • 动作采样采用 数据 informed proposal：从训练动作块估计经验协方差，用 PCA 主成分生成时间相干扰动，避免不可行动作导致 world model 被利用。
  • World model 训练使用策略 rollouts 和辅助 play data，并采用 rollout-length curriculum 自回归训练（从 1 到 16 步）。
Card 05 数据集与资源

数据集与资源

  • 主要评估环境为 LIBERO-Goal 十任务套件，扰动初始机械臂配置和物体位置；硬件实验使用 Franka Panda 机械臂。
  • 名义策略包括 π0.5（LIBERO checkpoint）和 diffusion policy。
  • 每个任务收集 200 条 π_b rollouts（每条最多 300 步），提供稀疏 episode-level 成功/失败标签；补充 53 分钟 LIBERO-Goal 示教数据作为 play data。
  • World model 参数量约 29.6M；π0.5 约 3.3B 参数（用于白盒参考 Filtered-BC 微调）。
  • 训练在单张 NVIDIA GeForce RTX 4090 GPU 上进行；部署规划周期 108 ms，amortized 后监控-规划循环 >10 Hz。
Card 06 评估与结果

评估与结果

  • 评估基准为 LIBERO-Goal 十任务套件，每任务 300 个配对 episode；另在 Franka Panda 硬件上测试。
  • 主要指标为任务成功率、干预的 Rescued/Broken 次数及差值 Δ。
  • 十任务上，π0.5 从 72.6% 提升至 81.5%（+8.9pp）；monitor 在 94% 的失败 trial 上触发，仅在 16% 的成功 trial 上触发；共拯救 369 次失败，破坏 102 次成功，净增 267 次成功。
  • 四任务对比：本方法平均 80.9%，优于 LatentSafe（59.2%）、IQL（42.2%）、TD3+BC（39.6%）；接近白盒参考 Filtered-BC（78.2%），且可叠加提升至 79.8%。
  • 任务 0 提升最大（+27.0pp），任务 2 唯一退步（-1.0pp，world model 对细酒瓶抓取产生幻觉）；任务 7 接近天花板。
  • 硬件实验中，diffusion policy 从 40% 提升至 60%；增加 50% 扰动仍保持增益；消融验证 ensemble、时间平滑和阈值 schedule 的作用。
