Card 03 核心贡献

核心贡献

  • 首次对 VLA 模型在单步扰动下的鲁棒性进行系统性研究，发现关键时间步的扰动可造成 50 个百分点以上的性能下降。
  • 分析并指出动作分块执行长度（execution length, H）是放大单步扰动影响的关键因素，执行长度越长，鲁棒性越差。
  • 提出 CARE（Consistency-Aware Robust Execution length selection），一种基于动作块预测一致性的自适应执行长度选择方法。
  • CARE 无需额外训练、无需额外策略推理、不改变模型架构，可广泛适用于各类预测动作块的 VLA 模型。
  • 在多个模型、多个基准和真实机器人上验证 CARE 能显著提升鲁棒性且基本保持干净任务性能。
Card 04 方法描述

方法描述

  • 在每一步推理时，将当前新预测的动作块与上一次预测中尚未执行的部分进行比较，作为"干净动作"的代理参考。
  • 通过不一致度函数 D(·,·) 判断是否需要缩短执行长度：不一致度大则说明观测或预测不稳定，采用短执行长度；否则保留长执行长度。
  • 不一致度函数基于归一化欧氏距离：r_i = \|\|a_{t+i} − â_{t+i}\|\|₂ / (\|\|a_{t+i}\|\|₂ + \|\|â_{t+i}\|\|₂ + ε)。
  • 采用折扣累积不一致度 D = Σ γ^i r_i（γ∈(0,1)），强调持续多步的不一致，抑制单步跳变（如夹爪开合翻转）带来的过度反应。
  • 执行长度选择公式：H_t = max{H ∈ {1,…,H_max} \|D(A_t^{1:H}, Â^{…}) ≤ τ}，其中 H_max = ⌊K/2⌋，与现有 VLA 部署中执行长度小于动作块一半的惯例一致。
  • 创新点在于首次将时间一致性用于自适应执行长度选择，从而在扰动时缩短执行长度以限制错误动作的持续影响。

Card 06 评估与结果

评估与结果

  • 评估协议：对每个推理步作为独立 rollout 的干预时刻，每个 episode 仅施加一次扰动；每个模型、任务、扰动在每个干预步运行 10 个 episode。
  • 扰动类型共 8 种：图像类（Overexposure、Blackout、Motion blur、Packet loss）、状态类（Zero fill、State spike、Random state）、图像+状态类（Data loss）。
  • 主要指标：干净成功率与 Bottom10%-SR（所有干预步成功率中最低 10% 的均值），用于衡量最脆弱时刻的表现。
  • 关键发现 1：所有评估模型在至少一种扰动下 Bottom10%-SR 比干净成功率低 超过 50 个百分点，如 X-VLA 在 State Spike 下从 96.4% 降至 2.8%（↓93.6）。
  • 关键发现 2：扰动影响强烈依赖发生时机，越早的扰动通常造成更严重的下降（可能与模仿学习中的误差累积有关）。
  • 关键发现 3：执行长度越长，扰动影响被放大越明显；H=1 时差距最小（每步可重新规划）。
  • 基线方法：RobustVLA、VLA-Corrector、AAC。
  • CARE 效果（LIBERO，Table 2）：π₀ 干净性能 70.9→72.5，状态扰动 Bottom10%-SR 由 5.9→51.2、13.8→47.4、19.6→50.5；π₀.₅ 在 Data loss 下由 47.2→92.4；π₀-FAST 在图像扰动下由 44.4→62.5、45.0→63.4。
  • CARE 在大多数模型上基本保持干净任务性能，部分模型（如 π₀、π₀.₅）干净性能甚至略有提升。
