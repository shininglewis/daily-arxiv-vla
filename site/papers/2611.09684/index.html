论文概述

Card 03 核心贡献

核心贡献

  • 提出轻量级转置卷积概率动作解码器，用局部相关的离散动作 bin 建模平移/旋转的空间不确定性，并支持基于期望的并行快速解码，无需迭代去噪。
  • 引入 Soft-DTW 对齐监督，使策略能从容忍局部执行速度差异的示教中端到端学习，从而应对时间不确定性。
  • 在 LIBERO、RoboTwin 2.0 与真实世界六任务基准上验证：以更少优化步数或更少数据取得更强性能（例如 10k 步达 97.0% 平均成功率，超过 50k 步的 OpenVLA-OFT）。
  • 额外给出推理效率分析（仅 16.93M 参数、10.96G FLOPs，1.57 ms/动作块）与数据效率、消融实验，说明两类不确定性建模互为补充。
Card 04 方法描述

方法描述

  • 骨干网络：基于 OpenVLA-7B，输入图像观测、本体状态与语言指令，输出动作 token 块（k×d_a×d_VLM）。
  • 概率动作解码器：先用分组 1×1 卷积融合 token，再分为平移、旋转、夹爪三支；平移与旋转分支经两层 Deconv Block（深度可分离转置卷积 + 逐点残差层）把有序 bin 轴上采样 1→R/4→R（R=256），softmax 得到各 bin 概率，再以 bin 中心求期望解码为连续动作；转置卷积的权重共享为“相邻 bin 应获得相关证据”提供了关键归纳偏置。
  • 夹爪维度：因空间不确定性弱，改用轻量 MLP 解码。
  • Soft-DTW 对齐：对去掉夹爪维后的累积轨迹计算两两代价，用可微 softmin（温度 γ 控制平滑度，训练中退火）替换 DTW 的硬最小；采用 Soft-DTW 散度（减去自相似项）作为对齐损失。
  • 监督目标：L1 动作损失为主 + 弱权重 KL 正则（λ_KL=0.05，目标为以示教动作为中心的高斯离散分布）+ Soft-DTW 散度与终点损失（λ_DTW=0.5），联合优化。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四套件、RoboTwin 2.0 五个双臂任务、六项真实世界任务，另含推理效率、数据效率与消融分析。
  • 主要指标：任务成功率（%）、动作头参数量 / FLOPs / 单动作块解码延迟，以及不同数据比例下的成功率。
  • LIBERO：10k 步、batch size 48 下平均 97.0%（Spatial 99.0 / Object 99.2 / Goal 98.8 / Long 91.0），比同预算 OpenVLA-OFT（87.1%）高 9.9%，并超过 50k 步的 OpenVLA-OFT（94.3%）2.7%。
  • RoboTwin 2.0：20k 步、BS 16 下平均 72.2%，比最强基线 π0 高 12.0%，比 OpenVLA-OFT 高 13.0% 且只用 20k vs 100k 步；Click Alarm Clock 100.0%、Lift Pot 98.0%。
  • 真实世界：平均 57.5%，比训练 50k 步的 OpenVLA-OFT（41.7%）高 15.8%，仅用其 40% 优化步数；Toy Duck 从 45% 提升到 95%。
  • 推理效率：标准实现 1.57 ms（相对 π0.5 12.7× 加速），同框架 JAX 版 0.69 ms（28.8× 加速），参数量仅为 π0.5 的 3.9%、FLOPs 的 13.8%。
  • 数据效率：仅用 25% 示教即达 95.0%，超过全量数据下 OpenVLA-OFT 的 94.4%；10% 数据仍达 93.8%。
  • 消融（LIBERO-Spatial, 10k 步）：完整模型 99.0%；去掉 Soft-DTW 为 97.4%；去掉概率解码器为 96.8%；两者都去掉降至 94.4%，说明空间与时间不确定性建模互补。
