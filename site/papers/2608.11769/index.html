研究单位

  • 作者为 Chaeyeon Jung 和 Juyoun Park（通讯作者）
Card 02 论文概述

论文概述

  • 本文研究 VLA（视觉-语言-动作）策略在人形机器人双臂操作中的初始位姿依赖（initial-pose dependence）问题，发现任务级聚合成功率会掩盖位姿特定的失败和不恰当的手部选择行为。
  • 论文首次将这种由初始条件决定的早期手部偏好定义为"策略诱导的手部先验"（policy-induced hand prior），并提出 HandPriorScore 指标对其进行量化诊断。
  • 研究通过17种初始位姿、9种训练配置和双向关节级干预实验，系统分析初始位姿-策略交互、腕部相机影响、位姿覆盖与训练数据组成对鲁棒性的作用。
Card 03 核心贡献

核心贡献

  • 提出并形式化策略诱导手部先验概念，定义三个量化指标：HandPriorScore（归一化左右动作偏差）、残差手部偏置（H_prior）和目标响应性（H_target），用于诊断初始条件依赖的手部选择行为。
  • 通过双向关节级干预实验识别特定初始手臂配置（R_arm,3 和 R_arm,5）作为姿势条件手部先验的因果控制手柄，交换这两个关节值可双向抑制或诱导非对称手部偏好。
  • 证明位姿多样化（从2个目标耦合位姿扩展到8个多样化位姿）将平均成功率从5.8%/14.2%提升至63.3%/72.5%（A1/A2），针对性增强（在低性能位姿附近增加2个采集位姿）将 right_real 位姿成功率从30%提升至75%。
  • 系统比较腕部相机观测、真实/辅助数据组成和仿真采样比例对初始位姿鲁棒性的影响，发现腕部观测整体有益但会强化局部错误手部偏好，足够的仿真任务暴露是关键因素。
Card 04 方法描述

方法描述

  • 基于 GR00T-N1.5-3B 基础模型进行微调，以 Unitree G1 人形机器人和 Dex3-1 灵巧手为实验平台，PickApple（摘苹果）为目标任务。
  • 定义初始决策窗口（T=120时间步）内的相对关节动作（Δa_t = a_t - q_t），通过归一化左右侧手臂与手部动作幅度计算 HandPriorScore，并分解为残差偏置和目标响应性两个分量。
  • 采用物理一致的闭环关节交换干预：在行为不同的初始位姿之间交换选定手臂关节值，同时保持其余关节不变，测试局部状态变化能否切换策略的手部选择行为。
  • 采用配对腕部相机遮挡分析（左、右、双腕掩码），结合视觉、中间token和预测动作的余弦距离分析，区分腕部观测的输入通道敏感性与因果贡献。
  • 通过PCA投影设计多样化初始位姿集和超出训练分布的合成位姿，评估位姿覆盖对泛化能力的影响。
Card 05 数据集与资源

数据集与资源

  • P_sim：仿真PickApple演示数据集，含8个多样化初始位姿，每个位姿配对左右侧苹果位置，共304个episode。
  • P_real：真实机器人PickApple遥操作数据（仅高位相机）。
  • 7-task：7个真实"拾取类"任务数据（仅高位相机）；13-common：13个任务、统一高位相机格式；13-all：13个任务、保留全部相机流（7个高位相机+6个高位与腕部相机）。
  • 训练配置9种：A1/A2（仅P_sim，高位/腕部相机）、B1-B3（P_sim+不同真实数据，自然采样比）、C1/C2（混合相机可用性）、D/E（重加权采样比约45.5%）。
Card 06 评估与结果

评估与结果

  • 评估协议：每个初始位姿-策略条件执行20次闭环滚动，共17个初始位姿、每种策略340次滚动；任务成功需完成抓取、运送、释放和抬臂全过程。
  • 初始位姿-策略交互：相同位姿在不同策略下成功率差异巨大（如pose_mean从15%到95%），同一策略在不同位姿间变化显著（如C2从10%到80%）。
  • teleop_default 位姿诊断：该位姿表现出强残差右手偏置和弱目标响应性；腕部掩码实验显示双腕掩码将成功率降至20%，右手腕掩码将左目标场景的右手尝试率从97.1%降至40.5%，但不能完全解释错误行为。
  • 关节级干预：交换 R_arm,3 和 R_arm,5 可将 teleop_default 的右手尝试率从7/8降至0/4，反向交换将 right_sim 从0/12提升至7/7；控制关节（R_arm,0/R_arm,6）交换无效果；四关节干预的"先验移除"效果在B1和C2策略间泛化。
  • 数据影响：腕部观测使整体成功率从61.5%提升至76.8%；自然采样下添加P_real略增至62.9%，但添加7-task和13-common降至40.3%和32.6%；仿真比例重加权（9.4%→45.5%）将整体成功率从40.3%提升至61.5%。
