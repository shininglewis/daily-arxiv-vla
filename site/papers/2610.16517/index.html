Card 03 核心贡献

核心贡献

  • 识别出在线 VLA 后训练中演化模拟器的可靠性瓶颈，并将其形式化为信任校准问题：想象 rollout 应按其估计可靠性影响策略学习。
  • 提出 MeRL 框架，将在线模拟器演化与两级信任控制（stage-level / chunk-level）结合，自适应地使用真实 grounded 更新与模拟器想象数据。
  • 给出理论分析：Proposition 1 证明想象代理进度分数的偏差随视觉预测误差沿 rollout 累积；Proposition 2 说明需联合控制想象比例 $\rho_s$ 与 rollout 视野 $h_s$。
  • 提出无 oracle 信任估计：用残差预测器 $g_\xi$ 对没有真实未来观测配对的递归想象 chunk 打分，且评分时冻结、不查询未来真值。
  • 提供受控消融、同协议外部对比、无 oracle 信任诊断以及真实机器人固定数据部署验证。
Card 04 方法描述

方法描述

  • 在线模拟器演化（Online Simulator Evolution）：模拟器由世界模型 $\mathcal{W}_\phi$（视觉预测）与奖励代理头 $\mathcal{Q}_\psi$（局部进度分数）组成，两者在每个在线阶段用当前策略采集的 grounded 轨迹更新。
  • 代理头监督信号：用截断的 success-to-go 目标 $q_t^{\star}(\tau)=z(\tau)\gamma_q^{\min(T-1-t,H_q-1)}$ 训练，模拟器总损失为 $\mathcal{L}_{\mathrm{sim}}=\mathcal{L}_{\mathrm{wm}}+\lambda_q\mathcal{L}_{\mathrm{proxy}}$。
  • 阶段级信任调度（Stage-level trust）：复用已存 grounded 窗口做无额外环境交互的校准，聚合观测误差与代理误差为 $\bar{\varepsilon}_s$，经指数平滑得 $\tilde{\varepsilon}_s$，再映射为非增的想象数据比例 $\rho_s\in[0,1]$ 与想象视野 $h_s$；模拟器越不可靠，想象越少、视野越短。
  • 块级信任回放（Chunk-level trust）：对每个想象 chunk 估计可靠性误差 $\varepsilon_{s,i}$，转换为回放概率 $p_{s,i}$（是否进入想象批次）与优化权重 $w_{s,i}$（梯度贡献强度）。
  • 混合策略优化：目标为 $\mathcal{L}_{\mathrm{MERL}}^{(s)}=(1-\rho_s)\mathcal{L}_{\mathrm{real}}^{(s)}+\rho_s\mathcal{L}_{\mathrm{imag}}^{(s)}$，真实与想象分支独立采样，共享同一 clipped 策略梯度形式。
  • 递归想象处理：当 $h_s>C$ 时在模拟器内递归调用策略；残差预测器 $g_\xi$ 每次模拟器更新后刷新，在想象与策略更新期间冻结，只使用预测残差而不查询未来环境状态。

Card 06 评估与结果

评估与结果

  • 评估指标：最终成功率 SR、归一化学习曲线面积 AUC、达到阈值的阶段数 S2T（S2T-H 为 Spatial/Object/Goal 的 S2T@80 与 Long 的 S2T@65 的平均，越低越好）。
  • 受控对比：SFT、MFRL、Static-MBRL、Static-MBRL+Trust、Online-Updated MBRL 与 MeRL，用于分离模拟器更新与两级信任的贡献。
  • 主要结果（LIBERO-PRO）：MeRL 达到 Avg. SR 79.7%、AUC 70.6、S2T-H 92.1；相对 MFRL（77.2 / 67.9 / 103.4），高阈值学习速度提升 10.9%；相对 Online-Updated MBRL（76.2 / 65.4 / 139.6），最终成功率提升 3.5 个点。
  • 外部对比（3 个训练种子）：MeRL 的 79.7±0.7 / 70.6±0.8 / 92.1±4.8 优于 SimpleVLA-RL（77.1±1.1）、WMPO†（75.4±1.2）与 WoVR†（77.8±0.9）；相对 WoVR 的配对 95% 置信区间为 $\Delta\mathrm{AUC}=2.2\,[1.2,3.3]$、$\Delta\mathrm{S2T\text{-}H}=-9.2\,[-15.4,-3.1]$。
  • 消融：仅加阶段级信任使 AUC 由 65.4 升至 68.4、S2T-H 由 139.6 降至 113.2；仅加块级信任使 AUC 达 67.6、S2T-H 降至 121.5；两者结合效果最佳，说明全局调度与局部回放控制互补。
  • 无 oracle 信任诊断：递归深度 2–4（$N=1500$）时 Pearson $r=0.68$、Rank-AUC $0.80$、ECE $0.067$、top-30% 低误差精度 $0.77$；深度 3–4（$N=900$）对应为 $0.64/0.77/0.074/0.74$，表明越深想象的预测能力减弱但仍可用。
  • 信任分箱策略效用：Top/Mid/Bottom 信任分箱的匹配精调策略 AUC 为 $69.9\pm0.8/68.3\pm0.9/66.7\pm1.0$，$\Delta_{\mathrm{Top-Bottom}}=3.2\,[2.0,4.4]$。
  • 真实机器人：从每任务 50 条演示做固定数据适配，两任务平均成功率达 80.0%；SFT 为 35.0%、MFRL 为 55.0%（Tab. 3）。
