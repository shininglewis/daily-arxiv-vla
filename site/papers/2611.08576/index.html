Card 03 核心贡献

核心贡献

  • 实证发现三条与既有假设相悖的规律：人类干预的门控是非马尔可夫的（基于轨迹进展停滞而非瞬时次优）、人类纠正是次优示范、纠正动作会随训练偏离学习到的策略（模式分歧）。
  • 提出 PAM（Progress-Aware Model）：一种基于价值进展（V*(s_t) - V*(s_t-k)）的非马尔可夫门控干预模型，与真实用户算法排名的 Spearman 相关系数达 ρ = 1.0，优于动作次优性与随机模型。
  • 提出 Q-OIL（Q-Optimistic Intervention Learning） 算法：把干预转移视为乐观探索引导而非最优监督信号，通过解耦评论家避免乐观奖励向非干预状态反向传播。
  • 在仿真、真人参与仿真、Franka Panda 真机及双臂 VLA 微调四类场景中验证：成功率提升 10–50%、人类干预成本降低约 30%。
  • 方法对底层离策略 RL 算法无关，可即插即用地扩展到预训练视觉-语言-动作（VLA）模型。
Card 04 方法描述

方法描述

  • 乐观奖励设计：在干预时刻 t-1 的转移上附加正奖励 r_bonus = b * 1(intervene)，把探索引导向人类纠正过的区域；随着训练收敛干预率 ρ_t → 0，奖励隐式退火，Q_Opt → Q_TD，不引入渐近偏差。
  • 解耦双评论家（关键创新）：任务评论家 Q_TD 仅用任务奖励与标准 Bellman 回归训练并提供 TD 目标；乐观评论家 Q_Opt 使用任务奖励加乐观奖励，但从 Q_TD 自举，从而把乐观性限制在干预转移上，避免灾难性过度乐观。
  • 策略优化目标：L_θ = -E[Q_Opt(s,a)] - λ·E[λ log π_θ(a\|s)]，即"乐观策略改进"加行为克隆正则（λ ≈ 0.1），后者在早期提供方向性信号。
  • PAM 门控模型：g(τ) = α if V*(s_t) - V*(s_t-k) < δ else β；通过网格搜索调 k, δ，纠正策略 π_h 使用约 50–70% 成功率的中间 RL 检查点模拟不完美纠正。
  • 实现细节：基于 JAX + RLPD 的离策略 actor-critic 框架；用 10–20 条示范热启动；VLA 场景基于 EXPO-FT 学习残差策略。

Card 06 评估与结果

评估与结果

  • 评估基线：HIL（干预入回放池）、HG-DAgger（将干预作为 BC 目标）、SIRIUS（加权 BC）、PVP（偏好人类动作的评论家损失）、RLIF（对干预前状态负奖励）、BC+RL。
  • 主要指标：任务成功率、学习效率（达到给定成功率所需交互步数）、人类干预次数与干预步数占比、执行吞吐（每千步成功数）、算法排名 Spearman 相关系数。
  • 仿真结果：在 PAM 模型下，Q-OIL 在 Robomimic 上以更少交互取得更高成功率；优于直接模仿、惩罚或简单将干预注入回放池的做法。
  • 真人参与仿真：Q-OIL 在两项任务上均优于所有基线；HG-DAgger 因过度模仿次优纠正而表现受限，HIL/RLIF 在交互预算内无法学会。
  • 真机结果：相比基线成功率提升 10–50%，人类干预成本降低近 30%，执行效率平均提升约 90%。
  • VLA 微调：Bag Assembly 全任务成功率 50% vs 0%，Coffee Pouring 70% vs 30%，且所需人类干预更少。
  • 消融实验：去除评论家解耦后，在较大乐观奖励 b 下性能显著退化（过度乐观）；Q-OIL 在 b ∈ [0.01, 0.5] 的 50× 范围内保持稳定，b=0 时退化为 BC+RL。
  • 局限：人类研究仅 8 名参与者、桌面操作任务；未来可扩展到非结构化环境与基于语言的语义干预。
