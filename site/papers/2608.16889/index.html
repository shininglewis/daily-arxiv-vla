Card 03 核心贡献

核心贡献

  • 提出 Baton，据作者称是第一个在 冻结 VLA 上端到端完成长时程机器人操作的 coding agent，仅依靠测试时探索和语言记忆，无任何梯度更新。
  • 设计 层次化子任务探索（Hierarchical Subtask Exploration）：先分解任务为子任务和交接边界，逐个短时程探索子任务，再逐层组合已验证单元，使探索成本从乘性变为加性，且失败可归因到具体阶段。
  • 设计 转换感知记忆（Transition-Aware Memory）：统一存储三类转换——子任务内部的 调用转换（invocation transition）、跨子任务的 交接转换（handoff transition）和 前瞻转换（lookahead transition），并形成可检查、可复用的 handoff contract。
  • 在 RoboMemArena 基准上，Baton 的任务成功率（TSR）提升 11.6 个百分点，累计成功率（CSR）提升 14.9 个百分点，超越当前 SoTA。
Card 04 方法描述

方法描述

  • 整体架构：LLM coding agent 编写程序控制机器人，使用解析式基元（逆运动学路径、夹爪控制等）处理非接触运动，仅在接触丰富阶段调用冻结 VLA 基元 VLA_ACT。
  • 层次化子任务探索：首先由 agent 将长指令分解为有序子任务链及 K-1 个 handoff 边界；每个子任务独立在短时程场景中 bootstrapping 探索，失败记录写入 failure memory，首个成功方案固化为粗粒度轨迹（含 staging 路径、调用条件、VLA 调用和终止检查），最后自底向上逐层组合验证。
  • 转换感知记忆：采用“节点-边”结构——节点保存子任务的失败记录和多个可竞争策略（rival strategies）；边保存边界上的 handoff contract，包括 entry condition（交接转换）和 execution constraint（前瞻转换）。
  • 关键 agent 角色：verifier agent 通过腕部相机判断场景是否满足调用条件，只有确认就绪才触发 VLA；scheduler agent 在子任务执行前读取剩余计划，检索满足后续约束的竞争策略。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboMemArena，指标为任务成功率 TSR（所有验证阶段完成）和累计成功率 CSR（完成阶段比例）。
  • 协议：探索在单一参考配置（seed 50）上进行，评估在两个保留配置（seed 51、52）上取平均；Harness VLA 基线使用整任务探索，预算为每个完整任务 20 个 episode。
  • 关键结果：Baton 平均 TSR 57.7%、平均 CSR 78.8%，超过最强报告系统 FrameSamp+Modul（TSR 46.1%、CSR 63.9%）以及 PrediMem + GT memory oracle（TSR 46.1%、CSR 64.8%）。
  • 类别分析：Baton 在 occlusion（50.0 vs 39.1 TSR）和 counting（68.8 vs 31.4 TSR）上提升最大；在 sequence 类别上，Baton 的 TSR 83.4% 略高于 FrameSamp+Modul 的 73.8% 但低于 Harness VLA 的 82.0% 的对比（实际 Harness VLA 82.0 低于 Baton 83.4）；Baton 将 73% 的已完成阶段转化为完整任务，为表中最高比例。
  • 对比 Harness VLA：整任务探索的 Harness VLA 平均 TSR 仅 26.9%，在 occlusion 任务上探索阶段从未成功；Baton 相同的预算下达到 57.7% TSR，证明子任务探索的有效性。
