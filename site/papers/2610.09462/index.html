Card 03 核心贡献

核心贡献

  • 提出 TMT，一种推理时 VLA 后门检测器，联合建模输入 token 结构和骨干网络的层间潜在动态。
  • 提出无需独立干净参考策略的自蒸馏策略净化方法，利用受害者策略在良性输入上的动作监督配对（良性/触发）观测的训练。
  • 将传统后门检测器及异常/失败检测方法适配为 VLA 后门检测器，并在三种 VLA 后门攻击下进行了系统评估。
  • 在 BadVLA、GoBA、DropVLA 三种攻击上，TMT 在未见任务上取得最高或并列最高的检测性能，并在真实机器人上验证了检测有效性。
Card 04 方法描述

方法描述

  • Token Manifold 分支：将输入 token 序列 X 送入以 flow-matching 目标训练的 velocity 预测网络 f_θ，以历史上下文 c 为条件学习良性 token 流形，用单次前向的预测误差作为异常分数。
  • Latent Transition 分支：为相邻层的潜在转移 Δ_ℓ 训练预测器 g_φ，并在通过 Transition Selection 选定的层 ℓ\* 处，对 top-K token 预测误差取均值作为一致性分数。
  • 动机：t-SNE 显示触发查询的 token 表征偏离良性簇但仍有重叠，因此需要结合层间动态一致性的互补证据。
  • 校准与在线检测：Token 分支阈值使用良性轨迹最大分数的 0.99 分位数 + MAD 边际；Latent 分支基于良性尾概率的负对数校准；任一分支超阈即触发告警。
  • 策略净化：教师为冻结的后门策略副本，学生在同一检查点初始化，通过执行教师良性输入动作生成配对观测，并最小化两项动作蒸馏损失。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO-10 长程操作任务套件（10 个任务），检测器用其中 3 个任务的良性 rollout 拟合，在其余 7 个任务上评估。
  • 模拟 victim 模型：OpenVLA-OFT、VLA-Adapter、π0.5。
  • 真实世界平台：Trossen Robotics WidowX AI 机械臂，部署 π0.5，采集四个任务数据。
  • 检测网络结构：velocity 预测器 f_θ 使用 4 个残差 MLP 块；transition 预测器 g_φ 使用 2 层、每层 8 头的 Transformer 编码器。
Card 06 评估与结果

评估与结果

  • 评估指标：rollout 级 TDR（触发器检测率）、FRR（误拒率）、AUC 及检测延迟（从触发器出现到首次告警的 policy query 数）。
  • 对比基线：STRIP、TeCo、DeDe、DUP-MS、TrustVLA，以及 Deep SVDD、RND、ReDiffuser、LogpZO、FIPER 共 10 个方法。
  • BadVLA：TDR 100%，FRR 0.57%，与 TrustVLA、ReDiffuser 并列最高，延迟最低（0.00 Query）。
  • GoBA：AUC 0.983、TDR 83.43%、FRR 8.57%，显著优于仅达 4%/4.86% TDR 的 STRIP、DUP-MS，且延迟仅 0.28 Query。
  • DropVLA：AUC 1.000、TDR 73.6%、FRR 0%，第二名 FIPER 仅 26% TDR。
  • 真实世界 GoBA 检测：AUC 100%、TDR 100%、FRR 0%。
  • 分支消融显示：在已见任务上 Token Manifold 分支覆盖更广，在未见任务上 Latent Transition 分支覆盖更广；净化后触发输入下原任务成功率提升至 92.2%–95.5%，良性输入成功率变化不超过 2.2%。
