GeoLAM: Learning Geometry-Grounded Latent Actions from Unlabeled Human Videos

2026-09-15 · 原文 · 翻译 · 2609.17099

GeoLAM 提出从无动作标签的人类视频中学习几何接地的潜在动作，并将其用于机器人操作控制。 论文要解决的问题是：仅靠视觉重建容易把可控操作运动与外观变化、相机运动纠缠在一起，且现有方法常依赖手部姿态、手部轨迹或机器人动作标注。 方法结合冻结的几何特征层次未来帧重建与训练专用的 4D 几何教师，学习连续潜在动作，再通过世界动作模型联合去噪潜在动作与可执行动作块。

Card 03 核心贡献

核心贡献

  • 提出 GeoLAM，一种从 action-free 人类视频中学习几何接地潜在动作的框架，无需显式手部姿态或轨迹标注。
  • 设计基于冻结几何基础模型特征层次的重建目标，并结合训练专用 4D 几何教师，监督 3D 位移、残差图像平面运动和表面朝向变化。
  • 引入可见性与置信度加权、运动加权空间池化，抑制不可靠估计和静态背景，鼓励潜在动作保留几何运动信息。
  • 将连续几何潜在动作接入世界动作模型，联合去噪潜在动作和机器人动作块；未来视频预测仅作为辅助训练任务，部署时无需几何教师或未来视频生成。
  • 在 LARYBench、LIBERO、RoboTwin 2.0 和真实机器人任务上验证有效性，尤其在 OOD 真实场景中显著提升成功率。
Card 04 方法描述

方法描述

  • 3D 潜在表示：使用冻结的几何基础模型 Depth Anything 3 和 GLD 多级重建解码器构建特征层次；浅层 GFM 特征经 stop-gradient 和状态编码器得到状态表示。
  • IDM/FDM 结构：逆动力学模型在状态差上操作，经位置感知 action queries 和确定性瓶颈输出连续 latent-action tokens；前向动力学模型根据当前状态和潜在动作预测未来浅层特征，并由冻结深层 GFM 与 RGB 解码器重建未来帧。
  • 4D 几何教师：训练时使用冻结的 D4RT 处理采样片段，构造包含场景归一化 3D 位移、残差 2D 运动、表面法向变化和残差运动幅度的教师目标。
  • 可靠性加权池化：基于可见性和置信度计算权重，并按运动幅度加权池化到粗空间区域，减少不确定轨迹与静态背景影响。
  • 训练目标：潜在动作预训练损失为像素重建损失与几何监督损失的加权和，先优化重建，再线性增加几何损失权重。
  • 世界动作模型：冻结潜在动作编码器提供转移目标；Video DiT 与 Action DiT 通过条件流匹配联合去噪潜在动作和动作块；使用 block-causal mask 和当前观测 anchor 缓存，推理时只依赖当前观测。
Card 05 数据集与资源

数据集与资源

  • 预训练数据：约 19,860 小时人类视频，来源包括 Egocentric-10K、EgoVerse、Ego4D、EgoLive、EgoDex、Something-Something V2、HoloAssist、EPIC-KITCHENS-100。
  • 数据使用方式：仅使用 RGB，时间步长采样为 {5,10,15,20}，不使用动作标注或相机参数。
  • 模型规模：IDM 与 FDM 各使用 8 个 Transformer 块；IDM 输出 4 个 latent-action token，通过 32 维确定性瓶颈。
  • 世界动作模型：视频分支初始化自 Wan2.2-5B（约 5B 参数）；动作专家 hidden width 为 1,024；动作 horizon H=32。
  • 训练资源：64 张 NVIDIA A800 GPU，bfloat16 混合精度；潜在动作模型训练 200,000 步，AdamW，学习率 1e-4，全局 batch size 2,048。
  • 下游机器人数据：LIBERO、RoboTwin 2.0，以及真实 Agilex Piper 机器人任务中的 100 条演示。
Card 06 评估与结果

评估与结果

  • 评估基准：LARYBench 潜在动作基准、LIBERO、RoboTwin 2.0，以及真实 Agilex Piper 桌面抓取放置任务。
  • 评估指标：控制回归 MSE、动作分类准确率、任务成功率、平均执行时间。
  • LARYBench：GeoLAM 在四个数据集上取得最低回归 MSE，平均 MSE 从 LAPA-DINOv3 的 0.60 降至 0.29，相对降低约 51.7%；平均分类准确率从 45.62% 提升至 71.22%，提升 25.60 个百分点。
  • LARYBench 分类细节：人类视频子集准确率 74.19%，机器人视频子集准确率 68.25%。
  • LIBERO：平均成功率 98.5%，匹配 LingBot-VA，超过 X-VLA 0.4 个百分点、Fast-WAM 0.9 个百分点；Long 任务成功率从 Fast-WAM 的 95.2% 提升至 97.8%。
  • RoboTwin 2.0：Clean 设置成功率 93.00%，Rand 设置 92.20%，平均 92.6%，超过 LingBot-VA 0.4 个百分点、Fast-WAM 0.8 个百分点。
  • 真实世界任务：ID 设置成功率 95.0%，与 Fast-WAM 持平；OOD 设置成功率 90.0%，比 Fast-WAM 的 65.0% 提升 25 个百分点，且 ID 到 OOD 仅下降 5 个百分点。
  • 消融实验：加入 4D 几何监督后，像素重建平均 MSE 从 0.46 降至 0.29，分类准确率从 68.76% 提升至 71.22%；定性结果显示几何监督可减少运动手部和工具周围的拖影。
