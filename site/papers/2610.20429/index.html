When Do Discrete Actions Make Good Continuous Controllers?

Card 02 论文概述

论文概述

  • 论文系统比较机器人策略中连续动作参数化与离散动作参数化，覆盖单任务从零训练、多任务 VLA 训练、仿真和真实机器人。

  • 核心问题是离散动作预测的瓶颈来源：并非量化精度，而是跨时间步和动作维度的因子分解误差（factorization error）。
Card 03 核心贡献

核心贡献

  • 系统比较 CR、CF、DR、DF 四种 action head 在单任务与 VLA 规模、仿真与真实场景中的控制性能。
  • 发现离散动作预测，包括最朴素的均匀分箱 DR，可以匹配甚至超过连续动作预测，并在多个基准上一致优于连续回归。
  • 识别离散策略的主要限制是因子分解误差：独立 token 预测会跨时间/动作维度组合不兼容模态。
  • 证明离散流（DF）的迭代计算和 classifier-free guidance（CFG） 可通过减少因子分解误差显著提升离散策略性能。
  • 表明显式注入几何信息或使用结构化 tokenizer 对离散策略的额外增益有限。
Card 04 方法描述

方法描述

  • 研究四种 action head：Continuous Regression (CR)、Continuous Flow (CF)、Discrete Regression (DR)、Discrete Flow (DF)。
  • CR 单次前向用回归预测动作 chunk；CF 用 flow matching 生成连续动作。
  • DR 将每个动作坐标均匀量化为 B=512 个 bins，用逐 token 交叉熵训练，单次前向分类预测。
  • DF 采用离散流匹配，从源分布迭代细化 token，通过多步计算引入位置间相关性。
  • 使用相对末端执行器（EEF）动作；VLA 旋转用 axis-angle 表示，RoboMimic 策略用 6D 旋转表示。
  • 分析工具包括 jerk ratio、state responsiveness、mode-mixture 计数和 translation quantiles，用于诊断时序变化与因子分解误差。
Card 05 数据集与资源

数据集与资源

  • 单任务仿真：RoboMimic 的 Can、Square、Tool Hang、Transport 任务。
  • VLA 仿真训练：混合 8 个数据源，包括六个 RoboCasa365 数据集（含 MimicGen 生成演示）、LIBERO-plus 和 DROID。
  • VLA 评估：RoboCasa（atomic-seen、composite-seen、composite-unseen）、LIBERO；DROID 用于离线诊断。
  • 真实世界任务：throw bottles into bins、open pen caps、turn mug up。
  • 模型：VLA 规模实验使用 PaliGemma VLM 作为 backbone 并后训练新 action heads；具体参数量和训练资源（GPU/TPU）未在给定原文中明确列出。
Card 06 评估与结果

评估与结果

  • 评估环境包括仿真与真实硬件；基准为 RoboMimic、RoboCasa、LIBERO、DROID 和真实任务。
  • 主要指标：闭环任务成功率、held-out 动作 ℓ2 预测误差、jerk ratio、state responsiveness。
  • 离散策略在多数设置中匹配或超过连续策略：DF 与 CF 竞争甚至略胜，DR 一致优于 CR。
  • 在 RoboCasa 汇总结果中，CFG 将 DR 成功率从 27.1% 提升到 49.2%，接近 DF 的 53.9% 和 CF 的 52.7%，高于 CR 的 38.8%。
  • DF 将每 chunk 不一致模态预测相对 DR 减少 5.28×，在 NFE≥10 时平均低于 1，并伴随 RoboCasa 成功率提升 4.7 个百分点。
  • 连续回归的 jerk ratio 明显小于 1（过度平滑），离散回归接近 1；离散策略更好地捕捉 chunk 内时序变化和对观测的响应。
