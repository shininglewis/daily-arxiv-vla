Card 03 核心贡献

核心贡献

  • 系统性实证研究：在 LIBERO 仿真基准的 40 个任务上，以及两个/三个站点采集的真实机器人数据上，对 π0.5、SmolVLA、GR00T N1.7 三种现代预训练 VLA 进行联邦微调研究。
  • 开源测试床 decent-vla：包含可复用框架（实验由单个 YAML 文件定义，新策略/聚合算法/运行时以插件形式加入）与固定划分、预算与评测协议的参考基准。
  • 得出可复用的经验结论：联邦范围（federated scope）而非聚合算法主导最终效果；跨站点标定异构使物理机器人上中心化微调仍占优。
  • 揭示联邦 VLA 学习的机会：在异构数据上可匹敌中心化微调、在分布偏移下至少与中心化同样鲁棒、并可通过部分联邦实现客户端个性化。
  • 发布所有报告数值对应的配置，支持公平比较与精确复现。
Card 04 方法描述

方法描述

  • 设定 K 个站点（客户端），各持有私有演示数据集 D_k（不可离开本地），均从同一预训练 VLA θ⁰ 出发，目标是在任务并集上得到单一全局策略。
  • 每轮流程：服务器广播联邦范围 S 内的参数 → 各客户端在本地数据上执行模仿学习更新 → 服务器聚合上传的更新（含样本数 n）得到全局参数。
  • 联邦范围可选全模型、LoRA（r=64, alpha=128）或模块级（action head 或 backbone），兼顾通信开销与个性化（S 之外的参数可留作本地个性化）。
  • 聚合算法对比 FedAvg、FedProx、FedAdam。
  • 解耦设计：一个通用控制器驱动轮循环，策略后端（openpi / lerobot / groot）与执行后端（local / flower / nvflare）独立插拔。
  • 工程细节：客户端仅上传 bf16 权重增量，服务器维护 fp32 主副本以稳定多轮混合精度训练；聚合按策略声明的 scope 执行；客户端划分由配置中的随机种子推导，保证可复现。
  • 研究围绕五个问题展开：Q1 联邦 vs 中心化、Q2 联邦范围、Q3 聚合算法、Q4 分布偏移鲁棒性、Q5 向物理机器人迁移。

数据集与资源

  • 仿真数据集：LIBERO，含 Spatial / Object / Goal / Long 四个套件，共 40 个任务、1,693 条演示、273,465 帧。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 仿真的 40 个任务、真实 SO-101 机器人实验，以及将同一检查点在与某一站点标定的仿真环境中重评（real-to-simulation），以获得可重复的布局与分阶段成功率。
  • 主要指标：任务/分阶段成功率，以及在不同联邦范围、聚合算法与分布偏移条件下的相对表现。
  • 关键结果：

- 当策略预训练较强时，联邦微调可匹敌中心化微调。

- 联邦范围主导结果，聚合算法影响次要；为异构客户端设计的 FedProx、FedAdam 在同等轮数预算下并未优于 FedAvg。

- 在真实机器人上，站点的标定异构超出仿真所能体现的程度，使中心化微调保持领先。

- 在分布偏移下，联邦微调至少与中心化微调同样鲁棒。

- 个性化（客户端只联邦策略的一部分、其余参数本地保留）在预训练较弱处有帮助，但会失去可用的全局模型。

  • 论文明确将 decent-vla 开源，以支持后续研究的公平比较。
