DIVA: Dual-Space Intent-Aware Visual Attenuation for Vision-Language-Action Policies

2026-10-06 · 原文 · 翻译 · 2610.09144

论文针对 Vision-Language-Action (VLA) 策略中密集视觉 token 缺乏显式相关性调控的问题，提出 DIVA 模块。 DIVA 采用 anchor-then-attenuate 设计，结合高层任务意图与低层视觉证据估计 patch-wise 相关性锚点，并在输入空间和潜在空间进行非破坏性视觉衰减。 目标是在保留完整场景上下文的同时，弱化任务无关视觉证据对策略计算的影响，提升标准与扰动条件下的操作鲁棒性。

Card 03 核心贡献

核心贡献

  • 识别密集 token VLA 策略的关键限制：缺乏根据任务相关性显式控制视觉 token 影响的机制。
  • 提出 DIVA 框架，通过 Grounded Text Pooling 和 Intent-Aware Visual Relevance Anchoring 构建 patch-wise 相关性锚点，并应用于输入与潜在双空间。
  • 设计 Dual-Space Visual Attenuation：输入空间重加权投影视觉 token，潜在空间跨层持续衰减低相关性视觉隐藏状态。
  • 在 LIBERO、零样本 LIBERO-Plus 和真实机器人任务上验证 DIVA 在标准与扰动条件下均带来一致增益。
  • 通过消融实验验证 Grounded Text Pooling、意图感知锚定和双空间衰减的互补作用。
Card 04 方法描述

方法描述

  • DIVA 是在 OpenVLA-OFT 上实例化的模块，整体遵循 anchor-then-attenuate 流程，不改变原始视觉 token 序列长度。
  • Grounded Text Pooling (GTP)：用局部视觉 patch 证据衡量每个指令 token 的局部支持度，对比均匀视觉基线，得到观察条件化的紧凑任务意图表示。
  • Intent-Aware Visual Relevance Anchoring：将每个视觉 token 与任务意图表示拼接，通过轻量自注意力模块估计上下文相关的 patch-wise 相关性锚点 α_i ∈ [0,1]。
  • 显式输入空间衰减：在骨干入口前按 α_i 重加权投影视觉 token，即 v_i' = α_i v_i。
  • 隐式潜在空间衰减：当 α_i < θ 时，对骨干各层中对应视觉隐藏状态进行插值衰减，即 m̃_i^ℓ = (1-λ)m_i^ℓ + λ(α_i m_i^ℓ)，阈值以上状态保持不变，保留非零上下文。
  • 训练目标：结合动作模仿损失 L_act 与相关性预算损失 L_budget，鼓励锚点平均相关性接近目标值 ρ，避免所有 token 被赋予高相关性或过度稀疏。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（Spatial、Object、Goal、Long 四个套件）和 LIBERO-Plus（七种扰动：相机、机器人状态、语言、光照、背景纹理、传感器噪声、物体布局）。
  • 真实世界平台：UFACTORY UF850 机器人，使用第三人称和腕部 Intel RealSense 相机。
  • 基础模型：OpenVLA-OFT，DIVA 在其上进行实例化与微调。
  • 训练资源：仿真使用 8 NVIDIA L20 GPUs；真实机器人训练使用 4 NVIDIA L20 GPUs。
  • 训练配置：仿真 160K 步，真实机器人 30K 步；LoRA rank 32，action chunk length 8（仿真）/ 25（真实），batch size 64（仿真）/ 32（真实）；DIVA 模块仅在最后 10K 步激活。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 标准基准、零样本 LIBERO-Plus 扰动基准、真实 UF850 机器人操作任务。
  • 评估指标：任务成功率（%）；LIBERO 每任务 50 个 episode，共 2000 个 trial；LIBERO-Plus 每个变体执行一次，按任务加权计算总分。
  • 主要结果：在 LIBERO 上，DIVA 将 OpenVLA-OFT 的平均成功率从 96.6% 提升至 98.0%，四个套件均优于基线。
  • 零样本 LIBERO-Plus：DIVA 将任务加权总分从 69.6 提升至 72.6，在相机、光照、噪声、背景和布局扰动下均有提升。
  • 真实世界：在标准、未见物体和未见背景条件下，DIVA 在多个任务中完成更多成功试验，尤其有利于区分相似物体和抗干扰。
  • 消融与稳健性：双空间衰减优于仅显式或仅隐式；Grounded Text Pooling 优于均值池化和仅视觉锚定；五种子结果为 98.00 ± 0.39%（LIBERO）和 72.60 ± 0.43%（LIBERO-Plus）。
