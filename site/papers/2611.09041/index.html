Card 03 核心贡献

核心贡献

  • 提出 DobotTrack 目标锚定跟踪框架，并系统比较了五种辅助任务：人物分割、边界框定位、视觉-空间分类（VSC）、未来 DINO 特征预测、未来帧预测；最终采用互补的掩码 + 边界框监督。
  • 提出 Q-identity，一个以目标为条件的历史视觉压缩模块，利用目标定位预测在紧凑历史 token 中保留身份判别性外观特征与空间线索。
  • 构建四足机器人真实跟踪数据集，包含 126 个跟踪 episode、596,323 帧带掩码标注，并设计从掩码自动推导边界框与结构化 VSC 标签的标注流程，无需额外人工标注。
  • 在 EVT-Bench 上，仅 0.8B 参数的模型平均成功率达 77.9%，比 OmTrackVLA 高出 16.9 个百分点。
Card 04 方法描述

方法描述

  • 主干基于 InternVL3 视觉-语言模型；视觉编码器与多模态投影器将每帧 RGB 观测映射为 256 个视觉 token，语言模型融合指令与时间序列做时序推理。
  • 输入为 H=8 帧、采样间隔 Δ=0.2s（5Hz）的 RGB 历史窗口，输出 P=8 个 10Hz 的未来自我中心路点（0.8s 预测视野），每个路点为平面位姿 (x, y, θ)。
  • 三类任务头：分割头结合 mask token 隐状态与当前帧稠密特征，经 SAM2 掩码解码器输出前景概率图；框头回归归一化边界框 (c_x, c_y, w, h) 与可见性；动作头回归路点。
  • 因果序列中 mask token 与 box token 排在路点 token 之前，使轨迹预测能通过因果注意力关注目标监督表征；一次前向即可同时输出掩码、框、可见性与轨迹。
  • Q-identity 将每帧历史压缩为 N_q=16 个 token：先用目标区域特征与可学习查询做目标条件自注意力，再与全图特征做交叉注意力，经 3 个注意力块输出；窗口总视觉 token 由 2048 降至 368（7×16+256）。
  • 训练时用扰动后的真值框确定目标区域（扰动概率 0.8），并以 0.3 概率压缩当前帧；推理时用缓存的框与可见性预测选择目标区域，可见性低于 0.5 时回退到无目标 token。
  • 总损失为轨迹损失（加权 MSE，权重 x:y:θ = 1:3:2）、分割损失（BCE + Dice + IoU-score + 物体存在性）与框损失（SmoothL1 + GIoU + 可见性 BCE）之和，λ_seg=0.001、λ_box=0.01。
  • 视觉编码器冻结，联合优化多模态投影器、语言模型、Q-identity 与各任务头。
Card 05 数据集与资源

数据集与资源

  • 仿真数据：基于 EVT-Bench（Habitat 3.0 + HM3D/Matterport3D 室内场景），约 180 万序列样本，STT:DT:AT = 1:2:1。
  • 真实数据：四足机器人采集，约 10.2 小时跟踪数据、596,669 帧原始 RGB，经位姿对齐与轨迹预处理后得到 565,994 个训练样本；分辨率 960×540；含 33 个目标外观档案（24 女 / 9 男）。
  • 标注使用 Qwen3.5 定位目标生成框提示，再由 SAM3 生成掩码，最后人工校验修正。
  • 模型规模：0.8B 参数（对比基线含 1B、3B、4B、7B、8B 等模型）。
  • 训练资源：8 块 NVIDIA B300 GPU，全局 batch size 256（每卡 32），约 28,000 步优化，AdamW + BF16 混合精度，学习率 2e-5（语言模型与 SAM2 解码器）/ 4e-5（其余），100 步 warmup + 余弦退火。
Card 06 评估与结果

评估与结果

  • 评测基准为 EVT-Bench 的 STT（单人跟踪）、DT（干扰跟踪）、AT（歧义跟踪）三种设置；指标为成功率 SR、跟踪率 TR、碰撞率 CR。
  • 主要结果：STT 上 SR/TR/CR = 90.2 / 92.3 / 3.6；DT 上 72.5 / 83.3 / 8.3；AT 上 70.9 / 85.5 / 6.6；平均成功率 77.9%，较 OmTrackVLA 提升 16.9 个百分点，且在仅 0.8B 参数下优于多个 4B/7B 模型。
  • 与纯轨迹基线对比：基线（0.8B，仅轨迹监督）DT 上 SR 为 55.9，加入框与掩码监督后提升至 72.5，AT 上从 52.4 提升至 70.9。
  • 辅助任务消融（DT 设置）：仅轨迹 SR 55.9；+Box 59.6；+VSC 59.6；+Mask 61.3；+Box & Mask 63.7（最优）；+未来帧预测 60.9；+未来 DINO 特征预测 58.9。
  • 目标条件消融：掩码监督下不加目标条件压缩 STT/DT/AT 的 SR 为 79.2/55.3/57.7，加目标条件后提升至 84.8/67.6/65.6；掩码+框联合并启用目标条件达 87.6/69.0/67.8。
  • 效率分析：在 Jetson Orin Nano（FP16、batch=1，含视觉编码器）上，token 数从 2048 降到 256 可使推理延迟下降约 52%，为端侧部署提供依据。
  • 论文还报告了真实世界场景的定性评估（室内单人、室内遮挡、室外开阔、复杂街道）以及掩码/框监督权重与 token 预算（256-token 池化、16-token 池化、16-token Q-identity）的对比实验。
