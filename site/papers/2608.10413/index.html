DriveVLA-M0: Failure-Aware Memory Augmentation for Autonomous Driving

Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出面向 VLA 自动驾驶的失败感知记忆增强框架，显式针对模型表现不佳的场景进行修正。
  • 设计结构解耦的检索机制，将静态道路结构与动态智能体交互分离，实现结构级场景检索而非纯视觉-语言语义检索。
  • 集成解耦 LoRA 的测试时训练（TTT）机制，实现高效、场景特定的在线规划修正，不修改主干网络参数。
  • 证明记忆与 TTT 的协同能显著提升鲁棒性、安全性与可扩展性，通过记忆扩展即可实现免训练的性能提升。
Card 04 方法描述

方法描述

  • Base Model：基于 InternVL3 的 VLM 骨干，通过 Q-Former 式压缩模块将 2800×1536 token 的中间特征压缩至 16×256（约 1050 倍压缩）；Action Decoder 包含 Trajectory Head 与 Score Head，采用 proposal-and-score 两阶段规划范式。
  • Retrieve Model：以 DINOv2 为特征提取器，采用解耦 LoRA设计，并行提取静态地图特征 F_map 和动态智能体特征 F_agent，并通过 occupancy grid 的 BCE 损失监督训练。
  • Memory Generation（离线阶段）：用 PDM 仿真评分识别失败场景（评分低于阈值 β），存储检索键、适配输入与监督标签到潜记忆池，并用余弦相似度去重控制规模。
  • Inference with TTT（在线阶段）：在测试时用 Retrieve Model 提取查询键，分别按地图和智能体层级检索 top-k 相似案例；基于余弦相似度触发门控，仅对评估有高失败概率的场景激活 TTT；用地图/智能体案例分别微调静态/动态 LoRA 分支，并按子分数类型选择对应分支的预测进行融合输出。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：NAVSIMv1（Navtest 评估集）与 NAVSIMv2（Navhard 评估集）
  • VLM 骨干：InternVL3，在自动驾驶问答数据上微调
  • Retrieve Model：预训练 DINOv2，LoRA 微调
  • TTT 延迟开销：仅 26.44 ms（每次测试场景的 LoRA 反向传播）
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIMv1（Navtest） 与 NAVSIMv2（Navhard），使用 PDMS/EPDMS 等指标。
  • 在 Navtest 上，DriveVLA-M0-Scale 达到 94.1 PDMS，超过既有 SOTA（如 iPad 91.7、Centaur 92.6、DriveSuprim 93.5）。
  • 在 Navhard 上，实现 47.0 EPDMS（摘要报告），在安全关键指标如碰撞避免（NC/TTC）与可行驶区域合规（DAC）上表现突出。
  • 消融结果表明：结构解耦检索优于纯视觉-语言检索；解耦 LoRA 的分支注入优于共享注入；记忆规模扩大带来额外性能提升，且无需重训练基础模型。
