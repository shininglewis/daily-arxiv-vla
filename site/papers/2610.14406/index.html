Card 03 核心贡献

核心贡献

  • 提出 Imprint：策略无关的潜在记忆框架，可压缩多流历史并在推理时增量更新，训练时先做历史重建与进度估计，再与策略联合微调。
  • 系统分析记忆容量、编码方式、训练目标和训练配方对下游任务性能的影响。
  • 在 RMBench、定制 RoboCasa 12 任务基准和 3 个真实世界任务上评估，验证多流记忆优于记忆策划方法。
  • 相比基础 VLA，在 RMBench 上提升 47.4%、真实世界提升 50%，并在记忆增强 VLA 中保持最低平均推理延迟 122.8 ms/动作块。
  • 证明该记忆框架可迁移到不同 VLA 主干，包括 π0.5、π0 和 MolmoAct2。
Card 04 方法描述

方法描述

  • 多流记忆编码：将历史表示为四个 token 流，即 历史视频、最近图像、已执行动作、本体感受状态。
  • 视觉压缩：使用冻结的因果视频 tokenizer 压缩历史视频，使用 DINOv3 编码最近图像；动作和状态通过独立 MLP 嵌入。
  • 记忆瓶颈：使用 B 个可学习 query embedding，在任务语言描述条件下读取四类 token 流，压缩为固定大小潜在记忆 m_t ∈ R^{B×d}。
  • 提供两种瓶颈：Full Attention 交叉注意力版本和 Recurrent 版本；后者使用 gated delta (GDN) 块更新固定大小矩阵状态，使存储和每步查询成本不随历史长度增长。
  • 第一阶段记忆预训练：解码器重建 K 个采样历史步的视觉特征、动作和本体感受状态，并预测任务进度 ρ_t；损失由 历史重建 与 进度估计 组成。
  • 第二阶段策略无关记忆适配：丢弃解码器，通过轻量 adapter 将记忆注入 VLA；动作 token 对记忆做交叉注意力并接受 FiLM 调制，联合微调编码器、adapter 和 VLA 的动作预测损失。
  • 关键创新：不预设记忆内容、直接监督多流记忆、用进度估计捕获任务阶段、用循环瓶颈保持低延迟、用 adapter 兼容不同 VLA 主干。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RMBench 的 9 个记忆依赖任务；基于 RoboCasa 和 ReMemBench 的定制 12 任务基准，含 6 个记忆任务和 6 个非记忆任务。
  • 真实世界任务：在双臂 YAM 平台上评估 Dust Table、Scan Bottle、Fold Cloth 三个记忆依赖任务。

  • 推理延迟在 L40S GPU 上测量；训练资源等细节位于原文附录 A.1.5，当前提供片段未展开具体 GPU/TPU 数量。
  • 评估规模：RMBench 每任务 100 次试验，RoboCasa 每任务 50 次试验；真实世界任务另有 OOD 物体评估。
Card 06 评估与结果

评估与结果

  • 对比基线包括无记忆 VLA π0、π0.5、MolmoAct2，以及记忆增强方法 Uniform Sampling、EventVLA、Mem-0、MemER、HAMLET、MemoryVLA。
  • 主要指标：任务成功率与每动作块推理延迟。
  • RMBench：Imprint 达 72.8% 成功率；启发式采样从 25.4% 提至 67.8%，层次化方法最高 42.0%，先前潜在记忆最高 41.7%。
  • RoboCasa：Imprint 在记忆任务达 65.3%，非记忆任务 68.0%，总体 66.7%；启发式记忆虽提升记忆任务约 15.3%，但使非记忆任务下降约 22%。
  • 真实世界：Imprint 在三个任务上分别达 80%、75%、72%；相比最强基线 Uniform Sampling 平均提升 26.7%；对未见物体的 OOD 成功率分别为 45%、70%、31%。
  • 推理效率：Imprint 平均 122.8 ms/动作块；HAMLET 为 144 ms、成功率 28.1%，MemoryVLA 为 321 ms、41.7%，EventVLA 为 960 ms、67.8%，层次化方法需数秒。
  • 多流消融：仅视觉 60.6%，视觉+动作 68.4%，视觉+状态 60.9%，全多流 72.7%，说明动作与状态等流提供互补信息。
  • 容量消融：记忆 token 从 1 增至 256，RMBench 从 67.0% 提至 72.7%；从 4 增至 256，RoboCasa 记忆任务从 54.0% 提至 61.0%；但 1024 token 虽重建损失最低，RMBench 反降至 70.0%。
  • 循环压缩：在 256 token 下，Recurrent Imprint 与 Full Attention 在 RMBench 均约 72.8%，并将 RoboCasa 总体成功率从 62.2% 提至 66.7%，延迟从 130.8 ms 降至 122.8 ms。
  • 训练消融：端到端动作监督 50.8%，仅预训练 58.8%，预训练+联合适配 72.7%。
  • 目标消融：完整重建+进度估计 72.7%；去掉进度估计 68.7%；仅视觉重建 66.9%；仅动作+状态重建 62.7%。
  • 策略无关性：同一记忆流程使 π0.5 从 25.4% 提至 72.7%，π0 从 17.4% 提至 63.0%，MolmoAct2 从 18.8% 提至 59.7%。
