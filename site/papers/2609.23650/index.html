Card 03 核心贡献

核心贡献

  • 将 VLA 可靠性问题重新表述为任务语义动作校准，提出一种非对称目标：语义保持编辑应使行为保持在同一动作盆地，语义破坏编辑应强制行为明确分离。
  • 提出 BAS-VLA 框架，包含默认的以破坏为中心的校准核心（breaking-centered calibration core）与可选的证据门控保持辅助模块（evidence-gated preserving auxiliary）。
  • 提出统一的干预分类法（preserving vs. semantic-breaking）与三条件协议（clean / control / break），在匹配载体、任务族与 rollout 预算下进行评估。
  • 在多种载体（OpenPI-pi0.5、OpenVLA-OFT）与基准（LIBERO-Object、LIBERO-Spatial、Bowl-on-Ramekin）上给出匹配对比证据，证明可靠的 VLA 行为需要显式的任务语义校准而非仅靠外观鲁棒性。
Card 04 方法描述

方法描述

  • 冻结基座策略 π₀: (oₜ, x, hₜ) → aₜ⁽⁰⁾，BAS-VLA 在动作输出层上组合校准模块：aₜᴮᴬˢ = P_φ(B_θ(aₜ⁽⁰⁾, oₜ, x, hₜ), oₜ, x, hₜ)。
  • 破坏中心核心 B_θ：使用残差校准器 r_θ 与冻结指令特征 z(x)，构造 aₜᵇʳ = aₜ⁽⁰⁾ + λ r_θ(aₜ⁽⁰⁾, z(x))，保持基座策略作为干净任务参考。
  • 训练使用匹配指令三元组 (xᶜ, xᵘ, xᵇ)，损失包含三项：L_imit（clean/control 贴近干净动作）、L_cons（clean 与 control 相互贴近）、L_sep（break 动作以间隔 m 远离干净盆地），总目标 L_br = L_imit + λ_c L_cons + λ_s L_sep。
  • 证据门控保持辅助：构造外观规范化探针视图 õₜˢᵗʸ = φ_sty(oₜ)（基于文本条件 grounding 与 SAM 2 掩码精化的任务感知视觉过滤探针），并以 τₜ = τ_phase(t,hₜ)·g_vis·g_sem·g_act 作为门控，分别衡量阶段、视觉偏移强度、语义一致性与动作层分歧。
  • 辅助模块采用弱融合而非硬替换：aₜᵖʳᵉˢ = (1−ατₜ)aₜ⁽⁰⁾ + ατₜ aₜˢᵗʸ，当 τₜ=0 时退化为基座原始动作，保证有界修正。
  • 三种部署模式：默认（仅破坏核心）、仅保持辅助、以及用于消融的完整组合（在破坏核心动作上再做门控弱融合）。
  • 附录提供形式化性质：分离间隔推论（Prop. 1）、残差漂移界（Prop. 2）、门控取值与恒等情形（Prop. 3–4）、各部署模式开销（Prop. 5）。

Card 06 评估与结果

评估与结果

  • 主要评估：OpenPI-pi0.5 / LIBERO-Object Milk-Swap，在 BAS-VLA 下保持 98.0% clean 成功率与 97.5% control 成功率，同时将破坏条件下的干净任务成功率降至 0.0%，体现强陈旧任务抑制与任务语义分离。
  • 风格偏移：Bowl-on-Ramekin 上风格偏移成功率由基线 42.0% 提升至 70.0%（+28.0 pts），同时干净成功率由 97.0% 微升至 97.5%，未出现退化。
  • 动机性证据（表 1，方法前）：OpenVLA-OFT 在 LIBERO-Spatial 上从边缘杂乱 98.0%→65.0%（−33.0）、margin noise 97.0%→51.0%（−46.0）；OpenPI-pi0.5 在 LIBERO-Object 上光照变化 98.0%→89.0%（−9.0）、目标物体交换 98.5%→34.0%（−64.5）。
  • 语义破坏结果（表 4）：BBQ-Swap clean 90.0% / control 92.5% / break(clean) 0.0%，Ctrl.-Break gap 92.5；Ketchup-Swap 88.0% / 92.0% / 0.0%，gap 92.0；Milk-Swap 98.0% / 97.5% / 0.0%。
