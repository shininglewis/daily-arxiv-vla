Card 03 核心贡献

核心贡献

  • 提出 World Dreamer v5-lite 多机器人操作框架：由预训练视频编码器的标定多视角特征构建共享世界状态 φ，供所有机器人读取；并通过位姿感知的智能体查询（pose-aware agent queries）实现机器人间信息交换。
  • 提出掩码视角协同训练（masked-view cooperative training）：在两条视觉分支上同时遮蔽部分相机视角，但保留全部动作监督，迫使机器人利用队友共享的观测。
  • 在 RoboFactory 与四个真实机器人任务上取得所评估方法中的领先性能，平均成功率分别超出最强基线 23.7 与 13.8 个百分点；在 RoboCasa365 上取得有竞争力的结果。
  • 设计了“读取—解码—通信”顺序的动作解码器（Field Injection / Scene Decoder / Agent Interaction 三个模块），在保留机器人专属动作流的同时实现跨机器人协同。
Card 04 方法描述

方法描述

  • 视觉-语言条件化：VLM 处理指令与当前图像，并在固定布局中预留 N 个机器人槽位，每个槽位接一个可学习查询，输入为 r_i = q_shared + e_i；一次 VLM 前向即产出共享场景前缀 KV 缓存与每个机器人的隐藏状态（投影为解码器初始查询 q_i^0，维度 d=1024）。
  • 视频编码器：因果视频 VAE + 预训练视频模型编码器，处理 T_o=3 个观测隐步；训练时额外输入 T_f=2 个加噪未来步做辅助视频流预测，使用前缀非对称注意力掩码；推理时无需生成视频。
  • 共享世界状态 φ：利用相机内参/外参（及可选深度）将每个 patch 的 token 提升到 3D 工作空间坐标，融合几何嵌入后以加权双线性 splatting 写入 XY/XZ/YZ 三个正交平面（φ ∈ R^{3×G×G×C_f}，G=16、C_f=256），空间尺寸与相机数量无关。
  • 无深度处理：沿视线取 S=8 个候选点，其权重由特征与几何学习得到；训练时以 0.25 概率丢弃深度，使同一模型兼容实测点与无深度射线。
  • 可见性门控更新：φ_t = φ_{t-1} + g_t ⊙ (φ̃_t − φ_{t-1})，门控与逐位置可见性 v_t 相乘，避免相机移动导致的已观测区域被擦除。
  • 动作解码器：条件流匹配（conditional flow matching）训练，每个机器人保持独立因果动作流 [e_start, s̄_i, q_i, A_i]；L=36 层按“读取—解码—通信”顺序更新：Field Injection Block 让查询从 φ 做交叉注意力（偏向本机器人相机位置）、Scene Decoder Block 以 VLM KV 缓存条件化本机器人动作流、Agent Interaction Block 用 10 维相对位姿描述子 P_ij（3D 平移 + 6D 旋转 + 距离）生成注意力 logit 偏置；推理时 5 步 Euler 积分。
  • 掩码视角协同训练：随机遮蔽某个机器人的全部相机或随机子集视角，VLM 前缀与 φ 同步遮蔽，但动作目标全部保留；总损失 L = 0.5·L_act + 0.2·L_future + λ_field·L_field，λ_field 从 0.1 线性衰减到 0.02。
Card 05 数据集与资源

数据集与资源

  • 预训练语料：20 种仿真机器人类型的操作轨迹 + RoboFactory 轨迹 + LeKiwi / OpenArm 真机轨迹，覆盖单臂与双臂、60+ 任务类型、总计 超过 10,000 小时交互数据。

  • 模型：视觉-语言主干初始化自 Qwen3-VL（视觉编码器与语言模型可训练，输入嵌入与 LM head 冻结）；解码器宽度 1024、36 层、动作块长 H=30、本体感知维度 20、动作维度 18。
  • 训练资源：使用 bfloat16 精度与 DeepSpeed ZeRO Stage 2；每次 VLM 前向被复用于 4 个流匹配样本。论文未给出具体 GPU/TPU 数量与型号。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真基准 RoboFactory、RoboCasa365，以及真实机器人平台（LeKiwi 同构团队、LeKiwi–OpenArm 异构团队）。
  • 主要指标：任务成功率（%）；RoboFactory 与真机任务取任务间无加权平均，RoboCasa365 总体分为 50 个任务的平均。
  • 基线：Diffusion Policy、ACT、π0.5、Fast-WAM、Global/Local GauDP（RoboFactory 与真机）；RoboCasa365 对比 PatchWAM、ABot-M0.5、PRTS、RLDX-1、GigaWorld-Policy 0.1、π0.5、Diffusion Policy（结果取自官方榜单）。
  • RoboFactory：平均成功率 74.0%，最强基线 π0.5 为 50.3%（+23.7 点）；三任务分别为 94 / 78 / 50，Place Food、Camera Alignment、Take Photo 上分别领先 π0.5 36 / 11 / 24 个百分点。
  • RoboCasa365：总体 58.08%（Atomic-Seen 80.8%、Composite-Seen 60.0%、Composite-Unseen 零样本 30.6%），比最强基线 PatchWAM（47.6%）高 10.48 点。
  • 真机任务：平均 78.8%，最强基线 π0.5 为 65.0%（+13.8 点）；block transfer 88%、cap unscrewing 70%、starfruit bagging 76%、block passing 81%。
