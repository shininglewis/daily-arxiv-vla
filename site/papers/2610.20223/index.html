Card 02 论文概述

论文概述

  • 提出 ObjDream，一个以对象为中心（object-centric）的 视觉-语言-动作（VLA） 框架，核心围绕对象级理解与未来对象状态预测。
  • 针对现有 VLA 模型普遍依赖从预训练 VLM 继承的图像级视觉表示、缺乏细粒度对象理解的问题，导致在分布外对象布局、杂乱场景和背景变化下鲁棒性下降。
  • 目标是通过显式结构化对象表示与动作条件下的未来状态监督，提升机器人操作在多种分布偏移与场景扰动下的泛化能力。
Card 03 核心贡献

核心贡献

  • 提出 ObjDream 对象中心 VLA 框架，引入时空对象编码器，通过独立通道分别表示持久对象身份与动态对象状态，并用身份引导路由机制将对象表示集成进 VLM 隐藏空间。
  • 引入动作条件下对象级前向动力学模块，训练时预测紧凑的未来对象状态以提供辅助监督，推理时无需未来状态预测；同时建模对象间关系以提供结构化上下文。
  • 在 LIBERO、LIBERO-Plus、RoboTwin 2.0 以及真实机器人实验上验证，展示在多样场景与环境扰动下的竞争力表现。
  • 通过消融实验系统评估各关键组件（ObjRel、ObjDyn、因子化注入、身份引导路由）的贡献。
Card 04 方法描述

方法描述

  • VLA 策略公式化：输入语言指令、多视角观测、本体状态与对象嵌入，输出连续动作块，动作专家采用流匹配（flow-matching）参数化。
  • 时空对象编码器：基于因果图像窗口与短语集构建因子化对象槽；用 Qwen3-VL-8B 提取任务相关对象短语，CLIP 文本编码器提供语义参考，DINOv2 提供初始视觉参考，SAM2 作为空间特征骨干。
  • 因子化对象注入：将身份与动态状态分别映射进 VLM 隐藏空间，身份缓存用于路由，注意力键值仍由完整上下文化 token 计算。
  • 关系与前瞻对象令牌：从对象特征与成对相对几何聚合出关系令牌，并结合槽重要性门控生成 N_p=2 个前瞻对象令牌。
  • 身份引导路由：计算身份匹配分数与头特定门控，将加性偏置加入注意力 logits，从而调制 VLM 对相应对象令牌的注意力。
  • 对象级前向动力学：由辅助头预测动作块，构建位置感知动作嵌入与动作条件门控，解码当前状态并并行预测未来 H_f 步的几何、可见性与掩码 logits，机器人槽被排除。
  • 训练目标：编码器预训练含掩码、几何、可见性与区域-文本对比损失；VLA 训练联合动作模仿损失与当前/未来状态、动作提议、门控正则等辅助损失，编码器保持冻结。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（Spatial/Object/Goal/Long 四套件）、LIBERO-Plus（七种受控扰动：相机视角、机器人初始化、布局、语言、光照、背景、传感器噪声）、RoboTwin 2.0（固定 8 任务子集）。
  • 模型骨干：实现使用 Qwen3-VL-4B 作为 VLM 骨干，搭配层级式流匹配动作专家，沿用 StarVLA 训练配方；短语提取使用 Qwen3-VL-8B。
  • 训练资源：8 张 NVIDIA H100 GPU 训练；评估时策略推理在 NVIDIA RTX 4090 GPU 上进行。
  • 评估协议：LIBERO 每任务 50 episodes；RoboTwin 每任务 50 条干净演示训练、100 次 rollout 评估（Easy 与 Hard）。
  • 训练分三阶段：编码器预训练 → 冻结编码器联合优化 VLM/动作专家/对象模块 → 冻结 VLM 与对象模块仅微调动作专家。
Card 06 评估与结果

评估与结果

  • LIBERO 标准评测：ObjDream 取得最高平均成功率 98.6%（Spatial 99.2、Object 99.6、Goal 98.2、Long 97.4）。
  • LIBERO-Plus 零样本鲁棒性：总体 84.4% 排名第二；在语言（90.6%）、光照（98.4%）、背景（98.5%） 扰动下最佳，传感器噪声 88.6% 为次佳；相机视角与机器人初始化仍是主要挑战。
  • RoboTwin 2.0：Easy 60.25%、Hard 22.75%，相比 StarVLA 分别提升 12.87 与 15.62 个百分点，Hard 设置提升更大。
  • 真实世界实验：四个任务（按钮按压、积木抓放、双水果放置、桌面清扫）上 ID 平均 74%、OOD 平均 55%；相比 π0.5 ID 提升 8 个百分点，相比 ControlVLA ID/OOD 分别提升 14 与 24 个百分点。
  • 消融实验：完整模型比骨干基线在 LIBERO-Long 和 LIBERO-Plus 上分别提升 2.0 与 3.2 个百分点；移除因子化注入（84.4→82.5）或身份引导路由（84.4→82.6）下降最大，移除 ObjDyn 降至 83.2%，移除 ObjRel 降至 84.1%，表明各组件互补有效。
