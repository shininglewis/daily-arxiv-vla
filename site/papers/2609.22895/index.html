Card 03 核心贡献

核心贡献

  • 提出分层 VLA 框架和两阶段训练策略，明确解耦高层关键动作推理与低层运动生成。
  • 引入 Key-Action Model、Motion Planning Model 和 Unified Camera-Centric Action Space，桥接语义推理、密集控制与跨数据集一致性。
  • 在 SimplerEnv 上取得 Google Robot VM 91%、VA 84%、WidowX VM 81% 的强性能。
  • 在 Agilex 双臂真实机器人上，相比最强基线在 ID、OOD Position、OOD Scene/Object 设置分别提升 10、47、16 个百分点。
  • 通过消融研究验证关键动作推理、运动规划、相机中心动作空间和两阶段训练策略的有效性。
Card 04 方法描述

方法描述

  • 使用预训练 Prismatic-7B VLM 提取多模态特征；第三人称 RGB 由 DINOv2 和 SigLIP 编码，语言由 LLaMA-2 处理。
  • Key-Action Model 预测结构化相机坐标系末端执行器关键动作（6-DoF 位姿和夹爪状态），作为下一个操作子目标，采用扩散去噪目标训练。
  • Motion Planning Model 以预测的关键动作、当前末端执行器状态、认知特征、全局视觉特征和腕部视图特征为条件，生成密集未来动作块，同样使用扩散目标。
  • Unified Camera-Centric Action Space 将当前状态、关键动作和动作命令统一到第三人称相机坐标系，使用标定外参进行变换，标准化异构数据集和本体。
  • 两阶段训练：Stage 1 Key-Action-Centric Pre-training 强调关键动作推理（λk=10，λa=1）；Stage 2 Motion-Planning-Oriented Fine-tuning 等权重，适应下游任务。
  • 关键动作标签从演示轨迹中夹爪状态变化和轨迹结束自动构造；腕部相机可用性通过 mask 处理。
Card 05 数据集与资源

数据集与资源

  • 预训练混合数据集约 183K 机器人轨迹，包括双臂 RoboCOIN Cobot Magic，单臂 DROID、FractalData、BridgeDataV2。
  • 使用 Prismatic-7B VLM 作为视觉语言模型；具体模块参数量在截断部分未完整给出，但模型总规模约 7B+。
  • 预训练使用 8 个 NVIDIA H100 GPU 约 3 天，1 个 epoch；FractalData 微调 8 H100 约 3 天，4 epochs；BridgeDataV2 微调 8 H100 约 3 天，6 epochs；Agilex 微调 4 H100 约 1 天，100 epochs。
  • 真实机器人数据：Agilex 双臂平台 150 个演示，3 个任务（PickBottles、HandOver、LiftPot），每任务 50 个。
Card 06 评估与结果

评估与结果

  • 仿真评估在 SimplerEnv 基准，包括 Google Robot VM/VA 和 WidowX VM。
  • 真实机器人评估在 Agilex 双臂平台，设置 ID、OOD Position、OOD Scene/Object。
  • 主要指标：任务成功率（%）。
  • 关键结果：

- SimplerEnv：H-VLA 平均最强，Google Robot VM 91%，VA 84%，WidowX VM 81%；Drawer+Apple 任务 98%，优于 DAM-VLA 78%。

- Agilex 真实机器人：ID 平均 93%，OOD Position 平均 83%，OOD Scene/Object 平均 66%；相比最强基线分别提升 10、47、16 个百分点。

- 消融研究验证关键动作推理、运动规划、相机中心动作空间和两阶段训练策略的有效性。
