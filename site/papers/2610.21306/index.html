VLA-$Δ$: Learning Physical State Transition for Vision-Language-Action Models

2026-10-15 · 原文 · 翻译 · 2610.21306

Card 02 论文概述

论文概述

  • 提出 VLA-Δ，一个以「当前状态与未来状态之间的物理变化」作为显式学习目标的通用视觉-语言-动作（VLA）框架。
  • 解决的核心问题是：现有 VLA 大多直接将观测映射为动作，缺乏对中间物理状态变化的显式监督，导致过拟合观测-动作对应关系（如未到达物体就闭合夹爪、抓取失败后仍继续移动）。
  • 现有中间推理类方法（Reasoning VLA）、世界动作模型（WAM）、隐空间世界模型（Latent-WAM）分别只监督高层任务语义或未来视觉外观，很少监督物理状态转变本身，且生成未来图像会带来额外推理开销。
Card 03 核心贡献

核心贡献

  • 提出 VLA-Δ 通用框架，将物理状态转变作为显式学习目标，同时建模任务语义与视觉运动变化，为连续动作生成提供更直接的监督。
  • 构建约 484 小时、2400 万帧的机器人演示预训练数据集，并开发完整的自动化数据标注流水线，生成大规模多层级物理状态转变标注。
  • 设计三条互补监督路径：Structured Transition Slots（结构化槽位）、Optical Flow（稠密光流）、Future-State Difference Text（未来状态差分文本）。
  • 在 LIBERO、LIBERO-Plus、RoboTwin 2.0 仿真基准上取得对比方法中的最高成功率，并在真机实验中超越 π0.5。
  • 监督信号仅用于预训练，下游微调只用动作学习目标，推理阶段无额外开销；消融实验验证各监督信号的独立贡献与表示的可迁移性。
Card 04 方法描述

方法描述

  • 整体架构沿用 GR00T N1 的视觉-语言骨干 + 动作专家设计，视觉语言模型为 Qwen3-VL-2B-Instruct，动作专家为 9 层 Diffusion Transformer。
  • 引入可学习的 Physical State Difference Queries，与多视角观测、指令组成的上下文序列共同输入 VLM，读取 Query 位置隐状态得到物理状态转变表示 Z_t。
  • 结构化槽位监督：将任务相关状态变量组织为 9 类目标（任务进度、任务阶段、目标位置、夹爪位置、运动与相对位移、可交互物位置、夹爪状态转变、接触转变、障碍风险），由轻量预测头分别回归，鼓励 Query 形成软性语义分工。
  • 稠密光流监督：用轻量光流解码器读取最后 N_flow 个 difference query 的隐状态，解码为图像平面上的稠密二维位移，损失由全像素项与运动像素项（含 β_motion 权重）组成。
  • 未来状态差分文本监督：用 VLM 原生自回归目标学习自然语言描述的差分文本，通过注意力掩码强制文本位置只能关注 Queries 与前置文本，不能直接看观测上下文。
  • 动作生成采用 Flow Matching 目标：动作专家通过交叉注意力融合 Z_t 与独立编码的本体状态 E_η(r_t)，将高斯噪声映射为连续动作块。
  • 总预训练损失为 L = λ_Text·L_Text + λ_slot·L_slot + λ_flow·L_flow + λ_act·L_act；下游微调退化为 L = L_act。
  • 自动化标注流水线：统一为 LeRobot v3 轨迹格式 → Qwen3.8 分段与语义标注 → SAM 3 生成检测框/分割掩码 → UniDepth V2 估计深度 → MegaFlow 离线估计光流 → GPT-5.6 逐字段复核 → 分层人工抽检。
Card 05 数据集与资源

数据集与资源

  • 预训练数据来自 DROID、MolmoAct、RH20T 三个机器人演示数据集。
  • 自建预训练数据集规模约 484 小时、2400 万帧。
  • 视觉语言模型初始化自 ZR-0_base 权重，基座为 Qwen3-VL-2B-Instruct（模型总参数量级约 2B VLM 规模）。
  • 仿真评估基准：LIBERO、LIBERO-Plus（Language / Light / Background / Layout 四类扰动）、RoboTwin 2.0（Clean 与 Random 设置）。
  • 真机平台：AgileX PiPER 6-DoF 双臂机器人。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（Success Rate, %）；LIBERO 覆盖 Spatial / Object / Goal / Long 四类共 40 个任务。
  • LIBERO：VLA-Δ 平均成功率 98.4%，为所有对比方法中最高（Spatial 98.8、Object 99.8、Goal 98.6、Long 96.4）。
  • LIBERO-Plus：在四类扰动下均保持较高成功率；Language 扰动下达 89.0%，比 π0.5（82.6%）高出 6.4 个百分点。
  • RoboTwin 2.0：Clean 设置平均 90.06%、Random 设置平均 89.74%，均超过所有对比方法，比最强基线 ZR-0 分别高 1.36 和 1.76 个百分点；从 Clean 到 Random 仅下降 0.32 个百分点（ZR-0 为 0.72，Motus 为 1.50）。
  • 真机实验：5 个任务各 40 个独立回合、共 200 次试验，平均成功率 68.0%，优于 π0.5 约 5.5%；避障任务达 42.5% 为最高。
  • 消融实验（LIBERO 平均）：稠密 VLM 特征基线 95.70 → 加入 Query 96.25 → 仅 Difference Queries 96.45 → +Difference Text 97.20 → +Structured Slots 96.90 → +Optical Flow 97.35 → 完整 VLA-Δ 98.40。
  • 可视化分析：t-SNE 显示结构化槽位监督使 7 组 Slot Query 形成更紧凑、边界更清晰的聚类，且该结构在仅用动作目标微调后仍然保留；注意力热图显示完整模型更聚焦于目标物体、夹爪与接触区域，无监督变体注意力更分散。
  • 代码开源：https://github.com/ZJU-OmniAI/VLA-Delta
