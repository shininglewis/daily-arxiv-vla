Card 03 核心贡献

核心贡献

  • 提出 PHRetune：用演示数据学习端口哈密顿（port-Hamiltonian）代理模型，估计策略预测动作对应的努力（effort）与能量（energy），并与演示导出的预算比较，得到唯一的动作缩放系数。
  • 给出由动作缩放到控制器增益的闭式映射：利用线性阻抗设定点端口模型做虚拟弹簧能量匹配，得到 **β\* = (s\*)²**，并保持阻尼比不变（k_p' = β\*k_p, k_d' = √β\*·k_d）。
  • 支持 shadow mode（影子模式） 推导：仅需演示数据与一次策略前向推理，不执行任何策略动作，无需机器人或仿真器交互即可在硬件上实用。
  • 在 LIBERO 三个套件与 4 个真实世界任务上，PHRetuned 策略优于名义策略、替代增益调优方法（Inv-Σ、DiffTune、MtG-SM2M）与策略重训练基线。
  • 同一流程可迁移至 SmolVLA 与 OpenVLA-OFT 等 VLA 骨干，在提升成功率的同时降低加速度与 jerk（运动更平滑）。
Card 04 方法描述

方法描述

  • 动作端口模型（Action Port Model）：用灰盒神经网络从演示转移拟合降阶端口哈密顿动作—运动代理，采用二次型哈密顿量 H = ½q̂ᵀKq̂ + ½p̂ᵀM⁻¹p̂，动力学 ẋ = (J−D)∇H + Ga。
  • 通过 Cholesky 参数化直接在参数化层面强制矩阵约束 M=Mᵀ≻0、K=Kᵀ⪰0、D=Dᵀ⪰0，保证连续时间代理相对动作端口无源（passive），储存能量不会超过通过动作输入供给的能量。
  • 影子模式评估：将冻结策略作为纯函数施加于记录的演示观测，把预测的动作块经代理传播，与演示导出的努力预算（动作幅度 90 分位）和能量预算（窗口内最大储能增量 90 分位）比较。
  • 动作缩放求解：施加包络约束 s·U_Φ^eff ≤ 1、s²·U_Φ^en ≤ 1，取最大可行缩放 s\* = min{1.0, 1/U_Φ^eff, 1/√U_Φ^en}，即只做衰减、不放大名义动作。
  • 阻抗设定点端口模型（Impedance Setpoint Port Model）：对 OSC-Pose 控制器 r_k = q_k + 0.05·s·a_k，通过匹配虚拟弹簧能量 W_k(s\*,1)=W_k(1,β\*) 得到 β\*=(s\*)²；也给出匹配虚拟弹簧力的替代映射 β†=s\*（较力匹配更柔顺）并对比。
  • 关键技术点：仅调整下游控制器增益，策略、动作表示与推理流程完全不变，且评估前增益固定，不引入运行时额外计算。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO-Goal、LIBERO-Object、LIBERO-Spatial 三个套件，单任务使用 20 或 50 条演示训练。
  • 真实世界任务：4 个任务（hat 放帽子、S&P 转移盐胡椒瓶、camera 放置相机到卡槽、eraser 擦白板），每任务 20 条 20Hz 人类遥操作演示，10 次评估试验。
  • 模型规模：SmolVLA 公开 0.45B 基础模型，微调 100M 参数动作专家、冻结视觉语言骨干；另使用 Diffusion Policy 与 OpenVLA-OFT。
  • 代理模型训练：只使用训练基础策略所用演示的 10%，端口哈密顿被控对象拟合约 3 分钟 CPU 训练。
  • 硬件平台：Franka FR3 机械臂 + Franka Hand，Deoxys OSC-Pose 控制器（基础 k_p=350），两台 Orbbec Gemini 335 相机（30 FPS）；推理服务器为 NVIDIA RTX Pro 6000、Threadripper 7970X、256GB RAM。
Card 06 评估与结果

评估与结果

  • 评估设置：仿真中每个单任务策略在 50 个留出初始状态、3 个种子（72/172/272）上评估；Robosuite 默认 k_p=150；真实世界由对方法盲测的评估者判定成功。
  • 主要指标：任务成功率、派生的增益缩放 β\*、控制器能量一致性（每动作块净任务空间控制器功相对演示包络）、末端执行器与关节的加速度/jerk、抓取时间。
  • LIBERO 仿真结果：PHRetune 使 Diffusion Policy 成功率最高提升 9.4 个百分点；20 条演示下总分从 78.5% 提升至 87.9%（接近 50 条演示的名义策略），50 条演示下从 89.0% 提升至 92.6%；独立增益扫描显示 β\* 落在经验最优增益平台上。
  • 真实世界 Diffusion Policy：整体成功率从名义 0.50 提升至 0.73（Hat 0.6→0.8、S&P 0.4→0.6、Camera 0.5→0.7、Eraser 0.5→0.8），基线方法（Inv-Σ 0.08、DiffTune 0.38、MtG 0.45）均未超过名义策略。
  • VLA 骨干结果：SmolVLA 整体成功率 0.58→0.80，DiffTune 仅 0.45；OpenVLA-OFT 在全部四个任务上同样提升。
  • 能量一致性验证：重调后每动作块平均能量由 1.47→0.93（Spatial）、1.37→1.00（Goal）、2.11→1.26（Object），接近演示能量水平。
  • 影子模式验证：闭环比影子模式导出的 β\* 差异在 0.05 以内（总成功率 88.0 vs 87.9），说明演示帧足以代理策略自身状态分布。
  • 运动平滑性：PHRetuned SmolVLA 将末端 jerk RMS 降低 47.7%、jerk 峰值降低 49.1%、末端加速度 RMS 降低 44.1%、关节加速度 RMS 降低 57.8%，抓取时间基本不变（3.66s），趋近遥操作水平。
