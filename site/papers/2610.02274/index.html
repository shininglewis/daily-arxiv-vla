Card 03 核心贡献

核心贡献

  • 仿真就绪的资产生成：提出 ISArt 结构接地（structure-grounded）的关节物体生成流程，以及共享的候选校验、规范化变换、碰撞构建与物理属性增强机制。
  • 互补的场景生成路线：Unravel 从单张图像重建可编辑场景，SimForge 从文本构建单房间与多房间环境。
  • 集成式执行与演示合成：Graph-Native Harness 负责带归属判定（owner routing）的修复与验收，PolicyForge 跨场景、任务与机器人本体生成可回放的演示数据。
  • 跨仿真器的策略学习证据：在 LIBERO-Plus 上以最优检查点比较，整体成功率提升 12.26 个百分点，目标泛化提升最大。
Card 04 方法描述

方法描述

  • ISArt（单图关节资产）：VLM 先预测类别、部件数、语义、父链接、关节类型（fixed/revolute/prismatic/continuous）、粗轴、部件框与空腔框；再用适配 TripoSG 先验的多部件 DiT 生成各部件网格（结构嵌入逐层注入 + 几何 token 对结构序列交叉注意力 + 部件内/跨部件注意力），以 rectified-flow 目标优化结构模块与注意力 LoRA；最后进行关节绑定与 Isaac Sim 渲染视频裁判验证。
  • Unravel（图像到场景）：免训练（training-free）的"规划–编辑–验证"循环，逐层移除物体以暴露遮挡区域；用未编辑锚点对齐并融合单目点图，按像素与移除轮次做实例归属；按移除逆序重组，采用截断相似性 ICP 配准 + 支撑感知物理沉降 + 渲染审计。
  • SimForge（文本到场景）：由语言模型规划房间几何、开口与物体需求，几何感知例程实例化并校验位姿；支持单房间与多房间（含拓扑与房间间连接）。
  • Graph-Native Harness：以类型化状态、验证证据、责任模块、修复范围、尝试预算与检查点组成执行图；编辑后按依赖关系失效并重校验，硬性校验与仿真打包共同决定世界是否被接受。
  • PolicyForge：将验收通过的世界绑定到任务、机器人本体与重置规范，由脚本或运动规划教师生成同步观测/状态/动作，保留成功回合作为演示；通过场景与任务"表亲"（cousins）及初始状态/语言增强扩展数据。
Card 05 数据集与资源

数据集与资源

  • 资产评测：60 个关节物体，来自两个来源、覆盖 12 个类别。
  • 场景重建评测：5 个场景、160 个物体；另有 20 个场景用于图像级相似度评测。

Card 06 评估与结果

评估与结果

  • ISArt 资产质量：部件几何 Chamfer Distance 0.163，优于 TRELLIS.2 + P3-SAM + X-Part 组合的 0.268；F-Score 在阈值 0.05 / 0.1 下分别为 0.604 / 0.789；在固定真值部件几何条件下 URDF 绑定 AxisErr 0.07、PivotErr 0.05、TypeErr 13.33%、绑定成功率 100%（该指标仅评估绑定，不代表端到端生成）。
  • Unravel 场景重建：资产保真度人类评分 4.9 → 8.6、VLM 评分 4.7 → 8.2（1–10 分）；平均场景点数 1.53M → 2.81M；直接掩码覆盖 Unravel 掩码面积的 77.2%。图像级对比中 CLIP-I 0.854（+6.4%）、LPIPS 0.632（−2.6%）、Edge IoU 0.156（+45.8%），全面优于 GPT-6 Astra。
  • SimForge 场景质量：相较 SceneSmith，房间级数量一致性提升 6.5 个百分点、多房间级提升 6.4；可达性提升 14.7 与 13.3 个百分点；在所述检查下碰撞率 0%、稳定性 100%。
  • 下游策略学习：在 LIBERO-Plus 上，SimData-Ultra 协同训练将 WAM 成功率从 77.17% 提升至 89.43%；目标泛化提升 31.66 个百分点，空间泛化提升 6.25 个百分点；长时序任务收益相对有限。
  • 评测口径说明：结果支持生成数据跨仿真器的训练价值，但未隔离各生成器或增强手段的独立贡献；世界构建质量、回合成功率与基准策略成功率被视为彼此独立的验证结果。
