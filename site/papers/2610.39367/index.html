Utility-WAM: Correcting Future-Induced Action Changes

2026-10-29 · 原文 · 翻译 · 2610.39367

论文研究World Action Models（WAMs）中以生成式视觉未来（visual future）为条件对机器人动作预测产生的影响，核心研究对象是“未来条件路径”与“无未来路径”之间的动作增量 Δa。 作者发现这一增量在基准平均指标上几乎不改变成功率（LIBERO +0.8 分、RoboTwin 2.0 −0.8 分），但视频未来生成会带来 1.7–1.9× 的推理延迟。 论文提出并定义了未来诱导负迁移（future-induced negative transfer）：预测未来对长时序任务有益（LIBERO-Long +2.4 分），对多数常规操作可忽略，但在精细任务上造成集中且可复现的严重性能崩塌（*Press Stapler* −54.0 分、*Place Can Basket* −34.0 分）。 目标是在保留未来预测前瞻能力的同时，修复未来诱导的有害动作变化，并在未来无益时省去视频生成计算。

Card 02 论文概述

论文概述

  • 论文研究World Action Models（WAMs）中以生成式视觉未来（visual future）为条件对机器人动作预测产生的影响，核心研究对象是“未来条件路径”与“无未来路径”之间的动作增量 Δa。
  • 作者发现这一增量在基准平均指标上几乎不改变成功率（LIBERO +0.8 分、RoboTwin 2.0 −0.8 分），但视频未来生成会带来 1.7–1.9× 的推理延迟。
  • 论文提出并定义了未来诱导负迁移（future-induced negative transfer）：预测未来对长时序任务有益（LIBERO-Long +2.4 分），对多数常规操作可忽略，但在精细任务上造成集中且可复现的严重性能崩塌（*Press Stapler* −54.0 分、*Place Can Basket* −34.0 分）。
  • 目标是在保留未来预测前瞻能力的同时，修复未来诱导的有害动作变化，并在未来无益时省去视频生成计算。
Card 03 核心贡献

核心贡献

  • 刻画未来诱导负迁移：以相对无未来参考路径的动作增量 Δa 形式化测试时想象，证明小的基准平均效应掩盖了在多种 WAM 配置下可复现的精细任务严重崩溃。
  • 提出定向动作修正：设计轻量残差适配器（residual adapter），通过真值未来对齐项与超额误差惩罚项修复未来诱导的速度增量；在 RoboTwin 2.0 上恢复两个严重任务 89% 与 59% 的损失（占其整体 +1.7 分提升的 80%），同时不牺牲其余 48 个任务与长时序收益。
  • 提出选择性部署门控：利用适配器配对结果（counterfactual 动作结果）训练生成前效用门控（pre-generation gate），在 RoboTwin 上仅对 24.5% 的查询调用视频生成，延迟降低 38%。
  • 取得领先的基准成绩：报告平均成功率 LIBERO 98.9%、RoboTwin 2.0 93.3%，优于 FAST-WAM-Joint（98.5%/90.6%）与 FAST-WAM-IDM（98.0%/91.3%）等未来生成变体。
  • 完成真实世界验证：在双臂真机三个任务上，60 次试验成功 53 次，对比 FAST-WAM 的 43 次（成功率 71.7% → 88.3%，+16.7 个百分点）。
Card 04 方法描述

方法描述

  • 共享 WAM 与流匹配：以 flow matching 联合建模视频与动作 token，同一套参数下设置两条动作路径——π_wo（掩码阻断对未来的访问）与 π_w（条件化于生成的未来），由不同注意力掩码 M_wo / M_w 控制。
  • 三阶段训练：阶段 1 联合训练视频与动作 DiT；阶段 2 冻结 WAM，仅训练残差适配器；阶段 3 冻结前两者，用配对最终动作误差训练门控。
  • 残差适配器：在动作 velocity 上加入修正项 v̂_w = v_w + Δv_φ(q_τ^a, F_k^+)，使用自生成的未来特征 F_k^+（与推理分布对齐）作为输入，并以真值未来条件下的速度 v_GT 判断未来是否支持有益增量。
  • 三项损失设计：L2 = w(τ)d(v̂_w, v*)（动作拟合）+ α·d(v̂_w − v_wo, δ*)（对齐项，δ* 在真值未来无优势时置零）+ β·max{d(v̂_w,v*) − d(v_wo,v*), 0}（超额误差项，以前景无关路径为安全锚点）。
  • 生成前门控：门控学习 g_ω(x) ≈ P(u_act > 0 \|x)，以二元交叉熵训练，推理时一次性判定并只执行被选中的完整动作流，从而跳过视频生成。
  • 创新点：不同于蒸馏为仅当前观测策略（如 PFD）或仅做路由的方案，该方法在保留未来条件路径的同时约束其负面副作用，实现“先修正、再分配计算”。
Card 05 数据集与资源

数据集与资源

  • LIBERO：40 个任务、2,000 次试验，从预测的 32 步动作中执行 10 步。
  • RoboTwin 2.0：每个任务 100 次试验，覆盖 clean 与 randomized 条件，从 32 步中执行 24 步。
  • 真实世界：AgileX PiPER 双臂平台，3 路 RGB 视角，3 个任务（*Place Empty Cup*、*Insert Can*、*Stack Three Blocks*），每任务 200 条遥操作示教，每方法每任务 20 次试验。
  • 基础模型：基于 FAST-WAM，骨干为 Wan2.2-TI2V-5B，每个基准训练一个模型；所有受控变体共享同一 Stage-1 检查点。
  • 训练具体 GPU/TPU 规模在可见正文中未给出（详见附录 A.2 训练超参部分）。
Card 06 评估与结果

评估与结果

  • 评估设置：仿真在 LIBERO 与 RoboTwin 2.0 上进行，所有变体使用相同初始状态与随机种子；真机在双臂平台进行闭环评测；门控阈值在留出验证集上固定（LIBERO η=0.439，RoboTwin η=0.541）。
  • 主要指标：闭环成功率、任务级成功率变化 ΔJ_t（百分点）、有效视频生成步数 N_eff、推理延迟。
  • 负迁移诊断：RoboTwin 50 个任务中 21 个受损但中位数为 0.0，总损失由两个严重任务驱动；其余 19 个受损任务每个最多损失 2.5 分。
  • 修正效果：严重任务损失由 54.0→6.0、34.0→14.0；仅用适配器达 LIBERO 98.7%、RoboTwin 92.8%；叠加门控后达 98.9% / 93.3%。
  • 效率：RoboTwin 上门控减少 38% 延迟，仅比无未来路径多 17%（换来 +1.4 分）；LIBERO 上节省 6.7% 计算。
  • 对照基线：门控曲线在所有中间预算（0 < N_eff < 10）上均优于静态截断与随机路由（随机路由最高 98.4% / 92.6%）。
  • 消融：仅用动作损失（类似 scheduled sampling）提升 ≤0.3 分；对齐项带来 RoboTwin +0.9、LIBERO +0.3；对齐与超额误差合用再贡献 +0.5 / +0.2 分。
