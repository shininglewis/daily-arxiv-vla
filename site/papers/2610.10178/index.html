Do Vision-Language-Action Models Understand Instructions? A Mechanistic Interpretability Study on Language Grounding

论文概述

Card 03 核心贡献

核心贡献

  • 提出一个面向 扩散/流匹配 VLA 动作专家 的因果与表征联合分析框架，整合 Attribution Patching、Activation Patching 验证与 Centered Kernel Alignment（CKA）。
  • 发现语言扰动敏感性具有 模型特异性：GR00T N1.7 呈周期性层间模式并与 cross-attention 条件模块位置吻合，π0.5 则集中在早期层与部分后期层。
  • 发现 GR00T N1.7 中方向性语言扰动会引发较大因果归因效应，但内部表征几何变化相对较小，表现出因果效应与表征变化的 解耦；π0.5 中未清晰观察到此现象。
  • 指出 Attribution Patching 的可靠性依赖模型：对 GR00T N1.7 与 Activation Patching 高度一致，但对 π0.5 不一致，尤其早期层。
  • 为 VLA 可解释性研究提供方法学警示：动作专家对语言条件的依赖是非均匀的，并受其条件注入架构影响。
Card 04 方法描述

方法描述

  • 聚焦 π0.5 与 GR00T N1.7 的 action expert / action decoder，在每层 self-attention 输出投影 o_proj 后干预 residual stream。
  • 使用 Attribution Patching 以梯度和一阶泰勒近似估计因果效应，再用 Activation Patching 对候选层进行精确验证。
  • 使用 CKA 比较干净输入与扰动输入下的层内表征相似性，以区分“表征不敏感”与“表征变化但未被行为性利用”两种失败模式。
  • 语言扰动策略包括五类：Synonym Replacement、Semantic Scaling、Directional Corruption、Random Object Replacement、Empty String。
  • 评估指标为流匹配目标中的 L2 loss，即目标速度与预测速度之间的差异；同时报告逐层、逐 token 的归因热图与 CKA 曲线。
  • π0.5 通过共享 attention 在动作专家与 VLM backbone 之间注入语言信息；GR00T N1.7 使用 masked cross-attention，每隔 4 层 让 cross-attention 关注语言 token。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 基准中的 LIBERO-10 离线示范数据子集。
  • 数据集包含 378 个 episode、约 101,000 步、10 个任务；实验中随机采样 10,000 步。
  • 每个样本使用两路相机视图（腕部相机与桌面视角相机）、机器人本体感知状态向量与任务指令作为输入。
  • π0.5 使用 SigLIP（400M） 与 Gemma（2.6B） 作为 VLM backbone，动作专家为 300M 参数 transformer。
  • GR00T N1.7 使用 Cosmos-Reason2-2B VLM，动作生成模块为 32 层交替 cross-/self-attention 的 transformer 扩散模型。
  • 使用 LIBERO-10 微调 checkpoint：π0.5 使用 pi05_libero_finetuned_v044，GR00T N1.7 使用 gr00t17-lerobot-libero_10-640。
  • 所有实验在单张 NVIDIA A100 GPU 上运行，使用模型发布时的默认精度（可能为混合精度）。
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO-10 离线数据，评估手段包括 Attribution Patching、Activation Patching 与 CKA。
  • 在 π0.5 和 GR00T N1.7 中，方向性扰动 均在早期层引发最大归因效应；π0.5 的 layer 1 与 GR00T N1.7 的 layers 3、5、7 反应显著。
  • π0.5 对动词扰动更敏感，GR00T N1.7 对名词扰动更敏感；随机对象替换对两者影响均小于动作/方向性改变。
  • 语言条件主要集中在早期层：π0.5 约在 layer 6 及 layer 12 之后，GR00T N1.7 主要在 layers 0-10，并呈每 4 层 cross-attention 的周期性模式。
  • 后期层可出现 负归因，可能对应语言模型中的 Hydra effect / 自修复 动态。
  • CKA 显示 π0.5 表征整体稳定，仅在 empty string 与 directional 扰动下明显变化；GR00T N1.7 对语言扰动更敏感，但 directional 扰动虽归因效应大，表征几何却变化较小。
  • Attribution Patching 相对 Activation Patching 系统性低估因果效应，尤其在 π0.5 的早期层与 directional 条件下。
  • 相关性分析表明：GR00T N1.7 中两者高度一致（Pearson r=0.946，Spearman ρ=0.972）；π0.5 中无显著相关（Pearson r=0.089，Spearman ρ=0.097）。
