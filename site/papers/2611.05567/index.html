Card 03 核心贡献

核心贡献

  • 提出 MESA-Bench：包含单臂 Franka 与双臂 YAM 两种形态，各有一个规范训练集和五个评测套件（分布内、空间、实例、类别、组合泛化）
  • 提出基于干扰任务完成情况的语言跟随率（Language Following Rate）指标，用于区分“指令定位失败”与“控制执行失败”
  • 提出 MESA-Gen：可扩展的任务与数据集生成框架，改进 MimicGen，支持在更大空间变化下生成高质量数据，并能对无人类示教的新任务生成数据
  • 发布 BiMESA：首个面向双臂泛化的大规模多任务语言条件基准
  • 系统评测 7 种基线方法，并验证 MESA 排名与真实世界 RoboArena Elo 排名大体一致
Card 04 方法描述

方法描述

  • 任务骨架（task skeleton）：用 Python 类定义初始化、示教与目标谓词，自动生成训练/评测用的 BDDL 文件，每个场景拥有独特布局、干扰物集合与可选纹理/相机位姿/机器人形态
  • 视觉混淆采样：每个场景包含多个可见的“物体-目标”配对作为干扰项，避免策略忽略语言指令、仅凭视觉直接操作唯一可交互物体（因果混淆）
  • MimicGen 改进：引入子任务拼接（subtask stitching），从按谓词类型与物体语义索引的共享子任务库中组合（如 Grasp(apple)、On(·, plate)），实现零人类源数据的任务生成；并引入轨迹优化以应对大位姿差异，避免不自然的扫掠动作与自碰撞
  • 语言跟随率：定义为 $L=\frac{S}{S+D}$，其中 $S$ 为成功率、$D$ 为干扰任务完成率，即在“完成某个可行任务”的条件下完成正确任务的概率
Card 05 数据集与资源

数据集与资源

  • MESA-70：单臂训练集，70 个任务、7,000 条示教
  • BiMESA-57：双臂训练集，57 个任务、6,833 条示教
  • MESA-Aux：736 个辅助单臂任务，用于研究数据多样性扩展
  • 评测套件规模：MESA-ID（70 任务）、MESA-Spatial（单臂 10 / 双臂 38）、MESA-Instance（20 / 18）、MESA-Composite（20 / 15）、MESA-Category（20 / 17）
  • 基线模型：Multitask Diffusion Policy (DP)、PG-Bin 与 PG-FM（基于 PaliGemma-3B 微调）、GR00T-N1.6、π0、π0-FAST、π0.5，另有零样本 GPT-6.1-Sol LLM 智能体

Card 06 评估与结果

评估与结果

  • 评估环境：仿真桌面操作平台，单臂 DROID 风格 Franka Panda 与双臂 YAM；每个任务固定初始状态集、采样未见干扰物与位姿，保证跨策略无偏比较
  • 主要指标：任务成功率、语言跟随率（LFR）、与 RoboArena Elo 的排名一致性
  • 总体性能：π0.5 在单臂 MESA 平均 52.0%、双臂 BiMESA 平均 48.7% 均为最强；π0-FAST 次之（35.3% / 39.4%）；DP 表现极差（1.1% / 10.6%），反映其多任务扩展性不足
  • 泛化落差显著：MESA-Category 上 π0.5 仅 26.4%，BiMESA-Category 上最强基线仅 18.6%，说明开放词汇物体类别泛化仍是空白领域
  • 语言跟随：具备 VLM 主干的模型 LFR 普遍较高，π0.5 达 MESA 平均 74.9%、BiMESA-ID 92.9%；DP 仅 14.4%，语言条件能力弱
  • 机器人预训练并非普遍可迁移：π0 在单臂优于 PG-FM，但在双臂反而略逊于 PG-FM
  • 数据规模与多样性：增加示教数量近单调提升性能，但 π0.5 用 10 条示教即稳定优于 π0 用 100 条，说明预训练质量主导数据量；加入 736 个辅助任务协同训练未带来一致的泛化增益
  • 跨臂迁移：单臂任务换臂与反向交接退化较小，但铰接物体操作技能的跨臂迁移退化最大，揭示技能对称性缺失
  • 与真实世界一致性：MESA 与 BiMESA 的模型排序与 RoboArena Elo 排序大体一致（主要分歧为 PG-FM 与 π0 的相对顺序）
