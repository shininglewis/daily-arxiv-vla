Card 02 论文概述

论文概述

  • 论文提出 StenoVLA-3D，一个面向胃肠道狭窄（stenosis）穿行的 3D 感知推理式 VLA 框架，用于自主内窥镜导航。
  • 现有 VLA 主要依赖视觉外观与短期上下文，缺乏几何 grounding 和整段 episode 级别的报告能力；而狭窄穿行需要在纹理稀疏的单目观测下预测动作、做出安全决策，并在病灶离开视野后仍保留证据。
  • 目标：同时实现结构化推理、导航状态判断、开口形状估计、离散运动动作预测以及基于记忆的病灶报告生成。
Card 03 核心贡献

核心贡献

  • 提出 3D-aware 推理 VLA 框架，融合 point-map 几何编码、时序记忆与持久记忆，统一完成导航动作预测、推理、形状估计和 episode 级报告。
  • 提出 EndoCausal 数据集，包含 400 条体模序列，将内窥镜观测与病灶标注、导航动作、重建控制目标和时序 grounding 的推理文本相连接。
  • 系统性地对几何表示（DA3 / EndoDAC / VGGT）与记忆组件进行受控评测，在食管与结肠体模上取得 88.9% 与 77.8% 的任务成功率。
  • 额外给出在外观与形变扰动下的零样本跨域评测，验证 3D 几何与记忆模块对推理、导航和报告的共同贡献。
Card 04 方法描述

方法描述

  • 骨干网络：以 Cosmos-Reason2-2B 初始化（采用 Qwen3-VL 条件生成实现），冻结预训练参数，仅更新 query/key/value/output 投影层上的 rank-16 LoRA 适配器。
  • 3D 几何编码：使用冻结的 DA3-Base 估计多视角相对几何，存储为点图 P_i = [X_i, Y_i, Z_i, M_i]（含有效性掩码），打包 16 张点图为 4×16×112×112 张量，经冻结的 3D 卷积编码器 得到 256 维几何嵌入 z_g,k。
  • 几何门控融合（创新点）：将几何嵌入投影到隐藏维度 q_k，由首个 backbone token 与 q_k 计算特征级门 g_k，以末层残差方式注入 H̃ = H + v^g_k (g_k ⊙ q_k)，不改变预训练 token 结构；训练时以 0.5 概率随机丢弃几何，缺失时文本输出 "not observable"。
  • 时序记忆：由图像 token 均值与末位 prompt token 拼接投影得到 512 维记忆特征，经 GRU 更新时序状态 h_k，用于病灶 logits 与后续记忆写入。
  • 持久病灶记忆（创新点）：维护类别槽 {s_k,j} 与累积存在度 p_k（j ∈ {polyp, ulcer, stenosis}），写入强度 γ = σ(d)·σ(w)，槽按 EMA 更新、存在度按 max 更新——病灶离开视野后仍保留证据。
  • 形状与报告头：线性头输出 5 类开口形状（circular / elliptical / slit-like / crescent / irregular），最终形状取最后一次有效预测 o_k*；episode 结束时以 [h_K; vec(S_K); p_K]（2051 维）经共享网络与分类头生成报告，阈值 0.5。
  • 推理与动作：语言头按顺序生成时序 grounding 推理 R_k（观察–解释–决策模板）、导航状态、安全约束、开口形状、运动动作（8 个面内平移 + 前后轴向 + stop）及重建命令。
  • 两阶段训练：Stage 1 使用 stride-4 采样；Stage 2 额外保留重建切换帧并输入上一控制状态，对运动/激活 token 加权；损失为 LM + lesion + write + report + shape 多项加权。
  • 异步推理：DA3 与 VLA 异步运行，重建开关由预测的导航状态决定（进入/穿行狭窄时 ON，确认结束/完成/终止时 OFF），仅消费完成批次，episode 结束时取消挂起任务。
Card 05 数据集与资源

数据集与资源

  • EndoCausal 数据集：400 条导航 episode，约 80 万帧，20 fps，采集于解剖结构化的食管与结肠体模。
  • 数据划分：320 训练 / 40 验证 / 40 测试；训练集增强产生约 2200 条额外序列（亮度、对比度、色彩、模糊、水平/垂直翻转、最大 45° 旋转）。
  • 采集平台：四电机装置控制内窥镜 3 自由度（yaw、pitch、轴向平移），两个反向旋转电机联合控制前后平移。
  • 标注流程：先用 SAM 3 生成狭窄/息肉/溃疡初始分割掩码，再人工审核修正为凸包标注；时序事件标记可用视野边界、狭窄确认、重建开始、狭窄进入、远端确认、重建停止、终止完整性。
  • 模型规模：VLA 主干 Cosmos-Reason2-2B（约 2B 参数级），几何嵌入 256 维，记忆特征与 GRU 状态 512 维。
  • 训练资源：NVIDIA RTX A6000 GPU。
Card 06 评估与结果

评估与结果

  • 评估协议：40 条留出录制测试 episode 上做开环 Semantic（六字段解析的精确匹配率）和 Action（运动动作精确匹配率）评测；物理 3-DoF 内窥镜上每个术式 36 次独立试验统计任务成功率（Esophag. / Colon.）。
  • 主结果（TABLE I）：StenoVLA-3D 取得 95.2 Semantic、83.4 Action、88.9% 食管镜、77.8% 结肠镜，平均 86.3，全面领先。
  • 对比基线与变体：EndoVLA\* 为 80.2 / 67.3 / 50.0 / 55.6（Avg. 63.3）；π₀.₅ 为 – / 55.2 / 33.3 / 22.2（Avg. 36.9）；Steno-DAC 为 92.1 / 84.7 / 63.9 / 52.8（Avg. 73.4）；Steno-VGGT 为 88.8 / 81.0 / 58.3 / 66.7（Avg. 73.7）——相对 EndoVLA\* 分别提升 15.0 / 16.1 / 38.9 / 22.2 个百分点。
  • 消融（TABLE III）：去掉推理监督平均降至 48.5%；去掉持久记忆虽保持较高开环分数（88.0 / 79.2）但物理成功率降为 0%；去掉时序记忆平均降至 51.2%；去掉几何融合开环仍有 85.5 / 78.3，但两种术式成功率均降为 0%。
  • 跨域零样本（TABLE IV）：视角偏移最好（91.1 / 77.8 / 83.3 / 72.2，Avg. 81.1），反射次之（Avg. 79.1），形变（Avg. 65.8）与纹理偏移最弱（Avg. 61.2，结肠成功率降至 50.0%）。
  • 延迟分析：VLA 单次决策约 25.20 s，DA3 单次重建约 3.63 s，端到端 28.83 ± 0.65 s；Steno-DAC 与 Steno-VGGT 为 32.71 s 与 36.85 s；π₀.₅ 最快（1.45 s）但动作与流程成功率显著更低。
  • 局限性：推理延迟高，无法做连续低层控制；仅体模验证；缺少标定化的狭窄长度与管腔直径估计；离线联合重建几何与在线因果几何之间存在不匹配。
