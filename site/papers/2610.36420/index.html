SO-101 Bench: Accessible Spatial Manipulation

2026-10-27 · 原文 · 翻译 · 2610.36420

论文提出 SO-101 Bench，这是一个面向低成本机械臂 SO-101 的语言条件空间操作（language-conditioned spatial manipulation）仿真基准；它基于 Isaac Lab 构建了真实 SO-101 装置的数字孪生。 论文要解决的问题是：SO-101 已成为机器人学习最常见的入门硬件，但现有 SO-101 基准只在真机上运行，任务简单、留出物体少、成本高（每个条件只有几十次 rollout），且受具体装配（舵机偏移、相机错位、物体磨损）影响，结果难以复现；而已有的通用仿真套件（如 LIBERO）已饱和且存在训练-测试重叠。 论文的核心目标是验证“仿真排名能否在真机上成立”，即数字孪生是否能替代真机进行策略评估，并同时揭示聚合成功率背后被掩盖的能力短板（空间放置、未见类别、旋转适配、遮挡记忆）。

Card 03 核心贡献

核心贡献

  • 发布 SO-101 Bench：面向低成本机械臂语言条件空间操作的数字孪生基准，包含实例级与类别级物体划分、ROBUST / PLAN / MEM 三个能力子集和自动评分，并附带 so101_bench_sim（3,629 条仿真回合）与 so101_bench_real（约 4,400 条真机回合）数据集。
  • 证明数字孪生能像真机一样给策略排序：独立训练的 real-only 与 sim-only 策略在条件难度和失败模式上对应（Pearson r = 0.86），五个无真机数据的策略在相同权重下于仿真与真机保持完全一致的排名（Spearman ρ = 1.00，MMRV 0.000），并且在未见环境和未见物体上开箱可用。
  • 给出 9 个 VLA/WAM + 2 个 LLM agent 的排行榜；所有学习型策略在相同数据和相同算力预算下微调，显示空间放置、未见物体类别与旋转适配规划仍是开放问题。
  • 消融实验表明：在本设定下，“代码即策略（code-as-policy）+ 把抓取交给学习策略”的 harness 优于两者单独使用，且 harness 的影响大于语言模型本身的影响。
Card 04 方法描述

方法描述

  • 数字孪生构建：在 Isaac Lab 中依据房间扫描与物体资产重建真实 SO-101 装置，物理仿真 240 Hz、策略控制 30 Hz；策略输入为俯视相机 + 腕部相机（均 640×480）与关节位置；包含 22 个背景（18 训练 / 4 留出）和 6 训练 + 4 留出的机器人配色；真机与仿真的关节标定对齐，使同一权重可跨域运行。
  • 任务设计（4 任务 / 5 任务族）：把每个物体放入塑料箱（1 物体与 4 物体两种族）、把物体放到另一物体旁边、把物体放到两个物体之间、沿指定方向推动物体直到边界物体；测试语义接地、抓取策略、关系空间推理、精细放置与部分遮挡鲁棒性。
  • 物体与泛化划分：138 个家居物体分为 seen（48）、unseen-instance（43）、unseen-class（47），其中 37 个未见类物体私有保留以防测试集泄漏；物体经 3D AI Studio 图像转 3D 生成，约 60 个由实物照片重建并调校外观与物理属性（Real2Sim 流水线）。
  • 数据与训练协议：所有学习型策略在 so101_bench_sim 的 3,629 条遥操作回合（含初始帧变体 so101_bench_sim_WM）上微调，统一 36 h × 4× A100-80GB 预算，按作者推荐配方（FLUX 3 Action 用 LoRA），在 39 回合验证集上选检查点。
  • 自动评分：从仿真状态判定，成功条件需连续保持 5 s，失败条件持续 5 s 结束（允许纠错），30 s 超时（4 物体入箱 75 s）；接触判定为任一连杆压力 > 0.05 N。
  • LLM Agent harness：Direct tool calls（inspect-robots 直接末端执行器指令）、PyRUA-Lean（写 Python 代码，用 SAM3 开集分割 + 3D 定位 + 逆运动学）、以及 PyRUA-Lean + Galaxea 0.5（把抓取交给冻结的微调 VLA，并周期性检查、可接管恢复）。
Card 05 数据集与资源

数据集与资源

  • so101_bench_sim：3,629 条仿真遥操作回合（30 fps 下约 18.5 h），其中 1,892 条入箱、1,150 条 next-to/between、587 条 move，3,004 条为四物体场景。
  • so101_bench_sim_WM：在上述数据上追加每回合初始俯视与腕部帧，供接受初始帧的策略（GR00T N1.7、π0.5、MolmoAct2）使用。
  • so101_bench_real：约 4,400 条真机遥操作回合（约 20 h），覆盖约 35 个物体。
  • 评估集：主评估 916 回合（15 个任务族 × 物体划分单元，均做可行性检查）；子集 ROBUST 178、PLAN 48、MEM 51；另有 39 回合验证集与 60 回合配对消融集。
  • 模型规模与算力：评估 9 个学习型策略（GR00T N1.7、π0.5、Galaxea 0.5、MolmoAct2 base/SO101、InternW0-Δ、ImageWAM、FLUX 3 Action、LaWAM）与 2 个 LLM agent（GPT-6.1 Sol、DeepSeek V4.1 Flash-1017）；每个策略统一 36 h × 4× A100-80GB 微调预算（消融显示各策略实际见到的样本数相差达 30 倍）。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真（多背景）与真机（训练中未出现的环境、未见物体）双端评估，同一权重、同一 45 个布局；真机端由操作员按基准规则人工评分，使用 40 个仍在手的物理物体（18 seen / 11 unseen-instance / 11 unseen-class）。
  • 主要指标：benchmark score = 15 个任务族×划分单元的平均成功率（95% bootstrap CI）；排序一致性用 Spearman ρ、MMRV、Pearson r；失败类型用总变差距离与 Cohen's κ 衡量；另有 ROBUST/PLAN/MEM 子集分数与推理时延（wall time）。
  • 仿真可替代真机排序：五个策略在仿真与真机排名完全一致（ρ = 1.00，MMRV = 0.000，95% CI [0.000, 0.169]；Pearson 0.90）；GPT-6.1 Sol+Galaxea 0.5 仿真 84% (38/45) vs 真机 64% (29/45)，Galaxea 0.5 为 67% → 53%，GR00T N1.7 为 56% → 24%，π0.5 为 49% → 18%，MolmoAct2-SO101 为 24% → 16%。
  • 仿真偏乐观：每个策略在仿真中高估 9–31 个百分点（agent 为 20 pp），配对回合中 57 例“仿真成功/真机失败”对 10 例反向，因此绝对成功率应视为上界，但策略间比较可迁移。
  • 排行榜结果：最佳学习型策略为 InternW0-Δ 61.4 [58.5, 64.1] 与 Galaxea 0.5 60.8 [57.9, 63.6]（统计并列），其后为 GR00T N1.7 45.8、ImageWAM 43.0、π0.5 41.0、LaWAM 39.9、MolmoAct2 base 23.8 / SO101 20.9、FLUX 3 Action 8.0。
  • LLM Agent 领先：GPT-6.1 Sol + PyRUA-Lean + Galaxea 0.5 得 83.2 [80.7, 85.7]，DeepSeek V4.1 Flash-1017 得 66.8 [63.7, 69.9]；两个 agent 均超过所有学习型策略。
  • 瓶颈定位：熟悉物体单件入箱已达 90–93%，但 next-to / between 仅 34–44%；跨 seen→unseen-class 下降 30–43 个百分点；PLAN 上无学习型策略超过 17%（agent 达 75%），MEM 最高 47%，ROBUST 用于区分视觉鲁棒性（LaWAM 39%→18%）。
  • Harness/模型消融（60 配对回合）：Sol 直接用工具调用 35% (21/60) → PyRUA-Lean 67% (40/60) → 交给 Galaxea 0.5 抓取 85% (51/60)，而 Galaxea 0.5 单独为 53% (32/60)；Gemini 4 Argon 65% → 77%，DeepSeek V4.1 30% → 65%，说明 harness 影响大于模型；同时真机上 agent 仍以 64% vs 53% 保持领先。
