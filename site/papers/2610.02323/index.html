Card 02 论文概述

论文概述

  • 论文提出 ProAct，一个面向 Vision-Language-Action（VLA） 模型的“世界校准式提案到动作流”（World-Calibrated Proposal-to-Action Flow）框架，核心思想是让扩散/流匹配的生成源分布本身变得可预测。
  • 指出现有基于流匹配的 VLA 策略从任务无关的各向同性高斯源出发，存在两个问题：(i) 丢弃了近期已执行动作建立的局部运动连续性；(ii) 即使引入预测式世界表征，也只条件化传输动力学，而未决定从哪里开始生成、允许偏离多远、沿哪些方向扩展。
  • 目标是构造“propose–calibrate–refine”（提议–校准–精炼）流程，使生成从更接近专家动作流形的区域起步，从而同时提升精度与推理效率。
Card 03 核心贡献

核心贡献

  • 提出 propose–calibrate–refine 的生成式动作预测范式：以近期运动作为局部软假设，用任务一致的未来预测对其进行校准，在局部运动连续性与未来感知的动作生成之间建立显式接口。
  • 设计不对称的、提案感知的 World Expert：用运动辅助未来预测，但期望未来的锚点独立于提案是否正确；并在每个 horizon 步联合预测提案专属的精炼幅度（extent）与几何（geometry）。
  • 用世界校准的、以提案为中心的各向异性源分布替换流式 VLA 原有的各向同性高斯源，同时保持基座 VLA 的传输参数化不变。
  • 在大量仿真基准与真实机器人操作任务上验证有效性，相对 π₀.₅ 降低去噪步数达 50%、推理延迟最多降低 25.8%、吞吐量最多提升 34.8%。
Card 04 方法描述

方法描述

  • 整体流程：由共享 VLM 上下文（逐层 K/V 缓存）驱动三个专家——Proposal Expert（提议）、World Expert（世界建模与校准）、Action Expert（动作流精炼）；生成过程分解为 p(A\|C,Hᵃ) = ∭ p_θ(A\|X,Hʷ)·p_η(X\|P,Hʷ)·p_ω(Hʷ\|P)·p_φ(P\|Hᵃ)。
  • 动作提议（Motion-Informed Action Proposal）：对近期动作做平滑（mₜ = βmₜ₋₁+(1−β)Δaₜ）并带衰减外推得到动量先验 Aᵗᵐᵒᵐ；轻量 Proposal Expert 仅用 6 层（VLM 为 18 层）与单步流时间 t_p=1，将动量先验作为“源”而非噪声，经一次 Euler 端点步得到场景感知提案 Pₜ。
  • 三层 KV 融合（Three-Layer KV Fusion）：深层提案层 j 从 VLM 深度集合 S_j={3j−2,3j−1,3j} 取压缩缓存，按免参可靠性权重 w∝σ̂⁻²（窗口内离散度估计噪声）加权平均，无需学习融合参数即可对齐深度差。
  • 世界专家与不对称监督：以冻结的 V-JEPA 2 编码器（来自 V-JEPA 2-AC）潜空间作为未来预测目标，空间池化与归一化后作回归；未来目标始终是示教未来而非执行提案的反事实结果，使提案保持为“软运动先验”，避免不准确提案自我合理化。
  • 校准读出：从同一世界表征中解码精炼幅度 U（由提案–未来残差的尺度化范数经 e=‖D_a⁻¹r‖/√d_a、U*=1−exp(−e/τ_u) 监督）与低秩几何 B（C = σ²d_a(I+BBᵀ)/tr(I+BBᵀ)），并投影到 ‖B‖²_F ≤ S_max（取 S_max=5）以给条件数设预算，保证数值良态。
  • 动作精炼：采样 X_src = P + Lε（L Lᵀ 为分块对角协方差），沿基座 VLA 原始线性流路径 X_s = s·X_src + (1−s)A* 与速度目标 v* = X_src − A* 做流匹配；总损失为 L = λ_p L_prop + λ_f L_future + λ_u L_U + λ_b L_B + λ_a L_flow。
  • 效率来源：起始点更接近动作流形，缩短所需传输距离，从而可用更粗的积分网格、更少去噪步数，并减少积分误差累积。

Card 06 评估与结果

评估与结果

  • 评估设置：仿真与真实机器人闭环控制，回融疑问 Q1–Q4：是否优于强 VLA 基线、扰动/长程条件下增益是否更大、各组件贡献如何、校准是否提升精炼质量与生成效率。
  • 主要指标：LIBERO 与 LIBERO-Plus 的任务成功率（%）（LIBERO 每套件 500 次 rollout）；RoboTwin 2.0 的成功率（%）；真实机器人任务成功率；以及去噪步数、推理延迟与吞吐量。
  • LIBERO 结果：ProAct 平均成功率 98.4%，比主干 π₀.₅（96.9%）高 1.5 个点；在单阶段套件接近饱和时仍优于对比方法，Long 套件上提升达 3.6 点（96.0%）。
  • LIBERO-Plus 结果：总分 86.8%，显著超过 π₀.₅ 的 73.6%；在 camera（76.1%）、robot（80.3%）、light（97.8%）、background（95.5%）、noise（90.2%）、layout（86.2%）等扰维度上均取得最优或领先表现。
  • RoboTwin 2.0 结果：平均成功率 60.3%，远超 π₀.₅（28.6%）；单项如 Place Burger Fries 84%、Pick Dual Bottles 78%、Put Bottles Dustbin 69%。
  • 效率结果：相对 π₀.₅，去噪步数减少 50%，推理延迟最多降低 25.8%，吞吐量最多提升 34.8%，表明校准源在提升精度的同时显著加快采样。
