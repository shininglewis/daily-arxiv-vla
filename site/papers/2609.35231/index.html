Card 03 核心贡献

核心贡献

  • 提出一种免训练、模型无关的引导式避障程序，适用于任何基于扩散或流匹配的动作块（action-chunk）策略，覆盖扩散策略与 VLA 模型。
  • 设计可微动作空间解码器，支持绝对/相对关节位姿以及末端执行器位姿等多种常见动作参数化方式，实现全身（whole-body）碰撞检测。
  • 通过将有符号距离场（SDF）梯度注入策略的去噪循环，在保持任务流形的同时推开障碍物。
  • 在两个仿真基准（球面约束任务、LIBERO-Object）上验证：NUDGE 在保持任务分布的同时避免碰撞。
  • 在真实机器人上部署微调后的 π₀ VLA 驱动 UR5 对抗动态障碍物，每个动作块仅增加 2.5 ms 开销。
Card 04 方法描述

方法描述

  • 总体思路：将每次去噪产生的中间动作块视为候选的短时域机器人运动；通过可微解码器从策略的动作表示映射到未来关节构型序列，评估全身避障间隙，并将碰撞代价对动作块求导。

  • 可微动作空间解码器：提供关节位姿、关节增量、EEF 位姿、EEF 增量四种解码方式（含逆运动学 IK 形式）。

Card 06 评估与结果

评估与结果

  • 评估环境与基准：

- 球面约束任务（200 个 episode，起止点相同，障碍物一致）——可控且流形可显式测量。

- LIBERO-Object 场景中注入未见过的球形障碍物（单个与三个障碍物条件，每条件每种方法 100 个 episode）。

- 真机 UR5 + π₀ VLA 对动态障碍物部署。

  • 基线方法：RAIL、OmniGuide、Post-Projection、Vanilla（无引导扩散策略）。
  • 主要评估指标：成功率（Success / SR）、到达率（Reach）、发生碰撞的 episode 比例（Coll. Ep.）、碰撞步骤比例（Coll. Rate）、流形保持（On-Sphere，距球面 5 cm 内的步数比例）、球面误差（Sphere Err., cm）；真机系统延迟。
  • 关键实验结果：

- 球面约束任务：NUDGE 在 ρₖ = 0.07 时取得最高综合成功率 71.5%，碰撞率仅 0.21%、碰撞 episode 仅 2.5%；而 Vanilla 为 37.0%、Post-Projection 为 25.0%、OmniGuide 为 39.0%、RAIL 为 37.5%（RAIL 碰撞率为 0 但到达率仅 37.5%）。

- NUDGE 在保持流形（On-Sphere 约 83.0%、Sphere Err. 2.87 cm）的同时显著降低碰撞，而 Post-Projection 流形保持崩溃（On-Sphere 56.4%、Err. 4.84 cm）。

- LIBERO-Object 单障碍物：NUDGE 平均成功率 44%，高于 Unguided（30%）、OmniGuide（30%）、RAIL（1%），且碰率更低（2.30%）。

- 真机：NUDGE 避免障碍物，每个动作块额外开销仅 2.5 ms，可实时反应运行。
