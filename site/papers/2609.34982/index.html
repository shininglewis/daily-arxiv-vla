Card 02 论文概述

论文概述

  • 论文提出 ActionUNet，一个高效的多尺度微调框架，用于提升预训练 VLA（Vision-Language-Action） 模型的鲁棒性，同时保持极低的训练与推理成本。
  • 核心问题是 时间尺度失配（temporal scale mismatch）：VLA 模型将粗粒度的多模态语义直接映射到细粒度动作序列，缺少多尺度时间结构，导致泛化能力受限、在杂乱环境中鲁棒性不足。
  • 论文进一步发现，直接引入多尺度建模会破坏动作的时间连续性，造成尺度边界插值误差、轨迹不平滑与机械抖动。
Card 03 核心贡献

核心贡献

  • 提出 ActionUNet 多尺度微调框架，在时间对齐的动作特征空间中构建轻量级 Temporal U-Net，以极低计算成本为预训练 VLA 注入层次化结构先验。
  • 设计 Conditional SIREN 连续动作解码器，以多尺度融合特征为条件输入，通过显式二阶平滑约束保证时间连续性并抑制高频运动抖动。
  • 引入 Matérn-5/2 核 对局部 SIREN 场进行平滑融合，并采用时间相关流噪声（temporally correlated flow noise）匹配 C² 连续性先验。
  • 在 RoboTwin 2.0、LIBERO-Plus 及真实双臂平台硬设定下，分别将 π0.5 成功率绝对提升 9.8%、6.1%、11.4%。
  • 方法对 OpenVLA-OFT（基于回归的策略）同样有效，验证其跨 VLA 框架的通用性与兼容性。
Card 04 方法描述

方法描述

  • Temporal U-Net（动作特征空间）：以动作特征 h⁽⁰⁾ ∈ ℝ^(H×d) 为输入，通过 Conv1D + GeLU + LayerNorm 逐级下采样（每级时间分辨率减半，r=2），再经最近邻上采样与跳跃连接（Fuse 线性层）恢复分辨率，注入多尺度层次先验。
  • Conditional SIREN 解码器：将动作块视为归一化时间 τ ∈ [-1,1] 上的连续轨迹采样；把 SIREN 各层的静态偏置替换为时间仿射函数 φₘ^τ(z) = sin(Wₘz + Uₘτ + bₘ)，使每一层具备显式时间感知，保证对 τ 无限可微。
  • Matérn 核平滑融合：全局连续函数 ψ(τ) = Σ αᵢ(τ)Φᵢ(τ)，权重 αᵢ(τ) ∝ κ₅/₂(\|τ-τᵢ\|/ρ)，鼓励相邻特征位置间的二阶时间平滑。
  • 训练目标：兼容直接回归（ℓ₁ 损失，L_reg）与流匹配（MSE 速度场损失，L_fm）两种策略；对 flow 模式使用 Matérn-5/2 过程噪声 K_ij = κ₅/₂(\|i-j\|/σ) + εδ_ij。
  • 微调策略：冻结预训练 VLA 主干，仅微调动作专家，可在基座模型原始目标下训练，训练与推理开销均很低。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：

- RoboTwin 2.0：50 个双臂任务，选取 12 个覆盖不同时间尺度组成；每任务 50 条干净演示，easy/hard 各 100 次 rollout 评估。

- LIBERO：4 个套件（Spatial、Object、Goal、Long），每套 10 任务、50 条演示，混合训练。

- LIBERO-Plus：在 LIBERO 基础上增加 7 类扰动（相机、机器人状态、语言、光照、背景、传感器噪声、布局），用 LIBERO 训练模型直接评测鲁棒性。

  • 真实机器人：Realman Gen72 双臂平台，3 个 Intel RealSense D435 相机（两个腕部 + 一个头部），任务为 Place Object Basket、Stack Blocks Two、Stack Bowls Two。
  • 基座模型：π0.5（flow-based）与 OpenVLA-OFT（regression-based）。
  • 训练资源：RoboTwin 2.0 使用 2×RTX 4090，8K steps，batch size 64，学习率 5×10⁻⁵（余弦衰减）；LIBERO/LIBERO-Plus 使用 8×A800，40K steps，batch size 256。
  • 超参数：时间金字塔下采样率 r=2，Matérn 长度尺度 ρ=0.2，采用标准 SIREN 初始化。
Card 06 评估与结果

评估与结果

  • 评估指标：平均成功率（average success rate, %），覆盖 easy/hard 及 7 类扰动条件。
  • RoboTwin 2.0：平均成功率由 59.6% 提升至 68.4%（easy，+8.8%），由 29.8% 提升至 39.6%（hard，+9.8%）；单尺度任务 easy/hard 由 66.0%/34.0% → 72.7%/44.0%，三尺度任务由 52.0%/25.7% → 62.0%/34.3%。
  • LIBERO：π0.5+ActionUNet 平均 97.7%（vs 95.6%）；OpenVLA-OFT+ActionUNet 平均 98.6%（vs 97.9%）。
  • LIBERO-Plus：π0.5+ActionUNet 平均由 65.8% → 71.9%（相机 48.2→56.9，机器人状态 45.9→54.4，噪声 52.0→61.1 等）；OpenVLA-OFT+ActionUNet 由 60.9% → 64.6%。
  • 真实世界：easy 由 76.0% → 88.7%，hard 由 57.3% → 68.7%（三个任务全面提升）。
  • 消融实验：分别验证 Temporal U-Net、Conditional SIREN 与 Matérn 融合各自的增益，完整 ActionUNet 效果最佳。
