论文概述

  • 论文针对双臂机器人操作中的两类异质性难题：感知异质性（多视角视觉信息的相关性随任务阶段动态变化）和交互异质性（双臂在独立运动与协调运动模式间切换），提出一种双层结构分解框架（Dual-Level Structural Decomposition Framework）

Card 03 核心贡献

核心贡献

  • 提出双模块架构：VSR 在 VLM 输入阶段根据任务上下文动态调制左右腕部视觉 token 的权重，IAMoE 在条件流匹配的 velocity prediction 阶段将动作生成分解为协调专家和左右臂独立专家
  • 提出基于路由的结构化动作生成机制：Action Router 通过硬 one-hot 交互模式选择（协调或独立），并使用 straight-through Gumbel-Softmax 保持训练时梯度传播与推理时一致的动作结构
  • 设计KNN 半自动标签生成流程，为 VSR 和 Action Router 提供监督信号，降低人工标注成本
  • 在仿真（RoboTwin 2.0）和真实世界双臂操作任务上分别提升平均成功率 27.7% 和 43.3%，且显著优于仅含单一模块的消融变体
Card 04 方法描述

方法描述

  • VSR（视觉层）：利用外部视图 token 和语言-状态 token 构造路由上下文，预测左右腕部视图的相关性权重 w_t ∈ [0,1]²，对腕部视觉 token 进行重加权后送入预训练 VLM
  • IAMoE（动作层）：由三个基于 LoRA 的专家组成——协调专家处理全动作空间，左右臂专家分别通过动作掩码 M^L、M^R 限定于各自的子空间；Action Router 根据路由上下文选择协调或独立模式，决定最终 velocity field
  • 训练目标：总损失 = 主动作损失 L_main（条件流匹配）+ 路由监督损失（L_vis 为二值交叉熵、L_act 为交叉熵）+ 辅助专家损失 L_aux（确保所有专家获得充分学习信号），其中 λ_aux 随训练逐渐衰减
  • 创新点：显式分离感知与动作的异质性来源，通过轻量路由器实现任务相关的动态选择，避免 monolithic 策略中的表征纠缠
Card 05 数据集与资源

数据集与资源

  • 仿真任务：RoboTwin 2.0 中的 6 个双臂操作任务（S1 Stack Bowls Three、S2 Blocks Ranking Size、S3 Lift Pot、S4 Place Bread Skillet、S5 Handover Block、S6 Put Bottles Dustbin）
  • 真实世界任务：3 个长时程六阶段任务（R1 Pack and Place、R2 Handover and Pour、R3 Rotate and Place）
  • 基础模型：π₀.₅（视觉-语言-动作流模型）
  • 训练配置：每个任务分别训练，LoRA 微调 30,000 步，batch size 16；仿真每任务 50 个演示，真实世界每任务 40 个演示
  • 评估配置：仿真每任务 100 次 rollout（同一随机种子）；真实世界 easy 条件每任务 10 次试验，hard 条件仅评估 Baseline 与 Ours
Card 06 评估与结果

评估与结果

  • 评估环境与基准：仿真与真实世界均区分 easy/hard 两种设置；对比 Baseline（monolithic π₀.₅）、w/o IAMoE（仅 VSR）、w/o VSR（仅 IAMoE）和 Ours（完整模型）
  • 仿真结果：Ours 平均成功率 69.6%，远超 Baseline（41.9%）、w/o IAMoE（54.3%）和 w/o VSR（59.7%）；在 hard 设置下相对 Baseline 提升 +35.7%
  • 真实世界结果：Ours 在 R1、R2、R3 上 hard 设置相对 Baseline 分别提升 +30%、+40%、+50%；Ours 在 R2、R3 上即使面对未见环境仍保持 60% 成功率
  • 消融分析：VSR 在感知异质性显著的任务（S1、S2）增益最大（S2 hard 下 +37%）；IAMoE 在交互异质性显著的任务（S3、S4）增益最大（S3 hard 下 +28%、S4 hard 下 +30%）；在两类异质性同时存在的复杂任务（S5、S6）上，双模块组合比单模块变体在 hard 下平均提升 13.2%–17.3%
