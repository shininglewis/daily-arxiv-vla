UniWALM: Unified World Action Language Model for Embodied Robot Control

2026-10-20 · 原文 · 翻译 · 2610.28626

提出 UniWALM，一个统一的 World-Action-Language Model（世界-动作-语言模型），在单一共享表示中同时学习视频、动作、语言三种模态，每种模态既是条件信号也是监督目标。 针对现有方法（VLA、CoT-VLA、世界动作模型、混合规划器系统）只能沿部分方向连接模态、语言仅作固定条件或依赖外部规划器/检索缓存的问题，论文追问：联合生成语言能否增强共享表示并提升操作能力，以及策略能否把自生成语言当作跨步工作记忆。 目标是用单一端到端模型替代由 VLM 规划器与视频-动作主干组成的、松耦合的串联式方案，并支撑长时序、依赖记忆的机器人操作任务。

Card 03 核心贡献

核心贡献

  • 提出 WALM（World Action Language Model）：以 Mixture-of-Transformers 实现的统一模型，输入视频、语言、动作，并同时生成三者；语言流在一次去噪中同步输出子任务（subtask）与文本记忆（textual memory），并在下一步作为 prompt 重新消费，形成“语言即记忆”闭环，无需外部规划器或记忆库。
  • 语言与动作专家完全从零训练于一个仅视频预训练的主干，不使用任何预训练语言模型或推理模型。
  • 提出 Flow Matching with Correction（FMC） 训练目标：训练时对动作轨迹施加扰动并监督纠正速度，让模型学会从动作空间扰动中恢复，推理阶段零额外开销（不增加条件、采样步数或模型容量）。
  • 设计三种内嵌记忆机制：文本记忆复用、视觉记忆（锚点关键帧）与任务完成信号 β（拼接进动作向量、门控记忆更新时机）。
  • 在仿真与真实世界操作任务上系统验证：MolmoSpaces 组合式抓放、RMBench 记忆子集 M(n)、真实双臂灵巧操作与 Find-the-Item 记忆任务。
Card 04 方法描述

方法描述

  • 架构：以 Wan2.2 视频 DiT 为主干，复制其结构（各 30 层）并降低隐藏维度，新增 1B 动作 DiT（hidden=1024） 与 0.5B 语言 DiT（hidden=512）；每层模态专家各自做自适应 LayerNorm + Q/K/V 投影，沿 token 维拼接执行统一自注意力（带 RoPE），再对任务指令与本体感知做交叉注意力。
  • 语言专家：采用离散扩散（RandomReplace 加噪 + 交叉熵损失）与视频、动作同步去噪，输出“子任务 ‖ 文本记忆”短字符串；推理时关闭视频生成，语言 DiT 与动作 DiT 同步运行，并可用缓存实现交错式语言生成。
  • 协同训练目标：𝓛 = 𝓛_video + 𝓛_action + α·𝓛_lang，其中视频与动作用 ℓ1 flow-matching 损失（比 ℓ2 更稳定），语言用交叉熵；同时提供帧级（未来视频）与任务级（未来子任务与任务状态）两级预测监督。
  • 记忆机制：文本记忆仅在子任务完成时更新（由 β 门控）；视觉记忆以 RoPE 偏移的锚点帧 token 化注入；β 与动作联合监督，不额外加损失项。
  • FMC：构造扰动样本 x₀ᵖ = x₀ + ε₁（ε₁~N(0, sI), s=0.2），在 t≥0.5 时以概率 p=0.5 走纠正分支，目标速度 v_corr = (ε − x₀) + (1−t)/Δt·ε₁；该目标在干净路径上与标准 flow matching 完全一致，故推理不变。
  • 训练细节：视频主干用 LoRA（rank 256） 微调，8-bit AdamW；以 10% 概率随机丢弃本体感知；推理时禁用视频生成。
Card 05 数据集与资源

数据集与资源

  • MolmoSpaces：221K 轨迹（Pick、Pick-RandCam、Pick&Place、Pick&Place-NextTo、Pick&Place-Color），DROID 风格 Franka 平台，每任务 1000 个 OOD episode；消融实验使用 38K 的 Pick&Place 子集。
  • RMBench M(n) 子集：四个记忆任务（Press Button、Blocks Ranking Try、Cover Blocks、Battery Try），双臂 AgileX 桌面平台，每任务 50 条示范 / 100 个 rollout。
  • 真实世界：两台 Flexiv Rizon 机械臂配灵巧手（Sharpa Wave 或 Paxini），三个任务（Cube Pick&Place、Empty Container、Find the Item），每任务 20 个测试 episode（记忆任务 18 个）。
  • 模型规模：视频主干 Wan2.2（预训练）+ 1B 动作 DiT + 0.5B 语言 DiT，动作/语言专家从零初始化。
  • 训练资源：12 个 H200 节点 × 8 GPU，训练 44 小时；batch size 3840，学习率 4e-4，15k 步；动作 chunk N=32、视频视界 H=5、每次生成 64 个语言 token。
  • 推理时延：无语言生成 76 ms，含语言专家 123 ms（未优化，生成 32 步动作块、10 步去噪）。
Card 06 评估与结果

评估与结果

  • 评估设置：围绕两个问题——Q1 语言生成是否提升操作成功率；Q2 自生成语言能否作为工作记忆。统一使用与 FastWAM 相同主干的对照以保证公平性；仅在 RMBench M(n) 上启用锚点帧与 β 信号。
  • 主要指标：任务成功率（%），MolmoSpaces 报 95% 置信区间，真实世界报 95% CI 区间。
  • MolmoSpaces：UniWALM 在 Pick&Place 系列全面领先——Pick&Place 68.0、Pick&Place-Color 70.8、Pick&Place-NextTo 38.8（其余基线最高 66.5/67.8/32.0）；相对同主干 FastWAM 平均提升 +14.8%，相对 MolmoBot 在组合放置任务上平均 +7%；在短时程纯抓取任务（Pick、Pick-RandCam）上因 303 步预算限制略逊。
  • RMBench M(n)（记忆）：达到 34.5%，超过同主干 FastWAM（13.3%）+21.2 点，并优于配备特权关键帧的 Mem-0（28.5%），而 UniWALM 仅用单个锚点帧。
  • 真实世界：Cube Pick&Place 95.0%（次优 80.0%）、Empty Container 50.0%（与 FastWAM 持平）、Find the Item 从 FastWAM 的 11.1% 提升到 61.1%，而 SOTA VLA 均不超过随机水平（≤33.3%）；三项平均 68.7% 为最佳。
  • 消融：FMC 带来更精确的动作与更高成功率；语言流带来的增益随任务组合复杂度上升而增大，说明提升来自统一表示而非继承的 VLM 先验。
