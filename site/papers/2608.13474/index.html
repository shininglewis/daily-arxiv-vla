Decoding Task Progress from VLA Representations

2026-08-13 · 原文 · 翻译 · 2608.13474

本文研究视觉-语言-动作模型（VLA）的内部表征，重点关注 \(\pi_{0.5}\) 模型中任务进度（task progress）这一语义信号是否可线性解码，即轨迹中剩余时间的归一化比例。 核心发现：任务进度在 VLA 的残差流激活中线性可读，且该信号在预训练的 PaliGemma 骨干中已经存在，无需机器人数据训练即可提取。 论文将进度探针用作无标签 OOD 检测器，可检测任务停滞状态，并与有监督基线方法（如 SAFE）性能相当，为部署中的 VLA 提供轻量级运行时监控工具。

Card 02 论文概述

论文概述

  • 本文研究视觉-语言-动作模型（VLA）的内部表征，重点关注 \(\pi_{0.5}\) 模型中任务进度（task progress）这一语义信号是否可线性解码，即轨迹中剩余时间的归一化比例。
  • 核心发现：任务进度在 VLA 的残差流激活中线性可读，且该信号在预训练的 PaliGemma 骨干中已经存在，无需机器人数据训练即可提取。
  • 论文将进度探针用作无标签 OOD 检测器，可检测任务停滞状态，并与有监督基线方法（如 SAFE）性能相当，为部署中的 VLA 提供轻量级运行时监控工具。
Card 03 核心贡献

核心贡献

  • 提出了区分弱可解码性（weak decodability）、强可解码性（strong decodability）和可操控性（steerability）的正式定义，分离了"存在线性相关信号"、"依赖正确输入"与"对输出有因果影响"三层含义。
  • 证明任务进度在 \(\pi_{0.5}\) 的残差流中既弱可解码又强可解码（单一线性探针即可恢复），但不可线性操控——激活注入无法有效引导策略行为。
  • 验证了进度信号在大规模机器人预训练中涌现，而非微调阶段产生（对比 PaliGemma、base \(\pi_{0.5}\)、\(\pi_{0}\) 和微调 \(\pi_{0.5}\) 四种模型）。
  • 展示了进度探针在语言反事实（名词交换）下的响应行为：朴素探针忽略语言输入，而对比训练可恢复语言敏感性。
  • 将进度探针作为无监督 OOD 检测器，在跨任务和跨扰动模式上展现强泛化能力，无需 OOD 标签。
Card 04 方法描述

方法描述

  • 使用线性探针 \(\varphi(\mathbf{z}^i) = \mathbf{w}^\top \mathbf{z}^i + b\)，在 \(\pi_{0.5}\) 各层（SigLIP 视觉编码器、Gemma 语言层、动作专家层）提取残差流嵌入并预测任务进度。
  • 定义了进度特征 \(\tau(\mathbf{x}_t) = 1 - t/T\)（归一化剩余时间），并构造探针训练数据集 \(\mathcal{D}_{\text{probe}}\)。
  • 采用控制任务（shuffled labels）验证探针选择性，排除高容量 MLP 记忆随机标签的可能。
  • 使用对比探针训练（contrastive objective）增强语言反事实下的强可解码性，将名词交换的 shadow pass 标记为 \(\tau = 1.0\)。
  • OOD 检测通过计算预测进度与期望进度的残差 \(V_\tau(t) = \tau_{\text{pred}} - (1 - t/\mathbb{E}[T\|\ell])\)，超阈值即标记为 OOD。
Card 05 数据集与资源

数据集与资源

  • VLABench 数据集：10 个操作任务，每个任务 500 条轨迹，包含语义变化。
  • 目标模型：\(\pi_{0.5}\)（基于 PaliGemma 3B 视觉-语言骨干的 VLA 模型）。
  • 对比模型：PaliGemma 骨干、base \(\pi_{0.5}\)（微调前）、\(\pi_{0}\)（另一 VLA 架构）和 VLABench 微调后的 \(\pi_{0.5}\)。
  • 训练数据：400 条轨迹用于训练探针（每任务 100 条），50 条每任务用于验证。
  • 实验在仿真环境中进行，主要使用 GPU 资源（论文未具体说明 GPU 型号和数量）。
Card 06 评估与结果

评估与结果

  • 弱可解码性：进度信号在早期视觉骨干层和前几个 Gemma 层达到低 L1 损失（层 0 的 \(R^2 = 0.95\)），且高容量 MLP 在 shuffled-label 控制任务上表现差，验证了信号的真实性。
  • 跨模型对比：\(\pi_{0.x}\) 系列模型（预训练后）的性能显著优于仅 PaliGemma 骨干，说明进度特征由大规模机器人预训练建立。
  • 强可解码性：朴素层 0 探针在语言名词交换下无响应（弱可解码但非强可解码）；对比训练后层 10 探针在反事实下预测 \(\tau \approx 1.0\)，ID 性能 \(R^2 = 0.33\)（受代理标签噪声影响）。
  • 可操控性：在层 0 注入 \(\tau_{\text{boost}} = 0.2\) 后，后续层的预测进度不变，注入动作 \(\\|A_{\text{inj}} - A_{\text{GT}}\\|_2\) 与策略基线无显著差异，结论为进度特征不可线性操控。
  • OOD 检测（跨任务）：\(V_\tau\) 在 per-episode 级别对已见任务取得最佳 AUROC（0.910），未见任务 0.851；per-replan 级别未见任务 0.833（唯一不下降的检测器），但落后于有监督 SAFE-MLP（0.935）。
  • OOD 检测（跨扰动模式）：在未见扰动模式下，\(V_\tau\) 在 per-replan 取得 0.871、per-episode 取得 0.960，均超越有监督 SAFE 基线，且无需任何 OOD 标签。
  • OOD 定性分析：在 Gaussian 噪声、颜色偏移、模糊、遮挡四种扰动下，预测进度在注入点（\(k = 0.25, 0.5, 0.75\)）均出现停滞，提供清晰的检测信号。
