Uni-VLaT: Whole-Body Tactile Adaptation of VLA Policies for Humanoid Loco-Manipulation

Card 03 核心贡献

核心贡献

  • 触觉锚定的多模态学习：通过学习一个触觉锚定的多模态上下文，并施加辅助预测监督，同时预测未来触觉、本体感知与视觉表征，促使策略捕获物理交互的耦合演化。
  • 预训练 VLA 的触觉适配策略：在不从零训练策略的前提下，借助预训练 VLA 的语义、视觉与动作先验，把触觉信息落地到任务上下文中，支持接触丰富控制。
  • 大规模真实人形机器人评测：在 Unitree G1 上、跨两个预训练 VLA 主干（Isaac-GR00T、π0.5）以及一个从零训练策略对比，在五个真实任务上验证，并对触觉与预测组件做受控消融。
  • 揭示了触觉预测的上下文位置（post-DiT 触觉状态）与绝对未来目标（而非 delta 目标）对性能的关键作用。
Card 04 方法描述

方法描述

  • 空间触觉编码：触觉传感器覆盖八个身体区域（胸部、中背、左右肩、左右上背、左右臂）；使用固定死区抑噪并按区域归一化，袖套区域沿手臂周向池化以降低旋转敏感性；每个区域由独立 MLP 编码，再用 8 个可学习 query 对区域嵌入做交叉注意力，得到 8 个触觉 token。
  • 时间接触编码：用轻量级时间 Transformer 在 4 帧历史（H_T=4）上按 token 索引做时间注意力，加入学习的时间嵌入并经残差连接，最后用可学习标量门控后送入预训练策略。
  • 策略集成：触觉 token、本体感知 token 与含噪动作 token 在 VLA 的 DiT 主干中联合处理；视觉与语言特征经交叉注意力注入；动作 token 输出投影为 flow matching 速度预测，生成运动 token 块。
  • 触觉锚定的多模态预测：对 post-DiT 触觉 token 做均值池化得到紧凑上下文 c_t，再由三个模态专用 MLP 预测器分别预测未来 触觉/本体感知/视觉 的潜在表征（未来 4 步）。
  • 目标表征与损失：触觉与本体使用 EMA 目标编码器，视觉编码器冻结；目标用 stop-gradient；损失结合余弦方向对齐与 SmoothL1 幅值回归（β=1），总损失为动作损失加三项预测损失，权重 λ_T=0.05、λ_P=λ_V=0.005。
  • 训练与部署：冻结预训练 VLM，微调 action expert、状态编码器与触觉模块；预测头与 EMA 目标编码器仅训练时使用；部署时动作 token 经 SONIC Protocol v4 接口送入解码器输出关节位置目标，由 PD 控制器跟踪。

Card 06 评估与结果

评估与结果

  • 评估环境：真实机器人 rollout，主表配置每任务 20 次 rollout；跨策略 π0.5 配置每任务 10 次；消融中 Full Uni-VLaT 复用 20 次结果，其他变体用 10 次；不稳定、跌倒、急停或人工干预均记失败。
  • 五个真实任务：(a) Table Sweeping、(b) Basket Loading、(c) Back-Tap Walking、(d) Human–Robot Hugging、(e) Composed Cleanup。
  • 主要指标：成功率（SR）；对长时程的 Composed Cleanup 额外报告三阶段归一化得分（把垃圾扫入盒中、举起盒子、搬到垃圾桶各占 1/3）。
  • 主结果（Isaac-GR00T）：Uni-VLaT 平均成功率 75%，较 No Tactile（32%）提升 43 个百分点，较 Tactile w/o Pred.（68%）提升 7 点，较仅触觉预测（69%）也更高；剔除 Back-Tap Walking 后平均为 72.5% vs 63.8%。
  • 任务级提升：Table Sweeping 60%→75%，Basket Loading 65%→80%；Back-Tap Walking 上无触觉为 0%，所有含触觉变体达 85–90%。
  • 跨主干迁移：Isaac-GR00T 上 Table Sweeping 45%→75%、Basket Loading 30%→80%、Back-Tap Walking 0%→85%；π0.5 上 Table Sweeping 30%→60%、Basket Loading 30%→60%、Back-Tap Walking 0%→90%；两个主干上 Table Sweeping 均提升约 30 点，Back-Tap Walking 提升 85–90 点。
  • Composed Cleanup 阶段得分：Isaac-GR00T 43.3→70.0，π0.5 26.7→46.7。
  • 接触动力学分析：在 Basket Loading 中，No Tactile 一开始就保持较大接触响应且随加载变化不明显；Uni-VLaT 保持更温和的接触水平并随负重增加逐步响应，说明其根据触觉反馈自适应调整交互。
  • 消融结果（Isaac-GR00T）：Full Uni-VLaT 平均 80%，Multimodal-Input Prediction 60%，Pre-DiT Tactile Prediction 55%，Delta Prediction Targets 仅 35%；Table Sweeping 上分别为 75%/40%/30%/20%，说明后 DiT 触觉上下文与绝对未来目标至关重要。
  • 局限性（作者自述）：阵列传感器对噪声与安装差异敏感；全身触觉仿真有限，限制大规模鲁棒性研究；评测仅覆盖五个代表性任务，未来需扩展到更精细触觉调节与接触控制的场景。
