Card 03 核心贡献

核心贡献

  • 提出 StreamPI 流式多模态时间建模框架，将每个（视觉观测，语言指令）对视为原子时间单元，采用指令锚定建模以保持任务执行过程中的持续任务感知。
  • 引入随机间隔流式训练策略，通过暴露模型于多样帧时序扰动，弥合同步训练与异步真实机器人部署之间的差距。
  • 利用 LLM 骨干的长度外推能力，StreamPI 无缝继承 π0.5 的全部预训练权重，不增加参数量，同时支持灵活的单帧与多帧推理。
  • 在真实机器人操作（记忆依赖与精细感知任务）及 LIBERO 仿真基准上的大量实验表明，StreamPI 在各类任务上一致优于 π0.5。
Card 04 方法描述

方法描述

  • 指令锚定时间建模：将每个（多视角图像，语言指令）对视为不可分割的原子时间单元；单元内部采用双向注意力实现跨模态融合，单元之间采用因果注意力保持自回归流式推理结构。
  • 参数免费的时间扩展：仅通过重组现有 VLA 骨干的注意力掩码实现分层注意力模式，利用 LLM 长度外推能力继承全部预训练权重，无需新增任何参数。
  • 随机间隔采样：训练时在基础帧间隔 δ̄ 上添加均匀随机扰动 ε~U(−Δ,+Δ)，使模型适应部署时的异步观测到达率。
  • 时间掩码：随机掩蔽最早 k 帧，模拟流式推理中观测逐帧到达的模式，进一步对齐训练与推理。
  • 流式推理：缓存历史时间步的 Key&Value 表示，新帧仅需编码自身并通过交叉注意力访问缓存，避免重复计算，推理成本与时间跨度无关。
Card 05 数据集与资源

数据集与资源

  • LIBERO 仿真基准：包含 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long 四个套件，每套 10 个任务，每任务 50 次试验。
  • CALVIN 仿真基准：用于评估长时程多任务连续操作能力。
  • 真实机器人任务：涵盖记忆依赖型任务（Shell Game、Rolling Object Grasping）与精细感知型任务（Pen Insertion into Narrow Bottle、Cup Insertion into Cup Sleeve）。
  • 模型基础：基于 π0.5 预训练 VLA 模型，参数量与 π0.5 一致，无新增参数。
  • 训练资源：8 张 NVIDIA H100 GPU；LIBERO 使用 batch size 256、30k 步迭代，真实机器人任务使用 batch size 128、50k 步迭代。
Card 06 评估与结果

评估与结果

  • 真实机器人操作：StreamPI 在记忆依赖任务上大幅超越 π0.5 —— Rolling Object Grasping +36.6%，Cup Hiding and Retrieval +33.3%；在精细感知任务上同样显著领先 —— Pen Insertion +26.7%，Cup Insertion +32.0%。
  • LIBERO 仿真基准：StreamPI（T=5）平均成功率 98.3%，较 π0.5（96.9%）提升 1.4%；LIBERO-Long 提升最为显著（+2.6%），LIBERO-Goal 也获得 +2.8% 的提升。
  • CALVIN 基准：StreamPI（T=5）平均序列长度达 4.547，优于 π0.5（4.313）和 MemoryVLA（4.090）；在第 5 个连续任务上保持 85.0% 成功率，显著高于 π0.5 的 79.5% 和 MemoryVLA 的 69.4%。
  • 消融研究：双向 intra-pair 注意力与因果 inter-pair 注意力均对性能有正向贡献；随机间隔训练较固定间隔（δ=1）在 T=3 和 T=5 下分别提升 1.1% 和 1.3%；训练 T=5 的模型在测试时减少至 T=3 或 T=1 仍保持较高性能，展现了跨流泛化能力。
