Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs

2026-11-03 · 原文 · 翻译 · 2611.05249

研究对象是 Mixture-of-Transformers 式 VLA：预训练 VLM 负责处理视觉与语言输入，并通过逐层 K/V 缓存为 flow-matching 动作专家提供条件；论文探讨这种架构下“动作专家的损失是否应当回传并更新 VLM”这一训练决策。 核心问题是：动作专家到 VLM 的梯度流（coupling）与离散动作 token 监督这两个让 VLM 表征“变得可动作”的信号，是否互相替代；以往工作中被普遍采用的 gradient insulation（梯度隔离） 是否真的必要。 通过在自动驾驶与机器人操作两个领域独立交叉变化 “action-token supervision” 与 “expert→VLM 梯度路由” 两个因素，论文论证 VLM 隔离是一种条件性选择，而非 VLA 的默认训练配方。

Card 02 论文概述

论文概述

  • 研究对象是 Mixture-of-Transformers 式 VLA：预训练 VLM 负责处理视觉与语言输入，并通过逐层 K/V 缓存为 flow-matching 动作专家提供条件；论文探讨这种架构下“动作专家的损失是否应当回传并更新 VLM”这一训练决策。
  • 核心问题是：动作专家到 VLM 的梯度流（coupling）与离散动作 token 监督这两个让 VLM 表征“变得可动作”的信号，是否互相替代；以往工作中被普遍采用的 gradient insulation（梯度隔离） 是否真的必要。
  • 通过在自动驾驶与机器人操作两个领域独立交叉变化 “action-token supervision” 与 “expert→VLM 梯度路由” 两个因素，论文论证 VLM 隔离是一种条件性选择，而非 VLA 的默认训练配方。
Card 03 核心贡献

核心贡献

  • 首次将 action-token supervision 与 expert-to-VLM gradient routing 两个因素解耦，在固定数据、架构、优化与语义共训练的受控设置下进行 2×2（再加训练日程）因子实验。
  • 发现在开环驾驶中，有 action-token 监督时 insulation 与 coupling 几乎无差别；没有 action token 监督时，coupling 将轨迹预测误差降低约 25%（Public Golden 约 26%、OOD 约 24%）。
  • 在闭环驾驶中，coupling 一致提升路线完成度：有 token 监督时为 0.600→0.703（约 +17%），无 token 监督时为 0.425→0.601（相对提升约 40%）。
  • 将结论迁移到机器人操作（π0.5 复现与 MolmoAct2），coupling 在有无 FAST 监督下均提升任务进度，且无 FAST 时增益更大，说明结论不局限于驾驶域。
  • 指出训练顺序（concurrent / VLM-first / expert-first）只改变效应大小，不改变其依赖关系；并发现 concurrent 联合训练取得跨日程最佳绝对性能，与既有 VLM-first 配方形成对照。
Card 04 方法描述

方法描述

  • 采用 Alpamayo 风格的 MoT-VLA：Qwen3-VL-2B-Instruct 主干 + 同宽度、非因果的 flow-matching 动作专家；专家在每层注意力中读取对应 VLM 层的 K/V，VLM 不关注专家的连续动作输入。
  • 动作表示为 K 组（加速度、曲率）控制量，经离散化独轮车模型积分得到位置与航向路点；VLM 同时输出场景推理 rationale 与未来轨迹 token。
  • 联合目标为 L = L_CE + L_flow：CE 覆盖 VQA/推理/轨迹定界符，以及（可开关的）未来动作 token；flow 采用 rectified flow matching，时间采样 b~Beta(1.5,1.0)、t=0.999(1-b)。
  • 关键干预一：gradient routing —— coupled 时 H̃_θ = H_θ；insulated 时 H̃_θ = sg(H_θ)，仅阻断反传、不改变前向。
  • 关键干预二：action-token supervision —— 通过指示函数 1_action 关闭未来动作 token 的 CE，token 仍以 teacher-forcing 方式保留在上下文中，并固定被监督位置数 N 以保持其他 CE 项权重。
  • 关键干预三：训练日程 —— concurrent（同时训练）、expert-first（先冻结 VLM 训专家 100k 步）、VLM-first（先单独训 VLM 100k 步），总步数统一为 300k。
Card 05 数据集与资源

数据集与资源

  • 开环驾驶：PhysicalAI-Autonomous-Vehicles 数据集，Public Golden（1,434 场景）与 OOD（273 场景）两个 split；评估采样 6 条候选轨迹，主指标为 ADE，另有 minADE 作为 oracle 指标。
  • 闭环驾驶：AlpaSim 模拟器，827 个场景 × 5 次随机 rollout。
  • 推理质量评估：冻结的 Lingo-Judge 分类器计算 rationale 通过率。
  • 机器人操作：PolaRiS 三个任务（BlockStackKitchen、FoodBussing、PanClean），每条件每任务 50 次 rollout；训练数据为 DROID（90%）+ PolaRiS 训练数据（10%），VQA 混合 VQAv2 / COCO caption & localization / Visual Genome。
  • 模型规模：Qwen3-VL-2B-Instruct（驾驶）、PaliGemma-3B（π0.5 复现）、Molmo2-ER（MolmoAct2）；训练步数分别为 300k（驾驶 / MolmoAct2）与 400k（π0.5 复现）。
  • 计算资源：正文未给出具体 GPU/TPU 型号与数量，仅说明受算力限制，每个条件只做了一次训练，因此未度量训练随机种子带来的方差。
Card 06 评估与结果

评估与结果

  • 评估环境覆盖 开环驾驶（ADE / minADE）、闭环驾驶（AlpaSim 路线完成度、碰撞等安全指标）、生成推理轨迹质量（Lingo-Judge 通过率） 与 闭环机器人操作（归一化任务进度）；统计上使用 10,000 次按 clip 聚类的配对 bootstrap 给出 95% 置信区间。
  • 开环结果：有 action token 时 insulation 与 coupling 差异很小（Public Golden 上 insulation 略优）；无 action token 时 insulation 显著变差，coupling 降低 ADE 约 25%（Public Golden 26%、OOD 24%），且该模式在三种训练日程、分布内与 OOD 上均成立。
  • 闭环驾驶路线完成度：concurrent 下 coupling 使 0.600→0.703（tokens on）、0.425→0.601（tokens off，+17.6 个百分点，相对约 41%）；无 token 的 coupled 模型接近有 token 的 insulated 模型；整体最佳为 concurrent + coupled + tokens on（0.703）。
  • 推理质量：insulation 在所选 vision–language 共训练配方下并没有表现出稳定的 rationale 质量优势；在部分设置下 coupled 反而更高（如 concurrent tokens-on 下的 Public Golden 0.649 vs 0.647），OOD 方向不一致。
  • 操作任务：π0.5 复现中 coupling 使进度 19.5%→30.7%（FAST on）、10.3%→32.9%（FAST off）；MolmoAct2 中为 22.0%→24.3%（FAST on）、14.5%→36.5%（FAST off），四条件中最佳均为 “coupled + 无动作 token”。
  • 安全与局限：在有 token 监督的分阶段训练中，coupled 的 at-fault 碰撞率观测值更高；论文仅覆盖一个驾驶模型族与两个操作模型族、且全部为仿真评估，未上真机，也未做多随机种子重复。
