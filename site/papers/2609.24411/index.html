Card 03 核心贡献

核心贡献

  • 提出 Zeva-Ego 两阶段框架，将自我中心视频中期训练与 ICCL 条件动作生成相结合。
  • 开发以动作为中心的数据处理与表示管道，将 Ego 视频转换为用于 VLA 中期训练的连续动作 token 监督。
  • 系统分析动作表示、数据缩放和交互适应，证明 10K 小时 Ego 视频可匹配 2K 小时机器人数据，且冻结 ICCL 将跨尝试成功率从 58% 提升至 89%。
  • 引入 ACE 两阶段训练机制（动作条件残差学习与视觉动作提取）和 ICCL 引擎（CTE、BIT、PIM），实现跨具身动作几何对齐和部署时免参数适应。
Card 04 方法描述

方法描述

  • 两阶段学习：第一阶段在 π0.5 初始化基础上，使用大规模 Ego 视频进行中期训练，通过 ACE 从 RGB 帧对生成连续动作 token 监督，并采用统一 16D 末端执行器（EEF）状态/动作表示与相机帧动作块。
  • 第二阶段将 ICCL 集成到低级动作生成：Causal Transition Encoder (CTE) 将视觉状态、执行动作和观察反馈编码为因果交互证据；Brief Interaction Trace (BIT) 存储当前尝试内的近期证据，Persistent Interaction Memory (PIM) 累积跨尝试的阶段匹配经验。
  • 因果上下文 M_t 仅注入 Action Expert，不修改高层 VLM 路径；部署时所有模型参数冻结，仅在线更新交互记忆与因果上下文。
  • 关键技术包括：ACE 两阶段训练（动作条件解耦与视觉动作提取）、块锚定相机帧动作表示、多粒度指令合成、工业级数据清洗引擎。
Card 05 数据集与资源

数据集与资源

  • 机器人数据集：AgiBot World（真实双臂操作）、InternData-A1（7,434 小时合成数据，涵盖 4 种具身、18 种技能、70 项任务）。
  • 自我中心人类数据集：EgoDex（约 830 小时，194 项桌面操作任务）、EgoVerse（1,362 小时，约 80,000 个 episode）、Ego4D（3,670 小时，无动作标签）、Egocentric-10K（10,000 小时，使用 4,439 小时工厂数据）。
  • 基础模型：基于 π0.5（PaliGemma-based VLA），包含视觉编码器、VLM Transformer 主干和 flow-matching Action Expert。
  • 训练资源：论文未明确说明 GPU/TPU 具体配置，但涉及总计约 10K 小时 Ego 视频和数千小时机器人数据的大规模训练。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0（模拟双臂操作，Hard 设置）、LIBERO-PRO（五种分布偏移：object、position、semantic、task、environment）、ChemLab-Evo（真实世界化学实验室，ARX 双臂机器人）。
  • 主要指标：任务成功率（success rate）。
  • 关键结果：

- 扩展 Ego 数据至 10K 小时，RoboTwin 成功率从 63.8% 提升至 75.3%，匹配 2K 小时机器人演示（74.7%），经验数据比例约 4–5:1。

- ACE 在留出的 EgoDex–AgiBot 转换上，学习 token 距离与物理动作距离相关性达 0.801；零样本迁移至 EgoVerse 保持 0.724。

- ICCL 随交互证据累积，在四次尝试内将成功率从 58% 提升至 89%，无需参数更新。

- 在 RoboTwin 2.0 Hard 设定下与 π0、π0.5、StarVLA、Xiaomi-Robotics-0、Fast-WAM 等方法比较，完整 50 任务结果见附录。

- LIBERO-PRO 验证了结构化分布偏移下的鲁棒性；ChemLab-Evo 验证了真实世界迁移与数据效率。
