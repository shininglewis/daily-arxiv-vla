Card 02 论文概述

论文概述

  • 提出 GeoCoTDrive，一种面向自动驾驶 VLA（视觉-语言-动作）模型的显式几何思维链（Geometric Chain-of-Thought）框架，遵循“先用 2D 思考，再用专用 3D 先验驾驶”的范式。
  • 针对现有 VLA 模型的核心矛盾：驾驶动作需要精确的 3D 几何线索，而视觉-语言理解与推理主要在 2D 语义空间中进行。
  • 现有方法多以全局场景级表示注入几何信息（如 BEV 查询、全局几何 token、隐式特征融合），缺少面向规划决策的局部、关键空间线索。
Card 03 核心贡献

核心贡献

  • 提出 GeoCoTDrive 显式几何思维链框架，通过“2D 定位 → 3D 几何检索 → 交织生成轨迹”桥接语义推理与规划。
  • 提出 planning-relevant grounding（规划相关定位） 新任务：从传统对象级定位转向区域级、直接影响自车规划的决策关键线索（含冲突区域、被遮挡区域、密集目标区域等）。
  • 构建 PlanningGrounding 数据集：VQA 风格的定位数据集，包含 146K 条规划相关定位标注，并提供 0.6K 人工精修测试集。
  • 设计自回归几何检索机制：依据预测的定位区域，从冻结的几何基础模型中采样局部 3D 特征，并交织进生成上下文以支撑轨迹预测。
  • 在多个端到端自动驾驶基准上持续提升安全关键的规划指标，且兼容不同 VLM 主干与轨迹解码器。
Card 04 方法描述

方法描述

  • 两阶段自回归流程：给定前视图图像、驾驶指令与自车状态，先自回归生成规划相关 2D 边界框（归一化坐标），再据此采样几何特征，最后继续解码未来轨迹。
  • 几何基础模型：使用冻结的 Depth Anything V3（密集单目几何）与 VGGT（3D 感知隐表示）提取几何特征图 G = f_geo(I)。
  • 区域采样与对齐：在每个定位框内构造 K 点规则网格并做双线性插值采样，经轻量 MLP 对齐头投影到 LLM 隐空间，拼接后作为几何 token 交织进自回归上下文。
  • 训练目标：教师强制下的标准自回归语言建模损失，同时监督定位回答与轨迹回答，用户提示、图像占位符与几何特征 token 在损失中被掩码。
  • 两阶段训练：Stage I 全量 QA 训练更新视觉编码器与 LLM 以适配驾驶场景；Stage II 冻结视觉编码器，仅优化 LLM 与几何对齐头。
  • 关键技术点在于几何按需检索——几何只在与决策关键区域绑定时才被注入，而非全局无差别注入。
Card 05 数据集与资源

数据集与资源

  • 新构建数据集 PlanningGrounding：146K 条 VQA 风格区域定位标注，含 5 类：critical-object、road-boundary、conflict-area、occluded-unknown-area、dense-object-area；另有 0.6K 人工精修测试样本。
  • 标注来源数据：nuScenes、NAVSIM、Bench2Drive；标注流程使用 Gemini-3.1 生成并由人工校验。
  • 基础 VLM：LLaVA-1.5-7B（nuScenes、Bench2Drive）、Qwen2.5-VL（NAVSIM，3B 版本用于主表对比）。
  • 轨迹解码：nuScenes 与 NAVSIM 采用自回归文本解码，Bench2Drive 采用 ORION 的扩散规划器。
  • 几何基础模型：DepthAnythingV3、VGGT（均冻结，使用官方 checkpoint）。
  • 具体 GPU/TPU 训练资源在原文正文与附录中未给出明确信息（HTML 内容中未展示）。
Card 06 评估与结果

评估与结果

  • 评估基准：nuScenes（开环）、NAVSIM navtest（闭环，NAVSIMv1 非反应式仿真）、Bench2Drive（官方闭环协议）；外加 PlanningGrounding 定位测试集。
  • 评估指标：nuScenes 用 L2 距离误差、碰撞率（Collision）、交叉率（Intersection）；NAVSIM 用 PDMS（含 NC、DAC、TTC、Comf.、EP 五子项）；Bench2Drive 用 DS（驾驶分数）与 SR（成功率）；定位用 Recall@0.3/0.5/0.7、AP、mIoU。
  • nuScenes：GeoCoTDrive 在 VLA 类方法中具竞争力，安全相关指标表现突出（如碰撞率 Avg. 0.11%、Intersection Avg. 2.02%，优于 OmniDrive 0.30/3.00 与 VGGDrive 0.22/2.31）。
  • NAVSIM：以 Qwen2.5-VL-3B 为基座取得 PDMS 87.6，高于基线（85.9）、AutoVLA（80.5）、ReCogDrive（86.8）与 LaST-VLA（87.3），且 NC 98.4、DAC 95.6、EP 81.6 均为最优或次优。
  • Bench2Drive：DS 78.68 / SR 55.42，优于 ORION（77.74/54.62）与 SpaceDrive（78.02/55.11）。
  • 定位性能：PlanningGrounding 测试集上各项指标全面最优，R@0.3 56.82、R@0.5 42.73、R@0.7 21.04、AP 39.89、mIoU 38.93，在严格 IoU 阈值下增益尤为明显。
  • 消融结论：直接交织全局几何 token 收益有限，说明几何信息在以决策关键区域为条件时更有效；使用 PlanningGrounding 标注优于通用感知标注；定性可视化显示 GeoCoTDrive 的几何注意力更聚焦于决策关键区域。
