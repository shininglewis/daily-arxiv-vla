Card 03 核心贡献

核心贡献

  • 通过实证研究揭示了预训练 VLA 模型持续技能学习的两个特定挑战：模块级表示异质性和输出级表达瓶颈。
  • 提出模块级子空间预算策略（Module-Aware Budgeting），对 VLM 和 ActionHead 分别设置不同的能量阈值，在保护局部速度模式的同时保持语义塑性。
  • 设计特征感知 MoE 速度解码器（Feature-Aware MoE Decoder），为每个技能分配紧凑专家，并采用免训练的投影式路由机制基于特征空间亲和度选择专家。
  • 在LIBERO 模拟环境和真实机器人平台上验证了 OrthoSkillVLA 的有效性，显著优于子空间约束基线在旧技能保留和最终成功率上的表现。
Card 04 方法描述

方法描述

  • 基础模型采用预训练 X-VLA（约 0.9B 参数），由 VLM、ActionHead 和最终速度解码器三部分组成。
  • 技能子空间估计：从累积梯度中估计技能特征子空间，用 SVD 分解残差梯度并保留满足能量阈值的主方向，构建正交基集合。
  • 梯度信息正交低秩适配：将 LoRA 的 down-projection 矩阵 A 初始化为初始梯度（去除历史基投影后）的 top-r 左奇异向量并冻结，仅训练 up-projection 矩阵 B，确保更新被约束在历史子空间的正交补空间中。
  • 模块感知预算：为 VLM 设置较宽松的阈值（ε_VLM = 0.99）以保留长期语义塑性，为 ActionHead 设置较严格的阈值（ε_Head = 0.9999）以精确保留局部速度模式。
  • MoE 解码器：冻结预训练解码器，为每个新技能分配独立的专家矩阵 W_k，通过训练自由的特征投影路由（arg max \|\|x U_i^Dec\|\|²）选择专家。
  • 创新点在于将子空间约束与模块感知预算相结合，并解决了输出层表达灵活性的问题，整个框架无需演示回放和额外的可训练路由模块。
Card 05 数据集与资源

数据集与资源

  • 模拟环境：LIBERO-100 基准，重新组织了技能增量协议，定义了 OpenClose、Turn、PickPlace 三个技能组，各含 2-4 个任务。
  • 真实环境：7-DoF xArm 机械臂 + 6-DoF Inspire 灵巧手 + Orbbec 336 腕部相机，设计了 Flip、Pick、Push、Press 四种操作技能。
  • 每个真实技能收集 50 条专家演示，图像分辨率 224×224。
  • 模型规模：X-VLA 约 0.9B 参数；MoE 解码器参数量占比 < 0.01%。
  • 训练配置：AdamW 优化器，batch size 16，峰值学习率 5×10⁻⁵，cosine 退火调度，1000 步 warmup，每个技能约 40000 步收敛。
Card 06 评估与结果

评估与结果

  • 评估指标：FWT（前向迁移）、NBT（负向后向迁移）、AUC（学习过程稳定性）、Final SR（最终成功率）。
  • 模拟结果：OrthoSkillVLA 在三个技能顺序平均下取得 FWT 0.94、NBT 0.13、AUC 0.88、Final SR 83.50%，显著优于最强基线 KeepLoRA（FWT 0.90、NBT 0.46、AUC 0.72、Final SR 56.61%）。
  • 消融实验：单独分离模块感知预算将 Final SR 从 56.61% 提升至 60.44%；单独引入 MoE 解码器提升至 67.94%；两者结合达到 83.50%，验证了两种设计的互补性。
  • 真实实验：学习完四个技能后，OrthoSkillVLA 的平均成功率 86.25%，比 KeepLoRA 高 15.0%，主要收益来自对早期技能更好的保留。
  • 路由机制：训练自由路由达到 98.9%（OpenClose）、98.9%（Turn）、91.5%（PickPlace）的识别准确率，与 Oracle 路由相比仅差 2.7% 的平均成功率（83.5% vs 86.2%）。
  • 子空间占用分析：统一阈值下 VLM 子空间占用率远高于 ActionHead，验证了模块感知预算的必要性。
