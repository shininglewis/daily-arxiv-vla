研究单位

  • 京都大学（Kyoto University）
  • 作者：Kaneyoshi Hiratsuka、Satoshi Yamamori、Jun Morimoto（三人均隶属京都大学）
Card 02 论文概述

论文概述

  • 提出 Verify, Act, Distill 框架，将视觉-语言-动作（VLA）模型的测试时计算（TTC）收益固化到策略参数中，而非每次推理都重新计算。
  • 现有 TTC 方法（如 VGA-GPS、RoboMonkey）在推理时对多个候选动作打分但不更新策略，导致同一任务的收益无法保留。
  • 核心思路：把候选聚合执行中已经产生的"优质监督"（成功回合中的观测与聚合动作块）直接蒸馏进 VLA，实现测试时自适应。
Card 03 核心贡献

核心贡献

  • 提出将基于验证器的执行决策直接蒸馏进 VLA 的自适应方法：从成功轨迹中提取 TTC 执行时已生成的聚合动作块作为教师数据，无需额外 RL 优化或专门的教师生成回合。
  • 验证 TTC 收益的保留与再放大：在 40 个 LIBERO 任务、SmolVLA 5k 上，每任务仅 10 个自适应回合即把无验证器单候选成功率从 54.1% 提升到 70.6%（保留约 74% 的八候选收益）。
  • 展示蒸馏与候选聚合的协同效应：对蒸馏后策略再次施加聚合，成功率从 76.4% 提升到 82.3%，其中 LIBERO-Long 从 44.0% 提升到 57.8%。
  • 系统分析教师选择与适用性：量化成功过滤器与教师动作块的作用、分布偏移下的行为，以及对候选数量与自适应预算的依赖。
  • 验证方法在 10k checkpoint（83.2% → 86.2%）以及含分布偏移的 LIBERO-plus 上仍有效。
Card 04 方法描述

方法描述

  • 候选生成：在每个重规划点从独立噪声采样 N=8 个候选，第一个来自 z∼N(0,I)，其余来自 z∼N(0,α²I)（α=1.2），保证基础策略自身分布中始终有一个动作。
  • 验证器（Verifier）：沿用 RoboMonkey 设计，V_act 把观测特征与前 H₂ 步环境动作映射为标量分数；使用冻结 VLM connector 输出（双视角、各 64 token、960 维），6 层 Transformer、隐藏维度 512，用全对 Bradley–Terry 损失按与成功轨迹动作的 RMSE 距离排序，训练 60k 步。
  • 加权执行：分数标准化后经 softmax 加权（温度 λ=0.3），聚合在归一化空间完成，仅执行前 H₂=10 步。
  • 蒸馏（Distill）：仅保留成功回合（y_e=1）的 (o_b, Ā_b) 对存入缓冲区；只更新动作专家的 LoRA 参数（rank 8、scaling 16、0.37M 可训练参数），使用标准流匹配损失训练 200 步。
  • 关键创新：教师是完整的 H₁=50 步聚合块（尽管只执行了前 H₂ 步），权重 w_i 跨时间步共享，保证生成一个连贯计划；验证器与基础策略在自适应期间保持冻结，奖励/价值模型训练与策略更新完全解耦。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO 四个套件（Spatial、Object、Goal、Long，各 10 任务）；LIBERO-plus（每套件 105 任务，含 7 类扰动）；官方 LIBERO 示范轨迹（用于验证器训练）。
  • 基础模型：SmolVLA（H₁=50、d=32、H₂=10），在 10,000 次 π0.5 rollout 中 5,225 条成功回合上训练；使用 5k / 10k / 20k checkpoint。
  • 训练资源：NVIDIA RTX PRO 6000（96 GB） 与 RTX 6000 Ada（48 GB） GPU。
  • 实验预算：每任务默认 K=10 个自适应回合，评估在 held-out seeds 10–59（每任务 50 回合）。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO（干净，SmolVLA 5k，seeds 10–59）与 LIBERO-plus（10k，分布偏移），指标为成功率（%），报告套件均值、四套件宏平均及逐任务配对差异（±SEM）。
  • 主要结果：Base 54.1% → Distill 70.6%（配对差 +16.5±2.7，34/1/5 任务改善/持平/退化）；Agg-8 76.4% → Distill+Agg-8 82.3%（Long 44.0% → 57.8%）。
  • 与自模仿对比：Self 单候选 63.7%，低于 Distill 的 70.6%，在 Goal 套件上高出 16.2 点；自适应期 Distill 试次成功率 73.8% vs Self 53.5%。
  • 与 噪声空间 GRPO（N-GRPO） 对比：单候选 58.1%、聚合 79.2%，均低于蒸馏方案（70.6% / 82.3%），说明直接监督远比 RL 奖励样本高效。
  • 消融：去掉成功过滤器降至 64.4% / 78.8%；使用最高分候选替代聚合块为 67.8% / 82.5%。
  • 10k checkpoint：单候选 83.2% → 86.2%，但聚合 89.8% 未超过原 Agg-8 的 90.4%（验证器在高质量候选上区分度下降，验证集成对准确率从 0.82 降至 0.73）。
  • 分布偏移：LIBERO-plus 公共子集上 Base 20.7% → Distill 24.5%（+3.9±1.4）；但 140 个任务中有 66 个在自适应期间无成功样本、无法更新。
  • 预算效率：LIBERO-Long 上仅 K=2 即达 29.6% 单候选成功率，K=50 达 34.6%；同预算 K=10 下蒸馏 27.0% > N-GRPO 25.6% > DSRL-style SAC 19.4%。
