Card 02 论文概述

论文概述

  • 论文提出 RoboFL，一个面向 世界-动作模型（World-Action Models, WAMs） 的联邦学习框架，让各机构在不共享原始机器人轨迹的前提下联合训练通用具身智能策略。
  • 要解决的核心问题是：机器人交互数据稀缺、机构间数据孤岛化且任务高度异构，直接用 FedAvg 聚合 LoRA 适配器会稀释任务专精，而把 MoE 路由引入联邦聚合又会破坏专家选择的稳定性。
  • 目标是在任务级 Non-IID 的联邦设置下，把各客户端互补的任务专精能力组装成一个通用且不泄露来源的策略。
Card 03 核心贡献

核心贡献

  • 提出 任务孤岛式联邦专家组装 框架 RoboFL 与 MoSAIC（Mixture of Slotted Adapters），将客户端训练的 LoRA 适配器直接安装为服务器 MoE 的专家分支，原始轨迹始终保留在本地，客户端训练与通信仍保持单适配器规模。
  • 提出 FARD（Foresight-to-Action Routing Distillation），将理解路径与生成路径的可靠路由共识蒸馏到动作路由器中，指导基于 MoT 的世界-动作模型的专家选择。
  • 提出 PCEA（Path-Consensus Expert Aggregation），利用三路径（理解/生成/动作）共识对完整的服务器精炼专家更新加权，重构出秩受限的全局适配器用于个性化再分发。
  • 在仿真与真实机器人上验证了结构化专家组装的优越性，同时大幅降低通信开销。
Card 04 方法描述

方法描述

  • 基于 三路径世界-动作架构：理解路径 U（Qwen3-VL 编码图像与指令）、生成路径 G（Cosmos 令牌化预测未来帧隐变量）、动作路径 A（投影状态令牌 + 噪声动作令牌 + 时间嵌入），三条路径通过统一掩码自注意力共享注意力计算，但投影与 MLP 权重独立。
  • 动作策略采用 流匹配（Flow-Matching）：对动作块 $a$ 加噪得到 $x_t=(1-t)a+t\epsilon$，预测速度 $u_t=\epsilon-a$，损失为有效维度上的 MSE；推理时从 $t=1$ 到 $t=0$ 显式欧拉积分。
  • 适配器槽位化（Adapter Slotting）：客户端 $k$ 上传的 LoRA 因子直接覆盖服务器第 $k$ 个专家槽位，安装过程不做平均，客户端到槽位映射跨轮固定，但 token 到专家的分配保持灵活。
  • 路由专家集成：适配后投影为 $h_m(z)=W_m^0 z+\gamma_m\sum_{e}\pi_{m,e}(z)B_{m,e}A_{m,e}z$，其中 $W_m^0$ 冻结，$\pi_m$ 为重归一化 top-$k_{\mathrm{route}}$ 权重；服务器在混合任务数据上联合精炼路由器与专家因子。
  • FARD：以几何平均构造教师分布 $q^{UG}_{m,b}$ 并用熵定义可靠性 $r_{m,b}$，以 JS 散度对齐动作路由，梯度仅穿过动作分布，教师与可靠性均 stop-gradient。
  • PCEA：收集 Hellinger 重心证据 $g_{m,b,e}$，按模块统计后计算全局权重 $\bar{w}_e$ 与 Hellinger 中点权重 $\widetilde{w}_{m,e}$，最后通过 QR 约减 + 小规模 SVD 得到 $\Delta W_m^{\mathrm{glob}}$。
  • 服务器总目标为 $\mathcal{L}_{\mathrm{MoSAIC}}=\mathcal{L}_{\mathrm{action}}+\lambda_{\mathrm{gen}}\mathcal{L}_{\mathrm{gen}}+\lambda_{\mathrm{aux}}\mathcal{L}_{\mathrm{aux}}+\lambda_{\mathrm{FARD}}^{(\tau)}\mathcal{L}_{\mathrm{FARD}}$。
Card 05 数据集与资源

数据集与资源

  • 数据集：RoboTwin 2.0（50 个任务划分为 8 个客户端任务族 + 1 个服务器残余组）、RLBench（8 个任务划分为 4 个客户端 + 1 个服务器划分）、以及真实世界 Franka 单臂机器人（6 个操作任务划分为 4 客户端 + 1 服务器）。
  • 基础模型：从预训练的 InternVLA-A1-3B 检查点初始化，采用 PEFT/LoRA 微调。
  • MoSAIC 配置：RoboTwin 2.0 使用每模块 8 个专家分支 + top-4 服务器路由；RLBench 与真实场景使用 4 个专家分支 + top-2 路由；专家秩 $r=16$，LoRA $\alpha=32$（有效缩放 $\alpha/r=2$），dropout 0.05。
  • 优化设置：完整客户端参与，100 轮通信，每轮 1 个本地 epoch；客户端/服务器步数为 500/200/300；客户端 batch size 32，服务器 batch size 8/16/16；AdamW，学习率 $1\times10^{-4}$，betas (0.9, 0.95)，weight decay 0.01，梯度裁剪 1.0，余弦衰减。
  • 损失系数：$\lambda_{\mathrm{gen}}=0.01$，$\lambda_{\mathrm{aux}}=0.001$，$\lambda_{\mathrm{FARD}}=0.01$ 并带 10 轮 warmup。
  • 对比基线：集中式 PEFT 参考 InternVLA-A1、Motus；联邦方法 FedAvg、FedMoE、FedVLA、ForgeVLA。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 与 RLBench 仿真器，以及真实 Franka 机械臂平台，均在 任务孤岛（task-silo）协议 与极端 Non-IID 数据划分下评估，指标为任务成功率。
  • RoboTwin 2.0 上达到 83.12% 总体成功率，比 FedAvg 高 4.2%，比集中式 InternVLA-A1 高 1.52%。
  • 真实 Franka 六任务上达到 59.17%，而集中式 InternVLA 为 46.94%，相对集中式 PEFT InternVLA-A1 提升 12.23%。
  • 通信效率：相比基于 MoE 的联邦 VLA 基线，每轮客户端通信量最多降低 86.81%。
  • 消融实验验证了 FARD 与 PCEA 的作用，以及路由耦合与干预的影响；附录还提供了失败案例分析、统计报告协议与局限性讨论。
