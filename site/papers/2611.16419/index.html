论文概述

Card 03 核心贡献

核心贡献

  • 提出分层意图预测任务：从视觉遥操作历史中联合预测开放词汇的 ongoing action 与 ongoing mission。
  • 构建 VI AMO 数据集：包含 6,600 个 episode、13,653 个时间对齐动作标注和 9,702 个 mission 标注，覆盖 11 个机器人来源。
  • 提出 VIM：在 VI AMO 上微调视觉语言模型，在动作和 mission 预测上显著优于 GPT-4o、GPT-5.6 Luna、两个具身基础模型及未微调骨干。
  • 验证下游应用：将 VIM 预测的 mission 作为 VLA 策略的语言指令，在真实环境共享自治任务中减少人工遥操作时间并降低意图预测延迟。
Card 04 方法描述

方法描述

  • VI AMO 标注流程包含五阶段：动作分解、mission 分组、粗时间定位、精细边界修正和人工审核。
  • 使用 GPT-5.6 Sol 进行动作分解与 mission 分组，使用 Qwen3.7-Plus 进行粗时间定位和精细边界修正。
  • VIM 以 Qwen3.5-27B 为骨干，通过 LoRA 微调视觉与语言注意力及 MLP 模块。
  • 对每个原子动作构造六种观测序列，输入视觉历史 H_t 和文本执行上下文 C_t，单次自回归生成 OA 与 OM。
  • 下游共享自治中，微调 π0.5 VLA 策略，使用条件流匹配目标，并将 VIM 预测的 OM 作为 VLA 的语言指令。
Card 05 数据集与资源

数据集与资源

  • 使用 VI AMO 数据集：6,600 个 episode，来自 11 个机器人来源，包含 13,653 个动作标注和 9,702 个 mission 标注。
  • 数据划分为 5,500 个训练 episode、550 个验证 episode、550 个测试 episode。
  • 测试集包含 1,091 个原子动作和 781 个 mission 实例，其中 35.4% 的测试动作其 OA 和 OM 标签均在训练中未出现。
  • VIM 训练使用 11,481 个训练动作，经六种时间采样构造出 68,886 个训练样本。
  • VIM 骨干模型为 Qwen3.5-27B，LoRA 设置包括 rank 16、alpha 16、dropout 0。
  • VIM 微调使用单张 NVIDIA A100 80GB GPU，约 13.44 GPU-hours。
  • VLA 策略微调使用 4× NVIDIA A100 80GB GPU，训练 10,000 步。
  • 真实部署使用 RTX 5090 GPU，通过 TensorRT-Edge-LLM 并量化为 NVFP4。
Card 06 评估与结果

评估与结果

  • 在 VI AMO test set 上评估，覆盖动作进度 0%–95% 的九个相对时间点。
  • 评估指标包括 Token F1、SBERT 语义相似度、SigLIP 相似度和 Top-10 检索准确率。
  • VIM 取得 OA/OM SBERT 0.825/0.821，显著高于最强基线的 0.581/0.564。
  • VIM 取得 OA/OM SigLIP 0.879/0.872，以及 Top-10 76.59%/78.77%。
  • 在 35.4% 的 OA 与 OM 标签均未见的测试动作上，VIM 仍达到 0.726/0.717 SBERT，高于基线最高 0.570/0.564。
  • 消融实验显示：移除 wrist view 后 OA/OM SBERT 降至 0.798/0.798；移除文本上下文后降至 0.767/0.788；仅使用 0% 单帧历史后降至 0.793/0.792。
  • 真实世界 5 个共享自治任务中，VIM 相对 GPT-4o 减少 34.6% 人工遥操作时间，相对 GPT-5.6 Luna 减少 39.8%。
  • VIM 单次意图预测延迟约 0.70–0.81 s，而 GPT-4o 为 3.09–3.53 s、GPT-5.6 Luna 为 1.92–2.27 s。
