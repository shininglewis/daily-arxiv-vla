Card 03 核心贡献

核心贡献

  • 提出 ActiveArena-Sim：支持头部与躯干关节主动视角控制（可视场景覆盖提升 6.3 倍）、约 180° 扇形大规模多层工作空间（交互面积 2 倍），并集成 Astribot S1 双臂人形机器人，动作空间为 18 维向量（双臂、双夹爪、躯干、头部）。
  • 提出 ActiveArena-Bench：包含 35 个任务、2 大任务族（视觉搜索、交互式信息获取）与 5 个细分类别（SS、SL、MD、ML、IA），每个任务都难以仅凭被动观测完成，需多轮证据获取与基于记忆的推理。
  • 提供丰富的多粒度记忆标注（目标可见性、发现历史、图像空间位置、相机朝向、操作目标），并按 search / anchor / action 三阶段与语义子任务进行逐帧标注，支持不依赖特定记忆架构的训练与评估。
  • 提出 ActiveArena-VLA：基于 StarVLA 模块化框架构建 13 种 VLA 配置，系统解耦记忆写入策略、记忆容量、本体感知状态、辅助子任务监督、高层规划与动作解码的影响。
  • 建立严格的 ID/OOD 训练与评测协议，并设计 8 个真实世界任务（采集 640 条轨迹）验证仿真结论向真机迁移的有效性。
Card 04 方法描述

方法描述

  • 在 RoboTwin 2.0 基础上重设计工作空间，采用机器人中心柱坐标参数化物体布局，无单一固定视角可覆盖全场景，迫使机器人旋转头部/躯干进行搜索与回访。
  • 将主动感知操作形式化为部分可观测下的语言条件策略：策略接收观测 $o_t$、本体状态 $x_t$、记忆 $M_t$ 与语言指令 $l$，动作按信息获取（视角调整、空间探索、开容器、物体重定向）与任务执行两类功能角色交替。
  • 任务设计遵循 4 条原则：初始信息不充分性、信息可获取性、历史依赖性、闭环决策。
  • 记忆写入策略对比三种：subtask（子任务切换写入）、motion（夹爪切换或末端/头/躯干位移阈值触发）、chunk（每个动作块后写入），容量取 6 帧与 12 帧。
  • 动作头支持 OFT、FAST、GR00T 三种；ActiveArena-Plan 引入规划器中介的记忆管理与决策；ActiveArena-Fixed 仅移除主动视角动作维度作为对照。
  • 提出失败状态分解指标：Discovery Miss (DM)、Context Omission (CO)、Context Retained (CR)，用于区分失败源于主动感知不足、记忆检索失败还是下游决策/控制错误。
Card 05 数据集与资源

数据集与资源

  • 训练数据：每个任务 100 条 ID 轨迹，35 个任务共 581.2k 帧、约 10.76 小时视频，模型训练 3.9 个 epoch。

Card 06 评估与结果

评估与结果

  • 评估基准为 ActiveArena-Bench（35 任务 × 5 类别 × ID/OOD），主指标为任务成功率（%），同时报告 DM/CO/CR 失败分解。
  • ActiveArena-OFT 取得最佳综合表现：平均成功率 ID 62.97% / OOD 47.60%；ActiveArena-Plan 紧随其后（ID 60.97% / OOD 45.54%），且仅使用稀疏记忆即可接近最优配置。
  • 去除主动视角控制的 ActiveArena-Fixed 几乎完全失败（Avg. ID 0.34% / OOD 0.17%），证明主动可视角运动是任务完成的前提。
  • 记忆类基线中 MemER 表现最好（ID 35.31% / OOD 23.43%），而无记忆模型（如 π0.5、FAST-WAM）在 ML 等类别上接近 0%，说明记忆对主动感知任务至关重要。
  • 所有方法均存在显著的 ID–OOD 性能落差，表明现有模型难以将信息获取与记忆维护策略泛化到分布外场景。
  • 消融结论：均匀时间采样优于基于子任务转移或机器人运动的事件触发写入；更大记忆容量并非天然有益，其收益取决于写入策略的稳定性；本体感知输入与辅助子任务监督带来额外增益；规划器中介的记忆管理能以稀疏记忆达到接近最优的性能。
  • 真实世界实验中 ActiveArena-OFT 平均成功率 55.6%，显著高于 MemER（34.4%）、SaPaVe（24.4%） 与 π0.5（23.8%），且相对排序与仿真结果一致，验证了 ActiveArena 对真实操作挑战的刻画能力。
