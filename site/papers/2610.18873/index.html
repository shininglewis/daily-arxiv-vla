LoopWAM: Closed-Loop Generalist Policy Improvement from Deployment Rollouts

2026-10-13 · 原文 · 翻译 · 2610.18873

Card 03 核心贡献

核心贡献

  • 提出 LoopWAM，可直接从自身和其他策略的 mixed-quality deployment rollouts 中更新 generalist policy。
  • 提出 source-dependent noise sampling，在单一模型中统一行为学习与动作条件世界建模。
  • 提出 quality steering 与 quality-weighted supervision，保留所有质量轨迹的视频世界监督，并按质量调节动作模仿权重。
  • 采用视频-动作 token 并行去噪与双向注意力，使后果表示直接参与动作生成，无需单独的后果评估阶段。
  • 在多个真实/仿真 benchmark 上取得最佳综合结果，并验证多任务和单任务后训练下的闭环部署自提升。
Card 04 方法描述

方法描述

  • 模型为 Mixture-of-Transformer (MoT) 双流扩散 Transformer，视频分支初始化自 Wan2.2-TI2V-5B，动作分支为 action DiT，hidden dimension 1024。
  • 联合建模动作块与未来观测 latent，条件为当前观测、机器人状态、语言指令和质量分数 q。
  • 使用 flow matching 训练，视频和动作目标独立加噪；source-dependent noise sampling 区分专家与 rollout 数据。
  • 对专家数据，视频噪声来自 Beta(7,1)，动作噪声来自 base noise distribution；对 rollout 数据，视频噪声来自 base noise distribution，动作噪声来自 Beta(1,7)。
  • Quality steering 将轨迹质量分数编码为指令后缀 Quality: q，专家演示使用专家分数 q*，部署时条件于 q* 以偏向高质量行为。
  • Quality-weighted supervision 对所有轨迹保留视频预测损失，动作损失用非减权重 λ(q) 调节；专家 λ(q*)=1，失败轨迹 λ(q)=0。
  • 闭环自提升流程：部署当前策略收集 rollout，进行质量标注，与专家数据和累积 rollout 混合后重新训练，再用 q* 重新部署。
  • 支持从其他部署策略的 rollout 中学习，不仅限于自身部署经验。
Card 05 数据集与资源

数据集与资源

  • RoboChallenge Table30-V2：真实机器人 benchmark，30 个桌面操作任务，覆盖 ALOHA、DOS-W1、ARX5、UR5 四种 embodiment。
  • RoboTwin 2.0：50 个双臂操作任务，使用 2500 条 clean 专家演示与 25000 条强随机化专家演示。
  • RoboTwin 2.0 rollout：额外加入 LoopWAM、X-VLA、π0.5 生成的 22500 条 rollout，每任务每策略 20 条 clean 和 130 条 randomized。

Card 06 评估与结果

评估与结果

  • 评估环境包括真实机器人 RoboChallenge Table30-V2、仿真 RoboTwin 2.0 和 RoboCasa365，以及真实 shirt folding 任务。
  • 主要指标为成功率 SR (%)、Score 和 average success。
  • RoboChallenge Table30-V2：三轮部署-训练将成功率从 23.67% 提升到 28.00%、37.67%、43.33%，提升 19.7 个百分点；Score 从 36.10 到 42.63、51.65、56.80。
  • Table30-V2 最终结果超过 VLA-DM0.5 2.38 Score 和 2.67 个百分点 SR，在比较方法中成功率和 Score 均第一。
  • RoboTwin 2.0：clean 94.6%，randomized 94.4%，平均 94.5%；无需额外具身预训练，超过 AHA-WAM 1.70 个百分点和 LingBot-VA 2.0 0.90 个百分点。
  • RoboCasa365：Atomic-Seen 79.7%，Composite-Seen 50.3%，Composite-Unseen 14.9%，Overall 49.5%；超过 ABot-M0.6 2.9 个百分点。
  • Shirt folding：两轮部署自提升将成功率从 13.20% 提升到 32.54% 和 55.56%，Score 从 14.44 到 38.89 和 67.78。
  • 消融表明 quality steering 是学习 mixed-quality rollout 的关键；即使 extra-coarse 标注也有效，quality-aware rollout action supervision 进一步提升性能。
  • RoboTwin 2.0 消融最佳配置为 Coarse steering + quality-weighted action supervision，平均成功率 94.5%。
