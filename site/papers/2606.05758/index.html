DRIFT: A Residual Flow Adapter for Decoding Continuous Outputs in Vision-Language Models

2026-06-04 · 原文 · 翻译 · 2606.05758

提出 DRIFT（Decoding via Residual Flow Adapter），一个将预训练视觉语言模型（VLM）从离散 token 解码接口适配到连续输出任务的通用框架，覆盖感知（视觉/时间定位）与规划（机器人控制）任务。 核心思想：将确定性基础预测器（如 MLP 回归头或 token 解码器）提供的粗估计，与基于 Flow Matching 的生成式细化模块 级联，通过建模围绕强先验的局部分布而非全局输出分布，显著简化生成建模的优化难度。 解决的关键问题：离散 token 接口存在量化误差、丢失序数结构与细粒度变化，而直接回归或纯生成式解码难以兼顾精度与不确定性建模；DRIFT 意图在保留 VLM 预训练知识的同时实现精确连续输出。

Card 02 论文概述

论文概述

  • 提出 DRIFT（Decoding via Residual Flow Adapter），一个将预训练视觉语言模型（VLM）从离散 token 解码接口适配到连续输出任务的通用框架，覆盖感知（视觉/时间定位）与规划（机器人控制）任务。
  • 核心思想：将确定性基础预测器（如 MLP 回归头或 token 解码器）提供的粗估计，与基于 Flow Matching 的生成式细化模块 级联，通过建模围绕强先验的局部分布而非全局输出分布，显著简化生成建模的优化难度。
  • 解决的关键问题：离散 token 接口存在量化误差、丢失序数结构与细粒度变化，而直接回归或纯生成式解码难以兼顾精度与不确定性建模；DRIFT 意图在保留 VLM 预训练知识的同时实现精确连续输出。
Card 03 核心贡献

核心贡献

  • 提出 DRIFT 通用框架，可将任意具有离散解码接口的预训练 VLM 适配至连续预测任务，无需修改 VLM 原有架构。
  • 核心创新在于残差细化适配器：基础预测器先给出粗糙估计，flow matching 模块围绕该估计迭代建模并修正残差分布，同时包含可学习的门控向量 α 和方差缩放向量 σ，并引入跳跃连接融合二者。
  • 提供理论分析（Appendix A）证明：相对于直接 MLP 回归或直接 flow matching，残差细化可严格降低预测误差并加快收敛，因为桥接状态天然携带目标信号且残差管域更窄。
  • 通过大量实验（VLA、TVG、空间定位、WAM 四类任务、多种 VLM 架构）验证框架的通用性与 SOTA 效果，并给出完整的 toy experiment 与可视化验证。
Card 04 方法描述

方法描述

  • 两阶段级联架构：基础预测器 g(z)（可为现成 token 解码器或新引入的 MLP）从 VLM 隐藏状态 z 输出粗预测 ŷ；flow matching 细化模块 h_θ(y(t), t, z) 学习将中心位于 ŷ 的高斯分布 N(ŷ, σI) 传输到真实目标条件分布 p(y\|z)。
  • 速度场参数化：采用目标预测参数化 v_θ = (y_θ(y(t),t,z) − y(t))/(1−t)，且 y_θ = α·g(z) + (1−α)·h_θ，通过可学习门控 α 混合粗预测与细化输出，等价于在生成模型中引入对基础预测器的跳跃连接。
  • 学习目标：使用线性插值桥接状态 y(t) = (1−t)(σε + g(z)) + ty，训练时联合优化细化模块、门控向量和缩放向量；对 MLP 基础预测器额外施加 MSE 回归损失 L_p，并在构建插值状态时对 g(·) 做梯度停止以保证训练稳定性。
  • 推断方式：从 y(0) = g(z) + σε 出发求解 ODE，通常仅需 10–20 步；多次采样取平均可进一步降低预测偏差。
  • 在集成到现有 VLM 时配合 LoRA 轻量微调，兼容冻结参数或联合更新两种设置。

数据集与资源

Card 06 评估与结果

评估与结果

  • VLA（行动成功率）：DRIFT + Qwen3-VL-2B 在 LIBERO 平均达到 97.9%，Simpler WidowX 为 61.5%，均为新 SOTA；在 OpenVLA 基础上将 LIBERO 平均从 75.5% 提升至 77.7%、Simpler 从 7.7% 提升至 13.5%。
  • TVG（零样本 Recall@1 与 mIoU）：DRIFT（ET-Chat）在 Charades-STA 上 R@0.3 达 67.2%、mIoU 43.8%；在 ActivityNet Captions 上 R@0.3 达 57.9%、mIoU 37.3%，全面超越最强通用基线 ED-VTG（7/8 指标）。
  • 空间定位（RefCOCO 系列）：Qwen3-VL-2B 集成 DRIFT 后平均精度从 85.6% 提升至 88.5%（refcoco 91.7%、refcoco+ 85.8%、refcocog 87.9%）。
  • WAM 集成：FastWAM + DRIFT 在 LIBERO 上平均成功率从 96.9% 提升至 98.2%。
  • 消融实验（LIBERO-Long 成功率的均值±方差）：DRIFT 96.33±0 > 纯 Flow Matching 93.67±0.35 > Diffusion 92.23±0.64 > MLP 88.2±0，验证残差细化设计显著优于各独立解码方案。
