Card 02 论文概述

论文概述

  • 论文提出 HIL-UMI，一个基于 Universal Manipulation Interface (UMI) 的机器人无关（robot-free）人类在环 VLA（Vision-Language-Action） 模型后训练框架，把迭代式策略改进从真实机器人上解耦出来。
  • 针对现有 SFT 后训练的两大局限：静态示范数据对策略诱导的 分布外（OOD）状态 覆盖不足，以及标准模仿目标不区分样本对任务进展的贡献大小。
  • 目标是在不依赖真实机器人反复 rollout 与人工干预的前提下，实现可并行、可扩展、策略感知的 VLA 后训练流程。
Card 03 核心贡献

核心贡献

  • 提出基于 UMI 的人类在环框架，将迭代式 VLA 后训练从机器人上迁移到手持设备采集，实现跨操作者、跨地点的可扩展并行数据采集。
  • 提出实时 OOD 检测方法，在 UMI 采集过程中将人类动作轨迹与当前策略的动作分布进行对比（Energy Score），实现策略条件化的数据选择。
  • 设计迭代工作流：每轮在线刷新 优势模型（advantage estimator），并用更新后的优势模型为采集数据打标签，执行 ACBC（优势条件行为克隆）。
  • 在四个真实世界长时序与高精度操作任务上验证有效性，性能一致优于 SFT，并在 Clean Up Table 任务上超越 HG-DAgger，采集效率提升 5.63×。
Card 04 方法描述

方法描述

  • 在线数据采集（两条并行流）：每条采集流分配相同帧预算（\|D_r^A\|= \|D_r^P\|），分别用于优势模型精修与策略改进。
  • 策略数据采集与 OOD 定义：操作者给出手部动作块 H_t，同时对同一观测执行 N=10 次随机策略采样得到动作分布 A_t^(n)；用动作块距离 ρ²(A,B)（位置、SO(3) 测地旋转距离、夹爪命令加权组合）计算 Energy Score：第一项衡量人类动作与策略样本的距离，第二项衡量策略样本自身离散度，避免退化为逐点误差；ES(H_t) > τ_P 即触发采集（τ_P 全任务共享）。
  • 优势数据采集：以 K 帧时间偏移的观测对 f_ψ(o_{t-K}, o_t, c) 预测相对任务进展，Â_t^online < τ_A 时触发采集；τ_A = κ₀/2，其中 κ₀ 是按初始优势模型 f_ψ0 在基础数据上取前 η=0.3 分位的经验阈值。
  • 优势模型训练：直接回归两帧间相对进展 f_ψ(o_u, o_v, c)，避免两次独立预测相减带来的复合误差；基础回合目标 z_{i,t}=t/(L_i-1)，迭代段目标 z_{r,j,t}=(t/(L_{r,j}-1))·(L_{r,j}/L̄₀)，保证段与基础数据进展尺度一致；用 Mix 算子混合当前轮与历史数据（系数 α=0.5）后做 MSE 回归。
  • 策略更新（ACBC）：基础数据按经验阈值 κ_r 取前 η 分位赋正标签，新采集的策略数据全部赋正标签；将标签拼接到 prompt 中得到 c^b，在混合数据集 D̃_r^P 上以 BC 损失继续训练；推理时使用正优势提示，倾向任务推进行为。
  • 关键技术点：策略与优势推理在本地工作站并行执行（策略 OOD 检测延迟 112 ms，优势 OOD 检测延迟 93 ms），保证人类在环实时性；数据采样与检测分离，策略采样与 UMI 采集并发进行。
Card 05 数据集与资源

数据集与资源

  • 基础数据集：每个任务使用固定的基础 UMI 示范集；长时序任务（Fold Towel、Clean Up Table）为 50 条示范，其余任务（Stack Cube、Stamp）为 80 条示范。
  • 每轮新增数据预算：长时序任务 12,000 帧/轮，其余任务 2,500 帧/轮。
  • 基础模型：适配开源 π0.5 策略（flow-based VLA）到各任务。
  • 硬件设备：自研 UMI 手持设备（AgiBot OmniPicker 夹爪 + Meta Quest 3 手柄追踪，通过定制连接件耦合），Intel RealSense D405 腕部视角 + Intel RealSense D455 固定第三人称视角，采集频率 30 Hz；推理工作站配备 NVIDIA RTX 4090D。
  • 评测机器人：单台 Franka 机械臂。
  • 训练超参：输入分辨率 224×224，动作 horizon 20，优化器 AdamW，策略学习率 1.0×10⁻⁵，优势学习率 5.0×10⁻⁵， cosine 调度，warm-up 500 步，batch size 128，weight decay 1.0×10⁻¹⁰，每轮 5000 更新步。
Card 06 评估与结果

评估与结果

  • 评测环境：四个真实世界操作任务——Fold Towel（长时序折叠毛巾）、Clean Up Table（长时序收纳笔与玩具、开关抽屉）、Stack Cube（精确堆叠方块）、Stamp（精度要求在 1 cm 容差内盖章）。
  • 评测协议：每个 checkpoint 每任务 10 次试验，初始物体位置在 30 cm × 60 cm 工作空间内随机变化以测试空间泛化；指标为 Task Progress Score（TPS），对预定义子任务按 0–100 给出部分分（如表 I 中 Fold Towel 各子任务 +25，Clean Up Table 每项 +10，Stack Cube 为 +30/+30/+40，Stamp 为 +20×5）。
  • 主要结果：HIL-UMI 在四个任务上相比 SFT 一致提升，SFT 仅取得有限提升并出现平台期/短暂回退；在 Stack Cube 上阈值 (τ_P, τ_A) = (1.2, 0.2) 时 TPS 从 base 84 提升到第 3 轮 100。
  • 消融结果：去掉优势模型、以简单微调替代 ACBC 后性能显著下降，说明按效用区分样本至关重要；阈值消融显示过松或过严都会变差，适度阈值最佳，且 HIL-UMI 在测试范围内均优于 SFT。
  • 效率对比：HIL-UMI 每帧采集时间略高于 SFT（如 Clean Up Table 73.40 ms/frame vs 41.70 ms/frame），但 TPS 随采集时间持续上升；与 HG-DAgger 相比，HG-DAgger 需 412.99 ms/frame，HIL-UMI 仅 73.40 ms/frame，效率高 5.63×，且最终 TPS 高出约 5 分。
