Card 03 核心贡献

核心贡献

  • 提出 OpenViTac 统一视触觉操作基准：按四类触觉相关能力（物理属性感知、易碎/力感知、富接触操作、精细操作）组织任务，提供 11 个仿真任务与 8 个配对真实任务，支持 VLA/WAM/VTLA 策略的一致评估。
  • 系统研究预训练 VLA 的触觉适配设计空间：从 触觉表示（SigLIP、T3、Sparsh、AnyTouch2）与 触觉融合（Token 拼接、特征调制、动作层条件、专用触觉专家、后期精修）两个维度进行受控对比。
  • 提出 OpenVTLA 触觉增强框架：采用表现最佳的 AnyTouch2 表示 + Token 级拼接，在不引入额外融合模块或触觉专家的前提下保持 π0.5 原有 VLM 与动作生成通路。
  • 开展 sim–real 协同训练 研究：在固定真实数据预算下引入仿真示范，分析跨域策略学习的影响因素，并考察光照扰动下的鲁棒性。
  • 提供支持多种夹爪配置（2 种夹爪）与多种触觉传感器（3 种类型）的基准，并验证仿真与真实评估的排名一致性（Pearson r=0.967）。
Card 04 方法描述

方法描述

  • 基准设计：将触觉操作划分为四个能力维度——Property Perception（PP）、Fragility-Aware（FA）、Contact-Rich（CR）、Precision Manipulation（PR），使用任务级二值成功判据进行平衡条件下的评估。
  • 任务套件：包含重量/硬度/粗糙度分类（WC/HC/RC）、粗糙度引导重抓取（RR）、空罐选择（ECS）、抓取芯片（GC）、齿轮装配（GA）、拉抽屉（PD）、插入 USB、插入方块 v1/v2（In-B v1/v2）。
  • Real–Sim 对齐：提出 agent 辅助的 real-to-sim 流水线，在资产层用多视角图像重建仿真物体并按功能部件分解，在任务层按参考物、目标配置与机器人初始状态实例化仿真任务并生成可执行子动作轨迹；支持通过背景、工作台外观等变化实现场景多样化。
  • 触觉适配设计空间：表示侧对比单帧编码器（SigLIP、T3）与时间感知编码器（Sparsh、AnyTouch2）；融合侧对比 ① Token 级拼接、② FiLM 特征级调制、③ 动作层条件（如 N0-VTLA）、④ 触觉专用专家（如 FTP-1）、⑤ 触觉引导后期精修（如 T-Rex）。
  • OpenVTLA：AnyTouch2 将触觉历史编码为紧凑 token，投影到 VLM 隐维度后前置到视觉 token 序列，实现早期触觉注入。
  • 协同训练：遵循 digital-cousin 原则对齐本体、任务目标、语言指令、物体类别与成功判据，并统一动作/本体感知表示、坐标系、单位、夹爪约定与控制频率；训练损失为 L_co = (1−α)L_BC(D_r) + α L_BC(D_s)，α 独立于数据规模（公式 1），无需成对跨域轨迹或显式特征对齐损失。
  • 创新点：首次在统一 sim–real 配对框架下系统解耦"触觉表示"与"触觉融合"两个设计维度；给出"使用预训练时间感知触觉编码器 + 将 token 直接注入 VLM 输入"的简洁适配配方。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：OpenViTac 自带数据，含 11 个仿真任务 与 8 个配对真实任务；覆盖 2 种夹爪类型与 3 种触觉传感器类型。
  • 真实数据规模：协同训练实验中每个任务固定使用 100 条真实示范，并额外加入 250 或 500 条仿真示范（采集于多样化场景配置）。

Card 06 评估与结果

评估与结果

  • 评估环境：仿真环境与真实世界环境并行，采用预定义且平衡的任务条件与任务级二值成功判据；所有策略在单任务设置下分别训练与评估（每个任务实例化一个策略），多任务变体分别评估后按任务级聚合，Avg. 为任务级成功率非加权平均。
  • 主要指标：任务成功率（Success Rate，%）及四类能力维度的分组平均；仿真–真实一致性用 Pearson 相关系数 r 与 MMRV 衡量。
  • 仿真结果：最强的 VLA、WAM、VTLA 基线平均成功率分别为 51.5%、53.3%、61.2%，OpenVTLA 达 68.7%，分别领先 FTP-1 与最强 VLA 基线 7.5 和 17.2 个百分点；WAM 整体弱于较强 VLA，VTLA 整体最强。
  • 真实世界结果：VLA 基线平均成功率 34.0%–43.1%，FastWAM 29.0%，FTP-1 51.9%，OpenVTLA 达 54.6%（相较 π0.5 提升 13.5 个百分点）。
  • 能力维度差异：触觉增益在 Property Perception 与 Fragility-Aware 任务上最明显；Contact-Rich 任务上强 VLA 仍具竞争力；Precision Manipulation 对所有模型族均困难，说明仅靠触觉不足以支撑可靠的精细操作。
  • Sim–real 一致性：在 8 个共有任务上对 7 个方法统计，任务平均得分的 Pearson r=0.967、MMRV =0.006，OpenVTLA 与 FTP-1 在两个域中均排名第一与第二。
  • 触觉表示消融：在相同 Token 拼接接口下，AnyTouch2 平均 68.7% > Sparsh 64.7% > SigLIP 59.5% > T3 58.1%；AnyTouch2 在 ECS 上比 Sparsh 高 12 个点、在 USB 插入上高 10 个点；随机初始化 AnyTouch2 编码器性能明显下降，去除时间变化（重复当前帧）尤其损害硬度与重量等物理属性识别。
  • 触觉融合消融：① Token 级拼接最优（Avg. 68.7，PP 90.2 / FA 69.0 / CR 95.0 / PR 15.3）；④ 触觉专家（FTP-1）次之（61.2）；② 特征调制 56.5；⑤ 后期精修 50.4；③ 动作层条件最低 48.6，说明在 VLM 输入端早期注入触觉更有利于学习接触相关表示与决策。
  • 协同训练与鲁棒性：在固定 100 条真实示范下加入 250/500 条多样化仿真示范，并对 real-only 与 500-sim 策略施加光照扰动进行对比（该部分详细数值位于原文被截断的表 5 中）。
