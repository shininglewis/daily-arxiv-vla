Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation

2026-09-30 · 原文 · 翻译 · 2610.00575

Card 03 核心贡献

核心贡献

  • 研究直接 VLM 视觉 token 模拟作为 RGB 世界模型管线的替代方案，使模拟器在策略消费的表示接口上运行。
  • 提出 Token-World，一种自回归动作条件世界模型模拟器，使用 flow-matching DiT 在紧凑 VLM 视觉 token 空间建模动力学，不依赖预训练视频生成模型。
  • 通过开环预测、闭环策略评估和表示消融验证 Token-World，展示改进的长时程特征和策略动作保真度、更可靠的策略成功率估计、更低模拟成本，以及紧凑表示设计对动力学预测的重要性。
Card 04 方法描述

方法描述

  • 使用单独训练并冻结的语义 VAE（S-VAE） 将 VLM 特征压缩为紧凑 token 状态，仅沿特征维度压缩，保留原始空间 token 布局。
  • 主配置中，VLM 表示包含 N=108 个空间 token、D0=2560 通道，压缩为 d=16 通道每 token。
  • 动力学模型为时空 Transformer，分解空间注意力和因果时间注意力，并维护固定大小 GRU 状态以保留超出注意力窗口的上下文。
  • 训练采用 x0 参数化 flow-matching 目标，结合 shortcut forcing 支持少步生成；VLM 编码器和 S-VAE 在世界模型训练中保持冻结。
  • 自回归 rollout 完全在紧凑状态空间进行，需要时通过冻结语义解码器映射回策略面向的 VLM 表示；RGB 渲染仅用于评估可视化，使用单独训练的卷积解码器。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 模拟基准和 真实 Franka 平台；包括开环动作回放、闭环策略评估和表示设计消融。
  • 对比基线：IRASim（ICCV’25）、Ctrl-World（ICLR’26）、WorldGym（ICLR’26）。
  • 开环指标：VLM 特征保真度（Cosine ↑、NMSE ↓）和策略动作一致性（Cosine ↑、NMSE ↓）。
  • 主要开环结果：在 RoboTwin 上，Token-World 特征 Cosine 0.7714、NMSE 0.4892，动作 Cosine 0.9439、NMSE 0.1145，优于 IRASim 和 Ctrl-World。
  • 真实 Franka 上，特征 Cosine 0.7506、NMSE 0.5129，动作 Cosine 0.9402、NMSE 0.1208；长时程 rollout 退化比 Ctrl-World 更慢。
  • 闭环策略评估：模拟成功率与参考成功率的 Pearson 相关性 r=0.794，高于 Ctrl-World 的 0.583。
  • 模拟效率：Token-World 每步延迟 0.359 s，相对 IRASim、Ctrl-World、WorldGym 分别实现 2.0×、5.3×、6.1× 加速。
  • 表示消融：S-VAE 维度 d=16 取得最佳动力学预测权衡；S-VAE 显著优于原始 VLM 特征和 SDXL-VAE latent。
