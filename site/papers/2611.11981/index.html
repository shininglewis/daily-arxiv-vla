Card 03 核心贡献

核心贡献

  • 构建真实世界热感知机器人操作基准，包含 4 个温度相关任务 和 2 个 RGB 基础任务，用于评估代表性 VLA 方法在 RGB 与 RGBT 设置下的表现。
  • 提出 ThermoRes Encoder，通过 Dual-Branch Attribute Decomposition 将热图分解为冷、热属性表示，再通过 Gated Residual Injection 以语言条件门控方式注入 RGB token。
  • Thermo-VLA 在四个热依赖任务上取得平均 0.86 成功率，摘要称较直接融合 RGB-热图的 π0.5 基线高 18 个百分点。
  • 在未见物体和场景变化下保持较强泛化能力，摘要报告平均成功率为 0.78，为对比方法中最佳。
  • 消融实验验证门控残差注入与双分支属性分解的有效性，并通过 RGBRes Encoder 将机制迁移到颜色属性任务。
Card 04 方法描述

方法描述

  • 以 π0.5 为基线，RGB 观测经视觉编码器和投影器得到 RGB token；语言指令与机器人状态被映射为文本 token。
  • ThermoRes Encoder 先对热图进行背景校准，并分解为冷属性视图 x_cold 与热属性视图 x_hot，两者共享基于 SigLIP 的热编码器及 RGB 投影器。
  • Text-Gate Cross-Attention 以文本 token 为 query、冷/热 token 为 key/value，并通过轻量 Gate MLP 预测冷热分支动态权重 α、β。
  • Residual Injection 保留 RGB token 的身份路径，将热属性以加权残差形式注入，得到 Z_rgb^cold 与 Z_rgb^hot，避免直接拼接热模态带来的下游建模负担。
  • 多模态 prefix 由冷/热增强 token、左右腕部 RGB token 和文本 token 组成，经 Gemma-based 多模态主干与 flow-matching action expert 生成连续动作块。
  • 动作维度 d_a=8，包含 7 个手臂关节维度和 1 个手部开合维度；动作生成为长度为 H 的连续动作 chunk。
  • 讨论部分将残差机制推广为 y = x + f(a;l)，并构造 RGBRes Encoder 将颜色属性注入 RGB token。

数据集与资源

  • 真实世界实验使用 Unitree G1 双臂人形机器人，头部安装固定相对位姿的 RGB 与热相机，左右腕部配备 RGB 相机。
  • 六个真实任务共收集 1,307 条专家演示，涵盖位置引导、温度引导、身份引导、温度排序和热排除等任务。

Card 06 评估与结果

评估与结果

  • 评估环境包括真实世界 Unitree G1 双臂平台和 LIBERO 仿真环境；主要指标为任务成功率。
  • 对比方法包括 ACT、π0.5、直接融合 RGB-热图的 π0.5 (RGBT) 以及 ThermoAct；每条指令评估 20 次。
  • 在热依赖任务中，Thermo-VLA 在 Task II 达 1.00、Task IV 平均 0.86、Task V 平均 0.58、Task VI 达 1.00，四个热依赖任务平均 0.86。
  • 在 RGB-only 任务 I 和 III 上，Thermo-VLA 平均成功率分别为 0.88 和 0.76，略低于原始 π0.5，但在 RGBT 方法中退化最小。
  • 泛化实验中，未见物体平均成功率 0.79，较 π0.5 (RGBT) 和 ThermoAct 分别高 0.15 和 0.41；光照变化和未见桌布下分别为 0.76 和 0.79。
  • 消融显示：移除 Gated Residual Injection 后，Task VI 小目标设置从 0.85 降至 0.60；移除双分支分解后在场景扰动下性能下降；将热残差强制置零后，热依赖任务成功率约为 0.5。
  • 颜色属性迁移实验中，RGBRes 将四个颜色条件测试的平均成功率从 0.572 提升到 0.775。
