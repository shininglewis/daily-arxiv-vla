Card 02 论文概述

论文概述

  • 论文提出 Uni-LaDiR（Unified Latent Diffusion Reasoner），一个将多模态推理中间步骤（thought tokens）统一映射到共享潜空间的框架，而非将各模态专属 token 拼接或交错。
  • 核心论点：感知可以保持模态相关，但推理动态应在统一的推理空间中演化；现有方法在跨模态切换表征时，将"跨模态表征转换"与"推理动态"纠缠在一起，增加了学习难度。
  • 目标：让中间推理步骤既保留后续推理与最终答案/动作所需的充分信息（reasoning sufficiency），又能从推理时可获得的上下文预测出来（context predictability）。
Card 03 核心贡献

核心贡献

  • 提出统一编码器（unified encoder），将不同模态的教师推理步骤映射为共享潜空间中的固定宽度 thought token 块，脱离模态专属的潜格式。
  • 使用扩散（flow matching）建模下一块 thought token 的条件分布，以应对同一上下文可能对应多个有效后续步骤的多峰性问题。
  • 提出联合训练统一编码器与扩散推理器并共享骨干权重，通过下游 grounding 监督（预测后续推理步骤与最终输出）与扩散目标联合优化。
  • 在 11 个 VLM 基准和 2 个 VLA 操作套件上验证，相对最强基线在数理逻辑推理平均准确率上取得 7.3% 相对提升，在 RLBench 操作成功率上取得 6.1% 相对提升。
Card 04 方法描述

方法描述

  • 构造共享 thought tokens：对每个教师步骤经模态编码器得到特征 $s_i$ 后，附加固定长度可学习嵌入 $q$，统一编码器将 $q$ 位置最后隐状态映射为干净 thought token $z_i^\star$；构造注意力掩码隔离各步骤，防止跨步骤信息泄露。

  • 扩散生成：对 $z_i^\star$ 加高斯噪声得到 $z_i^t$，以 $x$、前序干净块与噪声水平为条件预测去噪速度 $\hat{v}_i$，优化 flow-matching 损失。
  • 联合训练：总损失 $\mathcal{L}=\mathcal{L}_{\text{ground}}+\lambda\mathcal{L}_{\text{diff}}$，扩散分支对干净 token 停止梯度，使表征与预测器相互适应。
  • 推理：不需要教师观测与统一编码路径，从 $x$ 出发逐块去噪生成 $z_1,\dots,z_K$，再据此预测答案或动作。

Card 06 评估与结果

评估与结果

  • 评估协议：VLM 报告各基准准确率；VLA 报告成功率，并在 RLBench 上报告不做 action chunking 的控制频率（Hz）。
  • VLM 结果（Table 1）：视觉中心 7 项平均 76.31%（较 Qwen2.5-VL-7B 提升 18.1%，较 Mirage 提升 1.7%）；数理逻辑 4 项平均 49.03%（较基座相对提升 34.7%，较 ILVR 相对提升 7.3%）；单项最大增益为 VisualPuzzles 上较 Mirage +30.3%、VisuLogic 上较 ILVR +12.6%。
  • VLA 结果：RLBench 平均成功率 87.0%（较 LaST₀ 相对提升 6.1%，十项任务九项提升一项持平，Plants 上增益最大 +16.7%），推理速度 16.5 Hz，比 LaST₀ 快 7.1%、为显式 CoT-VLA 的 15×；LIBERO 平均 99.15%，较 PearlVLA + PRL 提升 0.45 个百分点。
  • 消融：统一更多模态带来累积收益（文本+图像共享潜空间提升 9.0%；RLBench 三模态全共享较分开目标提升 6.1%）；下游接地监督优于源重构（六基准平均提升 5.4%）；联合训练优于分离阶段（11.3%）与冻结目标（21.9%）；flow matching 优于 L2（14.9%）与余弦相似度损失（19.5%）。
