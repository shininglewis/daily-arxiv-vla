Card 02 论文概述

论文概述

  • 论文关注 VLA（Vision-Language-Action） 和 WAM（World-Action Model） 在分布外任务变化下性能退化、但可能仍保留部分任务能力的问题。
  • 提出 RoboIRS，一种推理时内部表示引导方法，利用成功与失败 rollout 训练线性分类器，选择结果相关干预位置并导出任务特定引导方向，且不更新策略参数。
  • 目标是在推理阶段将已有能力但不稳定的机器人策略偏向更可能成功的内部状态，从而提升 OOD 任务成功率。
Card 03 核心贡献

核心贡献

  • 提出 RoboIRS，将大语言模型中的内部表示引导范式适配到机器人策略，实现对冻结策略的推理时干预。
  • 使用成功/失败 rollout 的残差流训练线性分类器，以分类器权重作为引导向量，无需匹配的 nominal/perturbed 观察对，也无需更新策略参数。
  • 在 LIBERO-PRO 仿真 15 个任务上，将 π0.5 策略平均成功率从 44.4% 提升到 66.2%，优于其他推理时干预基线。
  • 在真实机器人操作任务上验证有效性，平均成功率从 18.0% 提升到 38.0%。
  • 将方法扩展至世界动作模型 Cosmos Policy，平均成功率从 35.4% 提升到 55.4%。
Card 04 方法描述

方法描述

  • 在基于 Transformer 的机器人策略的动作专家残差流中进行干预，收集成功与失败 rollout 在每层、每去噪步和每动作 token 位置的内部表示。
  • 对每个任务、层、去噪步和动作 token 位置训练线性分类器，区分成功与失败表示；使用分类器权重 w 作为引导方向，也探索均值对比差异作为引导向量。
  • 使用验证集上的 AUC 选择干预层和动作 token 位置；实验表明在每层选择最高 AUC token、仅在最后去噪步引导效果最佳。
  • 干预方式为在选定残差表示上添加缩放后的引导向量：r_steered = r + sα(\|\|r\|\|/\|\|v\|\|)v，其中 α 控制强度，s ∈ {-1,+1} 决定方向。
  • 创新点：仅需成功/失败 rollout，无需梯度引导或动作候选重排；线性分类器训练开销小，推理时额外耗时低。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO-PRO，选择 15 个非饱和任务（未引导策略成功率约在 10% 到 85% 之间）。
  • 真实机器人任务：H1: Disassemble RAM from motherboard、H2: Pull out USB connector，在视觉分布偏移下评估。
  • 模型：π0.5 VLA（PaliGemma 视觉语言骨干 + 18 层 Transformer 动作专家，隐藏维度 1024，动作块长度 10，去噪步 10）；世界动作模型 Cosmos Policy。
  • 数据收集：每个任务最多收集 10 个成功和 10 个失败 rollout；分类器与数据集体量小，可在多 CPU 上 3 分钟内完成训练。
  • 训练资源：策略模型保持冻结，未报告策略模型训练资源；分类器在多个 CPU 上训练。
  • 评估规模：仿真每个任务 150 次 rollout（3 个随机种子）；真实机器人每个任务 50 次试验。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-PRO 仿真和真实机器人操作；主要指标为成功率（SR）。
  • 仿真结果：π0.5 平均成功率从 44.4% 提升到 66.2%（+21.8 百分点）；15 个任务中 12 个提升超过一个标准差，其余任务下降在标准差范围内。
  • 真实机器人结果：平均成功率从 18.0% 提升到 38.0%。
  • Cosmos Policy 结果：平均成功率从 35.4% 提升到 55.4%。
  • 基线对比：与 CAA、Re-rank (K=16)、Gradient Guidance 相比，RoboIRS 取得最高平均成功率 66.2%；Re-rank 推理时间约 1074.86 ms，约为其他方法的 8 倍。
  • 消融实验：在每层选择最高 AUC token 且仅在最后去噪步引导达到最佳 66.2%，优于所有去噪步引导（59.3%）、随机 token（57.3%）等策略。
