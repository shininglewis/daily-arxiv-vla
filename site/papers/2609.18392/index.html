研究单位

  • 牛津机器人研究所（Oxford Robotics Institute），牛津大学（University of Oxford）
  • 作者：Reece O'Mahoney、Ioannis Havoutis
Card 02 论文概述

论文概述

  • 论文提出 DistAL（Distance-based Advantage Learning），用于视觉-语言-动作模型（VLA）的微调，通过将稀疏的成功/失败奖励替换为基于特征距离的稠密奖励来改进优势条件（advantage conditioning）训练。
  • 解决的核心问题是：现有优势条件方法仅使用简单的二值成功/失败奖励，导致价值函数无法区分质量不同的状态（例如稳固抓取与勉强持物的不稳定抓取）。
  • 研究目标是利用部署数据，在不依赖人类专家干预的情况下，提升 VLA 在仿真与真实硬件任务上的成功率。
Card 03 核心贡献

核心贡献

  • 提出并比较多种分布外（OOD）检测方法作为 VLA 任务失败的预测器，涵盖轨迹级与逐时间步级别，确认基座 VLA 的 SigLIP 特征空间中的 kNN 距离是最强信号。
  • 进行受控研究，将 kNN 距离作为稠密奖励用于优势条件训练，其余流水线保持不变，并分析该假设成立与不成立的条件。
  • 在 LIBERO 与 LIBERO-plus 仿真基准套件以及两个真实的双臂灵巧操作任务上验证方法有效性。
  • 提出将 OOD 检测信号从"运行时拒绝"重新定位为"离线价值学习的逐时间步奖励"这一新用途。
Card 04 方法描述

方法描述

  • kNN 特征距离奖励：对每个部署观测 $o_t$，用冻结的 SigLIP 编码器提取特征，计算其到基座 VLA 训练集特征索引的 $k$ 近邻平均欧氏距离 $s_k(o)$，令奖励 $r_t = -s_k(o_t)$ 并归一化到 $[-1,0]$，采用 $k=10$。
  • 保留终端失败惩罚：保留 $\pi^*_{0.6}$（RECAP）中对失败回合的大终端惩罚，防止策略通过停留在熟悉但未完成任务的状态来"刷奖励"。
  • 价值函数：由 Gemma3 270M 语言模型 + 400M SigLIP 视觉编码器组成，输出 token 经 2 层 MLP 头预测离散化回报分箱上的类别分布，使用交叉熵损失训练。
  • 优势条件策略：基于微调的 $\pi_{0.5}$（PaliGemma 3B VLM + 300M 流匹配动作专家）；通过在语言输入末尾追加"Advantage: positive/negative"注入二值优势标签，阈值设定使 30% 标签为正；仅微调动作专家、冻结主干。
  • 推理：使用无分类器引导（CFG），引导权重 $w>1$，将速度场推向正优势动作。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO-10（LIBERO-Long） 与 LIBERO-plus；每个任务收集 50 条部署回合。
  • 真实硬件：双臂 Piper 机械臂，每条臂配腕部相机 + 一个外部场景相机；每任务收集 50 条遥操作演示 + 50 条部署回合。
  • 硬件任务：remove pen lid（移除笔帽） 与 remove ethernet cable（拔掉网线）。
  • 模型规模：策略 VLM 主干 3B + 动作专家 300M；价值函数语言模型 270M + 视觉编码器 400M。
  • 评测：仿真每配置 3 个种子、每任务 50 回合；硬件每任务 50 回合评测。
Card 06 评估与结果

评估与结果

  • OOD 失败预测（AUROC）：kNN + SigLIP（pre-LM）在轨迹级（均值 0.82）与逐时间步级（均值 0.67）均为最强检测器，优于 VAE 似然（0.79 / 0.65）、Mahalanobis 距离（0.71 / 0.58）、post-LM 图像 token（0.57 / 0.51）与动作块方差（0.58 / 0.51）。
  • 仿真结果（Table III）：DistAL 在 LIBERO-10 达 96.2%（最佳）；跨 LIBERO-10 与 LIBERO-plus 总均值 78.4%，较基座 +3.3%，较二值奖励基线 +1.2%；在 Camera（+4.8）与 Texture（+7.7，达 100.0%）扰动上增益最大。
  • 硬件结果（Table IV）：Ethernet 任务 87%（基座 46%、二值奖励 72%）；Pen lid 任务 52%（基座 42%、二值奖励 48%，差异不显著）；均值 69.5%。
  • 关键结论：DistAL 在失败与成功视觉可区分的任务上收益最大（如 Ethernet、Camera、Texture 扰动）；在失败主要为触觉/接触事件的 Pen lid 任务上收益有限，其逐时间步 AUROC 仅 0.56。
  • 局限：仅基于图像、忽略力/接触/机器人状态；奖励偏向训练分布可能导致策略"停滞"；仅评估单一基座 VLA（$\pi_{0.5}$）、两个真实任务与三个种子。
