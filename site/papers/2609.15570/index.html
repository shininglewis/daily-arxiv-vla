Card 03 核心贡献

核心贡献

  • 揭示并实证了视频去噪中静态结构先成形、夹爪–物体交互动力学后出现的渐进规律，说明朴素单步截断会丢失关键操作信息。
  • 提出 DIDO，将多步动力学蒸馏为单步去噪，并结合分布匹配蒸馏（DMD）与交互中心表示引导。
  • 设计四组交互中心 token（object / interaction / gripper / alignment），通过未来边界框轨迹监督与多层 DINOv3 视觉对齐显式建模目标物体、夹爪及其交互。
  • 提出基于动力学的 token 精炼策略，依据预测变化幅度保留高动态区域细粒度 token、压缩静态区域，减少冗余上下文。
  • 在 LIBERO（99.0%）、LIBERO-Plus（76.6%）、RoboTwin（92.0%） 及真实机器人任务上取得领先结果，并实现约 32% 的推理延迟降低。
Card 04 方法描述

方法描述

  • 单步世界动力学蒸馏：以 Wan2.2-TI2V-5B 四步蒸馏变体为基础，先在机器人演示数据上微调得到"机器人域教师模型"，再用 DMD（KL 散度分布匹配）将四步教师蒸馏为单步生成器，匹配其收敛后的输出分布而非第一步的粗糙预测。
  • 交互中心视觉推理：向视频 Transformer 中注入四类 token——目标物体、交互、夹爪、对齐 token；物体分支与夹爪分支共享交互 token，分别预测长度为动作块 $H_a$ 的未来边界框序列，用 smooth L1 + GIoU 损失监督。
  • 多层视觉对齐：用冻结的 DINOv3 编码目标物体裁剪区域，在多个 Transformer 层上将对齐 token 的表示投影后与 DINOv3 特征做 L1 对齐，保证判别性视觉信息被保留。
  • 基于动力学的 token 精炼：将空间特征图划分为 4×5 网格（每区域含 2×2 细粒度单元），按当前帧与未来帧 value 特征的 L2 差异排序，保留 top-3 高动态区域的全分辨率 token，其余区域做 2×2 平均池化。
  • 交互感知动作预测：采用 mixture-of-transformers 架构，动作专家直接访问视频模型内部潜在表示（无需解码再编码未来视频），并以流匹配（flow matching）生成动作块。
  • 两阶段训练：Stage I 联合优化 $\mathcal{L}_{DMD}+\mathcal{L}_{inter}+\lambda_{align}\mathcal{L}_{align}$；Stage II 联合优化视频生成目标、动作损失、交互轨迹与对齐损失，语言 tokenizer、VAE、DINOv3 保持冻结。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、RoboTwin、LIBERO-Plus 仿真环境 + Galbot G1 真实机器人；仿真以成功率（%）衡量，真实世界以归一化任务进度分数衡量。
  • 对比基线：VLA 类方法 π₀、π₀.₅、OpenVLA-OFT、X-VLA；WAM 类方法 LingBot-VA、Motus、Fast-WAM、Faster-WAM、Flash-WAM、ST-WAM。
  • LIBERO：平均成功率 99.0%，刷新 SOTA，超过 LingBot-VA 与 Faster-WAM 0.5 个百分点，超过 Fast-WAM 1.4 个百分点，超过同为单步蒸馏的 Flash-WAM 2.9 个百分点。
  • RoboTwin：平均 92.0%，仅比最强的 LingBot-VA（92.2%）低 0.2 个百分点，但在无具身预训练的方法中排名第一，分别超过 Fast-WAM 和 Flash-WAM 0.2 与 6.5 个百分点。
  • LIBERO-Plus：平均 76.6%，超过 Faster-WAM 1.6 个百分点；在机器人初始化（74.3%）、语言表述（94.4%）、光照（96.6%）、物体布局（83.3%）扰动下均排名第一。
  • 真实世界：basic 协议 80.8 分（π₀.₅ 为 74.5，Fast-WAM 为 53.8）；advanced 协议 66.0 分（分别为 53.3 与 33.0），从 basic 到 advanced 的退化仅 14.8 分，优于 π₀.₅（21.2）与 Fast-WAM（20.8）。
  • 消融实验：从单步截断基线（LIBERO 97.7% / LIBERO-Plus 71.4%）出发，加入单步蒸馏提升至 98.3% / 72.3%，加入交互中心推理提升至 98.9% / 75.9%，再加入动力学 token 精炼达到 99.0% / 76.6%，同时将条件上下文从 323 个 token 压缩到 191 个。
  • 推理开销：端到端动作预测 384 ms，相比四步教师（562 ms）降低约 32% 延迟；相比无未来想象的 Fast-WAM（356 ms）仅多 28 ms，但 LIBERO 提升 1.4 个点、LIBERO-Plus 提升 25.1 个点。
  • 去噪步数分析：固定模型下，动作条件使用第 1→4 步的去噪表示时性能持续上升（LIBERO 97.7%→98.4%，LIBERO-Plus 71.4%→72.6%），验证了"后段去噪包含更多动作相关动力学"的动机。
