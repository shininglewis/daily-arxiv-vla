论文概述

Card 03 核心贡献

核心贡献

  • 提出 interference-aware 分层 world-action 模型 MHWA，将慢速 context 推理与原生分辨率局部动态预测解耦。
  • 用 stop-gradient 隔离的 skip-step 高层目标 L_high 学习慢速 context，减少概念干扰。
  • 在低层使用 context-aware 稀疏 MoE，gate 同时条件于广播高层 context 和瞬时 token state，缓解结构干扰。
  • 在 14 游戏 Atari、10% 离线数据上，MHWA-77M 的 IQM HNS 0.884 优于匹配 JOWA-70M 的 0.529，并接近 JOWA-150M 的 0.833。
  • 提供开环动力学诊断、消融和专家激活可解释性分析，支持结构归纳偏置而非单纯 scaling 的收益。
Card 04 方法描述

方法描述

  • 接口与预测头：沿用 tokenized world-action 接口，VQ-VAE 将观测编码为 K=36 个离散视觉 token，与动作 token 交错；保留任务嵌入及 JOWA 的观测/奖励/终止/Q 值预测头。
  • High-Level Manager：在 stride k=4 的下采样序列上运行 causal Transformer，输出 h_high，并由 Context Projector 产生慢速 context z_ctx；通过 stop-gradient 阻断低层损失回传。
  • 高层目标 L_high：用 skip-step 预测目标预测下一粗粒度观测 token，形成信息瓶颈，促使 context 捕捉慢变语义而非瞬时噪声。
  • Low-Level Worker：以原子分辨率自回归预测，将 FFN 子层替换为稀疏 MoE；默认 N=4 个专家、Top-2 路由。
  • Context-aware routing：gate 输入为 (x_t ⊕ z_ctx_m)W_g，经 Top-K masked softmax 选择专家；输出为 y_t=x_t+Σ w_{t,j}E_j(x_t)，使路由兼具模式感知和局部反应性。
  • 训练目标：L_total = L_base + L_critic + λ_h L_high + λ_a L_aux；其中 L_base 为观测/奖励/终止交叉熵，L_critic 为分布 TD(C51)+CQL，L_aux 为专家负载均衡 KL 正则。
Card 05 数据集与资源

数据集与资源

  • 数据集：使用 RL Unplugged 的 rlu-atari 替代原 DQN Replay Dataset，保持 50M transitions/game/run 分布；使用 2/5 training runs，并随机抽取 10% 数据，约 10M transitions/game（含 frame stacking）。
  • 游戏子集：选取 14 个 Atari 游戏，因 rlu-atari 不含 Berzerk；保持 easy/medium/hard 难度分布。
  • 模型规模：MHWA 总参数 77.27M，每前向激活 60.49M；使用 K=36 视觉 token/帧，L=8 帧 context window。
  • 训练资源：2 张 NVIDIA A40 GPU，AdamW，学习率 1e-4，batch size 1024，0.875M gradient steps，约 21.6 GPU-days。
  • 计算量：48.199 GFLOPs/sequence，比 JOWA-70M 少 42.78%，比 JOWA-150M 少 70.88%。
Card 06 评估与结果

评估与结果

  • 评估环境与基准：多游戏离线 Atari，14 游戏子集，10% 离线数据，每游戏 16 episodes；对比 MTBC、MGDT、EDT、Scaled-QL、JOWA-40M/70M/150M。
  • 主要指标：Human Normalized Score (HNS)、IQM HNS、Median HNS，采用 RLiable 的 seed-by-game 聚合和 3 个训练 seed；开环诊断使用 MSE/PSNR/SSIM。
  • 主结果：MHWA-77M 达到 IQM HNS 0.884，95% CI [0.736, 1.031]；匹配 JOWA-70M 为 0.529 [0.459, 0.602]；JOWA-150M 已发表结果为 0.833。
  • 表 1 补充：Ours 的 IQM HNS 为 0.867±0.047，Median HNS 为 0.676±0.049，优于 JOWA-150M 的 0.833/0.582。
  • 开环 rollout：JOWA-70M 随 rollout 深度增加明显退化；MHWA 在 t=5..8 稳定，MSE/SSIM 匹配或超过 JOWA-150M，长程 t=5..54 诊断也优于小基线并接近大基线。
  • 消融：k=1 导致最大相对 IQM 下降 62.1%；w/o State 36.3%，w/o L_aux 21.3%，MoE-only 21.1%，w/o MoE 20.2%，w/o L_high 10.8%；stop-gradient 有正面作用，4 experts Top-2 配置最佳。
  • 可解释性：PCA 专家激活显示 Assault 与 Phoenix 在完整 MHWA 中具有相似专家使用模式；移除 L_high 或 stride 后该相似性消失。
