Card 02 论文概述

论文概述

  • 提出 RoboSynChallenge 竞赛，旨在量化评估“模拟数据在真实数据稀缺时对操纵策略泛化性的提升效果”，聚焦 Sim2Real 迁移能力。
  • 该竞赛构建了统一的基准，将大规模合成数据生成与标准化真实世界机器人评估相结合，最终评估仅在未见过的真实世界操纵环境中进行。
  • 提供多种基线模型（Transformer、扩散模型、VLA、World Action Model）和完整开源工具链，以促进可复现、可比较的通用机器人操作研究。
Card 03 核心贡献

核心贡献

  • 首个标准化的 Sim2Real 迁移性基准：填补了现有基准（大多为 Sim2Sim 或 Real2Real）的空白，系统评估策略在真实世界噪声和域偏移下的鲁棒性、适应性与泛化能力。
  • 生成式数据流（Generative Data Streaming）：集成 EmbodiChain 自动化数据生成管线，过程式合成仿真环境并闭环生成运动轨迹，支持样式迁移、视频生成模型和场景增强，实现大规模多样化数据获取。
  • 真实世界评估：将真实机器人评估纳入官方排行榜，提交的策略在标准物理平台上部署测试，与仿真任务定义和指标一致，直接度量 Sim2Real 性能。
  • 双机械臂灵巧操作：与以往单臂或纯仿真基准不同，RoboSynChallenge 统一了双臂操作场景，覆盖刚性物体、铰接物体、可变形物体和工具使用。
  • 开源工具与基线：提供 ACT、Diffusion Policy、π₀、π₀.5、Motus 五种代表性基线，以及数据加载器、训练脚本、检查点格式和评估包装器。
Card 04 方法描述

方法描述

  • 数据生成：基于 EmbodiChain 生成大规模仿真数据，每任务 1000 条轨迹，包含 RGB-D、本体感觉、物理场景元数据及任务语义标注；同时通过遥操作采集少量真实数据（每任务 60 个样本）。
  • 数据扰动与泛化：仿真中随机扰动光照、物体属性、桌面属性、背景色、机器人配置、相机内外参；真实数据在五种实验条件 × 四种位置 × 三种朝向组合下采集。
  • 基线策略：提供五类策略——ACT（Transformer 动作分块）、Diffusion Policy（条件去噪扩散）、π₀（VLM + flow matching）、π₀.5（部分微调 VLM 主干）、Motus（基于光流的潜在动作世界模型，混合 Transformer 架构）。
  • 评估协议：在真实世界进行背景变化（3 种纹理）、光照变化（3 个位置/颜色）、物体变化（已见/未见实例）、干扰物（2/4/8 个）和空间泛化（3×3 网格）的系统性变化评估。
Card 05 数据集与资源

数据集与资源

  • 数据集名称：RoboSynChallenge 专用数据集（由 EmbodiChain 生成）
  • 数据规模：每任务 1,000 条模拟轨迹 + 每任务 60 个真实遥操作样本
  • 数据模态：RGB-D 图像、本体感觉信号、物理场景元数据、任务语义/接触/成功标注
  • 数据发布：通过 Hugging Face 公开，使用 CC BY-NC-SA 4.0 许可证，并提供元数据、文档和生成代码
  • 硬件资源：双 AgileX Piper 6-DoF 机械臂平台，配备可调高度桌面、可更换桌布、可配置照明；部署推理使用 NVIDIA A800 GPU
Card 06 评估与结果

评估与结果

  • 评估环境：真实世界双机械臂物理平台，包含三套备份工作站，任务分为入门级（点击铃铛、桌面重排、倒水、提篮）、中级（物品交接、抽屉开关放置、搅拌器操作）、高级（物品组装、移液枪操作、样本加载）。
  • 主要指标：成功率（SR，%）、推理时间（秒）、动作步数（最大 1000）
  • 关键实验结果（表 2）：

- Motus（real） 在点击铃铛任务上取得最佳成功率 14/20，动作步数 420.50，时间 70.11s

- π₀.5（sim） 在桌面重排任务上取得最佳 SR 12/20，动作步数 612.90，时间 61.31s

- π₀.5（sim） 在篮子取放任务取得 10/20，抽屉开关放置 11/20，表现优于 π₀

- Motus 在物品交接任务上表现突出（sim 10/20，real 12/20），但推理时间较长（约 80-160s）

- 高级任务（移液枪、样本加载）整体成功率较低，最高为 π₀.5（sim）的 4/20，显示高难度任务仍具挑战

- 任务平均成功率方面，π₀.5（sim） 为 38.50%，Motus（sim） 为 31.50%，均优于 π₀（22.00%）
