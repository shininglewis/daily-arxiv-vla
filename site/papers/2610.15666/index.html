Card 03 核心贡献

核心贡献

  • 构建首个波斯语 VLA 数据集：258 条实例、230 张真实（非模拟）家庭/办公照片，包含参考计划、显式歧义与不可行标签、消歧问答对，以及训练集自动蒸馏的思维链（CoT）推理。
  • 对检索增强（RAG）、思维链提示（CoT）与智能体消歧进行受控消融实验，并通过 36 组配对显著性检验量化哪些效应在现规模下可统计区分——发现检索增强是唯一稳健显著的主效应。
  • 提出 PGOS-FA 指标：在 PG2S 基础上扩展步骤顺序敏感性、过度生成惩罚与波斯语适配嵌入，并在 79 条真实模型输出上与盲评人类判断做相关性验证，表现不逊于 LLM-as-Judge。
  • 通过匹配生成对照实验分解开放权重模型与强闭源模型的差距，发现差距主要来自模型代数更新而非闭源模型本身的能力优势。
  • 揭示细粒度消融排序在现规模下不稳健，而粗粒度检索增强收益稳健，作为关于基准实践的方法论贡献。
Card 04 方法描述

方法描述

  • 任务定义：给定波斯语指令 I 与单张静态场景图像 V，输出可执行步骤序列 P，或判定指令不可执行并说明原因。
  • 设计 8 种流水线配置（Baseline → 1-shot RAG → 3-shot RAG → +CoT → 未澄清示例变体 → +消歧 → +消歧+CoT → CoT 示例检索），逐步叠加组件。
  • 检索模块：基于 Tooka-SBERT 指令嵌入的余弦相似度检索 k=3 个训练样本，仅以文本形式（指令、参考计划、CoT）注入提示。
  • 消歧智能体：三阶段交互（最多 3 轮）——验证器判断歧义并提问、人类模拟器依据真值问答作答、指令合并器重写为明确指令 I′。
  • 评估方法：LLM-as-Judge（7 个候选评判模型 × 3 种少样本设置，最终选 Gemini-2.5-Flash）与 PGOS-FA（含不可行短路、goal-wise 与 sentence-wise 子分数、Kendall τ 顺序分，α=0.3）。
  • 依赖解析使用 Stanza 的波斯语流水线（基于波斯语依存树库）。
Card 05 数据集与资源

数据集与资源

  • 数据集：258 条实例 / 230 张唯一照片；划分含 120 条检索池、39 条验证集、99 条测试集。
  • 标注统计：23 条歧义、13 条不可行、1 条同时具备两种属性；由 19 位贡献者采集。
  • 主干模型：开放权重 Gemma-3-27B-IT（所有智能体角色统一使用），另测试更新一代开放权重模型与更强闭源规划器。
  • 评判模型候选：GPT-4.1-nano/mini/4.1、GPT-4o/4o-mini、o4-mini、Gemini-2.5-Flash。
  • 论文未明确给出训练所用 GPU/TPU 等硬件资源信息。
Card 06 评估与结果

评估与结果

  • 评估环境：n=39 验证集消融 + n=99 留出测试集；置信区间用 1,000 次非参数 bootstrap（百分位法）估计。
  • 主要指标：PGOS-FA 与 LLM-as-Judge 准确率；LLM-Judge 在 PGOS-FA 有效的场景下统计功效接近零。
  • 关键结果：检索增强是幅度大且稳健显著的主效应；更细粒度组件方向一致但未达统计显著。
  • 留出集上配置 7（RAG + 消歧 + CoT，英文提示）为最佳配置；最佳配置以更弱主干显著优于独立复现的外部基线。
  • PGOS-FA 在顺序敏感性专项测试中区分度极强（顺序正确 1.000 vs. 顺序打乱 0.531，Cohen's d=3.15，Wilcoxon p<10⁻³⁸，n=233），且与人类判断的相关性至少与 LLM-Judge 相当。
