Card 02 论文概述

论文概述

  • 论文关注部分可观测条件下的语言条件机器人操作问题：仅凭当前观测往往无法获得近期运动信息或更早的任务相关视觉证据，因此相同的当前画面可能对应不同的正确动作。
  • 论文提出 PREM（Prediction-Regulated Memory） 框架，利用动作条件下的未来预测同时指导记忆学习与视觉状态更新。
  • 论文要解决的核心问题是：在循环视觉记忆架构中，视觉状态应当表示什么，以及如何在新观测到来时更新视觉状态，才能既保留有用的历史，又不丢失关键信息。
Card 03 核心贡献

核心贡献

  • 提出用动作条件下的未来预测作为记忆学习的时间监督信号，使视觉状态倾向于保留对预测后续视觉特征有用的历史信息。
  • 提出以空间归一化的预测偏差作为反馈来调节视觉状态更新：对预测偏差大的空间位置，更多地纳入新的观测；对偏差小的位置，则保守更新。
  • 将预测机制与 VLA 策略（基于 π0.5） 端到端联合微调，视觉状态作为时间上下文与当前观测一起用于动作生成。
  • 无需关键帧标注、事件标注或外部运动估计器，更新信号直接来自未来观测。
  • 在动态操作、记忆依赖操作、通用操作与空间扰动鲁棒性四类任务上均取得提升，并且只带来 7.7 ms 的平均推理开销。
Card 04 方法描述

方法描述

  • 基础架构：以 π0.5 为基座 VLA 策略，耦合循环视觉记忆（RVM）架构与动作条件预测器，形成“预测—验证—更新”循环。
  • 预测偏差：对当前观测提取 patch 级视觉特征，与上一决策缓存的预测在相同空间布局上逐位置比较；偏差函数 δ 结合余弦距离与逐 token 归一化后的 Smooth-L1。
  • 空间归一化：用空间中位数 μ 与中位绝对偏差 ρ 归一化得到相对偏差 ξ，使信号反映“相对其他位置”的差异，而非绝对帧级不可预测性。
  • 更新系数：β 由 sigmoid 门控给出，β_min=0.25、τ=2.0、γ=0.5；视觉状态按 M_t = M_{t-1} + β ⊙ (M̃_t − M_{t-1}) 插值更新，β_min 保证非零最小更新量。
  • 动作条件预测器：查询式 Transformer 解码器，输入为流入视觉状态 M_{t-1}、当前视觉特征 X_t 与策略动作专家最后一层动作 token 特征池化得到的潜在动作表示，输出下一决策的视觉特征预测。
  • 训练目标：L = L_act + λ_pred · L_pred，λ_pred=0.1；预测损失对目标特征做 stop-gradient，并按 0.75 的伯努利采样选择监督 patch；不引入额外或 EMA 目标编码器。
  • 训练细节：按观测片段因果展开循环通路，片段间重置且无 burn-in；更新系数在训练中由 1 线性过渡到完整 β；推理时使用完整预测调节系数，回合边界重置状态并清空缓存预测。

Card 06 评估与结果

评估与结果

  • 评估方式：以回合成功率（episode success rate）为主要指标，同时评测端到端推理延迟；对比基线包括 OpenVLA、SpatialVLA、π0、π0-FAST、GR00T-N1、X-VLA、PAM、MemoryVLA、MemoryVLA++、CronusVLA、ChainVLA、PUMA、DP、ACT、MemER、Mem-0、MaP-WAM 等。
  • 通用操作（LIBERO）：平均成功率从 96.9% 提升到 98.7%，其中 LIBERO-10 从 92.4% 提升到 97.2%（+4.8），Spatial / Object / Goal 分别提升 0.4 / 0.8 / 1.4 个百分点。
  • 空间扰动鲁棒性（LIBERO-Pro）：平均成功率从 25.7% 提升到 43.1%，Object 套件从 16.2% 提升到 67.4%（+51.2）。
  • 动态操作（DOMINO）：35 任务平均从 9.63% 提升到 20.74%（+11.11），比 PUMA 高 3.54 个百分点，35 个任务中有 31 个优于 π0.5；例如 Adjust Bottle 52%→74%，Dump Bin Bigbin 0%→37%。
  • 记忆依赖操作（RMBench M(1)）：平均从 14.4% 提升到 83.8%（+69.4，高于 MaP-WAM 8.2 个百分点），Rearrange Blocks / Put Back Block / Swap Blocks / Swap-T 分别达 100% / 100% / 98% / 99%。
  • 消融（DOMINO）：仅加 RVM 达到 15.43%，再加未来预测监督达到 18.31%，再加预测调节更新达到 20.74%，说明二者均有独立增益。
  • 推理效率：端到端平均延迟 51.5 ms，对比 π0.5 的 43.8 ms，平均开销 7.7 ms；优于 PUMA（57.4 ms）、Mem-0（96.6 ms）与 MemoryVLA（133.8 ms）。
  • 机制分析：预测偏差曲线在抓取、物体运动、遮挡变化与放置等关键时刻显著升高，更新响应在空间上集中于夹爪与被操作物体附近，与设计动机一致。
