Card 03 核心贡献

核心贡献

  • 提出分离 自然预测精度、受控目标状态响应性 与 上下文稳定性 的评估框架，利用物理验证的交叉观测（目标坐标 × 机器人上下文）。
  • 证明在固定表示–读出器对中，高自然轨迹精度可与弱受控目标状态响应性共存；四个任务–表示组合中全部 12 个场景的端点增益 G_s < 1。
  • 通过表示、读出器、训练数据和模型选择等比较与干预，表明三种诊断属性提供不同信息；受控诊断还能在初始状态误差和物理变量之外提供额外策略失败预测信息。
  • 将诊断与策略行为、任务结果关联，发现干预条件下的精度排序并不总能保持成功率排序，强调需同时检查预测、动作、物理进展和成功。
  • 报告跨任务、跨表示和跨模型的鲁棒性，并指出自由物体设置未复现相同中心模式，部分比较因物理/支撑条件不可估计。
Card 04 方法描述

方法描述

  • 设冻结表示 z = f(o)，拟合状态读出器 q̂ = h(z)；对同一 h∘f 在自然观测和交叉受控观测上评估。
  • 目标状态 q 为单一连续物理坐标，如关节位移、旋转角或物体位置分量；机器人上下文 p 为观测时的机器人位姿/构型。
  • 交叉设计：P 个机器人上下文 × K 个目标坐标；固定 p 变化 k 评估响应性，固定 k 变化 p 评估同一状态下的上下文稳定性/敏感性。
  • 指标包括：

- 自然 MAE / 受控 MAE：加权平均绝对误差。

- 端点增益 g_sp：q̂ 端点差与真实 q 端点差之比；场景均值 G_s；完美响应为 1，0 表示端点预测不变，负值表示方向相反。

- 增益误差 E_G,s：平均 \|g_sp - 1\|，检测不同上下文中欠响应/过响应抵消。

- 上下文敏感性 R_s：固定坐标下不同上下文预测范围的均值；小 R_s 表示跨上下文变化小，但需与响应性和精度联合解释。

  • 受控观测构造：恢复模拟器状态，设置物体关节坐标和零速度，执行 60 步固定中性动作；进行物理与视觉验证（目标可见面积、端点质心位移、重复渲染一致性等）。
  • 读出器：冻结编码器，使用训练特征拟合 Ridge 读出器（λ=0.001），并比较 RBF、MLP、PCA-ridge 等；比较全自然训练、匹配自然训练、匹配受控训练和联合训练。
  • 统计：以独立初始化为单位，精确符号检验、Holm 校正、配对场景 bootstrap（主确认 20,000 次；坐标–上下文分配分析 5,000 次）。
Card 05 数据集与资源

数据集与资源

  • 主确认任务：Meta-World 3.1.1 中的 drawer-open-v3 与 faucet-open-v3，物理引擎 MuJoCo 3.3.0。

Card 06 评估与结果

评估与结果

  • 主确认：在 Drawer 和 Faucet 上使用 SmolVLA、OpenVLA 冻结特征 + Ridge 读出器。
  • 关键现象：低自然 MAE 与小端点增益共存：

- Drawer/SmolVLA：自然 MAE 5.554，受控 MAE 74.184，G 0.1806，E_G 0.8194，R 16.499。

- Drawer/OpenVLA：自然 MAE 3.892，受控 MAE 75.884，G 0.1525，E_G 0.8475，R 9.797。

- Faucet/SmolVLA：自然 MAE 0.0763，受控 MAE 0.6698，G 0.0211，E_G 0.9789，R 0.1285。

- Faucet/OpenVLA：自然 MAE 0.0570，受控 MAE 0.6475，G 0.0512，E_G 0.9488，R 0.1008。

  • 所有 12 个场景中 G_s < 1；四个响应性符号检验经 Holm 校正后 p = 0.001953125。
  • 鲁棒性：实际坐标匹配、RBF/MLP 读出器、不同表示位置/池化以及 π0、GR00T N1.6 和多种非 VLA 视觉编码器上仍可见分离；但非线性设置对受控误差或响应的改进并不一致地转化为自然精度提升。
  • 自由物体范围：马克杯 world-x 位置情境下，自然 MAE 128.314 mm、受控 MAE 39.765 mm、G 0.140，高自然精度 + 弱受控响应的中心模式未复现；支撑条件后续分析不可估计（43 个物理有效、5 个支撑有效、交集 0，低于最小 32）。
  • 训练干预：用 36 个受控观测替换 36 个自然观测可降低受控 MAE 和增益误差，但提高自然 MAE 和平均上下文敏感性；联合自然–受控训练可同时降低两个 MAE 且不降低上下文敏感性；50:50 MLP 混合在原始评估下四个组合均改善两个 MAE，但实际坐标匹配下仅一个组合改善。
  • 失败预测：在 96 个开发初始化上拟合，在 128 个独立评估初始化上评估；M0 仅用初始状态误差和物理变量；M_GR 加入 E_G 和 R；M_C 加入受控 MAE；M_CGR 加入受控 MAE + E_G + R。

- Brier：M0 0.181515、M_C 0.175654、M_GR 0.171381、M_CGR 0.169677。

- Log loss：M0 0.543533、M_C 0.528602、M_GR 0.519075、M_CGR 0.514777。

- 受控诊断提供超出初始误差和物理变量的额外失败预测信息；但 M_GR−M_C 与 M_CGR−M_C 的个体 95% 区间对两个损失均包含零。

  • 行为关联：自然整条轨迹 MAE 与成功相关，但干预条件下的精度排序不一定保持成功率排序；同一初始目标坐标下，改变机器人上下文使 MAE 从 38.766 mm 降至 30.684 mm，但成功率从 106/128 降至 52/128；在 Stove 上小读出响应可与高策略成功率共存。
  • 总体结论：评估 VLA 状态读出时，不能只看自然预测精度，应同时考察目标状态响应性和上下文稳定性/敏感性，并检验其与实际策略行为和任务结果的关系。
