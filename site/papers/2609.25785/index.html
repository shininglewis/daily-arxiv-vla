Card 03 核心贡献

核心贡献

  • 提出 力落地的当前视觉表征：将每根手指的执行器力与其对应指尖位置在同一腕部相机图像中空间对齐（渲染为指尖处的 3D 箭头力线索）
  • 提出 力落地的目标表征：构建前景隔离的力目标图像，统一表达任务相关的手/物期望配置与逐指期望力
  • 提出 目标条件交叉注意力（goal-conditioned cross-attention）：让当前腕部 token 显式关注任务相关的前景目标 token，实现当前观测与期望目标的耦合，进而生成力感知动作
  • 在真实机器人上验证：跨期望力条件呈现一致的抓取力响应，并在力敏感抓取与多阶段力感知操作任务上优于多种力条件化基线
  • 证明该方法在指尖被物体遮挡与保持持续工具接触下反复调整力两类困难场景中的有效性
Card 04 方法描述

方法描述

  • 基础模型为 π0.5 VLA 模型，在其之上新增两个组件：力落地视觉表征与目标条件交叉注意力
  • 腕部相机对齐渲染：在 MuJoCo 中复现真实机器人构型，通过手部掩码 IoU 与边缘 Chamfer 损失优化模拟腕部相机的 6-DoF 外参；真实掩码由 GroundingDINO + SAM2 获得；采用 Differential Evolution 粗优化 + Powell 精优化
  • 力视觉线索生成：以指尖位置 p_t^i 与法向 d_t^i 构造向量 v_t^i = α f_t^i d_t^i（α = 1×10⁻⁴），按手指特定颜色渲染为 3D 箭头，仅对超过阈值（滤除小幅执行器波动）的力渲染，再叠加到真实腕部图像
  • 力目标图像构建（离线）：从参考示范中选取测量执行器力最接近预设期望力 F_k^g 的代表帧 → 用 GroundingDINO + SAM2 分割手与物体得到前景隔离图 → 在同一渲染流程下在指尖位置渲染期望力，推理时按子任务检索，无需在线分割
  • GoalAttnBlock：预 LayerNorm 交叉注意力，8 个注意力头；使用 14×14 patch 级前景掩码 M_fg 限制 key/value 仅为前景目标 token；残差连接 + 两层 FFN（扩张比 4，GELU）
  • 腕部图、目标图与外部相机图共享同一 SigLIP 视觉编码器；交叉注意力仅作用于腕部流，外部相机 token 走 π0.5 原视觉通路；训练损失沿用基模型的 flow-matching 损失
  • 训练策略：视觉编码器与交叉注意力模块全参数更新，VLM 主干与动作专家用 LoRA（rank r=16，scaling α=16）微调，所有对比方法使用相同 LoRA 配置
  • 动作定义为 12 维 delta 动作：[Δa_arm (6), Δa_hand (6)]，输出长度为 H 的动作块

Card 06 评估与结果

评估与结果

  • 真实机器人评估，每任务 N = 20 次独立试验；T2–T4 采用累计阶段成功率（要求前序阶段全部成功），报告 95% Wilson 置信区间
  • 四个评估维度/任务：T1 力条件抓取（刚性物体、鸡蛋、牙膏）、T2 杯子插入与瓶子倒水、T3 夹钳辅助面包转移、T4 滑移调制的 peg-in-hole
  • 对比方法：π0.5（无力信息）、State Force + Text Force Goal（力作为状态 + 文本期望力）、Visual Force + Text Force Goal（力落地腕图 + 文本期望力）、VisForce w/o CA（去掉交叉注意力，直接拼接），以及 VisForce（完整方法）
  • T1 结果：随期望力增大，VisForce 的聚合执行器力一致上升且三种力水平清晰分离（对比方法区分度有限）；鸡蛋抓取-提升成功率 70%、牙膏 80%（对比：Visual Force + Text Force Goal 为 40%/20%，State Force + Text Force Goal 为 35%/5%）
  • 多阶段任务最终成功率：VisForce 在 T2 达 70%、T3 达 55%、T4 达 40%；对应 Visual Force + Text Force Goal 为 65%/20%/20%，State Force + Text Force Goal 为 20%/5%/5%，π0.5 为 20%/5%/5%
  • 交叉注意力消融：VisForce w/o CA 在 T2/T3/T4 仅 10%/5%/15%，远低于 VisForce 的 70%/55%/40%，说明目标条件交叉注意力比简单 token 拼接更有效
  • 结论：指尖对齐的视觉力表征可有效用于 VLA 灵巧手操作中的力感知条件化，尤其在指尖遮挡与持续接触下反复调整期望力的场景中优势明显
