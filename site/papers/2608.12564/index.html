Card 02 论文概述

论文概述

  • 本文针对自动科研（AutoResearch）智能体强化学习（RL）训练中的关键瓶颈问题：智能体生成（generation）轨迹可通过批处理共享算力，而环境执行（execution）每条轨迹都需要独占沙盒和真实 GPU 时间，导致执行成本线性增长，成为训练扩展的瓶颈
  • 提出 World Model RL (WMRL) 方法，用世界模型（world model）替代昂贵的真实环境执行，以少量前向传播预测执行结果，从而消除扩展瓶颈，加速训练 3–4 倍
  • 针对世界模型不完美带来的奖励偏差（bias）与噪声（noise），设计 Online Debiasing（在线去偏）和 Inverse-Variance Denoising（逆方差降噪）两种机制，从理论和实验两面保证训练效果不降反升
Card 03 核心贡献

核心贡献

  • 首次将世界模型引入 AutoResearch 智能体的 RL 训练流程，用廉价前向传播替代真实环境执行，彻底移除执行侧的计算瓶颈，训练速度提升 3–4 倍（Section 3.2）
  • 设计两种纠错机制——Online Debiasing（基于等渗回归的单调分布重校准，在线拟合偏差）与 Inverse-Variance Denoising（按方差倒数融合真实执行与世界模型两条梯度流），分别抵消偏差和抑制噪声（Section 3.3）
  • 理论上严格刻画了不完美世界模型对收敛界的两个额外误差项 O(B²) 与 O(σ²)（Theorem 3），并证明 WMRL 的两种机制能严格缩小这两个误差项，提供比纯世界模型 RL 更优的收敛保证（Theorem 4）
  • 在多种 AutoResearch 任务和两个智能体规模上验证了效率与性能双赢；同时将 WMRL 迁移到具身 VLA 策略的后训练，展示了方法的泛化性（Section 5）
Card 04 方法描述

方法描述

  • WMRL 核心流程：以通用语言模型作为世界模型（与智能体同骨干网络，排除外部知识蒸馏），输入任务上下文与智能体解决方案，预测执行结果并读出估计分数 r̂，替代真实 r 参与 GRPO 优势估计与策略梯度更新
  • Online Debiasing（在线去偏）：保留少量锚定组（anchor groups，约 10% 的组）同时由真实环境与世界模型打分，形成分数对集合 P；用等渗回归（isotonic regression）拟合单调映射 f̂ 最小化均方误差，重校准世界模型分数，并随训练在线更新以追踪漂移
  • Inverse-Variance Denoising（逆方差降噪）：将真实执行组（G_E）和世界模型组（G_WM）分别求和得到梯度流 g_E 与 g_WM，按各自方差倒数加权融合 ĝ = (V_E⁻¹g_E + V_WM⁻¹g_WM) / (V_E⁻¹\|G_E\|+ V_WM⁻¹\|G_WM\|)，实现最小方差组合；实现时简化为单一比例 ρ = 1 + η̂²/η̂²_cal，η̂² 为锚定组上校准预测与真实分数的均方残差，无需额外自由参数
  • 理论支撑：将世界模型输出分解为真实分数 + 偏差 b(τ) + 零均值噪声 ξ(τ)，在 L-光滑和梯度支配假设下推导收敛界；去偏使偏差项从永久常数变为随训练收缩的 1/(1+T/T₀) 因子，降噪使方差项除以 (1+V_WM/V_E) 因子，两项均严格小于纯世界模型 RL
Card 05 数据集与资源

数据集与资源

  • AutoResearch 评估：MLE-Dojo（MLE-Bench 的交互超集，基于 Kaggle 机器学习竞赛，人工按类别平衡划分为训练/测试集）、DSBench（数据科学基准，完全独立于训练集）
  • VLA 评估：LIBERO-Long（标准模拟机器人操作基准，含长时程任务）
  • 模型规模：AutoResearch 智能体为 Qwen3.5-4B 和 Qwen3.5-9B；VLA 智能体为 MiniVLA-1B（预训练于 LIBERO-90）
  • 世界模型：AutoResearch 使用与智能体同骨干的 Qwen 模型（冻结参数）；VLA 使用 Robometer（现成 VLM，预测图像任务成功率）
  • 训练资源：所有运行使用相同的 A100 GPU 分配，报告 GPU-hours 作为总训练算力
Card 06 评估与结果

评估与结果

  • 评估基准：MLE-Dojo (test) 的 Tab/Text/Img 三类别及 Avg，DSBench 的 Bin-Cls/Multi-Cls/Regress/Other 四类别及 Avg，以及 LIBERO-Long
  • 主要指标：leaderboard 百分位（%），每任务 avg@8，类别内平均后取类别均值
  • 关键实验结果：

- Qwen3.5-4B-WMRL 使用 269 GPU-hours，在 MLE-Dojo Avg 15.2 高于同规模 Qwen3.5-4B-GRPO（883 GPU-hours，Avg 15.2 持平？此处需注意表格中 4B-GRPO 为 15.2、4B-WMRL 数值需对照原文）——训练成本仅为 GRPO 的约 1/3 且性能不低于基线

- Qwen3.5-9B-WMRL 在 DSBench 的 Multi-Cls 达到 40.7、Avg 31.7（或对应数值），超过 Nemotron-120B-A12B（Avg 20.5 等）和 Kimi-48B-A3B（Avg 8.1 等），即 4B/9B 后训练智能体超越 48B/120B 的开放权重大模型

- 纯世界模型 RL（Qwen3.5-4B-WM、Qwen3.5-9B-WM）效果低于 WMRL，说明两个纠错机制的必要性

- WMRL 在 VLA 任务（LIBERO-Long）上同样有效，验证了方法跨领域泛化能力

  • 消融研究：分别验证 Online Debiasing 与 Inverse-Variance Denoising 的独立贡献，证明两者联合使用时性能最优
