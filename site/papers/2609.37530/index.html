核心贡献

  • 系统分析了成像管线对 VLA 模型的影响，涵盖增益、传感器噪声、色度响应、色调响应和位深五个维度，证明 ISP 选择会实质性影响 VLA 动作预测。

Card 04 方法描述

方法描述

  • 因果流式公式化：RawVLA 是因果、任务驱动的 ISP，从连续 RAW 帧经 burst denoising 得到去噪帧 $X_t$，并递推更新：$(Y_t, S_t, \Theta_t) = \operatorname{RawVLA}(X_t, S_{t-1}, \Theta_{t-1})$，其中 $Y_t$ 为渲染观测、$S_t$ 为潜在时间上下文、$\Theta_t$ 为显式 ISP 参数集。
  • 递推光度条件化：为解决 ISP 参数可辨识性问题，将正交的非彩色（achromatic）与彩色（chromatic）条件编码为解耦的递推状态。亮度状态基于等通道亮度图 $L_t$ 提取空间特征 $g_t$ 与亮度描述子 $h_t^L$，经 GRU 更新；色度状态仅使用尺度不变统计量（色度坐标 $\chi_t$ 与对数色度比 $q_t$），避免全局亮度泄漏到颜色估计。
  • 结构化神经 ISP 解码：从解耦状态预测结构化参数 $\Theta_t = \{e_t, w_t, A_t, \ell_t\}$，包括曝光（EV 空间）、白平衡（零和通道偏移）、$3\times3$ 颜色校正矩阵（单位矩阵中心的有界残差）和单调非彩色色调曲线（8 阶 Bernstein 多项式，softmax 参数化保证单调性和端点保持）。
  • 动作驱动优化：直接使用下游 VLA 策略的原生动作目标 $\mathcal{L}_{\mathrm{action}}=\mathcal{L}_{\mathrm{VLA}}(Y_t,\mathbf{a}_t)$ 优化，VLA 参数固定，梯度经 $Y_t$ 更新 RawVLA，无需像素级监督。并加入两个路径特定正则项：亮度正则 $\mathcal{L}_{\mathrm{bright}}$（均值趋向 0.48）和色度正则 $\mathcal{L}_{\mathrm{chroma}}$（约束输出对数色度在线性范围内）。

数据集与资源

  • 使用基准：LIBERO（四个套件，重放 2,000 条官方示范，保留 1,771 条成功轨迹）和 RoboTwin 2.0（13 个双臂任务，重放 650 条示范，获得 632 对成功轨迹）。

Card 06 评估与结果

评估与结果

  • 评估环境：模拟环境（LIBERO、RoboTwin 2.0）与真实世界双臂机器人平台；RawVLA-Bench 的详细构建与评估设置见附录 B。
  • 主要评价指标：任务成功率（Success Rate，%），在 LIBERO 上按 SOG（Spatial、Object、Goal 平均）、Long（LIBERO-10）和 Avg（四个套件平均）报告。
  • ISP 敏感性分析结果：曝光是最具影响力的维度（严重欠曝/过曝时性能崩溃，WAM 稳定范围最窄）；传感器噪声在中等噪声起迅速退化（WAM 退化更早更剧烈）；色度响应中 VLA PI 系列较鲁棒而 WAM 有明显颜色偏好（偏好暖色调）；色调响应在过平或过高对比时急剧退化；位深影响相对最小，VLA 可稳定至 3 bit，2 bit 时明显下降。
  • RawVLA-Bench 关键结果（LIBERO，Qwen3-OFT 主干）：ExtremeLow 照明下，Default ISP 仅 0.00% Avg，DarkISP/RAWAdapter/RAWild 约 1.30–2.10%，而 RawVLA（Ours）达 40.70% Avg；Lowlight 下 RawVLA 达 84.35% Avg，远超基线（最佳基线 RAWild 约 5.10%）；说明 RawVLA 在退化成像下大幅提升鲁棒性。
  • 论文还展示了在低光条件下的真实世界任务完成定性结果，并将 ISP 的显式建模确立为物理相机与具身策略之间的有效接口。
