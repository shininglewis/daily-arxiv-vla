Card 02 论文概述

论文概述

  • 论文提出 NEO-VLA，一个"结构原生（structurally native）"的视觉-语言-动作（VLA）框架，去掉独立预训练视觉编码器，让像素直接进入语言主干并与文本联合演化。
  • 核心研究问题：动作策略应当继承一个固定的视觉端点（编码器输出），还是直接访问不断演化的视觉计算（主干各层表示）？
  • 论文指出机器人操作依赖局部几何、边界、深度与细微状态变化等信号，而这些恰恰最容易被视觉编码器的抽象过程削弱。
Card 03 核心贡献

核心贡献

  • 提出 NEO-VLA：轻量像素到 token 嵌入器 + 共享视觉-语言主干 + 可配置读取主干层级的 flow-matching 动作专家，无需视觉编码器、图像码本或自编码器。
  • 系统研究"动作读出深度（action readout depth）"：在专家容量匹配条件下比较不同层映射（first-28、skip-28、end-28、full-40），并进行挂载点干预实验。
  • 发现动作关键信息常在最终视觉表示之前就已达到峰值：冻结主干时早期层读出显著更优，全量微调后早+晚联合读取最佳。
  • 在匹配的动作专家与机器人训练语料下对比原生主干与编码器式主干（Qwen3-VL-2B、Gemma-3-4B），验证原生接口的优势。
  • 在 LIBERO、LIBERO-plus、RoboTwin 2.0 及真实世界设置上验证分布内性能与分布偏移下的鲁棒性（相机扰动、图像噪声下提升尤为明显）。
Card 04 方法描述

方法描述

  • 原生视觉接口：两级卷积 patch embedder（总步长 32）将原始图像映射为主干 token，每个 32×32 区域对应一个视觉 token；采用 Native Rotary Position Embedding 将位置分解为时间、高、宽三维坐标。
  • 模态感知注意力：文本 token 使用因果注意力，视觉 token 在视觉块内双向交互，使视觉与语言表示逐层共同演化。
  • 多模态前缀：先前与当前多视角图像（每视角含相机身份 token、几何 MLP 编码的内参/旋转、patch token，每视角最多 88 个视觉 token 且保持原始长宽比）、结构化提示（控制频率、具身、夹爪配置、动作坐标系、任务指令）与 6 个机器人本体状态 token 统一拼接。
  • 跨深度动作读出：动作专家第 *j* 层注意力读取主干第 *m_j* 层的缓存 keys/values（层映射 M），使"视觉读出深度"成为显式架构选择。
  • 连续动作建模：采用 flow matching，采样噪声与 flow time τ~Beta(1,1.5)，预测速度场 v_θ(a_τ, τ, C)，目标为 a − ε；损失按四类动作组加权 w_g=(2,1,1,1)（末端/夹爪、臂关节、手关节、身体），并掩蔽缺失通道与越界目标；推理用 10 步 Euler 积分，不使用 CFG。
  • 动作空间：每条臂 R^{2×30×26}（7 关节 + 3 平移增量 + 3 旋转向量增量 + 1 夹爪 + 12 手关节），身体 R^{30×8}（3 基座 + 3 躯干 + 2 头部），按具身归一化。
Card 05 数据集与资源

数据集与资源

  • 预训练语料：9 个公开数据集族共 2,231,583 条 episode、928.40M 行、9,927.7 小时、7,444 视角、2,704 场景。
  • 具体数据集：AgiBot-World、Bimanual YAM、RoboCOIN、Open X-Embodiment、Galaxea Open-World、RoboMIND、RH20T、DROID、InternData-A1（仿真）。
  • 数据清洗管线：关节读数 ±2π 越界检查、五帧局部中位数偏移、恒定通道掩蔽、动作离群值、损坏 episode 剔除、相机标定校验（3D 投影与图像运动一致性打分）。
  • 模型规模：40 层、2B 参数的无编码器视觉-语言主干；first-28/skip-28/end-28 使用 28 层动作专家，full-40 使用 40 层专家。
  • 训练配置：三阶段训练，stage 1 冻结主干训练专家（113,400 步，峰值 lr 2×10⁻⁴）；stage 2 全量解冻（75,000 步，专家 lr 2×10⁻⁴、VLM 参数 5×10⁻⁵）；stage 3 用自建动作数据再训 75,000 步；全局 batch size 8192，AdamW（β₁=0.9、β₂=0.95、ε=1e-8、weight decay 1e-10），2,000 步 warmup + cosine 衰减，bfloat16 混合精度，梯度裁剪 1.0。
  • 多模态理解数据每两步插入一次，辅助下一 token 预测损失权重 0.1。
  • 论文提供的资源：模型权重（HuggingFace weepiess2383/NEO-VLA）、数据集（NEO-VLA-Action-Pretrain）、GitHub 仓库。
Card 06 评估与结果

评估与结果

  • 基准：LIBERO（Spatial/Object/Goal/Long 四个 suite）、LIBERO-plus（相机、机器人、语言、光照、背景、噪声、布局七类扰动）、LIBERO-Pro、RoboTwin 2.0、真实世界平台（含推理时延测试）。
  • 主要指标：任务成功率（%），LIBERO 结果取最终 30k 步检查点，每 suite 500 episodes、共 2,000 rollouts 平均；控制变量统一用 Open X-Embodiment 预训练 75k 迭代。
  • 主干对比（LIBERO 平均）：NEO-VLA 冻结主干 90.9%，优于 Qwen3-VL-2B 的 79.5% 与 Gemma-3-4B 的 84.5%，甚至接近两者全量微调水平；全量微调后 NEO-VLA 达 95.3%（Qwen3-VL 全 FT 90.8%、Gemma-3 全 FT 91.0%）。LIBERO-Long 冻结下 85.4%，超过两个编码器式模型的全 FT 结果。
  • 接口对照：给 Qwen3-VL 直接开放 13 层视觉塔中间特征反而使冻结主干性能从 79.5% 降到 64.9%，全 FT 下两者相当（90.9% vs 90.8%），说明"原生预训练如何塑造表示"比单纯访问早期特征更关键。
  • 层映射消融（LIBERO 平均）：冻结主干时 first-28 94.9% > skip-28 90.9% > end-28 86.7%；first-14 93.6% > last-14 89.6%；全 FT 时 skip-28 95.3% > first-28 94.6% > end-28 92.5%。
  • 干预实验：交换第 0–10 层挂载点的 prefix KV 会造成最大平移误差，而同幅度残差噪声几乎无影响（变化在 0.004 cm 内）；腕部图像敏感性峰值在 6–10 层，指令敏感性峰值在第 0 层（17 层附近次峰），腕部相机位姿掩蔽的影响依赖动作坐标系选择。
  • LIBERO-plus 扰动轴：在已列出的轴中，NEO-VLA（2B、开源）Camera 94.5、Robot 72.6、Language 91.7、Light 96.2、Background 96.6、Noise 96.9，在相机与语言扰动轴上明显优于 π₀（13.8 / 58.8）、StarVLA（52.5 / 88.5）、ABot-M0（60.4 / 86.4）等模型（表格 Total 列在提供的原文中被截断）。
  • 总体结论：具身控制受益于对计算层级中多层视觉表示的访问，而非固定编码器输出；有效控制不仅取决于主干"表示了什么"，还取决于"哪些阶段的视觉计算对动作保持可见"。
