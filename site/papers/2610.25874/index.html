Card 02 论文概述

论文概述

  • 论文提出 Vision-Language-Delta-Action（VLDA） 新范式，把机器人操作从“观测直接生成动作”或“预测完整未来状态”重构为紧凑的可操作状态变化（Delta）建模。
  • 核心观点：机器人操作的本质不是生成整个未来画面，而是实现任务指定的稀疏物理状态变化；大部分视觉内容保持静态，因此完整未来预测会浪费模型容量。
  • 目标是学习一个选择性、可预测、可执行的中间过渡变量 Delta，作为视觉语言理解与动作生成之间的统一表征接口，形成“理解—过渡—执行”闭环。
Card 03 核心贡献

核心贡献

  • 提出 VLDA 范式，用紧凑 Delta 替代完整未来状态预测，作为可操作的过渡接口（actionable transition interface）。
  • 设计统一的 Delta 学习目标：Local Transition Filter（LT-Filter） 提取稀疏、操作相关的局部变化；Global Transition Anchor（GT-Anchor） 提供粗粒度全局未来趋势正则，二者互补。
  • 提出 Delta-Driven Action Refinement（DDAR），包含 DSAF（Delta-Seeded Action Flow）与 DAMG（Delta-to-Action Manifold Grounding），把 Delta 对齐到动作流形并作为结构化种子注入动作去噪过程。
  • 在 LoongForge 框架内实现两阶段统一优化，验证 Delta 在长程一致性、鲁棒性与泛化性上优于直接动作预测与完整未来建模。
Card 04 方法描述

方法描述

  • 整体分解：将动作生成因式分解为 p(A_t\|s_t,l)=∫p_θ(Δ_t\|h_t)p_φ(A_t\|h_t,Δ_t)dΔ_t，其中 World Expert 预测 Delta，Action Expert 依据 Delta 与多模态上下文生成动作块。
  • Delta 生成：在 Delta 空间使用条件流匹配（Conditional Flow Matching），采用 x-prediction 参数化（受 JiT 流形视角启发），由预测的 Δ̂ 反解速度场。
  • LT-Filter：用在线编码器 E_on 与 EMA 教师编码器 E_ema 分别编码当前/未来主视角图像，计算稠密特征差 D_t，取 top-K 变化最大的 token 压缩为紧凑 Delta 目标（K≪P，d_Δ≪d_v）。
  • 集合匹配：因 top-K token 无序，用熵正则化 Sinkhorn 最优传输构建软对应（置换不变），得到集合级匹配损失 L_LTF。
  • GT-Anchor：对当前/未来特征做 adaptive pooling 得到粗粒度全局过渡锚 G_t，将 Δ̂ 上投影回视觉空间后与锚做集合距离约束 L_GTA，避免只关注局部。
  • DSAF：把 Delta 池化为全局过渡上下文，映射为动作空间偏置 b_t，构造带偏置的噪声起点 ε_A' = ε_A + γb_t，并把 Delta 前缀 token 拼接到动作 token 序列参与去噪。
  • DAMG：将 Delta token 与真实动作 token 投影到共享对比空间，以 InfoNCE（软 token 池化 + 困难负样本采样）把 Delta 锚定到动作流形。
  • 防坍缩设计：非对称梯度流、缓慢更新的 EMA 目标、互补过渡约束等。

Card 06 评估与结果

评估与结果

  • 评测设置：LIBERO-Plus 零样本泛化评测（相机、机器人、语言、光照、背景、噪声、布局 7 类扰动 + Spatial/Object/Goal/Long 四个任务套件），并含 RoboTwin 2.0 仿真与两平台真机实验。
  • 主要指标：任务成功率（%）及跨扰动/任务套件的平均值。
  • 关键结果（LIBERO-Plus 平均）：VLDA 84.5%，显著优于 GuidedVLA 75.4%、π0.5 73.6%、DreamVLA 69.9%、OpenVLA-OFT 69.6%、VLA-Adapter 59.1%、π0 53.6%、UniVLA 43.9%、WorldVLA 25.0%。
  • 分项优势：在 Robot（75.3）、Language（84.0）、Light（96.0）、Background（95.5）、Noise（89.4）、Layout（85.7）、Spatial（89.6）、Object（89.8）、Goal（80.1）、Long（78.3）等维度多数取得最优，仅 Camera 维度（72.4）略低于 GuidedVLA（73.7）。
  • 消融实验覆盖：过渡范式对比、LT-Filter / GT-Anchor、DSAF、DAMG、Delta 噪声偏置、token 选择策略、集合匹配目标、Delta token 数量等。
