Learning to Act While Waiting: RL Finetuning of Generalist Robot Policies Under Inference Latency

2026-08-24 · 原文 · 翻译 · 2608.23831

论文针对通用机器人策略（如视觉-语言-动作模型 VLA）在部署中因推理延迟而导致 RL 微调失效的问题，提出了一种延迟感知的微调框架 Arli（Asynchronous RL with Intermediate Information）。 核心思路是结合异步推理（在动作执行的同时计算下一动作）与 RL 微调，通过状态增强恢复近马尔可夫性，使标准 RL 算法在延迟条件下仍能有效学习。 论文在模拟和真实世界操纵任务上验证了 Arli 的有效性，显示其能匹配甚至超越无延迟理想条件下的标准 RL 性能。

Card 02 论文概述

论文概述

  • 论文针对通用机器人策略（如视觉-语言-动作模型 VLA）在部署中因推理延迟而导致 RL 微调失效的问题，提出了一种延迟感知的微调框架 Arli（Asynchronous RL with Intermediate Information）。
  • 核心思路是结合异步推理（在动作执行的同时计算下一动作）与 RL 微调，通过状态增强恢复近马尔可夫性，使标准 RL 算法在延迟条件下仍能有效学习。
  • 论文在模拟和真实世界操纵任务上验证了 Arli 的有效性，显示其能匹配甚至超越无延迟理想条件下的标准 RL 性能。
Card 03 核心贡献

核心贡献

  • 提出 Arli 框架，首次将 RL 微调与异步推理结合，解决了异步推断导致的非马尔可夫状态问题。
  • 提出两种状态增强机制：将中间动作（已承诺待执行的动作序列）纳入 RL 状态，以及利用策略分解（VLM 骨干 + 动作专家）引入中间观测状态，提升对延迟后状态的预测能力。
  • 将 Arli 与 Rtc（Real-Time Chunking）结合，通过 inpainting 保持动作块间连续性，进一步提高微调效率。
  • 提供理论保证（Proposition 1），证明在延迟观测下应用 Q-learning 的次优性上界，且延迟越小子优度越小。
  • 在模拟（Kinetix、AlohaTransferCube）和真实世界（双 UR5e 机器人）上进行了全面实验，包括消融研究，验证了中间状态和中间动作的贡献。
Card 04 方法描述

方法描述

  • 基础算法为 Dsrl（Diffusion Steering via RL），通过训练一个小型 RL 策略选择扩散/流策略的输入噪声，从而“引导”预训练策略的行为。
  • Arli 的关键修改：

- RL 状态从仅使用初始状态 $s_{t-t_{delay}}$ 扩展为 $(s_{t-t_{delay}}, a_{t-t_{delay}:t}, s_{t-t_{delay}^{rl}})$，其中 $a_{t-t_{delay}:t}$ 是已承诺将在延迟期内执行的中间动作，$s_{t-t_{delay}^{rl}}$ 是 RL 策略实际推理时获得的最新中间状态（因为 VLM 骨干占主要延迟，动作专家前才需要噪声）。

- 利用 VLA 的分解特性（VLM 骨干 + 动作专家），将 RL 策略的推理安排在动作专家调用之前，从而获得比初始状态更新的观测。

- 结合 Rtc 的 inpainting 引导，保持新旧动作块间的连续性，同时仍由 Dsrl 选择初始噪声进行 RL 引导。

  • 算法基于 Q-learning（类似 action-chunking Q-learning），在延迟状态下进行策略优化。
Card 05 数据集与资源

数据集与资源

  • 模拟任务：Kinetix 基准（mjc_swimmer, mjc_walker, car_launch），以及 AlohaTransferCube（模拟 bimanual 操作）。
  • 真实任务：Assembly（电源连接器插入）、Shoe-in-Bag（鞋放入袋子）、Bag-Placement（双手放置袋子），在 bimanual UR5e 机器人上进行。
  • 基座策略使用 π0.5（VLA，基于 π0 的微调），以及公开的 π0（3.3B 参数）作为 Aloha 微调策略。
  • 训练资源：模拟实验使用 3 个随机种子；真实实验使用 NVIDIA GeForce RTX 5090 GPU，推理延迟约 $t_{delay}=10$（真实）或 20（模拟），RL 延迟 $t_{delay}^{rl}=7$ 或 10。
Card 06 评估与结果

评估与结果

  • 模拟实验：在 Kinetix 任务上对比 Arli、Dsrl（异步 naive）、Dsrl+Rtc、residual RL，Arli 显著优于所有基线，收敛更快、最终成功率更高；在大规模 VLA 场景（AlohaTransferCube）同样有效。
  • 真实实验：从约 40% 成功率出发，Arli 在 100–125 集内达到接近 100% 成功率，而 Dsrl（synchronous） 和 Dsrl（Rtc） 在相同训练量下难以超过 80%，或在 Shoe-in-Bag 任务中需近两倍时间。
  • 消融实验：

- 中间状态和中间动作均不可或缺，两者结合显著优于单独使用。

- 对延迟 $t_{delay}$ 的敏感性：Arli 比 Dsrl 性能衰减更慢，鲁棒性更强。

- 对 RL 延迟 $t_{delay}^{rl}$ 的敏感性：信息越新（越接近动作专家调用）效果越好，当 $t_{delay}^{rl}$ 大于一半 $t_{delay}$ 时学习改善明显。

  • 吞吐量：Arli 在所有真实任务上的成功率/小时显著高于其他方法。
