Card 02 论文概述

论文概述

  • 提出 InternW0-Δ，一个统一的 World Action Model（WAM），将预训练的视觉动态、场景级语义理解、4D 几何与运动先验以及动作生成整合在单一框架中。

  • 关键在于把视觉动态建模中的预测知识转化为对动作生成直接有用的表征，同时 推理时无需显式采样未来视频。
Card 03 核心贡献

核心贡献

  • 带有动作相关预测表征的世界动作模型：通过在定向 Mixture-of-Transformers（MoT）中耦合预训练视频专家与动作专家，实现未来监督到动作表征的传递。
  • 提出 Causal Imprint：利用仅训练时的未来监督学习与未来相关的场景变化，并将这些预测表征直接暴露给动作专家，推理时无需未来视频 rollout。
  • 引入 training-only 4D-aware 表示蒸馏：从冻结的 Track4World 教师向视频专家注入几何与运动先验，推理时不增加额外策略路径。
  • 可扩展、可复现的"数据到部署"配方：统一 20K+ 小时异构机器人与人类演示数据到规范状态-动作表示，采用两阶段训练并适配目标本体。
  • 跨本体、从仿真到真机的全面评测：覆盖单臂、双臂、移动操作及灵巧手真机平台，并承诺开源代码、权重、训练配方、数据过滤索引与部署工具。
Card 04 方法描述

方法描述

  • 架构：30 层定向 MoT 耦合预训练 Wan2.2-TI2V-5B 视频专家与 ActionDiT 动作专家；每个耦合块中两专家独立计算 Q/K/V 后拼接做一次掩码联合注意力，再各自走跨注意力、FFN 与残差路径。
  • 稀疏记忆上下文（Sparse Memory Context）：仅保留 anchor（片段起始）、recent（上一动作块之前）、current 三帧观测，由冻结 Wan VAE 编码为视觉潜变量，兼顾片段级上下文与近期执行历史。
  • 多模态上下文编码：T5 路径保留视频预训练的语言先验；额外 冻结 VLM 联合处理多视角当前观测、视角标识与指令，为动作专家提供场景级语义（物体、空间构型、机器人-物体关系）。
  • 明确注意力掩码：未来帧 token 可用观测上下文做预测，但 Causal Imprint 与动作 token 无法直接访问真实未来，实现"未来监督"与"策略推理"的定向分离。
  • Causal Imprint：可学习 token 注入视频专家自注意力层，空间布局对齐当前视频潜变量；训练目标包括 (1) 回归相邻干净潜变量差分 ΔZ_t，(2) 与第 20 层末端未来切片特征做余弦对齐（stop-gradient）。
  • 4D 蒸馏：教师输出 clip 级 1430 维 4D 描述子并离线缓存；学生分支从第 15 层 VideoDiT 提取 A/R/C 干净特征，经 16 个可学习 query 与两层 Transformer decoder 聚合后对齐，用 MSE 蒸馏。
  • 训练目标：视频 flow matching + 动作 flow matching + Causal Imprint 损失 + 对齐损失 + 4D 蒸馏损失加权求和。
  • 高效推理：一次视频专家 prefill（缓存各 MoT 层 A/R/C/Δ token 的 K/V）后仅对动作流做 N 步 flow 去噪（从 σ=1 到 σ=0），每步只需重算动作专家；无需未来视频采样或 VAE 解码。
  • 规范动作空间：所有动作映射到固定语义槽位的 80 维规范空间，动作块形如 H_a×D_a（32×80）。
Card 05 数据集与资源

数据集与资源

  • 总规模：超过 20K 小时 处理后训练数据，据称是同类中最大的开源语料。
  • 机器人数据：AgiBotWorld、InternData-A1、RoboMIND / RoboMIND 2.0、RW-RL、Dexora、ABC-130K、Galaxea Open-World Dataset、RoboCOIN、RH20T、RDT-1B、RoboSet、RealSource-World、MolmoAct2-BimanualYAM、HABIT、ActionNet。
  • 第一人称与 Ego2Robot 数据：EgoDex、EgoVerse。
  • UMI 数据：Hy-UMI-10K。
  • 后训练/评测：EBench、RoboDojo、LIBERO / LIBERO-Plus、RoboTwin 2.0。
  • 数据处理：信号异常与一致性过滤、静止边界裁剪、视觉质量过滤、动作幅度守卫、指令正确性与视频-指令一致性过滤、人工语义校验；Ego2Robot 需动作对齐、运动学对齐、视觉对齐、动作速度对齐。
  • 部署硬件：单张 NVIDIA RTX 5090 GPU，灵巧手部署下平均控制器观测往返延迟 152.8 ms，相对标准运行时加速 5.11×。
  • 训练基础设施：视频 VAE 潜变量与冻结视觉语言特征缓存、逐层 MoT 编译、激活检查点。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-Plus、RoboTwin 2.0、EBench、RoboDojo 四个仿真基准，覆盖不同本体、任务需求与分布偏移；另有真机部署（两种夹爪平台 + 两种灵巧手平台）。
  • 主要指标：任务成功率 / 平均成功率 / 综合得分。
  • 关键结果：

- LIBERO-Plus：分布偏移下最佳成功率 92.8%。

- RoboTwin 2.0：Clean2Random 71.9%（最佳），Clean2Clean 90.0%（领先）。

- EBench（移动双臂操作）：最高综合得分 66.0。

- RoboDojo（记忆、精度、长时程任务）：最佳平均成功率 23.9%，约为最强先前 WAM 的 两倍。

  • 消融实验：验证 Sparse Memory Context、VLM、Causal Imprint、4D-aware 表示蒸馏 各组件的贡献，并做了数据来源消融。
  • 真机实验：验证预训练对真机性能的提升、物理条件泛化、跨本体适配以及 RTC 连续性对比；另探索 GPT-Guided Policy。
