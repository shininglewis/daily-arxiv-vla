Card 02 论文概述

论文概述

  • 提出了 Logic-VLA，一个基于 Signal Temporal Logic（STL） 条件的视觉-语言-动作（VLA）模型，可在推理时接收时态逻辑公式作为额外策略输入
  • 解决了自然语言指令难以精确表达安全关键、时空、反应式行为要求的问题，使单一策略能适应不同部署时变化的正式需求
  • 在闭环四旋翼导航仿真中，Logic-VLA 相较于 STL 盲基础策略将 STL 满足率提升 24.8 至 40.7 个百分点（pp），同时名义 NL 任务成功率最多仅下降 1.8 pp
Card 03 核心贡献

核心贡献

  • 提出 Logic-VLA，一种基于 π₀.₅ 的时序逻辑条件 VLA，将结构化正式需求与多模态 VLA 输入融合
  • 开发了 两阶段需求感知后训练框架：先进行 STL 条件监督微调（SFT），再进行轨迹级偏好优化（基于匹配的满足-违反轨迹对）
  • 引入 语法图 STL 编码器（基于 TeLoGraF），并通过 STL 鲁棒语义预测进行预训练，使模型捕捉谓词、时间与逻辑结构
  • 实验证明模型可泛化到训练中未见过的 STL 公式（参数变化和结构变化），无需为每个规格单独训练策略
Card 04 方法描述

方法描述

  • 使用 TeLoGraF 的语法图骨干将 STL 公式编码为有向图，节点表示布尔、时序、比较运算符，并包含时间边界、信号标识、阈值等特征
  • STL 编码器预训练：通过 Huber 损失预测轨迹-公式对的鲁棒语义值，预训练后丢弃轨迹编码器与回归头，将公式表示投影为规范 token 序列注入 VLA 前缀
  • Stage 1：STL 条件监督微调，在满足 STL 的演示数据上优化条件流匹配目标，使策略模仿满足行为
  • Stage 2：轨迹级偏好优化，采用 Identity Preference Optimization（IPO） 的流匹配代理目标，用条件流匹配损失之差替代参考相对 log 策略比率，并引入单边 preferred-rollout anchor 防止满足轨迹拟合退化
Card 05 数据集与资源

数据集与资源

  • 使用 随机化摄影逼真四旋翼导航仿真环境，包含 10 个随机仓库环境
  • 共 6 个自然语言导航任务（如图中所示，覆盖绕桌飞行等多种机动）
  • 基础模型采用 π₀.₅（流匹配 VLA 策略）

Card 06 评估与结果

评估与结果

  • 评估基准分为 Seen（训练中见过的公式）、Unseen Parameter（未见过参数）、Unseen Structure（未见过结构）三类
  • 主要指标：STL 满足率、鲁棒性均值 ρ、最小鲁棒性 ρ_min、NL 任务成功率
  • 与基线比较（Base、STL-SFT、Smooth Robust Semantics 1×/2×）：

- Logic-VLA 在 Seen 上 STL 满足率 82.0%，较 Base（41.3%）提升 40.7 pp，同时 NL 任务成功率 89.0%（Base 90.5%，仅降 1.5 pp）

- 在 Unseen Parameter 上 STL 满足率 74.8%，较 Base（50.0%）提升 24.8 pp，NL 任务成功率 92.2%（Base 93.9%）

- 在 Unseen Structure 上 STL 满足率 82.0%，较 Base（56.8%）提升 25.2 pp，NL 任务成功率 87.5%（Base 89.3%，仅降 1.8 pp）

  • Smooth Robust Semantics 基线虽然能提升 STL 满足率（如 Seen 上 76.2/78.8），但 NL 任务成功率大幅下降（68.5/45.0），暴露其对基础任务能力的破坏；Logic-VLA 在保持任务性能上显著更优
  • 消融研究表明 STL 编码器预训练 和 结构化 STL 编码（vs 提示词） 对最终性能均具有正面作用
