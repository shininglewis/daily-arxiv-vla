  • 作者：Jinze Tao、Yuxiao Han、Kangkang Dong、Yancong Wei、Xiaojun Zhu（通讯作者）、Bokui Chen、Houde Liu
Card 02 论文概述

论文概述

  • 论文研究"调用 VLA 的智能体（LLM 规划器）能给被调用的 VLA 带来什么"，提出任务级经验蒸馏方法 H2E，把前沿 LLM 导航智能体的成功会话蒸馏进它调用的 VLA 中。
  • 现有系统在每个测试回合都需要 LLM 规划器，带来高昂代价（中位数每回合 70k tokens、耗时是纯 VLA 的两倍以上）；已有蒸馏工作多是把规划器缩小，而保持 VLA 冻结。
  • 核心目标：训练后的 VLA 在测试时独立运行、不再需要 LLM，同时继承智能体的导航能力（尤其是到达目标后停住）。
Card 03 核心贡献

核心贡献

  • 首次将前沿 LLM 导航智能体蒸馏进它自己调用的 VLA，使 VLA 在测试时脱离 LLM 独立导航。
  • 提出 H2E：用任务级标签、进度掩码和单一停止规则把完整智能体会话转成 VLA 训练数据，并给出 L1 损失 + 停止规则为何能教会 VLA 停止的理论说明（Proposition 1）。
  • 在未见场景上显著优于基础 VLA 和测地线专家自适应（geodesic adaptation）基线。
  • 证明蒸馏后的 VLA 在无 LLM token、每回合耗时约为智能体四分之一的条件下，成功率反而超过完整智能体。
Card 04 方法描述

方法描述

  • 问题设定：REVERIE-CE 回合中机器人接收 4 路 RGB 视角，VLA（8B NavGPT）读取最近 16 帧观测与指令，预测 K=8 个航点；无独立停止头，连续两次全零输出即停止。
  • 智能体会话采集：在 57 个训练场景上运行 LLM 规划器（gpt-6-astra）驱动的智能体，保留到达目标的会话，共 2395 个会话、332,405 条带标签步。
  • ①任务级标签：不论运动由 VLA 还是规划器工具产生，每一步都按原始任务指令打标，目标为会话中接下来 K 个位姿。
  • ②进度掩码：若 \(d(p_{t+K}) \le d(p_t)+\delta\)（\(\delta=0.25\) m）或有位姿接近目标则保留损失，否则掩掉该步目标（仍保留在历史中）；约 23.3% 的步被掩码。
  • ③停止标签：距目标 1 m 内的所有访问状态标为零动作停止标签，形成多数投票。
  • 训练：掩码 L1 损失 混合三源数据（智能体会话 0.60 : DART 0.25 : R2R-CE 0.15）；LoRA（rank 16、\(\alpha\)=32）微调注意力与 MLP 层，动作头全量训练，视觉编码器冻结；部署时可把 \(BA\) 合并进 \(W_0\)，推理开销与基础 VLA 相同。
Card 05 数据集与资源

数据集与资源

  • 基准：REVERIE-CE（Habitat + MP3D 场景），val-unseen 全部 3189 个回合（10 个未见场景）；另有 100 个来自 26 个额外场景的开发回合用于与智能体对比。
  • 训练数据：2395 个智能体会话（57 个场景）+ DART 测地线专家数据 + R2R-CE 路径跟随数据；消融中仅用 504 个会话。
  • 模型规模：8B NavGPT VLA，LoRA rank 16、\(\alpha\)=32，历史帧 16、航点 8。
  • 训练资源：4 块 NVIDIA L40 GPU 数据并行，训练 9000 次更新、约 28 小时。
Card 06 评估与结果

评估与结果

  • 评估指标：成功率 SR、oracle 成功率 OSR、路径长度加权成功率 SPL、导航误差 NE；每回合上限 500 步 / 2400 秒。
  • 主要结果：在全部 3189 个 val-unseen 回合上，H2E 把 8B VLA 的 SR 从 35.0% 提升到 44.9%（+9.9，95% 区间 3.9–16.3），SPL 提升 11.9 点、NE 降低 1.6 m；而测地线自适应仅 34.9%（无增益）。
  • 同配方对比：仅用 504 个会话，H2E 已达 43.2% SR，测地线自适应仍为 34.9%。
  • LoRA 秩消融：rank 16 达 45.6%，rank 64 仅 33.2%（861 个回合），说明小适配器即可吸收会话经验。
  • 分场景/分距离：在 10 个未见场景中 9 个提升；按起终点测地距离三分位划分，H2E 相对测地线自适应的领先从短程 4.4 点增至长程 17.5 点。
  • 与完整智能体对比（100 回合）：智能体 SR 53、OSR 70、NE 5.50、每回合 423 s / 70k tokens；基础 VLA 单独运行 SR 38、OSR 59、NE 8.60，耗时与 token 均大幅更低。
