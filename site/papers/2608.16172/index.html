Card 03 核心贡献

核心贡献

  • 将子任务终止与执行长度选择形式化为统一候选集上的单一排序问题，消除独立检测器、阈值调参和在线奖励的需求，解决两者间的相互依赖
  • 提出 Anchor-Conditioned Context Encoding（锚定条件上下文编码）：通过缓存历史感知的子任务锚（编码起始状态记忆与目标语义），引导视觉 token 剪枝聚焦任务相关区域，并编码高层隐藏特征
  • 提出 Stop-Aware Action-Prefix Selection（停止感知动作前缀选择）：在块边界通过全自注意力一次评分所有候选，同时决定是否停止与执行多长，提升效率与准确性
  • 验证 SparkVLA 高层系统对不同低层执行器（OpenVLA-OFT、SmolVLA）具有通用性，并在仿真与真实世界平台均实现迁移
  • 仅需离线序数偏好（ordinal preferences）即可训练，无需在线强化学习
Card 04 方法描述

方法描述

  • 采用分层架构：高层保留 VLM 主干用于子任务生成与选择器部署，低层使用完整 VLA（含动作专家） 提出动作块；两者从预训练 VLA π₀.₅ 独立衍生
  • History-Aware Subtask Anchor：在子任务开始时从生成命令的倒数第二层提取原始锚，并通过自注意力与历史锚池融合，获得跨子任务上下文感知
  • Anchor-Guided Visual Pruning：使用可微分的 Grid-Sampler 算子，以锚作为条件预测归一化 2D 采样坐标，将每相机的视觉 token 从 N 剪枝到 K，降低序列长度
  • Unified Candidate Scoring：评分头为全自注意力 Transformer，Stop 与所有动作前缀候选互相 attending；动作前缀 token 由前缀末端动作加学习长度嵌入初始化
  • Stop-Aware Ranking Objective：结合成对排序损失与停止感知辅助损失（log-sum-exp 对比 Stop 分数与继续分数），并采用边界扰动增强标注鲁棒性；短确认窗口过滤瞬时波动
  • 选择器仅在块边界调用（而非每步），结合子任务命令缓存，推理速度达 4.14 Hz，保持独立 π₀.₅ 88% 的吞吐量
Card 05 数据集与资源

数据集与资源

  • RoboCerebra：长时程操作基准，1000 条标注轨迹，100 个任务变体（平均 9.1 个子任务，2972 步），6 种条件（Dynamic、Memory、Mix、Ideal 等），评估 60 个保留场景各 10 次 rollout（共 600 个 episode）
  • LIBERO（Spatial、Object、Goal、Long）：40 个任务，每任务 100 episode，子任务标注来自 LaRA-VLA
  • 真实世界：AirbotPlay 双臂平台（两个腕部 + 一个头部 RGB 相机），3 个任务（Shelf Arrangement 6 子任务、Drawer Restocking 6 子任务、Tea Preparation 12 子任务），每任务 50 条演示，50 次 rollout 评估
  • 基于预训练 π₀.₅ VLA 模型微调，使用 LoRA 适配器；未明确列出具体 GPU/TPU 数量和型号
Card 06 评估与结果

评估与结果

  • RoboCerebra 主结果：SparkVLA 平均 SR 47.12%；其中 Dynamic Obs. 43.87%（+34.78%）、Memory Exp. 60.30%（+47.69%），超越独立 π₀.₅（12.29%）、HPE（16.55%）、Mem-0（20.29%）等基线
  • 执行器通用性：SparkVLA + OpenVLA-OFT 达 24.15%，+ SmolVLA 达 25.32%，均显著超越独立执行器基线，证明高层系统可跨执行器迁移
  • LIBERO 结果：SparkVLA 平均 SR 98.5%，在 Long 套件上以 98.0% 超过 π₀.₅（92.4%）和 OpenVLA-OFT（94.5%），优势最明显
  • 消融研究：统一候选集将 Stop Acc. 从 80.37% 提升至 96.65%（+16.28%），SR 从 42.53% 提升至 47.12%；历史感知锚贡献 1.94% SR；选择器置于规划器主干较执行器主干提升 9.84%；块边界调度将 Stop Acc. 提升 3.55 pp
  • 真实世界结果：SparkVLA 平均 SR 69.3%，超越 π₀.₅（48.0%）+21.3%；Tea Preparation 任务提升最大（+30.0%），验证了学习策略在真实物理动态上的定性迁移
