Card 02 论文概述

论文概述

  • 论文聚焦自回归视觉-语言-动作（VLA）模型中的动作分词器（action tokenizer），指出其保真度通常仅用逐点重建指标（如 MSE）衡量，而无法刻画不同演示之间动作调整关系的保持程度。
  • 提出 物理秩一致性（Physical Rank Consistency, PRC）指标，通过比较重建前后动作块与其原始近邻之间的物理距离排序，衡量分词器对局部物理关系结构的保持能力。
  • 目标是设计一种在压缩动作空间时既保持逐点重建精度、又保持动作间相对物理关系的离散动作分词方案，用于标准自回归策略学习与执行。
Card 03 核心贡献

核心贡献

  • 提出 PRC（物理秩一致性）指标，在解码后的动作空间中测量局部物理距离排序的保持程度，可与不同词表大小、序列长度和解码器架构的分词器进行统一比较，补充了 MSE 等逐点指标的不足。
  • 提出 ActionPiece，通过联合监督表示学习与量化两个阶段来保持物理动作关系：物理秩保持（PRP）作用于编码器与量化特征距离，量化正则化（QR）作用于码字分配分布的 Jensen–Shannon 散度。
  • 在统一 Qwen3-VL-4B 策略训练设置下，ActionPiece 在 LIBERO 取得 94.8%、在未见过的 LIBERO-Plus 取得 68.8%，分别超出最强基线 1.1 和 4.5 个百分点。
  • 在 SimplerEnv 与 VLA-Arena（L0–L2）上进一步验证，分别达到 71.9% 和 51.5% 的聚合成功率。
  • 通过组件消融与受控对比，证明 PRP 与 QR 两个目标共同提升 PRC 与下游策略成功率，说明物理关系监督对动作分词具有实际价值。
Card 04 方法描述

方法描述

  • Tokenizer 主体：使用浅层 Transformer 编码器/解码器 + 残差向量量化（RVQ），将 8 步动作块压缩为 16 个离散 token，解码器单次前向重建完整动作块，保证每个码序列都映射到完整动作块（完全可解码）。
  • 物理动作距离 $d_{\mathrm{phys}}$：组合归一化平移、$SO(3)$ 上最短测地旋转距离（矩阵对数形式）与夹爪状态差异，对动作块按时间步取平均，作为近–远排序的物理依据。
  • 物理秩保持（PRP）：对批次内每个锚点动作，按物理距离选取第 5 百分位（近正样本）与第 95 百分位（远负样本）动作，用 softplus 排序损失 $L_{\mathrm{rank}}$ 约束「加权表示距离」（0.25×编码器距离 + 0.75×量化距离）保持近–远顺序，边距 $m_r=0.1$。
  • 量化正则化（QR）：以码字软分配分布之间的平均 Jensen–Shannon 散度 $d_{\mathrm{JS}}$ 替代表示距离，施加同样的 softplus 排序损失 $L_{\mathrm{quant}}$，边距 $m_q=0.1$，把物理顺序监督直接传递到码字概率层面。
  • 总目标：$L_{\mathrm{tok}} = L_{\mathrm{MSE}} + \lambda_{\mathrm{vq}} L_{\mathrm{commit}} + \lambda_r L_{\mathrm{rank}} + \lambda_q L_{\mathrm{quant}}$，其中 $\lambda_{\mathrm{vq}}=0.25$，$\lambda_r=\lambda_q=6.25\times10^{-4}$。
  • 策略集成：分词器训练完成后冻结，将其索引加入 VLM 词表，VLA 使用标准下一 token 预测目标训练；生成序列经冻结解码器还原为可执行动作块，无需修改策略架构或评测协议。
Card 05 数据集与资源

数据集与资源

  • LIBERO：分布内基准，模拟环境中人类遥操作演示，用于参考基线。
  • LIBERO-Plus：分布外评测，涵盖相机、机器人、语言、光照、背景、噪声、布局七类未见扰动，仅用 LIBERO 数据训练。
  • SimplerEnv：基于真实机器人 BridgeData V2 演示训练的 WidowX 策略，测试真机到仿真迁移。
  • VLA-Arena：键盘遥操作仿真演示，在 L0 训练、跨 L0–L2 评测，含安全、状态保持等高难度条件。
  • Token 预算：8 步动作块 → 16 个离散 token。
  • 训练超参：分词器用 AdamW，学习率 $1\times10^{-4}$，批大小 128，训练 100K 步；策略训练学习率 $1\times10^{-5}$，余弦退火，8 步预测与执行视界，全局批大小 128。
  • 计算资源：8 块 NVIDIA RTX PRO 6000 GPU，使用 DeepSpeed ZeRO-2，梯度裁剪范数 1.0，无梯度累积。
Card 06 评估与结果

评估与结果

  • 评估环境：受控对比中固定 VLM 骨干（Qwen3-VL-4B）、提示、演示数据、优化器、全局批大小、训练预算、动作与执行视界、随机种子和评测协议，仅替换动作分词器。
  • 评价指标：动作重建保真度（MSE）、PRC@k（$k=32$，基于 Spearman 相关）、以及机器人任务成功率；VLA-Arena 另报告累计代价（CC）。
  • 代理指标关联：在 55 组分词器–基准评测中，PRC 与成功率的 Spearman 相关性为 0.681，高于重建保真度的 0.544，表明物理结构指标更能预测策略表现。
  • LIBERO / LIBERO-Plus：ActionPiece 达 94.8%（LIBERO，最强基线 ActionCodec 93.7%）与 68.8%（LIBERO-Plus，最强基线 64.3%），在七类偏移中有六类领先，优势从 1.1 点扩大到 4.5 点。
  • SimplerEnv：宏平均成功率 71.9% 为最高，其中堆叠积木 58.3%、放勺子 83.3%、放茄子 91.7%。
  • VLA-Arena：L0–L2 聚合成功率 51.5%，在动态障碍物、状态保持等安全相关任务上表现突出，同时保持较低累计代价。
  • 消融实验：去除 PRP 或 QR 中任一目标都会同时降低 PRC 与策略成功率，二者联合使用时效果最佳，验证物理关系监督的双重作用。
