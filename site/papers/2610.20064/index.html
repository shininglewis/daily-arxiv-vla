FoveaVLA: Foveation Actions Replace the Wrist Camera in VLAs

2026-10-14 · 原文 · 翻译 · 2610.20064

提出 FoveaVLA，一种用学习到的 foveation actions 替代腕部相机的 Vision-Language-Action (VLA) 模型。 核心目标是让策略仅依赖外置相机，也能获得操作所需的近景细节，从而摆脱腕部相机在视野覆盖、硬件成本和演示数据不匹配方面的限制。 解决的关键问题是：外置相机可覆盖全场景，但整图缩放到低输入分辨率后，夹爪与物体附近的细粒度信息丢失；腕部相机虽有近景细节，却只能看到末端执行器周围。

Card 02 论文概述

论文概述

  • 提出 FoveaVLA，一种用学习到的 foveation actions 替代腕部相机的 Vision-Language-Action (VLA) 模型。
  • 核心目标是让策略仅依赖外置相机，也能获得操作所需的近景细节，从而摆脱腕部相机在视野覆盖、硬件成本和演示数据不匹配方面的限制。
  • 解决的关键问题是：外置相机可覆盖全场景，但整图缩放到低输入分辨率后，夹爪与物体附近的细粒度信息丢失；腕部相机虽有近景细节，却只能看到末端执行器周围。
Card 03 核心贡献

核心贡献

  • 提出 foveation action：在每个策略查询中，与动作块一起预测下一个观测时刻的交互区域边界框，并用该框从原始分辨率图像中裁剪 foveal crop 作为下一帧输入。
  • 利用 RoboInter 在 DROID 上的交互标注构造监督信号，无需额外人类 gaze 数据、额外相机硬件或相机主动控制。
  • 设计 FoveaVLA-Single 与 FoveaVLA-Dual 两种配置，分别使用一个和两个外置立体相机，输入 full/foveal RGB 与对齐 depth。
  • 在四类真实世界操作任务和 MolmoSpaces 零样本基准上验证，FoveaVLA 在不使用腕部相机的情况下超过腕部相机基线 π0.5。
  • 证明 foveation 预测可解码未来交互区域，精度接近 YOLO11s，且 box decoding 不增加额外等待延迟。
Card 04 方法描述

方法描述

  • 基于 π0.5 后训练，保留 PaliGemma 视觉语言骨干与 flow-matching 动作专家。
  • 观测包括机器人状态、语言指令、每个外置视角的 full view、foveal crop 以及二者对应的对齐深度图。
  • 使用 Fast-FoundationStereo 从立体图像对估计视差并转换为度量深度，深度经对数映射和着色后送入视觉编码器。
  • 复用 PaliGemma 的 location tokens，以自回归方式预测未来交互框，坐标为 4 个量化到 1,024 个 bin 的值；Single 输出 4 个 token，Dual 输出 8 个 token。
  • 训练目标为动作 flow matching loss 与 foveation 交叉熵 loss 的联合优化，权重 λ=0.1。
  • 闭环推理时，初始 foveal 输入为 full view；后续查询使用上一轮预测框裁剪当前 RGB 与深度，执行 H=16 个动作中的 w=8 个后重新规划。
Card 05 数据集与资源

数据集与资源

  • 使用 DROID 数据集，包含约 75K 条遥操作 Franka Panda 机械臂 episode，配备 Robotiq 2F-85 夹爪。
  • 使用 RoboInter 提供的交互标注构造 foveation 监督，模型仅使用外置视角，不使用腕部相机图像。
  • 训练资源为 8 张 NVIDIA H100 GPU，全局 batch size 为 256。
  • 在 MolmoSpaces 上进行零样本泛化评估，使用两个适配后的外置相机视角和模拟器深度。
Card 06 评估与结果

评估与结果

  • 真实世界评估包含四个任务套件：普通 Pick-and-Place、带干扰物的 Pick-and-Place with Distractors、Fold/Unfold 以及远距离物体的 Move。
  • 每个套件 12 个共享随机 trial，总计 48 个 trial；在 DROID 真实设置上以 15 Hz 目标频率运行。
  • FoveaVLA-Single 总体成功率 70.8%，FoveaVLA-Dual 为 77.1%，显著高于腕部相机 π0.5 的 52.1%。
  • 在干扰物场景中，Single 将成功率从 25.0% 提升至 58.3%；在远物体移动任务中，从 41.7% 提升至 75.0%。
  • Dual 在 Fold/Unfold 和 Move 上达到 75.0% 与 83.3%，表现最佳。
  • 消融表明：foveal crop 与深度信息互补；单视角下二者结合将成功率从 20.8% / 6.3% 提升至 70.8%。
  • 在 MolmoSpaces 零样本评估中，FoveaVLA-Dual 平均成功率 22.4%，高于 π0.5-DROID 的 17.8%，在 9 个任务中的 7 个取得更优结果。
  • Foveation box 预测达到 0.465 mIoU 和 0.483 Acc@.5，与 YOLO11s 的 0.492 / 0.488 相当，且等待延迟为 0 ms。
  • 推理延迟方面，FoveaVLA-Single 在 RTX 5080 上每次策略查询约 125 ms，缓存前缀 box decoding 约 50 ms；Dual 约为其两倍。
