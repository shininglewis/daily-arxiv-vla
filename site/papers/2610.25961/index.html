PaceVLA: Adaptive Temporal Action Quantization in Vision-Language-Action Models

2026-10-19 · 原文 · 翻译 · 2610.25961

论文聚焦 Vision-Language-Action（VLA）模型 的执行时间效率问题：策略从遥操作示教中继承细粒度、谨慎的动作模式，导致完成任务需要大量低速底层动作步。 指出时序动作量化（temporal action quantization）若全轨迹使用固定粒度，会引入速度–精度权衡：粗粒度在自由空间运动中足够，但在抓取、接触密集的精度关键阶段会丢失轨迹细节；同时粒度与预测时域强耦合。 提出 PaceVLA，把“时序粒度”和“预测时域”当作策略决策，由模型根据当前视觉–语言上下文在每个推理步自适应选择执行模式。

Card 03 核心贡献

核心贡献

  • 揭示 VLA 策略会从遥操作示教中继承细粒度执行模式，这是其时间效率低下的关键来源。
  • 提出 PaceVLA：一种轻量框架，用共享动作专家 + 模式专用动作解码器建模不同时序量化级别与动作时域的执行模式。
  • 设计可量化性引导的模式选择机制，包含量化判别器（quantization judge）、上下文条件路由器（router），以及基于大视觉语言模型（LVLM）标注的可量化性监督（quantizability supervision）。
  • 在 3 个多任务仿真基准与 3 种机器人本体上的 6 个真实任务中验证有效性，相比基线在保持成功率的同时实现最高 1.8× 加速，在 ALLEX 人形传送带任务上达到 1.75× 吞吐提升。
  • 给出与控制器增益配置相关的系统级实践（加速执行需要更高跟踪与夹爪增益）。
Card 04 方法描述

方法描述

  • 基础架构为预训练扩散式 VLA（GR00T N1.5、RLDX-1-IMG），动作专家采用 DiT 骨干 + flow matching 训练，预测长度为 H 的动作块。
  • 时序动作量化：定义 K 个模式，模式 k 将 $H_k$ 步示教聚合为 $T_k$ 条命令，量化比 $q_k = H_k/T_k$；绝对动作保留块内最后一条命令，delta 位姿动作对平移求和、旋转增量复合、夹爪取最后值。
  • 共享动作专家 + 模式专用解码器：动作编码器与 DiT 骨干跨模式共享，每个模式仅有轻量 MLP 解码器 $D_k$，输出 $T_k \times d_a$ 的速度预测；无需对数据集做全局时间重采样。
  • 模式分组与路由：模式分为细粒度组 $\mathcal{K}_{fine}=\{k:q_k=1\}$ 与量化组 $\mathcal{K}_{quant}=\{k:q_k>1\}$；量化判别器 $J_\psi$ 先决定组别，再由路由器输出 $\alpha_t$ 在组内选具体模式。
  • 监督信号：先在多种固定量化设置下观察任务表现，得到任务级线索，再由 LVLM 细化阶段级判据并逐帧标注 $y\in[0,1]$。
  • 训练目标：策略损失含各模式流匹配误差的加权和、向目标分布 $r_k \propto \exp(-\ell_k/\beta)$ 的 KL 项、以及防止路由坍缩的平衡损失 $\mathcal{L}_{bal}$；判别器用 stop-gradient 的均方误差回归 $y$，总损失 $\mathcal{L}=\mathcal{L}_{policy}+\lambda_{conf}\mathcal{L}_{conf}$。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboCasa-Kitchen（24 个任务，每任务 300 条示教，分 PnP 与 Others 报告）、LIBERO（Spatial / Object / Goal / Long 四个套件）、DexJoCo（6 个接触密集的单臂灵巧操作任务）。
  • 动作表示覆盖两类：RoboCasa-Kitchen 与 LIBERO 用 delta 动作，DexJoCo 用绝对动作。
  • 真实世界任务（6 个，3 种本体）：Franka Research 3 + 夹爪（Pick-and-Place、Air Fryer、Stack Cup）、OpenArm + 双臂 6-DoF 灵巧手（Table Sweeping、Pump-and-Scrub）、ALLEX 人形 + 15-DoF 灵巧手（Conveyor Package Handling）。
  • 模型配置：使用 4 个动作解码器（2 个细粒度 + 2 个量化，各含长/短源时域），基于 GR00T N1.5 与 RLDX-1-IMG 微调。

Card 06 评估与结果

评估与结果

  • 指标：成功率 SR（%）、throughput-with-regret（TPR）、有效加速比 ES（失败试验按完整回合预算计费，故“快但易失败”的方法 ES 可低于 1）；真实任务另报执行时间（s）与吞吐（packages/min）。
  • 仿真（GR00T N1.5 为基座）：RoboCasa-Kitchen PnP SR 55.0 / TPR 1.64 / ES 1.16，Others 72.9 / 3.30 / 1.14；LIBERO Short SR 97.1 / ES 1.27，Long SR 89.2 / ES 1.26；DexJoCo SR 77.3 / TPR 2.22 / ES 1.11。
  • 换用 RLDX-1-IMG 基座同样有效（如 LIBERO Short SR 97.7 / ES 1.31，Long SR 90.2 / ES 1.31），说明方法可跨 VLA 骨干泛化。
  • 基线 Fixed Quantization、DemoSpeedUp、SAIL 常以牺牲成功率换取高原始吞吐，导致多处 ES 低于 1（如 GR00T 上 SAIL 在 RoboCasa PnP 的 ES 仅 0.52）。
  • 真实世界：Franka 上执行时间降低 37–45%（Air Fryer 由 24.6 s 降至 14.6 s 且成功率不降）；OpenArm 双臂任务降低 33–39%；ALLEX 传送带吞吐由 3.6 → 6.3 packages/min，成功率由 86% → 94%。
  • 消融（RoboCasa-Kitchen 24 任务平均）：完整模型 SR 66.9 / TPR 2.75 / ES 1.14；去掉模式专用解码器降至 63.3 / 2.44 / 1.00；去掉量化判别器降至 65.1 / 2.01 / 1.01；去掉 KL 项降至 63.7 / 2.04 / 0.98；路由器输入用平均池化优于注意力池化与 last-token。
  • 定性分析：可量化性分数在接近与搬运阶段较高、在抓取与放置附近下降，说明标注能捕捉各阶段的精度需求变化。
