Card 02 论文概述

论文概述

  • 论文研究冻结视觉-语言-动作（VLA）策略在测试时被外部检索文本修改输入提示（prompt）的问题，将检索增强视为一种提示权限控制（prompt-authority control）问题。
  • 通过匹配审计发现 prompt-form collapse：无论附加文本是否有语义，只要改变指令形式，就会严重破坏策略执行（原始附加文本使成功率从 92.47% 降至 3.00%，有义/无意义附加均为 0/500）。
  • 提出 TOWN-VLA（Think Only When Needed） 接口，分离候选内容生成与“是否授权修改策略输入”的决策；拒绝时精确恢复原始 Base 提示，授权时仅允许规范紧凑指令。
Card 03 核心贡献

核心贡献

  • 首次系统化定义并研究冻结 VLA 的提示权限控制问题，识别出 prompt-form collapse 作为核心失败模式，并给出定量证据。
  • 提出 proposal ≠ authority 的操作化设计：TOWN-VLA 仅接受规范指导、拒绝时以哈希级精度恢复 Base 提示、并限制最多检查 2 个候选（Top-2 Fail-Closed Cascade）。
  • 在匹配评估中，TOWN-VLA 将 LIBERO-Plus 成功率从 69.46% 提升至 73.07%（+362 episodes，95% CI 1.89–5.45 点），在 6/7 扰动轴上提升，且所有 4 个任务套件均获益。
  • 在物理 PiPER 机械臂 + 冻结 π₀.₅ 上，成功率从 52.7% 提升至 78.7%（p = 3.16×10⁻⁶），验证了跨骨干网与实体的迁移性。
  • 通过预注册边界量化了选择性计算的收益：oracle 路由保留全部 2,826 个成功的同时将慢路径调用减半；而 oracle-free 门控仍是校准挑战，仅授权 2/36 个 held-out 单元。
Card 04 方法描述

方法描述

  • 方法整体包装一个冻结的 VLA 策略 π_θ，θ 全程固定，策略作为唯一动作生成器。
  • Compatibility-Reranked Capsule：从 48 条演示轨迹中通过 CLIP 文本特征检索 top-5 候选，再用固定文本级兼容性规则（对象/目标 token 集 Jaccard 重叠、上下文重叠、CLIP 距离、秩惩罚）重排候选顺序。
  • Top-2 Fail-Closed Cascade：硬检查器只允许与任务对象/目标无冲突的候选通过；至多检查 rank-1 和 rank-2，第一个通过者被渲染为规范指令 put
