Card 03 核心贡献

核心贡献

  • 识别并形式化 state-representation mismatch 是 VLA 开环规划的核心障碍，指出现有推理范式难以同时保持静态场景与动态状态。
  • 提出 SSVR：初始图像和指令只编码一次为 KV cache，使用 action-conditioned GRU 递归更新 latent state，并以 state token 条件化动作预测。
  • 提出 soft-target training：利用 safe action 与 optimal action 集合的加权均匀分布作为监督，平衡安全性与最优性。
  • 在三个规划任务上取得 93.2/96.1 平均 EM/PR，超过最强像素基线 VPRL 12.6/11.2 个百分点。
  • 支持高效缓存解码，Maze 上比 LVR/Monet/VPRL 分别加速 5.81×/38.24×/98.58×，同时较好保留通用 VQA 能力。
Card 04 方法描述

方法描述

  • 使用 Qwen2.5-VL 作为 MLLM backbone，冻结预训练权重，训练 LoRA 适配器和 latent-state 模块。
  • 初始图像 I₀ 与指令 x 编码一次，构建静态 prefix KV cache，避免重复编码静态视觉-文本上下文。
  • 视觉特征均值初始化 latent state z₀；每一步将 e_t = z_t 作为独立 token 追加到缓存上下文后解码，预测动作 a_t。
  • 预测动作 a_t 通过动作嵌入与 GRU 更新为 z_{t+1}，实现动作条件化的递归状态转移。
  • 训练时使用 soft target q_α 混合 safe 与 optimal 动作均匀分布，最小化策略预测与软目标之间的交叉熵；主干使用 α=0.7。

Card 06 评估与结果

评估与结果

  • 评估环境：三个开环规划任务，指标为 EM (Exact Match) 和 PR (Progress Rate)，对照最短最优动作序列。
  • 主要结果：FrozenLake 99.5/99.6，Maze 96.3/98.0，MiniBehavior 83.9/90.6，平均 93.2/96.1。
  • 相比 VPRL：平均 EM/PR 提升 12.6/11.2 个百分点；Maze 上 EM/PR 从 74.5/77.6 提升至 96.3/98.0。
  • 鲁棒性：prompt 复述后 EM 从 96.4 到 96.8；颜色反转 EM 降至 94.00，翻转后 legal rate 仍保持 100%。
  • 跨数据集：FrozenLake→Maze 迁移 EM 达 33.6，远超 Qwen-CoT 的 2.3 和 VPRL 的 6.8。
  • VQA 保留：VQAv2 准确率 68.0%，相比原生 Qwen 的 71.9% 仅下降 3.9 个点。
  • 效率：Maze case0 上 cached SSVR step latency 为 45.611 ms，rollout latency 为 182.442 ms，比 LVR/Monet/VPRL 加速 5.81×/38.24×/98.58×。
