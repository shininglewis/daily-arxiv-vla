Card 03 核心贡献

核心贡献

  • 提出 Trace-WAM，联合学习未来视频预测、未来 3D 运动预测和动作生成。
  • 设计 Tri-MoT 三分支 Transformer 架构，分别处理视频、运动和动作，并通过结构化注意力掩码控制信息流。
  • 使用未来 3D 点轨迹作为辅助监督，同时编码图像平面位移和深度变化，直接描述操作过程中的时空变化。
  • 推理时移除未来视频和运动预测分支，仅保留当前观测到动作的去噪路径，不增加部署时预测开销。
  • 在 RoboCasa-GR1、LIBERO、LIBERO-Plus 和真实机器人任务上验证了性能与泛化优势。
Card 04 方法描述

方法描述

  • 3D 运动表示：在当前主相机图像上放置 20×20 网格锚点（Q=400），预测每个锚点未来 32 步的位移，包括图像坐标 (u,v) 和深度 d。
  • 相对位移目标：每个未来位置相对当前帧位置计算位移，统一到参考相机坐标系，以补偿相机运动。
  • B 样条压缩：使用 K=10 个三次 B 样条控制点表示每条运动轨迹，降低预测目标维度并提升运动预测精度。
  • Tri-MoT 架构：视频专家处理当前和未来视频 latent；运动专家预测 B 样条系数；动作专家生成动作 chunk。
  • 结构化注意力：当前视频 token 只关注自身；未来视频、运动和动作 token 可关注当前视频及各自组内 token；当前视频和动作不依赖未来视频或运动分支。
  • 训练目标：使用 Flow Matching 联合优化视频、运动和动作损失，并加入动态/静态锚点平衡损失及静态运动惩罚。
  • 推理路径：仅对当前 RGB 做一次视觉前向，动作专家使用缓存的视觉 key/value、语言和本体感知进行动作去噪。
Card 05 数据集与资源

数据集与资源

  • RoboCasa-GR1：24 个桌面重排和铰接物体操作任务；全量设置 24,000 条轨迹，few-shot 使用 10% 子集。
  • LIBERO：四个任务套件 Spatial、Object、Goal、Long。
  • LIBERO-Plus：用于零样本迁移评估，包含相机、机器人初始状态、语言、光照、背景、噪声和布局七类扰动。

  • 训练资源：LIBERO 和 RoboCasa-GR1 few-shot 使用 16 张 NVIDIA H20 GPU，训练 26,000 步，全局 batch size 128；RoboCasa-GR1 全量使用 32 张 NVIDIA H20 GPU，训练 50,000 步，全局 batch size 1,024。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboCasa-GR1、LIBERO、LIBERO-Plus 仿真基准，以及 Piper 真实机器人平台。
  • 主要指标：任务成功率；运动预测额外使用图像平面平均位移误差 ADE 和深度平均绝对误差 MAE。
  • RoboCasa-GR1：Trace-WAM 在 few-shot 和全量设置下分别达到 63.6% 和 80.3%，优于 Fast-WAM 的 44.8%/74.6% 和 Joint-WAM 的 54.8%/78.3%。
  • RoboCasa-GR1 few-shot OOD：平均成功率为 58.6%，分别超过 DIAL、Fast-WAM、Joint-WAM 12.4、16.3、8.6 个百分点。
  • LIBERO：平均成功率达到 98.7%，略高于 Joint-WAM 的 98.5% 和 Fast-WAM 的 97.6%。
  • LIBERO-Plus 零样本迁移：平均成功率为 84.5%，分别超过 Fast-WAM 和 Joint-WAM 18.3 和 5.8 个百分点；在 Robot 和 Background 扰动下分别达到 87.4% 和 76.1%。
  • 真实机器人：三个任务平均成功率为 85.0%，显著高于 Fast-WAM 的 63.3%；其中 Place and Close Drawer 从 55.0% 提升到 95.0%。
  • 消融结果：保留深度使 LIBERO-Plus 成功率从 82.4% 提升到 84.5%；B 样条表示优于原始逐步位移；动态/静态运动监督平衡和静态运动惩罚均带来额外收益。
