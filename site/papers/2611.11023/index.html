Card 03 核心贡献

核心贡献

  • 提出面向 device–edge–cloud 连续体的边缘中心协同推理框架，将设备状态监控、模型压缩优化、分割点选择与分布式执行串联为统一架构，并支持应用相关的隐私约束。
  • 通过仿真 + 私有 5G 网络真实硬件实验研究时延最小化的 device–edge 分割，揭示最优分割点随无线条件与模型结构的变化规律，并将其归因于计算代价与中间特征尺寸的权衡。
  • 给出 ResNet-101、Qwen2.5-VL-7B、OpenVLA-7B 在不同无线条件下的时延最小化分割点，为分割策略提供实证依据。
  • 指出未来研究方向：串行/分支模型结构的分割、动态条件下端到端时延预测、将隐私约束纳入分割点选择。
  • 明确界定研究边界：聚焦推理部署与执行而非分布式训练，案例研究主要验证框架中的分割点选择组件。
Card 04 方法描述

方法描述

  • 设计原则一：边缘中心分割——分割决策放在边缘服务器而非设备端，因为边缘具备 RAN 内所有设备的全局视图（网络拥塞、自身后台负载），可做系统级最优决策，避免各设备贪心优化导致资源争用。
  • 设计原则二：隐私保护式分割——采用 三段式（U 型）分割：设备执行前几层 → 边缘执行计算密集的中间层 → 预测头/最后几层回到设备执行，使敏感输出与个性化参数不落到共享边缘设施；由于现代 DNN 末层仅占极小比例时延与能耗，隐私代价低。
  • 四种协同推理模式（对齐 ITU-T Y.4509）：D2D（设备间）、D2E（设备–边缘）、E2E（边缘–边缘，经 5G/6G 回传）、C2E2D（云–边–端分层）。
  • 五阶段流水线：① 设备负载监控（CPU/GPU、内存、电量、链路质量）→ ② MEC 模型优化（推理时延预测、模型下载与缓存、量化/剪枝/蒸馏压缩）→ ③ MEC 分割策略（输出模型版本与分割点）→ ④ 设备执行前缀模型（隐私模式仅跑 1~k 层）→ ⑤ MEC 执行剩余层（隐私模式回传中间特征图，非隐私模式直接回传最终预测），随后设备触发Action。
  • 云侧角色：模型仓库管理、大规模训练与微调、周期更新、网络切片/定价编排。
  • 案例研究采用候选分割点枚举方式，在给定信道条件下选择端到端时延最低的分割点，不包含在线切换开销。

Card 06 评估与结果

评估与结果

  • 评估环境：Test A 为 Python 解析式仿真（按算子数、有效算力、固定开销估算计算时延，按特征尺寸与 SNR–吞吐映射估算通信时延）；Test B 为私有 5G 真实测试床（机器人 rover + Xavier + 5G 模组 ↔ Thor 边缘服务器）。
  • 主要指标：端到端推理时延（设备计算 + 中间特征传输 + 边缘计算），辅以 Thor 侧每帧能耗（tegrastats 100 ms 采样估算）与目标识别是否成功。
  • 信道条件：仿真取 SNR = 30/25/15/8/5 dB，分别标记为 Excellent/Good/Fair/Poor/Bad；真实实验用 C1–C3 三档（按 k=S1 处实测通信时延升序排列）。
  • ResNet-101：最优分割点由 Excellent/Good 的 k=4 → Fair 的 k=8 → Poor/Bad 的 k=31，端到端时延从 71.33 ms 增至 555.17 ms；信道变差时把更多计算留在端侧可因特征变小而获益。
  • Qwen2.5-VL-7B：Excellent/Good/Fair 选 k=S1，Poor/Bad 转为 k=SM；原因是 pre-merger 视觉块不改变特征张量维度，加深分割只增算力不减排，而把 patch merger 放到端侧才能真正压缩传输载荷。
  • OpenVLA-7B：整个 SNR 范围内始终 k=S1 最优，因其视觉分支加深执行不减少传输元素数，融合与投影阶段也不保证更小载荷，"SNR 越低就越往深分"的通用规则不成立。
  • 真实 5G 实验（Qwen2.5-VL-7B）：C1 下 k=S1 最优（2426.73 ms）；C2、C3 下 k=SM 更优，相对 k=S1 分别降低 6.61% 和 18.86%；C3 下切到 k=SM 使通信时延由 2362.33 ms 降至 1594.57 ms，Thor 侧能耗由 46.45 J 降至 39.55 J（降 14.85%）。
  • 重要观察：时延最优分割点未必是能耗最优分割点（C1 下 k=S4 边缘能耗最低但 k=S1 时延最低）；所有配置均成功完成目标识别，说明在该演示场景下分割不损害任务功能。
  • 局限性（作者自述）：依赖稳定通信与准确时延预测，高动态网络下频繁重分割与模型同步会带来额外开销；三段式分割虽保护预测头，但传输的中间特征仍可能被特征反演/表示重构攻击泄露信息，严格保密场景需额外隐私机制。
