Card 02 论文概述

论文概述

  • 论文针对「开放世界机器人自主性」这一目标，提出 RobotAgentBench（RAB），一个面向真实家庭开放环境的机器人智能体评测基准。
  • 指出现有基准多评估孤立的操作能力（预定义任务、显式目标），无法刻画任务发现、情境推理、执行、失败恢复与适应所构成的闭环自主性。
  • 目标是通过「任务级 + 场景级」的多层级评测，系统比较独立 VLA/WAM 模型与不同机器人智能体架构的能力差异，并量化「操作能力」与「自主性」之间的鸿沟。
Card 03 核心贡献

核心贡献

  • 构建 RobotAgentBench 基准：通过智能体辅助、人机协同的 real-to-sim 流水线，重建真实家庭场景并扩展为 50 种户型布局，含可交互物体与物理落地的任务。
  • 提出可组合任务体系：90 个原子任务 → 18 个短时程任务 + 8 个长时程任务，并覆盖刚体、可变形物（桌布）与颗粒物（咖啡豆）等多样操作技能。
  • 设计五维任务级能力评测：任务发现（Task Discovery）、情境推理（Context Reasoning）、操作（Manipulation）、失败恢复（Failure Recovery）、鲁棒性（Robustness），并提供针对性的指标。
  • 引入 4 个开放式家庭场景（准备晚餐、招待客人、出门准备、整理房间），进行端到端自主性评测，并额外提出 任务覆盖率、任务进度、恢复率、停滞率 等行为指标。
  • 提出统一的 规划–执行–验证（P/E/V） 智能体框架，形式化对比 5 种代表性架构（C/L/H/– 组合），并引入 harness 级 递归自我改进（RSI）。
Card 04 方法描述

方法描述

  • 环境构建：从真实房间出发，在 Isaac Sim 中经「真实参数采集 → 相似资产检索 → 新资产重建」迭代流程重建场景，由编码智能体检索并调整 3D 资产几何、尺度与外观，人类评审持续校验视觉与物理一致性。
  • 环境增强：修改户型（T 形、L 形）、重排功能区、改变家具位置与朝向，生成 50 种布局，并变化颜色、纹理、材质与室内风格。
  • 示范采集：采用 AgiBot G1 作为本体，真实遥操作采集 → 仿真回放对齐物理参数 → 编码智能体在全状态可访问下合成并执行动作程序，批量扩展轨迹。
  • 智能体架构：planner 负责理解上下文与任务分解；executor 可用学习策略（VLA/WAM）或代码控制；verifier 监控执行、识别失败并纠正。比较 –/L/C、C/L/–、C/C/C、C/H/C、C/C/C + RSI 五种配置。
  • 创新点：将代码控制与学习策略统一为可调用工具（C/H/C），以及通过工具复用与经验积累实现 harness 级 RSI。
Card 05 数据集与资源

数据集与资源

  • 数据集：RobotAgentBench（RAB），共 101.8 小时训练数据；每个原子任务与短时程任务采集 50 条训练轨迹，每个长时程任务与开放场景提供 10 条完整示范。
  • 仿真平台：Isaac Sim；机器人本体：AgiBot G1，动作空间为 22 维（头部、躯干、双臂与夹爪、移动底盘）。
  • 观测：头戴相机 + 两个腕部相机的 RGB、本体感知状态、任务指令/上下文提示、逐步揭示的导航地图。
  • 被测模型：VLA 含 π₀.₅、Xiaomi Robotics-1、InternVLA-A1.5、MolmoAct2、LingBot-VLA2、HY-VLA、Galaxea G0.5、X-VLA；WAM 含 τ₀、OpenWAM-Alpha、LingBot-VA。
  • 编码智能体：Codex（GPT-6 Astra）、Claude Code（Opus 5.5）、Antigravity CLI（Gemini 4 Argon）。
  • 训练所用 GPU/TPU 规模在给定原文中未明确说明。
Card 06 评估与结果

评估与结果

  • 评测协议：每个任务/场景评测 30 个随机实例，覆盖 50 种布局及全部随机化维度；每回合编码智能体最多 200 次模型响应，每次工具调用最多 600 个控制步（约 30 秒仿真时间）。
  • 主要指标：任务级用目标物体覆盖率（发现）、目标选择准确率（推理）、任务进度分（操作/恢复/鲁棒性）；场景级用开放场景最终进度分 + 覆盖率/进度/恢复率/停滞率。
  • 独立策略最佳为 InternVLA-A1.5（任务级平均 18.0，开放场景 1.0），其余模型平均多在 3–12 区间，任务发现普遍接近 0（0.3–1.7）。
  • 智能体架构显著优于独立策略：C/H/C（Codex + InternVLA-A1.5） 任务级平均 48.5、开放场景 15.4，为最佳；C/C/C + RSI 平均 42.3、开放场景 10.8。
  • 同为全代码架构下：Antigravity CLI 平均 39.7 / 开放场景 9.8，Claude Code 平均 33.3 / 9.2，Codex 平均 31.0 / 8.4。
  • 关键结论：独立策略在任务发现与情境推理上接近随机；代码智能体 harness 显著提升表现；planner 能力与 executor 指令跟随能力共同决定上限；RSI 通过工具精炼与经验积累持续提升；真机评测出现性能下降但相对排名基本一致。
