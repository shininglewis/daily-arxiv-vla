ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning

2026-10-27 · 原文 · 翻译 · 2610.37666

论文提出 ThinkWorld，一个将动作推理建立在“世界动力学变化”之上的 VLA（视觉-语言-动作）学习框架，并通过“世界想象”强化学习来增强这种推理。 针对的核心问题是：VLA 模型的策略学习高度依赖带动作标注的机器人轨迹，数据覆盖有限；而人类视频行为多样性丰富，却缺少可直接执行的机器人动作标注，现有潜动作方法（latent action）又容易捕捉外观或相机运动这些并非行为的因素。 目标是构建一个跨具身（human/robot）共享的动作推理接口，使无动作标注的视频也能为动作推理提供监督，从而实现人类到机器人的技能迁移与泛化。

Card 02 论文概述

论文概述

  • 论文提出 ThinkWorld，一个将动作推理建立在“世界动力学变化”之上的 VLA（视觉-语言-动作）学习框架，并通过“世界想象”强化学习来增强这种推理。
  • 针对的核心问题是：VLA 模型的策略学习高度依赖带动作标注的机器人轨迹，数据覆盖有限；而人类视频行为多样性丰富，却缺少可直接执行的机器人动作标注，现有潜动作方法（latent action）又容易捕捉外观或相机运动这些并非行为的因素。
  • 目标是构建一个跨具身（human/robot）共享的动作推理接口，使无动作标注的视频也能为动作推理提供监督，从而实现人类到机器人的技能迁移与泛化。
Card 03 核心贡献

核心贡献

  • 提出 ThinkWorld 框架，将动作思考表述为 Chain-of-Dynamics (CoD)——一串离散运动 token，作为人类与机器人共用的 VLM 原生动作推理接口，并配合内部世界想象。
  • 提出后果驱动的强化学习（consequence-grounded RL）：依据生成的 CoD 所诱导的“想象未来”与“真实观测未来”的一致性给予奖励，使无动作标注视频也能改进动作推理。
  • 证明 ThinkWorld 能从无动作标注的人类视频规模扩展中获益，并实现人类到机器人的技能组合：机器人仅需对原子技能有监督，即可执行由人类视频演示的完整组合任务。
  • 在仿真基准与真实机器人上验证了对未见任务、物体与环境的强泛化能力。
Card 04 方法描述

方法描述

  • 动作锚定的推理空间：将机器人动作与标注的人手轨迹统一映射到归一化的末端执行器增量表示，用 FAST 风格的 motion tokenizer 离散化为 CoD（词表 2,048），实现跨具身共享的运动词汇。
  • CoD 条件化未来想象：在 CoD 之后附加 64 个可学习 future query，经 VLM 上下文化后用两层 MLP + 六层 cross-attention 解码器预测 1 秒后的未来表示；预测目标是冻结 DINOv3 ViT-H/16+ 特征（14×14 patch，1,280 维），而非重建 RGB 像素。
  • 联合监督：L_SFT = L_CoD + λ_future · L_future，其中 CoD 用交叉熵，未来预测用特征距离。
  • 世界想象 RL：用 GRPO 优化，奖励为“运动增强的特征相似度”（对当前到未来变化更大的 patch 加权），并加入监督重放防止遗忘；RL 阶段仅更新 VLM，动作专家冻结。
  • 部署效率：推理时不需要生成 CoD 或做未来预测，控制由动作专家基于 VLM 表示输出（flow matching，10 步 Euler 积分）。

Card 06 评估与结果

评估与结果

  • 仿真：LIBERO（Spatial/Object/Goal/Long）与 LIBERO-PRO（Object/Position/Semantic/Task/Environment 五种分布偏移），仅在标准 LIBERO 训练集后训练，直接评测 LIBERO-PRO。
  • 真实机器人：双臂 YAM 系统（顶部全局相机 + 双腕部相机，仅用 RGB），三个任务（挂杯子、颜色匹配、物体分拣）分别在 ID / OOD 条件下评估，每设置 5 次试验。
  • 主要结果：

- LIBERO 平均成功率 97.3%，LIBERO-PRO 平均 55.6%，均为对比方法中最佳（参数量仅 2.9B）。

- 任务偏移 31.9%、环境偏移 60.9%，分别超过 VLA-JEPA 11.1 和 19.9 个百分点。

- 真实机器人 OOD 场景下（新颜色、新物体、新环境、新轨迹）成功率最高，而 Diffusion Policy、MolmoAct2、LaWAM 明显下降。

- 人类视频演示 open → put-left → close 可驱动机器人在单次 rollout 中完成从未在机器人数据中出现过的完整技能序列。

  • 消融（LIBERO-PRO 平均）：基线 40.1 → +历史帧 40.7 → +未来预测 50.4 → +CoD 54.4 → +RL 55.6。
  • 人类数据扩展性：机器人数据固定时，人类视频占比从 0 → 10%/25%/50% 使成功率从 45.4% 单调升至 47.8%，且比同训练规模的纯机器人对照组高约 1.2 个百分点。
  • 机理分析：CoD 特征的 t-SNE 主要按运动方向而非具身来源聚类；注意力集中在手/机械臂与被操作物体；CoD 使 top-25% 动态 patch 的未来预测余弦相似度从 0.54–0.55 提升至 0.62。
