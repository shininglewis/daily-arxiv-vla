Card 02 论文概述

论文概述

  • 论文提出 NebulaVLA，一种双频（Dual-Frequency）视觉-语言-动作（VLA）模型，用于解决真实世界机器人操作中效率-性能权衡、跨形态泛化和执行平滑性三大瓶颈问题。
  • 针对现有单块同步架构中语义推理与运动控制在时间分辨率上的冲突，以及异步推理导致的轨迹抖动问题，NebulaVLA 设计了快慢双系统解耦架构，将高层语义规划与低层动作控制分离。
  • 论文同时提出 GESTURE-7 统一动作表示和 Guide Action 引导动作机制，旨在提升跨机器人平台的语义泛化能力和轨迹连续性。
Card 03 核心贡献

核心贡献

  • 异构双频架构：将 ~10 Hz 的语义规划 VLM（System 2）与 ~20 Hz 的反应式动作生成 DiT（System 1）解耦，优化计算-延迟权衡，并原生支持分布式部署。
  • GESTURE-7 统一动作表示：提出 7D 连续末端执行器向量，通过自然语言关键词映射统一异构机器人平台的动作语义，支持强化学习训练。
  • Guide Action 引导动作机制：受图像外推（Image Outpainting）启发，在扩散去噪过程中引入掩码约束，基于已执行轨迹锚点条件化生成下一动作块，消除块间抖动。
  • 三阶段训练流程：Stage 1 SFT + Stage 2 GRPO 强化学习优化 System 2 语义规划，Stage 3 加权流匹配损失监督 System 1，确保训练-推理频率严格对齐。
Card 04 方法描述

方法描述

  • 采用 Qwen3-VL 作为 System 2 的视觉-语言骨干网络，通过可学习 token 提取隐藏层特征作为抽象动作指导。
  • System 1 受 InternVLA-M1 启发，引入 Q-Former 压缩 System 2 指导与高频视觉输入，并通过带有 DINOv2 对比微调的视觉-本体感知对齐模块。
  • Guide Action 将动作块拼接嵌入生成流程：去噪过程中掩码区域（锚点区域）保持不变，仅对新生成区域计算损失（公式 2、3），训练时锚点数从 0 到 3 随机采样以适配推理延迟变化。
  • System 2 强化学习采用 GRPO 算法，并使用加权 GESTURE-7 距离（位置距离 + 角度距离 + 手势一致性惩罚）等任务奖励函数。
Card 05 数据集与资源

数据集与资源

  • 模拟实验使用 LIBERO-Plus 基准，包含 7 个扰动维度（21 个子维度）、10,030 个任务，按 L1-L5 五个难度等级划分。
  • 真实世界实验在 AgiBot A2 双臂机器人平台上进行，任务包括 Pick-and-Place 和 Packaging Line Material Feeding。
  • 训练使用单节点 8×NVIDIA H800 GPUs，batch size 为 96；部署测试使用 NVIDIA RTX 4070 GPU。
Card 06 评估与结果

评估与结果

  • LIBERO-Plus 模拟评估：NebulaVLA 达到 85.5% 平均成功率，超越 InternVLA-M1（81.3%）、OpenVLA-OFT（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。
  • 真实世界评估：在 Pick-and-Place 任务中成功率达 92.08%，在 Feeding 任务中达 92.5%；相较于同构频率变体（115 ms）和 InternVLA-M1（81 ms），异构架构平均推理延迟降至 42 ms。
  • Guide Action 消融：在 10 次真实实验中，关节平均 jerk 降低 25.6%，其中 Joint 12 和 Joint 13 分别降低 41.2% 和 45.1%。
  • 训练策略消融：三阶段完整训练相比省略 SFT/RL 的设定总成功率提升 1.7%（83.8% → 85.5%），SFT 显著改善 Layout 维度（+6.2%），RL 进一步增强语义耦合的 Language 和 Layout 维度性能。
  • 局限性：频率分配为经验性的静态设定，Guide Action 依赖固定锚点可能引入响应延迟，且硬件同步、多传感器时间戳对齐仍面临工程挑战。
