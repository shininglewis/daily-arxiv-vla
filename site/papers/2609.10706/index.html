HuRo: Robotizing Human Videos for Scalable VLA Pretraining

2026-09-09 · 原文 · 翻译 · 2609.10706

研究核心问题：机器人化的（robotized）人类视频能否作为视觉-语言-动作（VLA）策略预训练的有效且可扩展的监督来源。 现有人类视频利用方法要么局限于任务匹配（task-matched）场景，要么将观测对齐与动作对齐分开处理，缺乏大规模联合观测-动作机器人化的通用预训练数据。 论文构建了机器人化流水线并发布 HuRo 数据集，通过大规模真实机器人实验验证机器人化人类视频预训练的缩放规律与泛化收益。

Card 03 核心贡献

核心贡献

  • 设计了一套联合观测–动作机器人化流水线：从异构自我中心人类视频中推断缺失标注，完成视觉机器人化与动作重定向，输出统一的机器人观测–动作格式。
  • 构建 HuRo 数据集：约 630K 机器人化回合、142M 处理帧、约 1,317 小时（30 fps），来自五个来源，规模比此前机器人化视频预训练方法大一个数量级以上。
  • 首次系统验证机器人化人类视频预训练的缩放效应：随预训练规模提升，下游真实机器人任务 ID 与 OOD 性能持续提升（平均完成度 51.5% → 80.3%）。
  • 通过消融证明视觉机器人化（机器人叠加）显著提升 OOD 鲁棒性，且端到端 VLA 预训练（含重定向动作） 大幅优于仅迁移视觉通路。
  • 与 I2V + IDM 视频生成式预训练基线在匹配帧预算下对比，HuRo 在同等预算下性能更优且缩放趋势更好。
Card 04 方法描述

方法描述

  • 三阶段机器人化流水线：人类视频标注 → 动作转换（Action Conversion）→ 视觉转换（Visual Conversion）。
  • 人类视频标注：用 droidcalib / AnyCalib 估计相机内参并去畸变；用 100DoH + BOT-SORT 检测与跟踪手部；用 HAWOR 估计基于 MANO 的手部姿态；用掩码 DROID-SLAM + MoGe-2 估计带绝对尺度的相机轨迹，GeoCalib 对齐重力方向；分块后用 Qwen3.5 VLM 生成语言指令并校验。
  • 动作转换：将手部指尖与结构线索变换到世界系，用 PyRoKi 两阶段求解——先联合优化机器人基座对齐变换（3D 平移 + 偏航）与关节配置，再固定对齐优化完整关节轨迹；动作标注由重定向状态导出（a_t = s_{t+1}）。
  • 视觉转换：用 SAM2 + Detectron2 分割人手臂，ProPainter 修复去除人体，再用 Isaac Sim 按相机内参与重定向关节配置渲染机器人并叠加，得到机器人化观测。
  • VLA 策略：基于 GR00T-N1.6-3B 架构，采用末端执行器（EEF）动作接口，预测 H=40 步动作块，输出含左右腕部位姿（3D 平移 + 连续 6D 旋转，相对当前腕部）与手指关节目标；以 flow-matching 目标优化，视觉编码器联合微调。
Card 05 数据集与资源

数据集与资源

  • HuRo 数据集：约 630K 机器人化回合、142M 帧、约 1,317 小时（30 fps）。
  • 五个来源（按帧占比）：EgoDex（56%）、EgoVerse（27%）、Ego4D（10%）、Ego10K（6%）、EPIC-Kitchens（2%）。
  • 主数据集实例化为 ALLEX 双臂灵巧机器人（两条 7-DoF 手臂、两只 15-DoF 手、2-DoF 颈部、2-DoF 腰部）；附录中另测试 OpenArm 等其他本体。
  • 策略骨干 GR00T-N1.6-3B（VLM 骨干从官方 checkpoint 初始化，动作头从零训练）。
  • 训练配置：预训练 80k 步、全局 batch 2048、AdamW、学习率 1×10⁻⁴、权重衰减 1×10⁻⁵，常数调度加线性 warmup；下游微调 30k 步、batch 128、初始学习率 1×10⁻⁴，余弦衰减。
  • 计算资源由 RLWRLD 提供（含 ALLEX 平台与算力），论文未明确说明具体 GPU/TPU 型号与数量。
Card 06 评估与结果

评估与结果

  • 评估平台与任务：在 ALLEX 真实机器人上评测四个操作任务——Apple Pick-and-Place（43 条演示）、Cup Stacking（40 条）、Cup-Noodle Handover（16 条）、Microwave Loading（20 条），并包含 Diverse Pick-and-Place 任务。
  • 评估协议：ID（分布内留出）与 OOD（空间位移 + 视觉变化，如棋盘格桌布）条件；Apple 任务用二值成功率，其余用分阶段部分完成度评分。
  • 缩放结果：平均完成度从 51.5%（无 HuRo 预训练）提升至 80.3%（完整 HuRo）；ID 完成度 68.1% → 88.4%，OOD 完成度 34.9% → 72.2%；全规模 HuRo 在 ID/OOD 上均超过 π₀.₅ 与 GR00T N1.6 参考模型。
  • 视觉机器人化消融：无叠加变体 ID 相近（89.4% vs 88.4%），但 OOD 明显更低（55.7% vs 72.2%），甚至低于仅用 10% 数据预训练的模型（59.5%）。
  • 端到端预训练消融：PT (Visual + Action) 在 Diverse Pick-and-Place 上达 61.1%（ID）与 50.0%（OOD），显著优于 No PT 与 PT (Visual Only)，定性上抓取行为更符合演示。
  • 与视频生成基线对比：在 0.7M / 3.5M / 7.0M 帧匹配预算下，HuRo 每档均优于 I2V + IDM；HuRo 仅用 0.7M 帧即超过 I2V + IDM 的 7.0M 帧结果。
  • 局限性：机器人叠加未显式建模遮挡；无接触力/触觉监督；运动学重定向不建模自碰撞（五源审计中仅 55.2% 轨迹无检测到非抓取自接触），故轨迹用作预训练监督而非可直接执行的机器人演示。
