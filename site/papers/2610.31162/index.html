Card 03 核心贡献

核心贡献

  • 提出 HiSTEVE 层级式 VLA 智能体与 能力感知智能体框架（capability-aware agent harness），使智能体在长程执行中维持目标并自适应调整计划。
  • 设计 能力受限规划、证据驱动的交接与恢复协议 以及 结构化记忆（工作记忆、情景记忆、程序记忆、世界记忆），形成可验证的规划-执行闭环。
  • 提出 RS-Norm（Regime-Specific RMSNorm） 与 Dual-Mouse 分离式鼠标位移 token 表示，缓解 GUI 与非 GUI 异构交互之间的负迁移。
  • 提出 策略耦合的任务完成状态检测器，以 VLA 策略上下文为条件输出候选完成信号，其精度优于通用 VLM 的提示式判断。
  • 采用 世界知识注入 → 模仿学习 → 环境反馈强化学习 三阶段训练，并实现 SOTA 原子任务性能与“从零打造铁镐”等长程任务。
Card 04 方法描述

方法描述

  • 高层编排（Harness）：由 GPT-4o 担任 VLM 规划器，在能力受限的原子子任务模式集合中选择并实例化子任务，输出语义目标而非脚本动作。
  • 能力受限规划：每个子任务模式规定适用条件、参数、可视觉观测的进度/完成条件、可识别失败条件与执行预算，保证计划落在 VLA 能力范围内。
  • 证据驱动交接与恢复：检测器给出完成概率，超过阈值或预算耗尽时交还控制权；harness 依据观测验证并记录 success / failure / interrupted，决定前进、局部恢复或重规划。
  • 结构化记忆：工作记忆承载当前规划状态，情景记忆记录每次调用的前后状态与结果，程序记忆沉淀子任务依赖，世界记忆存储地标与空间关系。
  • VLA 策略：以 Qwen2.5-VL-7B 初始化，20 Hz 自回归输出离散化键鼠动作 token；动作空间沿用 VPT 风格分组，鼠标位移经 μ-law 变换后量化。
  • RS-Norm：每层注意力前与 MLP 前的 RMSNorm 各维护非 GUI / GUI 两组可学习尺度向量，仅增加 2Ld 参数。
  • Dual-Mouse：为非 GUI 与 GUI 分配不相交的鼠标位移 token 子集，并加入交互类型 token，两者解码回同一物理动作码表。
  • 三阶段训练：世界知识注入建立概念与视觉 grounding；模仿学习学习指令到键鼠动作的映射；RL 阶段用同起点分支组相对优势（GRPO 裁剪更新）+ 匹配状态片段的 DPO 式成对损失，并加入世界动作回放与对参考策略的 KL 正则。
  • 完成检测器：以 Qwen2.5-VL-3B 为骨干，共享 VLA 图像编码器，采样 800/600/400/200 ms 历史帧，将 VLA 前缀末层隐状态作为策略上下文，每隔 4 层通过交叉注意力注入，并用 Wanda 式通道评分将 FFN 中间宽度剪枝至约 1/3。

Card 06 评估与结果

评估与结果

  • 评测设置：原子任务采用严格 pass@1（MineStudio）与族级 episode 成功率（OpenHA），长程任务采用 final-goal success（LongBench），隐藏诊断节点仅用于进度分析；对照 VPT、STEVE-1、ROCKET-1、JARVIS-VLA、LatentHA、MotionHA、GroundingHA、TextVLA、Text/CoA 等基线。
  • MineStudio Bench：Mine 93.3%、Kill 86.7%、Craft 66.7%、Smelt 93.3%，平均 85.0%，较最强基线平均提升 20.0 个百分点；Craft 提升最大（+26.7）但仍是最弱类别。
  • OpenHA：平均 37.4%（Embodied 46.0%、GUI 27.2%、Combat 39.0%），较 Text/CoA 的 36.8% 略高，增益主要集中在 Embodied。
  • LongBench：R&C 42.9%、E&M 28.6%、Rec. 14.3%、Open 14.3%，相对基线分别提升 28.6 / 21.5 / 11.4 / 12.9 个百分点，多阶段资源生产与探索信息复用任务增益最大。
  • 完成检测：准确率与 F1 均达 0.863，精确率 0.861、召回率 0.865、FPR 0.140、FNR 0.135，显著优于 GPT-4o（F1 0.690）、GPT-5.5（F1 0.776）与 Qwen3.5（9B/35B）等提示式基线。
  • 消融：仅模仿学习 MineStudio 平均 50.4 → 加世界知识注入 65.1 → 加环境反馈 RL 80.7；共享表示 41.1 → 加 RS-Norm 57.3 → 加 Dual-Mouse 61.9，验证各组件互补有效。
  • 关键结论：固定 VLA 时，完整 harness 相比固定步数交接可使长程目标成功率提升一倍以上，说明围绕持久任务状态组织局部执行是长程性能的关键。
