Card 03 核心贡献

核心贡献

  • 因果动作 tokenization（条件退火）：将动作 tokenization 形式化为顺序生成过程，每个 token 条件于所有前序 token，并在特定噪声水平编码残差重建信号，形成粗到细、因果有序的 token 空间。
  • Token 条件 flow-matching 解码器：基于 MMDiT 构建解码器，从紧凑离散 token 重建连续动作块，兼具连续生成动作头的控制保真度与纯自回归 VLA 的训练兼容性。
  • 强实证性能：在多个仿真与真实机器人基准上，在重建保真度-压缩权衡、推理效率和 VLA 任务成功率方面一致超越 FAST、OAT 等基线。
Card 04 方法描述

方法描述

  • Dual-Stream Action Encoder：使用 2D CNN（带权重归一化）编码动作块，保留时空局部相关性；并行初始化可学习 query 嵌入，通过 MMDiT 启发的共注意力 Transformer 双向交互，输出紧凑 latent query。
  • Bottleneck Vector Quantizer：采用 ViT-VQGAN 的 factorized codes 设计，先将 latent 投影到低维空间（瓶颈），再量化到可学习码本，最后投影回原空间，提升码本利用率。
  • Flow-Matching Decoder with Conditional Annealing：在 rectified flow 插值路径上，逐步掩码前 κ(t)=⌊tK⌋ 个 token 嵌入，仅保留活跃子集作为条件；训练目标为 flow-matching 速度预测损失，迫使不同 token 在不同生成阶段发挥作用。
  • 损失函数：结合 flow-matching 损失 L_FM、基于 DCT 的频率域平滑损失 L_smooth 和 VQ 承诺损失 L_VQ，并使用 EMA 更新码本、周期性重初始化低使用率条目。
  • VLA-CATok：将 CATok 集成到自回归 VLA，VLA 骨干自回归预测动作 token，冻结的 MMDiT 解码器单步恢复连续动作；离散 token 作为唯一接口，实现 知识隔离，避免动作梯度污染 VLM 预训练知识。
Card 05 数据集与资源

数据集与资源

  • 模拟基准：LIBERO（4 个官方套件，40 任务）、SimplerEnv（WidowX 平台，4 任务零样本迁移）、RoboTwin 2.0（50 任务，clean/randomized 设置）。
  • 真实机器人：Franka 机械臂，三个任务套件：*Pick-Spatial*、*Pick-Color*、*Stack-Long*；收集 362 条 *Pick-Cups* 轨迹和 220 条 *Stack-Cups* 轨迹。
  • 模型骨干：LIBERO 微调 π0-FAST-base；SimplerEnv 和 RoboTwin 2.0 使用 Qwen3-VL-4B-Instruct 作为共享 VLM 骨干；真实实验使用 Qwen3.5-VL 作为共享骨干。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、SimplerEnv、RoboTwin 2.0 仿真基准 + 真实 Franka 机器人操作任务。
  • 主要指标：任务成功率（Success Rate）、训练效率（达到最佳基线性能所需步数）、推理延迟、有效重建率（VRR）、压缩率（CR）、VRR×CR 权衡、编码/解码延迟。
  • 关键结果：

- LIBERO：CATok 平均成功率 0.959，优于 FAST（0.955），长时任务 Long 达 0.910（FAST 为 0.901）。

- SimplerEnv：CATok 平均 0.490，显著高于 FAST（0.469）、OAT（0.365）和 BIN（0.213）；在 *StackGreenCubeOnYellowCube* 任务上相对最强基线提升超过 16.7%。

- RoboTwin 2.0：CATok Clean 0.489、Randomized 0.531，均高于 FAST（0.478/0.478）。

- 真实机器人：CATok 在三个任务套件上一致比 FAST 提升约 20 个百分点。

- 训练效率：CATok 仅需约 50% 训练步数即可达到 FAST 的最佳性能。

- 推理效率：端到端 VLA 推理速度比 FAST 快 1.7×，重建保真度-压缩平衡强 3.6×。

- 内在属性：VRR×CR 最高达 16.85，优于所有基线；编码/解码延迟显著低于 FAST。

- 因果性验证：token 熵在正向顺序递减、反向顺序递增，证明因果有序；t-SNE 显示 token 嵌入按槽位组织，前缀重建呈现粗到细的轨迹更新。
