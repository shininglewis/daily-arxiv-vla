Card 03 核心贡献

核心贡献

  • 提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适应视为显式的 query-skill 记忆调优，减少持续学习中反复更新模型权重的需求。
  • 设计 Inline Memory Interface：将可学习的记忆 token 插入 VLA 前缀流，使骨干网络在原生策略动作条件路径中生成控制相关的 query 与 skill 表示。
  • 提出 Query-Skill Memory Bank：将技能外化为解耦的 query 原型（决定检索"什么"）与 skill 值（指定"如何"行动），支持技能复用、扩展与持续任务适应，仅需少量参数更新。
  • 设计 Bridge-and-Adapt 训练策略：通过轻量适配器与残差记忆更新进行记忆空间对齐，提升源域技能在目标域偏移（如 sim-to-real）下的可检索性。
Card 04 方法描述

方法描述

  • Inline Memory Interface：向 VLA 前缀流注入可学习记忆 token，通过两个独立的注意力池化算子（AttnPool_q / AttnPool_s）分别提取 query 嵌入 q_t（用于检索）和 skill 嵌入 s_t（行为表示），skill 由轻量 Skill Decoder 监督以重建未来动作块。
  • Query-Skill Memory Bank：以解耦的 key-value 原型 B = {(p_j^q, p_j^s, n_j, E_j)} 存储技能，初始 bank 通过运动感知下采样、进度分层采样与技能聚类构建；检索时先进行记忆坐标对齐 q'_t = A_mem·q_t，再用相似度加权聚合检索技能，并通过残差 Δp_j^q、Δp_j^s 实现不覆盖基础原型的技能更新。
  • Bridge-and-Adapt 三阶段训练：

- Stage A（接口预训练）：训练记忆 token、Query/Skill Encoder、Skill Decoder、Token Projector 及 VLA 骨干最后几层，优化 L_pre = L_fm + λ_q·L_q^nce + λ_s·L_skill。

- Stage B（桥接适应）：解冻骨干并更新 A_mem、τ_mem 及活跃原型残差，通过低秩残差 Skill Adapter（s̃_t = ŝ_t + U_s V_s^T ŝ_t）校正跨域技能空间失配。

- Stage C（记忆适应）：冻结骨干与接口，仅更新 A_mem、τ_mem、原型残差与记忆 bank，使用存储的潜在 query-skill 对进行重放以缓解遗忘。

Card 05 数据集与资源

数据集与资源

  • 使用的数据集与基准：LIBERO（Spatial、Object、Goal、Long 四个套件）、CALVIN（ABC→D）、RoboTwin 2.0（Hard 设置），以及 9 个真实世界双机械臂任务。
  • 真实平台：14-DoF 双臂 GALAXEA R1 Lite 机器人，配备腕部相机与第三人称相机，分辨率 224×224。
  • 模型初始化：基于预训练 π_0.5，附加记忆 token、query-skill 接口与技能 bank。
  • 关键超参：4 个记忆 token（m=4），维度 d_q = d_s = 256，每个检索原型 4 个 skill token（n_s=4），top-2 检索，初始 bank K_0=128 个原型。
  • 训练资源：8× NVIDIA A800 GPU，全局 batch size 256，训练 30,000 步。
Card 06 评估与结果

评估与结果

  • 评估场景涵盖三类：域内适应（in-domain adaptation）、跨域适应（cross-domain / sim-to-real）、域内终身学习（in-domain lifelong learning）。
  • 主要指标：LIBERO 平均成功率、CALVIN 平均完成长度（Avg. Len）、RoboTwin 2.0 Hard 成功率、真实世界任务成功率、旧任务遗忘率 F。
  • 域内适应：仅用 30% 训练数据，LIBERO 平均成功率提升 16.5%，CALVIN 平均完成长度提升 0.42，RoboTwin 2.0 Hard 成功率提升 5.0%；全量数据下 Optimus-R 在 LIBERO 平均（97.8%）与 RoboTwin 2.0 Hard（55.0%）均为最优。
  • 跨域适应：仅用每个任务 20 条演示，真实世界平均成功率达 33.3%，超越 π_0.5 达 13.9%；80 条演示时平均成功率达 72.2%。
  • 终身学习：20 条演示新任务成功率提升 11.0%；80 条演示适应后旧任务留存 77.5%，平均遗忘率由 15.0% 降至 10.0%。
  • 参数效率：相比 π_0.5 全量微调（3.6B 可训练参数、560 GPU 小时），Optimus-R 仅新增 7M 参数、约 86 GPU 小时，推理速度 14 Hz，且在 30% 数据下成功率（88.6%）显著优于全量微调（72.1%）。
