Card 03 核心贡献

核心贡献

  • 提出一种 VLA 记忆新范式：把预训练视觉几何基础模型（VGGT-Ω）的特征并入时间记忆，使过去的场景几何结构可用于动作生成，兼顾外观与几何历史上下文。
  • 设计联合的视觉-空间检索机制：当前视觉 token 与空间 token 共同通过跨注意力检索记忆库；检索机制包含一个*相关性–非冗余*评分，仅作为条目级注意力先验，不引入额外的学习型打分器。
  • 采用有界记忆库，并把空间 token 放进独立的 policy-prefix 区段，通过块因果注意力掩码让动作生成直接访问空间信息，同时保持主干预训练的图文表示不变。
  • 在 4 个仿真基准 + 3 个真实世界任务上验证：在每个仿真基准上都取得对比方法中最高平均成功率，真实任务相对 π0.5 提升 58.33 / 30.00 / 35.00 个百分点。
Card 04 方法描述

方法描述

  • 以 PaliGemma 视觉-语言模型与 π0.5 的 flow-matching 动作专家为基础架构；SigLIP 编码当前视觉 token。
  • 空间 token 化：用冻结的 VGGT-Ω 从多帧 RGB 窗口（默认 K=4 帧头相机）提取当前帧几何特征（1024 个 patch、宽度 2048），再经可训练压缩器（学习查询池化交叉注意力 + 变分瓶颈）压缩为 N_s = 256 个空间 token。
  • 有界时间记忆：把视觉与空间 token 拼接后存入容量为 L_m = 16 的记忆库；容量超出时会丢弃最旧条目，并在每次轨迹（episode）开始时重置；检索通过 L = 2 层堆叠的跨注意力实现，检索结果经门控（gated fusion）与当前表示融合。
  • 相关性–非冗余评分：由余弦相似度 r_j 与归一化特征差 u_j 相乘得到条目得分 s_j = r_j·u_j，经标准化后以 β 偏置 token 级 softmax 注意力，从而引导检索，但不会排除历史条目。
  • 训练目标：用 flow-matching 动作损失、辅助特征重建损失和 KL 正则联合训练策略与空间压缩器；推理时使用后验均值替代采样。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（libero-spatial/object/goal/libero-10/libero-90）、LIBERO-Mem、MIKASA-Robo、SimplerEnv Bridge（训练数据为 BridgeData V2）。
  • 真实机器人：AGIBOT G2 双臂机器人，头相机 640×400、双腕相机 640×528。
  • 模型规模：冻结的 1B 参数 VGGT-Ω 几何模型，输入为 512px 头相机图像；VLA 图像输入缩放至 224×224。
  • 训练资源：8 张 NVIDIA H100 GPU，每卡 batch size 为 16；λ_r = 1，λ_kl = 1e-4，采样组大小 16。
Card 06 评估与结果

评估与结果

  • 评估环境：在 4 个仿真基准与 3 个真实任务（方块堆叠、物体整理、手机包装）上汇报任务成功率。
  • 主要指标：任务平均成功率（SR，%）以及相对基线 π0.5 的提升（百分点）。
  • 关键结果：

- LIBERO 五套件平均 97.8%，优于 π0.5 的 96.6% 与 MemoryVLA 的 96.5%（libero-goal 97.6% vs 94.6%，libero-10 97.6% vs 95.4%）。

- LIBERO-Mem 平均 41.0% vs π0.5 的 38.0%，在 B×5 与 B×7 重复放置任务上各提升 30 个百分点。

- MIKASA-Robo 平均 45.2%，分别超过 π0.5 与 MemoryVLA 12.8 与 4.0 个百分点。

- SimplerEnv Bridge 平均 74.0% vs MemoryVLA 的 71.9%；Stack Cube 任务 54.2% vs 37.5%（+16.7）。

- 真实任务相对 π0.5 分别提升 58.33 / 30.00 / 35.00 个百分点。

  • 消融实验：验证空间信息与记忆模块的作用、检索偏置强度（β/τ_r）的影响，以及 VGGT-Ω 输入帧数 K 的影响。
