EgoGenesis: Egocentric World-Action Modeling with Online Anchored Projective Memory and Action-3D RoPE

Card 03 核心贡献

核心贡献

  • 提出了 OAPM（Online Anchored Projective Memory）：保留不可变的第一帧 3D 场景锚点，同时在自回归生成过程中在线刷新近期状态槽，解决场景和目标物体漂移问题。
  • 提出了 A3D-RoPE（Action-3D Rotary Position Embedding）：将骨架/末端执行器关节点栅格化到潜空间 patch 网格上，并用相机感知的 3D 度量坐标作为旋转相位注入骨架-视频交叉注意力，实现精确的动作控制。
  • 构建了覆盖人手、灵巧手、平行夹爪、机器人臂末端执行器的源平衡多实体训练语料，提升跨实体泛化能力。
  • 在真实机器人下游任务中验证了数据增强价值：400 条真实轨迹 + 400 条 EgoGenesis 生成轨迹，将单臂 OOD 成功率从 77% 提升至 84%，双臂从 53% 提升至 70%。
Card 04 方法描述

方法描述

  • 采用分块因果 DiT（chunkwise DiT）架构，基于预训练视频生成先验（Wan2.2-5B-Control 骨架）进行两阶段训练：第一阶段 6k 步 SFT（使用预处理的记忆槽），第二阶段 6k 步自回归训练（使用生成帧作为近期状态刷新）。
  • OAPM 使用预训练 VGGT-Ω 提取 3D 场景重建特征，通过门控交叉注意力读取锚点槽与近期槽，每间隔 sᵣ 个块用最新生成帧刷新近期槽，锚点槽永不覆盖。
  • A3D-RoPE 将 Q/K 通道按 x/y/z 三轴分组，每组内相邻通道构成 2D RoPE 对，旋转角度由参考帧度量坐标 Xₐ 决定（s=4，κ=10⁴），仅作用于覆盖骨架的有效 patch，背景 token 不变。
  • 训练数据为 210K 条片段，来源包括 EgoDex、AgiBot、RoboTwin、Real-world Ego、DexJoCo，视频统一为 81 帧、16 FPS、832×480 分辨率。

Card 06 评估与结果

评估与结果

  • 评估指标：PSNR、SSIM、LPIPS（帧级保真度）；Kpt.Err（关键点末端误差，动作对齐）；Phys.Faith（Kimi K2.7 评估物理可信度）；Subj. Cons.（主体一致性）；Bg. Cons.（背景一致性）。
