Card 02 论文概述

论文概述

  • 论文研究具身操作中组合泛化（combinatorial generalization）的极限，目标是在不提供组合技能训练轨迹的情况下，让 VLA 模型将已学的原子技能重组为新的长时序任务。
  • 直接全指令微调（full-instruction fine-tuning）容易记忆已有组合序列，在未见组合上性能大幅下降，说明模型学到的是序列模板而非鲁棒技能重组。
  • 论文提出诊断框架 HSE 和基准 RoboCombine，识别出 start state gap，并通过 PRTI 扩展原子技能起始状态覆盖，从而提升下游子任务的交接执行能力。
Card 03 核心贡献

核心贡献

  • 提出诊断执行框架 HSE（Hierarchical Subtask Execution），将规划器、触发器和策略共享为模块化接口，把长时序失败分解为子任务顺序错误、边界时机错误和下游执行失败。
  • 提出 RoboCombine 基准，在训练仅含孤立原子任务轨迹的条件下评估未见有序组合，并提供有序成功率、第一/第二子任务成功率、跨子任务边界转换率等细粒度指标。
  • 识别并定义 start state gap：下游原子技能需要从前一子任务产生的交接状态启动，而非原子训练中的规范起始状态，这是原子能力无法自动转化为有序执行的关键瓶颈。
  • 提出 PRTI（Pose Robust Task Initialization），利用成功原子轨迹的后期片段扩展原子任务起始状态覆盖，在不使用组合演示的前提下提升交接鲁棒性。
  • 在模拟和真实机器人上验证 PRTI 与 HSE 的有效性，并开源 RoboCombine 与 HSE 代码。
Card 04 方法描述

方法描述

  • HSE 将组合命令分解为原子子任务队列 \(q\)，通过 handoff cue \(g\) 控制何时切换当前激活的原子指令，底层 VLA 作为指令条件原子执行器 \(\pi\)。
  • HSE 定义四种可控诊断模式：Pred（预测队列和切换线索）、Ordered（固定正确子任务顺序）、Oracle（固定正确顺序和切换线索）、Enhanced（在 Oracle 基础上替换原子策略），通过匹配模式间的性能差距定位失败来源。
  • PRTI 构建辅助起始状态池 \(\mathcal{S}\)，来源于成功原子轨迹的后期片段；对每个目标技能 \(z_i\)，采样任务有效子集 \(\mathcal{S}_i\) 并重新启动单技能轨迹。
  • 后训练阶段将规范原子轨迹与 PRTI 轨迹按 1:1 混合，策略始终只以目标原子指令为条件，保持 atomic-only 训练边界。
  • 关键技术点：HSE 将层次结构用作测量接口而非单纯解决方案架构；PRTI 以轻量后训练方式扩展起始状态覆盖，无需组合轨迹。

Card 06 评估与结果

评估与结果

  • 模拟评估在 RoboCombine 上进行，主要使用 Oracle-HSE 和 Ordered-HSE 等受控执行模式。
  • 主要指标包括有序成功率 \(\mathrm{SR}_{\mathrm{ord}}\)、第一子任务成功率 \(\mathrm{SR}_{1}\)、第二子任务成功率 \(\mathrm{SR}_{2}\) 和转换率 \(\mathrm{Conv}_{1\rightarrow 2}\)。
  • Full Instruction Fine Tuning 在已见组合 Set A 上达到 40.0% 有序成功率，但在 Set B 降至 15.0%，Set C 仅 4.4%，Set B/C 平均仅 7.7%。
  • 在 Oracle-HSE 下，Motus 聚合有序成功率为 19.7%，Ordered-HSE 为 17.4%，Full-Inst 为 10.0%；聚合转换率显示首阶段成功并不保证下游执行成功。
  • PRTI 在 Oracle-HSE 下达到 18.16% 平均有序成功率，显著优于随机扰动 4.21%、执行时重置 oracle 9.47% 和基础原子策略 2.63%。
  • PRTI 的非零任务覆盖率达到 89.47%，转换率 \(\mathrm{Conv}_{1\rightarrow 2}\) 为 39.88%，均高于 Random 和 Reset 等控制方法。
  • 真实机器人实验中，Oracle-HSE+PRTI 在多个组合任务上取得更高平均进度，例如任务 1-8-6 上达到 0.66，高于 Full-Inst-FT 的 0.62、Oracle-HSE 的 0.44 和 Order-HSE 的 0.34。
