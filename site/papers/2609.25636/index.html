Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出语言必要性诊断基准 RoboFollow：构造高熵场景，同一视觉配置对应多个语义有效且运动学可行的任务分支，并通过简单物体、短时程交互和训练已覆盖的动作原语减少运动执行混淆。
  • 提出分层诊断协议 L0–L3：L0 分布内测试、L1 视觉定位（交换物体位置）、L2 语义组合（视觉不变、指令重组）、L3 视觉-语义联合扰动。
  • 提出阶段式评分框架：用 Intent Score（语义定位） 与 Execution Score（运动执行） 区分语义误解与低层控制失败，并补充 Completion Rate（CR）；其中收尾阶段占总分 20%，要求完成任务后不再产生无关动作。
  • 对 9 个代表性 VLA/WAM 策略进行系统评测，并验证更强 VLM 主干、QA 协同训练、LangForce、Classifier-Free Guidance 等缓解手段均无法弥补 L1–L3 的泛化差距。
  • 开源代码与数据集（GitHub AutoLab-SAI-SJTU/RoboFollow 与 Hugging Face AutoLab-SJTU/robofollow-data）。
Card 04 方法描述

方法描述

  • 场景熵量化：定义 \(H_{scene}=H_{train}(T\mid S)\)，即任务标签对任务无关初始场景规格的条件熵；RoboFollow 取 \(K_s=(16,16,16,16,7,4)\)、\(K=75\)，得 3.782 bits，显著高于 LIBERO 系列同等定义下的 0.880 bits。
  • 四类诊断场景：① 外延空间关系（left/right/behind 等谓词绑定）；② 内在物体属性与动作选择（颜色/尺寸/形状组合 + pick/push/stack/place）；③ 细粒度动作调制（waypoint 路径点与最终朝向约束）；④ 基础逻辑接枝（时序、显式否定、条件分支）。
  • 受控实验设计：训练与验证划分保证语言清晰、无跨级别泄漏、测试目标动作均在演示行为库内，从而隔离"理解"与"执行"。
  • 多阶段 Intent-Execution 评分：按子阶段判定语义目标选择是否正确，再判定对应子目标是否物理完成。

Card 06 评估与结果

评估与结果

  • 评估环境：仿真基准 RoboFollow（含 L0–L3 四级划分与四个场景 S1–S4），辅以真实机器人试点；指标为 IS / ES / CR（百分比）。
  • L0 表现强但不可迁移：多数模型在分布内 L0 接近满分（如 PI05 在 S1 为 IS 99.1 / ES 98.5 / CR 98.8，S2 为 100.0/100.0/100.0），但在 L1–L3 上 Intent Score 急剧下降。
  • 总体平均表现（四场景全级别均值）：PI05 IS 55.7 / ES 53.0 / CR 47.3 为最优；ACoT-VLA 53.5 / 49.3 / 42.5；PI0 48.4 / 44.9 / 38.9；MOTUS 36.8 / 30.8 / 27.3；Lingbot-VLA 35.2 / 32.5 / 27.4；XVLA 34.3 / 30.9 / 22.3；GROOT N1.6 32.7 / 25.6 / 20.5；OpenVLA-OFT 仅 10.7 / 4.2 / 3.5。
  • 语言必要性验证：PI05 在"空语言"（empty language）条件下 L0/S1 的 IS/ES 仅 16.0/16.0（CR 6.3），平均降至 12.3 / 8.9 / 5.2，表明高熵场景下视觉无法独立完成任务。
  • 缓解手段无效：更强的 VLM 主干、QA 协同训练、LangForce 与 Classifier-Free Guidance 均未能把 L1–L3 的差距缩小到 L0 水平，说明稳健的语言条件任务选择仍是当前策略的关键被忽视瓶颈。
