Card 02 论文概述

论文概述

  • 提出 ExStereo，一个将预训练 2D 视觉-语言-动作（VLA）模型提升至 3D 的立体视觉模块，无需重新预训练基础策略。
  • 解决的核心问题：多数 VLA 仅依赖单目 RGB，缺乏度量深度与精确几何信息，无法应对高精度操作、遮挡与透明/反光物体等场景。
  • 与依赖 RGB-D 传感器或隐式立体特征（如 StereoVLA、StereoPolicy）的方法不同，ExStereo 通过显式重建场景几何获取精确 3D 表示。
Card 03 核心贡献

核心贡献

  • 提出 ExStereo，一个可即插即用、将任意 2D VLA 提升为 3D 感知的立体模块，无需对基础策略额外预训练即可快速适配。
  • 证明显式立体表示在适当使用下，其下游操作性能优于隐式立体表示。
  • 提出 action-stereo cross-attention（ASCA） 机制，让动作 token 作为 query 选择性检索立体 token，不改动 VLM 前缀 token 与权重，与任意 VLA 架构无关。
  • 引入 mid-training 阶段，利用掩码自编码（MAE）目标在大规模立体数据上学习稳健的 3D 表示，post-training 时冻结立体模块防止过拟合。
  • 在仿真与真实双臂 PiPER 平台上全面验证，性能显著超越 RGB、点云和隐式立体基线。
Card 04 方法描述

方法描述

  • 多视角观测渲染：使用冻结的 Fast-FoundationStereo 从校正后的立体图像对预测视差图，结合相机内参 $K$ 与基线 $B$ 计算度量深度 $Z_t = f_x B / d_t$，反投影得到 3D 点云。
  • 用 RANSAC 检测桌面主平面并旋转对齐至 $+Z$ 轴、平移到 $z=0$、水平居中，放置四个正交虚拟相机（Top、Front、Left、Right），用 z-buffer 渲染为 $128\times128$ 的正交视图（含深度、3D 坐标、有效性掩码），水平拼接为 $128\times512\times5$ 的多视角观测 $O_t$。
  • 多视角编码：用 ViT $\rho$ 以 $16\times16$ patch 划分为 256 个立体 token $z_t=\rho(O_t)\in\mathbb{R}^{256\times d}$，加入可学习位置嵌入，不使用 class token 或池化。
  • Action–Stereo 交叉注意力（ASCA）：动作 token $a'_t$ 作 query、立体 token $z_t$ 作 key/value，经多头缩放点积注意力后残差加回动作 token，不修改 VLM 前缀与权重。
  • 两阶段训练：mid-training 时联合 VLA 目标与 MAE 重建目标 $\mathcal{L}_{\mathrm{Total}}=\mathcal{L}_{\mathrm{VLA}}+\lambda\mathcal{L}_{\mathrm{MAE}}$；post-training 时冻结立体模块与 ASCA，仅用标准 LoRA 微调，丢弃 MAE 解码器。
  • 技术亮点：使用显式几何表示降低从视差/代价体推断几何的开销；动作专家规模远小于 VLM，更易优化。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 基准，选取 10 个双臂操作任务评估；mid-training 使用 7 个非重叠任务的各 500 条 episode，post-training 使用 100 条干净（无域随机化）episode。
  • 真实世界数据：从互联网收集 20 个 AgileX PiPER 数据集（来自 11 位贡献者，共 3469 个片段），并用 StereoEngine 将单目左视图提升为立体图像对。
  • 真实任务数据：Stack Two Bowls（200 条演示）、Lift Glass Bottles（50 条）、Close Fridge Door（20 条），由资深机器人专家用 Meta Quest 2 遥操作采集。
  • 被测模型：公开预训练 VLA π₀.₅ 与 SmolVLA。
  • 硬件平台：双 AgileX PiPER 机械臂 + ZED Mini 立体相机。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 仿真基准（每个方法 25 个未见 episode、含域随机化，3 个训练种子平均）与真实双臂 PiPER 平台（每方法每任务 20 次试验）。
  • 主要指标：任务成功率（% / 成功次数）。
  • 仿真关键结果：π₀.₅-ExStereo 平均成功率从 51.2% 提升至 76.4%；SmolVLA-ExStereo 从 18.7% 提升至 42.0%；单任务最大提升达 50.6%（π₀.₅）与 65.3%（SmolVLA）于 Handover Mic。
  • 真实世界关键结果：π₀.₅-ExStereo 合计 50/60（83.3%），远优于 π₀.₅ 基线 16/60（26.7%）、π₀.₅-ExStereo w/o MT 36/60（60.0%）；StereoVLA 最差仅 11/60（18.3%）。Lift Glass Bottles 上达 18/20（基线仅 5/20）。
  • 消融实验：显式立体 + ASCA（66.7/72.0）显著优于 VLM + 隐式立体特征（32.0/20.0）；mid-training 加入 MAE（61.3/92.0）优于无 MAE（57.3/90.7）。
  • 局限性：依赖立体基础模型（对远处、无纹理、细薄结构可能退化）；单视角点云存在遮挡空洞；假设平面桌面世界坐标；mid-training 数据仅来自单一基准与单一双臂本体。
