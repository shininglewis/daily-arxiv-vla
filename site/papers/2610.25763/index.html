Card 02 论文概述

论文概述

  • 论文提出 TrajWAM，一个面向动态机器人操作（dynamic robotic manipulation）的轨迹引导世界动作模型（World Action Model, WAM），目标是让机器人在抓取移动物体时既能预测目标未来运动，又能以足够低的延迟重规划。
  • 现有 WAM 方法在全帧场景级上建模未来演化，机器人自身运动与背景动态会淹没目标物体的运动信息；同时迭代式视频-动作去噪带来高延迟，导致预测在执​​行前已过时。
  • 论文的核心思路是：用预测的未来目标物体掩码轨迹显式地引导未来视频想象，再通过该未来表示条件化动作生成，并用解耦蒸馏把整条“轨迹 → 未来视频 → 动作”通路压缩为单步推理。
Card 03 核心贡献

核心贡献

  • 提出 TrajWAM，将预测的目标物体运动（未来掩码轨迹）显式注入未来视觉想象，并把这种预期（anticipation）传播至下游动作预测。
  • 设计解耦的单步蒸馏策略，分别加速视频生成与动作生成，同时在压缩后保留轨迹可控性与准确的未来条件动作预测。
  • 在仿真（DOMINO）与真实机器人平台上系统验证，在动态操作任务上取得 SOTA，并实现高效单步视频-动作推理（108.5 ms）。
  • 通过消融实验证明：预测轨迹条件显著优于静态/全零条件；动作 rollout 蒸馏显著优于 CD、DMD 与未蒸馏单步推理；轨迹适配器重对齐带来稳定增益。
Card 04 方法描述

方法描述

  • 以物体为中心的未来轨迹预测：用冻结的语言条件分割模型（SAM3）从固定第三人称视角提取目标物体掩码历史；紧凑 2D U-Net 以 K=4 帧历史掩码（时间步长 s=4）一次前向预测 H_v=8 帧未来掩码，训练损失为 BCE（logits）+ Soft Dice（概率），各权重 0.5。
  • Trajectory ControlNet：将预测掩码经视频 VAE 编码为轨迹潜变量 z_M，轻量 ControlNet（与 Wan2.2-5B 同深度、隐宽度从 3072 降至 512）按视频 flow time 向每个视频 block 注入零初始化卷积残差。
  • 非对称视频-动作注意力：视频 token 只关注视频 token，动作 token 可关注动作与视频 token，从而让动作分支读取受轨迹控制的未来表示，而视频预测不受动作 token 影响。
  • 训练目标：冻结视频骨干、VAE、文本编码器，仅训练 ControlNet、零初始化投影层与动作专家（隐宽度 3072→1024），采用 flow matching 速度回归损失联合优化视频与动作。
  • 三阶段解耦蒸馏：① 视频骨干蒸馏（DMD 分布匹配，冻结真实分数模型 + 可训练假分数模型）；② 轨迹适配器重对齐（从慢速 ControlNet 初始化，冻结单步生成器，用潜变量重建 + 扩散判别器对抗目标训练）；③ 动作 rollout 蒸馏（学生单步 rollout 匹配教师 10+10 步 rollout 输出的动作块，带 padding 掩码）。
  • 在线部署：推理时掩码由冻结 SAM3 在线异步更新（平均 69.1 ms），策略使用最新可用掩码历史而不等待当前帧分割；预测 T_a=32 个动作，执行 8 个后重规划；真实世界使用 Real-Time Chunking (RTC)。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：DOMINO 动态操作基准，35 个任务，每任务 50 条演示，共 1,750 条演示；Aloha-AgileX 机器人，Level 1 动力学、动态系数 α=0.1，干净（clean）设置。
  • 真实世界任务：传送带抓取（线性运动）与转盘抓取（旋转运动），共 400 条遥操作演示（每任务 200 条）；物体含香蕉、瓶子、胶带、毛绒玩具四类，每种任务三档速度（低/中/高），每个（任务, 速度, 物体）组合 20 次试验。
  • 模型规模：视频骨干与动作专家均初始化自预训练 Wan2.2-5B（经 Fast-WAM-Joint 初始化）；ControlNet 隐宽度 512，动作专家隐宽度 1024；论文未单独报告总参数量。
  • 训练配置：轨迹条件训练 5,000 步（batch 128，lr 5e-5）；视频蒸馏 5,000 步（batch 8，生成器/假分数 lr 5e-7 / 1e-7，1:5 更新比）；适配器重对齐 1,000 步（lr 2e-6）；动作蒸馏 2,000 步（lr 1e-6），后两者 batch 4；教师每模态 10 步，学生 1 步。
  • 硬件：训练用 NVIDIA H200；DOMINO 评测用 A800；真实世界实验与全部延迟测量用单张 NVIDIA RTX 5090 32 GB。
Card 06 评估与结果

评估与结果

  • 指标：仿真报告成功率 SR、操作分数 MS（DOMINO 定义的连续质量指标）与推理延迟；真实世界仅报告成功率。
  • DOMINO 主结果：SR 43.54%、MS 54.07，超越最强基线 InternVLA-A1.5 达 14.24 个百分点（SR）与 11.57 点（MS），推理延迟 108.5 ms，快于 Fast-WAM（183.7 ms）与 InternVLA-A1.5（552.2 ms）。
  • 真实世界主结果：传送带抓取 77.9%、转盘抓取 70.4%，显著优于 π0.5（54.2% / 44.2%）与 Fast-WAM（29.6% / 27.9%）；两任务合计 480 次试验的总体成功率 74.2%（π0.5 49.2%，Fast-WAM 28.8%）；高速条件下优势最大（65.0% / 70.0%，领先 π0.5 约 35–37.5 个百分点）。
  • 掩码来源消融：训练用真值掩码、测试换用 SAM3 或 GroundedSAM2 仍保持竞争力，换成 GroundedSAM2 仅使 SR 下降 2.11 点、MS 下降 1.51 点。
  • 轨迹条件消融：Predicted 47.30% SR / 58.32 MS，优于 Black（32.00 / 44.32）与 Static（20.90 / 33.72），Static 因强加错误“静止轨迹”反而最差。
  • 动作蒸馏对比：动作 rollout 蒸馏 42.25% SR / 53.38 MS，远高于 CD（18.42 / 36.33）、未蒸馏单步（7.39 / 15.82）与 DMD（1.08 / 19.10）。
  • 适配器重对齐消融：重对齐将 SR 从 42.20% 提升至 43.20%、MS 从 52.76 提升至 54.11。
  • 局限：当前实验主要针对独立运动的目标物体，将轨迹预测扩展到动作依赖的物体动力学仍是未来方向。
