Card 03 核心贡献

核心贡献

  • 建立了 VLA 部署失败的分类体系：在 LIBERO-90 上对 OpenVLA-OFT 和 π0.5 两种模型进行 133 项任务评估，识别出四种失败模式——任务误解（~50%）、感知失败（~23%）、执行错位（~23%）、多步规划失败（~6%）。
  • 提出 CorrectVLA 三阶段语言-动作接地机制：通过 LLM 将稀疏的语言反馈转化为稠密的、逐时间步、逐维度的动作修正信号，保持策略权重完全冻结。
  • 通过实验证明：执行错位类失败可通过单次任务级修正被恢复，且修正结果可横跨同一任务的所有 rollout 泛化，无需逐回合人为干预。
  • 在真实机器人上，面对环境漂移（机器人基座移位）导致的策略崩溃，CorrectVLA 将成功率从基础策略的 10% 提升到 95%，且跨目标位置与对象类别泛化。
  • 揭示了推理时修正的可操作性边界：策略具备"策略正确性"（strategic correctness）时修正有效，语义理解缺失时修正无效。
Card 04 方法描述

方法描述

  • Phase A（结构化参数提取）：使用 LLM 将自然语言反馈（如 "move left more in 1-2 seconds"）解析为结构化五元组：动作维度、方向符号、幅度词、时间窗口起止。
  • Phase B（幅度量化）：将语言幅度词映射到数值范围——"slightly" → [0.3, 0.5]，"more" → [0.5, 0.8]，"much" → [0.8, 1.0]，LLM 在范围内取值并结合方向生成带符号幅度。
  • Phase C（时间分布）：构造分段线性包络函数 φ(t)，在指定时间窗口内从 0 上升至峰值中点再回归 0，保证修正平滑局部化，窗口外影响为零。
  • 完整接地函数：对于 K 条反馈，按动作维度聚合多个修正的叠加，形成稠密的修正张量 δ；修正后的动作 $a^{corrected}_{t,d} = a_{t,d} + \delta_d(t)$。
  • 真实机器人适配：采用 Jacobian 伪逆将笛卡尔空间修正转换为 xArm7 的关节速度指令：$\dot{\mathbf{q}} = J^\dagger(\mathbf{q})\,\dot{\mathbf{x}}$。
Card 05 数据集与资源

数据集与资源

  • 模拟基准：LIBERO（MuJoCo 物理引擎，Franka Panda 7-DoF 机械臂），包含 LIBERO-90 全部 90 个任务（Spatial、Object、Goal、10 四个子套件）。
  • 仿真基础模型：OpenVLA-OFT（7B 参数 VLA，基于 Llama 2 7B + ViT 视觉编码器，在 40 个 LIBERO 任务上微调）和 π0.5（LeRobot 微调版，lerobot/pi05_libero_finetuned）。
  • 真实机器人平台：UFactory xArm7 + Robotiq 2F-85 夹爪 + Intel RealSense 相机（3 个视角），基于 RIO 框架；真实机器人策略为 π0.5-DROID 微调模型。
  • 训练/推理硬件：NVIDIA RTX 4090 GPU、AMD Ryzen 7 5700X CPU、64GB RAM；所有实验均在推理阶段完成，无 GPU 训练开销。
Card 06 评估与结果

评估与结果

  • 模拟-分布内恢复：π0.5 基础策略在 LIBERO 分布内成功率为 93.0%（1861/2000），CorrectVLA 修复 139 个执行错位失败中的 65 个，恢复率 46.8%，整体成功率提升至 96.3%。
  • 模拟-分布外恢复：π0.5 在 LIBERO-90 OOD 任务上基线成功率 27.1%（122/450），CorrectVLA 修复 328 个失败中的 33 个，恢复率 10.1%，整体成功率提升至 34.4%。
  • 真实机器人实验：π0.5-DROID 在原始环境中成功率为 95%（19/20），机器人基座移位后骤降至 10%（2/20）；使用单条任务级修正，CorrectVLA 恢复至 95%（19/20）——同一位置 100%、不同位置 100%、不同对象+位置 80%。
  • LLM 基线（VLM 自主生成修正，GPT-5 mini）：在模拟与真实实验中恢复率均为 0%，证明纯视觉自主推理无法可靠估计修正幅度，人类反馈中的关键信息不可替代。
  • 失败分类结果：任务误解（OFT 47% / π0.5 50%）、感知失败（25% / 22%）、执行错位（23% / 22%）、多步规划（5% / 6%）；两种架构不同的模型呈现一致的失败分布，表明该分类是通用 VLA 策略的普遍属性。
