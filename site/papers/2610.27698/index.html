Card 02 论文概述

论文概述

  • 论文提出 VLA-Retain，一个成对（paired）基准，用来衡量视觉-语言-动作（VLA）模型在针对某一扰动做视觉模块微调后，对其他扰动维度的鲁棒性如何变化。

Card 03 核心贡献

核心贡献

  • 提出 VLA-Retain 成对基准：每个微调检查点都与自己的基座检查点在同一批 10,030 条 LIBERO-Plus 回合上对比，从而把适配效应与架构差异、基线鲁棒性差异分离开。
  • 覆盖 5 个开源 VLA 模型（OpenVLA-OFT、π0.5、InternVLA-A1.5、NORA-1.5、X-VLA）× 2 个目标域（Camera-view / Sensor-noise），并额外引入 Mixed 训练与多种微调策略。
  • 提出目标增益（target）、平均非目标增益（mean off-target）、最差非目标增益（worst off-target）、总体增益（overall）四类指标，揭示聚合分数会掩盖单维度严重退化。
  • 给出四条实证结论：定向视觉微调不是局部影响，目标增益无法预测保留度；非目标回归不能仅用源域遗忘解释；扩大训练覆盖只提升总体增益而不消除维度级回归；微调策略的效果依赖具体模型。
  • 开源代码与全部逐回合评测结果（GitHub 仓库），支持结果复现。
Card 04 方法描述

方法描述

  • 将 VLA 形式化为 a = g_φ(f_θ(x), ℓ, s)，仅更新视觉主干与连接器 f_θ，冻结下游多模态主干与动作模块。
  • 核心度量是变化向量 Δ：Δ_{m,c,d} = 微调后成功率 − 基座成功率（单位：百分点），在 7 个扰动维度上分别计算。
  • 默认训练配置为 Dual LoRA：对视觉主干和连接器同时施加 rank-32 LoRA，下游模块全部冻结；各模型保留官方学习率调度与归一化统计。
  • 对比的微调策略包括：Connector-only / Backbone-only / Dual LoRA（微调范围）、WiSE-FT 权重插值（α=0.75）、DELTA-style 特征保持（在 Dual LoRA 基础上加入泰勒加权惩罚，将微调后的连接器后表示锚定到冻结的基座分支）。
  • 统计方法：对 40 个源任务做成对聚类 bootstrap（20,000 次重采样）计算 95% 置信区间；并加入原始 LIBERO 对照与检查点/训练种子分析以排除其他解释。
Card 05 数据集与资源

数据集与资源

  • 训练数据：LIBERO-Plus 的 Camera-view、Sensor-noise 子集，以及覆盖全部训练集的 Mixed 设置；均基于 LIBERO 的 40 个基础操作任务。
  • 评测集：10,030 条 LIBERO-Plus 扰动回合，涵盖 7 个维度（Camera view 1,599 / Robot state 1,550 / Language 1,537 / Lighting 1,142 / Background 1,076 / Sensor noise 1,601 / Object layout 1,525）。
  • 模型：OpenVLA-OFT（SigLIP+DINOv2，视觉参数占比 10.64%）、π0.5（SigLIP，11.40%）、InternVLA-A1.5（Qwen3.5 ViT，12.34%）、NORA-1.5（Qwen2.5-VL ViT，16.77%）、X-VLA（DaViT，41.26%）。
  • 训练配置：AdamW、BF16、有效批大小 32、12,000 次优化步；LoRA rank 32、α=16、dropout 为 0。
  • 仿真环境：LIBERO 模拟器 + robosuite 1.4.1 + MuJoCo，评测通过 vla-evaluation-harness 统一接口执行；具体 GPU/TPU 型号与数量在给定原文中未明确说明。
Card 06 评估与结果

评估与结果

  • 评测方式：每个基座-微调对在相同 episode key 上配对评测，报告目标、均值非目标、最差非目标与回合加权总体增益，并附 95% 聚类 bootstrap 置信区间。
  • 发现 1：10 个“模型×目标域”配置中有 8 个平均非目标增益为负；语言与物体布局在 10 个配置中的 9 个上下降。Camera-view 微调下 X-VLA 目标从 19.6%→89.0%（+69.4），但非目标 −4.6、最差 −10.7；OpenVLA-OFT 目标 +39.3 且非目标 +1.4、总体 +7.5。
  • 发现 2：原始 LIBERO 上的变化除 NORA-1.5（−13.4）外均不超过 3.8 个百分点，但扣除后所有 Camera-view 微调模型仍在至少一个非目标维度回归。
  • 发现 3：Mixed 训练对全部 5 个模型的总体增益都高于单一目标域训练（−2.1 至 +13.6），但每个模型仍至少在一个维度回归。
  • 发现 4：策略效果因模型而异——DELTA-style 使 X-VLA 非目标增益从 −4.6 升至 +1.2（总体 +10.9），却使 OpenVLA-OFT 降至 −23.1（总体 −16.6）；WiSE-FT 提升保留度但牺牲目标增益。
  • 其他观察：视觉模块参数占比与非目标平均增益呈 Spearman ρ = −0.70 负相关，即视觉模块越大保留越弱。
