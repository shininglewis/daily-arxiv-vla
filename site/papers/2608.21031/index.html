PhysCaP: Grounding Code-as-Policy Agent with Physics-Informed Exploration

2026-08-21 · 原文 · 翻译 · 2608.21031

提出 PhysCaP（Physics-Informed Code-as-Policy Agent），在代码即策略（Code-as-Policy）框架中引入物理学启发的主动探索层，使机器人能够通过交互主动获取隐藏的物理属性（如质量、刚度）。 针对现有 VLA 策略和被动式 CaP 系统在部分可观测环境中无法推断潜在物理属性的问题，PhysCaP 通过成本可控的信息寻求机制，实现高效、可解释的物理世界接地。 采用双智能体架构（Planner + Prioritizer）平衡探索成本与信息收益，避免过度探索或信息不足。

Card 02 论文概述

论文概述

  • 提出 PhysCaP（Physics-Informed Code-as-Policy Agent），在代码即策略（Code-as-Policy）框架中引入物理学启发的主动探索层，使机器人能够通过交互主动获取隐藏的物理属性（如质量、刚度）。
  • 针对现有 VLA 策略和被动式 CaP 系统在部分可观测环境中无法推断潜在物理属性的问题，PhysCaP 通过成本可控的信息寻求机制，实现高效、可解释的物理世界接地。
  • 采用双智能体架构（Planner + Prioritizer）平衡探索成本与信息收益，避免过度探索或信息不足。
Card 03 核心贡献

核心贡献

  • 提出无需训练的物理属性提取模块（PhysX），仅利用机器人本体感知（关节扭矩、夹爪位移）即可估计物体质量（get_mass）和刚度（get_stiffness），无需额外传感器。
  • 设计Planner 智能体：判断当前观测是否足够，决定何时开始探索、何时终止探索，提供动态停止准则。
  • 设计Prioritizer 智能体：通过视觉启发式过滤不可信或冗余的交互候选，并依据优先级评分排序，实现定向高效探索。
  • 通过双智能体分离（而非合并）显著提升任务成功率与交互效率，消融实验验证其必要性。
  • 在真实世界和 LIBERO 仿真环境中验证 PhysCaP 对 VLA 基线的优势，证明主动物理探索在部分可观测操作任务中的关键作用。
Card 04 方法描述

方法描述

  • 基于 CaP-Agent0 框架扩展控制 API（get_object_pose、goto_pose、open_gripper、close_gripper），使用 Molmo2 进行对象定位，ZED 2i 深度相机进行空间感知。
  • 质量测量：通过空载与负载状态下关节扭矩差分（Δτ），结合垂直方向雅可比（Jz）计算物体质量，公式 m̂ = (Jz·Δτ)/(g\|Jz\|²)。
  • 刚度测量：通过夹爪渐进闭合，检测真实接触并记录夹爪位移与归一化电机力矩，插值得到目标力矩（f*=0.50）下的形变，映射为 1–5 级离散刚度，多次测量取多数投票。
  • 规划流程：Planner 输出候选探索列表（JSON），Prioritizer 过滤并排序，最后由代码生成智能体调用 PhysX 模块合成可执行策略。
  • 框架为模型无关设计，主骨干使用 Gemini 3.1 Pro，可替换为其他 VLM/LLM。
Card 05 数据集与资源

数据集与资源

  • 真实环境：AgileX PiPER 7-DoF 机械臂 + ZED 2i 深度相机，工作台尺寸 120cm×70cm，图像分辨率 1280×720。
  • 仿真环境：LIBERO 基准（Identify Empty Cup 任务）。
  • 计算资源：配备 RTX 3090 GPU (24GB VRAM) 的工作站。
  • 模型：Gemini 3.1 Pro（Planner/Prioritizer/Coding），Molmo2（对象定位），对比 VLA 使用 OpenVLA、π0.5、MolmoAct2 公开检查点。
  • 测试物体：标准商用物品（汽水罐、牛油果、咖啡杯、3D 打印刚度校准按钮等）。
Card 06 评估与结果

评估与结果

  • 评估任务：Find Blue Cube（寻找隐藏蓝立方）、Identify Empty Can（识别空罐）、Pick Ripe Avocado（挑选成熟牛油果），每任务 10 次真实实验；仿真任务 50 次。
  • 评估指标：任务成功率（SR↑）、物体交互次数（OI↓）、机器人执行时间（Time↓）（OI 和时间仅在成功试验中统计）。
  • 真实世界结果（PhysCaP vs. 基线）：

- Task 1: SR 9/10，OI 1.33（最少），Time 40.48s（最短）。

- Task 2: SR 8/10（最高），OI 2.5，Time 239.0s（最短）。

- Task 3: SR 9/10（最高），OI 2，Time 300.47s（最短）。

- 被动 CaP 在 Task 2/3 成功率仅 2/10 和 1/10；CaP+PhysX 虽提升成功率但交互次数和耗时显著增加（如 Task 3 耗时 515s）。

  • 仿真结果（LIBERO）：PhysCaP SR 78%，OI 1.44，Time 71.24s；OpenVLA 成功率 0%，π0.5 4%，MolmoAct2 23%；显示 VLA 在部分可观测任务中几乎失效。
  • 物理模块验证：质量估计与真实值高度一致（5 个参考质量 13g–963g，20 次重复）；刚度测量可区分 1–5 级刚性；使用 ground-truth 质量替代后空罐任务成功率提升至 10/10。
  • 消融：合并 Planner 和 Prioritizer（PhysCaP-joint）性能下降，验证了双智能体分离设计的重要性。
