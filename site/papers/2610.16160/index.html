Card 03 核心贡献

核心贡献

  • 提出 FlowVLA，将 3D flow 作为训练时特权信号注入 VLA 潜在表示，推理时无额外 3D 输入或计算开销。
  • 设计 双层级 3D flow 学习：Point-Level Flow 预测任务关键 3D 点的未来位移，TCP-Level Flow 聚合点运动以对齐机器人 TCP 轨迹。
  • 基于 VDPM 从 RGB 序列重建时序一致的 3D 点轨迹，并进行机器人基座坐标对齐与幅度 top-K 选择。
  • 方法可即插即用地应用于不同 VLA 骨干，如 Seer 和 π_0.5，无需修改推理路径。
  • 在 LIBERO、LIBERO-Plus 和真实世界任务上验证，提升操作成功率、零样本鲁棒性与数据效率。
Card 04 方法描述

方法描述

  • 使用 VDPM 从 RGB 观测中提取参考帧锚定的 3D 点轨迹，并转换到机器人基座坐标系。
  • 通过相邻帧 3D 点位置差构造 3D flow，作为未来运动监督目标。
  • 进行 坐标对齐：将参考相机坐标系下的 3D 点变换到机器人基座坐标系，使 3D flow 与 TCP 位移可比。
  • 进行 幅度选择：根据窗口内平均 flow 幅度选择 top-K 运动显著点，聚焦动态区域。
  • Point-Level Flow：将动作 latent 广播到 K 个关键点，与 3D 坐标融合后由 flow head 预测未来位移，使用 Smooth L1 损失监督。
  • TCP-Level Flow：通过 softmax 权重头聚合预测的点流为 TCP 流，并与真实 TCP 位移对齐，蒸馏控制相关动态。
  • 总损失为 L_total = L_action + λ_point L_point + λ_tcp L_tcp；推理时丢弃所有辅助头与 3D 几何输入。
Card 05 数据集与资源

数据集与资源

  • 模拟数据集：LIBERO、LIBERO-Plus。
  • 真实世界平台：UR5e，配备第三人称和腕部相机，包含 7 个长时程与 3D 感知任务，每任务 40 条演示。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、LIBERO-Plus 模拟基准，以及 UR5e 真实世界操作任务。
  • 主要指标：任务成功率（%）。
  • LIBERO-Long：Seer 从 80.4% 提升至 87.8%；π_0.5 从 92.4% 提升至 94.8%。
  • LIBERO 平均：Seer 从 87.3% 提升至 92.4%；π_0.5 从 96.8% 提升至 97.5%。
  • LIBERO-Plus 零样本：Seer 平均从 36.1% 提升至 41.1%；π_0.5 从 57.5% 提升至 59.2%。
  • 真实世界任务：Stack Cups 73.3% → 93.3%，Basketball 60.0% → 80.0%，Hang Cup 46.7% → 86.7%，Ring Insertion 66.7% → 73.3%。
  • 测试时变化：Basketball 视角变化 0% → 46.7%；Ring Insertion 高度变化 46.7% → 73.3%。
  • 消融：动态 3D flow 达到 87.8%，优于 2D optical flow（84.5%）和静态 3D 点云（85.0%）；坐标对齐、参考帧对齐、幅度选择及双层级损失均有贡献。
