Card 03 核心贡献

核心贡献

  • 提出 AffordDrive3D，将世界动作建模从视觉外观扩展到动作相关空间结构，并基于 VLA 框架实现。
  • 联合建模 RGB-conditioned future depth 与 temporal driving affordances，预测当前和未来可行驶区域及碰撞关键区域。
  • 在 NAVSIM 上取得 91.3 PDMS 和 89.9 EPDMS 的新 SOTA，并通过消融验证 affordance、RGB、几何联合建模的有效性。
  • 通过 VLM 表征消融表明，显式 affordance 监督可显著提升碰撞关键区域预测（AP 从 0.782 到 0.912）。
Card 04 方法描述

方法描述

  • 使用共享 causal VLM backbone（Qwen3-VL-2B）编码多视角图像、导航指令和自车状态，并引入四组可学习 token：affordance、RGB world、geometry、action token。
  • Future RGB modeling：RGB world token 的 hidden states 条件化视频扩散模型（Wan2.1-Fun-1.3B-InP），以 flow-matching 预测未来 RGB latent。
  • RGB-conditioned geometry prediction：以去噪后的未来 RGB latent 为条件，通过 3D 卷积与几何特征融合，分别解码当前和未来深度 latent，并以 Depth Anything 3 伪深度作为监督。
  • Temporal affordance forecasting：对每个预测时域和相机视角的 affordance token，与视觉 token 做投影点积，解码为可行驶区域图和碰撞关键区域图；可行驶区域用加权软 BCE，碰撞关键区域用类别归一化 BCE + Dice 损失。
  • Action generation and joint learning：action token 条件化 DiT，用 flow-matching 生成轨迹；辅助分支在训练时提供多任务监督，推理时仅需 action 分支；SFT 后用 GRPO 对动作扩散模型进行 RL 微调。
Card 05 数据集与资源

数据集与资源

  • 使用 NAVSIM 基准，基于 OpenScene；训练集 navtrain 约 103K 样本，评估集 navtest 约 12K 样本。
  • VLM backbone：Qwen3-VL-2B；RGB 扩散世界模型：Wan2.1-Fun-1.3B-InP。
  • 设置 C=3 相机视角，K=8 个未来时域（2 Hz，4 秒预测），VAE 编码后 T=3 个 latent group。
  • 可学习 token 规模：\|Q_aff\|=27、\|Q_rgb\|=64、\|Q_geo\|=64、\|Q_act\|=8。
  • 训练包括 SFT 14,140 步（batch size 256，AdamW，峰值学习率 5e-5，404 warmup，cosine decay）和 GRPO RL 4,500 步（学习率 3e-6，50 warmup）。

Card 06 评估与结果

评估与结果

  • 在 NAVSIM v1 上评估：PDMS 91.3，NC 98.6，DAC 99.0，TTC 96.3，Comf. 100.0，EP 84.7；超过 ExploreVLA 0.9 PDMS。
  • 在 NAVSIM v2 上评估：EPDMS 89.9，DDC 99.7，TLC 99.9，HC 98.3；超过 ExploreVLA 1.1 EPDMS。
  • 消融（无 RL）：action-only 88.1 PDMS；+affordance 89.2；+RGB 88.9；+geometry 89.1；完整模型 89.6 PDMS，且 NC、DAC、EP 最高。
  • 时序 affordance 预测：当前帧碰撞关键区域 AP 0.918、可行驶区域 AP 0.986；近程（0.5–2 s）平均 0.846/0.983；远程（2.5–4 s）平均 0.732/0.971。
  • 定性结果显示，在狭窄弯道和前车制动场景中，AffordDrive3D 能保持车道并避免碰撞，优于 action-only 与 RGB-based DriveVLA-W0 基线。
