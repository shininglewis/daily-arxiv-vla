Card 03 核心贡献

核心贡献

  • 提出 具身技能（embodied skill） 的统一抽象，用显式的本体假设、接口需求、适用条件与反馈解释规则扩展智能体技能，并从 1,052 条资源构建了包含 250 个技能的 Embodied Skill Repository（133 个动作技能、20 个感知技能、97 个经验技能）。
  • 发布 EmbodiedSkillBench 基准：在共享的多轮"观察—动作"闭环中支持多种智能体与灵活的技能组合，记录成功率、动作数、token 数与墙钟时间。
  • 实验发现技能对智能体的帮助上限取决于"技能是否超出其原有能力"：技能可显著提升较弱智能体并大幅降低开销，但会限制更强的 GPT-6-Astra。
  • 提出 Agent-Directed Reuse（ADR） 新交互范式，允许智能体保留原生控制能力的同时，对每个技能自行决定调用、修改或忽略。
  • 将 Jev 封装为航点执行技能，让智能体保留规划与恢复能力、仅委托局部运动决策，实现成功率与效率的更好权衡。
Card 04 方法描述

方法描述

  • 将技能表示为 s = ⟨m, I, S, R, A⟩：m 为元数据（名称与能力描述）、I 为使用与反馈解读及恢复指令、S 为控制与模型调用脚本、R 为方法文档与过程经验、A 为模型描述符与配置等资产。
  • 遵循开放的 Agent Skills 格式，元数据与指令写入 SKILL.md，可选组件分别组织在 scripts / references / assets 目录；模型权重与推理服务作为外部依赖，不打包进技能。
  • 技能构建流程分三步：模块收集（Module collection）→ 组件结构化（Component structuring）→ 智能体辅助技能装配（Agent-assisted skill assembly），并由智能体撰写适用条件、调用步骤、验证与有界恢复规则。
  • 模块按来源分为 模型模块、代码模块、文本模块 三类；模块与技能为多对多映射。
  • 环境提供 Observe（场景与腕部 RGB、机器人状态、执行反馈）和 Act（末端执行器运动、旋转、夹爪控制或调用 VLA 技能）共享接口，形成多轮闭环直至任务终止或预算耗尽。
  • 评估器分三阶段：Rollout Logging、Per-Task Metric Computation、Cross-Task Aggregation。
Card 05 数据集与资源

数据集与资源

  • 评估数据集为 LIBERO-Pro 的 Clean100：25 个基础任务 × 语言/物体/任务/交换四类扰动各 25 例，共 100 个任务用例。
  • 任务域覆盖 LIBERO-10（24）、Goal（28）、Object（24）、Spatial（24）。
  • 技能仓库源自 1,052 条去重资源记录（227 控制资源、33 感知接口、20 模型描述符、417 经验材料、23 论文引用、13 仓库引用、319 支撑资产），结构化为 260 个 S 资源、453 个 R 资源、339 个 A 资源。
  • VLA 模型覆盖 四个模型族、五个配置：两个 π0.5 检查点（RLinf、Madokalif）、OpenVLA-OFT、SmolVLA、X-VLA。
  • 感知模型包括 SAM3、Molmo2、Contact-GraspNet；动作技能覆盖 grasp、place-in、place-on、place-next-to、open、close、toggle、push 八类任务范围。
  • 被评估的智能体为 gpt-5.6-sol、gpt-6-astra（Codex CLI v0.148.0）、Kimi-K3（Kimi Code CLI v0.40.0）、claude-opus-5（Claude Code v2.1.186）。
  • 技能检索基线使用 BM25 与 BGE-small-en-v1.5 嵌入；论文未报告训练所需的 GPU/TPU 规模。
Card 06 评估与结果

评估与结果

  • 主要指标：成功率（SR，主要指标），以及平均动作数、记录 token 数、耗时（分钟）作为执行开销度量。
  • RQ1（有效性）：技能将 GPT-5.6-Sol 从 11% 提升至 63%，Kimi-K3 与 Claude-Opus-5 各提升约 20 个百分点，同时 token 用量降低 58%–85%；三者的平均动作数分别下降 90.9%、75.6%、62.9%。
  • 但三者在共享技能供给下最终收敛到 61%–64%，且 L10 域均仅有 41.7%，说明多阶段任务仍是共同瓶颈，模型差异未被技能抹平。
  • RQ2（组合）：五种技能配置差异显著——HarnessVLA (ESB) 77% > Zetta (ESB) 69% > Selected 63% > Embedding 42% > BM25 36%；检索更广不等于更高效，Embedding 在 7 个任务上未提供任何动作技能且全部失败。
  • RQ3（互补性）：GPT-6-Astra 原生控制达 92%，纯技能执行仅 61%，说明其已内化部分具身能力；但技能仍将动作数减少 86.50%、token 减少 75.51%、时间减少 83.43%。
  • Agent-Directed Reuse（ADR） 让 GPT-6-Astra 回升至 85%（较纯技能 +24 点，仅落后原生控制 7 点），同时 token 减少 14.1%、时间减少 11.9%。
  • Jev 技能配置达到 81% 成功率，平均耗时从 20.52 分钟降至 8.74 分钟，token 减少约 50%。
  • 结论：随着智能体变强，具身技能的角色从"补充缺失能力"转向"降低执行成本"。
