Card 03 核心贡献

核心贡献

  • 接收 token 保留的光谱迁移：连续光谱残差通过每个目标 token 自身的参考注入，保持预训练编码器、动作解码器与原生 token 宽度不变；86 个留出采集上类别 bAcc 从 0.812 提升到 0.883（配对 session 增益 0.071 [0.050, 0.107]），第二骨干复现同样的富集效果（0.812→0.914）
  • 连续富集优于类别压缩：五项 session 分组测试中，连续状态与后验码状态恢复类内光谱形状的 R² = 0.802 / 0.337；学习残差在匹配的 16-session 比较中同时提升类别 bAcc（0.865 / 0.773）并降低平均解码器 KL（0.048 / 0.062）
  • 光谱内容与组合方式的交互：86 次采集中，own-token addition 使冻结解码后的目标特异性恢复增量约翻倍（交互效应 0.0171 [0.0121, 0.0228]）；镜像无关测试显示其参考固定复用比 pooled replacement 高 0.111
  • 识别与扰动的可校准权衡：在共同扰动预算下，base-fine 达到与未投影消融相当的识别性能，但扰动尾部更小
Card 04 方法描述

方法描述

  • 在冻结视觉主干与预训练投影器之后、冻结动作解码器之前注入光谱残差；仅训练光谱分支与辅助头，两个 VLA 组件完全冻结
  • 假彩色参考：固定波段 [119, 60, 0]（900–1700 nm）经掩膜通过冻结主干，得到 256×4096 的 post-projector 嵌入 Z_base；非仿射 LayerNorm 定义参考网格 G 与池化状态 B（式 2–3）
  • 光谱细残差：120 个原始波段 + 16 个 NMF 坐标标准化后经瓶颈网络（W_down → GELU → W_up）得到 u_i，投影到 base 正交补方向，再按 ρ‖B°‖₂ 重缩放（ρ=0.1，训练时 q~U(0,4)）
  • 组合方式（式 8）：(1-m)G + m·LN(G + qD)；零权重 token 不变，q=0 精确还原 G；加法使注入分支与跳连分支都使用 token 自身参考，而 pooled replacement 只在分数跳连中使用
  • 训练目标：类别加权 CE（共享头 h_c 同时分类参考态与采样注入态）+ 细残差头 h_f 监督 + 残差范数惩罚；验证集选择注入尺度 q（含共同扰动预算约束 d̄_val(q) ≤ b），训练头在部署时丢弃
  • 关键技术：base 正交投影定义基补方向、范数控制、验证校准注入三者共同约束执行扰动
Card 05 数据集与资源

数据集与资源

  • 数据集：SpectralWaste，514/167/171 训练/验证/测试源图像，切分出 2,295 个目标对象（1,392/442/461），六个操作类别：film、basket、cardboard、video tape、filament、bag
  • 立方体从 224 波段线性重采样至 120 波段，空间尺寸 224²，保留原始对象平均光谱，不做逐图像辐射归一化
  • 冻结 VLA 主干：OpenVLA（7B 动作 token 模型）为主要骨干，SpatialVLA 为第二骨干（使用全部 8,194 个动作坐标）
  • 映射器规模：base-fine 为 271,184 参数，base-conditioned direct 对照为 275,024 参数；隐层宽度 64/32
  • 推理环境：bfloat16、batch 4、无 key–value cache、PyTorch 2.6.0、CUDA 12.4、Transformers 4.40.1
Card 06 评估与结果

评估与结果

  • 评估协议：86 个留出采集 session（2,291 对象）的留一 session 交叉验证，内层 12 epoch 选择、60 epoch 重拟合；核心对比为 session 聚类的 out-of-fold 类别 bAcc
  • 主要指标：类别 bAcc、token-proxy bAcc、类内光谱恢复 R²、角度/余弦相似度、解码器 KL 散度、参考固定与重拟合解码器 logit 探针
  • 关键结果：

- 类别 bAcc 0.812 → 0.883（+0.071，95% CI [0.050, 0.107]）；proxy bAcc +0.056 [0.033, 0.097]

- 高锚点直接替换余弦达 0.991 但 bAcc 仅 0.814；base-fine 高出 0.069 [0.047, 0.107]

- 类内光谱恢复 R²：连续 0.802 vs 后验码 0.337，ΔR² = 0.465 [0.429, 0.502]

- 五组匹配控制显示 own-token addition 相比 pooled replacement 的交互效应为 0.0171 [0.0121, 0.0228]

- 六类中五类召回提升，仅 filament 由 0.859 微降至 0.848（92 对象/33 session）

- 单 session 删除鲁棒性测试全部保持正增益（0.068–0.078）；省略 pair 效用项几乎不改变结果

- 波段排除实验：全谱 bAcc 0.886 vs 假彩色三波段 0.835（CI [0.032, 0.075]），排除 base 波段后仍达 0.878
