Card 03 核心贡献

核心贡献

  • 统一的具身基础模型：首个在五个核心导航任务上实现“Grand Unification”的基础模型，显著优于任务特化的专用模型。
  • 最大规模的具身导航数据引擎：构建了包含 7,802 个高保真 3D 场景、16.9M 专家轨迹和 5.0M 推理样本的大规模数据集，覆盖室内外多种环境。
  • 可部署的 Agentic 导航系统：提出集成分层拓扑记忆（Map-as-Memory）、Agentic Planner（CoT 推理与闭环纠错）和 Neural Controller 的完整系统，并成功部署到真实机器人。
  • 技术创新：Universal Multi-Modal Encoder 统一异构输入；Flow Matching Action Head 实现连续、多模态轨迹生成；三阶段训练范式（Cognitive Warm-up、Unified Sensorimotor SFT、SAFE-GRPO）保障模型认知与动作能力协同提升。
Card 04 方法描述

方法描述

  • 架构：采用层次化“Brain-Action”设计，包含三大部分：

- Universal Multi-Modal Encoder：灵活的视觉接口（支持全景/前视）、异构导航目标编码器（语义目标 via 文本 tokenizer，几何目标 via MLP）、推理任务编码器。

- Cognitive Brain：基于预训练 LLM（Qwen3-4B），采用任务条件式双分支设计（Reasoning Head 与 Action Head 并行），而非串行 CoT。

- Action Expert：基于 Flow Matching 的轨迹生成模块，预测 5 个本地 BEV 坐标系下的 waypoints（位置 + yaw），支持连续精确控制和多模态分布建模。

  • 训练策略：

- Phase 1: Cognitive Warm-up —— 用推理数据集冻结视觉编码器微调 LLM。

- Phase 2: Unified Sensorimotor SFT —— 联合优化 NTP 损失和 Conditional Flow Matching 损失（轨迹:推理 ≈ 4:1）。

- Phase 3: SAFE-GRPO 后训练 —— 冻结 Brain，仅微调 Action Expert，通过社会合规、专家相似性、平滑性、效率等多项奖励实现价值对齐。

Card 05 数据集与资源

数据集与资源

  • ABot-N0 Trajectories Dataset：约 16.9M 专家轨迹，涵盖 5 种任务（Point-Goal 4.0M、Instruction 1.5M+0.3M+0.2M+0.8M、Object-Goal 3.6M、POI-Goal 2.5M、Person-Following 4.0M）。
  • ABot-N0 Reasoning Dataset：约 5.0M 推理样本，包括 Navigable Areas Analysis (1.2M)、Social Navigation CoT (0.8M)、Instruction-Following Reasoning (1.3M)、Object-Goal Reasoning (0.1M)、POI Grounding (0.5M)、General VQA (1.1M)。
  • 场景资源：7,802 个 3D 场景，包含 HM3D（住宅）、InteriorGS（住宅）、大型室内公共空间 3DGS 扫描（办公/商场/车站）、真实户外扫描（路口/公园）、SocCity 动态虚拟城市。总面积 10.7 km²（室内 6.25 km² + 室外 4.42 km²），导航图总长 384,754 米。
  • 模型规模：LLM 骨干为 Qwen3-4B（约 4B 参数），未明确报告总参数量和训练 GPU/TPU 资源。
Card 06 评估与结果

评估与结果

  • 评估基准：CityWalker、SocNav、VLN-CE (R2R/RxR)、HM3D-OVON、BridgeNav、EVT-Bench，共 7 个 benchmark。
  • Point-Goal 开环（CityWalker）：ABot-N0 将平均 MAOE 从 CityWalker 的 15.2 降至 11.2，在 Turn/Crossing/Detour/Proximity/Crowd/Other 等所有场景均优于基线。
  • Point-Goal 闭环（SocNav）：ABot-N0 取得 SR 88.3、RC 92.1、SPL 79.2、DCR 85.1、TCR 85.4，大幅超越对比方法（如 CityWalker SR 47.8）。
  • 其他任务：在指令跟随（VLN-CE R2R/RxR）、物体目标（HM3D-OVON）、POI 导航（BridgeNav）和人员跟随（EVT-Bench）上同样达到 SOTA，具体数值见正文表格。
  • 实际部署：在 Unitree Go2 四足机器人 + NVIDIA Jetson Orin NX 上实现 2Hz VLA 推理和 10Hz 闭环控制，验证了系统的实用性与鲁棒性。
