Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出紧凑的任务状态表示：将停止信号（SS）与失败信号（FS）作为动作 chunk 的两个额外维度拼接，与动作一起去噪，仅带来极小参数开销。
  • 设计无需帧级进度标注的监督方案：利用成功示范、失败 rollout、干预前失败片段和恢复示范四类数据的互补性质，结合填充掩码（padding mask）自动构造 SS/FS 目标。
  • 设计受控的信号与动作交互与异步去噪机制：动作与两类信号双向注意力交互但屏蔽 SS–FS 直接交互，并让信号比动作更早收敛，使后续动作去噪步骤以更干净的状态估计为条件。
  • 在五个真实世界操作任务上验证了状态预测的准确性以及策略性能的一致提升，并给出组件消融、信号干预和失败数据量的扩展性分析。
Card 04 方法描述

方法描述

  • 基于 flow matching 的 VLA 策略（π0.5 为骨干），以观测、机器人状态和语言指令为条件预测速度场。
  • 使用动作 chunk 的填充掩码同时完成两件事：屏蔽越界动作，并提供边界级信号标签（如成功段末端即停止位置）。
  • 状态语义：低 SS 表示执行中（此时 FS 升高代表可恢复失败）；高 SS + 低 FS 表示成功；高 SS + 高 FS 表示终止性失败；块内取均值得到标量估计，并按阈值 δs、δf 分类。
  • 四类数据的监督规则不同：成功/恢复示范提供动作监督（失败动作被排除出模仿），恢复段仅监督非填充位置；恢复段的 FS 目标用随恢复进度线性下降的二值序列构造。
  • 注意力控制：动作 token 关注多模态前缀与两个信号组，信号 token 关注动作 token；阻断 SS–FS 双向注意力以保持语义分离。
  • 异步去噪：将 flow time 从每样本一个值扩展为每 token 一个值，信号组使用 τq = max(0, (τA − τclean)/(1 − τclean))，使其在动作去噪结束前达到干净端点并保持固定。
  • 损失为三组（A/S/F）掩码加权的速度匹配均方误差，λ 权重用于平衡有/无填充样本数量。

Card 06 评估与结果

评估与结果

  • 评估环境：五个真实世界操作任务，每个模型每任务 30 次试验；SS/FS 判定阈值均为 0.5，轨迹级决策窗口为 15 帧（0.2 s 推理间隔下约 3 s）。
  • 评估指标：Task Completion Score（0–10 归一化分数）、帧级 Macro-F1（与进行中/成功/失败逐帧标注比对）、轨迹级 F1（固定窗口内是否正确识别结果），报告均值 ± 标准误。
  • 主结果（Echo vs. 仅动作 π0.5 分数）：Insert Flower 5.67 → 8.33、Insert Pen 6.87 → 8.60、Open Drawer 5.40 → 7.90、Make Tanghulu 4.33 → 5.33、Capsule Toy 8.40 → 8.57。
  • 状态预测精度：各任务帧级 F1 约 88–92%，轨迹级 F1 约 90–100%（Capsule Toy 达 100.00 ± 0.00）。
  • 方法对比（Insert Flower）：CycleVLA 得分 3.00、帧级 F1 43.10、轨迹级 F1 36.67；VLA-Corrector 得分 5.67；Echo 得分 8.33、帧级 F1 92.18、轨迹级 F1 96.67。
  • 消融与机制分析涵盖域内/分布外（OOD）表现、组件消融、信号干预验证状态信号对动作生成的影响，以及失败数据数量的扩展性；仿真实验见附录 A.10。
