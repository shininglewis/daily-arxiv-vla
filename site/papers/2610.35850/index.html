Card 03 核心贡献

核心贡献

  • 提出 OSWAM：学习紧凑的 imagination tokens（想象令牌）作为动作 DiT 的结构化起点，单次前向即可获得，开销可忽略，单步去噪解码出高质量动作。
  • 引入 Action Imagination Tokens（AIT） 与 Scene Imagination Tokens（SIT） 两组令牌，在 Video DiT 中与首帧视觉特征交互，分别编码动作先验与场景上下文。
  • 提出 特权信息蒸馏（privileged-information distillation）：教师模型关注完整未来视频片段，学生（OSWAM）推理时仅用首帧，从而在不引入未来特征的前提下迁移长时程上下文。
  • 设计 Role-aware 3D RoPE，用不同空间锚点显式区分视频令牌、AIT 与 SIT，同时保持动作与视频潜空间的时间对齐。
  • 在自动驾驶与具身控制两类任务上验证：相对 direct-policy WAM 基线约 3× 加速，RTX 5090 上编译后延迟低至约 40 ms。
Card 04 方法描述

方法描述

  • 骨干：Video DiT 采用 Wan2.2-5B 预训练视频生成模型，配 T5 文本编码器与视频 VAE；Action DiT 由 Video DiT 权重插值下采样初始化，整体为 Mixture-of-Transformer（MoT） 结构，视频块与动作块共享注意力。
  • AIT：由动作噪声经编码器构造并赋固定时间步 t_max，在 Video DiT 内关注首帧视觉令牌、SIT 与其他 AIT，经辅助解码器得到动作速度，形成结构化先验；再按 σ_r = τ_r / t_max 重新加噪，交给 Action DiT 单步精修。
  • SIT：独立高斯噪声初始化，锚定在视觉网格中心，作为场景上下文槽位供 AIT 关注，梯度经注意力从 AIT 间接回传。
  • Role-aware 3D RoPE：视频令牌保留原始时空坐标，AIT 分配网格外空间坐标，SIT 锚定网格中心；AIT/SIT 与动作位置共享时间坐标 t_n = n·s_a/(s_v·d_t)。
  • 特权蒸馏：冻结教师（Video DiT + AIT）在完整未来视频潜变量（未来帧按固定时间步加噪）条件下前向，学生与教师共享同一视频/动作噪声样本，在 Video DiT 第 [8,16,24,30] 块后做多深度特征对齐。
  • 训练目标：L = L_vid + L_AIT + λ_dist·L_dist + L_act，其中 λ_dist = 10；L_act 以 σ_r^{-1} 缩放残差，保证一次欧拉更新即可从结构化初值直达真实动作。
  • 关键设置：AIT 时间步 t_max = 1000，重加噪时间步 τ_r = 500（σ_r = 0.5）；蒸馏在第 500 步后启动并在随后 500 步线性升温；imagination token 使用 rank 8、α=4 的 LoRA 适配。
Card 05 数据集与资源

数据集与资源

  • NAVSIM（自动驾驶）：2 Hz 真实驾驶数据，8 路相机 360° 视野 + LiDAR；1192 个训练场景、136 个测试场景；单前视相机 384×672，预测 4 秒内 8 个路点，训练用当前帧 + 8 帧未来。
  • RoboTwin 2.0（具身控制）：50+ 双臂操作任务；2500 条干净场景示范 + 25000 条强随机化示范；头部与双腕视图拼接为 384×320，动作时域 32，采样 9 帧视频、时间步长 4。
  • 模型规模：基于 Wan2.2-5B（约 5B 参数）视频 DiT；Action DiT 隐层维度降为 1024；LoRA rank 8。
  • 训练配置：AdamW，学习率 1e-4，权重衰减 0.01，余弦衰减 + 5% 线性预热；NAVSIM 训练 40,000 步、全局 batch 256；RoboTwin 训练 29,335 步、全局 batch 1024。

Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM navtest 使用 PDMS（由 NC、DAC、TTC、Comfort、EP 加权组合）与推理延迟；RoboTwin 2.0 在 Clean 与 Randomized 两种条件下各任务 100 次试验的平均成功率。
  • NAVSIM：PDMS 90.3，延迟 136 ms；与 SimWAM PDMS 持平但动作去噪从 10 步降为 1 步，加速 3.01×；比 Metis 高 1.2 PDMS 且快 3.24×；比 DriveVA 快 4.36× 而 PDMS 仅低 0.2。
  • RoboTwin 2.0：平均成功率 90.00%（Clean 90.04 / Rand. 89.96），延迟 142 ms；相对 Fast-WAM 加速 2.80×，成功率仅降 1.83%；相对单步 Flash-WAM 提升 8.59% 且加速 4.29×；比 Light-WAM 多 35 ms 延迟但成功率大幅提升。
  • 推理效率：RoboTwin 上动作 GPU 时间由 67.61 ms 降至 6.78 ms，视觉 GPU 时间增加 5.48 ms，总体延迟 323.67 → 95.35 ms（3.39×）；NAVSIM 上总体延迟 330.8 → 99.70 ms（3.32×）；启用 torch.compile + CUDA Graph 后分别为 40.81 ms 与 52.64 ms，支持 10 Hz 以上推理。
  • 消融：基线 PDMS 71.04 → 加入 AIT 89.81 → 加入蒸馏 89.96 → 加入 SIT 90.28（ADE 从 1.049 降至 0.587）；RoboTwin 上对应成功率 57.38/55.80 → 87.42/88.16 → 89.42/89.62 → 90.04/89.96；另对蒸馏权重 λ_dist 做了敏感性分析。
