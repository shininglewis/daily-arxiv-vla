Card 03 核心贡献

核心贡献

  • 引入 能力感知仲裁策略，联合使用语义意图置信度和执行能力置信度来分配控制权。
  • 开发 人类-VLM-VLA 共享控制框架，集成 VLM 置信度校准、贝叶斯意图滤波和在线 VLA 能力估计。
  • 在 ID 和 OOD 条件下评估 VLM/VLA 置信度以及共享控制性能，验证方法有效性。
Card 04 方法描述

方法描述

  • VLM 语义意图推断：从候选指令集中选择操作指令，使用温度缩放校准置信度，并通过递归贝叶斯滤波减少意图切换。
  • VLA 能力置信度估计：从 VLA 采样多条随机动作轨迹，计算轨迹分散度 \(D_t\) 和局部不稳定性 \(A_t\)，归一化后映射为能力置信度 \(\beta_t\)。
  • 能力感知仲裁：通过 sigmoid 映射将意图置信度 \(\alpha_t\)、能力置信度 \(\beta_t\) 和命令分歧 \(\delta_t\) 结合，得到机器人权限 \(w_R(t)\)，并混合人类与 VLA 命令。
  • 创新点：同时考虑意图置信度和执行能力置信度，避免过度帮助；在线估计 VLA 能力置信度；非线性仲裁策略平滑过渡控制权。
Card 05 数据集与资源

数据集与资源

  • 机器人平台：六关节 LeRobot SO-101 机械臂，两个 Nintendo Switch Joy-Cons，顶部和腕部 RGB 相机。
  • 任务：5 个指令（3 个拾取放置、2 个堆叠方向），使用立方体和 LEGO，分为 ID 和 OOD 条件。
  • 数据：收集 400 个 ID 演示（每个指令 80 个），按 episode 划分训练/验证/测试集。
  • 模型：VLM 使用 Moondream3（rank-8 LoRA 适配，冻结主干）；VLA 使用 SmolVLA（在相同数据集上微调）。
  • 参数：VLA 采样 \(M=4\) 条轨迹，每条 \(S=50\) 个路点；参考尺度 \(D_0=12.167\,\text{mm}\)、\(A_0=6.909\,\text{mm}\)。
Card 06 评估与结果

评估与结果

  • 评估环境：人类研究，12 名参与者（年龄 \(38.08\pm15.13\) 岁，5 女 7 男），IRB 批准，ID 和 OOD 条件下拾取放置与堆叠任务。
  • 对比基线：手动遥操作 (Manual)、固定 50/50 混合 (Fixed 50/50)、仅语义意图置信度 (Semantic Intent)、提出的 Sem-Cap。
  • 评估指标：任务成功率、完成时间、轨迹平滑度（RMS jerk）、控制友好度、权限加权分歧 (AWD)、问卷评分（Q1–Q10）。
  • 关键结果：Sem-Cap 总体成功率 92%（ID 100%，OOD 83%），显著高于 Manual (83%)、Semantic Intent (44%)、Fixed 50/50 (10%)。
  • 控制质量：Sem-Cap 控制友好度最高 (0.714)，AWD 最低 (0.035)，轨迹平滑度优于其他辅助方法（8.68 vs. 12.13 vs. 9.47 \(\text{m}\,\text{s}^{-3}\)）。
  • 主观评价：Sem-Cap 在 Q1–Q8 平均 3.66，Q9–Q10 平均 3.00，显著优于两种辅助基线，与 Manual 差异不显著。
  • 置信度评估：VLM 校准将 ECE 从 39.67% 降至 7.62%，贝叶斯滤波将错误切换率从 3.84% 降至 1.05%；VLA 能力置信度随微调步数增加，且 ID 高于 OOD。
