论文概述

  • 提出 CF-Prune，一个免训练（training-free）框架，用于在预训练的 World Action Models (WAMs) 中剪枝未来帧（future-frame）token，以降低推理延迟。

Card 03 核心贡献

核心贡献

  • 重新审视 WAM 中未来帧的辅助性作用，从动作预测的角度构建 token 剪枝问题，揭示了传统视频生成中未考虑的冗余性。
  • 提出 CF-Prune 框架，无需额外训练：利用未来帧 token 相对动作与指令 token 的信息集中度，从高噪声的初始潜变量中识别冗余 token，并基于跨视角与时间维度的注意力熵差异选择性放宽剪枝。
  • 在 RoboLab、RoboCasa 仿真基准以及真实世界操作任务上进行了广泛评估，在保持操作性能的同时一致提升推理效率。
Card 04 方法描述

方法描述

  • 基于注意力的未来帧 token 剪枝：在初始去噪前向传播中计算 token 相关性并完成选择，之后整个去噪过程沿用该剪枝。
  • 指令空间先验（Instruction-Based Spatial Prior）：利用观测 token 到指令 token 的注意力（观测无扩散噪声）获取指令相关区域的空间先验；通过归一化熵（熵越低表示相关性越集中，取值范围 [0,1]）选择剪枝层。
  • 动作视觉相关性（Action-Based Visual Relevance）：动作 token 到视觉 token 的注意力衡量动作生成对各视觉区域的关注；对腕部视角（wrist view）按每个未来帧分别计算，对第三人称固定视角（third-person view）在所有未来帧上共享动作到观测的注意力分数。
  • 层选择（Layer Selection）：层间熵分布在不同任务与 rollout 阶段保持相似，因此在每个环境的首次策略查询时确定评分层（$ \ell_{inst}$、$ \ell_{act}$）后固定使用，避免重复选择。
  • 空间平滑（Spatial Smoothing）：将聚合注意力分数重塑为 2D 空间图并施加 5×5 高斯模糊，使相关性扩散到邻近 patch，鼓励空间连续的 token 选择（借鉴 EADP）。
  • 动作–指令互补选择：先按动作相关性保留 top $(1-\alpha)/2$ 比例的 token（动作优先），再排除已选 token 后按指令相关性保留另外 $(1-\alpha)/2$，共保留 $1-\alpha$ 比例。
  • 基于熵的阶段识别（Entropy-Based Phase Identification）：定义熵对比分数 $C=C_{view}+C_{temp}$，其中 $C_{view}=\mathcal{H}_{third}-\mathcal{H}_{wrist}$ 度量朝向夹爪的注意力集中程度，$C_{temp}=\mathcal{H}_{early}-\mathcal{H}_{late}$ 捕捉动作对后续帧注意力定位增强；当 $C>\tau$ 时判定为精度阶段（precision phase），此时禁用剪枝，仅在粗略阶段（coarse phase）应用剪枝。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboLab（64 个 Simple、39 个 Moderate、17 个 Complex 任务，每任务 10 次 rollout）、RoboCasa（每类选一个代表任务，每任务 100 次 rollout）。
  • 真实世界任务：Franka Emika Panda 平台上的三个桌面操作任务——按急停按钮、方块拾取放置、方块堆叠；物体在 50×50 cm 区域内随机摆放，使用腕部相机 + 两个固定相机（右视、前视），每任务 25 次 rollout，每任务采集 60 个成功演示。
  • 基础模型：Cosmos3（Cosmos3-Nano-Policy-DROID）；RoboLab 使用 DROID 数据集预训练权重且不额外训练；RoboCasa 微调 16,000 步、batch size 1,024；真实世界使用 LoRA 微调。
  • 训练/推理资源：延迟测量在 NVIDIA RTX A6000 GPU 上、相同推理设置下进行；剪枝仅在推理时应用，无需额外训练。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboLab、RoboCasa 仿真环境 + 真实机器人平台；指标包括各任务与各难度层级的成功率、粗阶段/平均推理加速比、FLOPs 降低比例。
  • 对比方法：Dense 基线、SpecPrune-VLA（适配 WAM，Obs-only 70% 与 Obs + future 25% 两个变体）、SP-VLA（同两个变体）、Sparse VideoGen（稀疏化注意力连接）。
  • RoboLab 结果：$\alpha=35\%$ 时平均 1.23× 加速、FLOPs 降低 26.8%，总体成功率从 36.5% 提升至 37.8%；$\alpha=50\%$ 时 1.33× 加速、FLOPs 降低 38.3%，成功率仅下降 0.8 个百分点；Sparse VideoGen 因 profiling 开销反而比稠密基线更慢。
  • RoboCasa 结果：$\alpha=35\%$ 时平均 1.19× 加速、FLOPs 降低 15.6%，总体成功率从 65.0% 提升至 69.0%；$\alpha=50\%$ 时 1.29× 加速、成功率 64.0%（低于基线 1.0 个百分点），其中导航任务对激进剪枝更敏感（38.0%→18.0%）。
  • 真实世界结果：$\alpha=35\%$ 时三个任务成功率为 88.0%、96.0%、88.0%，总体 90.7%（基线 85.3%），粗阶段加速 1.37×、平均加速 1.27×。
  • 消融实验：动作–指令互补选择（action-first）达 35.3%，优于仅指令（34.0%）、仅动作（30.8%）、指令优先（34.3%）；阶段识别将成功率从 35.3% 提升至 37.8%，且仅 31.4% 的推理调用被判定为精度阶段，仍保有 1.23× 平均加速；高斯平滑将成功率从 36.0% 提升至 37.8%，计算开销可忽略。
