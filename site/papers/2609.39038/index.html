Card 02 论文概述

论文概述

  • 论文提出 TeV（Temporal Verification），一种面向 flow-matching VLA 策略的高效、具备时间感知能力的动作验证框架，用于生成式机器人策略的测试时扩展（test-time scaling）。

Card 03 核心贡献

核心贡献

  • 提出 temporal token，压缩近期「观测–动作」历史，使候选动作块被评估为执行轨迹的延续而非孤立预测，并采用动态感知的辅助未来动作预测目标进行正则化。
  • 设计基于能量的对比式验证器训练，无需额外专家演示或偏好标注：以专家动作为正样本，构造时间错配负样本与粗积分负样本两类互补负例。
  • 首次将验证从「事后排序」扩展到「生成时引导」：利用学到的能量梯度在 flow 积分过程中将中间样本导向低能量区域，再做最终候选选择。
  • 极轻量：参数量增加不到 0.15%，可作为 flow-matching VLA 的即插即用模块。
  • 在仿真与真实环境中一致提升任务成功率 6–18 个百分点，并产生更平滑的执行轨迹。
Card 04 方法描述

方法描述

  • Temporal Token Learning：从预训练 VLM 主干提取每帧观测 token，投影到潜空间并加入可学习读出 token，经轻量双向 Transformer 得到观测摘要；再与前一执行动作配对，由因果时序 Transformer 生成 temporal token，并用未来动作预测损失 $\mathcal{L}_{\tau}$ 进行动态感知正则化。
  • Contrastive Verifier Training：以时序 token 为条件，训练轻量能量模型 $E_{\theta}$，用 margin-based 排序损失使专家动作块能量低于负样本至少一个 margin。
  • 两类负样本：❶ 时间错配负样本（同一回合中时间距离 $\ge \delta$ 的专家动作块）；❷ 粗积分负样本（用更少 Euler 步 $n
  • Verification as Guidance：在 Euler 更新中加入能量梯度项 $-\frac{\eta_s}{N}\nabla E_{\theta}$，引导强度 $\eta_s$ 从 $\eta$ 线性衰减至 0，早期施加较强引导、后期恢复基础策略的精细细化。
  • 最终按最小能量 $\arg\min_m E_{\theta}(\mathbf{z}_1^{(m)} \mid \boldsymbol{\tau}_t)$ 选择候选动作块执行。

Card 06 评估与结果

评估与结果

  • 评估基准与对比方法：Random selection、Temporal Ensembling（TE）、Bidirectional Decoding（BID）、TACO / TACO*（M=50）、V-GPS、LPB、DynaGuide、FOREWARN。
  • LIBERO-Plus（Table 1）：TeV 平均成功率 79.8%，优于 Base（73.2%）、TACO（76.0%）、FOREWARN（75.0%）；在 Camera（48.4）、Language（91.9）、Light（84.7）、Background（95.8）、Layout（92.6）等扰动上取得最佳。
  • RoboTwin 2.0（Table 2）：TeV 平均 81.3%，优于 Base（72.3%）与最强基线 TACO*（69.7%）；Adjust Bottle 95.0%、Place Container 94.0%。
  • 真实环境（Table 4，任务完成分数）：Bottle to Bag 69.3±26.7（Base 60.7）、Cup Transport 88.3±15.9（Base 79.8）、Water Filling 68.0±12.8（Base 40.5），均优于 BID 与 TACO。
  • 消融结论：仅验证即可稳定提升；单独使用引导可能显著退化，但「验证+引导」在 RoboTwin 2.0 上从 72.7% 提升至 75.1–77.3%；两类负样本组合（81.3%）优于单一负样本（78.1% / 77.4%）；候选数 M 增大并不单调提升性能；学习到的 temporal token 优于 Zero/Random/Frozen 变体。
  • 机制分析：验证器在超过 70% 的情况下选中与专家动作块潜空间距离最近的两个候选之一；TeV 产生更低 jerkiness 的更平滑关节速度/加速度曲线，减少洒水、掉落等失败。
