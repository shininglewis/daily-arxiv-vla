Card 03 核心贡献

核心贡献

  • 构建了面向 WAM 泛化能力的三轴评估协议：环境扰动（LIBERO-Plus 七类扰动因子）、数据效率（每任务减少示范数）、任务泛化（四折交叉验证 + 无动作视频迁移）。
  • 发现一（Finding 1）：缺乏推理时未来建模会导致泛化能力显著退化——隐式 WAM 在分布内仅差 0.9 分，但在三个泛化轴上分别落后 13.97、8.45、64.00 分。
  • 发现二（Finding 2）：完全加噪的未来（fully noised future）已足以恢复几乎全部泛化增益，收益几乎全部来自第一次去噪的前向传播，而非生成清晰未来帧。
  • 提出 Simple-WAM：在推理时对完全加噪的未来视频 token 只做一次前向传播，并配套训练时的混合流时间采样策略（概率 p=0.5 采样 τ=1）。
  • 证明 Simple-WAM 在仿真与真实世界中同时实现显式范式的泛化性能与隐式范式的推理效率，打破"泛化 vs 效率"的固有取舍。
Card 04 方法描述

方法描述

  • 基础设定：WAM 由视频专家（参数 θ，从预训练视频生成器初始化）与动作专家（参数 ψ）组成，视频专家读取当前帧与未来帧的 latent 序列 $Y_t^{\tau}=[y_t; y^{\tau}_{t+1:t+T}]$，动作专家回归动作速度场。
  • 显式范式：保留未来 video token 并把流时间 τ 从 1 去噪到 0，代价为 $K C_{vid} + K C_{act}$。
  • 隐式范式：推理时丢弃未来 token，仅单次前向传播，代价为 $C_{cur} + K C_{act}$。
  • Simple-WAM 推理：未来视频 token 以纯高斯噪声（τ=1）保留在上下文中，视频专家只前向一次，其特征 $c_{t,k}=\Phi_\theta(Y_t^{\tau=1})$ 条件化全部 K 个动作去噪步，代价为 $C_{vid} + K C_{act}$。
  • Simple-WAM 训练：采用混合调度，以概率 p 将未来 token 的流时间采样为 τ=1，其余 (1−p) 按原调度 $\mathcal{S}(u)$ 采样，在不新增模块或损失项的前提下对齐推理行为。
  • 关键创新点：证明泛化收益来自"准备（preparing）"未来而非"生成（generating）"未来，且加噪 token 与视频预训练分布一致，因而最大化利用了视频先验。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（四个套件，每套 10 任务 / 500 专家示范）、LIBERO-Plus（七类扰动因子）、RoboTwin 2.0（双臂操作基准，含干净与随机场景）。
  • 真实世界平台：AgileX Aloha 双臂机器人，4 个任务（Stack the Bowls、Store the Blocks、Sort in Row、Move in Order），每任务 200 条示范，全局 batch size 512，每任务 30 次试验。
  • 模型规模：预训练 Wan2.2-5B 视频 DiT 作为视频主干，1B 动作专家（从视频 DiT 插值初始化）；动作块长度 H=32，每个 chunk 使用 9 帧视频。
  • 训练与推理配置：视频损失权重 λ=3.0，K=10 步去噪，CFG scale=1.0；训练使用 NVIDIA A800 GPU，延迟测量使用单张 NVIDIA GeForce RTX 5090。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、LIBERO-Plus、RoboTwin 2.0 仿真基准 + AgileX Aloha 真实机器人，在三个泛化轴上与匹配基线的显式 / 隐式 WAM 及 VLA 模型对比。
  • 主要指标：任务成功率（%）、每动作 chunk 推理延迟（ms）。
  • 仿真关键结果：

- 环境扰动平均 79.5（Simple-WAM） vs 67.7（显式）vs 53.8（隐式），在 7 个因子中 6 个最优。

- 数据效率：LIBERO 5-shot 92.4、10-shot 97.2，RoboTwin 10-shot 37.2（隐式仅 4.8）。

- 任务泛化：LIBERO 无视频 10.1 / 有视频 73.6；RoboTwin 6.2 / 44.5。

  • 效率结果：每 chunk 延迟 74.7 ms，比显式范式（286.9 ms）快 3.8×，与隐式范式（62.0 ms）仅差 12.7 ms（约 1.2×）。
  • 真实世界结果：分布内三者相差 2.3 分以内；环境扰动下 Simple-WAM 保持 69.2（隐式仅 25.2）；50 条示范下保持 69.6（隐式 37.2）；未见任务 *Store in Order* 借助无动作视频从 2.2 提升至 87.8（显式 68.9，隐式 10.0）。
  • 消融结论：p=0.25/0.5/0.75 三轴平均仅差 1.3 分，端点 p=0（90.8）与 p=1（88.6）均下降；将噪声未来 token 替换为可学习 query 或零向量会使三轴平均从 94.2 跌至 52.7 与 54.9，验证"与预训练对齐的加噪条件化"是关键。
