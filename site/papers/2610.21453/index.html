Card 03 核心贡献

核心贡献

  • 提出 CarryOn 双环 harness，在不更新底层 VLA 权重的前提下连接上下文敏感任务决策与可靠物理执行。
  • 规划环维护持久用户记忆和场景记忆，并结合对话与观测进行修订，支持跨交互、跨场景、跨查询模态的个性化任务决策。
  • 执行环结合主动几何屏蔽与可重用、可迭代精炼的恢复技能，在危险接触前过滤动作，在失败后修复物理状态。

  • 通过离线反思与重试轮次，将恢复成功率从 13% 提升至 80%，并在多个策略骨干上验证屏蔽的泛化性。
Card 04 方法描述

方法描述

  • 规划环：给定请求和可选参考图像，规划器结合用户记忆 M^u、场景记忆 M^s 与可用技能描述生成计划；每个子任务包含指令、端点和依赖关系。
  • 记忆更新：用户记忆从对话中提取长期偏好并支持替换/删除；场景记忆从观测中更新，若观测发现目标位置陈旧，运行时会要求执行 update_scene 操作，否则计划验证器会打回重规划。
  • 执行环：冻结的 VLA 根据观测和子任务指令预测动作块；Visual Judge 根据摄像头图像判断子任务为 running、success 或 failed。
  • 主动屏蔽：使用 RGB-D 观测构建抓手和所携带物体的障碍集，通过阻尼动力学预测末端执行器运动，并按最小距离阈值过滤动作；若第一个动作即被阻挡，则执行短距离撤退。
  • 反应恢复：失败时挂起 VLA，调用基于控制的恢复技能，依次进行观察、重定位、抓取、抬升验证、运输验证与恢复原任务；若失败，则尝试返回预抓取位姿或失败前位姿。
  • 离线反思：使用参数记忆 P 记录数值调整，使用策略记忆 S 记录控制流修改；经验证后形成新版本恢复技能库，VLA 权重保持不变。

Card 06 评估与结果

评估与结果

  • 个性化规划：真实机器人三明治准备中，Textual 和 Memory 条件均为 24/24，偏好更新后为 20/24；活动相关打包中，Memory 为 16/16，No-habit 为 16/20，Isolation 为 16/18。
  • 场景记忆：隐藏食材任务中，Write and retrieve 为 12/12，Search without memory 为 8/10，Revise stale memory 为 9/12；RoboLab 中记忆提高文本/图像查询正确率并降低延迟。
  • 安全执行：π0.5-SFT 的违反率从 52.6% 降至 6.1%，违规无任务成功率 VF 从 25.3% 到 25.6%；原始 π0.5 违反率从 71.1% 降至 22.7%，VF 从 6.7% 升至 14.6%。
  • 跨骨干泛化：OpenVLA-OFT + Ours 违反率为 17.2%，VF 为 14.8%；VLAct + Ours 违反率为 26.1%，VF 为 13.9%。
  • 真实安全执行：插入障碍物后，无屏蔽策略接触自由完成率为 0/20，带屏蔽策略为 20/20。
  • 恢复与改进：LIBERO-Object 扰动实验中，纯 VLA 为 13.0%，R0 为 29.0%，R1 为 70.5%，R2 为 80.0%；LIBERO-Recovery 770 例中，纯 VLA 为 32.08%，R0 为 50.00%，R1 为 73.90%，R2 为 76.10%。
  • 真实恢复：对象移除后，原始策略为 3/20，基础恢复为 9/20，修订技能为 18/20。
  • 综合任务：真实食物服务中，系统结合场景记忆开盖、屏蔽避障、恢复掉落抓取，并在发现肉与素食偏好冲突时更新场景记忆并拒绝服务。
