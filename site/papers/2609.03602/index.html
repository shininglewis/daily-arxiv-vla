SV-WAM: An Efficient Surround-View World-Action Model for End-to-End Autonomous Driving

2026-09-03 · 原文 · 翻译 · 2609.03602

论文提出 SV-WAM，一个高效的环视（surround-view）世界-动作模型（World-Action Model, WAM），用于端到端自动驾驶规划，保留完整六摄像头观测的同时避免推理阶段的高开销未来视频生成。 现有世界模型规划器大多在推理时生成未来视频，导致延迟高，因此通常只使用单前视摄像头，缺乏变道、汇入、转弯等安全关键场景所需的侧向与后方空间感知。 SV-WAM 将未来视频预测作为训练时的稠密监督信号而非推理输出，通过共享生成模型联合去噪未来动作与未来视频潜变量，从而在部署时只保留低延迟的动作推理路径。

Card 03 核心贡献

核心贡献

  • 提出 SV-WAM，利用行动中心因果掩码（Action-Centered Causal Mask）协作训练未来动作与六视角未来视频潜变量，使动作分支不依赖未来视频 token，从而在部署时移除视频分支，实现保留全六视角条件的纯动作推理（Action-Only Inference）。
  • 设计可微的可行驶区域合规正则化器（Drivable-Area Compliance Regularizer），对车辆足迹角点靠近或越过可行驶边界的行为进行平滑惩罚，提升规划安全性和边界感知能力，且不增加推理成本。
  • 在闭环 NAVSIMv2 基准上取得最优 EPDMS 91.0，在 nuScenes 零样本迁移下取得平均 L2 误差 0.89 m、碰撞率 0.16%，并具有低推理延迟。
Card 04 方法描述

方法描述

  • 输入 Tokenization：将六路摄像头图像按宽度方向拼接，使用冻结的 Wan2.2-TI2V-5B 3D 因果 VAE 编码历史与未来视频；通过共享视频 tokenizer 得到参考视频 token 和未来视频 token，并用 MLP 将 8 维 ego 状态历史与未来动作序列映射为状态 token 与动作 token。
  • 环视世界-动作模型：在共享的 DiT（Wan2.2-5B） 骨干上采用 flow matching 联合去噪未来动作和未来视频潜变量；掩码设计使动作 token 只能关注状态和参考视频 token，而未来视频 token 可关注动作 token，从而形成 p(A\|Ω) · p(Z_fut\|Ω,A) 的因果分解，支持训练时视频协同监督、推理时动作独立采样。
  • 可行驶区域合规正则化：利用二值可行驶区域图构造符号距离场，将预测动作经 NAVSIM LQR 轨迹跟踪器展开为车辆位姿序列，采样车辆四角符号距离，用 soft-margin 惩罚和 log-mean-exp 聚合，突出高风险越界足迹。
  • 高效推理：推理时省略未来视频噪声 token，仅保留 [状态, 参考视频, 动作噪声] 序列；复用缓存的条件前缀 KV，采用两步动作去噪即可输出轨迹。
Card 05 数据集与资源

数据集与资源

  • 主要评估数据集：NAVSIMv2（闭环规划，EPDMS 指标）、nuScenes（开环 L2 与碰撞率零样本迁移），并在附录报告 NAVSIMv1 与 navhard 结果。
  • 输入配置：历史 H=4 帧、六摄像头（前左、前、前右、后右、后、后左），每视角分辨率 448×224，时间采样间隔 2 Hz。
  • 动作/视频设置：预测 12 个未来动作 token，训练监督为 12 帧六视角未来视频潜变量。
  • 训练资源：16 块 NVIDIA H800 GPU；阶段一 10k 迭代（batch 80，lr 1e-4），阶段二微调 1k 迭代（有效 batch 640，lr 1e-5 衰减至 1e-6），每阶段约 1 天。
  • 推理硬件：单块 NVIDIA H20 GPU 上报告 342 ms 延迟（预处理输入至轨迹输出）。
Card 06 评估与结果

评估与结果

  • NAVSIMv2（闭合环 navtest）：C×6（六视角）版本达到 EPDMS 91.0，显著优于 EponaV2（88.9）、PWM（88.2）、DriveLaW（88.9）、WoTE（87.7）等基线；DAC 达 98.8、DDC 99.6、TLC 99.9、EC 88.4。
  • nuScenes 零样本迁移：不经过 nuScenes 微调时，SV-WAM 实现平均 L2 误差 0.89 m、平均碰撞率 0.16%，均优于同为零样本的 DriveVLA-W0（1.43 m / 0.77%）和 PWM（3.99 m / 0.36%），并可与部分域内微调方法竞争。
  • 组件消融：仅视频联合监督使 EPDMS 由 83.1 提升至 87.7；加入可行驶区域正则化提升至 90.1（DAC 从 95.6 升至 98.6）；最终微调后达到 91.0 EPDMS。
  • 效率表现：在单 H20 GPU 上以六视角输入取得最好的 EPDMS 与最低延迟，验证了“训练时世界模型、推理时纯动作”的高效方案。
