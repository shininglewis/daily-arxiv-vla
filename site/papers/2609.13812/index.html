Card 02 论文概述

论文概述

  • 提出 GeomVLA，一种在共享机器人中心 3D 坐标系中统一感知、潜在场景运动预测与动作生成的 Vision-Language-Action（VLA） 模型。
  • 针对现有 VLA 多依赖 2D 图像表示、而机器人操作需要 3D 几何/接触/运动推理的失配问题，将 2D VLM 特征提升到 3D 空间，并引入未来 3D 场景运动作为中间推理信号。
  • 核心观点：仅做未来运动预测不够，关键在于让 场景表示、运动推理和机器人动作 在整个感知到动作流程中保持几何一致性。
Card 03 核心贡献

核心贡献

  • 提出 GeomVLA 框架，在统一 3D 坐标框架下联合场景表示、潜在未来运动推理和动作生成。
  • 设计 3D Scene Trajectory Denoiser，以任务/语言为条件，直接在 3D 空间预测未来场景点运动，并通过几何感知注意力向动作生成提供中间运动 token。
  • 在 CALVIN 上取得 SOTA，在 LIBERO、RoboTwin2.0 上取得有竞争力结果，并在无机器人动作预训练的真实世界操作任务中优于强基线。
  • 通过大量消融表明：几何一致性（而非单纯未来运动预测或特定坐标系）是性能提升的主要来源，且 3D 一致性在笛卡尔动作和关节角动作参数化下均有效。
Card 04 方法描述

方法描述

  • 使用预训练 Florence-2 VLM 编码多视角 RGB 与语言指令，结合深度和相机标定将 patch 视觉 token 提升为机器人基座坐标系下的 3D 场景 token。
  • 3D Scene Trajectory Denoiser：基于条件 flow matching，对前视图 20×20 个 3D 锚点预测未来位移增量轨迹（时间下采样后 15 步，对应原始 45 帧），训练标签来自 SpatialTrackerV2 伪标签，采用运动加权 rectified-flow 损失。
  • 动作生成时，在初始流状态 τ=0 对轨迹去噪器执行一次速度场评估，提取中间运动 token，通过几何感知 cross-attention 融入场景 token，得到运动感知场景表示。
  • 3D Action Denoiser：基于 flow matching 预测末端执行器平移/旋转速度与夹爪开合状态；使用 3D RoPE、几何感知 Transformer 块、adaLN-FFN 等结构。
  • 可选 Joint Angle Denoiser：以语言特征、运动感知场景 token 和中间末端执行器动作特征为条件预测关节角命令，支持关节空间控制。
  • 两阶段训练：先冻结 VLM 训练 3D 场景轨迹去噪器；再联合微调动作去噪器、轨迹去噪器和 VLM，仅使用动作损失，无需机器人动作预训练。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：CALVIN、LIBERO、RoboTwin2.0（含 50 个任务及五任务子集评估）。
  • 真实世界平台：ALOHA2 机器人，使用 ViperX300S follower arm、WidowX250S leader arm 遥操作采集数据，配 Microsoft Azure Kinect DK 和 Intel RealSense D405 相机。
  • 模型规模：GeomVLA 约 1.2B 参数；GeomVLA-JA 约 1.3B 参数；2D-JA 基线约 1B 参数；使用公开 Florence-2 初始化，无机器人动作预训练。
  • 训练资源：CALVIN 约 15 小时 / 4×48GB NVIDIA L40S；LIBERO 约 25 小时 / 8×40GB NVIDIA A100；RoboTwin2.0 五任务设置约 48 小时 / 8×40GB NVIDIA A100。
  • 真实任务数据：8 个桌面操作任务，其中 3 个任务各 50 条演示，其余 5 个任务各 20 条演示。
Card 06 评估与结果

评估与结果

  • 评估基准：CALVIN、LIBERO、RoboTwin2.0 仿真，以及 ALOHA2 真实世界 8 任务。
  • 主要指标：CALVIN 平均连续完成任务数；LIBERO 各任务成功率与平均成功率；RoboTwin2.0 Easy/Hard 成功率；真实世界 20 次试验成功次数/平均成功率。
  • CALVIN 结果：4.624，优于 FLOWER（4.480）、X-VLA（4.430） 等方法，取得 SOTA，且无额外机器人动作预训练。
  • LIBERO 结果：平均 98.4%，在无 RL 微调方法中表现最佳；长时程和接触丰富任务提升明显。
  • RoboTwin2.0 结果：50 任务 Easy/Hard 成功率 78.6%/76.2%，超过全量微调 π0.5 的 75.9%/75.7%；五任务子集上 GeomVLA-JA 81.6% 优于 2D-JA 66.2%。
  • 真实世界结果：GeomVLA 平均成功率 62.5%，优于 GeomVLA w/o motion 44.4%、π0.5 29.4%、2D-JA 28.8%；GeomVLA-JA 59.4%，在插马克笔任务上表现突出。
  • 消融结论：完整模型 4.624 优于去掉运动模块的 4.508；图像空间运动 + 3D 动作降至 4.085；使用完全去噪轨迹（4.047）或完全去噪 latent（4.334）均不如使用早期运动 latent；采用任意统一刚体坐标系仍保持 4.596，说明几何一致性比特定机器人基座坐标系更关键。
