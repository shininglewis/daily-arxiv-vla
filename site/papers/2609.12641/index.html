Breaking the Vision-Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models

2026-09-11 · 原文 · 翻译 · 2609.12641

论文研究机器人基础模型（VLA 与 WAM）在视觉分布偏移下泛化能力下降的问题。 核心诊断：模型在从预训练视觉表征生成动作时，会利用训练分布中与动作相关的任务无关视觉线索，形成 vision–action shortcut（视觉–动作捷径），从而在分布偏移下失效。 目标是约束视觉信息被用于动作生成的方式，同时保留任务相关的空间信息（如末端执行器位置）。

Card 02 论文概述

论文概述

  • 论文研究机器人基础模型（VLA 与 WAM）在视觉分布偏移下泛化能力下降的问题。
  • 核心诊断：模型在从预训练视觉表征生成动作时，会利用训练分布中与动作相关的任务无关视觉线索，形成 vision–action shortcut（视觉–动作捷径），从而在分布偏移下失效。
  • 目标是约束视觉信息被用于动作生成的方式，同时保留任务相关的空间信息（如末端执行器位置）。
Card 03 核心贡献

核心贡献

  • 提出 Latent Interface Training（LIT）：一种模型无关（framework-agnostic）的两阶段训练策略，将无图像的空间目标条件动作预训练与姿态监督的潜在接口相结合。
  • 在四种架构（π0.5、MolmoAct2、FAST-WAM、ImageWAM）上验证 LIT 将 LIBERO-Plus 整体成功率提升 3.87–10.70 个百分点，同时保持或提升 LIBERO 平均成功率。
  • 通过消融与反事实分析证明 LIT 能缓解视觉–动作捷径，并保留任务相关空间信息（注意力更集中于机器人–物体区域，对目标变化仍能正确响应）。
  • 真实机器人实验显示，在未见相机配置、光照变化与干扰物条件下，三个操作任务总成功率的提升达 13.3–16.7 个百分点。
  • 提供项目主页：magiclab-nus.github.io/LIT
Card 04 方法描述

方法描述

  • 阶段 1（Spatial-Goal-Conditioned Action Pretraining）：动作专家从零训练，仅以语言、机器人状态和每个演示动作块的终端 SE(3) 末端执行器姿态 g_t ∈ R^8（位置 + 轴角 + 夹爪）为条件，学习无图像的空间目标条件动作先验；骨干网络及其模态编码器保持冻结。
  • 阶段 2（Vision–Action Interface Learning）：引入可学习潜在 token（K=100），通过自注意力、语义交叉注意力与视觉交叉注意力逐层聚合骨干的语义与视觉表征，作为预训练动作专家唯一的视觉条件通路。
  • 姿态重建监督：MLP 解码器从最终潜在 token 重建阶段 1 使用的同一终端姿态，损失 L_stage2 = L_act + λ_pose·L_pose，其中 λ_pose = 0.3。
  • 关键创新：共享的空间目标（终端姿态）连接动作先验学习与视觉接口学习，而"独占式"接口限制了视觉信息的使用方式。
  • 保留各框架原生的动作生成目标（如 flow matching）、动作表示与预测时域；接口通过架构原生的条件机制（层间共享参数，每 m 层共享注意力参数）注入。
  • 推理时潜在接口保持激活，姿态编码器与解码器被移除，仅需视觉观测、语言与机器人状态。
Card 05 数据集与资源

数据集与资源

  • 训练数据：LIBERO 原始演示（模型仅在原始 LIBERO 演示上训练，不做适配）。
  • 评测基准：LIBERO（Spatial、Object、Goal、Long 四个套件，共 40 个任务）与 LIBERO-Plus（7 类扰动，共 10,030 个扰动实例）。
  • 真实机器人任务：Keep LEGOs、Wipe trash、Transfer egg，每任务 100 条演示，共 300 条演示训练单一多任务策略。
  • 模型：接入 π0.5、MolmoAct2（VLA）与 FAST-WAM、ImageWAM（WAM）四种架构，基线随机初始化动作专家、使用相同预训练骨干。
  • 训练预算：LIT 阶段 1 用 10K 步、阶段 2 用 20K 步，与基线 30K 步总预算一致（MolmoAct2 设置）。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（success rate）；LIBERO 每任务 50 次 rollout（共 2,000 episode），LIBERO-Plus 每个扰动实例 1 次 rollout（固定随机种子）。
  • 分布内（LIBERO）：LIT 使 π0.5 平均成功率由 87.75% → 91.80%，MolmoAct2 由 93.50% → 94.10%，FAST-WAM 由 97.60% → 98.10%，ImageWAM 由 98.10% → 98.40%，无架构出现平均性能下降。
  • 零样本泛化（LIBERO-Plus Overall）：π0.5 68.97% → 79.67%（+10.70）；MolmoAct2 63.62% → 71.92%（+8.30）；FAST-WAM 51.44% → 60.63%（+9.19）；ImageWAM 83.02% → 86.89%（+3.87）。
  • 单项最大提升：FAST-WAM 在相机视角下 +27.43，MolmoAct2 在传感器噪声下 +21.74，π0.5 在相机视角下 +22.01；28 个架构–扰动对比中 26 个改善，最大下降不超过 2.11 个百分点。
  • 真实机器人：三任务聚合 ID 成功率由 74.7% → 88.0%；Lighting OOD 53.3% → 70.0%，Camera OOD 30.0% → 46.7%，Distractors OOD 50.0% → 63.3%；如 Wipe trash 的 Camera OOD 由 10.0% 提升至 80.0%。
  • 训练动态：阶段 1 动作损失 10K 步后降至 0.029，阶段 2 姿态重建损失 20K 步后达 0.003，且 LIT 用 20K 视觉训练步即超过基线 30K 步的最终动作损失（比值 0.63×）。
  • 消融：验证了阶段 1 动作预训练、姿态监督与"仅通过潜在接口进行视觉条件化"三者的必要性；去除阶段 1 或姿态监督的变体在 LIBERO-Plus 整体上均低于完整 LIT。
