Sensorimotor Alignment: A Platonic Proxy for Embodied Policy Success

论文概述

  • 论文将 Platonic Representation Hypothesis（PRH） 扩展到具身智能领域，提出“物理运动轨迹”也可视为世界的一种投影模态：具身模型能力越强，其视觉-语言（sensory）表征应越贴近机器人末端执行器轨迹（motor）的结构。

Card 03 核心贡献

核心贡献

  • 提出把 PRH 引入机器人领域的“具身版”观点，并给出可测量的 S² 指标：比较感官表征空间与运动表征空间中的 k 近邻集合重叠度。
  • 在 4 类具身模型上验证 S² 与下游任务成功率正相关：12 个 VLA、8 个原始 VLM、6 个 WAM、5 个真机策略，覆盖仿真与真实机器人。
  • 证明 S² 比替代指标更贴近任务成功：VQA 分数几乎不相关（r=−0.154），视频质量指标（SSIM/PSNR/FID）相关性弱甚至方向相反。
  • 用 S² 在表征层面解释此前仅靠闭环结果观察到的现象：模态主导（VLA 更依赖视觉而非语言）、冻结视觉编码器导致性能下降、WAM 可跳过迭代去噪、中层 block 最重要。
  • 验证 S² 对参考数据集、轨迹时域、实现细节、DTW 设置等选择具有鲁棒性，并在具身形态不匹配时按预期失效（负对照）。
Card 04 方法描述

方法描述

  • 参考数据集：从 DROID（Franka Panda）与 BridgeDataV2（WidowX）采样 N 个 episode，每个 episode 随机取一帧图像并配对任务指令，构成感官输入。
  • 感官表征：用模型（VLA/WAM 的视频生成器 latent 或 VLM）的视觉编码器与文本编码器编码，平均池化为 d 维向量。论文还按 token 位置拆分出视觉特征、文本特征、视觉-文本联合特征。
  • 运动表征：取该帧之后 h 步的末端执行器状态序列，包含位置 (x,y,z)、姿态 (φ,θ,ψ) 与夹爪状态 g，形状为 h×7；位置用 ℝ³ 向量、姿态用 SO(3) 旋转表示，使距离符合平移与旋转的几何。
  • 距离度量：感官空间用 余弦距离，运动空间用 Dynamic Time Warping（DTW） 以容忍不同速度。
  • 对齐估计：对每个 episode 取两侧 k 近邻集合的交集，除以 k 后对全部样本平均（式 1）；实际报告值用中心化、归一化的 CKNNA 变体，默认 k=10。
  • 创新点：不需要训练、不需要闭环交互，且显式把“机器人实际执行的运动”纳入表征质量评估。
Card 05 数据集与资源

数据集与资源

  • 参考数据集：DROID、BridgeDataV2（单臂）；ALOHA（双臂，用于 WAM）。
  • 评估基准：SimplerEnv（SimplerEnv-WidowX 任务成功率）、RoboTwin 2.0、MolmoB0T 报告的 40 个真机任务结果。
  • 模型规模：涉及 12 个 VLA、8 个原始 VLM 骨干（来自 VLM4VLA，如 Qwen2.5-VL-3B）、6 个 WAM（含 Motus、LingBot-VA、Vidar）、5 个真机策略。
  • 训练资源：论文未报告 GPU/TPU 规模；S² 本身为免训练指标，仅需前向推理。
Card 06 评估与结果

评估与结果

  • VLA：12 个 VLA 的 S² 与 SimplerEnv 成功率 Pearson r = +0.717，模型 bootstrap 95% 置信区间 [+0.436, +0.912]。
  • 原始 VLM：8 个骨干的 S² 与其后续微调成 VLA 的成功率 r = +0.681（单尾 p = 0.031）；同期 VQA 分数 r = −0.154，几乎无相关。
  • WAM：6 个模型在 ALOHA 上计算 S²，与 RoboTwin 2.0 成功率 r = +0.718（p = 0.054）；3 个可比模型上 S² 达 r = +0.999，而 SSIM r = +0.558、PSNR r = +0.468、FID r = +0.680（方向相反）。
  • 真机：5 个策略的离线 S² 与真机成功率 r = +0.831（p = 0.041）。
  • 鲁棒性：DROID 与 BridgeDataV2 上均约为 r ≈ +0.7；DROID 时域至 h=220、BridgeDataV2 h=3–40 时 r 均大于 0.5；把双臂 WAM 放在单臂 DROID 上（形态不匹配）后 r 从 +0.999 降至 +0.246。
  • 表征层面解释：微调后 VLA 的视觉 S² r = +0.694 ≈ 联合 +0.699，文本仅 +0.237；原始 VLM 则文本 +0.501 > 视觉 +0.425，联合最高 +0.681；冻结视觉编码器使 S² 下降 41%、成功率下降 40%；WAM 的 S² 在去噪全程仅波动约 6%，并在 30 层骨干的 Block 14 达到峰值。
