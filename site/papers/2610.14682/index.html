Card 02 论文概述

论文概述

  • 论文指出标准 VLN 评测只看成功率（SR）、路径效率（SPL）和轨迹相似度（nDTW），却不衡量与墙壁、家具的物理接触，导致"成功但危险"的导航被当作好结果。
  • 提出 VLN-Safe 基准，在连续环境 VLN-CE 下系统测量碰撞，并区分滑动（slide）与阻挡（block）两种模拟器碰撞处理机制。
  • 目标回答两个问题：P1 成功回合是否也避开了碰撞；P2 评测设置与碰撞定义如何影响测得的结果。
Card 03 核心贡献

核心贡献

  • 提出 VLN-Safe 基准，用脏成功率（DSR = 成功中存在碰撞的比例）量化成功与无碰撞之间的落差，并分析评测设置的敏感性。
  • 系统分析碰撞预测信号，比较策略自身输出（熵、top-two margin、停止概率）、深度几何与运动历史三类信号的可预测性。
  • 提出免训练碰撞守卫（training-free collision guard），在不改权重、不读策略分数的前提下否决危险前向动作、执行逃逸转向后再交还控制权。
  • 揭示只有 3 篇被调研的 VLN-CE 论文说明了所用碰撞机制，说明已发表成功率部分依赖于未记录的模拟器设置。
Card 04 方法描述

方法描述

  • P1 接触感知评测：以模拟器导航网格缩短指令位移作为碰撞标志 $\kappa_{\rho,t}$，定义碰撞步、碰撞事件、脏成功与干净成功，并报告碰撞步率、首次接触位置与深度净空剖面。
  • P2 敏感性分析：在slide与block两机制下对同一策略、同一回合、同种子成对运行，用 McNemar 精确检验与配对 bootstrap 比较；并复现基于位移的代理谓词 $\hat{\kappa}$ 并报告其漏检率。
  • 信号分析：在决策点标注未来 3 个原始动作内是否发生碰撞，对比策略输出、深度几何与运动历史三类信号的 AUROC 及可替换安全候选（Swap）比例。
  • 碰撞守卫：包含停滞否决（stall veto）（位移 < 1 cm 的位置-朝向被记入阻塞集 $\mathcal{B}$）与深度否决（depth veto）（净空 $c < \tau = 0.05$ m），配合连续计数 $q=3$ 与每回合上限 $K=12$ 防止卡死；否决后按 15° 步长在 ±90° 内寻找两步路径安全的朝向逃逸，再交还策略。
Card 05 数据集与资源

数据集与资源

  • 模拟器：Habitat + Matterport3D，不模拟刚体动力学，仅通过导航网格约束圆柱体运动。
  • 数据集：R2R-CE（主基准，1,839 条 unseen validation 回合）与 RxR-CE（泛化检验，1,223 条去重回合）。
  • 评测智能体共 6 个、来自 3 个架构族：循环基线 Seq2Seq、CMA；导航 VLA StreamVLN、OmniNav；拓扑规划器 ETPNav、ETP-R1，全部冻结权重、只改执行层。
  • 感知资源：十二相机全景环深度，投影为度量占据点云，逐像素地面测试避免丢弃低矮障碍物（论文可见部分未给出 GPU/TPU 型号与训练算力）。
Card 06 评估与结果

评估与结果

  • P1：slide 下 R2R-CE 有 38.5–56.8% 的成功回合含至少一次碰撞步；RxR-CE 长路径上 ETP-R1 达 79.1%、ETPNav 达 78.3%。脏成功中首次接触的中位位置出现在回合的 32–46% 处，并非终点附近的假象。
  • P2：改用 block 后成功率下降 11.7–36.1 个百分点（R2R-CE，全部 $p<10^{-50}$），OmniNav 从 67.5% 跌到 31.4%；碰撞步率由 4.0–8.0% 升至 13.9–62.4%。位移代理把 77.7–87.6% 的引擎标志碰撞回合误判为干净。
  • 信号分析：深度几何 AUROC 0.759–0.832，运动历史 0.862–0.981（历史召回率 82.3–99.3%，被标记的步几乎必然再次碰撞），而策略输出仅 0.301–0.673；风险决策中仅 0.4–4.0% 存在分数接近的安全替代动作。
  • 守卫效果：block 下减少碰撞步 62–98%，成功率提升 6.9–29.3 个百分点（如 OmniNav +29.3、StreamVLN +22.4）；slide 下成功率不变，同时把无碰撞成功比例提高 4.1–12.4 个百分点。
