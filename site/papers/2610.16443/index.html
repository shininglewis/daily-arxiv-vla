论文概述

  • 提出 RAP-WAM，通过预测排练（Predictive Rehearsal） 与动作扰动（Action Perturbations） 将视频生成先验适配为机器人控制策略，联合预测未来观测与动作。

Card 03 核心贡献

核心贡献

  • 提出 RAP-WAM 框架：采用未来监督动作接口（future-supervised action interface），让记录的未来帧监督动作生成特征，并通过预测排练让策略暴露于自身预测误差影响的观测。
  • 设计动作响应驱动的时空信用机制（response-derived spatiotemporal credit）：将动作响应、当前预测误差和历史误差先验（spatial prior）结合，指导视觉监督；对响应进行空间池化以分配未来动作步的监督强度。
  • 提出执行引导的后训练与任务特定策略保留机制：用评估反馈优化示范采样，保留互补的任务专家策略，而非对所有任务替换基础策略。
  • 无需额外的评分网络、区域标注或部署时的探针（probe），即可实现自适应监督。
Card 04 方法描述

方法描述

  • 未来监督接口：将 K=16 个可学习查询 token 附加到视频 V、噪声动作 A、观测状态 S token 上，形成 [V,A,S,Q]，通过余弦对齐损失 L_align 与记录的未来视频隐变量对齐。
  • 定向注意力掩码：禁止动作 token 查询行直接读取视频 token 键列，但保留视频 token 读取动作路径（供响应探针使用）。
  • 耦合动作投影（CAP）：用紧凑 MLP H_c 与时序调制头 H_r 之和预测动作流匹配速度 v_θ^a，两分支共享同一目标，零初始化新增分支。
  • 预测排练：用前一 chunk 的无梯度预测帧替代后一 chunk 的初始观测；调度采样可替换初始状态；预测图像与记录的未来帧联合 VAE 编码，动作目标保持为记录值。
  • 空间先验更新：将排练误差在通道、batch、未来时间上平均并池化到 14×14 网格，以衰减系数 ρ=0.9 做移动平均更新 P ← ρP + (1−ρ)e^roll。
  • 响应信用：对同一记录示范做两次前向，第二次在归一化噪声动作上加入 δ~N(0,τ²I)（τ=0.1），分别计算响应 S_i 和误差 E_i；组合权重 W_i = 1 + α_P N(P)_i + α_S N(S)_i + α_E N(E)_i，其中 α_P=α_S=1、α_E=0.5。
  • 时序权重：将原始响应在空间上平均后按未来时间做 min-max 归一化，每个系数重复 R=⌈H_a/T⌉ 次（T=4, H_a=16，即每个系数对应 4 个连续动作）。
  • 完整目标：L = L_0 + b_c λ_c r_c(k) L_1 + b_P L̃_P，λ_z=0.5、λ_a=0.3、λ_c=1、p_P=0.5。
  • 后训练与策略保留：agent 根据执行反馈提出干预 u_r；重放策略为 50% 自然重放、20% 任务均衡重放、15% 失败边界窗口、15% 后期进度窗口；候选只有在 SR 提升或 SR 持平但 Score 提升时才替换当前任务策略。
Card 05 数据集与资源

数据集与资源

  • RoboDojo 仿真：共 42 个任务，覆盖 Gen-Std、Gen-Rand、Precision、Long-Horizon、Memory、Open 等能力维度。
  • 真实机器人评测：15 个真实机器人任务（包括瓶子排序、积木重排、极值覆盖、风扇插入、手机装箱等）。
  • 诊断数据：315 个固定输出仿真窗口，来自 35 个条件，用于分析响应与误差的互补性。
  • 基线包括 G0.5、Xiaomi-Robotics-1、Hy-Embodied-0.5-VLA、KinRT、SimpleMemVLA、Pi-05、InternVLA-A1.5、VLAct、MolmoAct2、OpenWAM-α、X-WAM、GigaWorld-Policy-0、AHA-WAM、Fast-WAM 等。
  • 模型基于视频预训练骨干网络，不在外部具身数据上做中间预训练。
  • 后训练阶段每个任务只需数千步微调，最终系统在 14 个任务上使用基础策略、28 个任务使用 16 个其他 checkpoint。
Card 06 评估与结果

评估与结果

  • RoboDojo 42 任务：RAP-WAM 基础版平均成功率 12.85%、Score 17.86；完整后训练系统达 15.62% 成功率、20.59 Score，分别提升 2.77 个百分点和 2.73。
  • 能力维度提升：Precision 从 16.51% → 21.03%，Memory 从 7.00% → 9.33%，Generalization 从 7.50% → 10.50%。
  • 长程任务：Long-Horizon 成功率从 32.50% → 36.50%，Score 从 45.12 → 48.43。
  • 任务级示例：tower building 从 60% → 72%，pen-holder filling 从 6% → 18%，tic-tac-toe 从 80% → 86%。
  • 真实机器人 15 任务：完整系统达到 89.00% 任务宏平均成功率，超过五个基线中最强者 37.67 个百分点。
  • 响应诊断：在 315 个固定输出窗口上，45.21% 的 response-top20 位置落在 error-top20 之外，说明动作响应包含预测误差之外的信息；P、S、0.5E 的中位重分配份额分别为 5.47%、2.22%、1.14%。
  • 局限：Open 成功率仅 0.75%、随机泛化成功率保持为零，说明该增益尚未解决广泛的场景迁移鲁棒性问题。
