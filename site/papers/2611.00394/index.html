Card 03 核心贡献

核心贡献

  • 提出 CalVLA，通过成功与失败 rollout 对 VLA 策略的原生动作 token 置信度进行结果监督塑形。
  • 设计 ACal 平方边际排序损失，使同一任务中成功观测的置信度高于失败观测，且不依赖辅助检测器。
  • 在 OpenVLA-7B 上使用 rank-16 LoRA 适配器，仅更新注意力 q_proj/v_proj，保持预训练主干冻结。
  • 构建受控评测，比较冻结原生置信度、相同 min-top 摘要及三种冻结特征探针，区分“检测器”与“控制器”改动。
  • 揭示置信度与控制的权衡：失败判别提升，但任务成功率下降，且未证明优于线性探针的统计显著性。
Card 04 方法描述

方法描述

  • 将 原生置信度 定义为 7 个动作维度上最大 token 概率的均值：c_mean(o)=1/7 Σ_d max_k p_θ,d(k\|o)。
  • 在同一任务内，按归一化已用时间 ρ=t/L 配对成功与失败观测，要求 \|ρ+ - ρ-\|≤ 0.02，但不保证物理任务阶段等价。
  • 使用 ACal 平方边际排序损失：[max(0, γ - c(o+) + c(o-))]^2，其中 γ=0.2，训练成功观测置信度高于失败观测。
  • 在 OpenVLA-7B 上训练 rank-16 LoRA，冻结主干；验证选择前向 KL 系数为 λ_KL=0，即仅优化 ACal 损失。
  • 测试时以观测前缀置信度均值的负值作为失败风险分数，可在线更新，但不设置报警阈值或执行恢复动作。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO-10 模拟基准：10 个任务，每个任务 50 个初始状态，共 500 个配置。
  • 数据划分为 350 训练 / 50 验证 / 100 测试；冻结 OpenVLA 在 500 个配置中成功 243 个，生成 202,906 个观测-动作步。
  • 训练集包含 11,378 个同任务成功-失败观测对、15,869 个唯一观测；失败观测限制在轨迹最后 130 步，每个源 episode 最多 128 对。
  • 模型为 OpenVLA-7B，LoRA 可训练参数 8,388,608；主干 FP16，置信度/损失/LoRA/优化器状态使用 FP32。
  • 训练使用 AdamW、学习率 1e-5、batch size 为 1 对、单遍更新；论文未报告具体 GPU/TPU 型号、数量或训练时长。
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO-10 保留测试集，采用确定性解码和 3 个适配种子；指标包括 130/260 步 AUROC、联合 AUROC、任务成功率 TSR 和平均精度 AP。
  • CalVLA/ACal 的联合失败判别 AUROC 为 0.7392 ± 0.0480，AUROC130 为 0.7004，AUROC260 为 0.7780。
  • 冻结原生 min-top 置信度的联合 AUROC 为 0.4485；使用相同 min-top 摘要时，适配后 AUROC 从 0.4485 升至 0.7327。
  • 冻结特征探针联合 AUROC 为 0.6146–0.6436；相对最强探针 P-LINEAR 的点增益为 0.0956，但 95% 区间 [-0.0105, 0.2017] 包含零， superiority 未确立。
  • 适配后平均 TSR 从 58% 降至 55%（三个种子分别成功 58/100、54/100、53/100），论文明确未证明控制性能或安全收益提升。
