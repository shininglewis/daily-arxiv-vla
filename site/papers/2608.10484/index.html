Card 02 论文概述

论文概述

  • 论文研究视觉-语言-动作模型（VLA）中动作表示与语言抽象对齐的问题，指出当前动作表征仅以 L1/L2 重建损失优化，未显式保留语言相关的语义区分
  • 在 BridgeV2 数据集上验证了动作轨迹包含超越视觉状态变化的动词接地信息，且重建导向的离散标记化会系统性侵蚀该信息
  • 提出 SALT（Semantically ALigned Tokenization）方法，通过冻结视觉-语言模型从量化动作潜在变量中恢复指令，显著提升语言条件控制任务的成功率
Card 03 核心贡献

核心贡献

  • 诊断发现一：动作轨迹包含动词接地信息，且动作目标（视觉状态变化）与运动动态（7-DoF 动作轨迹）提供互补的动词信息
  • 诊断发现二：仅优化重建的离散标记化（Bin、VQ-VAE、FAST）会随压缩增强逐步侵蚀动词-动作互信息，成为语言与控制的瓶颈
  • 方法贡献：提出 SALT，在 VQ-VAE tokenizer 训练中增加生成式语言对齐目标，使量化动作隐变量可恢复对应指令
  • 实验验证：SALT 在 SimplerEnv 中平均成功率提升至 71.9%，显著优于 VQ-VAE（42.7%）与 FAST（31.2%）
  • 涌现分析：SALT 训练的词表自发出现动词专用编码，如 flip 和 turn 的专用代码，而重建方法产生语义混合的通用代码
Card 04 方法描述

方法描述

  • SALT 基于残差 VQ-VAE 架构（8 时间步 chunk、7 组残差、每组 256 个码），共 7 个 token ID 表示每个 chunk
  • 对齐损失使用冻结的预训练语言模型，将量化隐变量作为软前缀软提示，要求模型生成该 episode 的自由形式指令
  • 语言模型梯度经直通量化器传入编码器和码本，改变动作空间划分方式，但冻结语言模型本身
  • 对齐目标不需要预定义动词表或单独文本编码器及对比负样本，直接作用于自由形式的指令
  • 训练完成后语言模型被丢弃，tokenizer 冻结，下游 VLA 策略训练流程不变
Card 05 数据集与资源

数据集与资源

  • BridgeV2 数据集：遥操作真实机器人操作轨迹，配自由形式自然语言指令，筛选后保留 17 个动词类、27,271 个 episodes
  • SimplerEnv 视觉匹配 WidowX 套件：4 个桌面任务（put spoon on towel、put carrot on plate、stack green block on yellow、put eggplant in basket），每任务 24 个 episodes
  • 模型：miniVLA（Prismatic 风格），Qwen2.5-0.5B 骨干，从视觉-语言检查点开始训练，无机器人动作预训练
  • 训练配置：15k 梯度步、全局 batch size 128、FAST 用 1024 词表
  • 计算资源详见附录 J（硬件与总计算预算）
Card 06 评估与结果

评估与结果

  • SimplerEnv rollout 成功率：SALT 平均 71.9%（Spoon 75.0、Carrot 62.5、Stack 70.8、Eggplant 79.2），全部任务领先
  • 对比基线：VQ-VAE 平均 42.7%，FAST 平均 31.2%，SALT 与 VQ-VAE 架构完全一致，仅差异为对齐损失，29.2 个百分点差距归因于语义划分
  • 动词可解码性：SALT 在 token ID 上 macro-F1 39.1（VQ-VAE 37.3、FAST 30.3），在策略学习的动作嵌入上 43.7（VQ-VAE 38.3、FAST 36.3）
  • 重建保真度：SALT 重建 L1 误差 0.088，接近 VQ-VAE 的 0.080，语义对齐不牺牲重建质量
  • 可解释性：SALT 的动词专用编码达到 flip 98%、turn 74% 的代码-动词纯度，代码还能捕捉同义改写（如 "lever vertical to front" 归入 turn 编码）
