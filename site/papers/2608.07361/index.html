Depth-Wise Probing and Pruning of the Planning Token in a Driving Vision-Language-Action Model

2026-08-07 · 原文 · 翻译 · 2608.07361

论文研究驾驶Vision-Language-Action (VLA) 模型中规划 token（planning token）在不同解码器深度上信息的产生与演化过程，以ORION模型为代表架构进行实证分析。 核心问题是：深度语言模型的大量堆叠层中，动作规划本身究竟需要多少层计算，以及各层的规划信息是否可以在不损失性能的前提下被剪枝。 论文采用轨迹空间 logit lens 方法，从每一层解码器的隐藏状态读取规划 token，并通过冻结的原生规划器解码出轨迹进行评估。

Card 02 论文概述

论文概述

  • 论文研究驾驶Vision-Language-Action (VLA) 模型中规划 token（planning token）在不同解码器深度上信息的产生与演化过程，以ORION模型为代表架构进行实证分析。
  • 核心问题是：深度语言模型的大量堆叠层中，动作规划本身究竟需要多少层计算，以及各层的规划信息是否可以在不损失性能的前提下被剪枝。

Card 03 核心贡献

核心贡献

  • 提出轨迹空间 native-head lens：将模型的冻结规划器作为输出头，解码每一层的规划 token，测量中间层表示与原生态规划器的兼容性。
  • 通过线性探针（linear probe）发现导航命令的语义意图在第一个解码层之后即可被线性解码（准确率 97.7%，chance 16.7%），而轨迹误差仅在最终层达到最低值。
  • 在 Bench2Drive 五个能力类别上进行分层分析，证明规划器兼容性的深度演化在各场景族中一致。
  • 提出以规划 token 输入输出余弦相似度作为层剪枝排序标准，优于基于单独解码质量的排序，可在删除 8/32 层时保持约 5% 相对误差增加，并实现 1.33× 解码器实测加速。
  • 证明早期层已包含可恢复的规划信息：MLP 适配器可将第一层 Avg-L2 从 8.51 m 降至 3.47 m，序列重采样器进一步降至 2.98 m（最终层基线为 2.17 m）。
Card 04 方法描述

方法描述

  • 模型为 ORION 驾驶 VLA：6 路环绕摄像头输入，经视觉骨干与 QT-Former 感知头生成数百个查询 token，拼接固定文本提示词后送入 32 层 LLaMA 风格解码器，并附加单个特殊 token 作为规划 token。
  • 在每个中间层的隐藏状态上读取规划 token，经过最终归一化后送入冻结的生成式规划器（条件 VAE + 循环网络 + 解码头），输出 3 秒、6 个路点的轨迹。
  • 使用线性探针（ℓ2 正则化多项逻辑回归）预测 6 个 Bench2Drive 导航命令，进行五折交叉验证。
  • 剪枝方法：利用残差连接的性质，将层替换为恒等映射等效于删除该层，以规划 token 输入输出余弦为排序标准进行层移除。
Card 05 数据集与资源

数据集与资源

  • Bench2Drive（CARLA 仿真）基准，包含五个能力类别：合并、超车、紧急制动、让行、交通标志服从。
  • 评估集分为四组：probing set（2,000 帧能力均衡冷启动）、pruning set（800 帧）、reshaping set（500 帧命令均衡）、streaming set（5,291 帧路线顺序）。
  • 模型使用 4096 维规划 token，训练/推理在 A100 80GB GPU 上进行，FP32 单次非自回归解码器前向传播用于延迟测量。
Card 06 评估与结果

评估与结果

  • 命令线性可解码性：隐藏状态 0 处为 16.7%（chance），第一层后达到 97.7%，峰值 98.6%。
  • 规划器兼容性：Avg-L2 随深度逐渐下降，最终层达到最低 2.11 m；超过一半的总误差降低在隐藏状态 15 之后才完成。
  • 剪枝结果：删除 8 层（集合 {9,10,13,17,18,19,27,30}）后 Avg-L2 从 2.06 m 变为 2.17 m，约 5% 相对增加；解码器延迟从 497.52 ms 降至 373.22 ms（1.33×）。
  • 排序策略对比：按解码误差排序会因误删晚期关键层（29-31 层）导致首轮即 27% 误差增加；按余弦排序在 k≤8 时误差保持平稳。
  • 重采样实验：全序列训练的 resampler（约 40M 参数，8 个潜在查询）从第一层到达 2.98 m；测试时只保留 529 个视觉 token 时性能损失仅 0.15 m，说明视觉信息是主要来源。
  • 在统计层面，所评估的样本规模下未能解析出任何能力特定族中的剪枝性能退化。
