论文概述

Card 03 核心贡献

核心贡献

  • 提出首个 3D-native WAM，在每次交互的共享度量 3D 坐标系中统一观测、动作与场景动态，并使用跨机器人本体与人类手部的通用表示。
  • 提出 action flow（动作流） 以 3D 点轨迹表示人手与机器人夹爪的运动，提出 scene flow（场景流） 表示由该运动条件化的场景点位移，策略模式与模拟器模式共享该接口。
  • 提出 world-aligned 3D position embedding（世界对齐 3D 位置嵌入），在有/无深度输入下均可将视觉观测锚定到度量空间。
  • 提出 physical-time trajectory tokenizer（物理时间轨迹分词器），按经过时间对齐轨迹，并把整条轨迹编码为锚定于当前 3D 位置的单个 token。
  • 以 1.7B 参数在动作条件场景预测与操作方法均取得领先性能。
Card 04 方法描述

方法描述

  • 观测对齐：每个预测窗口内观测、动作与场景轨迹共享一个固定度量坐标系 F^W；机器人演示用机器人基座/本体坐标系，第一人称人类演示用窗口锚定相机坐标系。
  • 世界对齐 3D 位置嵌入：有深度时，利用相机内参 K_i 与 SE(3) 外参 T^W_{t,i} 将像素反投影到世界坐标，并用 Fourier 映射 ψ 编码；无深度时沿标定相机光线采样 M=64 个候选深度（0.1–2.0 m），通过注意力路由加权组合，并用以深度为目标的路由监督损失 L_PE 约束。
  • 动作流与场景流：机器人在 URDF 夹爪几何上采样 N_g=20 个点并保留 link-local 坐标，经正运动学映射到世界系；人类手部用每手 21 个 MANO 关键点；场景点通过 URDF 掩码机器人像素后反投影 RGB-D 采样。
  • 物理时间轨迹分词器：以秒而非帧索引编码时间（τ_k = k/f，T_max = 3 s），用固定时间基 φ_time 与 FiLM 参数将轨迹编码为单一 latent，再在任意请求时间解码位移。
  • 模型架构：采用 Mixture-of-Transformers，包含一个点动力学专家（建模动作流与场景流）和一个动作专家（生成末端执行器动作块）；通过层耦合注意力掩码实现场景预测条件于干净动作流、动作块不依赖未来流 token。
  • 训练与推理：先训练并冻结轨迹分词器，两专家用 rectified flow 训练，损失为 L = λ_A L_A + λ_s L_scene + λ_ctrl L_ctrl + λ_PE L_PE；推理时动作流与动作块并行去噪，场景去噪复用 KV 缓存，策略模式可跳过两条点动力学分支。

Card 06 评估与结果

评估与结果

  • 动作条件场景预测（RoboTwin 模拟器模式）：在全部四项场景预测指标上领先，相比 PointWorld 将 Moving ADE、Moving FDE、Static ADE 分别降低 35%、21%、49%。
  • LIBERO 策略性能：平均成功率 99.8%（Spatial 99.8 / Object 100.0 / Goal 100.0 / LIBERO-10 99.4）；无混合预训练时为 99.5%，仍超过所有基线。
  • RoboTwin 2.0：Clean 92.94%、Randomized 93.04%，以 1.7B 参数超越 Fast-WAM（6B）与 Motus（8B）。
  • VLABench：成功率 56.2%（对比 π_0.5 的 48.1%），进度分 67.6 领先。
  • LIBERO-Plus 鲁棒性：总体成功率 89.1% 最高；相机扰动下 82.1%，优于 Cosmos Policy（75.8%）与 LaMP（64.5%）。
  • 真实机器人：Organize Books 90%（18/20）、Pack the Ball 80%（16/20），均超过 π_0.5 与 Fast-WAM，平均约 85%。
  • 消融实验：世界对齐视觉 grounding、动作流与场景流监督、运动历史 token 均提升策略性能与鲁棒性；混合数据预训练带来整体 +2.6 个百分点增益，机器人初始状态扰动下从 84.8% 升至 94.2%，语言扰动下从 77.6% 升至 85.0%。
