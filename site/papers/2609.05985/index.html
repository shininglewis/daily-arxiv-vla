Card 02 论文概述

论文概述

  • 提出 ActionReasoning 2.0，一种受人类大脑功能分工启发的零样本（zero-shot）分层机器人任务推理与执行框架
  • 针对端到端 Vision-Language-Action（VLA） 策略缺乏显式结构、难以支持长时程任务分解、物理可行性验证和错误恢复的局限
  • 框架将自然语言命令与 RGB-D 观测映射为结构化场景表示，通过物体状态推理、原子动作组合、成本式计划选择和闭环执行验证，实现真实机器人上多类操作任务的零样本执行
Card 03 核心贡献

核心贡献

  • 提出大脑启发的分层框架，整合物体状态感知、语言 grounding 与原子动作序列组合、基于成本的计划选择和执行验证
  • 建立基于共享原子动作库的统一动作序列生成范式，同一推理 pipeline 可支持 pick-and-place、金字塔堆叠和表面清理三类任务
  • 在全部测试条件下超越 ReKep、Dream2Flow 和 π0.5 基线，取得最高成功率和任务进度
  • 通过消融实验验证分层结构、物体状态推断和成本式计划选择等关键组件的有效性
Card 04 方法描述

方法描述

  • 以脑功能区为功能类比设计层次结构：视觉皮层模块负责感知与状态推断，"小脑模块"负责语言grounding与动作组合，

"前额叶皮层模块"负责成本式计划选择；类比是功能性的，而非神经生物学意义上的

  • 视觉感知采用 SAM 3 获取概念条件分割 mask，结合深度投影恢复物体在机器人坐标系中的位姿与几何尺寸；场景状态由物体状态描述符、空间关系和机器人状态组成
  • 提出可复用的共享原子动作库，包含 Move、Descend、Rotate、Close、Lift、Release 六种核心原语，任务差异通过动作选择、排序、参数化及验证条件表达
  • 采用两阶段动作生成：先由 LLM 将语言指令 grounding 为结构化目标，再基于当前物理状态从原子库中组合出多个候选动作序列
  • 成本式计划选择以执行时间估计为标准，综合平移距离、旋转量和夹爪操作次数对候选序列排序，选择成本最低的计划
  • 执行与验证环节在每个原子动作后刷新观测并核验真实物理结果；失败时丢弃剩余序列并基于新场景重新生成动作规划
Card 05 数据集与资源

数据集与资源

  • 未使用公共数据集，在真实机器人平台上完成三类任务的多轮 rollout 评测
  • 基线 π0.5 的微调数据：每个任务采集 50 episodes
  • LLM 主干：Qwen3-7B，承担视觉状态推理、任务 grounding 与动作组合
  • 视觉基础模型：SAM 3，用于概念条件分割

Card 06 评估与结果

评估与结果

  • 涉及三类任务：Clean Board（N=10）、Pick-and-Place（N=10）、Pyramid Stacking（flat 与 irregular 两种初始布局，各 N=5）
  • 使用成功率（SR）、任务进度（TP）和完成时间作为评估指标；TP 报告均值 ± 标准差，完成时间仅统计成功试验
  • Clean Board 上 ActionReasoning 2.0 成功率 100%（10/10），TP 99.03±1.67%；对比 ReKep 0%、Dream2Flow 10%、π0.5 30%
  • Pick-and-Place 上成功率 100%（10/10），TP 100.00±0.00%；对比 ReKep 10%、Dream2Flow 0%、π0.5 50%
  • Pyramid-Flat 上成功率 80%（4/5），TP 96.67±7.45%；对比 ReKep 0%、Dream2Flow 0%、π0.5 40%
  • Pyramid-Irregular 上成功率 80%（4/5），TP 96.67±7.45%；所有基线均未成功完成任何试验（0%）
  • 消融结果显示：移除分层结构（single agent / single LLM）在多数任务上明显降低成功率；在 Pyramid-Irregular 条件下去除状态推断或成本选择后成功率从 80% 降至 0%，验证关键模块的不可或缺性
  • 定性 rollout 展示了外部人为扰动下的状态更新与继续执行、清洁残留区的闭环覆盖，以及失败抓取后重新定向并恢复堆叠等能力
