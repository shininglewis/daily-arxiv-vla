论文概述

  • 论文构建 SurgTAP-3D，一个大规模 in-vivo 跨手术伪3D手术运动跟踪数据集与基准，包含 520K 帧、4,549 个动作片段、1.4M 条 2D/3D 点轨迹。

Card 03 核心贡献

核心贡献

  • 构建首个大规模 in-vivo、contact-aware、同时覆盖器械与组织 的 3D 像素级轨迹数据集，覆盖机器人手术与手动手术。
  • 提出首个统一的手术 3D 点跟踪标注框架，将无标定单目手术视频转换为结构化 4D 标注。
  • 建立覆盖 SurgPose、SurgT、STIR 的综合基准，用于评估器械与组织场景下的 2D/3D 点跟踪。
  • 展示下游应用价值，包括器械位移估计、可变形表面重建与渲染、以及基础模型微调。
  • 数据集同时提供相机坐标系与全局坐标系下的轨迹，并包含相机内参、位姿、深度、器械掩码等标注。
Card 04 方法描述

方法描述

  • 采用单帧接触区域标注：标注接触区域边界框，并在活动器械和背景上提供正负点提示，输入 SAM2 生成逐帧活动器械掩码。
  • 从接触区域采样查询点，使用 TAPNext 获得 2D 点轨迹、可见性与置信度。
  • 使用 Endo3R 估计深度、相机位姿和内参，并将外部深度预测通过对齐尺度与偏移融合到 Endo3R 深度中。
  • 引入 dynamic bundle adjustment，以重投影代价和单目深度代价联合优化相机内参、位姿与深度，并利用器械掩码和低置信度区域加权抑制动态干扰。
  • 将 2D 轨迹提升为相机坐标系 3D 轨迹，再通过相机位姿转换到全局坐标系。
  • 进行 global 4D refinement，通过光流一致性、跟踪一致性、器械刚性、关节流一致性和时间平滑等约束优化轨迹与几何。
Card 05 数据集与资源

数据集与资源

  • 机器人手术数据来源包括 GraSP、SAR-RARP50。
  • 手动手术数据来源包括 SLAM、SurgicalActions160、AutoLaparo、HeiCo 的 proctocolectomy/rectal resection 子集、CholecT50、MultiBypass140。
  • 覆盖 prostatectomy、hysterectomy、cholecystectomy、gastric bypass、rectal resection、proctocolectomy 等多种手术类型。
  • 数据集统计为 4,549 个片段、519,642 帧、1,376,987 条轨迹；片段长度约 5–30 秒，对应 20–300 帧。
  • 统一动作类别为 dissection、tissue retraction、needle grasping、vessel clipping、coagulation。
  • 提供的 HTML 原文未给出模型参数量与 GPU/TPU 训练资源；方法使用 Endo3R、SAM2、TAPNext、DROID-SLAM 更新模块、光流模型等现成基础模型或模块。

评估与结果

  • 评估任务包括 2D/3D 点跟踪、视频深度估计、相机位姿估计 与消融实验。
  • 基准数据集包括 SurgPose、SurgT、STIR，覆盖器械跟踪与组织跟踪场景。
