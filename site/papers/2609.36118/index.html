Card 02 论文概述

论文概述

  • 研究 VLA（Vision-Language-Action） 策略中预训练 VLM 主干与动作头之间的潜在接口（latent interface） 设计问题，即应当从主干的哪些层读取特征 token。
  • 系统对比两大范式：单层范式（single-layer） 与 层融合范式（layer-fusion），并追问层选择对策略性能与推理开销的实际影响。
  • 指出领域内既有结论相互矛盾（GR00T N1 主张中层、ABot-M0 主张末层、VLA-Adapter 主张融合），且这些结论普遍缺乏多随机种子与误差棒支撑。
Card 03 核心贡献

核心贡献

  • 在 3 个 VLM 主干 × 2 个基准 × 3 个训练种子 下系统复现并比较融合方法，发现 54 种融合方法—层配置组合中有 47 种低于最佳单层策略，融合优势有限。
  • 通过 单边 Welch t 检验 统计分析证实，各融合方法相对最优单层的优势统计置信度极低（仅 APT+CALVIN 为例外）。
  • 通过穷举 layer-sweep oracle 实验揭示最优层从不是最深一层，且最优层深度在主干与基准间不可迁移（如 Qwen-2B 从 LIBERO 的第 3 层漂移到 CALVIN 的第 16 层）。
  • 提出 InfoNCE 作为层质量代理指标：在 4 种候选代理中最具一致正相关，且将选择遗憾从 17.89 个百分点降至 3.71 个百分点。
  • 从信息瓶颈（IB）视角证明 InfoNCE 目标与动作预测目标是重加权等价的，给出理论解释。
Card 04 方法描述

方法描述

  • 将 VLA 网络建模为 $f = g \circ \phi$，其中 g 为动作头、φ 为从 VLM 主干若干层读出特征的潜在接口，$Z=\phi(X)$。
  • 借用 信息瓶颈（IB）目标 定义理想潜在接口：Proposition 1 为动作预测目标 $\max_\phi I(Z,A)-\alpha I(Z,X\|A)$，Proposition 2 为 InfoNCE 目标 $\max_\phi I(Z',A',Y)-\beta I(Z',X'\|A',Y)$。
  • Theorem 1（IB 目标等价性）：当 $\beta < 1/(N-1)$ 时，InfoNCE 的 IB 目标等价于动作预测 IB 目标的重加权形式，两者由相同的 $I(Z,A)$ 与 $I(Z,X\|A)$ 定义。
  • 采用 InfoNCE critic 对每层潜表征与动作对打分，作为免闭环评估的廉价层质量代理。
  • 对比 3 种融合机制（VLA-Adapter 交叉注意力、APT 加权累积注入、BEHAVIOR-1st 学习式层组合）与 3 种层子集策略（Even 等间隔、Last 最深若干层、Best 最优单层集合）。
  • 关键洞察：InfoNCE 单层曲线能跟踪非单调的"成功率-层深"曲线，说明其优化不完美性与 VLA 训练共享同类任务无关噪声。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：LIBERO 与 CALVIN（两个机器人操作基准）。
  • VLM 主干（均为冻结）：Cosmos-Reason2-2B（28 层）、Qwen3-VL-2B（28 层）、ABot-Pretrain-4B（36 层）。
  • 训练配置：每层/每配置使用 3 个独立随机种子；训练流程基于 flow-matching，代码库基于 GR00T。
  • 计算开销（GPU-Hours，1 单位 = 1 张 H100 运行 1 小时）：

- LIBERO oracle 扫描 129.1 / 127.4 / 152.5，InfoNCE 扫描仅 10.6 / 14.1 / 4.6。

- CALVIN oracle 扫描 119.1 / 94.0 / 133.7，InfoNCE 扫描仅 7.4 / 7.5 / 13.4。

- 即 InfoNCE 扫描比 oracle 扫描便宜约 9–33 倍。

Card 06 评估与结果

评估与结果

  • 评估方式：闭环仿真基准的总体成功率，所有非层/融合相关因素严格受控一致。
  • 最优层定位：LIBERO 上 Cosmos-2B 为第 15 层（76.3%）、Qwen-2B 第 3 层（76.8%）、Abot-4B 第 31 层（98.4%）；CALVIN 上分别为第 11（64.4%）、16（64.7%）、12 层（66.1%）。
  • 末层普遍次优：对应最深层的成功率分别降至 LIBERO 的 62.9% / 55.6% / 96.6%，CALVIN 的 39.6% / 36.0% / 48.8%。
  • 代理指标 Spearman 相关（相对 oracle 成功率）：InfoNCE 在 LIBERO 达 +0.82 / +0.85 / +0.94，CALVIN 达 +0.82 / +0.72 / +0.36，优于 DiME、Prompt-level 矩阵熵、Dataset-level 矩阵熵。
  • 层选择效果：以 InfoNCE 选层相比穷举策略扫描可省 9–33 倍 GPU 算力，平均选择遗憾由最深层层选择的 17.89 个百分点降至 3.71 个百分点，接近事后用全部 6 次 oracle 扫描调优的固定层层启发式的 3.28–3.50 个百分点，且选择过程无需闭环评估。
  • 例外分析：7 个融合胜出案例中 5 个来自 APT，解耦实验表明其增益主要来自动作头架构改动而非层融合本身。
