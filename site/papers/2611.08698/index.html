Card 02 论文概述

论文概述

  • 论文提出 VICTR，一种面向 视觉-语言-动作模型（VLA） 的上下文学习框架，通过估计任务相对进度来检索演示片段，而不是仅依赖视觉相似度。
  • 核心问题是：现有基于检索的上下文学习方法使用视觉相似度选择演示块，但视觉相似的状态可能出现在不同执行阶段，导致检索到的上下文与当前动作需求不匹配。
  • 论文将进度估计本身建模为上下文学习问题，提出 In-Context Value Function Estimator（IC-VFE），以参考演示视频为条件估计当前状态的任务进度，并用于检索和指导动作生成。
Card 03 核心贡献

核心贡献

  • 提出 IC-VFE：以参考演示视频、语言指令和当前观测为输入，估计任务相对进度，无需任务特定微调即可适应未见任务。
  • 提出 VICTR 框架：基于进度对齐检索演示块，并将其作为上下文提供给 π0.5 策略进行动作生成。
  • 在真实机器人上构建 8 个域内任务和 8 个域外任务 的评估体系，验证进度信息检索对域外泛化的有效性。
  • 实验表明，在域外任务上，VICTR 将微调 π0.5 基线的成功率从 6.2% 提升到 23.8%，任务进度率从 28.9% 提升到 55.5%。
  • IC-VFE 在与人工标注进度曲线的一致性上优于现有在线价值估计器，且该优势能传递到下游控制性能。
Card 04 方法描述

方法描述

  • IC-VFE 使用冻结的 Gemma 3 4B 视觉编码器处理当前观测和参考演示，使用 Gemma 3 270M 解码器进行进度预测。
  • 参考演示的每个视角被压缩为 16 个 summary tokens，当前观测保留 256 个 detail tokens 并额外计算 16 个 summary tokens，以兼顾细节与上下文长度。
  • 解码器采用混合注意力：大多数层进行块内双向注意力，在 第 6、12、18 层 引入 block-causal attention 以聚合演示中的时间信息。
  • IC-VFE 输出 201 个离散进度 bin 的概率分布，再转换为 [0,1] 范围内的连续进度估计。
  • VICTR 根据当前估计进度与候选演示块进度的距离检索上下文块，并将其与当前观测、语言指令一起输入 π0.5 策略。
  • IC-VLA 在 π0.5 基础上微调，使用 FAST tokenized 动作块，并保留动作块最低 20/30 个离散余弦变换频率 bin 以缩短上下文。
  • 训练 IC-VFE 时使用 Robo-Dopamine 生成的伪进度标签作为监督，采用分类交叉熵损失；部署时模型权重保持固定，不进行测试时参数更新。
Card 05 数据集与资源

数据集与资源

  • 使用自采真实机器人数据集：28 个任务、1,180 个 episode、总计 7.5 小时，其中约 7 小时用于训练，30 分钟演示构成 16 个评估任务的演示池。
  • 评估集包含 8 个域内任务 和 8 个域外任务；域外任务涵盖新物体替换、已学技能组合和语义相似但未见任务。
  • 机器人平台为 YOR 双臂机器人，配备头部 ZED 相机 和两个 7-DoF AgileX Piper 机械臂 的鱼眼腕部相机。
  • 本体状态为 18 维，动作空间为 20 维，动作块长度 H=30，数据采集控制频率为 30 Hz。
  • 基础策略为 π0.5；IC-VFE 视觉编码器为 Gemma 3 4B，解码器为 Gemma 3 270M（18 层）。
  • 训练资源包括 NYU IT 高性能计算资源，以及通过 NVIDIA Academic Grant Program 获得的 NVIDIA RTX 6000 Ada GPU。
Card 06 评估与结果

评估与结果

  • 评估在真实机器人上进行，覆盖 16 个任务，每个任务执行 10 次 rollout。
  • 主要指标为 任务成功率 和 任务进度率；进度率基于预定义里程碑给予部分完成信用。
  • 价值估计质量使用 Kendall τ_b 和 Pearson r 衡量，与人工标注进度曲线比较。
  • 域外任务上，微调 π0.5 为 6.2% 成功率、28.9% 进度率；RICL-π0.5,nointerp 为 15.0% 成功率、42.1% 进度率；VICTR 达到 23.8% 成功率、55.5% 进度率。
  • 融合视觉相似度的 VICTR+vision 达到 21.2% 成功率、47.8% 进度率，未超过仅使用进度检索的 VICTR。
  • 域内任务上，各检索方法进度率为 87.5%–90%，高于 π0.5 的 82.2%，成功率整体较高。
  • 在 VFE 质量对比中，IC-VFE 在域内取得 Kendall τ_b=0.51、Pearson r=0.62，在域外取得 0.52、0.65，优于 RECAP、Robometer 等在线价值模型。
  • 部署时使用 IC-VFE 的 VICTR 在域外达到 62.7% 进度率，而最佳替代价值估计器仅为 29.2%。
  • 演示池消融显示性能随演示数量增加而提升，约在 5 个演示 附近趋于饱和；训练与部署使用相同检索信号时性能最佳。
