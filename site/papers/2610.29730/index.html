Card 02 论文概述

论文概述

  • 研究视觉–语言–动作（VLA）策略在部署后如何识别自身训练知识中的空缺，以便主动请求人类协助或补充演示数据。
  • 提出事后（post-hoc）核方差头：仅利用单个已训练策略的嵌入来估计认知不确定性，无需训练、微调或同时运行第二个策略。
  • 质疑此前 SAVE/VFD 等工作依赖双策略（甚至多策略）集成才能获得可用不确定性分数的必要性，并重新审视 LIBERO-10 上既有评测实际衡量的性质。
Card 03 核心贡献

核心贡献

  • 提出事后核方差头（kernel-variance heads），直接从单一 VLA 策略的嵌入读出认知不确定性：只需一次特征提取和对支持集的一次 Cholesky 分解，无需回归目标、无梯度更新，且完全不改动策略本身。
  • 在 LIBERO-10 上复现 SAVE 研究：核方差头在任务级校准、主动学习中的演示采集、以及向更强监督策略转交（referral）三方面，均与双策略集成分数（VFD、GU）相当或更优。
  • 显著降低计算成本：相较集成分数，不确定性打分速度快约 50 倍，每轮微调的建置成本快约 44 倍（头部开销约 1.0 分钟/轮 vs. 43.8–44.6 分钟/轮）。
  • 指出既有评测主要奖励“任务覆盖度”的识别（一个仅统计各任务演示数量的参照分数即可达到 -ρ_S = 0.82），而对任务内排序的检验很弱。
  • 设计受控扰动评测（相机、指令、状态及其组合）：模态专属头能定位“哪一输入不熟悉”，融合头能检测“各自熟悉但组合不熟悉”的情况，且在任务内 referral 上可超过集成分歧。
Card 04 方法描述

方法描述

  • 核方差头：以 SmolVLA 的嵌入 φ_b(o) 为输入，经预处理后计算零均值 GP（高斯核、带宽 ℓ、岭 λ）的后验条件方差 u_KV(z) = k(z,z) − k(z,Z)(K_ZZ+λI)⁻¹k(Z,z)，取值在 (0,1]，远离支持集趋于 1，可视为核插值的最坏情形误差。
  • 预处理几何：坐标标准化 + 可选主成分投影 + Ledoit–Wolf 收缩协方差白化，等价于正则化马氏距离；支持集为训练演示的观测嵌入，不引入任何执行结果。
  • 两种整体观测头：KV-Ctx 读取最终前缀状态（3×960+8 = 2,888 维，降至 512 主成分）；KV-Dec 读取动作专家第 9 步流匹配的最终隐状态（50 个动作 token 均值，480 维）。
  • 上下文专属头：8 个头部按 KV-Ctx 配方构造，4 个 *raw* 头读取 transformer 混合前各模态（工作台相机、腕部相机、指令、8 维状态），4 个 *fused* 头读取混合后对应 token 组，用于归因“哪一模态不熟悉”。
  • SAVE 采集流程：保留原有任务打分与采样规则（τ=2.5），仅把 VFD 分数替换为核方差分数；每轮用新策略重嵌支持集并重拟合头部。
  • 评测指标：任务级校准（-Spearman / -Pearson）、监督转交（归一化 AUC，nAUC，相对随机与事后 oracle）、任务内失败 AUROC 与方差分解。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO 仿真基准（LIBERO-Spatial、-Object、-Goal 的 30 个任务 + LIBERO-10）；目标为 LIBERO-10 的 10 个任务，其 379 条演示构成候选池。
  • 训练数据：主策略与集成第二策略在 1,437 条演示上训练 30,000 次更新（batch size 32）；监督策略在 1,693 条演示（40 任务）上训练 39,993 次更新。
  • 支持集规模：1,437–1,512 个输入（头部拟合在 GPU 上远低于 1 秒）；精确 GP 条件化在约 10,000 输入以内仍可负担。
  • 模型：SmolVLA（流匹配动作专家，10 步 Euler 积分，50×7 动作块）；论文未给出参数量。
  • 计算资源：单卡 RTX 3090 或 A100；三个随机种子；每轮 5 次查询、4,000 次更新，共 15 轮。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-10 仿真任务，每任务 30 次 rollout、520 步时域；校准与转交使用 Random 采集臂第 0 与第 10 轮的同一批策略与初始状态，保证各分数可比。
  • 主要指标：任务级 -ρ_S / -r_P、SAVE 学习曲线成功率与每轮开销（GPU 分钟）、referral nAUC、任务内失败 AUROC、受控扰动下的检测灵敏度。
  • 校准（表 1）：KV-Ctx 达 -ρ_S = 0.77±0.08、-r_P = 0.82±0.09，与 VFD（0.75±0.12 / 0.64±0.17）相当；对 VFD 的配对差为 +0.02 [-0.02, 0.09]（Spearman）与 +0.18 [0.11, 0.25]（Pearson）；Round 0 时 KV-Ctx 的 -r_P 高达 0.94。
  • 演示采集（表 2）：SAVE/KV-Ctx 最终成功率 65.7±1.8%（全程均值 51.2%），与 SAVE/GU（64.4±3.1%）持平、高于 SAVE/VFD（61.9±2.5%）与 Random（54.7±5.1%）；KV-Dec 为 61.8±1.9%。
  • 开销：KV-Ctx 每轮评分开销 1.0 GPU 分钟，KV-Dec 为 12.0 分钟，而集成分数为 43.8–44.6 分钟（尚未计入第二策略 30,000 步的一次性预训练）。
  • 关键分析结论：任务级校准基本等价于“识别任务覆盖差异”（演示计数参照已达 0.82/0.83），而执行噪声削弱了任务内排序的检验；受控扰动下的模态专属头与融合头可补足这一评测缺口。
