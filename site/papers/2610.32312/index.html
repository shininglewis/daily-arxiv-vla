核心贡献

  • 提出双重条件化 VLA 框架，在同一共享策略内联合建模原始技能结构与交互相关的空间定位。
  • 设计技能条件化 LoRA-MoE 适配：用技能查询 token（skill-query tokens）与路由偏置（routing bias）条件化 LLM 主干中的低秩专家特化。
  • 设计轨迹-可供性（Trajectory-Affordance）空间先验：将未来夹爪运动与场景几何转化为热图监督，并进一步转成动作头中的 patch 级空间注意力偏置。

Card 04 方法描述

方法描述

  • 问题设定：给定观测 $\mathbf{o}_t$、语言指令 $\mathbf{l}$ 与粗粒度原始技能条件 $s_t$，预测未来 $H$ 步动作序列；$s_t$ 由指令经归一化词法/模糊匹配归入紧凑技能分类（旋转、滑动/推动、提起/拾取、放置/存储、堆叠、切换）。
  • 技能条件库：维护输入侧技能查询库 $\mathbf{E}_{query}\in\mathbb{R}^{N_s\times N_q\times d}$ 与逐层路由偏置库 $\mathbf{E}_{route}^{(\ell)}\in\mathbb{R}^{N_s\times N_e}$；技能查询 token 与视觉、语言、动作查询 token 拼接输入。
  • LoRA-MoE 路由：路由器计算 $\mathbf{p}=\mathrm{softmax}(\mathbf{W}_{gate}\mathbf{h}+\mathbf{b}_s^{(\ell)})$，经 Top-k 选择后重归一化并加权求和低秩专家输出；路由偏置只做软性偏移，专家选择仍保持内容自适应而非硬绑定。
  • 可供性热图构造：基于当前场景表面点与未来 $H$ 步夹爪轨迹的 3D 最小距离，用高斯核 $\exp(-d_u^2/2\sigma^2)$ 与半径阈值 $r_{\max}$ 生成稠密监督目标，无需额外人工标注。
  • 热图引导动作解码：预测热图归一化降采样为视觉 patch 对齐的空间先验 $\mathbf{M}$，以加性偏置 $\tau\mathbf{M}$ 注入动作头注意力 logits，只调整相对权重、不做区域屏蔽。
  • 训练目标：动作块 $\ell_1$ 回归 + 加权二元交叉熵热图损失 + MoE 路由辅助正则，后两者由 $\lambda_{hm}$、$\lambda_{moe}$ 加权。

Card 06 评估与结果

评估与结果

  • 评估指标：Success@1–5（连续完成至少 k 个子任务的序列百分比）与 Avg. Len（平均完成序列长度）；真实机器人场景使用 Success@1–3 与 Avg. Len。
  • CALVIN ABC→D 主结果：MAST-VLA 达 99.4 / 97.4 / 94.2 / 89.2 / 84.7，Avg. Len 4.65，优于 FLOWER（4.54）、VLA-Adapter-Pro（4.50）、FALCON（4.40）等方法。
  • 增益分布：早期子任务成功率接近饱和，提升主要出现在后段——相对直接基线，Success@4 由 85.3%→89.2%、Success@5 由 80.0%→84.7%，说明对技能切换误差与空间定位误差累积更鲁棒。
  • 消融结果：仅技能查询 4.53；查询 + LoRA-MoE 4.59；仅热图 4.61；完整模型 4.65，验证两条路径互补；将匹配技能条件替换为随机不匹配条件后 Avg. Len 降至 4.55，说明技能条件确实被有效利用。
  • 路由与可视化分析：Top-2 LoRA-MoE 路由签名显示不同技能有各自的主/次专家偏好且随 token 组保持一致；预测热图集中在物体接触区、目标容器、插入区与堆叠界面，并在运动型任务中沿物体运动方向延伸。
  • 真实机器人：在逐序列 Avg. Len 与整体序列完成度上均优于基线，表现出对真实感知与控制噪声下误差累积的更强鲁棒性。
