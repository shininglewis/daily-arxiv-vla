Card 02 论文概述

论文概述

  • 提出首个 Spike-driven VLA 框架，支持机器人操作的端到端直接训练，将脉冲神经网络（SNN）的事件驱动稀疏计算引入视觉–语言–动作建模。

  • 通过脉冲视觉编码器、脉冲指令编码器、多赢家脉冲融合模块与脉冲动作分块 Transformer，实现高效的多模态感知、跨模态融合与连续动作生成。
Card 03 核心贡献

核心贡献

  • 开发 SVE（Spiking Visual Encoder）与基于 BERT 的 SIE（Spiking Instruction Encoder），将视觉观测与语言指令编码为稀疏可靠的脉冲表示。
  • 提出 MWSF（Multi-Winner Spike Fusion），通过双向 top-k 赢家通吃脉冲路由抑制背景干扰，实现指令引导的场景理解并降低跨模态计算量。
  • 提出 SpikeACT（Spike Action Chunking Transformer），结合融合记忆与当前机器人状态，通过脉冲交叉注意力并行生成连续动作块。
  • 构建完整的 Spike-driven VLA 框架，支持直接训练，在 LIBERO 与 Meta-World 上以更少参数和更低能耗取得有竞争力的性能。
  • 在 LIBERO-Plus 上验证零样本分布偏移下的鲁棒性。
Card 04 方法描述

方法描述

  • 采用离散 LIF（Leaky Integrate-and-Fire）脉冲神经元模型，使用代理梯度（sigmoid、fast sigmoid、arctangent 等）实现脉冲域端到端训练。
  • 基于 Spiking Self-attention（SSA） 构建脉冲 Transformer，去除 Softmax，保持缩放并利用二进制脉冲的稀疏矩阵乘法。
  • SVE 基于共享脉冲视觉 Transformer，处理主视角与腕部视角双路观测，前两阶段使用 Conv Mixer 块提取局部特征，末阶段使用 SSA 模块。
  • SIE 使用脉冲 BERT 主干提取上下文语言特征，训练时冻结，采用掩码语言建模预训练。
  • MWSF 构建共享跨模态亲和矩阵，在视觉与语言两个方向分别执行 Top-k 多赢家选择（WTA_k），生成指令引导的视觉表示与视觉接地的指令表示，并通过残差连接与可学习通道缩放融合为场景记忆。
  • SpikeACT 使用 K 个可学习动作 token 作为查询，状态增强记忆作为键值，经脉冲交叉注意力与 WTA_k 稀疏路由后，通过时间平均读出与 tanh 输出 K 步连续动作块。
Card 05 数据集与资源

数据集与资源

  • 使用数据集：Meta-World（MT50）、LIBERO（Spatial/Object/Goal/Long 四个套件）、LIBERO-Plus（10,030 个扰动任务实例，覆盖 7 个扰动维度）、ImageNet-1K（视觉编码器预训练）。
  • 模型规模：0.15B 参数。
  • 计算量：Meta-World 上 10.5 GFLOPs，LIBERO 上 15.68 GFLOPs。
  • 训练配置：LIBERO 上训练 80K 步（含 10K 预热），有效批大小 256，预测 12 步动作块。

Card 06 评估与结果

评估与结果

  • 评估环境：Meta-World（50 任务，每任务 50 次 rollout）、LIBERO（每任务 50 次 rollout，共 2,000 次评估）、LIBERO-Plus（7 个扰动维度）。
  • 主要指标：任务成功率（Success Rate）、参数量、FLOPs、估计推理能耗（mJ）。
  • Meta-World 结果：平均成功率 72.4%，优于所有对比 ANN 基线，Medium 与 Hard 任务分别达 66.7% 与 81.7%；相比 SmolVLA (2.25B) 和 SmolVLA (0.45B) 分别高 4.2 与 15.1 个百分点，参数量仅为后者的 1/15 与 1/3；估计推理能耗仅 11.6 mJ。
  • LIBERO 结果：平均成功率 92.4%（Spatial 95.0%、Object 95.4%、Goal 96.6%、Long 82.4%），超过 OpenVLA 15.9 个百分点、SmolVLA 3.6 个百分点，接近 DreamVLA（92.6%）；相比 π₀ 参数量减少 95.3%。
  • LIBERO-Plus 结果：在仅 0.15B 参数下取得 53.2% 的总体成功率，优于多数 ANN 基线并接近更大规模 VLA 模型，表现出较强的分布偏移鲁棒性。
