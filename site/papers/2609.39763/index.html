Card 03 核心贡献

核心贡献

  • 直接的预测到运动（predictive-to-motion）建模范式：将连续 UAV 导航表述为从预训练视频模型中间预测表征直接解码相机运动，部署时无需完整未来视频合成。
  • 几何锚定的运动解码与预测蒸馏：提出几何条件化的运动读出模块，保留时空结构，并通过基于 rollout 配对的离线监督学习，在冻结视频与几何骨干的前提下预测相机轨迹。
  • FastDreamer 延迟感知连续执行框架：通过并行推理、飞行时间感知调度和时间戳感知的前瞻性交接（prospective handoff），打通轨迹预测与无人机连续执行。
  • 多场景综合验证：在基准测试、仿真、真实飞行、机载部署与消融实验中验证方法在连续与结构化 UAV 导航任务上的有效性。
Card 04 方法描述

方法描述

  • 骨干与读出接口：以 MiniMax H3 作为冻结视频世界模型骨干，提取 DiT block 15/25/35 的隐层特征；用冻结的 MoGe2 从首帧图像估计几何与度量尺度，二者可并行计算。
  • Grid-Motion 模块：在池化前保留时空布局，做两类关联——跨视频时间槽的时序运动关联（参考 u-1、u-4 槽位）与预测特征到首帧观测锚点的几何条件关联，经门控残差融合后池化为 312 个 motion-memory token（39×8）。
  • Geometry-Guided Trajectory Decoding（Latent2Pose）：用 38 个未来位姿 query 与 8 层 Transformer 解码器，输出 38 个未来位姿；位置头输出经场景尺度 $s_0$ 调制，旋转头经 Gram–Schmidt 正交化得到 SO(3) 旋转矩阵。
  • 几何引导预测蒸馏（GPD，S2）：非对称 teacher–student 训练。教师用 π³ 从完整视频 rollout 重建相机轨迹，并用 MoGe2 深度做尺度标定（median 比值 α）得到度量级参考轨迹；学生只用早期预测表征与首帧几何。
  • 三阶段训练：S0 视频骨干准备 → S1 导航感知读出预训练 → S2 几何引导预测蒸馏；训练期间视频骨干与 MoGe2 始终冻结，仅优化读出模块。
  • 损失函数：位置项 $\mathcal{L}_{pos}$（除以 stop-gradient 的 $s_0$ 归一化，鲁棒惩罚 ρ）+ 旋转项 $\mathcal{L}_{rot}$（SO(3) 测地距离平方），权重 $\lambda_R$。
  • DiffWAM-Flash 变体：仅保留调度索引 0 的特征，首次评估在 block 35 后即终止，大幅降低机载延迟。

Card 06 评估与结果

评估与结果

  • 评估指标：端点精度（endpoint accuracy）、轨迹精度（trajectory accuracy）、旋转精度（rotation accuracy）、闭环任务成功率（closed-loop task success）、执行效率（execution efficiency）。
  • 基准结果：在 DiffWAM-1000 上达到轨迹 RMSE 0.3492 m，端点成功率 74.40%。
  • 真实世界表现：完成受限穿越、环绕（orbiting）、S 形飞行、降落及多阶段导航等复杂行为；包含长时程真实导航实验。
  • 机载推理：DiffWAM-Flash 在 NVIDIA Jetson AGX Thor 上模型流水线延迟仅 1.08 s。
  • 消融实验：涵盖不同 WAM 架构、特征层选择、预测计算量、训练数据规模、损失函数与深度归一化方式。
  • 结论：预测性视频表征可被高效锚定为连续 3D 运动，是"先生成再重建"导航流水线的直接替代方案。项目主页：https://zzmmzzm.github.io/diffwam.github.io/
