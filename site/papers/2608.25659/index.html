GaussianDream++: Efficient 3D Gaussian World Modeling for Robotic Manipulation

2026-08-26 · 原文 · 翻译 · 2608.25659

Card 03 核心贡献

核心贡献

  • 紧凑的策略原生高斯世界建模：将 GaussianDream 的密集 VGGT/TGE 前缀替换为仅 20 个直接嵌入 PaliGemma 主干的 World State Tokens 和 World Prediction Tokens，使 Action Expert 通过原生注意力路径使用世界监督表征。
  • 角色结构化的当前与未来表示：World State Tokens 重建当前世界（Current World），World Prediction Tokens 表示共享高斯原语上的短期演化；静态-动态分解保留了持久场景结构，将残差运动集中于交互相关区域。
  • 高效的异步监督与鲁棒控制：高斯解码与渲染仅限训练阶段，部署时移除 World Representation Head、渲染器及辅助目标，无需在线高斯解码或未来 rollout。
  • 显著的性能提升：在 LIBERO 上达到 98.6% 成功率，在 LIBERO-Plus 上达到 87.8%，在相机（Camera）和布局（Layout）偏移场景下较 GaussianDream 分别提升 2.8 和 1.6 个百分点。
Card 04 方法描述

方法描述

  • 基于 PaliGemma 主干和 flow-matching Action Expert，在多模态前缀中插入 16 个 World State Tokens 和 4 个 World Prediction Tokens。
  • 训练时使用轻量级 World Representation Head 将世界令牌解码为当前世界（Current World）和未来预测（Future Prediction），通过可微高斯溅射渲染提供 RGB、深度、覆盖率等稠密监督。
  • 采用几何-外观分解策略：几何分支预测度量深度和非外观属性，外观分支在 stop-gradient 几何特征上运行，防止光度捷径干扰度量结构。
  • 未来预测采用原始对齐残差公式，预测以当前世界为共享模板、仅预测中心位移，并通过静态-动态门控（运动系数）将预测集中在交互相关区域。
  • 联合优化目标：动作损失、当前世界损失和未来预测损失共同约束世界令牌，使其同时具备物理结构性和控制有用性；未来观测仅用于监督目标，不进入策略前向传播。

Card 06 评估与结果

评估与结果

  • LIBERO 标准任务：GaussianDream++ 平均成功率 98.6%，优于复现 π0.5（96.9%）1.7 个百分点，优于 GaussianDream（98.4%）0.2 个百分点。
  • LIBERO-Plus 零样本鲁棒性：Overall 得分 87.8%，为表中最优；较复现 π0.5 提升 2.3 个百分点，较 GaussianDream 提升 0.8 个百分点。
  • 几何敏感偏移场景：Camera 偏移从 73.2%（π0.5）提升至 80.1%，提升 6.9 点；Layout 偏移从 87.7% 提升至 90.0%，提升 2.3 点；Noise 偏移从 89.9% 提升至 94.2%。
  • 真实世界操作：平均成功率从复现 π0.5 的 29.2% 提升至 GaussianDream++ 的 52.5%；其中 Eggplant-to-Pink-Plate 任务从 33.3% 提升至 58.3%，Bowl-Proximity 任务从 25.0% 提升至 46.7%。
  • Robot 偏移局限：在 Robot（机械臂形态）偏移下性能仍低于复现 π0.5，表明当前方法在几何相关偏移上增益明显，但具身泛化仍是挑战。
