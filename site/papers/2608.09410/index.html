Card 02 论文概述

论文概述

  • 提出 HyMeS（Hybrid learning framework with Memory-management coding agents to Steer VLAs），一种面向记忆依赖型机器人操作任务的混合学习框架
  • 核心思路是将运动技能学习与记忆策略学习解耦：技能在权重空间通过梯度模仿学习获得，记忆策略在代码空间通过启发式学习由编码智能体迭代更新
  • 解决的核心问题是：现代 VLA 策略本质上是马尔可夫的，只能基于当前观测或短窗口决策，而真实操作往往需要从长程交互历史中保留和推理任务相关信息
Card 03 核心贡献

核心贡献

  • 将记忆依赖操作问题形式化为混合学习问题，实现运动技能与记忆策略的完全解耦，避免为每个历史依赖配置采集示范数据
  • 提出 HyMeS 框架，利用可执行符号记忆通过记忆条件下的去噪约束来引导马尔可夫 VLA，无需更新策略权重
  • 引入多模态阶段进度验证机制（PACE），结合本体感觉信号与多帧 VLM 判断，闭环更新记忆状态
  • 在 RoboMemArena 上，HyMeS 将 CSR 从 52.5% 提升至 66.2%，TSR 从 41.3% 提升至 60.1%，分别超越 PrediMem 4.5 和 14.5 个百分点
  • 在 SO-101 真实机器人上，将 TSR 从 25.7% 提升至 57.1%，验证了框架在硬件上的有效性
Card 04 方法描述

方法描述

  • 权重空间技能学习：使用预训练 VLA（如 π0.5）作为基础，通过 flow-matching 目标在专家示范上进行微调，学得接触丰富的运动技能；微调完成后权重永久冻结
  • 代码空间记忆策略学习：编码智能体（基于 Claude/Codex 类模型）维护可执行程序 P=(C, V, U)，包含约束选择规则、事件验证规则和记忆更新规则，通过 rollout 反馈的启发式学习迭代修订程序，即 P(n+1)=Edit(P(n), ξn, bn)
  • 记忆条件行为引导：符号记忆状态 s_t 选择当前阶段的微分约束 R_t，其梯度注入 flow-matching 速度场以引导去噪过程，即 v̂ = v_θ*(a^τ, τ \|o_t, ℓ) + λ_t ∇_{a^τ} R_ρt(a^τ, o_t; s_t)；还设计了随残差衰减的引导权重调度
  • PACE 多模态验证：本体感觉证据检测动作相关运动模式，视觉证据由 Qwen3-VL-8B 结合最多五帧 RGB 图像判断阶段完成；两者取或操作后在滑动窗口（w=5, k=3）中投票，抑制孤立错误
  • 关键创新点：将记忆以代码形式与 VLA 去噪过程内部耦合，实现逐动作的引导而非粗粒度子任务指令；VLA 保持马尔可夫性，长期任务状态由外部程序承载
Card 05 数据集与资源

数据集与资源

  • 使用 RoboMemArena 基准的修正版 12 任务协议，涵盖 transferring、counting、sequential execution 和 occlusion 四类记忆能力
  • 评估规模为 160 个仿真 episode（每个 transferring/counting 任务 10 episodes，occlusion 任务 15，sequence 任务 20）
  • 真实实验在 SO-101 机器人上进行 3 个记忆依赖任务，共 35 次试验
  • 基础策略使用 π0.5 的 RoboMemArena 微调 checkpoint（通过 OpenPI 仿真）及 SO-101 示范微调权重（通过 LeRobot）
  • 编码智能体使用 Opus 4.8 模型，VLM 使用 Qwen3-VL-8B，关键点提取使用 SAM 和 DINOv2，深度反投影基于 VLS 方法
Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（TSR）和累计成功率（CSR，衡量阶段级进度）
  • 基线对比：相同权重的 π0.5 策略和 RoboMemArena 自带的记忆增强基线 PrediMem
  • 仿真实验结果：HyMeS 在相同策略权重下将 CSR 从 52.5% 提升至 66.2%、TSR 从 41.3% 提升至 60.1%；超越 PrediMem 4.5 CSR 点和 14.5 TSR 点
  • 类别分析：counting 任务 TSR 提升 30.0 点、transferring 提升 26.6 点、sequence 提升 22.5 点；occlusion 是最难类别，但 HyMeS 仍保持 CSR 并提升 TSR 7.0 点
  • 真实机器人：总 TSR 从 25.7% 提升至 57.1%，三个任务分别提升 50.0、26.7 和 20.0 个点
  • 消融实验：rollout 强化学习带来 CSR +8.5、TSR +18.4 点；视觉单模态验证降低 CSR 16.0 点和 TSR 21.7 点，本体感觉单模态降低 CSR 8.8 点和 TSR 8.4 点，验证多模态互补的必要性
  • 失败模式分析：正确记忆状态下仍可能因预抓取姿态的侧向偏差、按钮任务中的垂直抖动导致意外重复按压、按压深度不足未被 PACE 识别等原因失败，说明任务表现仍受限于运动执行与事件验证能力
