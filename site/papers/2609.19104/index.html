rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference

2026-09-16 · 原文 · 翻译 · 2609.19104

提出 rMuscle，一个受人类肌肉记忆启发的实时 VLA（Vision-Language-Action） 推理框架，利用跨任务执行的相似性实现计算与权重访问复用。 目标是在不损失任务成功率的前提下降低 VLA 推理延迟，提升机器人响应速度与运动平滑性。 解决现有 VLA 推理框架未充分利用具身工作负载特性、且未分别针对 VLM prefill 计算密集 与 action denoising 内存密集 瓶颈进行优化的问题。

Card 02 论文概述

论文概述

  • 提出 rMuscle，一个受人类肌肉记忆启发的实时 VLA（Vision-Language-Action） 推理框架，利用跨任务执行的相似性实现计算与权重访问复用。
  • 目标是在不损失任务成功率的前提下降低 VLA 推理延迟，提升机器人响应速度与运动平滑性。
  • 解决现有 VLA 推理框架未充分利用具身工作负载特性、且未分别针对 VLM prefill 计算密集 与 action denoising 内存密集 瓶颈进行优化的问题。
Card 03 核心贡献

核心贡献

  • 发现重复执行相同任务时，FFN 输入与神经元激活模式高度相似，为跨执行计算复用提供机会。
  • 设计端到端双阶段缓存推理系统：Context Cache 加速计算密集的 VLM prefill，Action Cache 加速内存密集的 action denoising。
  • 提出异步在线重建、滑动窗口预取、组共享神经元掩码等技术，降低缓存内存占用与访问开销。
  • 在 3 个 VLA 模型、2 个仿真基准和 92 个任务上评估，在 RTX 4090 和 Jetson Thor 上分别取得最高 1.29× 和 1.42× 加速，同时保持原始策略成功率。
Card 04 方法描述

方法描述

  • Context Cache：复用参考执行中视觉 token 的 FFN 输出，仅重算输入漂移大的 token；指令与机器人状态行始终重算，注意力保持稠密。
  • Action Cache：基于参考执行的神经元激活模式预测重要神经元，仅加载并计算其权重，其余神经元用当前策略调用中较早的稠密锚点输出近似。
  • 缓存管理：异步在线重建与机器人动作执行重叠；基于视觉特征和机器人状态历史检索参考；利用时间局部性维护滑动窗口 GPU 工作集；连续去噪步骤分组共享神经元掩码。
  • 实现细节：离线 profiling 确定重算比例 ρ_p 和 ρ_n，并构建组神经元掩码；CUDA 侧流重叠检索与权重收集，主流程执行 VLM prefill 和去噪。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（40 个任务，Spatial/Object/Goal/Long 四套件）、RoboTwin（50 个任务）、物理任务：双机械臂 ALOHA 协作拾取放置、单臂装配线包装（DOBOT 和 Franka）。
  • 模型：π0.5、GR00T N1.6、X-VLA；缩放实验使用 Gemma 系列配置 (VLM, denoise) = (2B, 0.3B)、(2B, 2B)、(7B, 2B)、(7B, 7B)。
  • 硬件平台：RTX 4090（24 GB 显存）+ Intel Core i7-11700 + 32 GB RAM；Jetson Thor（128 GB 统一内存）。
  • 软件环境：PyTorch 2.6.0/CUDA 12.4 与 PyTorch 2.8.0/CUDA 13.0；使用 BF16/FP16，无量化；仅推理评估，无训练。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO、RoboTwin 仿真基准及两个物理机器人任务；基线包括 torch.compile、vla.cpp、FlashRT、NIRVANA、DP-Cache 和 rMuscle w/o Cache Repo。
  • 主要指标：推理延迟（Hz）、相对加速比、任务成功率（SR，%）、平均策略调用次数。
  • 关键结果：RTX 4090 上，π0.5、GR00T N1.6、X-VLA 分别达到 28.1、51.0、35.7 Hz，相对 SOTA 引擎加速 1.29×、1.20×、1.50×；Jetson Thor 上分别达到 13.4、17.5、19.7 Hz，加速 1.42×、1.23×、1.43×。
  • 策略质量：在 LIBERO 上与 vanilla 和 DP-Cache 平均成功率持平，优于 NIRVANA；在 RoboTwin 50 个任务和物理任务上保持成功率。
  • 模型规模扩展：从最小到最大配置，加速从 1.3× 提升到 1.6×（RTX 4090），从 1.4× 提升到 1.9×（Jetson Thor）。
  • 开销：在线重建约 25 ms/条，RTX 4090 可容纳超 100 个重建条目；15 动作块在 30 Hz 下提供约 500 ms 重建窗口，可准备约 20 个条目。
