Card 02 论文概述

论文概述

  • 提出 UniW(A)M：一个基于扩散 Transformer 的混合专家（MoE）统一框架，将动作条件世界模型（AC-WM）与四种世界-动作模型（WAM）接口整合在同一骨干网络中联合训练。
  • 解决的核心问题是：世界模型与世界-动作模型虽共享物理动力学与交互语义，但通常被孤立训练，导致预测与控制之间无法复用知识，数据效率低下。
  • 进一步解决部署问题：不同 WAM 接口在未来视频预测使用方式与推理开销上差异显著，需要按执行片段（chunk）动态选择最合适接口，以兼顾任务成功率与执行效率。
Card 03 核心贡献

核心贡献

  • 提出 UniW(A)M 统一框架，通过视频–动作可见性掩码（video–action visibility masks）统一 AC-WM 与四种 WAM 接口，共享动力学专家与原子能力专家，使各接口保留各自的条件通路。
  • 提出 CATR（Capability-Aligned Token Routing）：按模态与预测角色为视频/动作目标 token 组分配可用专家集合，并在集合内学习混合权重，实现能力对齐的专家路由。
  • 提出 PAIR（Plug-in Adaptive Interface Router）：在骨干网络冻结的前提下，仅用少量目标任务的 chunk 场景离线训练一个轻量分类头，实现 chunk 级接口自适应选择。
  • 实验验证：AC-WM 联合训练对所有四种动作接口（包括部署时不预测未来视频的接口）均有增益，统一模型在动作条件世界预测上领先。
  • PAIR 将分布外（OOD）平均成功率从 63.3% 提升至 76.7%，并改善执行效率。
Card 04 方法描述

方法描述

  • 统一接口建模：将轨迹（观测历史、语言指令、未来观测、未来动作）组织为五种接口，通过视频–动作注意力掩码显式指定各接口的条件依赖关系。
  • 四种原子能力：VGM（无动作视频预测）、VLA（直接动作生成）、WM（动作条件视频预测）、IDM（视频条件动作生成）；视频类目标使用 VGM/WM 专家，动作类目标使用 VLA/IDM 专家，并共享公共专家。
  • 五种接口：AC-WM、Joint-WAM（VGM+IDM，双向可见、联合去噪）、IDM-WAM（VGM+IDM，单向顺序依赖）、Action-Centric-WAM（VLA+WM，动作先验、视频仅作辅助监督）、Action-Only-WAM（VLA+VGM，未来跨模态注意力关闭，部署时不生成未来视频）。
  • 架构：将扩散 Transformer 的稠密 FFN 子层替换为 MoE 模块，并由预训练稠密子层初始化；每个接口使用各自的注意力掩码。
  • PAIR 训练目标：以四接口对同一 chunk 的动作预测 MAE 归一化后构造软标签，在误差最小的接口 1% 范围内优先选择更快接口；用交叉熵训练路由器，部署时按最高概率选择接口，骨干保持冻结。
  • 关键技术点：接口级可见性掩码、能力对齐的组级专家路由（区别于 sample-level 路由）、以及冻结骨干下的 plug-in 路由适配。

Card 06 评估与结果

评估与结果

  • 真实世界（标准配置）：IDM-WAM 平均成功率 88.3%，较最强基线 WorldScape Policy 2.0（76.7%） 提升约 11.7 个百分点；四种 UniW(A)M 接口均超过该基线（Joint-WAM 86.7%、Action-Centric-WAM 81.7%、Action-Only-WAM 80.0%）。
  • LIBERO：平均成功率 97.5%，其中 Spatial 子任务达 99.2%。
  • RoboTwin 2.0：仅用干净数据训练时，C2C 达 84.38%，C2R 达 66.60%，C2R 超过基线 π0.5 达 20.60 个百分点。
  • WorldArena：在三个真实任务上 EWMScore-P 均为最高，动作条件世界建模全面领先 Cosmos-Predict 2.5 与 CtrlWorld。
  • OOD 适配：PEAR 路由仅适配（骨干冻结）将平均成功率由最强单接口的 63.3% 提升至 76.7%；PAIR 在接近阶段偏好 Action-Centric/Action-Only-WAM，在接触与精细操作阶段更多选择 Joint-WAM/IDM-WAM。
  • 效率：chunk 推理时间（除以 16 步）Action-Centric-WAM 154.3 ms、Action-Only-WAM 225.8 ms、Joint-WAM 428.1 ms、IDM-WAM 532.7 ms；PAIR 集成预测约 2 ms，含共享专家特征计算的路由平均约 63 ms；UniW(A)M+PAIR 处于成功率–耗时 Pareto 前沿（76.7% 成功率、308.9 s 平均完成时间）。
  • 消融：去除 AC-WM 共同训练使 Joint-WAM/IDM-WAM 平均成功率下降 15.0 个百分点，Action-Centric-WAM 与 Action-Only-WAM 分别下降 31.7 与 43.3 个百分点；单一稠密 DiT 基线最高仅 16.7%；sample-level 路由下两个纯动作接口仅 10.0%，CATR 将其提升至 81.7% 与 80.0%。
