Decoupling Intention from Trajectory: A Representational Deduction Framework for World Action Models

2026-08-07 · 原文 · 翻译 · 2608.06994

论文提出 PILOT（Physical Inference for Latent Optimized Trajectories）框架，针对世界动作模型（WAMs）中高层物理状态演化与低层轨迹生成之间存在表征纠缠（Representational Entanglement）的问题。 现有 WAM 的视觉分支倾向于预测静态视觉观测，而非反映动作交互下世界状态演化的潜在转换信息，导致 Action Model 的联合优化偏向视觉重建，削弱了世界演化建模对动作生成的预测能力。 PILOT 通过引入表征演绎（Representational Deduction, RD）机制，将潜在状态转换信息压缩为可学习的运动语义 token（Motion-CoT），在推理空间中作为思维链（Chain-of-Thought）引导细粒度动作轨迹生成，从而实现高层运动意图与低层轨迹的解耦。

Card 03 核心贡献

核心贡献

  • 提出 PILOT，一种新型 WAM 框架，通过 Representational Deduction 机制解耦高层运动意图与低层轨迹生成，并将潜在状态转换信息内化为 Motion-CoT，以缓解表征纠缠。
  • 引入因果动力学引擎（Causal Dynamics Engine, CDE），结合因果解耦注意力机制，基于 VJEPA2-AC 潜在空间赋予动作模型显式物理因果性，同时绕过推理时像素级未来帧重建的计算瓶颈。
  • 在 LIBERO 和 RoboCasa-GR1 基准上分别取得 97.9% 和 62.6% 的成功率，达到最先进水平；真实世界操作任务平均成功率达 83.1%。
  • 相比"先预测后动作"（Predict-then-Act）范式，运动-CoT 推理路径将推理延迟降低 90%，展现出卓越的泛化能力和效率优势。
  • RD 机制引入的丰富状态转换监督信号有效缓解动作生成的稀疏监督问题，可作为高效的 few-shot 真实机器人微调策略。
Card 04 方法描述

方法描述

  • 框架由三个协同组件构成：World-Model 分支（基于预训练 Wan2.2）、Action Model 分支（从零训练的 Perceiver 风格流匹配头）、RD 分支（基于冻结 VJEPA2-AC 编码器和可训练 CDE）。
  • 采用可学习运动语义查询 token（K=64, d=1024），通过因果解耦注意力机制实现不对称信息流：运动语义可条件化动作解码，同时阻断反向噪声泄漏。
  • 使用流匹配（Flow-Matching）动作解码，以条件速度目标监督动作 chunk 生成；推理时从高斯噪声出发，通过欧拉积分条件于运动语义 token 生成动作。
  • CDE 以运动语义和本体状态为条件，在当前 VJEPA2-AC 表征基础上预测未来状态表征，通过 SmoothL1 损失进行监督，使动作模型学习"状态如何随动作演化"而非仅"未来外观如何"。
  • 世界模型分支保留生成能力，通过辅助未来帧潜在预测目标（变化加权损失）维持指令 grounded 的未来先验，但在推理时禁用生成管线以避免视觉瓶颈。

Card 06 评估与结果

评估与结果

  • LIBERO 基准：平均成功率 97.9%，超越 Motus (8B, 97.7%)、Fast-WAM (6B, 97.6%)、π₀.₅ (3.5B, 96.2%) 等所有基线；在 Goal (98.1%) 和 Long-horizon (97.2%) 套件上表现突出。
  • LIBERO-Plus 基准：总成功率 81.0%，超越 PokeVLA (79.3%)，在 Robot (70.0% vs 46.1%) 和 Layout (82.0% vs 77.2%) 维度提升显著，验证了 RD 学习的是转换动力学而非表观特征。
  • RoboCasa-GR1 基准：成功率 62.6%，达到最先进水平。
  • 真实世界评估：平均成功率 83.1%，验证了模拟到真实的迁移能力及 few-shot 微调有效性。
  • 推理延迟：Motion-CoT 范式相比 Predict-then-Act 范式降低 90% 延迟。
  • 表征分析：t-SNE 显示 PILOT 形成清晰的动作类型聚类簇（隔离运动意图与静态细节）；PCA 显示 PILOT 聚焦于交互区域的高方差动态状态转换，而基线受背景噪声干扰。
