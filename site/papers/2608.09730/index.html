Card 03 核心贡献

核心贡献

  • 提出 World Tokens 训练时世界建模架构：联合训练视频世界模型与 VLA 策略，部署时移除整个视频分支，保留预测性监督带来的收益且保持 VLA 级推理延迟
  • 设计 World Adapter 模块：将 VLM 输出序列映射为 256 个世界 token，并作为动作专家的唯一视觉-语言上下文，使视频未来监督直接塑造控制表征
  • 引入结构锚定（Canny 边缘图）替代 RGB 首帧，抑制视频分支对表观信息的依赖，迫使世界 token 携带丰富的语义与演化相关内容
  • 实验证明 2B 模型无需具身动作预训练即可在 LIBERO 达到 98.2%，在 SIMPLER 上取得最佳报告均值，并将真实机器人成功率从 59.4% 提升至 76.0%
Card 04 方法描述

方法描述

  • World Adapter 采用 Perceiver resampler 设计，通过 256 个可学习查询与 VLM 序列进行交叉注意力，输出固定数量的世界 token
  • 动作专家为 DiT 流匹配模型，仅以世界 token 为条件生成 8 步动作块，无并行访问完整 VLM 序列（独占路径）
  • 视频去噪器使用预训练 Cosmos Predict2.5-2B，以投影后的世界 token 为交叉注意力条件，以 Canny 边缘图的 VAE 潜码为结构锚
  • 训练损失为动作流匹配损失与视频去噪损失加权和（λ_w=5），两个梯度路径汇聚于世界 token，强制表征同时满足预测与决策需求
  • 部署时仅需 VLM + World Adapter + 动作专家，动作块生成使用 4 步流积分
Card 05 数据集与资源

数据集与资源

  • LIBERO：四个语言条件操作套件（Spatial、Object、Goal、Long），共 40 个任务，每任务 500 条演示，评估 2000 个回合
  • SIMPLER：基于 BridgeV2 和 Fractal 真实机器人数据训练，在视觉匹配模拟器中评估 WidowX 和 Google Robot 任务
  • R1 Pro 真实机器人：Galaxea R1 Pro 右臂，头戴鱼眼相机裁剪视图，8 维关节+夹爪动作，4 类水果放入篮子的任务
  • 模型配置：Qwen3-VL-2B-Instruct 为 VLM 骨干，Cosmos Predict2.5-2B 为训练专用视频去噪器，DiT-B 动作专家，World Adapter 含 256 查询
  • 延迟测量硬件为 24GB RTX 5090 D
Card 06 评估与结果

评估与结果

  • LIBERO 平均成功率 98.2%，其中 Spatial 99.6%、Object 98.8%、Goal 97.4%、Long 97.0%；无需具身预训练即超过 4B StarVLA 0.4 个百分点
  • 对比 Qwen-GR00T 基线（96.9%），提升集中在 Long 套件（97.0% vs 92.8%），表明世界建模对多阶段任务改善显著
  • 消融实验显示：移除视频监督 Long 降至 95.0%；添加 VLM 旁路降至 94.1%；FFN 适配器降至 93.4%；RGB 锚替代 Canny 降至 91.5%
  • SIMPLER：WidowX 平均 71.5%，Google Robot 平均 82.1%，均为最佳报告结果
  • 真实机器人成功率从 59.4% 提升至 76.0%，每动作块延迟 61.85ms，与 π0.5 相比保持 1.1× 延迟范围内
