2026-09-02 · 原文 · 翻译 · 2609.02653

Card 03 核心贡献

核心贡献

  • 提出 HINT 框架：将高层语言指令转化为跨多视角的密集连续语义视觉线索，实现意图-动作对齐。
  • 提出模式感知的语义感知调度（Pattern-Aware Perception Scheduling）：以操作模式转移作为语义推理触发点，并自适应选择优先相机视角，降低推理延迟。
  • 提出语义承诺与视觉跟踪（Semantic Commitment and Visual Tracking）：在模式切换时由任务管理器解析当前子任务与目标实体，并在模式内用 SAM2 持续跟踪目标，低置信度时触发重定位。
  • 提出无参数语义注入接口（View-Routed Semantic Intent Injection）：通过像素级视觉高亮与 token 级注意力先验（attention prior）两条互补通路向动作策略传递意图，不修改动作骨干网络。
  • 实验表明 HINT 在三项长时程任务及语义组合式 OOD 设定下大幅提升两个基础策略的意图分数与成功率，同时保持低延迟控制。
Card 04 方法描述

方法描述

  • 操作模式定义：将操作行为划分为四种与任务无关的模式——free move（自由移动）、pre-contact（预接触）、transport contact（搬运接触）、dexterous contact（灵巧接触），每种模式对应不同感知源优先级（全局视角/腕部视角/力觉触觉）。
  • Pattern Router：轻量级多模态网络，以共享 ResNet-18 编码多视角图像、GRU 分支建模本体感受与关节力矩时序，经门控融合联合预测模式类别与模式内进度，用 CE+MSE 损失训练，并在三个任务数据上联合训练。
  • Task Manager：基于 Qwen3-VL，在重置时生成有序子任务计划，并在每次模式转移时结合执行上下文解析当前子任务指令与活动目标实体。
  • Semantic Grounder 与跟踪：结合 Grounding DINO（物体级定位）与 Qwen（细粒度语义/空间关系解析）在多视角中生成目标边界框；SAM2 在模式内持续传播目标掩码，低置信度触发重新定位。
  • 意图注入：在路由视角中按 λ=0.32 透明度叠加目标掩码高亮（形成外观不变的外部指代），并将目标相关性先验以 head-shared bias 注入视觉编码器中间层自注意力与动作解码器 action-to-vision 注意力，采用"中间层集中、外部稀疏"的注入层选择策略。
Card 05 数据集与资源

数据集与资源

  • 三项语言条件任务：水果蔬菜分类（Fruit-Vegetable Sorting）、单词拼写（Word Spelling）、插销入孔（Peg-in-Hole Insertion），分别采集 50/80/150 条演示（30 Hz 双臂遥操作）。
  • 机器人平台：双 AgileX PiPER 机械臂 + 三台 Intel RealSense D435 RGB-D 相机（1 个全局视角 + 2 个腕部视角）。
  • 基础动作策略：π0.5 与 Wall-OSS-0.5 两个大规模预训练策略，HINT 不向其中添加可训练参数。
  • 训练与评估资源：2× NVIDIA RTX 3090 GPU 工作站。
Card 06 评估与结果

评估与结果

  • 评估指标：Intention Score（IS）、Subtask Success Rate（Sub. SR）、Full-Task Success Rate（Full SR）；每任务 ID 测试 15–20 次，OOD/消融各 10 次。
  • ID 结果（π0.5 + HINT vs 基础策略）：排序任务 IS/Sub.SR/Full SR 达 91.2/91.2/60.0%（基础 52.2/52.2/10.0%）；拼写任务达 97.9/95.7/86.7%；插销任务 IS 从 35.0% 提升至 100.0%，Full SR 从 5.0% 提升至 40.0%。
  • OOD 结果：π0.5 平均 IS 从 41.4% 提升至 89.4%、Sub.SR 从 36.2% 提升至 74.3%，三项任务均从 0.0% Full SR 提升至 30.0%；Wall-OSS-0.5 同样获得稳定增益。
  • 视觉捷径实验：π0.5 在固定映射"easy"设定下 Sub.SR 达 89.5%，在可变映射"mixed"设定下降至 52.2%，HINT 使 mixed 设定 Sub.SR 提升 38.5 个百分点，说明其能克服视觉捷径、恢复语言意图主导。
  • Pattern Router 可靠性：模式预测成功率 ID/OOD 为 94.7%/91.1%，子任务切换成功率达 95–100%（260 次转换中 251 次正确）。
  • 延迟分析：基础策略 185 ms/帧、Pattern Router 14 ms、SAM2 43 ms、Grounding DINO 227 ms、Qwen 431 ms；推理帧（DINO/Qwen）426/630 ms，而跟踪帧仅 242 ms，辅助开销从 445 ms 降至 57 ms（降低 61.6%）。
  • 消融发现：仅高亮（无注意力先验）或仅注意力（无高亮）的单一通路效果均低于完整 HINT；连续跟踪使子任务/全任务完成时间分别降低 25.3%/21.5%，腕部视角使 Full SR 从 10.0% 提升至 30.0%。
