Card 03 核心贡献

核心贡献

  • 提出 PAIR 通用训练框架，通过联合图像-射线表示学习释放本体感受对齐的收益。
  • 设计基于 Plücker 坐标 的相机射线位置编码，将末端执行器相对与机器人基座相对的射线注入视觉 token。
  • 使用基于机器人状态相似度的监督对比学习，对齐不同视角下相似本体感受状态的图像-射线表示。
  • 证明 PAIR 可同时提升 Diffusion Policy 与 SmolVLA 在未见视角下的操作成功率。
  • 在多个仿真基准和真实世界任务中系统评估视角变化下的鲁棒性，并分析射线模态、损失权重与注意力行为。
Card 04 方法描述

方法描述

  • 将每个视觉 token 对应的相机射线用 Plücker 坐标 表示，并构造两种射线：相对末端执行器的 \(r^{CE}\) 与相对机器人基座的 \(r^{CB}\)。
  • 射线特征经轻量卷积网络编码后，与图像 token 拼接，并通过一个 identity-initialized 线性投影 注入原视觉特征，作为选择性位置嵌入。
  • 该投影初始化为保留原图像特征、射线贡献为零，因此对预训练 SigLIP/SigLIP2 编码器只增加极小架构改动。
  • 使用监督对比学习，将本体感受状态相似（末端位置、姿态四元数、夹爪宽度）的观测在表示空间中拉近。
  • 将几何距离转换为基于百分位的软正样本权重，并优化加权 InfoNCE 损失 \( \mathcal{L}_{PA} \)。
  • 最终目标为行为克隆损失与本体感受对齐损失的组合：\( \mathcal{L}_{total}=\mathcal{L}_{BC}+\lambda_{PA}\mathcal{L}_{PA} \)。
Card 05 数据集与资源

数据集与资源

  • MimicGen：使用 Square、Three Stack、Three Piece Assembly 三个单任务，D1 分布，每任务 1,000 条示范。
  • AlohaGym：使用双臂 Aloha 平台的 cube transfer 任务，共 100 条示范。
  • LIBERO：四个任务套件 Object、Goal、Spatial、Long，共 130 个任务、6,500 条示范。
  • 真实世界：使用 Franka Research 3 机械臂与两个 RealSense D435 相机，三个桌面任务，每任务 100 条 VR 遥操作示范。
  • 策略模型包括带预训练 SigLIP2 编码器的 Diffusion Policy，以及微调的 SmolVLA。
  • 论文未明确报告模型参数量与具体 GPU/TPU 型号；训练设置为 DP 200K 步、SmolVLA 160K 步，PAIR batch size 为 192。
Card 06 评估与结果

评估与结果

  • 评估覆盖单任务/多任务、单视角/多视角、单臂/双臂，以及真实世界随机相机位姿场景。
  • 主要指标为任务成功率；真实世界同时报告子任务完成率与最终任务成功率。
  • 摘要报告 PAIR 在仿真与真实世界中分别比无射线条件的 BC 基线高 12.7 与 26.7 个百分点。
  • 单任务仿真中，PAIR 带射线条件平均最大成功率比无射线 BC、带射线 BC、无射线 PAIR 分别高 16.2、9.1、9.5 个百分点。
  • LIBERO 上 PAIR 平均成功率达 88.9%，比带射线 BC 高 5.6 个百分点。
  • 真实世界三个任务中，PAIR 带射线条件平均子任务完成率为 76.7%、最终任务成功率为 57.8%，显著优于各基线。
  • 消融显示末端执行器相对与基座相对射线均重要；移除基座相对射线在 Aloha 上导致 18.8 个百分点下降，移除末端相对射线导致 7.0 个百分点下降。
