Card 03 核心贡献

核心贡献

  • 提出 V-JEPA Policy：在冻结 V-JEPA 编码器的预测隐空间上，单阶段从头联合训练指令条件的未来隐变量预测器与流匹配动作专家，实现不依赖预训练视觉生成器的有效 WAM 学习。
  • 开展跨基准评测与受控分析：在共享下游框架与训练预算下，V-JEPA 预测性视觉隐变量优于判别式（DINOv2/DINOv3）、重建式（WAN2.2 VAE）和视频理解导向（InternVideo3）的替代方案，且在分布偏移下优势更显著。
  • 证明仅用 DROID 视频–指令对（无动作标签）预训练预测器，即可在同一隐空间内迁移未来建模知识，在相同下游预算下将 LIBERO-Plus 成功率从 79.25% 提升至 91.50%，超过延长训练得到的 81.64%。
  • 以仅 0.9B 总参数（0.6B 可训练） 的规模，在 LIBERO、LIBERO-Plus、RoboCasa-GR1 及真实双臂平台上取得与代表性 WAM/VLA 基线有竞争力的表现。
Card 04 方法描述

方法描述

  • 固定视觉空间：使用冻结的 V-JEPA 2.1 编码器定义隐空间；按编码器时间 tubelet 大小（2 帧）构造最小观测上下文，把未来 tubelet 位置设为掩码区域，目标路径用同一冻结编码器处理完整视频并归一化后取未来位置作为预测目标。
  • 未来查询预测器：沿用 V-JEPA 2 预测器架构，从头训练；将上下文隐变量与可学习未来查询 token 拼接，通过双向自注意力联合更新，采用 3D RoPE 编码时空坐标，并加入可学习视角嵌入区分相机。
  • 指令与状态条件：用冻结 T5 编码器编码任务指令，与本体状态 token 拼接成条件序列；每个预测器块执行视觉自注意力、对该序列的交叉注意力与 FFN。
  • 预测–动作耦合：不直接使用最终未来隐变量预测，而是把预测器各层上下文位置的 key–value 状态（保留 3D RoPE 的 key 与未旋转的 value）作为接口，条件化动作专家。
  • 流匹配动作生成：采用 Mixture-of-Transformers（MoT） 架构，预测器与扩散 Transformer 动作专家参数分离、层数一致；动作 token 可同时关注上下文 KV 与动作 token，而预测器 token 不能关注动作 token；以 v = a_t − ε 为流匹配目标。
  • 联合训练与推理：单阶段联合优化未来隐变量回归损失（L1，λ=1）与动作流匹配损失（MSE）；动作损失会经上下文接口反向传播到预测器。推理采用 "imagine-then-act"：一次预测器前向构造并缓存上下文接口，再用 10 步 Euler 积分 仅评估动作专家。

Card 06 评估与结果

评估与结果

  • 评估指标：所有基准均报告成功率（%），真实任务每项 20 次试验。
  • LIBERO / LIBERO-Plus：从头训练版本达 97.3%（LIBERO 平均）与 79.3%（LIBERO-Plus），接近更大的生成式 WAM，并与带动作预训练的 VLA 基线竞争；使用预测器预训练后提升至 LIBERO 98.7%、LIBERO-Plus 91.5%。
  • RoboCasa-GR1：从头训练达 50.92%，超过 StarVLA-π、GR00T N1.6（47.60%）和 π0.5（37.00%），低于 ABot-M0（58.30%）；预测器预训练后升至 55.58%。
  • 真实世界双臂：从零策略在 Table Cleanup / Saucer Racking 达 55% / 35%，与 FastWAM（60%/35%）相当；预测器预训练后提升至 75% / 85%，平均成功率从 45% 升至 80%。
  • 视觉基础对比：V-JEPA 2.1 ViT-L 取得 LIBERO 97.25%、LIBERO-Plus 79.25%；相对最强判别式基线 DINOv2，优势从分布内 2.35 分扩大到偏移下 12.23 分；重建式隐变量（WAN2.2 VAE）鲁棒性明显更弱。
  • 预测质量与规模：从 V-JEPA 2 升级到 V-JEPA 2.1 在两个规模上均提升 LIBERO-Plus 鲁棒性；单纯从 ViT-L 扩到 ViT-G 主要提升分布内表现，偏移下增益有限甚至为负，V-JEPA 2.1 ViT-L 的 LIBERO-Plus 表现最佳。
  • 未来预测消融：移除未来查询（context-only）或保留查询但去掉未来隐变量监督，均导致性能下降，说明收益来自显式学习与动作生成耦合的未来视觉表征，而非仅扩大预测器通路。
