PAIR: Bridging Perception and Action in Vision-Language-Action Models

2026-10-06 · 原文 · 翻译 · 2610.09016

Card 02 论文概述

论文概述

  • 论文提出 PAIR 框架，用于在连续动作视觉–语言–动作（VLA）模型中学习一个共享的“感知–动作”中间表示，以弥合视觉语言语义与可执行动作语义之间的鸿沟。
  • 指出核心问题：现有 VLA 策略仅通过最终动作预测损失隐式地完成从场景/指令表示到动作生成表示的转换，即存在 perception–action representation gap（感知–动作表示鸿沟），动作 token 需自行发现并组织控制相关信息。
  • 目标是显式构造一个既携带任务语义（来自感知）又携带可执行结构（来自专家动作）的桥接表示，为动作专家提供“动作就绪”的起点。
Card 03 核心贡献

核心贡献

  • 明确刻画了连续动作 VLA 中在最终动作监督下从视觉–语言语义到可执行动作语义的隐式转换问题，即感知–动作表示鸿沟。
  • 提出 PAIR：学习由专家动作结构组织的、源自感知的 Bridge Tokens，并通过早期 Bridge Injection 为 Action Tokens 提供动作感知的起始状态。
  • 在标准操作、零样本分布偏移、长程执行和真实世界控制四类场景中验证一致性收益。
  • 提供表示层面证据（线性探针、RSA 等），表明 Bridge Tokens 保留任务语义并在 Action Expert 精化前即可访问动作结构。
  • 通过消融实验确认动作对齐与早期注入是该方法的关键要素。
Card 04 方法描述

方法描述

  • 掩码动作自编码器（Masked Action Autoencoder）：对专家动作块随机掩码并加高斯噪声，用自注意力编码为与时间步对齐的 Action Latent Tokens，再解码重建干净轨迹，采用 ℓ1 重建损失；训练后冻结。
  • 桥接模块（Bridge Module）：用 H 个可学习查询通过交叉注意力从视觉–语言表示中抽取任务相关特征，再经自注意力在动作时间跨度上协调，形成 Bridge Tokens。
  • 跨空间对齐（Cross-space alignment）：用对齐投影器将 Bridge Tokens 与 Action Latent Tokens 按时间槽做余弦对齐（L_align），把动作结构迁移到感知派生的表示中。
  • 桥接注入（Bridge Injection）：将 Bridge Tokens 投影到动作 token 空间，并以 token 级门控（tanh 激活）加到 Action Expert 入口处的 Action Tokens 上。
  • 训练分两阶段：先训练动作自编码器学习动作结构，再冻结自编码器并把结构迁移到 Bridge Tokens，同时联合优化策略与桥接模块（L_PAIR = L_act + λ_align · L_align）。
  • 推理时移除动作自编码器，Bridge Tokens 仅由当前观测与指令直接生成。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO / LIBERO-Plus / CALVIN 仿真基准 + 真实机器人平台；指标为成功率、零样本 OOD 总成功率、平均完成任务序列长度。
  • LIBERO：VLA-Adapter 平均成功率从 97.3% 提升到 98.4%（四个套件全部提升，Spatial/Goal +1.4、Long +1.2、Object +0.4）。
  • LIBERO-Plus：总体成功率从 59.1% 提升到 64.2%，七个 OOD 类别全部改善，最大增益来自相机视角（+8.1）、机器人初始状态（+7.8）、传感器噪声（+6.7）；LIBERO 到 LIBERO-Plus 的性能落差由 38.2 点缩小到 34.2 点。
  • CALVIN ABC→D：平均完成序列长度 OpenVLA-OFT 由 4.28 → 4.40，VLA-Adapter 由 4.42 → 4.53；五任务连续成功率分别提升 3.9 与 3.7 点，说明长程执行收益更明显。
  • 真实世界：OpenVLA-OFT 在 7 个任务上总体成功率由 51.4% 提升到 65.0%（+13.6 点），倒水任务增益最大（+20 点）。
  • 表示分析：Bridge Tokens 任务身份探针准确率 87.8%（动作自编码器潜变量仅 35.2%），动作簇准确率 91.5%；首个 block 前动作块解码 R²=0.878（基线最终 block 仅 0.844）；RSA 达 0.878、top-10 邻居重叠 80.4%（打乱后为 0.014 / 21.6%）。
  • 消融：入口处注入最优（98.4%）优于中间（97.9%）、全部层（97.6%）与末端（97.4%）；对齐权重 λ_align=0.1 最优（98.4%），关闭对齐降至 97.2%。
