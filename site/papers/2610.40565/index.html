Card 03 核心贡献

核心贡献

  • 提出 Gym-Anything for Robotics：一个模块化多智能体流水线，用于自动构建高质量机器人仿真，并给出“什么是好仿真”（10 条标准、4 类）与“什么是好任务”（6 条标准）的明确定义。
  • 构建 RoboWorld：25 个以美国 GDP 数据为基础的仿真，包含 25 个测试与 175 个训练 RL 环境，每个环境均支持可替换机器人（单臂、双臂、移动操作器、人形）及物体位姿、外观、物理变化。
  • 评估表明当前前沿模型在 RoboWorld 上表现极差：完整基准上所有模型得分为 0%，最佳平均奖励仅 0.06。
  • 提出多种“在仿真中学习”的新范式：跨尝试的上下文学习、特权教师指导学生、模型从自身特权经验中自学习、以及用代码策略生成演示来训练 VLA（如 π_0.5）。
  • 开源发布流水线、RL 环境与基准，推动后续研究。
Card 04 方法描述

方法描述

  • GDP 驱动的仿真选择：利用 LLM 将各职业的物理任务分解为原子物理动作（如拧螺栓、倾倒液体），按经济价值加权，通过优化选择覆盖最有价值动作及其所需物理/机器人能力的仿真，共选出 120 个动作组（本文实现 25 个）。
  • 创建-审查循环（creation-audit loop）：创建智能体编写仿真代码并产出证据（渲染、物理测量、辅助演示），4 个独立审查智能体按四类标准检查（含专门用合法动作破坏仿真的对抗智能体），共进行 3 轮迭代；所有智能体共享经验记忆。
  • 好仿真定义：涵盖物理真实性、视觉真实感、动态与可解性、运行速度与可配置性、文档完备性、对合法动作利用的鲁棒性等 10 条标准。
  • 任务创建与难度控制：每个仿真生成多个任务，6 个审查智能体按“意义、场景、验证器正确性、可解性、奖励质量、难度覆盖”6 条标准检查；用 Claude Haiku 5.5 与 Claude Opus 5.5 测量难度以构建难度阶梯；奖励基于物理状态计算并给出连续部分分。
  • 特权与受限访问：受限访问仅提供真实机器人可得信息（指令、相机图像、机器人反馈、命令文档）；特权访问额外暴露仿真器真值状态与任务评估，用于学习研究。
  • 学习机制：利用即时重置做上下文学习；特权教师通过定性提示指导学生；模型从自身特权经验中学习；代码策略在多样场景生成演示以训练 π_0.5 等 VLA。
Card 05 数据集与资源

数据集与资源

  • RoboWorld：25 个仿真、200 个 RL 环境（25 测试 + 175 训练），另设 25 个较易训练任务子集；覆盖制造、建筑、餐饮、家庭、实验室与医疗、物流、体育、教育等领域。
  • 物理类型：涵盖液体、化学、布料、熔融金属、颗粒土壤、膏体、软组织与声学。
  • 机器人平台：单臂（Franka FR3、Panda、UR10e）、双臂、移动操作器、人形机器人（Unitree G1、H1-2）。
  • 智能体模型：创建与审查智能体均为 Claude Opus 5.5，通过 Claude Code 等编码智能体框架运行；难度测量额外使用 Claude Haiku 5.5。
  • 训练 VLA：使用 π_0.5 作为被训练的视觉-语言-动作模型。
Card 06 评估与结果

评估与结果

  • 评估设置：在 RoboWorld 的 25 个测试任务上评估前沿模型，默认使用受限访问（仅相机图像与机器人反馈）。
  • 主要指标：任务成功率与连续奖励（0–1）。
  • 关键结果：

- 所有前沿模型在完整 RoboWorld 基准上成功率为 0%，平均奖励仅 0.06；在较易子集上最佳模型达 32%。

- 机器人自由度增加时成功率显著下降。

- 在仿真质量上，RoboWorld 的仿真优于同交互类型的最强先前仿真器（如对比 SoftGym、ManiSkill2、Chemistry3D、LabUtopia、GarmentLab），且是唯一同时具备液体/布料仿真、AI 构建、真实物理校验与基于职业数据选型的基准。

- 学习实验：上下文学习可提升表现，特权状态可加速该过程；特权教师仅凭语言提示即可将能力传递给学生；模型可从自身特权经验中学习；代码策略生成的演示可将 π_0.5 的成功率从 0% 提升至 53%。
