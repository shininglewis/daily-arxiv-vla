Card 03 核心贡献

核心贡献

  • 提出一个仅用 RGB 的 agentic 设定，将任务记忆隔离在 Agent 中、把所有任务相关运动集中在单个情节级无状态 Action Model 中，便于清晰的性能归因。
  • 设计组合式转向接口：把记忆中的意图转化为"子任务语言 + 可选的 2D grasp、place、move 提示"，在不同时间尺度上绑定物理参数。
  • 提出从演示中自动恢复监督信号的方法（阶段标签、物体框、接触与物体运动、投影机器人运动），无需模型教师（model teacher）。
  • 引入结构化提示丢弃（constrained hint dropout）、空间噪声与时间抖动训练，使 Action Model 能容忍 Agent 输出的不完整与不精确。
  • 在 LIBERO-Mem 上验证：不使用深度、在线几何或基于规划器的物体运动，取得 76.3% 平均完成度，显著超过已发表最强基线 14.8%。
Card 04 方法描述

方法描述

  • 双模型分解与显式契约：Agent Model 计算 c_k = AM_agent(g, I^a_k, H_k)，输出转向命令；Action Model 计算 â_{t:t+L-1} = AM_action(I^a_t, I^w_t, s_t, c_k)，预测一个动作块。
  • 两模型运行在不同时钟：Agent 每个短动作块更新一次；Action Model 在该块内基于当前视觉与本体现测执行局部控制，不访问历史 H_k，也不跨 Agent 调用保留状态。
  • 组合式命令：c_k = (ℓ_k, q^grasp_k, q^place_k, q^move_k)，坐标为当前 Agent 视角图像、左上原点、[0,1000]² 归一化范围；缺失字段直接省略而非用特殊点表示。
  • 三种提示的时间尺度：grasp_target 绑定下一个物体实例（接触前有效）；place_target 跨运输阶段保持目的地承诺；move_target 是未来若干步的有用夹爪位置，被解释为局部方向线索而非必经路点。
  • 监督信号恢复：grasp/place 使用物体框归一化中心 q = 1000((x+w/2)/W, (y+h/2)/H)；move 从投影末端轨迹 robot_xy 采样，Δ ~ U{10,…,20}，索引在回合边界截断。
  • 鲁棒性训练：在可用性约束下独立掩码命令字段（m_t ⪯ v_t，‖m_t‖₀ ≥ 1），对保留点加入各向同性高斯噪声并裁剪到合法范围 q̃ = clip_[0,1000]²(q+ε)，覆盖遗漏、定位误差与时间错位三类接口误差。
  • 闭路执行：每个动作块后 Agent 重新观测新鲜 RGB，更新 H_{k+1} 并可修正子任务或任意提示；不暴露任何基准状态或完成度预言机。

Card 06 评估与结果

评估与结果

  • 部署观测严格限制为：任务语言、Agent 视角 RGB、腕部 RGB、机器人状态；移除深度、分割、框、物体标识与位姿、oracle 子目标、奖励、阶段标志与完成谓词。
  • 评估指标：strict success（严格成功，要求按序完成完整任务且满足重复次数，超步即失败）、relaxed success（松弛成功，允许后期超出）、completion（有序子目标达成比例）。
  • 对比基线：已发表的 π₀、SlotVLA、SlotSSM；另加入同骨干（Qwen3-VL-4B）的复现版 π₀ 作为对齐参照。
  • 关键结果：2AM 达 76.29% completion、63.00% relaxed SR、11.83% strict SR；已发表最强基线 SlotSSM 为 14.80% completion（已发表基线 strict 均为 0）。
  • 相对对齐参照：复现版 π₀ 为 70.79% completion、37.42% relaxed、12.25% strict；2AM 在 completion 上提升 5.50 个百分点、relaxed 上提升 25.58 个百分点，但 strict 略低（未体现统一提升）。
  • 接口消融：language-only（仅 Agent 生成子任务、去掉全部 2D 提示）为 53.72% completion、19.42% relaxed、7.25% strict；加入 grounded 提示后分别提升 22.57、43.58、4.58 个百分点。
  • 任务级表现：2AM 在全部十个任务上 relaxed 更高、七个任务上 completion 更高；复现版 π₀ 在 T1–T6 strict 更强，2AM 在 T7–T10（关系与遮挡任务）更强。
  • 局限：仅单一仿真基准；2D 接口无法表达隐藏几何、力与连续运动历史；63.0% relaxed 与 11.8% strict 的差距说明"到达目标状态"与"精确停止"仍是两个独立问题，语义终止尚未解决。
