CausalWAM: Learning the Causes of Actions in World Action Models

Card 03 核心贡献

核心贡献

  • 给出无稀疏约束下的负面结论（Proposition 1）：在仅做观测等价拟合时，估计出的动作机制对隐变量的依赖数只会不少于真实机制，即允许“过度覆盖（over-coverage）”，无法保证动作侧与冗余变量分离。
  • 给出稀疏支撑下的可辨识性（Theorem 1）：在动作机制支撑稀疏约束下，配对 Proposition 1 的下界，状态到动作的二部依赖结构可被识别到隐变量的一个置换为止。
  • 给出紧凑状态的等价性（Theorem 2）：用于生成动作的紧凑状态 C_t 是真实动作相关隐变量块 s_{t,I_A} 的一个可逆函数，即该动作相关块被整体识别并与冗余变量分离。
  • 放宽理论假设：结论仅依赖观测示教，无需干预、无需充分的时间依赖、无需对隐动力学做假设，且允许动作相关隐变量与冗余变量之间存在统计相关。
  • 提出 CWAM 方法：在预训练 WAM（Cosmos 3）的动作头上加一条稀疏路由路径，世界模型目标函数保持不变，把理论约束以 token 级代理损失实现。
Card 04 方法描述

方法描述

  • 骨干与训练范式：以 Cosmos 3 Nano 为骨干，采用 Mixture-of-Transformers（MoT） 生成器与rectified flow 目标，联合去噪未来视频 latent 与动作 chunk，条件为干净历史帧与语言；世界建模损失 L_WAM 与基线完全一致。
  • 动作相关路由器：每个动作隐状态 h_i 在干净上下文 token（任务 token + 干净视觉 token，排除未来加噪 token）上做注意力路由，含位置、模态、chunk 进度等关系偏置（d_r=512，8 头），经初始化较小的门控 g 注入：h_i ← h_i + g·h̃_i。
  • 稀疏正则（token 级代理）：L_sparse = λ·E_i[1 − Σ_{j∈T_k(i)} w_ij]，即惩罚 top-k 之外仍占有注意力质量，λ=0.01，在 10³ 步后逐步引入；总损失 L_total = L_WAM + L_sparse。
  • 紧凑状态定义：C_t 取所有动作 query 的 top-k 路由质量中出现过的干净上下文 token 集合，公式为 C_t = { j ∈ J_t \|∃i: j ∈ T_k(i) }；默认策略仍保留稠密的视觉→动作通路。
  • 创新点：不改变世界模型（预测仍可用全部隐变量），只在动作侧施加最小通路偏置，从而把“致动原因”从“预测所需”中切分出来。

Card 06 评估与结果

评估与结果

  • 评估设置：仿真侧用已知真值隐变量与 I_A 做直接检验；机器人侧在 RoboCasa365、LIBERO 与真机上比较闭环成功率（匹配的 Cosmos 3 基线 vs. 加入稀疏路由的 CWAM）。
  • 主要指标：从 C_t 到动作相关隐变量的held-out 线性探针 R²、冗余变量的超出量 Δ_nuis（C_t 相对真实块对冗余变量的额外可预测性）、置零消融后的动作 MSE 比、以及闭环任务成功率。
  • 仿真结果：CWAM 选出的坐标对动作相关隐变量的解码效果与稠密读出相当，对冗余变量的解释力仅与真实动作相关块相当；将这些坐标置零会破坏已拟合的动作头，说明动作头确实依赖该子集。
  • 机器人结果：稀疏路由路径在聚合闭环成功率上优于匹配的 Cosmos 3 基线；在 CWAM 表现最好的 4 个 RoboCasa365 任务上，仅使用路由到的 token 即可保留大部分成功率；可视化中路由质量多数落在被操作物体及其目标位置上。
