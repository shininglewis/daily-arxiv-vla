论文概述

Card 03 核心贡献

核心贡献

  • 提出成对回放基准与协议：同一命令源与同一延迟实现下对比不同控制器，统计在源单元（episode/人/种子）上成对进行，区间采用 95% 单元自助法（5000 次重采样）。
  • 构建由浅入深的证据层级：从受控合成到达 → 20 人人体运动 → 三条开放 VLA 流水线（含 598 条新 episode 的计划复现）→ 实测网络时延轨迹，并区分冻结分析（v1.1/v1.3）、计划复现（v1.4）、事后稳健性检查（v1.5）与探索性硬件跟进（v1.2a）。
  • 给出关键结论：插值在每种来源上都降低 jerk 但付出跟踪代价；不确定性关联具有表示依赖性（在不同流水线中符号相反且均可复现）；熵门控在部分输入上失败。
  • 提供有界的 UR3 实物验证，包括位置派生指标的零结果（null result），揭示该测量分辨率下无法分辨对比。
  • 承诺开源：代码（Apache-2.0）、转换后的 VLA 动作流、20 人手工轨迹窗口与实测延迟轨迹。
Card 04 方法描述

方法描述

  • 成对回放（Paired replay）：每个控制器接收相同的源（episode / 人或合成到达）与相同的延迟实现（种子或轨迹偏移），使差异可归因于控制器而非随机输入。
  • 时序流水线：用 RTX 5090 实测的 VLA 推理服务时间驱动单 worker FIFO 队列，再叠加网络延迟（零延迟、Gamma 分布均值 0–400 ms、形状 2，或来自 12 小时实测实验室网络路径的序列采样：LAN、互联网往返、冷启动 HTTPS 请求）；按序送达，最新送达目标优先。
  • 被控对象（plant）：通用三轴质点模型（3 kg、临界阻尼阻抗、20 ms 力滞后、3000 N/s 力变化率上限、1 ms 步长），明确不是 UR3 模型，绝对 jerk 值不能作为硬件预测。
  • 控制器对比：B0 保持目标（阶跃）、B2 在一个命令周期内线性插值、A2 在插值上加入熵门控刚度、B3（Ruckig，加加速度限 25 m/s³）显式限 jitter 轨迹生成；另设 8 个固定刚度值的恒定增益网格，检验门控是否优于"可达最优恒定增益"。
  • 评价指标：p99 与 RMS jerk、跟踪 RMSE（相对无延迟参考）、LDLJ（log dimensionless jerk） 与 SPARC（spectral arc length） 平滑度指标，用于验证结论不依赖单一 p99 jerk。
  • 关键创新点：通过"相同命令 + 相同到达"的回放控制变量法，把控制器效应从数据源与延迟随机性中分离，实现可比较的 jerk–tracking 权衡刻画。
Card 05 数据集与资源

数据集与资源

  • 3D-ARM-Gaze：公开去标识化数据集，取 20 人手部到达轨迹窗口作为人体运动源（次要分析，Apache-2.0）。
  • BridgeData V2：用于 OpenVLA（每步 token 表示，token 熵作为不确定性）。
  • DROID：用于 pi0-FAST（10 步 chunk，chunk 熵）与 pi0.5（15 步 flow chunk，无不确定性量）。
  • 合成到达：10 条，5 Hz 目标；UR3 遥操作轨迹：作者录制，30 + 30 次运行。
  • 规模与总量：69,988 次成对回放（Gamma 延迟 10×7 + 20×7×10 + 838×61 = 52,588；实测轨迹 3×（10+10×579）= 17,400）；VLA 共 838 个 episode，复现使用 598 条新 episode。
  • 计算资源：推理服务时间实测于单张 RTX 5090；仿真 CPU 可复现全部表格，无需模型权重或机器人；硬件为 UR3（CB3 控制器，125 Hz）。
Card 06 评估与结果

评估与结果

  • 评估环境：CPU 可复现的质点仿真流水线 + 实测网络轨迹回放，最后在真实 UR3 CB3（125 Hz）上做有界实物检验；基准指标为 p99/RMS jerk、跟踪 RMSE、LDLJ、SPARC。
  • R1 插值在各来源上均以跟踪换 jerk（冻结并复现）：零延迟下 B2−B0 的 Δjerk / ΔRMSE 为合成 −504 m/s³ / +2.39 cm、人体 −521 / +2.32 cm、OpenVLA −202 / +0.78 cm（新样本 −193 / +0.77）、pi0-FAST −371 / +0.28 cm（新样本 −343 / +0.26）、pi0.5 −374 / +0.56 cm（新样本 −363 / +0.54）。
  • 时序不规则而非平均延迟驱动阶跃目标 jerk：纯固定延迟 0/200/400 ms 下阶跃 p99 jerk 基本不变（535、534、533 m/s³），而 200 ms 延迟波动 使其升至 623 m/s³；三条实测轨迹下 B2−B0 方向对每个来源均成立。
  • R2 低 jerk 并非免费（人体输入、200 ms 均值延迟）：B0 为 615 m/s³ / 9.91 cm，B2 为 106 m/s³ / 11.87 cm（jerk 降 83%），B3 达 23.5 m/s³ / 14.79 cm，熵门控 A2 为 150 m/s³ / 16.72 cm，在两轴上都劣于 B2；LDLJ 与 SPARC 在所有测试单元中均偏向 B2 且区间不跨零。
  • R3 不确定性与不连续性关联依赖表示（冻结并复现）：OpenVLA 中 token 熵与目标步长呈弱负相关（ρ=−.065 [−.110, −.021]，新样本 −.089 [−.117, −.061]）；pi0-FAST 中 chunk 熵与 chunk 边界跳变呈正相关（ρ=.221 [.169, .271]，新样本 .217 [.181, .253]），两者符号均在复现中保持。
  • 门控效果依流水线分裂：pi0-FAST 上 A2 相对 B2 降低 p99 jerk 208 m/s³（新样本 199），跟踪代价 +0.18 cm（+0.16），并在可行子集上优于最佳恒定增益（−12.4 m/s³，66/80；新样本 −5.6，162/199）；OpenVLA 上 A2 无帮助（+2.3 [−0.7, 5.2]，新样本 +3.4 [1.9, 4.8]）。
  • 复现统计：pi0-FAST 全部 28/28 预注册对比复现，OpenVLA 为 22/28（6 个未中主要为接近零的单元）。
  • R4 UR3 有界实物检验：位置派生的 p99 滤波 jerk 在 77.7–81.9 m/s³ 之间，未分辨计划对比（零结果）；探索性 v1.2a 改用工具法兰加速度计后，B0 在两种延迟的各 3 次成对重复中均高于 B2，平均高 3.07 m/s³（无附加延迟）与 5.79 m/s³（200 ms 均值延迟），降幅 3.0–14.0%；但传感器增益、带宽与信号来源未标定，不构成硬件 jerk 或安全性结论。
  • 局限性：主结果基于单一通用质点 plant 与开环 VLA 预测；三条流水线在模型、数据集、动作表示、熵定义与不连续事件上共同变化，不构成受控模型比较；UR3 研究规模小且加速度计未标定；所有指标均为运动质量代理指标，未测量舒适度、偏好、信任与感知安全。
