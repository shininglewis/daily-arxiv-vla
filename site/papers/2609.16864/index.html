TEMPO: Learning Temporal Context for Dynamic Robot Manipulation

2026-09-15 · 原文 · 翻译 · 2609.16864

论文提出 TEMPO，为预训练 VLA 模型注入时间上下文，以解决动态机器人操作中的 motion ambiguity 和 state aliasing 问题。 单帧观测无法编码场景动态，也无法区分不同任务阶段中视觉相似但动作相反的状态，导致动态任务失败。 作者认为瓶颈是缺少时间上下文而非模型规模或推理延迟，并通过两个紧凑时序信号使 VLA 具备运动感知能力。

Card 02 论文概述

论文概述

  • 论文提出 TEMPO，为预训练 VLA 模型注入时间上下文，以解决动态机器人操作中的 motion ambiguity 和 state aliasing 问题。
  • 单帧观测无法编码场景动态，也无法区分不同任务阶段中视觉相似但动作相反的状态，导致动态任务失败。
  • 作者认为瓶颈是缺少时间上下文而非模型规模或推理延迟，并通过两个紧凑时序信号使 VLA 具备运动感知能力。
Card 03 核心贡献

核心贡献

  • 识别并形式化单帧 VLA 在动态操作中的两种表示失败模式：motion ambiguity 与 state aliasing，并证明二者不是延迟或容量问题。
  • 提出 TEMPO_MOT，从冻结视频基础模型提取运动表示，用于感知物体和场景动态。
  • 提出 TEMPO_ACT，用紧凑本体感知历史为策略提供任务阶段上下文，缓解状态混叠。
  • 两个信号以即插即用方式接入预训练 VLA，仅增加 2M 参数（0.08% 开销），无需修改 backbone。
  • 发布 TEMPO-Bench，包含超过 50k 标注帧的动态操作运动理解基准，支持回归和多项选择评估。
Card 04 方法描述

方法描述

  • TEMPO_MOT：当前帧 patch 特征作为 query，与过去 W-1 帧特征缓存做 cross-attention，生成运动码 m_t；使用冻结的 SAM 2.1-Tiny 作为默认运动编码器。
  • TEMPO_ACT：将最近 H 个本体感知命令划分为 K=10 个连续时间桶，每桶平均 L=30 个命令，得到固定大小紧凑摘要 c_t。
  • 集成方式：m_t 和 c_t 投影到 VLM token 维度并附加到前缀；c_t 还通过 AdaRMS 残差调节 action expert。
  • 零初始化 conditioning 路径保留预训练策略初始行为，flow-matching 损失不变，TEMPO 仅添加 2M 参数。
  • 采用并行编码与异步推理：运动编码在后台线程以传感器速率运行，策略每步仅增加约 1.5 ms 开销。
Card 05 数据集与资源

数据集与资源

  • 使用四个真实世界动态操作任务：Bottle Handover、Drop Catch、Flick Catch、Wine Pour。
  • 发布 TEMPO-Bench：超过 50k 帧的人机动态操作标注数据，含每帧物体速度标注及多项选择变体。
  • 硬件平台：双臂 I2RT YAM Ultra 7-DOF 机械臂，三路摄像头以 224p@30Hz 流式输入。
  • 训练资源：8 张 NVIDIA RTX PRO 6000 Blackwell GPU，单个策略训练约 2 小时。
  • 模型：基于预训练 VLA backbone（如 π0.5、RTC、VLASH）和冻结视频基础模型 SAM 2.1-Tiny；TEMPO 新增约 2M 参数。
Card 06 评估与结果

评估与结果

  • 评估环境：真实世界双臂机器人平台，每个任务 50 次 rollout；Wine Pour 以倒酒结束后保留在容器中的质量百分比衡量。
  • 主要指标：任务成功率；运动探测采用 MLP probe 从隐藏状态解码物体速度并报告 R²。
  • Bottle Handover：TEMPO 将成功率从 44% 提升到 74%；TEMPO+UVT 达到 88%。
  • Flick Catch：在未修剪完整任务上，RTC 和 VLASH 均为 0%，TEMPO 达到 68%；修剪版为 66%。
  • Wine Pour：未修剪完整任务上基线为 0%，TEMPO 达到 97.6%；修剪版为 98.1%。
  • Drop Catch：TEMPO 达到 66%，与 RTC 的 80% 相比仍有差距，说明该任务更依赖执行时序而非表示。
  • 消融：仅 TEMPO_ACT 为 52%，仅 TEMPO_MOT 为 56%，完整 TEMPO 为 74%，两个信号互补且各自必要。
  • 运动探测：Flick Catch 上 TEMPO 的 R²=0.57，基线 ≤0.03；Wine Pour 上 R²=0.44，基线 ≤0.09。
  • 推理延迟：TEMPO 中位数 35.3 ms，接近 VLASH 的 33.8 ms，远低于 RTC 的 127.7 ms。
  • 即插即用：在 π0.5 上从 26%→56%，RTC 上从 44%→80%，VLASH 上从 38%→74%。
