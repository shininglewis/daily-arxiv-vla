论文概述

  • 提出 Axiom-0，一种面向视觉-语言-动作（VLA）策略的分层自精炼（Hierarchical Self-Refinement）框架，是 4Axiom Robotics 迈向具身系统安全递归自我改进（SRSI）研究计划的第一步

  • 核心思路是"先精炼后行动（refine-before-act）"：在训练期监督中间多模态特征，并在动作采样前对条件表示进行递归精炼
Card 03 核心贡献

核心贡献

  • 提出 IVRR（Intra-VLM Representation Refinement）：利用空间基础模型作为参考，通过可学习投影对选定 VLM 中间特征施加一致性监督
  • 提出 VAIR（VLM–Action Interface Refinement）：在 DiT 动作生成器之前，用共享循环 Transformer 对条件键值缓存进行递归精炼，并以门控残差方式更新 value
  • 设计选择性联合优化的两阶段训练流程：Stage I 联合训练 VLM/DiT 与对齐投影，Stage II 联合优化被监督 VLM 层、VAIR 与 DiT，从而把表示监督与下游使用连接起来
  • 在 RoboCasa365 上取得 62.32% 总体成功率，超过最高公开榜单成绩 Paimon-0（58.1%） 4.22 个百分点、超过 Xiaomi-Robotics-1 4.92 个百分点
  • 证明性能提升仅带来极小推理开销：平均动作块生成延迟仅增加 1.73%，参数仅增加 约 14.7M（0.287%）
Card 04 方法描述

方法描述

  • 基础架构沿用 Xiaomi-Robotics-1 的 VLM + DiT 组合，动作生成采用 flow matching，推理用 5 步 Euler 采样器生成动作块
  • IVRR 细节：设空间基础模型为 E_sp，对 VLM 第 l 层视觉特征 H_vis^l 施加可学习投影 G_l，与空间参考 T_t = E_sp(o_t) 做一致性损失 L_cons；总目标为 L_I = L_action + λ·L_cons
  • VAIR 四个操作：(a) value 投影 P_l 将合并头后的 value 压到紧凑隐空间 Z_l^(0)；(b) 共享循环 Transformer T_φl 迭代 R 次得到 Z_l^(R)；(c) 门控残差更新 Ṽ = V + tanh(g_l)·ΔV，键 K 保持不变，g_l 初始化为 0 保证恒等起点；(d) 精炼后的缓存供 DiT 注意力使用，每次观测只计算一次并跨 5 步采样复用
  • 训练策略：Stage I 运行 16,000 步，Stage II 运行 2,000 步，全局 batch size 为 2,048
  • 推理：所有参数固定，VAIR 每次观测只执行一次，无需辅助对齐分支
Card 05 数据集与资源

数据集与资源

  • 评测基准：RoboCasa365 的 target-50 多任务评测套件（RoboCasa 1.0.1），包含 18 个 Atomic-Seen、16 个 Composite-Seen、16 个 Composite-Unseen 任务，每任务 50 回合，共 2,500 回合
  • 训练数据：仅使用 pretrain_human300，未使用 target-50 演示、评测轨迹或其他额外数据集
  • 模型规模：总参数约 5.12791B（基线 5.11322B，新增约 14.684M）
  • 训练资源：32 块 NVIDIA RTX PRO 5000（72 GB 显存）GPU，分布于 4 个节点
  • 推理 profiling 环境：单张 NVIDIA RTX PRO 5000（72 GB），batch size 为 1，每块 16 个动作
Card 06 评估与结果

评估与结果

  • 评估方式：由作者自行评测（pending independent benchmark verification），对比分数取自 2026 年 10 月 3 日官方榜单快照
  • 主要指标：各划分与总体任务成功率（%），分数差异以百分点（pp）表示
  • 总体结果：Axiom-0 达 62.32%（2,500 回合中成功 1,558 次），高于 Paimon-0 的 58.1% 4.22 pp、Xiaomi-Robotics-1 的 57.4% 4.92 pp
  • 分项结果：Atomic-Seen 86.22%、Composite-Seen 60.12%、Composite-Unseen 37.62%；相对 Xiaomi-Robotics-1 分别提升 +6.02、+3.02、+5.52 pp
  • 组件分析：仅 IVRR 达 60.32%（+2.92 pp，Composite-Unseen 提升最明显 32.10→37.50）；仅 VAIR 达 60.76%（+3.36 pp，三个划分全面提升）；两者结合达 62.32%，为最优
  • 推理开销：平均延迟 133.25 → 135.55 ms（+1.73%），P95 延迟 +0.96%，峰值显存增加约 55 MiB（0.56%），估算算力增加约 0.59%
  • 局限：作者指出点估计不构成统计显著性，缺少重复评测不确定度与匹配预算的组件对照，尚未验证递归自改进（SRSI）的安全性
