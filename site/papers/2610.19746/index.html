Card 02 论文概述

论文概述

  • 论文提出 CapPro，一种面向 Vision-Language-Action (VLA) 模型的单样本人类视频引导适应框架。
  • 目标：让预训练 VLA 策略仅凭一个人类演示视频适应未见操作任务，避免目标任务机器人演示和目标任务微调。
  • 关键挑战：人类视频存在视觉冗余，且人-机器人 embodiment、视角和动作空间差异大，直接行为迁移困难。
Card 03 核心贡献

核心贡献

  • 形式化 one-shot human-video-guided adaptation：单个演示提供任务特定执行指导，无需目标机器人数据或微调。
  • 提出 CapPro：结合阶段感知人类视频表示与视频条件适应，从单个演示中提取阶段相关信息并融入机器人动作生成。
  • 在 RoboTwin 的 26 个未见任务及真实世界任务上验证，跨未见目标组性能提升且源任务性能保持。
Card 04 方法描述

方法描述

  • 基座为预训练 π0.5 VLA 策略；CapPro 包含 phase-aware human video representation 和 video-conditioned adaptation 两个模块。
  • 视频表示：采样 8 帧人类视频，用共享视觉编码器提取特征，经 GridS 可学习空间 token 选择保留每帧 32 个 token，并加入归一化视频进度嵌入，得到紧凑表示 Z^H。
  • 阶段感知上下文：将源任务划分为若干语义阶段并配文本描述，离线定义每个 episode 的归一化阶段边界；使用 4 个可学习 query token 与机器人视觉上下文、Z^H 及阶段 caption 进行 masked 交互，输出 query 表示 S_t^H。
  • 视频条件适应：通过可学习门控 tanh(γ) 缩放 S_t^H，构造动作前缀 P_t = [Z_t^R; Z^H; \tilde{S}_t^H; Z^L]，保留基础 VLA 的动作生成结构。
  • 训练目标：L = L_act + λ_cap L_cap；L_act 为流匹配动作生成损失，L_cap 为阶段字幕自回归语言建模损失。
  • 推理时仅需当前机器人观测、语言指令和单个人类演示视频，无需阶段字幕、教师强制 token 或机器人执行进度。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin，共 39 个任务，划分为 Source 13、Target-A1 6、Target-A2 10、Target-B 10。
  • 训练数据：Source 训练集每任务 50 条 clean 和 500 条 randomized 机器人轨迹。
  • 真实世界评估：7 个操作任务，包括 3 个 Source、2 个 Target-A、2 个 Target-B；每任务 5 次试验。
  • 模型资源：基于 π0.5，含 2B VLM backbone 与 300M action expert，对两者应用 LoRA。
  • 关键超参数：人类视频支持帧 N_s=8、GridS token S=32、查询 token M=4、字幕损失权重 λ_cap=0.1、batch size 128、峰值学习率 2.5×10^-5。
  • 训练配置：AdamW 优化器与 cosine 学习率调度；结果默认使用 30K-step checkpoint；原文未提供具体 GPU/TPU 型号与数量。
Card 06 评估与结果

评估与结果

  • 评估协议：每个目标任务在推理时提供单个 egocentric 人类演示视频；每任务在 clean 和 randomized 设置下各 100 回合，报告成功率。
  • 基线：匹配的 π0.5 策略；Direct Video Prefix 基线（直接将人类视频 token 拼入 π0.5 前缀）。
  • 主结果（成功率 %）：CapPro 总体 42.6，优于 π0.5 的 28.4 和 Direct Video Prefix 的 19.1。
  • 分项结果：CapPro 在 Source 68.9、Target-A1 44.8、Target-A2 29.0、Target-B 20.7；相比 π0.5 分别提升 Source 4.5、A1 10.3、A2 26.5、B 16.7 个百分点。
  • 迁移幅度越大，提升越明显；直接拼接人类视频 token 会显著降低性能，说明需要结构化表示与整合。
  • 消融：移除 Phase-Aware Caption 后，Target Avg. 从 29.5 降至 12.7，表明阶段级字幕监督对跨目标泛化关键；其他消融变体结果在提供文本中未完整显示。
  • 真实世界：论文报告了 7 个真实操作任务的评估，用于验证超越仿真的适应能力；提供文本中 CapPro 的真实世界结果列未完整显示。
