Card 02 论文概述

论文概述

  • 论文提出 H2RB（Human-To-Robot Bridge），一个人类-机器人联合训练框架，用于从非配对的人类与机器人演示数据中适配预训练的 VLA（Vision-Language-Action）策略。
  • 针对的核心问题：在目标机器人上采集演示数据成本高；人类演示数据易采集，但存在巨大的人-机具身差异（embodiment gap），尤其是当 VLA 主要在机器人数据上预训练时，直接利用人类数据效果很差。

Card 03 核心贡献

核心贡献

  • 提出 H2RB 框架，可在无配对人类-机器人轨迹、无人类→机器人观测合成、无人工配对数据的前提下，将人类演示用于适配机器人预训练 VLA。
  • 提出手部几何锚定对齐（geometry-anchored alignment）：用腕部位姿与五个指尖位置作为共享物理参照，在每条观测上独立对齐 VLM 条件特征，实现动作无关的跨具身感知桥接。
  • 提出解耦解码器的隐动作分词器（decoupled-decoder latent tokenizer）：共享 VAE 编码器学习统一隐动作空间，但为人类与机器人保留各自的解码器，避免把两种运动动力学压缩进单一动作映射。
  • 引入跨域隐空间正则（逐位置质心匹配 + 方差/协方差正则），将归一化人-机隐空间差距从 3.81 降至 1.53（降低 59.8%）。
  • 验证了方法的可扩展性：异质多具身联合训练（HT）进一步提升迁移性能，并能改善另一台机器人上的纯机器人下游适配；表明人类演示可作为可扩展的监督来源。
Card 04 方法描述

方法描述

  • 共享腕-手参数化：动作表示为 a_t = [p_t, r_t, q_t]，其中 p_t ∈ R³ 为腕部位置、r_t ∈ R⁶ 为 6D 旋转、q_t ∈ R^D 为手部关节角；人类视频经 HaWoR 重建管线恢复腕部运动与手部关节，转换到机器人坐标约定后重定向到机器人手；部署时通过逆运动学将腕部位姿转为机械臂指令。
  • 解耦解码器隐动作分词器：对人类动作 A^H 与机器人动作 A^R 训练变分动作自编码器，共享编码器 q_ψ 采样隐动作，分别用 D_H、D_R 重建；优化重建项与 KL 项，并加入逐位置质心回归、方差与协方差正则，以对齐两个隐分布。
  • 策略学习：分词器训练完成后冻结编码器与两个解码器，以 Z_t = E_ψ(A_t)（后验均值）作为 VLA 预测目标，采用条件流匹配（latent flow matching）损失 L_pred 预测速度场。
  • 几何锚定 VLM 条件：共享残差适配器 A_φ 与仅训练期使用的读出层 R_ω，从池化后的 VLM token 回归手部几何 ĝ_t，以掩码 Smooth-L1 损失 L_geo 监督；总损失为 L_VLA = L_pred + λ_geo · L_geo，该阶段 VLM 主干、分词器与解码器均冻结。
  • 部署：对学习到的速度场做数值积分得到隐动作策略 π_θ，条件为机器人观测、本体状态与指令；隐动作经解码器转为机器人指令（共享编码器与策略由人类+机器人双方数据共同学习）。
  • 附加设计：指令条件增强——将指令表示与状态条件化的视觉-语言隐表示拼接，并在专家层中持续注入。

Card 06 评估与结果

评估与结果

  • 评估环境：全部为真实世界机器人实验（非仿真），任务进度采用 0-100 的加权任务得分；含 ID 与 OOD（物体摆放位置偏移）两种设置。
  • 对比基线：Base policy human-only、Base policy in-domain-only、Base policy co-train，以及 HaWoR-shared action、Ego-Pi-shared action（均为共享动作空间方案，且不使用几何对齐与隐分词器，训练数据与预算相同）。
  • 物体迁移：H2RB 将平均得分从基线 co-train 的 8.0 提升到 51.8（+43.8），同时保留域内性能（Doll 49.0）；OOD 平均从 6.0 提升到 45.3，显著优于 Ego-Pi（ID 30.2 → 55.0，OOD 21.3 → 45.3）。
  • 技能迁移：HaWoR 与 Ego-Pi 在 Open/Close 上均为 0.0（完全无法迁移），H2RB 达到平均 62.7（Open 50.7 / Close 74.7），域内从 0.0 提升至 81.0。
  • 异质多具身训练（HT）：OpenArm 上物体迁移 51.8 → 57.2，技能迁移 62.7 → 81.7；RB-Y1 包裹方向成功率 64%（纯机器人）→ 72%（人-机 HT）→ 78%（几何锚定 HT）。
  • 指令条件增强：技能迁移从 62.7 进一步提升到 83.3（+20.6）。
  • 分析与消融：引入动作分词器使物体迁移 34.7 → 43.3、技能迁移 0.0 → 49.7；跨域隐正则进一步带来 51.8 / 62.7 并大幅缩小隐空间差距；人体演示带来的更快动作被保留——人类迁移策略速度 7.36 cm/s，机器人仅策略为 2.52 cm/s（×2.92），而任务得分相当（62.7 vs 65.3）。
  • 失败模式分析：human-only 策略在接触阶段腕部对齐与抓取构型失败；robot-only 策略可执行但无法定位人类演示的目标行为；共享动作基线产生无效抓取位姿或回退到机器人熟悉的 pick-and-place 动作，验证了“仅统一动作空间不足”的论点。
