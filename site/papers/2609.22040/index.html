Card 03 核心贡献

核心贡献

  • 提出 Situational Memory 模块：一个有状态的记忆组件，通过跨注意力在 L 步时间窗内聚合 6 类潜在反馈源，覆盖场景感知（SA1）、情境理解与导航意图（SA2）、未来行为预测（SA3）三个层级。
  • 针对结构、基数各异的反馈源，设计两个轻量集成模块：FiLMXAttn（处理紧凑源，结合 FiLM 仿射调制与跨注意力）与 Attention Pooling（用可学习的 Extraction Queries 压缩高基数结构化记忆）。
  • 提出基于 adapter 的研究范式：冻结主干、只训练源专用反馈通路，从而可隔离评估单个潜在表征的作用，无需昂贵的端到端重训。
  • 对 VLA 驾驶模型中的跨阶段反馈进行系统性实证研究，回答"记忆应保留感知表征还是高层推理/规划表征"这一问题。
  • 在 Bench2Drive 闭环基准上验证有效性：Driving Score 82.47（较 ORION +4.73）、Success Rate 60.00%（+5.38 个百分点），在所比较的 Think2Drive 训练 VLA 中取得最高报告 Driving Score。
Card 04 方法描述

方法描述

  • 反馈注入点：Situational Memory 在 QT-Former 的 Box Decoder（物体级）与 Map Decoder（地图级）解码器查询 Q = [B; D] 处理当前相机特征之前对其条件化，使有限的查询瓶颈选择"任务相关"信息而非纯自底向上视觉信息。
  • 记忆构建：不跨时间步传播梯度，而是维护 detached rolling buffers；每步将 6 个反馈源 detach 后写入各自缓冲（最多 L 条有效项），场景间重置或掩码；在 t 时刻从 M_{t-1} 检索。
  • 六个反馈源：SA1 的 Q（QT-Former 联合查询潜在）、M（潜在运动预测）；SA2 的 R（LLM 潜在推理 token）、P（规划导航命令）；SA3 的 S（预测自车状态查询）、T（多模态自车未来轨迹）。
  • FiLMXAttn（用于 R、P、T）：将查询与记忆投影到共享嵌入空间并加时间编码 → 源特定跨注意力检索（含时间一致性掩码）→ 用 MLP 预测 FiLM 的 γ、β 对查询做特征级仿射调制 → 输出 MLP → Z^(i)。
  • Attention Pooling（用于 Q、M、S）：记忆展平并加时间 + 位置编码 → 可学习 Extraction Queries 跨注意力池化为固定数量 token → LayerNorm(FFN(·))，充当学习式信息瓶颈。
  • 共享反馈融合：各源表示加源嵌入 e^(i) 后拼接为 Z_cat，查询经 MLP+位置编码后对 Z_cat 做跨注意力，得到 U_Q，最后以门控残差融合：Q̂ = Q + σ(α)·U_Q，门控初始化为 σ(α)=0.1，使训练起点接近原 ORION 计算，并允许模型自适应增强或抑制反馈。
  • 新颖点：把控制工程中的"状态观测器/反馈"思想引入 VLA —— 反馈调节的是特征选择而非提供额外视觉证据，且无需额外前向传播。

Card 06 评估与结果

评估与结果

  • 评估环境：CARLA + Bench2Drive 闭环评测；所有 PRIME 变体从收敛的 ORION checkpoint 初始化。
  • 主要指标：Driving Score (DS)、Success Rate (SR)、NDS（开环感知）、mL2（越小越好），以及场景级 SR（Merge / Overtake / Emergency Brake / Give Way / Traffic Sign）。
  • 训练配方消融（表 II）：Alignment-only（DS 59.74、SR 33.63）与直接 E2E（DS 70.96、SR 50.00）均低于 ORION 基线（DS 77.74、SR 54.62），说明单加反馈不够，必须先对齐 QT-Former 再联合优化。
  • PRIME-Full 结果：NDS 73.62、mL2 0.6788、DS 82.47、SR 60.00%，相对 ORION 提升 +1.90 NDS / +4.73 DS / +5.38 pp SR。
  • 单源 adapter 消融（表 III）：仅 推理状态 R 反馈改善闭环（DS 77.74→79.31，SR 54.62%→56.36%）；感知源 Q（DS 61.76、SR 32.72%）与预测源 S（DS 62.96、SR 39.09%）虽提升 NDS，却显著恶化闭环表现——揭示开环感知指标与驾驶性能的脱节。
  • 跨阶段源多样性消融（表 IV）：仅用感知侧源（PRIME-SA1，Q+M）NDS 略升至 71.96、mL2 降至 0.6114，但 DS 掉到 64.18、SR 仅 42.27%；而覆盖 SA1/SA2/SA3 的 PRIME-Full 同时提升感知与驾驶，说明有效反馈依赖行为相关性而非单纯保留更多感知历史。
  • 与 SOTA 对比（表 V）：UniAD 45.81、VAD 42.35、ORION 77.74、SpaceDrive 78.02（PDM）、AutoVLA 78.84（PDM）、GeRo 81.90；PRIME-Full 82.47 为 T2D 训练 VLA 中最高 DS，SR 60.00% 与 GeRo 的 60.10% 相当；PRIME 在 Merging 场景最强（47.50），GeRo 在 Overtake / Emergency Brake / Traffic Sign 更强。
  • 作者指出：PRIME 改进感知前端，与 GeRo 等改进规划/决策的工作正交互补；局限包括仅验证单一骨干与单一专家策略（Think2Drive）、纯相机设置、未评估真实世界分布外失效场景。
