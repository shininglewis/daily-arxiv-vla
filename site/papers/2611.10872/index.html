Card 03 核心贡献

核心贡献

  • 生成式示范框架：使用生成的人体动作 + SONIC 主干上的残差强化学习，在仿真中自动采集自然、类人的全身交互示范，无需任务特定的人类遥操作采集。
  • 基于 DAgger 的 VLA 蒸馏方法：以 RL 专家在“学生实际访问到的状态”上监督 VLA，并引入参考条件化的专家恢复（reference-conditioned recovery）与成功筛选的轨迹聚合。
  • 四任务仿真研究：对平台抓取、开抽屉、按按钮、行走并抓取四个任务进行受控消融，涵盖 DAgger 迭代轮数、残差 RL、生成数据规模三个维度。
  • 明确区分于标准逐点 DAgger：本文聚合的是“完整、相位一致的恢复片段”，而非对每个状态独立打标签。
Card 04 方法描述

方法描述

  • 参考生成：沿用 DreamControl 流程，由 OmniControl 依据语言指令与时空间约束（关节 j_k 在时刻 t_k 到达位置 v_k）采样人体动作；再由 OmniRetarget 重定向到 Unitree G1，并用 HumanoidMimicGen 修改接触点扩充轨迹。
  • 残差 RL 专家：以 SONIC 的运动编码器/控制解码器为骨干，学习运动 token 的残差修正 Δz_t = π_res(s_t, R_{t:t+F}, x̄_{t:t+F}, ℓ)，最终命令 z_t^E = z_t^nom + Δz_t 经解码器生成身体动作，手部动作为二值开合。
  • 人-物协同跟踪：参考窗口包含目标关节角/角速度（27 维）、相对根部位姿、41 个关键点的相对坐标与双手开合状态；物体参考 x̄_t 单独刻画交互进度（物体位姿、抽屉关节位移、按钮行程）。奖励 = 人体参考跟踪 + 稀疏任务奖励 − 控制正则，并对机器人与物体物理参数做域随机化（不做视觉域随机化）。
  • 数据构建：仅保留满足任务成功谓词 S(τ) 的专家 rollout，按 LeRobot 格式导出同步图像（仅第一视角自拍摄像头）、本体感知、动作、时间戳、episode id 与语言指令。
  • 蒸馏：先在 D_0 上微调预训练 GR00T（动作块监督）；随后执行参考条件化恢复 DAgger——学生 rollout 失败后，从失败轨迹中均匀采样时刻 t 恢复仿真状态，专家以同一参考的后缀从第 t 相位继续，仅保留在剩余参考时域内成功的恢复片段，动作块不跨 episode/恢复边界构造。
Card 05 数据集与资源

数据集与资源

  • 自主生成的仿真示范数据，采用 LeRobot v3.0 数据集格式；无外部公开机器人数据集。
  • 任务规模：初始 200 条专家成功轨迹；每轮 DAgger 额外收集 200 条成功纠正轨迹，k=3 时总计 800 条；离线对照同样使用 800 条成功轨迹以匹配数据预算。
  • 数据规模消融使用 10 / 50 / 200 条生成运动参考（嵌套子集）。
  • 模型：GR00T VLA 主干（微调而非新架构）、SONIC 全身控制骨干、OmniControl 动作生成模型；文中未给出 VLA 参数量与训练算力（GPU/TPU）配置。
Card 06 评估与结果

评估与结果

  • 评估环境：Unitree G1 的四个仿真交互任务（平台抓取、开抽屉、按按钮、行走并抓取），每个成功率评估使用 100 次 rollout、随机环境设置。
  • 主要指标：任务成功率；辅助指标为专家成功率、学生相对专家表现、平均逐关节位置误差 MPJPE（mm）。
  • DAgger 消融：离线初始化（k=0）抓取 0%、行走抓取 0%；k=3 提升至抓取 54%、开抽屉 60%、按按钮 69%、行走抓取 18%。同预算的 800 条离线成功数据对照组仅为 0% / 54% / 57% / 0%，说明增益来自“纠正性状态分布”而非数据量。
  • 残差 RL 消融（3000 次 RL 迭代匹配预算）：残差 token RL 达 88.6% / 74.0% / 81.0% / 75.95%；无残差的原始 SONIC 跟踪为 0% / 30.0% / 68.0% / 17.30%；绝对 token RL 四任务均为 0%（MPJPE 62.29 mm，远差于残差的 25.51 mm）。定性上，原始 SONIC 会把芥末瓶碰落台面，残差控制则稳稳握住。
  • 数据规模：参考数从 10 增至 200，开抽屉由 13.0% 升至 51.0%，按按钮由 0% 升至 59.0%；但抓取与行走抓取在该消融中始终为 0%。
  • 局限：仅四个仿真任务、单一具身；生成运动可能与机器人运动学或接触需求不兼容，仍需任务特定引导、筛选、物体参考与奖励权重；成功筛选会低估困难场景；专家在学生状态上的纠正可能不可靠或突跳；无真机部署与视觉 sim-to-real 验证。
