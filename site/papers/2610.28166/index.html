论文概述

Card 03 核心贡献

核心贡献

  • 识别出 decision bottleneck（决策瓶颈） 是 VLA 中多模态性应当存在的独立位置，并形式化定义 addressability（可寻址性）：即保留备选决策以便采样、选择与修订的能力。
  • 提出 Generative Plan Latent（GPL），用条件分布 p_θ(z\|c) 取代确定性计划读出，通过 rectified-flow 头实现，并以冻结主干 + 少量适配接入 π₀。
  • 通过匹配的计划级与动作级干预实验证明：决策瓶颈是比原生动作分布更强的行为控制手柄。
  • 提出 冗余性原则（redundancy principle）：显式计划只有在携带观测未确定的决策信息时才影响行为，并给出冗余度指标 R̃ = 1 − H(y\|c)/ln m 加以量化。
  • 验证三个能力（coverage / steering / outcome adaptation）不依赖手工设计坐标，可跨表示、跨具身、跨域迁移。
Card 04 方法描述

方法描述

  • 整体流程：冻结 VLA 主干 f_φ 将观测 o 与指令 l 编码为条件向量 c；小型 rectified-flow 头从中采样计划 z ~ p_θ(z\|c)；投影器 P_η 将 z 映射为 k=8 个软 token 注入执行器前缀（plan interface）；执行器再按原生动作目标预测动作块。
  • 计划生成器训练：采用 rectified flow 的速度场回归损失 L_plan(θ)=E‖v_θ(z_t,t,c)−(z−z₀)‖²，推理时用 Euler 积分少量步数即可采样。
  • Steering（引导）：训练轻量、噪声条件化的分类器 q_ψ(y\|z_t,t,c)，推理时以 v_guide = v_θ + w∇log q_ψ 偏置速度场，w=0 恢复原分布，且无需重训生成器或 VLA。
  • Outcome adaptation（结果自适应）：在冻结生成器的前提下，用 p_adapt ∝ p_θ(z\|c)·exp(β s(c,z)) 对候选计划做 Boltzmann 重加权；s 可为学习型 critic 或零训练的奖励表（reward table）。
  • VLA 适配：在 π₀ 的动作专家上加投影器与 LoRA，仅用原生动作目标训练，并用 classifier-free guidance（CFG） 随机丢弃计划 token 以增强鲁棒性。
  • 成本优势：单次计划潜变量采样约比同等条件下 ECoT 式推理链便宜 80×。

Card 06 评估与结果

评估与结果

  • 评估设置：SimplerEnv 闭环执行（多随机种子、held-out 布局、bootstrap 置信区间），并在 RoboCasa、LIBERO、迷宫域做泛化验证；主要指标包括 commanded-mode rate、steer range、P(cover all)、invalid draw、成功率、regret 与训练 FLOPs。
  • Coverage：确定性 MSE 读出把两个合法模式平均成对角抓取（invalid draw = 1.00，cover = 0.00）；WTA 虽几乎消除无效预测但 cover 仍为 0.00；GPL 达到 P(cover all) = 1.00、rerank feasible = 1.00。
  • Steerability：GPL 的 commanded-mode rate 从 0.48 单调升至 0.94；对 π₀ 原生 128 维动作块施加同等引导无可靠增益，且在 w>2 后下降；相对 ECoT 式语言基线，GPL steer range 为 +0.54 而语言基线仅 +0.02；对抗性引导下计划在全部 240 次 rollout 中决定执行目标。
  • Outcome adaptation：三物体重排中，冻结生成器的计划重排序显著降低期望 regret；双立方体隐藏可靠性任务中，critic 与奖励表在严格等效边界内追平 Continued-BC 与 AWR，其中 critic 约省 388× 训练 FLOPs，奖励表为 0 FLOPs。
  • 冗余性原则验证：歧义扫描显示生成式优势随任务模糊度单调上升，单模控制下反而出现净损失；遮挡实验中最长领先 stock π₀ 与无计划对照 36 / 28 个百分点；LIBERO 反事实干预把冗余度从 0.47 降至 0.00，oracle steer range 由 +0.19 提升至 +0.65，五点剂量扫描呈完美负秩相关（Spearman ρ = −1.00）。
  • 泛化性：学习式 2-D 计划潜变量在闭环中将 commanded-mode rate 从 0.50 提升至 0.78（oracle 编码真值路径上限 0.92），与手工 3-D 锚点统计不可区分（配对差 +0.03）；RoboCasa 上计划级重排序把任务成功率从 0.65 提升至 1.00。
  • 局限：全部实验在仿真中进行，未上真机；多模态场景多为自建；即便去除冗余，计划条件接口仍保留 0.274 的抓取率基线代价，且四项预注册的效应量预测均未达成。
