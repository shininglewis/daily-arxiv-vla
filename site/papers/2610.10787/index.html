Card 03 核心贡献

核心贡献

  • 提出 NavGPT-3 harness：把上下文管理、空间工具（observe、delegate、revise、annotate、terminate 四类操作）、持久路线状态与模型执行统一为具身接口，使 VLA 执行结果可被 Planner 检视、回溯、局部修复并显式决定任务完成。
  • 设计 OS-like runtime：推理、执行、监控作为独立线程以各自上下文、工具与权限运行，runtime 通过 motion authority（运动权限）与事件优先级进行调度、切换与撤销（如安全监控可直接夺权），支持中断与线程切换。
  • 提出 NavGPT VLA：以 Qwen3-VL-Instruct 为骨干、加 MLP 动作头，单步预测 8 个 waypoint；在 19.28M 有效样本上训练 4B 与 8B 两个规模，作为可跨任务、跨具身的导航基础模型。
  • 提出 Codec allocation 视觉 token 分配策略：借鉴 I 帧/P 帧视频编码，按场景变化量（P 帧的像素差）与位置权重联合分配视觉 token，使有限视觉预算流向真正发生变化的视图。
  • 用 Recursive Self-Improvement (RSI)（KDLoop 风格树搜索，含 Think/Critic/Experiment/Distill/Reflect）自动迭代 harness 的工具定义与视觉提示，形成最终接口。
  • 首次让自主智能体在 RxR-CE 上达到人类水平，并开源模型、代码与评测记录。
Card 04 方法描述

方法描述

  • Harness 层：构建 Planner 所见的观测与历史上下文，维护空间引用与标注，校验并执行工具调用，返回证据供下一轮决策；Planner 通过 $\pi_{\mathrm{Planner}}(\cdot\mid C_k,\mathcal{T}_k)$ 选择工具调用，harness 负责校验与执行。
  • Runtime 层：将活动组织为逻辑线程，用控制转移规则 $f_{\ell+1}=\sigma(S_{\ell},f_{\ell},e_{\ell})$ 决定运动权限归属，用 $\operatorname{eligible}_{\ell}(j,a)=\mathbf{1}[j=f_{\ell}\wedge a\in\mathcal{P}_j]$ 判定某线程是否有资格发起任务运动；保护性事件优先级最高，陈旧事件不能恢复已作废操作。
  • 工具分组：basic（observe_forward、observe_panorama、navigate_relative、terminate_episode）+ VLA（navigate_by_instruction）+ Map（observe_map）+ Backtrack（navigate_to_node、annotate_node）；VLA 的 stop 只结束一次委派，回合终止权始终在 Planner。
  • NavGPT VLA：输入指令与最多 16 个保留观测（每观测前/右/后/左四视图），输出 8 个累计目标 $\tau_n=((x_{n,r},y_{n,r},\theta_{n,r}))_{r=1}^{8}$，每步只执行第一个 waypoint 后重新预测。
  • Codec token 分配：对相邻保留图像做 64×64 缩略图 L1 差分 $\delta_{h,v}$，首帧为 I 帧（$s^{\text{change}}=1$），后续 P 帧为 $\operatorname{clip}(5\delta_{h,v},0.05,1)$；权重 $w^{\text{codec}}_{h,v}=w^{\text{pos}}_{h,v}s^{\text{change}}_{h,v}$，在预算与容量比 $\rho_{\text{vis}}<1$ 时把 token 从低变化图移向高变化图。
  • 训练目标：$\mathcal{L}=\mathcal{L}_{\text{nav}}+\mathcal{L}_{\text{NTP}}$，其中 $\mathcal{L}_{\text{nav}}$ 是 24 维 waypoint 的 L2 回归，两种损失等权；导航样本不参与下一 token 监督，QA/grounding 样本无动作目标、被掩码而非当零运动学习。
  • 数据加工：Habitat 离散动作模拟为 0.25 m 前进/15° 转向/补零停止，归一化尺度为 $(1.0,0.433,2.094)$；几何感知重采样降低前进动作偏置、提升转弯与停止占比；SRDF 的 DAgger 轨迹用"当前位置到目标的最短路径方向"重新标注，把在轨状态变为可恢复的偏离状态监督。

Card 06 评估与结果

评估与结果

  • 评估指标：SR（成功率）、SPL（路径长度加权成功率）、nDTW（归一化动态时间规整）、OSR（oracle 成功率）、NE（导航误差）；QA 任务报告准确率与归一化步数
  • 单模型性能：8B NavGPT VLA 单独在 R2R-CE 达 76.94 SR，在 RxR-CE 以 82.39 SR 领先已发表方法
  • 完整系统性能：NavGPT-3 在 R2R-CE 达 81.51 SR（SOTA）；在 RxR-CE 达到人类水平——90.43 SR vs 人类 90.4，78.47 nDTW vs 人类 77.7，每回合 1 分 22 秒（人类约 3 分钟）
  • 反应时间：纯语言模型决策的反应间隔为 3–19 s；由 VLA 执行路线时降到 0.5–1 s/步（1–2 Hz），大幅缩短推理回路
  • 工具消融（100 条 R2R-CE 子集，8B VLA）：GPT-6 Astra 仅 basic+Map+Backtrack 时 SR 72%；加 VLA 后 75–76%；VLA+Map+Backtrack 全开达 SR 82、OSR 84、NE 3.34、成本 $0.391；Opus 5 相应最佳为 SR 81、SPL 69.29
  • RSI 开发过程：单视图+原始步进 66% SR → VLA 委派 72%（4B）/76%（8B）→ VLA+空间工具开发最佳 81%；早期 place-graph 接口仅 54%，整合接口 77%
  • 资源开销：VLA-only 配置下语义 PLanner 推理开销为零，最省成本（$0.391–0.469/回合）；纯 Planner 配置 token 消耗高达 325k–721k、成本 $0.593–0.690、反应延迟 8.9–105.7 s
  • 跨任务迁移：同一 runtime 可迁移到 object-goal navigation 与具身问答；真实 Unitree Go2 上完成部署验证与"玻璃门执行可视化"恢复案例
