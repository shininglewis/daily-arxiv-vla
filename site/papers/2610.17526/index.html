Card 02 论文概述

论文概述

  • 论文研究世界动作模型（World Action Models, WAMs） 中未来状态表示的设计问题：用何种紧凑状态既能保留未来预测带来的规划与监督收益，又能避免昂贵的计算开销。

  • 目标是验证：相比动作only策略与现有 WAM，基于框轨迹的紧凑未来想象能否在更低成本下提升机器人操作的动作预测性能。
Card 03 核心贡献

核心贡献

  • 提出框轨迹（box trajectories） 作为一种可解释、以物体为中心的未来状态表示，用于世界动作模型。
  • 提出 BoxWAM：一个rectified-flow transformer，通过状态引导的注意力机制联合生成未来框轨迹与机器人动作。
  • 设计了因果状态-动作注意力掩码：动作 token 可关注未来状态 token，但未来状态 token 不能关注未来动作 token，使框轨迹成为引导动作生成的物体运动计划。
  • 在仿真（RoboTwin2.0）与真实机器人上验证：在更低未来建模成本下获得更好的动作预测表现。
  • 证明框轨迹可作为插件增强预训练 VLA 模型（π0.5），在匹配数据与训练步数下提升多任务性能。
Card 04 方法描述

方法描述

  • 状态表示：用每个被操作物体的最小体积有向 3D 边界框，将 8 个角点投影到第三人称相机图像平面，得到 16 维向量 x_t ∈ R^16；双臂场景为左右臂各保留一个框槽位。
  • 动作表示：相对关节位置指令 a_t = q_target − q_curr，归一化到 [-1,1] 后训练，推理时反归一化加回当前关节角。
  • 模型架构：冻结的 DINOv3 视觉编码器产生视觉上下文 token；每个未来时间步分配 1 个框 token 和 1 个动作 token；当前本体状态与流时间步通过 adaLN 注入每个 transformer block。
  • 注意力设计：框 token 关注视觉上下文与其他框 token；动作 token 关注视觉上下文、框 token 与其他动作 token；未来状态不依赖未来动作。
  • 训练目标：对联合变量 z¹ = [x¹, a¹] 使用 rectified-flow 目标，速度场分解为状态与动作两部分，损失为两项加权平方误差（λ_X = λ_A）；流时间步按 Beta(1.5, 1.0) 分布采样，与 π0.5 一致。
  • 推理：从 τ=0 到 τ=1 用 Euler 积分，采用二次积分调度 τ_k = 1 − (1 − k/N)²；动作块执行完后再重规划；任务特定仿真用 H=15，多任务与真实世界用 H=50。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin2.0（含 clean 与 randomized 两种设置），任务特定设置每任务 50 条演示，多任务设置 50 个任务 × 50 条演示 = 2500 条演示。

  • 模型规模：大规模设置下 3.35B 参数。
  • 训练/推理硬件：RTX Pro 6000 Blackwell GPU。
  • 真实世界框监督由 RGB-D 记录、已知网格与相机标定重建，抓取时做刚性位姿传播（附录 A）。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin2.0 仿真（clean/randomized）与真实机器人；对比 ACT、Diffusion Policy、DP3、π0、π0.5 及动作only（Flow）变体，并做状态表示、状态-动作交互、运行时消融。
  • 主要指标：任务成功率（SR），真实世界额外报告子目标进度率（Progress）；以及推理延迟（ms）。
  • 任务特定仿真：BoxWAM 在 clean 设置平均 78.3%（仅次于使用深度输入的 DP3），在 randomized 设置取得最高平均成功率 37.8%。
  • 多任务仿真：加入框轨迹预测后，π0.5 的 clean 成功率从 52.6% → 61.5%，randomized 从 26.9% → 34.0%。
  • 真实世界：BoxWAM 平均 60.85%，优于动作only变体 51.1% 与 Diffusion Policy 23.7%。
  • 状态表示消融：框轨迹在 randomized 设置最高（37.8%），优于 VAE（34.5%）、DINO（29.0%）、6D 位姿、2D OBB、功能关键点与末端轨迹；VAE 在 clean 最高（80.1%）但代价更高。
  • 状态-动作交互消融：future-then-action（BoxWAM） 最佳（clean 78.3 / randomized 37.8），优于完全分离、完全联合、action-then-future 等设计。
  • 运行时：动作only 168.3 ms、BoxWAM 172.4 ms、VAE 250.5 ms、DINO 251.4 ms，说明框轨迹是近乎零开销的轻量未来表示。
  • 与现有 WAM 及 IK 基线对比：BoxWAM 在 easy 达 87.94%、hard 达 87.62%，延迟 64.9 ms、3.35B 参数；基于 Mink 的差分 IK + M2T2（使用真值任务计划、位姿、深度与掩码）仅 26.78% / 26.30%。
  • 局限：依赖可靠的目标跟踪以获得真值监督，在严重遮挡、高度可变形物体或框信息不充分的场景下可能退化。
