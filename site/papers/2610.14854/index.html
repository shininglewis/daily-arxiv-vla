Card 02 论文概述

论文概述

  • 论文提出 DEFT-VLA（Dual-Expert Force-specialized Training for Vision-Language-Action Manipulation），针对接触密集型机器人操作中的“阶段依赖性感官冲突”问题。
  • 核心观察：非接触阶段（定位、对齐、接近）主要依赖视觉与本体感受，力反馈信息量低甚至具干扰性；接触阶段则相反，视觉相似状态可能对应不同物理状态，力反馈变得关键。
  • 目标是在不破坏已适应任务的视觉运动能力前提下，将力反馈特化局限在接触关键阶段，并抑制模型对视觉细节与机器人状态的“捷径”依赖。
Card 03 核心贡献

核心贡献

  • 提出阶段特化的双专家 VLA 框架：保留任务自适应的 base expert 处理非接触行为，另训练一个力感知的 contact expert 专注于接触阶段演示数据。
  • 提出接触局部化的力关注课程（contact-localized force-attending curriculum），包含视觉模糊抑制与状态 token 掩码（state-token masking），以缓解接触阶段的视觉与本体感受捷径。
  • 在三个真实机器人任务上验证有效性，相比最强基线整体成功率提升 20–40 个百分点，并给出对未见抓取高度的泛化实验与状态 token 掩码消融实验。
  • 表明“将感官适应局部化到其信息最有价值的任务阶段”这一设计原则的价值。
Card 04 方法描述

方法描述

  • 基于 π0.5 构建策略：共享多模态 VLM 前缀（图像 token、语言 token、状态 token）加两个独立参数的动作专家。
  • 两阶段训练：先完整演示数据微调得到任务自适应 base expert；再冻结 VLM 与 base expert，仅用接触阶段数据训练从 base expert 初始化的 contact expert 及其力输入模块。
  • 力特化接触专家：将归一化的腕部力/力矩历史展平线性投影为力 token，与动作 token 一同进入接触专家（参照 TA-VLA 的 token 注入设计）。
  • 接触阶段提取：以力阈值 δ_task 判定并按时间邻域 (n, m) 扩展，构造接触阶段数据集 D_C。
  • 自动专家路由：轻量级阶段估计器融合 VLM 图像 token（注意力池化）、机器人状态（MLP）、因果 GRU 编码的力历史，经融合 MLP 与 sigmoid 输出；采用滞回阈值 + 连续多步稳定机制避免频繁切换，切换时丢弃并重新生成未执行动作块。
  • 课程机制：早期对输入图像施加高斯模糊（σ_s = σ_max·λ_s），并对序列化状态 token 按 Bernoulli(p_max·λ_s) 采样替换为词表索引 0 的固定 token，两者随训练步数线性衰减至零，语言与力输入全程可用。
Card 05 数据集与资源

数据集与资源

  • 演示数据：移液枪头安装 130 条演示；双臂移液吸取 50 条；白板擦拭 50 条。
  • 机器人平台：Elephant Robotics Mercury B2 双臂机器人，控制频率 15 Hz。
  • 传感器：三台 Intel RealSense D435 相机（两个臂载近距视角、一个外部第三人称视角）＋两个腕部六轴力/力矩传感器。
  • 训练配置：接触专家与阶段估计器训练 30,000 步，批大小 8；σ_max=4.0，p_max=0.5，S_w=1,000，S_d=29,000；接触阈值分别为 5.0 N、2.0 N、4.0 N；时间扩展 (n,m) 分别为 (10,25)、(20,20)、(40,40) 帧。
  • 论文未明确给出模型参数量与 GPU/TPU 等具体训练硬件资源。
Card 06 评估与结果

评估与结果

  • 评估环境：真实机器人平台；主对比中每个方法每任务评估 20 次试验，测试摆放位置在方法间保持一致；阶段成功率以非接触阶段成功为前提条件。
  • 评估指标：整体成功率、非接触阶段成功率、接触阶段成功率，以及吸取任务的吸取体积平均绝对误差（Volume MAE，μL，越低越好）。
  • 主结果：DEFT-VLA 在三项任务上均取得最高整体成功率——枪头安装 70%（比最强基线高 40 个百分点）、双臂吸取 50%（高 20 个百分点）、白板擦拭 90%（高 20 个百分点）；接触阶段成功率分别为 93.3%、50%、90%。
  • 基线表现：π0.5 非接触阶段强（90%/95%/100%）但接触阶段弱（33.3%/5.3%/70%）；单纯加力 token 或全局施加 FAC 均不稳定，全局 FAC 使非接触成功率降至吸取 35%、擦拭 50%。
  • 泛化结果：在未见抓取高度下，DEFT-VLA 在枪头安装与双臂吸取上均达 50%，基线大多为 0–10%。
  • 消融结果：枪头安装上，无接触局部化 FAC 为 20%，仅有视觉课程无状态掩码为 15%，完整方法达 70%，说明状态 token 掩码在减少本体感受捷径中起关键作用。
  • 局限：仅在三个任务族上评估，白板擦拭使用手动触发专家切换；未来计划研究更通用的自动路由与跨任务迁移。
