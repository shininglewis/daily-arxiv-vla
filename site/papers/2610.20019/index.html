Card 03 核心贡献

核心贡献

  • 通过原子任务诊断实验，识别出参数冲突是跨多样化环境和交互扩展机器人学习的关键挑战。
  • 提出 MorphAct，使用两个表示耦合的生成器分别产生上下文相关的视觉-语言和动作参数更新，并通过原生动作目标联合学习。
  • 在三个 VLA 骨干（X-VLA、π0、π0.5）、两个模拟基准（LIBERO、Meta-World）和四个真实世界任务上验证了性能提升。
  • 消融实验表明，上下文生成和表示耦合对性能提升至关重要。
Card 04 方法描述

方法描述

  • MorphAct 在每次重规划时，根据当前观测上下文生成低秩参数更新：生成器 G_v 从多模态嵌入生成视觉-语言模块的更新，生成器 G_a 以适配后的 VLM 表示和机器人状态为条件生成动作模块的更新。
  • 两个生成器通过适配后的视觉-语言表示耦合：动作侧参数生成依赖于上游适配产生的特征，形成计算依赖链。
  • 使用结构化低秩合成（基于 HY-WU）产生 A/B 因子，避免物化密集权重矩阵，支持不同模块的宽度和深度。
  • 训练时冻结主干参数，仅优化生成器参数，通过原生动作目标（条件流匹配）联合训练，无需操作标签或专家适配器目标。
  • 推理时，参数更新在每次重规划上下文生成一次，并在整个动作块预测过程中重用，避免测试时优化。

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估环境：闭环任务成功率，模拟环境分别进行 50 次（LIBERO）和 20 次（Meta-World）rollout，真实世界每个任务 50 次物理 rollout。
  • 主要指标：任务成功率（%），LIBERO 报告四个套件平均分（Mean），Meta-World 报告 Easy/Medium/Hard/Very Hard 四组平均分（Avg.）。
  • LIBERO 结果：X-VLA 从 93.05% 提升至 97.20%（+4.15），π0 从 94.15% 提升至 96.65%（+2.50），π0.5 从 96.85% 提升至 98.60%（+1.75）。
  • Meta-World 结果：X-VLA 平均成功率从 55.54% 提升至 63.11%（+7.57），π0 从 50.75% 提升至 67.05%（+16.30），π0.5 从 48.70% 提升至 64.42%（+15.72）。
  • 真实世界结果：π0.5 + MorphAct 在四个任务上提升 8.00–14.00 个百分点，最大提升在 Sort Hardware（8% → 22%）。
  • 消融实验支持当前上下文条件、双模块适配以及通过适配后的 VLM 特征进行耦合的必要性。
