Card 02 论文概述

论文概述

  • 提出 ForkCast，一种面向冻结 VLA 策略的预测式恢复框架：在每个决策点比较“反事实未来”，判断是否干预以及如何干预。
  • 解决的问题是：视觉遮挡或物体滑移会使 VLA 策略执行失败，而现有方法要么在训练期学习恢复，要么依赖单独的失败检测器触发脚本化修复，无法判断“修复是否比继续更好”以及“哪种修复最有效”。
  • 核心思路是在共同预测时域上评估三类候选：Commit（继续名义动作块）、Reobserve（调整相机视角后重新查询策略）、Replan（重规划机械臂轨迹），由任务进度分数统一比较。
Card 03 核心贡献

核心贡献

  • 将冻结 VLA 策略的运行时恢复形式化为候选选择问题：在名义执行、视角条件化的策略延续、规划式机械臂修复之间，按共同时域上的预测任务进度进行比较。
  • 设计共享的预测与打分机制处理异构恢复候选：以规划臂动和相机偏移为条件，用适配的潜在世界模型预测候选端点潜变量，再由共享进度头映射为任务进度分数。
  • 无需失败检测器、无需干预阈值、不更新 VLA 主干，仅凭单次进度比较即可同时决定是否干预与如何干预。
  • 在 RoboTwin 2.0 五个任务（注入遮挡与滑移）上把冻结 π0.5 的合并成功率从 13.3% 提升到 30.0%，并零更新迁移到 RDT 与 XR-0 两个额外主干。
  • 在真实机器人候选回放上适配后，在干净与受限可见性条件下均优于基座策略；代码将开源。
Card 04 方法描述

方法描述

  • 三阶段流程：候选生成 → 候选条件化的反事实未来预测与打分 → 选择并执行最高分候选。
  • 候选构建：视觉前端使用 OWLv2 开词检测、SAM 分割与 Depth Anything V2 度量深度，多视角反投影得到目标点云质心 p_t。
  • Commit：复用冻结策略预测的原始动作块，并恢复名义参考视角。
  • Reobserve：从 J=21 个预定义相机位姿库（横向偏移 ≤ ±8 cm、偏航角 ≤ ±24°，无目标位置估计时扩展为 35 个）中，按目标像素数筛选候选，再以离中心代价排序选出最佳视角并重新查询冻结策略，生成的动作块被缓存复用。
  • Replan：基于 p_t 用现成运动规划器生成无碰撞路径到达 p_t + Δ_tcp，保持末端执行器朝向，终点保证夹爪可包住目标。
  • 候选编码：前向运动学把关节轨迹映射为末端位姿，条件量 U_t^c = (Ã_t^c, D̃_t^c, ΔG_t^c)，即逐步末端增量、累积位移与相机位姿偏移；Align_Hf 对长计划截断、对短计划补齐至共同时域 H_f。
  • 预测与打分：冻结 V-JEPA 2 ViT-g 编码器将 16 帧历史（步长 2）编码为 T_0=8 个潜在步 × N_z=256 token；适配自 V-JEPA 2-AC 的预测器以 M 个里程碑自回归预测端点潜变量，共享进度头对潜变量取平均后经 LayerNorm 与两层 MLP 输出进度分数。
  • 训练：通过 mining 在决策点回放各候选分支收集数据；损失 L = λ_Z L_Z + λ_ρ L_ρ，两项均用 smooth-L1，权重 ω_m = exp(β(m−M)) 向端点几何增长；训练时 teacher forcing，推理时自回归展开；只训练预测器最后 4 个 block、三个条件编码器与进度头。
  • 选择与执行：仅用最终里程碑 m=M 的端点分数做 argmax，并列时优先 Commit；Reobserve 的相机位姿更新不计入臂控制步，Replan 是唯一额外消耗臂控制步的候选。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboTwin 2.0（基于 SAPIEN 的双臂桌面基准），使用 clean 配置、不做域随机化。
  • 五个任务：Place A-to-B left、Place A-to-B right、Place cup、Stack two blocks、Click bell。
  • 基座策略：π0.5，每任务用 LoRA 在 50 条演示上微调后冻结；迁移实验另用 RDT 与 XR-0（各在同一批 50 条演示上微调）。
  • 注入扰动：Occlusion（宽 1.8 cm 立柱遮挡头部相机视线）、Slip（第 40 控制步将目标在桌面随机方向位移 4 cm）。
  • 超参数：H_a=32、H_f=64、M=8，首次决策在第 64 步；编解码步长等见上文；训练 30 epoch，AdamW，batch size 3，学习率 10⁻⁴，β=0.35，λ_Z=λ_ρ=1。
  • 进度标签：ρ = clip(1 − d/d_ref, 0, 1)，d 为物体到目标距离，d_ref 为同一决策状态各分支首个里程碑距离的最大值。
  • 评估协议：每任务每条件 6 个 episode × 5 任务 = 每方法每条件 30 个 episode，pooled-OOD 为 60 个；episode 上限 240 控制步；评估种子与 mining 种子不重叠。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0 闭环仿真（五任务 × clean/slip/occ）+ 真实机器人实验；基线包括 Commit、固定 Reobserve/Replan、Random、Direct progress regressor 与特权 Oracle。
  • 主要指标：闭环任务成功率（%），并按 pooled-OOD（slip 与 occlusion 平均）汇总；另报告 95% Wilson 置信区间。
  • 主要结果（π0.5，表 I）：ForkCast 在 clean/slip/occ/pooled-OOD 分别为 76.7 / 33.3 / 26.7 / 30.0，优于基座 53.3 / 10.0 / 16.7 / 13.3、最佳固定策略 21.7、Random 16.7 与 Direct 20.0，且在每个条件均为最优或并列最优；特权 Oracle 为 83.3 / 36.7 / 26.7 / 31.7，pooled-OOD 仅高出 ForkCast 1.7 个点。
  • 固定策略对照：Replan 在 clean 与 slip 下最好，Reobserve 在 occlusion 下最好，没有任何单一固定策略在两种扰动下同时领先。
  • 跨主干迁移（表 II）：直接复用 π0.5 分支上训练的 ForkCast，XR-0 pooled-OOD 从 0.0% → 21.7%，RDT 从 5.0% → 23.3%，全部条件均有提升。
  • 消融（表 III）：全模型与独立重训的 Replica 均满足敏感性、效应方向与排序方向三项判据；NoCond 在敏感性与效应方向上失败；NoState 排序判据失败（+.157，与 Replica 的 +.161 区间不可区分）；NoCamera 降低敏感性与潜变量效应对齐，闭环 pooled-OOD 仅 21.7%、遮挡下 16.7%（与 Commit 相当），显著低于全模型的 30.0% 与 26.7%。
  • 选择质量诊断：在 N_diff=16 的候选集上，ForkCast 最佳集命中率 75%（Random 37.5%、Direct 25%），丢失进度 0.046（Random 0.103、Direct 0.092）。
  • 真实机器人：在真实候选回放上适配后，ForkCast 在干净与受限可见性条件下成功率均优于基座策略（含 Reobserve+Replan 的定性案例）。
