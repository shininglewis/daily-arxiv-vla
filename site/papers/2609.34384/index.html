Card 02 论文概述

论文概述

  • 论文研究 隐式指代定位（Implicit Referential Grounding, IRG），即机器人需从语言或感知上下文中恢复指令未显式给出的目标实体、属性、数量或关系。
  • 现有 视觉-语言-动作（VLA） 模型基准普遍假设任务相关信息在指令中被显式指定，忽略了人类日常使用 "it"、"the one there"、"the other one" 等省略式指代表达的现实情况。

Card 03 核心贡献

核心贡献

  • 首次将 隐式指代定位 形式化为 VLA 模型中重要但未被充分探索的评估维度，考察策略能否从语言与感知上下文中恢复任务相关信息。
  • 提出 RoboIRGBench，一个包含 40 个任务变体、覆盖四类互补挑战（Direct、Reasoning-Mediated、Spatial、Contextual）的仿真操作基准。
  • 对显式与隐式指令进行 成对系统评估，发现代表性 VLA 系统存在显著指代鲁棒性缺口，且仅靠更强的外部视觉-语言推理模型也无法消除这些失败。
  • 在 Franka Research 3 机械臂上完成真实世界验证，确认仿真中的鲁棒性缺口在物理执行中同样存在。
  • 阐明 IRG 与 记忆（memory） 的关系：记忆决定可用上下文，而 IRG 决定如何解释并落地这些信息用于控制，记忆本身并不足以保证鲁棒指代定位。
Card 04 方法描述

方法描述

  • 以 RoboMME 为基础构建基准，核心设计原则是 保持操作目标不变、仅改变任务相关信息的表达方式（如把显式目标名替换为代词、序数、排除关系、空间线索等）。
  • 定义四类 IRG 挑战：

- Direct Referential Grounding：恢复前文已引入但最终指令未重述的目标（it、them、the former、the latter、that 等）。

- Reasoning-Mediated Referential Grounding：通过颜色排除、数量推断、序数/时序关系、上下文逻辑四种推理模式推导目标。

- Spatial Referential Grounding：依据机器人坐标系中的空间地标定位目标（Swap 任务以操作前初始位置定义地标）。

- Contextual Referential Grounding：构造五阶段上下文序列（Referent Introduction → Referent Reinforcement → Distractor Context → Action Cue → Referential Instruction），测试长上下文中指代的保持与恢复。

  • 使用 基于规则的语言模板 生成指令，确保受控且可复现，每类任务在 Easy / Medium / Hard 三个难度上评估。
  • 评估覆盖采用 不同记忆机制 的代表性 VLA 架构，并对比引入外部 VLM 的变体。
Card 05 数据集与资源

数据集与资源

  • 基准数据来源：RoboMME 的 Counting、Permanence、Reference 三个套件。
  • 共 40 个任务变体，源自 11 个操作任务；排除 5 个指令中不含可变任务定义变量、难以构造隐式对应版本的 RoboMME 任务。
  • 空间指代设置覆盖 11 个任务中的 7 个；StopCube、VideoRepick、VideoPlaceButton、VideoPlaceOrder 因目标由动作计数或时序定义而被排除。

  • 涉及的模型：MemER、π0.5、TTT-Expert、FrameS-Modul、GroundSG-QwenVL，以及外部 VLM Qwen-VL 和更强的 Gemini 3.1 Pro。

Card 06 评估与结果

评估与结果

  • 评估设置：在统一仿真环境中对 显式指令 与四类 隐式指代指令 进行成对比较，指标为 任务成功率（%），包含各任务与平均（Avg）成功率。
  • 关键结果（显式 → Direct 的平均成功率）：

- FrameS-Modul：45.82 → 29.76（▼16.06，下降最大）

- GroundSG-QwenVL：37.03 → 36.18（▼0.85）

- MemER：42.91 → 32.67（▼10.24）

- π0.5：22.73 → 21.15（▼1.58）

- TTT-Expert：22.24 → 20.48（▼1.76）

  • 显式指令下表现良好的模型在隐式指代下 显著退化，说明记忆机制本身不足以保证指代鲁棒性。
  • 推理介导 与 空间指代 尤其困难；部分任务上模型成功率降至 0（如 GroundSG-QwenVL 在多处出现 0.00）。
  • 引入 外部 VLM（如 Qwen-VL） 的模型整体鲁棒性更强（GroundSG-QwenVL 平均 36.18，为对比中最稳者），但仍存在大量失败案例。
  • 将外部 VLM 替换为更强的 Gemini 3.1 Pro 并不能消除 这些失败，说明单纯扩展上游视觉-语言组件不足以保证鲁棒指代定位。
  • 真实机器人实验中，相同鲁棒性缺口在物理操作下持续存在，失败既表现为 指代目标定位错误，也表现为 下游执行失败。
  • 结论：IRG 是可靠机器人指令遵循中一个独立且尚未充分探索的能力，需要 VLA 模型更稳健地整合语言、感知、推理与动作。
