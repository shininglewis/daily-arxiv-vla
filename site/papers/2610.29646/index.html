Card 02 论文概述

论文概述

  • 研究机器人示教语料库（corpus）的选择问题：能否用训练前的诊断指标，对候选语料库排序，从而挑出能训练出更好 VLA（视觉-语言-动作） 策略的语料库。
  • 提出 paired instruction dependence（配对指令依赖度，A_d）：在同一观测和动作历史下，只更换目标指令，统计示教器改变首个决策的切换率。
  • 核心问题：这种无符号（unsigned）切换率在已知示教器边际正确率之后，是否还能带来增量预测价值与决策价值（不只是相关性）。
Card 03 核心贡献

核心贡献

  • 前瞻式决策价值评估：将「可靠性 → 关联性 → 增量预测 → top-k 选择」四个判据明确分离，并以语料库为推断单元，在 80 个完全留出语料库上做预设（prespecified）检验。
  • 定位预测-排序错配的结构性来源：发现无符号切换率混合了「两个目标都答对」与「两个目标都答错」两类行为，拆解后（a_d、b_d）在探索性分析中取得更大留出增益。
  • 决策分辨率基准与实用基线对比：用跨随机种子的排序一致性给出经验分辨率上界，并与示教器成功率、训练轨迹首步正确率、Qwen3.5 小模型代理选择器等实际可选方案对比定位。
  • 负结果的方法论价值：证明一个可靠且与下游相关的诊断信号，压缩成无符号统计量后仍可能缺乏增量决策价值。
Card 04 方法描述

方法描述

  • 同状态目标交换审计：对每个审计状态用相同 RGB 观测与动作历史查询示教器两次，仅改变目标（两个目标要求相反分支），计算切换率 A_d（式 1），在平衡确定性干预下等价于状态平均的条件互信息。
  • 统计分解：令 a_d、b_d、c_d 分别为「两个目标都对」「两个目标都错」「仅一个对」的比例，边际正确率 p_d = a_d + ½c_d；二值情形下 A_d = a_d + b_d，即 (p_d, A_d) 是 (a_d, b_d) 的可逆重参数化（无符号和 vs. 有符号差）。
  • 嵌套 Beta-Binomial 预测器：C_{d,s} ~ BetaBinomial(m, μ_{d,s}, ρ)；M₀ 用 W_d（逐目标示教正确率、训练目标熵、动作熵）+ 交叉种子项 γ_s，M₁ 仅额外加入 ηA_d，两者使用相同 48 条示教响应，从而隔离「配对结构」本身。
  • 主估计量：等语料平均的恰当对数得分增益 δ̄（式 6），语料簇 bootstrap 给 95% 置信区间；选择端按预测平均正确率排序，取 K=16/80（top-20%）。
  • 推断协议：预测器、留出语料 ID、top-20% 操作点在揭示结果前预先固定；分解、分辨率、代理、校准、闭环相关分析均标注为探索性。
Card 05 数据集与资源

数据集与资源

  • 仿真环境：Isaac Lab 中的 Unitree Go2 物体目标导航任务；每个语料库使用独立训练的表格 Q-learning 示教器（训练/布局/物理/渲染种子均不同）。
  • 语料库规模：共 136 个独立种子语料库（56 个开发 + 80 个留出），检查点覆盖 10、50、250、1,000、50,000 episode 五档。
  • 数据量：6,528 条训练轨迹（43,084 步）、3,264 个审计状态、6,528 个 ID 评测状态；每语料含 24 个配对审计状态、48 条训练轨迹、48 个配对 ID 评测状态（审计/训练/评测在状态、图像、轨迹层面完全不相交）。
  • 模型：主学习器 Qwen2.5-VL-3B-Instruct，辅助骨干 Qwen3.5-VL-0.8B；冻结视觉塔，仅在语言模型投影层训练 rank-8 LoRA 适配器，全因子共 544 个 adapter。
  • 计算成本：审计中位 4.18 GPU-min/语料库；一次 Qwen2.5 微调平均 10.68 GPU-min（微调+ID 评测 11.46 GPU-min，约为审计的 2.74 倍）；Qwen3.5 微调平均 13.41 GPU-min。
  • 真机：48 次物理 Go2 闭环运行 + 36 张人工筛选静止图像（72 次查询/adapter）。
Card 06 评估与结果

评估与结果

  • 评估设置：Qwen2.5/Qwen3.5 各在 ID 与受控场景偏移（2×2 几何/光照设计）下评测；另有 16 个分层语料库 × 24 场景 × 2 目标 = 768 个闭环仿真 episode。
  • 主要指标：恰当对数得分增量（主终点）、MAE、Pearson/Spearman 相关、top-20% 选中正确率、regret、oracle 重合度、审计可靠性。
  • 可靠性与关联：A_d 可靠性 .802（留出 .766）；与 Qwen2.5 配对正确率 Spearman 全体 .467、留出 .356——信号本身可靠且与下游相关。
  • 主结果（未达标）：加入 A_d 的对数得分增益仅 +0.059 nats（95% CI [-0.027, 0.133]），区间跨零；受控偏移 +.029、Qwen3.5 ID +.036、Qwen3.5 偏移 +.010，全部跨零。
  • 预测-排序错配：MAE 从 .110 降到 .096（改善），但 Spearman 从 .589 降到 .490、选中正确率从 .838 降到 .811、regret 从 .078 升至 .105——绝对预测变好，排序却变差。
  • 结构分解（探索性）：M₀+a_d 增益 +.104 [.049, .153]、M₀+b_d +.110 [.022, .188]，均超过无符号 A_d 的 +.059；选中正确率 .846/.842 vs .811。
  • 分辨率基准：两个 Qwen2.5 种子排序一致度 ρ=.567，交叉选种正确率 .874、oracle 重合 .50，显著高于 M₀(.838) 与 M₁(.811)，说明留出终点仍含可恢复排序信号。
  • 实用基线：Qwen3.5 代理选择器排序 ρ=.715、选中正确率 .866，优于两个审计预测器，但成本（13.41 GPU-min）并未低于单次微调。
  • 局部 vs. 闭环分离：768 episode 中首指令正确率 .829，但到达目标仅 .655，存在 17.4 个百分点差距；637 次首步正确中有 134 次后续失败，131 次首步错误无一挽回。
