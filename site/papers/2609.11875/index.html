Card 03 核心贡献

核心贡献

  • 识别并形式化 transition realizability gap，将其分解为 transition ambiguity、prediction–execution mismatch 和 experience–realization mismatch，并提出统一模型 UniMPA。
  • 设计 Persistent-Selective Future Prediction：持续 latent 流跟踪任务级进展，transition-critical pixel 流选择性解决细粒度交互变化，并用未来目标监督 World-Expert transition tokens。
  • 引入双向 Visual-Action Memory Bank 和 Action-Visual Memory Bank，存储时间对齐的视觉-动作转移经验，使预测的未来能够检索历史上可执行的视觉-动作证据。
  • 提出 Prototype-Biased Flow，利用检索到的可执行动作原型偏置 flow source，将动作生成推向历史支持的动作流形，并由策略针对当前场景进行上下文自适应细化。
  • 实验表明 UniMPA 仅需 π₀.₅ 基线 25–50% 的训练 epoch，即在 LIBERO、LIBERO-Plus、RoboTwin 2.0 Hard 和真实世界任务上分别提升 1.7、11.7、18.5、12.6 个百分点。
Card 04 方法描述

方法描述

  • 采用三系统 Transformer 架构：VLM backbone、World Expert、Action Expert，通过 action-grounded transition interface 进行跨流交互。
  • Persistent-Selective Future Prediction：World Expert 将零初始化的 transition queries 转换为 latent transition tokens，训练时用未来 latent 和触发式像素目标监督；Trigger Gate 仅在接触、释放等 transition-critical 时刻激活像素解码。
  • Transition-Aligned Bidirectional Memory Pretraining：使用冻结的 V-JEPA 2 提取视觉 key，使用 Mamba 模块编码 episode 级时序 value，并通过 cross-stream transition grounding 将动作动态注入视觉记忆、将视觉转移语义注入动作记忆。
  • 记忆训练包含 Future-Oriented Memory Reconstruction 和 Retrieval-Simulation Training，前者将视觉 value 解码为未来图像、动作 value 解码为未来动作块，后者模拟检索并优化 key/value 空间。
  • Prototype-Biased Flow：Action-Visual Memory Bank 检索视觉 grounded 的动作原型，将其作为 flow 初始分布偏置；Action Expert 再基于当前观测、语言和机器人状态进行细化。
  • 推理时移除显式 latent/pixel 解码头，保留 World Expert 及其 transition tokens，并与检索到的动作流形先验共同条件化动作生成。

Card 06 评估与结果

评估与结果

  • 评估环境覆盖多个仿真基准和真实世界任务，主要评估指标为任务 成功率。
  • LIBERO 成功率 98.6%，LIBERO-Plus 成功率 85.3%，分别超过 π₀.₅ 基线 1.7 和 11.7 个百分点。
  • 在 RoboTwin 2.0 Hard 上提升 18.5 个百分点，在真实世界任务上提升 12.6 个百分点。
  • 训练效率显著：仅需 π₀.₅ 基线 25–50% 的训练 epoch。
  • 消融研究验证了 Persistent-Selective Future Prediction、Transition-Aligned Bidirectional Memory、Future-Oriented Memory Pretraining 和 Action-Manifold Prototype Refinement 等组件的有效性。
  • 与 Fast-WAM、MemoryVLA 等预测型或记忆型范式相比，UniMPA 在基础性能和泛化性能上均表现更优。
