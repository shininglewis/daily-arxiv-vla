Plausible Future, Wrong Choice: Steering World-Action Models toward Intended Future

2026-10-20 · 原文 · 翻译 · 2610.28431

论文关注 World-Action Models（WAMs） 在长时序机器人操作中的失败模式：模型能生成视觉上合理、物理上可行的未来，却把执行引向错误的任务阶段，作者将这一现象命名为 Stage Confusion（阶段混淆）。 现有 WAM 仅从任务指令、当前观测和原始历史中隐式推断阶段进展，当相似观测-动作片段在不同任务/阶段重复出现时会发生跨任务混淆与任务内混淆（阶段重复或跳步）。 研究目标是让 WAM 显式地在“任务要求”和“执行进度”双重约束下生成符合意图的未来，并建立一个可控的多阶段评测基准。

Card 03 核心贡献

核心贡献

  • 首次识别并形式化了世界-动作建模中的 Stage Confusion 问题，区分 Cross-task confusion（走向其他任务的阶段）与 Within-task confusion（同任务内相似阶段重复/跳过）。
  • 提出 TaskWAM 闭环、阶段感知框架：用 Mode Tokens 编码细粒度任务要求，用 State Tokens 跟踪执行进度，构成结构化任务状态并据此引导世界-动作生成。
  • 提出 Task-State Conditioned Future Steering，通过注意力条件注入、层间 AdaLN 调制和残差流（velocity residual）校正，将世界流与动作流同时导向意图未来。
  • 构建 StageBench：基于 LIBERO 与 RoboTwin 2.0 的可控多阶段操作基准，覆盖 8–10 个任务族、参数化阶段变体（顺序、时序、重复、双臂分配）与自动化阶段级评测器。
  • 在仿真与真实世界、以及单臂/双臂夹爪/灵巧手/人形等多种本体和异构 WAM 主干上验证了即插即用的迁移能力。
Card 04 方法描述

方法描述

  • Structured Task-State Grounding：任务状态表示为 T_t = [M; S_t]，其中 M 为 Mode Tokens、S_t 为 State Tokens。
  • Mode Tokens：用预训练 T5 编码指令，路由头预测对 K_prior 个可学习模式的软分配，从模式码本 E 中软检索槽位，再以检索槽位为 query 对语言 token 做交叉注意力（Q_ground）完成指令接地，获得持久保留的细粒度执行要求表示。
  • State Tokens：每个历史槽将上一动作块 A_{k-1}、Wan Video VAE 编码的视觉隐变量 F_k 及其差分 ΔF_k 拼接，经 Q-Former 聚合为单 token，再由因果时序编码器按执行顺序建模最近 K 次交互，实现闭环执行进度跟踪。
  • Task-State Conditioning：把 T_t 追加到世界流与动作流的 key-value 上下文，并将 Mode Tokens 池化为 m̄ 做逐层 AdaLN 调制，保持主干原有 world-action 注意力结构以支持异构主干。
  • World-Action Flow Steering：轻量交叉注意力头 R_b 以隐藏状态查询 T_t，预测速度残差 Δv，以可学习有界尺度 γ_b 修正世界与动作速度（Cosmos Policy 则在原生 EDM 形式下校正去噪潜变量）。
  • 训练目标：端到端沿用主干原生生成目标，L = L_world + L_action（flow matching 或 EDM denoising）。

数据集与资源

  • StageBench：基于 LIBERO（单臂）与 RoboTwin 2.0（双臂）构建，覆盖厨房与家庭多阶段场景，共约 10 个任务族。

  • 训练资源：16× NVIDIA H100 80GB GPU；效率测试在单张 RTX 5090 上进行（30 次预热 + 100 次计时）。

Card 06 评估与结果

评估与结果

  • 评测环境：StageBench 仿真、RoboTwin 2.0（Clean / Randomized）、四类真实世界多阶段任务；仿真结果均为 100 次试验平均。
  • 主要指标：任务成功率 Suc.、阶段进展率 SPR（Stage Progress Rate）、逐阶段累计完成率 S_k、端到端推理时延。
  • StageBench 主结果：Fast-WAM 从 40.9% → 69.4%（+28.5%），超过最强单模基线 π0.5（54.5%）；Cosmos Policy 从 32.6% → 45.5%（+12.9%）；单臂任务提升 15–25%，双臂任务提升 28–54%，最大提升为 Size-Order Cubes（11% → 65%）。
  • RoboTwin 2.0：平均成功率 Clean 92.70（+0.82）、Randomized 93.06（+1.28），随机化设置下取得最佳结果。
  • 阶段混淆缓解：SPR 从 68.4% 提升到 87.1%；在 Cooking & Cleanup 案例中后段阶段的优势随执行推进而扩大。
  • 消融实验：基线 40.9 → +Mode Tokens 56.4 → +State Tokens 61.6 → +Residual Flow 69.4，各组件均有稳定增益。
  • 真实世界：最终阶段成功率较 FastWAM 提升 15–35%；在近 2 分钟的 Bread Toasting & Spreading 任务中，FastWAM 末阶段仅 5.0%，TaskWAM 保持 20.0%。
  • 效率：时延从 0.190s 增至 0.209s，以极小推理开销换取显著的多阶段可靠性提升。
