WorldBridge: Bridging Video and Action for Task Generalization in World Action Models

2026-10-29 · 原文 · 翻译 · 2610.40748

论文研究世界动作模型（World Action Models, WAMs）在物理环境中的任务泛化问题，将其拆解为两个互补能力：视频泛化（预测新任务的视觉演化）与动作泛化（把视觉预测转成可执行动作，即“video-to-action bridge”，扮演逆动力学模型 IDM 的角色）。 通过在 RoboTwin 2.0 上系统改变分布内（ID）与分布外（OOD）任务的视频/动作监督量，论文量化了两类监督各自对任务迁移的贡献，并据此提出 WorldBridge 模型与配套的统一数据处理流程。 论文要回答的核心问题是：更广的视频覆盖与额外的动作监督分别如何促进任务泛化，以及二者之间的“桥接”何时成为瓶颈。

Card 03 核心贡献

核心贡献

  • 从视频泛化与动作泛化互补视角系统研究 WAM 的任务泛化，量化了“仅 ID 视频-动作监督（25.07% OOD）” → “加入 OOD 视频但无动作标签（55.90%）” → “每任务仅 1 条动作示范（70.70%）”的增益规律。
  • 提出 WorldBridge：基于 Mixture-of-Transformers（MoT） 的视频专家 + 动作专家架构，通过结构化注意力与联合 flow matching 把视觉动态显式接到动作生成上。
  • 设计统一数据处理管线，将异构机器人轨迹与第一视角人类（ego）演示标准化到共享 46 维动作空间，并用逐维有效性掩码支持部分监督。
  • 引入双时间尺度视觉记忆（短期/长期）与Action Forcing（动作块内不同噪声水平训练），增强时序上下文利用与动作对视觉信息的依赖。
  • 在多个仿真基准与真实机器人平台上取得对比方法中的 state-of-the-art 表现，验证了视频预测与动作落地联合训练的价值（含跨本体迁移）。
Card 04 方法描述

方法描述

  • 架构：两个模态专属专家（video expert / action expert）各自持有 FFN 与输出解码器；video expert 额外通过 cross-attention 注入 T5 语言特征；条件上下文由 video VAE 编码的观测与 T5 语言编码构成。
  • 联合 flow matching：视频流时间步 $\tau_v$ 与动作流时间步 $\tau_a$ 独立采样，两专家在不同噪声水平下联合去噪，损失为等权重的视频/动作 flow-matching 损失。
  • 结构化注意力掩码：预训练阶段视频 token 不看动作 token（保证动作无关的视频生成），动作 token 可看全部视频与动作；后训练阶段则构建“记忆/当前帧 → 未来视频帧 → 动作”的单向信息通路，使动作显式以预测的视觉演化为条件；强记忆需求任务回退到预训练掩码。
  • 双尺度视觉记忆：短期记忆偏移 $[-8,-6,-4,-2]$ 捕捉局部运动，长期记忆偏移 $[-128,-96,-64,-32]$（长步长 $\delta_l=H=32$）刻画任务进展；与当前帧一起经因果 video VAE 编码为 3 个 latent 帧。
  • Action Forcing：把标量动作流时间步扩展为向量，按组大小 $g$ 独立采样每组时间步，使同一动作块内同时存在干净与被高度破坏的 token，迫使每个动作 token 更多依赖视觉上下文；推理时仍用统一时间步联合去噪。
  • 统一动作空间：46 维 = 机械臂关节 14D + 末端位姿 14D + 夹爪 2D + 灵巧手 12D + 腰部 4D；末端位姿以当前末端坐标系表达为相对量（位置差 + 旋转向量 log map），并用逐数据集/机器人类型的掩码归一化。
  • 数据清洗：机器人数据经语义审计与表示标准化、静止首尾裁剪与长度过滤（<48 帧剔除）、正运动学（FK）位姿一致性校验、突变/状态-动作一致性/极端值异常检测；ego 数据经坐标标准化（转到当前相机系）、手部几何到动作的映射（腕部位姿、夹爪开合、灵巧手关节）、几何与运动学质量过滤。
  • 效率优化：解耦视频/动作去噪（先做 $n$ 步同步去噪并缓存逐层 video KV，剩余 $N-n$ 步仅用缓存特征去噪动作，视频分支不再解码 RGB）；torch.compile 算子融合 + CUDA Graph 重放；真实机器人上采用异步执行与动作块时间戳丢弃过期动作。
Card 05 数据集与资源

数据集与资源

  • 机器人数据：ABC-130K、AgiBotWorld-Beta、AgiBotWorld2026、DROID、Galaxea Open-World、RoboMIND、RoboCOIN、RoboMIND 2.0，以及仿真来源 GenieSim 3.0、InternData-A1。
  • 第一视角（ego）数据：EgoStandard、Lightwheel、XDOF、CyberOrigin、GenRobot、Xperience、EgoDex。
  • 数据规模（清洗后）：机器人 1,275,715 episodes / 9,729.58 小时；ego 2,105,846 episodes / 12,591.63 小时；合计 3,381,561 episodes / 22,321.21 小时（清洗前 3,888,958 episodes / 28,104.87 小时，保留率 79.42%）。
  • 模型规模：论文（提供的文本）未明确给出参数量；模型组件包括视频 VAE（时间压缩因子 4）、T5 文本编码器与 $L$ 层 MoT 块。
  • 训练资源：BF16、64 张 GPU，每卡 12 个样本、2 步梯度累积，有效 batch size 1,536；AdamW（$\beta_1=0.9,\beta_2=0.95$，weight decay 0.01，梯度裁剪 0.5），基础学习率 $10^{-4}$，共预训练 60,000 步，前 2,000 步线性 warmup。
  • 训练配置：动作块 $H=32$、8 帧未来视频（每 4 个动作步对应 1 视频帧）；机器人/ego 动作采样率 15 Hz 与 30 Hz，采样概率 0.7/0.3；三视角数据拼成 T 形布局并缩放为 320×384。
Card 06 评估与结果

评估与结果

  • 基准：RoboTwin 2.0（含 full data 与 clean-to-random C2R 设置）、RoboCasa GR1 TableTop、RMBench、DOMINO Level-1、SimplerEnv-WidowX、RoboDojo；真实平台 AgiBot-G2 与 ARX AC-1（同一联合预训练 checkpoint 分别微调）。
  • 主要指标：任务成功率（Success Rate, %），并区分 ID / OOD / Overall SR；真实实验覆盖长程执行、记忆依赖任务、空间定位与双臂协同。
  • 任务泛化（RoboTwin 2.0，OOD 动作监督量扫描）：仅 ID 监督 91.85% ID / 25.07% OOD / 71.81% 总体；加入 OOD 视频后 OOD 升至 55.90%（+30.83），ID 保持 91.96%，总体 81.14%；每任务 1 条示范 → 70.70%；5 条 → 84.67%（较无 OOD 动作标签 +28.77）；20 条 → 90.03%（仅比 550 条低 2.80 点，约用 3.6% 的标注预算）；100 条 → 93.17%；550 条 → 92.83%（收益递减）。
  • 仿真基准成绩：RoboTwin 2.0 全数据 96.23%、C2R 设置 80.9%、RoboCasa GR1 TableTop 82.8%、DOMINO Level-1 57.6%、RMBench 83.0%（与对比最优持平），均为对比方法中的 state-of-the-art。
  • 消融与分析：验证了联合视频-动作预训练的收益、记忆对“饮料扫描”类记忆依赖任务的作用、跨本体迁移效果，以及推理延迟（解耦去噪、异步执行）的影响。
