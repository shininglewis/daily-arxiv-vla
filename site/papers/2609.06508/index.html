Card 03 核心贡献

核心贡献

  • 识别出执行状态理解是当前 VLA 系统缺失的关键能力，并将其定义为从动作生成到可靠闭环控制之间的桥梁
  • 提出基于可观测历史的 Learned Verifier，利用视觉-本体-动作时间序列联合估计操作进度和执行风险，无需特权环境状态
  • 提出 Prompt Recovery 机制，通过保留原指令并拼接阶段恢复提示，使冻结的 VLA 策略完成闭环纠错，无需微调或修改动作
  • 建立基于扰动的系统评估协议，覆盖 LIBERO 与 LIBERO Plus 的多种执行偏差场景，并在真实机器人平台验证迁移能力
Card 04 方法描述

方法描述

  • 基础策略为冻结的 OpenPI pi05_libero 策略，推理时每 5 步重新规划，输入为 224×224 图像
  • Learned Verifier 采用轻量时序网络：双视角 RGB（112×112）经参数无关的空间统计特征提取后投影至 64 维，8 维本体感知与 7 维动作拼接后投影至 32 维，经 GRU（隐含维度 64）整合后输出二值风险概率与阶段预测
  • 特权规则验证器（Rule-Based Verifier）利用仿真真值追踪状态机，作为训练教师和性能上界参考
  • 在线触发门控采用风险阈值 0.40、连续 4 帧确认、10 步冷却期，避免瞬时误报；阶段置信度低于 0.9625 时回退到通用恢复提示
  • 恢复提示格式为原指令 + "Immediate recovery: " + 阶段指令，恢复后恢复原指令继续执行
Card 05 数据集与资源

数据集与资源

  • 模拟评估使用 LIBERO（SPATIAL/GOAL/OBJECT/10/90）与 LIBERO Plus（难度 4 和 5）
  • 真实世界使用物理机器人平台，评估 Pick and Open、Place、Pour Water 三个操作任务
  • Learned Verifier 收集 120 个 episode 数据，按 60% 训练 / 20% 验证 / 20% 测试切分
  • 训练配置：30 epochs、batch size 32、学习率 1e-3、权重衰减 1e-4，训练设备为 CPU
Card 06 评估与结果

评估与结果

  • 模拟环境主要指标为 episode 成功率，另有精度、召回、F1、AUROC、AUPRC 等检测指标
  • 标准 LIBERO：No Assistance 为 70.9%，Rule + Prompt 提升至 82.6%，Learned Binary + Prompt 达到 80.2%
  • LIBERO Plus 难度 4：No Assistance 为 73.7%，Rule + Prompt 为 79.7%，Learned Binary + Prompt 为 79.0%
  • LIBERO Plus 难度 5：No Assistance 为 66.7%，Rule + Prompt 为 73.6%，Learned Binary + Prompt 为 72.6%
  • Learned Verifier 检测性能：准确率 93.1%、精度 61.1%、召回 94.9%、Positive F1 74.4%、AUROC 0.902、AUPRC 0.7123
  • 在线门控触发精度为 79.2%，Rule + Prompt 恢复成功率为 77.0%，Learned Binary + Prompt 为 75.0%
  • 消融实验表明，Temporal + Fusion（时间序列 + 多模态融合） 配置效果最佳（Positive F1 74.35%），仅用单帧、仅视觉或仅状态-动作均有明显下降
  • 真实世界实验：冻结 pi05_libero 基线平均成功率为 82.5%，VLA-Corrector 提升至 88.3%，绝对提升 5.8 个百分点
