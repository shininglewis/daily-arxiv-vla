Card 02 论文概述

论文概述

  • 论文提出 World-Action Model（WAM），面向轮式装载机连续堆料挖掘的闭环决策框架。
  • 核心目标是把世界模型从“预测器”扩展为执行时决策模块：在执行每个铲掘动作前预测多个候选的后果，并据此选择动作。
  • 要解决的问题是：连续铲掘会不断改变地形，后续动作受前序动作影响，因此需要在不可逆地形改变前评估候选动作的装载量与地形变化。
Card 03 核心贡献

核心贡献

  • 提出 Proposal–Selection WAM 闭环决策过程：扩散生成多模态铲掘候选，几何可行性过滤，冻结世界模型批量评估，执行预测装载量最大的候选，并从新观测地形重规划。
  • 提出 physics-structured action-conditioned predictor：使用地形高度、表面法线通道、轨迹导出的扫掠掩膜与挖掘深度图，联合预测 signed terrain change 与 loaded volume。
  • 实现 real-world closed-loop deployment：将完整 perception–proposal–prediction–selection–execution 循环部署到全尺寸轮式装载机，ROS2/TensorRT 在 Jetson AGX Orin 上以 72.4 ms 处理 5 个候选。
  • 在 MinSlope 32 个 geometry-disjoint 测试 episode 上，加入世界模型排序后平均 scoop 数从 651.8 降至 540.6（降低 17.1%），保持 32/32 完成，并改善全部 32 个配对 episode。
  • 系统级对比中，WAM 完成 32/32 episode，而独立训练的 SAC 策略完成 29/32；同时在额外仿真数据与真实装载机数据上验证预测接口的可学习性。
Card 04 方法描述

方法描述

  • 动作表示为 7 维归一化向量：approach heading、lateral offset、approach distance、cutting length、maximum cutting depth、speed scale、bucket-curl angle，并映射到物理范围。
  • 世界模型基于 DigNet++ Large，10.48 M 参数双头网络；输入为 10 m×10 m ROI、50×50 网格的 6 通道数据；输出 signed terrain change 与 loaded volume。
  • 训练损失由加权 terrain L1 损失与 loaded-volume SL1 损失组成，changed pixels 权重为其他有效像素的 5 倍，总损失为 L = L_H + λ_V L_V，λ_V=1。
  • 扩散动作提案使用条件 DDPM，余弦 schedule，T=50 步；两阶段训练包括 coverage pretraining 与 productive fine-tuning，并按装载体积分层采样。
  • 每轮采样生成 16 个 proposal，最多 8 轮，接受 5 个合法且 distinct 的候选，动作空间距离阈值 δ_a=0.02。
  • 几何可行性过滤定义 A_legal(s_t)：动作数值有限且在 [-1,1]，关键点位于工作空间，approach corridor 高度不超过 0.25 m，容量限制 swept volume 至少 0.05 m³，entry-point 位移通常不超过 9 m。
  • Geometric-5 构造五个确定性候选：锚点、短/浅切割、长/深切割、左/右工作面偏移；WAM 对五个 admitted candidates 单批次评估，并执行预测装载量最大的动作。
  • 执行后观察新地形并重复决策循环，直到剩余堆料体积不超过初始体积的 10%。
Card 05 数据集与资源

数据集与资源

  • 模拟数据集包括 MinSlope、Chrono、Isaac Sim、Newton MPM；其中 MinSlope 用于主实验、预测器消融和连续 depletion 评估。
  • 数据规模：MinSlope 72,241 train / 25,014 test；Chrono 506/127；Isaac Sim 1,672/188；Newton MPM 662/142；另有 MinSlope validation set 25,349 samples。
  • 真实数据集来自 XCMG XC958EV electric wheel loader，额定载荷 5.5 t，用于港口铁矿石粉堆转运；样本数 1,015 train / 130 test。
  • 真实平台传感器包括 RTK、3 个 LiDAR、3 个鱼眼相机、boom/bucket 角度传感器、前向针孔相机。
  • 世界模型 DigNet++ Large 参数量为 10.48 M；SAC baseline 的 actor 与 critic 各使用两层 256 单元隐藏层。
  • 世界模型使用 AdamW，batch size 32，初始学习率 10^-3，最多 100 epochs；SAC 训练 300,000 环境交互，batch size 256，discount 0.995，replay buffer 250,000，warm-up 20,000 步。
  • 部署硬件为 NVIDIA Jetson AGX Orin 64 GB；架构效率 profiling 使用 NVIDIA GeForce RTX 3070 Laptop GPU，FP32，batch size 5。
Card 06 评估与结果

评估与结果

  • 评估环境为 MinSlope 32 个 geometry-disjoint test episodes，任务目标为剩余体积降至初始值的 10% 以下，单 episode 上限 1600 scoops，失败按右删失处理。
  • 主要指标包括 success、N_10（达到 10% 剩余体积所需 scoop 数）、terminal residual 百分比、mean loaded volume；预测指标包括 terrain MAE、changed-region MAE、changed-region IoU、loaded-volume MAE。
  • Diffusion-direct 达到 32/32，mean N_10 为 651.8，mean loaded volume 为 4.03 m³；Diffusion-5+WM（WAM） 达到 32/32，mean N_10 降至 540.6（降低 17.1%），mean loaded volume 提升至 4.78 m³，全部 32 个配对 episode 均有改善。
  • 几何候选对比中，Geometric-heuristic 完成 15/32，mean N_10 740.1，terminal residual 22.61%，mean load 2.36 m³；Geometric-5+WM 完成 22/32，mean N_10 549.2，terminal residual 16.80%，mean load 3.66 m³。
  • 系统级对比中，WAM 完成 32/32，SAC 完成 29/32；SAC 的 mean N_10 为 596.2，terminal residual 11.00%，mean load 4.19 m³。
  • 空间支持消融显示，ROI-10 相比 ROI-5 将 changed-region MAE 降低约 43%、loaded-volume MAE 降低约 34%，IoU 从 0.87 提升至 0.93；Global-60 无额外精度收益且推理延迟为 23.73 ms。
  • 输入消融显示，加入 action-derived sweep 与 dig-depth maps 后，terrain、changed-region、loaded-volume MAE 分别降低 43.20%、41.60%、51.31%；再加入 surface normals 带来小幅额外改善。
  • 架构比较中，DigNet++ Large 取得最高 IoU 0.928，terrain MAE 4.237 mm，参数 10.48 M，batch-5 latency 4.280 ms；Terrain-JEPA terrain MAE 略低但参数更多、推理更慢且 IoU 略低。
  • 域特定评估结果：MinSlope IoU 0.928、terrain MAE 0.004 m、volume MAE 0.312 m³；Chrono 0.695/0.048 m/0.218 m³；Isaac Sim 0.692/0.004 m/0.066 m³；Newton MPM 0.641/0.001 m/0.003 m³；Real loader 0.640/0.054 m/0.148 m³。
  • 部署结果显示，ROS2/TensorRT 混合精度 C++ 管线在 Jetson AGX Orin 64 GB 上处理 5 个候选：预处理 60.6 ms、推理 4.1 ms、后处理 7.7 ms，总延迟 72.4 ms。
  • 局限：定量增益主要建立在 MinSlope 的 height-field 动态上；真实装载机试验证明闭环可行性，但尚不足以支持统计显著的效率增益；预测器按域单独训练，不声称零样本迁移；选择器只排序即时预测装载量，没有显式地形变化 look-ahead。
