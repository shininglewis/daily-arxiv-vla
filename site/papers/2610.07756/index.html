Card 02 论文概述

论文概述

  • 论文提出 StairVLA，一个阶段感知（stage-aware）的层次化动作生成框架，用于视觉-语言-动作（VLA）模型。
  • 核心观察：扩散/流匹配动作头的去噪过程并非均匀处理条件信息——早期阶段联合语言指令和视觉观测建立粗粒度动作轨迹，后期阶段更依赖当前视觉观测进行动作对齐。
  • 目标：利用去噪过程本身天然存在的阶段分工，低频率执行昂贵的任务条件生成、高频率执行观测条件的局部修正，从而降低推理成本并保持闭环反馈。
Card 03 核心贡献

核心贡献

  • 揭示了生成式 VLA 动作形成中的阶段依赖性：任务相关动作结构逐步涌现，多模态条件的作用随去噪阶段演化。
  • 提出 StairVLA 框架，直接以部分去噪的动作作为粗粒度长程生成与局部观测条件修正之间的自然接口，而非依赖外部设计或学习到的动作抽象。
  • 设计多速率推理与轨迹复用机制：高层返回的长程部分去噪轨迹可跨多个局部动作块复用，摊销高层 VLM 计算。
  • 在两种 VLA 骨干（GR00T 风格与 π 风格）、仿真基准（LIBERO、LIBERO-Plus）和真实机器人任务上验证，在降低推理代价的同时保持强任务性能。
Card 04 方法描述

方法描述

  • 高层意图轨迹生成：保留原生成式 VLA 架构与流匹配训练目标，将动作时域扩展至 H=32；推理时在去噪进度 γ=α<1 处提前终止，输出长程部分去噪轨迹并缓存。
  • 观测条件低层精炼：轻量 refiner 采用 GR00T 风格 DiT，交织堆叠交叉注意力与自注意力；输入分为动作侧 token（机器人状态、可学习未来 token、查询动作块）与条件侧 token（SigLIP-B/16 视觉 token、经自适应平均池化压缩并缓存的 VLM 隐状态、时序动作上下文）。
  • 重构精炼路径训练：由于预测误差使部分去噪动作偏离理想生成路径，用 ε_ref = (a^α − α·a^gt)/(1−α) 反投影虚拟起点，重建通向真值的精炼流并构造训练输入与目标速度。
  • 多速率推理与复用：高层缓存轨迹跨 M 个低层精炼循环复用，每个循环取长度 h=5 的局部片段精炼；平均每块推理代价为 T̄(M) = T_ref + T_high/M，M 控制效率与信息新鲜度的权衡。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（Spatial、Object、Goal、Long 四个套件，联合训练单一模型，每任务 50 次 rollout）、LIBERO-Plus（7 类扰动，零样本迁移与监督微调两种协议）、真实世界 Fruit25（24 个语言条件抓取放置任务 + 1 个长程多物体分拣任务）和 PushBlock（连续推块任务）。
  • 模型规模：高层策略默认使用 Qwen3-VL-4B-Instruct 视觉语言骨干 + GR00T 风格流匹配动作头；低层 refiner 使用可训练的 SigLIP-B/16 视觉编码器；真实实验使用 Qwen3-VL-2B-Instruct。
  • 训练资源：8 张 NVIDIA RTX A6000 GPU，bf16 混合精度；AdamW，全局批大小 128，初始学习率 5×10⁻⁵，余弦衰减，1k warmup，权重衰减 0.01；两阶段训练各 30k 步（高层训练后冻结，再训练 refiner）。
  • 推理测量：延迟测量在单张 NVIDIA A100 GPU 上进行；真实世界对比实验在 NVIDIA RTX A4000 上进行。
Card 06 评估与结果

评估与结果

  • 评估环境与基准：LIBERO / LIBERO-Plus 仿真基准 + 真实 AgileX PiperX 机器人平台；对比 OpenVLA、π₀、GR00T、π₀.₅、HiMoE-VLA、StreamVLA、CF-VLA、Coarse-to-Control、Libra-VLA 以及 StarVLA 基线。
  • 主要指标：四个套件成功率与平均成功率（%）、每个动作块的平均推理延迟（ms/chunk）；LIBERO-Plus 按扰动类别报告成功率。
  • 关键结果：

- LIBERO 上 GR00T-base 实例化将平均成功率从 96.5% 提升至 97.8%，同时摊销延迟从 115.0 ms 降至 44.2 ms 每动作块。

- π-base 实例化平均成功率从 97.8% 提升至 98.3%，延迟从 183.3 ms 降至 44.5 ms。

- LIBERO-Plus 零样本平均 70.4%（对相机等图像扰动更敏感），监督微调后平均回升至 83.7%，在多个类别取得有竞争力的结果。

- 消融：仅扩展高层时域（Top-only）平均下降 −4.1；加入 refiner 后 +0.7；再加入时序动作上下文后达 +1.3（97.8%）。

- 分析显示后期精炼阶段对视觉观测依赖更强，refiner 在累积误差下仍保持低且稳定的误差；指令 token 全部加入只能提升高噪声下的恢复能力，但不提升性能上限；推理迁移点 α=0.97 附近性能最佳，且跨基准与骨干无需重新调参。
