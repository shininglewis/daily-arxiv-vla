MM-Future: Multi-Mode Joint World-Action Modeling for Autonomous Driving

2026-09-17 · 原文 · 翻译 · 2609.20377

论文提出 MM-Future，一种面向自动驾驶的多模式联合世界–动作模型（World–Action Model, WAM），将多个"场景–动作"配对假设进行双向协同演化，以同时刻画驾驶中的决策耦合与多模式不确定性。 现有世界–动作模型存在两类局限：级联式（Cascaded）WAM 具备多模式覆盖但场景与动作之间是单向条件，无法互相修正；联合式（Joint）WAM 具备双向交互但通常只生成单一场景–动作推演结果。 论文目标是同时实现多模式覆盖与场景–动作双向耦合，解决单结果监督下多样未来学习、多模式推演计算开销大、以及从多个配对假设中选出最优动作三大挑战。

Card 03 核心贡献

核心贡献

  • 提出 MM-Future，一种多模式联合世界–动作模型，通过混合条件流（mixture conditional flow）从仅有单一真实结果的训练片段中学习多个成对的"场景–动作"假设。
  • 提出面向规划的 MM-Tokens（Planning-Oriented MM-Tokens），一种紧凑的多视角场景表示，用少量规划导向 token 替代稠密视频/BEV 潜变量，使多模式未来推演的计算代价可控。
  • 设计未来条件化的提议打分器（Future-Conditioned Proposal Scorer），联合历史上下文与每个候选自带的预测未来对轨迹进行排序，实现"面向未来"的动作选择。
  • 实验证明多模式生成、模态感知的场景–动作交互、以及未来条件化打分三者均带来一致提升，并验证多模式联合建模优于单模式与"仅动作"变体。
Card 04 方法描述

方法描述

  • 整体框架：输入历史多视角图像序列、自车状态与导航指令，输出 M 个成对的场景–动作模式 $\mathcal{H}_m=(\hat{\boldsymbol{\tau}}_m, \hat{\mathbf{X}}^+_m)$，三者由在线 MM-Encoder、模态感知联合生成器与打分器组成。
  • MM-Tokens：用预训练 ViT 骨干（LoRA 微调）提取每帧每相机的 register token，按时间分块后用可学习 chunk-wise query 经自注意力聚合，得到 $\mathbf{X}_j\in\mathbb{R}^{N_x\times d}$；训练时用 EMA 目标编码器产生未来目标 $\bar{\mathbf{X}}^+$ 并 stop-gradient，不做 RGB 或 BEV 重建，由世界–动作建模目标反向塑造表示。
  • 结构化配对源：对归一化轨迹做 K-means 聚类，用各簇均值/方差参数化高斯混合噪声（GMN）采样动作先验 $\boldsymbol{\epsilon}^a_m$，并与独立未来 token 噪声 $\boldsymbol{\epsilon}^x_m\sim\mathcal{N}(\mathbf{0},\mathbf{I})$ 配对，形成每个模式的初始场景–动作源。
  • 联合条件流：采用 $x$-prediction 参数化与线性插值路径 $\mathbf{z}^\kappa=(1-\rho^\kappa)\boldsymbol{\epsilon}^\kappa+\rho^\kappa\mathbf{y}^\kappa$，动作与未来流使用独立流时间；生成器 $G_{\theta_g}$ 为模态感知 Transformer，共享注意力实现双向交互，模态专属 AdaLN 调制与前馈分支保留各自统计特性；非对称块掩码把历史作为干净前缀，历史 query 只看历史，动作与未来 query 互相可见。
  • Best-of-Many 监督：以 L1 解码误差选出最优模式 $m_{\mathrm{win}}$，仅对该模式的动作与场景两个流施加速度回归损失，避免所有模式被拉向同一条件均值。
  • 未来条件化打分：$\mathcal{D}_h$ 以历史 MM-Tokens 交叉注意力编码提议，$\mathcal{D}_f$ 只对每个候选自身的未来 $\hat{\mathbf{X}}^+_m$ 做块对角注意力，输出 PDMS 各分量的 logits，用 BCEWithLogits 训练；提议与未来 token 均 stop-gradient。
  • 训练与推理：总目标 $\mathcal{L}=\mathcal{L}_{\mathrm{BoM}}+\lambda_s\mathcal{L}_{\mathrm{score}}$，在线编码器、生成器与打分器联合优化，目标编码器仅 EMA 更新；推理时编码历史、积分 M 条配对流、逐条打分并返回最高分轨迹。

Card 06 评估与结果

评估与结果

  • NAVSIM navtest（NAVSIM-v1，trainval）：PDMS 94.0，NC 98.7、DAC 99.0、TTC 95.8、EP 91.6；train 设定下 PDMS 93.4。
  • NAVSIM-v2 navtest：EPDMS 91.5，NC 99.0、DAC 98.8、DDC 98.8、TL 99.4、EP 92.2、TTC 98.6、LK 95.4、HC 96.3、EC 89.2，优于 DiffusionDriveV2、MeanFuser、UniTeD、DriveWorld-VLA、IRR-Drive-4B、DriveFine、Latent-WAM、GraphWorld、DriveFuture 等 E2E/VLA/WAM 方法。
  • HUGSIM 零样本闭环：HD-Score 32.3；Route Completion 平均 44.5（E 64.8、M 51.5、H 39.5、X 22.8），显著优于 VAD、Latent-TF、UniAD、Latent-WAM。
  • 消融（NAVSIM-v1 navtest）：

- 多模式生成：仅动作单模式 PDMS 84.1 → 仅动作 32 模式 92.3 → 配对 32 模式 92.9，说明成对建模与多模式覆盖均有增益。

- 场景–动作交互：Mixture-of-DiT 双向 92.9，优于单向或单 DiT 变体。

- 打分器：仅历史 92.9 → 历史 + 配对未来 93.3，验证未来条件化打分的必要性；Efficiency 方面 32 模式推演延迟约 132 ms。

  • 整体结论：多模式联合世界–动作建模在轨迹规划精度、闭环迁移能力与模式多样性上均优于单模式或仅动作建模的基线。
