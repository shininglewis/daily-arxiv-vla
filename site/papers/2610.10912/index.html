Card 03 核心贡献

核心贡献

  • 证明 捷径易感性强烈依赖架构：在相同数据上训练的 VLA 变体表现差异巨大，VLM 骨干大小和通用基准性能无法预测鲁棒性。
  • 提出 action margin 表示级指标：无需策略 rollout 即可量化模型对捷径的依赖程度，与捷径率（SC）高度相关（Kendall's τ_b = 0.83）。
  • 引入 注意力 knockout 机制分析：发现视觉捷径在早期层进入动作表示，后期层通过语言信息进行修正，而修正能力因模型而异。
  • 提出 task scrubbing：一种领域对抗训练方法，通过梯度反转使视觉路径预测任务身份变难，从而增强语言对动作预测的相对影响。
  • 在 LIBERO Spatial、RoboTwin 2.0 和 真实 ALOHA 平台上验证，task scrubbing 显著降低捷径率并提升 OOD 成功率。
Card 04 方法描述

方法描述

  • 问题定义：将视觉输入分解为任务相关视觉信息 \(U\) 和任务无关视觉线索 \(Z\)；训练时 \(T\) 与 \(Z\) 统计相关，OOD 评估使用交叉组合 \((T_A, Z_B)\) 和 \((T_B, Z_A)\)。
  • Action margin：计算动作 token 隐藏状态与任务一致中心 \(c_{\text{task}}\)、线索一致中心 \(c_{\text{cue}}\) 的相对距离，正值表示倾向捷径，负值表示倾向指令。
  • Language share：通过反事实位移投影到任务轴，衡量语言与视觉线索对动作表示的相对影响，值越高表示语言控制越强。
  • Task scrubbing：在视觉投影后接入对抗任务分类器（mean-pool → LayerNorm → 两层 MLP + GELU），通过梯度反转层使视觉路径最大化分类损失，总损失为 \( \mathcal{L} = \mathcal{L}_{\text{action}} + w \mathcal{L}_{\text{task}} \)。
  • 适配冻结模型：对于冻结 VLM 和视觉编码器的模型（如 SmolVLA），在视觉投影上添加可训练残差适配器 \( \tilde{p}(x) = p(x) + f_2(\text{GELU}(f_1(x))) \)，计算开销可忽略。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO Spatial 高视角差异设置、RoboTwin 2.0 Place-Block 任务、真实 ALOHA 机器人平台。
  • 评估指标：分布内成功率（ID Succ.）、分布外成功率（OOD Succ.）、捷径率（SC，即 OOD 中执行线索一致任务而非指令任务的百分比）。
  • 关键结果：

- Action margin 与 SC 在 21 个模型-视角差异组合中强相关（Kendall's τ_b = 0.83，p = 1.35×10⁻⁷）。

- LIBERO 高差异设置：π0 经 task scrubbing 后 OOD 成功率从 0% 升至 48%，SC 从 99% 降至 0%，ID 成功率无显著下降。

- SmolVLA 系列在 task scrubbing 后消除观察到的捷径行为，ID 性能同时提升。

- π0.5 对 task scrubbing 响应不稳定：3 个种子中仅 2 个成功，平均 ID 从 66% 降至 45%。

- RoboTwin 实验复现类似趋势：SC 降低，OOD 成功率提升，部分模型 ID 性能有所下降。

- 真实机器人实验：在杯子颜色与背景联合线索条件下，task scrubbing 消除所有捷径 episodes，两个模型 OOD 成功率均超过 90%。

- 消融实验：直接 注意力正则化 在 SmolVLA 变体上有效但弱于 task scrubbing，在 π 系列上失败（π0 保留 68% SC，π0.5 保留 79% SC），说明高语言注意力比例并不保证语言控制动作。
