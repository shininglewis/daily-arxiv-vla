Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出 SA-VLA：一种空间感知的 RL 适应框架，将隐式空间表示与 2D 视觉 token 融合，并结合步骤级密集奖励，用于鲁棒的流匹配 VLA 策略微调。
  • 提出 SCAN（Spatially-Conditioned Annealed Noise）：一种空间条件退火探索策略，将几何理解注入噪声驱动的策略探索中，改善信用分配并保持 RL 微调期间的空间一致性。
  • 系统性验证了空间表示对齐、步骤级密集奖励与空间条件探索三者协同作用，能稳定 RL 微调并改善空间分布偏移下的泛化性能。
  • 通过三个研究问题（RQ1-RQ3）分别隔离验证空间 token 融合、奖励密度和 SCAN 探索各自对鲁棒性的贡献。
Card 04 方法描述

方法描述

  • 空间 Token 融合：使用预训练的多视角空间编码器提取隐式空间 token，通过投影、位置/视角编码增强后，利用单向交叉注意力（unidirectional cross-attention）将视觉 token 与空间 token 融合，并通过可学习的通道门控（channel-wise gating）和残差 MLP 产生几何感知嵌入。
  • 步骤级密集奖励：将操作任务分解为 Reach（接近）、Place（放置）和 Leave（离开）三个阶段，基于末端执行器-物体距离和物体-目标距离的归一化时序变化计算相位特定奖励，通过在线相位推断（基于夹爪状态和物体相对位姿）实现无需标注的稠密监督。
  • SCAN 探索：噪声尺度由融合嵌入预测的学得项与退火最小噪声下限组成，σ(t) = σ_min(t) + softplus(σ_learned(x_t) − σ_min(t))，保证严格正噪声并实现从粗到细的探索-利用平衡，与 PPO 兼容。
  • 策略优化使用 actor-critic PPO 与 GAE，在流匹配策略上注入噪声进行探索。
Card 05 数据集与资源

数据集与资源

  • 训练数据集：LIBERO（语言条件操作任务，含视觉和本体感觉观测）
  • 评估数据集：LIBERO-PLUS 的空间扰动子集（相机视角和初始状态扰动）
  • 训练资源：4 张 H800 GPU，训练约 38.5 小时
  • 模型配置：预训练流匹配 VLA 策略（视觉语言骨干冻结），隐式空间 token 由预训练多视角空间编码器提取
  • RL 超参数：策略学习率 5×10⁻⁶，价值函数学习率 1×10⁻⁴，clip 0.2，γ=0.99，GAE λ=0.95，batch size 1024，64 并行环境，8 rollout epochs，最大回合长度 240 步，训练 100 step
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-PLUS 空间扰动子集（80 个并行环境，5 个非重复采样 epoch，每设置 2 个随机种子）
  • 零样本空间泛化（RQ1）：空间 token 融合使总成功率从 81.00% 提升至 83.25%（+2.25%），其中视角扰动下提升 +3.83%，初始状态扰动下仅 +0.52%
  • 奖励密度影响（RQ2）：密集奖励在零样本和少样本评估中均带来更快收敛和更平滑的训练动力学，说明稠密监督稳定优化而非仅提升最终性能
  • SCAN 探索效果（RQ3）：密集奖励 + SCAN 相比仅有密集奖励获得更高最终成功率，SCAN 主动引导智能体访问采样不足的几何区域，改善状态访问和信用分配
  • 消融研究：完整 SA-VLA（SCAN + DR + Fusion）少样本成功率为 83.75%；移除 SCAN 降至 83.00%；移除密集奖励降至 77.50%；移除空间融合（无 RL 适应基线）为 81.00%，验证了三个组件的互补性和必要性。
