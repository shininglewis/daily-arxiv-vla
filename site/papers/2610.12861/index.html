Card 02 论文概述

论文概述

  • 研究视觉–语言–动作（VLA）策略在机器人演示数据长尾任务分布下的性能退化问题，聚焦共享策略中的头部任务动作偏置（head-task action bias）。
  • 核心发现：当尾部任务所需的任务特定视觉证据不足时，策略会退回到由数据丰富的头部任务强化出的动作模式，导致稀有任务性能下降。
  • 提出 Evidence-Guided Counterfactual Learning（ECL） 训练框架，在不增加训练数据、不需要区域级标注、部署时不增加计算的前提下，增强指令–视觉证据–动作之间的关联。
Card 03 核心贡献

核心贡献

  • 重新审视"尾部任务失败源于数据稀缺"的传统观点，通过玩具实验证明：当任务特定视觉接地不足时，尾部任务预测会退回到由头部任务塑造的动作偏置。
  • 提出 ECL，通过反事实监督训练抑制尾部任务对动作先验的依赖，构建其任务特定的视觉证据，且不需要额外标注或训练数据。
  • 在 LIBERO-Core-LT 上的两种 VLA 策略（MiniVLA、π₀.₅）和两个真实机器人平台（AGILEX PIPER、xArm6）上验证，取得最优性能。
  • 引入频率感知机制，按任务演示数量自适应分配反事实监督强度，头部任务弱正则、尾部任务强监督。
Card 04 方法描述

方法描述

  • 诊断实验：构造双任务环境，定义 Head-Prior Score（HPS = P_H(x)/(P_H(x)+P_T(x))） 与 Head-Action Rate，量化任务不平衡下头部任务偏置的加剧现象。
  • 关系感知反事实分支：结合指令相关注意力 α_j^L 与动作相关注意力 α_j^A，以乘积 r_j = α_j^L·α_j^A 排序，选取 top-K 视觉 token（默认 10%）进行掩码，得到反事实观测 I⁻ 与预测 z⁻ = f_θ(I⁻, L)。
  • 反事实对比输出：z^effect = z⁺ − λ·z⁻（λ = 0.3），通过对比分支引导策略关注任务特定视觉证据。
  • 损失设计：L_BC = ℓ(z⁺, a*)、L_mask = ℓ(z⁻, a*)、L_CF = ℓ(z^effect, a*)，对应基础监督、掩码分支监督和反事实动作效应监督。
  • 频率感知监督：归一化稀有度 r_i = (N_max − N_i)/(N_max − N_min)，总目标为 L_i = L_BC + μ·L_mask + r_i·L_CF，使尾部任务获得更强的反事实约束。
  • 反事实分支仅在训练时使用，部署时策略直接从完整观测生成动作。

Card 06 评估与结果

评估与结果

  • 仿真基准：LIBERO-Core 10 任务闭环评测，7-DoF Franka Panda 机械臂，指标为每任务成功率与宏平均成功率。
  • MiniVLA：宏平均成功率从 40.8% → 53.0%（+12.2 个百分点，相对提升约 29.9%）；π₀.₅：40.3% → 47.2%（+6.9 个百分点，相对提升约 17.1%）。
  • 与 APA 对比：MiniVLA 44.8% → 53.0%，π₀.₅ 41.7% → 47.2%；尾部任务（Task 7–9）MiniVLA 从 11.3% 提升至 23.5%，π₀.₅ 从 19.0% 提升至 21.6%。
  • 真实世界：AGILEX PIPER 上 APA→ECL 为 17.3%→25.7%（MiniVLA）与 21.0%→27.3%（π₀.₅）；xArm6 上为 19.3%→26.0% 与 24.0%→30.7%；尾部任务平均提升分别为 9.0% 和 4.3%。
  • 上下文级长尾（LTC）：仿真平均成功率 34.7% → 37.6%，真实世界 28.5% → 34.3%。
  • 消融实验：训练系数 λ = 0.3 最优；掩码比例 0.10 最优；Object–Action Relation 联合选择策略最佳（53.0%）；μ = 0 时性能接近标准长尾基线，说明掩码分支监督对构建有效反事实参考是必要的。
