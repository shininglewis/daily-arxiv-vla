Card 03 核心贡献

核心贡献

  • 提出用两个互补条件替代语言：视觉定位提示（目标物体边界框）与可学习的原子操作 token（pick、place、handover、click 等），实现原子操作分解与统一共享参数的策略网络。
  • 设计紧凑的 0.5B 潜空间 WAM 骨干：冻结预训练视觉编码器、无语言编码器，包含推理专家（推理专家输出掩码、末端位姿、任务摘要三类可监督信号）与世界动作专家（双层未来对齐：视觉前瞻 + 语义前瞻）。
  • 提出模型无关的智能体兼容层，包含 detect / execute / query 三个原语，使本地 VLM 或在线 Agent API 都能直接驱动策略，实现智能体可插拔替换。
  • 将长程记忆与闭环错误恢复委托给智能体侧（策略保持马尔可夫性），失败可归因于"意图错误"还是"执行错误"，并通过重新 detect 更新提示词重试。
  • 在仿真与真机基准上系统验证：视觉条件优于语言条件，推理专家与双层前瞻均有显著增益，并保持最低推理延迟。
Card 04 方法描述

方法描述

  • 任务条件化：原子操作嵌入 $e_s$、参与者属性 $e_u$（左臂/右臂/双臂）、风格属性 $e_w$（放置方式）与边界框嵌入 $\phi(g)$ 融合为任务条件 token，通过 AdaLN 条件调制注入策略（而非 cross-attention）。
  • 推理专家：用可学习推理 query token 探测观测与任务条件，经推理头解码为掩码 $\hat{m}_t$、双臂终止末端位姿 $\hat{T}_t$、结构化任务摘要 $\hat{c}_t$，以 BCE + CE + L2 损失监督，作为显式可监督意图信号与故障诊断依据。
  • 前瞻要点（foresight gist）提取：离线预训练 潜空间逆动力学模块 G^IDM 与前向动力学模块 G^FDM，仅用片段两端帧的潜表示压缩场景演化，训练时作为目标、推理时不使用。
  • 世界动作专家：与推理专家共享 Transformer，用 flow matching 单一去噪器联合去噪三类输出——动作块、视觉前瞻 $\hat{f}$（对齐 foresight gist）、语义前瞻 $\hat{q}$（对齐未来观测产生的推理 token，采用 stop-gradient）。
  • 注意力掩码与效率：分块注意力掩码允许动作/前瞻分支条件化于推理输出而不污染它；推理前向与首个去噪步共用一次前向，其余步复用 KV cache。
  • 训练目标：$\mathcal{L}=\mathcal{L}_{act}+\lambda_{reas}\mathcal{L}_{reas}+\lambda_{vis}\mathcal{L}_{vis}+\lambda_{sem}\mathcal{L}_{sem}$。
  • 视觉提示增强：训练时随机抖动边界框中心、高度与宽度，使策略容忍智能体给出的松散/略偏移框。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 2.0（选取 10 个双臂长程任务，每任务重新生成 50 条干净 + 500 条随机化示教）、RMBench（每任务 50 条示教）。
  • 真机平台：Astribot S1 双臂机器人。
  • 模型规模：0.5B 参数，其中 0.2B Transformer（推理专家与世界动作专家共享）+ 冻结的 0.3B DINOv3 视觉编码器；无语言编码器。
  • 智能体侧模型：本地部署 Qwen3.8-27B 与在线 API Kimi-K3。
  • 数据生成细节：在可能遮挡被操作物体的连续操作之间插入归位动作，保证子任务结果可观测。
Card 06 评估与结果

评估与结果

  • 评估基准：RoboTwin 2.0（干净 C / 随机化 R 两种设置，每任务 50 次试验）、RMBench（记忆依赖任务）、Astribot S1 真机长程任务。
  • 对比基线：语言条件 VLA（π0.5、X-VLA）、世界动作模型（Fast-WAM）、潜世界动作模型（Motus、LiLa-WAM），以及记忆增强策略 Mem-0、Goal2Skill、Cortex。
  • 标准操作平均成功率最高：85.7%（干净 87.2% + 随机 84.2% 的平均），其中随机化设置 84.2% 为最优，干净设置 87.2% 仅比最强基线低 0.6%。
  • 长程与真机任务最优：RMBench 记忆依赖任务成功率提升 5.9%，真机长程任务提升 36.7%。
  • 推理延迟最低，仅 14.1 ms。
  • 消融结论：文本条件替代视觉提示掉 13.0%；视觉提示额外加文本反而掉 2.6%（语言冗余）；cross-attention 替代 AdaLN 掉 13.8%（且过度依赖本体状态，易走捷径学习）；去掉推理专家掉 7.8%；去掉前瞻对齐掉 8.6%；用原始 patch 特征替代紧凑 gist 目标掉 10.8%（低于无前瞻变体）。
  • 注意力可视化：推理分支聚焦被操作物体与目标位置，前瞻分支转向将发生运动的区域。
