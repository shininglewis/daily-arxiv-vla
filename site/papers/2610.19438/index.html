Card 03 核心贡献

核心贡献

  • 提出并系统测量paraphrase consensus在VLA策略上的效果，通过逐时间步日志揭示其失败机制：改写成员不可交换，聚合只能降方差不能消偏差。
  • 设计指令依赖探针，用同场景下其他任务的指令测试策略，在LIBERO四个套件和三种策略上发现改写代价与指令依赖度强相关。
  • 证明训练时指令增强（LoRA在改写指令上后训练）可将单改写惩罚从 -38.0 点变为 +2.0 点，而匹配对照仍为 -32.0 点。
  • 引入三个控制实验：匹配训练控制、迁移到留出改写、接地检查（确保策略仍读取指令），弥补此前补救措施未报告的验证。
  • 发布多种类型的改写集（llm / easy / hard / adversarial / held-out），并给出配对统计与可复现细节。
Card 04 方法描述

方法描述

  • Paraphrase Consensus (LCC)：对同一任务用 K 个语义等价的改写指令查询冻结策略，取动作块的中位数（medoid）执行；用检查点自身的动作统计归一化距离，支持连续动作空间。
  • 改写集生成：LLM生成候选，经独立LLM判定等价且与训练指令的句嵌入余弦超阈值，再用贪心最大-最小选择距离，构建每任务的 llm / easy / hard / adversarial / held-out 集合。
  • 指令依赖探针：将当前任务的指令替换为同一套件中另一任务的训练指令，场景、初始状态和成功谓词保持不变；成功即表示策略未依赖指令。
  • 训练时增强：在原始演示上保留真实动作，将每个样本的指令替换为同任务改写，用 LoRA（rank 32, lr 1e-4, 2000步）后训练 OpenVLA，并设置仅用原始指令训练的匹配控制。
  • 创新点在于指出改写轴与采样轴的本质区别：自一致性聚合的是同一条件分布的样本，而改写共识聚合的是 K 个不同条件分布，只有一个是策略拟合过的。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 模拟基准的四个套件：Spatial、Object、Goal、Long，以及 LIBERO-PRO 中带干扰物 mug 的分布偏移 Spatial 版本。
  • 策略模型包括 OpenVLA（7B Llama-2 骨干）、OpenVLA-OFT（7B，同骨干，加并行解码与连续动作头）和 π0.5（PaliGemma-based flow-matching 策略）。
  • 训练资源：LoRA 后训练约 1 小时；延迟测量在空闲 A100 GPU 上进行，K=4 时即使批处理仍为单次查询的 2.98× 成本。
  • 评估采用配对初始状态，每任务 50、25 或 10 个 episode，并报告 Wilson 95% 区间、bootstrap 95% CI 和 Holm 校正的 McNemar 检验。
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO 模拟套件，基准策略均复现其发表数值（OFT 在 ±2 点门限内，base OpenVLA 在 Wilson 区间内）。
  • 主要指标为任务成功率（%）及相对于规范控制器的配对差值 Δ，辅以任务聚类区间和按任务的依赖度分析。
  • 在 base OpenVLA / LIBERO-Spatial 上，单一改写使成功率变化 -38.0 点；含训练指令的共识损失 -16.8 点，无训练指令的改写中位数损失 -32.4 点，置信度选择损失 -28.0 点。
  • 对强策略 OpenVLA-OFT，Spatial 上共识为零效应；在 Goal 上（依赖度 100%）共识仍损失 -4.0 点，单改写损失 -10.4 点。
  • 指令依赖探针显示：base OpenVLA 在所有套件需 97–100% 的成功依赖指令；OpenVLA-OFT 仅在 Goal 需 100%，在 Object 仅 2%；π0.5 在 Goal 需 100%、Object 需 67%。
  • 训练时增强将单改写效应从 -38.0 点降至 +2.0 点，匹配控制保持 -32.0 点；该结果在第二个种子和 OpenVLA-OFT 上复现，并迁移到留出改写，且错误指令探针显示策略的语言份额仍为 97%。
