Card 02 论文概述

论文概述

  • 提出 AdaDE（Adaptive Dynamic Expert Deactivation）框架，通过将稠密 FFN 块转化为 MoE 结构并自适应地停用冗余专家，压缩视觉-语言-动作（VLA）策略中 LLM 侧的参数量。
  • 解决的问题是：现代 VLA 策略参数量持续增长，难以部署在算力、内存和功耗受限的真实机器人平台上，而 LLM 主干占据了绝大部分参数，是压缩的理想目标。
  • 初步实验表明 ViT 与动作生成模块对压缩更敏感，而语言主干冗余度显著更高，因此选择 LLM 侧 FFN 作为压缩对象。
Card 03 核心贡献

核心贡献

  • 提出面向 VLA 的 Dense2MoE 转换方案，将 LLM 侧 FFN（含语言模型 FFN 与动作专家 FFN）的中间隐藏通道划分为连续的专家切片，在初始化时保持与原稠密网络函数等价，且不产生重复的稠密专家副本。
  • 提出 AdaDE 自适应专家停用框架，基于逐层 EMA 平滑的路由统计量决定专家保留掩码，实现按层自适应的稀疏化，而非全局固定稀疏比例。
  • 设计包含 warmup、动态停用、最终冻结的三阶段训练流程，并结合 Wanda 重要性评分保护关键专家，避免早期崩溃与性能骤降。
  • 在仿真（LIBERO、RobotWin2.0）和真实机器人平台上验证了方法的有效性，证明学到的稀疏专家结构可迁移到现实环境。
Card 04 方法描述

方法描述

  • 函数保持的 Dense2MoE 转换：将稠密 FFN 的中间隐藏维度切分为连续通道切片，每个切片作为一个专家；路由器采用均匀初始化，经重归一化与缩放后精确复现原稠密 FFN 输出，无需单独的恢复阶段。
  • EMA 专家重要性估计：为每个专家维护指数移动平均重要性分数 s = β·s_prev + (1-β)·u，抑制路由噪声，使停用决策依赖持续性而非瞬时波动。
  • AdaDE 掩码更新规则：EMA 分数低于阈值 τ_deact 的专家成为停用候选；约束每层至少保留 M_min 个专家、单次更新最多移除 K_update 个专家；已停用专家不可复活，保证单调稀疏化。
  • 专家保护：warmup 后基于 Wanda 准则锁定每层最重要的 25% 专家，排除在停用候选之外。
  • 辅助路由正则：惩罚层内最弱原始路由概率低于下限 τ_aux 的情况，防止路由过早塌缩；总损失为 L = L_task + λ_aux·L_aux。
  • 与标准稀疏 MoE 的区别：本方法采用宽度划分 + 掩码式 MoE 用于自适应压缩，而非以稀疏路由加速为目标的标准 token 级 top-k 调度 MoE。
  • 推理导出：冻结掩码后物理删除非活跃专家切片，仅保留 W_gate/W_up 的活跃行与 W_down 的活跃列，部署时无需运行时掩码。
Card 05 数据集与资源

数据集与资源

  • 数据集/基准：LIBERO（长时程语言条件家庭操作任务）、RobotWin2.0（全部 50 个 DemoClean 任务）、真实机器人平台
  • 基础模型：稠密 pi0.5（总参数 3.618B，其中 ViT 0.268B、LLM 2.043B、Flow 1.307B）；对比实验使用 OpenVLA（7.5B）
  • 压缩后参数：40% LLM 停用后总参数降至 2.841B；50% 停用后降至 2.619B
  • 训练资源：仿真实验使用 NVIDIA A100 GPU；真实机器人部署使用 NVIDIA RTX 4090 GPU
  • 训练细节：warmup T_warm=1000 步，掩码每 ΔT=100 步更新，T_freeze=15000 步冻结，总训练 30k 步
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 与 RobotWin2.0 仿真基准 + 真实机器人任务；对比稠密基线、无自适应停用的 Dense2MoE、固定停用策略，以及 LLM-Pruner、FLAP、量化、Wanda 等压缩方法
  • 评估指标：任务成功率（SR）、紧凑检查点参数量、TFLOPs、峰值显存（GB）、每任务执行时间
  • LIBERO：停用 40% LLM 参数时平均成功率 95.1%；停用 50% 时仍保持约 95%；50% 停用时 TFLOPs 从 4.692 降至 2.921
  • RobotWin2.0：40% 停用下全部 50 任务平均成功率 42.0%（稠密基线 46.7%），TFLOPs 从 4.38 降至 3.18；10 个代表性任务平均从 81.3% 降至 78.0%
  • 真实机器人：AdaDE 平均成功率 61.4%，表明稀疏专家结构可迁移到现实
  • 消融实验：50% 停用下，固定调度成功率仅 88%，AdaDE 为 95%；移除 Wanda 保护降至 90%；更新间隔 ΔT=50 过快降至 68%，ΔT=500 过慢降至 93%
  • 部署对比：AdaDE (20%) 在 OpenVLA 上达 84.3% Spatial 成功率，30% 停用下达 82.0%，无需额外 SFT 恢复；50% 停用时峰值显存从 7.12GB 降至 5.25GB（B=1）
  • 局限：当前主要针对 LLM 侧 FFN；未降低端到端推理延迟（B=1 时稠密基线 212ms vs 50% 停用 236ms），因稀疏路由引入额外开销且小专家投影不如稠密 GEMM 高效。
