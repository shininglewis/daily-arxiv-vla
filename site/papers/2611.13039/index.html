Card 02 论文概述

论文概述

  • 论文提出 Robo-MLT（Robotic Medical Laboratory Tasks），一个面向长时序医学检验实验室操作的分层双系统机器人操作框架，用于执行血气分析、采血管分拣等严格有序的样本处理流程。

Card 03 核心贡献

核心贡献

  • 提出 Robo-MLT 分层框架，将显式的低频工作流监控与高频生成式动作控制解耦，专门面向长时序医学实验室操作任务。
  • 设计轻量级多帧执行监控器（System 2），用完成头（completion head）与恢复头（recovery head）两个决策头判断当前技能"已完成"或"已不可完成"，并在后者触发时依据协议与当前场景重规划剩余流程。
  • 构建基于原子技能库的顶层规划接口：规划器冻结、不重训，因此实验室可重排或重复已知技能（如对任意数量的试管重复同一检测），无需采集数据或重新训练。
  • 在两个真实任务（血气分析、采血管分拣）上开展对比实验、消融实验、监控器切换时机的离线分析，以及"样本被取走"扰动测试，同时报告端到端任务成功率与干预后恢复成功率。
  • 验证了实用价值集中于工作流连续性：执行中样本被操作员取走后，系统能修订剩余计划并继续处理其他样本，而不会停滞。
Card 04 方法描述

方法描述

  • 顶层规划：以冻结的 Qwen3.7-Max API 作为规划器 $\Phi_{\mathrm{plan}}$，输入任务指令、仪器协议、原子技能库 $\mathcal{S}$ 与初始观测 $I_0$，输出有序技能序列 $\mathcal{P}$；血气分析含 7 个原子技能，试管分拣含 5 个。同一模型兼任重规划器 $\Phi_{\mathrm{replan}}$，全程零样本、不微调。
  • System 2（低频执行监控）：冻结的 SigLIP2-300M 图像/文本编码器提取多视角观测与技能指令特征；主干先用带学习位置编码的因果时序编码器沿时间混合特征，再通过交叉注意力（文本为 query、时序特征为 key/value）把历史"落地"到当前指令，得到技能接地向量 $v_t$。
  • 双决策头与去抖：两个无参数共享的两层 MLP 分别输出完成概率 $\hat{\gamma}_t$ 与恢复概率 $\hat{\beta}_t$；连续 $k_a$ 次超过 $\tau_{\mathrm{done}}$ 判为 advance，连续 $k_b$ 次超过 $\tau_{\mathrm{rec}}$ 判为 recover，否则 stay；两者同时触发时 recover 优先；另设每技能停滞超时 $T_{\max}=30$ s 作为兜底触发。
  • 协议内重规划：以已完成前缀 $\mathcal{C}_t$、尝试记录 $\mathcal{R}_t$ 与当前观测 $I_t$ 调用 $\Phi_{\mathrm{replan}}$ 生成 $\mathcal{P}'$，拼接为 $\mathcal{P}\leftarrow\mathcal{C}_t\oplus\mathcal{P}'$，指针天然指向首个修订步骤而无需重置。
  • System 1（高频生成执行器）：以 Qwen3-VL-2B 为骨干编码三路视角与技能指令，本体状态经 MLP 投影后拼接为条件序列；用流匹配（flow matching）学习条件动作分布，线性路径 $A_\tau=\tau A_{gt}+(1-\tau)\epsilon$，回归速度场 $u=A_{gt}-\epsilon$，推理时从 $\tau=0$ 积分到 $\tau=1$ 得到动作块（$N=30$）。从 StarVLA 权重初始化，骨干与动作头联合微调。
  • 异步推理运行时：两个系统各自作为非阻塞后台 worker（至多一个在途任务）；每 $K=15$ 步做一次历史窗口快照并派发 System 2，窗口容量 $M=6$；System 1 在队列剩余 $\le r=8$ 时预取下一块，块边界用前 $w=4$ 步与上一动作单调加权融合以消除跳变；技能切换后设 $\Delta_{\mathrm{cd}}=10$ 步冷却，控制频率 20 Hz。
Card 05 数据集与资源

数据集与资源

  • 数据规模：遥操作采集 1200 条血气分析示范与 1000 条试管分拣示范，每条任务包含两类语料——完整长时序工作流示范（在线标注各原子技能起止边界）与随机初始位姿下的单技能片段。
  • 恢复头监督：额外采集"人为干预"（执行中取走样本）与"自发遥操作失败"（如运输途中掉落试管）两类正样本，每条失败片段末 $K_{\mathrm{rec}}\in[20,40]$ 帧标为正，且不计入常规语料。
  • 硬件平台：Agilex 双臂 Static-Aloha 平台，配 3 台 Intel RealSense D435i（1 路固定全局视角 + 2 路腕部视角）。
  • 训练与部署：训练使用 NVIDIA A100，部署使用 RTX 4090；System 1 训练 80k 步（batch 8），System 2 训练 60k 步（batch 128），均用 AdamW、学习率 $1\times10^{-4}$、余弦退火，损失权重 $\lambda_c=\lambda_r=1$。
  • 模型规模：System 1 骨干为 Qwen3-VL-2B，System 2 编码器为 SigLIP2-300M（冻结），规划器为 Qwen3.7-Max API。
Card 06 评估与结果

评估与结果

  • 评估任务与条件：任务一 血气分析（7 个技能，约 5 mm 入口间隙，插入/拔出构成感知歧义）；任务二 采血管分拣（5 个技能，两类试管随机摆放，更强调规划与防漏拣）。每种任务设正常运行（50 组配置）与样本被取走（20 组配置）两种条件。
  • 评估指标：任务成功率 SR、样本完成率 SCR、完成时间，以及干预后的恢复成功率；监控器另做离线评估，将每个技能边界判为准时/提前/滞后/漏检，仅当全部边界准时才算整个工作流正确。
  • 对比基线：ACT、SmolVLA、$\pi_0$、$\pi_{0.5}$（子任务监督复用与 System 2 相同的边界标注）、VLM-Monitor（保留计划与指针但用 Qwen3.7-Max 零样本判定替代学习决策头）。
  • 消融变体：Ours w/o System 2、Ours w/o Temporal Context（$M=1$）、Ours w/o Replanning、Ours w/o Learned Trigger，以及作为切换时机上界的 Oracle Pointer（人工推进指针）。
  • 主要结论：论文报告了端到端任务成功率、样本完成率与完成时间的对比结果（Fig. 5），并单独分析了监控器的离线切换时机、样本被取走后的恢复能力、运行时与计算开销以及失败案例；具体数值位于原文图表中，所提供正文片段已截断于指标定义处。
  • 作者自述局限：仅在两种实验室协议、单一工作区和一种外部干预下验证，尚未在真实生产实验室部署；教学全新技能仍需遥操作示范并重训监控器；未来将扩展原子技能库并在更广扰动与实验室配置下评估。
