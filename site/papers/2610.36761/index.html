Card 03 核心贡献

核心贡献

  • 提出 LAM 测量条件化策略架构：在 VLA 范式上扩展类型化遥测输入，同时输出连续机器人轨迹块与离散仪器 API 调用（Role–Op–Parameters）。
  • 提出 OpenSDL 执行基座：以 Role/DeviceProvider 抽象映射异构设备，用带单调时钟与因果父节点的事件账本记录 proposal/gate/dispatch/acknowledge/complete/compensate 六类生命周期事件。
  • 提出 Safe-SDL 运行时门控：派发前做 schema 与资源检查，执行中用信号时序逻辑（STL）持续监控（含长等待期），并以鲁棒度阈值触发阻断、降级或安全中止。
  • 提出 L3-Bench 情节级（episode-level）评测协议：覆盖物理产率、计时、可复现性、安全违规与故障恢复，并给出四条研究问题（RQ1–RQ4）与预注册评测矩阵。
  • 给出可审计性设计不变量（语义可移植、动作可组合、时间一致、安全门控、可重放）与三级制品发布（Tier-1/2/3）与复现清单。
Card 04 方法描述

方法描述

  • 问题建模：将实验过程建模为 POMDP，观测 $o_t=\{I_t,q_t,M_t\}$（视觉、本体感觉、仪器测量），动作空间为机器人臂空间与仪器调用空间的笛卡尔积 $\mathcal{A}=\mathcal{A}_{arm}\times\mathcal{A}_{inst}$。
  • LAM 三段式结构：约 3B 参数的多模态上下文骨干（VLM）+ 约 300M 参数的连续运动专家（采用 flow matching 生成轨迹块，参考 π0 路线）+ 离散函数调用头（受 schema 约束的结构化解码），另有可选动力学头预测下一时刻测量 $M_{t+1}$。
  • 测量编码：遥测经 Scale_κ 保尺度变换 + MLP + 元信息嵌入（角色、单位、时间戳、质量标志），缺失/过期数据使用显式状态标志与受限注意力。
  • 训练目标：流匹配损失 $\mathcal{L}_{flow}$ + 调用序列交叉熵 $\mathcal{L}_{CE}$ + 可选测量预测损失 $\mathcal{L}_{pred}$，加权为 $\mathcal{L}_{total}$。
  • 不确定性处理：输出动作级置信度 $u_t$ 与设备质量摘要 $g_t$，低于预注册阈值或遥测过期时触发只读模式、人工确认或安全降级，弃权与设备重试分开统计。
  • 执行与调度：动作图（DAG）+ 资源预留 + 互斥/快照读 + prepare-and-dispatch 两阶段协议；运行时状态机含 Observed / Proposed / Gated / Dispatched / Verified / SafeAbort / Compensated 等状态。
  • 安全监控：STL 规范 $\varphi_{safe}=\Box_{[0,\tau]}[(T\le T_{crit})\wedge(\\|F_{contact}\\|\le F_{max})\wedge(d_{vial,obs}\ge d_{safe})]$，用归一化最小裕度 $m_t$ 定义带符号时序鲁棒度 $\rho_t$，$\rho_t<\epsilon$ 或输入失效即阻断。
  • 可重放：提供 dry-run（仅检查）、sim-replay（数字孪生）、hardware-replay（白名单+人工批准）三种回放模式。

Card 06 评估与结果

评估与结果

  • 评测基准为 L3-Bench（Level-3 Laboratory Benchmark），统计单元为完整情节，覆盖四种设定：Nominal（常规）、Measurement shift（测量漂移）、Fault injection（故障注入）、Device transfer（设备迁移）。
  • 四个研究问题：RQ1 测量 token 是否提升对测量漂移的适应；RQ2 并发混合动作是否在资源约束下缩短完成时间；RQ3 运行时门控能否以可测吞吐代价抑制故障并恢复；RQ4 保角色设备替换能否维持动作语义与可重放性。
  • 主要指标：归一化物理产率 Y、时间成本 C、完成率、传质误差 Δm、点样均匀性 CV、超调、调节时间、温度控制误差 ITAE、时序安全违规率 SVR（含拦截率、误报率、故障到安全状态时间）、恢复时间与 schema 失败率。
  • 对比基线：仅视觉单臂策略、无测量 token 的 LAM、以及完整 LAM × OpenSDL 框架；安全门控消融仅限仿真或经风险评估的 HIL（硬件在环）环境。
  • 论文尚未给出任何实验数值结果：作者明确说明端到端训练、跨设备迁移与硬件/安全验证均待完成，吞吐、适应性与故障恢复的改进仍是“待检验假设”。
  • 作为替代，论文提供了复现性清单：运行清单需绑定代码/schema 版本、模型哈希、Provider 清单、校准、数字孪生资产、随机种子、故障配置与事件日志索引，缺失必填项即判为复现失败。
