Card 02 论文概述

论文概述

  • 论文提出 VeriVLA，面向 Flow-based 视觉-语言-动作（VLA） 策略的测试时自适应验证框架，旨在利用策略本身固有的随机性提升操作精度。
  • 核心问题是：Flow-based VLA 策略在推理时因噪声种子不同会产生质量不一的动作块，但模型无法区分哪个动作块最可能成功，而执行欠佳动作会造成不可逆的失败。
  • 目标是在关键决策时刻触发重复采样，并用隐空间世界模型对候选动作块排序，从而在不重新训练策略的前提下提升细粒度操作性能。
Card 03 核心贡献

核心贡献

  • 提出以隐空间世界模型作为验证器：利用预训练潜世界模型产生的动作条件潜表征来估计候选动作块的增量进度（delta progress）。
  • 给出 Flow-based VLA 策略随机性的实证刻画，并提出免训练的双轴触发器（Two-Axis Trigger），基于时间动作变化与跨采样方差检测关键状态，降低推理开销。
  • 提供简洁的训练、评测与真机部署流程：在真机任务上平均完成分数提升 14.7 个百分点，优于 VLM 验证器与像素级世界模型验证器等基线。
  • 通过消融实验验证了隐动力学建模与预测器预训练对进度估计的必要性与有效性。
Card 04 方法描述

方法描述

  • 双轴触发器：分别计算时间轴信号 T_temp（动作块内相邻动作的均方变化）与样本轴信号 T_cross（不同采样动作块的方差），归一化后按 OR 规则触发；使用 k=2 个样本，仅需一次轻量校准即可确定阈值。
  • 隐空间世界模型验证器：基于 JEPA 框架，包含冻结的预训练视觉编码器与动作条件自回归预测器；引入与本体相关的状态/动作编码器，并将动作块划分为 M 个子块进行多步潜空间滚动预测。
  • 增量进度预测分支：引入任务特定的可学习查询 token，在潜空间联合预测未来潜状态与 delta progress；通过注意力掩码阻止潜状态预测访问任务查询，避免任务语义泄漏到任务无关的动力学建模中。
  • 训练目标：进度损失 = Huber 回归损失 + 成对排序损失（λ_rank 平衡），视觉预测损失采用 L1 损失（参照 V-JEPA 2-AC），并使用 teacher forcing 与 self-forcing。
  • 推理优化：累积应用 KV 缓存复用（O1）、流水线重叠计算（O2）与 PyTorch 预编译（O3） 三项延迟优化。
Card 05 数据集与资源

数据集与资源

  • 真实世界任务：AgileX PiperX 双臂机器人，配备 1 个前置相机（RealSense D455）与 2 个腕部相机（RealSense D435）；三个任务为钢笔插入（pen insertion）、移液（pipetting）与苹果放置（apple placement）。
  • 仿真基准：RoboTwin 2.0（Clean 与 Clean2Random 设置）与 LIBERO（40 个任务、两个基础策略）。
  • 基础策略：π_0.5、Hy-Embodied-0.5-VLA、StarVLA-GR00T。
  • 预训练资源：冻结的 V-JEPA 2 视觉编码器；动作条件预测器在 DROID 数据集的 23k 条轨迹上预训练。
  • 数据规模：每个任务采集 50 条演示微调基础策略，另采 50 条 rollout 轨迹并用 Robometer 自动标注进度。
  • 训练/部署资源：训练使用单张 H800 GPU；测试时部署使用单张 RTX 4090 GPU，策略与验证器同设备运行；验证用 K=10 个样本。
Card 06 评估与结果

评估与结果

  • 评估指标：排序损失（rank loss）、Huber 损失、真实世界完成分数（completion score）、仿真成功率、触发器分析用 Status AUC 与 Variance Correlation。
  • 真实世界结果：平均完成分数从 50.8% 提升至 65.5%（+14.7 个百分点），每次触发决策额外增加 326 ms（采样+验证，不含 14 ms 触发开销）；优于 RoboMonkey（VLM 验证器）与 GPC-RANK（像素级世界模型验证器）。
  • RoboTwin 2.0 结果：Clean 设置平均成功率 66.4% → 73.6%；Clean2Random 设置 62.8% → 69.6%（提升 6.8 个百分点，体现泛化能力）。
  • LIBERO 结果：平均成功率 96.9% → 97.6%，尤其在未饱和的 LIBERO-10 套件上提升明显。
  • 消融实验：去除世界建模（w/o WM）完成分数降至 55.2%；去除预测器预训练（w/o pretrain）降至 59.5%，验证了隐动力学建模与预训练的重要性。
  • 触发器分析：组合触发器 Status AUC 达 0.727、Variance Correlation 达 0.887，均优于单一分量（T_temp 与 T_cross）及 DINO、ACE 等基线。
