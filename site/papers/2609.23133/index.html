Card 03 核心贡献

核心贡献

  • 提出 AquaCap-Agent：双智能体 Code-as-Policy 架构，将高层任务规划与动作级代码生成分离，并通过基于观测的条件检查形成闭环执行与恢复。
  • 提出 AquaCap-Perception：结构化感知方法，联合表示目标语义、空间几何和估计质量，在退化水下观测下提供可靠、可解释的观测。
  • 提出 AquaCap-Memory：失败感知记忆机制，将执行失败转化为可复用修正，用于后续重规划和代码修订，无需更新模型参数。
  • 在仿真和真实水下机器人上验证框架有效性，并展示对流体动力扰动导致目标位移的自主抓取和运输能力。
Card 04 方法描述

方法描述

  • 使用预训练大语言模型将感知和控制 API 组合为可执行程序，整体为无需训练的 Code-as-Policy 框架。
  • AquaCap-Agent：Policy agent 负责生成和修订任务计划，Coding agent 负责将当前动作实现为程序；执行前后通过 Perception 验证动作的物理结果，决定局部代码修复或任务重规划。
  • AquaCap-Perception：使用 VLM 识别目标并提示 SAM3 分割；结合腕部深度图、点云滤波、PCA 和 ICP 进行近场几何估计，输出目标位置、主轴和可靠性字段。
  • AquaCap-Memory：记录动作、场景、结果、证据、失败原因和修正建议；检索相似失败经验，为 Policy 提供规划建议，为 Coding 提供实现约束。
  • 执行沙箱限制运动、权限和时间预算；验证融合执行结果、传感器有效性、目标估计一致性、动作后置条件和下一步前置条件。

数据集与资源

  • 仿真基准：Gu 等人提出的 20 个水下任务，在 Stonefish 模拟器中评估，共 700 次试验/方法。

Card 06 评估与结果

评估与结果

  • 评估环境：Stonefish 仿真和真实水下 ROV 池中实验；与 U0、OpenVLA-ft、CaP-Agent0 对比。
  • 主要指标：SR（成功率）、SPL（成功加权路径长度）、ASD（平均成功耗时）、SSR（阶段成功率）、MTD（平均目标距离）。
  • 仿真结果：AquaCap 总体 SR 66.43% (465/700)，高于 U0 的 47.14%、OpenVLA-ft 的 7.29% 和 CaP-Agent0 的 0.00%。
  • 分任务结果：导航 86.88% SR / SPL 0.861，抓取 61.25% SR / ASD 288.20 s，运输 62.50% SR / SSR 70.00%，跟踪 70.00% SR / MTD 3.85 m。
  • 消融结果：完整 AquaCap 抓取 65.0% SR；单智能体 50.0%、无 Memory 52.5%、VLM 感知 17.5%，表明几何感知和双智能体/记忆机制重要。
  • 真实世界：抓取和运输各 2/10（20% SR）；抓取 ASD 391.5 s / 2.5 次重规划，运输 ASD 545.0 s / 3.0 次重规划；失败主要与低层推进器动力学和流体扰动导致目标漂移有关。
