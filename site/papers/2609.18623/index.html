FIVE-VLA: Fast and EffectIVE Autonomous Driving with Recurrent Action Memory

Card 02 论文概述

论文概述

  • 论文提出 FIVE-VLA（Fast and EffectIVE VLA），面向自动驾驶的轻量高效视觉-语言-动作模型，旨在同时解决现有 VLA 的三类瓶颈：参数量过大、高分辨率图像处理低效、缺乏时序记忆。
  • 研究目标是让 VLA 能在车载边缘设备上实时运行，同时保持甚至超越当前最优的闭环驾驶性能。
  • 核心思路是：用高效视觉编码器压缩 token、跳过文本生成实现单次前向轨迹预测，并引入动作域的记忆模块提供时序上下文。
Card 03 核心贡献

核心贡献

  • 提出 FIVE-VLA，在 Bench2Drive 与 Fail2Drive 泛化划分上分别取得约 77% 和 67% 的成功率（SR），较此前 SOTA 的 VLA SimLingo 绝对提升 至少 10%。
  • 提出 RAM（Recurrent Action Memory）：一个轻量级记忆机制，将当前动作预测条件化于上一时刻的动作 token，在让行、超车、紧急制动和行驶平顺性等最依赖时序推理的能力上带来选择性提升。
  • 效率方面：仅 641M 参数，在 A100 上约 30 fps、在 T4（边缘设备代理）上约 4 fps，相比 ORION 和 SimLingo 分别约 30× 和 8× 的吞吐提升（总体 8–30× 加速）。
  • 在真实大规模 NVIDIA Physical AI AV 数据集上的非反应式开环仿真中，碰撞违规率比 SimLingo 在单视图和四视图设置下分别低 10.2% 和 7.7%。
  • 首次将 FastVLM 适配为自动驾驶 VLA，验证了卷积+注意力混合视觉编码器在驾驶任务上的有效性。
Card 04 方法描述

方法描述

  • 高效视觉骨干：采用 FastVLM（FastViTHD 视觉编码器 + Qwen2 LLM），处理 448×896 高分辨率图像仅生成 98 个视觉 token，相比 ViT 减少约 21×、相比 InternViT-300M 减少约 5×，且无需 tile 切分，可在编码器内进行全局 token 交互。
  • 单次前向轨迹预测（Efficient Driving）：识别到输出文本 "Waypoints:" 在所有输入下恒定，将其直接拼接到输入 token 序列，从而绕过自回归文本生成，实现单次前向输出路径点与速度点。
  • RAM 设计：由 RAMEncoder（1 个自注意力 Transformer 块）编码上一时刻动作 token 得到 RAM 状态，再由 RAMDecoder（1 个交叉注意力 Transformer 块）让可学习 action query 通过交叉注意力读取该状态；共仅 2 个 Transformer 块（对比视觉域记忆通常 8 块）。
  • 两阶段微调：先在不含 RAM 情况下完成基础微调，再注入 RAM；关键初始化策略是把交叉/自注意力输出投影层与 MLP 第二层线性层置零，使初始时 RAM≈恒等映射（action query 仅经残差连接传播），从而保留预训练知识。
  • RAM 累积推理：训练流长度受显存限制（如 T=4），推理时采用双实例机制——主实例负责生成轨迹，次实例在后台累积记忆，每 T/2 步互换，避免周期性重置记忆造成的信息丢失。
  • 多能力支持：除默认的高效驾驶模式外，还支持 CoT 推理（输入 "What should the ego do next?"）与 VQA 问答，用于可解释性；训练样本按时间流（长度 T）组织，每条流仅含单一能力类型。
Card 05 数据集与资源

数据集与资源

  • 闭环训练：SimLingo 数据集，由 CARLA 仿真器配合 PDMLite 专家采集，约 200 万张图像（4 fps），约 140 小时驾驶数据，含 CoT 与 VQA 标注。
  • 闭环评测：Bench2Drive、Fail2Drive（含 In-Distribution 与 Generalisation 划分），指标为 DS（Driving Score） 与 SR（Success Rate）。
  • 开环评测：NVIDIA Physical AI AV 真实数据集，约 860 小时训练 / 350 小时测试，仅使用驾驶监督；采用 NAVSIM 风格非反应式仿真，指标包括 ADE/FDE、NC-V（责任碰撞率）、TTC-V（碰撞时间违规率）等。
  • 语言能力评测：DriveLM-CARLA VQA。
  • 模型规模：641M 参数（基于约 620M 参数的最小号 FastVLM，预训练分辨率至 1024×1024）。
  • 推理硬件：NVIDIA A100（约 30 fps）与 NVIDIA T4（约 4 fps，作为边缘设备代理）。
Card 06 评估与结果

评估与结果

  • 基准环境：CARLA 闭环仿真（Bench2Drive、Fail2Drive）+ NAVSIM 风格非反应式开环仿真（NVIDIA Physical AI AV）。
  • 主要指标：闭环用 DS / SR / Mean Ability / HM；开环用 ADE / FDE / NC-V / TTC-V（均为越低越好）。
  • 关键结果一：FIVE-VLA 在 Bench2Drive 上超越包括 SimLingo、AutoVLA、ORION、DriveMoE 在内的所有 VLA 及 E2E-AD 方法，并高出最优纯相机基线至少 10% 的绝对 SR 提升。
  • 关键结果二：在 Fail2Drive 泛化划分上 SR 约 67%，同样显著领先 SimLingo（SimLingo 的 SR 下降约 30.6%，而 FIVE-VLA 的退化更小，泛化更稳健）。
  • 关键结果三：在 NVIDIA Physical AI AV 开环仿真中，单视图与四视图下碰撞违规率分别比 SimLingo 低 10.2% 和 7.7%。
  • 关键结果四（消融）：仅用视频流的非 IID 采样训练会使性能在流长 T>2 后显著下降（图 3a），因此验证了"先无 RAM 训练、再注入 RAM"两阶段策略的必要性；RAM 累积推理优于周期重置 RAM。
  • 关键结果五（效率）：模型在 A100 上约 30 fps、T4 上约 4 fps，较 ORION 约 30×、较 SimLingo 约 8× 加速。
