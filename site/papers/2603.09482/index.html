Card 02 论文概述

论文概述

  • 论文提出 StyleVLA，一个驾驶风格感知的视觉-语言-动作（VLA）框架，用于生成多样化且物理上可行的自动驾驶轨迹。
  • 现有 VLA 模型主要聚焦于通用无碰撞轨迹生成，缺乏对多样化驾驶风格（如运动型、舒适型）的适应；同时将轨迹生成视为朴素 token 预测任务，导致生成动作在运动学上不可行。
  • 论文构建了包含 5 种驾驶风格的大型指令数据集，并引入物理信息混合损失函数与连续回归头，以增强轨迹的物理可行性和风格贴合度。
Card 03 核心贡献

核心贡献

  • 构建 StyleVLA 数据集：包含 1,216 个场景、76,030 个 BEV（鸟瞰视图）样本和 42,084 个 FPV（第一人称视角）样本，具有五种驾驶风格（Default、Balanced、Comfort、Sporty、Safety）的 ground-truth 轨迹和自然语言指令。
  • 提出 物理信息 VLA 模型微调框架：将标准交叉熵（CE）损失与辅助 MLP 回归头及物理信息运动学一致性损失（PIKC）相结合，在微调 4B 参数 VLM 时提升轨迹可行性和风格遵循度。
  • 开展 大规模评测：对现成商业 VLM（如 Gemini-3-Pro）和 SOTA VLA 模型在 BEV 和 FPV 域上进行全面评估，揭示了它们在风格感知轨迹生成任务上的局限性。
Card 04 方法描述

方法描述

  • 数据集生成采用开源采样运动规划器 Frenetix，在 CommonRoad (CR) 框架内通过调整多目标成本函数权重（如纵向/横向加加速度、速度偏差、障碍物距离、Phantom Risk、Visibility Seeking）实现不同驾驶风格。
  • 采用 Mahalanobis 距离与卡方 CDF 映射的统计过滤方法（阈值 S>80），去除运动学特征不明确的模糊样本，确保风格标签清晰可区分。
  • BEV 域使用 LLaVA VQA 对话格式构建指令数据，包含视觉图像、自车历史、交通代理状态、目标区域和风格指令；FPV 域通过 CARLA 模拟器进行地图转换与场景重放，采用仅视觉（vision-only）提示以防止捷径学习。
  • 微调以 Qwen3-VL-4B 为基座模型，使用 QLoRA（4-bit 量化低秩适配），训练时引入辅助 MLP 回归头将语义嵌入映射为连续运动学状态，混合损失采用 同方差不确定性加权（Homoscedastic Uncertainty Weighting）自动平衡 CE 损失与回归损失。
Card 05 数据集与资源

数据集与资源

  • StyleVLA 数据集：1,216 个 CR 场景，53,457 个动态代理，11.2 小时驾驶数据，过滤后得到 76,030 个 BEV 样本和 42,084 个 FPV 样本。
  • 场景来源涵盖 14 个国家（德国 597 个、希腊 258 个、波兰 245 个等），包含城市交叉口、环岛、高速公路等多样化交通场景。
  • 基础模型为 Qwen3-VL-4B（约 4B 参数），使用 QLoRA 微调，冻结语言模型权重，仅训练注意力和前馈层中的轻量适配器矩阵。
  • 轨迹输出格式为 JSON 结构，覆盖 3 秒（标准）或 5 秒（扩展）预测时域，采样频率 2 Hz，状态向量包含位置、速度、加速度和航向角。
Card 06 评估与结果

评估与结果

  • 评估对比对象包括商业专有模型 Gemini-3-Pro 和现有 SOTA VLA 模型，分别在 BEV 和 FPV 两个视觉域上进行评估。
  • 主要评估指标为复合驾驶分数（composite driving score），综合衡量成功率、物理可行性和对用户指定驾驶风格的遵循程度。
  • StyleVLA 在 BEV 域上取得 0.55 的复合分数，在 FPV 域上取得 0.51；而 Gemini-3-Pro 仅为 BEV 0.32、FPV 0.35，充分表明专用化、物理信息增强的轻量模型在领域特定任务上可超越闭源大型模型。
  • 消融研究表明，混合损失（CE + 回归 + 运动学一致性）相比纯 token 预测显著提升了轨迹的物理可行性和风格贴合度。
