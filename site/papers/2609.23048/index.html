Card 03 核心贡献

核心贡献

  • 定位病灶：失败集中在 transport-to-target 阶段边界，早期阶段仅渐进退化（移动约 90%、抓取约 55%），最后阶段类别式失败（0%）；配对动作轨迹分离出 负向、后期加重的 z 残差，约为修复后的 10 倍，并在基础蒸馏和两个 continuation 分支中持续存在。
  • 受控证伪四种标准疗法：继续训练无效；域内离线数据在成功率上无效但可改善边际动作统计；命令级补偿在任何偏移下均无恢复，尽管同一扰动可退化健康策略；命令级 clamp 保留抓取但成功率仍在底线。
  • 提出充分疗法并做最小对控制：在其余设置不变的情况下，用部署环境中的成功教师 rollout 替换一半训练流，使 held-out 成功率恢复至教师水平（18/36 vs 17/36），消除负向后期签名，并恢复类教师的扰动响应曲线。
  • 操作性结论：离线 gate（包括模型家族自身验证指标）不足以作为压缩策略的验收测试；数十次闭环试验即可发现离线评估漏掉的类别式崩溃。
Card 04 方法描述

方法描述

  • 压缩与蒸馏：教师为 Octo-Base-1.5（12 层）；student 通过 expert surgery 保留层 {0,1,3,4,6,8,10,11}，训练 300k steps，batch 128，peak LR 3e-5，warmup 2000 后 cosine decay 到 1e-6。
  • 蒸馏目标：隐藏状态蒸馏（权重 α=0.5，对 observation、task、readout token groups 做 cosine distance）与 diffusion action head 原生 loss（权重 1−α）的凸组合；训练在 Open X-Embodiment 混合数据上完成。
  • 离线评估：使用模型家族自带验证工具，在 Bridge、Fractal、Kuka 各 200 条 held-out 轨迹上测 gripper-prediction accuracy 与 end-effector translation-direction error；student 通过所有离线 gate。
  • 闭环评估：在 SimplerEnv / ManiSkill2 (SAPIEN) 的 PutEggplantInBasketScene-v0 与 WidowX 臂上运行；gripper 动作在 0.75 阈值二值化；诊断协议评估 72 个配置（seeds {0,1,2} × episode IDs 0–23），记录 moved、grasped、sustained hold、transport 阶段；单 seed 切片携带密集 instrumentation。
  • 因果干预：先做 necessity arm（继续训练、域内离线数据、命令级补偿、命令级 clamp），再做 sufficiency arm 最小对（相同训练脚本、相同 seed/LR/optimizer/loss/batch/steps/checkpoint cadence/host/GPU，仅 ρ_R=0.5 vs 0 不同，即是否用 rollout 数据替换一半 batch）。
  • 证据分级：counted outcomes 承担所有因果主张；paired trace statistics 承担面板级动作诊断；0.002–0.006 尺度 unpaired micro-displacement 不承担机制主张。
Card 05 数据集与资源

数据集与资源

  • 教师模型：Octo-Base-1.5（12 层）；学生模型：8 层，总参数 202.5M → 174.1M（保留 86%；transformer stack 压缩至 68%）；推理延迟 135.4 → 124.9 ms（约 1.08× 加速）。

  • 修复数据：在部署环境中收集 324 条成功教师 rollout，打包为 RLDS 数据集 38,880 帧；录制 seeds {100–179} 与评估 seeds {0,1,2} 不相交；held-out episode IDs（{3–8,15–20}）从不录制。
  • 闭环环境：SimplerEnv / ManiSkill2 (SAPIEN)，任务 PutEggplantInBasketScene-v0，机器人 WidowX。

Card 06 评估与结果

评估与结果

  • 离线评估：student 达到教师比例 0.996（gripping） 与 1.000（xyz angle）；在六个探针上跟踪教师，无明显离线差异。
  • 闭环 stage profile（instrumented slice，seed 0，episodes 0–23）：教师 15/24 success，moved 20，grasp 20，sustained 19，target 15；student V1 0/24，moved 18，grasp 11，sustained 11，target 0；+5k OXE target 0；+5k Bridge target 0。
  • 全协议：教师 40/72，student 0/72；所有重训练变体 transport 均为 0；student 在项目任何评估中从未超过 2/36。
  • 配对 z 残差（固定 4-episode 诊断面板 IDs 2,11,14,23）：V1 full rollout d_z=-0.0067，final third -0.0103；+5k OXE full -0.0048，late -0.0073；+5k Bridge full -0.0047，late -0.0081；修复后 full +0.0009，late -0.00065，early -0.0069→-0.0005。
  • 标准疗法结果：继续训练 0/24（+5k）和 0/36（+10k）；域内离线数据成功 0/24，但 gripper close-fraction gap 从 -0.161 到 -0.065、raw-open 0.097→0.046、rotation 0.0053→0.0033；命令级 z-offset sweep 成功率 1,0,1,0,0,0,0；命令级 clamp 成功率 0/36 和 2/36，抓取保留 16–17/36。
  • 充分疗法结果：最小对修复后预选 step 8k 在 held-out 上 18/36，教师 17/36；held-out grasp 34/36，未修复 student 17/36；zero-rollout 对照在所有 checkpoint 处于底线（step 8k 仅 1/36）；修复模型扰动剂量响应为 22,22,14,3,0，教师 19,16,8,3,0，zero-control 为 0,2,2,1,0。
  • 因果结论：近因是学习到的 state-conditional action mapping 缺陷，最强烈表现在 late transport regime，并经闭环执行放大为 transport 阶段类别式失败；压缩是 enabling condition，而非容量判决；修复数据 bundle 中具体 active component 未解（部署状态覆盖、success-only filtering、teacher-consistent labels 或组合）。
