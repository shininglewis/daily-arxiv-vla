GWM-VLA: Geometry-Aware Latent World Modeling for Vision-Language-Action Learning

2026-08-07 · 原文 · 翻译 · 2608.07619

提出 GWM-VLA（Geometry-Aware Latent World Modeling for Vision-Language-Action Learning），一种面向 VLA 模型的几何感知潜在世界建模框架，旨在解决 VLA 模型在视觉与环境变化（如视角、光照、背景、物体布局、传感器噪声）下性能显著退化的问题。 现有潜在世界模型（如 VLA-JEPA）通常独立编码每个相机视角再拼接特征，缺乏显式的跨视角几何关系建模；而显式世界模型需要生成未来视觉观测，代价过高。GWM-VLA 通过引入 VGGT-Ω 联合多视角聚合构建几何感知状态，并结合共享潜在动作表征实现预测与控制的统一学习。 在 LIBERO 和 LIBERO-Plus 仿真基准及 SO-101 真实机器人上验证了方法的有效性和鲁棒性。

Card 03 核心贡献

核心贡献

  • 提出几何感知潜在世界建模方法，将联合聚合的多视角几何表征作为预测状态，建模动作条件下的时间转移过程。
  • 提出 GWM-VLA 框架，通过共享潜在动作表征整合几何感知潜在世界建模与流匹配动作生成，使潜在预测监督与真实动作监督共同塑造表征。
  • 设计全局上下文条件下的目标视图预测机制：借助 VGGT-Ω 的 patch 与 register token，仅预测腕部视图的下一时刻 patch token，同时保留多视角几何信息。
  • 在仿真与真实环境实验中证明 GWM-VLA 在分布内性能和分布外鲁棒性方面均优于现有机器人演示预训练的 VLA-JEPA 等基线。
Card 04 方法描述

方法描述

  • 几何感知多视图状态编码：使用冻结的 VGGT-Ω 编码器在每个时间步联合聚合多视角观测，输出 register tokens 和 patch tokens，构成几何感知的隐状态序列。
  • 全局上下文条件下的目标视图预测：选择腕部视图作为预测目标，利用其 register tokens 作为全局几何上下文，潜在世界模型仅预测下一时刻腕部视图的 patch tokens；采用时间因果注意力与 teacher forcing 训练，使用 ℓ1 损失优化。
  • 统一潜在动作表征：基于 Qwen3-VL-2B 视觉语言骨干，插入按时间步分组的可学习潜在动作查询 token，产生共享的潜在动作序列，同时条件化潜在世界模型和动作头。
  • 条件流匹配动作头：使用 Flow Matching 生成连续动作块，以共享潜在动作序列和当前本体感受状态为条件，建模连续动作的多模态分布。
  • 联合训练：总损失为动作损失与带权重 λ=0.1 的世界模型损失之和，世界模型损失仅在训练时作为辅助目标。
Card 05 数据集与资源

数据集与资源

  • 预训练数据集：DROID（约 76,000 条机器人演示轨迹，覆盖多机构、多操作者、多样任务与视角）。
  • 仿真 benchmark：LIBERO（Spatial、Object、Goal、LIBERO-10 四个任务套件）及 LIBERO-Plus（7 种扰动维度：视角、机器人初始状态、语言、光照、背景、噪声、布局）。
  • 真实实验：SO-101 机器人，基于 LeRobot 开源部署栈，采集 100 条遥操作演示，覆盖 5 个训练任务。
  • 基础模型：视觉语言骨干为 Qwen3-VL-2B，几何编码器为 VGGT-Ω（冻结）。
  • 训练资源：预训练与仿真微调使用 8 块 NVIDIA A800 GPU；消融实验使用 1 块 NVIDIA RTX 6000D GPU，batch size 16，10,000 步。
Card 06 评估与结果

评估与结果

  • LIBERO 基准：GWM-VLA 平均成功率达到 97.1%，与 OpenVLA-OFT 并列最优；在 Goal 套件（98.0%）和 LIBERO-10（94.4%）表现突出，优于机器人演示预训练的 VLA-JEPA 基线 1.0 个百分点。
  • LIBERO-Plus 鲁棒性基准：GWM-VLA 平均成功率 76.9%，比 OpenVLA-OFT 高 7.3 个百分点，比机器人演示 VLA-JEPA 基线高 14.0 个百分点；在语言、光照、物体布局扰动下排名第一，在视角、机器人初始状态、背景扰动下排名第二。
  • 真实世界实验：GWM-VLA 在 ID（分布内）和 OOD-layout（新物体布局）设置下取得最高成功率，总体平均成功率最高；在 OOD-task（新指令组合）设置下达到 53.3%，明显优于 π₀，但低于 π₀.₅ 的 60.0%。
  • 消融实验（LIBERO-Spatial）：腕部视图作为预测目标效果最佳（92.8%），优于第三人称视图（87.8%）和混合视图（92.4%）；VGGT-Ω 最后一层（Layer 24）表征效果最优，越深层的几何表征带来的收益越大；直接共享潜在动作表征比额外的 embodied-action query 高 4.8 个百分点。
  • 定性探针实验：用冻结的深度解码器对预测的隐状态进行可视化，结果显示预测的下一时刻隐状态保留了以夹爪和被操作物体为主的主要场景几何布局，但细节较平滑。
