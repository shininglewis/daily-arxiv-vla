Card 03 核心贡献

核心贡献

  • 提出 FastVLA，一个训练无关、即插即用的视觉 token 压缩框架，可在每个动作步独立执行任务条件化的 token 剪枝，无需缓存或额外训练。
  • 设计 步骤自适应压缩策略：根据当前步视觉 token 重要性分布的集中程度，动态设定每步的 token 预算与压缩率，而不是使用固定压缩率。
  • 采用 task-to-vision attention 作为视觉 token 重要性信号，并通过实验证明其比 vision-to-vision 和 all-to-vision 注意力更适合 VLA 动作预测。
  • 使用 inverse-Simpson uniformity 度量重要性分布的有效 token 数，并结合 在线滑动窗口校准，将分布均匀性映射为受限于 [ρ-τ, ρ+τ] 的逐时间步压缩率。
  • 在 OpenVLA、OpenVLA-OFT、CogACT 以及真实 Franka Research 3 机器人上验证，仿真中减少 LLM 主干 FLOPs 35–59%、动作延迟 9–32%，真机实现约 1.25 倍端到端加速且成功率相当。
Card 04 方法描述

方法描述

  • FastVLA 在每一步基于 task tokens 对 visual tokens 的注意力计算重要性：对 task 和 visual 表示做 RMSNorm，计算缩放点积注意力并对 visual tokens 做 softmax，再对任务 token 子集平均，得到每个视觉 token 的重要性分数。
  • 根据目标压缩率 ρ 和偏差因子 τ，先确定最小保留预算 K = ceil((1-(ρ+τ))N)，并取 Top-K 重要性 token。
  • 通过 inverse Simpson 度量当前步重要性分布的均匀性：归一化 Top-K 权重后计算有效 token 数 K_eff，再得到 U(t) = K_eff / K；U(t) 越小表示注意力越集中，越大表示分布越均匀。
  • 使用长度为 T 的在线滑动窗口维护历史 U，计算当前步在窗口极值间的相对位置 α(t)，再映射为逐时间步压缩率：ρ(t) = clip(ρ + τ(1-2α(t)), ρ-τ, ρ+τ)。
  • 当 α(t) 小（比近期更集中）时更激进剪枝；当 α(t) 大（需要更广上下文）时更保守剪枝；该方法属于 hard token pruning，每步独立执行，无需训练和跨步缓存。

  • 计算资源：所有实验在单张 NVIDIA RTX 4090 GPU 上完成；FastVLA 本身为训练无关方法，不需要额外训练压缩模块。
Card 06 评估与结果

评估与结果

  • 评估指标包括：成功率 (SR)、LLM 主干 FLOPs、动作预测延迟、控制频率、CUDA 延迟 和 端到端加速比。
  • 仿真中，FastVLA 将 LLM 主干 FLOPs 降低 35–59%，动作延迟降低 9–32%，实现 1.09×–1.46× 加速，同时保持与基线相当的任务成功率。
  • 在 OpenVLA-OFT + LIBERO 上，平均成功率 96.5%（基线 97.0%），LLM FLOPs 从 3.98T 降至 1.65T，延迟从 118.52 ms 降至 81.17 ms，加速 1.46×。
  • 在 OpenVLA + LIBERO 上，平均成功率 75.8%（基线 76.4%），延迟从 186.64 ms 降至 161.53 ms，FLOPs 从 1.86T 降至 1.20T，加速 1.16×。
  • 在 CogACT-base + SIMPLER 上，Visual Matching 平均成功率 77.1%（基线 77.5%），Variant Aggregation 平均成功率 61.9%（基线 60.9%），分别实现约 1.09× 和 1.11× 加速。
  • 在真实 Franka Research 3 上，FastVLA 将端到端延迟降低约 20%，实现 1.25× 加速，控制频率最高提升 25%；Pick 任务成功率 80%（基线 84%），Pick and place 成功率 66%（基线 68%）。
  • 消融实验表明，在相同 token 预算下，自适应压缩率 优于固定压缩率，例如 LIBERO Spatial 成功率 97.8% vs 预算匹配固定策略 96.5%，Object 98.0% vs 97.1%，Goal 97.0% vs 95.7%，Long/10 93.1% vs 92.0%。
