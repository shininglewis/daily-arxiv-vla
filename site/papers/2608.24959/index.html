Card 03 核心贡献

核心贡献

  • 高斯空间分词器（Gaussian Spatial Tokenizer, GST）：将冻结的语义与深度特征提升为紧凑的 3D 高斯基元，每个基元由 3D 均值（空间位置）、协方差（局部几何结构）和 opacity（深度置信度）参数化，并通过空间注意力池化精炼
  • 深度感知链式思维（Depth-Aware Chain-of-Thought, DA-CoT）：引入非自回归的结构化推理模块，通过少量可学习查询在语言和流时间双重条件下交叉注意力到 GST token，将空间推理信号直接注入动作生成过程
  • 高效统一框架：将 GST 与 DA-CoT 集成于 Mamba 线性时间序列建模骨干中，实现实时推理与较低的计算开销，总参数仅 200M（可训练 179M），推理速度达 12.97 ms/步
Card 04 方法描述

方法描述

  • 采用双流视觉编码：冻结的 SigLIP-SO400M/14 提取语义 patch 特征，冻结的 Depth-Anything-V2 (ViT-L) 提取深度特征，patch 对齐后输入 GST
  • GST 通过可学习仿射校正补偿单目深度尺度偏差，反投影到 3D 空间，用语义特征预测残差均值偏移、对数尺度向量和置信度，构建几何感知 patch token，再经多查询空间注意力池化为紧凑 token
  • DA-CoT 以少量可学习推理查询对 GST token 进行自注意力与交叉注意力迭代精炼，生成结构化推理 token，并通过辅助损失监督其与目标流速度场对齐
  • 采用 Mamba 骨干处理多模态 token 序列，flow-matching 动作解码器（10 步 Euler 采样）预测 7-DoF 动作块，训练目标由 flow-matching 损失、GST 深度一致性损失和 DA-CoT 监督损失加权组合
Card 05 数据集与资源

数据集与资源

  • LIBERO 作为主要仿真基准（Spatial/Object/Goal/Long 四个套件）
  • LIBERO-PRO 用于鲁棒性测试，Meta-World 用于难度分层评估（Easy/Mid/Hard/Very Hard）
  • CALVIN ABCD→D 用于长时程序列泛化评估（10% 子集，1-5 个连续任务完成率）
  • 真实世界评估使用 SO-101 机器人（6-DoF 臂 + 平行爪，RealSense 相机，每任务 50 条遥操作演示）
  • 模型总参数量 200M，可训练参数 179M；GST 使用 N_g=128 高斯查询/相机，DA-CoT 使用 N_r=4 推理查询，Mamba 骨干维度 512，5 层
  • 训练配置：AdamW 优化器，学习率 2.5×10⁻⁵，批量大小 256，BF16 精度，在单块 NVIDIA RTX Pro 6000 Blackwell 上推理
Card 06 评估与结果

评估与结果

  • 仿真评估：LIBERO 平均成功率 93.5%，Spatial 套件达到 100.0% 成功率
  • 与 SpatialVLA（4B 参数）相比，GaussVLA（200M 参数）相对平均成功率提升 19.7%，同时参数效率显著更高
  • 对比基线包括 Diffusion Policy（80M）、MaIL（24M）、QueST（152M）、OpenVLA（7B）、ThinkAct（7B）、CoT-VLA 等
  • 在 LIBERO 各套件中均取得领先：Spatial 100.0%、Object 约 92%、Goal 约 89%、Long 约 87%（相对表现）
  • 进行消融实验验证 GST、DA-CoT 以及各组件对最终性能的贡献，并在真实 SO-101 机器人上验证 sim-to-real 迁移能力
