STAR: Steering Action Representations during Inference

2026-10-29 · 原文 · 翻译 · 2610.41009

论文研究视觉-语言-动作模型（VLA）中动作表征与任务相关视觉证据之间的关联强度，发现了一个“深层 grounding gap”：在原生推理过程中，动作表征对目标物体的感知从浅层到中层逐渐增强，但在靠近动作输出的最后若干层明显衰减。 为验证这一点，作者设计了扰动实验（把目标物体区域替换为图像平均 RGB），并定义了 object awareness 分数（即掩码前后隐藏状态的相对差异）。 提出 STAR，一种免训练（training-free） 的推理期干预方法，在不更新权重、不改网络结构的前提下，把早期层中具备物体感知的残差更新方向“传导”到深层，从而提升下游操作成功率。

Card 02 论文概述

论文概述

  • 论文研究视觉-语言-动作模型（VLA）中动作表征与任务相关视觉证据之间的关联强度，发现了一个“深层 grounding gap”：在原生推理过程中，动作表征对目标物体的感知从浅层到中层逐渐增强，但在靠近动作输出的最后若干层明显衰减。
  • 为验证这一点，作者设计了扰动实验（把目标物体区域替换为图像平均 RGB），并定义了 object awareness 分数（即掩码前后隐藏状态的相对差异）。
  • 提出 STAR，一种免训练（training-free） 的推理期干预方法，在不更新权重、不改网络结构的前提下，把早期层中具备物体感知的残差更新方向“传导”到深层，从而提升下游操作成功率。
Card 03 核心贡献

核心贡献

  • 通过可控探测实验揭示了 VLA 推理中深层动作表征的视觉 grounding 不足，并提出 object awareness 指标来量化该现象。
  • 提出 STAR：对深层 Transformer 的残差更新做跨层 EMA 混合，让深层继承早期层的物体感知更新方向，且完全免训练、没有推理额外前向。
  • 设计本体感知调制的混合系数：用末端执行器轨迹与姿态的因果历史（方向一致性、平移尺度、抖动、旋转变化）动态调节 EMA 强度，在“稳定推进”阶段强干预、在“过渡/精细调整”阶段保守干预。
  • 在 SimplerEnv 与 LIBERO-PRO 上跨 GR00T-N1.5、OpenVLA、π0.5 三种不同架构骨干验证，平均成功率提升约 4.0 个百分点。
Card 04 方法描述

方法描述

  • 层间残差 EMA：设骨干共 n 层，按相对深度 ρ=2/3 划分，前 p=⌊ρn⌋ 层不改动以形成语言条件化的视觉证据；对后 1/3 层（ℒ_mix）的残差更新 Δh 维护跨层动量 m^k_t = β_t·m^{k-1}_t + (1-β_t)·Δh^k_t，并用 h^k_t = h^{k-1}_t + m^k_t 替换原更新。
  • 因果本体感知证据：从机器人状态中提取四个量——方向连续性 c_t、平移尺度 v_t、类加速度的抖动 j_t、姿态变化 ω_t，全部只使用当前控制步之前的信息，严格因果。
  • 因果归一化：用滑动窗口 W = f_ctrl·T_w 的均值/方差对四个量做 z-score 式标准化；再对加权得分 r_t 施加基于 median / IQR 的鲁棒归一化，抑制瞬时尖峰。
  • 本体感知条件化系数：β_t = β_min + (β_max−β_min)·σ(κ·r̂_t)，实现值域约 (0.25, 0.55)；符号设计上，方向一致性和平移尺度提供正向证据，抖动与旋转变化提供负向（过渡）证据。
  • 关键特性：只改残差更新流，不改 attention map、不改 token、不加额外前向，与基于注意力裁剪的 DTP 等基线形成对比。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：SimplerEnv（6 个 Fractal/Google Robot 桌面操作任务：Open Drawer、Place in Drawer、Pick Coke Can、Move Near、Close Drawer、Pick Object）；LIBERO-PRO（LIBERO-10 上的 5 个泛化切分：lan、object、swap、task、env，每切分 10 个任务）。
  • 评测规模：π0.5 + STAR 每任务 50 回合，每切分 500 回合，五切分共 2,500 回合。
  • 骨干模型：GR00T-N1.5（NVIDIA Eagle VLM + 流式动作头）、OpenVLA-7B（DINOv2+SigLIP+Llama-2）、π0.5（PaliGemma 风格 VLM + flow matching 动作专家）。
  • 训练资源：方法为推理期免训练，所有权重冻结，无需额外数据采集或参数更新；文中未给出 GPU 型号与数量的具体说明。
Card 06 评估与结果

评估与结果

  • 评估方式：遵循各基准官方评测协议，仅推理时启用 STAR；主指标为任务成功率（单任务与平均）。
  • SimplerEnv 主结果：GR00T-N1.5 平均成功率 41.0% → 46.3%；OpenVLA 30.3% → 36.0%；均优于免训练基线 DTP（40.0% / 34.3%），且 STAR 为单次前向。
  • LIBERO-PRO 主结果：GR00T-N1.5 40.3% → 43.2%（object 切分 40.4%→48.0% 增益最大）；π0.5 48.2% → 50.1%（task 切分 6.8%→18.8% 提升最显著，但 lan/swap/env 切分略有下降）；DTP 在该长程基准上增益有限或参差。
  • Object awareness 分析：STAR 使深层动作表征的物体感知分数回升，缓解了原生推理的深层衰减，与成功率提升趋势一致。
  • 消融实验（OpenVLA / SimplerEnv）：移除任一单体感知线索导致平均成功率下降 4.3–5.9 个百分点；仅用正向证据 29.3%、仅用过渡证据 33.2%、完全不用本体感知 27.8%，均低于完整的 36.0%。
  • β 调度消融：固定 β=0.25/0.35/0.45/0.55 分别仅得 31.6%/30.3%/30.7%/30.7%；动态区间 (0.15,0.55)=31.2%、(0.35,0.55)=28.9%、(0.25,0.45)=30.9%，而本文的动态 (0.25, 0.55) 取得最佳 36.0%，说明“本体感知调度 + 适中区间”是关键。
