OmniVLA: An Omni-Modal Vision-Language-Action Model for Robot Navigation

2025-09-23 · 原文 · 翻译 · 2509.19480

论文提出 OmniVLA，一个面向机器人导航的全模态（Omni-Modal）视觉-语言-动作（VLA）模型，能够同时理解并组合多种目标指定方式，包括 2D 位姿、自我中心图像和自然语言。 现有导航策略大多只针对单一模态训练，限制了其在真实场景中的适应性；本文通过统一多种目标模态，使策略同时利用多源信息（如"去哪里"的位姿 + "怎么走"的语言指令），实现更灵活和通用的导航。 该模型训练于近 10,000 小时的跨实体真实世界导航数据，据作者所知是规模最大的端到端导航策略预训练数据集，展示了在新模态、新环境和新型机器人平台上的泛化能力。

Card 03 核心贡献

核心贡献

  • 提出首个统一多种目标模态的端到端 VLA 导航模型 OmniVLA，支持 2D 位姿、自我中心图像、自然语言及其任意组合作为条件输入。
  • 设计随机模态融合（randomized modality fusion）训练策略，结合模态丢弃（modality dropout）与注意力掩码，缓解模态不平衡和稀缺问题，使策略学会跨模态表示。
  • 在 7.5B 参数的 OpenVLA 骨干上扩展多种模态编码器，并构建轻量级 OmniVLA-edge（50M 参数）版本，适用于资源受限的边缘部署场景。
  • 构建了包含 13 个公开数据集、10 种机器人平台、9,500+ 小时的导航训练数据混合，显著超越所有单模态专家基线。
Card 04 方法描述

方法描述

  • OmniVLA 架构：基于 OpenVLA（7B VLM + 跨实体机器人动作预训练），新增视觉骨干和投影器，将目标图像与 2D 位姿投影到共享 token 空间，语言指令由 LLM 处理，最终通过线性动作头（参考 OpenVLA-OFT）输出 N=8 步动作序列（3Hz，对应 2.4 秒）。
  • OmniVLA-edge 架构：基于 ViNT 导航 Transformer（50M 参数），增加 2D 位姿投影器以及 ResNet/CLIP + FiLM 语言编码器，采用早期融合机制，输入最近 M=5 帧图像 token。
  • 训练策略：每个训练样本根据可用模态独立采样条件输入，并通过注意力掩码排除未选模态；针对 LeLaN 数据集引入额外的目标接近（J_obj）和动作平滑（J_sm）正则化目标；使用 LoRA 将可学习参数限制在约 5%，在 8 张 H100 GPU 上以有效 batch size 224 训练。
  • BDD-V 数据重标注：针对自动驾驶数据集与小型机器人之间的实体差距，修改 MBRA 重标注模型，仅在 GNM 数据上施加碰撞避免目标，并约束速度/角速度以匹配目标机器人运动学模型。
Card 05 数据集与资源

数据集与资源

  • GNM mixture：62 小时，6 种平台，包含 2D 位姿与自我中心图像模态（室内外、越野、人行道等）。
  • LeLaN mixture：128.7 小时，3 种平台，提供合成语言标签与目标位姿（由 NoMaD 生成）。
  • Frodobots-2K：700 小时，ERZ 平台，包含位姿、自我中心图像与卫星图像（MBRA 重标注动作）。
  • BDD-V：8,680 小时，车载平台，使用定制 MBRA 重标注生成合成动作标签。
  • 模型规模：OmniVLA 7.5B（Llama2-7B + DINOv2/SigLIP）；OmniVLA-edge 50M（EfficientNet-B0 + CLIP）；对比模型含 SmolVLA（500M）、MiniVLA（1B）、CounterfactualVLA（2.9B）。
  • 训练资源：8 张 H100 GPU，每 GPU batch size 7，梯度累积 4 步，有效 batch size 224，应用 LoRA 缩短训练开销。
Card 06 评估与结果

评估与结果

  • 评估平台：FrodoBots ERZ 低成本移动机器人为主要评估平台，另在 VizBot 轮式机器人和 Unitree Go1 四足机器人上测试跨实体泛化。
  • 语言导航：OmniVLA 成功率达 0.73，行为遵循（Behavior）0.65，显著优于 LeLaN（0.43/0.15）、CounterfactualVLA（0.33/0.45）和 CoW（0.30/0.05），在分布外（OOD）语言指令上表现突出。
  • 2D 位姿导航：OmniVLA 成功率达 0.95，部分进展 0.98，超越最强专家基线 MBRA-pose（0.86/0.92）9 个百分点。
  • 图像导航：OmniVLA 和 OmniVLA-edge 均实现 100% 成功率，与 MBRA-image 持平，优于 NoMaD（0.63）和 ViNT（0.50）。
  • 全模态组合任务：同时给定 2D 位姿（where）和 OOD 行为语言指令（how）时，OmniVLA 达到 0.80 成功率与 0.60 行为遵循率，而所有基线均无法同时处理两种模态。
  • 微调适应能力：仅用 1.2 小时新环境数据微调，卫星图像导航成功率从 0.57 提升至 0.83，2D 位姿从 0.81 提升至 0.86；融合 CounterfactualVLA 数据集后语言导航各项指标进一步提升（SR 0.725→0.825，Behavior 0.650→0.700）。
