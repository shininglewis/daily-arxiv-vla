Card 02 论文概述

论文概述

  • 论文研究 VLA（视觉-语言-动作）模型的强化学习微调，指出 GRPO 将轨迹级优势统一分配给整条 rollout 的所有动作块，导致失败轨迹中“错误动作”与其后的“恢复尝试”被同等惩罚。
  • 提出核心问题：When to stop penalizing actions?（何时应停止对动作施加负反馈），并用鞅（martingale）理论刻画“理想停止点”。
  • 目标是设计一种基于可见错误与恢复线索的事件引导式失败反馈截断方法 MART-GRPO，在保持 GRPO 原有优势估计期望的同时降低方差。
Card 03 核心贡献

核心贡献

  • 失败反馈的鞅分析：用成功概率鞅与策略得分鞅定义“剩余条件信用”（remaining conditional credit），证明在零剩余信用处截断可保持参考 GRPO 组梯度估计的期望，且不增大协方差（条件投影性质）。
  • 回溯边界的残差刻画：针对由完整 rollout 事后选择的边界，给出条件投影残差 $\eta_B$ 及其对期望偏移和总方差影响的界，并导出偏差-方差权衡的精确表达式。
  • 事件引导的截断方法 MART-GRPO：用 LoRA 微调并冻结的 VLM 定位“最后一次可见且未观察到恢复的错误”，将错误区间右端点作为边界 $B$，保留 $0..B$ 的失败反馈、屏蔽其后缀。
  • 保持原始训练语义：成功 rollout 的损失项、组内优势、原始 token 归一化 $N_i$ 均被保留，不引入额外截断校正权重。
  • 实证验证：在 RoboTwin 2.0 七个任务上相较 Full GRPO 提升平均成功率，并额外提供定位质量评估与反馈消融实验。
Card 04 方法描述

方法描述

  • 理论工具：在固定策略下构造 Doob 鞅 $P_k=\mathbb{E}[R\mid\mathcal{F}_k]$ 与累积得分鞅 $S_t=\sum Z_k$，配对增量得到策略梯度 $\nabla J=\sum_k \mathbb{E}[Z_k \Delta P_k]$。
  • 条件投影定理：若停止规则只看已观测前缀且剩余信用为零，则截断后的组梯度估计是完整估计在保留信息 $\mathcal{K}$ 下的条件投影，期望相同、协方差半正定减小。
  • 失败认证特例：当 $P_T=0$（失败已由历史确定）时必然零信用，这为“可见错误 + 无恢复”的启发式边界提供理论依据。
  • 回溯边界处理：定义 $\eta_B=\mathbb{E}[D_B\mid\mathcal{K}_B]$ 与 $\epsilon_B^2=\mathbb{E}\\|\eta_B\\|^2$，给出 $\\|\mathbb{E}[G_B]-\mathbb{E}[G]\\|^2\le\epsilon_B^2$ 与 $\Delta_V\ge V_D-2\sqrt{V_B\epsilon_B^2}$。
  • VLM 事件模型：输入任务指令、三路同步相机视角、本体感知与帧-块对齐信息；输出结构化字段（可见结果、错误类型、定位区间 $[\ell,u]$、恢复标志、支撑帧）。
  • 训练细节：冻结主干 + LoRA 适配器，按响应 token 平均的负对数似然训练；以验证集任务宏平均区间 IoU 选 checkpoint（update 304 / epoch 8），RL 阶段冻结。
  • 边界映射：通过校验的事件取 $B_i=u_i$；语义回退情形取 $B_i=K_i-1$（即完整保留反馈）；无效响应报错。
  • 策略优化：沿用 PPO 裁剪目标 $\mathcal{J}_w(\theta)$，掩码在每次更新中固定且不回传梯度，分母仍用原始 $N_i$。
Card 05 数据集与资源

数据集与资源

  • 策略评测基准：RoboTwin 2.0，七个操作任务（Hammer、Handover、Lift pot、Dual bottles、Container on Plate、Empty cup、Stack bowls）。
  • VLA 模型：OpenVLA-OFT（采用 SimpleVLA-RL 的 action-token 实现），各任务独立 SFT checkpoint 作为 RL 起点。
  • 事件标注语料：1,024 条带事件标注的失败 rollout 视频，辅以成功参考视频；训练/验证/测试按任务-场景身份不相交划分。
  • 定位评测集：220 条未恢复的测试失败样本。
  • VLM 主干：Qwen3.8-27B 视觉-语言模型（主干冻结，仅训练 LoRA 适配器）。
  • 训练资源：配备 8×H100 GPU 的服务器；每次更新 64 个接受组 × 每组 8 条 rollout，PPO minibatch 128；主评测点为 update 40。
  • 评测协议：贪心评估，每 5 次更新测 128 条训练种子（Seen）与 128 条留出种子（Held-out）回合。
Card 06 评估与结果

评估与结果

  • VLM 事件定位：任务宏平均区间 IoU 从基座 28.5% 提升至 epoch 3/6/8 的 50.9% / 67.8% / 72.1%；选定 checkpoint 达 68.1% 端点完全一致率、91.8% 一区块内一致率。
  • 七任务策略性能：update 40 时平均成功率由 Full GRPO 的 65.01% 提升至 68.64%（+3.63 点）；Seen +1.23 点、Held-out +6.03 点。
  • 单任务增益：六个任务提升，最大为 Handover +8.98、Hammer +7.03；Lift pot 仅 +0.39，Container on Plate 为 −1.95（该任务 Full GRPO 已达 93.75）。
  • 历史最佳均值：per-task best 由 66.02% 提升到 69.87%（+3.85 点）。
  • 消融实验：两任务消融显示事件引导截断优于“统一缩放惩罚”和“随机前缀”两种对照，支持边界选择而非单纯减弱负反馈是关键。
  • 理论-实验一致性：实验在裁剪 PPO 目标下评估，与定理的理想投影条件存在差距，作者以残差分析解释该偏离。
