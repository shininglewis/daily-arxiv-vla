Card 03 核心贡献

核心贡献

  • 动作角色分配（Action-role allocation）：在固定动作 token 预算下，形式化地定义稀疏参考链与稠密执行链，将监督跨度与执行前缀解耦。
  • 共享专家的联合生成（Shared-expert joint generation）：控制标签监督、物理时间对齐与有向跨链注意（A 可读 R，R 不可读 A）在同一动作专家内完成，且不新增动作参数、保留宿主可见性约束。
  • 双宿主实证验证：JAC 将 FastWAM 与 LeapBot-WA 在 LIBERO 上的成功率提升至 98.3%，在零样本 LIBERO-Plus 上分别提升 16.9 与 4.2 个百分点。
  • 系统性消融：基于 FastWAM 的三组消融分别刻画对访问方向、参考监督权重、参考时间跨度的敏感性。
  • 真实部署评估：在 RoboTwin 2.0 与两个真实世界任务上提供部署验证。
Card 04 方法描述

方法描述

  • 双链结构：稀疏参考链 R（16 个稀疏控制目标）与稠密执行链 A（16 个稠密控制目标）共享输入投影、Transformer 层、输出头与每一次动作前向计算。
  • 时间对齐：两条链在统一物理时间轴上对齐，位置向量为 p = [0,3,…,45; 0,1,…,15]；使用 RoPE 的宿主中，执行 token i 与参考 token j 的相对偏移为 3j−i。
  • 联合去噪：采用宿主原有的线性流匹配参数化，两链共享同一噪声水平 σ，但使用独立高斯噪声 ε_R、ε_A，仅在重叠时间点处区分噪声实现。
  • 有向可见性掩码：M_JAC = M_host ∧ M_role，其中角色矩阵为 [[1,0],[1,1]]，即 A 可读 R、R 不可直接读 A，且不改动宿主既有的注意力边。
  • 边界填充：超出回合的索引被裁剪至最后一个有效动作并以 P 标记，填充目标不参与直接监督但保持注意力可见。
  • 训练目标：L = E[ℓ_A + λ_R ℓ_R] + L_host,world，默认 λ_R = 0.2；重叠时间点在两种角色下均被监督；λ_R = 0 并不等价于基线，因为参考表示仍会接收执行损失的间接梯度。
  • 推理：两链从 σ=1 联合积分到 0，仅对 Â 做逆变换并执行前 K 个控制量；参考链不返回、不驱动机器人。
  • 超参数：预算 B = 32，n_R = n_A = 16，参考步长 s = 3，LIBERO/LIBERO-Plus 用 K = 10，RoboTwin 用 K = 16；数据加载窗口 T = 48。
Card 05 数据集与资源

数据集与资源

  • 数据集与基准：LIBERO（Spatial、Object、Goal、Long 四套件）、LIBERO-Plus（七类扰动、零样本评估）、RoboTwin 2.0（Clean/Random 双臂操作）、以及两个真实世界任务。

  • 训练资源：使用 8 张 NVIDIA H100 组成的系统进行训练与评估。
Card 06 评估与结果

评估与结果

  • 评估设置：LIBERO/LIBERO-Plus 用 K=10，RoboTwin 的 Base 与 JAC 均以 K=16 重新评估以对齐执行链长度；LIBERO-Plus 直接在 LIBERO 训练策略上零样本评估，无微调与测试时参数自适应。
  • 主要指标：平均成功率（%），括号内为相对各自复现基线的绝对百分点变化。
  • 核心结果：

- LIBERO：FastWAM 与 LeapBot-WA 从 97.0%、97.3% 提升至 98.3%。

- 零样本 LIBERO-Plus：FastWAM 从 53.5% 提升至 70.4%（+16.9 pp）；LeapBot-WA 从 73.1% 提升至 77.3%（+4.2 pp）。

- RoboTwin 2.0 与两个真实世界任务提供额外部署评估支撑。

  • 消融实验（LIBERO）：G1 跨链可见性、G2 参考监督权重、G3 参考步长，用于验证角色组织结构与超参数的影响。
  • 计算成本：在固定预算 B 下结构上保持参数量、每步 token 数与前向次数不变，但结构等价不等于运行时等价，论文在第 4.4 节单独讨论延迟与显存开销。
