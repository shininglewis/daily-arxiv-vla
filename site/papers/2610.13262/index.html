Card 03 核心贡献

核心贡献

  • 引入任务无关的 Gated DeltaNet（GDN）压缩器，以进度预测与动作条件特征重建为监督，将历史压缩为单个时间 token，同时编码执行上下文与可重建的视觉历史。
  • 将任务条件化的证据访问形式化为阈值检索（threshold retrieval），配合共享的时间与空间监督，使保留帧数量随可用证据自适应变化。
  • 提出线性多尺度融合（linear multi-scale fusion），在每帧16 个 token 的固定预算内融合粗粒度上下文与细粒度空间细节。
  • 设计两阶段训练流程：Stage 1 预训练时间压缩器，Stage 2 冻结 GDN 并联合优化检索器与策略学习。
  • 在 RoboMME 全部 16 个任务与4 个真机任务上取得一致提升，并揭示了杯互换（cup swap）场景下持续性身份跟踪仍为未解难题。
Card 04 方法描述

方法描述

  • 双流记忆结构：时间流对步长为 3 的前视图历史做递归压缩，空间流选择并编码任务相关帧；两流均为因果（causal），策略同时接收当前相机观测、本体感知与指令。
  • 递归执行上下文：DINOv3 的 class token 投影至宽度 512，经 6 层 GDN 输出 c_t ∈ R^512；进度头用 SmoothL1（β=0.1）预测归一化执行进度；辅助 Retrospector（4 层因果 Transformer，最多 16 个动作）结合逆序动作重建过去特征。
  • 压缩目标函数：L_C = L_progress + L_feat + 0.25·L_anchor + 0.09·L_SIGReg，其中 SIGReg 通过匹配随机投影到标准高斯防止表征坍塌，anchor loss 保持在线特征贴近冻结目标。
  • 任务条件阈值检索：冻结 SigLIP（So400m/14） 在 16×16 网格上产生 N=256 个 patch token；用冻结 MiniLM 编码任务目标，计算 patch 分数与 log-sum-exp（LSE）帧 logits；推理时保留 ℓ_i > 0.6 的帧，保留帧数 m_t 不固定、按时间顺序排列。
  • 监督信号：空间目标为归一化实例掩码占用率池化到 patch 网格，时间目标在关键帧 ±2 帧与前三执行帧上赋予均匀质量，使用交叉熵 L_R = L_patch + L_interval。
  • 线性多尺度融合：将 16×16 特征均值池化为 8×8、4×4、2×2 对齐网格，保留 16 个 base slot，与 4 个 fine child 和 1 个 coarse parent 组合；投影初始化令 P_4 为单位阵、其余为零以恢复基表示；每帧产出 16 个 1024 维策略 token。
  • 策略集成：基于 RoboMME 的 π0.5 栈（Gemma 前缀 + 流匹配动作专家），动作专家隐状态通过 cross-attention 读取空间记忆库 M_patch 与时间 token M_temp，门控 g_l = σ(α_l) 初始化为 0.01。
  • 训练流程：Stage 1 用 L_C 预训练时间压缩器（更新 GDN 与 DINOv3 最后两个 block）；Stage 2 冻结 GDN 与 SigLIP/MiniLM，用 L_action + L_R 训练检索器与 π0.5 策略。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboMME 仿真基准（16 任务）+ Piper 真机平台（4 任务）；每任务每评估种子 50 个 episode，评估种子为 {0, 7, 42}；真机每任务 30 次 rollout 且初始状态匹配。
  • 主要指标：任务成功率 TSR（Task Success Rate, %）；另用 Temporal/Spatial Hit@1 与 Average Precision（AP）评估检索定位，用 MSE 评估进度读出。
  • RoboMME 完整基准：完整模型平均 TSR 49.22%，优于 FrameSamp+Modul 44.51%、NativeMEM 20.54%、无记忆 π0.5 17.93%；14 个任务与全部 4 个 suite 均值均有提升（Reference 增益最大 +8.98 pp，Counting +5.61 pp）。
  • 组件对比（Table I）：GDN 在 Counting 提升 +6.94 pp（StopCube 最高 +15.33 pp）；阈值检索在 Permanence 提升 +4.22 pp（ButtonUnmaskSwap +7.11 pp）；线性多尺度融合在 Reference 提升 +4.50 pp（VideoPlaceOrder +12.00 pp）。
  • 检索定位性能：Temporal Hit@1 96.88%、Spatial Hit@1 95.00%，AP 分别为 96.53% 与 92.24%。
  • 进度读出：进度头在 46,800 帧上 MSE 为 0.03430。
  • 真机评估（Table III）：完整模型平均 TSR 62.5%，相对 FrameSamp+Modul（37.5%）提升 25.0 pp；Pick×3 达 80.0%（24/30）、Swing×2 达 93.3%（28/30）；RePick 仅 36.7%（11/30），Shell 从 53.3% 下降至 40.0%。
  • 局限与失败模式：增益非可加（Counting 与 Permanence 低于对应的单组件变体，VideoUnmaskSwap −1.44 pp、PatternLock −1.56 pp）；杯互换场景暴露持续性身份跟踪为尚未解决的需求，作者建议下一步将受限检索与跨帧显式身份传播相结合。
