ChunkAct: Action Chunking for Agentic Robotics

2026-10-13 · 原文 · 翻译 · 2610.18874

论文提出 ChunkAct，将动作分块（action chunking）引入 agentic robotics，让 LLM planner 每次调用提交一个链式感知与控制原语组成的动作块，而不是单个原语。 现有 agentic robotics 方法在每个原语执行前都需要一次 LLM 推理，导致调用次数、输入 token 和输出 token 随 episode 长度快速增长，效率低且成本高。 论文发现子目标确定后，后续原语通常由记忆中的固定流程决定，因此可离线将记忆编译为可复用动作块，测试时无需读取记忆，LLM 只负责真正需要推理的决策和失败恢复。

Card 02 论文概述

论文概述

  • 论文提出 ChunkAct，将动作分块（action chunking）引入 agentic robotics，让 LLM planner 每次调用提交一个链式感知与控制原语组成的动作块，而不是单个原语。

Card 03 核心贡献

核心贡献

  • 提出 ChunkAct，据作者所知是首个让 LLM agent 在机器人操作中每次调用承诺一个链式感知与控制原语动作块的方法。
  • 设计离线动作块构建机制，将记忆编译为可泛化的可执行动作块，使测试时执行不依赖显式记忆检索。
  • 设计在线动作块触发机制，动作块自主执行，仅在失败时通过类型化退出将控制权交还 planner。
  • 在 LIBERO-Pro 上相比此前 SOTA agentic robotics 方法 Harness VLA 提升 5.0 个点任务成功率，同时减少 2.9× LLM 调用、4.4× 输入 token、2.3× 输出 token。
  • 在 LIBERO-Plus 上展示零样本迁移能力，整体成功率超过此前最强方法 11.0 个点，并在 7 个扰动维度中的 6 个领先。
Card 04 方法描述

方法描述

  • 将 agentic loop 形式化为 LLM planner 在上下文 \(c_t\) 上选择原语 \(p_t\) 及参数 \(\theta_t\)，并执行后追加结果 \(y_t\)，分析其调用次数和输入 token 随步数增长的问题。
  • 离线动作块构建：按任务类别划分子目标类型，将记忆中的流程知识、原语分工、参数化规则、失败回退策略和验证标准编译为统一动作块。
  • 编译时丢弃不可在部署时观测的坐标和特权模拟器状态，几何量改为从当前场景实时感知估计，使动作块可迁移到不同布局。
  • 在线动作块触发：planner 通过单次工具调用启动动作块，动作块按阶段顺序自主执行，阶段间进行验证，成功则继续，失败则返回类型化退出。
  • 类型化退出：失败时返回失败阶段、错误码、错误日志、机器人状态和新观测，planner 据此重新感知并选择重新 grounding、重做子目标或回退到原语。
  • 最终 planner 的角色从逐步执行者转变为子目标选择者和失败恢复者，LLM 计算量随决策数而非原语数增长。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率 TSR、planner 调用次数、输入 token 数、输出 token 数。
  • 主要对比基线：OpenVLA、π_0、π_0.5、MolmoAct、NORA、X-VLA、AtomVLA、π_RLinf、CaP-X、Harness VLA 等。
  • LIBERO-Pro 上 ChunkAct 总体成功率 83.8%，比 Harness VLA 的 78.8% 高 5.0 个点；同时 LLM 调用从 24.2 降至 8.3（2.9× 更少），输入 token 从 2.2M 降至 0.5M（4.4× 更少），输出 token 从 8.5k 降至 3.7k（2.3× 更少）。
  • 关闭 reasoning 后，ChunkAct 仍保持 80.0% TSR，而 Harness VLA 降至 56.0%，表明 ChunkAct 对 planner 推理强度依赖更低。
  • 无 LLM planner 的脚本驱动下动作块单独达到 57.5% TSR，说明 planner 主要通过失败恢复贡献剩余成功率。
  • LIBERO-Plus 零样本迁移中，ChunkAct 总体成功率 83.9%，超过此前最强方法 11.0 个点，并在 camera、robot、language、light、noise、layout 等六个维度领先。
