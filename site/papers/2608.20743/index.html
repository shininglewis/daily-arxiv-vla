Card 03 核心贡献

核心贡献

  • 提出 L0–L2 草拟侧并行度分类体系：L0 为每步推进一个未来 token 的顺序草拟；L1 为从共享前缀并行预测多个预定义未来位置；L2 将未来块视为联合生成/精炼的整体（如 DFlash、DSpark），候选宽度与草拟深度是正交维度。
  • 系统综述多模态推测解码全景：覆盖 VLM、视频语言模型、VLA、语音/音频模型和自回归视觉生成五大应用域，从草拟器设计、条件访问、候选形式、接受语义和运行时自适应等维度归纳表格式对比。
  • 首次实证诊断多模态 L2 就绪度：通过跨模型、跨任务的受控实验，发现直接将在 Qwen3 上训练的 L2 草拟器迁移至多模态模型时 draft-target 一致性有限，而更新颖的多模态变体上相同范式显著更对齐，说明多模态本身不是根本障碍。
  • 揭示多模态条件瓶颈：分析视觉信息对 draft-target 一致性和端到端效率的影响，发现多模态 prefill（而非块草拟本身）制约端到端加速，接受率对上下文移除具有鲁棒性。
  • 给出 L2 就绪性刻画与未来方向：从模型兼容性、多模态条件、任务/输入依赖性、系统生态支持四个维度总结就绪条件，并提出轻量多模态条件注入、依赖建模、动态并行级别、树感知并行草拟训练、多模态验证与标准化评估等挑战与机遇。
Card 04 方法描述

方法描述

  • 提出以草拟侧并行度为核心的 L0–L2 统一分类法，将候选组织形式（树构建、验证策略等）与草拟并行性解耦，强调"候选宽度与草拟深度正交"。
  • 通过跨架构实证研究，将现有文本 L2 方法（如 DFlash、DSpark 为代表的扩散式块并行草拟）迁移到多模态目标模型，考察其在不同模型规模与架构下的表现。
  • 分析视觉条件注入方式（直接视觉输入、复用目标特征、压缩/剪枝视觉 token 等）对草拟质量与端到端延迟的权衡，并评估多模态 prefill、块草拟、接受率之间的瓶颈关系。
  • 从训练/推理框架支持角度检查现有系统对 L2 块并行草拟的适配程度，综合判断 L2 就绪性条件。

Card 06 评估与结果

评估与结果

  • 评估以 draft-target 一致性、接受率（acceptance rate）和端到端加速比为核心指标，对比 L0/L1/L2 不同并行度下的表现。
  • 关键发现一：直接将 L2 草拟器从 Qwen3 迁移到较旧多模态模型时，draft-target 一致性有限；而相同的块并行草拟范式在新颖多模态变体上取得显著更强的对齐，表明多模态信息如何表示/对齐比模态本身更关键。
  • 关键发现二：多模态 prefill 阶段（而非块草拟阶段）成为端到端加速的瓶颈，意味着仅优化草拟并行度不足以实现实际加速。
  • 关键发现三：接受率对上下文移除（context removal）具有鲁棒性，提示在某些条件下可以降低多模态条件注入开销而不损失草拟质量。
  • 总体结论：多模态推测解码对 L2 的"就绪度"取决于模型兼容性、多模态条件设计、任务/输入条件以及系统生态支持，现有方法尚未完全满足广泛部署的要求，需要在轻量条件注入、依赖建模、动态并行控制、树感知训练和标准化评估等方面继续推进。
