论文概述

  • 论文提出 LaST0.5，一种面向机器人操作的通用世界动作模型（World Action Model, WAM），旨在弥合“世界建模”与“动作生成”之间的表征错配问题。

Card 03 核心贡献

核心贡献

  • 提出 Interaction-Centric Latent Reasoning (ICLR) 框架，在世界模型与动作生成之间引入交互中心的物理抽象表征，缓解全局场景表征对局部操作交互的忽视。
  • 设计 Adaptive World-to-Action Transfer (AWAT) 机制，联合预测未来表征与其进度值（progress value），利用进度一致性动态调整动作执行长度并触发未来重采样。
  • 构建 World Expert / Latent Expert / Action Expert 三专家 Mixture-of-Transformers (MoT) 架构，并以 blockwise-causal 注意力显式实现层级化的 video → latent → action 推理。
  • 在超过 14k 小时 的异构机器人数据上完成大规模预训练，验证交互中心物理推理范式的可扩展性。
  • 在 LIBERO（99.5%） 与 10 项 RLBench 任务（88.0%） 上取得 SOTA，并在真实双臂平台上展现长程执行与精细操作能力。
Card 04 方法描述

方法描述

  • World Expert：基于 Cosmos-Predict2.5-2B 扩散 Transformer，输入 5 帧历史主视角（256×256）与语言指令（cross-attention 注入），去噪生成 12 帧未来视频并划分为 M 个时间对齐片段。
  • Latent Expert：由 Janus 初始化，用少量可学习 query token 在单次并行前向中提取紧凑的交互中心表征 Z，并以余弦相似度对齐潜目标。
  • 潜目标构建：对每个未来片段的末帧叠加两类视觉交互线索——投影到图像平面的 2D 末端执行器运动曲线 与 目标物体 affordance 边界框（由 Grounding DINO 生成并经 TCP 空间匹配筛选），再经冻结的 SigLIP 视觉塔与可训练 MLP 聚合为 1×d_v token。
  • Action Expert：与 Latent Expert 共享语言骨干但参数独立，用 flow matching 目标生成动作块；采用两组噪声 token 与 MLP 头分别预测手腕运动与执行器指令，缺失维度零填充以支持异构本体。
  • 关键技术点：blockwise-causal 注意力掩码限制跨专家注意力只访问对应及之前的片段；对 World Expert 的 key/value 做 detach，保护预训练物理先验；总损失为 L = λ₁L_world + λ₂L_lat + λ₃L_act。
  • AWAT：冻结主干后接轻量 MLP 价值头，对去噪后的未来帧特征池化预测各片段进度值（监督目标为 t_i/T），并通过时间反转/重复帧增广提升对停滞与回退的鲁棒性；当进度值不再上升时截断执行并重新推理，若初始值低于上一周期则并行采样多个未来并选最高分者。
Card 05 数据集与资源

数据集与资源

  • 预训练语料：超过 14k 小时 的异构机器人数据，涵盖遥操作演示、UMI 类手持夹爪野外数据、人类第一视角数据等（含 OXE / DROID / AgiBot World 等公开数据源）。
  • 仿真基准：RLBench（10 项任务，每任务 100 条演示）、LIBERO（Spatial / Object / Goal / Long 四个官方套件）。
  • 真实数据：天玑 Tianji Marvin 双臂平台，PICO VR 遥操作采集，4 项任务各 150 条 轨迹。
  • 模型规模：World Expert 采用 2B 参数的 Cosmos-Predict2.5-2B；Latent / Action Expert 基于语言骨干初始化。
  • 训练资源：8× NVIDIA H20 GPU，AdamW 优化器；LIBERO 训练 100 epoch，RLBench 训练 300 epoch。
Card 06 评估与结果

评估与结果

  • 评估环境：RLBench（CoppeliaSim + Franka Panda，3 次独立运行、每任务 60 rollouts）、LIBERO 四套件、真实双臂四任务（每任务 20 rollouts）。
  • 主要指标：任务成功率（Success Rate），真实任务另报告分阶段成功率与 OOD 泛化成功率。
  • LIBERO：平均 99.5%（Spatial 99.7 / Object 100.0 / Goal 99.1 / Long 99.3），优于 OpenVLA-OFT（97.1）、π0.5（96.9）、InternVLA（98.9）、Cosmos Policy（98.5）、LaST0（98.1）。
  • RLBench：平均 88.0%，显著超过 OpenVLA-OFT（45.0）、π0.5（65.0）、HybridVLA（74.0）、Cosmos Policy（77.0）、Fast-WAM（63.0）与 LaST0（82.0）；去除 AWAT 的版本为 85.0%。
  • 消融：去掉 World Expert 降至 96.0%，去掉 Latent Expert 降至 97.8%；去掉运动与 affordance 线索降至 98.6%；AWAT 时间粒度以每 4 步一个进度值最优（99.7%）。
  • 真实世界：平均成功率 63.8%，优于 π0.5（52.5%）、Cosmos Policy（43.8%）与 LaST0（43.8%）；螺丝装配插入阶段 50.0% vs 30.0%，包裹封箱阶段 30.0% vs 20.0%。
  • 泛化：物体位置偏移下平均 40.0%（π0.5 为 15.0%、Cosmos 为 17.5%）；背景偏移下平均 72.5%，Object Organization 达 90.0%。
