论文概述

  • 论文研究主动视觉操作中的 evidence-aware retain–acquire 问题：相机运动决定有限观测窗口内哪些任务证据被保留，获取新视角可能丢失已有任务关键线索。

Card 03 核心贡献

核心贡献

  • 将主动视觉操作形式化为 evidence-aware retain–acquire 行为，并提出 Task-Guided History Inversion，在有限历史窗口内保留任务证据和可见时序变化，并将训练信号迁移到 raw-input policy。
  • 提出 ActiveWAM，从 view-aware history 生成可执行 head–arm actions，包括 stay 和 reacquisition 行为；未来视频预测仅作为 co-training signal，部署时无需解码未来视频。
  • 引入 RoboTwin-AV，一个 50 任务的主动视觉基准扩展，具有可执行 pan/tilt 控制、同步 RGB 和自动生成 demonstrations。
  • 在 TAVIS、RoboTwin-AV 和物理双臂厨房任务上验证 retain–acquire 耦合，报告相对最强基线最多 17.0 个百分点（TAVIS OOD）、20.0 个百分点（RoboTwin-AV compound）和 26.7 个百分点（真实厨房）的提升。
Card 04 方法描述

方法描述

  • 物理设置：固定底座双臂机器人，单个 RGB 相机安装在两自由度 pan/tilt 头部，固定焦距；动作空间为 16 维：左右臂各 6 个位姿增量 + 1 个夹爪命令，再加 2 维头部增量；零头部运动为有效的 stay 动作。
  • 统一生成建模：学习条件分布 \(p_{\theta}(Y_{t+1:t+K}, A_{t:t+H_a-1}\mid C_t)\)，条件 \(C_t=(\ell,\mathcal{H}_t,s_t,p_{\leq t},\kappa,\delta_{\leq t})\) 包括语言指令、多相机 RGB 历史、机器人状态、测量相机位姿、标定和帧获取元数据。
  • Training-Time Inversion（TTI）：用冻结的 Wan T2V 视频先验处理每路相机历史；从语言指令中选取 task-bearing spans，利用冻结 cross-attention 权重构造 task preservation 损失 \(L_{\rm pres}\)，用互最近邻特征匹配构造 dynamics preservation 损失 \(L_{\rm dyn}\)，再做 8 步 guided partial inverse。
  • View-aware history adapter：为视觉 token 加入相机身份、测量位姿、相对曝光时间和有效性标志，经时间重采样器聚合成固定尺寸历史摘要 \(B_t\)；当前 RGB 保留细粒度路径用于接触检测。
  • 统一 head–arm 生成：头动作和臂动作在同一个 world–action 模型中生成，头坐标加入原生动作向量；未来视频 token 与动作 token 在联合去噪中交互，动作生成不需要测试时未来视频解码。
  • Paired learning：raw 和 transformed 条件共享相同原始未来/动作目标，并用 \(L_{\rm pair}\) 对齐动作速度；部署用 raw-history inference，执行短前缀后从新测量 RGB 更新上下文，无需在线反演、候选排序或信息增益计算。

Card 06 评估与结果

评估与结果

  • 评估环境和基准：TAVIS（Head/GR1T2、Head/Reachy2、Hands/GR1T2、Hands/Reachy2；ID/S/P 分布条件），RoboTwin-AV（Clean/App./Pose/Both），以及真实物理厨房任务。
  • 主要评估指标：任务成功率 SR（%）、物体–目标共视率 Co-vis.、头部移动行程 travel（rad/episode），以及 OOD 条件（空间 OOD、初始位姿 OOD、复合偏移）下的成功率。
  • TAVIS 关键结果：ActiveWAM 在 Head/GR1T2 上达到 ID 63.7、S 47.0、P 24.7；Head/Reachy2 上 ID 52.7、S 44.0、P 31.3；Hands/GR1T2 上 ID 75.7、S 64.0、P 36.3；Hands/Reachy2 上 ID 79.7、S 63.3、P 54.7；相对最强基线 OOD 成功率最高提升 17.0 个百分点。
  • RoboTwin-AV 关键结果：ActiveWAM 取得 Clean 80.3、App. 60.7、Pose 65.0、Both 53.3；比 Fast-WAM 在 compound 条件（Both）高 20.0 个百分点（53.3 vs 33.3）。
  • 真实机器人结果：物理厨房任务上比 Fast-WAM 高 26.7 个百分点。
  • 消融与控制实验：完整模型 Clean 80.3/Compound 53.3；去掉 history 为 73.7/34.0；去掉 inversion 为 76.7/41.7；去掉 task preservation 为 78.7/41.0；去掉 dynamic preservation 为 82.0/44.7；去掉 pair consistency 为 81.0/44.7；联合学习头控制优于 Locked、Object tracking 和 Relation look-at + stay，达到 Clean 80.3、Pose 65.0、Co-vis. 87.7。
