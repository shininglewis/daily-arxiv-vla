SimWAM: A Simple World Action Model for End-to-End Autonomous Driving

2026-08-07 · 原文 · 翻译 · 2608.07468

Card 03 核心贡献

核心贡献

  • 提出仅将视频生成作为训练信号的 WAM 范式：SimWAM 通过训练时的视频联合建模将交通动态先验迁移到动作专家，推理时无需未来场景生成或辅助运动模块。
  • 设计隔离注意力掩码：动作 token 与未来帧 token 互不可见，仅共享当前观测表示，使视频分支可在训练后被安全移除，实现高效推理并支持独立强化学习。
  • 引入 Flow-GRPO 强化学习：将确定性流 ODE 重构为保持边缘分布的 SDE，用组合式驾驶奖励对动作专家进行直接优化，仅更新 LoRA 适配器以保持已蒸馏的运动先验。
  • 架构高度解耦：视频专家与动作专家无共享参数、仅通过统一注意力接口交互，支持视频生成器可替换与动作专家独立缩放，无需修改学习目标或推理管线。
  • 在 NAVSIM 上以单前视相机达到 91.5 PDMS，显著超越 SGDrive、ExploreVLA、DriveLaW、DriveWAM 等 SOTA 规划器，并实现远低于世界模型规划器的推理延迟；代码与权重已开源。
Card 04 方法描述

方法描述

  • 问题建模：给定前视相机观测 $o_t$、自车状态 $s_t$ 与导航指令 $l$，直接预测 $H$ 步自车轨迹 $a_{t+1:t+H}$（每个航点含位置与航向），采用 $p(a_{t+1:t+H}\|z(o_t),s_t,l)$ 的直接策略接口，而非先生成未来潜变量再规划。
  • 视频专家（Video Expert）：基于 Wan2.2-5B 视频扩散 Transformer（DiT）初始化，配合视频 VAE 与 T5 文本编码器；VAE 将帧映射为潜 token，导航指令经 T5 交叉注意力注入，当前帧作为干净条件，未来 8 帧通过流匹配去噪重建。
  • 动作专家（Action Expert）：轻量扩散 Transformer，隐藏维度 $d_a=1024$，以观测表示、自车状态与导航指令为条件，通过流匹配预测轨迹速度场，小 MLP 嵌入自车状态；推理时仅保留该专家并丢弃视频 DiT。
  • 联合训练：两个专家仅通过共享注意力交互，联合目标为 $\mathcal{L}=\mathcal{L}_{\text{FM}}^{\text{act}}+\lambda\mathcal{L}_{\text{FM}}^{\text{vid}}$，其中 $\lambda=1$，未来场景预测可塑造用于规划的观测表示。
  • 隔离注意力掩码：当前观测 token、未来帧 token 与动作 token 组成的共享注意力流中，未来帧和动作 token 均关注当前观测但彼此不可见，使动作专家从共享表示学习而不依赖未来帧。
  • 强化学习：将确定性流 ODE 替换为保持边缘分布的 SDE（$\sigma_\tau=a\sqrt{\tau/(1-\tau)}$），每场景采样 $G=8$ 条候选轨迹，用 NAVSIM PDM 奖励计算组内相对优势并做裁剪策略更新；仅更新注意力投影上秩 32、$\alpha=16$ 的 LoRA 适配器，聚焦模仿学习后 PDMS 低于 90 的困难 navtrain 场景。
Card 05 数据集与资源

数据集与资源

  • NAVSIM 基准（基于 nuPlan OpenScene）：训练集 navtrain 含 103,288 个场景，测试集 navtest 含 12,146 个场景；SimWAM 仅使用单目前视相机，分辨率 384×672。
  • nuScenes 数据集：用于零样本跨域迁移验证，无需微调。
  • 动作专家预测 8 个航点（4 秒、2 Hz），视频专家预测对应的 8 帧未来帧。
  • 视频专家参数量约 5B（Wan2.2-5B），动作专家参数量 1.02B；消融中还测试了 LTX-Video、Wan2.1-1.3B、Cosmos-Predict2.5 等视频主干及 0.21B、0.45B 的小型动作专家。
  • 训练优化器为 AdamW，余弦学习率调度，初始学习率 $10^{-4}$，联合训练 100 个 epoch；RL 阶段学习率 $5\times10^{-5}$。
Card 06 评估与结果

评估与结果

  • 基准与指标：NAVSIM navtest 上的 PDMS（Predictive Driver Model Score），由 NC（无碰撞）、DAC（可行驶区域合规）两个惩罚因子与 EP（自车进度）、TTC（碰撞时间）、C（舒适性）加权质量项组成。
  • 主结果：SimWAM 以单相机达到 91.5 PDMS，超越最强 VLM 规划器 SGDrive（91.1）0.4 分、ExploreVLA（90.4）1.1 分；超越世界模型规划器 DriveLaW（89.1）2.4 分、DriveWAM（90.1）1.4 分，同时 DAC 与 EP 指标最优，推理延迟显著低于世界模型基线。
  • 组件分析：动作专家单独训练为 86.6 PDMS；联合视频训练提升至 90.3（NC 98.7、DAC 98.0）；再加入 RL 后达到 91.5，视频协同训练与 RL 合计带来 4.9 分提升，验证了两阶段设计的互补性。
  • 注意力掩码消融：与双向注意力（90.2）和 action→video 单向注意力（90.1）相比，隔离掩码取得最佳 PDMS（90.3），且允许推理时丢弃视频分支；进一步说明动作分支暴露于视频 token 在本设置中无额外收益。
  • 视频主干灵活性：LTX-Video 为 88.7 PDMS，Wan2.1-1.3B 为 90.2，Wan2.2-5B 为 90.3，而经驾驶视频预训练的 Cosmos-Predict2.5 取得最佳 90.4 PDMS（EP 84.2、TTC 96.0），表明更强大的驾驶相关视频先验可直接提升规划性能。
  • 动作专家缩放：0.21B、0.45B、1.02B 动作 DiT 的 PDMS 分别为 89.9、90.1、90.3，容量可独立扩展且不影响视频专家或训练目标。
  • RL 训练动态：在困难子集（PDMS<90）上训练始终优于在全部 navtrain 场景上训练，强化学习对模仿学习困难场景的针对性优化更有效。
