Card 02 论文概述

论文概述

  • 论文提出 Latent-WAM++，这是一个以表示（representation）为核心的世界行动模型（World Action Model, WAM），用于端到端自动驾驶规划。
  • 现有 WAM 大多只监督未来状态或最终动作，导致连接预测与规划的中间世界表示与动作表示只受到间接约束，表示学习效率低、规划性能次优。
  • 核心研究问题是：如何联合塑造世界表示与动作表示，使二者更好地支撑基于 WAM 的驾驶规划。
Card 03 核心贡献

核心贡献

  • 将 WAM 规划中的联合表示塑形形式化为：与角色匹配的表示目标 + 视觉-动作接口的显式正则化，并遵循“每种中间表示的监督方式应匹配其在规划中的角色”这一统一原则。
  • 提出 Latent-WAM++，构建可预测、非退化且几何感知的世界表示，通过一步多模态生成产生轨迹预测性动作特征，并以非对称方式与视觉语义对齐。
  • 提出 WoRC（World Representation Construction）：结合场景-自车未来预测、SIGReg 分布稳定化与冻结几何先验，无需 EMA 目标编码器即可避免表示坍缩。
  • 在 NAVSIM v2 与零样本 HUGSIM 上取得state-of-the-art，同时将规划器端到端训练成本降低 88.1%（190 vs. 1,600 GPU-hours）。
Card 04 方法描述

方法描述

  • WoRC 世界表示构建：用 DINOv2 编码器加可学习查询做多视角场景编码；引入冻结 WorldMirror 教师做 patch 级几何蒸馏（余弦损失）；冻结占据提取器生成占据 token，经跨注意力注入当前帧视觉 token；世界表示由自车 token、视觉 token、占据 token 拼接而成。
  • 动态世界模型（DWM）：带 3D 旋转位置编码与逐帧 teacher-forcing 掩码的 Transformer 解码器，预测未来场景-自车隐变量，损失含隐变量 MSE 与自车状态（命令分类、速度、加速度）监督。
  • 特征分布稳定化：对每个视觉 token 身份跨场景施加 SIGReg，用经验特征函数匹配标准高斯，替代 EMA 目标编码器，防止低方差坍缩。
  • TrajMF 轨迹 MeanFlow 规划器：以可学习动作查询从世界表示提取规划条件，直接在轨迹空间做条件流匹配；预测干净轨迹并转换为诱导速度，用 JVP 求方向导数，形成 Improved MeanFlow 速度空间目标，实现一步采样多模态轨迹提案，再由 refiner 聚合。
  • VARA 视觉-动作表示对齐：将提案特征投影平均得动作表示，与停止梯度的当前视觉 token 均值做余弦对齐，采用非对称梯度设计，仅正则化动作表示而不回传视觉侧梯度。
  • 推理阶段仅使用模态编码器与 TrajMF，输入仅为相机图像与自车状态，无需额外传感器。

Card 06 评估与结果

评估与结果

  • NAVSIM v2：EPDMS 90.1，超过 Latent-WAM 的 89.3 与 MeanFuser 的 89.5，为当前最优；分项为 NC 98.5、DAC 97.5、DDC 99.7、TLC 99.8、EP 87.8、TTC 98.3、LK 97.7、HC 98.3、EC 89.0。
  • HUGSIM 零样本闭环：平均 RC 47.0、平均 HD-Score 30.1，均优于 Latent-WAM（45.9 / 28.9）等此前方法。
  • 效率：端到端训练成本 190 GPU-hours，相对 Latent-WAM 降低 88.1%，同时 EPDMS 提升 0.8。
  • 消融：逐步加入 DWM、EMA（88.6）、SIGReg 等模块验证各组件增益；EMA 需 +86.6M 参数，而 SIGReg 在更小代价下取得更好稳定化效果。
  • 表示分析：SIGReg 使视觉 token 跨场景标准差最大、同 token 余弦相似度最低（分布最不退化）；VARA 使动作表示按 DINOv2 语义聚类更清晰；轨迹可视化显示本文方法比 World4Drive 与 Latent-WAM 更贴合人类驾驶参考轨迹。
