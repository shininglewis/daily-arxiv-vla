Card 03 核心贡献

核心贡献

  • 提出双分支视觉编码结构：原始视觉通路完全冻结以保留通用视觉-语义知识，并行的 LoRA 适配分支专门学习空间表征，避免单一通路同时承担两类相互竞争的需求。
  • 提出空间表征蒸馏：用冻结的 3D 专家（VGGT）通过注意力响应蒸馏（共享同一 query，替换为专家的 key/value）教会适配分支"如何注意"，而非直接模仿输出特征，从而保持与原 Transformer 结构兼容。
  • 提出轻量动作驱动知识路由器：以语言指令为条件，为通用 token 与空间 token 联合打分，决定每个空间位置由哪种知识表征、或两者共同表征。
  • 提出基于梯度的门控监督：以动作损失对门控概率的梯度（负梯度取 ReLU）作为 token 重要性，并配合动量滑动平均与 focal BCE、预算正则、熵正则，无需人工 token 级标注。
  • 在 0.5B 语言骨干、仅约 53M 可训练参数下，于 LIBERO、LIBERO-Plus、CALVIN 与真实机器人操作上达到与远超其规模的 VLA 相当甚至更优的性能。
Card 04 方法描述

方法描述

  • 骨干构建：基于 OpenVLA-OFT 实现，采用 Prismatic VLM + Qwen2.5-0.5B 语言骨干，视觉编码器仅用 DINOv2（不含 SigLIP）。
  • 双分支编码：给定 RGB 观测，同时输出冻结通路的 $Z_v$ 与 LoRA 适配通路的 $Z_p$。
  • 注意力响应蒸馏：在第 $l$ 层用同一 query 分别与视觉分支、3D 教师的 key/value 计算注意力响应，以 $\ell_1$ 损失对齐，逐层累加。
  • 路由器结构：线性投影对齐文本嵌入维度 → 跨注意力建模视觉-文本相关性 → 轻量 MLP（Linear-GeLU-Linear）→ Sigmoid 得到门控概率，含温度参数 $\tau$。
  • Token 选择与融合：按 top-$k$（$k=\max(k_{\min},\mathrm{round}(\rho N))$）选取；同一空间位置上两者均选中则拼接投影，仅一个选中则与零向量拼接后投影，均未选中则丢弃，从而保持位置对齐与统一输入格式。
  • 训练目标：总损失为动作损失 $\ell_1$、蒸馏损失与路由损失的加权和 $L_{\text{spark}}=L_{\text{act}}+\lambda_{\text{attn}}L_{\text{attn}}+\lambda_{\text{router}}L_{\text{router}}$。
  • 推理效率：3D 专家仅在训练期使用，推理时被丢弃，不引入额外 3D 传感或专家开销。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四套件平均成功率（SR）、LIBERO-Plus 七类扰动下的成功率与总平均、CALVIN ABCD→D 的连续完成任务数与平均长度，以及真实机器人操作成功率与样本效率。
  • 主要指标：成功率 SR (%)、CALVIN 平均完成长度 Avg. Len、可训练参数量与 LLM 规模。
  • LIBERO 结果：平均 98.5%（Spatial 99.6、Object 99.6、Goal 98.0、Long 96.6），在 tiny-scale（<1B）模型中取得最优，与 7B 级 Spatial Forcing（98.5）、OpenVLA-OFT（97.1）持平或略优，且可训练参数仅为其约 1/5。
  • LIBERO-Plus 零样本结果：总平均 78.6%，在 Light（94.6）、Background（95.9）、Noise（89.6）、Layout（78.8）四项取得最优，显著优于 VLA-Adapter（59.0）、π₀（53.6）、NORA（39.0）等小模型；在 Camera（68.5）与 Robot（59.8）上与最强基线 VLANeXt（71.6 / 63.4）仍有差距。
