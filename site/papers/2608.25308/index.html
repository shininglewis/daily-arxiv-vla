V-Link: Recovering Lost Visual Representations in Action DiT for Vision-Language-Action Models

2026-08-26 · 原文 · 翻译 · 2608.25308

论文针对双系统视觉-语言-动作（VLA）模型中一个被忽视的问题：在从视觉-语言模型（VLM）到动作专家（Action DiT）的特征传递过程中，Action DiT 对 VLM 特征中蕴含的 3D 几何信息 和 2D 语义信息 的可访问性严重不足，削弱了精细操作所需的感知基础。 通过诊断实验（冻结特征并训练轻量级深度估计与语义分割头）发现，GR00T N1.6 的 Action DiT 特征相比 VLM 特征存在明显的视觉表示可访问性鸿沟，例如深度 MAE 从 0.015 恶化到 0.071，分割 mIoU 从 0.665 下降到 0.290。 为此提出 V-Link，一种显式的表示恢复框架：在 VLM 内部学习互补的 空间查询（Spatial Queries） 和 语义查询（Semantic Queries），并通过非对称路径注入 Action DiT，以恢复动作生成过程中缺失的视觉表示。

Card 03 核心贡献

核心贡献

  • 揭示瓶颈：首次指出双系统 VLA 中最终层 VL-to-A 特征传递导致动作专家难以访问 3D 几何与 2D 语义信息，这一瓶颈此前被忽视。
  • 提出 V-Link 框架：通过可学习的空间与语义查询，在 VLM 中解耦并强化几何与语义表示，再以不对称方式注入 Action DiT，同时不破坏原有多模态计算流。
  • 轻量级训练设计：利用仅训练阶段使用的深度头与分割头提供显式监督，推理时移除辅助头且不需要任何深度/分割标注，额外推理延迟仅 1.58 ms。
  • 显著实验提升：在三个模拟基准（LIBERO、LIBERO-Plus、RoboTwin 2.0）和真实人形机器人任务上均稳定超越基座模型 GR00T N1.6，且在分布偏移场景下提升尤为明显。
Card 04 方法描述

方法描述

  • 在 VLM 输入中引入两组可学习 token：Spatial Queries 与 Semantic Queries，通过定制因果注意力掩码使其独立地从 VLM 深层特征中聚合几何与语义线索，而不干扰原有图像-文本计算。
  • 使用轻量级 深度估计头（约 2.3M 参数）和 语义分割头 对查询专门化：深度损失含 smooth L1、相对距离损失和 hard-patch 损失；分割损失结合交叉熵与 soft dice 损失。训练分两阶段：先预热查询与任务头，再联合优化。
  • 在 Action DiT 中采用非对称注入：语义查询与原始 VLM 图像 token 并行做交叉注意力并融合，空间查询则作为后续独立的几何条件通路；注入只作用于交替注意力中的图像交叉注意力层（ℓ = 4k+2）。
  • 总损失为动作 flow-matching 损失 + 深度损失（权重0.1） + 分割损失（权重0.002），仅训练阶段存在辅助头。
Card 05 数据集与资源

数据集与资源

  • 模拟基准：LIBERO（80K 步训练，batch 160，双相机视图）、LIBERO-Plus（直接泛化评估，不微调）、RoboTwin 2.0（6 个挑战性任务，每任务 50 条演示，共 300 条，120K 步训练，batch 128）。
  • 真实机器人：AGIBOT A3 Ultra，包含自主上电与断电两项任务，各 100 条遥操作演示。
  • 基础模型：GR00T N1.6 3B；VLM 采用 rank-128 LoRA 适配，冻结语言与视觉骨干。
  • 训练资源：4 张 NVIDIA H100 GPU，DeepSpeed ZeRO-2，BF16 精度；优化器 AdamW，学习率 1e-4，权重衰减 1e-5，余弦衰减 + 5% warm-up。
  • 查询 token 数：LIBERO 上每组 2×5×5，RoboTwin 上每组 3×5×5（3 视图）；推理时用 torch.compile、4 步去噪。
Card 06 评估与结果

评估与结果

  • LIBERO 基准：平均成功率 99.3%，较 GR00T N1.6（97.4%）提升 +1.9%，在 Long 套件上提升最大（+5.1%），四项全部第一。
  • LIBERO-Plus 分布偏移基准：平均成功率 75.0%，较 GR00T N1.6（43.8%）提升 +31.2%，七项中六项第一；其中 Noise 提升 +60.4%、Language +47.3%、Light +30.6%。
  • RoboTwin 2.0 基准：平均成功率 56.8%，较 GR00T N1.6（38.0%）提升 +18.8%，所有任务均一致提升。
  • 真实 AGIBOT A3 Ultra：自主上电成功率 98%（基座 78%，+20%）、自主断电成功率 94%（基座 70%，+24%），均为 50 次连续试验结果。
  • 消融分析：空间查询贡献 +13.2%、语义查询贡献 +9.8%，二者结合 +18.8%；任务监督与查询注入缺一不可（单独使用仅 +2.3% 与 +1.8%）；查询 token 规模 3×5×5 为精度-延迟最优平衡点。
  • 推理成本：从 43.21 ms 增加到 44.79 ms，仅增加 1.58 ms 延迟，验证了极低计算开销下的显著性能提升。
