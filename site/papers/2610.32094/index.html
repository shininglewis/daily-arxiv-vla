TTT in VLA Models: Exploring Training with Human Demonstrations

2026-10-23 · 原文 · 翻译 · 2610.32094

论文探索长程机器人任务所需的记忆能力，将 Test-Time Training（TTT） 的快速权重记忆机制集成进 VLA 模型 InternVLA-A1 与 Pi0.5，研究以人类演示为条件的动作生成。 核心设定是把每个训练样本构造成“人类演示视频 + 对应机器人轨迹”的配对，让演示先写入快速权重，再由机器人轨迹在继承的记忆上做动作监督。 论文旨在复现并清晰描述 TTT 架构及其训练流程（含 TBPTT、记忆迁移、对比正则），并如实报告：在当前训练规模下，模型并未学会依据演示选择目标，属于偏负面/观察性报告。

Card 03 核心贡献

核心贡献

  • 复现并详细公开 TTT 层（快/慢权重、写-读两阶段、门控残差）及其在两类 VLA 骨干中的插入位置与集成方式。
  • 提出并实现人类演示与机器人轨迹之间的记忆迁移，以及跨人-机边界的 transition segment（过渡段），使机器人动作损失能在段内回传到演示写入。
  • 系统梳理 TBPTT 分段反向传播、梯度截断与慢权重累积更新流程，并给出两个完整算法（TTT 层算法与 TBPTT 训练算法）。
  • 在视频演示、短视频演示、单帧提示三种由难到易的设定下做完整实验，并尝试对比正则化，公开训练配置、评估协议与未解释的观察结果。
  • 指出 open-loop 动作误差下降并不等价于真机任务性能提升（TTT abs 的 AR-state MAE 更低但真机完成率更差）。
Card 04 方法描述

方法描述

  • TTT 层结构：输入经 RMSNorm 后线性投影出 Q/K/V；内层模型是两层 GELU MLP（每头独立快速权重），用重构目标 V̂ = K + Norm(g_F(K))、L_inner = MSE(V̂, V) 做一次梯度写（F⁺ = F − η∇_F L_inner），再用 Q 读取更新后的 F⁺，最后经输出投影与 tanh(α) 门控残差加回输入。
  • 快/慢权重分离：投影、归一化、门控与初始快速权重 F_init 为慢权重（由外层任务损失训练），内层 MLP 运行时参数为快速权重（承载记忆）；快速权重更新保持可微，使任务损失可回传到记忆写入。
  • 集成位置：InternVLA-A1 在 generation expert 与 action expert 的每一层插入 TTT（位于注意力输出投影与首个残差之后、FFN 之前），understanding expert 不改；Pi0.5 在全部 18 层 action expert 插入。写分支使用 16 个可学习 register token + 1 个机器人状态 token，动作 token 只读不写（并屏蔽动作 token 对 register 的直接注意力）。
  • 写频率与去噪解耦：每个观测 anchor 只写一次，后续多次去噪迭代共享同一记忆；训练使用 GT-state 监督 + 增量动作表示。
  • TBPTT：轨迹切分为含多个 anchor 的 segment，段内保留计算图反向传播，段边界 detach 快速权重但保留其数值；慢权重梯度跨段累积，整个轨迹 batch 结束后才更新一次。
  • 对比正则化（附录）：保留原拟合损失，用错误配对的演示–轨迹组合惩罚“错配对损失低于正确配对”的情况，促模型区分演示条件。
Card 05 数据集与资源

数据集与资源

  • 第一阶段（抓取预训练）：杯子抓放数据集，InternVLA-A1 为 30,000 步，Pi0.5 亦为 30,000 步。
  • 第二阶段（视频演示目标选择）：654 个完整配对样本、556,302 帧，按配对划分 621 训练 / 33 验证；InternVLA-A1 训练 60,000 步，Pi0.5 训练 30,000 步。
  • 短视频演示数据集：273 个配对（264 训练 / 9 验证），训练 60,000 步。
  • 单帧提示数据集：210 个配对（seed 42，200 训练 / 10 验证），训练 60,000 步。
  • 额外预训练：Pi0.5 在 InternData 上做 60,000 步 TTT 预训练；InternVLA-A1 有 20,000 步 TTT 预训练变体。
  • 模型规模细节：Pi0.5 的 constrained Fast MLP 为 256→1024→256，内学习率 0.03 基值 + 可学习系数、上限 0.05；multi-head core 为 16 头、每头 64→256→64、内学习率固定 1；快速权重以 FP32 存储。
  • 训练资源：2 块 GPU，每卡并行 2 条轨迹，全局 batch = 4 条轨迹；学习率 InternVLA-A1 为 5e-5、Pi0.5 为 2e-5，warm-up 分别为 50 与 2,000 步，衰减周期 60,000 步。InternVLA-A1 预训练数据约 6.92 亿帧（原文后续被截断）。
Card 06 评估与结果

评估与结果

  • 评估协议：两种开环评测——GT-state（每个 anchor 用数据集真值状态）与 AR-state（用上一 chunk 的预测动作递推状态，图像仍来自数据集）；均解码回物理单位后计算 MAE / RMSE，关节与夹爪误差分开报告；另做真机杯子选择成功率/完成率测试。
  • 主要指标：GT-state MAE、AR-state MAE、真机任务完成率与目标选择成功率（三选一，随机基线 1/3）。
  • 预热对比（6,000 步）：baseline delta 的 GT/AR MAE 为 0.023604 / 0.099308、真机完成率 90%；TTT delta 为 0.022631 / 0.091122、完成率 73%；TTT abs 为 0.028153 / 0.082412、完成率 64%——AR 误差更低但真机表现更差。
  • 视频演示实验：InternVLA-A1 与 Pi0.5 在真机上均表现出固定方向偏好，成功率低于 1/3 的均匀选择基线；跳过演示记忆写入仅引起很小的动作误差变化，说明模型几乎未利用演示条件。
  • 短视频 + 全轨迹梯度：InternVLA-A1 在 10,000 与 60,000 步后成功率仅 25% 与 13%；加入对比正则化无明显改善。
  • 单帧提示：两模型仍倾向抓取固定位置的杯子，成功率均低于 33%，未出现对提示的稳定依赖。
  • 结论性观察：序列缩短、全轨迹梯度连通、对比正则化均未带来预期收益；作者明确表示尚无法判定问题出在写入、保持还是读取使用环节，并缺乏规模化验证。
