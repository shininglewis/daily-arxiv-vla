Card 02 论文概述

论文概述

  • 论文研究语言条件机器人策略中的指令跟随问题：当同一场景存在多个可行动作时，语言应决定机器人执行哪一个动作。

Card 03 核心贡献

核心贡献

  • 提出场景保持的指令干预评测范式，用有效目标替换、随机名词、无关句子在固定场景下检验策略是否真正被指令控制。
  • 发现并命名场景条件行为先验（scene-conditioned behavioral prior）：指令要求另一可见物体时，所有被测策略仍主要抓取原始目标。
  • 通过逐层动作透镜（layerwise action lens）与线性探针证明：策略对语言确有敏感性，且当前指令目标在表征中高度可解码，失败并非"语言未被编码"。
  • 通过注意力贡献分析、UMAP 与共享半非负矩阵分解（shared semi-NMF）定位失败原因：指令 token 对动作生成贡献弱、目标 token 视觉注意力未随指令重定向、微调后表征组织由目标主导转向场景主导。
  • 提出更严格的接地评测准则：有效的指令变化应可靠地选择同一场景中的不同行为，即使与场景偏好相冲突。
Card 04 方法描述

方法描述

  • 指令干预设计：三种条件——Original、Noun Replacement（含 *In-scene Target Replacement* 与 *Random Noun*）、Random Sentence，保持初始场景与机器人状态不变，仅改变指令文本。
  • 逐层动作透镜：类比 logit lens，在每一层 $l$ 与去噪步 $s$ 将动作读出应用于中间隐状态，以归一化动作坐标下的均方偏差 $D_q^{(s,l)}$ 衡量指令变化对中间动作预测的影响。
  • 线性探针（Ridge Regression）：从指令 token 均值池化表征中分别预测目标身份与场景身份，比较微调前后及仿真/真机设置下的可解码性。
  • 注意力贡献分析：聚合各层各头的注意力加权 value 向量并做输出投影，计算指令、视觉、机器人状态等模态对动作 token 的相对贡献比例 $s_{ij}$。
  • 表征几何分析：用 UMAP 观察逐层指令表征聚类结构，用共享半-NMF联合分解 base 与微调表征，并通过方差划分（$U_{\text{scene}}$、$U_{\text{target}}$）量化场景/目标独有方差变化。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO、RoboTwin 2.0（Clean/Randomized）与六场景真机闭环 rollout，策略参数冻结，报告 *Tend*（趋近/操作意图）与 *Success*（任务完成）两类指标。
  • 核心失败现象：LIBERO-Object 中 86.5%–98.3% 的试验指向原始目标，仅 0.5%–13.0% 指向当前指令目标；原始目标成功率 69.5%–95.3%，当前目标成功率仅 0.0%–11.5%。真机中原始目标抓取率为 74.2%（π0.5） 与 90.8%（GR00T N1.7），当前目标仅 5.8% 与 3.3%。
  • 语言敏感性证据：随机句子在所有模型与套件上显著降低成功率（如 LIBERO-Goal 下 π0.5 降 88.1%、GR00T N1.7 降 95.9%）；名词替换影响较小但任务依赖，且在 LIBERO-Goal 上最大。RoboTwin 2.0 中两类干预均导致性能下降。
  • 动作层响应：逐层动作透镜显示偏差排序一致为场景外名词 < 场景内目标替换 < 随机句子，且随去噪步数增大分离度增加。
  • 可解码性：线性探针对目标身份与场景身份均达到接近上限的准确率（微调前后、仿真与真机皆然），说明目标信息并未丢失。
  • 贡献度失衡：指令 token 对动作生成的贡献占比在 π0.5 上为 LIBERO 25.6%–27.9%、RoboTwin 2.0 约 1.7%、真机 9.7%；GR00T N1.7 为 18.5%–23.4%、约 12%、13.5%，均低于视觉或机器人状态输入。
  • 注意力错位：指令由 *tomato sauce* 改为 *BBQ sauce* 时，目标 token 视觉注意力仍聚焦原始番茄酱，策略在两种指令下抓取同一物体。
  • 表征重组：UMAP 显示微调前按目标聚类，微调后首层保留目标聚类、中间层转为按场景聚类、末层趋于分散；共享半-NMF 显示组件由目标主导转向场景主导，场景独有方差上升、目标独有方差下降。
