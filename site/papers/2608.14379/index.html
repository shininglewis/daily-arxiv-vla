论文概述

Card 03 核心贡献

核心贡献

  • 引入 ReflexBench，包含 6 个需要快速反应和未来感知决策的动态操作任务，并采用延迟感知评估协议
  • 提出 ReflexVLA，一种轻量级（1B 参数）VLA 框架，无需大规模机器人数据预训练即可用于反应关键型操作
  • 设计三个关键技术：潜空间未来预测（Latent Future Prediction）、多帧时序融合（Multi-Frame Temporal Fusion）、推理延迟优化（Inference Latency Optimization）
  • 在仿真和真实世界环境中进行大量实验，验证了提出的设计对动态场景的有效性，同时在静态基准（LIBERO）上保持竞争力
Card 04 方法描述

方法描述

  • ReflexVLA 基于紧凑的 VLA 架构，视觉编码器为 DINOv2 与 SigLIP 融合的 ViT（224×224 分辨率），语言主干为 Qwen2.5-0.5B
  • 引入 Latent Future Prediction：在冻结的 DINOv3 语义特征空间中预测未来视觉表征，使用可学习未来 token 和掩码余弦相似度损失，与动作预测联合优化
  • 引入 Multi-Frame Temporal Fusion：在视觉骨干的中间层特征上对历史帧进行因果时序注意力融合，仅将融合后的当前帧 token 送入语言模型，避免语言模型侧的额外计算开销
  • 推理延迟优化：将所有视角-帧图像批量编码为一次视觉前向传播，并将完整推理流程捕获为 CUDA Graph 进行重放，减少 kernel 调度开销
  • 延迟评估框架支持同步/异步推理，并利用 Real-Time Factor (RTF) 将真实推理延迟映射到仿真中的阻塞时间
Card 05 数据集与资源

数据集与资源

  • ReflexBench：6 个仿真动态任务（传送带抓取、接球、打地鼠、滚球拦截、抛球入筐、旋转插销插入），每个任务 200 个演示 episode
  • 数据采集采用基于规划的分阶段管线，复杂交互任务使用强化学习策略生成演示
  • 静态基准使用 LIBERO（Spatial、Object、Goal、Long 四个子集）
  • 模型规模：ReflexVLA 为 1B 参数，对比模型包括 OpenVLA-OFT（7B）、π0.5（4B）、PUMA（4B）、DynamicVLA（0.5B）、SmolVLA（0.5B）、VLA-Adapter（1B）
  • 训练与评估硬件：单张 NVIDIA RTX 5880 Ada GPU
Card 06 评估与结果

评估与结果

  • ReflexBench 主结果：ReflexVLA 平均成功率 50.4%，在所有基线中最高；相比其骨干 VLA-Adapter 的 30.3% 提升显著；优于 7B 的 OpenVLA-OFT（36.0%）和 4B 的 π0.5（36.9%），与 PUMA（50.2%）相当但参数仅为其四分之一
  • 静态基准 LIBERO：ReflexVLA 平均准确率 97.2%，与最佳 VLA 模型（VLA-Adapter 97.3%、OpenVLA-OFT 97.1%）基本持平，表明动态设计不损害静态任务性能
  • 消融研究：逐步加入冻结 DINOv3 未来预测（36.8%→62.8%）、中间层因果时序融合（71.7%）、延迟优化（73.8%），同时推理延迟从 125.1 ms 降至 65.0 ms
  • 真实世界实验：在 AgileX Piper 机械臂上验证，ReflexVLA 在 Conveyor Belt Pick-and-Place（16/20 成功）、PressButtons（22.5 次）和 CatchBalls（6.7/10）三个任务上均优于 SmolVLA，并与更大的 PUMA 模型性能相当
  • 关键发现：在动态场景中，更大 chunk 大小 + 更短 action horizon + 高频异步推理 的组合效果最优
