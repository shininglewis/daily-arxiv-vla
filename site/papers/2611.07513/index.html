Card 03 核心贡献

核心贡献

  • 提出 eVLM 范式：在表示、监督信号和生成过程三个层面把操作能力内嵌进单一 VLM，使连续轨迹生成、坐标监督都落在共享扩散 VLM 骨干的计算与参数路径上。
  • 提出 Concertina 架构：把一条长度为 H 的轨迹表示为 H 个连续隐动作 token（每个控制步一个 token，而非 H×D 个标量符号），采用块内双向、块间因果的可见性，并使用 packed teacher forcing。
  • 引入 Action Interface Audit（动作接口审计） 方法论，含 EGC（误差几何一致性）、TCA/NLR（轨迹耦合归因）、ASCR（动作专属容量比）三项指标，用于定位动作表示与轨迹计算究竟发生在哪一层。
  • 通过反事实干预证明：在共享隐空间上再叠加第二个坐标目标会产生方向相反的梯度（余弦相似度为 −0.891），使 CALVIN 链长从 2.970 跌至 0.237，说明动作表示与监督目标必须协同设计。
  • 在 LIBERO、LIBERO-Plus、CALVIN ABC–D 上取得领先的闭环成功率。
Card 04 方法描述

方法描述

  • 连续隐动作 token：轻量逐位置（position-wise）编码器 E_φ 将 D 维动作向量映射为 d 维隐空间中的单个 token，解码器 D_ψ 再将骨干隐状态映射回物理坐标；二者均为逐时间步独立作用的 MLP，不做时间混合。
  • 共享骨干建模时序：所有跨时间、跨模态依赖由共享 Transformer F_θ 计算，骨干初始化自 BARD-VL，复用其掩码块“破坏—重建”算子处理连续隐动作，无需第二个训练范式或外部扩散网络。
  • 块式拓扑与 packed teacher forcing：将 H 步划分为 M 个有序动作块，块间因果、块内双向；训练序列打包为 [C, Z̃, Z]（多模态前缀、加噪动作和教师强制干净动作），一次前向即可同时监督全部 M 个块条件分布。
  • 块分层加噪与坐标重建：对 [0,1] 分层采样每块的掩码率，并随机置换分配到各块；损失直接在归一化物理坐标上计算，坐标权重为 500:10:1（平移、6D 旋转和夹爪），位姿用 Smooth-L1、夹爪用概率型 BCE，并按掩码概率的倒数加权。
  • 多具身统一隐空间：用维度有效掩码与时间步有效掩码把异构控制空间对齐到统一最大坐标宽度，非激活维度置零且不计入损失分母。
  • 推理与闭环执行：前缀预填 KV cache，逐块生成；用轻量 token 风险头预测对数重建误差，按负风险排序并进行可选的重掩码精修，最后以滚动时域方式闭环重规划。
Card 05 数据集与资源

数据集与资源

  • 评测数据集：LIBERO（4 个套件、每任务 50 回合，共 2,000 回合）、LIBERO-Plus（10,030 个扰动任务）、CALVIN ABC–D（1,000 条官方五任务指令链，D 为未见环境）。
  • 预训练数据：多具身混合数据，规模为 80.2M 帧。
  • 模型规模：4.46B 参数；活跃动作投影仅占 0.21% 参数，零独立动作生成层。
  • 训练资源：8 张 GPU；多具身预训练 60,000 次更新和 30,000 次更新续训，全局 batch 1,536（每卡 192）；CALVIN 微调 5,000 次更新；LIBERO 微调全局 batch 448（每卡 56）。
Card 06 评估与结果

评估与结果

  • 评估环境：标准闭环操作基准 LIBERO / LIBERO-Plus / CALVIN ABC–D，以及作者提出的 Action Interface Audit 检查点级审计。
  • 主要指标：LIBERO 与 LIBERO-Plus 的成功率（%）；CALVIN 的平均完成链长 AvgLen 与 SR@k。
  • LIBERO 常规基准平均 98.15%（Spatial 99.0 / Object 100.0 / Goal 98.8 / LIBERO-10 94.8），高于 π0 94.2%、π0.5 97.5%、X-VLA 98.1%、Dream-VLA 97.2%。
  • LIBERO-Plus 总体 85.9%（8,615/10,030），比 EFFVLA 79.8% 高 +6.1 点，比 OpenVLA-OFT 69.6% 高 +16.3 点，四个套件全部最优。
  • CALVIN ABC–D 平均链长 4.142，SD@1 98.6%、SR@2 93.8%，优于共享骨干扩散策略 LLaDA-VLA（4.01）。
  • 审计结果：离散分箱单元token误差可造成 25.14× 的物理误差跨度，FAST 类压缩 token 单 token 扰动下出现 77.9%–82.2% 结构性解码失败；π0 / π0.5 / SmolVLA / X-VLA 的 ASCR 分别为 16.51% / 19.17% / 22.19% / 35.10%，而 Concertina 仅 0.21%。
  • 耦合定位：Concertina 的动作接口自身 NLR = 0（无跨时间响应），跨时间轨迹耦合全部出现在共享骨干的中后层（预训练 4.06%、CALVIN 4.10%、LIBERO 1.22%）；动作编码器有效秩 18.63/20，未发生表示塌缩。
