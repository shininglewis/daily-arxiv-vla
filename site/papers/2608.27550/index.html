Card 03 核心贡献

核心贡献

  • 提出 VLAct，一种以表示为中心的 VLA 持续预训练方法，通过保留 VLM 先验、多头动作协同监督、部分统一跨具身动作布局来学习可迁移的视觉-动作表示
  • 通过浅层保护（冻结视觉编码器和低层 LLM）和字幕数据混合两个机制保留 VLM 的广泛视觉-语言先验，避免机器人数据训练导致表示漂移
  • 提出多头连续动作协同监督，在同一骨干上并行训练 OFT、PI、GR00T 三种连续动作头，防止表示向单一解码器塌缩，提升跨动作头的可迁移性
  • 设计部分统一的跨具身动作空间：夹爪开合维度跨具身共享，机械臂维度按具身保留并掩码，配以 wrap-aware loss 处理周期性关节角
  • 全部模型和训练管线开源，仅使用公开数据集和 16 块 GPU 即可达到与大规模工业 VLA 系统竞争的性能
Card 04 方法描述

方法描述

  • 以 Qwen3-VL-4B 为基础 VLM 骨干，持续预训练阶段冻结视觉编码器和下半部分 LLM 层，仅更新上层 LLM 和动作头，微调阶段解冻全部参数
  • 将机器人轨迹数据与字幕数据混合训练，字幕提供密集的对象、属性、空间关系监督，作为 VLM 表示的锚点
  • 在共享骨干上并行挂载 OFT、PI、GR00T 三种连续动作头，优化目标为三者损失之和，迫使骨干编码对不同头都可达的动作信息
  • 采用单一共享动作头 + 部分统一动作空间：跨具身的夹爪维度共享坐标，不兼容的机械臂维度保留为具身特定并掩码，避免隔离的具身特定头或全维度强制对齐
  • 对绝对关节角维度使用 wrap-aware 损失（模 360° 的角残差），避免 179° 与 -179° 被错误视为 358° 距离

  • 持续预训练机器人数据集：DROID、InternA1、RoboCoin、MolmoAct（全为开源数据）
  • 另混入字幕数据用于 VLM 表示保留
  • 基础模型：Qwen3-VL-4B（4B 参数级 VLM）

Card 06 评估与结果

评估与结果

  • LIBERO-Plus（单臂 Franka 操作，鲁棒性基准）：VLAct 总分 82.6%，超过最强的同骨干基线 Qwen3VL-OFT（75.0%）7.6 个百分点，并超越阿里巴巴 Abot-M0（80.5%）
  • VLA-Arena（Franka）：VLAct 达到 54.8%
  • RoboTwin 2.0（双臂 AgileX 操作）：Base 设置 Clean 达 80.5%、Random 达 41.5%；Data Scaling 设置 Clean 达 92.5%、Random 达 90.8%，超过 LingBot-VLA、ABot-M0、π₀.₅ 等系统，且 PI 头 Clean 达 93.0%
  • RoboDojo（ARX X5 仿真，42 任务）：VLAct 平均分 10.66、成功率 7.60%，在 35 个策略中按成功率排名第 6，超过所有明确指定的 world-action-model（WAM）条目及多个工业系统；相比同为 Qwen3-VL 基座的 StarVLA-α 提升 4.26 分和 4.36 个百分点
  • RoboCasa-GR1（未见过的 GR-1 人形具身）：仅用 20% 下游轨迹即达 49.5%，超过全数据训练的 GR00T-N1.6（47.6%）；全数据微调达 54.0%
  • 真实机器人实验（Franka Research 3）：单臂短时 ID 任务平均成功率 92.5%（基线 77.5%）、单臂长时任务 table cleaning 达 86.6%、scooping beans 达 80.0%、OOD 短时泛化 novel object 任务达 90.0%、双臂协调任务平均 72.0%（基线 44.0%）
