Card 03 核心贡献

核心贡献

  • 多源分层规划监督数据：融合 Ego、UMI 与遥操作数据，采用 L3 Task / L2 Subtask / L1 Action / L0 Segment 四级层级；遥操作数据含全部四级，Ego 与 UMI 仅保留 L1–L3。
  • 失败感知的进行中监督：利用标注的接管时刻（takeover-time）监督执行中的错误识别，并补充人工设计的失败演示以降低对单一策略失败分布的依赖。
  • Staircase Decoding 双形态规划：共享 VLM 主干同时支持离散事件状态（可解释）与连续隐式 CoT（跨错位 Transformer 深度并行传递），避免规划器内部逐 token 串行化。
  • 冻结的隐到文重建目标：以冻结语言模型从隐状态前缀重建文本 CoT，为紧凑隐表示提供语义锚点，仅优化 staircase 分支与前缀投影器。
  • 离线与真机双重评测：离线评估两步规划文本质量，真机评估完整 event-mode 系统的任务进度与泛化能力。
Card 04 方法描述

方法描述

  • 骨干网络：采用 Qwen 系列 VLM 作为共享视觉–语言主干，负责场景 grounding、事件分解与进度估计。
  • 离散形态：输出结构化事件状态（初始有序事件计划、进行中进度/当前事件/下一事件/继续状态/错误识别、episode 结束标记），可被人类或上游 agent 检查与编辑。
  • 隐式形态与 Staircase Decoding：在relay depth 处分区 Transformer，下层编码共享视觉–语言上下文，上层跨推理步并行更新，每位置使用独立因果缓存。
  • 文本条件接口：通过边界掩码选取文本 token 状态，经可学习投影 $\mathcal{P}_Q$ 与下游原生文本 MLP $\mathcal{M}_T$ 映射进 world-action 模型的交叉注意力通路。
  • 训练目标：结构化 JSON 上的自回归 SFT 损失、与下游文本特征几何对齐的距离损失、以及冻结隐到文重建损失。
  • 推理耦合：event mode 发出事件描述文本控制下游模型；unified mode 直接以连续 CoT 隐状态通过相同交叉注意力接口条件化固定长度动作块。
Card 05 数据集与资源

数据集与资源

  • 数据来源：Ego（第一视角）、UMI、遥操作三类演示数据，同步视觉与动作流后标注。
  • 分析子集：从 1,654 个候选 episode 中确定性筛选出 1,500 个 episode，覆盖 167 个数据集、30 个命名任务类别及未知标签。

  • 动作标签：含 41 个原子动作标签，Move/Grasp/Place 分别覆盖 68.4%/57.0%/40.3% 的 episode。

Card 06 评估与结果

评估与结果

  • 离线两步规划评测：指标为 BERTScore-F1（不加基线重缩放）与 Doubao Judge Overall 综合评分；对比 Qwen、Doubao、kimi3。
  • 离线结果：X-Planner 以 BERTScore-F1 0.9011、Overall 1.411 排名第二，优于 Qwen（0.8878 / 1.367）与 Doubao（0.8846 / 1.366），低于 kimi3（0.9108 / 1.434）。
  • 真机设置：桌面双臂机器人+同步多视图观测，主指标为 Task Progress（0–100 的密集分数，按任务评分细则计分）；事件模式运行。
  • Reasoning Manipulation：X-Planner 平均 71.60% 最高，领先 U-Scratch（59.50%）12.10 个百分点，远超 $\pi_{0.5}$（56.40%）、DreamZero（32.70%）、LingBot-VA（31.60%）。
  • Generalization：X-Planner 平均 53.75%，领先最强基线 DreamZero（28.50%）25.25 个百分点，$\pi_{0.5}$ 为 24.00%、U-Scratch 为 18.50%；LingBot-VA 在此设置无结果。
  • 结论与局限：两套评测中 X-Planner 真机平均任务进度最高；但作者强调实验未做组件消融、未提供方差或显著性检验，也未证实端到端延迟优势，隐式形态与离散形态的受控对比留待未来工作。
