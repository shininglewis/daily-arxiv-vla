Card 02 论文概述

论文概述

  • 提出 JEPA-WAM 框架，将短期物理未来（局部场景演化）与阶段级语义未来（任务进展目标）相结合，用于机器人操作任务
  • 核心思想：在现有世界动作模型（WAM）基础上，引入目标条件化的 JEPA（联合嵌入预测架构）预测器，推断任务下一阶段的潜在表示，并将其注入 WAM 以引导短视频预测和动作生成

Card 03 核心贡献

核心贡献

  • 将机器人未来建模划分为两个互补时间尺度：短期物理未来（局部视频-动作演化）与阶段级语义未来（任务进展状态）
  • 提出 JEPA-WAM 架构，使用目标条件化 JEPA 预测器（Stage-JEPA）估计下一阶段潜在表示，并通过门控接口注入 WAM 的视频生成流
  • 提出无需人工标注的阶段边界自动推断方法：基于冻结 V-JEPA2 特征的表示变化启发式 + 时序 NMS 生成关键帧
  • 在 50 个 RoboTwin 2.0 任务上（干净与随机化环境）达到 90.25% 总体成功率，较最强基线 Motus 提升显著
  • 成功 rollout 的平均执行步数减少 5.97%，验证了阶段引导对执行效率的提升
Card 04 方法描述

方法描述

  • 两阶段训练：Stage I 训练目标条件化 JEPA 预测器；Stage II 冻结 JEPA，训练阶段条件化的 WAM
  • Stage-JEPA：使用冻结的 V-JEPA2 编码器（facebook/vjepa2-vitl-fpc64-256），通过余弦损失对齐预测的下一阶段 token 与目标 token
  • 阶段边界推断：对轨迹每 8 帧采样候选中心，编码 64 帧片段，计算特征变化分数后经时序 NMS 保留最多 5 个关键帧
  • WAM 基础：基于 Motus（Mixture-of-Transformers 架构），包含视频生成专家（初始化自 Wan2.2）、动作专家和视觉-语言理解专家（冻结 Qwen3-VL）
  • 门控注入机制：将 Stage-JEPA 输出经 mean-pool 和 MLP 映射后，以全局标量门控 α=0.2σ(β) 加性注入视频 token，配合正则化损失约束注入幅度
Card 05 数据集与资源

数据集与资源

  • 使用 RoboTwin 2.0 双机械臂操作基准，覆盖 50 个任务，分为干净和随机化两种配置
  • 每个任务-配置对运行 100 个闭环 episode，共 10,000 epi-sode/检查点
  • 训练资源：8 × NVIDIA A800 80GB GPU，有效 batch size 为 256
  • 视频分辨率 384×320，预测 8 帧未来视频和 16 个动作
Card 06 评估与结果

评估与结果

  • 与 GO-1、π0.5、X-VLA、Motus 四种基线对比，使用任务成功率作为主要指标
  • JEPA-WAM 在干净环境达到 91.42%，随机化环境 89.08%，总体 90.25%，全面超越所有基线
  • 在 7 个语义任务类别中，JEPA-WAM 在干净设置下 5 类最优、随机化设置下 6 类最优，尤其在手递、目标放置、容器装箱等需要显式任务状态变化的任务上提升明显
  • 消融实验显示：移除 JEPA 组件导致最大性能下降（87.23% vs 90.25%），验证了阶段引导路径的有效性；移除 Stage-I 训练和门控正则化也有不同程度的性能损失
  • 执行效率方面：所有 rollout 平均长度从 Motus 的 156.28 步降至 132.80 步（-15.02%），成功 rollout 从 79.57 步降至 74.82 步（-5.97%）
