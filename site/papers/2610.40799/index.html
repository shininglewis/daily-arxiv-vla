Card 02 论文概述

论文概述

  • 论文提出 CaPtain，一个开放的“后训练”（post-training）流水线，把小规模开源视觉语言模型（VLM）训练成代码即策略（Code-as-Policy, CaP）机器人智能体。
  • 论文要解决的问题是：现有 CaP 智能体普遍绕开训练，要么在测试时调用闭源前沿模型（成本高、不可微调、无法端侧部署），要么把操作能力外包给预训练 VLA 或高层技能（如 grasp/place），而小型开源 VLM 直接控制机器人则完全失败。
  • 核心主张：机器人操作只要建立在低层执行框架之上，就可以像其他语言智能体一样用“SFT + 多轮 RL”的通用配方进行后训练。
Card 03 核心贡献

核心贡献

  • 提出 CaPtain：端到端 SFT + RL 开源流水线，将小型开源 VLM 转为独立 CaP 智能体，并开源 SFT 数据、训练代码与 CaPtain-4B 权重。
  • 提出 CaPtain-Harness：可移植执行框架，仅暴露 22 个低层感知、几何测量与安全运动原语，并返回结构化文本回执（receipt），无 grasp/place 等语义技能、无 VLA。
  • 提出模拟器评论家（simulator critic）：利用策略不可见的特权物理状态，将稀疏的回合级结果转化为稠密的逐请求（per-request）信用分配，分析表明信用集中在抓取与放置等物理决策上。
  • 给出系统性评测：RL 增益在三个扰动套件上依然保持；4B 策略以极低成本超过多个前沿模型智能体；可零样本迁移到多个基准、不同本体与真实机器人。
Card 04 方法描述

方法描述

  • 执行框架（CaPtain-Harness）：智能体运行 ReAct 式循环，每回合最多 60 个请求；唯一工具是持久化 Python 会话（预置 robot 模块），变量与辅助函数跨请求保留。
  • 原语设计：感知（observe、segment（SAM 3）、point（Molmo2）、mark_point、track_target）、测量（measure_object_geometry、接触/释放几何校验）、运动（move_to、hold、recover、release）、规划与状态查询；每个 move_to 被展开为笛卡尔直线运动 + 逆运动学 + 自碰撞检查 + 逐子步力监控。
  • 上下文管理：工具输出截断、每单元格最多 20 行回执、仅保留最近 12 张图像；接近上限时按轮压缩，但保留任务上下文与最近轮次；压缩在 RL 与测试时行为一致。
  • 阶段一 SFT：在框架内用 GPT-6 Astra 生成合成轨迹，渲染格式与部署时完全一致；仅监督智能体产生的 token（含推理与代码），屏蔽重复失败/恢复循环的轮次；以 0.2 概率将历史坐标替换为 mask token 迫使模型重新看图；冻结视觉塔。
  • 阶段二 RL：从模拟器提取 36 维特权特征（5 组：末端与夹爪状态、目标记账、距离、目标抬升与位移、关节与持握标志），刻意排除策略自身行为计数。
  • 评论家：由 5 个小 MLP 组成的集成模型，预测 host 成功概率，先预热再在线共训练（co-train）；逐请求信用为同一时间索引下的价值变化 + 即时代价，故纯感知/验证请求信用接近 0。
  • 优势与更新：GAE（λ=0.9）+ 组相对结果项（每个起始状态 rollout G=4 次）；采用 SAO 式流式单遍更新 + 双侧 ratio 掩码（0.2 < r < 4）+ KL 到 SFT 模型；每步累积 1024 条 episode 的梯度以抑制梯度噪声。
  • 奖励设计：成功且调用 finish() 得 1.0，成功未调用得 0.25，普通失败 0，预算耗尽 −0.1，假完成 −0.3；并有失败动作、超额动作、已完成后仍动作等代价项与提前停止机制。
Card 05 数据集与资源

数据集与资源

  • 训练数据：仅在 LIBERO 的 40 个原始任务 上训练；RL 采样新起始状态（宽布局、随机光照/相机位姿/材质），排除评测用的 240 个官方初始状态。
  • SFT 数据：由 GPT-6 Astra 在框架内生成的合成多轮轨迹（另含权重 0.5 的 VQA 样本）。
  • 基础模型：Qwen3.5-4B（指令微调版），产出 CaPtain-4B；最终模型取第 300 轮（75 次优化器更新）检查点。
  • 评测基准：LIBERO、LIBERO-PRO、LIBERO-Plus、LIBERO-MAX；零样本迁移用 RoboTwin 2.0、RoboDojo、SimplerEnv、CaP-Bench。
  • 计算资源：具体 GPU/TPU 规模见附录 M「Compute accounting」（原文该部分未在给定片段中给出）。
Card 06 评估与结果

评估与结果

  • 评测协议：全部在 CaPtain-Harness 内运行，温度 1、开启思考、最多 60 请求 / 150 物理动作 / 1080 秒；测试时移除评论家，物体坐标全部由 RGB-D 与回执在线估计。
  • 指标：Host 成功率（基准最终状态判定）与 Strict 成功率（额外要求以 finish() 结束）；配对 McNemar 检验 + 任务簇 bootstrap 置信区间。
  • LIBERO 主结果：Qwen3.5-4B 基线 0% → SFT 55.4% → RL 73.8%（strict 52.1% → 67.5%）；假完成率从 7.1% 降至 2.1%，平均请求数从 39.1 降至 32.6。
  • 扰动鲁棒性：LIBERO-PRO 3 套件 78.5%（+19.0），4 套件 68.6%（+19.4）；LIBERO-Plus 66.1%（+17.6，7 个扰动维度全部提升，6 个通过 Bonferroni 校正）；LIBERO-MAX Dynamic 61.2%（+21.2）、Base 70.0%（+18.8）。
  • 对比前沿系统：LIBERO-PRO 上 78.5% 超过 K1（77.2%）、WAA（75.6%）、ASPIRE（71.7%）、RACaP（45.0%）；RL 增益幅度（+19.4）亦高于基于冻结 VLA 的 AgenticRoboRL（+5.9）。
  • 零样本迁移：SimplerEnv WidowX 83.3%；CaP-Bench 75.0（超过前沿模型与在该基准上 RL 训练的 7B coder）；仅经粗粒度仿真孪生适配后即可在真实机器人上运行。
  • 局限：RoboTwin 2.0（22.6%）与 RoboDojo（0.8%）迁移受限，主要因双臂协同与陌生机械臂运动学。
