Card 02 论文概述

论文概述

  • 论文研究 视觉–语言–动作（VLA） 策略在长时程、历史依赖操作任务中的记忆问题：当前观测 \(o_t\) 不足以决定正确动作，策略必须保留并复用历史信息。

Card 03 核心贡献

核心贡献

  • 从信息论与 POMDP 出发证明：最优记忆应最大化动作与记忆在当前观测下的条件互信息 \(I(a_t; m_t \mid o_t)\)，等价于最小化被丢弃的历史信息，并给出统一视角解释已有三类记忆方法。
  • 提出 D&R：把全历史的 top-\(K\) 选择递归分解为对 \(2K\) 个 token 的子问题，使用固定尺寸、轻量级的 selector，使记忆可支持无界历史且计算开销低。
  • 所有递归节点共享同一个 selector，捕捉各层共有的选择规则，进一步保持方法高效；训练与部署对相同前缀构建相同选择树，避免离线–在线不匹配。
  • 记忆保持在 VLA 预训练 token 空间中，是历史 token 的子集，既能被动作损失端到端优化，又能精确保留空间细节且可精确读回。
  • 在 RoboMME 的 16 个长时程任务上以仅 64 token 预算取得 SOTA 平均成功率，并在真机长时程任务、人工干预与感知噪声下取得最高成功率。
Card 04 方法描述

方法描述

  • 以 POMDP 建模模仿学习，将记忆定义为历史 token 的映射 \(m_t=\mathcal{M}(\mathcal{H}_t)\subseteq\mathcal{H}_t\)，预算 \(\|m_t\|\le K\)，目标为 \(\mathcal{M}^\star=\arg\max_{\mathcal{M}} I(a_t;\mathcal{M}(\mathcal{H}_t)\mid o_t)\)。
  • 通过变分下界把互信息目标转化为最大化策略动作对数似然 \(\mathbb{E}_{\mathcal{D}}[\log \pi_\theta(a_t\mid o_t,m_t)]\)，实际使用 π0.5 的 flow-matching 动作损失作为代理，同时优化策略参数与记忆。
  • 递归记忆机制：输入固定为 \(2K\) 个候选 token，selector \(f_\psi\) 输出 top-\(K\)；相邻块的保留结果两两合并后再次选择，逐层向上，最终根节点得到 \(K\) 个历史 token。
  • selector \(f_\psi\) 结构：冻结 SigLIP 编码 token，采用 M-RoPE 编码时间/高/宽位置，经 \(N\) 层 Transformer 自注意力与 FFN 后由线性头打分。
  • 选择采用直通式（straight-through）sigmoid 松弛：前向用硬选择，反向经软选择回传梯度；训练时向分数加入 Gumbel 噪声 以促进探索；根节点的选择掩码控制 action expert 对记忆 token 的注意力。
  • 记忆通过自适应 LayerNorm 调制进 action expert，动作特征与记忆 token 做交叉注意力。
Card 05 数据集与资源

数据集与资源

  • 使用 RoboMME 基准：16 个长时程操作任务，按六类功能特征分组（Motion-Centric、Time-Sensitive、Short-/Long-Horizon Video、Dynamic Scene-Change、Event-Salient）。
  • 在所有 16 个任务的 RoboMME 演示数据上多任务训练；所有方法基于 π0.5 骨干，冻结 SigLIP 编码器，微调 Gemma VLM、action expert 以及记忆模块（D&R 为 selector）。
  • 记忆预算统一为 64 token；策略预测 20 步动作块并执行前 16 步。
  • 训练 80k steps，batch size 为 64（TTT 为 16）。
  • 评估在每任务 50 episodes（共 800）上进行，最大 horizon 为 1,300 步，结果对最后 3 个 checkpoint 与 3 个随机种子取平均（共 9 次运行）。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboMME 的 16 个长时程操作任务，按四个套件与六类记忆需求分析；所有记忆方法共享 64-token 预算，仅填充内容不同。
  • 对比基线涵盖三类记忆：感知记忆 FrameSamp、TokenDrop；隐式记忆 HAMLET、RB-VLA；参数记忆 TTT；以及无记忆的 π0.5。
  • 主要指标为任务成功率；D&R 在 64-token 预算下取得 SOTA 平均成功率 38.6%，优于最佳隐式记忆的 32.2% 与无记忆策略的 17.9%。
  • D&R 在所有四类记忆需求上均领先：重复事件的计数累积、物体被遮挡后的追踪、回溯 episode 早期时刻、复现演示序列。
  • 在真机长时程任务、人为中途干预与感知噪声条件下，D&R 取得最高成功率。
