Card 03 核心贡献

核心贡献

  • 提出 GatedVLA 策略：VLM 主干 + 逐层 flow-matching DiT 动作专家，输出 25 步 [加速度, 曲率] 控制序列，重规划频率 0.5 s。
  • 设计带预算约束的软视觉掩码：以导航意图（目标点 + 自车状态）为查询对视觉 token 打分，通过二分法按构造精确满足预算 ρ=0.2，无需额外预算损失项。
  • 提出三路径自蒸馏训练（Path A 无门控教师、Path B 学生 DiT、Path C 仅更新门控模块），使掩码学会保留编码导航意图的视觉 token。
  • 引入纯相机、规则式 AEB 模块（RT-DETRv2-R18 检测 + 地面投影 + 纵向走廊匹配 + 沿路径重定时），仅在部署阶段生效，可即插即用于任意策略检查点。
  • 给出同一 150 场景、每场景两次 rollout 的配对闭环统计（bootstrap 置信区间 + 符号检验），并开源代码与完整配置。
Card 04 方法描述

方法描述

  • 输入：两帧前视广角相机图像（t₀ 与 t₀−0.1 s）+ 固定文本提示 “predict trajectory” 送入 VLM。
  • 自车状态与导航条件仅输入动作专家：5 个 10 Hz 历史步的 [x, y, heading, speed, a_lon]，拼接目标点 (x_tp, y_tp) 与二值存在标志；训练时目标点为 ≥25 m 的首个未来位置，部署时取地图路线上 25 m 处。
  • 动作专家：32 块 DiT，交替自注意力与交叉注意力，每个交叉注意力块对应一个 VLM 层（学习线性投影）；条件 flow matching + 速度 MSE，推理 10 步 Euler 积分；由单轮车（unicycle）动作空间积分得到位姿。
  • 视觉掩码：门控头输入 [h_p, q, h_p⊙q]，帧内标准化得 z_p，m_p = σ(b + 2z_p)，用 40 次二分求解 b 使每帧均值等于 ρ=0.2；将 log m_p 加到视觉 token 的交叉注意力 logits（文本 token 加 0、padding 加 −∞），VLM 内部表示不被掩码。
  • AEB 规则：7 类交通目标（置信度 >0.5），框底边中央 40% 投影到自车平面 z=0；1.3 m 横向走廊内最近目标给出弧长间距 d，用最近 1 s 的 d 线性回归估计接近速度 c。
  • 制动判定：g = d − 2.5 m − 0.4 s·c，a_req = c²/(2·max(g, 0.1 m))；当 g ≤ 0 或 a_req > 3 m/s² 时按 clip(1.2·a_req, 3, 8) m/s² 线性减速；d/c < 3 s 时限制不加速；AEB 释放后保持一拍再重规划。
Card 05 数据集与资源

数据集与资源

  • 训练数据：NVIDIA PhysicalAI-Autonomous-Vehicles 数据集训练集，仅使用前视广角相机流与自车轨迹，不使用 LiDAR、Radar 或机器生成感知标签。
  • 预训练权重：VLM 初始化自 Qwen-Drive-1.0-4B（Apache-2.0）；检测器为现成 RT-DETRv2-R18（PekingU/rtdetr_v2_r18vd，COCO 预训练，Apache-2.0）；无私有资源。
  • 模型规模：VLM 32 层、隐藏维 2560；动作专家 DiT 宽 1024、16 头×64 维、dropout 0.2；策略显存约 11.6 GiB，检测器额外约 0.2 GiB。
  • 训练配置：12 epoch / 38,400 步，1 个 Intel Aurora 节点、12 个 XPU tile（每 tile batch 4），bf16 + 梯度检查点，AdamW，学习率 VLM 1e-6 / 专家 5e-5 / 门控 1e-4，首 epoch 冻结 VLM（LP-FT 思路），seed 42。
  • 评估数据：固定 240 样本开环验证集（左转/右转/直行各 80）；闭环用从 441 场景筛选验证集中采样的同一 150 场景，dev 预设（40 m 路线偏移）。
  • 可复现性：代码 https://github.com/Azuma413/GatedVLA（main，commit 80ab247）；单 rollout 平均 Drive RPC 延迟 0.10–0.11 s。
Card 06 评估与结果

评估与结果

  • 开环（240 样本，step 38,400，基线/掩码）：ADE 0.337 / 0.341，FDE 1.029 / 1.023，Miss 0.125 / 0.125；左转 FDE 1.213 → 1.100、Miss 0.200 → 0.150；直行变差（0.737 → 0.879）；黑帧消融使 FDE 升至 1.408 / 1.564，说明视觉证据对规划影响很大。
  • 闭环（150 场景，两次 rollout）：基线均分 0.479 → 掩码 0.517（配对差 +0.038，95% bootstrap CI [−0.018, +0.093]，胜/负 37/26，符号检验 p=0.21，不显著）。
  • 加 AEB@10 Hz：均分升至 0.599（+0.082，CI [+0.023, +0.143]，41/28，p=0.15）；有责碰撞场景数均值从 34.0 降至 11.0。
  • AEB@5 Hz vs 10 Hz：−0.009（CI [−0.065, +0.044]，34/34，p=1.00），频率差异不显著。
  • 代价与局限：AEB 使被追尾场景 15 → 25（仿真中不计责但现实有风险），且 3 个原本满分场景出现新碰撞；剩余 12 起有责碰撞中 6 起源于横向偏移约 2 m、过晚进入 1.3 m 走廊的目标；横向失效（越野/出走廊）占 0.393 总失分中的 0.253，纵向 AEB 无法缓解；AEB 阈值在同样 150 场景上调参，泛化增益可能偏乐观。
