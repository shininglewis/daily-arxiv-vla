Card 02 论文概述

论文概述

  • 论文关注 VLA（Visual Language Action）模型 在多机器人及人机协作场景中的能力不足问题。
  • 指出现有 VLA 模型即使在单机器人任务数据上微调，也难以在去中心化协作任务中协调动作。
  • 提出 Co2Gen 框架，无需多机器人人类遥操作数据，自动生成协作任务规划与协作演示数据，用于去中心化 VLA 微调。
Card 03 核心贡献

核心贡献

  • 证明 VLA 模型在仅使用单机器人任务演示微调时，无法泛化到简单协作任务，缺乏协调行为。
  • 证明使用 多机器人协作演示数据微调 能显著提升 VLA 在去中心化协作任务中的表现。
  • 提出 Co2Gen：利用 VLM 与协作式 MCTS 自动生成可执行的 Python 协作计划，将单机器人技能组合为多机器人协作计划。
  • 提出无需多机器人人类遥操作的 协作数据生成流程，并支持每个机器人基于本地数据流进行去中心化 VLA 微调。
  • 展示 Co2Gen 数据微调的 VLA 能匹配人类遥操作协作数据微调的 VLA 性能，并扩展到 零样本人机协作。
Card 04 方法描述

方法描述

  • 协作计划生成模块：两个 VLM 代理分别作为 actor 和 critic，输入俯视相机图像、协作任务提示和可用技能集合。
  • 协作式 MCTS：通过 Selection、Expansion、Evaluation、Backpropagation 迭代优化可执行 Python 计划；评分标准包括 Progress Score、Distribution Score、Condition Check Score。
  • 任务执行模块：协作计划通过 VLM 查询子任务前置条件，并结合 YOLOv8、混合 blob 检测、IK 求解器 和腕部相机执行底层技能。
  • 协作数据生成：引入 human verifier 检查任务是否成功，避免 VLM 误判导致错误轨迹进入数据集。
  • 去中心化 VLA 微调：将协作数据拆分为各机器人本地数据流，分别微调每个机器人的 VLA；还提出将 Co2Gen 数据与单臂人类演示数据混合，以兼顾协调信号和轨迹多样性。
Card 05 数据集与资源

数据集与资源

  • 使用 两个协作任务：Collaborative Storage Task 和 Collaborative Stacking Task。
  • 每个任务收集 50 个 episode 的演示数据，微调 20,000 steps，并使用 DAgger 收集额外纠正数据。
  • VLA 模型使用轻量级 SmolVLA，具体为 smolvla_base。
  • 规划与语义前置条件检查使用 GPT-5.6，具体为 gpt-5.6-sol。
  • 机器人平台为双臂低成本 SO-101 机械臂，配备 ZED2 俯视立体相机 和腕部相机。

Card 06 评估与结果

评估与结果

  • 在 Collaborative Storage 和 Collaborative Stacking 两个任务上评估去中心化协作执行与人机协作。
  • 主要指标包括 Task Success Rate（TSR）、Task Score（TS） 和 Sub-Task Success Rate；每个任务最高任务分为 14。
  • 对比基线包括 VLA_SA（单臂人类演示）、VLA_BM（双臂人类遥操作协作演示），以及 VLA_Co2Gen 和 VLA_Co2Gen+SA。
  • VLA_SA 表现最差，两个机械臂缺乏协调信号，常出现同时伸向柜子或堆叠碰撞。
  • VLA_BM 明显优于 VLA_SA，但去中心化任务成功率仍低于 50%，协调信号触发不稳定。
  • VLA_Co2Gen+SA 在 Storage 任务上匹配 VLA_BM 的性能（误差范围内），在 Stacking 任务上超过 VLA_BM。
  • 人机协作实验中，整体成功率高于多机器人去中心化执行；人类伙伴更能适应 VLA 策略，但协作数据仍显著影响表现。
