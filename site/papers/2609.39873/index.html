SplineWAM: Adaptive Action Horizons for World Action Models via B-Spline Representations

2026-09-30 · 原文 · 翻译 · 2609.39873

论文针对 World Action Models（WAMs，世界动作模型） 普遍采用固定长度、均匀时间网格的动作块（action chunk）这一问题，提出 SplineWAM。 核心思想是用固定数量的 三次 B 样条（cubic B-spline）节点时间与控制点 替代固定动作块，使一个参数预算可解码出不同时间分辨率与不同时长的动作序列。 目标是让"预测参数量、实际执行步数、预测时间分辨率"三者解耦：自由空间运动用长块少调用，接触密集阶段用短块精细重规划，从而在保持甚至提升成功率的同时降低云端推理调用次数。

Card 02 论文概述

论文概述

  • 论文针对 World Action Models（WAMs，世界动作模型） 普遍采用固定长度、均匀时间网格的动作块（action chunk）这一问题，提出 SplineWAM。
  • 核心思想是用固定数量的 三次 B 样条（cubic B-spline）节点时间与控制点 替代固定动作块，使一个参数预算可解码出不同时间分辨率与不同时长的动作序列。

Card 03 核心贡献

核心贡献

  • 在 WAM 的动作分支中引入 B 样条动作表示，并将视频监督对齐到示教轨迹拟合得到的 节点时间（knot times），使参数预算固定而表示时长可变，让预测自身携带未来时域与分辨率。
  • 提出 JP-RTC（Jacobian-Pullback Real-Time Chunking）：把块连续性约束施加在解码后的原始动作上，并通过解码器的局部 Jacobian 将其"拉回"到样条参数空间，实现可异步部署的高效自适应推理。
  • 在 LIBERO-Plus 与 RoboCasa 两个仿真套件上相比动作分块 WAM 提升 8.2 与 4.4 个成功率点，同时每回合策略调用次数减少 22% 与 26%。
  • 在三个双臂真实机器人任务（异步执行）上于六项精度指标中的四项超过固定块基线、第五项打平，每次调用解码 1.2~1.6 倍 的执行动作量。
Card 04 方法描述

方法描述

  • 架构：仅改动 WAM 的动作分支。视频帧编码为 latent，与 B 样条动作窗口分别加噪、使用各自的 flow matching 时间步，在共享注意力掩码下联合处理；动作损失定义在 样条参数 上而非解码动作上。
  • B 样条动作曲线：用 3 次 B 样条表示动作轨迹，所有动作维度共享同一 节点向量 U，控制点为 C，解码器 D 在整数控制步上求值得到可执行动作；策略只预测固定大小的局部窗口而非整条轨迹。
  • 自适应节点拟合：采用类似 FITPACK 的误差驱动节点插入循环（在残差最大处插节点），在归一化动作空间中以最大逐元素偏差 E_max 低于容差 ε 为停止条件；平滑段用少量节点，接触/高曲率段吸引密集节点，容差 ε 是唯一可调参数。
  • 视频–动作时间对齐：对比 时间窗对齐（均匀网格）与 节点网格对齐（沿节点按固定步长取未来帧，重复尾节点作 padding）；后者让视频监督与动作监督共享非均匀时间结构，在动作复杂处监督最密。
  • 推理与自适应时域：解码窗口在整数偏移处得到 M = ⌊t_max⌋+1 个动作，M 由预测节点时间决定而非行数决定；执行时给定行预算 H ≤ L_BSP，执行跨度与重规划间隔随任务阶段变化。
  • JP-RTC 关键公式：在解码动作上构造残差 r_S，用 **δ* = J_Sᵀ(J_S J_Sᵀ + λI)⁻¹ r_S 修正采样速度，引导权重沿用 RTC；对逐时间步动作块，J_S** 退化为行选择，公式回到普通 RTC，故 JP-RTC 是 RTC 的严格推广。

Card 06 评估与结果

评估与结果

  • 对比基线：Action Chunking（原始 Fast-WAM 动作块）、BEAST（固定时长 B 样条 token 化）、Naive B-Spline（无本文对齐策略）、Naive B-Spline w/o video（去掉视频辅助项，λ_v = 0）。
  • 主要指标：成功率（Success）、每回合策略调用次数（Calls/ep.）、每次调用执行的控制步数（Steps/call）；真实机器人用 SR（全部任务节点完成）与 PG（节点到达比例）、Chunk（每调用执行步数）。
  • 仿真结果：SplineWAM-Knot 在 LIBERO-Plus 达 74.5%（基线 66.3%，+8.2），RoboCasa 达 73.5%（基线 69.1%，+4.4）；调用次数分别为 26.2 vs 33.6 与 16.3 vs 21.9（降 22% / 26%）。
  • 消融结论：节点网格对齐优于时间窗对齐（+1.2 / +1.6 点）；BEAST 未获益（LIBERO-Plus +0.3，RoboCasa −4.1），说明收益来自"时长可变"而非仅样条参数化；移除视频监督项损失 10.7 与 14.5 点。
  • 容差与执行长度消融：紧容差一侧曲线平坦（少量压缩即获得大部分收益，说明增益主要来自连续平滑表示），过松则跌破动作分块基线；在相同推理成本下达到基线最佳精度需 2.2 倍（RoboCasa）/ 2.5 倍（LIBERO-Plus） 更少的策略调用。
  • 真机结果：JP-RTC 在六项精度指标中四项领先、一项持平，Clean Whiteboard 优势最大（SR +10.0、PG +6.7）；Naive RTC 虽解码更长的块，但在三个任务上均明显更差；唯一劣势在 Charge Earphone 的插座插入阶段，反映连续表示在接触精度上的代价。
