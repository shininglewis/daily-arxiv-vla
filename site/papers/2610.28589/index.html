Card 02 论文概述

论文概述

  • 论文提出 AgenticRoboRL，将编码智能体的“监督微调 + 多轮强化学习”后训练范式迁移到机器人规划器，提升智能体机器人系统自身规划能力。

Card 03 核心贡献

核心贡献

  • 作者称据其所知，AgenticRoboRL 是首个面向智能体机器人系统的通用规划器后训练框架。
  • 提出“先用成功示范做 SFT，再用多轮 RL 精炼”的训练配方，只优化规划器，保持 VLA、运动控制器等执行组件冻结。
  • 设计轻量级、框架特定的适配器，将记录到的规划器调用与任务结果关联，无需在不同机器人框架间统一低层动作表示。
  • 在 LIBERO-PRO 上把 9B 规划器成功率从 18.1% 提升到 71.0%，接近带外部记忆的 Codex (GPT-5.5) 的 72.1%；在 CaP-X 上从 2.7% 提升到 28.5%。
Card 04 方法描述

方法描述

  • 系统由规划器和机器人执行框架组成；规划器输出框架原生响应，如结构化工具调用或可执行 Python 控制代码，框架执行后返回观测与反馈。
  • 训练接口放在“模型调用边界”而非低层动作边界；记录代理保存每次请求的上下文、生成 token ID 与 rollout log-probabilities，避免依赖重建完整轨迹。
  • 框架特定适配器为每个 episode 报告任务、初始状态 ID、尝试序号、奖励和有效性标志；基础设施失败被排除，任务失败保留为零奖励样本。
  • SFT 阶段使用教师轨迹初始化规划器；对 RPent 重构学生上下文并处理记忆依赖响应，对 CaP-X 直接重渲染提示并使用教师输出 token 作为目标。
  • RL 阶段使用任务成功作为唯一终端奖励，采用 leave-one-out 组内优势与双裁剪 PPO 损失，不使用学习型 critic，并按策略版本分轮收集与更新。
Card 05 数据集与资源

数据集与资源

  • 主要评估使用 LIBERO-PRO，包含位置交换与任务扰动等 8 个评估套件，共 800 个 episode。
  • 鲁棒性评估使用 LIBERO-Plus，覆盖相机、机器人初始状态、语言、光照、背景、噪声、布局等扰动，共 10,030 个配置。
  • 泛化实验使用 CaP-X 框架，并在 LIBERO-PRO 的 Object、Goal、Spatial 套件上评估，共 60 个任务。
  • 学生规划器为 Qwen3.5-9B，教师规划器为 Qwen3.8-27B；学生评估时不访问外部记忆。
  • 数据划分为：评估初始状态 1–10，教师示范与 RL rollout 使用状态 11–44，状态 45–49 用于验证与检查点选择。
  • 提供的原文未明确给出 GPU/TPU 型号与数量；训练规模包括 RPent SFT 626 步、CaP-X SFT 37 步，RPent RL 收集 2,304 个 episode、26,052 个响应并执行 206 个优化步。
Card 06 评估与结果

评估与结果

  • 评估指标为任务成功率；主要在 LIBERO-PRO、LIBERO-Plus 和 CaP-X 框架中比较原始、SFT 与 RL 检查点。
  • 在 LIBERO-PRO 上，9B 规划器从 18.1% 提升到 SFT 的 65.1%，RL 后达到 71.0%，RL 额外带来 5.9 个百分点提升。
  • 该 9B RL 规划器超过无记忆的 27B 规划器 57.9%，接近带记忆的 27B 教师 74.0% 和带记忆的 Codex (GPT-5.5) 72.1%。
  • 在 LIBERO-Plus 上，同一检查点从 19.2% 提升到 SFT 的 66.7%，RL 后达到 72.2%；在未用 LIBERO-Plus 训练的方法中总体成功率最高。
  • 在 CaP-X 控制代码生成框架中，后训练将成功率从 2.7% 提升到 28.5%，说明方法可跨不同机器人执行框架迁移。
