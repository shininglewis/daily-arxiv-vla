论文概述

  • 论文研究 Vision-Language-Action（VLA）模型 在闭环机器人控制中的高推理成本问题，目标是在不额外训练的情况下降低视觉计算量。

Card 03 核心贡献

核心贡献

  • 提出 ActPrune，一种 training-free 的视觉 token 剪枝框架，可直接从机器人动作导出几何先验，并将剪枝决策提前到视觉编码器之前。
  • 发现同一动作在 固定第三人称视角 和 腕部视角 中产生不同的冗余模式，并设计视角特定的剪枝策略。
  • 在 LIBERO 和 VLABench 上取得领先的效率表现，最高实现 1.61× 加速 和 59.5% FLOPs 降低，同时保持有竞争力的任务成功率。
  • 在 7-DoF Franka Research 3 真实机器人平台上验证了方法的实际优势。
Card 04 方法描述

方法描述

  • 使用上一时刻预测的动作 chunk A_{t-1}，预测末端执行器未来轨迹，并将其投影到第三人称相机图像平面。
  • 在 第三人称视角 中，保留投影轨迹周围的 patch 区域，并结合从首帧注意力得到的 semantic anchors 保留任务相关静态区域。
  • 在 腕部视角 中，利用深度图将上一帧 patch 反投影到 3D，再按动作引起的相机运动重投影到当前视角，通过余弦相似度剪除运动补偿后仍冗余的 patch。
  • 被剪除的 patch 不直接丢弃，而是合并为粗粒度 context tokens，以保留粗略内容。
  • 采用两级预算分配：patch-level pruning 在编码前执行，剩余预算以 embedding-level pruning 在编码后根据编码器注意力完成。
  • 总保留比例满足 γ = γ_patch + γ_embed，方法无需额外训练。

Card 06 评估与结果

评估与结果

  • 评估环境包括 LIBERO、VLABench 仿真环境和真实机器人平台。
  • 主要指标：成功率（Success Rate）、FLOPs、端到端推理延迟 和 相对原始模型的加速比。
  • 对比基线包括通用 token 剪枝方法 FastV、SparseVLM、DivPrune，以及 VLA 专用方法 VLA-Cache、VLA-Pruner、SpecPrune-VLA。
  • 在 OpenVLA-OFT + LIBERO 上，25% token 保留率时 ActPrune 达到 96.1% 平均成功率、1.921T FLOPs、53.61 ms 延迟 和 1.61× 加速。
  • 在 OpenVLA-OFT + LIBERO 上，50% 保留率时达到 96.9% 平均成功率、1.33× 加速；12.5% 保留率时仍保持 88.6% 平均成功率 和 1.66× 加速。
  • 在 π_{0.5} + LIBERO 上，25% 保留率时 ActPrune 平均成功率为 91.8%，FLOPs 为 3.063T；12.5% 保留率时平均成功率为 74.0%。
  • 给定原文的 VLABench 表格显示，π_{0.5} 原始平均成功率为 42.0%，ActPrune 在 50% 保留率下平均成功率为 26.3%、FLOPs 为 3.019T；原文后续结果被截断。
