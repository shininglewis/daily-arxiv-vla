Asynchronous Robot Policies

Card 02 论文概述

论文概述

  • 论文提出 Asynchronous Robot Policies（ARP），一个将高层语义推理与底层动作生成解耦为异步双频环路的机器人策略架构框架。
  • 研究目标是解决现有 VLA（Vision-Language-Action） 模型的根本矛盾：扩大 VLM 规模能提升语义能力，但推理延迟会拖垮实时物理反应性。
  • 核心问题是：如何在保留大规模基础模型语义能力的同时，维持高频率的感知—动作闭环，以应对动态扰动、接触动力学等实时任务。
Card 03 核心贡献

核心贡献

  • 提出首个真正意义上的异步机器人控制框架：慢语义环（VLM 语义专家） 与 快动作环（视觉-动作专家） 以互不相同的频率独立运行，控制延迟不再随 VLM 规模线性增长。
  • 设计固定宽度的语义记忆（semantic memory） 接口：将 VLM 多层 KV cache 激活压缩投影为与骨干规模无关的 S×D 表示，实现速率解耦。
  • 显式建模并训练异步带来的两类失配：语义记忆陈旧度 d_t 与 执行延迟 ℓ_t，通过陈旧度正弦嵌入与 AdaRMS 条件注入动作专家。
  • 提出陈旧语义记忆训练策略：在训练中从离散混合分布采样历史帧与延迟，使策略能在时间错配的观测—记忆对上稳健执行。
  • 验证了 ARP 可扩展到 14B 级别语义骨干，并支持将 VLM 以低于标称频率 10× 运行而无显著性能损失。
Card 04 方法描述

方法描述

  • 慢语义环：VLM 周期性处理第三人称视角图像与语言指令，抽取 L 层 KV cache，经 LayerNorm + 线性投影、位置嵌入 P 与陈旧度嵌入 E_stale(d_t) 得到语义记忆 M_τ。
  • 快动作环：轻量级 N_AE 层双向 Transformer 融合多相机视觉 token、本体状态、register token 与动作 token，通过各层 cross-attention 持续读取语义记忆。
  • AdaRMS 条件化：以 flow-matching 时间步 τ_i 与延迟特征 [d_t ∥ ℓ_t] 联合调制归一化，兼顾去噪进度与系统延迟鲁棒性。
  • 陈旧训练：训练时按 d_t ~ p₀δ₀ + (1-p₀)U{1,…,d_max} 采样时间错配帧对，延迟 ℓ_t 取自实测运行时延迟经验分布；默认范围 U{1,…,40}。
  • 部署技巧：采用 prefix action conditioning（d=8）实现平滑在线重规划；LIBERO 上用 LoRA 微调、冻结 InternVL-4B 的 ViT 编码器以隔离 LLM 规模变量。
Card 05 数据集与资源

数据集与资源

  • LIBERO：4 个任务套件、40 个任务、约 2,000 条示范，每套件评测 500 回合。
  • LIBERO-Perturb（论文自建）：从 Spatial/Object 套件选 10 个任务，末端接近 10 cm 时对目标施加 5 cm 确定性横移。
  • Dynamic Bump Benchmark（论文自建，基于 Robosuite）：追踪运动目标，中途施加最大 ±100° 的航向速度脉冲。
  • DROID 大规模真实数据集（15 Hz），并在 RoboLab 仿真与 Franka 真机上评测。
  • 模型规模：LIBERO 上 ARP-1B / 2B / 8B / 14B（InternVL LLM 骨干）；DROID 上用 PaliGemma-3B 作语义骨干 + DINOv3 作视觉-动作专家编码器。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO / LIBERO-Perturb / Dynamic-Bump 仿真、RoboLab 仿真、Franka 真机；基线为 π₀ 系列（1B/8B、π₀.₅-DROID）与 Diffusion Policy。
  • 主要指标：任务成功率 SR%、执行时间、平均回合长度、EE 平滑度（ISJ、SPARC）。
  • 准静态（RQ1）：LIBERO 平均成功率 ARP-8B 89.3%、ARP-14B 89.1%、ARP-2B 86.6%、ARP-1B 84.8%，均高于 π₀ 系列（最高 94.2% 的预训练版之外，π₀-1b-replicated 仅 80.2%、8b-replicated 82.7%）。
  • 真机（Franka-DROID）：成功率高出约 18%、执行时间少约 20%；RoboLab 上平均回合长度比 π₀.₅-DROID 低 20%，整体性能相当。
  • 动态响应（RQ2）：LIBERO-Perturb 上 ARP-1B 51.5% vs π₀-1B 9.5%；Dynamic-Bump（p=1）44.7% vs 12.7%，（p=0.5）46.7% vs 20.0%，约为基线 3–5×。
  • 算力鲁棒性（RQ3）：VLM 吞吐受限时 ARP-1B 保持 79.0%–84.8%，而同步基线从 81.5% 崩落至 45.0%（下降超 36 个百分点）。
  • 消融（RQ4）：无陈旧训练（d_t≡0）在 0.5 Hz 下仅 2.0%，默认 U{1,…,40} 仍保持 81.8%，U{1,…,80} 在 1 Hz 下达 87.5%；ARP-DROID-RTC 相比普通部署成功率 +5.6pp（31.9%→37.5%）、时间 -15.3%、运动更平滑。
