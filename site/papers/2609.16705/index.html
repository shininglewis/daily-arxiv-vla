Card 02 论文概述

论文概述

  • 提出 Robot Data Factory (RDF)，一个以任务（mission）为驱动、闭环运行的“训练场”框架，用于持续生成、验证和工程化机器人经验
  • 核心论点：Physical AI 的关键稀缺资源不是数据体量，而是 high-performance physical experience——保留感知–动作–后果闭环、可复现、有明确任务与具身参照、具备可测量物理结果的交互经验
  • 针对现有机器人数据集与基准的局限（单一平台采集、任务专用协议、缺乏外部真值、静态评测）提出统一基础设施
Card 03 核心贡献

核心贡献

  • 提出任务驱动方法论，形式化为 Mission → Task → Skill → Episode → Dataset → Benchmark → Capability 层级
  • 提出基准评测公式：显式加权任务分数与难度乘子，并配套任务级（mission-level）与技能级（skill-level）指标
  • 设计 cyber-physical flywheel（赛博–物理飞轮），把数据生成、模型训练、物理与仿真部署耦合为单一可度量改进回路
  • 实现三个多舱室训练场（Home、Environment、Energy），配套 agentic robot network、数据流水线与可运行排行榜
  • 给出闭环机器人数据生产中算力与存储扩展律的定量分析
Card 04 方法描述

方法描述

  • 将机器人经验形式化为耦合子系统轨迹：机器人 S_R、物体 S_O、环境 S_E、其他智能体 S_A 的广义状态描述子 ξ_i 与复合状态 Ξ(t)
  • 区分真实物理轨迹 **E*_T 与观测记录 E_T = O(Ξ(t))，并据此定义经验质量 Q_E = Q(Q_obs, Q_phys)**（观测保真度 + 物理交互信息量）
  • 四大原则：任务驱动、生成回路（非固定数据集）、多舱室/环境专用、以能力为中心（技能为可复用单元）
  • 闭环机制为 Deploy → Measure → Learn → Repeat，由 Mission-Control 仪表盘、Ubiquitous Data Pipeline、基准框架与 Pitstop Leaderboard 支撑
  • 强调人类表现作为金标准（Gold Standard is Human Performance），并规划向联邦式 Robot Data Factory 演进
Card 05 数据集与资源

数据集与资源

  • 三阶段落地：Phase 1 三个舱室（Home 家庭服务、Environment 海洋与户外、Energy 基础设施巡检）及数据流水线、排行榜已在 MBZUAI 运行；Phase 2 扩展任务库、具身与数据集/基准发布
  • 硬件系统模型（附录 C）：Energy 舱室采用 B2 移动机器人，Home 舱室采用 WidowX 机械臂

Card 06 评估与结果

评估与结果

  • 评估载体为 Pitstop Leaderboard 与任务级基准，外部算法可在共享物理平台上于相同真实条件下评测，实现可复现对比
