Card 02 论文概述

论文概述

  • 论文提出 VLA-ULAP，一种将云端 VLA（视觉-语言-动作）大模型调用与机器人端超轻量本地动作预测器 ULAP 交织执行的混合推理框架，兼顾任务成功率、响应速度与低功耗。
  • 解决的问题是：Billion 级参数的 VLA 策略在机器人本体运行功耗极高（如 GR00T N1.7 在 RTX A6000 上约 234–284 ms/次、108 W，58 Wh 电池仅能支撑约 32 分钟），而远程推理又引入约 25 ms 通信延迟与抖动，导致观测过期、动态任务响应不及时。
  • 目标是让本地决策无需服务器往返即可响应最新观测，同时周期性调用远程 VLA 保留基座策略能力，从而减少高功耗请求、延长电池续航并提升多机器人共享 GPU 的吞吐。
Card 03 核心贡献

核心贡献

  • 提出一种自包含、以已执行动作历史为条件的预测器，用单次前向传播的本地动作块替换完整 VLA 调用，不修改基座模型、不需要其隐藏状态。
  • 提出可部署于低功耗边缘设备的分离式推理框架，减少每台机器人的重负载请求，与共享 GPU 调度方案互补，为更多机器人释放推理容量。
  • 在 GR00T N1.7、VLA-JEPA（LIBERO）、Cosmos-Policy（RoboCasa）及物理 SO-101 任务上验证了成功率保持能力，并给出 Jetson Orin Nano 实测数据。
  • 通过 LIBERO-Safety 的延迟感知评估，证明快速本地更新不仅能降本，还能在动态任务中提升成功率（较 π0.5 提升 11.0 与 15.5 个百分点）。
  • 与 ACT、SP-VLA、RT-Cache 等本地加速/替代方案对比，展示更优的成功率—成本前沿。
Card 04 方法描述

方法描述

  • ULAP 架构：冻结的 Theia-Tiny 视觉编码器（5.52M 参数）+ 紧凑 Transformer（1.422M）+ 状态 MLP（350.8K）+ 并行动作头（89.4K），在线总计约 7.4M 参数，约为 3B 参数 GR00T N1.7 的 1/400。
  • 状态响应性：输入为当前相机视图 I_t、机器人本体状态 p_t、前 H 个已执行动作 A⁻_t（无论由 VLA 还是 ULAP 产生）以及任务条件 c，即 Â_t = g_θ(I_t, p_t, A⁻_t, c)，用以区分接近、抓取、撤离等外观相似阶段。
  • 独立性：动作头一次前向并行输出整段 H 步动作块，无自回归展开、无迭代去噪，不依赖 VLA 隐藏状态、在线验证或服务器往返，因而可在边缘设备本地运行。
  • 训练与执行：仅训练预测器，VLA 与 Theia 冻结；用示范数据或基座策略成功轨迹以 Smooth-L1 损失监督；部署时首个决策调用 VLA 初始化动作历史，随后由固定调度器将本地预测尽可能均匀地插入 VLA 调用之间，每次本地决策均基于最新观测生成新动作块。
  • 可选风险感知调度：以与任务训练嵌入的均方距离作为风险代理并映射为校准百分位，在高风险输入上优先安排更早的 VLA 调用（受调用预算与本地连续段长度约束），仅改变调用时机而非预测方式。
Card 05 数据集与资源

数据集与资源

  • 数据集/基准：LIBERO（40 个任务，16 步 chunk；含 LIBERO-Safety）、RoboCasa（24 个任务，官方物体泛化协议，训练 split A / 测试 split B）、物理 SO-101 机器人（乒乓球入碗、胶棒入杯两项抓放任务）。
  • 模型规模：ULAP 在线模型约 7.4M 参数（1.86M 可训练 + 5.52M 冻结视觉参数）；对比的基座 VLA 包括 GR00T N1.7（3B）、VLA-JEPA、Cosmos-Policy、π0.5。
  • 训练资源：在单张 RTX A6000 GPU 上训练数百条 episode 仅需数分钟。
  • 推理硬件：边缘端 Jetson Orin Nano，服务器端 RTX A6000。
Card 06 评估与结果

评估与结果

  • 评估环境：三个仿真基座策略/基准组合（LIBERO × GR00T N1.7、LIBERO × VLA-JEPA、RoboCasa × Cosmos-Policy）、真实 SO-101 机器人、Jetson 端侧测量，以及 LIBERO-Safety 延迟感知仿真；每个仿真点使用 1,200–2,000 条 episode。
  • 主要指标：任务成功率及其相对基座的保持率、VLA 调用削减比例、每次成功 episode 的推理时间/GPU 能耗加速比、单次推理延迟与能耗。
  • 关键结果：

- 仿真中在选定工作点减少 48.8%–76.7% 的 VLA 调用，仍保留基座 95.0%–97.5% 的成功率（如 LIBERO×GR00T 减 50.7% 调用成功率 88.50%，保留 95.0%；LIBERO×VLA-JEPA 减 76.7% 调用成功率 94.65%，保留 95.8%；RoboCasa×Cosmos 减 48.8% 调用成功率 64.08%，保留 97.5%）。

- 端侧效率：ULAP 在 Jetson Orin Nano 上单次推理 19.9 ms / 0.183 J，对比 GR00T 在 RTX A6000 上的 284.3 ms / 50.55 J（时间减少约 93.0%，能耗减少约 99.6%）。

- 与本地加速方案对比（LIBERO×VLA-JEPA）：相较 ACT（94.15% 成功率）在 94.65% 成功率下少用 49.2% 推理时间和 51.0% GPU 能耗；在同等 87.25% 成功率下相较 SP-VLA 最激进设置少用 77.1% 时间与 79.9% 能耗；RT-Cache 独立运行峰值仅 69.10%，ULAP 以 91.45% 成功率仍比其少用 16.4% 时间与 32.5% 能耗。

- 真实机器人：在训练内与留出摆放位置上保留基座 95.2%–100% 成功率，成功 episode 的平均调用数减少 52.3%–62.8%，推理时间估计减少 47.9%–58.0%，推理设备能耗减少 52.1%–62.5%。

- 动态任务：LIBERO-Safety 上较 π0.5 在两个任务上分别提升 11.0 与 15.5 个百分点，同时将 VLA 调用约减半。

- 风险感知调度在固定调度基础上带来稳定的小幅增益：LIBERO×GR00T 上 0.45–2.00 个百分点，RoboCasa 上 0.08–0.92 个百分点。
