Card 02 论文概述

论文概述

  • 论文研究 World Action Models（WAMs），即基于预训练视频扩散骨干网络、联合预测未来视觉观测与机器人动作的机器人控制范式。
  • 核心问题：WAM 沿用视频预训练中“对所有视觉区域一视同仁”的视觉预测目标，但不同区域对机器人控制的相关性并不相同。
  • 论文发现将视觉监督向动态区域（机器人运动、物体交互）倾斜能显著提升策略性能，并据此提出新的视觉预测任务 MoGAP。
Card 03 核心贡献

核心贡献

  • 通过一个直观的激励性研究（motivating study）证明：视觉监督的空间分配方式对下游控制性能有实质性影响，应作为 WAM 的重要设计考量。
  • 提出 Motion-Guided Asymmetric Prediction（MoGAP）：让模型从损坏较轻的静态区域作为上下文，去预测损坏更严重的动态区域，无需外部教师模型或额外模态。
  • 在多种 WAM 架构、仿真基准与真实机器人上验证 MoGAP 带来一致且显著的性能提升。
  • 在真实 OpenArm 人形机器人上展示出对执行中目标物体被移动（未在训练中出现）的鲁棒自适应能力。
Card 04 方法描述

方法描述

  • 沿用标准 WAM 框架：以流匹配（flow matching）在预训练视频自编码器的隐空间联合训练视频预测损失与动作预测损失。
  • 运动分数：由干净视频隐帧间时序差分计算，m_{n,p}=‖z_{t,n,p}-z_{t,n-1,p}‖₂，可归一化后作为加权监督的权重。
  • 非对称噪声分配：将扩散加噪视为部分掩码；对运动分数阈值化得到二值运动掩码，动态区域使用更高噪声步 τ_v⁺ = τ_v + (1-τ_v)ξ，静态区域保留基础噪声 τ_v。
  • 只在运动 token 上计算流匹配损失，并对每个时序切片按选中位置数归一化，避免运动区域占比影响总损失权重。
  • 训练专用辅助路径：MoGAP token 与原始 WAM 输入在共享视频扩散骨干中并行处理，不增加参数；通过非对称注意力掩码保持原路径独立（原 WAM token 不能关注 MoGAP token）；推理时省略 MoGAP token，推理流程不变。
  • 总损失 L = L_video + λ_action·L_action + λ_MoGAP·L_MoGAP，其中 λ_MoGAP = 1.0。
  • 多视角适配：对两个外置相机视角应用运动引导噪声分配，腕部相机视角 token 全部划入高噪声组（腕部相机自运动易主导运动分数）。
Card 05 数据集与资源

数据集与资源

  • RoboCasa GR-1 Tabletop：24 个桌面人形操作任务，用于主实验、对比与消融。
  • RoboCasa-Kitchen：24 个单臂机器人厨房操作任务，三视角配置，用于多视角验证。
  • 真实世界：OpenArm 人形机器人（双 7-DoF 臂 + 双 Inspire RH56F1 五指 6-DoF 手 + 第一人称立体相机）。
  • 主 WAM 骨干为 Cosmos3-Nano（16B 参数），另验证 Fast-WAM（Wan2.2-5B 视频扩散骨干）。
  • 训练：仿真基准 16K 梯度步、真实实验 8K 梯度步，全局批大小 256；仿真每个任务评估 50 次，共 1200 次 rollout。
  • 推理：单步去噪、无 CFG、缓存文本嵌入并省略 VAE 解码器，在单张 RTX 5090（32GB） 上实现 48ms 延迟。
  • 代价：训练因额外 token 使实际耗时增加 1.26 倍。
Card 06 评估与结果

评估与结果

  • GR-1 Tabletop 主结果：Cosmos3-Nano 平均成功率由 52.3% → 62.3%（+10.0），超越所有对比的 VLA（GR00T-N1.6 47.6、StarVLA-α 57.3、RLDX-1 58.7）与 WAM（Fast-WAM 38.8、DiT4DiT 50.8）方法。
  • 按任务类型：Pick-and-Place 由 48.3% → 60.8%（+12.5），Articulated 由 64.3% → 66.7%。
  • 对比教师监督方法（同一 Cosmos3-Nano 基线）：Geometry Forcing 53.9、AGRA 55.4、TSA 56.8、VideoREPA（VideoMAEv2）57.8、VideoREPA（V-JEPA2.1-L）59.2，MoGAP 以 62.3% 领先且无需外部教师。
  • 跨架构泛化：Fast-WAM（Wan2.2-5B）由 38.8% → 47.5%。
  • 消融：去掉辅助路径 54.4、去掉噪声非对称性 55.3、反转非对称方向 55.2，均显著低于完整 MoGAP 的 62.3。
  • 多视角：在 RoboCasa-Kitchen 上稳定优于 Cosmos3 基线，并保持长执行时域优势。
  • 真实机器人：三类任务（In-Domain、OOD 物体与环境、OOD 物体移位）上均一致提升，物体移位任务增益尤为明显。
  • 分析：运动分数区域 AUROC 为运动手臂 0.887、被操作物体 0.834、背景 0.430；动作到视觉的注意力比值为手臂 1.80→2.07、物体 2.00→2.29、背景 0.86→0.82；生成视频中运动手臂结构更清晰。
