FACT: Failure-Aware Causal Training for World-Action Models

Card 02 论文概述

论文概述

  • 论文提出 FACT（Failure-Aware Causal Training），一种 因果 World-Action Model（世界-动作模型），用于双机械臂操作任务的语言条件策略学习。
  • 核心问题：现有世界-动作模型（WAM）主要利用成功演示进行训练，模型缺乏预测错误动作后果的能力，导致在测试时面对错误动作会"幻觉"出成功导向的未来画面。
  • FACT 的关键思路是先产生动作，再预测该动作所导致的未来视频和任务进度，使失败轨迹（failure rollouts）能够作为动作后果的监督信号参与训练，而不必成为动作模仿的目标。
Card 03 核心贡献

核心贡献

  • 提出 FACT，一种采用 "动作-然后-未来"（action-then-future）因果顺序的 World-Action Model，使失败轨迹可以与成功演示共同训练，且不会污染动作解码。
  • 引入 teacher-forced action-conditioned mask（教师强制的动作条件化掩码），将动作生成与未来预测分离，使失败动作可以监督未来视频与价值学习，同时不影响策略学习。
  • 引入 failure-aware value targets（失败感知的价值目标），对成功演示和失败 rollout 分别构造归一化的任务进度目标，使价值头对动作质量敏感。
  • 在 RoboTwin 模拟基准 与 真实世界双机械臂操作 上进行广泛验证，证明模型在策略成功率、减少未来幻觉和可选候选动作排序方面均取得显著提升。
Card 04 方法描述

方法描述

  • FACT 基于共享的 WAN2.2-5B 视频扩散 Transformer 骨干，将动作、价值和未来视频 token 统一进行去噪预测，token 顺序为 [观测前缀 \|\|预测动作 \|\|真实动作条件 \|\|价值 \|\|未来视频]。
  • 通过因果注意力掩码实现动作与世界的分离：世界侧预测（价值、未来视频）仅关注干净的真实动作条件 $G$，而预测动作段 $A$ 无法看到 $G$，从而保证训练时未来预测不会泄漏动作信息。
  • 训练采用 flow-matching denoising objective，成功演示监督动作、价值、未来视频三项损失；失败 rollout 则掩码动作模仿损失，仅保留价值与未来视频损失。
  • 推理采用两阶段策略：第一阶段仅从观测去噪生成动作；可选地，第二阶段将生成的动作填入干净动作槽，预测价值与未来视频；价值头可以进一步用于对 $N$ 个候选动作进行排序（best-of-N）。
  • 价值目标定义为归一化任务进度 $p_t = G_t / G_T$，失败 rollout 在失败发生时刻通过 $\lambda_{fail}$ 对进度目标进行惩罚性裁剪。
Card 05 数据集与资源

数据集与资源

  • 模拟实验：RoboTwin 基准中的 50 个双机械臂操作任务，并额外加入约 1.3K 条模型 rollout 失败数据 作为后果监督。
  • 真实世界：5 个已见任务（Stack Cubes、Pick Cubes、Handover、Stack Bowls、Pour）与 3 个未见泛化任务；立方体操作任务使用 200 条专家演示，其余任务使用 50 条，另收集约 30 条失败 rollout。
  • 模型初始化权重来自 WAN2.2-5B 视频生成模型；优化器为 AdamW，动作 FFN 学习率 $2\times10^{-4}$，骨干学习率 $2\times10^{-5}$，损失权重 $w_a=20$、$w_v=w_I=1$。
  • 动作块长度 $H=48$，未来视频监督使用 $[0, H/4, H/2, 3H/4, H]$ 五个时间偏移；推理默认使用 20 步 flow-Euler 去噪。原文未说明 GPU 数量等具体训练资源。
Card 06 评估与结果

评估与结果

  • 模拟评测（RoboTwin 50 任务平均成功率）：Ours 达到 85.6%，Ours w/ failure 达到 87.5%，接近 Motus 的 87.8%，且部署速度快约 3 倍；去掉视频协同训练后降至 81.8%。
  • 真实世界已见任务（平均成功率）：Ours 为 82%，加入失败数据后提升至 89%，可选价值排序进一步达到 92%；相比之下 Motus 为 64%，π0.5 为 88%。
  • 真实世界未见任务（平均成功率）：Ours 为 67%，加入失败数据后提升至 77%，可选价值排序达到 82%，接近 π0.5（85%）但未使用大规模机器人预训练。
  • 失败数据减少未来幻觉：在失败 rollout 条件下，成功-only 模型的未来预测 PSNR 为 19.51，失败感知共训模型提升至 25.92，且不损害成功演示条件下的预测质量（26.08 vs. 26.12）。
  • 消融实验显示：因果掩码对策略性能至关重要（移除后成功率从 82% 降至 77%）；若失败 rollout 不掩码动作损失，成功率大幅下降至 63%；失败数据比例从 0% 增至 100% 时成功率单调提升（32.7% → 57.3%）。
  • 价值引导候选排序在 $N=4$ 时取得任务完成率与推理延迟的最佳平衡，且仅有成功数据时价值排序无效（79%），证明失败感知训练是价值头发挥作用的前提。
