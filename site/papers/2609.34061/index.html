Card 02 论文概述

论文概述

  • 针对 Vision-Language-Action（VLA）模型中动作头（action head）设计的局限：点回归只能给出动作分布的点估计，而标准流匹配（flow matching）采样需要昂贵的迭代推理。
  • 提出将回归与流匹配统一到同一监督目标下，并由此推导出分位数（quantile）目标，进而设计 Quantile Head：一次前向传播即可预测中位数与正间隔，形成有序的边缘动作分位数。
  • 目标是兼顾单次前向预测的高效性与对条件动作分布的显式建模能力，并提升 VLA 控制的成功率与推理效率。
Card 03 核心贡献

核心贡献

  • 理论贡献：从回归与流匹配的统一监督框架出发，推导出用于动作分布建模的分位数目标（Theorem 1：积分 pinball 损失与 CDF 监督等价，仅差因子 2），并证明在标定分位数、固定间隔与匹配修正速度条件下，联合分位数监督可降低直接中位数更新的方差（Theorem 2）。
  • Quantile Head 设计：提出一种分位数动作头，在单次前向中预测有序分位数；以中位数加正值间隔累加构造左右分位数，天然避免分位数交叉，并支持默认中位数解码与可选的分位数采样。
  • Masked Pinball Loss：提出掩码 pinball 损失，按动作坐标随机扣留监督（同一坐标的所有分位数共享同一掩码），以缓解对示教数据的过拟合。
  • 实验验证：在 LIBERO、LIBERO-Plus、LIBERO-Pro 及两个真实机器人任务上取得领先性能，并在匹配的 LIBERO 基线上取得最短平均回合时间。
  • 开源代码：代码发布于 https://github.com/xwangrs/Quantile-Head-for-VLA。
Card 04 方法描述

方法描述

  • 统一目标：定义参考路径上的共享监督 $\mathcal{L}_{\nu,\pi}(\theta)=\mathbb{E}\|f_\theta(X,A_\alpha,\alpha)-(Y-B)\|^2$，其中 $A_\alpha=(1-\alpha)B+\alpha Y$；取 $B=\alpha=0$ 退化为平方回归，取高斯参考与采样时间则得到条件流匹配（CFM）的速度监督。
  • 分位数目标：将平方监督扩展到阈值标签 $Z_z=\mathbf{1}\{Y\le z\}$，Theorem 1 证明其 CDF 监督等价于积分 pinball 损失，从而可用有限个分位数表示每个动作坐标的条件分布。
  • 架构：冻结预训练 VLM（SigLIP 图像嵌入 + 任务文本嵌入 + 离散化机器人状态），插入 $N_p=16$ 个可学习提示（prompt）token；采用块自注意力掩码，使 prompt 读取 VLM 特征、action token 读取 VLM 与 prompt 特征，VLM token 仅内部双向注意。
  • 有序分位数头：两个共享的线性投影分别预测中位数 $m$ 与两侧原始间隔 $r_i^\pm$，经 $g_i^\pm=\frac{\delta_0}{\log 2}\mathrm{softplus}(r_i^\pm)$ 映射为正间隔，再围绕中位数累加得 $q_{c-j}=m-\sum_{i=1}^{j}g_i^-$、$q_{c+j}=m+\sum_{i=1}^{j}g_i^+$。
  • 超参数：分位数层数 $K=21$，$\tau_k=0.025+0.95k/20$，$\tau_c=0.5$，间隔尺度 $\delta_0=0.02$；训练与推理均将时间条件固定为零。
  • 损失：对每个动作坐标的 $K$ 个有序分位数施加 pinball 损失 $\rho_\tau(e)=\max\{\tau e,(\tau-1)e\}$，并按样本对保留坐标与分位数层取平均。
  • 坐标掩码：每个训练前向随机无放回地丢弃 $\min(\lceil rN_b\rceil,\max(N_b-1,0))$ 个有效坐标（$r=0.1$），掩码在所有分位数间共享；评估时使用全部有效坐标且不丢弃。
Card 05 数据集与资源

数据集与资源

Card 06 评估与结果

评估与结果

  • 评估设置：仿真基准 + 两个真实机器人任务；默认使用中位数解码（单次前向），并对比 Diffusion Policy、OpenVLA、OpenVLA-OFT、π₀、π₀-FAST、π₀.₅、VLANeXt、SimVLA、WLA-0、InternVLA-A1.5、GAM、GE-Act 2.0、ACoT-VLA、MemoryVLA(++)、X-VLA、VLA-Adapter、MolmoAct、SUREFlow 等方法。
  • 主要指标：任务成功率（%）、LIBERO 上的平均回合时间（s）、零样本与微调迁移成功率。
  • LIBERO（中位数解码）：平均 99.3%，Spatial 99.0、Object 100.0、Goal 99.6、Long 98.6，比最强对比基线高 0.4 个百分点。
  • LIBERO-Pro：60.2%（无需额外训练），超过 π₀.₅ 的 53.3% 达 6.9 个百分点；任务类 26.0%、位置 31.3%、物体 85.8%、语义 97.8%。
  • LIBERO-Plus：零样本 87.1%、微调 89.1%，分别超过最强对比基线 1.4 与 5.0 个百分点。
  • 真实机器人：平均 75.0%，对比 π₀.₅ 的 58.5% 提升 16.5 个百分点；放苹果由 31% 提升至 52%（+21），移除长方体由 86% 提升至 98%（+12）。
  • 推理效率：平均回合时间从 $L_1$ 的 8.13 s 降至 5.88 s，减少 27.7%，为匹配 LIBERO 基线中最快。
  • 消融结果（LIBERO 平均成功率）：完整头 99.3%；Median-Only 97.5%；Detached Median Anchor 98.7%；Symmetric Quantiles 97.9%；Noise Query 93.8%；VLM Query 92.8%；默认全零动作查询优于两类替代查询。
  • 联合监督效果：在四种 prompt/标签掩码配置下，联合分位数监督均提升平均评估成功率（83.5→91.8、95.5→98.8、86.0→97.0、97.5→99.3），即便推理仅使用中位数。
