UniFlowWAM: A Unified World-Action Model with Visual Semantics and 4D Geometry

2026-10-22 · 原文 · 翻译 · 2610.30991

提出 UniFlowWAM，一个统一的世界–动作模型（World–Action Model），把场景级 3D 流（scene-level 3D flow）提升为与视觉、动作并列的第三模态，其世界表征同时覆盖视觉语义（未来 DINOv3 特征）与 4D 几何（3D 流）。 解决的问题：机器人示教只记录“看到了什么、做了什么”，却不描述 3D 场景在两者之间如何变化；此前的流方法都把流当作独立模块、推理期先验或额外预测头，流始终位于策略之外。 核心研究问题：预训练的视觉–动作模型能否学会场景 3D 点的运动，以及学习这一能力是否能反过来提升动作预测质量。

Card 02 论文概述

论文概述

  • 提出 UniFlowWAM，一个统一的世界–动作模型（World–Action Model），把场景级 3D 流（scene-level 3D flow）提升为与视觉、动作并列的第三模态，其世界表征同时覆盖视觉语义（未来 DINOv3 特征）与 4D 几何（3D 流）。
  • 解决的问题：机器人示教只记录“看到了什么、做了什么”，却不描述 3D 场景在两者之间如何变化；此前的流方法都把流当作独立模块、推理期先验或额外预测头，流始终位于策略之外。
  • 核心研究问题：预训练的视觉–动作模型能否学会场景 3D 点的运动，以及学习这一能力是否能反过来提升动作预测质量。
Card 03 核心贡献

核心贡献

  • 将场景级 3D 流做成统一视觉–动作模型的对等模态，通过专门的 flow expert 与联合 mid-training / post-training，在同一批示教数据上引入，而非外挂模块或跟踪输入。
  • 设计十个角色条件目标（role grid）：每个模态在目标中被赋予 target / condition / absent 之一，使流既可作预测目标也可作条件，同时保留一个测试时不需要流输入的直接策略（用可学习占位符填充流槽位）。
  • 在 RoboCasa-GR1 上把基座模型成功率从 52.1% 提升到 56.4%（+4.27 点），且增益集中在基座最弱的 10 个任务上（平均 +6.47 点）。
  • 在 LIBERO 上保持分布内 98.1%，在 LIBERO-Plus 零样本达到 87.7%，相机扰动下 96.9%（对比最强基线 76.6%）。
  • 真实机器人双臂操作平均成功率 87.0%（过程分 92.3），显著优于最强基线 π0.5 的 68.5%；完整十目标后训练比只用策略目标在每个任务上高 12–18 点。
Card 04 方法描述

方法描述

  • 采用 MMDiT（多模态扩散 Transformer）架构，在 LDA 的视觉–动作骨干上为 3D 流新增一个独立专家，三个专家（动作 / 流 / 视觉）各有私有归一化、Q/K/V 投影、FFN 与 AdaLN 调制，仅通过联合自注意力交换信息。
  • 3D 流表征：用冻结的单目密集 3D 点跟踪器 Track4World 离线提取点图与逐帧位移，再用冻结的 MotionCrafter 4D VAE 分别编码几何与位移并沿通道拼接成 latent。
  • 位置编码：在基座绝对位置嵌入之外引入 MM-RoPE，将三个专家的 query/key 统一旋转到共享的 (t, h, w) 时空坐标系；流 token 每两帧合并、时间戳按 2t′ 对齐到视觉 patch 网格。
  • 训练目标：每个样本采样一个目标角色，损失为仅在 target 槽位上计算的流匹配速度损失；任务均衡采样器保证每个 batch 覆盖全部十个目标。
  • 训练策略：从 LDA 公开预训练 checkpoint 初始化，先做引入流的 mid-training，再在各下游域做 post-training；视觉/动作专家用预训练权重初始化，流专家从零训练，Qwen3-VL-4B 与 DINOv3 编码器全程冻结。
  • 关键工程选择：放弃用图像 VAE（SDXL）编码 3D 位移（会产生流坍缩），改用几何–流训练的 4D VAE；也放弃了逐层门控渐进引入流的设计（反而掉 3.3 点）。
Card 05 数据集与资源

数据集与资源

  • Mid-training 数据（三个公开机器人示教数据集混合）：RoboCOIN 47,050 条（6 个平台）、RoboMIND 2.0 140,231 条（3 种本体，含 Franka、UR）、MolmoAct2-BimanualYAM 27,162 条；合计 214,443 条 episode、1.33 亿帧、10 种本体，采样 16 步 chunk、3 帧间隔，约 4,200 万个训练窗口。
  • 仿真评测：RoboCasa-GR1（24 个桌面任务，每任务 1,000 条示教，共 24,000 条 / 约 836 万帧 / 83.6 小时 @20fps，29 维关节控制）、LIBERO（4 个 suite × 10 任务，Franka Panda，no-noops 版本）、LIBERO-Plus（7 类扰动共 10,030 条 episode，零样本协议）。
  • 真机平台：AgileX Cobot Magic（ALOHA 式，双 6-DoF PiPER 臂 + 平行夹爪，1 顶视 + 2 腕视相机，14 维状态/动作），4 个任务各 50 条示教、每任务 50 次试验。
  • 模型规模：基于 LDA-1B 约 1B 参数的视觉–动作骨干，外加新增 3D 流专家；Qwen3-VL-4B 提供视觉–语言条件（冻结），DINOv3 提供未来视觉特征目标（冻结）。
  • 训练资源：48 张 NVIDIA H200 GPU，全局 batch size 1,536。
Card 06 评估与结果

评估与结果

  • 评测环境：仿真（RoboCasa-GR1、LIBERO、LIBERO-Plus）+ 真实 ALOHA 式双臂机器人；指标为成功率（SR）与过程分（milestone 完成比例）。
  • RoboCasa-GR1：11 个共享随机种子（每任务每种子 50 条）下，带 mid-training 的 UniFlowWAM 达 56.38 ± 1.47%，优于 released LDA 的 52.11 ± 2.24% 与复现 LDA 的 52.76 ± 1.16%；不带 mid-training 为 54.84 ± 1.00%。
  • LIBERO / LIBERO-Plus：LIBERO 平均 98.05%（该基准已饱和，仅用于验证分布内性能未退化）；LIBERO-Plus 最佳 checkpoint 87.65%，7 类扰动中相机扰动优势最大（96.9% vs 基线 76.6%）。
  • 真实机器人：平均成功率 87.0%（过程分 92.3），对比 π0.5 的 68.5%/77.0、DreamZero 的 30.0%/34.5、LDA 的 15.5%/17.8；四任务全部最优，失败样本仍能拿到 41/100 里程碑分（π0.5 为 27，LDA 仅 3）。
  • 目标消融（真机，SR%）：仅策略目标 76/76/72 → 四目标无流 92/80/76 → 流仅作条件 92/88/76 → 完整十目标 94/90/84（chili/pen/towel），流目标在更难的 pen、towel 上分别贡献 +10、+8 点。
  • 分布外泛化：增益集中在示教覆盖稀疏处——辣椒横向 90° 姿态组中，仅策略目标成功率 20%，完整目标达 80%。
  • 位置编码消融：去掉 MM-RoPE 使 LIBERO-Plus 在各 checkpoint 上降 1.1–2.8 点（最佳点 −2.5），损失集中在机器人初始状态扰动；去掉绝对位置嵌入最佳点降 1.5 点。
  • 局限：流伪标签来自 Track4World 存在时序噪声（用 SAM 分割仅保留前景流缓解）；流 mid-training 仅约 1,200 小时示教，远小于 LDA 预训练所用的 EI-30k 语料。
