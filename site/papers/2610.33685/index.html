Card 02 论文概述

论文概述

  • 论文提出 EXE（Egocentric Cross-Embodiment Pretraining via Factorized Latent Actions），一个利用第一视角人类操作视频为 VLA（Vision-Language-Action）模型做跨本体预训练的框架。
  • 核心问题：机器人演示数据稀缺且昂贵，而第一视角人类视频数据量丰富、语义强，但人-机本体差异（embodiment gap）使得难以从视频中提取可直接迁移的动作表征。

Card 03 核心贡献

核心贡献

  • 提出 feature group-routed action tokenizer（特征分组路由动作分词器）：将动作按语义拆分为「共享位置子空间」与「本体特有关节子空间」，前者用跨域共享码本量化，后者用各域私有码本，避免本体几何污染共享表征。
  • 提出双重跨域对齐机制：结合 InfoNCE 对比学习（对齐空间轨迹相似的动作）与语言引导的关系蒸馏（以冻结语言嵌入的成对相似度作为软目标，对齐语义相同但轨迹不同的动作）。
  • 设计三阶段流水线：① 训练因子化动作分词器 → ② 跨本体 VLM 预训练（预测共享离散动作码）→ ③ 下游 VLA 微调（连续动作回归 + Bridge Features）。
  • 同一套预训练可同时惠及平行夹爪与灵巧手两类不同运动学结构，并在仿真与真机上均取得一致提升。
Card 04 方法描述

方法描述

  • Stage 1（分词器）：按路由表把动作向量拆成共享组（人手腕/机器人末端 3D 位置，双臂为 6 维）与特定组（手腕旋转+手指关节，或末端旋转+夹爪状态）；每组经独立 encoder（FFT 频率增强 + 膨胀 1D 卷积 + Transformer）、残差向量量化（RVQ）、decoder；latent 与码本均做 ℓ2 归一化后按余弦相似度检索。
  • 跨域对齐损失：共享码本使用对称 InfoNCE（同一码的正样本对拉近）；再用冻结的 Qwen3-Embedding-8B 编码任务指令，构造 S_text 与 S_act 相似度矩阵，以 L_lang = \|\|S_act − S_text\|\|²_F 做关系蒸馏，解决纯空间对比的「自举难题」；语言仅作训练期信号，不进入 encoder 输入。
  • Stage 2（VLM 预训练）：以 Florence-2-large 为骨干，LM head 词表扩展 K_s 个共享码条目，在文本提示后附加 T 个占位 token，预测各位置的共享码索引；人类数据只监督共享码，机器人数据额外监督特定码。
  • Stage 3（VLA 微调）：加载 Stage 2 权重，接入 action transformer 作为动作专家，抽取占位位置的 VLM 隐状态作为 Bridge Features 与视觉语言特征拼接；损失为纯连续动作回归（ℓ1），推理时不再需要分词器/码本。
Card 05 数据集与资源

数据集与资源

  • 人类第一视角视频：主实验用 EgoLive；泛化实验另测 VITRA-1M、EgoDex；相关工作总结中还涉及 Ego4D、Epic-Kitchens。
  • 机器人数据/基准：RoboTwin 2.0（ALOHA 双臂，50 个桌面任务，easy/hard 划分）；RoboCasa GR1（24 个灵巧手家务任务，约 1,000 条/任务、共约 24K 轨迹）；真机 AgileX Piper 双臂平台（自采 2,450 条遥操作「扫垃圾」演示）。
  • 模型规模：主模型基于 Florence-2-large 骨干，参数量约 0.8B；码本大小共享/特定各 64，量化维度 32。
  • 训练资源：8 张 NVIDIA A800 GPU；batch size 32，学习率 6e-4，warmup 20k 步；Stage 1 训练 50k 步，Stage 2 训练 30k 步，Stage 3 训练 60k 步（真机 30k 步）。基线为 SmolVLA (0.5B)、X-VLA (0.8B)、TurboVLA (0.4B)、StarVLA-GR00T。
Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0（easy/hard 各 50 episodes/任务）、RoboCasa GR1（24 任务平均成功率）、真机 AgileX Piper（两组各 10 次 rollout）。
  • 主要指标：任务平均成功率（%）；另含码本利用率（激活码数、跨域共激活码数）、t-SNE 潜空间可视化。
  • RoboTwin 2.0：EXE 平均 76.2%（easy 75.6 / hard 76.8），优于 X-VLA 72.9%、TurboVLA 60.2%、SmolVLA 60.0%，以及无预训练的 EXE_base 66.8%（+9.4）。
  • RoboCasa GR1：EXE 56.6%，高于 EXE_base 52.0% 与 StarVLA-GR00T 47.8%，说明共享空间意图词表对灵巧手同样有效。
  • 真机：同分布场景 80% vs 60%；放入未见物体作干扰时 30% vs 10%，显示更强的场景级泛化。
  • 消融：基线 73.2% → 加 InfoNCE 73.8% → 加语言对齐 74.1% → 加 Bridge Feature 达 76.2%，各组件独立有效；Stage 2 人机数据配比以 1:1 最佳（76.2%），优于 2:1（74.3%）与 3:1（75.5%）。
  • 分词器分析：共享码本 64 个码中激活 59 个、其中 58 个被人与机器人共同激活；t-SNE 显示共享组跨域重叠成簇、特定组清晰分离；同一共享码对应的真机与人手轨迹均为「自上而下放置」动作。
