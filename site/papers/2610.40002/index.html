Card 02 论文概述

论文概述

  • 针对推理型 VLA（vision–language–action） 策略：VLM 先写推理链（Chain-of-Causation, CoC），动作专家再基于该推理解码轨迹；错误的推理链会导致错误规划，甚至“看起来正确”的推理链也可能误导规划。
  • 论文不追问“推理是否正确”，而是追问“推理应以多大强度引导动作”，把推理的影响从“检测缺陷”转为“可控制的连续量”。
  • 目标：在冻结的驾驶 VLA 上，为每个去噪（Euler）步自适应选择引导权重，以最大化最终规划得分。
Card 03 核心贡献

核心贡献

  • 提出 CoC-CFG（Chain-of-Causation classifier-free guidance）：在“完整上下文”与“去除推理片段的上下文”之间做无分类器引导，用每个 Euler 步一个权重 w_k 衰减或放大推理影响，且 w=1 精确还原原始策略。
  • 将步级引导权重的选择建模为有限时域马尔可夫决策过程（终局奖励为规划得分），并提出动作值可被精确测量而非自举估计的框架。
  • 提出 Q-adaptive guidance：用小型 critic 拟合测量得到的动作值，并对偏离参考权重施加代价，迭代地“测量—拟合—改进”，保守地提升控制器。
  • 在 Alpasim 仿真器中，开环与闭环均超过所有固定权重以及在线 RL（SAC、GRPO）。
  • 在 Waymo 端到端驾驶基准的隐藏测试集上，以冻结的 Alpamayo 1.5 取得已发表方法中的新 SOTA。
Card 04 方法描述

方法描述

  • CoC-CFG 引导轴：设完整上下文为 C_full、仅删除推理片段（保留观测、指令、prompt 格式与位置）的上下文为 C_ref，每步更新为

- x_{k+1} = x_k + Δt( v(x_k,t_k,C_ref) + w_k·[v(x_k,t_k,C_full) − v(x_k,t_k,C_ref)] )

- w=0 等于移除推理，w=1 为原始模型，w>1 放大推理；权重取值于有限动作集 A（含 1）。

  • MDP 形式化：状态 s_k = (k, x_k, w_{k−1}, C)，动作为权重，转移为确定性引导 Euler 步，奖励仅在末步给出任务得分 R(x_K)；引导规则非预知性（不读取评分参考与得分）。
  • 测量而非自举：专家冻结、初始噪声固定 ⇒ 生成确定且可重置；单步分支（one-step branch，即 "vine" rollout）应用某权重一步、再以当前控制器续完，其得分 G^π(s_k,a) 即该权重的精确值；与锚点分支配对得到优势标签 A(s_k,a)，无需 bootstrapping、无需对下一动作取 max。
  • 拟合目标：y(s,a) = clip( A(s,a) − λ_c·1[a≠a_0] − λ_m·\|a−a_0\|, −τ, τ )，用固定偏离代价、距离比例代价与截断处理重尾，思路类比保守策略迭代。
  • 迭代训练：第 n 阶段用 π_{n−1} 在训练场景上采集标签（含少量探索性非锚权重），对每个访问状态分支全部 \|A\|个权重；损失按数据年龄折扣聚合：L_n = Σ_{j=1..n} ρ^{n−j} L_{D_j}。
  • 部署：w_k = argmax_{a∈A} ( Q̄(s_k,a) − η\|a−a_0\|)，Q̄ 为多 critic 均值；推理时不使用评分参考、不做分支 rollout。
Card 05 数据集与资源

数据集与资源

  • Alpasim：由真实驾驶数据重建的神经仿真器，用于开环与闭环评测。

- 控制器训练用 120 个场景；开环在 358 个不相交片段留出场景上评测。

- 闭环 300 个训练池外场景，10 s、10 Hz，每 25 个控制步推理一次。

  • Waymo Open Dataset 端到端驾驶基准（WOD-E2E）：478 个有评分的验证帧，其中 358 帧留出用于全部对比、120 帧供训练；隐藏测试集由官方评分。
  • 基础模型：冻结的 Alpamayo 1.5（VLM + flow-matching 动作专家），解码 K = 10 个 Euler 步；通过规则化的相机几何与车辆转换适配 Waymo。
  • 论文未报告模型参数量、GPU/TPU 型号与训练算力等资源细节。
Card 06 评估与结果

评估与结果

  • 评估设置：Alpasim 开环（负位移代价，3 s 与 5 s 的平均/终点位移误差加权）与闭环（通过率、有责碰撞、与日志轨迹距离、综合得分）；Waymo 使用 RFS（rater feedback score，11 类评分的均值）。
  • 对比基线：7 个固定权重、4 种自适应引导方法（CFG++、linear ramp、guidance interval、guidance rescale）、专家奖励微调（RAFT 式）、SAC、GRPO，以及场景级 Q 控制器。
  • Alpasim 开环：第三阶段将位移代价相对 w=1 降低 16.5 %（−1.1704 → −0.9767），优于最佳固定权重（w=0.5，+10.3 %）、SAC（+10.6 %）与 GRPO（+13.8 %）。
  • Alpasim 闭环：通过 262/300 场景（w=1 为 252、锚点 w=0.5 为 254），有责碰撞最少 7 次（w=1 为 13、锚点为 10），与日志距离 1.118 m、综合得分 0.712 均为最优。
  • Waymo 留出集：阶段 n=2 达 8.3032 RFS，比最佳固定权重（w=0.75，8.2412）高 +0.0620，比默认 w=1（8.2363）高 +0.0669；四阶段均值比场景级控制器高 +0.0867。
  • Waymo 隐藏测试集：8.135159 RFS，超过此前最佳已发表方法 DriveMA-4B 的 8.079，创下新 SOTA。
