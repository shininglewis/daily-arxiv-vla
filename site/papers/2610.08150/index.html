ViDAL: A Visual Dynamics-Grounded Action Latent Space for Vision-Language-Action Models

2026-10-06 · 原文 · 翻译 · 2610.08150

提出 ViDAL（Visual Dynamics-grounded Action Latent Space），将连续动作潜空间锚定在场景的未来视觉动态上，用于视觉-语言-动作（VLA）模型。 现有动作表示（原始动作块、离散动作 token、连续动作潜变量）主要建模动作轨迹本身，未考虑动作引起的视觉动态（物体运动、接触变化、任务状态转移）。 目标是学习一种既可执行、又以视觉动态为基础（dynamics-grounded）的动作表示，并作为即插即用的接口接入多种 VLA 架构。

Card 03 核心贡献

核心贡献

  • 提出 ViDAL，据作者所知是首个将动作潜变量锚定在未来视觉动态上的方法，通过联合训练 Action VAE（动作重建 + 未来视觉潜变量预测）实现。
  • 提出可插拔的动作潜变量接口：冻结后的 Action VAE 可同时服务于 回归型（OpenVLA-OFT、StarVLA-OFT）与 流匹配型（π₀、π₀.₅）动作专家，且无需修改 VLM 主干。
  • 在 LIBERO 与 RoboTwin 2.0 两个仿真基准、以及单臂 Franka 与双臂 ARX 真机平台上进行了系统实验，验证一致增益。
  • 通过消融与可视化分析，揭示视觉动态监督（L_dyna）是性能提升的结构性来源，并证明动作潜空间比原始动作更具结构性，可驱动可辨识的未来视频预测。
Card 04 方法描述

方法描述

  • Action VAE：将动作块 aₜ:ₜ₊H₋₁ 编码为连续潜变量 zₐ ∈ ℝ^{T×D}，采用高斯后验与重参数化，编码器使用 4× 时间下采样（T = H/4），解码器还原动作块。
  • 视觉动态监督：冻结的视频编码器 E_v（Wan VAE）从观测中提取初始视觉潜变量 z₀ 与未来视觉潜变量 z_f；轻量预测器 P_θ 以 (z₀, zₐ) 回归 z_f，从而让动作潜变量保留与场景演化相关的结构；E_v 与 P_θ 仅在表示学习阶段使用，部署时不需要视频模型。
  • 训练目标：L_ViDAL = L_rec + λ_freq·L_freq + λ_KL·L_KL + λ_dyna·L_dyna，分别对应时域 L1 重建、DCT 频域重建（参考 FAST）、KL 正则化，以及带 stop-gradient 的未来视觉潜变量 L1 对齐。
  • 下游集成：冻结 Action VAE 编码器给出确定性潜目标 z̄ₐ = sg(Norm(μ_φ(·)))，回归专家以 L_reg = ℓ(F_ω(c), z̄ₐ) 训练，流匹配专家在潜空间上学习向量场 v_ω，推理时由冻结解码器 D_a^ψ 将预测潜变量映射为可执行动作。

Card 06 评估与结果

评估与结果

  • 评估指标为任务成功率（%），仿真基准上以多任务策略形式训练，真机每任务评测 10 次 rollout。
  • LIBERO：π₀.₅+ViDAL 取得 98.1% 平均成功率；相对 OpenVLA-OFT 提升 +0.3%，相对 π₀.₅ 提升 +1.2%，增益主要集中在长时序 Long 套件。
  • RoboTwin 2.0：π₀.₅ 从 54.3% → 65.5%（Clean，+11.2%）与 33.2% → 43.1%（Random，+9.9%）；StarVLA-OFT 分别提升 +4.2% / +1.8%。
  • 真机：Franka 上平均 +20.0%，ARX 上平均 +23.4%，无需改动底层策略训练配方。
  • 消融：完整 ViDAL 在 RoboTwin 2.0 为 65.5/43.1，而仅重建的 vanilla Action VAE 为 57.4/38.3；去除 L_dyna 降幅最大，说明动态监督是主要增益来源。
  • 潜空间几何：首个主成分方差占比由原始动作的 40.9% 降至 ViDAL 的 15.6%，达到 95% 累计方差所需主成分由 40 降至 14；参与率从 4.7 升至 14.6（3.1×）。
  • 扩展性：随任务数与演示数增加，+ViDAL 的增益单调扩大；未来视频预测可复现物体位置、夹爪姿态与接触事件。
