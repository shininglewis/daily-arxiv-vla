Card 02 论文概述

论文概述

  • 提出 ROS2SmolVLA 框架，将 Hugging Face 的 SmolVLA（450M 参数轻量级视觉-语言-动作模型）通过 ROS 2 接口集成到工业级轻量机器人（Universal Robots UR10e）上，实现自适应生产场景中的机器人控制。
  • 论文旨在解决当前 VLA 模型部署面临的两大挑战：大规模模型无法在本地/边缘计算导致合规与安全风险，以及小模型仅在实验室级硬件上验证、缺乏真实工业环境适配。
  • 通过开源软件仓库、自采数据集和模型微调，在真实工业机器人上验证了 SmolVLA 的可行性，并给出了实施指南与经验教训。
Card 03 核心贡献

核心贡献

  • 提出并开源 ROS2SmolVLA 完整软件栈，包括 Docker 容器化环境、ROS 2 与 LeRobot/SmolVLA 的接口层、多相机 ROS 2 集成包，以及 UR10e 的虚拟/实体双胞胎执行环境。
  • 首次将 SmolVLA 适配到工业级 UR10e 机器人，验证了其在真实工业硬件（大工作空间、工业控制回路）上的可部署性。
  • 发布了自采集的 349 个 pick-and-place 训练 episode 数据集（含三相机视角、关节状态、笛卡尔位姿）和微调后的模型权重（通过 Hugging Face 公开）。
  • 设计了 9 个系统化测试场景（T1-T9），覆盖物体位置、颜色、盒子颜色/形状、机器人构型、分布内/外等影响因素，提供了全面的实证评估。
  • 总结出面向工业部署的 Lessons Learned，指出了数据采集策略、视觉token优化、颜色偏差等关键改进方向。
Card 04 方法描述

方法描述

  • 基于 Hugging Face LeRobot 框架和 Cartesian Motion Controller（Scherzinger 等）构建 ROS 2 与 VLA 模型的连接，采用 lerobot-ros 作为 LeRobot 与 ROS 2 生态之间的轻量级代理。
  • 系统采用分布式边缘-工作站架构：Nvidia Jetson AGX Orin 边缘设备负责相机数据采集与预处理，工作站（Nvidia RTX 4080）执行 VLA 推理，两者通过 10Gbit 以太网连接。
  • 模型输入为俯视裁剪图像 + 腕部相机 + 笛卡尔末端位姿，输出为 TwistStamped 速度指令，采用 Flow Matching Transformer 架构生成连续动作分布。
  • 微调配置：设置 train_expert_only=False、compile_model=True，训练 200,000 步（初始 50,000 步效果不足），在 NVIDIA L40S GPU 上耗时约 25 小时。
  • 容器化通过 docker（ur10e_vla_docker）隔离 CUDA/PyTorch/ROS 2 依赖，保障开发与生产环境一致性；Gazebo 仿真层提供与实物完全一致的 ROS 2 接口，支持虚拟预验证。
Card 05 数据集与资源

数据集与资源

  • 自采数据集：349 个 pick-and-place episodes，包含 3 个相机视图（双 Azure Kinect + 腕部 webcam）、关节状态、笛卡尔末端位置，以及动作的 Cartesian delta 值。
  • 工作空间划分为 5x5 立方体位置网格，每个位置 5 次重复，并包含多色立方体、错误恢复（如掉落重抓）episodes。
  • 模型：SmolVLA（450M 参数），基于 SmolVLM-2 骨干网络，视觉 token 限制为每帧 64 个。
  • 训练资源：NVIDIA L40S GPU（200,000 步约 25 小时）；推理硬件：Nvidia RTX 4080（16GB VRAM）+ 32GB RAM 工作站，以及 Nvidia Jetson AGX Orin 边缘设备。
  • 所有资源通过 GitHub（una-auxme/ros2smolvla_docker 等仓库）和 Hugging Face（数据集 una-auxme/ROS2SmolVLA_ur10e_no_joints_crop_pick_place 和模型卡片）公开。
Card 06 评估与结果

评估与结果

  • 评估环境：UR10e 真实机器人 + Robotiq Hand-E 夹爪，pick-and-place 任务（将立方体放入盒子）。
  • 评估指标：将任务拆分为 pick 子任务和 place 子任务，分别报告成功率；自动恢复尝试记为成功。
  • ID 场景（T1/T3/T4）成功率：pick 78.33%、place 72.50%、place-after-pick 92.47%。
  • OOD 场景（T2/T5/T8/T9）成功率：pick 76.56%、place 46.88%、place-after-pick 61.22%。
  • 全部场景总体成功率：pick 77.72%、place 63.59%、place-after-pick 81.69%。
  • 关键发现：模型对颜色存在显著偏差（绿色优先于灰色、黄色/橙色表现差）；对黑色盒子识别失败（17%），对蓝色/圆形盒子泛化良好（100%）；机器人起始构型对成功率影响显著（RC 5 因超出相机视野降至 50%）；提示要求灰色立方体时模型仅 20% 正确服从指令。
