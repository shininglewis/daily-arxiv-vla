Card 02 论文概述

论文概述

  • 提出 Speech-π0.5，一种 audio-language-action 模型，可将原始语音直接映射为机器人动作指令，跳过显式文本转录环节
  • 现有 VLA 模型（如 π0.5）只接受打字文本输入；传统方案是在 VLA 前接一个 ASR（如 Whisper）先把语音转成文本，但这会带来较大响应延迟，并传播转录错误
  • 核心目标是验证：能否在不经过 ASR 解码器的前提下，把语音模态直接接入高性能 VLA，同时保持任务成功率与口音鲁棒性
Card 03 核心贡献

核心贡献

  • 提出 cross-modal projection：把语音隐藏状态压缩为紧凑的 VLM token，绕过自回归 ASR 解码器
  • 提出 split LoRA 适配：为音频与任务分别设置专用低秩适配器，按 token 位置路由，缓解单一适配器对训练音色的过拟合
  • 设计两阶段训练流程（语音–语言对齐 + 任务训练），并采用非对称学习率，防止灾难性遗忘
  • 实现 3× 响应延迟降低（首动作 109 ms，对比 ASR 流水线 324 ms），同时在 LIBERO 上保持有竞争力的任务成功率
  • 在未见口音上表现稳健：基线单 LoRA 在 LIBERO-Object 上从 69% 骤降至 38%，而本方法仅轻微下降
Card 04 方法描述

方法描述

  • 语音编码：使用冻结的 Whisper-large-v3 语音编码器输出帧级隐藏状态 H ∈ R^{N×d_s}（N = 1500 帧）
  • 跨模态投影：两层 MLP（GeLU 激活）将帧级特征投影到 VLM token 空间 R^{d_v}，再由带 K = 32 个可学习查询向量的交叉注意力池化模块压缩为 Z_audio ∈ R^{32×d_v}，把 1500 帧压缩成 32 个 token，使 ASR 阶段延迟降低 94–97%
  • Split LoRA：Gemma-2B 主干共 18 层，每层配置两个 rank-16 适配器——task LoRA（B_t A_t，作用于文本/动作位置）与 audio LoRA（B_a A_a，作用于音频位置），按位置集合 P_audio / P_text/action 路由，使两条通路互不干扰
  • 阶段一（语音–语言对齐）：以原始 PaliGemma（π0.5 主干） 在真值文本输入下的输出作为教师，通过 MSE 蒸馏损失让带投影与 audio LoRA 的模型在语音输入下对齐语言内容；训练数据为机器人领域 TTS（100k 条指令、~30 种音色）混合任务专用词汇，动作专家保持冻结
  • 阶段二（任务训练）：在机器人示教数据上用 flow matching 动作损失优化 task LoRA、audio LoRA、动作专家 LoRA 与音频投影器；语音编码器与基座权重冻结；audio LoRA 使用更小的学习率，避免任务梯度覆盖已学到的语音表征
  • 关键创新点：投影层与 LoRA 模块的联合优化，兼得任务级操作能力与语音识别通路的泛化性
Card 05 数据集与资源

数据集与资源

  • LIBERO 基准的两个子集：LIBERO-Spatial 与 LIBERO-Object（各 10 个任务，每任务 50 回合，每条件 n = 500）
  • 训练语音合成：Piper TTS（22 个 VCTK 说话人），共 100k 条机器人领域指令、约 30 种音色
  • 留出评估语音：10 个 Azure Neural TTS 音色，其口音在训练中未出现
  • 模型规模：基于 π0.5（PaliGemma 视觉-语言主干 + Gemma-2B、18 层），LoRA 秩为 16；语音编码器为 Whisper-large-v3
  • 训练资源未明确给出 GPU 型号与数量；延迟测试在 NVIDIA H100 上进行（batch = 1，100 次运行）
Card 06 评估与结果

评估与结果

  • 评估环境：仿真基准 LIBERO-Spatial / LIBERO-Object，每条件 500 回合；延迟测试硬件为 H100（batch = 1，100 次运行）
  • 主要指标：任务成功率（%）、从语音输入到机器人首个动作的响应延迟（ms）
  • 任务成功率：本方法在 LIBERO-Spatial 达 89.2%、LIBERO-Object 达 86.0%，明显优于单 LoRA 基线的 69.0% / 69.0%；ASR 流水线 + π0.5 文本 oracle 为 95.6% / 95.0%（性能更高但延迟大）
  • 口音鲁棒性：在未见口音上，本方法为 85.4% / 84.8%（仅小幅下降）；单 LoRA 基线为 68.4% / 38.0%，其中 LIBERO-Object 上出现 69% → 38% 的严重退化
  • 延迟：ASR 流水线（Whisper-v3 解码 216.7 ms + π0.5 推理 107.7 ms）总计 324.4 ms；Speech-π0.5 仅 109.1 ms，实现 3.0× 加速
  • 结论：端到端语音到动作建模可消除 ASR 解码器瓶颈，在保持有竞争力成功率的同时显著降低响应延迟，并提升跨口音泛化能力
