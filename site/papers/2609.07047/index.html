MEMOBench: A Process Level Memory Benchmark for Robotic Manipulation

Card 02 论文概述

论文概述

  • 提出 MEMOBench，一个面向机器人操作的过程级（process-level）记忆评测基准，用于诊断“信息需在观测中消失后仍然被使用”的历史依赖型任务。
  • 现有记忆基准主要依赖最终任务成功率，容易将“遗忘”与“操作失败”混淆；MEMOBench通过可执行的记忆检查点把记忆过程显式区分出来。
  • 基准包含 30 个历史依赖任务、1,500 条专家演示和 4,200 个检查点实例，并定义了存储、更新、压缩三类记忆操作标签和对应评测指标。
Card 03 核心贡献

核心贡献

  • 引入 MEMOBench 基准，覆盖 30 个任务、1,500 条演示和 4,200 个标注检查点，按时间记忆、空间记忆、物体记忆和程序记忆组织。
  • 定义可执行的检查点约束，并给出 Memory Storage Rate (MSR)、Memory Update Rate (MUR)、Memory Compression Rate (MCR) 三类过程级记忆指标，将记忆保真度与最终操作是否成功解耦。
  • 系统评测标准型与记忆增强型 Vision-Language-Action 模型（如 π0、π0.5、OpenVLA-OFT、MemoryVLA、HiF-VLA、RoboMME Memory Module），发现当前模型往往能“存储”但难以“更新/压缩”信息。
  • 基于检查点语言设计 Semantic / Contrastive / Framewise Memory Alignment 三类监督目标，证明标注语言可用于改善不同记忆操作能力。
Card 04 方法描述

方法描述

  • 采用两层记忆分类法：任务层区分 Temporal（何时）、Spatial（何地）、Object（何物）、Procedural（如何做）；操作层给每个检查点分配 Storage、Update 或 Compression 标签。
  • 每个任务由有序的可执行检查点刻画，检查点包含从粗到细的文本描述和可直接在模拟器中验证的 simulator predicate。
  • 检查点谓词与仿真状态对接，按前缀完成规则得到整体过程级指标；三个记忆指标是该类检查点在轨迹中成功满足的比例。
  • 对带显式记忆模块的策略（π0.5 + RoboMME memory module），在动作损失外额外添加对齐正则化：总损失 = 动作损失 + 权重 × 对齐损失，其中对齐损失可为余弦语义损失、InfoNCE 对比损失或帧级时间对齐损失。
  • 新方法的核心在于把“记忆内容是否被正确写/改/压缩”变成可程序化验证的检查点，而不仅是依赖隐式的模型状态读取。
Card 05 数据集与资源

数据集与资源

  • 仿真平台采用 LIBERO / robosuite 栈上的 BDDL 任务规范。
  • 数据规模：30 个任务、每个任务 50 条演示，合计 1,500 条专家演示；覆盖 29 类物体和 5 类固定装置。
  • 检查点规模：84 个可执行检查点模板，每个演示按模板展开后获得 4,200 个检查点实例，默认配比为 Storage 1,750、Update 1,600、Compression 850。
  • 评测设置：每个任务 50 个保留仿真 rollout，共 1,500 个评估轨迹；使用 seed base 7、1200 步 horizon，replan 间隔 k∈{5,20,35,50}。
  • 评估与训练文本未披露具体 GPU/TPU 型号及模型参数量；可复现参数设置计划见论文附录 H（提供的截断文本未覆盖该明细）。
Card 06 评估与结果

评估与结果

  • 评测指标为最终任务成功率 SR 加上 MSR、MUR、MCR 三种记忆指标，并按时间、空间、物体、程序记忆类别做宏平均。
  • 在最佳 replan 设置下，最强记忆模块基线 π0.5 + RoboMME Memory Module 平均成功率仅达到 31.9%，对应 Avg MSR=58.1%、Avg MUR=16.5%、Avg MCR=7.8%。
  • 标准 VLA 模型在 MEMOBench 上成功率极低，例如 π0、π0.5、OpenVLA-OFT 不同 replan 下平均成功率多在 10% 以下，说明传统短时依赖策略难以处理进程记忆任务。
  • 结果显示高“存储率”与低“更新率/压缩率”常常并存——例如部分记忆增强模型 MSR 在 90% 以上，但 MUR 和 MCR 明显落后，说明策略记住了初始状态却没有修订过期信息或整合历史。
  • 记忆对齐实验表明，Semantic、Contrastive、Framewise Alignment 对不同记忆操作产生有限但有差异的提升，初步验证 MEMOBench 可作为 VLA 记忆模块的额外训练监督来源。
