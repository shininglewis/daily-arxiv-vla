Card 03 核心贡献

核心贡献

  • 提出 AtomicRL 框架，围绕原子任务结构统一解决长程操作中的信用分配与探索分配问题。
  • 提出 SAPO（Semantic-Aware Policy Optimization）：用语义感知软门控约束 TD 残差跨子任务边界的传播，抑制失败子任务的信用污染，同时保留子任务内信用分配与成功子任务间的依赖关系。
  • 提出 BATE（Bottleneck-Adaptive Targeted Exploration）：基于各原子子任务完成率的滑动平均，动态调整全任务采样权重与子任务级熵正则强度，将探索预算导向瓶颈子任务。
  • 设计轻量 PCC（Progress–Completion Critic）：从交互历史估计子任务进度与完成边界，为 SAPO/BATE 提供语义信号，并支持构造基于进度的塑形奖励（PBSR）。
  • 开发自动化 Real2Sim2Real 流水线：仅需单条真实多模态示教即可重建可交互仿真环境，把在线 RL 从真机迁移到可并行、可复现重置的仿真中训练。
  • 在仿真与真机上均验证有效性，并给出消融与 Sim2Real 相关性分析。
Card 04 方法描述

方法描述

  • 问题建模：语言条件下的部分可观测 MDP，长程指令分解为 K 个有序原子子任务 $G=(g_1,\ldots,g_K)$，定义语义边界指示 $b_t=\mathbb{I}[z_{t+1}\neq z_t]$，动作以 action chunk 形式输出。
  • SAPO：保持一步 TD 残差与价值自举不变，仅在递归 GAE 迹上施加结果感知软门控：子任务内部 $b_t=0$ 保持标准 $\gamma\lambda$ 衰减；边界处子任务成功取 $\kappa_t=1$（正常传播），失败取 $0<\kappa_t<1$ 衰减跨边界传播。
  • BATE：用指数滑动平均估计各子任务掌握度 $\mu_k$，以能力缺口 $1-\mu_k$ 同时驱动全任务采样分布 $P_{\text{task}}(i)$（保留基线权重 1 以防遗忘）与子任务级熵正则权重 $f_{\exp}(1-\mu_{z_t})$。
  • PCC：以当前原子任务为条件，输出 B−1 个序数进度 logits 与 1 个完成 logit，用累计序数损失 + 类别平衡完成损失离线训练；连续 N 步满足阈值即推进子任务索引并重置进度。
  • PBSR：$r_t = r_t^{\text{env}} + \alpha_n r_t^{\text{PBSR}}$，并采用线性退火逐步降低塑形权重，早期强化引导、后期回归稀疏终局奖励。
  • Real2Sim2Real：$(\mathcal{E}_{\text{sim}},\mathcal{C},\mathcal{S}_0)=\mathcal{B}(\tau_{\text{real}},m,\mathcal{D}_{\text{aux}})$，生成仿真环境、共享观测-动作接口与可复现随机初始布局，接入 RLinf 分布式训练框架，优化后在真机通过同一接口部署。

Card 06 评估与结果

评估与结果

  • 评估设置：LIBERO 每任务 50 次试验取平均成功率；CALVIN 1000 次试验统计连续 1–5 个任务成功率与平均完成序列长度；真机每任务 25 次试验。
  • LIBERO-LONG：π0.5 达 99.0%、OpenVLA-OFT 达 98.8%，分别比 PPO 提升 +3.6 与 +4.0 个百分点；SFT 基线为 89.0% / 86.5%。
  • CALVIN ABC-D：平均完成序列长度 3.56 → 4.56（PPO 为 4.36）；五任务全链成功率 70.6% → 80.1%，较 PPO 提升 +9.5%。
  • 真机结果：平均成功率 69.3%（BP 76 / WD 72 / TC 60），较 SFT（48.0%）提升 21.3%，较 PPO（61.3%）提升 8.0%。
  • Sim2Real 一致性：9 组（3 任务 × 3 方法）仿真-真机成功率皮尔逊相关系数 r = 0.909。
  • 消融（LIBERO-LONG，弱 SFT 初始化）：PPO 78.2% → +SAPO 87.8%（+9.6）→ +退火 PBSR 89.6%（+1.8）→ +BATE 91.2%（+1.6），累计 +13.0 个百分点；SAPO 贡献最大，且在不同奖励粒度（0/1、SubR、PBSR）下均稳定增益。
  • PCC 质量：准确率 95.92%、误检率 4.08%、召回率 89.20%，延迟 42.4 ms。
