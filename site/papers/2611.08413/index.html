T3R: Training-Free Two-Stage Token Refinement Towards Efficient and Robust VLA Models

2026-11-05 · 原文 · 翻译 · 2611.08413

论文研究 Vision-Language-Action（VLA） 模型的高效推理问题：每个决策步骤需处理数百个视觉 token，多相机输入进一步放大计算量，并可能让无关背景干扰动作预测。 作者指出 VLA 推理存在两类冗余：大量视觉 token 与任务空间无关；保留 token 上的注意力分配不合理，尤其在分布偏移下会削弱鲁棒性。 提出 T3R，一种免训练的两阶段 token 精炼框架：先做分割引导的 token 剪枝，再做显著性引导的注意力偏置，以提升 VLA 推理效率与鲁棒性。

Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action（VLA） 模型的高效推理问题：每个决策步骤需处理数百个视觉 token，多相机输入进一步放大计算量，并可能让无关背景干扰动作预测。
  • 作者指出 VLA 推理存在两类冗余：大量视觉 token 与任务空间无关；保留 token 上的注意力分配不合理，尤其在分布偏移下会削弱鲁棒性。
  • 提出 T3R，一种免训练的两阶段 token 精炼框架：先做分割引导的 token 剪枝，再做显著性引导的注意力偏置，以提升 VLA 推理效率与鲁棒性。
Card 03 核心贡献

核心贡献

  • 提出 T3R，将分割引导、位置保持的 token 剪枝与显著性引导的注意力偏置结合，在同一次推理中联合优化 token 选择与注意力分配。
  • 在 LIBERO-Spatial 与 OpenVLA-OFT 上，移除 85% 场景相机视觉 token，仍保持 96% 成功率（未剪枝基线为 97%），并将每次 VLA 推理延迟从 107.5 ms 降至 92.5 ms。
  • 在 OOD 物体位置扰动下，T3R 相比未剪枝基线最高提升 7 个百分点成功率；分辨率扩展实验中，LLM-forward 最高实现 3.3× 加速。
  • 在 CogACT/SIMPLER 与 π0.5/RoboTwin 上验证跨骨干、跨相机配置的泛化性，发现多相机场景因传感器冗余具有更大剪枝空间。
  • 强调 T3R 在解码器入口前完成剪枝，使所有 Transformer 层都受益，且无需重新训练或修改 VLA 权重。
Card 04 方法描述

方法描述

  • 第一阶段：分割引导的 token 剪枝。使用 SigLIP 计算指令与图像 patch 的相似度，并按词性（POS）加权，突出物体名词和描述性形容词。
  • 采用“过采样—聚类—精炼”策略：先选 50 个高分 patch，用 DBSCAN 聚类保留最大空间簇，再选 8 个正提示和 3 个负提示，输入 EfficientTAM-S 生成物体掩码。
  • 若掩码覆盖某 patch 超过 30% 像素则保留该 patch；剪枝时保留每个 patch 的原始 RoPE 位置 ID，避免位置重索引导致性能崩溃。
  • 分割异步执行，每 5 次 VLA 推理调用更新一次掩码；动作推理复用最近完成的掩码，不等待更新。
  • 第二阶段：显著性引导的注意力偏置。使用 Integrated Gradients（IG） 对指令 token 做归因，选取前 30% 显著 token，并在中间解码层向动作查询的注意力 logits 注入加性偏置。
  • 偏置强度 β=2.0，作用于第 8–23 层，仅对动作 token 查询生效；显著文本 token 按 IG 分数加权，保留视觉 patch 按 SigLIP 相似度乘以 0.5 加权。
  • 整体流程免训练，不更新 VLA 参数；先剪枝得到更干净的候选集，再通过注意力偏置强化决策相关证据。
Card 05 数据集与资源

数据集与资源

  • 主要评估数据集：LIBERO（Spatial、Object、Goal、Long 四类任务）、SIMPLER、RoboTwin。
  • 设计研究使用 ECoT-OpenVLA-7B 和 30 条离线 LIBERO-Spatial 演示，以 L2 动作误差分析注意力偏置策略。
  • 主要 VLA 骨干：OpenVLA-OFT（SigLIP ViT-SO400M + LLaMA-2-7B，LoRA rank 32，chunk size 8，双相机约 512 个视觉 token/次）。
  • 泛化评估骨干：CogACT（SIMPLER，单相机）与 π0.5（RoboTwin，三相机）；原文给定 HTML 未明确列出二者参数量。
  • 评估硬件：单张 NVIDIA L40S（48 GB）；致谢中提到使用 NVIDIA DGX Spark 和 NVIDIA Jetson AGX Thor，研究受 NVIDIA Academic Grant Program 支持。
  • 因方法为免训练框架，不涉及额外模型训练；分割每 5 次调用异步更新，IG 每任务计算一次并在该任务所有 episode 中复用。
Card 06 评估与结果

评估与结果

  • 评估基准包括未剪枝基线、TeamVLA、ADP、FastV；部分实验将 ADP/FastV 强制到 T3R 的高剪枝率设置下比较。
  • 主要指标：成功率 SR、场景相机 token 移除比例、每次 VLA 调用延迟、OOD 成功率、LLM-forward 加速比。
  • 在 LIBERO-Spatial 上，T3R 移除 85% 场景相机 token，SR 为 96%，接近未剪枝基线 97%；同样 85% 剪枝率下，ADP 为 66%，FastV 仅 14%。
  • 延迟从 107.5 ms 降至 92.5 ms，降低约 14%；其中约 7.8 ms 为剪枝与注意力偏置应用开销。
  • 在 93.9% 的视觉 token 仅获得少于 0.2% 动作查询注意力的观察下，T3R 仍能通过良好选择保留关键证据。
  • OOD 物体位置扰动实验中，T3R 在扰动 ≥2 cm 时匹配或超过基线，在 4 cm 时最高领先 7 pp；TeamVLA 退化最快。
  • 多相机 π0.5/RoboTwin 上，T3R 在 50% 保留率下与基线持平（均 33.3%），在 62.5% 保留率下达到 38.3%，超过基线 5.0 pp。
  • 单相机零样本 CogACT/SIMPLER 中收益有限：T3R 在 Bridge 上与基线持平，在 Google Robot 上落后 5.5 pp，说明传感器冗余较少时激进剪枝空间较小。
  • 消融显示：仅剪枝为 90%，仅注意力偏置为 98%，完整 T3R 为 96%；注意力偏置可恢复约 6 pp 的剪枝损失。
