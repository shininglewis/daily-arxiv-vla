Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action（VLA）模型是否必须依赖数十亿参数量的 VLM 骨干：当前 VLA 将动作模块挂载在大型 VLM 上，并在每个控制步都付出该骨干的推理代价。
  • 作者提出：对于底层操作策略，VLM 的职责只是把图像与指令编码成条件嵌入，而 DINOv3、NeoBERT 等现代独立编码器已在表征任务上追平甚至超过大型 VLM。
  • 通过固定演示数据、训练预算、任务与测量平台，仅变换视觉编码器、语言编码器和动作头进行受控实验，得到 Decoupled Embodiment Model（DEM），并与 7 个 VLA 基线对比。
Card 03 核心贡献

核心贡献

  • 在相同演示、任务、训练预算与测量平台下，对解耦策略的视觉编码器、语言编码器和动作头进行受控研究，对比 7 个已有/同期 VLA，覆盖 18 个仿真任务和 3 个真实机器人任务。
  • 证明在该任务范围内，现代解耦组件构成更优的「成功率–延迟–能耗」权衡：观测成功率与 VLM 骨干策略相当，推理频率高 8–17 倍，单次推理能耗低 6–15 倍。
  • 开源代码 https://github.com/Apollo-Lab-Yale/decoupled-embodiment-model，以支持高效多任务机器人策略的后续研究。
  • 通过动作头消融发现 MeanFlow 单次前向即可生成整段动作块，是 DEM 速度优势的主要来源，并使动作分块（action chunking）从必需变为可选。
Card 04 方法描述

方法描述

  • 视觉编码器：采用 DINOv3 ConvNeXt-B，取 stage-3 的 16×16 网格、512 维特征，每相机展平为 256 个 token，场景相机加腕部相机共 N_v = 512 个 token；从公开 checkpoint 初始化并与动作头联合微调。
  • 语言编码器：采用编码器-only 的 NeoBERT（222M 参数），指令填充/截断到 N_l = 32 个 token，保留最后一层每个 token 的隐状态与注意力掩码而非池化句向量；NeoBERT 保持 冻结；因语言 token 不依赖图像，指令不变时可复用缓存，仅在指令变化时重新编码。
  • 动作头：MeanFlow，学习区间 [r,t] 上的平均速度而非瞬时速度，训练损失含自适应权重 w=(‖·‖²+c)^{-p}（c=10⁻³，p=0.5）；(r,t) 按 logit-normal 采样并以 0.5 概率取 r=t；推理时只需一次前向：â = ε − u_θ(ε, 0, 1 \|C)。
  • 模块组装：三路输入投影到头部宽度 d 并加模态嵌入后拼接为上下文 C = [V W_v + e_v ‖ L W_l + e_l ‖ qᵀ W_p + e_p]，共 545 个上下文 token；动作 token 作为 query，上下文作为 key/value 做交叉注意力，配零初始化逐通道门控 g_i，允许每个模块独立替换。
  • 配置：d = 768，D = 8 个 DiT 风格 AdaLN 块，动作头 107M 参数；总参数 417M，每步仅 195M 活跃。
Card 05 数据集与资源

数据集与资源

  • 仿真数据：RoboCasa 的 18 个原子任务，使用 NVIDIA PhysicalAI-Robotics-Manipulation-Kitchen-Demos 数据集，每任务 500 条演示；用 Claude Opus 4.8 为每条指令生成 50 条同义改写，训练时每条 episode 采样一条，评估时使用 10 条未见过的改写。
  • 真实机器人数据：基于 FurnitureBench 的 3 个装配任务（drawer、lamp、cabinet），每任务 200 条遥操作演示；平台为 8 自由度机械系统（xArm 7 + 直线导轨）。
  • 训练资源：8 张 H100 GPU；仿真训练 300k 步，真实任务训练 100k 步。
  • 评估平台：单张 RTX PRO 6000 GPU 工作站，AMD Ryzen Threadripper PRO 9965WX CPU，128 GB 内存。
  • 基线：OpenVLA、Octo、SmolVLA、π0.5、GR00T N1.7、TurboVLA、ReactVLA，均在同一演示上用官方实现与默认配方全参数微调。
Card 06 评估与结果

评估与结果

  • 评估环境：18 个 RoboCasa 仿真任务（每任务 100 次 rollout，布局与物体放置来自随机化且与演示不同）+ 3 个真实机器人任务（每任务 50 次 rollout）；18 任务均值的标准误约 1.2 个点，2.5 个点以内视为噪声。
  • 主要指标：任务成功率、单次推理延迟、推理频率、单次推理 GPU 能耗、参数量。
  • 总体基准：DEM 平均成功率 55.6%，与 GR00T N1.7（56.9%）相差 1.3 个点、高于 π0.5（54.6%），均在采样误差内；DEM 为 417M 参数（每步活跃 195M），而两者约 3B。交替基线中 TurboVLA 46.3%、ReactVLA 41.9%，Octo 最低 25.6%。
  • 效率：DEM 单次推理 6.1 ms / 163 Hz / 2.07 J；GR00T N1.7 为 19.3 Hz / 13.7 J，π0.5 为 9.7 Hz / 31.7 J；即使每步都运行 NeoBERT，DEM 仍为 10.4 ms、96 Hz、3.09 J。
  • 视觉消融：微调比选型更关键——冻结的 DINOv3 ConvNeXt-B 仅 32.6%，微调后 55.6%；微调后各编码器均在 51.8%–55.6% 区间，VLM 视觉塔（SigLIP-So400M 53.9%、Qwen3-VL ViT 51.8%）未带来增益且成本高约 3–4 倍。
  • 语言消融：无语言 11.3%，one-hot 37.4%，T5-base 44.5%，BERT-base 47.8%，mmBERT-base 50.6%，NeoBERT（冻结）55.6%；微调 NeoBERT 无显著变化（55.1%）；Gemma 2 与 Qwen3-VL LM 分别 55.0% 和 54.3%，但参数量是 NeoBERT 的 8–12 倍。
  • 动作头消融：MeanFlow 55.6% / 162.7 Hz / 2.07 J；Flow matching 54.7% / 40.3 Hz / 8.50 J；Diffusion Policy 53.8% / 26.9 Hz / 12.85 J；ACT 52.4% / 164.4 Hz。
  • 动作块长度：H=16 为 55.6%，H=8 为 55.9%，H=4 为 52.7%，H=1（每步重规划）为 50.6%，说明在 163 Hz 下分块并非必需。
  • 真实机器人：GR00T N1.7 平均 68.0%，DEM 66.0%（每任务落后 2 个点、150 次 rollout 中差 3 次成功，在采样误差内），π0.5 63.3%，TurboVLA 53.3%。
