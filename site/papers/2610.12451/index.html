Card 02 论文概述

论文概述

  • 论文提出 VersaCamVLA，一种相机可配置的 VLA 框架，将相机集合表示学习与动作学习解耦。

Card 03 核心贡献

核心贡献

  • 形式化 相机可配置 VLA 策略学习 问题：策略须在变量数量的 posed RGB 视图下运行，不假设固定相机姿态，同时保持固定大小的视觉接口进行动作预测。
  • 提出 VersaCamVLA 两阶段框架：通过目标视图预测学习统一 scene-token 接口，再将场景 token 注入预训练 VLA 作为补充视觉条件。
  • 提出 Wrist-Augmented Pose Sampling (WAPS)，利用腕部相机的自然运动作为免费姿态多样性来源，用于场景 token 学习。
  • 在 RoboTwin 2.0、LIBERO 和真实机器人平台上验证，在变化相机数量和未见相机姿态下持续优于先前 VLA 方法和直接多视图基线。
Card 04 方法描述

方法描述

  • 采用两阶段训练：Stage I 学习统一场景 token 接口；Stage II 学习场景 token 条件化的 VLA 策略。
  • Stage I：场景编码器将 posed RGB 视图和 Plücker 射线嵌入编码为固定数量可学习 scene tokens；训练时用场景解码器根据目标相机射线查询 scene tokens，重建目标视图的 RGB、语义和边缘信号。
  • 多信号目标视图监督：RGB 使用 MSE + 感知损失，语义图和边缘图分别使用 MSE，总损失为加权和。
  • WAPS：每帧随机采样静态相机子集（1 到全部静态相机），每个腕部相机视图以 0.5 概率独立加入源视图，目标集始终包含所有可用相机视图，从而产生自重建和跨视图预测信号。
  • Stage II：丢弃场景解码器和预测头，冻结场景编码器；轻量卷积空间编码器将 scene tokens 压缩为紧凑补充视觉条件，与预训练 VLA 的原始 RGB 输入和本体状态一起输入动作专家。
  • 基础 VLA 实例化为 π0.5，动作学习使用标准 flow-matching 回归损失。
  • 推理时仅运行场景编码器、空间编码器和 π0.5，仅需 RGB 图像及相机内参和外参，无需新视图渲染、深度估计、点云处理或显式 3D 重建。

Card 06 评估与结果

评估与结果

  • 评估基准：RoboTwin 2.0、LIBERO 和真实机器人平台；额外设计相机姿态扰动和相机数量变化实验。
  • 主要评估指标：任务成功率（%）。
  • RoboTwin 2.0：VersaCamVLA 在 Clean 平均 52.56%、DR 平均 23.00%，优于 ACT（19.69/0.06）、DP（23.69/0.00）、DP3（39.94/2.56）、OpenVLA-OFT（15.19/3.56）和 π0.5（35.88/21.63）。
  • LIBERO：VersaCamVLA 平均 95.9%，优于 Diffusion Policy（72.4%）、OpenVLA-OFT（94.5%）和 π0.5（95.8%）。
  • 相机姿态鲁棒性：在 RoboTwin 2.0 Clean 上，未见姿态下 VersaCamVLA 为 52.63%，而 π0.5 为 32.88%；在真实机器人上，未见姿态下 VersaCamVLA 为 58.33%，而 π0.5 为 13.33%。
  • 相机数量灵活性：在 RoboTwin 2.0 上，VersaCamVLA 在 3V/4V/5V/6V 下分别达到 52.56%/53.44%/53.13%/55.63%；π0.5 在 5V/6V 下无法运行，在 3V/4V 下为 35.88%/48.88%。
  • 真实机器人上，VersaCamVLA 在 4V/5V 下分别达到 53.33%/65.00%，而 π0.5 在 4V 下为 41.67%、5V 下无法运行。
