Reflect-VLA: Internalizing Reflective Guidance via Dual-Path On-Policy Self-Distillation for Autonomous Driving

2026-10-09 · 原文 · 翻译 · 2610.13453

论文提出 Reflect-VLA，将 Reflective Guidance 作为训练时特权信息，通过 Dual-Path On-Policy Self-Distillation (Dual-OPSD) 内化反思引导带来的规划收益。 解决现有自动驾驶 VLA 的 RL 方法仅依赖标量轨迹奖励，无法区分场景理解、行为选择、轨迹执行等具体错误，难以在长尾场景中提供可操作纠正信号的问题。 目标是在推理时实现无引导、无迭代修正的单次轨迹生成，同时保留反思引导带来的规划提升。

Card 03 核心贡献

核心贡献

  • 构建 Reflective Guidance，将轨迹评价结果转化为结构化、轨迹特定的诊断与纠正建议，并作为仅训练可用的特权信息。
  • 提出 Dual-OPSD，一种轨迹质量感知的在线自蒸馏方法：对风险轨迹蒸馏教师的 token 级纠正分布，对可靠轨迹采用自模仿以保留原有规划能力。
  • 设计渐进式教师构建策略，包括 Driving-Knowledge Pretraining、Planning-and-Refinement SFT 和 Self-Refinement Rejection Sampling，以支持稳定的引导内化和高效单次规划。
  • 在 NAVSIM v1/v2 与 Bench2Drive 上验证方法，兼顾竞争性规划性能并将训练时间相比 RL 减少 90% 以上。
Card 04 方法描述

方法描述

  • 将端到端规划建模为条件自回归轨迹生成：输入为 \(q^{base}=(I_{cam},q_{cmd},q_{ego},q_{his})\)，输出未来路点，并将相对位移离散化为特殊轨迹 token。
  • 构造引导条件输入 \(q^{gui}=(q^{base},o^{init},g)\)，其中 g 包含 Trajectory Verdict、Planning Diagnosis、Expert Alignment 和 Refinement Directive 四个组件。
  • 三阶段 SFT：驾驶知识预训练、规划与精炼监督微调、自精炼拒绝采样，使同一模型具备直接生成轨迹和基于引导精炼轨迹的能力。
  • Dual-OPSD 中同一模型分别作为学生和教师：学生仅用 \(q^{base}\) 进行在线 rollout，由 NAVSIM 评估器给出 PDMS 并按阈值路由。
  • 对可靠轨迹（\(r \ge s\)）使用自保留目标 \(\mathcal{L}_{preserve}\) 进行自模仿；对风险轨迹（\(r < s\)）构造引导 \(g\)，冻结教师接收 \(q^T=(q^{base},o^S,g)\)，通过最小化 token 级反向 KL 散度 \(\mathcal{L}_{distill}\) 传递纠正偏好。
  • 总目标为 \(\mathcal{L}_{Dual-OPSD}\)，自适应保留可靠行为并在失败 rollout 上蒸馏纠正偏好，推理时无需引导、评估器或迭代精炼。
Card 05 数据集与资源

数据集与资源

  • 评估基准：NAVSIM v1、NAVSIM v2 和 Bench2Drive。
  • 预训练与驾驶 QA 数据：LingoQA、DriveGPT4、Senna、DriveLM、NuScenes-QA、NuInstruct、DriveLMM。
  • 基础模型：Qwen3.5-0.8B/2B/4B；实验覆盖 Reflect-VLA-0.8B/2B/4B。
  • 训练硬件：8 张 NVIDIA H20 GPU。
  • 训练设置：三阶段训练，驾驶知识预训练 2 epochs（batch size 1，lr \(1\times 10^{-5}\)）；规划/精炼微调 2 epochs（batch size 4，lr \(4\times 10^{-5}\)）；在线自蒸馏 2 epochs（batch size 2，lr \(8\times 10^{-6}\) 和 \(2\times 10^{-6}\)）。
Card 06 评估与结果

评估与结果

  • NAVSIM v1 使用 PDMS 评估；NAVSIM v2 使用 EPDMS；Bench2Drive 使用 DS、SR、Effi、Comf。
  • 在 NAVSIM v1 上，Reflect-VLA-0.8B/2B/4B 分别取得 89.3/90.0/91.5 PDMS，相比对应 RL 基线提升 0.5/0.8/0.3，其中 Reflect-VLA-4B 取得最佳 PDMS。
  • 在 NAVSIM v2 上，Reflect-VLA-4B 取得 91.2 EPDMS，超过 DriveVLA-W0-7B 的 86.1 等基线。
  • 在 Bench2Drive 上，Reflect-VLA-4B 取得 DS 80.15、SR 59.09%、Effi 212.20，优于 AutoVLA 等现有方法。
  • Reflective Guidance 有效性：教师相比无引导学生分别提升 6.1/5.3/4.8 PDMS（0.8B/2B/4B）；经过 Dual-OPSD 后学生分别提升 3.0/2.6/3.1 PDMS，大幅缩小与教师差距。
  • 训练效率：相比 GRPO，OPSD 在 0.8B 上将每 10k 样本训练时间从 5.3 h 降至 1.3 h（约 4.1×），在 2B/4B 上分别约 13.1×/13.9× 加速。
  • 消融显示：完整训练阶段最佳；完整 Reflective Guidance 组件在 4B 教师上达到 93.2 PDMS，其中 Expert Alignment 和 Planning Diagnosis 贡献最大。
