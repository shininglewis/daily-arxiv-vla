Card 02 论文概述

论文概述

  • 论文提出 WATCH，一种仅使用任务配对人类视频的跨视频世界-动作模型预训练方法，目标是在机器人后训练前学习可跨场景、跨体现迁移的交互表示。
  • 它要解决的问题是：标准 within-video 下一帧预测会让模型依赖同一演示中的外观、视角和采集源连续性，而不是学习跨场景、跨体现可迁移的动作与交互。
  • 核心思路是：让模型以一条人类演示的视频和动作为条件，预测另一条同任务演示的动作与未来帧，从而迫使模型捕捉任务相关运动与交互，而无需匹配的人-机器人演示数据。
Card 03 核心贡献

核心贡献

  • 提出 WATCH 跨视频世界-动作预训练目标：以一条人类演示为参考，联合预测另一条演示的动作和未来帧，并构建任务匹配的人-人配对以提供体现和环境变化。
  • 证明跨视频预训练将表示从源特定外观转向任务相关运动与交互，注意力更集中于动作手和被操作物体。
  • 在多种视频模型骨干、后训练协议和评估环境中取得一致增益，尤其在未见级别和跨机器人设置下提升最大。
  • 显示人类-人类配对可诱导与机器人-机器人配对相近的机器人运动表示，支持人类演示作为可扩展的预训练数据源。
  • 将跨视频预测确立为一种可扩展的学习可迁移世界-动作表示的路径，优于 within-video 预训练和 co-training 基线。
Card 04 方法描述

方法描述

  • 基于 Cosmos Policy 配方，在 Cosmos-Predict2.5 和 Cosmos3 骨干上实现世界-动作模型。
  • 使用六个槽位组织输入输出：当前 query 帧、query 状态、reference 视频、reference 动作、预测未来视频、预测动作。
  • 每个 token 带有槽类型和物理时间的位置编码，使参考起点和动作起点由槽标记而非绝对偏移决定，便于后训练时复用或移除参考槽。
  • 采用联合速度匹配目标：视觉损失加动作损失，动作项权重为 λ=48，仅作用于生成槽。
  • 从 EgoVerse 不同 episode 构建 query-reference 配对：用语义任务分类限定候选，用动态时间规整距离排序运动轨迹，并在窗口内标准化运动描述子。
  • 每个 query 的参考集最多包含 8 个同源匹配和 7 个跨源匹配；训练时从参考集中均匀采样一个参考。
  • 支持两种后训练协议：in-context（以人类参考演示为条件）和 context-free（移除参考槽，仅用机器人当前观测、状态和任务指令）。
Card 05 数据集与资源

数据集与资源

  • 人类视频数据来自 EgoVerse，构建了 10.99M 个 query-reference 对，对应 10.0K 小时配对 3 秒窗口。
  • 平均每个 query 有 10.52 个参考，其中 6.35 个为跨源匹配；90.7% 的 query 至少有一个跨源参考。
  • 机器人数据使用 RoboMIND（分析中对比 1K 小时机器人配对），以及 MimicDroid、TableTop-Sim、RoboCasa Kitchen-H50 作为评估基准。
  • 后训练基准涉及 GR1 humanoid、ALOHA、Franka 等机器人体现。
  • 模型规模：Cosmos-Predict2.5 2B 与 Cosmos3 Edge-2B。

Card 06 评估与结果

评估与结果

  • 评估环境包括 MimicDroid（in-context 与 context-free）、TableTop-Sim、RoboCasa Kitchen-H50，并分析 RoboMIND 上的动作与视频预测。
  • 主要指标包括成功率、动作 MSE、acc@0.1、FVD、FID、Spearman 相关、match@1。
  • 表示分析：WATCH 对任务变化的敏感度高于对采集源变化的敏感度；动作 MSE 从 0.0322 变为 0.0335（换源）和 0.0367（换任务）。
  • 跨体现运动回归：WATCH 特征预测未来运动的 Spearman 相关为 0.18（人类）和 0.24（机器人），优于原始视频模型的 0.06 和 0.01。
  • 在未见机器人 RoboMIND 上，WATCH 将动作 MSE 从 0.046 降至 0.039，acc@0.1 从 55.6% 提升至 68.5%，FVD 从 1485.1 降至 154.9。
  • 与机器人训练模型的表示对齐：人类训练 WATCH 的 match@1 达 0.76（人类窗口）和 0.60（机器人窗口），远高于原始视频模型的 0.21 和 0.19。
  • MimicDroid in-context：Cosmos Policy 平均成功率从 40.9% 提升至 68.3%，L2 从 29.4% 至 72.5%，L3 从 18.3% 至 40.8%。
  • MimicDroid in-context：Cosmos3 平均成功率从 59.8% 提升至 77.7%，L3 从 30.8% 至 55.0%。
  • Context-free MimicDroid：Cosmos Policy 从 49.3% 提升至 69.0%，Cosmos3 从 49.7% 提升至 63.4%。
  • Context-free TableTop-Sim：Cosmos Policy 从 59.6% 提升至 65.4%，Cosmos3 从 65.8% 提升至 72.0%。
  • Context-free RoboCasa：Cosmos Policy 从 56.0% 提升至 63.6%，Cosmos3 从 55.0% 提升至 55.8%。
  • 消融显示：WATCH 在 L2、L3 和三个 context-free 基准上一致优于 within-video、co-training 和 same-source top-1；在 2× 速度参考下，within-video 增益消失，而 WATCH 保留大部分增益。
  • 数据规模实验表明，随着配对人类视频数据量增加，in-context 与 context-free 性能均持续提升。
