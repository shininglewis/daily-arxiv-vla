Card 03 核心贡献

核心贡献

  • 提出一个连接空间问答、点级目标定位、家庭操作与导航的空间基准，三套子集共享场景与关系。
  • 设计诊断式评测协议：在固定训练布局下改变指令的 prompt-probe 设置，将“目标一致行为”与“任务完成”分离（soft success / strict success / wrong-target rate）。
  • 开展政策适配与视觉接地接口的实证研究（LoRA 微调、DROID 预训练初始化、oracle IR 提示），揭示 VLM 空间能力与 VLA 行为的关联条件。
  • 额外评测 code-as-policy 智能体（写作模型生成 Python 程序控制机器人），与 VLA 策略在同一测试集上比较。
  • 系统评测 14 个 VLM（含 GPT-6 Astra、Gemini 3、Fable5.1 等闭源模型与 Qwen、Molmo、Gemma、DeepSeek 等开源模型）在空间 VQA 与定位上的表现。
Card 04 方法描述

方法描述

  • BEHAVIOR-Spatial-VQA：1,572 道通用空间题（1,078 单帧 + 494 多帧）+ 1,684 道任务相关题（1,082 操作 + 602 导航），覆盖方向、距离、尺寸三类空间概念，含 locate、ordinal 子类型。
  • BEHAVIOR-Spatial-IR：要求模型直接从指令与头部相机图像预测目标点，采用 strict / tolerant 两种评测口径。
  • BEHAVIOR-Spatial-VLA：基于 π₀.₅ 架构，把主干替换为 Qwen3.5-4B；VLM 冻结、动作专家从头训练；用 flow matching 预测 32 步、23 维动作块（躯干、双臂、夹爪、移动底盘）。
  • 六种策略变体：Baseline（冻结 VLM）、+LoRA-VLM、+DROID 预训练初始化、+dot IR、+dot IR + first-frame anchor、+attn-map IR。
  • IR 干预：以 oracle 目标中心点/高斯热图作为受控变量，隔离“定位决策”与“执行误差”。
  • 执行细节：异步滚动时域控制，10 步重规划阈值，最多三个计划的时序集成，夹爪指令取最新计划。
  • Code-as-policy：写作 LM 通过感知与控制 API（RGB-D、开放词表指点模型、VLM、运动原语）迭代生成程序，验证后冻结并在测试集执行，不使用特权物体位姿。

Card 06 评估与结果

评估与结果

  • 评测指标：VQA 四选一准确率；IR 的 strict / tolerant 准确率；操作任务用 soft success（目标选择意图）、strict success（完成率）、wrong-target rate；导航用二元目标达成率。
  • VLM 空间问答：最佳单帧准确率为 GPT-6 Astra 82.1%，最强开源模型 Molmo2-8B 51.8%；多帧方向题上多个开源模型仅与随机猜测（25%）相当。
  • 任务相关感知：Qwen3.5-9B 以 57.2% 领先任务相关 VQA；IR 严格准确率 51.4%（宽松 59.7%），但 locate 子类仅 47.3%，说明通用 VQA 强不代表任务接地强。
  • VLA 操作行为：基线 held-out 41.6% soft / 27.9% strict，错误目标率 38.2%；在 prompt-probe 上骤降至 16.1% soft / 10.0% strict，70.0% 回合锁定非指令目标。
  • 适配手段收益有限：LoRA 仅把 probe soft success 提到 17.9%，DROID 初始化为 16.6%，strict 均未超过基线。
  • 显式接地显著有效：+dot IR 将 held-out 提升到 60.3% soft / 44.8% strict，probe 提升到 38.0% / 24.9%，错误目标率降至 42.4–46.0%；用 VLM 预测的 IR 替代 oracle 仍达 48.8% held-out。
  • 感知-动作相关性（14 任务 Spearman）：dot IR 策略 IR 相关性 ρ=0.701 高于 VQA 的 0.560；attn-map 策略为 0.753 vs 0.608，即“模型要生成的那个指标”更能追踪策略表现。
  • Code-as-policy：Fable 5.1 达 66.1% soft / 51.4% strict；开源写作模型约 37–39% soft 但 strict 仅约 5%，83–87% 回合未做出决定。
  • 导航：成功率从车库 22.5% 到书架 92.5%，导航方向题 VQA 准确率（16.7%–38.6%）与策略成功率相关性很弱。
  • 数据规模消融：dot IR 在 30%、50%、100% 数据上 held-out soft/strict 分别为 56.1%/34.5%、53.7%/33.7%、60.3%/44.8%，非单调但全量最优。
