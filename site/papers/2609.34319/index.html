Text-Vision Synergistic Token Caching: A Training-Free Framework for Efficient Vision-Language-Action Inference

Card 03 核心贡献

核心贡献

  • 识别出现有 VLA caching 对 text-vision synergy 利用不足的关键局限，并提出 TVCache 以 training-free 方式解决 token 级和 layer 级低效问题。
  • 提出基于 text-vision information focus 的 attention-head filtering 机制，缓解 token 级空间错位，提升任务相关视觉 grounding 的准确性与物理一致性。
  • 提出基于 text-vision entropy differences 的 reuse-layer selection 机制，缓解 layer 级深度错配，避免在不稳定层复用缓存并减少冗余计算。
  • 在 四个代表性 VLA 模型、两个仿真基准 和 真实机器人任务 上验证了 TVCache 的有效性与通用性。
Card 04 方法描述

方法描述

  • 整体框架：TVCache 是 training-free、plug-and-play 的 VLA 推理加速框架，基于 KV cache 复用连续观测中的时间冗余，对稳定视觉区域复用历史 KV 表示，对动态区域重新计算。
  • 时间 patch 相似性：通过 cosine similarity 选择时间上稳定且相似度高于阈值 τ 的 top-k 视觉 patch，形成初始缓存复用候选集合 P_static。
  • 注意力头筛选：提取 text-to-vision 跨模态注意力子张量，计算每个头的 semantic response intensity 和 attention entropy，用评分 S_head(n)=αI−βH 选择高质量注意力头，实验中固定 α=β=0.5。
  • 任务相关 token 选择：在筛选后的注意力头上计算视觉 token 的任务相关分数 V_j，将超过阈值 τ_task 的 token 归为 P_task，最终可复用集合为 P_reuse = P_static \ P_task。
  • 复用层选择：计算每层 text-to-vision 注意力的 Shannon entropy，定义层稳定性分数 R^(l)=1−归一化熵，在缓存层预算 K 和最小间隔 d_min 约束下，通过 interval-constrained greedy 算法选择复用层。
  • 深度感知缓存比例：为不同深度层分配 retention proportion γ^(l)，浅层更激进地减少 token，深层逐步恢复，最终复用层达到 γ=1.0。
  • 推理执行：在选定的复用层直接加载 P_reuse 的 KV 状态并按 γ^(l) 缩放，跳过其 self-attention 计算，从而降低计算量并避免不稳定层噪声传播。

Card 06 评估与结果

评估与结果

  • 评估环境：在 LIBERO 仿真基准和真实机器人任务上，对 OpenVLA-OFT、BitVLA、VLA-Adapter、π_0.5 进行测试。
  • 主要指标：任务成功率、token retention ratio、FLOPs、控制频率（Hz）、延迟（ms）和加速倍数。
  • OpenVLA-OFT 关键结果：在 12.5% token retention 下，TVCache 平均成功率为 84.0%，相比 VLA-Cache 的 69.5% 提升 14.5 个百分点；FLOPs 相对 full-token inference 降低 2.45×。
  • OpenVLA-OFT 其他 retention：50% 下 TVCache 97.55% vs VLA-Cache 96.80%；25% 下 TVCache 95.55% vs VLA-Cache 87.85%。
  • BitVLA 关键结果：12.5% retention 下 TVCache 平均 93.90%，VLA-Cache 92.50%；25% 下 TVCache 94.75%，VLA-Cache 93.00%。
  • π_0.5 与 VLA-Adapter：在 π_0.5 的 25% retention 下，TVCache 93.90% vs VLA-Cache 86.85%；在 VLA-Adapter 上整体也优于 VLA-Cache。
  • 效率结果：OpenVLA-OFT 在 12.5% retention 时 FLOPs 为 1.6414 T，低于 vanilla 的 4.0139 T；控制频率提升至 15.04 Hz，延迟降至 66.51 ms。
