Card 03 核心贡献

核心贡献

  • 提出 4D-WAM，一种模型无关的表示对齐方法，将 3D 轨迹场知识注入 WAM，无需改变推理架构。
  • 提出 运动对齐（Motion Alignment），通过 token 级帧间差分和余弦相似度对齐 WAM 与 4D 教师模型的时间动态。
  • 提出 目标点对齐（Destination Alignment），利用 source-to-destination 的注意力式相似度分布，引导模型感知操纵目标的最终位置。
  • 在 FastWAM-Joint 与 Lingbot-VA 等多个基座模型上验证了方法的通用性，并在仿真和真实世界任务中均带来显著提升。
Card 04 方法描述

方法描述

  • 使用 Trace Anything（4D 基础模型）作为冻结教师，提取视频片段的 3D 轨迹场特征。
  • 运动对齐：将 WAM 中间特征与教师特征分别通过两个 MLP 投影到共享空间，对相邻帧做 token 级差分，并用余弦相似度对齐两套差分向量，从而避免绝对特征空间不一致带来的优化冲突。
  • 目标点对齐：以第一帧为源、最后一帧为目标，计算源 token 与目标 token 的相似度分布，并使用 KL 散度让学生分布匹配教师分布，显式建模源到目标的对应关系。
  • 整体训练损失为 ℒ = ℒ_latent + ℒ_action + λ_motion·ℒ_motion + λ_dest·ℒ_dest，推荐两个对齐系数均小于 0.1，对齐操作在 DiT 第 20 层进行。
  • 训练结束后移除所有辅助模块，推理阶段与原始 WAM 完全相同，不增加任何推理延迟或参数量。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO、RoboTwin 2.0、LIBERO-Plus、RoboTwin Clean2Rand。
  • 真实世界任务：ARX LIFT2 双机械臂平台，包含 4 个长程操作任务，共 550 条演示。
  • 基座模型：FastWAM-Joint 与 Lingbot-VA；教师模型为 Trace Anything。
  • 训练资源：8 张 NVIDIA H100 GPU；RoboTwin 2.0 使用 global batch size 1024 训练 30K 步，LIBERO 使用 batch size 512 训练 25K 步，RoboTwin Clean2Rand 使用 batch size 64 训练 20K 步。
  • 额外开销：仅增加 56 MiB 可训练参数（轻量投影头），缓存轨迹特征后总训练时间从 51 GPU 小时仅增至 52 GPU 小时。
Card 06 评估与结果

评估与结果

  • 分布内实验：基于 FastWAM-Joint，4D-WAM 在 RoboTwin 2.0 Clean/Random 上成功率达到 91.92%/90.76%（基线为 90.84%/90.32%）；LIBERO 平均成功率从 98.2% 提升至 98.6%。
  • OOD 实验（LIBERO-Plus）：7 种扰动下平均成功率 71.01% vs 基线 62.21%，其中相机扰动提升最显著（45.15% vs 27.89%，+17.26 个百分点）。
  • OOD 实验（RoboTwin Clean2Rand）：以 Lingbot-VA 为基座时，4D-WAM 是唯一在两个设置下平均成功率超过 60% 的模型（61.7%），比原始 Lingbot-VA 有大幅提升。
  • 视频预测质量：在 LIBERO-Plus 上，PSNR 从 19.22 提升到 21.44，SSIM 从 0.75 提升到 0.83，未来帧结构一致性和物体跟踪明显改善。
  • 真实世界实验：4D-WAM 在 4 个长程任务上平均进度从 20.3% 提升到 31.8%，成功率从 1.0% 提升到 5.5%。
  • 消融实验：去掉任一对齐目标后 LIBERO 平均成功率降至 98.0%；在第 20 层进行对齐效果最佳，与已有表示对齐研究结论一致。
