Card 02 论文概述

论文概述

  • 研究视觉-语言-动作模型（VLAs）如何理解并执行否定指令（negated instructions），即机器人在完成目标任务的同时必须遵守"不要做什么"的显式排除约束。
  • 现有 VLA 主要在肯定指令上训练，面对如"给我一个工具，但不要刀"这类指令时仍会执行肯定内容，导致危险或违背用户意图的行为。
  • 核心目标：在不收集额外的否定专用机器人演示数据的前提下，让预训练 VLA 快速适配否定指令，同时保持原有肯定指令能力。
Card 03 核心贡献

核心贡献

  • 首次系统研究 VLA 中的否定指令理解与执行，揭示语言语义如何在内部表示中编码并逐步传播到视觉表示，最终影响动作生成。
  • 提出 NegaAlign，一种参数高效、即插即用的框架，通过 Negation Transformation Layers (NTLs) 修正中间指令表示，并通过 Teacher-Guided Visual Alignment (TGVA) 将否定语义传播到与指令相关的视觉 token。
  • 提出从现有肯定演示与手工构造的否定指令中构建否定监督的方法，无需否定专用动作轨迹。
  • 构建 NegaBench，一个覆盖 5 类否定、10 个场景的仿真基准，用于系统评估否定约束下的机器人操作。
  • 在仿真与真实机器人上对 GR00T、π0、π0.5 三种 VLA 验证有效性。
Card 04 方法描述

方法描述

  • 否定监督构造：将否定约束表示为关系三元组 R = (ℓⁿ, A, ℓᵉ)，其中 ℓⁿ 为否定指令，A 为满足约束的肯定指令集合，ℓᵉ 为被排除行为；同一观测-状态下构造学生/教师四路语言条件分支以隔离语言对比。
  • Negation Transformation Layers (NTLs)：插入 VLM 主干选定层，将指令 token 池化为内容嵌入 cˡ 与极性嵌入 pˡ，由 TransLayer 生成满足约束的肯定目标表示 rˡ，由 Gate 生成门控 gˡ，再通过 Modulator 将语义偏移以 token 级方式加回，仅修改指令 token。
  • Teacher-Guided Visual Alignment (TGVA)：在 NTL 之后提取视觉 key/value，利用教师分支（肯定/排除指令）的余弦距离差异计算自适应权重，将否定学生分支的视觉 token 对齐到满足约束的教师分支，实现语义向视觉表示的传播。
  • 训练配方与损失：两阶段训练——Stage 1 常规肯定微调，Stage 2 冻结全部预训练参数（含动作生成器），仅训练插入的 NTL，总损失为 L_total = (1/\|Ω\|)Σ(L_equiv + L_sem + α·L_gate)。
  • 关键创新：把否定理解从"指令改写"转变为"中间语言表示修正 + 视觉中介传播"，且只更新极少参数（如 π0.5 仅 11.6M 可训练参数）。
Card 05 数据集与资源

数据集与资源

  • NegaBench：基于 RoboTwin 2.0 仿真环境构建，含 10 个操作场景，涵盖物体排除、属性排除、相对比较、目标位置排除、多约束组合五类否定。
  • 真实世界数据：xArm 机器人上的 5 个安全关键家庭场景（Sorting、Laundry、Storage、Cooking、Dining），每个否定指令评估 50 次。
  • 使用的 VLA 模型与参数量：GR00T（4.35M/3.2B）、π0（11.6M/3.6B）、π0.5（11.6M/3.7B）。
  • 对比基线：Pos. FT（仅肯定微调）、Pos.&Neg. FT（肯定+否定联合训练）、APT、Qwen-π0.5（用 Qwen3-VL-2B-Instruct 做指令改写）。
  • 训练成本：π0.5 微调时间仅 4.6 小时，推理延迟 481.6 ms（基线 494.3 ms），几乎无额外开销。
Card 06 评估与结果

评估与结果

  • 评估指标：肯定指令成功率（Pos. SR）与否定指令成功率（Neg. SR），否定任务需同时完成任务目标并满足全部排除约束。
  • 仿真结果（NegaBench）：仅肯定训练时 GR00T/π0/π0.5 的否定成功率仅为 1.05%/15.40%/2.60%；NegaAlign 将其提升至 57.75%/63.30%/88.45%，三模型平均 69.83%，达到直接否定轨迹训练（Pos.&Neg.）性能的 91.6%，而肯定成功率几乎不变（72.89%/68.41%/92.51%）。
  • 基线对比：APT 否定成功率仅 8.20%，Qwen-π0.5 指令改写方案仅 55.70%，且引入额外上游 VLM 推理延迟。
  • 真实机器人结果：π0.5 否定成功率从 12.4% 提升到 88.8%（+76.4 个百分点），肯定成功率保持 90.8%（原 91.6%）。
  • 消融与机制分析：移除 TGVA 使否定成功率从 88.45% 降至 21.35%；移除 NTL 使肯定成功率从 92.51% 崩至 40.52%；NTL 插入中间层效果最佳，浅层/深层分别降至 85.10%/62.20%。
  • 机制发现：屏蔽图像对文本的注意力会使动作区分度趋近于 0，说明语言语义主要通过调制视觉表示间接影响动作生成，验证了 TGVA 设计的必要性。
