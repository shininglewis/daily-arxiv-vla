G0.5: One Autoregressive Stream for Robot Reasoning and Action

2026-08-12 · 原文 · 翻译 · 2608.11739

论文挑战当前 VLA（视觉-语言-动作）模型的主流范式——“VLM 作为编码器 + 流匹配动作专家”，提出 G0.5：一个统一的 VLM-as-Actor 模型，让预训练 VLM 本身同时承担推理和动作生成的角色。 G0.5 在单一自回归 token 流中，用一组权重同时生成推理 token 和动作 token，解决了传统自回归 VLA 因动作 token 过多而导致的高频控制低效问题。 论文要解决的核心问题：当 VLM 被降级为“条件编码器”时，其链式推理、上下文学习和提示驱动的行为控制能力无法直接影响动作生成，而 G0.5 通过统一自回归框架恢复并强化了这些能力。

Card 03 核心贡献

核心贡献

  • 统一的跨具身动作编解码器（Cross-Embodiment ActionCodec）：学习式 VQ tokenizer 将不同自由度、控制频率和形态的连续动作映射为共享离散 token 词汇表，支持稀疏激活预测（仅预测运动的部件组），显著降低解码负担。
  • 原生链式思维（Native Chain-of-Thought）：推理 token 与动作 token 共享解码器、上下文和训练目标，在单一自回归流中实现任务分解、目标物体框选（BBox）、2D 轨迹（Trace）和动作提示（ActionHint），支持测试时可选 CoT 模式，无需重新训练。
  • 提示驱动的行为控制涌现（Emergent Prompt-Driven Behavior Control）：保留自回归接口后，VLM 的语言上下文能力直接映射到动作生成，提示词（如副词限定、空间线索、近义动词）可直接影响策略行为，无需微调即可实现零样本行为引导。
  • 视觉记忆模块（Visual Memory）：在 ViT 中每 4 层插入分解式时空注意力模块，通过视觉编码器融合多秒历史帧，在严格限制推理延迟的同时缓解部分可观测性和状态漂移问题。
Card 04 方法描述

方法描述

  • 模型初始化自 Qwen3.5 2B 预训练 VLM，采用单阶段预训练，优化单一 next-token 交叉熵损失（仅计算生成段），联合监督 CoT 和动作生成。
  • 动作空间划分为 5 个语义对齐的部件组：(9) \|(1) \|(9) \|(1) \|(7)，共 27 维统一动作空间；采用 RVQ + 时间对比学习保证 token 一致性。
  • 使用自动标注流水线（Gemini 3、Doubao Seed 2.0 Pro、SAM3）生成多粒度语言注释（动作提示、原子任务描述）、视觉接地注释（bbox、mask）和 2D 末端轨迹。
  • 预训练数据混合机器人演示与 Web/VQA 数据（含 8 种 CoT 模板加权采样），并采用视觉记忆正则化（随机丢弃历史帧）防止过拟合。

数据集与资源

  • 预训练机器人数据覆盖 14 种具身，DROID 数据不包含在基础预训练中，仅用于后续 post-training。
  • 数据来源：DROID、BridgeData V2、RoboTwin 2.0、LIBERO、OmniGibson（BEHAVIOR-1K，10,000 条遥操作演示，超 1,100 小时）等。

  • 训练资源：使用 AdamW 优化器（warmup + constant + cosine decay），视觉塔全程不冻结；RoboTwin 2.0 上 batch size 1024，LIBERO 微调 100K 步。
Card 06 评估与结果

评估与结果

  • 真实世界微调（R1-Lite / R1-Pro）：G0.5 达到 76.7%，显著优于 π₀.₅（53.3%）和 GR00T-N1.7（24.4%）。
  • 2025 BEHAVIOR Challenge（50 个长程家庭移动操作任务）：单策略、1 epoch 微调即达 31.4%（Task Success Score），超过 π₀.₅（26.3% 4 epochs）和挑战赛冠军（26.1% 4 checkpoints）；4 epochs 提升至 31.36%。
  • DROID post-training + 零样本迁移（未见环境/物体）：平均成功率 82.5%，远超 π₀.₅-DROID（57.5%）和 MolmoAct2-DROID（52.0%）。
  • 模拟基准：LIBERO 平均 98.9%（Long suite 98.6% 为最优）；RoboTwin 2.0 平均 93.3%（Clean 93.7% / Random 92.8%）；SimplerEnv-Bridge 平均 87.3%，均为同基准下最佳或接近最佳。
  • 语言跟随 Pick-and-Place 基准：G0.5 在下游微调中语言跟随能力显著优于 VLM-as-encoder 基线。
  • 零样本 CoT 探针：启用 CoT 可提升长程指令的接地与执行；AR token 流比流匹配头更紧密地遵循 CoT；提示词措辞（如副词、空间线索、近义动词）可零样本改变 rollout 行为。
  • RL 兼容性：G0.5 开箱即用地支持强化学习微调（模型以 AR 动作 token 输出，可与标准 RL 目标兼容）。
