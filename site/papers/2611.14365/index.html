Card 02 论文概述

论文概述

  • 论文研究 World Action Models（WAMs，世界动作模型） 如何把低维机器人信号（本体感知、动作、任务类型、价值）注入预训练视频扩散模型（VDM）的潜空间。

Card 03 核心贡献

核心贡献

  • 将机器人信号注入重新定义为面向 Joint WAM 的分布感知潜空间接口问题，并指出“紧凑”本身不等于“兼容”。
  • 提供冻结去噪器相对重建误差作为诊断证据：频域打包（DCT 编码）比空间复制（Cosmos Policy 式）和 VAE 编码更贴近预训练 VDM 先验。
  • 提出 统一频域元帧（meta-frame）：把全部异构机器人信号写入单帧中互不重叠的通道频带，经解析 2D 逆 DCT 提升为空间潜帧，读出时用 DCT + 固定槽位解析恢复，无学习解码器。
  • 引入槽位感知任务路由（slot-aware task routing），同一元帧通过频带级掩码同时支持策略、世界模型与价值预测三种任务。
  • 在 RoboCasa 达到 68.9% 成功率、把每信号一帧压缩为单帧、推理延迟降低 39%，并在三个真实 Franka 任务上取得 85.0% 成功率。
Card 04 方法描述

方法描述

  • 分布感知频谱提升：为每个元帧构建稀疏系数张量，按预定义通道划分写入 $F=[F_{\text{task}},F_{\rho_t},F_a,F_{\rho_{t+H}},F_v]$，信号值写入各频带的 $k_H=0$ 行，其余置零。
  • 空间提升与解析读出：用正交 2D 逆 DCT 将系数铺展到 $H\times W$ 网格得到空间元帧；对去噪后的输出元帧做 2D DCT 并按固定槽位 Unpack，直接还原归一化信号。
  • 仅作条件的输入元帧：复用 tokenizer 本来就保留的首个空白槽承载任务 one-hot 与当前本体感知，使输入侧条件“几乎零成本”。
  • 双粒度掩码：细粒度带级掩码承载全部任务语义（决定某频带是干净条件还是去噪目标），由此确定性派生单通道粗掩码，仅用于维持与原始视频去噪路径的字节级兼容。
  • 序列压缩：潜序列由帧注入式的 11 帧降为 8 帧（1 个输入元帧 + 6 个视觉帧 + 1 个输出元帧），自注意力两两交互约减少 47%。
  • 训练目标：标准扩散去噪损失 + 动作/未来本体感知/价值的 Huber 信号损失 + 槽位外系数稀疏惩罚 $\mathcal{L}_{\text{off}}$（$\lambda_{\text{off}}=10^{-4}$），DCT 与槽位读出均可微。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboCasa（24 个静态厨房任务，每任务 50 条人类演示）、LIBERO（Spatial/Object/Goal/Long 四套件）、LIBERO-Plus（7 类扰动鲁棒性测试）。
  • 真实机器人：7-DoF Franka Panda 上的三个精细操作任务——Sweep、Place Cup、Build Block，含 ID 与 OOD 设置。
  • 骨干模型：初始化自 Cosmos-Predict2-2B-Video2World（2B 参数）；附录另在 Wan2.1-I2V-14B 与 Wan2.2-TI2V-5B 上做跨骨干验证。
  • 训练配置：AdamW，学习率 $10^{-6}$，每 GPU batch size 64，4 步梯度累积，4 张 NVIDIA H200 GPU。
Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率（SR）、单次查询推理延迟、潜帧数；辅助指标包括信号恢复的目标方向增益、相对读出 $L_2$、未来视角 PSNR、未来本体感知归一化误差（Prop. NEE）、价值 MAE。
  • RoboCasa：68.9% 平均成功率（3600 次试验、3 个随机种子），优于同数据设置的 Cosmos Policy（67.1%），并优于使用更多演示的 UWM（60.8%）、GR00T-N1.5（64.1%）、Video Policy（66.0%）等。
  • 效率：延迟从 0.479 s 降至 0.291 s（约 −39%），潜帧由 11 帧降为 8 帧，三种紧凑打包方案共享该延迟但本文成功率最高。
  • LIBERO：98.1% 平均成功率；LIBERO-Plus 总体 83.44%，比 Cosmos Policy（82.2%）高 1.24 个百分点，其中相机 82.93%（+7.13）、语言 89.56%（+7.86）、光照 97.81%、传感器噪声 94.87%、布局 86.73% 领先，但背景 72.68% 与机器人初始状态 59.90% 弱于基线。
  • 真实世界：ID 85.0%、OOD 68.3%，均超过 Cosmos Policy 的 78.3% 与 63.3%。
  • 消融（RoboCasa）：统一元帧在信号恢复（增益 0.7146、相对 $L_2$ 0.2928、PSNR 19.95）与世界/价值预测（Prop. NEE 0.0143、Value MAE 0.046）上也全面最优，说明策略收益未以其他任务为代价。
  • 诊断实验：$\sigma=1.0$ 时冻结去噪器相对重建误差为统一元帧 0.5613，低于分离空间复制 0.6178、Meta-Compact 0.6234、Meta-Quadrants 0.6730；单信号场景 DCT 编码在各噪声水平均最低。
