Robota-Embed: Unified VLA Embeddings for Robot In-Context Learning and Evolution

2026-10-14 · 原文 · 翻译 · 2610.19495

提出 Robota-Embed，一个统一的 VLA（视觉–语言–动作）嵌入模型，在查询（当前状态）和候选（记录的未来连续片段）两端联合编码视觉、语言和原生动作。 目标是解决物理经验检索中的任务与执行阶段敏感匹配问题：仅靠任务相似或视觉–语言相似不足，需要为机器人返回合适的“后续动作/视频”作为上下文。 论文还构建 Robota-Embed-Bench，并通过 Embed2ICL 和 Embed2Evolve 验证统一检索空间对机器人上下文学习与上下文进化的作用。

论文概述

Card 03 核心贡献

核心贡献

  • 提出 Robota-Embed：在检索查询和未来片段两端联合编码视觉、语言和原生动作的 VLA 嵌入模型，实现预测式物理经验检索。
  • 数据与评估：构建多源训练语料（1,695,684 个过滤后的 current–future 对）和 Robota-Embed-Bench（4,000 查询、8,000 候选共享库），并开展时间精度、表示学习和动作贡献的受控研究。
  • 提出 Embed2ICL：训练无关（DreamZero 视觉缓存初始化）和训练基于（Fast-WAM Context Tokens）的接口，将检索到的演示转化为策略上下文，并在仿真和真实机器人上评估。
  • 提出 Embed2Evolve：围绕冻结的 GPT-6 Astra 策略，用执行反馈进化任务本地记忆和上下文使用方式，提高成功率并降低策略 token 消耗。
Card 04 方法描述

方法描述

  • 问题形式化：对样本 i，查询为 (指令, 交互区域图像, 同步原生动作, 源标识)，目标为 (相同指令, 未来 4 秒视频片段, 对齐动作, 源标识)；目标是让当前查询检索到正确的未来连续片段。
  • 底座与架构：以 Cosmos3-Edge 4B 为基座；查询和目标共享 Transformer、视频 tokenizer 和 head，使用分离的 A_q / A_k adapters，并通过源特定 projector P_di 将不同原生动作映射到骨干。
  • 训练目标：总损失为 L_align + L_ground + L_reg；L_align 使用双向 InfoNCE，将精确未来片段作为正样本，任务/物体/动作/联合冲突作为负样本，并忽略兼容或不确定对。
  • 辅助目标：L_ground 结合任务/物体辅助监督与模态交换、硬语义冲突的 margin，使相似度对输入变化敏感；L_reg 对 query/target 批次中心化并抑制低方差、低秩表示。
  • 下游接口：Embed2ICL 使用 DreamZero 的视觉缓存或 Fast-WAM 的 Context Tokens；Embed2Evolve 持续将成功/失败尝试加入任务本地记忆，并搜索检索排序、刷新频率和保留历史等上下文配方。
Card 05 数据集与资源

数据集与资源

  • 训练数据：1,695,684 个过滤后的 current–future 对，来自 EgoDex、DROID、LIBERO、RoboMIND–Franka-dual，覆盖人类、仿真和真实机器人经验。
  • 评估基准：Robota-Embed-Bench，4,000 个 held-out 查询搜索一个共享的 8,000 片段 gallery；每个来源贡献 1,000 查询、800 episodes、1,000 paired future clips 和 1,000 nearby same-episode clips。
  • 模型规模：主模型基于 Cosmos3-Edge 4B 构建；对比的嵌入基线包括 2B/3B 级别模型（如 Qwen3-VL-Embedding-2B、Omni-Embed-Nemotron-3B）。
  • 训练资源：提供的 HTML 可见内容未明确给出完整训练 GPU/TPU 配置；检索延迟评估在单张 NVIDIA A100 上完成（1M–15M gallery 为 160.36–195.17 ms，15M 时 Top-10 搜索约 37.47 ms）。
Card 06 评估与结果

评估与结果

  • 检索基准与指标：在 Robota-Embed-Bench 上报告 clip-level 和 episode-level R@1/R@5/R@10/MRR；Robota-Embed 达到 47.33% clip-level R@1 和 81.77% episode-level R@1。
  • 对比提升：超过 Gemini Embedding 2 分别 22.09 和 33.47 个百分点；clip-level 详细结果为 R@5 91.9、R@10 97.0、MRR 67.05，episode-level 为 R@5 94.9、R@10 98.1、MRR 86.96。
  • 模态贡献：在 DROID 匹配设置下，加入动作将 clip-level R@1 从 59.8% 提升到 78.7%；重训练去除动作掉 18.9 个百分点，去除视觉仅掉 1.9 个百分点；固定模型时 mask query action/vision 分别掉 27.25/24.33 个百分点。
  • Embed2ICL 结果：在 DROID-Sim 上将平均成功率从 47.0% 提升到 56.3%；在 LIBERO difficult subset 上从 86.4% 提升到 92.8%；真实机器人任务进度也提升（如 Banana→Bowl 从 21.67 到 40.00，Split Cup 从 66.67 到 87.50）。
  • Embed2Evolve 结果：在五个 ManiSkill 任务上达到 68% 平均成功率，而 GPT-6 Astra Direct 为 24%，用 Omni-Embed-Nemotron-3B 进化的 harness 为 33%；相对 Omni-Embed harness 约少用 79.5% 的策略 token。
