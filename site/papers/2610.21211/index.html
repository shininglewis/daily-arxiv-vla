Card 03 核心贡献

核心贡献

  • 提出基于记忆的智能体框架用于主动机器人协助，通过用户特定作息上下文让高层 VLM 在无显式指令下决定"何时协助"与"执行什么任务"。
  • 提出 Procedural Assistance Memory (PAM)，一种以有限状态机（FSM）组织的记忆结构，包含活动阶段状态、状态内触发–动作规则以及事件驱动转移，利用用户与活动上下文降低协助需求歧义。
  • 设计自演化记忆闭环：反射器（reflector）每天离线根据当日行为与用户反馈修订 PAM，实现作息学习、变化适应与反馈吸收，全程无需微调或重训练权重。
  • 通过消融验证 FSM 结构本身（而非单纯增加记忆）是性能提升来源，并证明 System 1–2 分解优于单体 VLA。
Card 04 方法描述

方法描述

  • 任务预测器作为 System 2：以 1 Hz 频率接收最近 W=5 帧视频（stride=2）、文本化的 PAM 以及固定指令 *"Proactively help the user before they ask."*，输出自然语言任务或 NO_ACT，推理时关闭 thinking 模式以保证实时性。
  • PAM 序列化为结构化文本（如 JSON）注入提示词，包含状态描述、触发–动作对与转移；仅当任务可立即执行时才选择，否则输出 NO_ACT。
  • 记忆反射器作为离线更新模块，开启 thinking 模式，输入当日采样帧、上一版 PAM、当日动作历史摘要与用户反馈，识别被遗漏的协助机会、推断重复模式，并新增或修订状态、规则与转移。
  • PAM 在单日内保持固定，适应完全通过每日修订实现；VLA 执行器采用 π₀.₅ 骨干，每个任务采集 10 条示教微调。
Card 05 数据集与资源

数据集与资源

  • 自建 5 天桌面协助数据集：单一用户重复执行标准早餐桌面流程，每日录像约 3.5–4.5 分钟，按 1 fps 采样，共 1,146 帧标注（NO_ACT 673 帧，T1–T6 共 473 帧）。
  • 六个主动任务：T1 Cereal→Person、T2 Milk→Person、T3 Cereal→Storage、T4 Milk→Storage、T5 Bowl→Storage、T6 Wet wipe→Trash。
  • 另有 Scenario B（改吃维生素的变体作息）用于评估作息变化后的记忆适应。
  • VLM：Qwen 3.5–27B（任务预测器与反射器共用，经 vLLM 部署）。
  • VLA：π₀.₅ 骨干，三种变体（executor / monolithic / monolithic+reasoning）均微调 50,000 步，AdamW，学习率 1e−4 余弦衰减，有效 batch size 64，动作 chunk 长度 50，训练使用 NVIDIA B200 GPU。
  • 硬件：Franka Research 3 (FR3) 7-DoF 机械臂 + Deoxys 实时控制器（20 Hz），3 个 Intel RealSense 相机（左右后视 30 fps + 腕部相机），VR 遥操接口 TactAR（Meta Quest 3）。
Card 06 评估与结果

评估与结果

  • 评估协议：将主动任务预测形式化为逐帧分类问题（6 个任务 + NO_ACT），报告各类 precision/recall/F1 及宏平均，并报告 first-fire delay（应协助时刻到首次预测出任务的时间差）。
  • 基线：无记忆的 LIT、Event-driven VLM、Zero-shot VLM，以及 Ours w/ List Memory（扁平规则表）和 Ours w/ FSM Memory；执行层面与 π₀.₅ 及 π₀.₅ (Reasoning) 单体 VLA 对比。
  • 无记忆基线整体保守，T1–T6 召回率接近零且五天基本持平；记忆变体随天数持续提升，Ours w/ FSM Memory 取得最高的 precision、recall 和 F1，并将 first-fire delay 从 Day 1 的约 5 秒降至 Day 5 的约 1 秒。
  • FSM 记忆随天数持续改进，而 List Memory 因缺乏状态抽象而早早饱和，说明增益来自 FSM 结构；代价是其 NO_ACT 召回略低于保守基线（但 NO_ACT F1 持平）。
  • 作息切换（A→B）实验中，A-Evolving 在 Day 1 因旧记忆干扰而低于 Zero-shot VLM，但经过一次记忆更新后 Day 2 的 recall/F1 即恢复至与 Scratch-Evolving 相当，而 A-Frozen 始终低于 Zero-shot VLM。
  • 定性分析显示缺失的触发–动作对被逐日补全；作息变化后（如先吃维生素），反射器会把"人坐下→递麦片"的转移修订为"人坐下→递维生素"。
  • 与单体 VLA 对比中，Ours 在全部六个原子任务上成功率最高（如 Cereal→Person 9/10、Cereal→Storage 8/10、Bowl→Storage 8/10、Wet Wipe→Trash 8/10），远超 π₀.₅ 与 π₀.₅ (Reasoning)。
  • 局限：FSM 记忆在用户短暂触碰触发物而未真正进入该阶段时会误触发；且受限于开源 VLA 能力，评估仅限于已见场景，未覆盖新物体、新布局与新用户。
