Card 02 论文概述

论文概述

  • 论文提出 ChunkVLA-AM，一个面向增材制造（AM）场景的可复现 OpenVLA-OFT 部署流水线，用于在固定工作单元中的 FAIRINO FR3 机器人上执行打印后零件抓取与转移。
  • 目标在于解决两大部署难题：跨机器人本体的适配成本高昂（动作空间、坐标系、归一化规则不一致），以及环境变化（光照、物体位姿）下的鲁棒性退化。
  • 核心思路是用并行动作分块（action chunking）预测短时程动作序列，配合 LoRA 参数高效微调与云−边架构，实现“块内开环执行、块间闭环反馈”。
Card 03 核心贡献

核心贡献

  • 构建 TFDS/RLDS 数据转换流水线，将单目真实演示、笛卡尔末端状态、二值夹爪指令、语言指令和回合元数据统一转换为 OpenVLA 兼容格式。
  • 定义 7-D 笛卡尔动作表示（Δx, Δy, Δz, Δφ, Δθ, Δψ, g）及动作裁剪与归一化流程，明确 FR3 的坐标系与动作语义。
  • 提出 H=8 的动作分块接口与分块模仿目标，单次推理预测 8 步 7-D 动作，机器人执行完一个块后再采集新观测，实现块间闭环。
  • 设计 云−边执行架构与安全过滤机制：远程服务器跑 7B 模型，CPU-only 机器人端负责请求、反归一化、工作空间裁剪、NaN/超时/过期块拒绝与急停处理。
  • 完成 42 次物理 A-to-B 转移试验（成功率 92.9%） 与 多光照/色温鲁棒性扫描，给出可用亮度区间与失效模式分析。
Card 04 方法描述

方法描述

  • 数据转换（IV-A）：以机器人基座坐标系计算平移增量 Δp_t = p_{t+1} − p_t，旋转用 roll-pitch-yaw 欧拉增量；图像转 RGB、方形填充并缩放至 224×224，图像与状态按最近时间戳同步，采样率约 25 Hz。
  • 动作归一化（IV-B）：各维裁剪至对称范围后归一化到 [−1, 1]，默认裁剪值 c_x=c_y=c_z=5 mm，c_φ=c_θ=c_ψ=0.05 rad；夹爪通道不做连续归一化，改为二值离散命令 token。
  • LoRA 适配（IV-C）：冻结预训练主干，仅训练低秩更新；LoRA rank = 32、dropout = 0、学习率 5×10⁻⁴、batch size 8、梯度累积 4 步（有效 batch 32）、训练约 30 个 epoch；仅使用单目 RGB 与语言指令，无需深度、触觉或多视角输入。
  • 分块构造（IV-D）：训练目标 C_t = [ā_t, …, ā_{t+H−1}]，损失为分块对数似然 L_chunk；末端不足 H 步的块被截断并对 padding 位置做 mask。
  • 执行与安全（IV-E）：客户端通过 FastAPI 发送 (I_t, l, H)，收到动作块后逐条校验——工作空间约束 p_t+Δp_t ∈ B、最小底板间隙 z_t+Δz_t ≥ z_min、增量范数 ‖Δp_t‖∞ ≤ 5 mm 与 ‖Δr_t‖∞ ≤ 0.05 rad、夹爪命令合法；任一失败则丢弃该块剩余动作。
Card 05 数据集与资源

数据集与资源

  • 数据：FR3 单目真实演示数据（由 UTCRS 提供），含时间戳末端位姿、夹爪状态、控制器指令与相机帧；转换为 TFDS/RLDS 回合式数据集。
  • 模型：OpenVLA-OFT，参数量约 7B；对比基线包括 OpenVLA（单步，零样本）、OpenVLA-OFT（8 步分块，零样本）及单步微调模型（Bridging the Pretrain-to-Real Gap）。
  • 机器人：FAIRINO FR3 机械臂，固定单目 RGB 相机，固定 AM 工作单元。
  • 计算资源：推理服务器使用 NVIDIA RTX 6000 Ada，CPU-only 机器人工作站；单次请求模型侧推理耗时约 0.06–0.08 s（不含图像采集、网络传输与机器人执行）。
Card 06 评估与结果

评估与结果

  • 评估设置：两类语言条件任务 “catch the blue block” / “catch the red block”，各 21 次共 42 次物理 A-to-B 转移试验；轨迹级评估用 X/Y/Z 轴 MAE（式 19）与 3D L2 误差。
  • 轨迹预测结果：零样本模型误差极大（MAE 179.60–650.12 mm）；单步微调模型平均空间误差 9.50 mm，X 轴高达 16.90 mm；ChunkVLA-AM 平均 MAE 1.74 mm（X 0.37 mm、Y 0.97 mm、Z 3.87 mm），达到亚毫米级横向精度。
  • 物理闭环结果：42 次试验成功 39 次，成功率 92.9%；3 次失败均发生在终点放置阶段，因释放高度控制不足导致物体翻倒。
  • 光照鲁棒性：在 30–210 亮度（0–255 尺度）的 181 级密集扫描中，最小平均空间误差 5.459 mm 出现在亮度 95，低误差区间为 85–125；亮度 30 与 210 时误差升至 7.165 mm 与 6.598 mm；Z 轴是主要误差来源，极端过曝（亮度 190）使 Y 轴 MAE 升至 2.30 mm。
  • 主要结论：仅靠动作分块无法弥补空间语义缺失（零样本分块模型仍失败）；分块 + 本体适配的组合配置在固定 FR3 工作单元中可行，未来将补充物体/任务泛化、块长消融与接触力监测。
