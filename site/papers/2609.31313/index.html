Card 03 核心贡献

核心贡献

  • 提出在 VLA 冻结视觉编码器的嵌入空间（而非像素空间）上训练世界模型的架构，思路类似 JEPA（Joint-Embedding Predictive Architecture），以降低生成式模型“在像素中思考”的开销。
  • 设计嵌入评估（Embedding Assessment）框架：在视觉编码器上附加语义分割、深度估计与图像解码探针，量化嵌入是否包含物体掩码与场景几何信息，并将探针精度用于衡量世界模型想象的保真度与漂移。
  • 提出在训练好的世界模型内部用 model-free RL（如 PPO）继续精调 VLA 的流程，奖励为当前状态嵌入与目标状态嵌入之间的负均方距离，从而在推理时可基于目标图像进行短时规划。
  • 与 V-JEPA 2-AC 的 MPC 规划相比，该方法计算成本更低；与在嵌入空间中从头训练小型 MLP 策略相比，保留了 VLA 的语义先验与语言条件能力。
  • 提出该方案可替代传统仿真器生成轨迹，避免 sim-to-real gap，并减少构建与运行完整模拟器的算力需求。
Card 04 方法描述

方法描述

  • VLA 选择与训练：选用 π0-FAST 与 OpenVLA，因其基于 token 概率输出（而非 diffusion / flow-matching），便于采样动作并接入 RL 流程；两者分别在 NICOL 机器人模仿学习数据上微调。
  • 冻结策略：微调时冻结视觉编码器以避免与世界模型嵌入错位，同时对 VLA 的 LLM 主干施加强正则并冻结大部分权重，防止丢失语义知识。
  • 世界模型：使用随机动作、半专家/专家策略演示的混合数据训练，以保证动力学覆盖；输入为动作、机器人本体感觉状态（proprioception）与近期相机观测历史，输出为下一时刻的本体感觉状态和帧嵌入；对 OpenVLA 本体感觉仅作辅助损失。
  • 模型结构差异：π0-FAST 的世界模型需预测下一时刻本体感觉与帧嵌入；OpenVLA 的世界模型也将本体感觉作为辅助损失预测，但 RL 训练时不输入 VLA。
  • 图像解码器：额外训练一个图像解码器，仅用于探针与可视化，用于观察世界模型“梦境”的有损画面。
  • 嵌入探针：附加语义分割与深度估计探针，指标为 mIoU（分割）与 RMSE + 阈值精度（深度）；预期 OpenVLA 的 Prismatic 骨干因 DINOv2 在深度任务上表现更好，而 π0-FAST（SigLIP 起始、经 PaliGemma-3B 与 π0-FAST 机器人训练）可能较弱。
  • RL 训练：给定初始桌面配置嵌入与目标图像嵌入，将世界模型作为模拟器，奖励为当前嵌入与目标嵌入的负均方距离；限制想象时域并使策略贴近预训练先验，以抑制漂移累积与世界模型误差被利用。
