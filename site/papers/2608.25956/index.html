4DGS-WAM: Bridging Past and Future with an Object-Centric World Action Model based on 4D Gaussian Splatting

2026-08-26 · 原文 · 翻译 · 2608.25956

论文提出 4DGS-WAM，一种基于 4D Gaussian Splatting（4DGS） 的物体中心世界动作模型（World Action Model）。 核心思想是将动态场景显式分解为动态物体与静态背景：政策模型（Policy）预测未来动作，世界模型（World Model）预测物体高斯斑块的变换；静态背景可直接复用历史帧，无需重新生成。 该方法将 2D 观测提升为持久化的 4D 表示，使未来预测只需聚焦于动态物体的演化，解决了现有 2D 世界动作模型缺乏显式空间结构、重复计算冗余背景的问题。

Card 02 论文概述

论文概述

  • 论文提出 4DGS-WAM，一种基于 4D Gaussian Splatting（4DGS） 的物体中心世界动作模型（World Action Model）。
  • 核心思想是将动态场景显式分解为动态物体与静态背景：政策模型（Policy）预测未来动作，世界模型（World Model）预测物体高斯斑块的变换；静态背景可直接复用历史帧，无需重新生成。
  • 该方法将 2D 观测提升为持久化的 4D 表示，使未来预测只需聚焦于动态物体的演化，解决了现有 2D 世界动作模型缺乏显式空间结构、重复计算冗余背景的问题。
Card 03 核心贡献

核心贡献

  • 首次提出基于 4DGS 的世界动作模型，显式地将动态场景分解为静态与动态组件，实现静态背景的持久化复用。
  • 提出区别于以往多模态大模型（MLLM）框架的新式 WAM 框架：Policy + World Model 直接作用于物体轨迹和 4DGS 高斯状态，进行物体中心的动作为条件未来预测。
  • 引入时间条件化政策网络，可单次前向预测任意目标时域（horizon）的 SE(3) 动作，无需自回归逐步预测中间动作。
  • 在自动驾驶基准 KITTI-MOT 上，同时评估了未来帧预测与历史重建，并与视频类世界模型、点云方法及 4DGS 基线进行了比较。
Card 04 方法描述

方法描述

  • 过去感知（Past Perception）：使用 4DGS 重建器生成包含位置、旋转、尺度、不透明度、球谐系数、时间跨度及运动 twist 的高斯原语；并结合多个视觉基础模型（VFM）进行分割、深度估计、相机位姿估计和光流估计。

- SAM 3 提供分割掩码与跨帧物体身份；DA3 提供致密深度；VGGT / VGGT-Ω 恢复相机几何；WAFT 估计光流。

  • 未来预测（Future Prediction）：

- 政策网络 π：接收各 actor（动态物体 + ego）的物体中心轨迹，通过时间注意力与 actor 级 kNN 注意力，输出目标时域的单步 SE(3) 动作。

- 世界模型 W：接收预测动作与当前高斯快照，对每类物体的 part token 预测残差 SE(3) twist，经残差混合后与物体动作组合，预测未来 4DGS 状态，并渲染出未来图像。

  • 关键创新：利用静态背景不需要再生、动态物体单独建模的分解策略，显著降低未来预测的计算冗余。

评估与结果

  • 重建评估：渲染累积 4DGS 状态，相比 3DGS、点云方法和其它 4DGS 基线在 full-frame 指标上取得更高分数。
