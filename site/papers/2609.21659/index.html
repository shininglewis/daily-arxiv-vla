Outcome-Conditioned End-Effector Geometry Across Vision-Language-Action Policies

2026-09-18 · 原文 · 翻译 · 2609.21659

论文研究 Vision-Language-Action (VLA) 策略在相同任务、初始状态、指令和视觉条件下的 末端执行器路径几何，并按两条策略的联合结果划分为 both-success (SS)、mixed (SF)、both-failure (FF) 三层。 研究目标是回答仅靠任务成功率无法回答的问题：不同 VLA 策略是否以相似的物理轨迹执行同一操作，以及低跨策略轨迹距离是否意味着策略可互换。 基于 15,000 条 LIBERO 闭环 rollout 和四个策略，论文发现 SS 路径比 SF 更接近；该方向在多种表示下稳定，但距离幅度随表示变化，因此只报告方向而非固定倍数。

Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action (VLA) 策略在相同任务、初始状态、指令和视觉条件下的 末端执行器路径几何，并按两条策略的联合结果划分为 both-success (SS)、mixed (SF)、both-failure (FF) 三层。
  • 研究目标是回答仅靠任务成功率无法回答的问题：不同 VLA 策略是否以相似的物理轨迹执行同一操作，以及低跨策略轨迹距离是否意味着策略可互换。
  • 基于 15,000 条 LIBERO 闭环 rollout 和四个策略，论文发现 SS 路径比 SF 更接近；该方向在多种表示下稳定，但距离幅度随表示变化，因此只报告方向而非固定倍数。
Card 03 核心贡献

核心贡献

  • 提出 outcome-conditioned 跨策略末端执行器几何比较设计：以策略对为单位，按联合结果分层，并在匹配配置下比较归一化 DTW 距离。
  • 在 3,600 个 clean L0 配置匹配策略对中发现，SS 中位距离为 0.0120 m，低于 SF 的 0.0380 m 和 FF 的 0.0439 m；SS–SF 排序在全部任务、策略对、模板和九种表示中保持。
  • 引入成功保持控制：同任务换初始状态时中位数为 0.0157 m，换任务时为 0.0817 m，表明成功执行的一致性主要与任务相关。
  • 通过 within-policy baseline 和重复实验揭示残余策略差异：同策略中位数 0.0133 m，跨策略中位数 0.0156 m，说明低跨策略距离不等于策略等价。
  • 分析复合视觉压力下的性能与比较群体变化：clean ranking 在 L3 不再保持，且结果分层中的 pair composition 会随压力改变；FF 比较因支撑薄弱仅作探索性报告。
Card 04 方法描述

方法描述

  • 在 LIBERO-Spatial 上进行闭环 rollout，每个 episode 记录末端执行器位置；一个 configuration 固定任务、初始状态、指令模板和视觉等级，并枚举六个无序策略对。
  • 使用 outcome-conditioned 分层：两条执行均成功记为 SS，仅一条成功记为 SF，均失败记为 FF；每条路径每五个记录位置采样一次。
  • 采用归一化动态时间规整作为核心距离，局部代价为三维末端位置欧氏距离，分母为两条序列长度之和，距离单位为米。
  • 设计成功保持控制：固定 anchor 策略，将 partner 替换为同策略、同模板但不同初始状态或不同任务的成功轨迹，并设置 within-policy state-variation baseline。
  • 使用 task–state block bootstrap、九种对齐/重采样表示、固定 72 控制窗口诊断、endpoint/duration 回归和 permutation test 检验稳健性。
  • 设置 L0–L4 复合视觉压力：亮度缩放、高斯像素噪声、平移和遮罩；另做 1,200 次执行的重复实验，检验确定性策略与随机策略的重跑差异。
Card 05 数据集与资源

数据集与资源

  • 主要数据集为 LIBERO-Spatial：10 个任务，每个任务前 20 个初始状态，3 个指令模板，5 个视觉等级。
  • 额外使用 LIBERO-Object，但仅覆盖 π0.5 策略；跨策略几何分析限制在 LIBERO-Spatial。
  • 四个策略为 OpenVLA、OpenVLA-OFT (OFT)、UniVLA、π0.5；每个策略贡献 3,000 条 Spatial rollout，共 12,000 条 Spatial 执行，另有 3,000 条 Object rollout，总计 15,000 个不同键。
  • L0 clean 网格包含 600 个配置、2,400 个 episode 和 3,600 个配置匹配策略对；L0–L4 对应配置/episode/策略对计数为 3,000 / 12,000 / 18,000。
  • 外部参考使用官方 LIBERO demonstrations，共 500 条，每个任务 50 条，来自固定数据集修订版并逐文件校验。
  • 原文未报告各策略的参数量，也未报告训练或推理所用 GPU/TPU 等计算资源。
  • 策略接口存在差异：OpenVLA 使用外部视图 224²、每步查询；OFT 使用外部/腕部视图和本体感知 256²、8 动作队列；UniVLA 使用外部视图 224²、每步查询；π0.5 使用外部/腕部视图和本体感知 256²、5 动作 cadence。
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO 模拟器中的闭环 rollout；主要基准为 LIBERO-Spatial，LIBERO-Object 仅用于 π0.5 的辅助分析，官方 demonstrations 用作外部几何参考。
  • 主要评估指标包括任务成功率、归一化 DTW 中位距离（米）、SS/SF/FF 条件中位数、task–state block bootstrap 95% 区间、paired difference、Cliff’s δ 与 permutation test p 值。
  • Clean L0 主要结果：SS = 0.0120 m（n=2,588），SF = 0.0380 m（n=923），FF = 0.0439 m（n=89）；SF−SS bootstrap 区间为 [0.0235, 0.0284] m，FF−SS 为 [0.0245, 0.0506] m。
  • SS–SF 排序在 10 个任务、6 个策略对、3 个模板和九种表示中均保持；策略对 SS 中位数范围为 0.0109–0.0143 m，SF 为 0.0341–0.0431 m，但 SF/SS 比率范围为 2.53–6.13，幅度依赖表示。
  • 成功控制显示：同任务/同状态为 0.0120 m，同任务换状态为 0.0157 m，换任务为 0.0817 m；中心化后跨任务中位数从 0.0794 m 降至 0.0556 m，仍高于同任务控制。
  • Within-policy baseline 显示同策略 0.0133 m、跨策略 0.0156 m，中位配对差为 0.0021 m；重复实验中跨策略中位数比两策略内中位数均值高 0.0082 m，区间 [0.0077, 0.0085] m；确定性策略路径字节级一致，随机策略不一致。
  • 固定 72 控制窗口后，SS 为 0.0140 m、SF 为 0.0240 m、FF 为 0.0340 m，SF−SS 对比为 0.01007 m（95% 区间 [0.00842, 0.01172] m），约为同队列全 episode 对比的 39%。
  • Endpoint 与 duration 调整后，SF 系数从原始 0.0294 降至全模型 0.0048，但仍为正；permutation test 中观测 SF−SS 中位对比 0.0260 超过全部 5,000 次置换，p = 0.0002。
  • 视觉压力下 clean ranking 不保持：L0 成功率为 OpenVLA 0.762、OFT 0.673、UniVLA 0.962、π0.5 0.992；L3 排序变为 π0.5 > OFT > UniVLA > OpenVLA，UniVLA 从 577/600 降至 66/600，OFT 从 404/600 降至 192/600。
  • L3 时 SS 中位距离升至 0.0206 m 但仅剩 223 对，SF 为 0.0382 m（n=1,471），FF 为 0.0446 m（n=1,906）；L4 无 SS 对，3,564/3,600 为 FF，仅 36 对 SF，说明距离与样本组成必须联合解读。
