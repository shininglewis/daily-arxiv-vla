ForeTac-VLA: A Forecasting-Based Tactile-Vision-Language-Action Model for Contact-Rich Robotic Manipulation

Card 02 论文概述

论文概述

  • 提出 ForeTac-VLA，一种基于预测的触觉-视觉-语言-动作（Tactile-Vision-Language-Action）模型，面向接触丰富（contact-rich）的机器人操作任务。
  • 针对现有 VLA 模型过度依赖视觉感知、在接触密集场景中难以获取关键物理交互状态的问题，以及现有触觉增强 VLA 方法多为“反应式”而非“预测式”的局限。
  • 核心目标：通过预测未来触觉状态来指导动作生成，使机器人能够对即将发生的接触变化进行推理，而非仅依赖已观测到的触觉反馈。
Card 03 核心贡献

核心贡献

  • 提出 ForeTac-VLA，显式预测未来触觉状态并将其用于指导接触丰富操作中的动作生成。
  • 设计多模态融合策略，实现触觉表征与视觉-语言表征之间的双向交互，并利用基于 Transformer 的预测模块预测多步未来触觉状态。
  • 在四个真实世界接触丰富任务上验证，平均成功率达 95%，并展示在低光照与视觉杂乱等挑战性条件下的鲁棒性与泛化能力。
  • 引入真值到预测（ground-truth-to-prediction）课程学习策略，缓解早期预测不可靠对训练稳定性的影响。
Card 04 方法描述

方法描述

  • 模型基于预训练的 π0.5 VLA 模型构建，扩展了时序触觉编码、双向交叉注意力和多步未来触觉预测模块。
  • 每个控制步输入：腕部与外部相机视觉观测、语言指令、机器人本体感知，以及最近 K=10 个时间步的触觉测量。
  • 视觉观测由预训练 SigLIP 视觉编码器编码；语言指令与离散化本体感知通过 PaliGemma 分词器嵌入。
  • 触觉输入：每个夹爪手指提供 7×4 触觉阵列，将绝对触觉历史与相对首帧的变化拼接展平后，经轻量级 MLP 编码器得到触觉 token。
  • 双向交叉注意力：触觉 token 关注视觉-语言 token，同时视觉-语言 token 关注触觉 token，实现跨模态信息交换。
  • Transformer 触觉预测器：将精炼后的触觉与视觉-语言 token 拼接为多模态记忆，预测未来多个时间偏移的触觉状态变化，偏移集合 O={5,10,15,20}，对应约 0.083、0.167、0.250、0.333 秒（60 Hz 采样）。
  • 预测的未来触觉状态被编码为未来触觉 token，与精炼视觉-语言 token 拼接为多模态前缀，条件化动作专家生成连续动作块（采用 flow-matching 目标）。
  • 训练策略：从 π0.5 检查点初始化，使用 LoRA 微调；新增模块与 VLA 主干可训练部分联合优化，其余预训练参数冻结。
  • 两阶段课程：前 75% 训练步使用真值未来触觉 token 条件化动作生成，后 25% 替换为模型预测的未来触觉 token，缩小训练与推理差距。
Card 05 数据集与资源

数据集与资源

  • 使用 280 条遥操作演示，覆盖四个任务，每任务 70 条，通过 GELLO 遥操作接口采集，视觉、触觉、本体感知与动作以 60 Hz 同步记录。
  • 四个真实世界接触丰富任务：Peg Insertion（插销插入）、Chip Handling（芯片处理）、Cap Unscrewing（拧瓶盖）、Board Wiping（擦板）。
  • 机器人平台：UR7e 机械臂，配备 Robotiq 2F-85 平行夹爪与双指 TSF-85 触觉传感器；视觉由两个 Intel RealSense D455f 相机提供（固定外部相机与腕部相机）。
  • 模型基于预训练 π0.5 VLA 检查点，涉及 SigLIP 与 PaliGemma 等预训练组件；论文未明确给出总参数量。
  • 训练资源：Intel Core Ultra 9 285K CPU、128 GB 内存、NVIDIA RTX PRO 6000 Blackwell @ 96 GB GPU；所有模型训练 60,000 优化步。
Card 06 评估与结果

评估与结果

  • 评估环境：真实机器人平台，四个接触丰富操作任务，每个模型每任务 20 次独立试验，共 80 次试验。
  • 评估指标：任务成功率（task success rate）。
  • 对比基线：ACT、Fine-tuned VLA（无触觉）、FiLM-Fusion TacVLA、Concat-and-Gating TacVLA。
  • 主要结果：ForeTac-VLA 平均成功率 95.00%，显著优于 ACT 13.75%、Fine-tuned VLA 58.75%、FiLM-Fusion TacVLA 71.25%、Concat-and-Gating TacVLA 72.50%。
  • 相对提升：比微调 VLA 高 36.25 个百分点，比 FiLM-Fusion TacVLA 高 23.75 个百分点，比 Concat-and-Gating TacVLA 高 22.50 个百分点。
  • 分任务表现：Peg Insertion 20/20（100%）、Chip Handling 19/20（95%）、Cap Unscrewing 19/20（95%）、Board Wiping 18/20（90%）。
  • 消融实验：无触觉 58.75%；触觉拼接 68.75%；单向/双向交叉注意力 80.00%；单向交叉注意力+预测 81.25%；完整 ForeTac-VLA 95.00%。
  • 触觉预测精度：归一化触觉空间中未来触觉状态预测的平均绝对误差（MAE）为 6.48×10^-3。
  • 鲁棒性：低光照环境下 ForeTac-VLA 平均成功率 80.0%（Concat-and-Gating TacVLA 55.0%，Fine-tuned VLA 40.0%）；视觉杂乱环境下 81.25%（53.75%，27.50%）。
  • 失败案例分析：插入错位、芯片破损、瓶盖滑脱、抓取位置错误等典型失败模式。
  • 局限性：当前仅验证单一触觉传感配置与机器人本体；触觉预测器仅在预定义时间偏移上预测。未来工作将探索跨传感器配置的触觉表征、自适应预测时域以及更长时域任务与更多样物体的评估。
