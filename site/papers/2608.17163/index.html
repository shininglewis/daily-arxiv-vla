Card 02 论文概述

论文概述

  • 提出 QWM（Q-Learning With World Models） 框架，利用世界模型在标准 Q-learning 之上进行测试时搜索（test-time search），通过想象未来轨迹选择高价值动作。
  • 核心问题：传统模型增强 RL 在想象 rollouts 上优化策略/价值函数，容易累积世界模型的复合偏差，难以扩展到高维机器人操作任务。
  • 核心思路：策略与价值函数仍仅由真实环境 transition 训练，世界模型仅用于在线 rollout 和评估时的动作选择，从而既获得预测搜索的样本效率收益，又避免复合模型偏差。
Card 03 核心贡献

核心贡献

  • 提出 QWM：简单通用的框架，将世界模型与 Q-learning 结合，通过树搜索实现测试时动作选择，适用于任意带 Q 函数的 RL 微调算法。
  • 设计了基于世界模型的树搜索：从当前状态出发，策略采样候选动作，世界模型预测未来状态，递归扩展至深度 D，并结合 Q 函数与 rollout 价值进行聚合。
  • 提出双价值估计器组合：融合状态-动作价值估计（依赖 Q 函数、深度无关）与状态价值估计（依赖想象 rollout、含模型误差），通过加权平均提升动作评分的鲁棒性。
  • 引入基于 Q 函数的束搜索剪枝：用累计折扣 Q 值筛选最优路径，控制树规模与计算开销。
  • 在 Robomimic 与 LIBERO 基准上显著超越强基线（模型无关与模型增强方法），并在状态与像素两种观测设置下均展示收益。
Card 04 方法描述

方法描述

  • 树搜索构造：状态节点采样 N 个候选动作，动作节点通过世界模型采样 K 个下一状态，递归至深度 D；叶节点采样 N_leaf 动作并用 Q 函数聚合。
  • 节点价值聚合：结合两个互补估计器——直接 Q 值聚合（低方差、不依赖 rollout）与基于预测奖励和递归状态价值的 rollout 聚合（利用未来信息但累积模型误差），二者加权平均作为节点价值。
  • 搜索策略：以 Q 函数为启发式对路径进行束搜索，保留累计折扣 Q 值最高的 J 条路径，从而限制扩展节点数。
  • 世界模型实现：状态观测下使用确定性残差 MLP 动力学模型（三层，隐藏维度 256），预训练于离线演示数据；像素观测下将 Wan2.2-TI2V-5B 视频扩散模型改造为动作条件世界模型，通过 MLP 动作编码器注入动作 token，采用 flow-matching 目标训练。
  • 无奖励模型：由于稀疏奖励（除终止态外为零），直接利用终止奖励与价值函数，不额外学习奖励模型。
Card 05 数据集与资源

数据集与资源

  • Robomimic：Lift、Can、Square、Tool Hang 四个操作任务（低维状态观测）。
  • LIBERO：5 个视觉操作任务（像素观测），按先前工作协议评估。
  • 世界模型使用离线演示数据集预训练，在线 RL 使用离线数据 + 在线回放缓冲。
  • 像素世界模型为 5B 参数的扩散 transformer（Wan2.2-TI2V-5B），冻结 VAE 和文本编码器，微调 action encoder 与 transformer。
  • 训练资源：使用 Delta 系统（NCSA，ACCESS 分配 CIS260152），配合 NSF 与 ONR 资助。
Card 06 评估与结果

评估与结果

  • 对比基线：模型无关方法（RLPD、DSRL、QSM、QAM、FQL、IDQL、EXPO），模型增强方法（TD-MPC2、EfficientZero V2）。
  • 主要指标：在线微调过程中的任务成功率（success rate），关注样本效率与最终性能。
  • Q1（整体性能）：QWM 在 Robomimic 全部任务上显著优于模型无关基线，在样本效率上尤其突出；相比模型增强方法（TD-MPC2、EfficientZero V2），QWM 在所有操作任务上取得更强成功率（传统方法仅在 Lift 上有非零成功）。
  • Q2（相对基算法）：在 EXPO 与 RLPD 基础上分别叠加 QWM，均一致提升样本效率，Tool Hang 和 Square 任务上增益最大；QWM 性能随基算法增强而增强。
  • Q3（像素扩展）：在 LIBERO 五任务上，仅使用采样时搜索（无评估搜索）即获得对 EXPO 的明显提升，尤其是在 Task 60、79、29 上学习更快、最终表现更强。
  • Q4（组件消融）：

- 采样 + 评估双阶段搜索最稳定有效，优于单阶段。

- 搜索深度 D=2 最佳；折现因子 λ=0.2 左右最佳，过大/过小均降低性能。

- 候选动作数 N 需适中，过多会增加模型误差影响与计算开销。

- 束宽 J（扩展节点数）影响较小，启发式剪枝已足够。
