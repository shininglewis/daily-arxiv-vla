Card 02 论文概述

论文概述

  • 论文研究 视觉-语言-动作（VLA）模型 在机器人嵌入式设备上的高效推理问题，核心瓶颈是每个控制步中大量视觉 token 带来的 prefill 延迟。

Card 03 核心贡献

核心贡献

  • 提出 token 级诊断实验，发现一个缓存 token 应“复用”还是“剪枝”主要取决于其 drift（浅层表示相对变化），而不是 token 重要性。
  • 提出 TRIAGE 三集合结构：将视觉 token 划分为 重算集合、复用集合、剪枝集合，并指出 prune-only 与 reuse-only 方法只是该结构的两个极端。
  • 设计固定重算预算机制，使重算 token 数直接决定 prefill 延迟，便于在机器人控制循环中满足实时性约束。
  • 在 两个 VLA 骨干、两个基准 上验证方法有效性，在 Jetson AGX Orin 上实现最高 48% prefill 延迟降低。
  • 在极小重算预算下优势显著：仅重算 7% 视觉 token 时，在 LIBERO-Object 上比最强基线高 24.4 个百分点。
Card 04 方法描述

方法描述

  • 利用浅层网络已计算的信息提取两类信号：重要性（解码 token 对视觉 token 的注意力）和 drift（浅层 value 相对上次重算的变化）。
  • 缓存有效性定义为：token 已有缓存、drift < δ（默认 0.3）、且缓存年龄 age ≤ T（默认 10）。
  • 重要性评分结合当前浅层注意力与 SAFE-Pruner 风格的深层显著性预测记忆，并通过 patch 对应关系在帧间传递。
  • 在固定预算 B 下，优先重算“重要且缓存无效”的 token；其余 token 中，缓存有效则复用，无效则剪枝。
  • 重算集合按优先级填充：缓存维护、强制重算、可选刷新，从而兼顾背景缓存更新与关键 token 精度。
  • 方法为 免训练 加速器，不需要额外训练，也不引入显著额外计算。
Card 05 数据集与资源

数据集与资源

  • 评测基准包括 LIBERO 的四个 suite（每个 500 episodes）以及 SimplerEnv Google Robot 任务。
  • 使用的 VLA 骨干为 OpenVLA-7B（256 个视觉 token）和 OpenVLA-OFT（512 个视觉 token，单次前向预测 8 步动作块）。
  • 使用公开的 LIBERO checkpoints，SimplerEnv 上使用基础 OpenVLA checkpoint。
  • 方法为免训练方法，无额外训练资源消耗；延迟测试硬件为 Jetson AGX Orin 和 RTX 3090，均使用 bf16。
Card 06 评估与结果

评估与结果

  • 对比基线包括 Full recomputation、VLA-Cache、VLA-Pruner、SAFE-Pruner、SpecPrune-VLA。
  • 评估指标包括 成功率、prefill FLOPs、prefill 延迟、端到端延迟和 p99 延迟。
  • 在 LIBERO 上，TRIAGE 平均成功率与完整重算差距保持在 3 个百分点 以内，并在 Jetson 上取得最低 p99 延迟。
  • 在 OpenVLA-OFT 上，TRIAGE 的 prefill 延迟降至完整重算的 0.52×，即在 Jetson AGX Orin 上约降低 48%。
  • 在 SimplerEnv 上无需重新调参即可迁移，平均成功率 54.5%，接近完整重算的 54.8%，且延迟最低。
  • 在 LIBERO-Object 上，仅重算 7% 视觉 token 时，TRIAGE 仍显著优于剪枝和复用基线，最高领先 24.4 个百分点。
