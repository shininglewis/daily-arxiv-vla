PlanWAM: Planning-Shaped Future Representations for End-to-End Autonomous Driving

2026-10-08 · 原文 · 翻译 · 2610.11382

Card 02 论文概述

论文概述

  • 论文提出 PlanWAM（Planning-Shaped World Action Model），旨在解决端到端自动驾驶中“哪种未来表示对规划最有用”的问题。
  • 现有世界模型主要关注如何预测未来以及如何使用未来信息，但未来表示通常由像素重建或通用图像潜在预测定义，可能与下游规划目标不匹配。
  • PlanWAM 的核心思想是让规划任务直接塑造未来状态表示，使其优先编码对轨迹决策最有用的信息，从而实现前瞻性规划。
Card 03 核心贡献

核心贡献

  • 将端到端驾驶中的未来建模重新表述为规划导向的预测表示学习问题，未来表示由轨迹规划目标直接塑造，而非预定义的重建或通用预测目标。
  • 提出 PlanWAM，包括：提取紧凑历史表示、从真实未来观测和规划目标中学习规划塑造的未来潜在表示、通过Hindsight-to-Foresight Distillation 从历史中预测该表示以指导轨迹生成与选择。
  • 在 NAVSIM-v1/v2 上分别达到 93.8 PDMS / 90.9 EPDMS，在 HUGSIM 零样本闭环评估中达到 38.7 HD-Score，并证明规划塑造的未来表示能减少碰撞和低 TTC 等安全关键失败。
Card 04 方法描述

方法描述

  • 将未来建模形式化为规划导向的预测表示学习，规划目标定义哪些未来信息重要，未来预测指导历史信息的保留。
  • 使用 Temporal Register Pyramid 以近期感知方式压缩多帧多视角历史观测，学习紧凑的历史表示 \(h_t\)，保留对未来推理和规划关键动态线索。
  • 引入训练专用的特权未来后验分支 \(P_\phi\)，利用真实未来帧和规划目标构造规划塑造的未来潜在表示 \(z_t^+\)，并通过轨迹生成和选择目标反向传播塑造其表示空间。
  • 使用 Hindsight-to-Foresight Distillation 训练仅依赖历史的先验分支 \(P_\theta\)，对齐先验预测 \(\hat{z}_t^+\) 与后验目标 \(z_t^+\)，将特权 hindsight 转化为可部署的 foresight。
  • 预测的未来表示与历史表示融合为前瞻规划上下文，用于轨迹生成和选择（Foresight-Conditioned Planning）。
  • 两阶段训练：第一阶段仅优化特权后验；第二阶段冻结后验，用其初始化先验并以较低学习率微调先验。
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSIM-v1、NAVSIM-v2、HUGSIM；训练在 NAVSIM navtrain，评估在 navtest。
  • 视觉骨干：DINOv2 ViT-S，冻结基础权重，使用 rank-32 LoRA；每相机帧提取 16 个场景寄存器。
  • 历史表示：Temporal Register Pyramid 分配 [4,4,8,16] 查询每相机跨四个时间层级，产生 128 token 的历史表示。
  • 未来潜在：4 个未来时间、4 个相机、每相机 16 个寄存器，得到 256 个后验未来潜在 token。
  • 轨迹规划器生成 64 条候选轨迹，每条 8 个路点。
  • 训练资源：16 张 NVIDIA A800 GPU，每 GPU batch size 为 8；Stage 1 学习率 \(1\times10^{-4}\)，Stage 2 学习率 \(1\times10^{-5}\)，latent alignment 权重 \(\lambda_{\text{latent}}=0.05\)。
Card 06 评估与结果

评估与结果

  • 评估环境：NAVSIM-v1/v2 开环规划基准，HUGSIM 零样本闭环泛化测试。
  • 主要指标：PDMS（NAVSIM-v1）、EPDMS（NAVSIM-v2）、HD-Score 和 Route Completion（HUGSIM）。
  • NAVSIM-v1：PlanWAM 达到 93.8 PDMS，超过 DrivoR 基线 0.7 分，超过最强世界模型规划器 DriveFuture 3.1 分。
  • NAVSIM-v2：PlanWAM 达到 90.9 EPDMS，超过此前最强学习结果 1.0 分，超过人类基线 0.6 分；获得最佳学习 NC 99.0 和 TTC 98.5。
  • HUGSIM 零样本闭环：PlanWAM 达到平均 RC 53.7、HD-Score 38.7，超过最强基线分别 7.8 和 9.8 分；在 Hard/Extreme 子集上达到 51.9/37.2 RC 和 35.6/22.0 HD-Score。
  • 消融与分析表明，规划塑造的未来表示能改善轨迹生成和选择，并减少安全关键失败（如碰撞和低 TTC 事件）。
