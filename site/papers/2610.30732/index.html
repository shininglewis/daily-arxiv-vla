Card 02 论文概述

论文概述

  • 论文提出 SmolVLA-MoE，在轻量视觉-语言-动作模型 SmolVLA 的动作专家 FFN 层引入稀疏 Mixture-of-Experts (MoE)，用于多任务机器人操作。
  • 针对现有轻量 VLA 模型使用单一稠密动作专家、难以在固定推理预算下兼顾多任务容量的问题。
  • 目标是在不增加推理激活参数的前提下扩展模型容量，提高多任务操作成功率。
Card 03 核心贡献

核心贡献

  • 首次在轻量 SmolVLA 架构上构建 MoE 动作专家，在保持约 500M 激活参数预算的同时扩展模型容量。
  • 基于 AdaMoE 引入可控共享专家权重 α，平衡预训练能力继承与任务专家专业化。
  • 在 LIBERO 四个任务套件上取得 84.25% 平均成功率，超过稠密基线 SmolVLA（82.75%） 和 OpenVLA-7B（76.5%），并保持与稠密基线相当的推理效率。
  • 系统分析 top-K、共享专家权重、负载均衡损失等设计对多任务性能的影响。
Card 04 方法描述

方法描述

  • 将动作专家中的稠密 FFN 替换为 MoE-FFN 层，每层包含多个并行路由专家 FFN、一个共享专家、一个 token 级 router 和一个 scaling adapter，注意力层保持共享。
  • Router 使用无偏线性投影生成专家 logits，通过 top-K 选择专家，并对选中专家做 softmax 得到路由权重。
  • Scaling adapter 为每个 token 提供额外自适应缩放，与 router 权重相加，实现专家选择与专家权重的解耦。
  • 共享专家始终激活，最终输出为 α·E_s(x) + y_routed(x)，其中 α 控制预训练知识继承与专家 specialization 的平衡。
  • 采用 Sparse Upcycling 初始化：共享专家精确复制预训练稠密 FFN 权重，路由专家在稠密权重上加入高斯噪声（默认 σ=0.02）。
  • 训练损失为 Flow Matching loss + λ·load balancing loss，默认 λ=0.01，并通过层替换频率 f 控制 MoE 插入范围。
Card 05 数据集与资源

数据集与资源

  • 使用 LIBERO 基准，包含四个任务套件：LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-10。
  • 每个任务评估 10 次 rollout，以成功率作为评价指标。
  • 视觉语言主干为冻结的 SmolVLM2-500M；动作专家使用 4 个路由专家 + 1 个共享专家。
  • 模型总存储参数约 800M；推理时每 token 激活 1 个专家 FFN，动作专家约 100M 激活参数，总激活参数约 500M。
  • 训练使用单张 NVIDIA RTX 4090（24GB），AdamW 优化器，学习率 1e-4，batch size 48，训练 120,000 步，warmup 4,000 步，Flow Matching 推理 10 步。
Card 06 评估与结果

评估与结果

  • 在 LIBERO 四个套件上评估多任务机器人操作性能，主要指标为任务成功率。
  • SmolVLA-MoE 平均成功率为 84.25%；分套件为 Spatial 87%、Object 93%、Goal 93%、LIBERO-10 65%。
  • 相比稠密基线 SmolVLA（82.75%） 平均提升 1.5 个百分点，其中 Goal 提升 5 个百分点，LIBERO-10 提升 2 个百分点。
  • 在约 500M 激活参数下优于 OpenVLA-7B（76.5%），并接近 π0-3.3B（86.0%），后者激活参数约为其 6.6 倍。
  • 消融显示最佳配置为 top-1 routing + α=0.3；移除共享专家使 Goal 从 93% 降至 88%；移除负载均衡损失使 Goal 从 93% 降至 90%。
