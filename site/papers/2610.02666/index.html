CHASE-VLA: Post-Training Quantization Framework for Vision-Language-Action Models with Chunk-Aware Scale Estimation

Card 02 论文概述

论文概述

  • 论文研究面向 Vision-Language-Action (VLA) 模型的低比特训练后量化（PTQ），重点关注其中被反复调用的基于扩散的动作专家（AE, Action Expert）。
  • 核心问题：AE 在每个去噪步骤和每次策略查询中反复被调用，其激活范围随去噪进度和生成的动作上下文动态变化，而静态校准尺度无法匹配这种变化，导致裁剪误差或量化分辨率损失。
  • 研究目标：在不修改预训练策略的前提下，实现 AE 中 MLP 与注意力投影的 W4A4 量化，在保持控制精度的同时降低存储与内存流量。
Card 03 核心贡献

核心贡献

  • 识别出激活尺度不匹配（跨去噪步骤与动作上下文）是基于扩散式 VLA AE 实现低比特 PTQ 的核心障碍。
  • 提出 CHASE-VLA，利用上一次生成的动作块（含未执行的未来后缀）作为因果动作上下文，结合去噪步骤组信息估计激活尺度。
  • 将 W4A4 量化目标从 AE 的 MLP 投影扩展到 MLP 与注意力投影，覆盖重复调用路径上的更多计算。
  • 在 LIBERO 上跨 π0.5、GR00T N1.6、CogACT 三种不同 AE 架构验证方法有效性，并量化存储与内存流量收益。
  • 设计不确定性感知的尺度乘子预测器，通过高斯负对数似然项调节激进缩放风险。
Card 04 方法描述

方法描述

  • 保留标准均匀量化算子，但对校准得到的基础尺度施加动作条件化乘子自适应调整。
  • 动作上下文信号：将上一策略查询生成的完整动作块（含前缀与未执行后缀）展平为向量，作为因果可用的动作意图信号。
  • 去噪步骤分组：将 K 个去噪步骤映射为 M 个组，每组预测一个 log 尺度调整与不确定性估计，避免逐步骤预测开销过大。
  • 不确定感知乘子：γ = 10^(ŷ + ασ̂)，其中 α 为固定余量，σ̂ 由预测的 log 方差得到，用于抑制偏离校准分布时的过度缩放。
  • 训练目标：将预测值拟合为当前块实际尺度与初始尺度的 base-10 对数比，损失结合 pinball 损失、高斯 NLL 项与参数正则，校准期间预训练策略保持冻结。
  • 推理路径：首个策略查询使用初始尺度，之后每次生成动作块后立即更新下一查询所有目标层与去噪组的尺度，实现逐查询尺度刷新。
Card 05 数据集与资源

数据集与资源

  • 评估数据集：LIBERO，包含 Spatial、Object、Goal、Long 四个任务套件，每任务 20 个 episode 取平均成功率。
  • 评估模型：π0.5、GR00T N1.6、CogACT，覆盖多样化 AE 架构与模型规模。
  • 硬件与测量：NVIDIA A100 GPU，batch size 为 1，测量 AE 端到端延迟。
  • 对比基线：FP16、QuantVLA（含扩展 W4A4 配置）、Q-DiT、PTQ4DiT，所有 PTQ 方法使用相同校准集与评估协议。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四任务套件；指标为任务成功率、AE 线性层权重存储、单块内存流量、AE 延迟、预测器开销。
  • π0.5 上：CHASE-VLA 达到 97.3% 平均成功率，与 FP16（97.1%）相当，优于扩展 QuantVLA（95.3%）、Q-DiT（94.4%）、PTQ4DiT（93.5%）分别 2.0 / 2.9 / 3.8 个百分点；95% 置信区间与 FP16 重叠。
  • CogACT 与 GR00T N1.6 上分别达到 90.5% 与 91.5%，显著高于同精度基线（GR00T N1.6 上 QuantVLA / Q-DiT / PTQ4DiT 仅 49.4% / 22.9% / 20.0%）。
  • 消融实验：默认设置 M=3（97.3%）、α=3（97.3%）、使用完整动作块上下文（97.3%）、逐层预测器（97.3%）、6 条校准轨迹（97.3%）均取得最优。
  • 效率：量化 AE 线性层权重存储减少 73.4%，单块内存流量在 π0.5 与 GR00T N1.6 上分别减少 70.9% 与 71.2%；AE 延迟相对 FP16 降低 21.8% 与 12.7%，相对 W4A8 降低 17.7% 与 10.3%。
  • 开销：预测器存储开销仅 5.76 MB（π0.5）与 11.50 MB（GR00T N1.6），分别相当于节省存储的 1.26% 与 0.84%。
