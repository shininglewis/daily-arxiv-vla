Card 03 核心贡献

核心贡献

  • 揭示异构语义流的量化容忍度差异：在局部误差匹配的情况下，不同流、不同层、不同去噪步对最终动作的偏差影响相差数倍至上百倍，且这种影响随层与去噪步变化。
  • 提出 SteerQuant：用 Action-Impact Stream Map 指导共享的通道缩放（Shared-Weight Error Routing）与流特定、逐步的激活校准（Stream-Specific Activation Modulation），在保持每层单一静态量化权重矩阵和固定位宽的前提下优先保护高动作影响区域。
  • 提出 Rudder：面向 WAM 的 4-bit 推理引擎，通过两个融合 kernel 合并通道缩放、流增益、激活量化、反量化、逆增益补偿与偏置，减少 kernel 启动和中间内存流量。
  • 在三个 WAM、两个基准（LIBERO、RoboLab）上验证：W4A8/W4A4 下 LIBERO 平均成功率与全精度差距不超过 0.8 个百分点，去噪加速最高 2.23×，并显著降低显存峰值与权重存储。
  • 在真实双臂机器人上完成 W4A8 部署，取得 1.35× 端到端推理加速且平均任务成功率不降反升。
Card 04 方法描述

方法描述

  • Action-Impact Stream Map（4.1）：定义每层–去噪步–语义流的动作影响分数，用最终动作对局部输出的 Jacobian 与量化误差的一阶乘积的均方根来衡量动作偏移；为避免逐区域重跑前向，改用 Rademacher 随机投影（Hutchinson 估计） 做 VJP，把复杂度从 O(\|D\|R) 降到 O(\|D\|P)，且无需存储稠密 Jacobian。
  • Shared-Weight Error Routing（4.2）：对每个线性层引入正对角矩阵 D_ℓ，对权重乘以 D、对激活乘以 D⁻¹（全精度下相消），在固定位宽下重塑量化误差；以地图权重 ω 加权的重构误差最小化求解 D*，随后将 D* 折叠进权重得到 Ŵ = Q(D*W)，保持跨流/跨步的单一量化权重矩阵。
  • Stream-Specific Activation Modulation（4.3）：在权重固定后，对每层–每步使用共享裁剪阈值 c 作为参考范围，并对各流施加增益 γ，联合优化 γ 与 c；加入阈值与增益上下界约束及 Σ n_s log γ_s = 0 的归一化约束，防止过度裁剪或过粗量化；标定结果存入层–步查找表，无需在线优化。
  • Rudder（4.4）：第一个 kernel 在激活量化时融合通道缩放与流增益，仅写出整型激活 Q_X 和行缩放 r_i = Δ_X/γ_{s(i)}（已含逆增益补偿）；第二个 kernel 基于 CUTLASS 复用打包的 INT4 权重做 INT32 累加，并在 epilogue 中完成反量化、逐输出通道权重缩放与偏置，仅需在 kernel 间传递整型激活与行缩放。

Card 06 评估与结果

评估与结果

  • 评估设置：W4A8 对比 SmoothQuant、PTQ4DiT、Q-DiT；W4A4 对比 QuaRot、Atom、SVDQuant；各量化模型与自身 FP 参考及同精度基线比较。
  • 主要指标：闭环成功率（SR）、相对 FP 的标准化动作 RMSE（消融）、去噪延迟与加速比、峰值显存、打包权重存储。
  • LIBERO 结果：W4A8 下平均 SR 达 98.6%（Cosmos-Policy） 与 98.1%（FastWAMJoint），各比最强基线高 0.5 pp；W4A4 下为 98.3% 与 98.4%（后者比 QuaRot 低 0.3 pp）；所有设置相对 FP 平均下降不超过 0.8 pp。
  • RoboLab 结果：Cosmos-Edge 上 W4A8 达 14.67%（超 SmoothQuant/PTQ4DiT 1.00 pp），W4A4 达 17.33%（超 SVDQuant 1.33 pp），在两种精度下均优于所有对比基线，但与 FP 仍有差距。
  • 效率结果：W4A4 下相对 FP 去噪加速 2.229×、1.859×、1.690×（三个模型），相比最快 W4A4 基线 QuaRot 进一步降低 4.3%/12.5%/8.5% 延迟；W4A8 延迟也低于 SmoothQuant。峰值显存相对 FP 降低 24.7–72.2%，打包权重存储降低 31.3–73.4%。
  • 消融结果：Shared-Weight Error Routing 单独优于 Modulation 单独使用，二者结合最好；完整方法相对基础量化器将动作 RMSE 降低 24.79%，用均匀权重替换地图权重会使 RMSE 变差；在 1120 个层–步单元中有 935 个（83.48%） 出现"高影响流误差降低、低影响流误差增加"的预期重分布。
  • 真实机器人结果：W4A8 平均任务得分 82.41%，高于 BF16 的 75.93%，端到端推理延迟从 462.79 ms 降至 341.97 ms，取得 1.35× 加速（电池插入项得分有所下降）。
