Card 02 论文概述

论文概述

  • 论文提出 UniWAM，一个面向移动操作（mobile manipulation）的统一混合流世界-动作模型（mixed-stream world-action model），把导航与操作建模为共享骨干网络上的两条独立控制流。
  • 核心问题是：导航与操作在动作空间、视觉输入（前视 vs. 腕部/下视相机）和控制频率上高度异构，现有统一策略用单一动作 token 或仅在动作模块内部分离，且每个训练样本同时监督两种行为，导致空闲动作主导训练、无法直接使用单模态数据。
  • 另一个关键问题是缺少大规模、显式的"操作就绪位姿"监督数据，现有统一模型只能从完整轨迹中隐式学习"在哪里停下、以什么朝向停下"。
Card 03 核心贡献

核心贡献

  • 提出 UniWAM：导航流与操作流各自拥有独立的视觉输入、动作编码器与输出头，但共享视频 DiT 与动作 DiT；两条流独立采样、按 batch 行打包且无跨行注意力，因此每个样本只监督自身的流，支持单流独立推理与双流批量并行推理。
  • 定义 Manipulation Anchor Pose (MAP)，即机器人执行操作前的终止基座位姿（位置 + 朝向），由场景几何而非具体策略决定，可自动化生成，并对整条接近轨迹提供密集监督。
  • 构建 MAP-Data：基于大规模室内 3D 场景（HM3D、HM3D-Semantics、InteriorGS 及自建场景库）自动生成，包含 超过 150 万条 episode、7500 小时导航轨迹，提供逐帧目标框与图像平面 MAP 坐标标注，规模约为此前最大数据集 MoMa-Kitchen（12.7 万条）的 12 倍。
  • 构建 MAP-Bench：在 SE(2) 空间对初始位姿聚类以保证无泄漏的划分，包含 300 个目标、109 个场景，训练集 35,454 条轨迹、7,184,098 帧 RGB（15 Hz），评估集 15K 条轨迹，按初始距离分为 short（<1.5 m）、mid（1.5–3.5 m）、long（≥3.5 m）三档。
  • 在 MAP-Bench 上相对最强外部基线降低位置误差 30.1%、朝向误差 44.0%；在 24 个真实机器人任务上取得领先的 MAP 导航与移动操作表现，移动操作成功率提升 17.5 个百分点。
Card 04 方法描述

方法描述

  • MAP 生成流程：从 3D 场景以三阶段流水线构建——S1 统一目标实例、可通行区域与可渲染观测表示并经过语义/几何/基座放置/可见性与渲染四重过滤；S2 用 VLM 识别目标的操作朝向前沿边，通过射线与可通行区域边界的交点确定 MAP 位置、朝向指向目标表面，并独立采样多样化观测位姿；S3 用单段或多段三次 Bézier 曲线（必要时由 A\* 提供无碰撞走廊）合成接近轨迹，并施加可通行掩码、朝向、视野、曲率与路径长度约束。
  • 流接口与动作表示：导航动作预测相对基座位姿增量 (\Delta x, \Delta y, \Delta\theta)（而非速度 (v, ω)），以规避速度标签的强双峰分布问题；操作动作用双臂 20 维表示（每臂 3D 位置 + 6D 旋转 + 1D 夹爪），6D 旋转经 Gram–Schmidt 正交化恢复，位姿表达在相机坐标系以增强跨本体一致性。
  • 混合流批打包与注意力：两条流编码后沿 batch 维拼接，注意力不跨 batch 行；视频 token 的因果掩码保证动作 token 只能读取当前视觉上下文、可学习 token 及之前的动作，配合 clean action prefix 支持前缀条件化的异步推理。
  • 独立流采样：将完整移动操作轨迹按规则切分为导航窗口与操作窗口，并标记 active/idle，按数据源权重与窗口权重采样，避免 idle 窗口主导训练，使导航专用数据（如 MAP-Data）与操作专用数据可直接使用。
  • 图像平面辅助监督：为动作向量拼接辅助目标并联合去噪，导航流预测目标边界框与投影 MAP 坐标，操作流预测主相机视图中的双臂末端轨迹及可见性标志；轨迹标签由标定几何投影（Algorithm 1）与基于 DINOv2 的外观门控可见性判定（Algorithm 2，含迟滞阈值与形态学清理）生成，并可批量处理（Algorithm 3）。
Card 05 数据集与资源

数据集与资源

  • MAP-Data：超过 150 万条 episode、7500 小时导航轨迹，含逐帧目标框、投影 MAP 坐标与场景/目标标识。
  • MAP-Bench：300 个目标、109 个场景；训练划分 35,454 条轨迹（6,732 个观测位姿、7,184,098 帧 RGB，15 Hz），评估划分 15K 条轨迹；每个目标配 5 条等价英文指令。
  • 场景来源：HM3D、HM3D-Semantics、InteriorGS 以及大规模自建室内场景库。
  • 模型骨干：视频 DiT 由 Wan2.2-TI2V-5B 初始化，并与动作 DiT 通过 mixture-of-transformers 注意力耦合；辅助标签生成使用 DINOv2 编码器与 VLM。
  • 数据集、基准与模型权重发布于 Hugging Face（Fysics-AI/UniWAM、Fysics-AI/MAP-Data、Fysics-AI/MAP-Bench）。
Card 06 评估与结果

评估与结果

  • 评估环境：MAP-Bench 闭环仿真评估（所有模型从相同 held-out 初始位姿、相同指令出发），以及在 24 个真实机器人任务上的真机评估，涵盖未见场景与目标的零样本泛化。
  • 主要指标：MAP Position Error（E_pos，到达位置与参考 MAP 位置的平均 L2 距离）、MAP Heading Error（E_head，角度差绝对值，经 wrap 处理）、按距离分档并对 Overall 取平均；另统计移动操作任务成功率。
  • 关键结果：相比最强外部基线，MAP-Bench 上位置误差降低 30.1%、朝向误差降低 44.0%；24 个真机任务中移动操作成功率提升 17.5 个百分点，MAP 导航与移动操作均取得领先，固定基座操作性能具竞争力。
  • 对比与消融：论文对比了 π₀.₅、GR00T N1.7、Xiaomi-Robotics-1、ABot-M0.5、MobileWAM、CrossFormer、HPT 等模型（表 1 从独立视图、单行为样本、视频世界模型、显式终止位姿四个维度区分），并消融验证了姿态增量动作表示（尤其对长距离接近有效）等设计。
