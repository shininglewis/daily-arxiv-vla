Card 02 论文概述

论文概述

  • 论文研究如何让基于静态演示训练的 World–Action 模型（WAM） 在目标物体运动的情况下完成动态操作任务，无需额外采集动态数据或重新训练。
  • 指出核心失败模式 target-response collapse：随着执行推进，策略越来越偏向已学行为的延续，对目标位置变化的响应能力显著下降。
  • 提出 Dynamic Predictive Planning（DPP），将"用于生成计划的上下文"与"用于执行的物理状态"解耦，以反事实规划实现实时动态操作。
Card 03 核心贡献

核心贡献

  • 识别并实证刻画 target-response collapse 失败模式：反应式重规划会把机器人状态与静态演示不支持的移位目标配对，导致策略偏向熟悉但错误的子目标。
  • 证明将计划生成上下文与执行机器人状态解耦，可使已学操作技能在目标运动中依然有效。
  • 提出 DPP 框架：结合交互时刻预测、目标位置预测、反事实规范规划与异步计划切换，可适配不同 WAM 主干，无需动态数据再训练。
  • 在仿真与真实机器人上验证 DPP 优于所有对比基线，包括在仿真中额外用动态数据训练的方法，且单张消费级 GPU 即可实时推理。
Card 04 方法描述

方法描述

  • 三阶段规划流程：初始规划（initial planning）→ 规范规划（canonical planning）→ 当前状态规划（current-state planning）。
  • 交互时刻预测：用 WAM 预测性 rollout 超出原生 action chunk，通过任务特定谓词 φ_q 判断抓取/释放等关键事件何时发生，并映射到执行时钟得到 τ。
  • 目标位置预测：用 SAM 2 分割目标、FoundationPose 跟踪位置，拟合目标运动假设 x̂(·)，求得 x̂(τ)。
  • 反事实观测构造：通过视觉编辑 Edit(O_k, x') 将目标放置到预测交互位置，同时保留熟悉的机器人配置与本体感知，形成近似上下文 C̃(S₀, x̂(τ))。
  • 激活桥（activation bridge）：以逆运动学并受关节速度限制，将当前状态 S_k 连接到规范轨迹的入口点，替换剩余动作队列。
  • 异步执行：机器人边执行边规划，当前状态规划用新观测与真实状态修正剩余轨迹，交互段保留不重采样。
  • 多子任务衔接：按各阶段交互结构连接计划，重用延续段或在新规划周期生成新初始计划。
Card 05 数据集与资源

数据集与资源

  • RoboTwin2.0-Dyn：基于 RoboTwin 2.0 构建的动态操作基准，含 300 个 Bimanual Grasp（T1） 与 192 个 Pick-and-Place（T2） 回合。
  • 真实机器人平台：基于 I2RT 的平台，FastWAM 仅在静态演示上训练；每个任务 30 次试验。
  • 骨干模型：FastWAM、ImageWAM（冻结，不做额外策略训练）。
  • 基线模型：π0.5、AHA-WAM、PUMA、DynamicWAM、Refresh-24/8、Future-Conditioned（Bootstrap / Oracle）。
  • 计算资源：仿真端单张 RTX 5090，真机端单张 RTX 4090，渲染使用另一张 GPU，控制频率约 10 Hz。
Card 06 评估与结果

评估与结果

  • 评估指标：官方 RoboTwin Task Success、物理接触诊断 Contact、Route Completion（RC，0–100）；Pick-and-Place 需完成两个子任务。
  • 仿真结果（Table 1）：DPP 在 Bimanual Grasp 达 83.33%（FastWAM） 与 78.67%（ImageWAM）；Pick-and-Place 达 80.73% 与 91.15%；Future-Conditioned Bootstrap 仅 18.33%/48.96%，Oracle 为 27.00%/60.42%；DynamicWAM 最强基线为 52.00%/53.13%。
  • 真机结果：Task A 成功率 76.7%（Reactive 与 Future-Conditioned 均为 0%）；Task B 达 86.7%（26/30），Reactive (Hybrid) 仅 40.0%。
  • 目标响应衰减量化：48 步执行后预测抓取响应面积降至初始值的 1.47%；ImageWAM 平均目标响应增益从 0.885 降至 0.063。
