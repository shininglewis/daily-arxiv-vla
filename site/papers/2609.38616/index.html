Card 02 论文概述

论文概述

  • 论文研究 Vision-Language-Action（VLA）模型在组合泛化（compositional generalization）上的失败：当测试时对已见过的对象、目标位置、背景进行重新组合时，模型往往绑定到错误的参照物并盲目复现训练轨迹。

Card 03 核心贡献

核心贡献

  • 发现并验证 VLA 在组合性偏移下仍保留局部操作能力，可通过把末端执行器引导到正确参照物的“示范支持构型”来复用该能力。
  • 提出 Referential Guidance（ReGuide）：一种免训练、骨干无关的即插即用包装器，通过语义重绑定（semantic rebinding）与几何重绑定（geometric rebinding）纠正 WHERE 并保留 HOW。
  • 在仿真中跨多个 VLA 骨干将组合任务成功率最高提升 56.8 个百分点，在真实机器人上提升 75.0 个百分点，同时不损害标准任务性能。
  • 方法无需外部打分器、规划器或引导权重调参，直接从策略自身的训练示范中提取参考构型、运动边界与进度阈值。
Card 04 方法描述

方法描述

  • 问题建模：将阶段成功概率分解为绑定与能力两项，Pr(Sₖ)=Pr(Bₖ)·Pr(Sₖ\|Bₖ)，即 βₖ（binding，是否到达正确互动）与 γₖ（competence，是否完成互动），设计目标是恢复“局部技能可用的交互构型”。
  • 语义重绑定：

- 通过轻量 grounding 模块解析指令所指参照物 e*ₖ，并检索与首帧最相似的训练场景构建“习惯集合” Hₖ，候选集合 Eₖ={e*ₖ}∪Hₖ∪W。

- 利用未执行的动作块余量 Rₜ 预测末端落点与姿态（用示范拟合的控制器尺度 σ 与跟踪增益 κ），据此判断策略正在承诺的参照物 e^πₜ。

- 当预测参照物与指令参照物不一致、且尚未接触目标时触发引导；无需外部打分器即可获得前瞻性错配信号。

- 同时监测姿态兼容性与朝向示范抓取构型的进度，超时未取得一步示范级进展则判定绑定失败。

  • 几何重绑定：

- 按对象类型与目标类别分组示范，在重力对齐的规范坐标系 R_e C_e 中表达“接触时刻”位姿，取逐轴中位抓取偏移 ō、旋转中值 R̄、中位进入高度 z̄，得到目标位置 p*ₑ 与姿态 R*ₑ。

- 未见对象通过高度、两个宽度与顶部填充率的对数描述子最近邻继承统计量。

- 定义预接触集合 Kₑ（位置半径 s、侧向容差 rₑ、姿态容差 τ_R，均取自示范分位数），进入后丢弃待执行动作块并向冻结策略查询真实观测，完成交还（hand-back）。

- 迁移过程受示范单步运动上限约束（平移 s、旋转 s_R），执行阶段由侧向容差与高度下限（含 m_f 与下包络 m̄_f）继续约束；运输在前提变化、误差不降或阶段完成后解除，每阶段最多两次运输。

  • 关键创新：不修改权重、不解码重采样、不引入外部 oracle，仅“纠正 WHERE、保留 HOW”，且参考构型与边界均可从策略自身示范中推导。

Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 仿真（oracle 与基于感知两种 grounding）与 xArm6 真实机器人；指标为成功率（%）与 95% Wilson 置信区间，配对比较使用精确 McNemar 检验。
  • 仿真主要结果（Table 1）：

- 裸 π₀.₅ 组合平均仅 39.0%（原始任务 94.0%）；ReGuide (π₀.₅) 组合平均达 94.5%，原始任务 94.2%，即提升约 55.5–56.8 个百分点且 Orig. 变化不超过 0.8。

- ReGuide (GR00T N1.7)：Target Region 69.0、Target Object 52.5、Unseen Object 59.0、Task Scene 96.0，组合平均 78.8（原模型仅 13.0）。

- 非 π₀.₅ 策略在 Task Scene 轴普遍不高于 6.5%，ReGuide 显著改善该轴。

- 基于感知的 grounding 下，最强骨干 π₀.₅ 达到 87.5% 组合成功率，仅比 oracle grounding 低 7.0 点，仍比裸策略高 48.5 点。

  • 真实机器人结果（Table 2）：ReGuide 将 Comp. 成功率从 15.0% 提升至 90.0%（75 胜 0 负），Orig. 从 86.0% 提升至 92.0%，总体从 38.7% 提升至 90.7%；推动任务组合成功率从 0/20 提升至 20/20。
  • 机制验证：

- 构型迁移诊断：8 个重组合单元上抓取成功率从 64.5% 升至 95.8%。

- 交还动作替换：用固定下降闭合或保持动作替换 VLA 动作后，成功从 94.5% 降至 38.1%/28.0%（p<10⁻¹⁰⁰），说明交还后仍需策略自身动作。

  • 消融（Table 3，800 组配对试验）：完整 ReGuide 组合平均 94.5；朴素运输 68.5（−26.0）；去掉竞争参照物机制 85.9（−8.6）；去掉动作块承诺判断 86.4（−8.1）；去掉预接触集合 75.9（−18.6）；去掉有界运输 87.6（−6.9）；去掉交还后辅助 84.6（−9.9），均显著低于完整方法。
