研究单位

  • 清华大学车辆与运载学院（School of Vehicle and Mobility, Tsinghua University）
Card 02 论文概述

论文概述

  • 论文提出 READ 框架，学习显式、规划对齐的风险表示，用于端到端自动驾驶规划。
  • 解决现有学习型规划器中环境因素对候选动作的影响隐式、难以检查和细化的问题，同时克服经典安全场依赖手工设计、不能自适应场景的局限。
  • 将风险表示为连续时空场，支持沿候选轨迹的可微查询，以低风险区域引导轨迹预测，并兼容端到端模型与 VLA 模型。
Card 03 核心贡献

核心贡献

  • 引入显式、规划对齐的风险表示，桥接经典场安全表述与现代数据驱动规划，实例化为连续、行为感知的场。
  • 证明 READ 可跨规划器类型迁移，集成到端到端模型和 VLA 模型，并用于轨迹评估与可选可微细化。
  • 在 NAVSIM 上评估，匹配的端到端骨干网络取得一致增益，在 VLA 设置中表现强劲。
  • 在 NAVSIM v2 上也取得有竞争力的结果，验证学习空间风险作为显式、自适应表示的有效性。
Card 04 方法描述

方法描述

  • 将驾驶场景建模为连续时空风险场 R(x,y,t)，在 BEV 中用各向异性高斯基元参数化，预测每个网格和未来时刻的权重及尺度。
  • 使用五类部分安全约束：静态约束（不可驾驶区域高风险）、动态约束（未来智能体占据高风险）、全局稀疏性（防止全场高险）、演示路径约束（专家轨迹低风险）、运动学残差约束（匀速外推偏差匹配风险）。
  • 场损失由多个约束加权组合，空间影响由预测的高斯权重和尺度决定，而非固定损失权重。
  • 在 E2E 规划中，卷积解码器从共享 BEV 状态预测高斯参数，轨迹查询交叉注意力到该状态，训练损失为轨迹损失加场损失；在 VLA 中，风险潜变量 token 与动作查询交互，实现风险结构化潜在监督。
  • 提供可微轨迹细化：仅对平均风险超阈值的轨迹，优化风险项与轨迹保持项，后处理且无需重训练规划器。
Card 05 数据集与资源

数据集与资源

  • 使用 NAVSIM 基准（v1 和 v2），包含多视角相机、自车状态、地图和导航命令。
  • E2E 模型：ResNet TransFuser 风格编码器或从 Drive-JEPA 初始化的 ViT；VLA 模型微调 Qwen3-VL-2B。
  • 训练资源：E2E 在 2 个 A100 GPU 上训练 40 个 epoch；VLA 在 8 个 A100 GPU 上微调 20 个 epoch。
  • 风险场设置：x∈[0,80] m，y∈[-32,32] m，1 m 分辨率，预测 8 个时间切片（0.5 s 间隔，4 s 时域）。
Card 06 评估与结果

评估与结果

  • 评估环境：NAVSIM，主要指标 PDMS（由 NC、DAC、EP、TTC、C 组成）；NAVSIM v2 使用 EPDMS（增加 DDC、TLC、LK、HC、EC）。
  • 匹配端到端比较：TransFuser + READ 的 PDMS 从 84.0 提升至 84.6；Drive-JEPA + READ 的 PDMS 从 89.1 提升至 90.0，且各非饱和组件均有提升。
  • VLA 设置：READ 达到 90.7 PDMS，在所列 VLA 方法中 EP 最高。
  • NAVSIM v2：READ 达到 90.1 EPDMS；匹配 ViT 设置下，相比 BEV 监督，场学习使 EPDMS 提升 0.7、TTC 提升 0.4，并在 NC、DAC、DDC、LK 上也有改善。
  • 消融实验在原始 NAVSIM 协议上进行，控制表示和约束以隔离场学习效果。
