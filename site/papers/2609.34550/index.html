Card 02 论文概述

论文概述

  • 论文提出眼动仪监督的注视提示（eye-tracker-supervised gaze prompting），将 VR 遥操作中记录的人类注视作为时间密集监督信号用于 VLA 微调。
  • 解决 VLA 微调中监督粒度不匹配的问题：图像-动作对是逐帧的，而语言指令仅提供任务级目标，缺乏逐帧的视觉相关性标注。
  • 通过轻量级注视预测器在部署时提供视觉提示，无需眼动仪、无需修改策略架构，即可为 VLA 提供逐帧注视线索。
Card 03 核心贡献

核心贡献

  • 将遥操作中记录的人类注视作为时间密集监督信号用于 VLA 微调，并训练轻量级预测器在部署时提供注视提示，无需眼动仪或架构修改。
  • 在 6 个真实世界双臂操作任务上验证有效性，平均成功率从 26.3% 提升至 56.0%，且统一多任务训练下增益相当。
  • 通过受控的注入路径和线索来源分析，证明推理时注视线索的贡献，并显示人类注视可指示即将到来的任务相关位置。
  • 发布 GazeMani 数据集，包含 1,200 条带同步注视记录的双臂遥操作轨迹，覆盖六个任务。
Card 04 方法描述

方法描述

  • 注视预测器：冻结的 CLIP ViT-B/16 视觉编码器和 CLIP 文本编码器分别编码每帧图像和指令，线性投影到 256 维共享融合空间。
  • 逐帧提示条件化：每帧视觉 token 交叉注意力到文本 token（视觉查询文本），在时间混合前注入指令语义。
  • 时间融合：N=3 帧的提示条件化 token 网格经可学习时间位置嵌入后，由 2 层 transformer 编码器处理，取最后一帧的上下文 token。
  • 热图读出：最后一帧的 196 个 token 重塑为 14×14 特征图，经转置卷积上采样为 224×224 注视热图，输出逐 cell 的分数。
  • 视觉提示渲染：在头部相机图像上以固定几何和颜色绘制十字准星，腕部相机视图保持不变；推理时对热图峰值 3×3 邻域做 soft-argmax，再进行因果 EMA 平滑。
  • 训练与推理：预测器与策略独立训练，无梯度流动；策略在真实注视位置渲染的十字准星上微调，动作目标保持为原始演示动作。
Card 05 数据集与资源

数据集与资源

  • GazeMani 数据集：1,200 条遥操作轨迹，每条同步记录三路 RGB 视图、机器人本体关节状态、演示动作和操作者注视位置。
  • 每个任务提供 200 条演示，注视数据经卡尔曼滤波时间平滑。
  • 机器人平台：TeleAvatar 双臂移动操作机器人（灵御机器人），配备两个 7-DoF 臂、单自由度夹爪、头部立体鱼眼相机和两个腕部相机。
  • 数据采集设备：Pico 4 Enterprise 头显及集成眼动仪，仅用于数据收集阶段的 VR 遥操作和眼动追踪。
  • 注视预测器规模：约 2.9M 可训练参数；VLA 策略骨干实例化为 π₀。
Card 06 评估与结果

评估与结果

  • 评估环境：6 个真实世界双臂操作任务——Stack Bowls (T1)、Stack Cubes in Order (T2)、Bus Table (T3)、Fold Towel (T4)、Insert Toilet Paper (T5)、Catch Rolling Ball (T6)。
  • 对比方法：Vanilla π₀（无注视信号）、Aux-loss π₀（注视正则化 VLA，仅训练时使用注视）、Gaze-prompt π₀（本文方法）。
  • 主要指标：每任务 50 次 rollout 的成功率；平均成功率从 26.3% 提升至 56.0%（+29.7 点），Aux-loss 为 33.3%。
  • 分任务结果：Gaze-prompt 在所有六个任务上均优于 Vanilla，T1 从 38%→72%，T5 从 18%→72%，T6 从 14%→52%。
  • 统一多任务策略：Gaze-prompt 汇总成功率 49.2%（120 次 rollout），Vanilla 为 20.8%，Aux-loss 为 29.2%。
  • 线索来源消融（T6）：人类注视预测器 52%，Kalman 未来位置线索 38%，当前位置检测 12%，随机十字准星 10%，无提示 14%。
  • 指令交换分析（T1）：Gaze-prompt 的注视条件化注意力偏移 JS 散度为 0.117，高于 Aux-loss 的 0.068 和 Vanilla 的 0.047。
