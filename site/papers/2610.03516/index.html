XGenAct: Geometry-Enhanced World Action Models through Cross-Task Generation

2026-10-02 · 原文 · 翻译 · 2610.03516

提出 XGenAct，一种几何增强的世界动作模型（World Action Model, WAM），将 RGB 观测、机器人动作、度量深度（metric depth）、表面法线（surface normals）和功能角色分割（functional role segmentation） 统一表示为由确定性编解码器转换得到的 RGB 视频。 针对现有 WAM 的不足：基于 RGB 与动作的未来预测缺乏机器人操作所需的显式空间理解（如度量深度、表面朝向）；已有工作多通过专用预测头、门控残差模块或模态分支引入空间监督，导致监督范围零散、架构割裂。 目标是用一个视频扩散 Transformer、一个训练目标、无模态专用学习头，通过跨任务采样实现几何与语义监督对共享动作生成器的直接塑形。

Card 03 核心贡献

核心贡献

  • 几何增强的图像空间：在图像空间世界动作建模中超越 RGB 与动作，把深度、表面法线和功能角色分割编码进同一视觉模态，补充互补的几何与语义信息。
  • 无头且可扩展的任务接口：通过任务模板（task templates）与条件计划（conditioning plans），所有感知与动作任务共享同一冻结 VAE、DiT、输出头和流匹配目标，无需模态专用学习头或辅助损失。
  • 跨任务生成提升机器人控制：在留出（held-out）RLBench 任务上，结构化几何与语义生成在相同计算量和动作预算下，将平均闭环成功率相对纯 RGB 训练提升最多 28.75 个百分点，同时保留未来 RGB 生成能力。
  • 在五个外部对比任务上，XGenAct 达到 52% 平均成功率，约为最强基线（26%）的两倍，并在五个任务中的三个上领先。
Card 04 方法描述

方法描述

  • 基于 Action Images 公式与 Wan2.2-TI2V-5B 视频扩散骨干；视频 VAE 保持冻结，仅微调扩散 Transformer。
  • 每个训练样本选择一个感知模态 m（RGB / depth / normal / segmentation）与两路相机视角的动作流组成模板 Π_m = [m⁽¹⁾, a⁽¹⁾, m⁽²⁾, a⁽²⁾]，而非同时组合所有感知模态。
  • 确定性编解码器（无学习参数）：

- 深度：先用单调幂变换压缩，再映射到 RGB 立方体中的连续路径，解码时反投影并逆变换。

- 表面法线：γ_normal(n) = (n+1)/2 直接映射到 RGB，逆映射后重新归一化。

- 分割：为每个功能角色（目标物体、目标区域、机器人、工具、夹具、干扰物、背景）分配跨任务/视角/帧固定的 RGB 颜色码。

- 动作：沿用 Action Images 编解码器，把 7-DoF 末端执行器位姿投影到多视角并渲染为 RGB 视频。

  • 条件计划定义观测/生成位置，三种状态 F（完整段）、I（提供首帧）、1（仅首帧）：

- ρ_joint = (I,I,I,I)、ρ_policy = (1,I,1,I)、ρ_inverse = (F,I,F,I)。

  • 共享训练目标：仅对预测位置施加流匹配损失，观测位置保持干净、不参与重构损失；所有感知模态、模板、条件计划共用同一目标，无手工损失权重。
Card 05 数据集与资源

数据集与资源

  • 训练数据来源：

- RLBench：16 个任务、4 个相机视角、512²、20 Hz、3,960 条 episode（variation 0），含逐帧度量深度、实例掩码、相机内外参。

- ManiSkill3：7 个任务、1,750 条 episode，重放官方示范并重新渲染。

- 混合比例 70/30（RLBench / ManiSkill3）。

  • 模型规模：基于 Wan2.2-TI2V-5B（约 5B 参数视频扩散骨干），41 帧、512² 输入编码为 11×32×32 隐网格，C_l = 48 通道。
  • 训练配置：从 Action Images 检查点微调，有效 batch 4，学习率 5×10⁻⁷，在 4,000 步评估（菜单消融为 6k 步运行）。
Card 06 评估与结果

评估与结果

  • 评估环境：仿真闭环控制，每任务 20 次试验，在 IIII 计划下滚动时域重规划，时间上限为示范长度的 1.5×；成功信号为 RLBench 任务成功判定，方法按场景种子配对。
  • 感知评估指标：RGB 用 LPIPS，深度用绝对相对误差（AbsRel），法线用平均余弦相似度，分割用 mIoU。
  • 主要结果：

- 与 8 个外部策略（π0.5、Evo-1、VLANeXt、MolmoAct、PAD-Depth、UWM、LaWAM、VLA-JEPA）对比，XGenAct 平均成功率 52%，最强基线仅 26%；close drawer 达 100%，close microwave 60%，close laptop 40%。

- 失败模式分析：PAD-Depth 与 UWM 多为超时（88 / 86 次），VLA-JEPA 与 MolmoAct 常因逆运动学（IK）失败而停止（48 / 22 次）；XGenAct 的所有失败均为超时，从未耗尽更严格的 20 次 IK 失败预算。

- 训练菜单消融：任何带感知流的菜单都优于纯 RGB（32.5%），提升到 52.5%–61.25%；最佳为 RGB+N+S（61.25%，提升 28.75 点）。任务依赖性明显：分割对 close microwave（95%）和 meat on grill（70%）最有用，法线对 toilet seat down（40%）最有用；加入深度后 RGB+N+S 平均反而从 61.25% 降到 58.75%。

- 未来感知对比：直接生成几何与语义明显优于先生成 RGB 再用冻结专家（Depth Anything V2 / Lotus-G / CLIPSeg）后处理——深度 AbsRel 从 0.41–0.43 降至 0.28–0.33，分割 mIoU 从 0.22–0.24 提升至约 0.42–0.49；法线两条路线相当（约 0.76 余弦），但 RGB+D+N 下直接生成偏低（0.71 vs 0.76）。加入感知流对 RGB 生成影响很小（LPIPS 仅从 0.39 升至 0.40–0.43）。
