Card 02 论文概述

论文概述

  • 论文聚焦语言条件下的基于流的操作（language-conditioned flow-based manipulation），目标是以机器人速度场作为跨具身的运动中心表示，利用多机器人平台数据提升操作泛化性。
  • 现有方法要么用稀疏关键点位移粗略近似机器人流，要么无法处理语言条件，导致生成流物理一致性不足且易受背景、光照等任务无关视觉细节干扰。
  • 提出NarrativeFlow，在流匹配框架中将机器人流建模为连续概率速度场，并生成与真实操作物理一致的语言条件机器人流。
Card 03 核心贡献

核心贡献

  • 提出NarrativeFlow，一种语言条件机器人流生成方法，在流匹配框架下将机器人流建模为概率速度场，实现高质量机器人流生成。
  • 引入Narrative Delta loss作为辅助目标，将模型中间表示与任务相关场景变化对齐，并设计两个subtask tokens以减轻辅助目标与主流生成目标之间的干扰。
  • 在标准数据集上验证NarrativeFlow优于代表性基线方法。
  • 通过真实世界实验证明NarrativeFlow在多个移动操作任务上取得比基线更高的成功率。
Card 04 方法描述

方法描述

  • 输入为指令 ℓ 和初始图像 I0，分别用 Qwen3-Embedding-0.6B 和 DINOv3-ViT-B/16 编码为语言嵌入 z_lang 和视觉嵌入 z_img。
  • 视觉语言融合编码器将两种嵌入整合为两个任务特定联合表示（即两个 subtask tokens），分别用于条件化 Flow-as-Flow 模块和计算 Narrative Delta loss。
  • Flow-as-Flow 模块基于 Diffusion Transformer (DiT) 架构，通过 adaLN-Zero 调制，条件向量由 z_st^(1)、I0（ResNet-18编码）和 t（正弦位置编码）构成；使用条件流匹配损失 L_FaF 训练。
  • Narrative Delta loss 使用 MLLM 从 I0 到目标图像 G 生成多个任务相关场景变化的文本描述，再用 Qwen3-Embedding-0.6B 嵌入，通过余弦相似度对齐 z_st^(2) 与叙事表示；仅在训练时使用，推理不需要 G。
  • 总损失为 L = L_FaF + λ L_ND，其中 λ 为权重超参数。
Card 05 数据集与资源

数据集与资源

  • 使用标准真实机器人数据集 Fractal 和 Bridge V2，均为语言标注的跨具身操作数据集。
  • Fractal：训练/验证/测试集分别含 84,212 / 1,000 / 2,000 个样本（总样本数列为87,212）。
  • Bridge V2：训练/验证/测试集分别含 57,064 / 1,000 / 2,000 个样本（总样本数列为60,064）。
  • 辅助工具：CoTracker3 用于点跟踪生成机器人流标签，Robot-SAM 用于末端执行器分割，Qwen2.5-VL 生成指令，Qwen3.5-9B 生成叙事描述。
  • 模型规模约 487M 可训练参数。
  • 训练资源：单张 GeForce RTX 5090（32GB显存），训练时间约 6小时，推理时间约 62ms。
Card 06 评估与结果

评估与结果

  • 评估环境：标准数据集测试集（Fractal、Bridge V2）和真实世界 HSR 机器人（11-DoF移动操作器）上的三个移动操作任务。
  • 主要指标：ADE（平均位移误差，主指标）、FDE（最终位移误差）、LTDR（小于delta比率）；真实世界用成功率。
  • 在 Fractal 和 Bridge V2 上，ADE 分别为 21.68 和 30.59，优于最佳基线（37.14和50.73）达 15.46 和 20.14 点；FDE 分别为 31.59 和 42.42，优于基线（47.74和68.43）。
  • 真实世界平均成功率达 55%，比最强基线 Im2Flow2Act（42%）高 13 点；与 oracle 流（63%）仅差 8 点，而基线差 21 点。
  • 消融研究证实 subtask tokens 和 Narrative Delta loss 均能提升机器人流生成性能。
