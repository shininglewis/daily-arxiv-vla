2026-10-16 · 原文 · 翻译 · 2610.22951

论文关注流匹配（flow-matching）视觉-语言-动作（VLA）模型在实时机器人控制中的推理延迟瓶颈，典型代表为 π₀.₅：视觉-语言前缀每次策略查询只计算一次，但动作专家需要在迭代去噪的每一步重复评估。 实测显示，10 步去噪占 π₀.₅ 端到端延迟的 70.1%，占 SmolVLA 的 86.4%，说明动作生成是主导开销。 论文提出 MambaAct：保留预训练的视觉-语言主干与标准流匹配形式，仅将 Transformer 动作专家替换为轻量的 Mamba-3 动作专家，从而在不额外预训练、不蒸馏、不使用教师模型的前提下加速推理。

Card 03 核心贡献

核心贡献

  • 提出 MambaAct，将“动作专家替换”确立为流匹配 VLA 的一条互补效率优化路径：保留预训练 VLM 与标准流匹配目标，仅替换反复被评估的动作专家。
  • 证明 Mamba 可实现激进的动作专家压缩：参数从 311.5M 降至 29.7M（超过 10× 更小），同时在 LIBERO 上于三个独立微调种子下平均成功率提升 1.08 个百分点。
  • 设计 Context Compressor 与 Gated FiLM 条件接口，将 VLM 前缀压缩为紧凑条件信号，避免去噪过程中重复的 token 级交叉注意力。
  • 通过受控消融分析 Mamba 动作混合器与条件接口对“效率-性能”权衡的贡献。
  • 表明该方法可与 VLM 层数裁剪组合使用，并可迁移到 SmolVLA，说明动作专家替换在不同流匹配 VLA 主干上具有泛化性。
Card 04 方法描述

方法描述

  • 主干复用：以 OpenPI π₀.₅ 为基础，保留 PaliGemma VLM（SigLIP 视觉编码器 + Gemma 前缀编码器）全部 18 层，并与动作专家联合端到端微调。
  • Context Compressor（上下文压缩）：将 VLM 前缀投影到动作专家宽度后，视觉 token 按连续分段做掩码平均池化为 44 个视觉上下文 token，语言 token 池化为 16 个，另用 4 个可学习 query 通过多头注意力提取全局摘要，合计 K = 64 个上下文 token，再经 MLP 与 RMSNorm 融合并池化为单一条件向量 z。
  • Gated Mamba 动作专家：L = 4 个 Mamba-3 块沿动作 token 维度做选择性状态空间混合（宽度 512、状态维度 64、扩张因子 1、头维度 64），噪声动作块直接投影为 H 个动作 token，不额外引入机器人状态 token。
  • FiLM 门控调制：每个块由块专属 MLP 从 z 生成 scale、shift 与残差门控 logits，实现视觉-语言条件的注入；FiLM 参数在去噪各步间复用，时间条件与动作 token 每步重算。
  • 流时间注入：流时间经傅里叶/正弦编码 φ(t) 与 MLP 映射后，通过块专属投影以广播方式加到动作序列上。
  • 初始化策略：时间投影与 FiLM 的 scale/shift 输出零初始化（单位 FiLM 调制），残差门控 logits 初始化为 log(0.2/0.8)，使新初始化的 Mamba 分支初始残差乘子为 0.2，既保持活跃又抑制早期扰动。
  • 训练目标：标准流匹配速度回归损失 L_FM，目标速度为 **V\* = ε − A₀**；推理用 10 步 Euler 积分从 t=1 到 t=0。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：LIBERO（Spatial、Object、Goal、LIBERO-10 四个套件，每套件 10 任务，每任务 50 次试验，评估种子 7）；LIBERO-Plus（10,030 个测试实例，含 CAMERA、ROBOT、LANGUAGE、LIGHT、BACKGROUND、NOISE、LAYOUT 七类扰动）。
  • 真实世界任务：双臂 UR5 平台（腕部 + 第三人称 RealSense 相机），任务为 Tube Placing（插管）与 Nut Pouring（倒坚果）；每任务采集 112 条示范（28 种配置 × 4 回合），评估 28 次同分布（ID）与 52 次分布外（OOD）试验。
  • 模型规模：动作专家 29.7M 参数（原 311.5M），整体模型由 3.62B 降至 2.96B。
  • 训练配置：30,000 步优化，batch size 16，AdamW（梯度裁剪 1.0、权重衰减 1e-10），余弦学习率 5e-5 → 5e-6 无 warmup，bfloat16 精度 + 梯度检查点，8 个 CPU worker，单张 NVIDIA H100 GPU。
  • 部署与测速：真实世界推理在 NVIDIA RTX 5090 上进行，控制频率 30 Hz，动作时域 H = 50、执行前 30 步后重规划；仿真时域 H = 10、每 5 个环境步重规划。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO 仿真成功率、LIBERO-Plus 零样本鲁棒性、两个真实 UR5 任务的归一化成功率（含部分得分），以及 Prefix / Denoise / E2E 三段延迟。
  • LIBERO 主结果：平均成功率由 96.72 ± 0.14% 提升至 97.80 ± 0.43%（+1.08 pp）；分项为 Spatial 98.73、Object 99.60、Goal 98.60、L-10 94.27，均不低于基线。
  • 延迟收益：去噪延迟从 160.26 ms 降至 56.40 ms（↓64.8%）；Context Compressor 带来少量前缀开销（40.76 → 46.61 ms），端到端延迟从 228.6 ms 降至 107.6 ms（↓52.9%，约 2.12× 加速）。
  • 真实世界收益：部署场景去噪延迟降低 58.8%，并在 Tube Placing 与 Nut Pouring 的 ID/OOD 试验上保持性能增益。
  • 对比与消融：与 SnapFlow、Shallow-π、π₀-CLP、GR00T-N1.5-CLP、LightVLA 等高效 VLA 方法对比；消融验证 Mamba 动作混合器与条件接口各自的贡献，并显示可与 VLM 深度裁剪叠加、可迁移到 SmolVLA。
  • 开源：代码与模型权重已公开于 https://github.com/giakhuyendihoc/MambaAct。
