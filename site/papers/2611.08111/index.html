Card 02 论文概述

论文概述

  • 论文提出 NegWAM，一个面向统一世界-动作模型（WAM） 的安全后训练（safety post-training）框架，用于提升端到端自动驾驶在安全关键场景下的鲁棒性。
  • 核心痛点：现有 WAM 的动作分支主要依赖对专家轨迹的流匹配模仿学习（flow matching），只告诉模型“该模仿什么”，却没有约束那些与专家轨迹几何上极为接近、但实际不安全的“近专家失败轨迹”。
  • 目标是在不引入额外推理开销的前提下，让模型显式学出安全边界，既能提升困难场景表现，又不牺牲常规驾驶性能。
Card 03 核心贡献

核心贡献

  • 从安全后训练视角重新审视统一世界-动作模型，证明在流匹配模仿目标之上叠加近专家负样本监督，可提升挑战性场景性能且不损害常规驾驶表现。
  • 提出 NegWAM 后训练方法，联合优化原始流匹配目标与两个互补的近专家负监督目标，且不增加推理期模块与开销。
  • 设计两种互补的负监督机制：排斥锚点（repulsive anchors） 将预测轨迹推离局部不安全轨迹；场景条件 rider token（scene-conditioned rider tokens） 让统一 WAM 判断某条轨迹是否与当前场景兼容。
  • 提出噪声感知（noise-aware） 的距离自适应排斥损失，用随噪声水平变化的权重与自适应 margin 缓解固定 margin 与模仿目标的冲突。
  • 在 NAVSIM v2 与 HUGSIM 上验证了性能提升与跨基准零样本泛化能力，并开源代码。
Card 04 方法描述

方法描述

  • 基础架构：以预训练视频生成模型 Wan2.2-TI2V-5B 为骨干，沿用 DriveWAM 的统一世界-动作建模范式，将视频流与动作流拼接为共享 DiT 的四段序列（含 teacher-forcing 条件流），由冻结的因果视频 VAE 编码观测与未来帧。
  • 第一阶段（Stage 1）：仅优化流匹配目标，联合学习未来视觉动态与专家轨迹预测，得到所有实验共享的基础 WAM 检查点。
  • 第二阶段（Stage 2）：进行近专家负样本安全后训练，总目标为 𝓛_post = 𝓛_FM + λ_rep·𝓛_rep + λ_compat·𝓛_compat。
  • 负轨迹挖掘（离线）：从 GTRS 的 16K 密集轨迹词表中，以平均位移误差 ADE < 1.0 m 筛出近专家候选，再用 NAVSIM v2 的 EPDMS 离线评估器保留 EPDMS = 0 的失败轨迹，训练时再筛 ADE ∈ [0.3, 1.0) m 并最多采样 K = 16 条。
  • 噪声感知排斥损失：ℓ_rep = [α·a_{i,k} − d_{i,k}]₊（α = 0.9），并按 (1 − t^a) 加权、对有效负样本取均值，使损失仅在负锚点邻域内激活，专家轨迹处损失为零。
  • 场景条件 rider token：将专家与每条负轨迹编码为独立 rider 组（零条件块 + 8 步轨迹块，共 16 个干净 token，t = 0），通过共享 DiT 注意力只访问当前观测视觉 token 与自身组，原始序列无法注意到 rider，故不改变原有前向路径。
  • 兼容性排序损失：对 16 个 token 特征取均值后过共享兼容性头（线性→SiLU→标量，末层零初始化），用 softmax 排序损失 𝓛_compat 让专家得分高于负样本得分（τ_s = 0.1）。
  • 推理阶段：丢弃 rider 组与兼容性头，仅用更新后的骨干走原世界-动作生成路径（视觉 3 步 Euler、动作 10 步 Euler），不使用评估器或负样本候选。

Card 06 评估与结果

评估与结果

  • 评估基准与协议：NAVSIM v2 的 navtest / navhard，全部结果采用修正后的官方 NAVSIM v2.2 评测协议。
  • 主要指标：EPDMS（Extended Predictive Driver Model Score），由乘性惩罚项 NC / DAC / DDC / TLC 与加权平均项 TTC / EP / LK / HC / EC 组合而成。
  • navhard 结果：NegWAM 取得 40.4 EPDMS，相对最强可比的无评分器 WAM 基线 BeyondDrive（38.8） 提升 4.1%（相对值），也高于 DriveWAM（37.7）。
  • navtest 结果：93.3 EPDMS，超过最强基线 92.9 达 0.4 分，说明常规驾驶性能未被削弱。
  • 零样本闭环泛化（HUGSIM）：NegWAM 的 HD-Score 为 30.6，优于 DriveWAM 的 27.2，体现跨基准迁移能力。
  • 消融与分析：分别验证了排斥锚点、场景条件 rider token 的单独与联合贡献，并对后训练预算与超参数做了敏感性分析；此外提供定性轨迹对比、闭环 rollout 与推理效率分析。
  • 负样本覆盖统计：约 85.8% 的训练样本至少含一个有效硬负样本；全部有效负样本相对专家轨迹的中位 ADE 为 0.80 m，约 9% 落在 [0.3, 0.5] m 区间。
