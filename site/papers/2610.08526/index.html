Card 03 核心贡献

核心贡献

  • 发布 WareFly-VLA 数据集：人类遥操作 UAV 采集的视觉–语言–动作数据，包含同步视觉观测、基于外观的语言描述和连续 4-DoF 飞行动作。
  • 构建基于 NVIDIA Isaac Sim 的人类示教数据采集流水线，捕获真实的空中搜索、目标定位、目标获取与连续跟随行为。
  • 定义两个空中具身任务：*approach-and-locate*（接近并定位）与 *person-following*（人员跟随），涵盖遮挡、高度变化、远距离搜索、视角变化和杂乱工业环境等挑战。
  • 建立统一空中 VLA 基准，在无泄漏的 episode 级协议下评估代表性开源 VLA 架构。
  • 开源完整研究平台（数据、基准配置、训练流水线与评估工具），并指出由该数据集支持的世界模型研究方向。
Card 04 方法描述

方法描述

  • 仿真与数据采集：在 Pegasus Simulator（基于 NVIDIA Isaac Sim 的无人机动力学仿真扩展）中构建大型工业仓库场景，含货架、传送带、叉车通道等，无人机搭载前视 RGB 相机采集 1920×1440 图像，位姿由仿真器状态直接给出。
  • 遥操作策略：人类飞手遵循确定性的 *search–decide–approach* 有限状态机，含 *Look Around*（原地 360° 偏航扫描）、*check_open* 决策、*Scan Shelves*（沿货架 45° 外侧飞行扫视）、*Move to Open* 与 *Approach Target*，并设置搜索耗尽回环，保证行为一致而轨迹多样。
  • 动作表示：由相邻位姿差计算 4 维机体坐标系运动指令 a_t = (Δx, Δy, Δz, Δψ)，水平位移经 R(-ψ_t) 旋转到机体坐标，高度与航向分别为位置差与角度差（航向归一化到 [-π, π]），具备全局朝向不变性，可直接对接局部机体坐标控制器。
  • 语言标注：由标注者以远程操作员视角撰写，仅使用可观测外观属性（服装、颜色、配件、PPE），避免身份信息与场景位置指代，并提供多组改写句并进行二次审核。
  • 基准协议：固定随机种子做 episode 级划分（避免帧级时间泄漏），所有模型使用官方实现与推荐训练流程，输入单帧 RGB + 语言指令，仅单次前向推理，无测试时增强。
Card 05 数据集与资源

数据集与资源

  • 数据集规模：507 条轨迹（episode）、8,504 条非终止转移；训练/验证划分为 431 / 76 个 episode，对应 7,276 / 1,228 条转移（1 FPS），10 FPS 时为 73,979 / 13,371。
  • 数据规格：帧率 1 FPS（另评估 10 FPS），图像分辨率 1920×1440，动作维度 4-DoF。
  • 语言统计：15 个任务动词族，指令词表 448 个 token，平均指令长度 20.0 ± 5.1 词；动词以 *approach* 与 *follow* 为主，另有 *accompany*、*pursue*、*trace* 等 13 个改写族。
  • 难度标签：*find*、*close*、*far*（>10 m）、*height_change*（>0.5 m）、*obstructed*、*extended*。
  • 基准模型及参数：OpenVLA-7B（7.6B 总参 / 49.3M 可训练，LoRA，离散动作 token 化，Prismatic + SigLIP/DINOv2 + Llama-2 7B）、GR00T N1.7（3.1B 总参 / 1.62B 可训练，扩散策略，Cosmos-Reason2-2B）、π₀/OpenPI（3.3B 总参 / 145M 可训练，flow matching，PaliGemma-3B，LoRA）、SmolVLA（450M 全参数微调，flow matching，SmolVLM-2 + Action Expert）。
  • 训练预算：主实验统一 15,000 步优化预算；10 FPS 下仅重训 π₀ 与 SmolVLA；论文正文节选未给出具体 GPU/TPU 型号与数量。
Card 06 评估与结果

评估与结果

  • 评估环境与基准：在统一无泄漏 episode 级划分的 76 个验证 episode（N = 1,228 帧）上评估，指标为各动作维度的 MAE 与 Pearson 相关系数，并设置 常数均值（constant-mean）基线作为下界；同时在 1 FPS 与 10 FPS 两种控制率下评测。
  • 总体结论：仓库中的语言条件化空中控制远未解决，严格泛化设置下性能显著下降。
  • MAE 关键结果：π₀/OpenPI 整体最优（Δx 0.413、Δy 0.244、Δz 0.003、Δψ 0.220），优于常数均值基线（0.590 / 0.242 / 0.003 / 0.248）；SmolVLA 次之（Δx 0.468）；OpenVLA-7B 全部维度均劣于基线（0.620 / 0.368 / 0.005 / 0.409）；GR00T N1.7 在 1 FPS 下发散，误差极大（Δx 5.728、Δy 3.867、Δz 0.637、Δψ 0.555）。
  • 主要发现：连续动作建模（flow matching / 扩散）一致优于离散动作 token 化；单帧输入下仅前向通道（Δx）可被可靠学习，横向与航向修正难以预测；现有基础模型接口从地面与人形本体向空中平台的迁移效果差。
  • 部署导向分析：论文还分析成本–精度前沿、推理延迟与控制速率、开环 rollout 漂移，以及训练–验证差距、逐动词族语言鲁棒性和失败模式。
