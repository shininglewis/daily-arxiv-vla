Card 03 核心贡献

核心贡献

  • 提出配对反事实单元（Paired Counterfactual Unit, PCU）评估框架：固定初始场景、非语言输入与随机种子，只改变指令，从而区分"孤立成功"与"配对反事实成功"。
  • 在 Language2Drive 中实例化四类语言控制范围：A 原子动作、B 持续行为、C 场景锚定导航、D 长时程程序，并配套构建扩展 CARLA 仿真器（六张定制地图）、AlpaSim 真实场景重建赛道及开环评测。
  • 揭示驾驶质量与可靠指令跟随之间存在巨大落差：93.2% 的成功 rollout 在替代指令下没有对应成功，主要表现为"单侧完成"（one-sided completion）。
  • 提出以机器可校验的空间、时间与安全判据替代参考轨迹匹配，并给出 SISR / CFPS 等新指标体系及聚合度量 L2D。
  • 发现配对成功在等价改写（paraphrase）下极不稳定，且长时程程序类任务中仅"事件前保持不变式"一族取得严格成功。
Card 04 方法描述

方法描述

  • 配对反事实单元（PCU）：同一决策场景下评测两条互斥但均可行的指令，两条运行共享地图、自车/他车状态、历史、非语言输入与仿真种子，仅语言指令不同。
  • 机器可校验成功判据：对指令绑定几何、行为、时间谓词（如停车位足迹、朝向、速度、停留时长；路口出口门；有序访问序列），要求完成请求目标且拒绝配对替代目标。
  • 核心指标：

- SISR（Strict Instruction Success Rate）：单个请求的严格完成率。

- CFPS（Counterfactual Paired Success）：仅当一个 PCU 的两个臂都成功才计分。

- 二者差值为 SISR − CFPS = ½ q_one，精确量化"单侧完成"比例。

- 补充 SemISR / Sem-CFPS（放宽语义代理）、SCS / PCS（分级完成度）、PSM / Safety / DrivingScore（驾驶质量）与汇总指标 L2D。

  • 四类语言控制范围：A 原子动作（局部机动/设定点）、B 持续行为（区间内速度/车道/他车关系）、C 场景锚定导航（命名道路、泊车区域、精确车位）、D 长时程程序（有序访问、条件回退、事件前不变式、记忆引用复用）。
  • 构建流程：源场景筛选 → 几何锚定 → 配对规格定义 → 公开/私有信息编译分离 → 静态与动态验证 + 人工复核（每个 PCU 在三个种子下均有双向成功特权执行见证）。
  • 辅助诊断：FDQ（基础驾驶资质，无乘客指令的交通反应）与 Safety-Q（指令与安全冲突时的安全回退/拒绝/受限替代）。
  • 评测保持发布权重冻结，每个系统包含其输入适配器与控制器；公开输入不泄露目标与评分信息。
Card 05 数据集与资源

数据集与资源

  • Language2Drive 基准（Hugging Face 发布）：CARLA 64 个 PCU + RealSim 30 个 PCU（来自 23 个重建场景）。
  • CARLA-Language2Drive：基于 CARLA 扩展，新增六类定制地图——地下停车场、港口、中国城市道路、带详细标志的美国城市、校园、高速。

Card 06 评估与结果

评估与结果

  • 评估环境：闭环 CARLA 仿真（64 PCU）+ RealSim/AlpaSim 真实场景重建（30 PCU）+ 三个数据集上的开环预测轨迹评测，形成三种互补评估范式。
  • 主要指标：SISR、CFPS（严格与语义代理版）、SCS/PCS（分级完成度）、PSM/Safety/DrivingScore（驾驶质量）以及综合指标 L2D。
  • 关键结果：

- 主要 CARLA 系统中 93.2% 的成功 rollout 缺少替代指令下的对应成功，即"单侧完成"占主导。

- LMDrive 取得最高 SISR 12.24%，但 CFPS 为 0；Alpamayo 1.5 与 SimLingo 的 CFPS 均仅 1.04%，分别有 27/31 与 26/30 的孤立成功未被配对。

- RealSim 中 240 个系统–PCU 对仅有 1 个严格成功（SimLingo）；Alpamayo2-Super 达到 13.33% SISR 但 CFPS 为 0。

- Alpamayo 1.5 在 RealSim 上取得 100% Safety 与 97.17 DrivingScore，但严格与放宽代理配对成功均为 0；P11 场景中两臂 DrivingScore 均为 100 却未完成请求的车道变换。

- SimLingo 在 P22 上以 DrivingScore 97.82 与 85.78 完成两条速度区间指令，说明完整指令执行并不等价于最大化参考路径推进。

- 没有任何 CARLA 系统在全部三种等价表述下完成同一 PCU 的两个臂；SimLingo 仅 9/128 臂结果发生变化，但这些变化占到其解出的 15 个臂中的 60%。

- 长时程程序类在 504 次 rollout 中，7 个严格成功全部集中于"事件前保持不变式"一族，有序访问、条件回退、引用返回类均无严格成功。

- Safety-Q 诊断中，六个主要系统仅有的三次严格成功全部是"拒绝执行"，24 次回退或受限替代试验无一成功。

  • 结论：驾驶分数与孤立指令成功会显著高估语言跟随能力；有效评测必须检验"改变指令是否可靠改变并成功执行所选可行行为"。
