论文概述

  • 论文研究机器人门控式 DAgger（robot-gated DAgger）中的专家接管时机（takeover timing）问题，即机器人自主判断何时请求专家介入。

Card 03 核心贡献

核心贡献

  • 问题形式化：首次将专家接管时机形式化为机器人门控式 DAgger 中的数据采集决策问题，并通过实验证明时机显著影响示范内容与后续策略改进（定义效用函数 $U_B(Q,T)$ 与偏好关系 $T_1 \succ_{B,Q} T_2$）。
  • 方法提出：提出 TimelyDAgger，包含两个组件：Bridge-PCA（监控 VLA 内部桥接特征的偏离以触发接管）和 Feedback-guided Threshold Adaptation (FTA)（利用已完成干预的专家反馈自适应调整阈值）。
  • 评测框架：提出专用于机器人门控式 DAgger 的评测框架，串联失败检测、接管时机与下游策略提升三个环节。
  • 新指标 TASR：提出 Target-Aligned Supervision Ratio（TASR），无需重训练策略即可评估所采集专家监督的质量。
  • 实验验证：在 11 个操作任务、多种 VLA 骨干与真实机器人任务上验证，TimelyDAgger 在多数设置下取得竞争力的失败检测性能与更高的训练后成功率。
Card 04 方法描述

方法描述

  • 离线门控构建（Offline Gate Construction）：

- 使用冻结策略从 ID 示范中提取 bridge feature（VLM 传向动作生成模块的中间表示）。

- 对 ID 特征拟合 PCA 主子空间，用残差 $s_{\mathrm{BPCA}}(o_t)=\\|(I-P_B)(z_t^B-\mu_B)\\|_2$ 作为监控分数。

- 在 ID 校准数据上按分位数校准初始接管阈值 $\gamma_B$。

  • 在线专家数据采集（Online Collection）：

- 当监控分数超过阈值 $\gamma$ 时请求专家接管，专家控制剩余回合；否则继续执行 $\Delta$ 步策略动作后再次检查。

  • 反馈引导阈值自适应 FTA：

- 纠正性反转（corrective reversal）：比较接管前机器人与接管后专家初始动作，若专家首先"回退"机器人动作则说明接管过晚（$c_i=1$，advance 信号）。

- 策略–专家一致性（policy-expert agreement）：若策略预测动作与专家动作接近，则说明接管可推迟（$u_i=1$，postpone 信号）。

- 更新规则 $\gamma_{i+1}=\gamma_i\exp(-\beta y_i)$，其中 $y_i \in \{+1,-1,0\}$，$\beta>0$。

  • 策略更新：将保留的专家后缀 $\mathcal{D}_{\mathrm{corr}}$ 与原始 ID 示范 $\mathcal{D}_{\mathrm{ID}}$ 按固定比例混合，微调基础策略。
  • 关键创新：选择 bridge 表示作为监控位置，比输入观测或动作输出更贴近期望干预窗口；且复用现有 VLA 特征与干预反馈，无需额外训练失败预测器或专门采集数据。

Card 06 评估与结果

评估与结果

  • 评估指标：

- AUPRC：失败检测可靠性（以失败为正类）。

- TASR：监督质量（无需重训练即可评估）。

- Success Rate：训练后 OOD 条件下的成功率。

  • 主要结果（15 个任务–骨干设置，Table I）：

- TimelyDAgger 在 AUPRC、TASR、训练后成功率三项指标中均有 13/15 个设置取得最高值。

- TASR 与成功率在四种方法间的 Spearman 相关系数平均 $\bar{\rho}_s=0.72$，15 个设置中 14 个为正相关（支持 H3）。

  • 接管时机受控研究（OpenDrawer Grasp-OOD，6 个固定接管步）：

- 训练后成功率从立即接管的 42% 提升到第 80 步接管的 78%（相同专家动作预算与训练设置），支持 H1。

  • FTA 消融（StackCube–Green、OpenDrawer–Pose）：加入 FTA 后 TASR 与下游成功率均更高。
  • 真实世界验证：在相同有限专家动作预算下，TimelyDAgger 在两个 OOD 位置均取得最高成功率，优于 Human-Gated DAgger 与 Offline BC；FTA 可在一次晚接管后降低阈值，实现下一回合更早介入。
  • 结论：接管时机是影响策略提升的关键数据采集决策；监控 bridge 特征并利用干预反馈调整阈值，可在匹配专家预算下更有效利用监督。
