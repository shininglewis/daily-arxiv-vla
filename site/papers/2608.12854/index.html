Card 02 论文概述

论文概述

  • 论文提出 BrainWAM，一个受脑科学启发的动作空间协调框架，用于自动驾驶规划，旨在同时利用 VLA（视觉-语言-动作）模型 的语义先验和 WAM（世界动作模型） 的预测动力学能力。
  • 核心问题是：现有端到端驾驶方法通常只强调语义推理或预测建模中的一方面，而简单地将二者在 token 级注意力中联合融合（Tri-MoT）会导致 注意分配失配——语义信号主导共享注意力空间，压制预测动力学信号，甚至性能不如单独使用 WAM。
  • 受神经科学中大脑功能特化与协调机制的启发，BrainWAM 将语义推理与预测世界建模转化为两条互补的动作导向通路，并在紧凑动作表示层面进行对齐与协调。
Card 03 核心贡献

核心贡献

  • 提出 BrainWAM 动作级协调框架，将 VLM 语义推理与 WAM 预测世界建模转化为互补的动作表示，并在统一动作空间中进行协调（受脑功能特化启发）。
  • 识别并诊断了 Tri-MoT 中的 注意分配失配 问题：动作 token 在大多数 Transformer 层中过度关注语义 token 而忽视视频 token，导致原始 token 融合性能低于 WAM-only。
  • 设计 Callosal Action Bridge（CAB），受胼胝体启发，实现两条动作流之间的双向跨流交互（带可学习的门控残差注入）；设计 Cerebellar Intent Fusion（CIF），受小脑运动协调启发，融合精炼动作意图并解码为可执行轨迹。
  • 提出 异步整流流（asynchronous rectified-flow）推理策略，解耦视频与动作去噪过程，缩短推理延迟同时保留规划相关预测上下文。
  • 在 NAVSIM v1（89.5 PDMS） 和 NAVSIM v2（89.6 EPDMS） 上达到最先进性能，一致超越 VLA-only、WAM-only 及原始 token 融合基线。
Card 04 方法描述

方法描述

  • 采用 三阶段训练：阶段 1 训练 WAM 分支（视频与动作整流流目标），阶段 2 训练 VLA 分支（视觉与语言输入），阶段 3 冻结两个分支，仅优化 CAB、CIF 和动作解码器。
  • WAM 分支：以 Wan2.2-TI2V-5B 作为视频生成骨干，附加轻量动作专家，通过 Dual-MoT 模块耦合视频与动作流，学习预测基元的动作表示。
  • VLA 分支：以 Qwen3-VL-4B 作为 VLM 骨干，编码多视角图像与驾驶指令，通过整流流动作专家生成语义基元的动作表示。
  • CAB：在层间对预测动作 token 与语义动作 token 做双向交叉注意力，采用零初始化的 tanh 门控残差注入，保留预训练动作流能力。
  • CIF：将两条动作流拼接后经轻量 Transformer 处理并做元素级平均，融合表示经解码器回归动作速度场（velocity field）。
  • 训练目标基于 Flow Matching / Rectified Flow，视频与动作使用独立的整流流时间步（decoupled schedule），动作流共享同一噪声轨迹与时间步。
Card 05 数据集与资源

数据集与资源

  • 数据集：NAVSIM v1（基于 OpenScene，即 nuPlan 的再处理版本）与 NAVSIM v2，模型预测 4 秒、2Hz 的 8 个轨迹点。
  • 模型骨干规模：Wan2.2-TI2V-5B（视频骨干，5B 级）+ Qwen3-VL-4B（VLM 骨干，4B 级），各附轻量动作专家。
  • 训练资源：每个阶段在 8 张 NVIDIA H20 GPU 上训练 100K 步，每卡 batch size 为 6。
  • 优化配置：AdamW 优化器、cosine 学习率调度、200 步 warmup、峰值学习率 5×10⁻⁵、bf16 混合精度。
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1 使用 PDMS 指标（NC、DAC、TTC、Comfort、EP 组成）；NAVSIM v2 使用 EPDMS 指标（额外加入 DDC、TLC 惩罚项及 LK、HC、EC 子分数）。
  • NAVSIM v1 结果：BrainWAM 达到 89.5 PDMS，超过 AutoVLA（89.1）、DriveLaW（89.1）、WoTE（88.3）、DiffusionDrive（88.1）等强基线。
  • NAVSIM v2 结果：BrainWAM 达到 89.6 EPDMS，超过 DriveDreamer-Policy（88.7）、ARTEMIS（83.1）、DriveVLA-W0（86.1）等基线。
  • 消融实验：VLA-only 为 86.1 PDMS，WAM-only 为 88.1 PDMS，Tri-MoT（token 级融合）仅为 87.8 PDMS，而 BrainWAM 达 89.5 PDMS，验证了动作级协调机制的有效性与分支互补性。
  • 关键提升集中在 DAC（可行驶区域合规） 与 EP（行驶进展） 指标，在 NAVSIM v2 上优势主要由 EP 和 EC 驱动；推理使用 3 步整流流采样。
