Card 03 核心贡献

核心贡献

  • 提出 RoboACE 框架，将可修订对象从执行软件扩展到课程 harness（任务选择与构造程序）与执行 harness（规划、代码技能、预训练控制）两者。
  • 设计交替更新协议：一侧固定时另一侧进化，被接纳的挑战形成固定快照 \(\mathcal{T}_k\)，为执行侧修订提供稳定比较基准。
  • 引入任务准入机制（编译、物理有效性、可达性检查 + Judge 语义一致性校验）与 Benchmark Curator 维护参考覆盖。
  • 引入不定期调用的 Strategic Advisor，跨多次局部更新做长时程审查，识别反复失败与停滞的修订方向，但只提建议、不直接安装改动。
  • 在四个 LIBERO 系列面板上取得所评估系统中的最高成功率，并通过案例研究记录课程证据使用、抽屉技能接地契约、控制器干预三类真实修订。
Card 04 方法描述

方法描述

  • Harness 定义：包含提示词、技能、工具、接口与 agent 可读记忆，用于组织冻结基础模型周围的行为；所有 LLM / VLA 权重均不训练。
  • 角色分离：独立 agent 负责运行时决策（提出练习或执行任务），外部 optimizer 依据证据提出并测试修订；版本分为 Stable（已接受）与 Candidate（候选）。
  • 阶段一（课程进化）：课程 agent 读取能力画像 \(P_k\)（已展示能力、可用经验、未解决缺口、不确定性），结合任务统计与资产描述，保留/替换/新增练习条件，兼顾前置条件与可暴露回归的熟悉条件。
  • 阶段二（执行进化）：执行 agent 在固定快照 \(\mathcal{T}_k\) 上先测量传入部署，再在代码技能与 VLA 控制间选择，诊断区分"技能失败"与"技能描述误导/工具选择不当"，通过独立运行对比后采纳 Candidate 或保留 Stable。
  • 闭环与记忆：Experience Consolidator 仅将许可的任务级结果与经验转为 \(P_{k+1}\)；原始图像、轨迹、模型调用留在执行侧。诊断必须落到可部署的提示词、技能描述或可检索手册中才算生效（技能主描述上限 2500 字符）。
  • 信息隔离：Judge 专用的几何信息不进入执行 agent 观测；最终评测证据完全在回路之外。
Card 05 数据集与资源

数据集与资源

  • 开发数据：仅使用 LIBERO 生态，演化中的练习库累计含 76 个不同的原生 LIBERO 条件，另加通过准入的构造世界。
  • 规模配置：维持 30 个练习条件，内部 benchmark 最多 40 个条件，共保存 27 个轮次记录。
  • 评测数据：四个各含 200 个条件的固定面板——LIBERO（40 任务 × 5 个预留初始化）、LIBERO-Plus（七类扰动）、LIBERO-PRO（四个扰动维度）、LIBERO-X（五个挑战等级）。
  • 模型与工具：GPT-6.1 (Terra) 作为 agent 基座，SAM 3 用于感知，\(\pi_{0.5}\) 作为全程冻结的 VLA 控制器；对比基线含 OpenVLA-OFT、\(\pi_0\)-FAST、Cosmos Policy、GR00T N1.7、RPent、VoLo。
  • 训练资源：论文明确本项目未训练或微调任何 LLM / VLA 权重；未报告具体 GPU/TPU 型号与数量。
Card 06 评估与结果

评估与结果

  • 评估设置：仿真操作环境，判定使用环境原生任务谓词；所有系统共享每回合 8000 个环境控制步（20 Hz，约 6 分 40 秒）预算；每条件只取一条指定观测，超时与基础设施错误均计入失败分母。
  • 主要指标：成功率（%），即确认的原生成功数 / 200；仅对完整且经独立审计的面板计分。
  • 关键结果（RoboACE 进化后 vs. 进化前）：LIBERO 99.0 vs 63.5（+35.5）、LIBERO-Plus 94.5 vs 64.5（+30.0）、LIBERO-PRO 74.0 vs 59.0（+15.0）、LIBERO-X 30.5 vs 19.5（+11.0）。
  • 相对直接执行控制器 \(\pi_{0.5}\)（96.9 / 92.0 / 60.5 / 11.5）：LIBERO-PRO 上 +13.5 点，LIBERO-X 上 +19.0 点，说明增益主要来自围绕预训练控制构建的完整 agent 系统。
  • 相对最强 agent 基线（VoLo，97.5 / 90.0 / 60.5 / 10.0）：四个面板分别领先 1.5 / 4.5 / 13.5 / 18.0 点。
  • 案例证据：课程证据阅读器修订后独立运行生成合法 30 条件课程并自主替换 2 项；抽屉技能接地契约修订后，同一 54 条件快照成功数 48 → 50；Strategic Advisor 将反复恢复失败归结为"何时继续 VLA、何时切代码技能、何时干预"的控制选择问题。
