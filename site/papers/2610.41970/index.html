Card 03 核心贡献

核心贡献

  • 提出以“前提链”为核心的审计方法论：三个前置检查（因果消融 + oracle 上限、统计功效门控、帧缓冲哨兵渲染完整性校验）依次把关。
  • Best-of-N 候选选择审计：可部署的 value selector 比随机选择差 1.66 pp（95% CI 不含零），即使事后 oracle 也仅 +1.40 pp 且 episode 级区间跨零；82% 的查询状态下所有候选结果完全相同（仅 48/263 ≈ 18% 状态存在结果变化）。
  • 自适应计算分配可行性审计：token 剪枝削减最高 47.9% 的单次前向 FLOPs，但端到端仅测得 1.152× 加速（排除未来图像解码为 1.253×），未达预注册 1.5× 目标；联合分配效应低于噪声分辨率，功效门控未通过，结论为“不确定”而非“无效应”。
  • 发现并修复一个静默渲染损坏：RoboCasa/robosuite 栈在硬重置时 OpenGL 上下文管理缺陷导致帧缓冲被静默失效，损坏率随单次推理计算量单调上升。
  • 开源发布帧缓冲哨兵检测器、修复补丁与复现脚本，使审计流程可被重复执行。
Card 04 方法描述

方法描述

  • 预注册 + 证伪优先（falsification-first）：在查看数据前锁定决策阈值与重复一致性门控，即使门控失败也如实报告其结论。
  • 因果消融与 Oracle 上限估计：对每个查询状态回放全部 N=8 个候选项，在固定续行策略下由事后 oracle 选择成功候选，估计结果层面的选择上限（不可部署，仅作上界）。
  • 统计功效门控：由小样本估计配对残差标准差 σ̂_r，投影置信区间半宽 h(N)=z_{0.975}·σ̂_r/√N，仅当 h(N_full) < Δ_prereg 才启动全量实验。
  • 快照回放闭环测量：恢复状态、执行候选动作块前 16 步，之后每 16 步在固定基座策略下重规划，直至成功或 500 步上限。
  • 帧缓冲哨兵（framebuffer sentinel）：渲染前用标记值预填渲染目标，渲染后若目标基本未被写入则判定为损坏，用于在静默失效时报警。
  • 完整查询级端到端计时：直接测量整条采用 eager 执行的查询路径（含 VAE 编解码），而非把各组件耗时拼接起来；另用 FlopCounterMode（matmul + SDPA）测量 FLOPs。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：RoboCasa / RoboCasa365，配合 robosuite 渲染栈；另在讨论中提及 LIBERO（未实际运行）。
  • 被测模型：Cosmos Policy，权重为 nvidia/Cosmos-Policy-RoboCasa-Predict2-2B（2B 参数级），bf16 精度。
  • 推理配置：batch 1、5 步去噪、隐变量形状 [1,16,11,28,28]（11 个 latent 帧 × 196 token = 2156 token）。
  • 硬件与软件：NVIDIA RTX A6000，PyTorch 2.7.0、CUDA 12.8、cuDNN 90701，eager 模式。
  • 实验规模：选择审计 263 个状态、N=8 候选、R=2 次重复；计时审计每格 N=30 次带时间戳的调用（共 420 次）；渲染损坏对照组为 4 个任务 × 50 episode = 200 配对 episode。
Card 06 评估与结果

评估与结果

  • 评估基准/协议：RoboCasa 官方 direct-policy 评测协议；success-rate 以快照回放闭环方式测量，报告 state-within-task 与 episode-within-task 两种 bootstrap 区间。
  • 主要指标：成功率相对随机基线的差值（pp）、候选结果可分性、单次前向 FLOPs、完整查询端到端延迟加速比、渲染损坏发生率。
  • 选择审计结果：value selector −1.66 pp（state CI [-2.97,-0.31]，episode CI [-2.49,-0.71]），主要由 TurnOnStove（−3.87 pp）驱动，剔除该任务后仍为 −0.77 pp；hindsight oracle +1.40 pp（state CI [+0.31,+2.60]，episode CI [-0.25,+3.40]）；若打乱标签，按零假设预期约 14.8 个稳定可分状态，而实测 20 个，故不能视作 20 个已确认机会；R=2 时可靠性仅约 0.33。
  • 效率审计结果：全部未来帧 + value 帧剪枝带来 47.9% 名义 FLOPs 节省，端到端仅 1.152×（部署路径）/ 1.253×（排除解码），原因是 VAE 编码 238.0 ms 与未来图像解码 434.4 ms 不可被 token 剪枝削减，5 次 DiT 前向仅占 530.7 ms / 1241.8 ms。
  • 联合分配审计结果：初步系统性分量 0.0045 小于平均噪声底 0.0066（90 分位 0.0173），与时间主效应 0.0053 相当，任何阈值下都无法分辨；锁定阈值 θ_B 下最小可检测交互为 0.0265–0.0583（主效应的 5–11 倍）。
  • 渲染损坏结果：direct policy 下损坏率 8/1200 = 0.67% 每 episode（修复臂为 0），配对修复效应为 +3/200 次成功，外推到 24 任务 × 50 episode 协议约 +0.25 pp，上界不超过 +0.6 pp，故官方 67.1% 的 direct-policy 数字基本不受影响；direct-mode best-of-N 为 0/40 损坏；而在计算密集的 planning 模式下达 65%（作者强调为趋势上界示意，非标准基准数值）。
