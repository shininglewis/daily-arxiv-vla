Card 03 核心贡献

核心贡献

  • 提出 ReVeal 评估框架，结合重建层级评估（通过 NVMF 与 APGF）与匹配的闭环真实/仿真策略性能一致性评估。
  • 提出深度引导的重建流程 PGSR-D，引入单目深度作为额外几何先验，改善多视角视觉线索有限区域（如桌面、墙面、反光表面）的几何重建质量。
  • 构建了包含 8 个评估场景、42 个标注平面区域 的重建保真度评估基准，并覆盖 8 个机器人操作任务、3 个 VLA 策略 的匹配闭环评估。
  • 实验表明三条重建 pipeline（2DGS、PGSR、PGSR-D）在重建保真度与 real-sim 一致性上呈现一致的排序，且更高重建保真度与更强的 real-sim 一致性相关联。
Card 04 方法描述

方法描述

  • 整体框架：给定真实工作空间的多视角 RGB 视频，ReVeal 构建对应仿真环境，并在两个层级进行评估——重建层级（NVMF + APGF）与策略层级（匹配闭环真机/仿真评估）。
  • PGSR-D 重建：在 PGSR 基础上加入单目深度监督；用手机拍摄 1-3 分钟 RGB 视频，用 COLMAP 估计相机内外参；用 Depth Anything V2 预计算单目深度图。
  • 深度对齐与监督：对每个训练视图，通过最小二乘估计逐视图的尺度 $s_i$ 与平移 $t_i$，把单目深度对齐到 PGSR 渲染的平面深度 $D_i^r$，得到对齐深度 $\hat{D}_i^m$；构造深度一致性损失 $\mathcal{L}_{\mathrm{depth}}$。
  • 分阶段训练：仅在 PGSR 预热阶段（$k > k_d$）之后引入深度监督，总损失为 $\mathcal{L}_{\mathrm{total}} = \mathcal{L}_{\mathrm{PGSR}} + \lambda_d \mathcal{L}_{\mathrm{depth}}$，避免不可靠单目先验破坏初始几何。
  • NVMF（Novel-View Mesh Fidelity）：将观测划分为重建视图（87.5%）与留出评估视图（12.5%），用留出相机位姿直接渲染最终提取的网格（而非中间高斯表示），与真实 RGB 对比。
  • APGF（Annotated Planar Geometry Fidelity）：对人工标注的任务相关平面区域（ROI），从四个属性评估几何保真度——平面性（RANSAC 拟合平面的 RMS 点到面距离 $E_{\mathrm{plane}}$）、完整性（网格化后的空洞率 $R_{\mathrm{hole}}$）、连通性（最大连通分量占比 $R_{\mathrm{comp}}$）、局部粗糙度（$k$ 近邻局部平面拟合残差 $E_{\mathrm{rough}}$）。
Card 05 数据集与资源

数据集与资源

  • 未使用公开数据集；自建评测场景集，包含 8 个真实世界场景（厨房、家居、办公、餐厅等），共标注 42 个平面区域 用于 APGF。
  • 重建输入：手持手机采集的 RGB 视频，COLMAP 相机位姿估计；前景任务物体使用 TRELLIS 与 SAM 3D 单独重建；ArUco 标记用于真实/仿真空间对齐。
  • 评测策略与规模：SmolVLA (450M)、GR00T N1.7 (3B)、π₀.₅ (3B)。
  • 训练数据：每任务 200-300 条 真机遥操作演示；22 维关节位置动作空间，两个头部相机观测；冻结视觉-语言主干，仅训练动作头 10,000 步，batch size 128，峰值学习率 $1\times10^{-4}$（1k 步预热 + 余弦衰减）。
  • 训练算力：4× NVIDIA A100 GPU；仿真平台为 Genesis World，使用 NVIDIA RTX 5090 GPU；真实机器人为 Dexmate Vega。
Card 06 评估与结果

评估与结果

  • 评估环境：Dexmate Vega 人形机器人，仿真在 Genesis World 中进行；每个 task-policy-pipeline 组合评估 50 个 episode，真机同样评估 50 个 episode。
  • 评估指标：重建层级使用 PSNR、SSIM、LPIPS、DINOv2 余弦相似度、SigLIP 余弦相似度，以及 APGF 的平面性/完整性/连通性/粗糙度；策略层级使用 Pearson r、MMRV（均值最大排序违背） 与 MAE。
  • NVMF 结果（8 场景平均）：PGSR-D 全面最优——PSNR 13.212、SSIM 0.727、LPIPS 0.350、DINOv2 0.697、SigLIP 0.847；优于 PGSR（12.637 / 0.681 / 0.382 / 0.587 / 0.805）与 2DGS（12.528 / 0.655 / 0.428 / 0.502 / 0.781）。
  • APGF 结果：PGSR-D 在 42 个标注区域上平面性与连通性更稳定，完整性更高、局部粗糙度更低（粗糙度 2.98×10⁻⁴，优于 PGSR 的 5.90×10⁻⁴ 与 2DGS 的 8.45×10⁻⁴）。
  • Real-sim 一致性：PGSR-D 获得最高的 Pearson r = 0.960、最低 MMRV 0.102 与 MAE 0.050，排序与重建保真度完全一致（PGSR-D > PGSR > 2DGS）。
  • 保真度与一致性关联：NVMF 指标中 DINOv2（r = 0.795） 与 SigLIP（r = 0.726） 关联最强，LPIPS 为 0.600，PSNR 仅 0.512、SSIM 仅 0.229；APGF 指标中完整性（r = 0.759） 与 粗糙度（r = 0.731） 关联最强，表明更高重建保真度对应更强的 real-sim 策略性能一致性。
