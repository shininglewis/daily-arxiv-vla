Card 04 方法描述

方法描述

  • 模型架构：MoonViT-V2（Kimi K3） 视觉编码器 + Qwen3-4B 语言解码器；可学习投影器聚合相邻 2×2 视觉特征，经两层 MLP（GELU + 输出归一化）映射到语言嵌入空间。
  • Grounding 形式化：语义标签、协议标记与 1000 个量化坐标 token（<0>–<999>）共享输出词表，以自回归方式生成变长响应；查询类别不存在时输出 None。
  • 三阶段训练：(1) 基础 VLM 训练（投影器对齐 → 联合多模态预训练 → 通用视觉/视频理解）；(2) SFT 坐标对齐（先全模块更新，后冻结视觉侧做语言侧精调）；(3) GRPO 强化后训练（每个图文-查询对采 G=8 条自回归响应）。
  • 奖励设计：grounding 使用 R_set（基于参考逐一最大 IoU 匹配 + 类别校验的覆盖率）与 R_strict（多阈值 F1、定位、格式、数量、顺序，惩罚重复与超大框），加权为 0.7·Z(R_set) + 0.3·Z(R_strict)；OCR 使用匈牙利一对一匹配联合评估文本与几何，得到单一复合奖励 Z(R_OCR)。
  • 下游接口：自动驾驶将未来轨迹表示为 3 秒内 6 个有序路点，复用 <0>–<999> 词表；机器人操作遵循 π 风格 flow-matching 策略 与 StarVLA 的层级连接方式，将中间特征注入 Action DiT 的对应交叉注意力层。

Card 06 评估与结果

评估与结果

  • 评测设置：对比 44 个基线，在 34 个基准、11 类感知能力上评测，涵盖闭集/开集专用检测器、通用 VLM、grounding 专家模型与具身基础模型；GroundingPI 结果取十次运行均值（5 个随机种子 × 每种子 2 次），部分本地基线取 3 次运行均值；GPT-6 Astra 以 thinking effort = High 评估。
  • 评测指标：框 grounding 与 OCR 用 F1mIoU，物体 pointing 用 F1@Point，空间/机器人/GUI grounding 用任务相关准确率；自动驾驶用开环 L2 误差。
  • Grounding 主结果：GroundingPI 平均 73.68%，超越规模更大的 GPT-6 Astra（71.54%），建立新的 SOTA。
  • 代表性单项：Dense200 74.53（Astra 65.04，Qwen3-VL-4B 仅 14.02）；COCO 62.98（列内最佳）；LVIS 56.02；VisDrone 40.44（仍具挑战）；HumanRef 88.56、RefCOCOg val 85.62、RefCOCO avg 83.92（均为最佳）。
  • 机器人操作迁移：在 RoboTwin 2.0 的全部四种分布外（OOD）设置中均优于所有被评测主流骨干，最强骨干相对提升最高达 24.8%。
  • 数据效率：在 RoboCasa-GR1 上，仅用 50% 演示数据训练的 GroundingPI 优于用 75% 数据训练的对比基线。
  • 自动驾驶迁移：在 nuScenes 上作为视觉骨干，达到平均开环 L2 误差 0.296 m。
  • 消融与结论：grounding 与动作学习随预训练规模同步提升；密集 grounding（dense grounding）对自动驾驶和机器人操作都有显著增益；OCR 表现出作为感知学习“催化剂”的潜力；互补监督组合能构建最强的感知-动作接口。
