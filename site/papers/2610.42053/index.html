Card 03 核心贡献

核心贡献

  • 提出 REA 三层运行时，为智能体、VLA 与程序化策略提供统一契约，并在三个仿真器与真实机器人上验证可移植性。
  • 设计具身路由器，由路线记忆 (route memory)、边界触发式裁判门 (boundary-triggered judge gate) 与共享预算的升级阶梯 (escalation ladder) 组成，在“任何运行中的策略都不等待大脑”这一准则下协调慢快系统。
  • 提出对齐评测协议 (Aligned Evaluation Protocol)，在相同 (task, seed)、相同初始状态语义、相同 horizon 与预算下比较不同方法。
  • 累计超过 30,000 个对齐测试 episode，系统验证路由与裁判两个模块各自的贡献。
  • 在独立 RoboTwin 2.0 研究中首次在同一运行时内同时运行 VLA 策略与代码策略（VLA+code 混合池）。
Card 04 方法描述

方法描述

  • System 0（小脑）：任意可从当前状态启动并最终返回的控制器（冻结 Python 程序、VLA 动作块、全身控制器），以原生频率跑自己的闭环，只在段边界或策略边界交还控制权；LIBERO-Pro 上为沙箱中调用 SAM 3、ContactGraspNet、PyRoki 逆运动学的程序。
  • System 2（大脑）：离线用 Generate(t) 产出候选策略集，在线仅提供 Judge（比较初始帧与当前帧判断 done/not_done）与 Advise（文本推荐策略）两种服务。
  • System 1（具身路由器）：基于开发集 episode 统计的路线记忆做 O(1) 查表派发（按成功率排序，成功率相同则选步数更少者），测试时不调用大脑。
  • 边界触发式裁判门：在每次策略返回时调用一次视觉裁判，not_done 则升级、done 则终止并保护已完成的结果；另设免费的异常门仅在异常/截断时升级。
  • 共享预算升级阶梯：L_t = [first(t), other(t), first(t)]，每次升级都从当前状态启动，所有运行与大脑调用共享同一 (H-u, W-w) 预算。
  • 变体：REA-M（路线记忆 + 异常门）、REA-A（智能体在派发/恢复时选策略）、REA-V（路线记忆 + 视觉裁判门）。
  • 学习式派发：RoboTwin 中使用观测条件选择器，编码初始指令、图像与机器人状态为 h_0，用成功头 q_p = σ(w_p^T h_0 + b_p) 打分并选最高者，扩展到 VLA+代码混合池。

Card 06 评估与结果

评估与结果

  • LIBERO-Pro 全量（3,000 episode）：REA-M / REA-A 均达 95.9% 成功率，超过最强单方法基线 Agents SDK + GPT-6 (94.7%)（86:51，p=0.004），距事后 per-task oracle (96.9%) 仅差 1%；每成功步数 1,003 vs 1,343（-25%），控制时间比 Agents SDK 少 17%、比阻塞式 advisor 少 25%；随机选方法仅 78.2%，说明增益来自路由而非策略池更大。
  • 匹配困难子集（72 episode）：完整路由器解 48/72，是唯一超过最佳单策略的方法（+11.1%，p=0.039）；把裁判门换成异常门损失 15.3%（p=0.003）；盲重试几乎无收益（24 vs 21，p=0.66）。
  • 跨方法提升：在 ASPIRE Fix 策略上 REA-M 从 66.3% → 71.9%（+5.6%），REA-V 再 +3.1% 至 74.9%；在零样本 GPT-6 策略上从 19.3% → 26.3%。
  • RoboTwin 2.0（100 episode）：REA (VLA) 84%、REA (VLA+Code) 86%，均超过单 VLA 基线 MEDex 的 80%；加代码策略把随机场景成功数从 40/50 提升到 42/50。
  • 迁移实验：BEHAVIOR-1K 解 27/50（Agents SDK 25/50，不显著；对冻结程序基线 13:4、12:3 显著）；RoboTwin 200 scene 并排对比 97 vs Codex CLI 75（p=0.007），隔夜重跑 133 vs ASPIRE 105、Agents SDK 103、Show-Harness 12。
  • 真实机器人：Unitree G1 推椅子 8/10（Agents SDK 5、Codex 4、ASPIRE 2，p=0.023）；AlohaMini2 积木放置 10/10（ASPIRE 8、Codex 5、Agents SDK 4）。
  • 失败模式诊断：Show-Harness 这类“大脑直接进控制环”的做法在 3,000 episode 中仅解 78 个（2.6%）；单 token VLM 直接输出动作仅解 1/1,987、Cartesian IK 直接策略解 0/600，说明大脑不能充当控制器。
