Card 03 核心贡献

核心贡献

  • 提出 V2X-WAM 协作世界-动作框架，显式耦合动作生成与未来世界建模：规划动作条件化未来交通演化，预测后果再反馈以精炼最终轨迹。
  • 设计可靠性感知协作场景表示，通过紧凑量化基础设施消息整合时序车端/路端观测，并用学习的空间可靠性与时间置信度调节协作信息贡献。
  • 引入动作条件未来世界建模机制，联合预测未来占据栅格与动态流，并通过流引导占据输运捕捉周围交通的空间与动态演化。
  • 在大规模真实世界协作驾驶数据集上进行综合实验，验证规划与未来世界预测效果，并通过消融研究检验关键组件贡献。
Card 04 方法描述

方法描述

  • 输入包括 ego 与基础设施的相机图像、LiDAR BEV 历史、历史 ego 位置、当前 ego 运动状态、高层路线命令、车-路相对几何与可行驶区域图。
  • 整体分为两阶段：可靠性感知协作场景编码与耦合世界-动作建模；过程可概括为 Z=f_scene(X)，(P^(0), A, Q)=f_plan(Z, s)，(O, V, W)=f_world(Z, P^(0), A)，P=f_ref(P^(0), Q, W)。
  • 时序多模态智能体编码：共享图像编码器与时序 BEV 编码器，结合 BEV 差分、局部运动相关性与运动融合特征。
  • 可靠性感知 V2X 通信与融合：基础设施特征经通道级对称 INT8 量化压缩为紧凑消息，训练使用直通估计器；用空间可靠性图 R_spa 和时间置信度 κ_t 加权融合。
  • 场景 token 化与潜在重采样：卷积 tokenizer 加 2D 坐标嵌入与条件 token，通过可学习 latent queries 和 cross-attention 得到共享场景 latent Z。
  • 多模态动作提议：并行预测 K 条轨迹假设，使用 mode/horizon 嵌入、常速度先验与残差精炼，经 mode scoring 选出初步轨迹和动作序列。
  • 动作条件未来世界建模：基于动作-时间条件调制世界状态，联合解码未来占据与动态流；使用运动置信度与自适应死区抑制静态区域噪声，并通过可微 BEV warping 进行流引导占据输运。
  • 世界感知轨迹精炼：将规划 token 与世界后果 token 配对，预测有界轨迹修正并裁剪到可行规划范围。
  • 跨任务梯度路由：使用 G_α(x)=sg(x)+α[x-sg(x)]，在前向不变的前提下缩放跨任务反向梯度，缓解密集世界预测损失对规划梯度的干扰。
  • 联合学习目标：单阶段联合规划、安全与未来世界监督；多模态规划采用匹配成本选择最佳模式并进行轨迹回归。
