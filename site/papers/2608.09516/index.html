Card 03 核心贡献

核心贡献

  • 明确识别了 WAM 的“预测—深思鸿沟”，并将可靠执行建模为模型外部的状态估计与闭环决策问题。
  • 提出证据接地任务状态（evidence-grounded task state）和能力条件化的可执行空间投影（capability-conditioned executable-space projection），将开放式 VLM 计划编译为可行的 WAM 技能序列。
  • 设计事件驱动、双时间尺度机制（event-driven dual-timescale mechanism），支持进度感知的任务转换、计划修订和局部具身状态恢复。
  • 在 RoboMemArena 和 RoboCerebra Ideal 上取得最先进（state-of-the-art）的性能，验证了框架在长时程、部分可观察、依赖记忆的操控任务中的有效性。
Card 04 方法描述

方法描述

  • 将全局指令分解为包含动作节点（motor nodes）和认知节点（cognitive nodes）的任务图，认知节点用于获取观察、验证状态、绑定变量或更新记忆。
  • 场景信念以四元组事实（主体、谓词、客体、值）加上认知状态（observed/inferred/unknown）、置信度和支持性 RGB 证据表示，区分“未观察到”与“观察为假”。
  • 可执行空间投影通过确定性计划编译器检查参数类型、依赖关系、前置条件—效果一致性、单臂持物约束和图无环性，将语义计划规范化为 WAM 支持的原语序列；若无可行投影则返回失败并要求重规划。
  • 轻量级进度估计器以冻结的 SigLIP2 视觉编码器加四层因果 Transformer 实现，预测连续进度、阶段完成概率和进度区间，事件触发由进度估计和历史状态共同驱动。
  • 执行失败时，HarnessWAM 保存每个动作节点开始时的手臂关节状态和夹爪状态，通过多步关节控制恢复到子任务初始状态，同时保留已获取的场景知识与任务记忆；替换未执行图后缀以继续执行。
  • 整体推理流程见 Algorithm 1，包括初始化、规划、投影、快速 WAM 执行循环、事件触发时的 VLM 任务管理器决策（continue/advance/observe/replan/recover/terminate）以及最终目标验证。
Card 05 数据集与资源

数据集与资源

  • RoboMemArena：包含 26 个长时程操控任务，平均轨迹长度约 1,076 环境步，68.9% 的子任务依赖历史信息；涵盖多物体转移、遮挡、计数和顺序执行四类任务。
  • RoboCerebra Ideal：面向长时程组合操控和高层推理的基准，使用官方 SR 指标。
  • 底层 WAM 为 LingBot-VA，架构保持不变，并在每个基准上分别微调；所有对比和消融共享同一 WAM checkpoint。
  • 任务管理器使用 Qwen3-VL-32B-Instruct，无任务特定微调，仅输入多视角 RGB 图像。
  • 进度估计器输入最近 5 步双视角 RGB 和当前技能指令，使用冻结的 SigLIP2-base-patch16-256 编码器与四层因果 Transformer。
Card 06 评估与结果

评估与结果

  • 评估环境为 RoboMemArena 和 RoboCerebra Ideal，RoboMemArena 采用全任务成功率（SR_task）和子任务成功率（SR_sub），RoboCerebra 采用官方 SR。
  • 在 RoboMemArena 上，HarnessWAM 获得平均全任务成功率 59.6%、子任务成功率 69.9%，分别比此前最优的 PrediMem 高 21.1 和 14.7 个百分点。
  • 在受控 WAM 对比中，WAM + Whole Task 为 44.4%/52.3%，WAM + Static Plan 为 47.9%/62.0%，HarnessWAM 比 Static Plan 进一步提升 11.7 和 7.9 个点，表明闭环任务管理比单纯分解更重要。
  • 在 RoboCerebra Ideal 上，HarnessWAM 达到 SR 23.7%，优于 GPT-4o Planner + OpenVLA（21.92%）和 HPE Framework（21.10%）。
  • 消融实验显示，移除可执行空间投影对性能影响最大（SR_task 降至 18.5%，SR_sub 降至 38.3%）；移除进度事件后为 38.3%/50.7%；移除结构化任务状态为 47.7%/61.1%；纯进度切换（progress-only switching）为 55.4%/68.4%；移除失败恢复为 54.2%/67.7%。
