DriveUniTok: A Unified Multimodal Tokenizer for Driving World-Action Models

2026-10-26 · 原文 · 翻译 · 2610.35044

论文提出 DriveUniTok，一种面向驾驶世界-动作模型（WAM）的统一多模态 tokenizer，将 RGB 外观、投影 LiDAR 深度所表示的度量几何、以及自车运动编码到同一个可解码连续 latent 中。 基于冻结的 DriveUniTok，论文将预训练扩散模型适配为 DriveUniWAM，预测未来统一 latent，并解码未来外观、深度和自车轨迹，实现联合未来场景预测与规划。 论文旨在解决现有 WAM 中外观、几何和自车运动表示不对称、模态流分离导致的信息损失与跨模态不一致问题。

Card 03 核心贡献

核心贡献

  • 提出 DriveUniTok：基于 query 的统一多模态 tokenizer，将 RGB 外观、投影 LiDAR 几何和 clip-relative 自车姿态编码进同一连续 latent。
  • 提出 DriveUniWAM：基于扩散的 WAM，在统一 latent 上联合预测未来场景与自车轨迹，而非使用独立的观测生成和动作生成通路。
  • 使用 Flow-GRPO 和 NAVSIM PDM 奖励进行强化学习后训练，在冻结 tokenizer 的前提下进一步优化规划策略。
  • 在 NAVSIM 上证明统一 tokenization 相比分离模态流方案具有更好的预测与规划性能，并降低下游计算成本。
  • DriveUniWAM 在强化学习后训练后达到 91.54 PDMS，在被评估的 WAM-based planners 中达到 state-of-the-art 水平。
Card 04 方法描述

方法描述

  • 多模态编码器：RGB 和投影深度共享冻结的 DINOv3-L 特征层级；深度使用单通道 patch embedding 和模态嵌入；自车姿态经可训练 ego state encoder 映射为 8 个 ego tokens。
  • 统一 query 融合：使用 576 个图像 query 和 8 个 ego query，共 584 个共享 query；通过 self-attention 与 deformable cross-attention 依次聚合 RGB 和深度特征，使三种模态在时序压缩前交互。
  • 时序压缩：对每个 query 的 T=5 帧状态使用 causal self-attention、learned pooling query 和 Gaussian bottleneck，压缩为单个 d=16 的连续 latent token。
  • 多模态解码器：将统一 latent 扩展回 T 个帧级 memory，使用共享 Transformer 和 target-specific mask tokens 分别解码 RGB、深度和自车姿态；额外加入仅训练时使用的语义分支，与冻结 DINOv3-L 特征做 cosine 对齐。
  • 训练目标：包含 RGB 重建损失、置信度加权深度回归损失、自车姿态 L1 损失、语义 cosine 损失和 KL 正则。
  • DriveUniWAM：冻结 DriveUniTok，从 Wan2.2-TI2V-5B 初始化去噪器，仅调整输入输出投影；使用 flow matching 预测统一 latent 的速度场，历史 latent 作为干净上下文，未来 latent 加噪重建。
  • 强化学习后训练：使用 Flow-GRPO 针对 NAVSIM PDM 奖励优化采样未来，仅训练去噪器中的 LoRA 适配器，tokenizer、解码器和参考策略保持冻结。

Card 06 评估与结果

评估与结果

  • 评估环境为 NAVSIM navtest 非反应式规划基准；同时评估多模态重建、联合未来预测和规划性能。
  • 重建指标包括 LPIPS_VGG、LPIPS_DINO、PSNR、SSIM、rFVD_I3D、rFVD_VJ；深度指标包括 MAE、AbsRel、RMSE；自车运动指标包括 ADE、FDE。
  • 规划指标包括 NC、DAC、EP、TTC、Comfort 和 PDMS。
  • DriveUniTok 在 benchmark-scale 方法中取得最低 LPIPS_DINO=0.1063 和 rFVD_VJ=3.4546，分别比第二名提升 18.7% 和 39.7%。
  • 与 natural-budget 分离流控制相比，统一设计使用约一半 token 和 latent scalars、序列长度减半、每步 DiT 计算降低约 52%，同时将 PDMS 从 90.1 提升到 91.0。
  • 在等预算分离流控制下，DriveUniTok 将 gFVD_VJ 降低约 48%、未来深度 AbsRel 降低约 43%、轨迹 ADE 降低近 9%，并将 PDMS 从 87.5 提升到 91.0。
  • DriveUniWAM 仅相机输入达到 90.5 PDMS；加入投影 LiDAR 后达到 91.0 PDMS；强化学习后训练后达到 91.54 PDMS。
  • DriveUniWAM 在 NAVSIM-v2 上取得 90.3 EPDMS。
  • 替换原生 VAE 为 DriveUniTok 后，Wan2.1-1.3B 的 PDMS 提升 2.5 点，Wan2.2-5B 提升 3.1 点；在五种视频扩散骨干上，统一 latent 取得 88.9–91.0 PDMS。
