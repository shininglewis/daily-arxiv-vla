Card 02 论文概述

论文概述

  • 论文提出 MotionWeave，一种面向动作块（action chunk）预测的以运动为中心的未来动态学习框架，用于视觉-语言-动作（VLA）策略。
  • 现有 VLA 世界模型方法通过预测完整未来图像、视频或全局隐表示提供动态监督，容易引入与控制无关的外观与背景信息，且共享全局动作特征难以建立“动作时间步—局部视觉变化”的对应关系。
  • 研究目标是显式定位与动作相关的动态区域，并利用其时间演化来引导逐步动作生成，而非重建完整未来视觉观测。
Card 03 核心贡献

核心贡献

  • 提出 Action-Induced Motion Grounder（AIMG）：以动作与本体感知表示为条件构建 horizon 特定查询，从当前 VLM 视觉 token 中定位每个未来动作步对应的交互区域，使不同动作 horizon 获得空间上差异化的视觉证据。
  • 提出 Horizon Residual Composer（HRC）：通过相邻 horizon 交互表示的差分编码时间运动线索，并经由门控残差注入动作表示，实现从区域定位到逐步控制的闭环。
  • 在六个 MetaWorld 任务上取得 75.3% 平均成功率，比最强基线 π₀（66.7%）绝对提升 8.6%，在五个任务上领先，尤其在持续交互任务上优势明显。
  • 设计基于未来帧机器人臂掩码的 KL 运动定位监督，训练时提供 horizon 特定动态监督，推理时仅使用当前观测，不增加额外推理开销。
Card 04 方法描述

方法描述

  • 整体框架：图像与文本由 InternVL3-2B（语言侧为 Qwen2.5 系列解码器）编码，与可学习动作查询占位符拼接后输出动作 token A 和空间视觉 token V；本体感知 Sₜ 经独立编码器得到 P；流程为 (A,V,P) → AIMG → (M,α) → HRC → A′ → Action DiT → 动作块。
  • AIMG：将动作 token 与本体感知映射到共同运动空间，与可学习 horizon 嵌入相加形成 horizon 特定查询 q_h；通过 softmax 注意力在视觉 token 上聚合，得到交互表示 m_h 与空间注意力 α；horizon 嵌入使各交互表示对齐未来动作时间步。
  • HRC：计算相邻 horizon 交互表示的差分 Δm_h = m_h − m_{h−1}，以运动差分作为 query、动作查询作为 key/value 进行多头交叉注意力，得到更新量 ΔA；采用本体感知条件门控 g = σ(Proj_g(P))，通过减法残差更新 A′ = A − g ⊙ ΔA，仅吸收对应时间步的运动增量并保留原始控制先验。
  • 训练目标：Action DiT 基于 A′、P、噪声动作块 a^τ、扩散时间步 τ，使用 flow-matching 损失 L_act 预测未来 4 步动作；AIMG 注意力 α_h 与未来机器人臂掩码分布 μ_h 进行 KL 监督 L_motion；总损失 L_total = L_act + 0.05·L_motion。
  • 创新点：不重建完整未来视觉观测，而是以运动为中心的局部区域定位与相邻 horizon 差分建模；推理阶段移除掩码渲染与 KL 分支，直接由 DiT 去噪输出动作。
Card 05 数据集与资源

数据集与资源

  • 数据集：MetaWorld 六个任务——Pick Place、Disassemble、Stick Pull、Assembly、Shelf Place、Hand Insert，覆盖抓取、装配、拉扯、插入与长时程放置。
  • 数据规模：每任务 25 条专家轨迹、每条 175 个时间步，共 150 条轨迹、26,250 帧；输入为单视角 224×224 RGB 图像、语言指令与本体感知状态，监督未来 4 步动作（H=4）。
  • 模型规模：基于 InternVL3-2B 全量微调；动作头为 12 层、768 维、12 头 DiT，4 步动作 horizon，flow-matching 目标，训练扩散步 100、推理步 10；AIMG 使用 4 个 horizon 查询、隐藏维度 512；HRC 使用 768 维、8 头注意力。
  • 训练资源：2 张 48GB NVIDIA A40 GPU，采用 FSDP 全分片与梯度检查点，训练 20k 步；每 GPU batch size 8，全局 batch size 16；学习率 1×10⁻⁵，权重衰减 0，梯度裁剪 1.0。
  • 未来帧仅在训练阶段用于构建运动监督，推理时不可用。
Card 06 评估与结果

评估与结果

  • 评估环境：MetaWorld 六个任务，每任务 25 个 episode，各方法共享初始化种子，175 步上限，每执行 2 步重新规划；成功判定采用官方二值标准，报告六任务宏平均成功率。
  • 主要指标：平均成功率（%），以及各任务成功率。
  • 主结果：MotionWeave 平均 75.3%，绝对超过 π₀（66.7%）8.6%，在 5/6 任务领先；Disassemble 达 92.0%（π₀ 为 68.0%），Shelf Place 为 76.0%（π₀ 为 64.0%）；在 Pick Place 上 π₀ 更优（72.0% vs 60.0%），该任务目标位移较短、全局特征已足够。
  • 基线对比：DreamVLA 平均 65.0%，WoG 平均 50.7%，Fast-WAM 平均 49.3%。
  • 消融结果：基线 58.0% → 加 AIMG 但无运动损失 62.0% → 加 AIMG 70.0% → 加 AIMG + HRC 75.3%，验证空间定位与时间差分各自的贡献。
  • 超参数敏感性：horizon 查询数在 4 时峰值 75.3%，6/8 时分别降至 73.3%/70.0%；运动损失权重 λ_motion=0.05 时峰值 75.3%，0.10/0.20 时降至 72.7%/68.7%。
