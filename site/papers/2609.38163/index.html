Card 02 论文概述

论文概述

  • 论文研究世界-动作模型（World-Action Models, WAMs） 中表征空间的设计问题，即表征作为控制与预测之间的接口应如何构造。
  • 通过受控对比实验发现：重建保真度（reconstruction fidelity）本身不足以评估控制效用，且预训练的感知特征若不经过适配也难以直接用于动力学建模。
  • 提出 ReWAM，一种以表征为中心的世界-动作模型，让策略目标塑造表征内容，世界模型学习表征的演化，无需生成式视频预训练。
Card 03 核心贡献

核心贡献

  • 通过系统性的受控对比实验证明：仅靠重建保真度不足以选择 WAM 表征，原始 DINO 特征在 RoboTwin 2.0 上优于 Video-VAE 潜变量，但其统计特性需经校准才适合扩散训练。
  • 提出 ReWAM，由 Feature Calibration（特征校准）、Temporal Representation Bottleneck（时序表征瓶颈, TRB） 与 Action-Grounded Representation Shaping（动作锚定表征塑造, AGRS） 组成，使动作目标塑造紧凑的预测-控制共享表征空间。
  • 设计 非对称梯度路由（Asymmetric Gradient Routing）：仅让动作损失梯度到达 TRB，世界模型损失梯度被截断，从而让表征编码受控于策略目标，而世界模型学习其演化。
  • 在 RoboTwin 2.0、RoboDojo 两个仿真基准以及真实机器人任务上验证方法有效性，且不依赖生成式视频预训练。
  • 揭示了校准 DINO 特征可带来 12.20 个百分点 的平均成功率提升，表明表征设计不止是编码器选择问题。
Card 04 方法描述

方法描述

  • 基础编码器：采用冻结的 DINOv3-L 骨干网络（特征维度 d=1024），提取多相机多视图的 patch 特征。
  • Feature Calibration（特征校准）：

- 多层聚合（Multi-layer aggregation）：从 DINOv3-L 的第 {12,14,16,18,20,22,24} 层提取特征，做非仿射 LayerNorm 后取平均，并叠加最后一层的空间均值以注入图像级上下文。

- 归一化（Normalization）：冻结特征基线使用固定均值方差标准化预测目标；ReWAM 中 TRB 改变预测空间，故采用运行统计量归一化。

- 表征感知噪声调度（Representation-aware noise schedule）：采样偏移 τ = αu / (1+(α−1)u)，α = √(D/D_base)，D_base=4096，兼顾 token 数量与通道宽度，未来状态独立采样 flow time，当前状态保持干净。

  • Temporal Representation Bottleneck（TRB）：

- 将每相机非重叠 2×2×2 时空块展平为 8d 维 token，跨视图拼接后经多头自注意力与线性投影得到 128 维紧凑世界状态 token。

- 使用因果运行归一化（causal running normalization）：基于历史批次的运行均值与方差归一化 TRB 输出，并以 EMA 更新统计量，推理时固定。

  • Action-Grounded Representation Shaping（AGRS）：

- 基于 Mo-T（Mixture-of-Transformers） 架构，包含世界分支 W_θ 与动作分支 A_θ，均以 flow matching 训练。

- 两个分支接收语言 ℓ 和本体感受 s₀ 的条件嵌入 c，未来状态与动作 token 均关注当前世界特征，但两组 token 间注意力被阻断；世界分支使用因果时序注意力及独立噪声水平，动作分支一次性预测整个动作块。

- 联合世界-动作学习：条件分布分解为 p_θ(z_{1:H}\|z₀,c) · p_θ(a_{1:H}\|z₀,c)。

- 非对称梯度路由：∇_θ L = ∇_θ L_world + ∇_θ L_action；∇_φ L = (∂z₀/∂φ)ᵀ ∂L_action/∂z₀，即世界损失梯度在表征处被停止，只有动作损失梯度进入 TRB。

  • 推理：世界分支仅在推理时处理当前状态 z₀ 以作条件，不生成未来状态，与 Fast-WAM 部署一致。

Card 06 评估与结果

评估与结果

  • 评估环境：RoboTwin 2.0（clean/random 设置）、RoboDojo（含/不含具身预训练两组对比）、真实机器人任务。
  • 主要指标：任务成功率（Success Rate）、RoboDojo 平均 Score 与成功率、表征分析（t-SNE、解冻像素重建探针等）。
  • 关键结果：

- 在 RoboTwin 2.0 的 clean 与 random 设置下均达到 93.6% 成功率，且不使用生成式视频预训练。

- 在 RoboDojo 上，具身预训练后平均 Score 达 12.29、成功率 8.28%；无具身预训练设置下在所有对比方法中领先（Score 3.48、SR 2.03，优于 Fast-WAM 的 3.48/2.03 同档位）。

- 具体分项上 ReWAM 在 Generalization（Score 14.65 / SR 10.50）、Long-Horizon（SR 16.25）、Memory（Score 9.05 / SR 7.67） 等维度表现突出。

- Feature Calibration 使 RoboTwin 2.0 平均成功率提升 12.20 个百分点，验证了校准对动力学建模的必要性。

- 消融实验覆盖表征设计、Feature Calibration、TRB、AGRS 等模块，并分析表征中的动作相关结构。

- 真机实验进一步验证了该设计的有效性，表明基于预训练感知先验、由控制需求塑造表征的路径可行，无需依赖生成式视频预训练。
