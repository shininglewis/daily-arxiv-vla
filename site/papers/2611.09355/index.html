Card 03 核心贡献

核心贡献

  • 提出受海马体-新皮层互补机制启发的元语义记忆巩固方法：通过跨场景统计分析，把环境条件、物体特性、操作策略及其执行成功概率压缩为紧凑的语义知识，提升经验跨任务迁移性。
  • 提出语义条件化情节记忆剪枝机制（SCDP）：在对应语义记忆建立后，删除内容高度相似、已被覆盖的冗余情节记忆，提高长期记忆的存储效率与有效容量。
  • 提出任务条件化的记忆组合与利用机制：依据当前场景与操作物体特性，联合使用不同抽象层级的情节记忆与元语义记忆，通过逐步任务规划为动作生成提供引导，支持新任务组合下的经验复用。
  • 在原有层级化双曲情节记忆框架（会议版 ECHO，NeurIPS 2026）基础上扩展为期刊版本，系统性地新增语义巩固、情节剪枝与联合记忆利用三项能力。
  • 在 LIBERO、LIBERO-Plus 与真实机器人平台上验证了方法在多种 VLA 主干上的通用性与鲁棒性。
Card 04 方法描述

方法描述

  • 情节记忆构建与组织：用 Qwen2-VL-7B-Instruct 提出任务分解与子目标边界；每条记忆表示为 \(M_i=(z_i, g_i^{task}, s_i, a_i, c_i, y_i, e_i)\)，包含双曲嵌入、全局任务、局部子目标、动作、场景条件、执行结果与证据；用双曲自编码器把主干隐状态映射到 Lorentz 空间（512 维），配合特征重构与任务-子目标蕴含约束，形成“从一般到具体”的层级树。
  • 跨情节元语义巩固：离线选取跨分支、条件或结果不同的相关操作，由 VLM 提出条件 \(C_j\) 与操作 \(A_j\)，形成规则 \(R_j=(C_j,A_j,\hat{P}_j)\)；用 Beta 先验（\(a_0=b_0=1\)）统计验证过的成功/失败计数得到 \(\hat{P}_j\)，相同规则合并、冲突与未定结果暂缓。
  • 语义条件化多样性保持剪枝（SCDP）：按条件签名 \(b_i=\mathrm{sig}(c_i,a_i,y_i)\) 分组，用最远优先遍历在 Lorentz 空间中选取代表性子集，最小化最大覆盖距离；保护集包含独特失败、条件边界等不可替代证据；仅当记录被规则覆盖、存在同签名近邻且对所有关联规则均可舍弃时才删除，并保留 provenance 账本。
  • 层级检索与语义调制：查询 \(q_t=E_\phi(h_t)\) 以束宽 \(k=3\) 由粗到细遍历包含锥，按 Lorentz 距离/相似度排序；规则匹配确定系数 \(u_i\) 与门控 \(g_i\)（低成功率且样本充足时置零以阻断风险操作）。
  • 几何记忆组合：沿 Lorentz 测地线在相容的成功记忆间插值 \(z_{syn}=\mathrm{Exp}_{z_i}(\rho\,\mathrm{Log}_{z_i}(z_j))\)，合成向量继承保守系数 \(g_s=\min(g_i,g_j)\)，仅用于当前推理，不写入树或规则计数。
  • 记忆融合与策略注入：softmax 加权后投影回 Lorentz 流形得到 \(z_{mem}^{sem,+}\)，与短期状态融合解码为残差 \(\Delta_t\)，按 \(\alpha_t=\alpha_0\beta_t g_{risk,t}\)（\(\alpha_0=0.03\)）缩放并注入动作生成通路（如 \(\pi_0\) 的 Action Expert 后缀 token）。

Card 06 评估与结果

评估与结果

  • 评估协议：LIBERO 每个任务 50 条 episode、种子 7/123/2024；记忆构建、验证与测试使用互不重叠的执行轨迹；每组配对共享检查点、初始状态、种子与动作时域；仿真记忆由每任务 10 条成功示范初始化，失败证据与评估集不相交。
  • 主要指标：各套件成功率与四套件平均成功率（LIBERO Avg.）、LIBERO-Plus 成功率、真实机器人基础/组合任务平均成功率。
  • LIBERO 平均成功率：\(\pi_0\) 从 91.88% → 98.20%（+6.32），\(\pi_{0.5}\) 从 95.05% → 98.70%（+3.65），OpenVLA-OFT 从 96.80% → 98.95%（+2.15）。
  • 相对 ECHO 的增益：三个主干分别再提升 0.90 / 1.17 / 0.57 个百分点。
  • LIBERO-Plus（零样本）：\(\pi_0\) 54.2 → 59.6，\(\pi_{0.5}\) 85.7 → 95.8，OpenVLA-OFT 69.6 → 74.2。
  • 真实机器人：基础任务平均 58.3%（backbone）→ 70.0%（ECHO）→ 78.3%（HiMEM）；组合任务平均 37.0% → 47.0% → 61.0%。
