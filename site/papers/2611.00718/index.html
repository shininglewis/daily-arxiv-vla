Card 03 核心贡献

核心贡献

  • 识别出 VLA 自动驾驶中的“过度思考”是关键挑战，并首次探索从比较性任务结果（而非场景难度标注）中学习显式路由偏好。
  • 提出 STEER 框架，包含 route-balanced SFT（保持双路径能力）、routing uncertainty-aware rollout（采样多样性与模型不确定性对齐）、cross-route advantage credit assignment（基于环境奖励强化最优路由决策）。
  • 在 NAVSIM v1/v2 上取得与 SOTA 竞争力相当的结果，同时提升规划质量、路由质量，并推动推理效率的 Pareto 前沿，优于固定路由与既有自适应推理方案。
Card 04 方法描述

方法描述

  • 问题建模：将首个生成 token 建模为离散路由决策 R ∈ {reason, direct}，响应分布分解为 p(y\|x) = p(R\|x)·p(y\|x,R)；推理路径使用 …，直答路径仅输出 …。
  • 三阶段训练流程：(1) driving-centric 预训练做领域适配；(2) route-balanced SFT；(3) route-aware policy optimization。
  • Route-balanced SFT（创新点 1）：对同一 prompt 同时提供推理与直答两个目标，损失包含 routing calibration（将初始路由分布正则到均匀分布，λ/2 系数）与 length normalization（按各路径长度归一化），避免模型因直答序列更短而提前坍缩到直答路径。
  • Routing uncertainty-aware rollout（创新点 2）：用二值熵 H(x) 与少数路径概率 p_min(x) 判断路由不确定性，动态选择 Mode A（各 n/2 强制推理与直答）、Mode B（各 n/4 强制 + n/2 标准 on-policy）、Mode C（全部标准 on-policy），实现“反事实”对比探索。
  • Cross-route advantage credit assignment（创新点 3）：定义 A_i^route，用实现路径的奖励减去另一条路径的组均值奖励（而非整体组均值），并给出期望更新分析 E[∂_z log π·A^route] = [q_r(1−p)+q_d p]·Δ，证明其能提升高期望奖励路径的概率。
  • 优化目标：L = L_content + λ_r·L_route + β_KL·L_KL，其中内容项与路由项均采用 GRPO 风格的 clip 代理目标，路由项仅作用于初始路由位置。
Card 05 数据集与资源

数据集与资源

  • 评测基准：NAVSIM v1 与 NAVSIM v2 官方仿真器（navtest 划分）；SFT 与 RL 训练数据均基于官方 navtrain 划分构建。
  • 预训练数据：ReCogDrive、LingoQA、NuScenes-QA、DriveLM、OmniDrive 等公开驾驶推理数据集。

  • 训练资源：64 张 NVIDIA H20 GPU，全部阶段采用全参数微调，基于 DeepSpeed ZeRO-3 实现。
Card 06 评估与结果

评估与结果

  • 评估设置：NAVSIM v1 使用 PDMS（聚合 NC、DAC、EP、TTC、C 等子指标）；NAVSIM v2 使用 EPDMS（新增 DDC、TLC、LK、HC、EC）；路由质量用 RouteAcc、AUC、AvgRegret（相对 oracle route）评估，另报告平均响应 token 数衡量效率。
  • NAVSIM v1：91.2 PDMS，优于依赖场景难度标签的 AdaThinkDrive（90.3），并在数值上略超 planner-assisted 的 SGDrive（91.1）；Best-of-N 评估下达到 93.4 PDMS。
  • NAVSIM v2：87.2 EPDMS 为最优，较 SGDrive（86.2）提升 1.0 点，同时取得最佳 DAC 97.6 与 EP 95.6。
  • 自适应路由 vs 固定路由：RL 后自适应策略 PDMS 91.2，优于强制直答（89.9）与强制推理（90.8）；强制推理平均 415 token，自适应仅 315 token，验证“过度思考”既费算力又损性能。
  • 消融（route-aware policy optimization）：两个组件同时启用时最佳——RouteAcc 81.1%、AUC 79.1%、AvgRegret 0.018、平均响应 315 token、PDMS 91.2；单独使用任一组件均明显退化。
  • 消融（route-balanced SFT）：同时加入长度归一化与路由校准后，推理/直答概率为 49.1% / 50.9%，接近平衡，显著缓解直答偏置。
  • 消融（训练流程）：无预训练且无 RL 为 85.9 PDMS，仅预训练为 86.5 PDMS，完整流程进一步提升。
