论文概述

  • 论文针对 GRPO 在视觉-语言-动作（VLA）策略强化学习中的样本效率问题：在二元成功奖励下，同场景采样的 rollouts 若全部成功或全部失败，组内优势为零，会被动态采样丢弃，造成大量昂贵的机器人 rollout 预算浪费

Card 03 核心贡献

核心贡献

  • 提出 Prism-GRPO 算法，将二元任务成功奖励与有界的轨迹质量评分结合，恢复同结果组中的训练信号
  • 证明了组合奖励的样本效率不低于二元奖励（Theorem 1），即 Prism-GRPO 不会增加获得有效组所需的期望 rollout 数；在连续质量评分下，每个组都能成为有效组
  • 推导出梯度对齐条件（Proposition 1）并证明组合梯度的有效性（Proposition 2）：当成功与质量的梯度对齐时，组合更新对成功目标仍是一阶上升方向
  • 在 RoboTwin 2.0 的四个任务上，Prism-GRPO 在匹配的 rollout 预算下同时提升成功率和执行质量，达到目标成功率最高可节省 56% 的 rollouts
  • 质量信号可来自模拟器接触、执行动作或视觉观察（VLM），避免任务特定的过程奖励设计，并验证了多种质量源的泛化性
Card 04 方法描述

方法描述

  • 采用组合奖励：R_combined(τ) = success(τ) + λ·q(τ)，其中 0 < λ < 1，保证成功主导性（success dominance），仅在同结果类内按质量排序
  • 使用 RLOO（leave-one-out） 优势估计器而非标准 GRPO 的组标准化，以保留同结果组中质量差异的原始尺度
  • 动态采样策略：丢弃 reward 完全相同的组并重新采样；连续质量评分使得同结果组不再退化
  • 理论分析表明，任务级质量-成功相关性（含场景间协方差）在有退化组时仍然提供信息，梯度对齐条件与策略集中度（条件数 κπ）相关
  • 默认质量信号为 GT-Max Force（最大非目标物体受力），并支持碰撞计数、VLM 判断、平滑度（flips/jerk）等多种替代信号
Card 05 数据集与资源

数据集与资源

  • RoboTwin 2.0 基准：双臂操纵benchmark，含域随机化（clutter、光照、背景、桌高、语言指令）
  • 四个评估任务：Lift Pot、Move Can Pot、Handover Block、Beat Block Hammer（覆盖单臂/双臂，短/长时域）
  • 组大小 G=8，每更新 512 条 rollouts，默认 λ=0.2，5 个随机种子
  • 参照 SimpleVLA-RL 的配置：clip-higher、温度采样、无 KL 惩罚
  • 硬件与训练资源详见附录 F；质量计算开销极小（模拟器信号增加 0.04% 墙钟时间，VLM 信号增加 4.8%）
Card 06 评估与结果

评估与结果

  • 对比基线：Binary GRPO（SimpleVLA-RL）、Binary RLOO、Random quality、RL-ZVP
  • 评估指标：成功率（raw success）、校准成功率（按非目标接触次数折扣）、Max-Force Quality、Sum-Impulse Quality
  • 在四个任务上，Prism-GRPO 相比 Binary GRPO 节省 22%–56% 的 rollouts，同时提升执行质量；最大增益出现在 Lift Pot（早期丢弃率从 70% 降至约 0%）
  • Move Can Pot 上发现 "shove-cheat" 奖励黑客行为：RL-ZVP 的作弊率范围为 0.6%–20%，Binary GRPO 为 0.7%–7%，而 Prism-GRPO 仅 0.6%–1.3%
  • λ 消融显示在有意义的（非随机）质量信号下，λ=0.2–0.9 均稳定达到目标并节省 41%–56% rollouts；随机质量虽能早期提升成功率但效益不稳定
  • 质量源消融（Lift Pot）：接触类信号节省 38%–56% rollouts，平滑度类信号节省 25%–44% rollouts，均改善对应质量指标
  • 真实机器人部署（Piper，每方法 25 次试验）：Prism-GRPO 的清洁行为在sim-to-real 直接部署中更可靠，抑制了 RL-ZVP 的 shove-cheat 行为
