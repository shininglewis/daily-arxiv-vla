Card 03 核心贡献

核心贡献

  • 提出 GAWM，一种 JEPA 风格的紧凑世界-动作模型：由任务条件化（而非动作条件化）的预测器预测冻结编码器的潜在 token，再由动作解码器从预测结果直接回归动作块，无需在测试时搜索候选动作。
  • 证明在不依赖 VLM 和视频生成器的情况下，参数少于 100M 的多任务策略在 RoboTwin 2.0 上超过十亿参数级 WAMs，并在真实双臂机器人上比微调后的十亿参数 VLA 预测更准、延迟更低。
  • 通过消融表明，世界模型在训练数据或训练时间受限时能带来显著性能提升。
  • 分析表明预测结果编码了未来场景的空间布局（几何感知），且动作解码器会按时间顺序关注预测结果。
Card 04 方法描述

方法描述

  • 视觉编码：使用冻结的 DINOv3 ViT-S/16 编码器，融合第 7、9、11 层 patch 特征（层归一化 + 拼接 + 线性投影），再用带 64 个可学习 query 的适配器将每个相机视角压缩为 64 个 token（双相机共 128 个），并加入相机嵌入。
  • 任务条件化潜在预测器：轻量 Transformer 预测器（4–6M 参数）以任务码 g_k（沿用 LiLa-WAM 的视觉转移 token）为条件，并行预测两个未来时间步（h1 = H/2、h2 = H）的 token，采用零初始化输出投影的残差更新形式，初始预测为静态场景。
  • 预测监督：训练时用 patch 解码器将预测 token 映射到冻结编码器对未来帧的稠密 patch 特征，采用余弦相似度损失；稠密目标迫使预测编码夹爪与物体的未来位置，从而获得几何感知，且目标来自冻结编码器不会坍缩，无需 SIGReg 等正则化。
  • 动作解码器：采用 ACT 风格的 Transformer 解码器 + MLP，从当前 token、两个预测、机器人状态 token 和任务码构成的内存中回归整段动作块，使用 ℓ1 损失确定性回归（无扩散/流匹配迭代采样）。
  • 训练目标：L_act + λ_fut·L_fut + λ_cur·L_cur + λ_reg·(L_div + L_var) + λ_tmp·L_tmp，除编码器外所有模块从零联合训练；推理时丢弃 patch 解码器。
Card 05 数据集与资源

数据集与资源

  • LIBERO：包含 Spatial、Object、Goal、Long 四个任务套件共 40 个任务，单策略训练全部任务；*Standard* 设置为 1,693 条演示，*Extended* 设置扩充至 6,585 条轨迹（1.03M 帧），每条任务评测 50 个初始状态（2,000 回合）。
  • RoboTwin 2.0：Aloha-AgileX 平台上的 50 个双臂任务，混合协议下每任务 50 条干净 + 500 条域随机化演示，采用 LiLa-WAM 的数据发布（27,071 条演示），头/前相机 320×240，14 维绝对关节目标，每设置每任务 100 回合（共 5,000 回合）。
  • 模型规模：GAWM-S 在 LIBERO 上 38M 参数、在 RoboTwin 2.0 上 77M 参数（含冻结的 21.6M DINOv3 ViT-S/16）。
  • 训练资源：LIBERO 使用 8 块 GPU、80k 步、batch size 160；RoboTwin 2.0 使用 32 块 GPU、765k 步、batch size 128；GPU 型号为 NVIDIA RTX PRO 5000，优化器为 AdamW，学习率 2×10⁻⁴，两阶段余弦调度。
Card 06 评估与结果

评估与结果

  • 评估基准：在仿真基准 LIBERO 与 RoboTwin 2.0（clean 与 randomized 两种设置）上与已发表的 VLA、WAM 及紧凑策略对比，并在真实双臂机器人的留出演示上评测，指标为成功率（Wilson 95% 置信区间）与动作预测误差/推理延迟。
  • 主要结果：GAWM-S 在 RoboTwin 2.0 上取得 93.94%（clean）与 93.10%（randomized）成功率，是图中最小且表现最好的方法，超过 Fast-WAM（11.9B）、LingBot-VA（10.9B）、LaWAM（2.1B）、Motus（13.9B） 等十亿参数级 WAM。
  • 在 LIBERO 上以 38M 参数达到 95.6% 平均成功率，高于 3.2B 的 π0（94.2%）与 4.5B 的 StarVLA Qwen3-OFT（96.6% 对比下仍具竞争力），整体接近十亿参数 VLA 水平。
  • 真机结果：在双臂机器人留出演示上，动作预测误差低于微调后的十亿参数 VLA，且推理延迟显著更低。
  • 消融：去掉世界模型（仅保留编码器、适配器、动作解码器与任务码的 ACT 式策略）后对比三种受限场景（LIBERO 仅用 1/4 数据、LIBERO Extended 数据、RoboTwin 缩短至 191k 步训练），结果表明世界模型在数据或训练时间受限时收益尤为明显，且预测确实编码了未来空间布局。
