论文概述

Card 03 核心贡献

核心贡献

  • 提出首个用于协调全身移动操作的第一视角人到人形机器人技能迁移框架。
  • 设计粗到细动作对齐（coarse-to-fine action alignment），结合运动学参考校正（K）与动力学感知精化（D），在提升末端执行器精度的同时保持全身协调。
  • 提出视觉对齐方法：机器人手臂渲染（robot-arm rendering）+ 训练时图像增强，缩小视觉具身差距并提升视角鲁棒性。
  • 在四个真实世界任务上验证零样本技能迁移，并分析精度、策略得分与数据采集成本。
  • 证明人类数据可作为直接技能监督，性能接近遥操作数据且采集成本更低。
Card 04 方法描述

方法描述

  • 人类示范采集：颈部安装 GoPro 获取第一视角 RGB，PICO 系统捕捉身体运动与手部姿态，50 Hz 同步。
  • 机器人部署：Unitree G1 人形机器人 + BrainCo Revo2 灵巧手，头部安装 GoPro，相机高度与人类相近以减少视角差距。
  • 策略学习：基于 π0.5 的 VLA 策略，输入为图像、43 维 G1 状态与语言指令，输出为 64 维 SONIC 运动 token 与 6 维手部命令。
  • 动作对齐三阶段：运动初始化 H（SONIC 仿真 rollout）→ 运动学参考校正 K（约束离线 IK 对齐末端目标）→ 动力学感知精化 D（MLP 响应模型 + 迭代 rollout 反馈）。
  • 动力学感知精化：用成对的扰动/未扰动 rollout 训练响应模型 R_ψ，通过控制解码器梯度优化运动 token 以补偿末端残差。
  • 视觉对齐：SAM2 分割人类前臂与腕部 PICO 追踪器，DiffuEraser 修复背景，再渲染 G1 手臂并合成；训练时使用随机缩放裁剪、小旋转与光度抖动。
  • 关键创新：离线修正参考与执行，控制器 SONIC 在所有任务间保持固定，无需任务特定训练或微调。
Card 05 数据集与资源

数据集与资源

  • 采集系统：人类端为 GoPro + PICO，机器人端为 Unitree G1 + BrainCo Revo2 手。
  • 每个任务使用 200 个人类示范；数据预算消融比较 25、50、100、200 条示范。
  • 四个真实世界任务：Close Laptop、Open Fridge、Pull Curtain、Close Drawer。
  • 策略训练：每个任务独立后训练 π0.5 策略 30,000 步，batch size 为 256，共享同一预训练 checkpoint。
  • 动作对齐控制器：固定 SONIC checkpoint，运动 token 维度 64，手部命令维度 6。
  • 仿真补充实验：50 个任务、112 条轨迹用于动作对齐分析；离线评估使用每任务 25 条训练轨迹子集。
Card 06 评估与结果

评估与结果

  • 评估环境：真实 Unitree G1 人形机器人；每个策略 20 次真实试验，每试验含 3 个顺序子任务，按成功/失败评分。
  • 主要指标：任务得分（%）、末端位置误差（cm）、方向误差（°）、全身运动质量（骨盆下沉、倾角、关节步长、额外偏航）与采集人力（人秒）。
  • 技能迁移（Q1）：200 个人类示范下四任务平均得分 51.67%（范围 38.33%–61.67%），25→200 条示范使均值从 38.33% 提升至 51.67%。
  • 人类 vs 机器人数据（Q2）：人类数据采集每示范平均减少 76.36% 人力（140.85 → 33.30 人秒），得分接近遥操作数据策略。
  • 动作对齐（Q3）：平均位置误差从 11.21 cm（H） 降至 4.45 cm（H+K） 与 3.41 cm（H+K+D_s）；方向误差从 21.22° 降至 13.77° 与 6.71°；策略均分从 21.25% 升至 47.08% 与 51.67%。
  • 在线 IK 对照：三种实现在四个任务上均产生不稳定 SONIC rollout（含跌倒），故未用于策略评估。
  • 视觉对齐（Q4）：三个手臂任务中，渲染、增强及二者组合得分分别为 38.89%、42.78%、48.33%，效果互补但任务相关。
  • 扩展验证：50 任务仿真中位置误差同样呈 17.03 → 5.22 → 3.83 cm 的阶段性下降；MLP 响应模型优于单位响应模型。
