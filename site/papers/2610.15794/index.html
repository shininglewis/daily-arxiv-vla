Card 02 论文概述

论文概述

  • 论文提出 Δ-flow matching（Δ-flow），一种面向机器人基础模型（Robot Foundation Models）的生成式建模新范式，核心思想是把"近期历史"而非固定高斯先验作为流的源分布，只学习历史到未来的残差变化 Δ。
  • 现有方法（VLA 与 WAM）均从纯高斯噪声出发生成动作块或未来视觉状态，导致训练收敛慢、部署时需要大量迭代采样（NFE），WAM 还面临视觉分支的额外开销。
  • 论文目标是在不修改网络架构、不增加数据的前提下，同时提升训练效率、推理速度、动作平滑性与分布偏移下的泛化能力。
Card 03 核心贡献

核心贡献

  • 提出 Δ-flow：以带轻微高斯扰动的历史表示（历史动作、历史视觉表征）构造源的统一"过去到未来"生成框架，将传输路径缩短为可高效学习的残差。
  • 将 Δ-flow 统一实例化到三类策略中：VLA 策略 π₀.₅（仅动作分支）以及 WAM 策略 ImageWAM、Fast-WAM（视觉与动作双分支联合建模）。
  • 设计 endpoint consistency（端点一致性）损失，直接监督单步欧拉更新结果，使推理只需 1 次函数评估（1-step inference）。
  • 证明 动作历史源可免训练（training-free）迁移到已训练的 WAM 策略：仅替换推理时的动作源初始化即可保持甚至略微提升成功率，无需重新训练。
  • 给出一系列反直觉的经验性研究：动作空间参数化、未来帧密度、动作损失梯度是否回传世界模型、动作表示选择等设计决策的影响。
Card 04 方法描述

方法描述

  • 源构造：对模态 m∈{a,v}，源为 s_m = α_m·h_m + σ_m·b_m⊙ε_m，其中 h_a 为最近执行的动作历史，h_v 为当前观测的潜在表征，ε_m 为高斯噪声。动作分支取 α_a=1、σ_a=0.5，噪声掩码排除夹爪与填充维度。
  • 插值与训练目标：y_m^τ = (1-τ)y_m + τ·s_m，网络拟合速度场 (s_m − y_m)，损失为 L_FM^m（式4）。
  • 端点一致性损失：以一次欧拉更新 ŷ_m = s_m − f_θm(s_m,1,c) 逼近真值，L_EC^m = E‖ŷ_m − y_m‖₁（式5）。
  • WAM 中的双分支耦合：视觉分支提供当前与未来视觉 token 的中间表示给动作专家，并在该连接处施加 stop-gradient，使动作损失梯度不更新世界模型（式8）；总损失 L_WAM = λ_v(L_FM^v + λ_EC^v L_EC^v) + λ_a(L_FM^a + λ_EC^a L_EC^a)。
  • 关键技术点：与既有 A2A flow matching 相比，Δ-flow 直接在动作空间操作（无需额外编码器/解码器）、可推广到视觉模态、并在机器人基础模型规模上验证。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO（Spatial、Object、Goal、Long 四个子任务套件）用于训练与主评估；LIBERO-Plus 用于分布偏移泛化评估，涵盖 7 类扰动（相机视角、机器人初始化、语言指令、光照、背景纹理、传感器噪声、物体布局），无需额外微调。
  • 模型骨干：

- ImageWAM：FLUX.2-klein-base-4B 图像编辑骨干 + 动作 DiT，视觉目标为未来第 16 帧图像的编码潜在。

- Fast-WAM：Wan2.2-TI2V-5B 视频骨干 + 动作 DiT，采用 Sparse8 稀疏联合配置（4 帧，时间步长 r=8，32 步时域），动作历史长度 32。

- π₀.₅：PaliGemma 视觉语言骨干 + Gemma 动作专家（采用 LoRA 与全参数微调两种设置）。

  • 训练资源：原文摘要与已提供正文未明确列出 GPU/TPU 具体型号与数量（细节置于附录 A）。
Card 06 评估与结果

评估与结果

  • 评估问题：(1) 训练收敛是否更快；(2) 分布偏移下泛化是否更好；(3) 推理延迟是否降低且动作仍连续；(4) 动作历史源可否免训练用于已训练策略。
  • 主要指标：LIBERO / LIBERO-Plus 各套件与总体的任务成功率（%）、训练轮次（epoch）至阈值所需时间、推理延迟加速比、动作jerk（抖动）、未来图像 PSNR。
  • 训练效率结果：

- ImageWAM：1 个 epoch 达 91.30%（原模型 24.60%），增益 66.70 个百分点；首次超过 90% 由第 6 个 epoch 提前到第 1 个 epoch（6× 训练轮次缩减）。

- Fast-WAM：1 个 epoch 达 72.60%（高斯稀疏联合基线 42.55%），2 个 epoch 达 95.65%（基线需 8 个 epoch，4× 缩减）。

- π₀.₅ + LoRA：1 个 epoch 达 92.20%，已超过十步基线五轮后的 91.30%（5× 缩减）；全参数微调下两个 epoch 即 ≥95%，峰值 99.30%。

  • 精度结果：π₀.₅ (Δ-flow) 在 LIBERO 总体达 99.00%（Spatial 99.60 / Object 100.00 / Goal 99.60 / Long 96.80），优于原 π₀.₅ 的 97.10%；ImageWAM (Δ-flow) 总体 97.80%，Fast-WAM-joint (Δ-flow) 优于同等设置下的高斯基线 97.45%。
  • 推理效率：单步推理分别带来 1.54×（π₀.₅）、2.49×（ImageWAM）、4.45×（Fast-WAM） 加速；单步下动作 jerk 相比一步高斯采样降低 4.5×，平滑度接近十步高斯采样。
  • 泛化与免训练适配：Δ-flow 在 LIBERO-Plus 上取得 88.55% 的七类扰动平均成功率，达到 SOTA 水平；用最近执行动作替换高斯动作源后，预训练 ImageWAM/Fast-WAM 无需重训练即可单步采样，成功率基本保持甚至略有提升。
  • 设计洞察：动作空间参数化在标准 LIBERO 上差异很小，但在 LIBERO-Plus 上可造成 >14 个百分点差异；在相同时域下预测更少的未来帧可带来 +5.19 点增益；stop-gradient 同时提升未来图像 PSNR 与 LIBERO-Plus 成功率；在源为历史且保留视觉监督时，仅监督一步端点即可接近完整流匹配目标（但收敛更慢）。
