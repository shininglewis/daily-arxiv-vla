Card 03 核心贡献

核心贡献

  • 提出可检查的更新准入契约：候选策略必须证明当前任务增益至少 η，同时历史任务性能下降不超过 ε_j，且在固定预算内完成检查。
  • 识别并量化基于范围的 Hoeffding 门在旧任务零分歧检查中的预算爆炸问题：示例中每项比较需 4,229 配对样本，总预算超过 20,000 回合上限。
  • 采用成对二项（Clopper–Pearson）区间构造准入规则，在零分歧时仅需约 117 配对样本，显著降低旧任务保留检查负担。
  • 指定 certified 历史参考提升机制：仅当现有下界 L_j ≥ 0 时晋升旧参考，保证在覆盖事件上参考性能非降，并限制活跃参考集大小。
  • 提出轮级错过机会指标：仅有可行候选但未采纳时计为错过机会，避免将正常候选选择误报为错误；同时报告覆盖率、合同违反、遗忘和资源成本。
Card 04 方法描述

方法描述

  • 持续策略学习设定：任务条件策略 π_θ 参数跨任务批次保留，允许有限演示回放和历史参考；每次尝试需在提交后使用新环境配对样本进行准入检查。
  • 合同定义：对每个保护任务 j，定义真实配对差异 g_j = E[S(π') - S(b_j)]，要求当前任务增益至少 η，旧任务下降不超过 ε_j。
  • 准入规则：对配对二项差异 X ∈ {-1,0,1} 分别构造正负差异的 Clopper–Pearson 区间，得到 L_j = ℓ_+ - u_- 和 U_j = u_+ - ℓ_-；所有 L_j ≥ q_j 则接受，任一 U_j < q_j 则拒绝，否则推迟。
  • 错误分配：每次尝试非覆盖概率 α_t = 6δ/(π²t²)，每个端点分配 β = α_t/(4m)，通过并集界限使整体失败概率不超过 δ。
  • 历史参考提升：接受候选后，仅当旧参考的同一有效区间满足 L_j ≥ 0 时替换参考，确保覆盖事件上参考序列非降；参考集容量为 10 个任务。
  • 机会审计：在流结束后对全部候选进行穷举评估，精确标注合同满足情况，不将审计标签用于训练或选择。
Card 05 数据集与资源

数据集与资源

  • 所有实验均为合成模拟，无物理机器人、无 LIBERO 运行、无预训练 VLA、无人类参与者。
  • 环境为构造的一步推动诊断：10 个移动任务顺序到达，2 个初始化策略，8 个更新；每个任务有 4,096 个重置的审计库。
  • 动作模型：a = clip[(θ_shared + θ_j)d, 0, 3]，终端位移 g_j(1+z)a，成功定义为绝对目标误差 ≤ 0.06。
  • 候选生成：每任务 4 个候选，包括两个当前任务 ridge 拟合、一个回放拟合、一个任务局部拟合；线性动力学代理由 32 个独立模拟探测拟合。
  • 资源：候选为小型 ridge 求解或局部拟合，无 GPU 使用，CPU 环境完整评估 50.9 秒，含 1,536 个种子/预算/方法/视图设置和 12,288 次决策。
  • 评估种子：32 个固定评估种子，4 个试点种子；预算 B ∈ {200, 2000, 20000}；每项比较样本数 n = ⌊B/(2m)⌋。
Card 06 评估与结果

评估与结果

  • 评估环境：共同候选流用于隔离准入规则，闭环运行允许决策改变后续提议；每个任务事后在 4,096 重置有限总体上穷举审计。
  • 主要指标：采纳率（coverage）、合同违反率、保留违反率、错过机会率、最终成功率、遗忘（百分点）。
  • 共同流结果：成对门在 B=2000 采纳 81/256（31.6%），在 B=20000 采纳 229/256，无观察到的合同违反；Hoeffding 门在所有预算下采纳 0；经验 Bernstein 在 B=2000 采纳 0，B=20000 采纳 195/256；所有三种门在 B=200 全部推迟。
  • 闭环结果（B=2000，32 种子）：成对门采纳率 37.1%，错过机会 60.4%，最终成功率 59.6%，遗忘 0；回放更新最终成功率 100%，合同违反 5.9%（均为当前任务增益不足，非保留损失）；直接微调遗忘 79.9 个百分点。
  • 动力学压力测试：线性代理拟合低动作转移后，自适应搜索在曲率 c=0.35、256 次查询时，代理成功率高估真实成功率 40.8/41.9 个百分点（复用/新鲜代理抽样）；c=0 时差距仅 0.15/0.32 个百分点，表明新鲜代理反馈不能消除选择乐观。
  • 主要结论与局限：标准区间选择改变有效更新机会的存活，但结果仅为合成诊断，不支持资源最优或优于回放的实践主张；物理机器人、VLA 和 LIBERO 迁移验证尚未完成。
