论文概述

  • 面向视频优先的世界动作模型（World Action Model, WAM）提出了一种部署一致的on-policy 蒸馏（OPD）后训练方法，旨在修复加速学生模型（如 Flash-WAM）在蒸馏后丢失的任务能力。

Card 03 核心贡献

核心贡献

  • 识别出视频优先 WAM 在 on-policy 蒸馏中特有的条件不匹配问题：部署时动作生成消费的是学生自生成的视频计划，而不是教师的视频计划。
  • 定义了联合视频–动作损失（pseudo-Huber 端点回归）加上动作流匹配（flow-matching）正则项的目标函数，并明确将其与精确 reverse-KL 和全路径 transition matching 划清界限。
  • 提出了参数高效的 JointLoRA 更新方案（rank-8，覆盖全部 30 个共享 Transformer 块），使视频与动作两条路径共享的可训练范围与部署时的共享计算一致。
  • 提供了精确配对（exact-paired）的 RoboTwin 评估：在六个 held-out 场景种子、两个固定噪声银行下，同一配方在两个任务上均提升了成功率。
Card 04 方法描述

方法描述

  • 部署一致的蒸馏流程：学生模型在环境中闭环行动并决定历史分布；冻结的教师（LingBot-VA）为这些学生历史生成一致的视频目标 z_T 和动作目标 a_T。
  • 训练时学生严格遵循部署计算图：先由视频分支生成计划 z_S，再在 sg(z_S)（stop-gradient）条件下由动作分支预测 a_S，使训练与部署的条件路径完全一致。
  • 联合目标函数：L = λ_z·ρ_δ(z_S−z_T) + λ_a·ρ_δ(a_S−a_T) + λ_FM·\|\|v_θ^act(x^a_{σ=1},1,c)−(ε_a−a_T)\|\|²，其中 ρ_δ 为伪 Huber 损失，权重设为 (1, 1, 0.2)。
  • 训练协议：固定轨迹包（release 学生收集、教师标注、三 epoch 复用），当前版本为单轮 post-training 能力验证，并预留了迭代刷新占用分布的扩展空间。
Card 05 数据集与资源

数据集与资源

  • 使用 RoboTwin 2.0 仿真环境的 demo_clean 任务：Handover Mic（双手传递麦克风）和 Put Object Cabinet（将物体放入柜子抽屉）。
  • 模型基于LingBot-VA / Flash-WAM 管线：共享 30 层 Transformer，视频与动作各自拥有独立的输入、时间和输出模块，采用流匹配（flow matching）生成。
  • 每个任务使用：8 条学生轨迹、160 个教师标记的 macro-step 上下文、4 条校准轨迹、120 个优化步骤（3 epochs，batch size 4）。
  • 优化配置：rank-8 JointLoRA 覆盖全部共享块，AdamW 优化器，学习率 2×10⁻⁵。
Card 06 评估与结果

评估与结果

  • 评估方式：每个任务 6 个 held-out 场景种子 × 2 个固定噪声银行 = 12 个精确配对单元，Released 与 WAM-OPD 共享指令、初始快照、场景种子和噪声银行；主指标为 RoboTwin 官方的 latched eval_success。
  • Handover Mic：Released 成功率 0.0% → WAM-OPD 58.3%（+58.3 个百分点）。
  • Put Object Cabinet：Released 成功率 16.7% → WAM-OPD 33.3%（+16.7 个百分点）。
  • 结果表明增益是任务相关的：同一配方在两个任务上都提升，但幅度差异显著；论文明确将当前成果定位为两任务纵向切片（capability proof），而非通用方法的最终结论。
