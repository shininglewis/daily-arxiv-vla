Card 03 核心贡献

核心贡献

  • 提出 Spa-Bench：包含六个桌面任务的真实机器人基准，覆盖 Object State、Relative Size、Referential Description、Relational Placement、Ordinal Position、Counting，并区分 ID 与 OOD 空间配置评测。
  • 设计受控评测协议：采用 withheld-cell（保留单元） 划分，并配合四种诊断条件，分别探查物理执行能力、措辞敏感性、物体—任务关联以及动作门控（是否应不动作）。
  • 评测了来自四种架构的五个微调 VLA 策略（VLA-0、MolmoAct2、π0.5、GR00T-N1.7 F-LLM、GR00T-N1.7 F-FT），并在 SO-101 机器人上发布 4,092 条 episode 数据。
  • 开源数据包含 1,200 条人类遥操作示范与 2,892 条真实机器人评测 rollout，以及任务规范、场景布局与视频。
Card 04 方法描述

方法描述

  • Withheld-cell 设计：将每个任务表示为"概念–参数矩阵"，行是空间概念（如 *upside-down*、*smallest*、*left of*），列是任务参数（物体身份、物体对、运动类型）；训练中出现的配对为 observed cells，保留用于 OOD 评测的配对为 withheld cells。
  • 关键约束：被保留单元中的概念、物体、物理动作都在训练中出现过（例如概念 *upside-down* 与条纹杯配对、白杯在直接指令下被操作，但"倒置的白杯"这一空间语言配对从未出现），从而排除物体与运动不熟悉作为失败解释。
  • 四种诊断条件：匹配场景下的直接操作指令（移除空间推理但保留相同动作）、prompt 复述（改写 OOD 空间与直接指令）、跨任务物体迁移（保持概念与动作、更换物体上下文）、无干预场景（正确行为是不动作）。
  • 任务设计：六个任务共用同一 SO-101 本体、工作空间、容器和"抓取—放置"动作族；方向与序数描述均以机器人自身视角定义；五个任务含 no-intervention 场景，Relative Size 因无唯一最小/最大物体而排除该条件。
  • 评分与统计：主结果为二值物理任务成功，无部分分；rollout 时限 60 秒（VLA-0 为 90 秒）；报告双侧 Wilson 95% 置信区间；匹配场景差异为描述性配对对比。
  • 部署细节：GR00T-N1.7 两个变体使用因果指数滑动平均动作滤波（α=0.25）抑制抖动；GR00T-N1.7 F-FT 额外施加固定微小上抬位移以脱离静止初始位姿。
Card 05 数据集与资源

数据集与资源

  • Spa-Bench 数据集：1,200 条人类遥操作示范（每任务 200 条），约 5.7 小时、612,733 帧；每条 episode 包含同步机器人状态、动作、自然语言指令与五路 RGB 相机视图（策略仅使用 middle 与 wrist 两路）。
  • 物体集合：27 个可移动物体实例，横跨 11 个形态家族；场景最多含 5 个候选物体。
  • 评测 rollout：三个完整评测策略各 900 次真实机器人 rollout，加上部分基线共 2,892 次评测 rollout。
  • 训练配置：全部策略训练 12 个 epoch，全局 batch size 96，使用 4× NVIDIA GH200 Grace Hopper Superchips；全局 batch 为 96，单卡 batch 为 24。
  • 数据变体：完整版 612,733 帧（MolmoAct2、π0.5、GR00T-N1.7 F-FT）；运动裁剪版 570,386 帧（GR00T-N1.7 F-LLM、VLA-0），移除 42,347 帧（6.91%）空转前缀。
  • 五种策略的动作预测视界 H 分别为：VLA-0 为 8，π0.5 为 50，MolmoAct2 为 30，GR00T-N1.7 两个变体为 16。
Card 06 评估与结果

评估与结果

  • 评估环境：真实 SO-101 机械臂，固定无窗房间、固定光照与相机位姿；对应 scene 在不同策略间手动复位到同一场景规范（物体身份与标称位置一致，但不保证像素级一致）。
  • 主要指标：二值任务成功率（含双侧 Wilson 95% CI），辅以匹配场景配对差值、失败模式分类与跨任务物体迁移的对比。
  • ID → OOD 下降：三个完整评测策略 ID 成功率 67.5%–73.3%，OOD 空间配置下降到 40.7%–52.0%（MolmoAct2 52.0%、GR00T-N1.7 F-LLM 44.3%、π0.5 40.7%）。
  • 匹配场景诊断：直接操作指令下成功率达 81.7%–89.2%，比 OOD 空间指令高 28.3–40.0 个百分点，说明许多物理动作本身可执行，失败源于空间接地而非运动能力。
  • Prompt 复述：60 个匹配场景上，空间指令复述后成功率一致下降（如 GR00T-N1.7 F-LLM 48.3%→38.3%，MolmoAct2 65.0%→50.0%），而直接指令的复述影响因模型而异，说明空间–直接性能差距对措辞稳健。
  • 跨任务物体迁移：五个可比任务上成功率由 64–70/100 降至 53–55/100，提示空间行为与训练时的物体–任务关联耦合。
  • 动作门控：四个无干预诊断的总体成功仅 20.0%–23.8%；当 *Counting* 目标已满足时达 80–85%，而 *Object State* 与 *Ordinal Position* 无效指令下为 0%；*Relational Placement* 中无需移动时成功 75–95%，但需要纠正时仅 5–15%，说明"静止"多为任务倾向而非真正识别目标状态。
  • 失败模式：OOD *Counting* 失败中 148/150 为不动作，*Ordinal Position* 中 74/79 为选错物体，*Object State* 中 75/77 为同类别错实例；*Relational Placement* 中 π0.5 与 MolmoAct2 的多数失败（32/39）发生在接近正确物体后空间结果错误。
  • 部分基线：GR00T-N1.7 F-FT 仅完成 120 次 ID rollout（25/120），VLA-0 完成 72 次（0/72），因 ID 表现不足，仅作为诊断性 ID 基线，未参与 OOD 分析。
