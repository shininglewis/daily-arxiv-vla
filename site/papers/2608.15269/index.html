Card 02 论文概述

论文概述

  • 论文提出 Remember Smarter (RS)，一个即插即用的记忆模块，用于增强视觉-语言-动作（VLA）模型在长时程机器人操作任务中的记忆能力。
  • RS 包含两个互补分支：细粒度视觉历史压缩（基于 Mamba 的状态空间模型）和粗粒度双曲经验记忆（基于 Poincaré VAE 的层次化经验检索）。

Card 03 核心贡献

核心贡献

  • 提出 Remember Smarter (RS) 即插即用记忆架构，在不修改 VLA 主干的前提下，以互补的在线视觉历史记忆与层次化经验记忆增强策略，适应 π₀ 等 VLA backbone。
  • 引入基于双向空间 Mamba 与因果时序 Mamba 的在线视觉历史压缩器，训练时采用状态传递的截断时间反向传播（TBPTT），推理时以固定形状循环状态进行因果流式更新。
  • 构建层次化双曲经验空间：结合 P-VAE 检索坐标、HypHC 启发的二叉树构建、entailment-cone 路由以及测地线经验 token 生成，实现异步非阻塞检索。
  • 通过残差交叉注意力适配器让行动预测隐状态读取压缩视觉记忆，同时保持 VLM 视觉 token 流不变，最小化对原有模型的干扰。
Card 04 方法描述

方法描述

  • 视觉历史压缩：复用 VLA 视觉编码器提取多视角 patch 特征，经轻量适配器映射到统一维度；每个视角用双向空间 Mamba 以蛇形扫描编码帧内空间结构，再用学习查询池化到帧级表示；随后用两层因果时序 Mamba 按时间顺序聚合，得到紧凑的多视角历史记忆张量。
  • 残差交叉注意力：以视觉历史记忆作为键/值，行动预测隐状态作为查询，进行多head缩放点积注意力，残差缩放系数 γ=0.05，增强后的表示送入原有行动头。
  • 双曲经验记忆：收集成功演示的最终层 VLM 隐状态，用 P-VAE 映射到 Poincaré ball 作为检索叶子；用 HypHC 启发的三元组目标解码出二叉层次拓扑，内部原型用 Karcher 均值初始化；推理时非阻塞 beam search 检索至多 8 个叶子，取最低公共祖先原型，沿测地线采样 4 个 token 作为提示注入 VLM 输入。
Card 05 数据集与资源

数据集与资源

  • 仿真评估：LIBERO 四个标准套件（Spatial, Object, Goal, Long）与 LIBERO-Plus 鲁棒性基准（10,030 个任务实例，覆盖 7 种扰动维度）。
  • 真实机器人：7 种记忆相关任务条件（重复按键 Press-2/4/6、有序事件 Order、遮挡放置 Occl.、物体-名称对齐 Chen.-S、组合长时程 Chen.-H）。
  • 基础模型：π₀（vision-language-action flow model），使用官方 π₀–LIBERO 检查点，仅在原始 LIBERO 演示上适配 RS，不使用 LIBERO-Plus 轨迹训练。
  • 训练配置：默认 TBPTT=16，历史长度至多 64 帧；消融实验覆盖历史长度 8/16/32/64/128 帧与 TBPTT 4/8/16/24/32。
Card 06 评估与结果

评估与结果

  • LIBERO-Plus：π₀+RS 总成功率从 53.6% 提升至 70.6%（+16.9 点）；在 camera（+37.0）、robot（+39.8）、noise（+2.2）、layout（+9.1）等维度均有显著提升；低于 MemoryVLA++ 零样本报告的 73.1%。
  • 真实机器人：7 个条件中 6 个提升，组合长时程任务 Chen.-H 成功率从 20% 提升至 80%（+60 点）；唯一下降为 Chen.-S（64%→60%）。
  • 组件消融：视觉 Mamba 压缩器（VMC）使 LIBERO Long 从 85.2% 提升至 92.6%；完整 RS 进一步将 Long 提升至 94.2%，四套件总体达 96.2%（相对 π₀ +2.1 点）。
  • 历史长度与 TBPTT 消融：64 帧与 128 帧历史在 20k–25k 步均达到约 6%–7% 的改进，64 帧足够；TBPTT=16 收敛最快且损失最低，更长窗口无额外收益。
