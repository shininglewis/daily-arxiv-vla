Card 03 核心贡献

核心贡献

  • 提出将 2D 点轨迹作为机器人策略与世界模型之间的中间表示，同时改善规划与未来预测能力。
  • 提出 TrAct 框架：基于流匹配的 VLAT 策略联合预测视觉轨迹与可执行动作，并以轨迹条件化世界模型进行奖励引导的动作选择。
  • 设计并发布 LIBERO-INTEGRAL 新基准，包含 10 个鲁棒性任务和 10 个 UR5 跨具身迁移任务，用于评估分布偏移和具身变化下的泛化能力。
  • 在仿真与真实 Franka Panda 机器人上验证：TWM 在视频预测质量上全面优于动作条件世界模型（AWM），并显著提升下游任务成功率。
Card 04 方法描述

方法描述

  • VLAT：基于预训练的流匹配 VLA 模型 π0.5，修改动作头使其同时输出动作块和 N 条 2D 点轨迹，采用联合流匹配目标 𝐿 = 𝐿_flow(动作) + λ𝐿_flow(轨迹)。
  • 轨迹监督：7 个来自夹爪网格的预定义关键点（通过机器人位姿与相机标定投影），外加手腕视角下 5×5 均匀网格背景点（用 CoTracker 跟踪）。
  • TWM：以 Stable Video Diffusion (SVD) 为骨干，通过 ControlNet 分支将轨迹坐标编码为空间控制图；多视角轨迹用不同颜色通道（agent 视角红色、wrist 视角蓝色）区分。
  • AWM 基线：将动作经 MLP 编码到 CLIP-L/14 特征空间，加入视角嵌入后通过 cross-attention 注入 SVD UNet。
  • 推理时：使用温度缩放重采样（TSR）生成 K 个多样化的动作–轨迹候选，TWM 生成对应未来视频，InternVL2 的 VLAC 评分并选择最优轨迹所对应动作执行。
Card 05 数据集与资源

数据集与资源

  • 预训练数据：DROID（76K 轨迹）与 EgoDex（150K 轨迹，1:2 混合比例）；附录中进一步加入 BridgeData V2 扩大预训练混合。
  • 微调数据：仿真使用 LIBERO（2K episodes）；真实使用自采 400 条 15Hz 演示（4 个训练任务、5 个未见任务测试）。
  • 模型规模：基于 π0.5 与 SVD 的预训练模型，参数量原文未明确列出；奖励模型为 InternVL2。
  • 训练资源：VLAT 预训练 30K 步，batch size 64，4 块 H100 GPU；世界模型预训练 30K 步、batch size 64；仿真微调 VLAT 5K 步、世界模型 25K 步、batch size 16；真实微调 VLAT 50K 步、batch size 32。
Card 06 评估与结果

评估与结果

  • 视频预测质量：在真实与仿真、agent 视角与 wrist 视角下，用 PSNR / SSIM / LPIPS / FID / FVD 评估，TWM 全面优于 AWM；例如仿真 agent 视角 PSNR 从 15.12 提升至 24.51，FVD 从 129 降至 38。
  • 标准 LIBERO 四个套件（LIBERO-10/Goal/Object/Spatial）：π0.5 平均 96.8%，VLAT 98.0%，VLAT+AWM 98.0%，TrAct 达到最优 98.3%。
  • LIBERO-INTEGRAL 基准：π0.5 成功率 27%，VLAT 44%，VLAT+AWM 49%，TrAct 最优 55%；跨具身任务上 TrAct 达 50%，明显高于 π0.5 的 17%。
  • 真实机器人实验：5 个未见任务（常规/不同背景）平均成功率 π0.5 49%、π0.5+VLAC 65%、VLAT 55%、VLAT+AWM 66%、TrAct 最高 76%；在未见背景和接触丰富任务（如关柜门）上优势尤为明显。
