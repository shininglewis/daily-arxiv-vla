研究单位

Card 02 论文概述

论文概述

  • 论文提出 HOIBlender，一个高效的人类-物体交互（HOI）检测框架，核心思想是"融合"（blending）：将检测器产出的视觉 token、主体-客体空间推理，以及 BLIP-2 视觉-语言先验统一到一条轻量化解码流程中。
  • 针对现有方法的两大痛点：HOI 检测头仍沿用较重的 DETR 式编码器；视觉-语言先验常被当作辅助校准分支或后处理，与主解码路径耦合微弱。
  • 目标是在保持甚至超越精度的同时，去掉专用 transformer 编码器，降低参数量与推理延迟，并缓解 HICO-DET 长尾标注下的稀有类别识别问题。
Card 03 核心贡献

核心贡献

  • 提出 HOIBlender：一种无编码器（encoder-free）的 HOI 检测器，直接从基于 DINOv2 的 RF-DETR/LW-DETR 风格骨干的多尺度投影器输出中选取 top-K 图像条件 token 作为主体与客体候选。
  • 设计双阶段交互解码器：Stage A 稳定人-物几何（双耦合流），Stage B 在渐进式 BLIP-2 先验融合下完成动词与 HOI 分类。
  • 引入分组查询训练（Group-DETR 风格，训练时 13 组，推理仅保留 1 组），提升优化质量而不增加推理成本。
  • 在 HICO-DET 上于三种模型规模（Nano / Small / 2XL）一致超越 SOV-STG-VLA 与 Hybrid-SOV-VLA，仅用 9 个训练 epoch 即达到 44.49 Default Full mAP。
Card 04 方法描述

方法描述

  • 检测器优先基础（Detector-First Foundation）：DINOv2 ViT 骨干 + 多尺度投影器，投影后的 token 直接送入 HOI 解码器，跳过传统 DETR 编码器。
  • 直接 HOI 查询选择：查询选择模块为每个 token 预测 objectness 分数与交互相关性分数，取 top-K 构成并行的主体查询与客体查询。
  • Stage A 空间解码：两条耦合解码流分别预测主体状态/人类框与客体状态/物体框，通过交叉注意力与投影骨干特征交互，无需显式枚举所有配对。
  • Stage B 语义解码：动词与 HOI 分支均实现为 vision-advisor 解码器，以 BLIP-2 特征作为额外 memory；相比前作，HOIBlender 将视觉顾问扩展到动词分支以获得更细粒度谓词语义；V-HOI Bridge 融合动词感知与 HOI 感知嵌入。
  • 多先验语义融合（两级）：*图像条件先验*——BLIP-2 特征作为解码器 memory；*标签条件先验*——用冻结 BLIP-2 文本编码器初始化动词与 HOI 分类器权重 W_verb 与 W_hoi，为长尾类别提供有结构的标签几何。
  • 训练目标：匈牙利匹配 + 变焦式分类损失、主体/物体框回归与 GIoU、动词与 HOI 多标签损失，各中间解码层施加辅助监督；使用 AdamW、混合精度、梯度累积与分组查询训练。
  • 三条设计原则：(1) 检测器优先、(2) 先空间后语义、(3) 训练丰富、推理紧凑。
Card 05 数据集与资源

数据集与资源

  • 数据集：HICO-DET（38,118 张训练图 / 9,658 张测试图；80 个物体类别、117 个动词、600 个 HOI 类别；Rare 子集含 138 个训练样本少于 10 个的类别）。
  • 模型规模：三种变体 HOIBlender-N / -S / -2XL，遵循 RF-DETR 缩放策略；骨干为 DINOv2-S（N、S）与 DINOv2-B（2XL）。
  • 输入分辨率分别为 384 / 512 / 880，解码器深度分别为 2 / 3 / 5（均小于 Hybrid-SOV 的 6 层）。
  • 训练资源：8 × NVIDIA A6000 GPU，batch size 16；延迟在单张 NVIDIA A100 上以 batch size 1、100 个样本平均测得。
  • 训练轮数：Nano 与 Small 用 15 epoch，2XL 用 9 epoch；AdamW 学习率 1×10⁻⁴（编码器 1.5×10⁻⁴），权重衰减 1×10⁻⁴。
Card 06 评估与结果

评估与结果

  • 评估基准：HICO-DET，报告 Default 与 Known Object 两种设定下的 Full / Rare / Non-Rare mAP。
  • 主要结果：

- HOIBlender-N：41.46 Default Full mAP，41.64 Rare mAP，15 epoch，67% 延迟约 69.8 ms。

- HOIBlender-S：43.19 Default Full mAP，74.9 ms，在无编码器、3 层解码器下匹配或超越 Hybrid-SOV-VLA。

- HOIBlender-2XL：44.49 Default Full mAP、44.86 Non-Rare mAP，仅 9 个训练 epoch，为表中最佳的 Default Full 结果；延迟 88.4 ms。

  • 消融结论：

- 去掉动词解码器使 2XL 的 Rare mAP 从 43.21 降至 42.11（相对下降 2.55%）。

- 再去掉 BLIP-2 VLA 后 Rare mAP 崩塌至 24.69（相对下降 42.86%），说明语义先验是长尾识别的关键锚点。

- 同时去掉主体解码器与 VLA：Default Full 36.97、Rare 30.65（分别相对下降 16.90% 与 29.07%），表明空间结构与语义先验高度协同。

- 分组查询：13 组最优；6 组降至 40.69；1 组（标准训练）仅 37.27 Full mAP（相对下降 10.11%），验证"训练丰富、推理紧凑"原则。

  • 定性分析：与 Hybrid-SOV 相比，HOIBlender 的动词分数图更集中于人-物交互证据区域（如"放风筝"中风筝线也获得高动词分）。
  • 局限：BLIP-2 视觉编码器仍是主要延迟瓶颈，未来可探索更高效的视觉-语言融合或更轻量的 VLM。
