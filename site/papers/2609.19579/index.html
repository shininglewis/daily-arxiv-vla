Card 02 论文概述

论文概述

  • 研究目标：探索能否在不进行在线环境交互、强化学习和奖励优化的情况下，恢复被激进结构化裁剪的视觉-语言-动作（VLA）模型。
  • 问题背景：VLA 的语言主干通常有数十亿参数，是部署到机器人硬件上的主要障碍；激进裁剪会让策略完全失效，例如 OpenVLA-OFT 裁剪 63% 后，LIBERO-Long 成功率从 93.2% 降到 0.8%。
  • 核心思路：通过“宽度裁剪 + 离线隐藏状态蒸馏”，让教师与学生隐藏状态形状一致，从而直接从教师缓存中监督学生恢复，避免 RLRC 等方法的在线 rollout 和数百 GPU 小时开销。
Card 03 核心贡献

核心贡献

  • 提出完全离线恢复被激进裁剪 VLA 的方法：宽度裁剪保留残差流，教师与学生隐藏状态可直接比较，无需投影层，也无需 rollout 或 reward。
  • 在 9 个压缩比和两个 VLA 主干（OpenVLA-OFT、CogACT）上做系统扫描，定位隐藏状态蒸馏开始显著优于监督恢复的压缩区间，并发现更大恢复预算会将优势点进一步外推。
  • 在匹配压缩率下比较宽度裁剪与 CKA 引导的深度裁剪：宽度裁剪成功率更高，深度裁剪延迟更低。
  • 在6-DoF 机械臂上验证：72% 裁剪的蒸馏学生达到 77.5% 成功率，高于监督恢复的 59.5%，且比教师快 2.23×、内存减少 62%。
Card 04 方法描述

方法描述

  • 隐藏保持的结构化宽度裁剪：只裁剪语言主干的注意力头和 MLP 通道，保留残差流宽度、嵌入、视觉编码器、动作头和 block 数量不变，并排除第一和最后一个 block。
  • 动作路径 Taylor 重要性：用一阶 Taylor 近似 \|w·g\| 评估头/通道组的重要性，梯度来自推理时动作头损失（OpenVLA-OFT 用 L1 回归损失，CogACT 用噪声预测损失），称为 action Taylor。
  • 离线教师缓存恢复：教师只跑一次，缓存输入、动作 token 位置的教师隐藏状态和真实动作；学生在缓存上训练，损失为 L = L_task + λ·MSE(H_S, H_T)，其中 λ 从 0 线性 ramp。
  • 参数高效恢复：在语言主干和视觉路径（OpenVLA-OFT）或仅语言模型（CogACT）上使用 LoRA rank 32、α=16；OpenVLA-OFT 动作头全量微调，CogACT 动作头冻结。
  • 蒸馏目标：OpenVLA-OFT 匹配 56 个动作 token 隐藏状态；CogACT 匹配单个 cognition feature。
Card 05 数据集与资源

数据集与资源

  • 数据集与基准：LIBERO（含 LIBERO-Long 和四个 suite）、SimplerEnv（Google-Robot）、LIBERO-Plus 鲁棒性基准。
  • 模型：OpenVLA-OFT（Llama-2 7B 主干，连续 L1 动作头）、CogACT（同 VLM 家族，扩散 Transformer 动作头）；教师主干为 6.74B 参数。
  • 训练数据与预算：OpenVLA-OFT 使用 101,468 条缓存 LIBERO-Long transition，训练 5,000 步，λ=3，约 8 H100 GPU-hours；CogACT 使用 100,000 条缓存 Google-Robot transition，训练 1,200 步，λ=2，约 1.7 A6000 GPU-hours。
  • 其他资源：重要性评分使用 512 条校准 transition；每次恢复只需单张 48 GiB GPU；真实机器人使用 AgileX PiPER 6-DoF 和 Jetson Thor 板载部署。
  • 真实机器人数据：教师用 450 条演示、10 个任务微调；学生用同一数据缓存恢复，训练 20,000 步。
Card 06 评估与结果

评估与结果

  • 评估设置：配对评估同一初始状态；OpenVLA-OFT 用 McNemar 精确检验，CogACT 按初始状态聚类后做单样本 t 检验；每个扫描点通常 3 个 seed。
  • 恢复效果：OpenVLA-OFT 在 63% 有效裁剪下从 0.8% 恢复到 89.7%±2.4%，教师为 93.2%；仅 SFT 为 87.6%，KD 额外提升 +2.1 点。
  • 蒸馏收益区间：45% 裁剪以内 SFT 与 SFT+KD 无显著差异；63%–87% 裁剪下 OpenVLA-OFT 的 KD 增益为 +2.1 到 +4.5 点；CogACT 从 63% 起增益为 +9.4 到 +22.1 点。
  • 恢复极限：CogACT 在 81% 裁剪下，三倍恢复预算将学生与教师差距缩小到平均 3.9 点，而监督恢复仍落后 20 点以上。
  • 宽度 vs 深度：宽度裁剪在全部测量点成功率更高（OpenVLA-OFT 高 2.8–12.9 点，CogACT 高 9.0–33.2 点）；深度裁剪延迟更低（1.31–1.66× vs 宽度 1.14–1.18×）。
  • 部署表现：72% 裁剪被选为工作点；CogACT 学生达到 68.6%（教师 67.2%），快 1.52×，内存少 62%；OpenVLA-OFT 延迟稳定在 50–52 ms。
  • 真实机器人：SFT+KD 学生 77.5% vs SFT 59.5%（+18.0，p<0.001），也高于教师 65.5%（+12.0，p=0.004）；板载延迟从 362 ms 降至 162 ms（2.23×），内存从 15.0 GiB 降至 5.7 GiB。
  • 鲁棒性：LIBERO-Plus 上 45% OpenVLA-OFT 学生与教师差距仅 1.8 点；SimplerEnv 变体上 72% CogACT 的 SFT+KD 为 60.7%，SFT 仅 37.2%，教师为 66.6%。
