Card 02 论文概述

论文概述

  • 论文提出 ECHO（Event-Augmented Context with Hindsight and Outlook），一个仅使用腕部相机（wrist-only）的潜在世界动作模型（latent world action model），首次将事件相机信号作为贯穿过去、现在、未来的策略模态。
  • 针对的问题：依赖 RGB 相机的操作策略在极端曝光、运动模糊、低光照下观测退化；而事件相机虽具高动态范围，却存在空间—时间局限——固定相机错过静态场景内容，腕部相机运动又会把已访问区域移出视野。
  • 目标是用事件流提供时序与空间上下文，弥补腕部视角在光照恶劣与相机快速运动下的观测缺失。
Card 03 核心贡献

核心贡献

  • 提出混合卷积-注意力事件编码器（hybrid convolution-attention event encoder），通过跨模态视觉重建与时间反转对比学习（time-reversal contrastive / MDC）进行预训练，提取鲁棒的时空运动先验。
  • 提出腕部单目感知框架：用轨迹记忆（trajectory memory，hindsight）把已离开视野的空间单元保持为可寻址的 off-camera context，用事件前瞻查询（event foresight queries，outlook）预测未来动作条件下的事件窗口。
  • 在 RLBench 六个任务的腕部相机协议下，正常光照中相较 RGB 与 RGB+event 基线分别提升 20.6 与 12.0 个百分点；在 -4 EV 严重欠曝下分别提升 14.6 与 11.3 个百分点，并超过使用第三人称相机的 RGB 参考方法。
  • 在真实机器人平台上用腕部事件相机验证，在正常与极暗光照下均优于 RGB-only 与 RGB+event 基线。
  • 提供事件前瞻的可视化与注意力分析，显示记忆 token 集中于夹爪—物体接触点、前瞻查询覆盖更广的交互区域。
Card 04 方法描述

方法描述

  • 采用 prefix-expert 架构：视觉语言主干把腕部 RGB、事件 token、语言指令、off-camera context、前瞻查询编码为前缀，flow-matching 动作专家从该前缀与本体状态生成连续动作块。
  • 事件表示：把决策窗口内的异步事件累积为 6 通道 signed voxel 体 $V_t\in\mathbb{R}^{6\times H_e\times W_e}$，编码为 $N=64$ 个事件潜在 token（宽 $D=1024$，排成 $8\times8$ 网格）。
  • 编码器预训练（潜在世界模型）：以冻结的 DINOv3 特征为教师，用 warp 头与合成头预测下一时刻教师特征，并通过门控融合；损失含运动加权 SmoothL1 重建、时间反转重建、运动方向对比（MDC） 与方差正则。
  • Hindsight（off-camera context）：将末端执行器轨迹按分辨率 $\delta$ 量化成空间单元，缓存访问过的前 $K$ 个单元，取前 $M$ 个位置嵌入与当前事件摘要相加，形成 $M$ 个上下文 token。
  • Outlook（event foresight）：附加 $N_f$ 个可学习查询 token，通过 MSE（带 stop-gradient、pad-mask）回归冻结事件编码器给出的未来事件潜在表示，实现动作条件下的事件前瞻预测。
  • 注意力分段设计：图像/事件/语言共享一段，context、foresight 与动作专家各自开启新段，段内双向、跨段单向（只注意前置段）。
Card 05 数据集与资源

数据集与资源

  • RLBench 六个代表性任务（laptop、toilet、fridge、umbrella、frame、plants），腕部相机 + 腕部事件流协议。
  • 每任务使用 episode 0–99 训练，episode 100–124 评估。
  • 仿真事件由 ESIM 模拟器渲染生成；真实实验使用 DVSense 的 DVSync 事件相机。
  • 事件编码器约 60M 参数；策略主干与动作专家由 π0 初始化；教师模型为 DINOv3-ViT-L/16（输入 $256\times256$）。
  • 训练 20k 步，全局 batch size 32，使用 2 张 H20 GPU，学习率 $1\times10^{-4}$。
  • 训练时肘部 RGB 以 0.3 概率被随机 pad-mask，事件流保持完整；动作视界 $H=1$（RLBench keystep）与 $H=16$（真机）。
Card 06 评估与结果

评估与结果

  • 评估基准：RLBench 腕部单目设置（正常光照与 $-4$ EV 曝光偏移）以及真机部署。
  • 主要指标：任务成功率（Success Rate, %），按任务报告 N（正常）与 D（欠曝）两栏。
  • 关键结果：ECHO 在正常光照与 $-4$ EV 两种条件下均取得最高成功率；相较 RGB 基线与 RGB+event 基线分别高出 20.6 / 12.0 个百分点（正常）与 14.6 / 11.3 个百分点（曝光下降）。
  • 对比方法包括 π0（仅前视、前视+腕部、仅腕部）、CogACT（仅腕部）以及 π0 + event 等；纯腕部 RGB 方法在欠曝下明显退化（如 π0 仅腕部 48.7 → 38.7）。
  • 消融（V-C）考察事件输入、预训练、轨迹上下文、事件上下文与前瞻等各组件的贡献；真机实验进一步验证暗光下的鲁棒性。
  • 定性分析显示前瞻查询能解码出未来事件的极性与运动位置，并重建出未来物体布局。
