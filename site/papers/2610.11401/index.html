WAM-Cache: Staleness-Bounded KV Reuse for Efficient World Action Models

2026-10-08 · 原文 · 翻译 · 2610.11401

论文研究 World Action Models（WAMs） 在闭环机器人控制中的视频 Diffusion Transformer（DiT）预填充瓶颈：每个 chunk 都需将当前观测编码为逐层 KV，供动作专家查询，该预填充占单 chunk 主要计算量。 现有训练无关加速方法未处理该预填充，而重训练压缩成本高；论文提出 WAM-Cache，跨 chunk 保留逐层 KV，仅重计算稀疏刷新集。 核心发现是动作精度取决于动作专家“关注哪里”而非视觉“什么移动了”；WAM-Cache 联合动作注意力、潜在 surprise 与年龄界限，在减少 32–42% 预填充 FLOPs 的同时接近密集策略。

Card 03 核心贡献

核心贡献

  • 提出 WAM-Cache，据称是首个面向 WAM 视频 DiT 预填充的训练无关 KV 重用框架。
  • 揭示缓存刷新应遵循策略注意力而非视觉漂移：基于变化的规则即使使用真值 KV 漂移 oracle 也远低于密集模型，而年龄界限严格限制陈旧性并几乎弥合差距。
  • 在 RoboTwin 2.0、LIBERO 和真实机器人实验中，将视频 DiT 预填充 FLOPs 减少 32–42%，与密集策略差距保持在 0.7–1.8 个百分点（模拟）和 2.5 个百分点（真机）。
  • 方法无需重训练，可与扩散步数减少、模型蒸馏、去噪器缓存等正交加速方法组合。
Card 04 方法描述

方法描述

  • 跨 chunk 为每个视觉 token 维护缓存 KV、最近刷新时的参考嵌入、年龄计数器、动作专家注意力质量。
  • 每 chunk 构建刷新集 R_t = S_t ∪ P_t ∪ A_t，其中三项分别来自潜在 surprise、动作条件选择与年龄界限。
  • 潜在 surprise S_t：计算当前 patch embedding 与参考嵌入的归一化距离，按 TopK 选取变化最大的 token。
  • 动作条件选择 P_t：对上一 chunk 动作专家交叉注意力质量按层和查询平均，按 TopK 选取策略敏感 token；该信号零额外成本。
  • 年龄界限 A_t：年龄计数器达到 G 的 token 强制刷新，严格限制每个 KV 对的最大陈旧度，抑制自指误差累积。
  • 视频 DiT 预填充仅在 R_t 上执行并原地更新对应 KV；未选中 token 保留缓存 KV；查询仅为刷新 token 形成并注意全部 KV。
  • 训练无关，仅增加轻量标量元数据，不修改动作专家，架构透明。
Card 05 数据集与资源

数据集与资源

  • 仿真数据集：RoboTwin 2.0（50 个双臂任务，每个任务 100 回合，clean/randomized 场景）和 LIBERO（Spatial、Object、Goal、Long 四个套件，每任务 50 回合）。

Card 06 评估与结果

评估与结果

  • 评估基准：RoboTwin 2.0、LIBERO 及 AIRBOT Play 真实机器人任务；与 FastV、ToMe、Eventful Transformer、VLA-Cache 等训练无关 token 减少方法在匹配 FLOPs 预算下对比。
  • 指标：成功率（SR）、每 chunk 视频 DiT 预填充 FLOPs、CUDA 延迟。
  • RoboTwin 2.0：默认预算下 clean 减少 41.6% FLOPs，SR 88.36% vs 密集 90.16%（-1.8 点）；randomized 减少 39.3%，SR 88.32% vs 89.66%（-1.3 点）；更大预算下 clean 减少 28.2%，SR 90.08%（-0.1 点）。
  • LIBERO：减少 32.3% FLOPs，平均 SR 95.85% vs 密集 96.50%；更大预算减少 26.1%，平均 SR 96.50% 匹配密集。
  • 真实世界：减少 40.2% FLOPs，平均 SR 82.5% vs 密集 85.0%。
  • CUDA 延迟：在视觉 token 数 120/480/1080 时预填充加速 1.23× / 1.47× / 1.67×，接近 FLOPs 理论上界 1/ρ。
  • 消融：仅动作注意力选择达到 81.46% SR，联合 surprise 达到 88.36%；年龄界限 G=2 相对无界限恢复 7.7 点，将差距缩至 1.8 点。
