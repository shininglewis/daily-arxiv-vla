论文概述

Card 03 核心贡献

核心贡献

  • 提出 nuisance orthogonality（干扰正交性）：量化特征位移中与“分布内经验子空间”正交的比例，用于刻画骨干是否在策略训练前就把动作保持型视觉变化与区分干净场景的方向分离。
  • 证明 nuisance orthogonality 与下游策略鲁棒性高度相关：跨多种图像/视频骨干，训练前测得的正交性可前瞻性预测 WAM 在 LIBERO-Plus 上的成功率，为世界模型骨干提供模型选择诊断工具。
  • 提出 nuisance suppression（干扰抑制）：衡量策略适配后表示空间的重塑，发现鲁棒策略（ImageWAM）对分布内与正交分量均表现出一致且更强的抑制，而 FastWAM 抑制弱且不一致。
  • 通过受控相机扫描实验与 3D PCA 可视化，显示 ImageWAM 表示在弱扰动下近似相机不变、强扰动下仍保持场景可区分；FastWAM 表示则被相机变化主导。
  • 揭示抑制的几何机制：适配主要放大分布内样本间差异（ImageWAM 总分布内方差放大 13.4 倍，位移分量仅增 2.73/2.48 倍），从而相对降低干扰影响。
Card 04 方法描述

方法描述

  • 在生成式骨干第 ℓ 层取中间表示，对参考（干净）观测做中心化并 SVD 分解，得到经验分布内子空间投影矩阵 P = V_r V_rᵀ（保留秩 r）。
  • 定义变换 T 下的特征位移 d = h(Tx) − h(x)，单层正交性为 q = 1 − ‖Pd‖²/‖d‖²，跨层与数据平均得到 O(T)。
  • 干扰抑制度量使用检查点各自的经验协方差做白化归一：分布内响应 s(x,T) 与正交响应 s⊥(x,T)，并取其 WAM/WM 比值 ρ_T 与 ρ⊥,T；比值小于 1 即表示抑制。
  • 关键创新：把“预训练目标”之外的全部设计选择（视觉/语言分词器、架构、初始化、语言注入方式、预训练数据）统一视为表示先验，并用几何量而非损失函数来刻画。
  • 实验采用 MoT 架构 + action expert，结合原骨干的未来预测损失与 flow matching 动作预测损失训练。
Card 05 数据集与资源

数据集与资源

  • 诊断数据集构建自 LIBERO-Plus（配合 LIBERO），使用同一仿真器状态、不同视觉外观的成对观测，覆盖 lighting、background、sensor noise、camera viewpoint 四类视觉偏移及多档强度。
  • 40 个干净参考观测用于估计分布内特征子空间（保留秩 r = 39），对应采集 1,200 个分布外观测。
  • 生成式骨干：Wan2.2（FastWAM）、FLUX.2、Scratch FLUX.2、OmniGen2、Ovis-U1（ImageWAM 系列），以及扩展的 FlashMotion、Kiwi-Edit、SANA-Video 2.0 5B、MAGI-1 4.5B。
  • 模型规模（骨干 + 动作专家）：FastWAM 5.00B + 1.02B；ImageWAM(FLUX.2) 3.88B + 0.64B；Scratch FLUX.2 3.88B + 0.64B；OmniGen2 3.97B + 0.76B；Ovis-U1 1.13B + 1.04B；FlashMotion 5.00B + 1.21B；Kiwi-Edit 5.00B + 1.02B；SANA-Video 2.0 4.47B + 0.75B；MAGI-1 4.46B + 0.64B。
  • 训练设置：AdamW，学习率 1e-4，余弦调度，5% warmup，最终学习率 1e-6，权重衰减 1e-2，10 个 epoch，batch size 128（FastWAM/Kiwi-Edit）或 80（SANA-Video/MAGI-1）；具体计算资源在附录 A.1 中说明。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO-Plus（LIBERO 训练、LIBERO-Plus 测试），共 5,418 条评估轨迹；指标为各类视觉偏移下的成功率（SR, %） 及其平均，并与 nuisance orthogonality 对照。
  • 平均成功率（括号内为平均正交性）：FLUX.2/ImageWAM 89.0%（0.799） > OmniGen2 77.3%（0.746）≈ Kiwi-Edit 77.1%（0.786）> MAGI-1 76.2%（0.750）> SANA-Video 75.4%（0.742）> Ovis-U1 72.9%（0.772）> FlashMotion 64.0%（0.645）> Scratch FLUX.2 63.9%（0.724）> Wan2.2/FastWAM 46.5%（0.594）。
  • 正交性与成功率呈整体正相关：正交性越高，WAM 训练后的视觉鲁棒性越强；相机视角变化最难，FastWAM 仅 16.4%，而 FLUX.2 达 77.6%。
  • Scratch FLUX.2 仅 63.9%，说明优势不能仅归因于“图像编辑预训练目标”，支持“表示先验由全部设计选择共同决定”的假设。
  • 秩消融显示正交性随保留秩变化保持一致趋势（秩越小正交性越高）。
  • 抑制分析：ImageWAM 的 ρ_T 与 ρ⊥,T 在所有测试变化下均小于 1；FastWAM 抑制更弱且在部分变化类型下不出现抑制。
  • 局限性：仅在仿真 LIBERO 操作与 LIBERO-Plus 视觉偏移上验证，结果为观察性研究，未完全隔离正交性或预训练目标的因果效应。
