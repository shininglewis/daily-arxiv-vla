Card 03 核心贡献

核心贡献

  • 提出纤维化（fibered）形式化：将异步行为-动作实现定义为“行为条件动作纤维”，把延迟块执行视为在语义有效动作族内的交接条件选择。
  • 设计指令感知、Haar 结构化的生成器：识别指令相关行为条件，通过成对 scaffold 与局部残差坐标（可精确重构）参数化动作实现。
  • 提出 BICPO：将已知输出动作滚动到实际交接状态，在语义匹配的实现间学习延续偏好（jump 与 trend 代价），无需在线候选搜索即可平滑块转换。
  • 证明所提参考相对 Flow-DPO 目标可迁移到 π₀.₅ flow matching、Legato、RTC 等策略，只改变其原生条件与执行机制中的延续质量，而不破坏任务能力。
  • 在 CALVIN、RoboTwin、LIBERO 与真实机器人任务上取得一致提升，验证了行为身份、实现结构与交接条件选择三阶段分解的有效性。
Card 04 方法描述

方法描述

  • 整体分三步：行为识别 → Haar 实现生成 → BICPO 交接偏好优化。
  • 行为识别：视觉 token 先通过指令门控注意力（instruction-grounded attention）过滤命令无关证据，再经因果历史编码器（causal Mamba + 互惠视动校准）得到行为状态，与检索到的长期记忆共同构成行为条件。
  • Haar 实现：对偶数长度动作块使用一阶 Haar 变换，得到成对 scaffold（C）与互补残差（D），先生成 C 再以 C 为条件生成 D，最后通过固定正交逆变换精确重构。
  • 交接条件：用冻结动作状态模型将已知输出动作滚动到真实交接状态，拼接绝对状态与差分状态（sign both），并通过投影得到交接条件 g。
  • BICPO：在同一行为纤维内采样候选对，计算 jump 与 trend 两类延续代价，用参考相对 Flow-DPO 优化，冻结语义通路、Haar 变换与参考专家，只更新交接投影与部分专家参数。
  • 训练流程：模仿学习（结构损失）→ 延续热身 → 离线 DPO；部署时仅滚动一次交接状态、生成 Haar 系数并重构动作块。

Card 06 评估与结果

评估与结果

  • 评估协议：报告成功率、CALVIN 平均链长、LIBERO 交接代价（jump、trend）。
  • CALVIN ABC→D：BICPO-VLA 达 4.52 平均链长与 80.7% 五子任务完成率，强于最强基线 B-VLA（4.36 / 77.3%），且各链长均提升。
  • RoboTwin 2.0 Hard：全部十任务提升 4–8 个百分点，总体成功率从 60.4%（B-VLA）提升到 65.8%。
  • LIBERO 延续质量：DPO 使 BICPO-VLA 的 jump 降低 21.3%、trend 降低 20.7%，成功率仅微增 0.3 点；转移至 π₀.₅-FM、Legato、RTC 时同样降低两类代价，SR 仅变化 0.1–0.2 点；直接 SFT 反而导致 SR 大幅下降（如 π₀.₅-FM 从 96.9% 降至 49.1%）。
  • 真实世界：平均成功率 69.3%，优于 B-VLA（60.2%）、π₀.₅（47.3%）与 OpenVLA-OFT（33.3%）。
  • 消融实验验证了各组件贡献，且指令入口（在视觉接口处融合语言）设计优于其他融合位置。
