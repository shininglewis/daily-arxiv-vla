Card 02 论文概述

论文概述

  • SimpleMemVLA 提出一种无需专用记忆模块的视觉-语言-动作模型（VLA），直接将分钟级历史观测以带时间戳的原生视频格式输入预训练主干，利用其原生视频处理能力作为记忆机制。
  • 核心动机在于指出既有记忆方法（检索库、学习压缩器、循环状态）存在"写入时承诺"（write-time commitment）问题——在未知未来决策需求前就必须决定保留哪些历史信息，导致相关信息可能被丢弃。
  • 论文论证，在当代 VLM 主干的长上下文支持下（60 秒历史仅约 5.6k tokens，远小于 262k 上下文窗口），可以直接保留完整历史，无需额外的记忆压缩模块。
Card 03 核心贡献

核心贡献

  • 提出 SimpleMemVLA：一个无专用记忆模块的 VLA 架构，利用主干预训练时的原生视频理解能力直接处理时间戳化历史帧。
  • 引入"窄文本通道"（narrow text channel）：主干生成的当前子任务（sub-task）的隐藏状态与 token 嵌入作为历史信息通向 flow-matching 动作头的唯一接口，保证历史信息以可检查、可编辑的紧凑形式传递到动作生成模块。
  • 提出精确流式推理（Exact Streaming Inference）：利用相邻决策共享绝大部分历史前缀的特性，在动作执行期间预填充共享前缀并复用 KV-cache，使决策延迟从 1.02s 降至 0.68s，且输出与全量重算完全一致。
  • 在 RMBench、RoboMME、MIKASA-Robo、RoboMemArena 四个记忆基准上取得最优成绩，同时在 LIBERO / LIBERO-Plus 通用控制任务上保持与最强反应式 VLA 相当的性能。
  • 通过固定主干与训练设定的对照实验证明：原生视频上下文（88.3%）大幅优于自建的检索（31.5%）、压缩（22.6%）和循环状态（20.6%）变体。
Card 04 方法描述

方法描述

  • 历史帧（head-camera）经子采样后通过主干的原生 video channel 输入，每个时间 patch 前附带纯文本时间戳，对齐视频预训练格式；当前 wrist 帧通过 image channel 输入，实现"多帧为视频、单帧为图像"的模态规则，让输入格式自然区分过去与现在。
  • 目标函数包含子任务语言建模（sub-task token 级交叉熵）与条件 flow-matching 动作损失两项，动作头采用 DiT 风格 flow-matching expert，通过生成子任务对应 token 的嵌合及其隐藏状态进行条件化。
  • 子任务标签由云端 LLM 离线生成，同一套标签用于所有对照变体训练，以隔离记忆接口本身的影响。
  • 流式推理采用窗口重建（windowed reconstruction）与共享前缀预填充（shared-prefix prefill）；附录中进一步探索了带滑动窗口注意力（SWA）的有界成本流式变体。
Card 05 数据集与资源

数据集与资源

  • 记忆基准：RMBench（10 个双臂记忆任务）、RoboMME（16 个单臂任务，覆盖 Counting/Permanence/Reference/Imitation 四类）、MIKASA-Robo（5 个遮挡与部分可观测任务）、RoboMemArena（26 个任务，trajectory 平均超过 1000 步）。
  • 通用控制任务：LIBERO（4 个套件）及其零样本扰动扩展 LIBERO-Plus（10,030 个扰动任务）。
  • 模型主干：Qwen3.5-4B（预训练 VLM 骨干），动作头为 flow-matching expert。
  • 训练配置：采用 window-relative 时间戳（标准部署）与 episode-absolute 时间戳（SWA 探索变体）；每套件配置由 (C_hist, C_cur, T_w, f_v, H, d_a) 元组指定。
Card 06 评估与结果

评估与结果

  • RMBench：单模型效果为 94.0% 的九任务平均成功率，比最优专用专家模型高 11.0 个百分点；是唯一在从单记忆 M(1) 到多记忆 M(n) 设置中平均分上涨的方法（91.6% → 97.0%）。
  • RoboMME：单模型平均成功率 88.3%，比最强非 oracle 基线高 43.7 个百分点，并在 16 个任务上全部第一。
  • MIKASA-Robo：平均成功率 74.0%，比此前最强 VLA 高 29.6 个百分点，优于每任务训练的专用非 VLA 策略 GMP（67.8%）。
  • RoboMemArena：在全部 26 个任务上取得最高报告性能（详细数据见原论文）。
  • 通用控制：在 LIBERO 上追平最强平均水平，在 LIBERO-Plus 零样本迁移上取得最优结果。
  • 效率：流式共享前缀推理令决策延迟降至 0.68s，与单帧 VLA 相当且输出与全量计算完全一致。
  • 因果干预验证：掩蔽任务相关历史帧会改变策略输出，掩蔽无关帧则不影响，证明策略确实在读取视觉历史；通过人为编辑或替换历史片段可引导策略行为变化，体现出新兴的视觉上下文学习能力。
