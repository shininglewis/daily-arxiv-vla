AdaRSI: On-Demand Recursive Self-Improvement for Embodied Agents

Card 03 核心贡献

核心贡献

  • 形式化了具身智能体的按需递归自我改进范式：将每个持续失败归因于 harness 或 executor，据此决定是否修改执行器权重，并以 AdaRSI 实例化该范式。
  • 发现 harness 决定了微调是否划算：它吸收了本会被错误训练的失败，并决定了策略训练和调用的状态分布；而微调能教会执行器缺失的动作，但也可能损害它原本已能完成的子步骤。
  • 在 RoboCasa365 全部 50 个目标任务上验证：在无任何人类演示的情况下，按需训练将预训练 VLA 在三个套件上全部提升，且训练成本仅为"微调每个子步骤"方案的一小部分。
  • 训练出的策略进入策略库，部署时的智能体按程序推荐选择策略，但保留在必要时回退到基座执行器的灵活性。
Card 04 方法描述

方法描述

  • 两级自改进结构：系统表示为 S = (A, H, Π)，其中 A 是语言模型编码智能体，H 是可写的 harness（技能、工具及组合程序），Π 是执行器库（初始为预训练 VLA π₀）。
  • Harness 级改进：智能体从执行反馈中编写工具与程序，使用反事实重执行（counterfactual re-execution）（保存仿真快照后以不同指令/接近方式重试子步骤），区分"调用方式不当"与"执行器无法完成的动作"。
  • 权重级改进（失败归因）：定义 executor-limited 子步骤 = 在 harness 已到位、指令执行器已知的情况下仍失败的子步骤；仅对这些子步骤训练。
  • 自收集演示：对基座执行器使用拒绝采样保留成功片段，或编写可读取特权状态（物体位姿、关节状态）的脚本化专家生成数据；特权信息仅用于生成和标注数据，测试时不使用。
  • 微调与验证：每个策略在留出起始状态上评估，仅在验证显示有提升时才织入程序推荐；每个被修改都以实证验证（类比自改进编码智能体）。
  • 跨轮次与任务的递归：S_{k+1} = g(S_k, E_k)，经验在轮次间累积；选定 pilot 任务生成经验文档并据其日志设定训练预算（训练步数与演示数量），使"在哪里训练"成为显式的成本权衡。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：RoboCasa365 全部 50 个目标任务，分三个套件：Atomic-Seen（18 个任务）、Composite-Seen（16 个任务）、Composite-Unseen（16 个任务）；每个任务测试于 50 个场景，采用官方协议（目标划分、官方任务时程与成功检查）。
  • 执行器模型：GR00T N1.5，组合任务使用官方 Composite-Seen 检查点，原子任务使用 Atomic-Seen 检查点。
  • 智能体模型：GPT-6.1-sol，通过 Codex 运行。
  • 训练资源：以 GPU 分钟计量（如 Composite-Unseen 上 AdaRSI 使用 966 GPU 分钟，Always train 使用 3,411 GPU 分钟，约 3.5 倍）。
Card 06 评估与结果

评估与结果

  • 对比系统：(1) VLA（π₀ 单独运行）；(2) Agent + VLA（智能体自行下发指令，无开发/训练）；(3) Agent + harness（仅 harness 轮）；(4) AdaRSI（增加权重轮）。消融包括 Agent + weights、Always train、Train lowest-success 等变体。
  • 评估指标：各任务成功率（%），按套件内任务平均。
  • 主要结果：AdaRSI 在三套件均取得最高成功率，整体 48.8%（VLA 42.4%，Agent + harness 46.7%）。

- Atomic-Seen：75.4% → 79.7%（+4.3）

- Composite-Seen：43.0% → 49.0%（+6.0）

- Composite-Unseen：4.6% → 13.8%（+9.2，约为基座的 3 倍）

  • 权重轮效果：Composite-Unseen 上权重轮额外带来 +3.9 个百分点；如 WaffleReheat 从 harness 单独时的 0% 提升到 38%，RecycleBottlesByType 从 0% 到 18%，BreadSelection 从 42% 到 52%。
  • 效率：AdaRSI 仅使用 28% 的 GPU 时间 和 22% 的自收集演示，却达到略高于"微调每个子步骤"的成功率；在 Composite-Unseen 上微调策略只执行 15% 的操控步骤（Always train 为 71%）。
  • 配对子步骤测试（从相同状态出发）：微调学到 π₀ 缺失的动作（打开微波炉门 0/18 → 7/18，平均开合度 0.01 → 0.61；拾取玻璃瓶 2/44 → 17/44），但会损害 π₀ 已能完成的动作（放羊角面包 16/40 → 11/40）。
  • 消融结论：移除 harness 只用微调训练更多却收益远小；仅训练成功率最低的子步骤（相同预算）相对 harness 无增益；两级缺一不可。
