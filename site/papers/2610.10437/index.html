Q-Learning with Scalar Adjoint Matching

Card 02 论文概述

论文概述

  • 论文研究如何用离策略（off-policy）强化学习对预训练 Flow 策略进行微调，使其超越示范数据的表现。

Card 03 核心贡献

核心贡献

  • 提出 SQAM（Q-Learning with Scalar Adjoint Matching），用闭式标量伴随（scalar adjoint）替换 adjoint matching 中每步的 vector–Jacobian product，显著降低了离策略微调 Flow 策略的计算成本（Proposition 1）。
  • 发现标量伴随使性能依赖于价值学习方案，并证明关键在于控制当前策略所生成动作处的 critic 值，据此提出 value penalty（在策略生成动作处惩罚 critic）。
  • 在 50 个 OGBench 任务上验证：SQAM 在离线与离线到在线 RL 中均优于已有方法，且增益集中在该基准最难的四个域，成功率比各域最强基线高 18–35 个百分点。
  • 将 SQAM 扩展至大规模预训练 VLA 策略在真实双臂机器人上的离线到在线微调，三个操作任务上均优于监督微调（SFT），而残差微调（residual fine-tuning）在同设置下表现不佳。
Card 04 方法描述

方法描述

  • 基于 flow matching：训练速度场 $v_\theta(x,\tau)$ 沿线性插值路径 $X_\tau=(1-\tau)X_0+\tau X_1$ 将噪声传输到动作分布。
  • 关键经验发现：预训练 Flow 策略的批量平均速度 Jacobian $J_\tau=\nabla_{X_\tau}v^{\text{base}}(X_\tau,\tau)$ 以对角线为主，故近似 $J_\tau = c_\tau I$。
  • Proposition 1：在等速 Jacobian 假设下，lean adjoint ODE 存在闭式解 $\tilde{a}_\tau = -\tau \exp(2\int_\tau^1 c_s ds)\,\nabla_{X_1}Q^\pi(s,X_1)$，即各流时刻的伴随都沿最终动作处 critic 梯度的负方向。
  • 实际使用的标量伴随去掉指数缩放因子：$\hat{a}_\tau = -\tau \nabla_{X_1}Q^\pi(s,X_1)$，只需在采样动作处计算一次 critic 梯度，完全不需要每步的 vector–Jacobian product。
  • 训练目标沿用 adjoint matching 形式（替换精确伴随为标量伴随），默认保留 TRQAM 的路径空间 KL 信任域以保证训练稳定。
  • Value penalty：$\mathcal{L}_{\mathrm{critic}} \mathrel{+}= c\cdot\big(Q^{\pi}(s,\operatorname{sg}(a_{\pi}))-Q^{\pi}(s,a_{\mathrm{data}})\big)$，在策略已生成的动作处约束 critic，恰是标量伴随所用梯度的位置，且不引入额外采样开销（与 CQL 不同）。
Card 05 数据集与资源

数据集与资源

  • 主要基准：OGBench 中基于奖励的单任务变体，共 10 个域 × 5 个任务 = 50 个任务；操作域使用 chunk size 为 5 的动作分块策略。
  • 真实机器人实验：RB-Y1（Rainbow Robotics）双臂机器人 + 两只 20-DoF 灵巧手（Wuji Hand 2），微调一个预训练 vision-language-action 策略。
  • 训练流程：Flow 策略先经 behavior cloning 预训练 300K 步；离线微调 1M 步，在线阶段延伸至 1.5M 步；结果在 8 个随机种子上取平均。
  • 对比基线（7 个离策略微调方法）：FQL、CGQL-L、DSRL、IFQL、QAM、QAM-E、TRQAM。
  • 代码与博客：github.com/yonghdong/sqam、yonghdong.github.io/blog/sqam/。
Card 06 评估与结果

评估与结果

  • 评估环境：OGBench 的离线 RL 与离线到在线 RL两种设置，指标为平均成功率（%）（8 seeds，±1 标准差）。
  • 离线结果（1M 步）：SQAM 在四个最难域上大幅领先最强基线——antmaze-giant +21、humanoidmaze-large +18、cube-triple +22、cube-quadruple +35 个百分点（后者最强基线 19 而 SQAM 达 54）。
  • 总体表现：50 个任务平均成功率 75%，优于最强基线 TRQAM 的 68%；该优势在在线阶段同样保持。
  • 消融与分析：

- 标量伴随与精确伴随对比表明其保留了精确传播的定性趋势；且伴随范数随流时刻的变化趋势与精确解一致。

- 价值学习方案对比显示：仅在数据集动作（如 in-sample critic）或动作距离（如 ReBRAC 式行为正则）上做正则的方法收益很小，在策略生成动作处施加 value penalty 的方法才有效。

- 进一步分析了 value penalty 系数 $c$ 与 KL 预算 $\epsilon_{\text{KL}}$ 的影响，并考察了无信任域、TRQAM 中的 value penalty、单次更新开销等其他实验。

  • 真实机器人：SQAM 在三个双臂操作任务上均优于监督微调，而 residual fine-tuning 在相同设定下表现困难。
