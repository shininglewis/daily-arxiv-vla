Grounded Action Model: 3D Grounding as a Foundation for Robotics

2026-09-20 · 原文 · 翻译 · 2609.23863

论文提出 Grounded Action Model (GAM)，一种以 3D grounding 为预训练基础的机器人基础模型新范式，区别于依赖语言生成或视频生成主干的 VLA 和 WAM。 现有方法（VLA/WAM）的预训练目标不直接要求显式的度量 grounding，导致动作学习需要从机器人演示中隐式学习空间定位，在目标移动、背景变化或指定新目标时容易失效。 GAM 通过可提示的 3D grounding 主干将语言、点、框统一映射为物体中心表示，显式提供“哪些物体重要、在哪里、占据什么几何”，再结合机器人状态历史预测动作块。

Card 03 核心贡献

核心贡献

  • 提出以 3D grounding 作为机器人动作学习基础的新范式，并实例化为 GAM。
  • 设计统一任务接口，支持 语言、2D 点、2D 框 三种提示模态，并映射到共享的 object-centric 表示。
  • 构建 object-centric 图像 token 与 检测 token 双流观察，结合状态历史，通过多流 Transformer（MM-DiT）和 flow matching 预测动作块。
  • 在 RoboTwin 2.0、LIBERO-PRO 和两类真实机器人上验证，在随机场景、目标重定位和新目标指定等扰动下取得更强泛化与鲁棒性。
  • 支持与 VLM planner 通过点接口组合，实现长时程和记忆依赖操作。
Card 04 方法描述

方法描述

  • 使用冻结的预训练可提示 3D 检测模型 WildDet3D 作为 grounding 主干，根据语言、2D 点或 2D 框提示输出每对象 2D 框、3D 框、度量深度图和视觉特征。
  • 语言提示通过基于 Flan-T5 的 span-tagging head 提取任务相关物体短语；点/框提示直接指定物体。
  • 构建 图像 token：将视觉特征平均池化到 16×16 网格，仅保留与目标 2D 框或机器人手臂轮廓重叠的单元，其余置零。
  • 构建 检测 token：从深度图和 3D 框裁剪物体点云，采样 512 个点，经点云编码器 φ 提取形状特征，结合中心、尺寸、旋转、傅里叶特征，线性适配为每对象 8 个 token。
  • 将图像 token、检测 token 与机器人状态历史 token 通过共享自注意力融合，得到条件序列 C。
  • 动作头采用 12 层 MM-DiT，包含图像、检测、状态历史和噪声动作块四个流，用 flow matching 训练，预测绝对关节位置目标块；语言嵌入通过自适应层归一化注入。
  • 部署时使用 CoTracker3 跨帧跟踪目标点，支持 planner 在子任务切换时通过点提示更新目标选择。

Card 06 评估与结果

评估与结果

  • RoboTwin 2.0：GAM 在 50 个任务上平均成功率 55.3%，优于 Spatial Forcing 的 52.0%；在场景随机化下达到 47.6%，远高于 Abot-M0 的 30.4%，且动作策略仅在干净场景演示上训练。
  • LIBERO-PRO：在 16 种扰动设置上平均成功率 61%，优于 π0.5 的 53%，在目标重定位和新目标指定下提升最大。
  • 真实机器人 YAM：分布内成功 19/20，视觉偏移下保持 17/20，而 π0.5 降至 4/20。
  • 真实机器人 Franka：与 Molmo2 planner 通过点接口组合，在长时程和记忆依赖任务上分布内步骤完成率 64.7%，分布外 49.8%。
  • 消融实验：移除图像掩码使平均成功率从 46.8% 降至 22.3%，移除点云裁剪降至 12.8%，两者都移除降至 10.3%；仅检测 token 为 16.0%，仅图像 token 为 20.3%，表明物体中心过滤和双流表示均重要。
