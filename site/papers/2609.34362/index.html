FutureDuet: Decoupling Observation Access from Future Supervision in World Action Models

2026-09-28 · 原文 · 翻译 · 2609.34362

论文提出 FutureDuet，一种 World Action Model（WAM），核心目标是将“观测接入”（哪些相机供策略使用）与“未来监督”（每个视觉流预测什么未来）解耦。 现有 WAM 通常把主视角（main view）与腕部视角（wrist view）拼接到同一视觉流中，并施加统一的未来视频预测目标；但主相机提供稳定的场景级任务演化，腕部相机随末端执行器移动、混入视角变化与自遮挡，二者的预测需求本质不同。 论文要回答的核心问题是：每个视角是否应该建模同一种未来？ 并提出让不同视角接收不同未来目标的训练范式，以同时改善动作生成与部署效率。

Card 03 核心贡献

核心贡献

  • 提出 FutureDuet：在保留主视角与腕部视角供动作生成使用的同时，允许两条视觉流的未来监督目标分别设计；所有辅助预测模块仅在训练阶段使用，不增加推理开销。
  • 设计两条互补的控制信息流：主视角通过未来 RGB 预测 + 交互掩码 + 机器人骨架学习 Task State（场景级任务进度）；腕部视角通过未来 latent 预测学习 Interaction State（近距离交互变化）。
  • 引入 Duet Interface 与 ActionDiT 联合读取两种状态，将不同监督下学到的表征在动作生成阶段融合，而非在早期视觉层融合。
  • 在 RoboTwin50 与 LIBERO 上验证有效性，最大增益出现在需要精确交互完成的任务上；控制实验显示腕部路径分离相比统一 RGB 建模带来 13.9 个百分点提升。
  • 通过注意力读出与 K/V 干预诊断，证明掩码监督主要增强对任务物体的读取、骨架监督主要增强对机器人的读取，二者组合最佳。
Card 04 方法描述

方法描述

  • 输入与输出：在控制步 *t*，模型接收语言指令 *c*、本体感知 *p_t*、主视角历史 *o^m_{≤t}*、腕部历史 *o^w_{≤t}*，输出动作块 *a = a_{t:t+H−1}*。
  • 主视角（Task State）：VideoDiT 提取主视角特征，未来帧经 VAE 编码为 latent，用流匹配（flow matching）预测速度；一个共享的 DPT 风格解码器从带噪中间特征预测交互掩码与骨架图（掩码用离线 SAM 3 标注被操作物体及目标区域，骨架将记录的机器人构型投影到标定主视角）；掩码用 focal–Tversky 损失，骨架用 focal–Dice 损失。
  • 腕部视角（Interaction State）：轻量在线编码器提取腕部特征；用冻结的 V-JEPA 2.1 离线编码未来腕部片段作为缓存目标，训练仅训练用的预测器 P_ψ 联合预测左右腕 latent（用视角嵌入区分相机），损失为平均绝对误差；通过 stop-gradient 阻止腕部目标经条件连接更新主流。
  • Duet Interface 与联合读出：学习式 query 适配器将两流特征汇总为 Task State 与 Interaction State，Duet Interface 将其投影融合为 C^duet，ActionDiT 结合主视角当前 K/V、指令与本体感知预测动作速度；延迟融合而非早期视觉融合。
  • 训练目标：总损失为 L_act + λ_rgb·L^m_rgb + λ_mask·L_mask + λ_ske·L_ske + λ_wrist·L_wrist；推理时 VAE 解码器、DPT 解码器与预测头、V-JEPA 教师、腕部预测器全部剪枝。

Card 06 评估与结果

评估与结果

  • 评估环境与基准：RoboTwin50（双臂，clean / randomized）与 LIBERO（单臂，Spatial / Object / Goal / Long 四套件）；主要指标为成功率（SR，%）。
  • 整体性能：LIBERO 平均成功率 99.2%，在 Spatial、Object、Goal 三个套件上取得报告中的最佳结果；RoboTwin50 达 94.2%（clean）与 94.1%（randomized），比 Fast-WAM 在两个设置上均高 2.3 个百分点。
  • 困难任务增益：50 个任务中 41 个在两种设置下均达到 ≥90% 成功率；6 个高难度任务上相比 Fast-WAM 在 clean 提升 9.2 pp、randomized 提升 12.8 pp，这 6 个任务贡献了 clean 总净增益的 48%、randomized 的 66%（如 Open Microwave、Hanging Mug、Turn Switch）。
  • 腕部路径受控研究：加入腕部观测（统一路径）使平均成功率从 34.3% → 55.8%；轻量独立路径无未来预测即达 60.9%；固定路径下未来 RGB 监督升至 64.1%，未来 latent 监督进一步升至 69.7%。
  • 部署效率：直接部署重型 V-JEPA 编码器延迟由 196.86 ms 增至 244.99 ms（成功率 63.2%）；将未来 latent 预测限定为仅训练用后，轻量路径在约 200 ms 近基线延迟下达到 69.7% 成功率，实现零推理开销。
  • 主视角结构化监督析因实验：统一腕部路径下加掩码+骨架使平均成功率 71.0% → 73.5%；分离未来 latent 路径下 76.0% → 80.3%（最优配置）；掩码与骨架各有侧重（掩码利于 Adjust Bottle、Blocks Ranking RGB，骨架利于 Grab Roller），组合最优。
  • 读出诊断：分离腕部路径下掩码监督将物体读出 RR(O) 从 1.10 提至 1.46，骨架监督将机器人读出 RR(G) 从 1.20 提至 2.00；K/V 干预结果与注意力模式一致，表明两类目标分别塑造 Task State 中“任务物体”与“执行机器人”两侧信息。
