3DWay: Generalizing Robot Manipulation via 3D Consistent Waypoints

2026-09-08 · 原文 · 翻译 · 2609.08224

提出 3DWay，一种用于机器人操作泛化的3D 一致路点（3D Consistent Waypoints）中间表示，旨在弥合预训练视觉-语言模型（VLM）与连续、高维的 3D 机器人动作模态之间的差距。 核心思想是将 3D 轨迹预测重构为多视角一致的 2D 路点预测 + 几何三角测量，从而无需依赖深度信息即可恢复明确、可执行的 3D 运动意图，同时保留 VLM 强大的视觉-语言先验。 论文指出，现有 2D 轨迹存在深度歧义，2.5D（深度反投影）路点在自由空间中仍然不唯一，而 3DWay 能提供更可靠、更具可扩展性的空间定位与动作引导。

Card 02 论文概述

论文概述

  • 提出 3DWay，一种用于机器人操作泛化的3D 一致路点（3D Consistent Waypoints）中间表示，旨在弥合预训练视觉-语言模型（VLM）与连续、高维的 3D 机器人动作模态之间的差距。
  • 核心思想是将 3D 轨迹预测重构为多视角一致的 2D 路点预测 + 几何三角测量，从而无需依赖深度信息即可恢复明确、可执行的 3D 运动意图，同时保留 VLM 强大的视觉-语言先验。
  • 论文指出，现有 2D 轨迹存在深度歧义，2.5D（深度反投影）路点在自由空间中仍然不唯一，而 3DWay 能提供更可靠、更具可扩展性的空间定位与动作引导。
Card 03 核心贡献

核心贡献

  • 提出利用多视角空间一致性约束生成 3DWay，一种能有效捕捉执行线索和显式空间关系的 3D 轨迹表示。
  • 通过对 NVILA 系列 VLM 进行定制微调，实现多视角一致 2D 路点（2D-MCW）预测，保持多视角监督一致性同时保留 VLM 视觉-语言知识。
  • 提出自适应路点引导集成策略（3DWay-augmented），可与基础 VLA 模型（如 π₀）无缝结合，显著提升新场景和跨机器人本体上的泛化表现。
  • 在仿真（RLBench、VLABench）与真实世界环境中系统性验证了 3DWay 的可执行性、直接零样本部署能力和对基础 VLA 泛化性的增强效果。
Card 04 方法描述

方法描述

  • 给定多视角 RGB 图像、相机内外参和语言指令，先由微调后的 VLM 预测多视角一致的 2D 路点（2D-MCW），再通过标准透视投影约束和三角测量（triangulation）恢复 3D 路点序列。
  • 系统以 NVILA（2B/8B/15B）作为基础 VLM，采用参考轨迹（TCP）提取、RDP 轨迹简化算法、任务相关自动数据筛选等流程构造训练数据，并对原始 VLM 进行两阶段微调（RoboPoint 数据集 + 自建路点数据集）。
  • 在执行层面支持两条路径：(1) 直接用自顶向下（Top-Down）固定策略执行 3DWay 完成简单任务；(2) 在 VLA 微调阶段将局部时间窗口的 3D 路点与机器人状态拼接，作为额外条件输入，增强基础 VLA 的空间感知和动作预测。
Card 05 数据集与资源

数据集与资源

  • 训练数据集：RoboPoint 点预测数据集、RLBench（仿真）、DROID 和 RH20T（真实），共约 290 个任务 / 13.4 万条轨迹。
  • 基础模型：NVILA-2B / 8B / 15B；集成实验使用基础 VLA 模型 π₀。
  • 训练资源：8 张 A100 GPU，最大模型（NVILA-15B）微调不到两天；默认采用双摄像头设置获取多视角观测。
Card 06 评估与结果

评估与结果

  • 评估基准：RLBench（10 个任务，seen/unseen）、VLABench（5 维泛化评估），以及真实环境中 AgileX PIPER 机械臂上的基础任务、视觉泛化和语义指令任务；主要指标为任务成功率。
  • 关键结果：在 RLBench 上，直接执行的 3DWay-TD 在 seen/unseen 设置下分别达到 84.8%/64.0%，明显高于 OpenVLA-OFT、π₀、π₀.5 等基础 VLA 基线；在 VLABench 上平均成功率比 π₀.5 高 6.4%。
  • 在 π₀ 的少数样本微调实验中，3DWay 增强在零样本/few-shot 下将成功率分别提升 +18.4%/+26.4%（10 demos/task），且用 20% 的训练数据即可达到标准微调基线相当的均值；真实环境中基础任务平均成功率从 21.7% 提升到 65.8%，在跨本体与语义指令等困难场景中成功率超 50%。
  • 消融分析表明：更大的 VLM 主干（15B > 8B > 2B）效果更好；对相机外参扰动（尤其是更大扰动）具有一定鲁棒性；多视角一致监督对 3DWay 泛化至关重要（去掉后 RLBench unseen 成功率从 64.0% 降至 22.0%）；该框架可适应不同机器人本体和摄像头配置，性能保持稳定。
