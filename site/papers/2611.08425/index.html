Card 03 核心贡献

核心贡献

  • 提出 VLA-Tug：一个在 VLA 隐层嵌入上做探针的早期失败检测器，在未见任务上把早期检测曲线下面积（early-detection AUC）相比最强学习型基线提升最多 30%，同时以低于 1 ms/步 的开销预测失败模式，top-3 准确率相比多数类基线提升最多 44%。
  • 提出联合校准框架：同时为 FPR（误报率） 和 TPR_early（早期检出率） 提供统计保证（Learn-then-Test），在全部认证运行中两项指标均达标，而基线仅 57%–71%；在分布偏移下，误报目标仍在 40%–86% 的运行中成立，而基线仅为 0%–21%。
  • 提出并验证了失败前区间监督（pre-onset supervision） 策略：只对失败时刻之前的嵌入进行标注训练（对比 pre-onset、onset、post-onset、trajectory 四种标注方式），证明其能显著提升早期检测能力。
  • 给出可解释的 PPV 下界（给定报警条件下真实失败的概率），这对实践部署有意义，而仅提供 FPR 保证的既有方法无法给出此类界。
  • 构建并开源带标注的 VLA 失败数据集：包含约 3,180 条 episode、约 289k（288k+） 个策略步的 VLA 骨干嵌入，并演示了在真实机器人上结合 steering 提升任务成功率。
Card 04 方法描述

方法描述

  • 输入表示：取 VLA 骨干的中间层嵌入（π0.5 的第 18 层、GR00T-N1.7 的第 16 层），分别对 agent camera、wrist camera、指令三种模态的 token 做平均，再拼接为 6144 维（3×2048）的单步嵌入。
  • 探针结构：单层 LSTM（256 隐藏单元） 编码嵌入序列，得到共享隐状态；接三个 MLP 头（各含 64 个 ReLU 隐单元）：失败分数头（sigmoid 输出失败分数）、失败模式头（10 类 softmax）、CLIP 语义对齐辅助头（对比学习对齐当前动作描述）。探针总参数约 6.6M。
  • 训练目标：总损失 = 失败分数二元交叉熵（负/正样本重加权）+ 失败模式交叉熵（模式平衡加权）+ CLIP 对比损失，权重均为 1；使用 Adam（学习率 3e-4、batch 32 条 rollout、最多 100 epoch、早停 patience 15），输入做标准化。
  • 监督策略创新：只使用失败时刻 t_fail 之前（pre-onset / onset 窗口 w）的嵌入作为失败正样本，并丢弃 t_fail 之后的嵌入（避免“已失败轨迹”与成功标签冲突），从而学到“即将失败”的表征而非“已经失败”的表征。
  • 校准与保证：用 Learn-then-Test 在候选阈值集合 Λ̂ 上联合控制 FPR ≤ α 与 TPR_early ≥ β（置信度 1−δ），并在合格集合中选 TPR_early 最大的阈值 h*；同时使用 max-conformal（MC） 与 functional conformal（FC） 校准器，并推导 PPV 的保守下界 πβ/(πβ+(1−π)α)。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO（leave-three-out 划分）、LIBERO-Occ（遮挡变体）、LIBERO-X（按 new-task / new-signature / new-skill 三种递增分布偏移划分，seen/unseen 任务数分别为 175/43、162/56、159–209/9–59）。
  • 真实机器人：8 个真实世界任务，采用 leave-one-out 划分（7 seen / 1 unseen）。
  • 总体规模：共 228 个不同任务（两个仿真环境 + 真实场景）；开源数据集含 3,180 条标注 rollout、约 289k 个策略步嵌入。
  • 标注流程：使用 Gemini（gemini-3.5-flash） 从视频自动生成 timeline（每 3 秒关键词，用于 CLIP 对齐）、失败模式（10 类分类体系）和失败时刻 t_fail，降低人工标注成本。
  • 模型资源：VLA 主干为 π0.5 与 GR00T-N1.7；探针仅 6.6M 参数，可训练、可校准、可边缘部署（论文给出 GPU/CPU 单步延迟与内存占用对比）。
Card 06 评估与结果

评估与结果

  • 评估设置：在 seen（训练任务的留出 episode）与 unseen（留出任务）上评估；对比基线包括失败检测方法 SAFE、ActProbe、STAC、FailureSpot，以及嵌入距离（embedding distance）、动作一致性（action consistency）、latent 三类基线。
  • 主要指标：早期检测的 TPR_early–FPR 曲线下面积、检测及时性（相对标注失败时刻的检测时间）、FPR/TPR_early 的校准覆盖率、失败模式 top-3 准确率、以及 PPV 下界、训练/校准/推理的成本与延迟。
  • 关键结果：

- 未见任务上早期检测曲线下面积相比最强学习型基线提升最多 30%（匹配 FPR 条件下）。

- 联合校准后 FPR 与 TPR_early 目标在每一次认证运行中都成立（基线仅 57%–71%）；分布偏移到未见任务时误报目标仍在 40%–86% 的运行中成立，基线为 0%–21%。

- 失败模式预测 top-3 准确率在未见任务上相比多数类基线提升最多 44%，且单步开销 < 1 ms。

- 真实机器人实验表明：将及时的失败预测与失败模式结合 steering 策略，可提升任务成功率（支持提前停止或专家模型介入）。
