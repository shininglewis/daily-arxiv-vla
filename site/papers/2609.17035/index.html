Card 03 核心贡献

核心贡献

  • 提出 SWIM 部署框架：通过虚拟 rollout 生成完整驱动指令序列，并依靠嵌入式机械智能（本征柔顺性）实现开环执行中的局部接触自适应，使 VLA 推理不进入物理执行回路。
  • 提出 SWIM-VLA 策略：以 扩散动作头（diffusion action head）建模专家指令块的条件分布，捕捉同一任务下多种可行的全身驱动策略。
  • 引入 Visual Soft Proprioception（VSP）：利用仿真中真值体锚点坐标作为辅助监督，促使共享多模态表征保留全身几何信息，从而在有限示教下更易学习。
  • 在平面腱驱动软体机器人上系统评估 packing、reaching、grasping 三类任务，并进行 VSP 与扩散动作头的消融实验。
  • 对比虚拟 rollout 执行与同一策略检查点的直接在线部署，验证部署策略对物理性能的关键影响。
Card 04 方法描述

方法描述

  • 以 OpenVLA-OFT 为骨干，输入为俯视 RGB 图像、语言指令和当前腱长向量（低维本体感知），输出为 H 步（H=15） 双通道绝对电机力矩指令。
  • 多模态编码器 f_θ 生成共享表征 h_t，分别送入扩散动作头 ε_ψ 与 VSP 头 v_φ。
  • 扩散目标：对专家指令块加高斯噪声并训练网络预测噪声，采用噪声预测的 L2 损失建模条件动作分布。
  • VSP 目标：对沿机器人主干由近端到远端排序的 N_b=4 个体锚点预测归一化图像平面坐标，用平均欧氏定位误差监督。
  • 联合训练目标为 L_train = L_act + λ_VSP · L_VSP，训练后丢弃 VSP 头，仅保留 f_θ 与 ε_ψ。
  • 推理阶段：由初始 RGB 观测初始化虚拟场景（HSV 分割 + 平面标定映射物体位置），迭代查询策略并执行前 K=8 步命令，将各段按时间顺序拼接为完整序列 U，最后在物理机器人上开环执行。
Card 05 数据集与资源

数据集与资源

  • 数据来源：MuJoCo 中按专家示教流程生成的驱动空间示教轨迹，每类任务条件采集 4 条不同指令序列的成功轨迹。
  • 训练数据规模：Packing 18 条件/72 条轨迹、Reaching 32 条件/128 条轨迹、Grasping 148 条件/592 条轨迹，共 792 条轨迹，包含同步 RGB、语言指令、腱长、驱动指令与体锚点坐标。
  • 测试集：50 个 packing、50 个 reaching、100 个 grasping 的留出测试条件，每条件 1 次 rollout。
  • 模型与训练配置：OpenVLA-OFT 骨干，LoRA rank 32，bfloat16 混合精度，AdamW 优化器，学习率 3×10⁻⁴ 余弦衰减，批大小 4/GPU，训练 20,000 步。
  • 训练算力：4 张 NVIDIA A100 GPU；策略推理时间约 700 ms/次查询（均值）。
  • 其他超参：指令频率 10 Hz，扩散训练 50 步，DDIM 推理 10 步，λ_VSP=0.15，VSP 头为含 512 维隐层的两层 MLP（GELU 激活）。
Card 06 评估与结果

评估与结果

  • 评估对象为平面腱驱动螺旋连续体机器人 SpiRob（24 关节对数螺旋本体，双腱驱动），仿真与物理平台采用一致的几何、腱驱动接口与俯视单目观测配置。
  • 对比方法：适配到相同驱动空间的 OpenVLA-OFT 基线，以及去掉 VSP、去掉扩散动作头的两组消融。
  • 仿真成功率（留出测试条件）：SWIM-VLA 达 100% / 96% / 88%（Packing / Reaching / Grasping），显著优于 OpenVLA-OFT 的 90% / 72% / 52%。
  • 消融结果：去掉 VSP 降至 98% / 90% / 78%；用确定性 L1 回归替代扩散头降至 94% / 84% / 69%，说明扩散建模对接触丰富的抓取尤为关键。
  • 空间分布分析显示，包络任务对初始位置鲁棒，而 reaching 与 grasping 对目标位置更敏感，去除 VSP 或扩散后外围区域失败显著增多。
  • 物理实验（每策略每任务 20 次）：SWIM 成功率 100% / 80% / 75%，大幅优于同一检查点直接在线部署的 75% / 40% / 25%，表明虚拟 rollout 部署恢复了直接 sim-to-real 迁移中损失的大部分性能。
  • 剩余仿真—现实差距被归因于场景初始化中的物体位置误差以及机器人材料与结构特性差异。
