Card 02 论文概述

论文概述

  • 提出 Uni-TMPO（Unified Trajectory Matching Policy Optimization），一个面向随机扩散与流匹配策略的统一强化学习后训练框架，同时适用于 T2I 图像生成与 VLA 视觉-语言-动作任务。
  • 核心问题是奖励最大化式 RL 后训练会导致 策略模式坍缩（mode collapse）：即使加入参考 KL 或熵正则，策略仍收敛到单一高奖励模式，在 T2I 中表现为图像同质化与 reward hacking，在 VLA 中表现为备选成功策略消失、任务与场景泛化能力下降。
  • 研究目标是：用共享的优化目标保留多样的图像模式与动作策略，同时适配 T2I 与 VLA 两类不同的轨迹结构，并提升 OOD 泛化。
Card 03 核心贡献

核心贡献

  • 统一的 RL 后训练框架：将标准化奖励转化为组内目标分布，用组内前向 KL 匹配奖励诱导分布与策略诱导分布，替代传统的期望奖励最大化。
  • 进度条件化由粗到细（progress-conditioned coarse-to-fine）T2I 采样：训练早期在较早去噪步分支以探索全局结构，后期移到较晚步以细化局部细节，相比 TreeGRPO 调度器提升奖励与多样性并将迭代时间减少 10.2%。
  • 反馈条件化动作块（feedback-conditioned action-chunk）VLA 采样：每条轨迹由多次策略查询产生的动作块组成，各块转移对数概率共同决定轨迹在组内的相对概率。
  • 去除学习式归一化器：在组内同时归一化奖励目标与轨迹概率，使共享归一化项相互抵消，无需 FlowRL 中的 $Z_\phi$。
  • 全面实验验证：在 T2I 单奖励与联合奖励优化下取得最优的奖励–多样性–效率权衡（LGMD 最高比最强基线高 28.4%），VLA 在任务 OOD 上平均超出最强奖励最大化基线 8.0 个百分点、场景 OOD 超出 4.8 个百分点，并包含真机实验。
Card 04 方法描述

方法描述

  • 统一轨迹表示：将 T2I 的完整去噪轨迹与 VLA 的动作块序列统一为上下文条件 $c$ 下的随机轨迹 $\tau$，每个样本组返回 $\{(\tau_i, R_i, s_{\theta,i})\}_{i=1}^{K}$。
  • 奖励诱导目标分布：对组内奖励做标准化得 $\widetilde{R}_i$，构造 Boltzmann 目标 $q_i = \exp(\beta\widetilde{R}_i)/\sum_j \exp(\beta\widetilde{R}_j)$，温度 $\beta$ 控制偏好的强弱。
  • 策略分布：由轨迹分数经组内 softmax 得到 $p_{\theta,i} = \exp(s_{\theta,i})/\sum_j \exp(s_{\theta,j})$（log-softmax 稳定实现）。
  • 前向 KL 匹配损失：$\mathcal{L}_{\mathrm{TM}}(\theta)=\frac{1}{\|\mathcal{B}_{\mathrm{valid}}\|}\sum_{\mathcal{G}}\mathrm{KL}(q_{\mathcal{G}}\\|p_{\theta,\mathcal{G}})$，仅优化奖励跨度超过阈值 $\epsilon_R$ 的有效组；梯度形式为 $\sum_i (p_{\theta,i}-q_i)\nabla_\theta s_{\theta,i}$。
  • T2I 轨迹构造：共享前缀分支 + 有界 Beta 进度调度器选择分支层级，轨迹分数为各随机转移对数密度之和（式 12）。
  • VLA 轨迹构造：每次查询由动作专家依据当前观测与语言指令生成动作块，执行前缀后重新规划，轨迹分数为各有效块分数的长度归一化平均（式 14）。
  • 在线策略更新：奖励与环境转移不可微且被 detach，梯度仅通过随机策略转移传播；VLA 中梯度通过可训练的动作专家，视觉-语言主干保持冻结。

Card 06 评估与结果

评估与结果

  • 评估环境与基线：T2I 对比 DAG-DB、DGFS-SubTB、Flow-GRPO、TreeGRPO、GARDO 与未后训练的 FLUX.1-dev；VLA 对比奖励最大化类方法（如 π_RL、GRAPE、ConRFT、SimpleVLA-RL 等）。
  • T2I 主要结果（Table I）：Uni-TMPO 在组合生成任务取得 GenEval 0.954、PickScore 22.967、HPS 0.305、ImgRwd 1.163、LGMD 0.136、Cos.Div. 0.248，迭代时间仅 91.9 s（TreeGRPO 为 126.2 s）。
  • 文字渲染任务：OCR 0.951、PickScore 22.281、HPS 0.316、ImgRwd 1.118、LGMD 0.115、Cos.Div. 0.235，时间 76.3 s。
  • 人类偏好对齐任务：PickScore 24.301、HPS 0.380、ImgRwd 1.605、LGMD 0.199、Cos.Div. 0.258，时间 68.3 s，均为最优或次优。
  • 多样性与效率：LGMD 最高比最强基线提升 28.4%，定性对比显示相同提示下 Uni-TMPO 在物体外观、美学风格与空间布局上的变化明显大于 Flow-GRPO；迭代时间较 TreeGRPO 减少 10.2%。
  • VLA 结果：在 ID 成功率上取得最佳，OOD 任务泛化平均超出最强奖励最大化基线 8.0 个百分点，OOD 场景泛化超出 4.8 个百分点。
  • 真机验证：当原本更高奖励的目标不可达时，多样的备选动作策略仍能支持任务完成，验证了保持多模式的实际价值。
