CometVLA: Co-Training on an Embodied Data Pyramid towards Physical Understanding

2026-08-31 · 原文 · 翻译 · 2608.30289

论文提出 CometVLA，一个端到端的视觉-语言-动作（VLA）模型框架，旨在将物理常识（physical commonsense）注入机器人操纵策略，弥合 VLM 物理理解与 VLA 动作生成之间的鸿沟。 现有物理 VQA 数据通常与机器人动作域"脱离"（disembodied），且缺乏与真实操作场景的对齐。论文通过构建与机器人动作数据和具身形态严格对齐的 CometData 语料库和 CometBench 基准，系统地验证了增强的物理理解能否真正提升下游动作生成表现。 核心思路是从数据、模型架构、训练策略三个层面系统性解决物理常识无法有效迁移至机器人操纵的问题。

Card 03 核心贡献

核心贡献

  • CometData 与 CometBench（数据层面）：首个与机器人动作数据视觉域和具身形态对齐的具身物理常识 VQA 语料库（约 100 万 QA 对、超 180 万张图像）及评估基准（2000 个问题）；验证了在 CometBench 上的 VLM 表现与动作生成表现呈正相关。
  • Global Action Prior（GAP）token（架构层面）：一种紧凑的可学习信息瓶颈，作为自回归骨干与扩散动作专家之间的唯一通信接口，有效聚合跨样本的动作先验，并防止低层控制干扰预训练 VLM 的多模态表征。
  • CometVLA 协同训练（训练层面）：利用知识隔离（knowledge insulation）技术实现 VLM-VLA 第一阶段协同预训练，覆盖遥操作、仿真、第一视角轨迹和 VQA 各层级的"具身数据金字塔"。
  • 系统评估与相关性分析：在真实世界双机械臂操纵任务和 RoboTwin 2.0 仿真基准上超越现有 SOTA 方法；通过域级 Pearson 相关性分析和线性探针实验验证了物理理解预训练对操纵性能的真实贡献。
Card 04 方法描述

方法描述

  • CometData 生成管线：从遥操作、仿真、第一视角轨迹多种异构源收集数据，通过"物理感知中间件"（提取动力学关键帧、描述交互事件、将低级本体感受/动作信号转为语义化物理状态描述），再由 16 个分类生成器覆盖 5 大域（空间推理、任务理解、物理与动力学、错误与工具、可供性）生成 VQA 对。
  • CometVLA 架构：基于 Qwen3-VL-4B 预训练骨干，统一自回归视觉-语言建模（L_AR + L_fast，含 FAST 动作分词器）与扩散式连续动作生成（flow matching 目标 L_fm）；通过 stop-gradient 屏障将动作专家与骨干隔离。
  • GAP token 设计：插入骨干 token 序列，经分离的潜在路径传递至动作专家，在注意计算时可穿越 stop-gradient 边界，实现受控信息流而防止梯度泄漏；类似 [CLS] token 的全局语义聚合器，条件化 DiT 动作专家的生成。
Card 05 数据集与资源

数据集与资源

  • 预训练数据：AgiBot-World-Beta（遥操作）、InternData-A1（仿真）、EgoLive（第一视角视频）、EgoDex（第一视角视频）、通用 VQA 数据（Cambrian-1）、以及 CometData（具身物理 VQA）。
  • CometData：约 100 万 QA 对，包含超 180 万张图像；CometBench：2000 个平衡留出子集问题，经人工审核。
  • 模型规模：Qwen3-VL-4B 骨干 + DiT-B flow-matching 动作头 + FAST tokenizer；动作空间填充至 32 维（双机械臂格式）。
  • 训练资源：4 节点 × 8 张 H200 GPU 分布式训练。
Card 06 评估与结果

评估与结果

  • 真实机器人实验（AgiBot Robotics G1 双机械臂，梳妆台整理场景，5 类化妆品对象，每任务 16 次试验）：成功率分别为 bb cream 75.00%、liquid foundation 31.25%、lotion 37.50%、makeup sponge 93.75%、serum 43.75%。
  • RoboTwin 2.0 仿真基准：CometVLA 在 easy（clean）split 上达 89.24% 成功率，在 hard（randomized）split 上达 88.38%，优于 π0、π0.5、RDT、X-VLA、Motus、JEPA-VLA、HALO、LingBot-VLA 等基线。
  • 消融实验：移除具身物理 VQA（w/o phys. VQA）导致最大性能下降；移除 GAP token 也持续降低性能，验证了各组件贡献。
  • VLM-VLA 相关性分析：5 个语义域均呈现正相关，其中 Spatial Reasoning（r=0.721）相关性最强，Physics & Dynamics（r=0.645）次之，说明几何/空间先验对操纵控制迁移最有效。
  • GAP token 分析：t-SNE 可视化显示 GAP token 保留了全局语义结构并形成交互相关的局部簇；线性探针实验中 GAP token 在抓取器状态（+7.0%）、运动方向（+0.7%）、运动幅度（+3.9%）上均优于 VLM-mean 均值池化基线，尽管其维度（1024-d）仅为 VLM 骨干（2560-d）的 2.5 倍更小。
