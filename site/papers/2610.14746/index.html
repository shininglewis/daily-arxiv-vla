Card 02 论文概述

论文概述

  • 论文提出 BridgeWAM，一种基于 Bridge-of-Experts (BoE) 架构的世界动作模型（World Action Model, WAM），用于从视觉观测、语言指令与本体状态预测机器人动作。
  • 针对现有 WAM 通过密集、逐层 Mixture-of-Transformers (MoT) 注意力耦合视频专家与动作专家的问题：动作预测被暴露于无关视觉特征、强制两个专家深度匹配、引入冗余计算。
  • 目标是构建一个紧凑的潜在接口，使动作专家能选择性读取任务相关视觉信息，同时让动作监督信号反向塑造视觉表征，并解耦专家深度以降低推理开销。
Card 03 核心贡献

核心贡献

  • 提出 BoE（Bridge-of-Experts）视频–动作接口：用 32 个 Latent Bridge Queries (LBQs) 构建受限潜在空间，聚合视觉、语言与本体先验为统一潜在表示；联合视频–动作优化使动作梯度经 LBQ 回传，引导视频专家产生更利于控制的表征。
  • 提出 BridgeWAM：解耦专家深度的具体实例，采用 30 层 Video Expert + 2 层交替 cross–self-attention Action Expert，总参数 5.06B，兼顾表征能力与效率。
  • 在仿真与真实机器人任务上证明 BoE 克服了 MoT 的上述局限，并配套系统的消融实验、动作条件化的视觉路由可视化与效率分析。
  • 消融支持联合表征适应与统一 LBQ 条件化设计的有效性。
  • 相对 Fast-WAM，单样本推理 FLOPs 降低 28.72%，真实机器人延迟降至 77.1 ms（2.47× 加速）。
Card 04 方法描述

方法描述

  • LBQ 构建：b_t = f_V(o_t, l, s_t; θ_V, Φ) ∈ R^{M×d_V}, M=32，将当前观测、语言指令与机器人状态编码为固定数量的桥接查询表示。
  • 受限读写机制：未来视频查询可读取视频与 LBQ 的 K/V，而 LBQ 查询仅读取当前帧与 LBQ 的 K/V，排除未来视频 token；其中视频 token 用 3D RoPE，LBQ 用 identity RoPE。
  • 跨专家传递：最终桥接表示 b_t = B^{L_V} 经投影 B̂ = Π(b_t) 进入 Action DiT 空间，动作查询仅读取 LBQ 的 K/V，不直接接收文本–状态 token 或密集视频 K/V。
  • 训练：同时微调两个专家与可学习 LBQ 嵌入 Φ，使用等权重的视频与动作 flow-matching 损失；视频损失更新 Video Expert 与 Φ，动作损失则通过可微 LBQ 路径更新 Action Expert、Π、Φ 乃至 Video Expert。
  • 推理效率设计：LBQ 在推理时仅由当前上下文计算一次，并在整个动作去噪过程中复用；推理阶段可省略未来视频生成而不改变动作专家的条件来源。
  • 动作头设计：沿用 GR00T N1 的交替结构，cross-attention 从 LBQ 检索信息，self-attention 协调动作块内部时序；动作 token 使用学习到的绝对位置嵌入，self-attention 使用 1D RoPE；各模块含残差与 AdaLN 时间步条件。
Card 05 数据集与资源

数据集与资源

  • 仿真基准：LIBERO、LIBERO-Plus、LIBERO-Pro、RoboTwin 2.0。
  • 真实机器人任务：合上笔记本电脑，以及抓取放置饮料、钢笔、鼠标等任务，并包含物体高度、类型、颜色、位置或数量等变体。

  • 初始化与训练：Video Expert 由 Wan2.2-TI2V-5B 初始化；LIBERO 训练 10 个 epoch，RoboTwin 2.0 训练 5 个 epoch（29,355 步）。
  • 数据规模：RoboTwin 2.0 使用 Fast-WAM 的 27,500 条演示（2,500 clean + 25,000 randomized），50 个任务，每任务每设定 100 次试验。
  • 计算设备：仿真性能剖析在 NVIDIA H20Z 上完成，真实机器人推理在 NVIDIA RTX 5090 上测量。
Card 06 评估与结果

评估与结果

  • 评估设置：LIBERO 使用 2 个 RGB 视角，RoboTwin 2.0 使用 3 个视角；评估时使用 10 步动作去噪；LIBERO-Plus 为七类扰动下的零样本评测。
  • LIBERO / LIBERO-Pro：平均成功率 98.25%（较 Fast-WAM 高 1.45 点），LIBERO-Object 达 100%，LIBERO-Pro 为 53.7%。
  • LIBERO-Plus（零样本）：平均成功率从 Fast-WAM 的 49.5% 提升至 72.2%，Camera 扰动取得最佳 56.5%；论文报告 pooled success 为 72.24%。
  • RoboTwin 2.0：50 任务平均成功率 Clean 89.84% / Randomized 90.22%；在 *Stack Bowls Three* 随机化设定取得 90%（优于 Faster-WAM 的 78% 与 LingBot-VA 的 83%），*Place Object Stand* 98%，*Move Pillbottle Pad* 100%。
  • 效率结果：H20Z 实测延迟 88.05 ms vs Faster-WAM 的 321.16 ms（约 1/3.65）；按各自原生配置测算 FLOPs 减少 54.67%；相对 Fast-WAM 单样本推理 FLOPs 降低 28.72%，真实机器人延迟 77.1 ms（2.47× 加速）。
  • 消融结论（RQ1–RQ4）：验证了视频表征需与动作学习联合适应、专用 LBQ cross-attention 优于 MoT 式读出、统一潜在条件化优于直接暴露多模态 token，以及 Action Expert 深度与潜在空间容量对泛化的影响。
  • 定性分析：动作条件化的视觉路由显示，在多种扰动下策略对目标物体与任务终点给予优先注意力。
