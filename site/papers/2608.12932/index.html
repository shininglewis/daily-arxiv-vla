FlashDrive: Flash Vision-Language-Action Inference for Autonomous Driving

2026-08-13 · 原文 · 翻译 · 2608.12932

论文提出 FlashDrive，一个用于自动驾驶 Vision-Language-Action（VLA）模型推理加速的算法-系统协同设计框架，解决 VLA 模型端到端推理延迟过高、无法满足实时控制需求的问题。 核心洞察在于 VLA 推理并非单一瓶颈，而是由编码（Encode）、预填充（Prefill）、解码（Decode）、动作生成（Action）四个阶段级联而成，每个阶段存在不同类型的冗余，需要逐一针对优化。 在 Alpamayo 1.5-10B 模型上，FlashDrive 将端到端延迟从 717 ms 降至 151 ms（4.7× 加速），控制频率从 1.4 Hz 提升至 6.6 Hz，同时几乎不损失轨迹预测精度。

Card 03 核心贡献

核心贡献

  • 提出流式推理（Streaming Inference）：利用车载视频帧的时间重叠性，仅编码新帧并复用历史帧的 KV 缓存，将编码和预填充阶段成本降低约 3×；引入流式注意力掩码、pre-RoPE 键存储和针对动作专家的流式微调以恢复精度。
  • 提出推测式推理（Speculative Reasoning）：利用驾驶领域推理 token 的低熵和强块内相关性，采用 DFlash 扩散模型作为非自回归并行草稿模型，两层草稿模型达到约 5.6 token 的平均接受长度，解码速度提升 4.7×（相对系统优化基线为 2.9×）。
  • 提出自适应步长流匹配（Adaptive-Step Flow Matching）：利用 flow-matching 速度场"端点陡峭、中间平缓"的 U 形结构，缓存中间步骤速度并跳过冗余计算，将动作阶段延迟从 113.9 ms 降至 47.6 ms（2.4× 加速），精度损失可忽略。
  • 结合 W4A8 量化（ParoQuant + Marlin 内核）和系统级优化（CUDA Graph 编译、内核融合），系统优化单独带来 1.40× 加速，量化进一步减少 14% 延迟。
Card 04 方法描述

方法描述

  • 编码与预填充：滑动窗口中约 75% 的帧在上一时间步已被编码，通过流式 KV 缓存复用避免重复计算；针对 view-major token 顺序插入新帧 token，采用流式注意力掩码保持跨视角因果性，并以 pre-RoPE 形式缓存键以处理位置偏移。
  • 解码加速：驾驶领域推理链（chain-of-causation tokens）结构化和可预测性强，采用扩散语言模型并行生成整个候选块，而非逐个 token 生成；仅将目标模型最后 8 个 token 的隐藏状态注入草稿层 KV 缓存以降低验证成本。
  • 动作生成：流匹配去噪过程中速度场中间区域高度冗余，通过缓存并复用中间步骤速度，将计算集中在轨迹结构形成的端点步骤。
  • 量化策略：VLM 主干采用 W4A8（4-bit 权重 + 8-bit 激活）以同时加速内存受限的解码和计算受限的预填充，动作专家保持 BF16 精度保护敏感输出。
  • 系统优化：将各流水线阶段编译为 CUDA Graph（减少 CPU 调度开销），融合 QKV 投影与 MLP 门控/升维投影内核，并采用 max-autotune 编译模式。

Card 06 评估与结果

评估与结果

  • 端到端加速：在 NVIDIA RTX PRO 6000 上延迟从 716.9 ms 降至 151.4 ms（4.7×）
  • 跨设备部署：Jetson Thor（4.0×）、RTX 3090（4.9×）、RTX 4090（6.0×）、RTX 5090（4.8×）；6 轨迹样本场景下加速比达 9.6×–10.6×，RTX 3090/4090 上基线 OOM 而 FlashDrive 可运行
  • 开环精度：minADE₆@6.4s 仅从 0.767 m 增至 0.844 m（约 0.08 m 退化），minADE₁@6.4s 从 1.705 m 改善至 1.573 m
  • 闭环评估（AlpaSim）：碰撞率从 0.19 降至 0.15，偏离道路率从 0.41 降至 0.32，规划偏差从 0.24 降至 0.16，每步回滚延迟从 1150 ms 降至 463 ms（2.5×）
  • 消融实验：系统优化单独 1.40×；流式推理使编码 3.4×、预填充 3.2×；推测推理使解码 2.9×（相对系统优化基线）；自适应步长使动作阶段 2.4×；所有算法增益合计节省 337.3 ms
  • 泛化验证：FlashDrive 在 Alpamayo 1（R1）上同样取得 4.5× 加速，验证了方法跨模型代际的通用性
