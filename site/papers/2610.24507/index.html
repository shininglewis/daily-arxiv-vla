Card 03 核心贡献

核心贡献

  • 构建 GazeAct 数据集：人类注视直接标注在机器人相机画面坐标系中，并通过跨视角对齐扩展为多视角注视监督（12,000 条示教、40 个任务、5 个场景域、300 Hz 注视）。
  • 设计基于屏幕遥操作、硬件 TTL 触发与时钟同步的数据采集与跨视角注视迁移流程，实现高频注视与多视角图像、本体感知、动作的精确对齐。
  • 提出注意力正则化方法：将注视转换为视觉 token 上的 patch 级分布，用 KL 散度约束语言条件下的视觉注意力，训练期使用、部署期移除。
  • 在 18 个实机任务上验证有效性（平均成功率 48.1% → 58.6%，单任务最多提升 25 个百分点），并证明方法可跨架构（π0.5、OpenVLA）与跨场景（LIBERO-Spatial）迁移。
Card 04 方法描述

方法描述

  • 数据采集：在 ALOHA 遥操作平台上，操作员观看屏幕上的机器人相机画面（左腕、右腕、固定俯视三视角），由 Tobii Pro Spectrum 眼动仪以 300 Hz 记录注视点，注视点天然表达在机器人图像坐标中。
  • 时间同步：硬件 TTL 触发定义试验起止边界，chrony/NTP 同步时钟将每个 300 Hz 注视样本对齐到最近的机器人时间步与相机帧。
  • 跨视角注视迁移：先用棋盘格标定多相机内外参，将源视角注视点反向投影为 3D 点并投影到目标视角得到几何候选；再用 LightGlue 局部特征匹配在几何引导的搜索区域内精修；不可靠时回退到中心先验。
  • Patch 级注视分布：以高斯核在注视位置生成热图，并在短时间窗内聚合以抑制微跳视与抖动，再按视觉 token 网格池化为归一化分布 \(G_t^i\)。
  • 注意力正则化：取最终视觉-语言融合层中语言查询对视觉 key 的注意力 \(S_t^i\)，损失为 \(\mathcal{L}_{\text{attention}}=\lambda D_{\mathrm{KL}}(G_t^i \\|S_t^i)\)，与动作损失相加联合训练；推理时与基线 VLA 完全相同。
Card 05 数据集与资源

数据集与资源

  • GazeAct 数据集：12,000 条实机示教，40 个任务，5 个域（home / hospital / kitchen / laboratory / sports），20 名参与者，每任务 300 条示教，平均轨迹约 30 秒。
  • 同步模态：多视角 RGB 图像、本体感知、动作、300 Hz 注视（含时间戳、归一化 2D 坐标、当前激活视角）。
  • 模型骨干：主实验使用 π0.5，泛化实验使用 OpenVLA；动作块长度 h = 50。
  • 训练设置：实机策略训练 40k 步；LIBERO-Spatial 结果报告 30k 步。

Card 06 评估与结果

评估与结果

  • 实机评估：18 个真实任务，每任务每方法 100 次 rollout（50 次标准 + 50 次鲁棒性试验，后者改变物体位置、外观或加入干扰物），报告 95% Wilson 置信区间。
  • 主要指标：标准成功率、鲁棒性成功率、总体成功率、绝对提升百分点（pp）。
  • 实机主结果：标准 55.8% → 66.8%，鲁棒性 40.3% → 50.3%，总体 48.1% → 58.6%（+10.5 pp）；所有任务均有提升，最大增益为 “pick cup and place on plate” 的 +25 pp（39% → 64%）。
  • 正则化强度消融：λ=0.001 最优（平均 73.5%，基线 59.5%），λ=10 时在所有任务上低于基线，说明注视更适合作为“软监督”。
  • 注视来源消融：真实人类注视平均 73.5% 最优，伪注视（显著性估计器）67.2%、中心先验 55.5%、均匀分布 49.5%，说明增益并非来自通用注意力塑形。
  • 跨架构：π0.5 平均 51.0% → 66.0%（单任务 +9~25 pp），OpenVLA 平均 45.2% → 55.7%（单任务 +7~14 pp）。
  • 仿真迁移：LIBERO-Spatial 上 57.9% → 69.6%，全部 10 种空间配置均有提升。
  • 注意力可视化：基线注意力较分散或偏向背景，正则化后更集中于按钮、工具、接触点与目标区域等可操作区域。
