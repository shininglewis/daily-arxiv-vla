Role-Conditioned Sub-Token Routing for Efficient Vision-Language-Action Policies

2026-08-19 · 原文 · 翻译 · 2608.18410

论文针对视觉-语言-动作（VLA）模型在长多模态 token 序列下的高推理开销问题，提出了一种新的压缩思路：在保留 token 的同时进一步压缩每个 token 内部的 value 表示。 现有方法主要依赖视觉 token 剪枝，但过度剪枝会完全丢失被移除 token 的信息，在闭环控制中误差会沿轨迹传播；而直接照搬子 token 压缩到 VLA 效果不佳，因为感知、语言理解和控制所需的信息在多模态表示中分布不同。 论文提出 Role-Conditioned Sub-Token Routing（RoleSub），通过学习的方式决定保留哪些 value 分组，并将该方法应用于视觉和语言表示，实现极低 KV 预算下的高效 VLA 推理。

Card 02 论文概述

论文概述

  • 论文针对视觉-语言-动作（VLA）模型在长多模态 token 序列下的高推理开销问题，提出了一种新的压缩思路：在保留 token 的同时进一步压缩每个 token 内部的 value 表示。
  • 现有方法主要依赖视觉 token 剪枝，但过度剪枝会完全丢失被移除 token 的信息，在闭环控制中误差会沿轨迹传播；而直接照搬子 token 压缩到 VLA 效果不佳，因为感知、语言理解和控制所需的信息在多模态表示中分布不同。
  • 论文提出 Role-Conditioned Sub-Token Routing（RoleSub），通过学习的方式决定保留哪些 value 分组，并将该方法应用于视觉和语言表示，实现极低 KV 预算下的高效 VLA 推理。
Card 03 核心贡献

核心贡献

  • 提出 RoleSub 方法，将正交值空间分解、可学习的潜在角色表示和按 token 类型分配的值预算结合起来，使子 token 路由适配 VLA 控制任务，且无需预定义语义角色。
  • 在匹配视觉 KV 预算的设置下，RoleSub 在 36 个 LIBERO 配置中的 33 个优于训练后的纯 token 剪枝基线，尤其在激进压缩和长时程任务上增益最大。
  • 揭示 token 保留与值宽度保留在 VLA 策略中具有不同的作用：语言 token 的移除高度敏感，而其 value 表示在独立压缩时可被压缩 16 倍（仅保留 1/16 分组）而无明显性能损失。
  • 组合视觉与语言压缩后，可将完整多模态前缀的 KV 降至原始大小的 9.2%–11.3%，同时保持大多数 LIBERO 套件的强控制性能。
Card 04 方法描述

方法描述

  • 方法分为两个维度：token 级缩减（保留哪些 token）与子 token 路由（每个保留 token 内保留多少 value 信息），二者独立控制。
  • 对每个保留 token，其 value 向量先通过固定的正交矩阵 R（随机 Stiefel 矩阵初始化并冻结）变换到正交路由空间，再划分为 S=16 个分组（每维 256）。
  • 轻量潜在角色估计器为每个 token 生成 C=6 维软角色表示；路由分数由三部分加权求和：token 隐藏状态分数、角色投影分数、语言上下文汇总分数。
  • 通过 Top-K 离散选择确定保留哪些分组，并使用 straight-through estimator 进行反向传播；不同 token 类型（视觉/语言/本体/动作）可设置独立的平均分组预算，并依据角色优先级在 token 间再分配。
  • 训练时冻结预训练 VLA 骨干，仅联合训练 LoRA 适配器、路由函数和角色估计器，使用 L1 动作预测损失。
Card 05 数据集与资源

数据集与资源

  • 模型：OpenVLA-OFT-7B，基于 Llama-2-7B 语言模型与 SigLIP + DINOv2 视觉特征，支持并行动作解码、动作分块、双相机输入。
  • 训练数据：LIBERO RLDS 数据（no-op 过滤后）：Spatial（432 个 episode）、Object（454）、Goal（428）、LIBERO-10（379）。
  • 优化配置：LoRA（秩 32、缩放 16、零 dropout）、AdamW、学习率 2×10⁻⁴、有效 batch size 8。
  • 参数量：总参数 7.65B；LoRA 可训练参数约 110.8M，路由头约 4.20M，潜在角色估计器约 0.55M；正交矩阵冻结，无额外参数。
  • 视觉 token：原始 512 个视觉 token（双相机各 256），实验中保留 8/16/32 个；value 维度 d_v=4096。
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO 四个套件（Goal、LIBERO-10、Object、Spatial），每个套件 10 个任务，每任务运行 50 次试验，固定模拟器配置与随机种子，指标为任务成功率。
  • 与训练后匹配预算的 token-only 剪枝相比，RoleSub 在 33/36 个视觉 KV 设置中胜出；在 LIBERO-10 上最高提升 10.5 个百分点，Goal 上最高提升 8.7 个百分点；3 个例外均出现在 8-token 下接近饱和的 Object/Spatial 套件，差距仅 0.1–1.1 点。
  • 训练无关的 token-only 剪枝在 K_vis=1 对应的 12 个操作点中，有 10 个成功率为零，表明激进预算下单纯增加 token 剪枝不可行。
  • 与plain sub-token routing（R=I、无角色条件、统一预算）相比，在保留 8 个视觉 token 时 RoleSub 将 LIBERO-10 从 59.8% 提升至 74.2%，Goal 从 89.4% 提升至 95.2%。
  • 语言值压缩实验显示，即使 K_lang=1（每语言 token 仅保留 1/16 分组），Goal/LIBERO-10/Object/Spatial 均接近稠密基线（如 Goal 98.0 vs 98.8，LIBERO-10 94.8 vs 94.8），证明语言 token 位置关键而大部分 value 宽度冗余。
  • 组合视觉+语言压缩（K_vis=K_lang=1）后，总 KV 降至 9.2%–11.3%；Object/Spatial 性能与仅视觉压缩时几乎持平（差异 -1.4 至 +0.7 点），Goal 损失 0.8–2.9 点，而 LIBERO-10 损失约 10–11 点，显示长时程任务对语言压缩更敏感。
