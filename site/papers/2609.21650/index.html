SynthDemo-RL: Breaking the Zero-Reward Barrier in VLA Adaptation with LLM-Guided Synthetic Demonstrations

Card 03 核心贡献

核心贡献

  • 提出 SynthDemo-RL 流水线，将自动化教师、VLA 离线蒸馏与稀疏奖励 PPO 结合，教师无需人类演示或任务特定训练即可把仿真器特权状态转化为成功操作轨迹。
  • 提出 reward coverage（奖励覆盖率） 指标，即至少观察到一次成功的任务比例，作为平均成功率的补充诊断量，揭示平均值所掩盖的零奖励任务。
  • 在 LIBERO-PRO 扰动基准上，蒸馏合成轨迹拯救了适应前 0% 成功的全部 27 个任务，而同等 RL 算力的稀疏奖励对照（直接 PPO）仅拯救 10 个、其余 17 个仍为 0%。
  • 在标准 LIBERO 上无人类演示达到 96.0%，距每任务 50 条人类演示的 π0.5（97.7%）仅差 1.7 个点。
  • 对合成 SFT 的局限给出分析：合成轨迹与人类轨迹在运动统计和冻结基座 flow-matching 损失上存在系统性差异。
Card 04 方法描述

方法描述

  • 自动化教师流水线：使用 Ground-truth 物体位姿、度量深度、实例分割与相机参数，通过反向投影得到 3D 点云；由预训练抓取生成器 GraspGen 提出 6-DoF 抓取，再用脚本控制器执行航点序列（approach/grasp/lift/place 或 contact-sweep-retreat）。
  • LLM 引导调优：失败后由 GPT-5.5 依据失败阶段与原因、观测图像、success library（其他任务上有效的配置）与 failure library（本任务已试过的配置）修订航点序列与接触深度、接近角、抬升与侧向回退、放置偏移等参数。
  • 闭环执行：按 proportional servo 逐步位置校正跟踪航点，应对接触丰富阶段的偏差；教师优先保证覆盖率而非最优性，直到每个任务都产出成功轨迹。
  • 离线策略蒸馏：学生为 π0.5（flow-matching VLA，从第三人称与腕部图像、本体状态与指令预测连续动作块）；教师在 LIBERO-Object 上约需 1.7 分钟/回合，故改为离线蒸馏；训练遵循 openpi 配方的标准 flow-matching 目标，30,000 步、batch size 32、峰值学习率 5×10⁻⁵。
  • RL 精炼：采用 PPO（经 RLinf 框架）与二值任务成功奖励、无奖励塑形；为获得可解似然使用 Flow-SDE，每个 MDP 步执行一个动作块，稀疏奖励在回合终止时给出，用 GAE 在块步上计算（无独立 critic）；3 个去噪步、探索噪声 0.5、5 动作块（7-DoF），γ=0.99、λ=0.95、clip 0.2、dual clip 3.0、value clip 0.2，无 KL 惩罚与熵奖励。
Card 05 数据集与资源

数据集与资源

  • 基准数据集：LIBERO（LIBERO-Spatial 10 任务、LIBERO-Object 10 任务、LIBERO-Goal 9 任务）、LIBERO-PRO（Position 与 Task 两个扰动轴）、RoboTwin 2.0（单臂 Agilex Piper，4 个任务）、真实机器人 Trossen WidowX AI。
  • 策略骨干：π0.5（flow-matching VLA），标准 LIBERO 从公开基座检查点微调，LIBERO-PRO 适配从自训练的 π0.5-LIBERO 出发。
  • 数据规模：每任务 50 条成功合成轨迹（无原 LIBERO 回放）；教师按任务保留 50 条成功轨迹为止。
  • 训练资源：8 张 MI300X GPU；RL 每次迭代采集 8 轮 rollout，每轮 64 个并行环境运行 240 个块步，LIBERO-PRO 平均 188 次迭代（2310 万个块步）。
  • 评估规模：每任务 50 次试验，LIBERO-PRO 使用 3 个 SFT 随机种子。
Card 06 评估与结果

评估与结果

  • 评估环境为 LIBERO / LIBERO-PRO 仿真与 RoboTwin 2.0，成功由仿真器内置成功检查器判定；报告各 suite 平均成功率与 reward coverage。
  • 标准 LIBERO：SynthDemo-RL 达 96.0%（Spatial 96.2 / Object 98.6 / Goal 93.3），人类演示参考 (d) 为 97.7%、(d') 为 97.4%；纯 SFT 仅 56.7%，RL 相对 SFT 提升约 40 个点并全面超过教师单次尝试成功率。
  • LIBERO-PRO：适应前 π0.5-LIBERO 在 57 个评分任务中有 27 个为 0%；直接 PPO 对照仅拯救 10 个（15 个 Position 中救 2 个、12 个 Task 中救 8 个），仍有 17 个为 0%；SynthDemo-RL 拯救全部 27 个，Position/Task 轴平均成功率达 97.8% / 97.1%，覆盖率 29/29 与 28/28。
  • 覆盖率对试验预算敏感：若只跑 10 次试验，π0.5-LIBERO 覆盖 26.6、对照 35.4、SynthDemo-SFT 53.6、SynthDemo-RL 57（满分 57）；要求 50 次中至少 5 次成功时，SFT 覆盖 53/57、SynthDemo-RL 覆盖 57/57。
  • 初始化成功率与 RL 后结果强相关（point-biserial r=0.71）：零成功初始化平均收于 26.0%，有至少一次成功的初始化平均收于 91.7%。
  • 教师消融：无 LLM 修订时冻结初始配置有 12/57 任务无成功轨迹，任务均值成功率为 54.4%（Position）/47.6%（Task）；启用调优后达 65.6%/71.0%，平均每任务额外产生 3.3 个有效配置。
  • RoboTwin 2.0：SynthDemo-RL 把 SFT 平均从 55.5% 提升至 74.3%，数值接近 SimpleVLA-RL（72.1%，其使用 1000 条专家演示/任务），但在 place_cup 与 move_can 上仍低于教师。
  • 真实机器人：在 MuJoCo 孪生中训练的检查点以开环方式在 Trossen WidowX AI 上执行，stack、banana、return、distractor 四个条件每条件 20 次试验全部成功；人类演示基线仅 stack 达 50%，其余三条件 0%。
