Card 02 论文概述

论文概述

  • 论文研究双臂视觉-语言-动作（VLA）模型中的 Arm-wise Compositional Generalization (ACG)，即在新顺序、同步或跨任务要求下重用熟悉的原子技能。

Card 03 核心贡献

核心贡献

  • 提出 ACG-Bench：系统评估双臂技能重组在 reordering、synchronization、Sync+Reorder 和 cross-task composition 下的泛化能力。
  • 进行统一实证研究：在相同 π0.5 骨干、源数据集和执行协议下，比较代表性数据增强策略和架构策略。
  • 提出设计洞见与 AE-VLA：发现 SkillLoRA（技能条件参数）与 AWA（arm-wise attention）具有互补优势，并在仿真和真实机器人上验证其组合效果。
  • 展示 AE-VLA 在仿真中达到 21.53% 泛化成功率，在真实 SO101 机器人上达到 39.00% 平均成功率。
Card 04 方法描述

方法描述

  • 基于预训练 π0.5 构建双臂 VLA 策略，保留视觉编码器、视觉–语言模型和 flow-matching 动作专家。
  • 研究三个设计选择：arm-token grouping、SkillLoRA 和 arm-wise attention (AWA)。
  • Token Group：用两组各 H=50 的动作 token 分别表示左右臂，共享同一动作专家和输出投影。
  • SkillLoRA：为 K=10 个原子技能类型维护低秩适配器，每臂独立 router 根据提示/状态选择技能适配器，应用于动作专家的注意力与 FFN 层。
  • AWA：限制跨臂动作 token 的注意力连接，允许全局查询读取两个局部前缀，同时保留共享全局上下文。
  • 训练目标：flow-matching 动作损失加 0.1 倍路由交叉熵损失；联合微调共享骨干、动作专家、适配器和路由器。
Card 05 数据集与资源

数据集与资源

  • 使用 ACG-Bench，基于 ManiSkill 和 RoboTwin 2.0 的任务/专家程序生成流程构建。
  • 六个源任务家族：Stack Bowls、Stack Cubes、Push Cubes、Burger & Fries、Can in Basket、Object in Cabinet。
  • 两个 held-out 跨任务家族：Cube in Bowl 和 Bowl in Cabinet。
  • 每个源任务收集 100 个专家演示，共 600 个源演示，汇总为多任务训练集。
  • 训练资源：2 张 NVIDIA A800 GPU，训练 30,000 步，batch size 32。
  • 真实实验使用 SO101 机器人。
Card 06 评估与结果

评估与结果

  • 评估指标：Constraint-compliant success rate (CCSR)，要求达到任务目标并满足物理里程碑、顺序和时间约束；同时报告归一化进度。
  • 评估设置：23 个条件，每条件 100 episodes，seeds 1000–1099，共 2,300 episodes；泛化均值覆盖 17 个非 in-domain 条件。
  • 仿真主要结果：AE-VLA 泛化成功率为 21.53%，显著高于 Single π0.5（2.94%）、MA-VLA（3.06%）和 Dual π0.5（5.53%）。
  • 分组结果：AE-VLA 在 Reorder 达 26.50%，Sync+Reorder 达 22.00%，Cross-task Combination 达 40.00%；纯 Sync 仍较难，为 8.67%。
  • 真实机器人结果：AE-VLA 在 SO101 五个未见条件下平均成功率为 39.00%，最强基线为 10.00%。
  • 部分任务表现：AE-VLA 在 Stack Bowls/Reorder 达 79%，Cube in Bowl/Cross-task 达 54%，但也在部分 in-domain 条件上低于部分基线。
