VLA-FAIL: Efficient Task Failure Detection for Finetuned Vision-Language-Action Models

2026-06-19 · 原文 · 翻译 · 2606.21386

论文聚焦于视觉-语言-动作模型（VLA）在真实机器人操控中的运行时失败检测问题，指出 VLA 即使经过微调，在分布外（OOD）场景下仍可能行为不可预测，安全部署需要提前发现任务失败。 现有失败检测方法存在三大缺陷：需要昂贵的多次动作采样、依赖特定架构假设（难以适用于 VLA）、或需要收集失败轨迹数据；本文提出 VLA-FAIL，一个轻量级、无需失败数据、近乎零额外开销的失败检测框架。 方法结合两个互补信号：LLMD（最后层特征马氏距离，检测特征分布偏移）与 ACC（动作块一致性，检测动作规划不一致），并引入新指标 AUCPDT 用于综合评价检测精度与检测延迟的权衡。

Card 03 核心贡献

核心贡献

  • 提出 VLA-FAIL 框架，组合两种新颖的失败检测器 LLMD 与 ACC，仅需最小计算开销，不需要失败数据或外部辅助模型。
  • 提出 LLMD：面向 flow-matching VLA 的 token-wise 最后层特征马氏距离，通过固定先验噪声采样消除动作采样引入的特征噪声，可早期检测 OOD 状态。
  • 提出 ACC：基于 receding-horizon 控制中重叠动作块的速度归一化不一致性得分，仅利用已生成动作即可检测危险/异常行为，无需额外采样。
  • 引入阈值无关评价指标 AUCPDT，联合衡量精确率、召回率与检测时间，并给出 Pareto 前沿与面积计算方法。
  • 在真实世界与仿真环境中系统验证：VLA-FAIL 在多个任务上优于计算成本高得多的基线方法。
Card 04 方法描述

方法描述

  • 问题设定：VLA 在每个环境时间步 t 接收观察 o（本体感知+多相机图像+语言指令），预测 H 步动作块 a_{1:H}，采用 receding-horizon 控制执行前 R 步。
  • LLMD 核心思想：假设模型分解为特征提取器 f 与线性层 g；对 flow-matching 模型固定一个随机但固定的先验噪声 a₀* ~ N(0,I)，在 t=0 时计算 f*(o)=f(o,t=0,a₀*)，从而消除采样噪声；随后在微调数据集上计算每个 token 位置的均值 μ_s 与正则化协方差 Σ_s^λ，运行时取各 token 马氏距离的最大值作为 LLMD 得分。
  • ACC 核心思想：比较相邻两个动作块重叠部分（前一动作块未执行后缀 vs. 当前动作块前缀）的绝对误差，并按各动作维度的速度范围（clamped 到 v_min）归一化；使用指数滑动平均（α=0.9）平滑，只对持续性的动作不一致触发失败信号。
  • VLA-FAIL 组合：FAIL(t) = (ACC 得分 ≥ τ_ACC) ∨ (LLMD 得分 ≥ τ_LLMD)，阈值通过校准集上的 conformal prediction band 确定，不使用时间相关阈值（因真实任务长度差异大）。
Card 05 数据集与资源

数据集与资源

  • 真实世界：6 个多样化操控任务——Blocks、Drawer、Cups、Kitchen、Stack T、Mixer，每个策略约 80 次 rollout，每个 rollout 3 个随机种子。
  • 仿真：LIBERO-Plus 大规模仿真基准。
  • 模型：π₀.₅（基于 PaliGemma VLM 的 3.6B 参数 VLA，逐层交叉注意力融合动作专家）；X-VLA（基于 Florence-2-Large 的 0.9B 参数 VLA，仅在最终编码器特征上条件化动作专家）。
  • 推理延迟对比在 RTX 5090 上测试（X-VLA，常数 17ms VLM 时间已排除）。
Card 06 评估与结果

评估与结果

  • 基线方法：ACE（动作分布熵）、STAC（相邻动作分布散度）、Diff（扩散损失），均使用 32 个样本，因计算开销大无法实时，仅在 rollout 回放上评估。
  • 主要指标：PR（精确率-召回率曲线下面积，↑）、PDT（Penalized Detection Time，↓）、以及新提出的 AUCPDT。
  • 关键结果：VLA-FAIL（FAIL）在几乎所有任务上进入前三级别，且在多个任务上获得最优 PR 与 PDT；例如 Blocks/X-VLA 上 LLMD PR 0.92（最佳）、FAIL PDT 0.25；Kitchen/X-VLA 上 ACC、LLMD、FAIL 的 PR 均达 1.00。
  • 互补性验证：ACC 与 LLMD 各自只在部分任务上表现优异，只有二者组合（FAIL）能在几乎所有任务上保持稳健，频繁超越计算昂贵的基线（ACE/Diff/STAC）。
  • 基线方法由于需要 32 个动作样本，推理延迟显著高于 VLA-FAIL 的单次前向开销，不具备实时部署能力。
