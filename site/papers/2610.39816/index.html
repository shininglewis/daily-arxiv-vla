Card 03 核心贡献

核心贡献

  • 系统刻画 WAM 中视觉 K/V 路由的脆弱性，指出表征扰动幅度与闭环行为失效之间存在系统性错配（例如 L03 在 5k/10k/20k 曝光下 SR 从 91.0% 降至 15.5%/9.5%，而 L28 始终接近干净性能）
  • 指出 action-conditioned readout（动作条件读出） 是「内部扰动 → 行为后果」之间缺失的一环，解释了 K 与 V 的不同角色：K 决定动作 query「读哪里」，V 决定「读到什么内容」
  • 提出 Tail-AV 短探测信号（基于 I = A·\|\|V\|\|₂ 的稀疏上尾增长），可在不依赖闭环 rollout 结果的前提下预测哪些层后续会成为强攻击目标
  • 提出 PASA-KV：先用 Probe100 低成本探测候选路由并排序，再用全新初始化在 Top-k 层上训练共享任务补丁，把路由识别与完整攻击优化解耦
  • 在同预算匹配对照下证明读出感知选择优于表征位移选择与无信息选择，并给出跨架构（FastWAM / LingBot-VA / Cosmos Policy）与真实机器人（Piper）的评测
Card 04 方法描述

方法描述

  • 攻击设定：冻结受害模型、已知任务的白盒攻击；单个 RGB 补丁（3×50×50，FastWAM 位于 (5,160)）跨 10 个 LIBERO-10 任务共享；训练时只改 clip 第 0 帧，部署时每个 replan 都对当前观测贴补丁，不回溯改写历史
  • 探针阶段（Probe100）：对每个候选层 ℓ 优化单层 K/V 相对位移损失 D^Z_ℓ = \|\|Z_ℓ(x⊕p) − Z_ℓ(x)\|\|_F / max(\|\|Z_ℓ(x)\|\|_F, ε)，J^KV_ℓ = ½E[D^K_ℓ + D^V_ℓ]，每层仅 100 次曝光；ε = 1e-8
  • Tail-AV 打分：用 I = A·\|\|V\|\|₂ 结合动作 query 路由与视觉内容幅度，取最大 ⌈0.005·H·Q·T⌉ 项均值 μ_q(I)，计算补丁前后该稀疏上尾的对数增长比，并在 10 个任务上平均；按分数降序（同分按层号升序）选 Top-k
  • 一阶分解支撑：δy_i ≈ u_K + u_V，其中 u_K 与 q_iᵀδk_j 的对齐程度有关、u_V 受注意力权重门控；因存在 2⟨u_K, u_V⟩ 交叉项，K/V 联合攻击并非单调占优（如 L20：K-only 达 0.0% SR，而联合 K/V 仍为 91.5%）
  • 最终训练：丢弃所有探针补丁与优化器状态，重新初始化后在选中层集合 S 上最小化 J_joint(p;S) = \|S\|⁻¹ Σ_{ℓ∈S} J^KV_ℓ(p)，10k 次 BS1 更新；优化器 AdamW，lr 5e-4，betas (0.9,0.95)，weight decay 0.01，无 warm-up / 调度器 / 梯度裁剪
  • 架构适配接口：FastWAM 在首个动作去噪步读固定 clip 视觉缓存；LingBot-VA 在 1 个视频步（endpoint 0.6）+ 首个动作步读取当前主视角缓存列；Cosmos Policy 在单一联合噪声层用 action-slot 4 的 query 读 slot 3 列
  • 防御侧：提出 PASA-KV Guard，通过层选择与干净标定进行检测/防护
Card 05 数据集与资源

数据集与资源

  • 数据集：LIBERO-10（10 个已知任务）；评测集包含 Eval500（10 任务 × 50 trials）与匹配对照用的 Eval200
  • 受害模型：FastWAM（direct 架构，30 个候选层）、LingBot-VA（cascaded，30 层）、Cosmos Policy（joint，28 层）
  • 模型与补丁规模：补丁为 FP32 3×50×50 RGB 张量，受害模型 BF16 前向、权重全程冻结；FastWAM 补丁占 224×224 主视角约 4.98%
  • 计算开销：构建总曝光为 100L + 10,000；论文以 GPU-h 报告构建成本（如 Cosmos 上 PASA-KV Top-3 为 2.98 GPU-h），但片段中未给出具体 GPU 型号/数量
  • 真实机器人：Piper 平台，重新跑完整流程得到任务共享 Top-5 补丁
  • 随机性设置：主实验 protocol/run 标签 42，单层配置种子 20260801，FastWAM/LingBot 评测种子 42，Cosmos 扩展为 195
Card 06 评估与结果

评估与结果

  • 评估环境：LIBERO-10 仿真闭环 rollout（Policy Success Rate 为主指标，越低表示攻击越强）+ Piper 真机部署
  • 跨架构攻击效果（Eval500）：PASA-KV Top-5 将 FastWAM 成功率从 92.4% 降至 0.0%，但 LingBot-VA 与 Cosmos Policy 仅降至 87.2% 与 89.2%，显示出强烈的架构相关抗性差异
  • 匹配对照（同最终 K/V 目标、同目标数、同几何、同预算）：Tail-AV 选层达 1.5% 策略成功率，而按探针 K/V 位移选层为 47.5%，等距或随机选层为 18.5–86.5%
  • 与基线对比：DP-Attacker 在 FastWAM / LingBot-VA / Cosmos 上分别为 81.0% / 94.2% / 95.2% SR，构建成本 4.23 / 1.97 / 2.88 GPU-h；PASA-KV 在 FastWAM、LingBot-VA 上成本低于所列适配基线，仅在 Cosmos 上 Top-3（2.98 GPU-h）略高于 DP-Attacker（2.88 GPU-h）
  • 相关性分析：30 层上归一化位移与攻击强度的相关性仅 ρ(D_K, AttackStrength)=0.316、ρ(D_V, AttackStrength)=0.528，说明表征位移不能可靠预测行为失效
  • 组件层面：同 10k 预算下联合 K/V 在 13/30 层取得有效攻击（SR ≤ 50%），K-only 为 7/30、V-only 为 11/30，但联合并非逐层占优
  • 真机结果：在单独训练的 Piper FastWAM checkpoint 上重跑完整流程，得到的任务共享 Top-5 补丁在三个干净成功率非零的任务上均为 0/10 成功
  • 选择器稳定性：重复 Probe100 运行产生高度稳定的排序，支持 Tail-AV 作为短预算排序信号（而非标定后的行为损伤代理）
