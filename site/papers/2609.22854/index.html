Card 03 核心贡献

核心贡献

  • 提出紧凑 VLA 架构，将冻结的视觉-语言特征、episode 持久的 mLSTM 控制器与独立动作生成器组合在单一控制回路中。
  • 将观测 token 与动作查询统一在单一因果循环流中，整个 episode 从不重置，记忆存储为 O(1)，每步成本与 episode 长度无关。
  • 在 LIBERO-Mem 上超越记忆基线 2AM 和 MemoryVAM 所有可直接比较的指标；在标准 LIBERO 上同样具备竞争力。
  • 通过循环状态干预实验（每 N 步清零）刻画策略对记忆的依赖：每步重置使全任务成功率从 77.5% 降至 7.0%。
  • 提供感知依赖、指令表征与基准局限性的分析，说明观测成功所证明的范围。
Card 04 方法描述

方法描述

  • 观测 token 化：冻结的 SmolVLM-256M-Instruct 提供空间网格 token（64，8×8）与指令 token（16）；另外用两个 ImageNet 初始化的 ResNet-18 编码腕部相机与单目深度（各 36），冻结的 DINOv2-S 提供旁路 patch 特征（64），本体感知经两层 MLP（1）。每控制步共 217 个观测 token，经可训练 512 维线性层投影。
  • 单一循环流：217 个观测 token 与 T=10 个可学习动作查询拼接为统一因果序列，送入 6 块、512 宽的 mLSTM 堆栈（4 个注意力头），每块维护矩阵记忆 C_t 与归一化项 n_t；状态固定大小，记忆为 O(1)，对比注意力的 O(t)。
  • 整流流动作头：采用条件流匹配预测连续动作块（10 步末端执行器位姿增量与夹爪命令），训练用单步流损失，推理用 8 步 Euler 积分；流只限动作头，每 ODE 步仅 4.87 M 参数头参与。
  • 强制使用状态：采用 观测 dropout（整个观测块以 p=0.15 替换为缺失 token，各传感器流以 p=0.10 独立置空）和 辅助潜在预测（从最后查询隐状态预测 DINOv2 场景特征 5 与 10 步后的变化方向，权重 0.5，推理时丢弃）。
  • 冻结 LLM 语言读出：探测 31 层隐状态，发现中层存在各向异性跳变与属性解码坍塌的 U 形分布，故提取第 1 层与第 30 层；两层各池化为 K=8 有序片段 token 并并列而非相加，同时做指令集均值中心化（计数对相似度从 0.9994 降至 0.63，最难的 LIBERO-Mem 对从 0.9972 降至 0.07）。
Card 05 数据集与资源

数据集与资源

  • 训练数据：LIBERO-{90, Spatial, Object, Goal, Long, Mem}，单一模型联合训练（无按套件微调）。
  • 模型规模：总计 0.32B 参数，其中仅 40.4 M（12.7%）可训练；VLM 与 DINOv2-S 骨干冻结。
  • 训练配置：30k 步 AdamW（学习率 3×10⁻⁴、权重衰减 0.05、100 步预热、梯度裁剪 0.5、累积 4），bfloat16；按 37,500 流 token 预算（约 165 控制步）组批；报告 checkpoint 为 25k 步。
  • 硬件：单张 NVIDIA RTX Pro 5000 Blackwell GPU 与 8 核 Intel Xeon 处理器。
Card 06 评估与结果

评估与结果

  • 评估基准：LIBERO-Mem（10 个任务，分 Object Motion/Sequence/Relations/Occlusion 四类，每任务 20 个未见初始状态）与标准 LIBERO（四套件，每任务 50 次 rollout）。
  • 主要指标：子目标覆盖率（coverage）与全任务成功率（success）；LIBERO 报告分套件与平均成功率。
  • 关键结果：LIBERO-Mem 上达到 85.1% 覆盖率与 77.5% 全任务成功率，覆盖率超 2AM 8.8 个百分点、超 E.-S.SSM 70.3 个百分点；成功率高于 MemoryVAM（42.5%）与 2AM（63.0%）。
  • 标准 LIBERO 上平均成功率 79.6%，优于回归变体（65.9%）及 VLM 初始化的 π₀ 基线（71.8%），但低于 SmolVLA-0.24B（82.8%）、SmolVLA-0.45B（87.3%）等大规模机器人数据预训练方法；OpenVLA-OFT 以 97.1% 为最高。
  • 消融结果：每控制步重置循环状态使成功率降至 7.0%、覆盖率降至 10.5%；OM 在 N=5 恢复、N=10 达 100%，OS 在 N=20 恢复，OR 即使不重置也仅 8%，OO 在 N=30 达 82%、不重置达 95%。
  • 传感器消融：移除 DINOv2 或深度仅降 1.5/3.0 个百分点，移除腕部相机则成功率骤降至 12%，显示对腕部视图的强依赖。
  • 局限性：OS 任务的终止条件无法区分「按指令次数停止」与「会继续重复」的策略；循环状态替换到相同子目标的其他 rollout 后成功率仍达 75.0%/70.0%，说明策略对丢失上下文比对该类替换更敏感。
