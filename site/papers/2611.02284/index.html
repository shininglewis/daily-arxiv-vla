Card 02 论文概述

论文概述

  • 针对 VLM/VLA 中数百个视觉 token 造成的计算瓶颈，研究视觉 token 剪枝问题。
  • 指出现有基于注意力、token 范数或跨模态相关性的 token-wise 评分在激进压缩下难以反映全局结构。
  • 提出 SVD-Prune，将剪枝视为保留视觉表示主导低秩谱子空间，并用 SVD 与统计杠杆分数进行全局 token 选择。
Card 03 核心贡献

核心贡献

  • 将视觉 token 剪枝重构为低秩子空间保持问题，用全局谱结构替代局部交互式重要性评分。
  • 提出 SVD-Prune：基于 SVD 与 统计杠杆分数 的 training-free、attention-independent 剪枝框架，支持 encoder-side、decoder-side、hybrid 部署。
  • 在 VLM 与 VLA 上统一评估，证明极端压缩下仍具鲁棒性，并可大幅降低视觉 token 数与推理成本。
Card 04 方法描述

方法描述

  • 对视觉 token 特征矩阵 F∈R^{N×d} 做 SVD（不中心化，奇异值反映谱能量而非 PCA 方差），提取全局模式。
  • 谱能量截断：按 e_i=s_i^2/Σs_j^2 计算归一化能量，选择最小秩 m 使累计能量 c_m≥ε；该秩 m 近似在 Frobenius 误差下最优（Eckart–Young）。
  • 用统计杠杆分数 h_t=Σ_{j=1}^m U_{t,j}^2 衡量 token 对保留低秩子空间的影响，并归一化为 ℓ_t=h_t/m。
  • 按杠杆分数排序保留 top-k token，再恢复原始序列顺序以兼容下游注意力；k 独立控制压缩率，ε 不直接决定剪枝率。
  • 创新点：将剪枝目标从局部 token 重要性转为全局低秩谱结构保持，且框架 training-free、attention-independent，可部署于多阶段流水线。
Card 05 数据集与资源

数据集与资源

  • 模型：LLaVA-1.5-7B 为主基准，LLaVA-1.5-13B 在补充材料中报告；另评估 QwenVL 与 OpenVLA。
  • 模型规模：LLaVA-1.5-7B/13B 参数量分别为 7B/13B；QwenVL 与 OpenVLA 的参数量原文未明确给出。
  • VLM 基准：SQA、VizWiz、POPE、GQA、TextVQA、MME；QwenVL 额外报告 TextVQA、SQA、MME。
  • VLA 基准：LIBERO-Spatial、LIBERO-Goal、LIBERO-Object、LIBERO-10。
  • 视觉 token 设置：LLaVA-1.5 输入 336×336 产生 576 个 token；QwenVL 448×448 产生 1024 个 token；OpenVLA 每个观察 256 个 token。
  • 实验资源：PyTorch，单张 NVIDIA RTX 3080 16GB GPU 与 Intel Core i7-11800H CPU；方法为 training-free，无需模型训练。
Card 06 评估与结果

评估与结果

  • 评估覆盖 VLM（LLaVA-1.5-7B 六个基准、QwenVL 跨架构）与 VLA（OpenVLA + LIBERO 四套件），并报告精度、成功率、FLOPs、延迟与加速比。
  • 在 LLaVA-1.5-7B 上，16-token 编码器侧剪枝将计算量从 3.450 TFLOPs 降至 0.606 TFLOPs（82.4% 降低），延迟从 930.00 ms 降至 222.56 ms，端到端加速 4.18×（含剪枝开销）。
  • 可将视觉 token 预算最多削减 99.3%（576→4 tokens）；在 8/4 tokens 极端压缩下，SVD-Prune 在多数基准上优于 FastV、SparseVLM、VisionZip 等方法。
  • 16 tokens 时编码器侧在六个基准上准确率均高于 VisionZip，GQA +8.83、POPE +10.11，但延迟高于 VisionZip（222.56 ms vs 184.52 ms）。
  • TextVQA 对激进剪枝最敏感；解码器侧剪枝延后至第 12 层可在 16 tokens 恢复较多性能，但 8/4 tokens 收益有限；Hybrid 在 ≤32 tokens 时多数基准最强。
  • VLA 中 LIBERO-Spatial/Goal/Object 较鲁棒，LIBERO-10 更敏感：成功率从 55.8%（256 tokens）降至 47.0%（56 tokens）。
  • QwenVL 保留 784 tokens（约 23% 减少）时 TextVQA 仅轻微下降且 SQA 略升；保留 256 tokens（约 75% 减少）时 TextVQA 明显下降，SQA 相对稳定。
