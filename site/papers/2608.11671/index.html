Card 02 论文概述

论文概述

  • 提出 StellaVLA，一种基于检索增强的视觉-语言-动作（VLA）模型框架，旨在提升模型在分布外（OOD）场景下的泛化能力
  • 核心思想：将原始专家轨迹自动转化为结构化演示（包含任务计划、子目标描述、3D/2D 运动语言化），在测试时作为上下文提示，使策略模仿专家的“推理过程”而非仅模仿像素级动作

Card 03 核心贡献

核心贡献

  • 提出 StellaVLA 框架，将 ICIL（上下文模仿学习）从模仿动作提升为模仿推理，显著降低 OOD 条件下的行为惯性
  • 设计零人工标注成本的离线结构化上下文提取流水线，利用 VLM 自动进行语义分割和运动语言化，生成跨具身统一的演示池
  • 提出并行双训练范式：动作专家回归连续动作，空间语言专家同时预测子目标和动作的 2D/3D 语言描述，通过联合目标强化共享表征
  • 提出非对称推理策略：推理时移除语言专家，仅使用动作专家，并利用演示前缀 KV 缓存，实现零额外延迟的高频控制
  • 在 VLA-Arena 排行榜（2026年8月1日）上排名第一，整体得分 0.63，并在 LIBERO（98.8%）、LIBERO-Plus（85.1%）及真实机器人基准上表现领先
Card 04 方法描述

方法描述

  • 使用现成的 VLM（如 Qwen3-VL） 对原始轨迹进行因果分割，识别高层子目标（语义 rationale），并通过确定性 verbaliser Φ 将动作块转换为 3D 位移和 2D 投影运动（运动 rationale）
  • 构建统一的结构化演示池，检索时通过任务指令的语言嵌入余弦相似度选取 top-1 演示作为上下文前缀
  • 主干为 Qwen3-VL-4B，两个并行专家：MLP 动作专家（连续动作块回归，L1 损失）和空间语言专家（自回归语言头，交叉熵损失，权重 λ=0.3）
  • 联合损失 L = L_act + λ·L_lang，其中语言监督同时提供语义、视觉接地和运动学信息
  • 推理时仅保留动作专家，演示前缀的 KV cache 在 t=1 时计算一次，后续仅处理实时观测，降低计算开销

Card 06 评估与结果

评估与结果

  • LIBERO 分布内验证：平均成功率 98.8%，其中 Spatial 99.6%、Goal 99.6%、Long 96.8%，优于匹配基线 StarVLA-OFT（96.6%）及多个强基线（MemoryVLA 96.7%、ACoT-VLA 98.5% 等）
  • VLA-Arena 任务级泛化：L0/L1/L2 平均成功率分别为 0.84 / 0.62 / 0.43，整体得分 0.63，大幅领先最优基线 π₀.₅（0.44）；在 Unseen Objects 上三个难度均保持 0.80，Task Workflows 从 L0 的 0.64 提升至 L2 的 0.84
  • LIBERO-Plus 零样本鲁棒性：平均成功率 85.1%，比 StarVLA-OFT 高 10.1 个百分点；最大增益出现在相机视角（+23.5）、传感器噪声（+19.7）、机器人初始状态（+14.7）和语言扰动（+8.3）
