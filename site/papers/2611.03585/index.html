Card 02 论文概述

论文概述

  • 论文聚焦 World Action Models (WAMs)，即联合生成机器人动作与“想象未来”的模型，研究如何在物理执行前对多个候选 world-action rollout 进行评估与选择，以实现推理时扩展（test-time scaling）。

Card 03 核心贡献

核心贡献

  • 提出统一的执行前选择器，将动作有效性、跨输出一致性与任务进度融合为单一有界分数（各分量归一化到 [0,1] 后相加），WAM 全程冻结、无需微调。
  • 设计逆动力学一致性分数：用 IDM 从候选自身想象的未来中反解出动作，并与该候选同时生成的动作比对，检验二者是否支持同一段机器人运动。
  • 在两组 WAM–本体（embodiment）搭配上做匹配预算（B=4）的闭环评测，并给出单分量消融、分量一致性分析与反事实移除分析。
  • 将“跨输出一致性（cross-output coherence）”作为一类新的决策时判据，与未来共识、跨视角几何、动作分布一致性、条件保真度等现有判据明确区分（Table 1）。
Card 04 方法描述

方法描述

  • 问题形式化：每个控制步 t，冻结策略采样 B 个候选 \(c_t^{(i)}=(\hat X_t^{(i)}, A_t^{(i)})\)（想象未来 + 动作块），选择 \(i_t^*=\arg\max_i R_{\text{WISE}}\)，执行完整动作块后重规划。
  • 执行分数 \(r^{\text{exec}}\)：按控制接口约束做合法性检查（位置范围、由连续指令推导的速度/加速度/加加速度 jerk），违规量 \(\delta_k\) 经 \(\exp(-\delta_k/\tau_k)\) 软化为分数，再按权重加权平均，避免硬拒绝。
  • 一致性分数 \(r^{\text{cons}}\)：在特定本体示教数据上训练一次视觉 IDM \(f_\phi\)，从想象未来反解动作；连续通道用标准化后的平均绝对偏差取指数得 \(r^{\text{cont}}\)，离散通道（如夹爪）用阈值化后逐帧一致率得 \(r^{\text{disc}}\)，二者各占 1/2。
  • 任务进度分数 \(r^{\text{task}}\)：冻结的任务评估器 \(q_\psi\) 输入当前观测、想象 rollout 与语言指令，取最后一帧的进度分数；评估器与 WAM 无关（model-agnostic）。
  • 融合：三个有界分数直接相加 \(R_{\text{WISE}}=r^{\text{exec}}+r^{\text{cons}}+r^{\text{task}}\)，取最大者执行；三个分量针对不同类型失败（平滑但无进展、看起来有用但与动作不兼容）。
Card 05 数据集与资源

数据集与资源

  • 评测基准 1 — RoboLab：10 个操作任务 × 5 个闭环 episode = 共 50 episodes；WAM 为 Cosmos 3 Edge。
  • 评测基准 2 — LIBERO：四个标准套件（LIBERO-Spatial / Object / Goal / Long），每套件 500 episodes，共 2,000 episodes/方法；WAM 为 DreamZero，使用公开的 RLinf WAN2.2-5B LIBERO SFT checkpoint（训练步 26,000）。
  • 辅助模型：任务进度用 Robometer（RoboLab 用 Robometer-4B，LIBERO 用 Robometer-LIBERO）；IDM 为视觉单模态，RoboLab 用 DROID 真机轨迹（21,000 训练 / 1,000 场景不相交验证 episode），LIBERO 用 physical-intelligence/libero（1,693 episodes，5% 留作验证）。
  • 预测视野对齐：RoboLab IDM 将 33 帧 rollout 映射到 32 步 Cosmos 3 Edge 动作块；LIBERO IDM 从 9 帧双视角片段预测 DreamZero 的 16 步动作块。

Card 06 评估与结果

评估与结果

  • 评估设置：WAM 全程冻结；直接执行用 B=1，WISE 与所有选择器用 B=4 匹配预算；对比基线为 Future Consensus、GeoBoN、Robometer；指标为闭环任务成功率。
  • RoboLab 主结果：Cosmos 3 Edge 直接执行 6.0% → WISE 24.0%；同预算下 Future Consensus 18.0%、GeoBoN 20.0%、Robometer 20.0%，WISE 领先最强基线 4.0 个百分点（50 episodes 中多 2 次成功）。
  • LIBERO 主结果：DreamZero 平均成功率 75.1% → WISE 78.3%，四个套件全部提升，最大增益在 LIBERO-Object (+4.8) 与 LIBERO-Spatial (+3.2)；总体领先 Robometer 0.9 个百分点（约 1 个标准误），但 GeoBoN 在 Goal、Robometer 在 Long 上更优。
  • 单分量消融（RoboLab）：Exec-only 10.0%、Cons-only 16.0%、Prog-only 20.0%、三者融合 24.0%，说明分量互补。
  • 一致性与反事实分析：任务进度与最终选择一致率最高（RoboLab 67.2%、LIBERO 65.5%），但三者同时选中同一候选的比例仅 7.8% / 7.0%；移除任务进度会改变约 47%–49% 的选择，说明其权重最大，执行项在 RoboLab 影响更大、一致性项在 LIBERO 影响更大。
  • 开销：相对单 rollout，WISE 使平均 episode 时长增加 3.4×（RoboLab）与 3.5×（LIBERO），在 LIBERO 上与 Robometer 相当、低于 GeoBoN；作者也指出 50 episodes 下几点差异仍在采样波动范围内、且性能依赖 IDM 与进度模型这两个辅助评估器的准确性。
