Card 03 核心贡献

核心贡献

  • 提出 DeltaForge：仅凭各领域微调权重与约 1% proxy 数据即可把 N 个独立微调的领域模型整合为单一多领域 VLA，后续新领域可低成本 opt-in，无需重训练也无需共享数据。
  • 提出 Post-hoc Expert Factorization (PEF)：用联合 SVD 将各领域 task vector 分解为冻结的共享技能基（shared skill basis）与每领域低秩 core（r×r），使路由只搬运极小的 core 而非稠密参数块。
  • 设计两层 clip-level 盲路由（skill-mixing routing）：一个在输入端路由 VLM 推理专家，一个在中间层路由 flow-matching 动力学专家，可在无领域标签下自由交叉组合“场景推理”与“车辆动力学”技能。
  • 给出基于 proxy 集的组合训练流程：软 oracle 路由训练（KL 对齐）+ core 专家微调，两阶段分别训练 VLM MoE 与 flow-matching MoE。
  • 在跨城市/越野/高速、轿车/卡车/ATV 的 6 个领域上接近各领域专家精度，并在参数量与计算量接近单模型的前提下超过所有 merging、routing、centralized、federated 基线，同时展示对未见领域的组合式零样本泛化。
Card 04 方法描述

方法描述

  • 问题形式化：给定基座权重 W₀ 与 N 个领域微调权重 {Wᵢ}，求组合算子 C 得到 W_MoE = C(W₀, {Wᵢ})，目标为能力匹配、无标签高效路由、灵活增长。
  • PEF（共享技能基）：对每个可分解权重矩阵计算 task vector Δᵢ = Wᵢ − W₀，对拼接矩阵做截断 SVD 得到 U、V（Eckart–Young 意义下的最优低秩近似），基的规模由秩 r 决定、与领域数 N 无关。
  • 低秩 core 专家：Cᵢ = Uᵀ Δᵢ V ∈ ℝ^{r×r}，重建 Ŵᵢ = W₀ + U Cᵢ Vᵀ；基座以零 core C₀ = 0 免费加入专家池作为默认路由。分解范围覆盖 ViT、LLM 与 flow-matching 动作专家的 attention/FFN，其余模块（token embedding、LM head 等）合并为单一共享副本不参与路由。
  • Clip-level 盲路由：每个输入 clip 只计算一次混合权重 w，所有分解层共享同一混合，避免 LLM MoE 的 token/layer 级细粒度切换开销。
  • 输入级 VLM 路由器：输入为冻结 ViT 的视觉 token 均值特征 v 与自车历史速度/加速度/曲率的 z-score 统计量 m，经小 MLP + softmax 得 pᴿ。
  • 中间层动力学路由器：输入为 VLM 末层隐状态均值池化 h 与同样的运动学 m，输出 pᴰ，从而可跨域自由配对推理与动力学技能。
  • Top-k 软混合：对路由分布截断到 top-k 并重归一化；由于混合对 core 线性，可在参数空间一次性完成，零额外推理开销，且 w 保留在计算图中保证端到端可训。
  • 软 oracle 路由训练：每个候选专家对 proxy 样本打分（VLM 专家用 teacher-forcing token 损失，flow-matching 专家用生成轨迹 ADE），经温度 τ 的 softmax 得软标签 q，最小化 KL(q‖p)；全程不使用领域标签。
  • core 专家微调（core repair）：冻结路由器与共享基，仅优化 top-k 选中的 cores，补偿 SVD 截断损失并让被混合的 core 协同适配。
  • 新领域 onboarding：冻结基下计算 Δ_{N+1} 并投影得 C_{N+1} = Uᵀ Δ_{N+1} V，在自身 proxy 集上做 anchor-repair（路由锁定到新专家），再重新生成软标签并在扩展 proxy 集上联合刷新路由器与全部 cores，无需端到端重训练。
Card 05 数据集与资源

数据集与资源

  • 基座模型：Alpamayo 1.5（10B），由 8B Cosmos-Reason VLM 骨干 + 2B flow-matching 动作专家组成；部署系统总参数 12.55B（N=5），其中仅 122.7M（约 1.0%） 需训练；共享基 U,V 约 1,257M，路由器约 2.1M，每领域 core 约 42M（占基座 0.3%）。
  • 六个领域数据集：ONCE（中国城市，24,885/2,769）、CoVLA（日本城市左行，26,987/2,893）、TartanDrive（森林越野 ATV，17,470/1,484）、ORAD-3D（中国越野轿车，34,801/4,897）、TruckScenes（欧洲高速卡车，33,305/3,172）、PhysicalAI-AV（基座原生域，美/欧四摄像头，19,545/3,000）。
  • 留出集：ParkRecon3D（地下车库鱼眼，新领域 onboarding）、Torc TruckDrive（美国高速卡车）与 BeVIS（室内车库灰度）用于零样本泛化。
  • 训练资源：每个领域专家在 8× H100 GPU 上两阶段训练（阶段 1 全参微调 VLM，AdamW，lr 1e-5，batch 32；阶段 2 冻结 VLM 训练动作专家，lr 1e-4，batch 8），最多 10 个 epoch。
  • 组合训练配置：PEF 秩 r=256，软 oracle 温度 τ=0.3，路由器训练 200 步、core 训练 500 步；proxy 集为每领域 200 个 clip（约训练数据 1%），评测集从不接触。
Card 06 评估与结果

评估与结果

  • 评估协议：指标为 5 秒时域上 6 条采样轨迹的 minADE@5s（米，best-of-6，越低越好）；路由器在 N 个领域专家 + 1 条默认基座路由间选择。
  • 对比基线：零样本基座（下界）、各领域专家（上界）、Centralized SFT、Federated SFT（FedAdam）、静态合并不知（Model soup、Task arithmetic、TIES、DARE、TSV-M、KnOTS、EMR-Merging、Twin-Merging）与路由式方法（BTX）。
  • 主结果：DeltaForge top-1 均值 1.0157、top-2 均值 1.0170，接近独立领域专家的 0.9798，优于所有 merging/routing 基线（最佳基线 BTX 1.2398、EMR-Merging 1.2732、Twin-Merging 1.3510）；且优于使用全量数据的 Centralized SFT（1.1129）与 Federated SFT（1.1086）。
  • 分领域表现：top-2 在基座域 PAI 从 0.9189 显著降至 0.7569（top-1）与 0.7569→0.6529 附近水平，说明保留基座路由可缓解合并类方法的灾难性遗忘；Tartan ATV 上 top-2 达 1.1727（较最佳基线 BTX 1.2049 更优）。
  • 效率结果：参数量随领域数近似常数增长（12.34 + 0.042N，N=5 时 12.55B；N=10 时 12.76B），而逐领域专家为 11.08(N+1)（N=5 时 66.5B）、BTX 为 11.08 + 7.26N（47.4B）；推理计算为 23.39 + 0.08k GFLOPs/token（top-1 23.5、top-2 23.6、top-5 23.8），远低于 BTX 的 6.35 + 14.52k（top-2 为 35.4、top-5 为 79.0）。
  • 零样本技能迁移：在无 Torc TruckDrive 任何训练数据的情况下，盲路由器将 90%（top-1）/ 83%（top-2） 的 clip 路由到卡车技能，误差从 8.99 降至 1.06（top-1）/ 1.00（top-2），接近该域自身专家（0.82）；无相关技能可借的领域则无此增益。
  • 新领域 onboarding：接入 ParkRecon3D 后其误差从 0.75 降至 0.65，系统仅增长 42M 参数，六个已有领域平均仅变化 +1.5%，并可同时提升仍未见过的相关领域。
