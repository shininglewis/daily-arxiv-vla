Card 03 核心贡献

核心贡献

  • 构建了一个经过筛选的 3,033 小时级 ego–robot 预训练语料，最终保留约 2,659 小时，并设计了可扩展的数据处理与质量控制 pipeline
  • 形式化并实现了三种将 egocentric 数据融入具身基础模型预训练的范式：领域隔离（Atom-DH）、显式具身对齐（Atom-CL）、联合视频–动作建模（Atom-WAM）
  • 在统一数据与实验框架下进行受控预训练和系统评估，比较不同 ego–robot 协同训练策略
  • 通过真实机器人多任务实验与语言条件跨具身表示分析，总结出可操作的 ego 数据使用经验与原则
Card 04 方法描述

方法描述

  • 数据预处理与质量控制：将不同来源数据统一为 RLDS episode 表示；构建 80 维统一状态–动作空间；构造 50 步目标动作 chunk；按数据集独立归一化；使用 S1 突变检测、S2 状态–动作趋势对齐、S3 极值过滤 进行质量检查
  • Atom-DH：共享感知、语言和动作表示，将最终动作投影拆分为 ego-specific head 与 robot-specific head，每个样本只监督对应 head，但两个域的梯度都更新共享 backbone
  • Atom-CL：三阶段渐进式课程；先在大规模 ego 数据上学习交互先验，再在任务匹配的人–机器人对齐数据上进行具身对齐，最后在机器人数据上预训练；对齐阶段将人手姿态视为规范末端执行器，并将机器人关节轨迹通过前向运动学转为 Cartesian 末端执行器位姿，使用相对变换作为对齐目标
  • Atom-WAM：基于 Fast-WAM 架构，使用 Video DiT 与 Action DiT 的共享注意力 Mixture-of-Transformers 形式；在 ego 与 robot 混合数据上联合微调，以未来视频建模作为跨具身共享通道，联合损失为 L_joint = L_action + λ_video L_video
  • 模型实例化：VLA 范式采用 π0.5 架构，但初始化自 PaliGemma VLM 基础权重而非预训练 π0.5 checkpoint；WAM 范式保留 Fast-WAM 架构
Card 05 数据集与资源

数据集与资源

  • 机器人数据：AgiBot World Beta、DROID、RoboCOIN、RoboMIND，以及自采集的 Piper 双臂机器人 演示数据
  • Ego 数据：EgoVerse，约 1,079.5 小时

  • 最终训练配方：334,054 episodes，约 2,659.5 小时；原始数据约 3,033 小时
  • 模型规模与参数量：文中未明确给出具体参数量；VLA 基于 π0.5 / PaliGemma VLM，WAM 基于 Fast-WAM
  • 训练资源：每个预训练运行使用 3×8 NVIDIA B200 GPU，约 4 天；所有预训练运行采用相同训练步数、batch size 和其他超参数
Card 06 评估与结果

评估与结果

  • 评估环境：真实双臂机器人平台，7 个操作任务：Cook Bread、Hang Cup、Place Fruits、Place Plate、Place Pot、Press Button、Push Box
  • 评估设置：每个任务在 ID 与 OOD 条件下各测 10 次，每个 checkpoint 共 140 次 试验；成功需达到完整预定义任务结束状态
  • 基线：分别构建 VLA robot-only baseline 与 WAM robot-only baseline；Atom-DH、Atom-CL 与 VLA baseline 对比，Atom-WAM 与 WAM baseline 对比
  • 主要指标：真实机器人 ID/OOD/combined 成功率；跨具身表示使用 raw matched-task similarity（越高越好） 与 normalized different-task similarity（越低越好）
  • 关键结果：Atom-CL 在 VLA 家族中最佳，ID 成功率 64.29%，combined 成功率 53.57%，相比 VLA baseline 分别提升 21.43 和 20.71 个百分点
  • 关键结果：Atom-DH combined 成功率为 43.57%；OOD 成功率从 VLA baseline 的 22.86% 提升至 41.43%；Atom-CL OOD 成功率为 42.86%
  • 关键结果：Atom-WAM 反而低于 WAM baseline，ID 从 30.00% 降至 21.43%，OOD 从 27.14% 降至 20.00%，combined 从 28.57% 降至 20.71%
  • 表示分析：Atom-DH 匹配任务相似度最高但任务区分较弱；Atom-CL 任务区分最好；Atom-WAM 居中
  • 主要结论：egocentric 数据并非天然有益；有效利用需要高质量跨具身对齐；ego 数据尤其有利于 OOD 泛化；WAM 路线需要更强的对齐机制或专门架构设计
