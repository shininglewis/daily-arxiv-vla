论文概述

Card 03 核心贡献

核心贡献

  • 提供了一次可复现的 VLA 词汇修复：三个独立的编辑会话共用同一个固定的留出集，结果变化只发生在包含被编辑 token 的指令上。
  • 设计了方向与规模分离的对照实验（匹配范数的随机方向编辑），以及全量目标替换与编辑器插值之间的对照，并明确说明“词典对照”已经能解释多少增益。
  • 记录了 16 个会话的编辑采纳与拒绝全过程：语言修复之外，13 个会话中有 12 个最终被编辑器拒绝（revert 或 decline）。
  • 给出一个独立发现：基准指令中的场景元数据（如 view 0 0 100 2 354 initstate 0）使 FastWAM 成功率从 70.0% 降至 48.6%，而被评估的 π0.5 总体成功率不变。
  • 明确指出边界：证据只支持精确的词汇修复，不支持“缺失机器人能力的通用获取”。
Card 04 方法描述

方法描述

  • 编辑接口：Astra 获得张量名称、形状、原始权重只读访问、tokenizer，以及一个状态持久的 CPU Python 内核；它可做静态线性代数和保存替换张量，但禁止梯度更新、训练循环、迭代损失拟合，也禁止在内核中执行目标网络。
  • 前向工具：独立的仿真前向工具用于运行 episode，或回放保存的输入并对动作、激活做检查；编辑可以看到观测结果与成败。
  • 核心技术：对选定的源 token 嵌入行做锚点插值，公式为 E′ᵢ = (1−αᵢ)Eᵢ + αᵢĒ_Tᵢ，其中 Ē_Tᵢ 为任务锚点 token（如 stove、bowl、wine）的均值；有歧义的线索采用质心，而不是单一目标。
  • 约束条件：只允许改权重数值，张量名、形状、输入指令、动作缩放和推理代码全部固定。
  • 统计学：同一变体、同一 seed、同一初始状态配对比较，报告 (g−l)/n、配对正态近似区间和精确双侧 McNemar 检验，并对三个主结果做 Holm 校正。
  • 结构性局部性论证：如果指令的 token ID 集合 I(c) 与编辑行集合 S 不相交，则 E′[I(c)] = E[I(c)]，在确定性执行下动作块完全相同。

Card 06 评估与结果

评估与结果

  • 主结果（765 个留出释义）：A（18 行）86.3%→89.4%（32/8，p=1.82×10⁻⁴）；B（20 行）86.3%→88.0%（18/5，p=0.0106）；C（65 行）86.3%→92.0%（48 修复/4 回退，p=1.31×10⁻¹⁰，配对 95% 区间 [+3.95, +7.55] pp）。
  • 局部性：C 在 335 条含被编辑 token 的指令上从 74.3%→87.5%（+13.13 pp）；其余 430 条指令 零结果变化；在另外六个类别的 360 episode 样本上也无变化。
  • 难度分布：增益集中在最难的 level 5（用描述替代物体/动作名）：104/174→136/174（59.8%→78.2%），该层仅占 22.7% episode 却贡献 44 个净修复中的 32 个（72.7%）。
  • 对照实验（同 765 变体）：匹配范数随机方向 85.2%（7/15，p=0.134，无效）；编辑器词典引导的全量替换 90.5%（43/11，p=1.40×10⁻⁵）；C 与全量替换直接比较为 20 胜 9 负，p=0.0614（0.05 水平不显著）。
  • 因果探针（固定观测回放）：距离比 ρ 在原版为 1.000、仅改范数为 1.004、仅改方向为 0.340、最终 B 为 0.367，说明语义方向而非模长承载效应；但最终 VLM 语言残差仍为原距离的 3.165 倍，表明动作对齐 ≠ 全局特征对齐。
  • 练习集多种子验证（B，1,533 对试验）：seed 23 为 451→465（14/0）、seed 37 为 458→464（7/1，p=.0703）、seed 61 与 67 各 +1、seed 73 为 332→330（2/4，负向）。
  • 编辑器拒绝行为：16 个会话中 4 个采纳；语言修复之外的 13 个会话中 12 个被拒绝；唯一保留的 FastWAM 后续候选留出增益不显著（48.0%→48.7%，p=.542）。
  • 指令元数据发现：FastWAM 在 210 配对 episode 上 70.0%→48.6%（47 增益/2 损失，p=4.36×10⁻¹²）；π0.5 两种格式均为 186/210（88.6%，9/9，p=1）。
  • Qwen 复现：p50c 单样本 MATH-500 得 49.4%（原报告 48.1%），本地未编辑检查点在固定 100 题子集得 9.0%（报告 8.8%）。
  • 局限：全部为仿真实验、仅两个已发布检查点、三个主会话共享同一留出集与 seed（独立性在于搜索而非环境覆盖），未与人工词典、prompt 改写或 LoRA 微调做对比。
