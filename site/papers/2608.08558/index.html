Card 02 论文概述

论文概述

  • 核心挑战：传统 WAM 假设未来监督必须来自目标任务专家轨迹，本文质疑这一约束，探索使用视频基础模型生成的任务条件化未来作为监督源

Card 03 核心贡献

核心贡献

  • 重新思考 WAM 未来监督的来源，首次将视频基础模型→WAM 蒸馏形式化为视频扩散先验的离线迁移框架
  • 提出双通道、源感知的迁移策略，同时蒸馏未来视觉动态（video latent）与 IDM 推断动作（pseudo-actions），避免动作恢复模型造成的信息瓶颈
  • 引入源感知残差动作适配器（source-aware residual adapters），在共享动作主干上学习源特定修正，缓解伪动作噪声的干扰
  • 推理阶段移除视频教师、IDM、未来预测头及伪源适配器，仅保留紧凑的 WAM 学生，保证低延迟部署
Card 04 方法描述

方法描述

  • 视频教师适配：以 Wan2.1-14B 视频扩散模型（LVP 检查点）为教师，用少量演示视频微调以适应机器人外观和具体化物理约束
  • 逆动力学模型（IDM）：基于 ResNet-50 主干，配动作与本体感受预测头；无需任务级语言标注，仅需任务无关的交互数据训练
  • 伪数据生成：冻结教师生成视觉 rollouts，经学生 VAE 编码至同一潜空间得到未来潜变量，再由 IDM 恢复伪动作 chunk 与状态序列
  • 源感知残差适配器：公式为 $\text{Ada}_d(x)=x+\alpha W_{up}^{d}\sigma(W_{down}^{d}\text{LN}(x))$，$W_{up}$ 零初始化使适配器初始为恒等映射，推理时仅保留 real 域适配器
  • 训练目标：采用流匹配（flow matching）损失，联合优化真实域（专家动作+真实未来）与伪域（伪动作+生成未来）四个损失项
Card 05 数据集与资源

数据集与资源

  • 模拟基准：RoboTwin 2.0（50 个双臂操作任务）、LIBERO（Spatial/Object/Goal/Long 四个套件）、LIBERO-Plus（7 类扰动：相机、机器人初始状态、语言、光照、背景、传感器噪声、布局）
  • 真实世界平台：两个 AgileX Piper 机械臂、1 个顶部 Intel RealSense D435 相机 + 2 个腕部 D435 相机；6 个已见任务 + 3 个新任务
  • 模型规模：视频教师约 140 亿参数（Wan2.1-14B），学生 WAM 约 50 亿参数
  • 真实世界数据增强：使用 GPT-Image-2 从真实观测生成 60 张多样化初始状态图像用于教师条件生成
Card 06 评估与结果

评估与结果

  • RoboTwin 2.0：novel-task 子集上 Vid2WAM 成功率 54.7%/55.3%（Clean/Randomized），较 Fast-WAM 提升 9.7/12.5 个百分点；low-data 与 novel regime 总体均最优
  • LIBERO：low-data 下平均成功率 89.7%，在四个套件上均取得最好或并列最好结果；novel regime 下同样最高
  • LIBERO-Plus：两大评估体制下总体成功率最高，在机器人状态、语言、光照等扰动上增益明显
  • 真实世界实验：9 个接触丰富任务（20 次试次/任务），Vid2WAM 在多数任务上取得最佳或并列最佳
  • 消融研究：完整模型 (89.7) > Dual Action DiT (89.1) > No Adapter (88.5) > Future Latent Only (88.2) > Pseudo Action Only (86.4)；在线 Teacher Policy（71.3）显著低于所有蒸馏变体，验证离线双通道蒸馏与源感知适配的有效性
  • 推理延迟：Vid2WAM 平均 212.5ms（5B 参数），与 Fast-WAM（209.1ms）相当，保持低延迟学生端部署
