ODEAction: From Predicting Chunks to Evolving Actions

2026-11-06 · 原文 · 翻译 · 2611.09672

论文指出，现有视觉-语言-动作（VLA）模型普遍采用动作块（Action Chunking）生成方式，即一次推理预测整段未来动作序列，但相邻动作块独立预测、缺少跨块时序一致性约束，因而在块边界处容易产生动作突变与轨迹不连续。 论文提出 ODEAction，一种“无块（chunk-free）”的动作生成范式，把动作生成从“预测未来片段”改为连续动作演化（Continuous Action Evolution）：通过在当前动作处积分一个学习得到的动作转移场（Action Transition Field），递归生成后续动作。 研究目标是同时提升任务成功率与轨迹质量（平滑性、连续性），并在仿真基准与真实机器人上验证该范式的通用性。

Card 02 论文概述

论文概述

  • 论文指出，现有视觉-语言-动作（VLA）模型普遍采用动作块（Action Chunking）生成方式，即一次推理预测整段未来动作序列，但相邻动作块独立预测、缺少跨块时序一致性约束，因而在块边界处容易产生动作突变与轨迹不连续。
  • 论文提出 ODEAction，一种“无块（chunk-free）”的动作生成范式，把动作生成从“预测未来片段”改为连续动作演化（Continuous Action Evolution）：通过在当前动作处积分一个学习得到的动作转移场（Action Transition Field），递归生成后续动作。
  • 研究目标是同时提升任务成功率与轨迹质量（平滑性、连续性），并在仿真基准与真实机器人上验证该范式的通用性。
Card 03 核心贡献

核心贡献

  • 提出 ODEAction：一种基于连续动作演化的无块生成范式，将动作生成从“未来动作块预测”转变为“可学习的连续演化过程”。
  • 在多个仿真基准（LIBERO、EBench、RoboTwin）与真实机器人任务上，相比严格对齐的动作分块基线，同时提升任务性能与轨迹质量，在精细操作任务上增益尤为显著（如 EBench 平均成功率相对提升 61.8%）。
  • 发现并量化了轨迹质量提升与任务性能提升之间的系统性关系：边界不连续度降低（BDR）与成功率增益强正相关（Spearman ρ_s = 0.939），边界连续性改善越大的评测单元，成功率增益也越大。
  • 验证了范式的通用性：作为动作头（action head）可即插即用于 π₀.₅、StarVLA-OFT、StarVLA-π 等不同 VLM 骨干，不依赖特定骨干架构。
  • 在与 RTC、Legato 等跨块连续性方法的对比中，ODEAction 在降低边界跳变的同时反而提升成功率，避免了“连续性换成功率”的权衡。
Card 04 方法描述

方法描述

  • 连续动作演化建模：将动作演化写成 ODE 形式 d a(τ)/dτ = F_θ(a(τ), τ \|c)，其中 c 为视觉观测、语言指令与本体感知构成的条件信息，F_θ 为定义在动作空间上的条件向量场（动作转移场），输出与动作同维度的转移向量（即演化速率）。
  • 演示诱导的目标场构造：将离散演示动作沿演化时间插值得到连续轨迹 γ(τ)，目标场定义为 **F\*(a,τ) = γ̇(τ) + k(γ(τ) − a)；第一项为沿演示轨迹的前进方向，第二项将偏离轨迹的动作拉回演示路径，k** 控制纠正强度。
  • 邻域采样监督：在演示动作附近采样查询动作 a ~ N(γ(τ), σ²I)，使离轨位置也具有明确的演化方向，从而抑制递归推理中的误差累积。
  • 直接监督训练：以 L2 损失直接回归目标场（损失公式为两向量之差的二范数平方的期望），训练过程无需解 ODE、无需对数值积分反向传播，训练效率高。
  • ODE 推理 rollout：推理时以当前动作为初值，用前向欧拉法 a_{n+1} = a_n + Δτ·F_θ(a_n, τ_n \|c) 逐步积分；也可换用龙格-库塔等高阶积分器而不改变已学模型；每次场查询只输出一个 d 维转移向量，相邻动作间具有显式生成依赖；新观测到来时更新条件 c 并从当前动作继续积分。
  • 超参数固定：全实验统一使用 σ = 0.1、k = 5，不做任务或平台特调。

Card 06 评估与结果

评估与结果

  • 评估指标：任务成功率为 SR；轨迹质量指标包括 NLDLJ（时域平滑性）、NSPARC（频域平滑性）、EE-MAJ（末端执行器平均绝对加加速度）与 Boundary Jump（块边界处相邻控制指令的跳变量）；并定义 BDR（边界不连续度降低率） 度量边界连续性改善幅度。
  • LIBERO：平均成功率由 96.85% 提升至 98.25%（+1.40 pp），四个套件全面提升（Long 套件 92.4 → 95.1）；EE-MAJ 相对降低 63.70%。
  • EBench：平均成功率由 15.28% 提升至 24.72%（+9.44 pp，相对提升 61.8%），EE-MAJ 相对降低 79.40%，Frame 任务 30.0 → 48.3、Nut 任务 11.7 → 23.3 提升突出。
  • RoboTwin（50 任务，StarVLA-OFT）：Clean / Random 成功率由 85.7% / 87.3% 提升至 89.4% / 89.8%，NLDLJ 25.96 → 23.89、NSPARC 2.298 → 2.159、EE-MAJ 1.145 → 0.635、Boundary Jump 0.11200 → 0.08710。
  • 与跨块连续性方法对比（5 个 RoboTwin 任务，StarVLA-π）：Base 82.4%、+RTC 81.2%、+Legato 78.0%、+ODEAction 84.4%；RTC 与 Legato 虽降低 Boundary Jump 但成功率下降 1.20/4.40 pp，而 ODEAction 将 Boundary Jump 降至 0.0847（降低 27.3%）的同时成功率最高，并在四项轨迹指标上全部最优。
  • 消融实验：去掉邻域采样（σ=0）成功率降至 47.4%、离线误差 E 由 4.25 升至 8.84；去掉纠正项（k=0）降至 56.2%、误差升至 13.17；完整模型误差累积比 E₂/E₁ = 0.92（两变体为 2.06 与 2.19），说明两项设计共同抑制递归误差增长；Direct Next-Action 仅 78.4%，表明收益并非仅来自“逐动作递归”。
  • 真实机器人：Base 65.00%、+RTC 63.75%、+Legato 66.25%、+ODEAction 80.00%（较 Base +15.00 pp）；EE-MAJ 3.01 → 1.81，Boundary Jump 0.14200 → 0.13100；精细任务增益显著，Place Cup 70.0% → 90.0%（端水不洒），Insert Spoon 25.0% → 55.0%。
  • BDR 与成功率相关性：LIBERO / EBench 平均 BDR 分别为 1.45% 与 13.59%，对应成功率增益 +1.40 与 +9.44 pp；十个评测单元上 BDR 与 SR 增益呈强正相关（Spearman ρ_s = 0.939）。
