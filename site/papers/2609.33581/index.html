Card 02 论文概述

论文概述

  • 论文提出 ForeFly，面向 空中视觉语言导航（AVLN） 的双时域潜在世界动作模型，让无人机在复杂三维环境中依据自然语言指令完成长航程导航。

Card 03 核心贡献

核心贡献

  • 将 AVLN 从反应式动作预测重构为双时域前瞻问题，联合建模近端与路线关键两类潜在未来表示，同时支撑局部运动连续性与长程路线引导。
  • 提出双记忆前瞻查询引导（Dual-Memory Foresight Query Priming）与非对称前瞻引导动作精炼模块（FGAR），用不同历史线索分别驱动两个时域的前瞻查询，并把两类前瞻分别转化为局部动作增强与路线级校正。
  • 在 TravelUAV 与 UAV-ON 两个基准上（seen/unseen 划分）一致超越强基线，在长程轨迹与未见过环境上优势尤为明显。
  • 消融实验验证了双时域前瞻的有效性与互补性。
  • 代码已开源：https://github.com/kunhuiW/ForeFly
Card 04 方法描述

方法描述

  • 问题形式化：在连续三维空间中，依据指令 $\mathcal{I}$、轨迹历史 $\mathcal{P}_{\leq t}$ 与观测历史 $\mathcal{O}_{\leq t}$，联合建模 $p_\theta(Z^p_{t+1}, Z^c_{t+\kappa_t}, a_t \mid C_t)$，动作表示为 4 维向量（归一化三维方向 + 移动幅值）。
  • 双记忆前瞻查询引导：构建近期视觉记忆 $\mathcal{M}_t^p$（最近 R 帧）与路线关键视觉记忆 $\mathcal{M}_t^c$（初始帧 + 基于转弯角阈值 $\tau_p$ 检测的转弯锚点 + 基于行进距离 $\tau_g$ 的覆盖锚点），让可学习的近端/路线关键前瞻查询分别对对应记忆做注意力，得到历史感知查询。
  • 双时域未来潜在预测：多模态大模型统一解码出近端前瞻表示、路线关键前瞻表示与动作表示；不在像素空间重建 RGB，而是用共享投影头在紧凑视觉嵌入空间监督未来表示，只保留导航相关语义布局与场景结构。
  • FGAR（前瞻引导动作精炼）：近端前瞻作为 key/value 对动作表示做注意力以增强局部动作证据；路线关键前瞻则以非对称方式使用——先经注意力得到路线条件上下文，再由 FiLM 生成缩放 $\gamma_t$ 与偏移 $\beta_t$ 对局部表示做特征级校正，同时经 stop-gradient 的并行分支产生加性路线级引导残差，避免该支路成为优化捷径。
  • 训练目标：世界模型损失 $\mathcal{L}_W$（双时域潜在表示与未来观测嵌入的 Frobenius 范数误差）+ 动作损失 $\mathcal{L}_A$（方向 1−余弦相似度 + 幅值绝对误差），总损失 $\mathcal{L}=\mathcal{L}_W+\mathcal{L}_A$；采用两阶段训练（先以 MLP 头替代 FGAR 稳定训练，再恢复 FGAR 联合优化）。
Card 05 数据集与资源

数据集与资源

  • 数据集：TravelUAV（12,149 条轨迹，22 个场景，目标距离 50–400 m）；UAV-ON（14 个高保真室外环境，从紧凑城市公园到开阔山地地形）。
  • 模型结构：语言主干 LLaMA 2-7B，视觉编码器 EVA-ViT-G；近端与路线关键前瞻槽位数均设为 $N_p=N_c=17$。
  • 超参数：转弯角阈值 $\tau_p=20^\circ$，距离间隔 $\tau_g=30$ m；LoRA 微调，学习率 $5\times10^{-5}$。
  • 训练资源：PyTorch 框架，4 块 NVIDIA RTX 5090 GPU。
Card 06 评估与结果

评估与结果

  • 评估基准与指标：TravelUAV（Seen / Unseen，分 Easy <250 m 与 Hard >250 m）与 UAV-ON（Seen / Unseen）；指标为 NE（导航误差，↓）、SR（成功率，↑）、OSR（Oracle 成功率，↑）、SPL（路径长度加权成功率，↑）。
  • TravelUAV Unseen：ForeFly 达 NE 79.80 m / SR 28.86% / OSR 52.87% / SPL 25.19%，相比 SpatialFly 分别降低 NE 8.02 m、提升 SR 3.40、OSR 8.46、SPL 3.43 个百分点；Hard 子集 SR 从 25.71% 升至 31.09%。
  • TravelUAV Seen：ForeFly 达 NE 48.74 m / SR 41.75% / OSR 70.25% / SPL 34.75%，在自主方法中整体最优；相比 SpatialFly，Full 与 Easy 子集 SR 分别提升 3.21 与 4.96 个百分点，Hard 子集 OSR 提升 6.62 个百分点（作为参考，人类操作者 SR 为 94.51%、NE 14.15 m）。
  • UAV-ON：Seen 划分取得 SR 25.13% / OSR 36.30% / SPL 16.31%，分别超越最强对比方法 2.41 / 5.82 / 7.18 个百分点；Unseen 划分 SR 由 17.57% 提升至 22.68%（+5.11），OSR 达 31.44%，SPL 达 14.59%。
  • 消融实验（TravelUAV）：移除全部前瞻的 Baseline 在 Seen 为 NE 103.75 / SR 21.73 / OSR 42.41 / SPL 18.04，Unseen 为 NE 130.60 / SR 11.41 / OSR 31.13 / SPL 10.45；仅用近端前瞻 Unseen 提升至 NE 84.50 / SR 19.25 / OSR 44.25 / SPL 16.91，仅用路线关键前瞻 Seen 达 NE 69.99 / SR 28.25 / OSR 57.25 / SPL 24.19，说明两个时域作用互补、单独使用各有局限。
